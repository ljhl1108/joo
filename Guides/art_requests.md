## R3. 바깥 풍경 소품 (`BG-ST*-SCENERY`)

방 바깥이 평평한 땅 무늬뿐이라 지도처럼 납작해 보인다. 방 둘레에 높이가 있는 풍경을 세워 깊이감을 만드는 그림.

```text
# 요청: 방 바깥을 채우는 풍경 소품 (스테이지 6곳 × 10개)

## 배경
탑다운(위에서 비스듬히 내려다봄) 픽셀아트 게임. 지금 방 바깥은 평평한 땅 무늬만 깔려 있어 지도처럼 납작해 보인다.
방 둘레 바깥에 "높이가 있는" 풍경 소품을 겹겹이 세워 깊이감을 만들려 한다.
소품은 벽 바깥에만 놓이고 캐릭터가 닿지 않는다 (장식 전용). 게임이 방 둘레에 자동으로 흩어 세운다.

## 먼저 읽을 것 (스타일·규격 기준)
C:\workspace\claude\Game_Develop\OnionCat\Art\Final\Backgrounds\
  ST{n}\BG-ST{n}-PROP\  Sprites\PROP_01~05.png + manifest.json  (방 안 소품 — 그림체·외곽선·피벗 규격을 똑같이)
  ST{n}\ST{n}_Assembly.png  (스테이지 분위기)
  BG-VILLAGE\, BG-FARM\  (서 있는 큰 물건의 크기감)

## 만들 것 — 스테이지마다 10개, 새 폴더 ST{n}\BG-ST{n}-SCENERY\
| 묶음 | 개수 | 캔버스(px) | 예 (ST1 해 질 녘 밀밭 기준 — 다른 스테이지는 그 테마로) |
|---|---|---|---|
| 큰 것 | 3 | 192×256 | 큰 나무, 풍차 조각, 건초 창고 모서리 |
| 중간 | 3 | 128×160 | 수레, 건초 더미, 허수아비 |
| 낮고 긴 것 | 2 | 192×96 | 울타리 한 토막(좌우로 나란히 놓으면 이어짐), 밀 이랑 |
| 작은 것 | 2 | 64×96 | 통, 덤불, 표지판 |
스테이지 테마: ST1 해 질 녘 밀밭 · ST2 독안개 늪 · ST3 시든 유리온실 · ST4 서리 과수원 · ST5 등대 오르는 길(바위 절벽·밤) · ST6 별 없는 하늘(검푸른 폐허)

파일: Sprites\SCENERY_01.png ~ SCENERY_10.png (01~03 큰 것, 04~06 중간, 07~08 낮고 긴 것, 09~10 작은 것)
manifest.json: BG-ST{n}-PROP\manifest.json과 같은 형식 (file, canvas, pivot_pixels, bounds). pivot_pixels = 바닥에 닿는 발밑 가운데 (위쪽 원점)
Proof.png: 10개를 발밑 선을 맞춰 한 줄로 세운 그림 + 고양이 크기 비교용 86px 막대

## 반드시 지킬 것
- 시점: 방 안 소품(PROP)과 같은 사선 탑다운. 위에서 본 평면도처럼 그리지 말 것 — 옆면과 높이가 보여야 한다.
- 그림자는 그리지 않는다 (게임이 발밑 그림자를 따로 깐다).
- 배경 투명, 알파는 0 또는 255만. 외곽선 굵기·채도는 PROP과 같게.
- 화면 가장자리에서 일부만 보이거나 서로 겹쳐도 어색하지 않게 (정면을 향한 얼굴·글자처럼 잘리면 이상한 요소 금지).
- 낮고 긴 것 2종은 왼쪽 끝과 오른쪽 끝의 높이·모양이 맞아서 여러 개를 나란히 놓으면 한 줄로 이어질 것.

## 합격 기준 (측정 가능)
- [ ] 6스테이지 × 10개 = 60장, 캔버스 크기가 표와 일치
- [ ] 모든 픽셀의 알파가 0 또는 255, 그림이 캔버스 가장자리에 잘리지 않음
- [ ] manifest의 pivot_pixels가 실제 그림의 바닥 접점(가장 아래 불투명 줄, 좌우 가운데)에서 4px 이내
- [ ] 큰 것은 그림 높이 200px 이상, 중간은 110px 이상 (고양이 86px보다 확실히 큼)
- [ ] 낮고 긴 것을 3개 나란히 붙인 그림을 Proof.png에 포함 — 이음매에서 끊기지 않음

## 하지 말 것
- 기존 폴더의 파일 수정, 캐릭터·적·문 그리기
```

**오면 게임 세션이 할 일**: 방 둘레에 자동으로 세우기 (큰 것은 뒤쪽, 낮은 것은 벽 가까이).
