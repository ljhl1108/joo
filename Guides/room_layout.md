## 2. 고치는 법

- [ ] Project 창 `Assets/Data/RoomLayouts/Layout_Room0N` 선택 → Inspector의 **Map** 글자를 고친다
- [ ] 메뉴 **OnionCat > Rooms > Apply Room Layouts** (플레이 중이 아닐 때)
- [ ] Play해서 확인. 마음에 안 들면 git으로 되돌리거나 Claude에게 "3번 방 더 크게"처럼 말하기

### 글자 규칙 (1글자 = 1칸 = 32px, 지도 크기 최대 40×20)

| 글자 | 뜻 | 성질 |
|---|---|---|
| `W` | 바깥 벽 | 방 테두리. 모양에 맞춰 벽 그림이 자동으로 골라짐 |
| `X` | 안쪽 벽 덩어리 | 방 안으로 튀어나온 벽 → **ㄱ자·십자·통로 모양** 만들기 (가로·세로 2칸 이상 권장) |
| (공백) | 방 바깥 | 아무것도 안 그림 |
| `D` | 출구 | **오른쪽 벽에 1개** |
| `.` | 바닥 | |
| `#` `c` `b` `p` | 돌·상자·통·기둥 | 막힘, 탄 막음, 걷어찬 적 CRASH |
| `o` | 구덩이 | 걸어서 못 지나감, 탄은 통과, **걷어찬 적은 떨어져 즉사** |
| `t` | 덤불 | 장식 (통과 가능) |
| `S` | 고양이 시작 위치 | 꼭 1개 |
| `E` | 적 위치 | 방의 적 목록 순서대로 (개수가 다르면 남는 적은 원래 위치) |
| `P` / `C` | 발판 / 수정 | 쌍둥이 스위치가 있는 방(2번)에서 위치 이동 |

### 지켜야 할 것

- 모든 줄의 길이가 같아야 함 (메뉴 실행 시 틀리면 콘솔에 빨간 에러로 알려줌)
- **출구 앞 왼쪽 4칸 × 위아래 2칸은 비워둘 것** — 보상 표식과 바닥 아이템 자리 (보스방 제외)
- 방은 가로 46칸을 넘지 않게 (방끼리 50칸 간격)
- 구덩이가 직사각형으로 붙어 있으면 한 덩어리 그림으로 합쳐진다
