## 2. 고치는 법

### 글자 규칙 (가로 16 × 세로 8, 1글자 = 1칸)

| 글자 | 뜻 | 성질 |
|---|---|---|
| `.` | 바닥 | |
| `#` | 돌 | 막힘, 탄 막음, 걷어찬 적 CRASH |
| `c` / `b` | 상자 / 통 | 위와 같음 |
| `p` | 기둥 | 위와 같음 (키가 큼) |
| `o` | 구덩이 | 걸어서 못 지나감, 탄은 통과, **걷어찬 적은 떨어져 즉사** |
| `t` | 덤불 | 장식 (통과 가능) |
| `S` | 고양이 시작 위치 | 꼭 1개 |
| `E` | 적 위치 | 방의 적 목록 순서대로 (개수가 다르면 남는 적은 원래 위치) |

### 지켜야 할 것

- 출구는 **오른쪽 벽 4번째 줄**. 출구 앞(오른쪽 3칸 × 2~6번째 줄)은 **보상 표식 자리라 비워둘 것** (보스방 제외)
- 2번 방: 왼쪽 아래 발판(2번째 칸, 8번째 줄)과 위쪽 가운데 수정(9번째 칸, 1~2번째 줄) 자리 비워두기
- 구덩이가 직사각형으로 붙어 있으면 한 덩어리 그림으로 합쳐진다 (ㄱ자 모양은 칸별 그림)
