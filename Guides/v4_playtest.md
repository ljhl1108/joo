# 장비 시스템 v4 플레이 테스트

> 2026-10-10. Claude가 스크립트로 기능은 다 확인했다.
> 확인한 것: 방 순서, 표식 고르기, 상자, 엘리트, 상점 구매·리롤, 효과 갈아끼우기, 저장 → CONTINUE, 보스 클리어 시 저장 삭제.
> **실제 키·패드로 조작해 보고, 재미·속도를 판단하는 것만 사람이 하면 된다.**
> 설계는 `Design/05_Items.md`, 구현 목록은 `Design/00_Implemented.md` 6·8장.

## 1. 한 판 끝까지 (둘이, 또는 혼자 키보드 모드)

- [ ] START RUN. 시작방 → 전투 2번
  - 화면 위에 다음 방 안내("NEXT: BATTLE")가 보이는지
  - 왼쪽 위 씨앗 숫자가 오르는지
- [ ] 세 번째 전투 뒤 출구 옆 표식 **TREASURE / ELITE**를 고른다 (고양이는 밟기, 양파는 클릭)
- [ ] 보물방: 가운데 노란 원(상자)에 닿거나 클릭 → 장비 선택 화면
- [ ] 엘리트: 금빛 큰 적들. 깨면 에픽 장비 선택
- [ ] 전투방에서 가끔 위쪽에 "CAT FOUND: …" 알림이 뜨는지 (장비 드롭, 30%)
- [ ] 상점: 파란 원(가판대) → 상점 화면
  - 구매한다
  - 리롤한다 (리롤할 때마다 가격이 오름)
- [ ] 휴식 정원: 들어가자마자 "RUN SAVED" 알림
  - 초록 원(샘물) → 체력 +40과 효과 갈아끼우기 화면
- [ ] 보스 → Stage Clear

## 2. 장비 화면 조작 (Tab / 패드 Select)

- [ ] 아무 때나 Tab → 두 사람 장비가 나란히 보이고 게임이 멈추는지
  - Tab · Esc · 패드 B로 닫히는지
- [ ] 상점·휴식 정원에서 효과 바꾸기:
  - 고양이: W/S로 줄 이동, A/D로 바꾸기 (패드는 십자키)
  - 양파: 마우스 좌클릭 = 다음, 우클릭 = 이전
  - 바꿀 수 있는 효과는 `< Solar Kick > (1/2)`처럼 표시된다. 분해한 장비가 있어야 생긴다
- [ ] 패드 모드에서 Select 버튼이 다른 동작과 겹치지 않는지

## 3. 이어하기

- [ ] 휴식 정원에서 ESC → MAIN MENU → **CONTINUE**가 맨 위에 생겼는지
  - 누르면 휴식 정원부터 장비·씨앗·체력이 그대로인지
- [ ] 저장이 있을 때 START RUN → "OVERWRITE SAVE?" → 한 번 더 누르면 새 런
- [ ] 죽으면 CONTINUE가 사라지는지
