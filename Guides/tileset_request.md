# 스테이지 배경 요청서

> 2026-11-07 개정 (처음 2026-10-18). 배경은 **한 장짜리 그림이 아니라 여러 겹을 쌓는다** — 방 모양이 글자 지도로 바뀌고 방을 스테이지마다 다시 쓰기 때문.
> 스테이지별 분위기·색·프롬프트는 `Design/Data/stages.csv` (도감 **스테이지** 탭에서 프롬프트 복사), 그림 공통 규칙은 `Design/Data/style.csv`.
> 다 만들면 `Assets/Sprite/Tiles/<스테이지ID>/`에 넣고 알려 주면 연결은 Claude가 한다.

## 공통 규격

- **한 칸 = 32×32 px** (PPU 32, 고정). 화면 640×360 → 가로 20칸 × 세로 11칸
- **시점: 사선 탑다운** (첨부 시안·엔터 더 건전·스타듀 밸리 방식 — 2026-11-07 결정)
  - 방은 **돌리지 않은 네모**. 벽·담은 화면에 **가로·세로로** 뻗는다 (아이소메트릭 마름모 ✗)
  - 위에서 비스듬히 내려다봄 → 벽은 **윗면 + 앞면**이 보인다. 내려다보는 각도는 깊어도 됨 (하데스 같은 깊이감은 각도·조명·그림자로)
  - **아래쪽(앞쪽) 벽은 낮게** — 높으면 캐릭터를 가린다
  - 바닥 위의 원형 예고·장판은 납작하게 그리지 않는다 (게임 판정이 원이라 그림도 원)
- **모든 그림은 같은 픽셀 크기**로 (확대한 큰 픽셀과 작은 픽셀이 섞이지 않게)
- 바닥 대비는 캐릭터보다 **한 단계 낮게** (싸울 때 적·탄이 먼저 보이게). 빨강·노랑 큰 면적은 피하기 (적 공격 예고 색)
- AI 그림이 칸에 딱 맞지 않아도 괜찮다 — 큰 그림으로 줘도 Claude가 잘라서 칸에 맞춘다

## 겹 구조 (전투방)

```
⑥ 분위기    빛 · 안개 · 날리는 이삭               ← Claude (조명·파티클) — 그림 거의 없음
⑤ 소품      수레 · 상자 · 물뿌리개 · 등불 기둥     ← 하나씩 배치, 발 높이로 앞뒤 정렬
④ 벽·담     돌담 · 울타리 · 출구 문                ← 타일, 충돌 있음 (글자 지도 W·X 자리에 자동)
③ 바닥 장식 꽃 · 돌멩이 · 흙 얼룩 · 낙엽            ← 방에 들어갈 때마다 무작위로 흩뿌림 ✅ 코드 준비됨
② 바닥      잔디 · 흙길                            ← 이어지는 타일
① 방 바깥   방을 둘러싼 밀밭 · 덤불 · 어둠          ← 채우기 타일 (지금은 빈 파란 화면)
```

## 스테이지마다 필요한 것

### ② 바닥 + ④ 벽 — 타일 시트 `Tiles_<ID>.png` (가로 8칸, 32px 격자)

```
열→   0        1        2        3        4        5        6        7
행0  바닥     바닥2    바닥3    바닥4    (비움)   (비움)   특수1    특수2     ← 바닥 변형 4장 (특수 = 물·빙판 등)
행1  벽┌     벽─위    벽┐      벽─위2   안쪽┘    안쪽└                       ← 바깥 벽 윗줄 (앞면이 보임)
행2  벽│왼   (비움)   벽│오            안쪽┐    안쪽┌                       ← 바깥 벽 옆
행3  벽└     벽─아래  벽┘                                                  ← 바깥 벽 아랫줄 (낮게 — 얇은 윗면만)
행4  덩어리 윗테 왼·가운데·오른   (비움)   구덩이┌  구덩이─  구덩이┐
행5  덩어리 몸통 왼·(비움)·오른   (비움)   구덩이│  구덩이■  구덩이│
행6  덩어리 앞면 왼·가운데·오른   (비움)   구덩이└  구덩이─  구덩이┘
행7  덩어리 밑단 왼·가운데·오른
```

- 바닥은 **이어 붙여도 이음새가 안 보이게** (seamless). 반복 티는 ③ 장식이 덮어 준다 → 바닥 자체는 차분하게
- **바깥 벽**: 방 둘레. "안쪽" 4장은 ㄱ자 방처럼 꺾인 곳
- **덩어리**(방 안의 솟은 벽 `X`): 가로세로로 늘릴 수 있게 9칸 + 앞면 줄
- **구덩이**: 가장자리 8 + 가운데 1
- (예전 시트의 "장식1·2" 칸은 ③으로 옮김)

### ③ 바닥 장식 — 따로 PNG 10~20개 (각 **16×16 이하**, 큰 것도 32×32까지)
- 꽃·돌멩이·흙 얼룩·낙엽·금 간 자리·작은 웅덩이 등 **납작한 것만** — 높이가 있어 보이면 장애물로 착각한다 (판정 없음)
- 같은 종류도 2~3가지 변형이 있으면 덜 반복돼 보인다
- 지금은 Cainos 풀·꽃·작은 돌멩이 임시 (`Assets/Resources/StageDecor.asset` — 그림이 오면 스테이지별 칸에 넣음)

### ① 방 바깥 채우기 — 타일 4~6장
- 방 둘레 바깥을 채우는 땅 (밀밭 → 이삭 덤불, 늪 → 검은 물, 탑 → 어둠). 걸어 들어갈 수 없는 곳이라 **어둡고 덜 자세하게**
- 이어 붙여도 이음새 없게 2~3장 + 방 벽에 닿는 가장자리 1~2장
- 코드는 그림이 오면 Claude가 연결 (지금은 빈 화면)

### ⑤ 소품 (장애물) — 각각 따로 PNG, 32×32 또는 32×64
`stages.csv` "장애물·소품" 열 — 스테이지마다 4~5개. **바닥에 닿는 부분이 1칸으로 보이게**

### 문 `Door_<ID>.png` — 64×64 두 장 (닫힘 / 열림)

## 고정 장소 = 큰 그림 (선택)

모양이 바뀌지 않는 곳은 **한 장(또는 큰 조각 몇 장)으로 그려도 된다** — 한 번만 그리면 되고 이야기 장면이라 효과가 크다. 충돌은 Claude가 그림 위에 맞춘다.
- 언덕 위 농장 (시작) · 마을 · 등대탑 · 최종 장소
- 크기는 방 하나 (최대 40×20칸 = 1280×640px). 서 있는 물체(나무·집·등대)는 앞뒤 정렬 때문에 **따로 떼어** 주면 좋다
