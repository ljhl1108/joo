# 스테이지 타일셋 요청서

> 2026-10-18. 스테이지별 분위기·색·프롬프트는 `Design/Data/stages.csv` (도감의 **스테이지** 탭에서 프롬프트 복사).
> 그림 공통 규칙(프롬프트 앞부분)은 `Design/Data/style.csv`. 다 만들면 `Assets/Sprite/Tiles/<스테이지ID>/`에 넣고 알려 주면 연결은 Claude가 한다.

## 공통 규격

- **한 칸 = 32×32 px** (게임 1칸 = 1유닛, PPU 32). 화면은 640×360 → 가로 20칸 × 세로 11칸이 한 화면
- 시점: **위에서 비스듬히 (3/4 탑다운)** — 벽은 윗면 + 앞면(벽돌면)이 보인다. 지금 Cainos 타일과 같은 시점
- 바닥은 **이어 붙여도 이음새가 안 보이게** (seamless). 같은 바닥이 반복돼 보이지 않게 변형 3장
- 색: 스테이지 주색·보조색(`stages.csv`). **빨강·노랑 큰 면적은 피하기** (적 공격 예고 색)
- AI 그림이 칸에 딱 맞지 않아도 괜찮다 — **큰 그림(예: 바닥 128×128, 벽 한 덩어리)으로 줘도 Claude가 잘라서 칸에 맞춘다**

## 스테이지마다 필요한 것 (최소)

### 1. 타일 시트 `Tiles_<ID>.png` (가로 8칸, 32px 격자)

```
열→   0        1        2        3        4        5        6        7
행0  바닥     바닥2    바닥3    바닥4    장식1    장식2    특수1    특수2     ← 바닥 (장식 = 꽃·금 간 곳, 특수 = 물·빙판 등)
행1  벽┌     벽─위    벽┐      벽─위2   안쪽┘    안쪽└                       ← 바깥 벽 윗줄 (벽돌 면이 보임)
행2  벽│왼   (비움)   벽│오            안쪽┐    안쪽┌                       ← 바깥 벽 옆
행3  벽└     벽─아래  벽┘                                                  ← 바깥 벽 아랫줄 (얇은 윗면만)
행4  덩어리 윗테 왼·가운데·오른   (비움)   구덩이┌  구덩이─  구덩이┐
행5  덩어리 몸통 왼·(비움)·오른   (비움)   구덩이│  구덩이■  구덩이│
행6  덩어리 앞면 왼·가운데·오른   (비움)   구덩이└  구덩이─  구덩이┘
행7  덩어리 밑단 왼·가운데·오른
```

- **바깥 벽**: 방 둘레. "안쪽" 4장은 ㄱ자 방처럼 꺾인 곳 (오목한 모서리)
- **덩어리**(방 안의 솟은 벽 `X`): 가로세로로 늘릴 수 있게 9칸 짜기 + 앞면 줄
- **구덩이**: 떨어지면 죽는 구멍. 가장자리 8 + 가운데 1

### 2. 문 `Door_<ID>.png` — 64×64 두 장 (닫힘 / 열림)

### 3. 소품 (장애물) — 각각 따로 PNG, 32×32 또는 32×64
`stages.csv`의 "장애물·소품" 열 — 스테이지마다 4~5개. 장애물은 바닥에 닿는 부분이 1칸으로 보이게

### 4. (선택) 특수 지형
`stages.csv`의 "특수 지형" — 물·빙판·독 웅덩이 등. 바닥처럼 seamless 1장 + 가장자리는 없어도 됨
