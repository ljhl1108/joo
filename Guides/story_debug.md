# 이야기 진행 디버그 방법 (2026-10-29)

판 전체(농장 → 스테이지 → 마을 → … → 엔딩)를 빨리 확인하는 방법.
메뉴는 전부 유니티 위쪽 메뉴 막대의 **OnionCat > Debug**에 있다.

---

## 1. 진행(이야기 단계) 바꾸기 — 플레이 전에

| 메뉴 | 하는 일 |
|---|---|
| `Story > Chapter 1 (To Village)` | 이번 판이 **마을**에서 끝남 (농장 → 1 → 2 → 마을) — 가장 짧음 |
| `Story > Chapter 2 (To Lighthouse Gate)` | **등대 입구**에서 끝남 (스테이지 4개) |
| `Story > Chapter 3 (To Lighthouse Tower)` | **등대탑**에서 끝남 (스테이지 5개) |
| `Story > Chapter 4 (Final)` | **최종 스테이지 → 엔딩**까지 (스테이지 6개) |
| `Story > Reset Lanterns` | 마을·등대 입구 등불에 쌓인 빛과 등대탑 작물 기록을 지움 |
| `Story > Log Progress` | 지금 진행을 Console 창에 한 줄로 (단계·등불 빛·작물·엔딩 수·파편·목표) |

⚠️ 이 메뉴들은 **진짜 진행(meta.json)을 바꾼다.** 확인이 끝나면 원래 단계로 돌려놓을 것.
지금 진행: **2단계** (마을 등불은 빨간빛으로 켜 둔 상태).
`Log Progress`로 먼저 적어 두면 돌려놓기 쉽다.

## 2. 플레이 중 빨리 넘기기

| 메뉴 | 하는 일 |
|---|---|
| `Story > Skip To Next Place (Play)` | 지금 자리를 건너뛰고 **길의 다음 자리로** (스테이지 → 다음 마을/스테이지). 보스를 안 잡고 넘어가므로 보스 보상·파편은 없음 |
| `Run > Jump To Boss` | 이 스테이지의 **보스방으로** 바로 |
| `Kill All Enemies In Room` | 방의 적을 전부 쓰러뜨림 (보스 포함 → 보스 보상까지 확인할 때) |
| `Toggle Cat Invincible` | 고양이 무적 켜기/끄기 |
| `Give 100 Seeds` | 씨앗 +100 (마을 가판대 확인용) |
| `Run > Greenhouse: +5 Fragments` | 기억 파편 +5 (농장 온실 해금 확인용) |

**빠른 흐름 예**: Chapter 1 → 플레이 → 농장 둘러보기 → `Skip` → `Jump To Boss` → `Kill All Enemies` → 보상 고르기 → 출구 → … → 마을 등불 밟기 → "마을에 도착했다!" 화면

## 3. 빛 섞기 확인

작물이 아직 양파(빨강)뿐이라 보통은 **어떤 빛이든 등불이 켜진다.**
섞기를 보려면 작물의 빛을 바꿔서 원래 요구(마을 노랑 · 등대 입구 초록 = 노랑+파랑)로 확인한다.

| 메뉴 | 하는 일 |
|---|---|
| `Story > Crop Light - Red / Yellow / Blue` | 이번 작물이 내는 빛을 바꿈 (켜 두는 동안은 원래 요구대로 검사) |
| `Story > Crop Light - Normal` | 원래대로 (양파 빨강) |

- [ ] Chapter 2 + `Reset Lanterns` + Crop Light **Yellow** → 등대 입구 등불: "초록빛이 필요하다" (안 켜짐)
- [ ] 다음 판 Crop Light **Blue** → 등대 입구 등불: 노랑+파랑 = **초록빛**, "등불이 켜졌다!" → 3단계
- [ ] 끝나면 `Crop Light - Normal` (에디터를 껐다 켜도 Normal로 돌아감)

## 4. 확인할 것 (농장 · 마을)

- [ ] **농장**: 판을 시작하면 "언덕 위 농장"에서 출발 (전투 없음)
  - [ ] 처음 한 번: 낡은 책이 말풍선으로 먼저 말을 건다 (새벽이 "…냥?") → 끝나면 목표 배너. 클릭·Enter로 넘기기, 가만히 두면 저절로 넘어감
  - [ ] 그다음부터: 책을 밟거나 클릭하면 이야기 단계에 맞는 말 + 오늘 할 일 (4단계·엔딩 뒤엔 이름표가 "그리모")
  - [ ] 첫 대사를 다시 보려면: 에디터를 끈 상태에서 meta.json의 `"introSeen":true`를 지운다
  - [ ] 온실 → 온실 화면 (파편으로 해금). Esc로 닫으면 바로 다시 움직일 수 있고 일시정지 메뉴가 같이 뜨지 않음
  - [ ] 화분 → 오늘의 작물과 빛 색
  - [ ] 출구 → 1스테이지 "해 질 녘 밀밭"
- [ ] **책장**: 기억 파편을 모은 만큼(1·3·5·8개) 책이 찢어진 책장을 하나씩 읽어 준다 (책을 밟을 때마다 한 장)
- [ ] **지나가는 마을**: 등불 · 샘물(한 번) · 가판대 · **마을 사람**(등대 입구는 등대지기) — 이야기 단계마다 다른 목격담. 들어오면 저장
- [ ] **등대탑 반전 (3단계)**: `Chapter 3` → `Skip`으로 등대탑까지 → 들어서면 바로 반전 장면 (그림자 "탑의 마녀" → "마녀", 책 이름표 "낡은 책" → "그리모") → **마녀의 부탁**: 등불에 작물의 빛을 모아 줘
  - [ ] 그 판에 등불을 밟으면 작물 하나가 모임 → "등대탑에 빛을 모으는 중" 화면. 다음 판엔 다른 작물로 → 다 모이면 4단계(최종)
- [ ] **작물 고르기**: 농장 화분을 밟을 때마다 양파 → 해바라기(2단계부터) → 푸른 버섯(3단계부터). 푸른 버섯 = 파란 느린 탄(맞으면 독) · 4번(R) 버섯 3개 — 적이 다가오면 포자. 해바라기 = 노란 빠른 탄 · 4번(R) 햇빛 기둥 안에 있으면 체력 회복 · 싸움 방마다 씨앗 +3
- [ ] **판이 끝나는 마을**: 등불을 밟으면 3초쯤 뒤 "○○에 도착했다!" 화면 + 다음 목표

## 문제가 생기면

- Console 창(Window > General > Console)에 빨간 글이 있으면 그대로 알려 주기
- `[DungeonManager] … 지도:` 로그 한 줄이 자리마다 찍힌다 — 어느 자리에서 멈췄는지 알 수 있음
