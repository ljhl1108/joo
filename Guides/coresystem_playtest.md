# 코어 시스템 1차 — 플레이 테스트 가이드

> 2026-10-03 구현 · 설계는 `Design/07_CoreSystem.md` 8장 1~7단계.
> 코드·프리팹·씬 연결과 기본 동작은 Claude가 플레이 모드에서 검증 완료 (스크립트 호출).
> **실제 키보드·패드·마우스로 조작했을 때의 느낌과 재미는 사람만 판단할 수 있다** → 이 문서가 그 체크리스트.

---

## 0. 시작하기

- [ ] Unity에서 Play → 메인메뉴 → Start
- [ ] 오른쪽 위 작은 글씨로 **입력 모드**가 표시된다
  - `P1 GAMEPAD | P2 KEYBOARD + MOUSE` → 패드 모드 (패드가 연결됨)
  - `KEYBOARD MODE (no pad)` → 키보드 모드 (패드 없음)
  - 플레이 중에 패드를 꽂거나 빼도 자동으로 바뀜

## 1. 조작표

### 패드 모드 (기본 구성: 고양이 = 패드, 양파 = 키보드+마우스)

| 고양이 (패드) | | 양파 (키보드+마우스) | |
|---|---|---|---|
| 이동 | 왼스틱 | 조준 | 마우스 |
| 할퀴기 | X | 씨앗 발사 | 좌클릭 |
| 걷어차기 | Y | 실드 | 우클릭 |
| 털뭉치 던지기 | B (오른스틱으로 조준, 안 기울이면 가까운 적) | 획득 스킬 1·2·3 | Q · W · E |
| 대쉬 | A | 작물 고유기 (매운 양파) | R |
| 합동기 | RB | 아이템 사용 | 1 ~ 5 |
| 아이템 줍기/사용 | 십자키 ↑ | 아이템 건네기 | Shift + 1 ~ 5 |
| 아이템 선택 | 십자키 ←→ | 합동기 | Space |
| 아이템 건네기 | 십자키 ↓ | 바닥 아이템·보상 표식 고르기 | 좌클릭 |

### 키보드 모드 (패드 없음 — 한 키보드를 나눠 쓰거나 혼자 테스트)

| 고양이 (키보드 왼쪽) | | 양파 (마우스 + 숫자) | |
|---|---|---|---|
| 이동 / 대쉬 / 할퀴기 | WASD / Space / F | 스킬 1·2·3 / 고유기 | 1 · 2 · 3 / 4 |
| 걷어차기 / 던지기 | G / H | 아이템 사용 | 6 ~ 0 |
| 합동기 | T | 아이템 건네기 | Shift + 6 ~ 0 |
| 가방 사용·줍기 / 선택 / 건네기 | Z / X / C | 합동기 | 마우스 휠 클릭 |

> 키보드 모드에서 양파 스킬이 Q·W·E가 아닌 이유: W가 고양이 이동과 겹치기 때문.

## 2. 테스트 체크리스트

### ① 걷어차기 + 터지는 박 — **이번 테스트의 핵심 질문**

시작 보상은 고양이 축복이라, 박 스킬은 2번째 보상(문 앞 표식에서 **CROP SKILL** 선택)에서 얻는다.
1번 방에서 바로 시험하려면 아래 "빠른 테스트" 참고.

- [ ] 양파가 박을 심는다 (스킬 키 → 커서 위치에 심김, 0.4초 뒤 다 자람)
- [ ] 고양이가 적을 박 쪽으로 걷어찬다 → 적이 박에 닿으면 폭발 + **KICK COMBO!**
- [ ] 고양이가 박을 직접 할퀴어도 터진다
- [ ] 걷어찬 적이 벽이나 다른 적에 부딪히면 **CRASH!** 추가 피해
- [ ] **판단**: 박에 적을 차 넣는 게 재미있는가? 노린 대로 들어가는가?
  - 재미있으면 → 정원사형(B) 방향 확정
  - 양파가 "심고 기다리는 게 지루하다"면 → 사격 비중을 올리거나 공명형(C) 쪽으로

### ② 양파 스킬

- [ ] 오른쪽 아래 스킬 4칸에 이름·레벨·쿨다운(어두운 막대)이 보인다
- [ ] 4번 칸(R / 4) = **매운 양파**: 심으면 분홍 원 안의 적이 느려진다
- [ ] 같은 스킬 카드를 다시 고르면 **Lv2** (카드에 "Level up Lv1 > Lv2" 표시)
- [ ] 3칸이 다 찼을 때 새 스킬 카드에 "Replaces ..." 표시 → 가장 낮은 레벨 스킬과 교체
- [ ] 스킬 4종 체감: Exploding Gourd(심기) / Seed Burst(산탄) / Nourish(회복) / Spore Cloud(기절)
- [ ] **판단**: 양파 조작(마우스 + 스킬 키)이 바쁘고 재미있는가, 아니면 복잡한가?

### ③ 고양이 축복 (하데스식)

- [ ] 왼쪽 아래 4칸(ATK / SPC / THR / DSH)에 받은 축복이 표시된다
- [ ] Sun Claw: 할퀴면 적이 불탄다 (주황 숫자가 0.5초마다)
- [ ] Blazing Dash: 대쉬 자리에 불꽃이 남는다
- [ ] Ember Hairball: 털뭉치가 맞으면 폭발
- [ ] Gale Hairballs (바람): 털뭉치 3개 → **둘 다 원거리 빌드**가 가능한지
- [ ] 같은 칸의 축복 카드에 "Replaces ..." 표시 → 교체됨

### ④ 털뭉치 던지기

- [ ] 던지면 적이 느려지고, 털뭉치는 그 자리에 떨어진다
- [ ] 고양이가 지나가면 다시 주워진다 (안 주워도 4초 뒤 자동 회수)
- [ ] 왼쪽 아래 `HAIRBALL n/n` 숫자가 맞게 바뀐다

### ⑤ 합동기

- [ ] 왼쪽 위 파란 게이지(JOINT %)가 **번갈아 때릴 때(COMBO)·박 연계·패링·기믹 성공** 시 찬다
- [ ] 가득 차면 화면 아래 "JOINT READY" 안내
- [ ] 한 명만 누르면 "P1 READY - P2 PRESS ..." 안내가 뜨고, 1.5초 안에 상대가 누르면 **ONION STORM**
- [ ] 늦게 눌러도 게이지는 사라지지 않는다
- [ ] **판단**: 둘이 동시에 누르는 맛이 있는가? 1.5초가 적당한가?

### ⑥ 각자의 가방

- [ ] 시작 아이템: 고양이 = 회복 열매(BERRY) / 양파 = 캣닢(NIP, **고양이 전용**) + 물뿌리개(WATER, 양파 전용)
- [ ] 양파가 캣닢을 쓰려 하면 "GIVE TO CAT!" → **Shift+숫자로 건네기** → 0.5초 뒤 고양이 가방으로
- [ ] 고양이가 캣닢 사용 → 8초간 빨라지고 할퀴기 강화 (상태 표시 `CATNIP 8s`)
- [ ] 물뿌리개 → 양파 스킬 쿨다운 전부 초기화
- [ ] 방 클리어 후 아이템이 떨어지면(60%) **먼저 줍는 사람** 가방으로 (고양이 = 위에 서서 줍기 키 / 양파 = 클릭)
- [ ] **판단**: 주고받기가 대화를 만드는가, 귀찮기만 한가?

### ⑦ 보상 문 (하데스식)

- [ ] 화면 위에 `ROOM REWARD: CAT BLESSING` 같은 이번 방 보상이 보인다
- [ ] 방을 깨면 그 종류의 카드 (축복 / 스킬 / 업그레이드)
- [ ] 카드를 고르면 출구 앞에 **표식 2개** → 고양이가 밟거나 양파가 클릭해서 다음 방 보상 선택
- [ ] 방금 고양이 보상을 받았으면 후보에 양파 보상(CROP SKILL)이 꼭 있다 (반대도 마찬가지)
- [ ] **판단**: 문 앞에서 "어디로 갈까" 상의하게 되는가?

### ⑧ 2인 기믹 — 쌍둥이 스위치 (2번 방)

- [ ] 왼쪽 아래 발판 `CAT: STAND HERE`, 위쪽 수정 `ONION: SHOOT ME`
- [ ] 고양이가 발판 위에 있는 동안 양파가 수정을 쏘면 → **TEAMWORK!** + 아이템 2개 + 게이지
- [ ] 수정은 맞고 2.5초만 켜져 있음 (꺼지기 직전 깜빡임)

## 3. 빠른 테스트 — 메뉴 `OnionCat > Debug` (플레이 중에만 활성)

보상 문을 기다리지 않고 바로 시험할 때:

| 메뉴 | 효과 |
|---|---|
| Give Exploding Gourd (Skill) | 박 스킬 바로 획득 → ① 걷어차기 테스트 |
| Give All Crop Skills | 스킬 4종 (3칸이라 마지막 하나는 교체됨) |
| Give All Sun Blessings | 햇살 축복 4종 (공격·특수·던지기·대쉬) |
| Give Gale Hairballs (Ranged Build) | 털뭉치 3개 (던지기 칸 교체) |
| Fill Joint Gauge | 합동 게이지 가득 → ⑤ 합동기 테스트 |
| Kill All Enemies In Room | 방 즉시 클리어 → ⑦ 보상 문 테스트 |
| Toggle Cat Invincible | 고양이 무적 켜기/끄기 |

## 4. 아직 안 만든 것 (설계 문서에는 있음)

- 비료 (스킬 변형) · 듀오 축복 · 정령 빗물/흙 · 합동기 종류(지금은 ONION STORM 1종)
- 패드로 하는 양파 (오른스틱 조준) — 지금 양파는 마우스 전용
- 적의 빨간 공격으로 식물이 부서지는 규칙
- 작물 선택 (당근·마늘·부추) · 런 간 성장 (온실·유대)
- 모든 그림은 임시 (원·사각형). 아트가 정해지면 교체
