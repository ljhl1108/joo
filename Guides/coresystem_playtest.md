## 0. 시작하기

- [ ] Unity에서 Play → 메인메뉴 → Start
- [ ] 오른쪽 위 작은 글씨로 **입력 모드** 표시
  - `P1 GAMEPAD | P2 KEYBOARD + MOUSE` → 패드 모드 / `KEYBOARD MODE (no pad)` → 키보드 모드
  - 플레이 중 패드를 꽂거나 빼면 자동 전환

## 1. 조작표

### 키보드 모드 (패드 없음 — 혼자 테스트)

| 고양이 (키보드 왼쪽) | | 양파 (마우스 + 숫자) | |
|---|---|---|---|
| 이동 / 대쉬 | WASD / Space | 조준 · 발사 · 실드 | 마우스 · 좌클릭 · 우클릭 |
| **할퀴기** | **왼쪽 Shift** | 스킬 1·2·3 / 고유기(매운 양파) | 1 · 2 · 3 / 4 |
| **걷어차기** | **왼쪽 Ctrl** | 공유 가방 칸 사용 | 6 ~ 0 |
| 털뭉치 던지기 | Q | 합동기 | 마우스 휠 클릭 |
| 합동기 | E | 바닥 아이템·보상 표식 고르기 | 좌클릭 |
| 공유 가방 사용 / 칸 선택 | Z / X | | |

### 패드 모드 (고양이 = 패드, 양파 = 키보드+마우스)

| 고양이 (패드) | | 양파 (키보드+마우스) | |
|---|---|---|---|
| 이동 / 대쉬 | 왼스틱 / A | 스킬 1·2·3 / 고유기 | Q · W · E / R |
| 할퀴기 / 걷어차기 | X / Y | 공유 가방 칸 사용 | 1 ~ 5 |
| 털뭉치 (오른스틱 조준) | B | 합동기 | Space |

| 가방 사용 / 칸 선택 | 십자키 ↑ / ←→ | | |

> ⚠️ 키보드 모드에서 Ctrl을 W·A·S·D와 같이 누르면 유니티 에디터 단축키(Ctrl+S 등)가 먹을 수 있다.
> 문제가 되면 알려주기 → 걷어차기를 다른 키로 바꿈.

## 2. 테스트 메뉴 — 유니티 위쪽 메뉴바 `OnionCat > Debug`

**플레이 중(Start로 런을 시작한 뒤)에만 켜진다.** 플레이 전에는 회색.
유니티 창 맨 위 메뉴바(File · Edit · Assets · … 옆)에 `OnionCat`이 있다 → `Debug` → 항목 클릭.
클릭한 뒤에는 **Game 창을 한 번 클릭**해야 키 입력이 다시 게임으로 간다.

| 메뉴 | 효과 |
|---|---|
| **Kick Test: Give Gourd + Plant Behind Enemy** | 박 스킬 지급 + **가장 가까운 적 뒤에 박을 심고 3초 기절** → 다가가서 Ctrl로 걷어차기 |
| Give Exploding Gourd (Skill) | 박 스킬만 지급 (1번 칸, 키보드 모드 키 1) |
| Give All Crop Skills | 양파 스킬 4종 (3칸이라 하나는 교체됨) |
| Give Sun Set (4 pieces) | 햇살 세트 4개 → 화상 +1, 화상 폭발 |
| Give Wind Set (4 pieces) | 바람 세트 4개 → 대쉬 3칸, 걷어차기 강화 |
| Claw: Whirl / Leaping / Triple / Frenzy | 할퀴기 변형 바로 적용 |
| Fill Joint Gauge | 합동 게이지 가득 |
| Kill All Enemies In Room | 방 즉시 클리어 → 보상 화면 |
| Toggle Cat Invincible | 고양이 무적 켜기/끄기 |

## 3. 테스트 체크리스트

### ① 걷어차기 + 터지는 박 (핵심 질문)

> 박 = 양파의 **Exploding Gourd** 스킬 (획득 스킬 1번 칸). R/4번의 **Spicy Onion(매운 양파)**은 적을 느리게 하는 다른 식물.

- [ ] 메뉴 **Kick Test** → 적 뒤에 박이 생기고 적이 3초 멈춤 → 적에게 붙어서 **Ctrl**
- [ ] 적이 날아가 박에 닿으면 폭발 + **KICK COMBO!** (게이지 +15)
- [ ] 박 방향에서 조금 비껴 차도 박 쪽으로 휘어 들어간다 (35° 보정)
- [ ] 공격 예고(빨갛게 깜빡임) 중인 적을 차면 **INTERRUPT!** → 예고가 끊기고 날아간다
- [ ] 직접 해보기: 박 스킬 키(1) → 커서 위치에 심김 → 적을 그쪽으로 차기
- [ ] **판단**: 박에 적을 차 넣는 게 재미있는가?

### ② 보상 — 동시 선택 + 다음 방 중점 축

- [ ] 방을 깨면 **왼쪽 고양이 3장 / 오른쪽 양파 3장** → 각자 1장씩 동시에 (고양이 A·D + Shift, 양파 클릭)
- [ ] 카드 위 색: **빨강 POWER(체급) / 파랑 PASSIVE(세트) / 보라 SPECIAL(스킬·할퀴기 변형)**
- [ ] 출구 앞 표식 2개 = 다음 방 중점 축 → 고른 축 카드가 다음 방에서 **2장씩 보장**
- [ ] **판단**: 둘 다 매번 받으니 지루함이 줄었는가? 성장 속도는 적당한가?

### ③ 패시브 세트

- [ ] 오른쪽 아래 `PASSIVE SETS` — 햇살·바람 진행도(#=모은 조각)와 다음 보너스
- [ ] 패시브 카드에 `SUN SET 1 > 2/4` 처럼 진행도, 보너스가 켜지는 카드는 보너스 이름 표시
- [ ] 고양이 조각 + 양파 조각이 **합산**된다 (예: 고양이 Sun Claw + 양파 Sun Seeds = 햇살 2 → 화상 +1)
- [ ] **판단**: "같은 세트 모으자"는 대화가 생기는가?

### ④ 할퀴기 변형 (고양이 특수)

- [ ] 왼쪽 아래 `CLAW: ...`에 현재 변형
- [ ] Whirl(회전) / Leaping(뛰어들기) / Triple(3타째 강타+날림) / Frenzy(빠르게)
- [ ] **판단**: 기본 공격이 바뀌는 느낌이 확실한가?

### ⑤ 대쉬 탄창

- [ ] 고양이 발밑 흰 막대 = 대쉬 남은 횟수 (기본 2칸, 0.9초마다 1칸 차오름), 아래 갈색 = 털뭉치
- [ ] 바람 세트 2개면 대쉬 3칸
- [ ] **판단**: 2칸 / 0.9초가 적당한가?

### ⑥ 공유 가방

- [ ] 가운데 아래 스킬 위 5칸. 시작: BERRY(회복) · NIP(캣닢) · WATER(물뿌리개)
- [ ] 양파는 숫자키(6~0)로 그 칸을 바로 사용, 고양이는 X로 칸 고르고(주황 테두리) Z로 사용
- [ ] 바닥 아이템은 고양이가 지나가면 자동으로 주움

### ⑨ 일시정지 메뉴 (ESC / 패드 Start)

- [ ] RESUME · SETTINGS(음량·화면 흔들림·전체화면) · CONTROLS(조작표) · RESTART RUN · MAIN MENU · QUIT GAME
- [ ] ESC를 다시 누르면 한 단계 뒤로, MAIN MENU·QUIT은 두 번 눌러야 실행
- [ ] 패드 십자키 + A, 키보드 화살표 + Enter, 마우스 클릭 모두 동작

### ⑦ 합동기 · ⑧ 쌍둥이 스위치 (2번 방) — 1차와 동일

- [ ] 게이지가 차면 고양이 **E** + 양파 **휠 클릭**을 1.5초 안에 → ONION STORM
- [ ] 2번 방: 고양이가 발판 위에 있는 동안 양파가 수정을 쏘면 TEAMWORK!
