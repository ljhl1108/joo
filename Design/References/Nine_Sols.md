## 핵심 시스템

### 1. 패리(Deflect) 시스템 — Sekiro 스타일 완성형
- 거의 모든 적 공격을 **타이밍 맞는 패리**로 막을 수 있음
- 패리 창(window): 약 0.15초 — 좁지만 시각적 전조(붉은 빛, 경고음)로 보조
- 패리 성공 시: **태극 태그(Talisman Tag)** 즉시 부착 → 이후 아무 공격으로 폭발 가능
- 패리 실패 시: 큰 데미지 (방어 자체가 없음 — 막거나 피하거나)
- **투사체도 패리 가능**: 원거리 공격을 튕겨서 되돌릴 수 있음

### 2. 태극 태그 & 폭발 콤보 (Tag & Detonate)
- 공격 또는 패리로 적에게 태그를 붙임
- 태그 최대 3개 누적 가능
- `Charged Strike` 또는 특정 기술로 태그 전부 동시 폭발 → 폭발 데미지 = 태그 수 × 배율
- 전투의 리듬: "태그 붙이기 → 패리 타이밍 맞추기 → 폭발"의 3박자

### 3. 보스 디자인 — 전조 시스템의 교과서
- 각 보스는 **고유 전조 방식** 보유: 색 변화, 사운드, 특정 자세
- 공격 전 반드시 0.3~0.8초의 예고 시간 존재
- 패리 타이밍을 가르쳐주는 튜토리얼형 첫 조우 디자인 (데미지 낮은 첫 공격으로 학습 유도)
- "억울한 죽음" 없음 원칙 — 모든 즉사 공격은 명확한 긴 전조

### 4. 태도 게이지 (Tao Technique Gauge)
- 패리 성공, 적 처치 시 게이지 충전
- 다양한 태도 기술로 소모: 돌진, 분신, 회복 등
- 게이지 관리가 심화 플레이의 핵심

### 5. 시각/사운드 피드백 설계
- 패리 성공: 금속성 타격음 + 흰빛 번쩍임 + 히트스톱 0.05초
- 태그 폭발: 붉은 폭발 + 카메라 셰이크 + 느린 슬로우 모션
- 적의 공격 예고: 붉은 이펙트가 공격 범위를 미리 표시

## OnionCat 적용 포인트

| Nine Sols 메카닉 | OnionCat 적용 |
|---|---|
| 투사체 패리 & 반사 | **Onion 방패 패리**의 핵심 기능 — 투사체를 튕겨 적에게 반사 |
| 태그 & 폭발 콤보 | Onion이 패리 시 Cat에게 "태그 마크" 부여 → Cat이 슬래시 시 폭발 콤보로 발전 가능 |
| 전조 필수화 원칙 | OnionCat 적 설계: 모든 공격에 0.3초 이상 시각적 전조 의무화 |
| 좁은 패리 창 + 시각 보조 | OnionCat 패리 창 0.1~0.15초 + 방향에 따라 방패 이펙트 색 변화로 타이밍 알림 |
| 패리 실패 시 큰 페널티 | 방패 방향이 틀리면 데미지 2배 받는 구조 → 방향 선택이 긴장감 생성 |
| 히트스톱 + 슬로우 | 강한 패리 성공 시 0.05~0.08초 히트스톱 구현으로 타격감 극대화 |

### 가장 중요한 인사이트: "패리의 보상 구조"
Nine Sols의 패리가 재미있는 이유:
1. **위험 → 보상**: 패리는 위험하지만 성공 시 강력한 콤보 기회 제공
2. **학습 곡선**: 전조를 읽는 법 → 타이밍 맞추는 법 → 태그 콤보 극대화 순으로 자연스럽게 심화
3. **협력 가능성**: OnionCat에서 Onion이 패리하면 Cat이 반응해야 하는 구조 → 두 플레이어가 소통 없이는 콤보 불가

**Onion 패리 설계 권장안** (Nine Sols 참고):
- 패리 성공 시 적에게 "마크" 부착 (시각적으로 Cat에게 신호)
- Cat이 마크된 적을 슬래시 → 폭발 데미지 + 경직
- 패리 실패 시 Onion 방패 쿨다운 3초 페널티
