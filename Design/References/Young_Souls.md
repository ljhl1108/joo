## 핵심 시스템

### 1. 2인 완전 협력 구조
- 두 쌍둥이(Jesto / Tristan)가 항상 함께 행동 — 솔로 플레이 시에도 AI가 나머지 한 명 조작
- 두 캐릭터가 **같은 공간**에 항상 존재하며, 거리가 벌어지면 카메라가 줄어들어 압박감 생성
- 역할 분담이 강제되지 않고 **자연스럽게 유도**: 한 캐릭터가 적을 잡으면 다른 캐릭터가 측면 공격

### 2. 개별 빌드 시스템
- 두 캐릭터는 **완전히 별개의 장비 슬롯**을 가짐
- 한 명은 헤비 아머(탱크), 한 명은 라이트 아머(딜러/기동성) 조합 권장
- 장비가 스탯에 직접 영향 → 무기/방어구 선택이 플레이스타일 결정

### 3. 전투 시스템
- **방어 & 패리**: 타이밍 맞는 방패 들기로 패리 → 적 스턴 → 강공격 기회
- **스태미나 관리**: 회피, 강공격 모두 스태미나 소모 → 무한 구르기 불가
- **약점 시스템**: 특정 적은 특정 공격 유형에만 취약 (스턴, 독, 화염 등)
- 콤보 시스템: 약→강 공격 체인으로 추가 데미지

### 4. 던전 구조
- 층별 던전(10개 레벨 묶음) 진행
- 보스 격파 후 다음 구역 해금
- 수집 아이템, 숨겨진 방, 복잡한 레이아웃 — 탐험 보상 있음
- 도시 허브(Base): 장비 강화, NPC 대화, 음식 구입 등 사이 활동

### 5. 협력 메카닉 하이라이트
- **동시 부활**: 한 명이 죽으면 다른 한 명이 일정 시간 안에 구해야 함
- **공유 포션**: 아이템이 양쪽에 동시 적용되는 경우와 개인 적용이 구분됨
- 협력 특수기는 없지만 위치 기반 협력 (한 명이 기절시키면 다른 한 명이 마무리) 자연 발생

## OnionCat 적용 포인트

| Young Souls 메카닉 | OnionCat 적용 |
|---|---|
| 두 캐릭터 개별 장비 슬롯 | Cat/Onion 각각 업그레이드 트리 별도 운영 |
| 거리 기반 카메라 압박 | 두 플레이어가 너무 멀어지면 화면 경계 진동 또는 패널티 힌트 |
| 패리 → 스턴 → 강공격 루프 | Onion 패리 성공 시 Cat에게 "공격 창" 시각 신호 전달 |
| 약점 시스템으로 캐릭터 선택 강제 | OnionCat의 핵심 — 근접 전용 적 + 원거리 전용 적 설계 그대로 적용 |
| 동시 부활 시스템 | OnionCat: 한 쪽 HP 0 → 다른 플레이어가 특정 행동(예: 꽃 물주기) 시 부활 |
| 도시 허브에서 메타 진행 | 메인 메뉴의 화분 정원 성장 아이디어에 연결 |

### 특히 중요한 인사이트
- **부담 없는 AI 보조 솔로 플레이**: 1인 테스트 시 AI가 나머지 캐릭터 담당 → 개발/테스트 효율 높아짐. OnionCat도 1인 플레이 시 간단한 AI로 Onion(또는 Cat)을 보조 제어하면 솔로 테스트 가능.
- **장비 차별화의 재미**: 두 캐릭터가 다른 방향으로 성장할수록 협력 의존도가 높아짐 → OnionCat 업그레이드 설계 시 Cat과 Onion의 업그레이드 트리가 서로 겹치지 않도록 의도적으로 차별화해야 함.
