## 핵심 메카닉

### 캐릭터 다양성 (역할 분리)
- 6종 캐릭터, 각각 완전히 다른 플레이 스타일
  - **Ao Bai** (곰): 듀얼 위펀, 근접 위주, 방어형
  - **Qing Yan** (사자): 근접+총기 혼합, 도약 공격
  - **Lei Luo** (호랑이): 번개 능력, 공격형 원거리
  - **Tao** (여우): 꽃잎 분신, 트릭 샷
  - **Zi Xiao** (용): 방어막, 쉴드 기반
  - **Crown Prince**: 원소 폭탄, 군중제어
- OnionCat과 유사: 각 캐릭터가 "할 수 있는 것"이 다름 → 협력 시너지 자연 발생

### 무기 × 능력 시너지 시스템
- 무기에 원소 속성(화염, 번개, 독, 바람) 부여 가능
- 업그레이드 스크롤이 특정 속성 강화 → 빌드 방향 자연 결정
- 플레이어마다 빌드가 달라지면서 협력에서 역할 분담 자동화

### 협동 설계 원칙
- 같은 화면 필요 없음(온라인), 각자 독립 행동 가능
- 그러나 부활 시스템: 다운된 플레이어를 팀원이 살려야 함 → 협력 동기
- 공유 자원 없음 → 경쟁 없이 각자 빌드
- 적이 인원수에 따라 스케일 (체력 증가) → 어렵게 유지

### 방 구조
- 3개 챕터, 각 챕터마다 4~5개 방 + 보스
- 방마다 "엘리트 몬스터" "일반 웨이브" "보물방" "상점방" 분류
- 클리어 조건이 명확 (웨이브 소탕 또는 특정 목표)

### 영구 해금 시스템 (메타 진행)
- 영혼 화폐로 패시브 트리 해금
- 무기 초월 (특정 무기 상향)
- 새 캐릭터 해금
- OnionCat 참고: 러닝 간 영구 진행감을 주는 가장 단순한 방법

## 플레이어가 사랑하는 것

1. **빌드 다양성**: 같은 캐릭터도 매 런이 다른 느낌
2. **협동의 자연스러운 역할 분화**: 강요하지 않아도 서로 다른 역할
3. **빠른 런 속도**: 초반 런은 30분 내 가능
4. **아이템 설명의 명확성**: 효과를 정확히 설명 → 빌드 판단 가능

## OnionCat 적용 포인트

### 1. 역할 강제 없는 역할 분화
- Gunfire Reborn은 "캐릭터 특성"으로 자연스럽게 역할 분화
- OnionCat은 "약점 시스템"으로 동일 효과 달성 가능
  - 근거리만 통하는 적 → Cat(P1) 담당
  - 원거리만 통하는 적 → Onion(P2) 담당
  - 두 플레이어가 자연스럽게 대화하고 전략 수립

### 2. 부활 시스템
- 다운 → 부활 메카닉은 공포/긴장감 생성
- OnionCat에서: Cat이 죽으면 Onion도 위험 → 일체형 신체 설정상 즉사
- 대안: "부활 아이템" 획득으로 1회 죽음 무효화

### 3. 무기/업그레이드 스크롤
- 업그레이드가 빌드를 자연스럽게 가이드
- OnionCat: 업그레이드 선택지가 "Cat 특화" vs "Onion 특화" vs "공유" 세 분류

### 4. 원소 약점
- 적마다 원소 속성 약점 존재 → 협력에서 역할 자연 분화
- OnionCat: 적마다 "근접 약점" / "원거리 약점" 표시 방법 차용

### 5. 적 스케일링
- 인원수 기반 적 체력 증가 → OnionCat은 항상 2인이므로 고정 밸런스 가능
- 단독 플레이 모드 지원 시 AI 파트너 또는 체력 감소 고려
