## 핵심 시스템

### 캐릭터 시스템 (63+ 캐릭터)
- 각 캐릭터는 단순 스킨이 아닌 **고유 제약 + 고유 강점**으로 차별화
  - Ghost: 소모품 수집 불가, 대신 영구 흡혈 내장
  - Crazy: 정확도 -10%, 대신 막대한 데미지 보너스
  - Baby: 아이템 가격 -20%, 무기 슬롯 추가
- 제약이 빌드 방향을 **강제 결정** → 각 런의 정체성 형성

### 무기 & 업그레이드
- **최대 6개 무기 동시 장착** (근접 + 원거리 자유 혼합)
- 무기마다 연동 스탯이 다름 (원거리 데미지, 근접 데미지, 공학, 원소 데미지)
- 수백 가지 아이템과 **시너지 조합** — 같은 스탯 방향 아이템들이 폭발적 스케일링 유발

### 17가지 스탯
- Harvesting(자원 수집), Luck(아이템 등급), Armor, Speed, Lifesteal 등
- 스탯 간 조합 전략이 런의 성패를 좌우
- 같은 캐릭터도 매 런마다 다른 스탯 빌드 가능

### 웨이브 구조
- **20웨이브** (웨이브당 20~90초) — 웨이브 사이 상점에서 무기/아이템 구매
- 웨이브 중 적 처치로 재료(Materials) 수집, 경험치로 레벨업 시 스탯 선택
- 기본 자동 조준, 수동 조준 선택 가능

### Co-op 시스템
- 로컬/온라인 2인 Co-op — **재료와 XP 공유**
- 시너지 조합 예시:
  - Builder(구조물 생성) + Streamer(정지 시 재료 획득): 구조물이 Streamer를 보호
  - Bull(피격 시 폭발) + Masochist(피격 시 데미지 증가): 둘 다 맞을수록 강해짐
  - Farmer(Harvesting 특화) + Baby(아이템 할인): 경제 폭발 조합

## OnionCat 적용 포인트

| 시스템 | OnionCat 적용 아이디어 |
|--------|------------------------|
| 제약 기반 캐릭터 | 작물 타입마다 제약+강점 설계: "감자" = 방패 사용 불가 but 탄환 속도 2배, "선인장" = 사거리 짧지만 탄환 반사 가능 |
| 6무기 = 다중 빌드 | 고양이와 작물이 각자 "빌드 방향"을 가짐 — 런 중 선택한 업그레이드들이 서로 다른 스타일의 런을 만듦 |
| 웨이브 아레나 방 | 특정 룸에서 탈출 불가 웨이브 서바이벌 도전 — 웨이브마다 근접/원거리 적 비율 변화 |
| 시너지 업그레이드 | 고양이 업그레이드와 작물 업그레이드가 조합될 때 추가 효과 발동: "고양이 대시" + "작물 전기탄" = 대시 경로에 전기장 생성 |
| Co-op 재료 공유 | 두 플레이어가 공유 자원 풀에서 함께 업그레이드 구매 — 자원 배분 의사소통이 핵심 전략 |
