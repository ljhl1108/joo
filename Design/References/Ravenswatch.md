## 핵심 메커니즘

### 기본 구조
- **시점**: 탑다운 2D 액션 (OnionCat과 동일한 시점!)
- **인원**: 1~4인 실시간 로컬/온라인 협동
- **캐릭터**: 동화 속 영웅들 재해석 (빨간망토, 백설공주, 베오울프, 피노키오, 어린왕자 등)
- **목표**: 악몽의 군주를 물리치기 위해 여러 구역을 탐험하고 보스 처치

### 캐릭터 시스템 (역할 분리)
각 캐릭터는 고유 역할을 가지며 협동 시 시너지 발생:
- **빨간망토 (Red)**: 원거리 투사체, 범위 공격 → OnionCat의 어니언과 유사
- **베오울프 (Beowulf)**: 탱커, 근접 돌진, 적 끌어당기기 → OnionCat의 캣과 유사
- **백설공주 (Snow White)**: 지원형, 아군 버프, 힐 → 지원 역할
- **피노키오 (Pinocchio)**: 섬멸형, 자기 희생적 능력, 고위험-고수익
- 각 캐릭터: 기본 공격 + 특수 스킬(쿨타임) + 궁극기(게이지 충전)

### 카드 업그레이드 시스템
- 전투 후 3~4장의 **업그레이드 카드** 제시
- 카드마다 고유 효과: 스탯 증가, 능력 변형, 새 메커니즘 추가
- **협동 특수**: 팀원이 같은 카드를 선택하면 **합동 시너지 효과** 발동
  - 예: 두 명이 "불꽃 어시스트" 선택 → 서로 공격 시 화염 폭발 추가
- 단독 플레이보다 협동 플레이에서 덱 빌딩 깊이 훨씬 증가

### 낮/밤 사이클 (핵심 시간 압박)
- 맵에는 **낮/밤 시계**가 있음
- **낮**: 자유 탐험, 이벤트 처리, 자원 수집
- **밤**: 적들이 강해지고 수가 증가, 악몽 보스 소환 가능
- 플레이어는 낮 동안 효율적으로 움직여 밤 전에 목표 달성 필요
- **공포(Fear) 게이지**: 밤이 지속될수록 상승 → 최대치 도달 시 런 실패

### 공간 탐험 (Semi-Open World)
- Enter the Gungeon처럼 방 구조가 아닌 **반오픈 월드** 탐험
- 맵에 이벤트 포인트, 자원 노드, 적 캠프, 보스 위치가 분포
- 어떤 곳을 먼저 갈지 경로 선택 → 시간 효율 전략

### 협동 부활 시스템
- 팀원이 쓰러지면 **다운 상태** (즉사 X)
- 다른 팀원이 근처에 있으면 **부활 행동** 가능 (시간 소요)
- 모든 팀원이 동시에 다운 시 런 실패
- 솔로 플레이: 다운 후 일정 시간 내 회복 가능 (제한적)

## 플레이어들이 사랑하는 것

1. **협동 시너지**: 혼자는 약한 카드도 팀원과 함께면 강력해지는 조합
2. **역할 다양성**: 탱커/딜러/서포터가 명확히 나뉘어 "내 역할" 감각
3. **시간 압박**: 낮/밤 사이클이 만드는 긴장감 — "빨리, 빨리!"
4. **탑다운 액션**: 직관적 이동 + 스킬 사용, 접근성 좋음
5. **팀원 부활**: "절대 포기하지 마!" 역전 드라마 연출

## OnionCat 적용 포인트

### 1. 협동 카드 시너지 → 두 플레이어 공동 업그레이드
```
업그레이드 선택 화면에서 캣과 어니언 둘 다 같은 카드 선택 시 강화 효과:
- 캣: "연속 슬래시" + 어니언: "연속 슬래시" 공동 선택
  → "쌍방향 연속 공격: 캣 슬래시 때 어니언 투사체 자동 발사"
이것만으로 협동의 보상 느낌을 강하게 줄 수 있음
```

### 2. 다운 시스템 → OnionCat 생존 드라마
```
- 체력 0 → 즉사 X, 다운 상태 (화분이 넘어진 연출)
- 캣이 쓰러지면 어니언 단독으로 일정 시간 생존 가능 (이동 불가, 방어만)
- 또는: 어니언이 특수 회복 능력으로 캣 부활 → 역할 의존성 강조
```

### 3. 역할 기반 캐릭터 설계 확인
```
Ravenswatch처럼 OnionCat의 두 "역할"을 명확히 구분:
- 캣 = 탱커/근접 딜러 (전면 진입, 받아치기)
- 어니언 = 포지셔닝 딜러/지원 (원거리, 방패, 패리)
적 타입으로 역할 강요: "이 적은 근접만 데미지" / "이 적은 원거리만 데미지"
```

### 4. 탑다운 반오픈 탐험 → 층 구조 대안
```
방 기반 구조 대신 반오픈 구역 탐험도 고려:
- 하나의 구역에 여러 이벤트 포인트 분포
- 플레이어가 경로를 선택 → 시간/자원 효율 고민
단, 초보 개발자에게는 방 기반이 구현 난이도가 낮으므로 참고만
```

### 5. 공포/압박 게이지 → OnionCat 긴장감 시스템
```
"시들음 게이지": 어니언이 흙이 마르면 점점 약해지는 시스템
- 물 아이템 수집 or 특정 적 처치로 게이지 유지
- 방치하면 어니언 능력 감소 → 탐험과 전투의 균형 강요
농업 테마와도 완벽히 맞음
```
