## 핵심 컨셉

중국 수묵화 미학을 2D 액션 로그라이트에 결합한 게임. Dead Cells의 전투 반응성 + Hades의 빌드 다양성을 목표로 하며, 흑백 수묵 배경에 컬러 이펙트를 대비시키는 독특한 비주얼 아이덴티티를 가짐.

- 플레이어: 붓으로 만들어진 무사 캐릭터
- 적 처치 → 먹물(잉크) 자원 획득 → 스킬 강화
- Dead Cells 스타일의 快속 근접 + 원거리 복합 전투
- 런 길이: ~30분

## 핵심 시스템 분석

### 1. 비주얼 설계 철학 — "수묵 + 컬러 대비"
- 배경: 흑백 수묵화 텍스처
- 플레이어 이펙트: 밝은 원색 파티클 (노랑, 빨강, 파랑)
- 적: 검정 윤곽선 + 한 가지 악센트 색
- **교훈**: 배경을 저채도로, 전투 요소를 고채도로 설정하면 가독성이 극대화됨

### 2. 전투 반응성 설계
- 공격 선딜(Pre-Attack) 0프레임 — 즉시 반응
- 취소 가능 콤보: 공격 중 대시로 언제든 취소
- 히트스톱: 매 타격마다 2~4프레임 일시정지
- 파티클 스케일: 적 체력 낮을수록 더 큰 파티클 = 피니셔 피드백

### 3. 먹물(잉크) 자원 시스템
- 적 처치 시 잉크 방울 드롭
- 잉크 = 강화 스킬의 소모 자원이자 점수 배율
- 잉크 풀 → 콤보 유지의 동기 부여
- **OnionCat 적용**: 근접(Cat) 처치로 원거리(Crop) 탄약 충전하는 시스템과 유사한 구조

### 4. 스킬 빌드 시스템
- 런마다 3개 선택지 중 스킬 픽업
- 같은 스킬 2번 픽업 = 강화(1tier → 2tier)
- 스킬 간 시너지 태그: [관통], [폭발], [독] 태그 조합으로 효과 변화
- 태그 기반 시너지는 공식 문서 없이도 직관적으로 이해됨

### 5. 적 설계 패턴
| 적 유형 | 특징 | 대응 방법 |
|---------|------|----------|
| 돌격형 | 예고 없이 직선 돌진 | 패링 or 측면 이동 |
| 포격형 | 2~3발 부채꼴 발사 | 투사체 사이 이동 |
| 방패형 | 정면 무적 | 후방 접근 필수 |
| 폭발형 | 사망 시 폭발 | 근접 처치 후 이격 |

## 플레이어들이 좋아하는 점

1. **타격감** — 공격할 때마다 화면이 살짝 흔들리고 파티클이 터지는 느낌
2. **비주얼 아이덴티티** — 수묵화라는 차별화된 아트스타일
3. **빌드 다양성** — 같은 스킬이라도 태그 조합으로 전혀 다른 플레이
4. **짧은 런** — 30분 내외라 부담 없이 반복 가능

## OnionCat 적용 포인트

### 비주얼 (픽셀아트 적용)
- **배경 저채도 + 이펙트 고채도** 원칙 채택
  - 배경 타일: 갈색/회색 계열 저채도
  - 타격 파티클: 고채도 원색 (Cat = 주황, Crop = 초록)
- **피니셔 이펙트**: 적 체력 10% 이하에서 처치 시 더 큰 파티클 발생

### 전투 반응성
- Dead Cells / Realm of Ink 모두 **즉시 반응 + 취소 가능 콤보** 구조
- OnionCat의 Cat 근접 슬래시도 선딜 0프레임 목표
- 대시 취소: 슬래시 모션 중 대시 입력으로 즉시 취소 가능하게 설계

### 자원 연계 시스템 아이디어
- Cat 근접 처치 → 잉크(또는 에너지) 획득 → Crop 스킬 충전
- 양 플레이어의 행동이 서로의 자원에 영향을 주는 구조

### 런 길이 참고
- Realm of Ink 런 길이 ~30분이 "적당함" 평가
- OnionCat 목표 런 길이: 25~35분 (초보 40분, 숙련 20분)
