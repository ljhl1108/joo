## 핵심 시스템

### 1. 세계관 & 세팅

- 무대: **Geodia** — Sparklite(행성의 생명력)로 이루어진 세계
- 주인공 **Ada**는 기계공(Mechanic)으로 Baron의 채굴 작전을 막기 위해 싸움
- **Disruption 시스템**: 행성 코어가 주기적으로 대지를 재배열 → 런 실패(사망) 시 월드 레이아웃이 초기화되는 설정적 근거
- 5개 **바이옴** (습지, 광산, 사막, 숲, 종착지) — 각각 고유 적·함정·퍼즐

### 2. 핵심 루프

```
탐험 → Sparklite(재화) 수집 → 사망/귀환 → 허브 업그레이드 → 재도전
```

- **허브(Fivestone Sky Village)**: 사망 시 귀환하는 하늘 마을
- 수집한 **Sparklite 유지** → 허브에서 Ada 스탯(체력, 대미지, 이동) 영구 강화
- 맵 레이아웃은 초기화되지만 **업그레이드·가젯은 영구 유지**
- → 전형적 로그라이트(roguelite): 런 간 영구 성장이 있는 구조

### 3. 전투 & 가젯 시스템

- 기본 무기: **Ada's Wrench(렌치)** — 밀리 기본 공격 + 차지 공격 + 대시
- **Vault(고대 유적)** 탐색으로 가젯 발견:
  - **Spark Slinger**: 원거리 사격, 스위치 작동 가능
  - **Spark Blitzer**: 원거리 연사, 전투 특화
  - **Remote Bomb**: 원격 기폭
  - **Crossbow**: 정밀 원거리
  - **Hammer**: 범위 근접 강화
- 가젯은 런 전반에 걸쳐 발견 → 빌드 방향 변화
- **Patch(패치) 시스템**: 멀티툴에 패치를 붙여 스탯 변조 (맵 공개, 공격력, 체력 등)

### 4. 보스 설계

- 바이옴마다 1개 보스(총 5개) → 고유 패턴, 약점 메카닉
- 보스 방 입장 전 반드시 해당 구역 탐색 완료 권장
- 각 보스는 **도구 기반 약점** 존재 (특정 가젯으로만 효율적 처치 가능)
- 비평가들이 "게임 최고 부분"으로 꼽은 요소

### 5. 화면 전환 방식

- **Screen-by-Screen 이동** (Legend of Zelda: A Link to the Past 방식)
- 방이 아닌 화면 단위로 스크롤 → 방 시스템과 화면 전환의 중간 형태
- 각 화면에 적·아이템·함정 배치 → 클리어 후 다음 화면으로

## 플레이어가 좋아하는 것

- 픽셀아트 비주얼: zelda 감성 + 현대 로그라이트의 조합
- 가젯 발견의 재미: 새 가젯 획득 = 접근 가능한 콘텐츠 확장
- 보스 패턴 디자인: 도구 기반 약점이 "아하!" 순간 제공
- 진입 장벽 낮음: 영구 성장이 있어 실패해도 좌절감 낮음

## 비판 포인트

- 반복성: 바이옴 내 화면들이 다소 단조롭게 느껴짐
- 과도한 파밍: 일부 구간에서 Sparklite 파밍 강제
- 어려움 곡선: 후반 보스가 초반보다 급격히 어려워짐

## OnionCat 적용 포인트

| Sparklite 시스템 | OnionCat 적용 |
|-----------------|--------------|
| **도구 기반 약점 보스** | 일부 보스는 Cat 근접으로만, 일부는 Crop 원거리로만 처치 → 협동 필수 강제 |
| **가젯 = 런 내 빌드 변화** | 런마다 Cat/Crop 각자 특수 능력 1개씩 발견 → 조합 전략 다양화 |
| **허브 영구 업그레이드** | Fivestone 허브처럼 고양이 마을에 NPC 구출 후 시설 강화 → 메타 진행 제공 |
| **화면 단위 이동** | 방 전환 대신 화면 전환으로 더 세밀한 맵 구성 가능 (옵션으로 검토) |
| **5 바이옴 구조** | 5개 던전 테마 (초원 → 숲 → 동굴 → 공장 → 마왕성) 구조 참고 |
