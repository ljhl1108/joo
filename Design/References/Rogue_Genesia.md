## 핵심 메카닉

### 1. 클래스 & 고유 패시브 시스템
- 런 시작 전 **직업(Class)** 선택 → 각 클래스마다 고유 패시브 1~3개
- 예: 전사 = 받는 피해 감소 + 근접 강화 / 마법사 = 마나 소비형 폭발 범위 증가
- 클래스 고유 패시브가 빌드 방향성을 결정 → 업그레이드 선택지가 자연스럽게 특정 방향으로 유도

### 2. 웨이브 & 서바이버 구조
- Vampire Survivors처럼 자동 공격, 웨이브형 적 등장
- 시간이 지날수록 적 수와 강도 증가
- 특정 시간 or 처치 수 달성 → 엘리트/보스 등장

### 3. 무기 진화(Weapon Evolution) 시스템
- 기본 무기 + 특정 패시브 아이템 조합 → **강화된 무기로 진화**
- 조합 조건이 게임 내에서 힌트로 제공됨 (숨겨진 시너지 발견하는 재미)
- 진화 무기는 새로운 공격 패턴과 시각 효과를 가짐

### 4. 아이템 선택 UI
- 레벨업 시 **3~4개 선택지** 제시
- 같은 아이템 중복 선택 → 레벨업(강화)
- 희귀도: 일반(회색) / 희귀(파랑) / 에픽(보라) / 전설(금색)
- 선택지 **리롤** 기능 (재화 소비)

### 5. 메타 진행(Meta Progression)
- 런 후 획득 재화로 **영구 강화** 트리 해금
- 새 클래스, 새 무기 시작 옵션 해금
- Hades처럼 "죽어도 조금씩 성장" 구조

### 6. 저주(Curse) & 난이도 스케일링
- 선택적으로 **저주** 추가 → 런이 어려워지지만 더 많은 보상
- Binding of Isaac의 "도전 런" 개념과 유사
- 저주 예: "적 이동속도 +30%", "아이템 선택지 1개 감소"

## 플레이어들이 좋아하는 점

1. **빌드 다양성이 극단적으로 넓다**: 수백 가지 아이템 조합, 진화 시스템으로 매 런이 달라짐
2. **클래스 개성이 강하다**: 단순 스탯 차이가 아닌 근본적으로 다른 플레이 스타일
3. **진화 발견의 재미**: 조합 레시피를 스스로 발견하는 만족감
4. **접근성**: Vampire Survivors처럼 조작이 단순하지만 빌드 깊이는 깊음
5. **활발한 업데이트**: EA임에도 콘텐츠가 꾸준히 추가됨

## OnionCat 적용 포인트

### A. 무기 진화 → 능력 조합 시너지
- Cat 슬래시 + Onion 투사체의 **조합 능력** 개념 도입 가능
- 예: "슬래시 직후 투사체 발사 시 관통탄으로 변환" 같은 연계 시너지
- 두 플레이어 모두 같은 업그레이드를 골라야 진화 조건 달성 → 협력 강화

### B. 클래스 시스템 → 런 시작 전 역할 선택
- 고양이 캐릭터: "돌격형 / 방어형 / 스피드형" 등 클래스 선택
- 작물(양파) 캐릭터: "폭발형 / 저격형 / 지원형" 등 클래스 선택
- 클래스 조합에 따라 최적 전략이 달라짐 → 재플레이 동기 부여

### C. 저주 시스템 → 자발적 난이도 상승
- 런 시작 or 진행 중 저주 선택 시 보상 증가
- 초보자는 저주 없이, 숙련자는 저주 쌓아가며 도전
- OnionCat에서 "화분 균열(flowerpot crack)" 같은 시각적 저주 표현 가능

### D. 리롤 메카닉 → 자원 관리 레이어 추가
- 업그레이드 선택지 마음에 안 들면 재화(예: 씨앗)로 리롤
- 씨앗 자원이 재화로 이중 역할: 업그레이드 리롤 + 특수 상점 구매
- 간단하지만 매 선택에 가중감이 생김

### E. 희귀도 시스템 구현
- ScriptableObject 기반 아이템에 `Rarity` enum 추가
- 희귀도별 드롭 가중치 → Random_Generation 기법 활용
- 업그레이드 UI에 희귀도 색상 테두리로 시각화
