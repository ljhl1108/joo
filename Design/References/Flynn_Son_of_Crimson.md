## 핵심 메카닉

### 기본 구조
- SNES/세가 메가드라이브 시대 감성의 2D 픽셀 아트 횡스크롤 액션 플랫포머
- **40개 이상**의 스테이지, 플레이타임 약 6시간 (短편이지만 밀도 높음)
- 주인공 Flynn과 수호 늑대(실은 여성 가디언독) **Dex**의 2인 구도

### 이동 시스템
- **기본 이동**: 좌우 이동 + 점프
- **구르기/닷지**: 전용 버튼으로 수행, **무적 프레임(I-frame)** 발생 → 전투 핵심 기술
- **구르기-점프 연계**: 롤 직전에 점프하면 더 넓게 도약 — 의도된 테크닉
- **대시**: 기본 이동 확장 옵션으로 존재
- **월 점프**: 後반 Crimson Claws 획득 후 해금 — 최종 구역 진입에 필수
  - 방향키 없이도 자동으로 반대쪽 벽으로 도약하는 방식 (조작 간소화)
- 더블 점프는 없음, 롤-점프 테크닉이 실질적 대체제

### 체력 시스템
- 체력은 **라이프 오브(Life Orbs)** 슬롯 방식
- 맵의 녹색 수정을 부수면 힐링 에너지(녹색 오브) 획득
- 언제든 버튼 한 번으로 힐링 오브 소모 → 회복 (포션 픽업 아이템 방식 아님)
- 힐링 슬롯 수와 회복량 모두 업그레이드 가능

### 재화 시스템
- **Crimson Gems**: 스테이지 곳곳 수집, 스킬/콤보 해금 화폐
- 희귀 아이템(Trinkets)을 집에서 찾은 거대 두꺼비 NPC에게 갖다 주면 추가 Gems 획득
- Gems로 기술 트리 업그레이드 (공격력 강화, 콤보 해금, 힐링 슬롯 증가 등)

## 전투 시스템

### 3가지 근접 무기 (자유 전환)

| 무기 | 특성 | 주요 용도 |
|------|------|-----------|
| **Crimson Sword** | 균형형, 여신 Sorrell이 최초 수여 | 피어싱 대시, 어퍼컷 언락 |
| **Crimson Axe** | 느리고 묵직함, 와인드업 필요 | 적 실드 파괴, 약점 벽 파괴, 스턴 중 집중 딜 |
| **Crimson Claws** | 빠른 다단 히트, 공중 우위 | 스태거 누적, 에어 콤보, 월 점프 연계, 드릴 어택 |

- 보스전 팁: Claws는 빠른 보스에게 난사, Axe는 스턴 시 집중 딜

### 4가지 마법 (자유 전환)

| 마법 | 특성 | 고유 효과 |
|------|------|-----------|
| **Crimson** | 기본형, 약하지만 빠름 | 차지 시 강화 발사 가능 |
| **Ice** | 범위 관통 가능 (업그레이드) | 적 **동결**, 물 위에 플랫폼 생성 |
| **Lightning** | 적 연쇄 감전 | **그린 아머(마법 반사)** 무력화 |
| **Fire** | 지속 화상 | 횃불 점화, 스턴 게이지 추가 누적 (업그레이드) |

- 마법은 무한 사용 가능하나 근접보다 데미지가 낮음
- 차지 공격은 강화되지만 타이밍이 까다롭고 실용성 논란 있음

### 스태거 시스템
- 모든 적에게 **노란색 스태거 게이지** 존재 (체력 바 별도)
- 게이지 충전 → 적 스턴 (별 애니메이션) → **수 초간 무방비 상태**
- Claws로 빠른 다단 히트 → 스태거 누적 효율 최고
- Axe로 스턴 중 강타 → 딜 극대화 조합

### 적 방어 메카닉
- **그린 글로우 아머**: 일반 마법을 반사 → Lightning 마법으로만 제거 가능
- **실드 적**: Axe로 실드 파괴 필수
- 일부 보스·적은 마법에 완전 내성 → 근접 전투 강제

### Crimson Mode (슈퍼 모드)
- Crimson 게이지가 가득 차면 발동
- 일시적 **무적 + 대량 데미지 + 고속 공격** — "슈퍼 사이야인" 연출
- 붉은 에너지와 번개 이펙트로 시각적 강조
- 지속 시간 수 초, 업그레이드 가능하나 밸런스는 무난한 수준

## 적 / 보스 디자인

### 일반 적 유형
- 식인 식물, 고블린, 광견(Rabid Wolves), 거대 곤충 등 바이옴별 배치
- **스카지 기사(Scourge Knights)**: 구역별 미니보스급, 아름답고 유기적인 공포스러운 디자인
- 고블린 계열이 주류 — 강한 적은 대체로 고블린 강화판 (리스킨 비판 있음)
- 구역별로 새로운 적 패턴 추가, 단순하지만 점진적 위협 상승

### 5대 보스

| 보스 | 칭호 | 위치 |
|------|------|------|
| **Bora** | Whirlwind Assassin | Mistral Peak |
| **Kravios** | Aquatic Voltknight | The Hollow |
| **Xellios** | Toxic Marksman | Rustwood |
| **Imbra** | Shadow Sorceress | Shivering Spire |
| **Zealock** | 최종 보스 | Zealock's Citadel |

- 보스는 각각 고유한 디자인과 패턴 — "패턴 인식 + 회피 후 반격" 방식
- 패턴 인식 전까지는 지구전 형태, 학습 후 클린 클리어 쾌감 있음
- 中간 빌런 Rozia와 반복 전투 (1~3회)

### 세계관 적 구조
- **Scourge**: 아름다운 세계 Rosantica를 파괴하려는 어둠의 세력
- 유기적이고 자연의 부패를 표현하는 적 디자인 — 기괴하고 아름다운 균형

## 협력 / 멀티플레이 요소

### Dex 컴패니언 시스템
- Flynn의 수호 동물 **Dex** (허스키/말라뮤트 기반의 미신화된 수호견, 암컷)
- 메인 스토리: Rozia가 Dex의 4가지 수호 정령을 빼앗음 → 보스 4마리 처치로 회복

### Dex 게임플레이 방식
- **소환 조각상(Guardian Statue)** 지점에서만 Dex를 동료로 불러낼 수 있음
- Dex를 탑승하면 Flynn이 스파이크 등 환경 피해 면역
- Dex가 탑승 중 벽·적 무리를 물어뜯고 박살냄
- 사다리나 높은 플랫폼은 단독으로 오르지 못함 → **붉은 보석을 모아 배리어 문 해제**하는 퍼즐 구조
- 구역 내 여러 조각상 배치 → Dex와 분리돼도 재소환 가능
- 탑승 구간은 "달리는 개 위에서 전투" — 리뷰어들이 특히 재미있다고 평가, 더 많았으면 한다는 아쉬움

### 멀티플레이
- **공식 Co-op / 멀티플레이 없음** — 순수 싱글플레이어 게임
- Dex는 AI 제어 동반자로, 플레이어가 직접 조작하지 않음
- Kickstarter 당시에도 2인 co-op 기능은 포함되지 않음

## 플레이어가 사랑하는 것

### Steam 평가
- 전체 리뷰 366건 중 **84% 긍정적** (Very Positive)
- Steambase 점수: **85 / 100** (689개 총 리뷰 기준)

### Metacritic
- Metascore: **81** (Generally Favorable)
- OpenCritic에서도 긍정적 평가 다수

### 주요 호평 포인트
1. **픽셀 아트 비주얼**: "현존 최고 수준의 스프라이트 작업" — 캐릭터, 적, 배경 모두 디테일하고 애니메이션이 매끄러움. 바이옴마다 풍부한 색감 변화
2. **반응성 좋은 조작감**: 도지, 점프, 공격이 모두 정밀하게 반응 — 고전 플랫포머 감성 그대로
3. **무기 다양성**: 검·도끼·클로의 플레이 스타일이 확연히 달라 자기 방식 개발 재미
4. **성장하는 전투 시스템**: 초반엔 단순하지만 후반 콤보·마법 해금 이후 전투 깊이 증가
5. **Dex**: "게임 최고의 수호견 중 하나" — 탑승 구간에서 특히 인기, 귀엽고 강렬함
6. **사운드트랙**: Jacob Lincke 작곡, 34곡 / 78분, 오케스트라+유기악기 혼합 — 스테이지마다 분위기 변화
7. **대화와 페이싱**: 위트 있는 대화, 스토리 비트가 간결하고 플레이 흐름을 방해하지 않음
8. **보스 디자인**: 각 보스가 고유 패턴, 패턴 학습 후 클린 클리어 쾌감

### 주요 비판
- 전체적으로 **다소 짧음** (6시간) — "더 하고 싶었다"는 반응 다수
- **적 다양성 부족**: 후반부로 갈수록 고블린 강화판 반복
- Dex 탑승 구간이 너무 적음 — 게임의 잠재적 하이라이트인데 분량 부족
- 마법의 실용성 한계 (특히 차지 마법)
- 쉬운 난이도, 하드 모드도 도전감 부족하다는 지적 일부

## OnionCat 적용 포인트

### 1. 무기별 용도 분화 → 적 취약점 설계
Flynn에서 Axe는 실드 파괴, Claws는 스태거 누적, Sword는 범용이라는 역할이 명확하다. OnionCat에서 **고양이(근접 180° 슬래시)는 스태거·밀리 취약 적에 특화**, **작물(원거리 조준)은 아머·마법 취약 적에 특화**하여 교대 기용을 강제한다.
- 구현 힌트: 적 에게 `MeleeImmune` / `RangedImmune` 플래그 추가, 면역 적용 시 데미지 0 또는 0.1배. 룸마다 두 유형을 혼재 배치.

### 2. 스태거 게이지 전이 — 공동 스턴 시스템
Flynn의 스태거 게이지(노란 바)는 단독 플레이어가 채운다. OnionCat에서는 **고양이의 슬래시와 작물의 원거리 투사체가 동일한 스태거 게이지에 기여**하도록 설계 — 혼자서는 게이지가 느리게 차고, 둘이 동시에 공격하면 급속 충전된다.
- 구현 힌트: `Enemy.staggerGauge += (meleeHit ? 1.0f : 0f) + (rangedHit ? 0.8f : 0f)` — 두 인풋이 같은 프레임에 들어오면 보너스 곱연산 적용.

### 3. Crimson Mode 대응 — 공동 게이지 필살기
Flynn의 슈퍼 모드(게이지 충전 → 무적+고화력)를 공동 시스템으로 확장한다. **고양이와 작물이 각각 게이지를 절반씩 채워야** 필살기 발동 가능 — 한 명만 달려도 나머지 절반이 비어 발동 불가.
- 구현 힌트: `SharedSuperMeter` (0~2.0f) — Cat contributes [0,1], Crop contributes [0,1]. 2.0 달성 시 둘 다 동시에 강화 상태 진입, 3초 지속.

### 4. 마운트 구간 응용 — 고양이 위 작물의 독립 시야
Flynn이 Dex를 타면 이동은 Dex가, 전투는 Flynn이 한다. OnionCat의 **"원 보디" 컨셉** 자체가 이 구조의 직접 발전형이다. 고양이가 이동하는 동안 작물은 고양이 등 위에서 마우스로 독립적인 방향을 겨냥한다 — 두 인풋이 물리적으로 분리된 시야와 조준 방향을 갖는다.
- 구현 힌트: Player1 transform은 이동 담당, Player2의 aimDirection은 World Space에서 독립 계산. 카메라는 두 플레이어 중점을 추적하되 둘의 화면상 분리가 일정 범위 이내로 제한.

### 5. 마법 원소 속성 → 방향성 실드 조합 응용
Flynn에서 Lightning은 그린 아머를 해제, Ice는 동결, Fire는 화상+스턴 가속. OnionCat에서 작물의 **방향성 패리/실드**에 원소 속성을 부여한다 — 실드로 특정 원소 투사체를 받아내면 역으로 흡수해서 버프로 전환(예: 불 투사체 패리 → 다음 슬래시에 화염 추가 데미지).
- 구현 힌트: 실드가 `ElementalProjectile`을 받으면 `CatBuffController.ApplyElementBuff(element, duration)` 호출 — 고양이 슬래시에 1~3회 원소 피해 추가.
