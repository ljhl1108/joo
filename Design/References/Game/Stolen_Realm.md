## 핵심 메카닉

### 육각 그리드 전투
- 이동은 실시간, 전투는 **턴제 + 육각 타일** 혼합
- 각 캐릭터가 아닌 **한 팀이 한 라운드씩** 이동·공격 → 6인이 모두 연속으로 행동한 뒤 적 턴
- 공간 위치가 중요(근접·원거리 차이, 포위 보너스)

### 빌드 유연성
- 클래스 없음 — 스킬 트리를 자유롭게 혼합 (전사+마법사+도적 동시 가능)
- 장비 5슬롯 + 소모품 인벤토리
- 런마다 스킬 선택과 장비 드롭이 달라지는 로그라이트 구조

### 장비 세트 시스템
- **세트 아이템**: 같은 세트를 N개 장착하면 보너스 효과 활성화
- 세트 종류: 어쌔신 세트(치명타 강화), 전사 세트(방어 반격), 마법사 세트(마나 자동 회복) 등
- **팀 시너지**: 한 명의 세트 보너스가 팀 전체에 영향을 주는 것들 있음

### 협동 특화 설계
- **연계 콤보**: 한 플레이어가 적을 기절시키면 다른 플레이어가 추가 공격 시 보너스 데미지
- **팀 능력치**: 파티 버프/디버프 스킬이 존재, 탱커-서포터-딜러 역할 분담 자연스럽게 유도
- **공유 경험치**: 처치 경험치가 팀 전원에게 동등 분배 → 뒤처지는 플레이어 없음
- **비대칭 역할**: 일부 스킬이 "자신은 약해지지만 동료를 강화" — 진정한 협동 요구

### 던전 구조
- 절차 생성 던전, 다양한 방 타입 (전투·보물·상점·이벤트·보스)
- 스테이지 완료 후 스킬 / 장비 선택 (업그레이드 픽)
- 중간 저장 없는 런 구조, 전멸 시 처음부터

## 유저들이 사랑하는 것

1. **스케일 유연성**: 혼자 해도 되고 6인으로 해도 모든 시스템이 자연스럽게 확장
2. **빌드 자유도**: 어떤 조합도 가능하고, 의외의 시너지를 발견하는 재미
3. **빠른 전투 리듬**: 턴제지만 지루하지 않은 빠른 속도 (한 라운드가 금방 끝남)
4. **협동 쾌감**: 연계 콤보가 실제로 강력해서 "팀플레이 성공" 느낌이 명확

## OnionCat 적용 포인트

### 세트 시스템 설계 참고
- Stolen Realm의 세트는 **팀 전체 시너지**를 의도적으로 설계함
- OnionCat의 세트 시스템도 "고양이 장비 + 양파 장비의 세트 합산"이 핵심 — Stolen Realm처럼 **팀 합산 세트**의 즐거움을 더 명확하게 HUD에 표시하면 좋음
- 예: 세트 단계 달성 시 "햇살 3단계 달성! 팀 보너스 활성화" 팝업 연출 강화

### 역할 분담의 명확화
- Stolen Realm에서 팱커-딜러-서포터 역할이 자연스럽게 생기듯, OnionCat에서도 장비에 따라 "고양이=근접 탱커 / 양파=버스터 딜러" vs "고양이=기동형 딜러 / 양파=포격 지원"처럼 런마다 다른 역할을 갖도록 세트 보너스 설계

### 팀 연계 스킬 설계
- Stolen Realm의 연계 콤보(한 명 기절 → 다른 명 추가타)는 OnionCat의 협동 콤보(교대 타격 1.5배)와 같은 철학
- 추가 아이디어: 특정 세트가 "협동 콤보 중 고양이 공격 시 양파 씨앗 자동 발사" 등 자동 연계 효과를 달면 협동 느낌을 더 강화

### 비대칭 희생 장비
- "고양이가 야성 게이지를 양파에게 보내면 양파 스킬 쿨다운 50% 감소" 같이 한 쪽이 자원을 양보하면 다른 쪽이 강해지는 장비 효과 — Stolen Realm의 서포터 스킬 철학
