# Undermine

리서치 날짜: 2026-10-14

## 기본 정보

- **개발사**: Thorium Entertainment (캐나다 인디)
- **출시**: 2020-08-06 (얼리 액세스 2019-08) — Steam
- **장르**: 탑다운 2D 던전 크롤러 로그라이크
- **공식 사이트**: https://www.underminegame.com/
- **Steam**: https://store.steampowered.com/app/656350/UnderMine/
- **위키**: https://undermine.wiki.gg/

## 핵심 게임플레이

### 기본 구조
플레이어는 **농부(Peasant)**를 조작해 던전을 파고 내려가며 금을 캐고 적을 처치한다. 매 런마다 시작점은 같지만 방 배치·드롭·이벤트가 무작위.

- **공격**: 곡괭이 휘두르기 (근접, 8방향 조준)
- **투척**: 들고 있는 바위·폭탄·유물 투척 (던져서 적을 맞히거나 스위치 활성화)
- **골드 경제**: 처치·채굴로 금 획득 → 런 내 상점 구매 / 기지 귀환 시 영구 업그레이드

### 죽음과 영구 성장
- 죽으면 소지한 금을 **절반** 잃고 처음 지점으로 귀환
- 귀환한 금은 **마을 NPC 영구 업그레이드**에 투자 (다음 런에 반영)
- 런 중 획득한 **유물(Relic)**: 강력하지만 서로 시너지·상충 관계. 런 끝에 소멸
- **축복(Blessing)**: 유물보다 약한 수동 버프, 일부 런 사이에 유지

## 협동 요소

### 2인 협동 (온라인/로컬)
- **완전 비대칭은 아님**: 두 명 모두 독립 농부로 플레이
- **공유 체력 없음**: 각자 HP 바, 한 명이 죽으면 다른 사람이 살아있으면 부활 가능
- **공유 경제**: 금·폭탄은 한 공간에서 공유 — 한 사람이 과소비하면 다른 사람도 영향
- **협동 기믹**: 두 플레이어가 동시에 레버를 밟아야 하는 방, 한 명이 적을 끌고 다른 명이 치료 아이템 수집 등

### 협동에서 배울 점
- "공유 경제"는 협력·갈등 양쪽을 모두 만들어 낸다 (한 명이 독식 가능 → 재미있는 긴장감)
- 부활 시스템이 "같이 끝까지 가자"는 동기를 만든다
- 비대칭 없이도 역할 분담(한 명 탱킹, 다른 명 채굴)이 자연스럽게 발생

---

## 주요 시스템

### 유물 시스템
- **런 내 유물**: 방·상자에서 랜덤 획득. 런 중에만 유효
- **시너지**: 유물끼리 상호작용 (예: "투척 시 폭발" + "이동할수록 투척 속도 증가" → 달리면서 폭탄 폭풍)
- **저주(Curse)**: 강력한 유물에는 부작용 (예: 체력 최대치 감소, 이동 속도 하락)
- 저주 있는 유물을 받을지 말지 **선택권**을 주어 플레이어 에이전시 유지

### 영구 성장 (기지 업그레이드)
- **신기(Shrine)**: 마을 기도를 통해 기본 능력치 영구 상승
- **NPC 해금**: 금 투자로 상인·주술사 등 NPC 해금 → 다음 런부터 만남 가능
- 영구 성장은 "죽어도 헛되지 않다"는 메시지를 전달하며 초보자 친화적

### 경제 흐름
- **런 내 즉시 사용 금** vs **기지 투자 금** 을 매 런마다 선택
- 욕심을 부리다 죽으면 절반 날아감 → 리스크/리워드 장력

---

## 플레이어가 좋아하는 것

1. **탐험 만족감**: 숨겨진 방·비밀 통로·NPC 퀘스트가 많아 뒤질수록 보상이 있다
2. **폭발적 유물 시너지**: "이런 조합이 되네?" 모멘트가 자주 발생
3. **직관적 조작**: 곡괭이 + 투척만으로도 다양한 전술 가능, 진입 장벽 낮음
4. **협동의 자연스러운 역할 분담**: 강제하지 않아도 최적화 과정에서 역할이 생긴다
5. **죽음이 무섭지 않음**: 영구 성장이 있어 "이번 런은 경험치" 느낌

---

## OnionCat 적용 포인트

### 1. 저주 있는 아이템 (Trade-off 장비)
Undermine의 저주 유물 시스템 → OnionCat 장비에도 "단점 있는 에픽/전설 아이템" 적용 가능:
- 예: "할퀴기 쿨다운 -50%" + "이동 속도 -20%" — 유리대포형 빌드
- 현재 OnionCat 장비는 전부 순수 버프. 트레이드오프 장비 1~2개가 생기면 빌드 다양성이 폭발

### 2. 공유 경제의 긴장감
Undermine에서 공유 금으로 협동·갈등이 동시에 생기는 구조 → OnionCat의 씨앗(공동 지갑)이 비슷한 역할:
- "내가 쓰면 네 아이템이 못 사진다"는 씨앗 소비 긴장감을 상점 진열에서 더 강조할 수 있다
- 두 플레이어가 **같은 씨앗 풀**을 두고 경쟁·협의하는 장면을 연출 (예: 두 명이 동시에 같은 아이템을 원할 때)

### 3. 비밀 방 / 숨겨진 보상
Undermine의 숨겨진 방 → OnionCat도 방 레이아웃에 "비밀 구멍" 개념 추가 고려:
- 특정 벽을 걷어차거나 양파가 수정을 쏴서 열리는 숨겨진 공간
- 발견 자체가 기분 좋은 경험, 탐험 동기 부여

### 4. NPC 영구 해금 구조
Undermine의 마을 NPC 해금 → OnionCat의 메타 성장에서 "방 풀 확장" 이외에도:
- 런 사이 허브에서 새 장비 카테고리 해금 (예: 처음엔 일반만, 나중에 에픽 상점 등장)
- 초보 플레이어가 "점점 세지는" 느낌을 받도록 메타 성장 가시화

### 5. 부활 대신 공유 체력 (현재 구조)
Undermine과 달리 OnionCat은 **공유 HP**이므로 "한 명이 죽고 다른 명이 살린다"는 구조가 없다.
대신 "둘 중 한 명이 실수해도 다른 명이 만회할 수 있다"는 공유 실드·패링 시스템이 이를 대체.
공유 HP가 OnionCat 정체성이므로 유지하되, **공유 자원(씨앗·가방)**의 협동 경영을 더 강조하는 것이 방향.

# UnderMine

리서치 날짜: 2026-07-16

## 기본 정보

- **장르**: 탑다운 액션 로그라이트 던전 크롤러
- **개발**: Thorium Entertainment (Jake & Kevin Johnson 형제)
- **출시**: 2020년 8월 6일 (Early Access 2019)
- **플랫폼**: PC, Console
- **공식 사이트**: https://www.underdungeon.com/
- **Steam**: https://store.steampowered.com/app/656350/UnderMine/
- **위키**: https://undermine.wiki.gg/

## 핵심 메카닉

### 곡괭이 이중 용도 시스템
- **근접**: 짧게 버튼 → 근접 휘두르기
- **투사체**: 길게 누르고 조준 → 투척 (다시 손으로 돌아옴)
- 동일한 도구가 상황에 따라 근접/원거리 역할 전환
- OnionCat과 구조적 유사성: 단일 오브젝트가 다중 역할

### 물리 기반 폭탄 시스템
- 폭탄이 중력에 의해 경사면을 굴러내려감
- 연쇄 폭발: 폭탄이 다른 폭탄에 닿으면 터짐
- 적 캐릭터를 폭발로 공중에 띄울 수 있음
- 픽셀아트 게임에서 간단한 물리 시뮬레이션의 게임플레이 깊이 증명

### 골드 순환 시스템
- **런 내 골드**: 사망 시 전부 손실 (고위험 수집)
- **상인 소비 골드**: 런 도중 상인에게 지불 → 사망해도 효과 유지
- **메타 업그레이드**: Sho 상인에게 지불 → 영구 해금
- 수집 자체가 긴장감을 가짐 — 골드가 살포되면 재수집해야 함

### Peasant(소작농) 동행 시스템
- 적을 때리면 소작농이 떨어져 나옴
- 소작농을 보호하며 출구로 데려가면 성수(Holy Water) 보상
- 성수: 능력 강화 또는 특수 효과 아이템
- NPC 보호 목표가 전투 중 부가 목적 추가

### 친숙한 동반자(Familiar) 시스템
- 런 도중 발견/해금하는 영구 동반자
- 각 Familiar는 고유한 패시브/액티브 능력 보유
- 런 시작 시 원하는 Familiar 선택 (최대 3개 동시 장착)
- 예: Mudge — 기절 시 폭탄 드롭 / Imber — 주기적으로 번개 발사

### 렐릭 & 저주 상호작용
- 렐릭: 강력한 런 수정자 (BoI 아이템과 유사)
- 저주: 렐릭 획득 시 함께 붙는 부정적 효과
- 강한 렐릭일수록 강한 저주 → 위험-보상 균형

| 단계 | 내용 |
|------|------|
| 런 시작 | 영구 스탯(HP/공격력 등) 적용 후 던전 진입 |

## 협동 요소 (Co-op)

- 2인 로컬 Co-op 지원
- 두 번째 플레이어는 **Beatrice(마녀)** 캐릭터로 플레이
- Beatrice: 다른 공격 패턴, 원거리 마법 중심
- 서로 다른 무기 타입 → 적에 따른 역할 분담 자연 발생
- 아이템 공유 / 부활 메카닉 존재

## 적 다양성

- 근접 전용 적: 충돌 피해, 갑옷 적
- 원거리 전용 적: 원거리 공격, 근접 시 도망
- 특수 적: 폭발 반응, 반사탄, 면역 타입
- 약점 시스템(명시적이진 않으나 상황별 최적 무기 존재)

## 게임 필 (Game Feel) 특징

- **곡괭이 무게감**: 스윙 시 약간의 딜레이 → 타이밍 기반 전투
- **골드 물리**: 수집 가능한 골드가 실제로 튀고 굴러다님
- **히트스탑**: 근접 타격 시 프레임 정지 효과
- **피격 리액션**: 적들이 타격 방향으로 넉백
- **진동 카메라**: 폭발/보스 등장 시 화면 흔들림

## OnionCat 적용 포인트

### 1. 단일 도구 이중 용도 철학
- 곡괭이처럼 Cat의 슬래시도 근접 모드와 투척 모드로 분리 가능
- "고양이가 발톱을 날리는" 원거리 변형 기술로 응용 가능
- 같은 버튼 → 다른 입력 길이 → 다른 행동: OnionCat 조작 확장에 참고

### 2. 골드 긴장감 → 영혼(Soul) 아이템에 응용
- OnionCat 런 내 소모성 자원이 사망 시 일부 손실되도록 설계하면 긴장감 UP
- 상인에서 소비한 자원은 보존 → 위험 감수할 이유 존재

### 3. NPC 보호 서브목표
- 방에 구출 대상 NPC 배치 → 보호 성공 시 보너스
- OnionCat: 동물 NPC를 보호하며 방 탈출하면 특수 아이템 보상

### 4. 저주-렐릭 균형
- OnionCat 업그레이드 시스템에 "강력한 아이템 = 부작용" 패턴 도입
- 예: "양파가 독 구름 생성(강함) + Cat 이동 속도 감소(저주)"

### 5. Familiar → OnionCat 동반 식물
- 등짝의 화분에서 추가 식물(Familiar)이 자라 패시브 능력 부여
- 런마다 다른 식물 선택 → 빌드 다양성 확보

### 6. Co-op 캐릭터 분리 설계
- Beatrice처럼 P2(Onion)도 독자적인 조작 세트를 가진 "별개 캐릭터"처럼 느껴지게 설계
- 폼팩터는 하나이지만 조작 감각은 두 캐릭터가 독립적으로 존재
