# Dave the Diver

리서치 날짜: 2026-11-11

## 기본 정보

- **개발사**: MINTROCKET (넥슨 자회사, 한국)
- **장르**: 아케이드 액션 + 경영 시뮬레이션 (장르 혼합)
- **출시**: 2023-06-28 (Steam Early Access → 정식)
- **공식 사이트**: https://mintrocket.com/dave-the-diver/
- **Steam**: https://store.steampowered.com/app/1868140/Dave_the_Diver/
- **수상**: The Game Awards 2023 최우수 인디게임 후보, 판매량 300만 이상 (2024)

## 핵심 메커니즘

### 장르 혼합 구조
- **낮**: 바다 다이빙 → 물고기 채집 (액션·어드벤처)
- **밤**: 스시 레스토랑 운영 → 수익 창출 (경영 시뮬레이션)
- 두 장르가 별개가 아니라 **낮에 얻은 재료 → 밤 메뉴 결정 → 밤 수익 → 낮 장비 업그레이드** 순환 형성
- 장르 전환이 명확하여 플레이어가 혼란 없이 각 모드에 집중할 수 있음

### 핵심 루프 설계
```
다이빙(액션) → 재료 수집 → 레시피 발견 → 레스토랑(경영) → 수익 → 장비 업그레이드 → 더 깊이 다이빙
```
- 루프 하나가 약 15~20분 (짧고 반복 가능)
- 각 사이클마다 "오늘의 목표"가 명확 (특정 물고기 잡기, 특정 메뉴 개발)
- 장기 목표(이야기, 더 깊은 다이빙)와 단기 보상(오늘 저녁 레스토랑 성공)이 균형

### 유동적인 월드 디자인
- 바다 맵이 **매일 조금씩 달라짐** (랜덤 요소 + 고정 이야기 이벤트 혼합)
- 절차적 생성이 아닌 **큐레이션된 랜덤** — 같은 구역에 매번 비슷하지만 다른 배치
- 플레이어가 "오늘은 어떤 물고기가 있을까" 기대감을 가지고 반복

### 성장 시스템
- 장비 업그레이드: 작살총 → 더 강력한 무기, 산소통 → 더 오래 다이빙
- 레스토랑 업그레이드: 테이블 수, 직원 고용, 메뉴 다양화
- 두 계통이 각각 발전하며 서로 시너지 형성

### 콘텐츠 밀도
- 다이빙 도중 무수한 서브퀘스트·미니게임 삽입 (사진 찍기, 특정 행동, 수집)
- 메인 스토리와 무관한 미니 에피소드가 풍부 → 세계가 살아있는 느낌
- NPC마다 고유 에피소드 존재 (박사, 반디, 지호 등)

## 플레이어들이 사랑하는 점

1. **장르 간 환기** — 액션에 지치면 경영, 경영에 지치면 다이빙으로 자연스럽게 전환
2. **명확한 루프** — "오늘 뭘 해야 하는지" 항상 보임
3. **콘텐츠 양** — 메인 외에 서브 콘텐츠가 무궁무진 (굴리 사가, 닌자 DLC 등)
4. **유머와 개성** — 캐릭터 대사와 애니메이션이 생동감 있음
5. **완성도** — 출시 시 버그 거의 없음, UI/UX가 직관적

## 개발 비하인드 (한국 인디 관점)

- 처음에는 작은 프로젝트로 시작 → 반응이 좋아 계속 추가
- **얼리 액세스 없이 정식 출시** — 넥슨 지원으로 가능했지만 완성도를 높인 뒤 출시
- 개발팀 약 20명 → 소규모 팀의 집중력 증명
- 한국 현지 감성(오마카세, 한국 음식 등)이 글로벌에서 먹혔음
- 한글 → 영어 번역 품질이 높아 세계 시장에서 긍정적 반응

## OnionCat 적용 포인트

### 1. 루프 구조 — 짧고 명확한 사이클
OnionCat의 "방 클리어 → 보상 선택 → 다음 방"은 Dave와 유사한 구조. Dave의 교훈:
- 각 사이클(방)마다 **"오늘의 목표" 느낌을 명확히** 줄 것
- 보상 선택 화면에서 "다음 방에서 이게 도움이 될 것"이라는 기대감 연결
- 매 방이 독립적이면서도 긴 목표(보스 처치, 세트 완성)와 연결

### 2. 콘텐츠 밀도 — 작은 경이감
Dave는 보스/메인 외에도 "오늘은 뭔가 새로운 것을 발견"하게 함. OnionCat 적용:
- 물음표 방의 이벤트를 더 다양하고 예측 불가능하게
- 첫 번째 방에서 반드시 "오, 이런 게 있네?" 순간을 하나 이상 넣을 것
- 반복 플레이에서도 발견의 기쁨 → 런별 고유 메모 하나씩

### 3. 장르 간 환기 → 고양이·작물 역할 대비
Dave가 액션/경영 간 환기를 주듯, OnionCat에서 고양이(액션)와 작물(지원·관리)이
**서로 다른 집중 순간**을 가지도록 설계:
- 고양이가 활발히 움직이는 동안 작물은 타이밍 관리(씨앗 쿨다운, 실드 타이밍)
- 적이 뜸한 순간 작물이 "다음 방 준비" 역할(가방 정리, 아이템 미리 계획)

### 4. NPC 에피소드 → 말하는 책·그리모
Dave의 NPC들이 각자 미니 에피소드를 가지듯, 낡은 책·그리모의 대사를 방마다 다양하게:
- 보스 등장 전 짧은 선 대사(1~2줄) → 세계관 색깔 형성
- 반전 후 그리모로 이름 바뀌면 말투·내용도 변화

### 5. 완성도 우선 출시 전략
OnionCat도 얼리 액세스보다 "1스테이지 완성도 100%"로 출시하는 전략이 맞을 수 있음:
- Dave는 완성도 덕분에 입소문이 빠름
- 1스테이지 + 보스 + 세이브/로드가 완벽하면 itch.io 무료 데모로 먼저 검증
