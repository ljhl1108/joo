## 핵심 메카닉

### 신체 분리 시스템
- 팔, 다리, 머리를 분리해서 별도로 조작하거나 던질 수 있음
- 각 부위가 독자적인 기능을 가짐
  - 팔: 당기거나 붙잡기, 먼 스위치 조작
  - 다리: 이동 도구, 발판
  - 머리: 굴리기, 특정 공간 진입
- 퍼즐의 핵심: "어떤 부위를 어디에 두어야 하는가"

### 2-플레이어 Co-op 모드
- P1: Bjørn의 몸통(이동, 방향)
- P2: 분리된 팔이나 다른 부위를 독립 조작
- **두 플레이어가 하나의 신체를 분담** — OnionCat의 개념과 구조적으로 동일
- 소통 없이는 클리어 불가한 퍼즐 설계

### 평화주의 설계
- 모든 적을 비전투적으로 처리
- 싸우는 대신 신체 부위를 활용해 우회, 속임수, 퍼즐 풀이
- "전투 게임이 아닌 창의적 해법 찾기"가 핵심 재미

## 2-플레이어 공유 신체 구현 방식

| 요소 | Helheim Hassle | OnionCat 대응 |
|------|---------------|---------------|
| 이동 | P1이 전담 | P1(고양이)이 전담 |
| 보조 능력 | P2가 분리 신체 조작 | P2(파)가 조준·방어막 담당 |
| 의사소통 | 직접 대화 필수 | 직접 대화 필수 |
| 사망 조건 | 신체 전체 붕괴 | 공유 HP 0 |
| 재미 원천 | "어떻게 나눌까" 협상 | "누가 뭘 할까" 협상 |

## 플레이어가 좋아하는 점

1. **독창적 신체 분리 개념** — 본 적 없는 메카닉이 강렬한 첫인상 제공
2. **2인 co-op의 필연적 소통** — "팔 어디 갔어?" 같은 웃긴 상황 발생
3. **노르딕 유머 스타일** — 바이킹 + 코믹 내러티브, 분위기가 가볍고 유쾌
4. **퍼즐 만족감** — 분리된 신체로 환경을 활용하는 '아하!' 순간
5. **짧은 세션** — 가볍게 즐기는 co-op 게임으로 적합

---

## 구조적 차이점 (OnionCat와의 비교)

- Helheim Hassle은 **퍼즐 플랫포머**, OnionCat은 **로그라이크 액션**
- Helheim은 레벨 디자인 중심, OnionCat은 절차 생성 + 전투 중심
- Helheim은 물리적 분리, OnionCat은 "같은 몸에 있지만 역할 분리"

---

## OnionCat 적용 포인트

### 1. '공유 신체' 게임의 UX 설계 참고
Helheim Hassle이 P1/P2 역할 분담을 어떻게 플레이어에게 직관적으로 전달하는지 분석.  
→ OnionCat 튜토리얼에서 "고양이는 이동, 파는 조준" 역할 구분을 어떻게 자연스럽게 가르칠지 응용

### 2. 부위 분리 = 능력 분리 아이디어
파(P2)가 마우스로 조준하는 현재 설계 외에,  
특정 업그레이드에서 "파의 투사체가 몸에서 분리되어 자동 순환" 등  
Helheim의 분리 개념에서 영감을 얻은 특수 업그레이드 발상 가능

### 3. 2인 소통 의존 퍼즐 방
OnionCat에 퍼즐 방 추가 시 Helheim 방식 참고:  
한 플레이어만으로는 절대 해결 불가한 방 (예: P1이 버튼 누르는 동안 P2가 파를 쏴야 함)

### 4. 분위기 — 유쾌한 캐릭터 관계
Helheim의 코믹 노르딕 톤 = OnionCat의 고양이+파 콤비 개성과 유사.  
두 캐릭터 사이의 대화/반응을 가볍고 유머러스하게 디자인하는 방향성 참고

### 5. 온보딩 — 역할 구분 튜토리얼
Helheim은 "팔을 떼어내 봐"처럼 단계적으로 메카닉을 가르침.  
OnionCat도 "P2야, 마우스로 조준해봐" → "이제 방어막 써봐" 순서의 온보딩 설계에 응용
