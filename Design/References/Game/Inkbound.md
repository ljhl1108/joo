# Inkbound

리서치 날짜: 2026-10-03

## 기본 정보

- **장르**: Co-op Turn-Based Roguelite (실시간 이동 + 턴제 전투)
- **개발사**: Shiny Shoe (Monster Train 제작사)
- **출시**: Early Access 2023 / Full Release 2024
- **Steam**: https://store.steampowered.com/app/1903100/Inkbound/
- **공식 사이트**: https://www.inkboundgame.com/
- **플레이어 수**: 1~4인 온라인/로컬 협동
- **플랫폼**: PC

## 핵심 시스템

### 하이브리드 이동 + 전투 구조
- **이동은 실시간**, **공격은 턴제** — 모든 플레이어가 행동을 완료하면 적도 행동
- 이동 거리는 "Stamina" 자원으로 제한 → 위치가 전술적 자원
- 공격 전 이동 → 위치 기반 스킬 범위 결정 → 행동 소비 순서

### 클래스 시스템 (역할 분화)
| 클래스 | 역할 | 특징 |
|--------|------|------|
| Meltdown | 탱커 | 화염 DoT, 근접 압박 |
| Weaver | 지원 | 실타래 묶기, 방어막 |
| Magpie | 원거리 | 광역 던지기, 아이템 재활용 |
| Clunkmachine | 엔지니어 | 구조물 설치, 간접 딜 |
| Trickster | 기동형 | 도망치고 다시 치기 |
| Ironclad | 근접 딜 | 콤보 카운터 누적 |

### 협동 메커니즘
- **적의 의도 표시**: 모든 적이 다음 행동을 미리 공개 → 협력 판단 가능
- **콤보 타겟팅**: 다른 플레이어가 이미 디버프 건 적을 치면 보너스
- **부활 시스템**: 팀원이 쓰러진 동료 근처에서 행동 소비해 부활
- **스킬 시너지**: 클래스 간 조합 효과 (예: Weaver가 묶은 적 = 타 클래스 공격 보너스)

### 빌드 시스템
- 방 클리어 후 **스킬 트리** 방식 업그레이드 선택 (카드 덱빌드 아님)
- "Bindings" = 패시브 보너스 노드
- 같은 스킬 중복 획득 시 강화(upgrade) 효과 발생
- 플레이어마다 독립 빌드 → 협동 중 역할 분화가 자연스럽게 심화

### 적 디자인
- 각 적은 다음 턴 의도를 아이콘으로 표시 (공격/이동/강화/소환)
- **특정 적은 특정 위치 패턴 강요** → 두 플레이어 포지션 조율 필수
- "Bulwark" 적: 정면 방어막 → 측면/후면으로 접근 필요

## 플레이어가 사랑하는 것

1. **"비동기 실시간"**: 실시간 긴장감 + 턴제 전략의 조합 — 기다림 없이 생각할 수 있음
2. **모든 클래스가 핵심**: 힐러 없는 co-op — 포지션과 스킬 조합으로 생존
3. **의도 가시화**: 적이 뭘 할지 보여주므로 소통이 쉽고 co-op 판단이 명확
4. **같은 세션 안에서 역할이 심화**: 초반엔 다 비슷하다가 빌드 분화로 역할이 뚜렷해짐
5. **Shiny Shoe의 Monster Train DNA**: 클리어 시 빌드 만족감

## OnionCat 적용 포인트

### 1. 적 의도(Telegraph) 시스템 → 이미 Enemy_Telegraph_System.md 참고
Inkbound의 의도 시스템이 co-op을 가르치는 핵심. OnionCat에서 적의 다음 공격을 **색깔/아이콘**으로 표시하면 Cat과 Onion이 역할을 자연히 분담:
- 빨간 아이콘 = 고양이 약점, 파란 아이콘 = 양파 약점으로 시각화

### 2. 역할 분화의 점진적 심화
OnionCat도 런 초반엔 두 캐릭터가 비슷한 기여를 하다가, 업그레이드(스킬/축복)를 받으면서 고양이는 "근접 특화", 양파는 "마법사형"으로 갈라져야 한다. Inkbound의 Binding 트리처럼 런 내에서 역할이 심화되는 구조 참고.

### 3. "둘 다 핵심" 설계 원칙
Inkbound는 힐러/탱커/딜러 삼각형을 깨고 **모든 클래스가 생존 책임을 공유**. OnionCat도 "양파가 공격만, 고양이가 이동만"이 아닌, 두 플레이어가 각자 생존에 기여하게 설계해야 한다.

### 4. 협동 콤보 보상
Inkbound는 디버프된 적 공격 시 보너스를 준다. OnionCat 코어 시스템의 `Attacker.Cat/Onion` 구분 → 고양이가 슬로우 건 적을 양파가 치면 보너스 피해 같은 콤보 reward 구조 참고.

### 5. UI: 개별 빌드 요약
런 중 현재 빌드 상태를 볼 수 있는 `InRun_Build_Viewer_UI`는 Inkbound에서 두 플레이어 빌드가 어떻게 시너지되는지 확인하는 데 영감. Cat 빌드와 Onion 빌드를 나란히 보여주는 화면.
