## 핵심 게임플레이

### 전투 시스템
- **기본 공격**: 빠른 콤보 공격(최대 3타) + 강 공격
- **회피(Dodge)**: 무적 프레임 있는 구르기 — 타이밍 기반 생존
- **패링(Parry)**: 정확한 순간 방어 버튼 → 적 공격 튕겨내어 Moonshard 획득 + 잠시 반격 기회 창출
- **만월 처형기(Moonwell)**: 특정 처형 조건 충족 시 강력한 피니시 동작 발동

### Moonshard 경제
- 적 처치 / 패링 성공 시 Moonshard(달빛 파편) 획득
- Moonshard = 체력 회복 비용 + 업그레이드 재료
- 사망 시 일부 손실(소울즈라이크 패턴) → 공격적 플레이 장려
- 포션 없음: 회복은 Moonshard 소비 또는 환경 오브젝트 활용

### Umbra 시스템 (클론 보스)
- 일정 진행 후 "Umbra" — 자신의 부패한 복제본 — 이 보스로 등장
- Umbra는 플레이어가 이 런에서 쓴 능력/패턴을 반영하는 디자인
- 처치 시 강력한 영구(런 내) 업그레이드 획득
- 서사적 장치: "나를 이겨야 앞으로 나아간다"

### Wish 시스템 (소원)
- 던전 내 NPC에게 소원을 빌어 능력 변경/강화
- 소원마다 트레이드오프 존재: 강한 효과 = 다른 능력 약화
- 런마다 다른 소원 조합 → 빌드 다양성

## 플레이어가 사랑하는 점

1. **전투 피드백의 무게감**: 히트스톱·파티클·사운드가 세 겹으로 쌓이는 타격감
2. **다크 픽셀아트 미학**: 흑백 위주 팔레트에 붉은 포인트컬러, 몽환적이고 위협적인 분위기
3. **보스전 품질**: 보스마다 고유 2페이즈 패턴, 학습-숙달 사이클 명확
4. **패링의 이중 보상**: 성공 시 자원 획득 + 반격 기회 → 방어가 공격의 일부
5. **환경 스토리텔링**: 텍스트 최소화, 시각적 단서로만 세계관 전달

## 비판적 분석

- 로그라이트 요소가 소울즈라이크보다 약함 → 반복 플레이 동기 다소 부족
- 초반 난이도 스파이크 → 진입 장벽
- 체크포인트 간격이 길어 초보 플레이어 좌절

## OnionCat 적용 포인트

### 1. Umbra → "그림자 만남 (Shadow Encounter)"
특정 방에서 Cat과 Crop의 부패한 그림자 버전이 보스로 등장. 그림자는 이 런에서 플레이어가 가장 많이 쓴 스킬 비율(근접 vs 원거리)을 반영해 패턴이 달라짐. 처치 시 런 내 강력한 1회성 "금지된 힘" 업그레이드 획득.

### 2. 패링 다중 피드백 설계
Moonscars 패링 → 흰색 섬광 + 적 전체 경직 + Moonshard 분출의 3중 피드백. OnionCat도 Crop 패링 성공 시: ① 흰 링 파티클 ② 0.1초 히트스톱 ③ 협공 게이지 20% 충전. 단순 방어가 "공격 기회 창출"로 느껴지는 피드백 구조.

### 3. Wish → "기도 사당 (Shrine Room)"
던전 내 사당 방에서 1~3개 선택지 제시. 강한 효과에는 반드시 트레이드오프 ("Cat 공격력 +25%, Crop 방어막 쿨다운 +50%"). Cat이 상호작용하되 Crop의 동의 버튼 입력을 함께 요구 → 두 플레이어 합의의 게임플레이화.

### 4. 포션 없는 회복 디자인
Moonscars가 포션 대신 환경 오브젝트(Moonwell) + Moonshard 소비로 회복하듯, OnionCat도 던전 내 물 샘에서 Cat이 버튼 홀드(1.5초) → Crop 체력 회복. 협력 액션 없이는 회복 불가 → 긴장감과 유대 동시 강화.

### 5. 다크 픽셀아트 팔레트 참고
전체 채도를 낮추고 Cat 눈(주황)과 Crop 잎사귀(연두) 두 포인트컬러만 선명하게 유지. Moonscars의 흑백+레드 전략을 OnionCat의 흑백+주황+연두로 변형 적용.
