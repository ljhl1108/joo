# Wizard of Legend 2

리서치 날짜: 2026-09-19

## 기본 정보

- **개발사**: Contingent99
- **출시**: 2024년 Early Access (Steam)
- **장르**: 협동 액션 로그라이크
- **플랫폼**: PC (Steam)
- **공식 사이트**: https://www.wizardoflegend.com/
- **Steam**: https://store.steampowered.com/app/2071570/Wizard_of_Legend_2/

## 핵심 메카닉

### 빠른 아케이드 전투
- 최대 4인 협동 (로컬/온라인)
- 대시 기반 이동 + 콤보 마법 연계
- 각 마법은 3단계 조합 가능: Normal → Charged → Dash Attack
- 원소 속성 시스템 (화염, 물, 번개, 바람, 땅, 얼음)

### 로그라이크 구조
- 무작위 생성 던전 (룸 기반)
- 런마다 새 마법 조합 구성
- **Relics**: 패시브 능력 강화 아이템
- **Cursed Items**: 강력하지만 페널티를 지닌 아이템 (패밀리아 = 원소석)

### 협동 특화 시스템
- **원소 시너지**: 플레이어 마법이 결합되면 추가 효과 발생
  - 예: 화염 + 바람 → 화염 토네이도 확장
  - 예: 물 + 번개 → 감전 / 범위 확산
- **부활 메카닉**: 죽은 플레이어를 부활시키거나 게임오버 유예
- **공유 보스 HP**: 보스는 파티 전체를 대상으로 설계됨

### 캐릭터 시스템
- 각 캐릭터별 원소 친화도 (어떤 마법을 배우기 쉬운지)
- Robe: 스탯과 원소 속성 보너스 결정
- 캐릭터 시각적 커스터마이징과 스탯은 분리

## 협동 요소 분석

### 강점
- 원소 콤보 = 협동 플레이 자연스럽게 유도
- 역할 분담: CC기 사용 플레이어 + DPS 플레이어
- 같은 화면에 있어야 효과적 (범위 마법 공유)
- 사망 페널티가 있지만 팀 부활로 완화

### 약점 (배울 점)
- 캐릭터가 서로 너무 비슷하면 협동 필요성이 줄어듦
- 1편보다 엔드게임 밸런스 문제 보고 多 (Early Access 특성)

## OnionCat 적용 포인트

### 원소 시너지 → 콤보 공격 시스템
```
고양이 근접 슬래시 + 작물 물 투사체 → "진흙 슬로우" 효과
고양이 불 마법 슬래시 + 작물 바람 투사체 → "화염 확산"
```
구현: 근접 히트 + 투사체 히트가 동일 타겟에 짧은 시간 내 발생하면 추가 StatusEffect 적용

### 적 설계: 속성 약점
- WoL2처럼 적마다 특정 공격 타입에 취약점 설정
- 근접에만 약한 적, 원거리에만 약한 적 → OnionCat의 핵심 협동 필요성과 직결

### 업그레이드 선택 UI
- WoL2는 런 중 마법 선택 화면이 직관적
- 아이콘 + 짧은 설명 + 현재 빌드와의 시너지 암시
- OnionCat: Cat용 / Crop용 / 공용 업그레이드로 분류 표시

### 보스 디자인
- 파티 전체를 타겟으로 하는 보스 패턴
- 플레이어가 하나의 몸이라면 보스가 "분리 공격" 패턴 시도 가능
  - 예: Cat을 끌어당기는 자기력 → Crop의 에임 방해

### 커스드 아이템 메카닉
- 강력하지만 단점 있는 아이템 = 위험/보상 계산
- OnionCat: 발을 빠르게 하지만 조준이 흔들리는 아이템

## 플레이어들이 좋아하는 것

1. 빠른 연계 콤보의 손맛
2. 원소 시너지 발견의 쾌감
3. 매 런마다 다른 빌드 실험
4. 2인 협동 시 자연스러운 역할 분담
