## 핵심 메커니즘

### "게스트 카드" 시스템
- 각 런에서 NPC "게스트"를 카드로 모집. 게스트마다 고유 능력(공격기·보조기·패시브)을 제공
- 덱 빌딩처럼 덱을 구성하되 **직접 조작 가능한 액션 RPG** 전투
- 카드를 "장착"해 사용 슬롯에 넣고, 전투 중 MP 소모로 발동
- 같은 계열 게스트를 다수 모으면 **세트 보너스** 발동 (유사한 주제의 카드 × 수 → 조합 보너스)

### 조합·시너지
- 카드들은 "속성 계열" 존재: 불꽃·냉기·번개·어둠 등
- 한 슬롯에서 발동하면 연쇄 콤보 발생. 슬롯 순서가 콤보 체인에 영향
- 중복 카드 획득 시 **레벨업** (카드 강화 → 효과 수치 향상 + 추가 효과 해금)
- 희귀도: 일반 → 희귀 → 에픽 → 레전더리

### 던전 구조
- 각 층(레이어)마다 방 선택지 (전투·이벤트·보상·상점)
- 보스가 있는 층을 클리어하면 다음 세계로 이동
- 중간 세이브: 체크포인트마다 "서버 연결 끊기"(실제 세이브) 가능
- 노드맵 형식 — RunMap처럼 갈림길 선택

### 전투 디자인
- 실시간 액션 (공격·회피·카드 발동)
- 적의 공격은 **색상 경고 → 전조 → 발동** 순서 (너그러운 패링 가능)
- 플레이어는 항상 "자기 카드가 무엇을 하는지" 완전히 알 수 있음 → 불투명한 RNG 없음

---

## 플레이어들이 좋아하는 것

1. **카드 시너지 발견의 즐거움** — 예상 못 한 조합이 폭발적인 효과를 낼 때 카타르시스
2. **NPC 각각의 개성** — 카드마다 스토리와 대사가 있어 세계관 몰입도 높음
3. **중간 세이브** — "한 세션에 끝내야 한다"는 압박 없음, 가볍게 플레이 가능
4. **한눈에 보이는 덱 상태** — 현재 조합·시너지 미리보기 UI가 항상 표시

## OnionCat 적용 포인트

### 장비 시스템 (v4) 비교
| Card-en-Ciel | OnionCat |
|---|---|
| 게스트 카드 = 장착 슬롯 | GearItem = 장비 슬롯 |
| 세트 계열 보너스 | Sun·Wind 세트 보너스 |
| 중복 카드 → 레벨업 | 중복 장비 → 레벨업 |
| 희귀도 4단계 | 희귀도 4단계 |

→ 거의 같은 구조. Card-en-Ciel의 **"슬롯 순서가 콤보에 영향을 준다"** 아이디어가 흥미로움:
  고양이가 연속 할퀴기를 할 때 **장착 순서에 따라** 발동 효과 체인이 달라지는 것도 고려 가능

### 세트 보너스 UI 힌트
- 현재 세트 계열 몇 개 모았는지 **런 도중 항상 작은 아이콘으로 표시**
- Card-en-Ciel처럼 "다음 세트 완성까지 N개" 를 HUD 한 구석에 보여주면 목표 의식 생김

### 중간 세이브 UX
- "서버 연결 끊기" 프레임으로 세이브를 **캐릭터 행위**로 표현 → 세계관 자연스러운 세이브 UI
- OnionCat도 "화분에 씨앗 심기 → 세이브" 같은 메타포 가능

### 적 공격 전조 색상
- 노랑 = 막을 수 있음 / 빨강 = 피해야 함 — OnionCat 설계 원칙과 완전 일치, 검증된 패턴
