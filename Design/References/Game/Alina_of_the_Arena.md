## 핵심 메카닉

### 덱 + 실시간 아레나 조합

Alina는 카드 덱빌딩과 실시간 격투를 합친 독특한 구조다.

- **카드 = 행동 슬롯**: 각 카드는 이동, 공격, 방패, 특수기를 나타냄. 매 "턴" 패를 보고 카드를 순서대로 선택
- **실시간이지만 카드 선택은 일시 정지**: 카드 선택 화면이 열리면 아레나가 멈추고, 선택 후 캐릭터가 연속으로 행동을 수행
- **공간 활용이 핵심**: 카드만 잘 쌓아도 안 됨 — 실제 아레나에서 위치를 잡고, 투사체를 피하고, 옆구리를 치는 것이 필요
- **에너지 관리**: 각 카드는 에너지를 소비. 한 턴에 쓸 수 있는 카드 수 제한

### 카드 시스템 세부

```
기본 카드 종류:
- Slash (공격): 근접 범위, 에너지 1
- Heavy Slash: 넉백 추가, 에너지 2  
- Block (방패): 다음 피해 1회 무효
- Step: 1칸 이동
- Dash: 2칸 이동 + 무적 프레임
- Counter: 블록 후 반격 발동

에픽/레전더리 카드:
- Spinning Slash: 주변 360° 타격
- Piercing Thrust: 직선 관통
- Riposte: 블록 성공 시 2배 반격
```

### 아이템 / 세트 보너스

- **렐릭(유물) 시스템**: 런 중 획득한 유물이 카드 행동을 강화
  - "블록 후 카드 1장 추가 드로우"
  - "대쉬 카드가 불 웅덩이를 남김"
  - "에너지 사용량 1 감소 (최소 0)"
- **카드 업그레이드**: 같은 카드 여러 장 획득 시 강화. Slash+Slash = Enhanced Slash (피해 +50%)
- **세트 연시너지**: 특정 조합 (방패+반격 카드 3장 이상) 시 별도 보너스 발동

## 플레이어들이 좋아하는 것

1. **전략 + 반사신경의 절묘한 균형** — 카드 선택은 체스, 실행은 액션. "생각하는 액션게임"
2. **빌드 다양성** — 근접 중심 / 방패-반격 / 광역기 / 속도 덱 등 판마다 완전히 다른 플레이
3. **즉각적인 피드백** — 카드를 쓰면 바로 화면에서 결과가 보임
4. **짧은 런 사이클** — 판 하나가 30~40분으로 부담이 적음

## OnionCat 적용 포인트

### 1. 마법서 차별화 — 행동 방식이 달라야 한다

Alina에서 카드마다 "쓰는 방법"이 다름. OnionCat 마법서도:

```
1번 마법서 (즉발형): 클릭 즉시 작은 범위 발사 — 빠르지만 조준 필요
2번 마법서 (차지형): 0.3초 충전 후 넓은 범위 발사 — 적이 뭉칠 때 효과적
3번 마법서 (배치형): 사용할 때마다 발동 위치가 순환 — 패턴 외우면 강력
```

현재 1~3번이 "쿨타임과 범위만 다름"이라면 Alina에서 배운 것처럼 **발동 방식 자체**를 다르게 해야 플레이 감촉이 구분됨.

### 2. 블록 카드 → OnionCat 패링 연결

Alina의 Block+Counter 조합은 OnionCat의 작물 실드+패링과 직접 대응:
- Alina: Block 카드 쓰면 피해 1회 무효 → Counter 카드 써서 2배 반격
- OnionCat: 실드 발동 → 패링 성공 시 반격 피해 증폭

Alina의 Block 카드 업그레이드 경로 참고:
```
Block → Parry Block (패링 판정 추가) → Perfect Parry (무적 시간 더 넓음)
```
→ 장비로 패링 창을 늘리거나, "패링 성공 시 쿨타임 초기화" 같은 효과 적용 아이디어

### 3. 에너지 관리 → 씨앗 탄약 경제

Alina에서 에너지를 아껴서 더 중요한 카드에 쓰는 판단이 핵심.
OnionCat에서 씨앗 탄약(잡몹에게 과소비 금지, 보스 등장 전 아끼기)도 비슷한 경제 구조.

**씨앗 회복 시스템** 아이디어:
```
- 근접 공격(고양이)이 적을 때릴 때마다 씨앗 소량 회복 → 협동을 강요
- 씨앗이 0개일 때 "빈 주먹 사격" (약한 무료 공격) → 양파가 완전히 쓸모없지 않게
```

### 4. 덱 빌딩 → OnionCat 장비 조합 대입

Alina의 렐릭 조합 로직을 OnionCat 장비 세트 보너스에 적용:
- Alina: "대쉬 카드 3장 이상이면 대쉬마다 불 발자국"
- OnionCat: "바람 세트 2단계 — 대쉬 완료 후 0.5초 이동 속도 보너스"

현재 세트 보너스가 "수동 패시브"라면, Alina처럼 **행동 연계 발동**으로 바꾸면 더 재미있음.

### 5. 짧은 런 사이클 — 판 길이 조절 참고

Alina 한 판 30~40분 vs. OnionCat 목표 1시간. OnionCat이 더 길기 때문에:
- 중간 저장(이미 구현) 중요성 재확인
- 런 전반부는 쉽고 빠르게 → 후반부에 집중 (페이싱 설계)
- "지금 얼마나 왔나" HUD 진행도(이미 갈림길 지도로 해결됨)
