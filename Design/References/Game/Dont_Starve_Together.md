# Don't Starve Together

리서치 날짜: 2026-11-11

## 기본 정보

- **개발사**: Klei Entertainment (캐나다 인디)
- **장르**: 멀티플레이어 협동 생존 로그라이크

## 핵심 메커니즘

### 비대칭 캐릭터 시스템
캐릭터 20종 이상이 각각 완전히 다른 플레이스타일:
- **Wilson** (기본): 긴 수염 → 자원, 무난한 능력
- **Willow** (불꽃 마녀): 불을 다루고 정신력이 불로 회복, 단 불로 아군을 태울 수 있음
- **Wendy**: 죽은 쌍둥이 유령 Abigail을 소환, 전투 보조
- **WX-78**: 로봇, 아이템 먹으면 업그레이드, 비에 취약
- **Wolfgang**: 충분히 먹으면 힘이 세짐, 굶으면 약해짐

**교훈**: 같은 목표(생존)를 향해 각자 다른 방식으로 기여하는 디자인.

### 공유 세계 + 비대칭 역할
- 한 플레이어가 베이스 캠프 관리 + 다른 플레이어가 탐험 채집
- 아이템·자원 공유 필요 (진정한 협동)
- 각자가 없으면 힘든 상황 유도 → 협동 가치 명확

### 압박 시스템 3축: 허기·정신력·체력
- 세 수치를 동시에 관리 → 항상 뭔가 부족한 느낌 (긴장감 유지)
- 허기 = 행동 제약 / 정신력 = 환각 등 패널티 / 체력 = 생존
- **하나를 올리면 다른 걸 소비**하는 구조 → 선택의 압박

### 세계 지속성 (영구 세계)
- 죽어도 귀신으로 2D 맵을 돌아다닐 수 있음 → 완전한 게임오버 아님
- 아군이 부활시켜 주거나 자가 부활 아이템 필요 → 협동의 이유
- 세계가 로그라이크와 달리 **계속 쌓임** → 성취의 기록

### 계절 시스템
- 봄·여름·가을·겨울이 순환하며 도전이 변화
- 겨울: 추위로 체온 관리 / 여름: 더위로 과열 위험 / 봄: 비 많음
- 같은 세계도 계절마다 다른 전략 → 장기 흥미 유지

## 협동 디자인 분석

### 왜 같이 해야 하는가?
1. **캐릭터 시너지**: Wendy의 유령 + 전투 특화 캐릭터가 보스에서 강력
2. **역할 분담 자연 발생**: 한 명이 베이스, 한 명이 탐험
3. **부활 메커니즘**: 죽은 파트너를 살려야 → 진정한 상호의존
4. **자원 공유**: 아이템 떨어트려 주기 → 소통 필수

### 협동 마찰 (의도된)
- 혼자서는 보스 버겁지만 같이 하면 여유로움 → 협동 보상
- 실수한 파트너를 비난하고 싶어지는 순간 → "함께 극복" 서사
- 아이템을 뺏거나 위험한 행동을 하는 경우 → 협의 필요

## 플레이어들이 사랑하는 점

1. **독특한 세계관** — 버튼 고딕 느낌의 아트, 어둡지만 귀여운 미학
2. **캐릭터 다양성** — 플레이스타일이 완전히 달라 "내 캐릭터"가 생김
3. **무한한 도전** — DLC와 업데이트로 10년 이상 콘텐츠 추가
4. **교류** — 파트너와 소통하며 함께 위기 극복하는 쾌감
5. **겸손한 시작** — 아무것도 모르는 상태에서 천천히 배우는 재미

## OnionCat 적용 포인트

### 1. 비대칭 캐릭터 → 고양이·작물 역할 차이 강화
DST의 캐릭터들이 "같은 세계에서 다른 역할"을 하듯, OnionCat의 고양이·작물은:
- 고양이: 이동·근접·물리적 솔루션 담당
- 작물: 원거리·버프·필드 관리 담당
**교훈**: 각 역할이 없으면 명확하게 약한 상황을 의도적으로 설계
  - 원거리 적이 많은 방 = 작물 플레이어 활약
  - 근거리 돌격 적이 많은 방 = 고양이 플레이어 활약

### 2. 압박 3축 → OnionCat 자원 관리 힌트
HP·실드·합동 게이지를 "항상 하나가 아슬아슬"하게 유지하는 설계:
- 실드가 꽉 차 있으면 너무 쉬움 → 소모와 회복 주기를 짧게
- 합동 게이지가 없으면 협동 플레이가 줄어듦 → 사용을 장려하는 상황 유도

### 3. 역할 자연 발생 → 선택 강요 않기
DST는 역할을 강제하지 않고 자연스럽게 발생시킴. OnionCat:
- "고양이 먼저 돌진하고 작물이 마무리" 같은 패턴이 의무가 아닌 선택
- 그러나 그렇게 하면 더 효율적인 상황 설계
- 협동 콤보가 "강제"가 아니라 "더 쉬워지는 방법"으로 작동

### 4. 부활/회복 메커니즘 → 여유로운 실패 허용
DST의 귀신 상태처럼, OnionCat의 HP가 0이 돼도 즉시 게임오버가 아닌 완충 구간:
- 현재: HP 0 → 게임오버
- 개선 아이디어: HP 0 시 "빈사 상태" 10초 → 그 안에 특정 조건(패링 성공, 특수 발동)으로 회복 가능
  → 협동의 긴박한 순간 창출

### 5. 세계관 아트 방향성 — 일관성 있는 미학
DST의 버튼 고딕 미학이 모든 UI·아이템·적에서 일관됨.
OnionCat도 "귀엽지만 긴장감 있는 픽셀아트" 미학을 UI·이펙트·폰트까지 통일:
- Galmuri11 한글 폰트가 귀여운 톤과 맞음 — 영문도 같은 계열 고수
