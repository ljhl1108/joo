## 핵심 메커니즘

### 시간 압박 난이도 시스템
Risk of Rain Returns(이하 RoRR)의 가장 독창적인 시스템:
- 게임 내 시간이 흐를수록 **적이 강해지고 스폰 속도가 빨라짐**
- HUD 왼쪽에 타이머와 난이도 단계 표시
- 아이템을 많이 먹을수록 빨리 움직여야 함 → **빠른 게임 속도 강제**
- 이 한 가지 규칙이 모든 전략적 결정을 유도: "지금 진행할까, 더 파밍할까?"

### 캐릭터 시스템
- 15개 언락 가능 캐릭터 (Commando, Huntress, Bandit 등)
- 각 캐릭터는 4가지 스킬, 고유 패시브
- **잠금 해제 조건**: 특정 미션/도전 달성 (메타 진행)
- 2인 협동 시 두 플레이어가 다른 캐릭터 선택 → 자연스럽게 역할 분화

### 아이템 & 빌드
- 런마다 랜덤 아이템 드롭 (Common/Uncommon/Rare/Boss)
- **스택 시스템**: 같은 아이템 중복 획득 시 효과 배수 증가
- 예: Gasoline 1개 = 불 번짐, 5개 = 대형 폭발 → 아이템 조합이 핵심 전략

### 2D 맵 & 적 스폰
- 6개 고유 환경 (Dried Lake, Hive Cluster 등) → 각 환경 전용 적
- **랜덤 스폰**: 적이 지형 어디서나 나타남, 예측 불가능
- 보스: 타이머 일정 이상 지나면 소환 (강제 전투)

### 픽셀아트 스타일 (리마스터 특징)
- 원작의 픽셀아트를 **HD화**: 더 선명한 스프라이트, 부드러운 애니메이션
- 동적 라이팅, 파티클 이펙트로 현대화
- **중요**: 픽셀 스케일 × 2~4 방식이 아닌 완전 리드로우 → 픽셀아트의 "정체성" 유지하면서 현대화

## 2인 협동 분석

### 로컬 협동 특성
- 화면 공유 방식 (둘 다 같은 화면)
- 한 명이 죽으면 팀원이 소생 아이템 없인 부활 불가 → 긴장감
- **아이템 경쟁**: 같은 아이템 두 명이 동시 못 먹음 → "네가 먹어" 소통 필요

### 역할 자연 분화
- Commando(균형) + Huntress(기동력) 조합 = 탱커/딜러 분업
- 이 분업이 강제가 아닌 **캐릭터 고유 특성으로 자연 발생**
- OnionCat이 배워야 할 설계: 시스템이 협업을 강제하되, 플레이어가 선택한 것처럼 느끼게

## 플레이어들이 좋아하는 것

1. **시간 압박의 긴장감**: "조금만 더 파밍"하다 죽는 아찔한 순간이 핵심 재미
2. **아이템 조합의 창발성**: 기대 못한 조합이 강해지는 발견의 기쁨
3. **빠른 게임 속도**: 30분~1시간 안에 한 런 완성
4. **언락 시스템**: 도전 미션으로 캐릭터/아이템 잠금 해제

### 비판받는 점
- 후반 화면이 너무 복잡해 가시성 저하 ("쥐포" 현상)
- 초보에게 설명 없이 던져지는 스팀
- 2인 이상 협동 시 균형 파괴 가능

## OnionCat 적용 포인트

### 1. 시간 압박 시스템으로 런 템포 조절
RoRR의 타이머 기반 난이도 스케일링은 OnionCat에 매우 적합:
- 방 안에 머무는 시간이 길어질수록 적 강도 상승 (Cat 이동 촉구)
- 타이머 HUD 표시 → 플레이어가 속도 vs 안전 선택
- 구현: `float roomTime` 값으로 `EnemySpawner.spawnRate`와 `Enemy.statMultiplier` 제어

### 2. 아이템 스택 시스템 → 단순하지만 강력한 업그레이드
단순히 +10% 대미지 아이템도 5번 먹으면 +50% → 느껴지는 성장감.
OnionCat에서 업그레이드 설계 원칙:
- Cat용 업그레이드 (대시 쿨다운 -20%) 스택 5회 → 거의 무제한 대시
- 이런 극단적 빌드 허용이 재미의 핵심

### 3. 픽셀아트 현대화 접근법 참고
RoRR이 원작을 리드로우한 방식:
- 스프라이트 해상도를 올리되 "픽셀 느낌" 유지
- OnionCat: 캐릭터는 16×16px, 환경 타일은 32×32px 기준으로 통일
- Filter Mode = None, PPU 통일이 핵심 (→ Sprite Atlas 파이프라인 참조)

### 4. "쥐포" 방지 설계
RoRR 후반의 화면 혼잡 문제를 OnionCat은 미리 예방:
- 최대 동시 투사체 수 제한
- 적 스폰 최대 10마리 → 추가는 기존 적 제거 후
- Z-Order 레이어 분리로 핵심 요소(플레이어, 보스) 항상 최상위
