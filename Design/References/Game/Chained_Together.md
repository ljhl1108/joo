## 한 줄 요약

플레이어들이 물리 시뮬레이션 체인으로 연결된 채 지옥 탈출을 시도하는 2D 협동 플랫포머. 한 명이 떨어지면 모두 끌려 내려간다.

## 핵심 메커니즘

### 체인 연결 물리
- 플레이어 간 체인 길이 고정 — 너무 멀어지면 당겨짐
- 체인이 오브젝트에 걸려 지렛대/도르래 역할 가능
- 체인 장력으로 동료를 올려주거나 흔들어서 점프 거리 연장

### 협력 필수 구조
- 높은 플랫폼: 한 명이 위에서 잡아주면 다른 사람이 올라감
- 위험 구간: 먼저 건너간 사람이 체인을 팽팽하게 당겨 다리 역할
- 동기화 점프: 동시에 점프하지 않으면 체인에 발목이 잡혀 실패

### 난이도와 카오스
- 2명 이상(최대 4명) 플레이 시 카오스 폭발적 증가
- 한 명의 실수가 체인 반응으로 전체 실패 유발
- 스트리밍에서 극적 장면 연출 → 바이럴 성공 요인

## 플레이어가 열광하는 이유

1. **공유된 고통** — 한 명이 실수해도 모두 같이 떨어지는 공동 책임감이 웃음 유발
2. **물리 장난감** — 체인 물리가 예측 불가능해서 매번 다른 상황 연출
3. **저렴한 가격** — 6달러로 친구와 즉흥 플레이 가능한 접근성
4. **스트리머 친화적** — 극적 장면이 클립으로 잘 잘림

## OnionCat 적용 포인트

### 1. 물리적 연결감 강화
현재 Cat+Onion은 "Cat이 Onion을 등에 업은" 구조지만, Chained Together처럼 **물리적 연결감**을 상황별로 느끼게 할 수 있음:
- 특정 능력(Cat의 대시)을 쓰면 Onion 화분이 흔들리는 Secondary Motion 연출
- Onion 조준 중 Cat의 이동 속도 소폭 감소(조준 집중 상태 표현)
- 대시 급정지 시 화분이 앞으로 기울었다 원위치되는 관성 연출

### 2. 공동 책임 설계
Chained Together의 "한 명이 죽으면 모두 죽는" 구조처럼, OnionCat도 Cat이 사망하면 Onion도 자동 사망하는 현재 설계가 동일한 긴장감을 만든다. 이 구조를 역으로 활용:
- Cat이 스턴 상태일 때 Onion이 치료 아이템을 조준해서 "먹여주는" 액션 추가 가능
- "연결된 하나의 몸"이라는 서사를 기계적으로도 강화

### 3. 수직 레벨 디자인 참고
Chained Together는 아래서 위로 올라가는 수직 구조가 핵심. OnionCat은 탑다운이지만:
- 층 진입을 "내려가는 방향"으로 설정해 던전 깊이감 연출
- 각 방 클리어 후 계단 내려가는 짧은 전환 애니메이션 추가 가능

### 4. 체인 장력 업그레이드 아이디어
Chained Together에서 체인 길이 조정이 전략이 되듯이, OnionCat에서도:
- 업그레이드로 Cat 대시 중 Onion 조준 방향이 대시 방향으로 0.2초 고정 (체인 장력처럼 당기는 느낌)
- 이 업그레이드는 Cat의 기동성과 Onion의 정확도를 동시에 높여주는 시너지형 업그레이드
