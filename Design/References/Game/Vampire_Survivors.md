리서치 날짜: 2026-08-17

- **장르**: 탄막 회피형 로그라이트 (Bullet Hell Survival Roguelite)
- **개발사**: poncle (1인 개발 → 소규모 팀)

- **플랫폼**: PC, Console, Mobile
- **공식 사이트**: https://poncle.games/vampire-survivors
- **Steam**: https://store.steampowered.com/app/1794680/Vampire_Survivors/

## 핵심 게임 루프

### 기본 구조
- **목표**: 30분간 생존 (혹은 죽을 때까지 최대한 버티기)
- **승리 조건**: 보통 없음 — 생존 시간과 레벨이 점수
- **특징**: 플레이어는 이동만 하고 공격은 자동으로 발사됨

### 핵심 루프 (3단계)
1. **스폰 & 이동**: 적이 사방에서 몰려옴 → 플레이어는 이동으로 회피
2. **자동 공격**: 보유 무기가 자동으로 타격 — 조준 불필요
3. **레벨업 선택**: 경험치 수집 → 레벨업 → 3~4개 업그레이드 중 선택 (10초 제한)

### 시간 경과에 따른 곡선
| 시간 | 상태 |
|------|------|
| 0~5분 | 쉬움, 기본 무기 1~2개 |
| 5~15분 | 빠른 성장, 진화 시작 |
| 15~25분 | 화면이 탄으로 가득 참, 빌드가 완성됨 |
| 30분 | Death (보스 러시) 등장, 극한 생존 |

## 핵심 시스템

### 1. 무기 진화 (Evolution) 시스템
- **기본 무기 + 패시브 아이템** 조합 시 진화된 무기로 변형
  - 예: Whip + Hollow Heart → Bloody Tear
  - 예: Magic Wand + Empty Tome → Holy Wand
- 진화 조건: 두 아이템 모두 최대 레벨(LV8) + 보물 상자에서 진화 아이템 획득
- **OnionCat에 적용 가능**: 근접(Cat) + 원거리(Crop) 스킬이 특정 조건에서 합체기로 진화하는 시스템

### 2. 패시브 아이템 + 무기 시너지
- 패시브가 무기에 수치 버프를 줌 (이동속도, 쿨다운, 투사체 수, 넉백)
- 빌드 다양성의 핵심: 같은 무기도 패시브 조합에 따라 완전히 다른 느낌
- **OnionCat**: 공유 몸체라서 Cat이 올린 이동속도 패시브가 Crop의 조준 안정성에 영향을 주는 등의 연계 설계 가능

### 3. 적 스폰 웨이브 시스템
- 시간 기반으로 적 종류와 밀도가 증가 (`WaveConfig` 방식)
- 분마다 새로운 적 타입 등장, 보스는 10분 / 20분 / 30분에 고정 출현
- 화면 외곽에서 스폰, 플레이어 방향으로 직선 이동 (NavMesh 없음)

### 4. 경험치 보석 (XP Gem) 수집
- 모든 적 처치 시 XP 보석 드롭
- **자석(Magnet)**: 보유 시 일정 반경 내 XP 자동 흡수
- XP 흡수 → 레벨업 → 선택 화면 = 핵심 피드백 루프

### 5. 캐릭터 언락 시스템
- 런 중 특정 무기를 특정 레벨까지 올리거나 조건 달성 시 새 캐릭터 언락
- 각 캐릭터는 고유 시작 무기 + 패시브 보너스 보유
- **OnionCat**: "특정 협력 공격 X회 성공" 조건으로 새로운 캐릭터 스킨 언락 응용 가능

## 플레이어가 사랑하는 이유 (Steam 리뷰 분석)

1. **압도적인 성장감**: 30분 후 화면을 뒤덮는 공격이 쾌감을 줌
2. **원핸드 플레이**: 한 손으로도 플레이 가능 (이동만 하면 됨) — 모바일 성공의 핵심
3. **빌드 발견의 재미**: 진화 조합을 발견했을 때의 "Eureka" 순간
4. **짧은 런 + 빠른 성장**: 30분 = 적절한 런 길이, 지루하지 않음
5. **가격 대비 가치**: 저렴하고 컨텐츠가 계속 추가됨

## 단점 / 비판

- 후반부 단조로움: 강해지면 뭘 해도 이기는 느낌 → 도전성 하락
- 협력 요소 없음: 솔로 게임이라 친구와 함께 플레이 어려움
- 빌드 문해력 요구: 어떤 조합이 좋은지 모르면 효율이 크게 차이남
- 시각적 혼잡: 후반부에 화면이 폭발로 가득 차서 플레이어 위치 파악 어려움

## Coop 관련 분석

Vampire Survivors는 **기본적으로 솔로 게임**이다. DLC에 로컬 멀티플레이가 추가되었지만 협력 의존성은 거의 없음.

- 멀티 모드: 화면 공유, 각자 독립 빌드
- **협력 시너지 없음** — 이것이 OnionCat과 가장 큰 차별점

OnionCat은 P1/P2가 *반드시 협력해야만 하는 구조*로, VS의 솔로 중심 설계를 반면교사로 삼을 수 있음.

---

## OnionCat 적용 포인트

### 1. 자동 공격 vs 수동 조준의 하이브리드
- VS는 자동 공격으로 조작 부담 낮춤 → 쉬운 진입장벽
- OnionCat은 Cat(P1) 근접 자동화 가능, Crop(P2) 원거리 수동 조준 유지 → **P2가 핵심 전략 결정권**
- 쉬운 진입(Cat 자동) + 깊은 플레이(Crop 조준) 레이어링 설계 참고

### 2. 무기 진화 → 협력 합체기 (Coop Fusion Attack)
- VS 진화 시스템을 협력 공격에 응용:
  - Cat 슬래시 충전 중 Crop이 동일 타겟에 적중 시 **합체 공격 발동**
  - 조건: Cat이 일정 시간 동안 근접 3타 이상 + Crop이 같은 방향으로 투사체 명중
- 이 메커니즘은 플레이어 간 "비언어적 소통"과 타이밍 협력을 자연스럽게 유도

### 3. 시간 기반 난이도 곡선
- VS처럼 고정 파수 기반보다 **방 클리어 기반 + 시간 압박** 조합:
  - 방 클리어 시간이 길어질수록 적 밀도 증가 (타임 리밋 간접 압박)
  - 일정 층수마다 더 강한 적 유형 등장

### 4. XP 보석 → 협력 수집 보너스
- VS의 XP 보석을 OnionCat에서 변형:
  - Cat이 혼자 수집 시 1 XP, Crop과 근접 수집 시 1.5 XP (공유 몸체이니 기본 유지)
  - 적 처치 방식에 따라 보너스 XP: 근접 처치 + 원거리 처치 콤보 = XP 보너스

### 5. 빌드 문해력 → 협력 빌드 선택 UI
- VS는 선택지가 개인에게만 귀속됨
- OnionCat에서는 업그레이드 선택 시 P1/P2 중 *누가 혜택 받는지* 시각적으로 표시 필요
  - 아이콘: 고양이 🐱 (Cat 전용), 양파 🌱 (Crop 전용), 하트 ❤️ (공유)
  - Coop_Upgrade_Selection_UI.md 시스템과 연계

### 6. 시각적 혼잡 방지
- VS 후반부 시각적 혼잡 문제 → OnionCat은 탄막 밀도를 의도적으로 제어:
  - 적 최대 동시 투사체 수 제한 (30~40개)
  - 화면 안에 플레이어 가시성 확보: Cat 캐릭터 외곽선 항상 표시

## 핵심 메카닉

### 자동 전투 시스템
- **플레이어 입력**: 이동(WASD/조이스틱)만. 공격은 완전 자동
- **무기 자동 발사**: 방향·타이밍 모두 자동 계산
- 결과: 시각적 혼돈(총알 지옥)이지만 플레이어는 포지셔닝에만 집중 → 접근성 극대화

### 런 내 성장
- **경험치 & 레벨업**: 적 처치 → 경험 보석 드롭 → 레벨업 시 3가지 선택지
  - 새 무기 획득 / 기존 무기 레벨업 / 패시브 아이템 획득
- **무기 진화(Evolution)**: 특정 무기 MAX + 특정 패시브 아이템 보유 → 합체해 강력한 진화 무기 생성
  - 예: 채찍(MAX) + 빈 토톰 → 피의 채찍(진화)
- **파워 판타지**: 후반부엔 수천 마리 몬스터를 한 번에 쓸어버리는 쾌감

### 런의 구조
- **30분 런**: 타이머 종료 시 "저승사자(Death)" 등장 → 런 강제 종료
- 시간이 지날수록 몬스터 밀도·속도 증가
- 맵 탐색 요소: 상자, 무기 획득 지점, 비밀 캐릭터 해금

### 메타 진행
- **골드**: 런 중 적 처치/상자에서 획득 → 런 종료 후 보관
- **파워업(Power Up)**: 메인 화면에서 골드 소비 → HP, 이동속도, 쿨다운, 행운 등 영구 수치 증가
  - 각 수치 소액 증가 여러 단계 → 그라인딩 부담 최소화
- **캐릭터 해금**: 특정 조건(특정 무기 레벨 10 달성 등)으로 새 캐릭터 해금

## 플레이어가 사랑하는 것

1. **낮은 진입 장벽**: 1분 만에 게임 이해 가능. 이동만 하면 됨
2. **시각적 폭발감**: 화면을 가득 채운 총알 → 몬스터 한 방 처리 장면의 만족감
3. **비밀·발견의 기쁨**: 숨겨진 캐릭터, 무기 진화 조합 발견 → 커뮤니티 활성화
4. **짧은 런**: 30분 → 출퇴근 중에도 완주 가능
5. **실패해도 보람**: 런 실패해도 골드·경험 적립 → 영구적 성장감

---

## 1인 개발 교훈 (초보 개발자 시사점)

- **완성 우선**: Vampire Survivors는 그래픽 퀄리티보다 게임 루프 완성에 집중
- **무기 조합**: 소수의 아이템도 조합 가능성이 크면 콘텐츠 풍부하게 느껴짐
- **숫자의 마력**: 레벨업·골드 누적 숫자가 쌓이는 시각적 피드백 → 심리적 진행감
- **낮은 가격 + 높은 완성도** → 입소문 마케팅
