## 핵심 시스템

### 1. 에이징(연령) 메카닉 — 죽음의 가중치
- 사망 시 주인공이 늙는다 (20대 → 40대 → 70대+). 체력 최대치 감소, 공격력 증가
- **완전히 죽으려면 나이가 75세 이상일 때** — 소울라이크식 사망 패널티의 창의적 변형
- 나이를 되돌리는 방법: 보스 처치 후 "되살아남 경험치"로 감소
- **OnionCat 적용**: 런 중 죽음에 복잡한 의미를 부여. 현재 단순 체력 감소인 사망을 "대가 치르기"로 재설계 가능

### 2. 거리 기반 콤보 & 환경 활용
- 근접-중거리-원거리 동작이 체계적으로 분리, 각 범위마다 베스트 옵션 존재
- **환경 킬**: 선반 걷어차기 → 적 넘어뜨리기, 테이블 점프 공격, 벽 꽂기, 2층 발차기
- 모든 환경 오브젝트에 가볍게 상호작용 가능 — 개발 비용 대비 임팩트 극대화
- **OnionCat 적용**: 고양이가 적을 벽에 날려보내는 `Launch` → 벽꽝(`WallCrash`) 메카닉과 거의 동일. Sifu의 체계적 환경 연계 설계를 참고해 방 소품·구덩이와 콤보를 설계할 수 있음

### 3. 막기 & 패링 (Parry/Deflect) 시스템
- **가드**: 항상 가능, 구조(structure) 게이지 소모
- **패링(퍼팩트 타이밍 가드)**: 구조 게이지 소모 없음 + 카운터 기회
- 패링을 연속으로 성공하면 적의 구조가 무너져 "피니셔" 발동
- 타이밍 윈도우: 레이턴시를 고려해 넉넉하게 (약 15프레임), 하지만 보상이 명확히 다름
- 황색(가드 가능) / 적색(회피 필수) 텔레그래프 — OnionCat의 색상 체계와 완전히 일치
- **OnionCat 적용**: 패링 보너스(반격 대미지, 게이지 충전)가 "선택적 보상"이지 "필수"가 아닌 설계 → OnionCat의 "패링은 보너스" 원칙과 동일. 타이밍 윈도우 조정법 참고

### 4. 구조(Structure) 게이지
- 플레이어·적 모두 갖고 있는 보조 체력 같은 개념
- 가드를 계속 하거나 맞으면 구조가 무너져 경직(스턴) → 무방비
- 적의 구조를 먼저 무너뜨리는 게 효율적 전략
- **OnionCat 적용**: 현재 적에게 슈퍼아머(`Enemy_SuperArmor_Interrupt_System`)가 있음. "구조" 개념을 더 명시적으로 보여주는 HUD 아이콘이나 흔들림 연출 참고 가능

### 5. 적 AI — 수동적 협공 방지
- 복수의 적이 있어도 **한 번에 1~2명만 공격**, 나머지는 대기·포위 준비
- 적들이 서로 충돌하지 않게 자동 위치 조정
- 각 적에게 뚜렷한 역할(잡기형, 돌진형, 무기형) → 싸우면서 판독 가능
- **OnionCat 적용**: 현재 `EnemyBase.Active`로 적 목록 관리. 방 안 적이 동시에 덤비지 않게 간격 대기 로직, 역할별 공격 순번 조율 고려

### 6. 스킬 트리 — 영구 vs 런별
- 처음엔 모든 기술을 한 번만 쓸 수 있음 (일시 해금)
- 같은 기술을 여러 런에서 반복 구매하면 영구 해금
- 런 중 습득 → 메타 진행에 반영 → 다음 런에 처음부터 사용 가능
- **OnionCat 적용**: `MetaProgress` 영구 해금 시스템에 직접 대응. 온실 해금 비용 구조가 비슷한 원리

## 플레이어들이 사랑하는 것

1. **전투가 격투 게임 수준으로 깊다** — 콤보 연결, 적 순서, 환경 활용이 맞물림
2. **패배가 의미 있다** — 죽어도 배우는 게 있고, 나이 덕에 "다시 도전"이 의미를 가짐
3. **60fps에서 느껴지는 타격감** — 타격 소리, 히트스탑, 카메라 흔들림이 정교하게 맞물림
4. **각 보스가 완전히 다른 도전** — 보스별 패링 패턴을 외우는 재미

## OnionCat 직접 적용 포인트

| Sifu 시스템 | OnionCat 현재 상태 | 적용 방향 |
|---|---|---|
| 황색/적색 텔레그래프 | 동일 색상 체계 | 텔레그래프 지속 시간·크기 미세 조정에 Sifu 수치 참고 |
| 패링 타이밍 윈도우 15f | `Parry_Shield_System` | 패링 판정 프레임 조정 시 Sifu의 "넉넉하지만 보상이 다른" 원칙 유지 |
| 환경 킬 연계 | `Launch` → `WallCrash` | 방 소품에 환경 킬 콤보 가능성 추가 — 소품을 쓰러뜨리면 적에게 대미지 |
| 구조 게이지 | 슈퍼아머 인터럽트 | 적 경직 직전 비주얼 피드백(체내 흔들림) 추가 고려 |
| 적 공격 순번 조율 | 군집 AI | 방 적 최대 동시 공격 수 제한 로직 (`MaxSimultaneousAttackers`) |
| 메타 해금 구조 | 온실 시스템 | 현재 구조와 동일 — 가격 밸런스 참고 |

## 개발자 인터뷰 핵심

- **전투 개발 기간**: 1.5년, 플레이어블 프로토타입까지만 2명이 진행
- **패링 타이밍**: 처음엔 너무 엄격 → 플레이테스트에서 "불가능하다"는 피드백 → 판정창 2배 확대
- **에이징 메카닉**: 처음엔 단순 "죽음 횟수 카운터"로 시작, 나이 그래픽은 개발 말기에 추가
- **적 AI 협공 방지**: 의도적으로 "대기 행동"을 프로그래밍, 무작위 공격을 금지
