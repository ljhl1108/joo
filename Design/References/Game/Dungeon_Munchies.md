## 핵심 메카닉

### 음식 기반 성장 시스템
- **재료 수집 → 요리 → 능력 획득**: 던전에서 몬스터가 재료(고기·버섯·과일)를 드롭 → 쉐프 NPC에게 요리 의뢰 → 요리가 **영구 능력치 버프**이자 **스킬 액션**이 됨
- 음식마다 공격 방식이 다름: "낙지 볶음" = 원거리 촉수, "삼겹살 구이" = 근거리 불꽃, "과일 스무디" = 체력 회복 + 방어력 강화
- 한 번에 장착 가능한 음식 수가 제한(슬롯 6개) → 빌드 구성의 핵심

### 요리책 (Recipe Unlock)
- 새 던전 구역 진입 시 새 재료·레시피 언락
- 언락된 요리는 영구 보존(런 간 유지) → 일종의 메타 성장

### 사이드킥 시스템
- 요리로 소환되는 미니언(개구리, 오이 인간, 해파리 등)이 자동 전투 보조
- 플레이어 주변을 따라다니며 공격·방어 지원

### 전투 스타일
- 근접 + 원거리 혼합, 무기는 요리에 내장(별도 아이템 없음)
- 점프·대쉬 있음 (사이드스크롤 뷰)
- 도전과 실패가 허용적 — 죽어도 재료 일부는 유지

## 협동 요소

- **2인 로컬 협동** 지원 (Ver 1.0.7+)
- 두 플레이어가 **각자 요리 빌드**를 구성하고 조합 → 서로 다른 역할 분담
- 한 명이 근접 탱커 빌드, 다른 한 명이 원거리 서포터 빌드로 자연스러운 역할 분화
- 협동 콤보 개념은 없지만 미니언들이 두 플레이어 주위를 분산 배치

---

## 플레이어가 좋아하는 것

1. **요리 = 빌드** 개념의 신선함: 음식 이름과 시각 효과가 일치해 직관적
2. 다양한 요리 조합으로 매 런이 달라지는 체험
3. 세계관과 캐릭터의 따뜻하고 귀여운 분위기 (언데드 요리사 NPC, 재료가 되는 몬스터들)
4. 재료 수집의 RPG 루프가 로그라이트 긴장감과 잘 섞임

## OnionCat 적용 포인트

### 1. 식물(R 스킬) 확장 아이디어
- Dungeon Munchies의 "재료 → 요리 → 효과" 구조를 참고: 양파가 필드에 심는 것이 단순한 폭발물/방해물을 넘어 **식물 종류마다 다른 효과**를 가질 수 있음
  - 고추(심기) → 화염 웅덩이 / 구근 → 벽처럼 적 경로 차단 / 허브 → 방 안 HP 재생 오라
  - 현재는 박(폭발) 하나뿐이나 마법서 Q·W·E의 각 스킬로 심기 종류를 다르게 배분 가능

### 2. 장비 효과와 시각 연동
- 요리 이름이 즉시 효과를 연상시키듯, OnionCat 장비 효과도 아이콘·색상이 효과를 직관적으로 나타내야 함
  - 현재: 효과 이름 텍스트 → 개선: 작은 아이콘 + 1줄 요약 (비교 화면, 선택 카드)

### 3. 사이드킥 = 식물 자율 행동
- 미니언이 플레이어 주위를 따라다니며 돕듯, 양파가 심은 식물이 **적에게 능동적으로 반응**하는 방향도 가능
  - 예: 발아 씨앗이 근처 적이 접근하면 자동 발사 (현재 고유기 R '매운 양파'와 다른 방향)

### 4. 허용적 실패 설계
- Dungeon Munchies처럼 "죽어도 재료 일부는 유지"하는 구조 → OnionCat의 씨앗(공동 지갑)이 일부 런 간 유지되는 메타 성장 시드로 기능할 수 있음
  - 현재 씨앗은 런 내 소모 화폐. 죽었을 때 다음 런 시작 보정으로 "씨앗 1~5개 이월" 정도는 진입 장벽 완화에 효과적
