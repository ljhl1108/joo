# Stardew Valley

리서치 날짜: 2026-11-28

## 기본 정보

- 개발사: ConcernedApe (Eric Barone, 1인 개발)
- 출시: 2016년 2월 (PC) → 모든 플랫폼 이식
- 공식 사이트: https://www.stardewvalley.net/
- Steam: https://store.steampowered.com/app/413150/Stardew_Valley/
- 위키: https://stardewvalleywiki.com/

## 핵심 메카닉

### 작물 재배 사이클
- **씨앗 → 성장 → 수확** 사이클이 게임의 기본 루프
- 각 씨앗은 성장에 계절별 일수 필요 (순무 4일, 딸기 8일 등)
- 계절이 바뀌면 한 계절 작물은 죽음 → 계획적 재배 강제
- **물주기**: 매일 작물에 물을 줘야 성장. 스프링클러 장비로 자동화 가능
- **품질**: 비료 사용 시 황금/다이아 품질 → 더 높은 판매가
- **특수 작물**: 고대 과일(모든 계절 · 1주마다 반복 수확), 커피(봄/여름 · 2일마다 수확)

### 성장 & 보람 시스템
- **커뮤니티 센터 번들**: 다양한 작물·물건을 모아 제출 → 마을 복구
- **쿠킹**: 작물 조합 → 체력/에너지 버프 음식
- **선물하기**: 마을 주민 특정 작물 좋아함 → 호감도 상승
- **장인 가공품**: 작물 → 주스·와인 (에이징 가능) → 가치 2~3배

### 협동 모드 (1.5 업데이트)
- 최대 4인 동시 플레이
- **공유 자원**: 금화·창고·농장 공유
- **개별 체력/에너지**: 각자 HP·에너지 별도 관리
- 한 명이 쓰러져도 나머지가 계속 플레이 가능
- **협동 긴장**: 한 명이 돈을 다 쓰면 다른 플레이어도 영향받음
- 플레이어별 개인 방 → 각자 아이템 보관 가능
- **공동 목표**: 커뮤니티 센터 번들은 모두 함께 완성

### 경제 시스템
- 초반: 작물 직접 판매 (저가치)
- 중반: 가공품 제조 (와인·치즈·피클 등) → 수익 2~3배
- 후반: 고가치 반복 작물 + 가공품 라인 최적화
- **선택의 여지**: 빠른 단기 수익 vs. 느린 장기 고수익

### 풀가능성 / 수집 요소
- 낚시 · 광산 · 요리 · 도감(동물·물고기·광물·유물 등)
- 모든 아이템을 "완성" 운반하면 100% 완성 → 별도 엔딩

## 플레이어들이 사랑하는 것

1. **자기 페이스로**: 강제 목표 없이 자기 하고 싶은 걸 하는 자유
2. **작은 보람**: 매일 성장하는 작물, 돈이 조금씩 쌓이는 느낌
3. **수집의 즐거움**: 도감 채우기, 번들 완성
4. **캐릭터 관계**: 주민들이 개성 있고 대사가 많음 → 애착 형성
5. **1인 개발의 따뜻함**: Eric Barone의 세심한 디테일과 완성도

## OnionCat 적용 포인트

### 1. 작물 고유성 차별화
Stardew에서 작물마다 계절·수확 주기·가공 방식이 달라 각자 쓸모가 있음.
OnionCat에서도 작물마다 단순 "탄 색 다름" 이상의 뚜렷한 플레이 차이를 줄 것:
- 양파: 빠른 연사, 짧은 사거리 → 근접 지원형
- 해바라기: 충전 후 큰 광선 → 고위험-고보상형
- 푸른 버섯: 독 포자탄, 장판 설치형 → 전략형

### 2. 작물 성장 느낌을 런 내에서
Stardew의 "씨앗이 하루하루 자라는 모습" 같은 시각적 성장감.
OnionCat에서는 화분의 작물이 보스를 잡을수록 더 무성하게 자라는 연출(잎사귀 늘어나기 등)
→ 성장감을 시각적으로 표현, 현재 `CatArtRenderer`의 작물 attachment 시스템 활용 가능

### 3. 협동 경제와 공유 자원의 긴장
Stardew 협동에서 금화가 공유되어 "한 명이 낭비하면 같이 손해"인 긴장감.
OnionCat의 씨앗(소모품)·아이템 가방 공유도 같은 원리.
→ 씨앗 쓸 때 작물 플레이어가 OK 사인 보내는 UI 고려? (공유 가방 선택 시 양쪽 HUD에 하이라이트)

### 4. 가공 개념 → 장비 시너지
Stardew에서 "작물 → 가공품" 가치 상승처럼,
OnionCat에서 세트 보너스가 "1개 장착보다 2개 세트가 훨씬 강한" 비선형 가치 상승.
세트 보너스 2단계 활성화 시 HUD에서 작물이 살짝 빛나는 연출로 "합쳐져서 더 강해졌다" 느낌 강화

### 5. 로그라이크 재배 루프
Stardew가 "심다 → 기다린다 → 거둔다"의 반복을 중독적으로 만드는 방식:
- 매 행동마다 즉각적 피드백 (물주기 사운드, 쑥쑥 자라는 애니메이션)
- 짧은 성취 사이클 + 더 큰 목표 (번들)
OnionCat도 "방 클리어 → 장비 선택 → 다음 방"의 사이클에 작은 시각 피드백을 꾸준히 더할 것

### 6. 1인 개발 완성도의 비결
ConcernedApe가 4년에 걸쳐 혼자 완성한 방법:
- 초기부터 핵심 루프 완성 → 살 붙이기 순서
- 커뮤니티 피드백 적극 반영 (Steam Early Access 아님 — 완성 후 출시, 그러나 지속 무료 패치)
- "지금 당장 플레이하고 싶은가?"를 기준으로 feature 추가
