# Dungeon Fighter Online (던전앤파이터)

리서치 날짜: 2026-10-17

## 기본 정보

- 개발: Neople (Nexon 계열, 한국)
- 장르: 벨트스크롤 액션 RPG / 한국 대표 온라인 액션 게임
- 공식 사이트: https://df.nexon.com/
- 글로벌: 누적 8억 명 이상 (2023 기준, 중국 포함)
- 플랫폼: PC (Windows), 모바일 (DNF Duel은 콘솔)
- 출시: 2005년 (한국), 현재까지 운영 중

## 핵심 시스템

### 1. 벨트스크롤 액션 구조
- 2D 횡스크롤 던전을 방 단위로 클리어
- 각 방에 적 웨이브 → 모두 처치 → 다음 방으로
- **OnionCat과 가장 유사한 구조**: 방 단위 진행, 방 클리어 → 보상/이동

### 2. 100개 이상의 캐릭터 클래스
- 기본 직업 → 1차 전직 → 2차 전직 → 오버마인드 전직
- 각 직업마다 완전히 다른 콤보 패턴과 캔슬 기술
- **총사, 격투가, 마법사, 성직자, 도적, 건너, 슬레이어** 등 대계열

### 3. 장비 세트 시스템 ⭐ (OnionCat 핵심 참고)
DFO의 장비 시스템은 매우 정교하다:

```
장비 칸: 무기, 상의, 하의, 어깨, 벨트, 신발, 넥, 팔찌, 반지, 보조장비, 칭호 등

세트 구성:
- 2조각 세트 효과: 기본 스탯 증가
- 3조각 세트 효과: 특정 스킬 강화 또는 특수 메커니즘
- 5조각 세트 효과: 강력한 세트 전용 효과 활성화
- 전체 세트 효과: 빌드 정체성을 완전히 바꾸는 핵심 효과

예시) "그란트 시리즈" 세트:
- 3조각: 특정 스킬 쿨다운 감소
- 5조각: 스킬 사용 시 추가 타격
```

**세트 설계 원칙 (DFO):**
- 각 콘텐츠 티어마다 세트 등급 존재 (일반 → 레이드 → 최상위)
- 세트를 완성하는 데 시간이 걸릴수록 기대감 상승
- "어떤 세트로 갈 것인가"가 캐릭터 성장 방향을 결정

### 4. 캔슬 콤보 시스템
```
기본 공격 → 스킬 캔슬 → 다른 스킬로 캔슬 → 연속 딜
적을 공중에 띄운 상태(에어리얼) 유지하며 콤보 연장
공중 콤보 vs 지상 콤보 전략 선택
```
- **콤보 중에 적이 무력화** → 플레이어는 계속 타격 가능 → 통제감
- 고급 테크닉: 딜레이 캔슬, 잡기 캔슬, 이동 중 스킬

### 5. 던전 타입 다양성
- 일반 던전: 방 클리어 형식, 30개 안팎 방
- 레이드: 20명 협력으로 대형 보스 패턴 격파
- 세계관 여행: 스토리 진행 전용
- PvP 모드: 단련장

### 6. 성장 루프
```
1. 스토리 던전으로 레벨업
2. 에픽 장비 파밍 시작
3. 세트 완성을 향해 파밍
4. 세트 완성 → 최적화 시작
5. 신규 콘텐츠/레이드 도전
```

## 플레이어가 사랑하는 것

1. **직업별 강한 정체성**: 어떤 직업을 선택하느냐가 완전히 다른 게임 경험
2. **콤보의 깊이**: 입문은 쉽지만 마스터하기 어려운 조작 깊이
3. **세트 완성의 성취감**: 조각 모으기 → 세트 완성 → 전투력 급등의 쾌감
4. **장비 경제**: 교환 가능한 장비로 트레이딩 요소 (OnionCat에는 불필요)
5. **업데이트 주기**: 꾸준한 신규 직업/콘텐츠 추가로 10년 이상 운영

## OnionCat 적용 포인트

### A. 방 단위 진행 구조 확인
```
DFO: 방 → 방 → 방 → 보스
OnionCat: 방 → 보상 선택 → 방 → 특수 방 → 보스

DFO에서 배울 것:
- 각 방 입장 시 "여기엔 이런 적이 나온다"는 암시 (적 그림자, 소리)
- 보스방 입장 직전 연출: 문이 잠기고 분위기 전환
- 방 클리어 순간 XP/골드 날아오는 연출 → OnionCat의 씨앗 획득 연출 참고
```

### B. 콤보 통제감 → 걷어차기 시스템 연계
```
DFO: 적을 공중에 띄우면 콤보 연장 가능 → "통제권"
OnionCat: 걷어차기로 적을 날림 → 벽 충돌 → CRASH

DFO에서 배울 것:
- 날아가는 적이 다른 적과 충돌 시 피해 (현재 OnionCat도 이 구현 있음)
- "적을 날리면 처치 확률 상승"이라는 인센티브
- 날아간 적이 구덩이에 빠지는 낙사 판정 (현재 구현됨)
→ 걷어차기의 전략적 깊이를 더하는 요소 참고
```

### C. 에어리얼 콤보 → 협동 콤보 연계
```
DFO: 한 플레이어가 적을 띄우면 다른 플레이어가 에어리얼 콤보
OnionCat: 고양이가 킥으로 적을 날리면 양파가 연속 사격

이 순간을 "협동 콤보" 보너스와 연결:
- 킥 직후 일정 시간 안에 양파가 맞추면 콤보 게이지 보너스
- 시각적으로 "좋은 타이밍!" 표시 → 협동의 재미 강화
(이미 구현된 협동 콤보 시스템에 킥→원거리 콤보 특화 강화 가능)
```

### D. 세트 조각 파밍 루프의 심리학
```
DFO 패턴:
- "3조각 세트 효과만 있어도 이미 쓸만하다" → 조기 보상
- "5조각 완성하면 완전히 달라진다" → 장기 목표
- 마지막 한 조각이 안 나올수록 조급함 → 릴리프 효과

OnionCat 장비 루프:
- 세트 2/4단계 효과가 조기 보상 역할 (현재 구현됨)
- 런 안에서 같은 세트 조각이 보상으로 나올 확률 조절이 중요
- "다음 방에서 저 세트 완성될 것 같다"는 기대감 유지 필요
```

### E. 직업 정체성 → 할퀴기 변형(ClawStyle) 참고
```
DFO: 직업에 따라 완전히 다른 콤보/기술 패턴
OnionCat ClawStyle: 회전/도약/3타/연타로 할퀴기 변형

DFO 교훈:
- 각 변형이 "전략적 선택"이 되려면 상황별 유불리가 명확해야 함
- 회전 할퀴기: 범위 우수, 단일 데미지 낮음
- 도약 할퀴기: 이동 + 공격, 적 뛰어넘기 가능
- 이런 기능적 차이를 명확히 해야 선택에 의미 생김
```

## 기타 메모

- **DNF Duel** (2022): DFO IP를 이용한 격투게임 (ArcSystemWorks 제작) → 픽셀아트 스타일 그래픽, 캐릭터들의 화려한 필살기 연출 참고
- DFO는 "무과금 플레이 가능하지만 시간이 오래 걸린다"는 설계 → OnionCat은 런 기반이라 무관하지만, 파밍 루프 설계의 교과서
- 한국 넥슨이 개발/운영 → 한국 유저 정서에 맞는 빠른 템포, 화려한 스킬 이펙트, 강한 타격감이 특징
- **Neople의 신작 DNFM (모바일)**: 같은 IP의 3D 버전 → 원작 2D 액션감을 3D로 옮기는 방법 참고 가능
