## 핵심 메카닉

### 인벤토리 = 전투 시스템
- 배낭(Backpack) 그리드가 곧 무기/스킬 장착 시스템
- 아이템을 그리드의 어느 칸에 놓느냐에 따라 **인접 보너스**가 발동
  - 예: 검 옆에 숫돌 → 공격력 +2, 물약 옆에 냄비 → 효과 증폭
- 인벤토리 공간 자체가 업그레이드 대상 (더 큰 가방, 특수 포켓)

### 아이템 배치 퍼즐
- 동일 아이템 조합도 배치 순서에 따라 시너지 차이 발생
- 공간 최적화 퍼즐 요소 → "내 아이템 빌드"를 시각적으로 볼 수 있음
- 무게 제한(Weight Limit)이 있어 강한 아이템일수록 공간 많이 차지

### 턴제 전투
- 턴마다 배낭 아이템을 클릭하여 효과 발동
- 쿨다운 없이 대신 재사용 주기(인터벌)가 아이템마다 다름
- 전략적 순서 결정: 어떤 아이템을 먼저 사용할지가 중요

## 협동/멀티 요소

- 기본적으로 싱글플레이
- 팬들이 요청하는 협동 모드는 없음
- 단, **아이템 공유 개념**은 OnionCat에 직접 응용 가능

---

## 플레이어가 사랑하는 것

1. **빌드 다양성**: 수백 가지 아이템 조합 → "내 빌드" 느낌
2. **시각적 인벤토리**: 무엇을 갖고 있는지 한눈에 파악 가능
3. **인접 시너지 발견의 재미**: "이거 옆에 놓으면 어떻게 될까?" 탐구
4. **짧은 런**: 1~2시간 내 완주 가능한 세션 길이
5. **명확한 피드백**: 아이템 효과가 숫자로 즉시 표시됨

## OnionCat 적용 포인트

### 업그레이드 선택 UI
- 현재 OnionCat은 런 중 업그레이드를 선택하는 방식
- Backpack Hero처럼 **업그레이드 슬롯 시각화**: 고양이 슬롯(근접) / 어니언 슬롯(원거리)을 그리드로 표현
- 아이템 간 시너지 표시 UI → 어떤 업그레이드가 다른 것과 궁합이 맞는지 색상으로 표현

### 근접/원거리 분리 업그레이드 풀
- Cat 전용 업그레이드 vs Crop 전용 업그레이드를 명확히 분리
- 일부 업그레이드는 "두 캐릭터 동시 강화"로 희귀도 높게 설정
- 배치 의사결정 → "이 런에서 근접 위주로 갈까, 원거리 위주로 갈까?"

### 인접 시너지 콘셉트
- 업그레이드 A를 먼저 획득한 상태에서 B를 얻으면 보너스 발동
- 예: [역습 업그레이드] + [방어막 업그레이드] = 패리 후 반격 피해 증가
- 별도 구현 없이 ScriptableObject 기반 시너지 테이블로 구현 가능
