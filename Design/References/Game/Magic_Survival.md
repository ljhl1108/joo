# 마법생존 (Magic Survival)

리서치 날짜: 2026-07-27

## 기본 정보

- **개발사**: Leme (한국 인디 솔로 개발자)
- **플랫폼**: Android, iOS (모바일)
- **장르**: 오토슈터 서바이버 로그라이크
- **출시**: 2018년 초기 버전, 이후 지속 업데이트
- **공식 링크**: Google Play / App Store 검색 "Magic Survival"
- **관련 글**: https://store.steampowered.com/app/1794680/Vampire_Survivors/ (후속 영향 게임 참고)

## 게임 개요

한국 인디 개발자 Leme가 혼자 만든 모바일 오토슈터 로그라이크. 플레이어는 자동으로 공격하며 몰려오는 적을 생존하고, 경험치로 레벨업 시 능력을 선택한다. **Vampire Survivors(2021)** 장르의 선구자 격 타이틀로, 국내외 커뮤니티에서 자주 언급된다.

---

## 핵심 메카닉

### 1. 오토슈터 (Auto-Shoot)
- 플레이어는 이동만 조작, 공격은 자동
- 가장 가까운 적 또는 랜덤 방향으로 투사체 발사
- **핵심 교훈**: 조작을 단순화하면 "빌드 고민"에 집중하게 됨

### 2. 레벨업 능력 선택
- 적 처치 → EXP → 레벨업 → 3~4개 중 1개 선택
- 능력 스택: 같은 주문 여러 번 선택 시 강화
- 시너지 발생: 특정 조합 보유 시 새 마법 해금
- **핵심 교훈**: 선택지 3개 법칙 — 너무 많으면 분석 마비, 너무 적으면 재미 없음

### 3. 시간 기반 서바이벌
- 정해진 시간(보통 20~30분) 동안 생존
- 시간이 지날수록 적 밀도·속도 증가
- 보스 등장으로 긴장 고조
- **핵심 교훈**: 긴장 곡선은 "시간+적 밀도" 조합으로 설계 가능

### 4. 빌드 다양성
- 화염, 냉기, 번개, 물리 계열 마법 존재
- 빌드마다 플레이 스타일 완전히 달라짐
- 런마다 다른 빌드 시도 → 반복 플레이 동기
- **핵심 교훈**: 다양한 빌드는 재플레이 가치의 핵심

### 5. 간소한 메타 진행
- 런 실패 시 재화 일부 획득
- 기본 능력치 소폭 강화 (메타 프로그레션)
- 과도하지 않아 코어 루프가 메인

---

## 협동/사회적 요소

- 기본적으로 싱글플레이 모바일 게임
- 하지만 빌드 공유, 스코어 자랑이 커뮤니티 핵심
- 코옵 없음 → OnionCat의 차별점이 될 수 있음

---

## 플레이어들이 사랑하는 점

1. **"돌아갈 수 없는 몰입"** — 레벨업 선택이 계속 잠깐만 하게 만듦
2. **빠른 런** — 20~30분 완결, 부담 없음
3. **빌드 발견의 기쁨** — 처음 보는 시너지 발견 시 만족감
4. **무료/저렴** — 접근성 높아 입소문

---

## 한계 및 비판

- 초반에는 밸런스 문제 있었음 (솔로 개발 한계)
- 모바일 터치 조작의 불편함
- 시각적 복잡도 높을 때 가독성 저하
- 장기 콘텐츠 부족

---

## OnionCat 적용 포인트

| 항목 | 적용 방향 |
|------|-----------|
| 오토슈터 제거 | OnionCat은 P2가 마우스로 조준 → 능동적 참여 유지. 자동화 대신 역할 분담 |
| 레벨업 선택 UI | 3개 업그레이드 카드 제시 — 능력 아이콘 + 설명 + 등급 색상 (Common/Rare/Legendary) |
| 시너지 시스템 | P1(근접) + P2(원거리) 각자의 업그레이드가 조합 시너지 발생 → 협력 필수성 강화 |
| 적 밀도 곡선 | 방 클리어 기반이지만 "방 내 시간 초과 시 증원" 패턴 참고 |
| 빌드 다양성 | 매 런 다른 업그레이드 풀 제공 → Brotato처럼 빌드 방향 달라짐 |
| 시각 가독성 | 화면에 투사체 많을 때 P2 투사체는 항상 밝은 색으로 구분 필요 |

## 설계 인사이트

```
"조작 단순화 → 전략에 집중"의 원칙은 OnionCat과 반대.
OnionCat은 조작 자체가 2인 협력이므로 복잡도가 허용됨.
단, 업그레이드 선택은 Magic Survival처럼 간결하고 즉각 이해 가능해야 함.
```
