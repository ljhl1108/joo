## 핵심 메카닉

### 루프 구조
- 영웅이 고리 모양 경로를 자동으로 반복 순환 (플레이어 조작 없음)
- 플레이어는 **카드(타일)**를 경로 위나 옆에 배치하는 것이 전부
- 배치된 타일이 적 생성, 자원 드롭, 지형 보너스를 결정
- 루프를 돌수록 적이 강해지고 드롭되는 자원이 쌓임

### 타일 인접 보너스 시스템
- 동일하거나 궁합 맞는 타일을 붙여 놓으면 추가 보너스 발동
  - 예: 산 + 산 + 산 = 봉우리 타일로 업그레이드 → 더 강한 적 + 더 많은 드롭
  - 강 + 숲 = 습지 생성 → 독 적 등장
- 전략적 "역설": 강한 적 = 좋은 드롭 → 위험을 감수하는 빌드 결정

### 메타 진행 (야영지 건설)
- 모은 자원으로 런 사이에 야영지 건물 건설
- 건물이 다음 런의 시작 능력치/카드 풀 확장
- 영구적 성장: 죽어도 일부 자원/건물 유지

### 자동전투 + 장비 관리
- 전투는 자동으로 진행, 플레이어는 드롭된 장비 중 하나 선택만 함
- 제한된 인벤토리 슬롯 → 버릴지 장착할지 빠른 판단

## 협동/멀티 요소

- 기본적으로 싱글플레이
- 루프 구조 자체가 "한 명은 배치, 한 명은 장비 관리"로 비대칭 협동에 완벽히 적합

---

## 플레이어가 사랑하는 것

1. **수동적 루프의 최면적 재미**: 영웅이 알아서 싸우는 걸 구경하는 zen 경험
2. **타일 배치의 전략성**: 어디에 무엇을 놓을지 고민하는 퍼즐
3. **역설적 성장**: 적을 더 강하게 만들어 더 강해지는 리스크/리워드
4. **빠른 메타 진행감**: 런마다 야영지가 조금씩 성장하는 성취감
5. **독특한 시각**: 일반 로그라이크와 완전히 다른 접근법

## OnionCat 적용 포인트

### 비대칭 협동의 레퍼런스
- Loop Hero의 루프 구조: P1(Cat)이 움직이는 동안 P2(Onion)가 "지원 배치" 담당
- 응용: Onion이 씨앗/꽃을 던져 바닥에 효과 구역을 만들고, Cat이 그 구역을 활용하여 전투
- 각자 다른 역할로 시너지 창출 → OnionCat의 핵심 협동 필라와 일치

### 메타 진행 구조 참고
- 야영지 건설 → OnionCat의 "정원 기지" 컨셉으로 적용 가능
- 각 런에서 획득한 씨앗/재료로 기지에 새 구역 건설
- 건물마다 새로운 런 시작 옵션 제공 (Cat 능력 언락, Onion 투사체 타입 언락)

### 타일/카드 인접 보너스 → 방 배치 보너스
- 로그라이크 맵에서 특정 방 배치에 보너스 적용 가능
- 예: 상점 방 옆에 회복 방이 있으면 "풍요로운 여정" 보너스 발동
- 플레이어가 맵을 탐색할 때 선택의 깊이 추가

### 자동전투 구경 → 적 예고 시스템
- Loop Hero처럼 "다음에 뭐가 나올지 예측 가능" 시스템
- 방 입장 전 적 타입 힌트 표시 (근접약? 원거리약?) → 준비 전략 유도
