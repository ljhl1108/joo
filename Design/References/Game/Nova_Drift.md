## 핵심 메카닉

Nova Drift는 Asteroids 스타일의 관성 기반 조작에 현대 Action RPG의 빌드 시스템을 결합한 아케이드 로그라이트 슈터다.

**기본 흐름**
- 무한히 밀려오는 적 웨이브를 뚫으며 레벨업 → 업그레이드 선택 반복
- 런은 짧고 빠르게 끝남 → 여러 빌드를 빠르게 실험 가능

**Gear 시스템 (3슬롯)**
- **Weapon** (무기): 기본 공격 형태 결정 (레이저, 그레네이드, 미사일, 근접 검 등)
- **Body** (선체): 이동 방식과 보조 능력 결정
- **Shield** (실드): 방어 메카닉 결정

Gear는 언제든 교체 가능하며, Gear를 교체해도 이미 구매한 Mod는 사라지지 않는다.

**Mod 시스템 (빌드의 핵심)**
- Gear를 고르면 해당 Gear에 연결된 Mod 트리가 열림
- Mod는 Tier 구조로 되어 있어, 하위 Mod 하나만 있으면 최종 Tier로 직접 점프 가능
- **선택의 대가**: 한 방향(무기) Mod를 계속 사면 방어·이동 Mod가 보상 화면에서 줄어듦 → 전문화 vs. 균형의 트레이드오프
- **Super Mod**: 조건 달성(예: 무기 Mod 10개 보유)으로 해금되는 강력한 보너스 Mod

## 시너지 시스템

Nova Drift의 최대 강점은 Gear × Mod 조합에서 나오는 창발적 시너지다.

**대표 빌드 예시**
- **Celestial Shield-Bomber**: Volatile Shields Mod를 조합 → 실드가 파괴될 때 폭발 → 실드를 의도적으로 파괴해 대미지를 주는 플레이
- **Seeking Cluster Grenade**: 그레네이드 + Heat Seeking Mod → 유도 클러스터 폭탄
- **Warpbreaker / Laser Drill / Boom Overload**: 각각 완전히 다른 플레이 스타일

**빌드 다양성을 보장하는 설계**
- Gear 조합이 다르면 근본적으로 다른 조작감과 전략이 나옴
- 같은 Gear라도 Mod 선택 순서에 따라 다른 결과 → 같은 조합을 두 번 경험하기 어려움
- 개발사는 "어떤 결정이든 뛰어난 시너지와 확실한 파멸 사이의 갈림길"이라고 묘사

**영구 진행 (Meta Progression)**
- 런을 거칠수록 새 Weapon, Upgrade, 게임 모드 해금
- 해금이 많아질수록 보상 풀이 넓어져 더 다양한 빌드 가능

## 플레이어가 좋아하는 것

- 개발 10년, Steam 압도적 긍정 10,000개 이상 — "완성도가 느껴진다"
- 런이 짧아 부담 없이 여러 빌드 시도 가능
- 각 빌드가 완전히 다른 게임처럼 느껴지는 플레이 스타일 다양성
- 의도치 않은 조합으로 OP 빌드를 발견하는 "유레카 순간"
- 1인 개발에서 출발한 완성도에 대한 커뮤니티의 존경

## OnionCat 적용 포인트

**1. Gear 슬롯 × Mod 트리 구조 — 장비와 효과의 관계**
OnionCat의 장비 아이템(GearItem)도 슬롯이 Gear 역할이고, 장비에 붙은 효과·세트가 Mod 역할이다. Nova Drift처럼 "슬롯 아이템을 바꿔도 이미 쌓인 세트 카운트는 유지한다"는 규칙을 명시하면 플레이어가 더 과감하게 장비를 교체할 수 있다.

**2. 전문화 vs. 균형 트레이드오프**
Nova Drift는 한 Gear에 집중할수록 다른 Gear Mod가 보상에서 줄어든다. OnionCat에서 세트 보너스를 하나의 세트에 올인하면 다른 세트 혜택이 희석되는 현재 구조와 동일하다 — 이 트레이드오프를 보상 UI에서 더 명확하게 시각화하면 더 의미 있는 선택감이 생긴다.

**3. Super Mod → 조건부 전설 장비**
"Mod N개 보유 시 해금되는 Super Mod" 아이디어를 OnionCat에 적용하면: 특정 세트 장비 N개를 모았을 때 해당 세트 전용 전설급 보상이 보상 풀에 추가되는 방식. 현재 세트 8단계 보너스와 달리 아이템 자체가 등장하는 연출이므로 더 극적인 "모았다!" 느낌을 줄 수 있다.

**4. 의도적 Gear 교체 전략 → 장비 교체 비용 설계**
Nova Drift는 Gear를 교체해도 Mod가 남는다. OnionCat은 현재 같은 슬롯 다른 장비 = 기존 것 분해다. "분해 없이 보관(가방)하고 나중에 되돌릴 수 있다"는 옵션을 넣으면 Nova Drift처럼 장비를 더 대담하게 교체하는 플레이를 유도할 수 있다.

**5. 빌드 명명 → 보상 선택 화면 커뮤니티화**
Nova Drift는 커뮤니티가 빌드에 이름을 붙이고 공유한다(Laser Drill, Warpbreaker 등). OnionCat도 세트 조합에 이름이 생기도록 설계하면(예: "햇살+바람 혼합 → 천둥구름 빌드") 커뮤니티 토론과 개발 콘텐츠 소재가 자연히 생긴다.
