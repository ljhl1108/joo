# 20 Minutes Till Dawn

리서치 날짜: 2026-06-11

## 기본 정보
- **개발사**: Flanne (1인 인디 개발)
- **출시**: 2022년 8월 얼리 액세스 → 정식 출시

- **공식 사이트 / Steam**: https://store.steampowered.com/app/1966900/20_Minutes_Till_Dawn/
- **테마**: Lovecraftian 공포, 밤을 버티는 생존극

## 핵심 메카닉

### 1. 20분 생존 타이머
- 여명까지 정확히 20분 버티면 런 성공
- 명확한 세션 길이 → 시작 전부터 "끝"이 보임 → 플레이어 심리적 안정감
- 시간이 지날수록 적 밀도/속도 상승 → 자연스러운 난이도 곡선

### 2. 수동 조준 + 자동 사격 하이브리드
- 이동: WASD 키보드 / 방향키
- 사격: 마우스 방향으로 수동 조준, 자동 연사
- 재장전 메카닉 존재 — 타이밍 관리 요소

### 3. 레벨업 업그레이드 시스템
- 적 처치 시 경험치 오브 드롭 → 레벨업 시 4개 카드 중 1개 선택
- 60+ 업그레이드, 매 런 랜덤 조합
- 업그레이드 재롤 가능 캐릭터도 존재

### 4. 시너지 시스템
- 특정 업그레이드 2개 조합 시 강력한 시너지 보너스 발동
- 예: "빠른 재장전" + "재장전 시 폭발" → 폭발 쿨타임 0
- 런 중 시너지 경로 미리 확인 가능 → 빌드 플래닝 가능

### 5. 룬 메타 진행
- 런 완료 시 영혼(Souls) 획득
- 공격 룬(Sword): 치명타 데미지, 상태이상 강화 등
- 방어 룬(Shield): 회피율, 체력 재생 등
- 동시에 2개만 장착 가능 → 빌드 선택지

## 캐릭터 시스템 (13종)
각 캐릭터가 고유 패시브 보유, 플레이 스타일 결정

| 캐릭터 | 능력 | 특징 |
|--------|------|------|
| Shana | 업그레이드 재롤 기회 | 빌드 플래닝 최적화 |
| Spark | 피격 시 50% 확률 번개 | 반격형 |
| Luna | 재장전 시 블랙홀 생성 | 군중 제어 특화 |
| Abby | 발사 속도 2배, 산탄 발사 | 공격적 근접 지원 |

무기 × 캐릭터 × 업그레이드 조합으로 수백 가지 빌드 가능

## 플레이어가 좋아하는 것
1. **20분이라는 명확한 세션 길이** — 짧게 한 판, 부담 없는 구조
2. **시너지 조합의 발견 쾌감** — "이 두 개가 이렇게 강해지다니!"
3. **Lovecraftian 분위기** — 어두운 픽셀아트 + 크툴루 몬스터
4. **빠른 피드백 루프** — 레벨업 → 강화 → 강해짐이 30초 주기
5. **캐릭터별 플레이 스타일 차별화** — 같은 무기도 캐릭터마다 다른 게임

---

## OnionCat 적용 포인트

1. **20분 타이머 도입** — 각 던전 런에 제한 시간 설정 → 긴장감과 명확한 세션 길이 제공. 두 플레이어가 효율적 협력 안 하면 클리어 불가 구조

2. **시너지 시스템 → 협력 보상** — 고양이(근접) 업그레이드 + 작물(원거리) 업그레이드 조합 시 "협력 시너지" 발동. 예: 고양이 "회오리 슬래시" + 작물 "번개 탄환" → "번개 회오리" 광역기

3. **캐릭터별 특수 능력** — 런 시작 시 두 플레이어 각각 특성 카드 선택 → 매 런 다른 협력 조합 경험

4. **룬 메타 진행** — 런 간 영구 업그레이드 두 트리 분리: 고양이 능력 트리 vs 작물 능력 트리 → 각 플레이어가 자기 캐릭터 성장 관리

5. **업그레이드 선택 UI** — 레벨업 시 카드 형식 4개 중 선택 인터페이스는 직관적이고 구현 난이도 낮음 → 그대로 참고 가능
