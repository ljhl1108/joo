## 핵심 메카닉

### 배터리 체력 시스템 (Battery Health)
기존 HP바 대신 **지속적으로 줄어드는 배터리**가 생명력:
- 아무 행동을 하지 않아도 배터리가 시간당 소진
- 처치한 적이 배터리 아이템을 드롭 → 즉시 줄을 서서 줍거나 무시
- 배터리 완전 소진 시 잠깐의 "오버드라이브" 상태 진입 후 사망
- **결과**: 소극적 플레이 불가, 끊임없이 적에게 돌격해야 하는 공격적 루프 형성

### 캐릭터별 무기 비대칭
8명의 안드로이드 각각 완전히 다른 주무기 + 슈퍼 어빌리티:
- **Cactus**: 고속 연사 → 근거리 압박
- **Android**: 산탄총(Shotgun) → 근접 폭발
- **Coral**: 전방 확산 사격 → 중거리 범위
- **Holly**: 유도 미사일 → 광역 화력
- **Colonel**: 레이저 빔 → 직선 관통
모든 슈퍼 어빌리티는 **배터리 소모와 별개** — 쿨다운 대신 배터리 충전으로 발동

### 협동 시너지 설계
- 같은 화면 내 1~4인 로컬 코옵
- 팀원이 죽으면 일정 시간 내 다른 플레이어가 근처에서 **부활 아이템**을 처치해 소생
- 배터리 드롭은 **가장 가까운 플레이어**가 가져감 → 의도치 않은 충돌/협력 발생
- 보스전은 팀 전체가 한 번에 전멸해야 실패 → 누군가 살아있으면 계속 진행 가능

### 웨이브 & 스테이지 구조
- 랜덤이 아닌 **디자인된 웨이브** 시퀀스
- 스테이지 클리어 후 등급(S~D) 판정 (처리 시간, 콤보, 사망 횟수 기준)
- 로그라이크 아님 — 진행 저장, 캐릭터 점진적 해금

## 적 디자인 철학
- 적마다 **명확한 실루엣**과 **공격 전조(Telegraph)**
- 대규모 군집 vs 소수 정예 혼합
- 일부 적은 특정 방향에서만 피해 받음 (방패 달린 유닛 등) → 포지셔닝 강요
- 보스: 다단계 페이즈, 각 페이즈마다 아레나 레이아웃 변화

## 플레이어들이 사랑하는 이유
- **배터리 시스템의 긴장감**: "계속 싸워야 산다"는 직관적 위기감
- **캐릭터 개성**: 각 안드로이드가 근본적으로 다른 플레이스타일 제공
- **화면을 가득 채우는 이펙트**: 폭발, 총알, 파티클이 과하게 터지지만 읽기 쉬운 색상 구분
- **로컬 코옵의 카오스**: 4인 플레이 시 화면 가득 채우는 총알과 배터리 경쟁

## OnionCat 적용 포인트

### 1. 배터리 → "공포 게이지" 변형 아이디어
OnionCat에서 시간이 지날수록 Onion(P2)의 두려움 수치가 오르는 압박 메카닉 참고:
- 적을 처치할수록 수치 감소 → 소극적 플레이 억제
- P1(Cat)이 앞에서 적을 패야 P2(Onion)의 공포가 줄어드는 협력 고리 형성

### 2. 협동 부활 루프
팀원 부활을 위해 **근처 적 처치** 조건 → 죽은 플레이어 곁에서 싸워야 하는 위기감 연출. OnionCat의 Coop_Revival_System에 직접 적용 가능.

### 3. 적 Telegraph 표준화
Assault Android Cactus의 적 공격 전조 방식(빨간 선 표시 → 0.5초 → 발사) 참고. `Design/References/Tech/Enemy_Telegraph_System.md` 구현 시 지속 시간 기준값으로 활용.

### 4. 캐릭터 슈퍼 어빌리티 → 협력 필수 어빌리티
Cat의 무적 대시와 Onion의 방향 방패를 "배터리(쿨다운 게이지)"로 묶어 과도한 무적 시간 남용 방지. 쿨다운 게이지가 찰수록 둘 다 쓸 수 있는 협동 슈퍼 스킬 아이디어 참고.
