## 핵심 시스템

### 클래스 & 마스터리
- 기반 5클래스(마법사·전사·원시인·경계의 문지기·시간의 파수꾼) × 마스터리 3종 = 15개 전문화
- 마스터리는 1회 선택 후 고정 — 각 마스터리는 전용 스킬 트리 제공
- 스킬 레벨업 + 스킬 트리 노드 선택으로 스킬 동작이 근본적으로 바뀜 (투사체 수, 범위, 전환 조건 등)

### 장비 & 아이템 시스템
- 슬롯: 무기·방패/보조무기·머리·몸·손·허리·발·반지×2·목걸이 (총 11~12칸)
- **등급**: 일반(회색) → 매직(파랑) → 희귀(노랑) → 유니크(오렌지) → 세트(초록)
- **어파이 속성**: 각 슬롯은 적합한 1차 속성(기본 스탯) + 연산된 접두/접미 조합으로 생성
- **아이템 레벨**: 아이템 레벨이 높을수록 속성 수치 범위가 넓음

### 아이템 제작 (Forge / Craft)
- **Forge Potential(FP)**: 각 아이템마다 부여된 제작 포인트. 접두/접미 추가·업그레이드할 때마다 소모
- **Glyph·Rune**: 다양한 제작 재료
  - Rune of Removal: 한 속성 제거, FP 일부 환불
  - Rune of Shattering: 아이템 파괴 → 샤드 생성
  - Glyph of Hope: FP 소모 없이 업그레이드 확률 보정
  - Glyph of Crafting: 특정 조건에서 접미 추가 비용 감소
- **샤드(Shard)**: 파괴한 아이템에서 나오는 재료 — 동일 속성 아이템에 다시 붙여 넣을 수 있음
- **레전더리 제작**: 유니크 아이템 + 엑살티드(특수 희귀) 아이템 → Eternity Cache에 넣으면 유니크 능력치 + 일반 속성 일부 합성 (레전더리 생성)

### 세트 아이템
- 세트 아이템은 인게임에서 초록색 테두리로 표시
- 세트 이름(예: "Exiled Mage's Regalia")이 동일한 아이템을 여러 개 장착할수록 단계별 보너스 발동
- 세트 보너스: 2개·3개·4개 등 단계별로 구분, 툴팁에서 현재 활성 보너스·비활성 보너스 구분 색상으로 표시
- 일부 세트는 클래스·마스터리와 시너지 (불 마법사 세트 + 화염 스킬 트리 극대화)

### 던전 & 런 구조
- 3개 시대(Ruins of Erased·Ancient Era·End of Time)를 시간이동하며 탐험
- 각 챕터는 선형 + 지역 분기 구조 (완전 절차적 생성은 아님)
- **Monolith of Fate**: 메인 엔드게임 — 노드 맵을 이동하며 에코(Echo) 클리어
  - 에코마다 조건·보상 레이블 표시 → 선택적 경로 진행
  - 완주 시 보스 싸움 + 유니크·세트 아이템 드롭 보장
- **Dungeons(3종)**: 입장권 소모, 내부에서 레전더리 제작 재료 획득

### 협동
- 기본 2~4인 온라인 협동 지원
- 각 플레이어 독립 아이템 드롭 (경쟁 없음)
- 공유 보상: 골드·경험치 일부 공유, 아이템은 개인 드롭

## 플레이어가 좋아하는 것
1. **스킬 시스템의 깊이** — 노드 선택 하나가 스킬 동작 방식을 완전히 바꿈 (투사체→번개·폭발 전환 등)
2. **제작 시스템의 명확성** — 아이템의 FP를 보면 제작 여지가 얼마나 남았는지 직관적으로 파악
3. **오프라인 플레이 지원** — 인터넷 없이도 싱글로 전체 게임 가능
4. **투명한 아이템 확률** — 드롭 테이블이 상대적으로 공개되어 있어 파밍 목표 설정 쉬움
5. **건강한 인디 지지** — EA 기간 개발 투명성이 높아 커뮤니티 신뢰 두터움

## OnionCat 적용 포인트

### 1. 장비 제작 → 씨앗 경제 설계
- Last Epoch의 FP(Forge Potential) = OnionCat의 씨앗(Seed) 경제와 구조가 유사
  - FP가 소진되면 해당 아이템은 더 이상 제작 불가 → OnionCat: 씨앗이 다 떨어지면 리롤·효과 교체 불가
  - 아이템 파괴 → 샤드 = 장비 분해 → 씨앗 환원
- **적용**: 씨앗 가격 체계를 "아이템 등급별 제작 비용 테이블"로 명확히 문서화. 리롤 가격이 점차 오르는 구조는 Last Epoch에서도 유사하게 사용
- 효과 갈아끼우기를 휴식·상점 제한에 두는 이유가 명확해짐: 전투 외 안전 공간에서만 심층 커스텀 = Last Epoch의 "Town 내 제작" 패턴

### 2. 세트 진행 바 UI
- Last Epoch 세트 툴팁의 단계별 색상 강조 (현재 활성=밝음, 비활성=어두움)
- **적용**: OnionCat HUD 우하단의 세트 미니 진행 바를 수정 시, "보유 n/최대" 표시에서 각 단계(2·4·6·8개)가 도달됐는지 여부를 색상 + 아이콘으로 구분
- 업그레이드 선택 카드에서 세트 아이콘에 마우스를 올리면 "현재 n개 보유, 다음 단계 m개 필요"를 보여주는 팝업 개선 가능

### 3. 레전더리 = OnionCat의 전설 등급 장비
- Last Epoch 레전더리: 유니크 속성 + 추가 속성 = 희귀 효과 + 조합 보너스
- OnionCat 전설 아이템(아홉 목숨·황금 양파 등)에 "조합 조건" 개념 추가 가능
  - 예: 특정 세트 장비 2개 + 전설 장비 → 런 내 강화 이벤트
  - 구현: `RunData`에 unlock 조건 체크 → 특별 보상 방 등장

### 4. Monolith 에코 맵 → 출구 표식 설계
- 에코의 레이블(보상 종류, 보너스 모디파이어)을 보고 다음 방향을 선택하는 구조
- **현재 OnionCat**: 출구 표식이 다음 방의 RewardAxis를 알려줌
- **개선 아이디어**: 출구에 "다음 방 보상 등급 힌트"(씨앗/아이템/세트 아이콘) 추가 — 플레이어가 방향을 전략적으로 선택할 수 있게

### 5. 오프라인 로컬 협동 우선 설계
- Last Epoch가 오프라인 지원으로 호평 → OnionCat은 처음부터 로컬 2인 전용으로 네트워크 코드 없음
- 온라인 기능 없이도 완전한 경험을 주는 것이 인디 개발자에게 현실적이고 플레이어에게 매력적
