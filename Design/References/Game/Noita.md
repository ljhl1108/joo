## 핵심 시스템

### 1. 픽셀 물리 시뮬레이션 ("모든 픽셀이 시뮬레이션된다")

Noita의 정체성. 모든 픽셀이 재질(물, 용암, 모래, 나무, 가스 등)로 정의되며 실시간 물리 법칙을 따른다.

- **액체**: 실제처럼 흘러내림 (물, 용암, 산성)
- **기체**: 위로 퍼짐 (연기, 증기)
- **화학 반응**: 물 + 용암 = 돌 + 증기, 불 + 나무 = 연소 + 연기
- **완전 파괴**: 모든 지형 파괴 가능 → 창의적 문제 해결 가능
- **기술적 구조**: 64×64 픽셀 청크 분할, dirty rect 최적화, marching square 강체 물리

**핵심 가치**: 의도하지 않은 연쇄 반응이 게임플레이의 재미 자체가 됨 → 창발적 게임플레이

### 2. 완드 빌딩 시스템

Noita의 두 번째 기둥. 주문(Spell)과 변환자(Modifier)를 조합해 완드를 커스터마이징.

| 요소 | 설명 |
|------|------|
| 완드 최대 보유 수 | 4개 |
| 비셔플 완드 | 순서대로 주문 발사 |
| 셔플 완드 | 주문 순서 랜덤화 |
| 주문 변환자 | 바로 오른쪽 주문에 속성 추가 (유도, 분열, 폭발 등) |
| 트리거 주문 | 탄환이 충돌 시 추가 주문 발동 |
| 체인소 주문 | 캐스트 딜레이 0으로 만들어 강력한 연계 가능 |

### 3. 퍼크 시스템 (런별 성장)

- 각 Holy Mountain(안식처) 통과 시 3개 중 1개 선택
- 리롤 비용: 200 → 400 → 800... (배로 증가)
- 일부 퍼크는 중첩 가능 → 파워 스케일링
- 총 103종+ 퍼크 존재

### 4. 11종 피해 유형 + 적별 저항/약점

| 피해 유형 | 특징 |
|----------|------|
| Melee / Slice | 근거리 |
| Projectile | 원거리 탄환 |
| Fire / Ice / Electric | 원소 |
| Explosive / Toxic / Physics / Curse | 특수 |

- **로봇 적**: 폭발·전기에 약함, 일반 탄환에 강함
- **Lukki(거미)**: 냉동 후 근접 타격에만 취약 → 두 가지 피해 유형 조합 필수
- 이 구조가 OnionCat의 "근접만 약한 적/원거리만 약한 적" 콘셉트와 직결

### 5. 바이옴 구조 (진행 구조)

**메인 경로**: 석탄 구덩이 → 눈 지하 → Hiisi 기지 → 지하 정글 → ...
**Holy Mountain**: 바이옴 사이 안식처 (완드 편집, 상점, 퍼크 선택)
**절차적 생성**: 바이옴마다 최대 22종 랜덤 변형 적용

### 6. 메타 진행 없음 (의도적 설계)

- 런 간 영구 해금/강화 없음
- 성장 = 플레이어 지식 + 실력
- 높은 진입 장벽이지만, 커뮤니티는 이를 장점으로 인식

---

## 플레이어가 사랑하는 이유

1. **창발적 물리**: 다른 게임에서 불가능한 고유한 경험
2. **완드 창의성**: "내가 필요한 도구를 직접 만드는" 느낌
3. **탐험 보상**: 정보 자체가 자산 (위키 없이는 모르는 것들)
4. **극강의 리플레이성**: 진행 구조 단순하나 매 런이 전혀 다름

**공통 불만**: 너무 어렵다, 설명이 없다, 급사한다 → 하지만 이게 Noita의 정체성

## OnionCat 적용 포인트

### 1. 적 약점 분기 시스템 ★★★
Noita의 11종 피해 유형 → 적마다 약한 피해 유형 고정 → 협력 강제
- OnionCat: Cat(근접) 전담 적 / Crop(원거리) 전담 적을 명확히 구분
- 시각적 피드백으로 구분 즉시 인식 가능하게 (색상, 실루엣, 움직임 패턴)

### 2. 퍼크 시스템 → 런 내 업그레이드 구조
- "안식처(rest zone)"에서 3개 중 1개 선택하는 구조 그대로 차용 가능
- Cat용 퍼크 / Crop용 퍼크 / 공유 퍼크로 분류
- 리롤 비용 배가 구조 → 골드 의사결정 긴장감

### 3. 환경 상호작용 퍼즐
- Noita 물리만큼 복잡하진 않아도, 환경 요소(물, 폭발물 등)를 두 플레이어 역할로 분담
- 예: Crop이 폭발물을 원거리로 폭파 → Cat이 열린 길로 돌진

### 4. 창발적 협력 시너지
- Cat의 무적 대시 + Crop의 유도탄 = "Cat이 떼어 모은 적무리를 Crop이 일제 사격"
- 미리 계획된 게 아닌 플레이 중 발견하는 조합의 재미

### 5. 멀티플레이어 미지원이 기회
- Noita는 솔로 전용 (공식 코옵 없음) → 커뮤니티 수요 증명
- OnionCat의 코옵 핵심 기계는 Noita가 채우지 못한 공백

### 6. 피해야 할 것
- 무설명 철학: 코옵 게임은 두 플레이어 간 명확한 피드백 필수
- 너무 복잡한 빌딩 시스템: 초보자 개발자로서 범위 관리 중요
