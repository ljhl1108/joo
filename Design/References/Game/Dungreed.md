## 핵심 메카닉

### 마을 재건 시스템
- 던전에서 주민(NPC)을 구출하면 마을이 재건됨
- 재건된 마을 시설(대장간, 상점, 훈련장 등)이 이후 런에서 활용 가능
- 영구 진행의 중심축 — 마을 성장 = 캐릭터 성장 가능성 확장

### 영구 능력치 업그레이드 (훈련 시스템)
- 런 실패 후에도 획득한 골드로 능력치 영구 상승 가능
- HP, ATK, DEF, SPD 등 기본 스탯 단계적 강화
- 플레이어 스킬보다 캐릭터 스탯이 중요한 로그라이트 설계 → 초보자 친화

### 무기 다양성
- 근접 무기부터 저격 소총까지 광범위한 무기 종류
- 각 무기마다 다른 공격 패턴, 사정거리, 연사 속도
- 무기를 교체할 때마다 전투 스타일 완전히 변화

### 식품 시스템
- 던전 내에서 음식 아이템 발견 → 체력 회복 + 일부 스탯 버프
- 일회성 소비 아이템으로 전투 리소스 관리 요소 추가

### 절차적 맵 생성
- 매 런마다 다른 레이아웃의 던전
- 층 구조 (여러 층을 내려가며 진행)
- 상점, 보물방, 일반 전투방 랜덤 배치

## 플레이어가 좋아하는 것

- 한국 인디게임 특유의 친근한 픽셀아트 스타일
- 마을 재건이라는 진행감과 목적의식 부여
- 다양한 무기 종류로 플레이 스타일 자유도 높음
- 영구 업그레이드 덕분에 초보자도 점차 강해지는 성취감
- 한 손으로 플레이 가능한 단순한 조작감

## OnionCat 적용 포인트

### 1. 마을 재건 = 허브 월드 아이디어
Dungreed의 마을 재건 시스템을 OnionCat에 적용:
- 런 클리어/실패마다 "고양이 마을" 발전 (영구 해금 허브)
- 새로운 시설 = 새로운 시작 업그레이드 선택지 해금
- 초보자 개발자에게도 구현 가능한 명확한 메타 진행 구조

### 2. 픽셀아트 + 무기 다양성
근접 무기는 Cat, 원거리는 Crop이라는 고정 역할이지만:
- Cat 근접 무기 다양화 (검/낫/주먹발톱 등) → 공격 패턴 변화
- Crop 원거리 씨앗 종류 다양화 (폭발씨앗, 유도씨앗, 관통씨앗 등)

### 3. 초보자 친화 영구 업그레이드
OnionCat도 Dungreed처럼 실패해도 느끼는 성장감:
- 런 중 획득한 자원으로 기본 스탯 영구 상승
- 완전 퍼마데스보다는 메타 진행 요소 포함하면 진입장벽 낮아짐

### 4. 식품 시스템 → 채소 아이템
양파/작물 테마에 딱 맞는 식품 기반 아이템 시스템:
- 던전 내에서 채소 아이템 획득 → HP 회복 + 임시 버프
- "양파가 스스로 치유" 내러티브와도 일치
