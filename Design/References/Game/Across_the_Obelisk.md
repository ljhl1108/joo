# Across the Obelisk

리서치 날짜: 2026-10-11

## 기본 정보

- **장르**: Co-op 카드 로그라이트 덱빌더
- **개발사**: Dreamsite Games / **퍼블리셔**: Paradox Arc
- **출시**: 2022-08-25 (Early Access 졸업)
- **플랫폼**: PC(Steam), Nintendo Switch, macOS
- **Steam**: https://store.steampowered.com/app/1385380/Across_the_Obelisk/
- **가격**: ₩19,500 (기본) / DLC 다수
- **플레이 인원**: 1~4인 (온라인 코옵)

---

## 핵심 시스템

### 덱빌딩 + 파티 운영
- 영웅 16종, 4개 클래스. 각 영웅이 **독립된 카드 풀**을 보유
- 솔로플레이 시 4명 영웅 전부 직접 조작, 2~4인이면 각자 1~2명씩 나눠 담당
- 카드 500장 이상. 영웅별 퍽(Perk) 포인트로 덱 개성화

### 장비·아이템 시스템
- 장비 300+종. 영웅별 슬롯에 장착 → 런 내내 유지 (로그라이트)
- **파티 크로스 시너지**: 영웅 A가 상태이상을 걸면 영웅 B의 카드가 그걸 소비해 폭발 데미지
- 상점(타운)에서 골드·샤드로 장비 구매 및 덱 강화. 액트 사이마다 타운 등장

### 코옵 구조
- 전투: 플레이어가 카드를 번갈아 내면서 영웅 간 콤보를 만들어냄
- **비전투 이벤트**: 분기 선택지에서 모든 플레이어가 카드를 뽑아 주사위처럼 결과 결정 → 공동 의사결정 메커니즘
- 맵 이동·상점·이벤트 모두 협력 진행
- 크로스플레이 지원

### 진행 구조
- 4막 구성, 막 사이에 타운. 마지막 막은 타운 없이 직행
- 절차적 이벤트와 분기 스토리 → 런마다 다른 경로
- Madness 모드(하드), Adventure 모드(절차생성 이벤트)

---

## 플레이어가 좋아하는 것

- 4명 영웅의 덱을 동시에 관리하며 **파티 전체 시너지를 설계**하는 깊이
- 크로스 클래스 조합 실험: 영웅 조합에 따라 완전히 다른 플레이 스타일
- 타운 업그레이드로 런 내 성장이 느껴지는 만족감
- 온라인 코옵에서 서로 역할을 나눠 최적 플레이를 찾는 협동감
- 활발한 커뮤니티(Discord ~15,000명)와 지속적인 업데이트

## OnionCat 적용 포인트

| 주제 | Across the Obelisk 방식 | OnionCat 적용 |
|---|---|---|
| 크로스 캐릭터 시너지 | 영웅 A 상태이상 → 영웅 B가 소비해 폭발 | 고양이 걷어차기로 날린 적을 양파 씨앗이 공중에서 맞추면 콤보 보너스 강화 |
| 비전투 공동 의사결정 | 이벤트에서 둘 다 카드를 뽑아 결과 결정 | 2인 기믹 방: 고양이는 발판을 밟고, 양파는 수정을 쏘는 구조를 더 다양화 |
| 영웅별 독립 장비 | 영웅마다 슬롯이 다름, 파티 크로스 시너지 존재 | 고양이/양파 장비 시스템 이미 분리 → 세트(햇살·바람)가 합산되는 구조와 일치 |
| 파티 구성 다양성 | 클래스 조합에 따라 완전히 다른 빌드 | 할퀴기 변형(ClawStyle) × 마법서(OnionSkill) 조합으로 런마다 다른 스타일 |
| 모든 플레이어 공동 결과 | 이벤트 결과가 파티 전체에 영향 | 합동기·협동 콤보가 둘 다 기여해야 채워지는 구조 → 이미 방향 맞음 |

### 핵심 인사이트
- **"한 사람이 깔면 다른 사람이 터뜨리는" 패턴**이 코옵의 핵심 재미. OnionCat의 박(gourd) 식물 + 걷어차기 콤보가 정확히 이 패턴. 이 패턴을 더 많은 상황(아이템·스킬)으로 확장할 수 있음
- **비전투 결정에도 두 플레이어가 관여**하게 만드는 것이 "같이 하는 느낌"을 올려줌. 상점 구매나 이벤트 선택에 양파가 참여할 수 있는 UI/인터랙션을 고려해볼 것
- 영웅별 전용 아이템이 있어도 파티 시너지 시스템이 협동을 강제. OnionCat도 "고양이 전용/양파 전용 효과지만 함께 쓸 때 더 강해지는 아이템"을 추가하면 협동 동기가 강해짐
