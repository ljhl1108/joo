## 핵심 메커니즘

### 캐릭터 & 전투
- **4명의 플레이어블 캐릭터**, 각자 완전히 다른 무기/전투 스타일
  - **Qaru** — 주먹 격투, 기본 콤보 중심
  - **Pancho** — 악기(기타)로 공격, 음악 기반 마법
  - **Renzo** — 두 개의 표창, 닌자 스타일 고속 공격
  - **Muray** — 마법 지팡이, 원거리 주문
- **콤보 시스템**: 공격 연속 입력으로 콤보 미터 채움 → 마법 강화 공격 발동
- **마법 포인트**: 적 처치 시 적립, 특수 능력 사용에 소모
- **이동**: 8방향 탑다운 이동, 구르기/회피 있음

### 로그라이트 구조
- **노드 기반 맵**: 분기 경로로 챕터 진행, 상점/이벤트/전투 방 선택
- **능력 업그레이드**: 방 클리어 후 3개 중 1개 스킬 선택 (캐릭터 고유 + 공유 풀)
- **퍼마데스**: 런 사망 시 처음부터, 영구 해금 요소 없음 (순수 로그라이트)
- **챕터 구조**: 아마존 정글 → 폐허 → 성소 등 3개 지역, 각 지역 보스

### 협력 시스템
- **로컬 협력 전용**: 온라인 없음, 같은 화면 공유
- **공유 체력 없음**: 각 플레이어 독립적 체력 바
- **부활**: 아이템 사용 시 쓰러진 동료 부활 가능
- **콤보 보너스**: 두 플레이어가 같은 적을 공격 시 콤보 데미지 배율 증가
- **짐살라빔(공유 특수기)**: 마법 게이지를 합산해서 발동하는 팀 특수기

### 아트 & 설정
- **손 그림 픽셀아트**: 아마존 밀림과 페루 신화 배경
- **애니메이션**: 손으로 그린 듯한 유기적인 프레임 by 프레임 애니
- **스토리**: 숲의 신 Tunche를 깨우는 악당을 막기 위한 모험

## 플레이어들이 사랑하는 것

1. **뚜렷한 캐릭터 개성** — 각 캐릭터가 조작감, 비주얼, 역할이 완전히 달라 협력 시 역할 분담이 자연스러움
2. **손 그림 아트의 독창성** — 픽셀아트와 수채화 스타일의 독특한 조합
3. **콤보의 쾌감** — 타격감이 명확하고 콤보 연계 시 시각적 피드백이 화려함
4. **짧은 런 길이** — 1~2시간 내 클리어 가능, 반복 플레이 부담 적음
5. **협력 보너스** — 혼자 하는 것보다 둘이 할 때 시너지 느껴짐

## OnionCat 적용 포인트

### 1. 두 캐릭터의 역할 분담 설계 철학
Tunche에서 근거리(Qaru)와 원거리(Muray) 캐릭터의 역할이 자연스럽게 분리되듯,  
OnionCat도 Cat(근거리 슬래시)과 Crop(원거리 투사체)의 역할을 시각적으로 명확히 구분해야 함.
- **아이디어**: Cat 공격 이펙트는 주황/빨강 계열, Crop 공격은 초록/노랑 계열로 색상 분리

### 2. 콤보 시스템 없이 협력 시너지 만들기
Tunche의 콤보는 버튼 연속 입력이지만, OnionCat은 두 플레이어가 각자 다른 버튼을 담당.
- **아이디어**: Cat이 적을 기절(Stun)시키면 Crop의 다음 탄환이 크리티컬 → 협력 시너지를 상태이상으로 구현

### 3. 팀 특수기 개념 (OnionCat 버전)
Tunche의 짐살라빔처럼, Cat과 Crop이 동시에 특정 버튼을 누를 때 발동하는 "협동 필살기" 시스템.
- 예: Cat이 적을 잡아두고(그랩), Crop이 집중 사격 발동 → 한 적에게 대량 데미지
- `CoopSkillManager.cs`에서 두 플레이어 입력 타이밍 체크 후 발동

### 4. 노드 맵 UI 참고
Tunche의 분기 경로 선택 화면은 OnionCat의 층 이동/방 선택 UI 설계에 참고 가능.
- 상점 / 전투방 / 이벤트방 아이콘을 노드로 표현하는 시각적 맵

### 5. 아트 방향 참고
- 손 그림 느낌의 픽셀아트: 각 프레임을 미묘하게 다르게 그려 생동감 추가
- 아마존 정글 배경처럼 배경과 캐릭터 색상 대비를 강하게 유지해 플레이어 식별성 확보
