## 핵심 메커닉

### 1. 원소 조합 시스템 (Spell Weaving)
- 8가지 원소(불, 물, 얼음, 전기, 바람, 생명, 방패, 암흑) 실시간 조합
- 최대 5개 원소를 큐에 쌓아 다양한 주문 생성
- 예: 불+물 = 수증기(시야 차단), 얼음+전기 = 얼어붙은 + 감전 콤보
- **학습 곡선**: 직관적 규칙 기반 → 실험/발견의 재미

### 2. 아군 피해 (Friendly Fire)
- 모든 주문이 아군에게도 적용됨
- 협동의 핵심 긴장감: 실수로 아군 공격 → 웃음 유발 + 전략 필요
- 방패 원소로 보호, 생명 원소로 힐 가능 → 상호 지원 필수

### 3. 자기 버프 (Self-Cast)
- 원소를 자신에게 시전 가능 (무기에 원소 부여, 자기 힐 등)
- 다른 플레이어에게도 버프 시전 가능 → 협동 심화

### 4. 죽음과 부활
- 동료가 죽으면 생명 원소 조합 주문으로 부활 가능
- "부활 의식" → 협동의 핵심 순간

## 협동 요소 분석 (OnionCat 관점에서)

| Magicka | OnionCat 비교 |
|---------|--------------|
| 4인 각자 독립 조작 | 2인 한 몸 공유 |
| 자유로운 원소 조합 | 근접(고양이) vs 원거리(양파) 역할 고정 |
| 아군 피해로 긴장감 | 역할 협동 실패 시 적 돌파 실패 |
| 생명 원소로 부활 | 공유 체력 → 한 명의 실수가 전체에 영향 |
| 실험과 발견의 재미 | 적 약점 시스템으로 유사한 "발견" 제공 |

### Magicka의 협동 성공 공식
1. **역할 분담 없이** 누구나 모든 것을 할 수 있지만
2. **상황에 따라** 자연스럽게 역할이 나뉨 (힐러, 딜러, 탱커)
3. **실수가 재미**가 되도록 설계 (friendly fire = 웃음)
4. **빠른 재시작** → 실패가 좌절이 아닌 다시 시도의 동기

## OnionCat 적용 포인트

### 1. "실패가 재미"가 되는 협동 설계
- 고양이가 잘못된 방향으로 대시하면 방패가 엉뚱한 곳을 막음
- 이 실수가 **웃음 포인트**가 되도록 → 처벌이 아닌 유머
- 단, 반복 실수는 클리어 불가 → 학습 동기 제공

### 2. 협동 시너지 순간 설계
- Magicka: 얼음 + 전기 = 극강의 데미지 콤보
- OnionCat: 고양이가 적을 기절시키는 동안 양파가 차지샷 → 보스 딜 순간
- **"시너지 순간"을 명확히 보여주는 시각 이펙트** 필요

### 3. 부활 의식의 중요성
- Magicka에서 부활이 협동의 핵심 긴장 순간
- OnionCat: 체력이 0이 되기 전 "위기 구출" 메커닉 고려 가능
  - 예: 양파 방패로 치명타 1회 방어 → 고양이 대시로 도주

### 4. 학습형 복잡도 (Progressive Complexity)
- 초반: 원소 1~2개 조합만 필요 → 후반: 5개 조합 필수
- OnionCat: 초반 룸은 근접 or 원거리 모두 클리어 가능, 후반은 정확한 역할 분담 필수

## 플레이어들이 사랑하는 것

1. **실험의 재미** — 어떤 조합이 어떤 효과? 직접 해봐야 앎
2. **아군 피해의 카오스** — 의도치 않은 폭발, 모두 폭소
3. **높은 재플레이성** — 같은 적도 다른 원소 조합으로 색다르게
4. **공유 경험** — "그거 기억해? 용암을 물에 넣어서 폭발했던 거" → 이야기거리
