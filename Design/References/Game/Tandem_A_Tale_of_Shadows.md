## 개요

빅토리아 시대 고딕 분위기의 퍼즐 플랫포머. 소녀 Emma와 테디 베어 Fenton, 두 캐릭터를 번갈아 조작한다.  
**핵심 아이디어: 같은 공간을 두 캐릭터가 완전히 다른 시점(투 다운 / 사이드 스크롤)으로 본다.**  
1인 플레이 전용이지만, 두 조작 방식을 분리하면 비동기 협동(2인 로컬)으로도 즐길 수 있다.

---

## 핵심 메커니즘

### 이중 시점 (Dual Perspective)
| 캐릭터 | 카메라 | 조작 방식 | 역할 |
|---|---|---|---|
| Emma (소녀) | **탑다운** | 8방향 이동, 등불로 그림자 생성 | 빛의 출처 — 그림자를 직접 만든다 |
| Fenton (곰) | **사이드 스크롤** | 2D 플랫폼 이동, 점프 | 그림자 위에 발판이 생겨 걸을 수 있다 |

- Emma가 등불을 움직이면 → 오브젝트의 그림자 방향·길이 변화 → Fenton이 건널 수 있는 발판 생성
- 두 캐릭터가 **같은 화면**에 나타나되 각자 다른 물리 규칙에 따라 움직임
- 스위치·기어·거울 등을 통해 "Emma가 위에서 블록을 밀면 Fenton의 발판이 생긴다"류 연쇄 퍼즐

### 그림자 발판 역학
- 그림자는 오브젝트 높이에 비례한 길이 — 등불 위치에 따라 각도와 길이 모두 달라짐
- Fenton은 그림자 위에서만 걸을 수 있음 → Emma의 이동 경로가 바로 Fenton의 가능 경로
- 빛이 없는 어둠 = Fenton이 추락·사망하는 위험 구역

### 5챕터 구성
- 각 챕터마다 하나의 거대한 저택/구조물을 탐색
- 챕터 전반부 = 기믹 도입 (새 그림자 오브젝트) → 후반부 = 복합 퍼즐
- 보스/장애물은 없음 — 순수 퍼즐 위주

## 플레이어들이 주목하는 것
1. **독창적 시점 아이디어** — 같은 공간을 두 각도로 보는 것 자체가 신선함
2. **퍼즐 설계의 정교함** — 등불 각도 한 칸 차이가 풀이를 바꾸는 세밀한 레이아웃
3. **분위기와 아트** — 빅토리아 고딕 그래픽, 조명 효과가 게임의 핵심 감성과 맞닿음
4. **단점: 협동 아님** — 2인이 함께 하고 싶어도 공식 협동 모드 없음, 1인 솔로 경험
5. **단점: 길이** — 약 4~5시간으로 짧다는 평

## OnionCat 적용 포인트

### 비대칭 시야 기믹 아이디어
- 두 플레이어가 같은 공간을 "다른 정보"로 보게 하는 퍼즐 가능성
- OnionCat 현재 구조: 고양이(패드 이동)와 양파(마우스 조준)는 이미 역할이 분리됨
- **확장 아이디어**: "양파가 쏘는 씨앗이 등불처럼 주변을 밝혀 -> 고양이가 함정 위치를 볼 수 있다"
  → 협동 정보 비대칭 — 한 명이 먼저 행동해 다른 명의 경로를 만드는 퍼즐 방

### 그림자/빛 발판 기믹
- 방 하나짜리 기믹으로 "양파가 조명 아이템을 쏴 그림자 발판 생성 → 고양이가 건너감"
- `Room_Special`에서 1회성 쌍둥이 스위치 대신 이런 조명 기믹을 추가 협동 퍼즐로 활용
- 구현: Unity의 URP 2D Light를 등불처럼 쓰고, 그림자 위에 trigger zone 발판 생성

### 오브젝트가 그림자에 반응하는 연쇄 퍼즐
- Tandem의 "블록 밀기 → 그림자 연장 → 발판 생성" 같은 연쇄 로직
- OnionCat에 적용: "고양이가 박(식물)을 발로 차 위치 이동 → 양파가 발판으로 사용"
  → 걷어차기 + 식물 기믹의 협동 퍼즐 방

### 1인 솔로 플레이 접근성
- Tandem처럼 "번갈아 조작"을 허용하면 1인 플레이어도 2인 콘텐츠 접근 가능
- OnionCat에서 패드 없을 때 고양이를 AI가 단순 추적하는 방식 대신
  → 1인이 탭으로 고양이·양파를 전환하는 솔로 모드 고려 가능
