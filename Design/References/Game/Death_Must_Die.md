## 핵심 메카닉

### 1. 신들의 은총 (Boon) 시스템
- 적 웨이브 클리어 후 그리스 신들(헤카테, 제우스, 크로노스 등)이 나타나 능력 제공
- 각 신마다 독특한 능력 계열 → 같은 신의 은총을 여러 개 조합하면 시너지 발동
- Hades의 Boon 시스템과 유사하지만 **캐릭터에 덜 묶여 있어** 빌드 자유도 높음

### 2. 아레나 방 + 웨이브 클리어
- 하나의 아레나에서 여러 웨이브 처리 후 다음 방 이동
- 방마다 다른 적 조합 → 전략적 적 처리 순서 필요
- **일부 적은 특정 공격 유형에만 취약** (근접 전용, 원거리 전용 등)

### 3. 다양한 플레이어블 캐릭터
- 각 캐릭터는 고유 기본 공격 + 스킬 보유
- 예: 근접 전사(Hopper), 마법사(Remi), 궁수(Scarlet) 등
- **협동 시 캐릭터 역할 분담**이 자연스럽게 발생

### 4. 협동 플레이 설계
- 화면을 공유하며 함께 이동 (공유 카메라 영역)
- 특정 강적은 여러 플레이어가 집중해야 처리 가능
- 은총 선택은 플레이어마다 독립적 → 빌드 다양화 가능
- 팀 시너지: 한 플레이어가 적을 모으고 다른 플레이어가 광역 공격

### 5. 메타 진행 (Meta-Progression)
- 런 사이 영구 해금: 새 캐릭터, 시작 아이템, 아티팩트
- 런 결과에 따라 "의식 포인트" 획득 → 영구 강화

## OnionCat 적용 포인트

### A. 적 유형별 취약점 강제 협력
- Death Must Die에서도 **일부 적은 특정 공격에만 취약**
- OnionCat의 핵심 필러("근접 약점 적 vs 원거리 약점 적")를 이 게임이 이미 검증
- **구현 힌트**: 적에게 `WeaknessType` enum(Melee / Ranged / Both) 필드 추가
  - Melee 전용 적: 원거리 피격 시 피해 50% 감소 or 0
  - Ranged 전용 적: 근접 피격 시 피해 0 + 반격 발동

### B. 신들 → 업그레이드 선택 UI 플레이버
- Death Must Die는 신이 대화하며 은총 제공 → 업그레이드 선택에 캐릭터성 부여
- OnionCat에서 업그레이드 선택 화면에 캐릭터 대사 추가 가능
  - 예: "고양이: 이건 내 발톱이 더 날카로워지는 거야!" / "파: 나는 이쪽이 더 좋은데..."

### C. 은총 시너지 → 아이템 시너지 설계 참고
- 같은 계열 아이템 2~3개 획득 시 시너지 보너스 발동 아이디어
- `ItemSynergySystem.cs`에서 아이템 태그(Tag) 기반으로 구현 가능

### D. 협동 공유 카메라
- Death Must Die의 공유 카메라는 두 플레이어 중점에 위치
- OnionCat은 한 몸이므로 더 단순하지만 **공격 범위 밖 에이밍 시 카메라 약간 이동** 아이디어 참고
  - P2(파)가 원거리 조준할 때 Cinemachine FramingTransposer가 조준 방향으로 약간 패닝

### E. 아레나 방 구조
- 웨이브 기반 아레나 구조는 OnionCat의 방 시스템과 호환
- 방에 입장 → 문 잠금 → 웨이브 처리 → 문 해제 + 보상 구조
- `EnemySpawnerWaveSystem.md` 참고
