## 핵심 메카닉

### 1. 형태 변환 시스템 (Form Switching)
- 플레이어 "Nobody"는 마법 지팡이를 얻어 15가지 이상의 형태로 변신 가능
- 각 형태마다 고유한 기본 공격, 보조 공격, 패시브 능력 보유
- **폼 잠금해제**: 스토리 진행 및 퀘스트 완료로 점차 해금
- 전환에 제한 없음 — 전투 중 언제든 변신 가능 (쿨다운 없음)
- 형태 예시: 인간(기본), 기사, 마법사, 용, 말, 로봇, 달걀, 뱀...

### 2. 업그레이드 & 커스터마이징
- 각 폼의 능력치를 별도로 업그레이드
- **폼 믹싱**: 다른 폼의 능력을 현재 폼의 슬롯에 장착 가능
  - 예: 기사 폼으로 플레이하면서 마법사 폼의 원거리 공격 장착
- 시너지를 통한 빌드 다양성 극대화

### 3. 퀘스트 기반 잠금해제
- 퀘스트는 각 폼에 귀속
- 퀘스트 완료 → 해당 폼 레벨업 → 새 폼 해금
- 단순 반복 방지: 각 폼마다 독특한 퀘스트 목표

### 4. 로컬/온라인 2인 협동
- 2인 동시 플레이 완벽 지원 (온라인 포함)
- Player 2가 합류 시 고유 형태 세트를 독립적으로 운용
- 피격 시 파트너가 부활 역할 (완전 사망 없이 쓰러진 상태로 대기)
- 공유 화면(shared camera): 두 플레이어가 한 화면에서 이동

### 5. 던전 구조
- 로그라이트가 아닌 로그라이크 요소: 맵은 고정, 내부 적/보상은 반복 가능
- 챕터별 던전 + 오버월드 구조
- 던전 내 엘리트 / 미니보스 / 챕터 보스

## 협동 플레이 설계 철학

### 역할 분담 없는 협동
- 두 플레이어 모두 동일한 폼 풀 접근 가능 → 역할이 유동적
- 자연스럽게 서로 다른 폼을 선택해 시너지 발생
- "강제 협동"이 아닌 "자연 발생 협동"

### 진입 장벽 낮춤
- Player 2는 기존 세이브에 언제든 합류/이탈 가능
- 두 플레이어의 진행도가 모두 저장됨 (Player 2도 아이템/폼 유지)

## 플레이어들이 좋아하는 점

1. **폼 다양성** — 15+ 형태가 전부 실용적이고 재미있음
2. **능력 믹싱의 창의성** — 예상치 못한 조합으로 강력한 빌드 발견
3. **공동 발견의 재미** — 파트너와 함께 시너지를 찾는 과정
4. **접근성** — 퀘스트 시스템이 목표를 명확히 제시, 막히지 않음
5. **비주얼 개성** — 기괴하고 유머러스한 설정이 기억에 남음

## 비판적 시각

1. **후반 단조로움** — 챕터가 길어질수록 목표가 비슷해짐
2. **협동 밸런스** — 온라인 시 카메라 제한이 가끔 불편
3. **로그라이크 깊이 부족** — 진정한 랜덤성이 적어 반복 플레이 유인 약함

## OnionCat 적용 포인트

### 1. 역할 분담의 자연스러운 유도
- Nobody Saves the World는 강제 역할 없이도 플레이어가 자연히 다른 폼을 선택
- **적용**: Cat(근접)와 Crop(원거리)의 고정 역할이지만, *각자가 보유한 업그레이드 슬롯을 통해 세부 역할을 커스터마이징* 가능하게 설계
- 예: Cat이 "돌진 후 광역 슬래시" vs "단타 고뎀" 특화를 선택

### 2. 능력 믹싱 → OnionCat 업그레이드 시스템 힌트
- Cat과 Crop 각자의 업그레이드 풀에서 "상대방의 성질을 빌린" 능력 추가 가능
- 예: Cat이 "작은 투사체 동반 슬래시" 업그레이드, Crop이 "근접 방어막 활성화 후 파이어볼" 업그레이드
- 이렇게 하면 협동 보상이 시너지 콤보로 직결

### 3. 파트너 부활 메카닉
- 한 플레이어가 쓰러지면 다른 플레이어가 소생 역할 → 완전 게임오버 방지
- **적용**: Cat이 쓰러지면 Crop이 홀로 일정 시간 버텨 Cat 부활 (공유 체력이라면 공유 HP 임계값 이하에서 "위기 모드" 발동)

### 4. 유머러스한 비주얼 컨셉
- 기괴한 형태들이 웃음을 유발 → 게임에 개성 부여
- **적용**: OnionCat도 Cat이 양파를 등에 지고 달리는 비주얼 자체가 유머 포인트 — 몬스터 디자인도 의도적으로 엉뚱하게 설계

### 5. 협동 카메라 처리
- Nobody Saves the World의 공유 스크롤 카메라는 두 플레이어 중심점 추적
- **적용**: OnionCat은 하나의 캐릭터(Cat 등에 Crop)이므로 카메라가 항상 Cat 추적 — 별도 처리 불필요하지만 Crop의 마우스 조준 범위(사거리)를 화면 밖으로 넘기지 않도록 제한 필요
