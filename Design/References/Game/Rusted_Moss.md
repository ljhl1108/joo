## 핵심 메커니즘

### 1. 로프 기반 2인 협동
두 플레이어가 **하나의 물리 로프로 묶여** 있다. 이 로프는:
- 두 캐릭터 간 거리를 제한하는 **제약 조건**
- 적을 감아 무력화하거나 지형을 활용하는 **무기**
- 스윙·비행의 핵심 이동 수단인 **그래플훅 연장선**
이 세 가지를 동시에 수행한다.

### 2. 그래플훅 이동
두 플레이어 모두 그래플훅을 사용할 수 있으며, **로프 텐션 + 스윙 + 당김**이 조합된다. 점프 버튼이 없고 그래플훅과 로프 물리로만 이동한다. 이는 마스터하기 어렵지만 달성 시 매우 유동적인 이동감을 준다.

### 3. 로프-적 상호작용
적 주위를 로프로 감으면 이동을 방해할 수 있으며, 두 플레이어가 반대 방향으로 이동하면 감겨 있는 적을 조여 추가 피해를 준다.

### 4. 1인 플레이 옵션
1인도 가능하지만, **양손으로 두 캐릭터를 동시에 조작**해야 한다. 이는 극단적으로 어렵지만 일부 플레이어에게 독자적 도전으로 어필한다.

### 5. 로그라이트 요소
- 런마다 능력치·무기 업그레이드 선택
- 사망 시 처음부터 (퍼마데스)
- 일부 지역·보스는 랜덤 순서로 접근 가능

## 플레이어가 사랑하는 요소

| 요소 | 이유 |
|------|------|
| 로프 물리 | 물리 시뮬레이션이 정직해서 "내 잘못"이 명확하다 |
| 로프=무기 아이디어 | 제약이 능력으로 반전되는 순간의 쾌감 |
| 2인 전용 콤보 | 혼자서는 불가능한 기술 조합 |
| 소규모 팀 작품 | 2명이 만든 게임치고 폴리시가 뛰어나다 |
| 분위기 | 포스트아포칼립틱 + 자연회귀 미학 |

## 비판 / 단점

- **진입 장벽 매우 높음**: 그래플훅 이동 학습 곡선이 가파르다
- **협동 필수성 불균형**: 한 플레이어가 주도적이 되면 다른 플레이어가 수동적으로 끌려다니기 쉬움
- **1인 플레이는 사실상 불가**: 마케팅과 달리 1인 플레이는 극히 어려움

## OnionCat 적용 포인트

### 핵심 인사이트: "제약 자체가 게임플레이"
OnionCat은 두 플레이어가 **하나의 몸(고양이 + 화분)**을 공유한다. Rusted Moss가 로프를 단순 이동 제한이 아닌 핵심 무기로 만들었듯이, OnionCat도 **공유 몸체 = 제약 → 강점**으로 설계해야 한다.

| Rusted Moss | OnionCat 대응 |
|-------------|----------------|
| 로프로 적 감기 | 고양이가 돌진해 적을 위치시키면 양파가 최적 각도로 조준 가능 |
| 두 캐릭터 반대방향 당기기 | 고양이(근접)와 양파(원거리)가 협력해야만 처치 가능한 적 설계 |
| 로프 텐션 피드백 | 두 플레이어의 "연결감" 표현 — 화분이 흔들리거나 고양이 이동 시 채소가 반응 |
| 1인은 극히 어려움 | OnionCat도 2인 전용으로 밸런스 잡는 게 옳다 — 솔로 모드 AI 보조는 별도 설계 |

### 구체 적용
1. **약점 시스템 강화**: Rusted Moss처럼 "로프 없이는 불가능한 전략"처럼 OnionCat도 "근접 없이는 못 죽이는 적 + 원거리 없이는 못 죽이는 적"이 공존해야 함
2. **연결 피드백**: 화분(Player 2)가 고양이(Player 1)와 너무 멀어지면 화분이 흔들리거나 채소가 시드는 시각적 표현
3. **공동 움직임 디자인**: 두 플레이어가 물리적으로 같은 오브젝트를 제어한다는 점 활용 — 고양이가 대시할 때 Player 2 조준점이 흔들리는 식의 의존성

## 기술 참고

- Unity 2D + Rigidbody2D 체인/스프링 조인트로 로프 구현 가능
- LineRenderer로 로프 시각화
- DistanceJoint2D와 SpringJoint2D의 조합으로 탄성 있는 로프 표현
