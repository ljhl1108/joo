# Hammerwatch

리서치 날짜: 2026-11-04

## 기본 정보

- **개발사**: Crackshell (스웨덴 인디, 2인 팀)
- **출시**: 2013년 PC
- **플랫폼**: PC(Steam), Switch, PS4/5, Xbox
- **장르**: 탑다운 협동 던전 크롤러 (로그라이크 요소 포함)
- **인원**: 1~4인 로컬·온라인 협동
- **공식 사이트**: https://crackshell.com/hammerwatch/
- **Steam**: https://store.steampowered.com/app/239070/Hammerwatch/

## 핵심 시스템

### 클래스 시스템
- 기본 4종: **팔라딘**(근접·방패), **레인저**(원거리 화살), **마법사**(마법 광선), **워록**(폭발탄)
- 각 클래스 완전 비대칭 — 사거리·이동 속도·특수기 모두 다름
- 같은 클래스를 여럿이 쓸 수 있음 (팔라딘 4명도 가능)
- **OnionCat 참고**: Hammerwatch에서 "근접 1명 + 원거리 1명" 조합이 가장 인기 — OnionCat의 고양이(근접)·양파(원거리) 분업과 정확히 일치. 10년 전부터 검증된 협동 구도

### 스킬 업그레이드 (런 내 성장)
- 방에서 **금화**를 모아 상점·업그레이드 기둥에서 스텟 구매
- 체력·스텟·특수기 강화 → 일부는 영구, 일부는 런 한정
- 복잡한 빌드 없음 — 선형 강화 (더 강해질수록 적도 많아짐)
- **OnionCat 참고**: OnionCat은 카드 선택 빌드가 있어 훨씬 복잡. Hammerwatch의 단순함이 오히려 협동의 화면 집중도를 높임

### 방 구조 & 레벨 디자인
- 각 방 = 적 웨이브 + 열쇠·보물 탐험
- **문-열쇠 구조**: 특정 색 문을 열려면 그 색 열쇠 필요 → 방 탐험 경로 자연스럽게 유도
- 방마다 비밀 통로·숨은 방 존재 → 협동으로 더 잘 발견
- **함정 방**: 화살·불꽃·톱날 등의 환경 위험 → 한 명이 버튼 누르는 동안 다른 명이 함정 통과
- **OnionCat 참고**: 열쇠-문 구조 없이 "방 클리어 → 출구 개방"으로 단순화한 것이 OnionCat. Hammerwatch식 환경 퍼즐(버튼+함정)은 OnionCat의 2인 기믹 방 아이디어와 직결

### 협동 메커니즘
- **복잡한 협동 없음** — 그냥 같이 싸우면 됨
- 쓰러진 플레이어는 그 자리에 고정, 아군이 밟으면 부활 (일정 HP로)
- **공유 금화**: 한 명이 먹어도 모두의 돈 — 쓰는 건 개인
- **OnionCat 참고**: 명시적 협동 시스템 없어도 "같이 있어야 하는 상황"이 협동감 만들어줌 (부활이 대표적). OnionCat의 "합동 게이지"는 더 적극적 협동 유인

### 보스 디자인
- 각 스테이지 마지막 보스 → 고정 패턴, 넓은 공간에서 2페이즈
- 보스 체력이 아주 높고, 혼자 클리어 가능하지만 협동 시 훨씬 빠름
- 함께 집중하면 단순히 "빨리 끝남" — 협동 보너스가 없음
- **OnionCat 참고**: OnionCat의 협동 콤보·합동기가 "협동 → 더 강해짐"을 명시적으로 보상 — Hammerwatch보다 발전된 설계

### 성능 & 기술
- 2인 팀이 2년 만에 출시한 작품
- 절차적 생성 없음 — 완전 핸드크래프트 레벨
- 멀티플레이: 로컬 / P2P 온라인 (서버 없음)
- 나중에 Heroes of Hammerwatch(로그라이트 리메이크), Hammerwatch II(오픈월드)로 발전

## 플레이어들이 좋아하는 것

1. **진입 장벽이 낮음** — 10초 안에 조작 이해, 1분 안에 재미 느낌
2. **협동의 직관성** — "저 방에 넌 가고 난 여기서 적 막을게" 같은 즉석 전략
3. **재플레이성** — 클래스 조합, 경로 선택으로 같은 맵도 다르게 플레이
4. **카오스 협동** — 4명이 뛰어다니며 화면이 엉망이 되는 재미 (특히 초보 그룹)

## OnionCat 적용 포인트

| 주제 | Hammerwatch 접근 | OnionCat 적용 |
|------|-----------------|--------------|
| 근접+원거리 분업 | 클래스 선택으로 자유롭게 | 고양이·양파로 고정 — 처음부터 "팔라딘+레인저 조합"을 강제해 더 집중된 경험 |
| 2인 기믹 방 | 버튼 누르기+함정 통과 패턴 | 쌍둥이 스위치 외 더 많은 패턴 개발에 Hammerwatch 맵 참고 |
| 보스 2페이즈 | 단순 HP 구간 패턴 강화 | 체력 50%에서 페이즈 전환 — 비슷한 접근 |
| 방 열쇠 구조 | 색상별 열쇠-문 | OnionCat에서는 불필요 (런 속도 중시), 하지만 "조건부 출구" 아이디어는 활용 가능 |
| 비밀 방 | 벽을 부수면 숨은 방 | 보물 방·특수 방 개념과 연결 — 분기 지도에서 "숨겨진 경로" 이벤트 |
| 부활 메커니즘 | 아군 밟으면 부활 | OnionCat은 공유 체력 → 한 명 쓰러짐 개념 없음. 체력 위기 시 협동 부활 아이템 가능성 |
