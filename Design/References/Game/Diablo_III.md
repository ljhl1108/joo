## 핵심 시스템

### 장비 & 세트 시스템 (OnionCat 직접 참고)

**아이템 등급**: 일반 → 매직(파랑) → 희귀(노랑) → 전설(주황) → 세트(녹색)
- 세트 아이템은 같은 세트를 2/4/6개 착용할수록 강력한 보너스를 주는 구조
- **2-piece 보너스**: 작은 숫자 강화 (스킬 쿨다운 –10% 등)
- **4-piece 보너스**: 의미 있는 강화 (특정 스킬 피해 ×2)
- **6-piece 보너스**: 빌드를 완전히 정의하는 거대 보너스 (피해 ×10,000 수준)

**OnionCat 적용**: OnionCat의 햇살(2단계·4단계)·바람(2단계·4단계) 세트는 Diablo III와 유사한 구조다. 다만 D3는 6단계까지 있어 '중간 보너스가 브리지 역할'을 한다는 점 참고 — OnionCat도 6·8단계 설계 시 중간 보너스를 점진적으로 늘려야 세트 조각 모으기가 내내 보람 있다.

### 레전더리 고유 효과

- 각 전설 아이템은 빌드를 바꾸는 고유 접사를 가짐 (예: 특정 스킬 피해 500% 증가, 사망 시 부활 등)
- 레벨업은 없고 **강화(Enchanting)**로 접사 하나를 재조합 가능
- 같은 전설 중복 획득 → **분해** → 재질로 재활용

**OnionCat 적용**: 전설 장비가 아직 0개인 상태. D3처럼 전설은 단순 능력치 강화가 아닌 '기술을 완전히 새로 만드는' 효과로 설계하면 희귀성이 살아난다. 예: 고양이 전설 무기 = "걷어차기가 두 방향으로 동시에 날아감", 양파 전설 마법서 = "씨앗 탄이 관통하며 2배 느리게 날아감"

### 시즌(계절) 시스템

- 3개월 주기로 초기화되는 캐릭터 서버
- 시즌 여정(Journey): 도전 과제를 단계별로 달성하면 해당 시즌 전용 세트 세트 보상
- **Journey 보상 구조**: 1장(기본 달성) → 2장(중급) → 3장(도전) → 마스터(최고 보상)
- 시즌 비주제(Theme): 매 시즌 특정 추가 효과 제공 (예: "공격 시 랜덤 룬 스킬 발동")

**OnionCat 적용**: 런 목표를 명시적으로 보여주는 Journey 스타일 미니 목표 UI는 초보 플레이어 가이드에 유용. 현재 OnionCat은 런 결과 화면에 통계만 있는데, 런 내 도전 목표("킥 콤보 10회", "패링 5회" 등)를 추가하면 협동 콤보 시스템을 더 잘 활용하도록 유도 가능.

### 그레이터 리프트 (Paragon 시스템)

- 반복 런 기반 무한 난이도 상승 (GR 레벨 1~150+)
- 런마다 시간 제한 + 진행 게이지 → 클리어 시 전설 보석 강화 기회
- 클리어 시간이 빠를수록 상위 난이도 해금 (즉각 피드백 루프)

**OnionCat 적용**: 현재 런 결과 화면에 시간이 있는데, 방별 클리어 시간을 기록하고 개인 최고 기록을 보여주면 리플레이성이 오른다.

## 협동 플레이

- 2~4인 자유 합류/이탈 (Drop-in/out)
- **각자 개별 드롭**: 같은 몹을 죽여도 각자에게 서로 다른 아이템이 드롭됨 → 드롭 경쟁 없음
- **경험치 공유**: 파티 내 경험치 공유 (보너스 없음, 페널티도 없음)
- **부활 시스템**: 파티원이 살아있으면 시체 클릭으로 부활 (GR에서는 불가)

**OnionCat과 비교**: OnionCat은 1체력·1공유 캐릭터라 D3 분업 구조와 다름. 단, D3의 "아이템 드롭을 개인별로 분리"하는 아이디어는 OnionCat에서도 전투방 드롭이 한 명에게 귀속되는 현 방식과 같아 검증된 구조임.

### 캐릭터 역할 분담

- 바바리안(근접 탱) + 위저드(원거리 딜): 전형적인 탱/딜 분업
- **Support 전문 빌드**: 자신은 피해 없이 팀 버프/디버프만 담당하는 빌드도 존재
- 협동 콤보는 명시적 시스템 없음 → 단순히 더 빨리 클리어

**OnionCat과 비교**: D3의 명시적 콤보 시스템 부재가 오히려 협동 심도를 낮춘다는 비판이 있음. OnionCat의 "번갈아 때리기 → COMBO!" 시스템이 더 명확한 협동 동기를 만드는 것은 좋은 설계.

## 플레이어가 좋아하는 것

1. **파워 판타지**: 약 → 강의 곡선이 극단적으로 명확 (전설 세트 착용 전후가 완전히 다른 게임)
2. **아이템 사냥의 도파민**: 15분마다 전설이 하나씩 떨어지는 드롭률 → 중독성
3. **빌드 다양성**: 같은 클래스도 세트에 따라 10가지 이상 빌드 존재
4. **공략 깊이**: 시즌 랭킹, 최적화 계산, 커뮤니티 빌드 공유

## 플레이어가 비판하는 것

1. **내러티브**: 스토리가 빈약하고 반복 시 스킵 불가 (패치로 개선됨)
2. **세트 의존성**: 세트 없이는 고난이도 불가 → "세트 수집이 진짜 게임 시작"이라는 느낌
3. **낮은 빌드 자유도**: 결국 최적 빌드 수렴 → 창의적 선택 여지 감소
4. **PvP 부재**: 2.0 이후 PvP 시스템 사실상 포기
