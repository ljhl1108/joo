## 핵심 메카닉

### 1. 절차적 레벨 생성
- 4×4 방 타일로 이루어진 레벨, 각 타일은 미리 제작된 서브룸 조각들로 채워짐
- 랜덤하지만 항상 클리어 가능한 경로 보장 (배경 생성 알고리즘)
- 세계 분기: Tide Pool / Temple / Volcana / Neo Babylon — 선택에 따라 다른 경로

### 2. 물리 기반 상호작용
- 모든 오브젝트에 물리 적용: 투척 가능, 연쇄 반응, 폭발
- 아이템 간 복합 인터랙션 (폭탄 + 상자 + NPC = 예상치 못한 결과)
- 전략적 투척: 적을 다른 적에게 던지기, 바위로 특수 아이템 파괴

### 3. Ghost Jar (유령 항아리) — 핵심 협력 메카닉
- 플레이어가 사망하면 유령이 되어 항아리(Ghost Jar) 속으로 들어감
- 살아있는 동료가 항아리를 집어 들고 이동 가능
- 안전 지점에서 항아리를 놓으면 부활 (제한된 HP로 복귀)
- **의의**: 완전 퍼마데스가 아닌 팀 단위 생존 유도

### 4. 마운트 시스템
- 터키, 롹독, 메가제리피쉬 등 탈 수 있는 생물
- 마운트별 특수 능력: 이중 점프, 수영, 탄성 공격
- 협력 플레이 시 마운트를 공유하거나 서로 던지는 전술

### 5. 세계 분기 & 히든 루트
- 에그플랜트 런: 최고 난이도 히든 루트, 복잡한 아이템 체인 요구
- Cosmic Ocean: 최후반부 극한 도전 지역 (7-99 레벨)
- 분기마다 독자적인 적/함정/보스/아이템 풀

### 6. 협력 플레이 특성
- 로컬/온라인 1–4인 협력
- 팀킬 가능 → 실수가 웃음과 긴장을 동시에 유발
- 아이템 쟁탈: 좋은 아이템을 두고 협력자와 경쟁
- 서로 들어올리고 던지기 가능 → 전략적 협동

## 플레이어가 사랑하는 것

| 요소 | 이유 |
|------|------|
| 발견의 즐거움 | 숨겨진 상점, 알타르, 시크릿 월드가 계속 나옴 |
| 상호작용 깊이 | 두 아이템/적을 조합하면 예상치 못한 결과 |
| 협력의 혼돈 | 동료가 실수로 죽이지만 그게 웃김 |
| 스피드런 커뮤니티 | 세계 기록 경쟁, 카테고리 다양 |
| 모든 죽음이 배움 | 억울해도 내 실수였다는 걸 알게 됨 |

## OnionCat 적용 포인트

### 1. Ghost Jar → OnionCat 부활 시스템 힌트
Spelunky 2의 Ghost Jar처럼, 한 플레이어가 사망해도 즉시 런이 끝나지 않는 메카닉을 고려할 수 있음.  
예: 양파(Player 2)의 HP가 0이 되면 일시적으로 비활성화 → 고양이(Player 1)가 특정 액션을 수행해 부활 → 협력 긴장감 유발.

### 2. 물리적 투척 전술 → 공유 바디의 전술 다양화
Spelunky 2에서 동료를 던져서 적에게 맞추는 전술처럼, OnionCat에서도 "꽃 화분 분리 던지기" 같은 리스키한 특수 협력 기술을 고려.

### 3. 세계 분기 → 런 내 경로 선택
매 런마다 분기 선택(어려운 길 vs 쉬운 길, 보상 차이)으로 협력자 간 의견 충돌 → 협동 게임의 사회적 드라마.

### 4. 팀킬 허용 여부 결정
Spelunky 2는 팀킬 가능이 핵심 긴장 요소. OnionCat도 Player 1의 범위 공격이 Player 2를 해칠 수 있는 설계를 고려할 수 있음 (옵션으로).

### 5. 죽음의 교육적 설계
모든 트랩/적이 명확한 사인을 주고, 첫 사망은 "배움"이 되도록 설계. OnionCat 초반 룸 설계 시 참고.
