## 핵심 메카닉

### 기본 구조
- 절차적으로 생성되는 동굴을 탐험하는 2D 플랫포머
- 완전 퍼마데스: 사망 시 처음부터 (메타 진행 없음)
- 3개 기본 클래스: **Rogue(도적)**, **Knight(기사)**, **Mage(마법사)**
- 각 클래스마다 고유한 이동/전투 패턴

### 협동 구조
- 2~4인 협동 시 **사망한 플레이어가 일정 시간 안에 부활 가능** (동료가 시체에 접근해 부활)
- 모든 플레이어가 죽으면 게임 오버
- 아이템은 개인 인벤토리 → 협동이 아이템 공유보다 전투 보완에 집중
- 플레이어들이 각자 다른 위협 대처 → 자연스러운 역할 분담

### 클래스 시스템
| 클래스 | 특징 | OnionCat 대응 |
|--------|------|--------------|
| Rogue | 근접+회피, 대시 중 무적, 빠른 이동 | Cat (고양이) |
| Mage | 원거리 마법, 느린 이동, 강한 화력 | Onion (원거리) |
| Knight | 근접+방어, 방패 블록, 안정적 | P1 공격 + P2 방어 혼합 |

### 레벨 디자인
- **4개 구역**: Cave → Forest → Ruins → ??? (최종 보스)
- 각 구역은 완전 절차 생성 + 고정 보스
- **비밀 방**: 특정 조건(폭탄 사용, 점프 타이밍)으로 발견하는 숨겨진 구역
- **함정/환경 위험**: 가시, 낙하 데미지, 어두운 구역 — 플랫포머 특성상 환경 자체가 적

### 전투 시스템
- 근접: 검 기본 콤보 2~3타
- 원거리: 마법 → 투사체 다양성 (직선, 호밍, AoE)
- **아이템 기반 강화**: 롤플레이 아이템(반지, 부적, 항아리 등)이 플레이스타일 결정
- 함정을 역이용해 적 처치 가능 (가시, 낙하 함정)

## 플레이어들이 좋아하는 것

- **높은 난이도와 공정한 학습 곡선**: "죽는 이유가 분명하다"는 평
- **협동 부활 메카닉**: 동료를 살리기 위한 위험 감수 → 의사결정 긴장감
- **클래스 조합 다양성**: Rogue+Mage가 가장 시너지 좋은 조합으로 꼽힘
- **원시적 퍼마데스**: 메타 진행 없는 순수 로그라이트의 재미
- **비밀 발견**: 처음에 모르는 숨겨진 구역과 이스터에그

## OnionCat 적용 포인트

### 1. Rogue+Mage 조합이 OnionCat의 청사진
Vagante에서 가장 인기 있는 협동 조합이 "빠른 근접(Rogue) + 강한 원거리(Mage)". OnionCat의 Cat+Onion 조합과 정확히 일치. Vagante 유저들이 이 조합에서 느끼는 "근접이 어그로 끌고 원거리가 화력" 역학이 OnionCat 전투 설계의 검증된 방향성임.

### 2. 협동 부활 시스템의 긴장감 설계
Vagante의 부활 메카닉: 사망 후 시체 옆에 동료가 접근해서 일정 시간 상호작용. 이 과정에서 동료가 적의 공격에 노출됨 → "구하러 가야 하나 vs 살아남아야 하나" 갈등.
OnionCat 적용: Cat이 쓰러지면 Onion이 화분에서 빠져나와 일정 시간 독립 행동하며 "부활 아이템"을 수집. Cat이 사망하면 Onion의 화분이 바닥에 쓰러지고 Cat이 다시 집어들어야 하는 부활 루프.

### 3. 클래스 특성이 이동에도 반영
Vagante는 Rogue가 대시, Mage는 블링크, Knight는 방패 슬라이드로 이동 자체에 개성이 있음. OnionCat도 Cat의 대시(무적 내장)와 Onion의 방패(이동은 없지만 방향성 있는 방어)가 이동+전투를 연결하는 구조를 이미 가짐 — Vagante의 검증된 패턴.

### 4. 환경 함정을 역이용하는 설계
방 내 가시, 낙하 구멍 등 환경을 적이 걸어들어가도록 유인하는 플레이. OnionCat 맵 설계에 응용: Onion의 방패로 적 탄막을 반사해 다른 적에게 맞히기, Cat의 대시로 적을 함정 위치로 유도.

### 5. 비밀 방 발견의 보상
Vagante 비밀 방: 폭탄 벽 파괴, 특정 점프. OnionCat: Cat의 슬래시로 파괴 가능한 숨겨진 벽 + Onion의 투사체로 찾는 비밀 통로. 두 캐릭터의 능력을 활용한 비밀 탐색.
