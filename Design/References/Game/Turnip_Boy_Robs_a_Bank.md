## 핵심 메카닉

### 은행 강도 로그라이트
- 플레이어는 Turnip Boy(순무 소년)가 되어 Botanical Bank를 털러 감.
- **매 런**: 은행 내부를 탐험, 직원/경비/손님 처치, 금고 목표 달성 후 탈출.
- **시간 제한** 없음 — 탐욕에 따라 더 많은 방을 털수록 더 많은 보상, 더 많은 위험.

### 전투 시스템
- **근접 무기**: 기본 채소 검(Vegetable Sword) — 전방 휘두르기.
- **원거리 무기**: 씨앗 권총, 고추 샷건, 호박 런처 등 다양한 "채소 무기".
- **특수 능력**: 아이템 사용 (방어막, 속도 증가 등).
- 무기는 런 중 보상으로 획득 → 런마다 다른 빌드.

### 핵심 루프
1. 런 시작 → 은행 입장
2. 방 클리어 → 현금 획득
3. 특별 방(보스/상점/무기고) 탐색
4. 탈출(경찰 도착 전) 또는 과욕으로 실패
5. 런 결과 → 영구 업그레이드 구매

### 채소 캐릭터 생태계
- 적도 모두 채소/과일 캐릭터: 당근 경비원, 배추 손님, 마늘 보스 등.
- 세계관 전체가 채소 기반 → 세계관 통일성, 귀여움+위협 동시 연출.

## 협력 요소 분석

이 게임은 솔로 전용이므로 협력 요소는 없음. 단, OnionCat에 참고할 설계 원칙이 있음.

---

## 플레이어가 좋아하는 것

1. **캐릭터 매력**: 순무(Turnip)가 악역 역할을 유머스럽게 수행 — 귀여운 외모와 범죄 행위의 대비.
2. **빠른 런**: 평균 런 길이 15~20분 → 짧고 임팩트 있어 "한 판 더" 유도.
3. **무기 다양성**: 모든 무기가 채소 테마 → 세계관 일관성 + 상상력 자극.
4. **유머 대사**: NPC가 맞으면서 하는 반응 대사가 웃기고 기억에 남음.
5. **게임패스 출시**: 접근성 높아 넓은 관객층 확보.

## OnionCat 적용 포인트

### 1. 채소 캐릭터의 귀여움 + 위협적 공존
가장 직접적인 참고 포인트. Turnip Boy처럼 OnionCat의 Onion(양파)도:
- 귀여운 외모지만 강력한 원거리 공격 → "귀엽지만 무서운" 이미지.
- 양파가 눈물을 흘리는 공격(산성 눈물 투사체?)처럼 채소 특성을 능력에 반영.
- 적도 채소 테마로 구성하면 세계관 통일성 확보 가능.

### 2. 채소 무기 네이밍 아이디어
Turnip Boy의 무기 네이밍에서 영감:
- OnionCat에서도 무기/업그레이드 이름에 채소/식물 테마 적용:
  - "마늘 폭탄 (Garlic Bomb)" — 범위 공격 아이템
  - "고추 대시 (Chili Dash)" — 대시 능력 강화
  - "당근 방패 (Carrot Shield)" — Onion 쉴드 업그레이드

### 3. 빠른 런 구조 (15~20분 런)
초보 개발자의 OnionCat에 이상적인 목표 런 길이:
- 초반 3~4개 방 → 보스 → 탈출: 약 10~15분 런
- 플레이어가 "잠깐 한 판"으로 시작했다가 계속하게 되는 구조
- 첫 데모/프로토타입 스코프: 방 5개 + 미니보스 1개면 충분.

### 4. 유머 반응 대사 (NPC 반응)
Turnip Boy에서 NPC가 맞을 때 하는 대사처럼, OnionCat에서도:
- 적이 Cat에게 슬래시 맞으면: "고양이한테 지다니!" 같은 짧은 텍스트 팝업.
- 적이 Onion의 씨앗에 맞으면: "채소한테 진 거야?!" 같은 반응.
- Unity 구현: HitReaction 컴포넌트에 random string 배열 → 피격 시 `FloatingTextSpawner.Show(randomResponse)`.

### 5. 탈출 조건 = 텐션 생성기
Turnip Boy의 "경찰 도착 전 탈출" 처럼:
- OnionCat에서 방 클리어 후 탈출 포털이 열리는 타이밍을 적절히 지연시키면 긴장감 생성.
- 또는 "방 클리어 후 N초 안에 나가야 함 → 보너스 보상" 같은 선택적 압박 요소.
