## 핵심 메카닉

### 1. 두 캐릭터 — 원거리 vs 근접 분리
- **Nina** (파란색): 버스터 캐논 → 원거리 사격 특화, 이동 균형형
- **Ace** (주황색): 에너지 소드 → 근접 전투 특화, 대시 공격 강조
- 두 캐릭터는 능력·플레이스타일이 완전히 다름
- 솔로 플레이 시 어느 캐릭터든 선택 가능, 코옵 시 역할 분담

### 2. 코옵 시너지 설계
- 근접(Ace)이 적을 모아두면 원거리(Nina)가 뿌리는 방식
- 약한 적은 Ace가, 먼 거리 적이나 떨어진 보스 패턴은 Nina가 처리
- 특정 구간(벽 뒤 적 등)은 Nina만 처리 가능 → 강제 협력
- 업그레이드 획득 시 두 플레이어 공유 여부 선택 필요

### 3. 절차적 생성 + Mega Man X 구조
- 스테이지 타일 조각이 무작위 조합으로 방 생성
- 보스 처치 후 그 보스의 능력(서브 웨폰) 획득 — Mega Man X 방식 계승
- 런마다 다른 업그레이드 풀에서 파워업 획득

### 4. 강화 시스템
- 런 중 업그레이드: 이동 속도, 쿨다운, 추가 점프 등
- Gearbits(재화): 사망 후에도 유지, 영구 해금 콘텐츠에 사용
- 영구 해금: 새로운 파워업, 코스튬, 코어 업그레이드 트리

### 5. 코옵 죽음 처리
- 한 명이 죽으면 유령 상태로 전환 → 일정 시간 내 파트너가 부활
- 부활 실패 시 런 종료 → 협력 의존성 강화

## 플레이어가 사랑하는 것

1. **반응성**: 정밀 컨트롤이 살아있는 플랫포머 — 느낌이 좋음
2. **코옵 재미**: 둘이서 하면 역할 분담이 자연스럽게 발생
3. **런 다양성**: 업그레이드 조합으로 매 런이 달라짐
4. **Mega Man 향수**: 레트로 감성 + 현대 로그라이트 혼합

## OnionCat 적용 포인트

### A. 원거리/근접 역할 분리 — 직접 참고 모델
- 20XX의 Nina(원거리) / Ace(근접) 분리가 OnionCat Cat(근접) / Crop(원거리)와 구조 동일
- **핵심 차이**: 20XX는 두 몸, OnionCat은 하나의 몸 → 훨씬 긴밀한 협력 필요
- 20XX의 "근접이 모으고 원거리가 청소" 패턴을 OnionCat 근접-약한-적/원거리-약한-적 시스템과 결합

### B. 특정 구간 강제 협력 설계
- 20XX의 "벽 너머 적 = Nina만 처리 가능" 구조
- OnionCat에 적용: "방패 근접만 뚫리는 적", "공중 원거리만 닿는 적" 로 강제 협력 연출

### C. 코옵 부활 시스템
- 한 플레이어가 죽으면 유령 → 파트너가 부활 → 실패 시 런 오버
- OnionCat에서 Cat과 Crop이 각각 HP를 갖는다면 이 부활 구조 그대로 참고 가능
- 단, 하나의 몸이면 공유 HP → 별도 설계 필요

### D. 영구 해금 + 런 업그레이드 이중 구조
- Gearbits(영구) + 런 파워업(임시) 두 레이어
- OnionCat 메타 진행: 언락 아이템은 영구, 런 중 획득 강화는 사라짐

### E. 절차적 타일 조합 방 구조
- 방을 "타일 조각 세트"로 쪼개서 무작위 조합 → Unity Tilemap + Prefab Variant 방식과 호환

## 기술 메모

- 두 캐릭터 독립 조작: 각각 별도 `PlayerInput` 컴포넌트 + 서로 다른 `InputActionAsset`
- 유령 상태 부활: 별도 레이어의 유령 오브젝트 스폰, 콜라이더 비활성화, 파트너 도착 감지
