## 핵심 메카닉

### 무기 다양성 시스템
Lost Ruins의 가장 큰 강점은 압도적인 **무기 종류**다. 양손검, 단검, 도끼, 창, 해머, 활, 마법 지팡이 등 40종 이상의 무기가 등장하며, 각 무기마다 고유한 공격 모션·범위·타격감을 갖는다.
- **경량 무기(단검/단검류)**: 빠른 콤보, 짧은 사거리 → 민첩한 플레이
- **중량 무기(해머/대검)**: 느린 스윙, 넓은 판정, 강력한 넉백
- **원거리(활/지팡이)**: 완전히 다른 거리 전투 스타일

### 마법 시스템
무기 외에 독립적인 **마법 슬롯**이 존재한다. 화염구, 빙결, 번개 등 다양한 속성의 마법을 무기와 조합하여 사용한다. 이 이중 공격 레이어가 전투에 깊이를 더한다.

### 생존 / 자원 관리
- 체력 회복은 룸 내 음식·포션 아이템으로만 가능 — 실수에 무거운 패널티
- 각 층마다 `저장 포인트`가 존재해 순수 로그라이크보다 진입 장벽이 낮음
- 보스 처치 후 다음 층 진행 — 계층 기반 구조

### 픽셀아트 히트박스 설계
근접 공격에 **너그러운(generous) 히트박스**를 적용했다. 무기 스윙 애니메이션의 중간 프레임에만 실제 데미지 판정을 부여하여 "빗나간 것 같아도 맞는" 경험을 준다.

## 협동/경쟁 요소

Lost Ruins는 싱글플레이어 전용이지만, **무기 약점 시스템**이 OnionCat와 직접 연결된다:
- 일부 적은 **근접 공격에 면역** (예: 독 식물 — 근접 시 독 데미지)
- 일부 적은 **원거리에만 반응** (예: 원거리 반사 쉴드를 가진 기사)
- 플레이어는 무기를 빠르게 전환하며 상황에 적응해야 함

→ OnionCat의 **Cat(근접) / Crop(원거리) 강제 협력 구조**의 프로토타입 형태

---

## 플레이어들이 사랑하는 것

1. **무기 다양성** — 같은 던전이라도 다른 무기로 플레이하면 완전히 다른 경험
2. **픽셀아트 퀄리티** — 어두운 분위기, 애니메이션 완성도 (Steam 긍정 평가 80%+)
3. **전투의 무게감** — 히트스톱, 파티클, 사운드가 잘 어우러진 타격감
4. **무기+마법 조합** — "이 마법이 이 무기와 시너지가?" 하는 발견의 재미

## OnionCat 적용 포인트

### 1. 적 약점 설계 레퍼런스
Lost Ruins의 약점 시스템은 "근접만 통함 / 원거리만 통함"을 명시적으로 드러낸다. OnionCat에서도:
- **근접 전용 약점 적**: 방어막이 투사체를 흡수하지만 Cat 슬래시 통과
- **원거리 전용 약점 적**: 근접 시 가시 반격 or 전기 충격 — Crop의 투사체만 유효
- 플레이어에게 시각 신호 필요: 근접 약점은 파란 오라, 원거리 약점은 주황 오라

### 2. 이중 공격 레이어 → 이중 플레이어 레이어
Lost Ruins의 "무기 슬롯 + 마법 슬롯" = OnionCat의 "Cat 슬래시 + Crop 투사체"  
두 공격 유형이 독립적이면서도 같은 캐릭터를 통해 발동된다는 점에서 구현 구조 참고 가능

### 3. 무기 타격감 공식
Lost Ruins의 근접 히트 피드백:
- 히트 프레임: 히트스톱 3~4프레임 (약 0.05초)
- 적 스프라이트 흰색 플래시 1프레임
- 작은 파티클 버스트 (방향성 있는 스파크)
- 짧은 금속 충돌음 SFX
→ Cat 슬래시에 동일 공식 적용 권장

### 4. 저장 구조 적용
완전 퍼마데스보다 "층 단위 저장 포인트" 방식이 초심자 친화적. OnionCat 첫 버전은 각 층 클리어 후 저장 허용을 고려.
