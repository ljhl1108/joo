## 핵심 메커니즘

### 1. 협동 구조 (최대 4인)
- 로컬 & 온라인 혼합 멀티플레이어 지원
- **공유 목숨 시스템**: 파티 전체가 목숨 풀을 공유 → 한 명이 죽으면 팀 전체에 영향
- 누군가 쓰러지면 팀원이 부활 아이템으로 살릴 수 있음
- 인원 수에 따라 적 난이도 자동 스케일링

### 2. 클래스 시스템 (12종+)
| 클래스 | 역할 |
|--------|------|
| Warrior | 근접 방패, 탱커 |
| Ranger | 원거리, 함정 설치 |
| Mage | 마법 원거리, 광역 |
| Ninja | 고속 근접, 회피 |
| Tinkerer | 폭탄, 기계 장치 |
| Druid | 자연 마법, 지원 |

→ 클래스별로 약점/강점이 명확히 나뉘어 **자연스러운 역할 분담 협동** 유도

### 3. 마을 건설 (메타 진행)
- 던전 내 자원(광석, 목재, 수정)을 수집
- 런 종료 후 마을(Tasos)을 재건하는 데 사용
- 마을 건물에 따라 새 클래스 잠금 해제, 패시브 강화 등 영구 업그레이드
- **영구 진행 + 런별 리셋** 구조의 균형 모범 사례

### 4. 던전 구조
- 젤다 스타일 방 + 로그라이크 무작위 배치
- 각 던전에 보스 존재
- 4개 던전 클리어 → 최종 보스 → 런 완료
- 열쇠/보물 방/가게 방 등 방 유형 다양

### 5. 전투 시스템
- 각 클래스별 기본 공격 + 스킬 2~3개
- 구르기(회피) 공통 보유
- 픽업 아이템(무기, 방어구, 소비품) → 인벤토리 관리 단순화
- 적 유형에 따라 클래스별 효율 차이 있음

## 플레이어들이 사랑하는 요소

1. **쉬운 진입 장벽**: 단순한 컨트롤, 명확한 목표 → 로그라이크 입문자 친화적
2. **협동의 실질적 이점**: 혼자보다 팀이 확실히 유리한 설계
3. **마을 건설의 성취감**: 런마다 마을이 발전하는 시각적 피드백
4. **다양한 클래스**: 반복 플레이 시 다른 조합 시도 욕구
5. **접근성 있는 로그라이크**: Hades/Isaac처럼 어렵지 않아 캐주얼 협동 가능

## OnionCat 적용 포인트

### 협동 설계
- **공유 목숨**: OnionCat의 "한 몸" 컨셉과 잘 맞음 → 고양이와 작물이 분리되지 않으므로 이미 공유 HP 구조
- **역할 분담 강제**: 근접(고양이)이 탱킹, 원거리(작물)가 딜 → Rogue Heroes의 Warrior/Ranger 조합과 동일 철학
- **파티 스케일링 없음**: OnionCat은 정확히 2인이므로 밸런스 단순화 가능

### 메타 진행
- 마을 건설처럼 **허브 공간** 개념 도입 가능 → 런 사이에 고양이의 집/텃밭 등 성장 시각화
- 자원 수집 → 영구 업그레이드 루프는 OnionCat에도 자연스럽게 적용 가능

### 적 설계 힌트
- 근접 전용 약점 적 / 원거리 전용 약점 적의 동시 등장 → Rogue Heroes도 유사한 구조
- 다양한 적이 섞인 방에서 두 플레이어가 자연스럽게 역할 분리되는 구도 참고

### 마을/허브 컨셉 아이디어
- 온이온캣의 이야기 배경: 고양이가 돌봐온 텃밭이 몬스터에게 황폐화 → 런마다 텃밭 재건
- 수확한 작물(런 보상) → 텃밭 업그레이드 재료로 전환
