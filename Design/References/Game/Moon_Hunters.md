## 핵심 개요

1~4인 협동 픽셀아트 로그라이트. 달이 사라진 세계에서 신화적 전사들이 5일(런) 동안 답을 찾는다. **런이 끝날 때마다 플레이어 행동이 별자리로 새겨져 세계가 영구 변화**하는 독특한 메타 내러티브 시스템을 갖췄다. 전투보다 탐험·대화·의식 중심의 짧은 런(~45분).

---

## 핵심 시스템

### 1. 1~4인 로컬/온라인 협동
- 각 플레이어 독립 클래스: Spellbinder(마법진), Daemon Hunter(석궁), Fool(지팡이), Ritualist(창), Druid(변신), Kingsguard(방패+검)
- **클래스별 완전히 다른 조작감** — 원거리/근거리/버프 역할 자연 분담
- 로컬 화면 공유, 온라인은 별도 세션

### 2. 짧은 런 구조 (5 Day Run)
- 런 = 5일. 각 날 하나의 지역 탐험
- 탐험 중 이벤트(전투·NPC·유물·의식) 텍스트로 표시
- 전투는 실시간 액션, 나머지는 텍스트 선택지
- **"보스는 없고 최종 대결도 텍스트"** — 핵 앤 슬래시보다 내러티브 경험에 집중

### 3. Constellation (별자리) 시스템
- 런 종료 시 플레이어 행동 패턴이 별자리 성격으로 기록됨
- 다음 런에서 해당 별자리가 세계에 영향을 미침 (NPC 대사, 이벤트 확률 변화)
- **영구 세계 변화** — 퍼머데스지만 유산이 누적됨
- 50+ 캐릭터 성격 조합 가능

### 4. 관계 시스템
- 같은 NPC를 여럿이 만나면 관계 지표 변화
- 협동 플레이 시 동료와의 "유대감" 스탯 → 런 결말 영향

### 5. 간결한 전투
- 공격 1개 + 스킬 2개 + 패시브 구조
- 짧은 조작으로 빠른 접근 가능 — 복잡성보다 리듬감 우선
- 업그레이드는 전투 능력보다 내러티브 옵션 확장 중심

## 플레이어들이 사랑하는 것

- **픽셀아트 분위기**: 세계관이 독특하고 신화적 분위기가 진함
- **짧은 런**: 45분 안에 완결되는 호흡 → 부담 없음
- **공동 신화 창조**: 런마다 세계가 변한다는 느낌 → 반복 동기
- **클래스 다양성**: 6개 클래스가 각기 달라 여러 조합 시도 욕구 생성
- **co-op 친화성**: 솔로와 4인 경험 품질 차이가 작음 (솔로도 재미있음)

## 비판받는 것

- 전투가 단조롭다 (스킬 2개로 변화 적음)
- 로그라이트 요소보다 비주얼 노벨 비중이 크다
- 레벨 디자인 반복성 → 장기 플레이 시 질림
- 온라인 멀티 매칭 인프라 약함 (소규모 스튜디오)

## OnionCat 적용 포인트

### 1. 클래스 역할 분담 = OnionCat의 핵심
Moon Hunters의 근거리/원거리/버프 클래스 분담은 OnionCat의 Cat(근거리)·Onion(원거리) 구조와 직접 대응.
→ **두 역할이 서로 약점을 커버해야 풀리는 적 설계** 참고 가능

### 2. 짧은 런 구조
45분 런은 초보 개발자가 플레이테스트하기 이상적인 호흡.
→ OnionCat도 "한 판 = 15~30분" 타겟으로 설계하면 플레이테스트 사이클 빠름

### 3. 단순한 조작으로 협동 효과 극대화
스킬 2개짜리 캐릭터로도 협동 재미가 충분하다는 증거.
→ Cat의 슬래시+대시, Onion의 투사체+방패 — 조작 복잡도 낮추고 시너지에 집중

### 4. 업그레이드 = 스타일 선택
Moon Hunters의 업그레이드는 수치보다 행동 패턴을 선택.
→ OnionCat 업그레이드도 "더 강한 슬래시" 대신 "슬래시가 적을 밀어내는 방향" 같은 스타일 선택으로 설계 가능

### 5. 협동 친화적 데스 설계
동료가 살아 있으면 부활 가능 → 완전한 퍼머데스 없이 co-op 긴장감 유지.
→ Coop_Revival_System 참고 병행
