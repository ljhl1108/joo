## 핵심 메카닉

### 이중 중력 세계 (Dual Gravity World)
- 화면이 위/아래 두 레이어로 나뉨. Ibb는 아래 중력, Obb는 위 중력(천장이 바닥).
- 두 플레이어는 **포털을 통해서만 세계를 오갈 수 있음** — 포털은 두 플레이어가 특정 지점에 동시에 서야 열림.
- 한 레이어에서만 보이는 장애물이 있어, 한 플레이어가 위험을 안 보면서 나머지가 경고해야 함.

### 물리 기반 협력
- 서로를 발판으로 삼아 더 높이 점프 가능 (부스트 점프).
- 한 플레이어가 적 위에서 점프 → 적 처치. 두 플레이어가 협력해 적을 끼워야 처치되는 적도 있음.
- 두 플레이어 중 하나가 죽으면 **곧바로 그 레이어에서 시간이 멈춤** — 파트너가 소생해야 계속 진행.

### 정보 비대칭
- 한 레이어의 플레이어에게 보이는 것이 다른 레이어의 플레이어에게는 안 보임 → 말로 소통해야 하는 구조.
- 협력의 핵심: "내 위에 스파이크 있어?" "왼쪽 포털 열려 있어?" 같은 실시간 소통 필요.

## 플레이어가 좋아하는 것

1. **"유레카" 순간**: 두 플레이어가 동시에 퍼즐을 이해하는 순간의 만족감.
2. **낮은 진입장벽, 높은 숙련도**: 컨트롤은 단순하지만 퍼즐 난이도는 올라감.
3. **아트 스타일**: 미니멀한 기하학적 디자인, 선명한 색상 대비 → 누가 어느 레이어인지 명확.
4. **온라인 협력**: 같은 공간이 아니어도 협력 가능 — 친구와 원격 플레이에 최적.
5. **파트너와의 유대감**: 힘든 퍼즐을 함께 풀었을 때 연대감이 강해짐.

## OnionCat 적용 포인트

### 1. 역할 분리 → 정보 비대칭 협력
Ibb & Obb처럼 Cat(P1)과 Onion(P2)이 서로 다른 정보를 갖도록 설계할 수 있음.
- 예: 특정 방에서 Cat은 근접 적을 보고, Onion은 원거리 적을 먼저 인식 (시야각/인식 거리 차이).
- 또는 쉴드 방향 선택 시 Onion이 모르는 정보(화면 밖 적)를 Cat이 알려줘야 하는 상황.

### 2. 동시 행동 조건 (Two-Player Sync)
두 플레이어가 **동시에 같은 행동**을 해야만 발동되는 특수 기믹:
- 두 플레이어가 동시에 버튼 → 숨겨진 문 열기
- Cat 슬래시 + Onion 발사 동시 → 특수 패리 보너스 발동 (패리 → 강화 슬래시 연계 확장 가능)
- Unity 구현: `InputManager`에서 두 플레이어 입력 타임스탬프 비교, 0.1초 이내면 "sync" 이벤트 발생.

### 3. 소생 시스템의 역할 강조
Ibb & Obb의 "한 명 죽으면 멈춤 → 소생" 구조는 `Coop_Revival_System.md`와 유사.
OnionCat은 한 몸 공유라 다름 → 대신 **특정 상태(기절, 혼절)** 에서 살아있는 역할이 회복 행동을 해야 재기동 가능.
- 예: Cat이 맞아 기절 → Onion이 쉴드로 3초 방어 완료 시 Cat 회복.

### 4. 미니멀 UI 철학
Ibb & Obb의 UI는 아이콘 없이 색상만으로 구분. OnionCat도:
- Cat(주황)/Onion(초록) 색상 코딩으로 UI 혼란 없이 즉각 역할 인식 가능.
- 체력바, 쿨다운 등 모든 HUD 요소를 색상으로 구분 → 초보자도 즉시 "내 것" 인식.
