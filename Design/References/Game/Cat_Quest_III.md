## 핵심 메카닉

### 1. 비대칭 직업 협동 구조

- P1은 처음부터 전사(Warrior) 고정, P2는 궁수(Archer) 또는 마법사(Mage) 선택
- 두 플레이어는 **완전히 독립된 캐릭터**이지만 HP를 공유하지 않음 — 둘 다 죽어야 게임 오버
- P2가 빠지면 솔로 플레이로 전환, 체력·보상 수치가 그에 맞게 자동 조정
- 직업별로 **기본 공격 모션·궤적·범위**가 달라 서로 보완이 자연스럽게 발생

### 2. 해양 탐험 + 던전 구조

- 오픈월드 바다를 범선으로 항해 → 섬에 상륙 → 던전(선형)
- 던전은 짧고 명쾌 (5~10분): 방→방 이동 없이 연속 오픈 공간
- 적 엘리트 / 미니보스 / 보스 3단계
- **런이 없음**: 퍼마데스 아닌 일반 사망 후 부활 (HP 절반으로 최근 저장 지점 복귀)

### 3. 장비 시스템 (Equipment + Arcane Stones)

| 슬롯 | 역할 |
|------|------|
| 무기 | 기본 공격 모션 결정 |
| 갑옷 (상체) | 방어·체력 스탯 |
| 모자 (머리) | 마법력·쿨다운 관련 |
| 장신구 (반지·목걸이) | 특수 효과 |
| **아케인 스톤** | 능동 마법 슬롯 (최대 3개) — 스킬 역할 |

- 장비마다 등급(일반→희귀→에픽) + 고유 이름
- 세트 보너스: 같은 이름 계열 장비를 묶으면 추가 효과 (예: "Watcher Set" 2개→피해 증가)
- **중복 장비 = 자동 강화 대신 직접 장착 교체** (교체 전 툴팁으로 비교)
- 아케인 스톤은 원소 속성(불·얼음·번개·어둠·빛)을 가지며 지형 반응 없음

### 4. 텔레그래프 + 전투 리듬

- 적 공격은 **굵은 선** 또는 **영역 표시**로 0.5~1초 예고
- 닷지롤은 쿨다운 없이 자유 — 타이밍 숙달 시 무적 판정 활용 가능
- 보스는 2~3페이즈: 패턴 추가가 아니라 **기존 패턴 속도 증가** 방식
- "예고가 시작되면 확정" 원칙과 동일하게 운영됨

### 5. 협동 전용 요소

- 두 플레이어가 **정확히 같은 시간에** 각자 스킬을 발동하면 콤보 폭발 발생
- 상점에서 구매는 각자 독립적 (골드 공유 아님)
- P2가 사망하면 P1이 부활 가능 (반대도 마찬가지) — 타이밍 기반 미니 게임
- 협동 퍼즐: 한 명이 스위치를 밟고 버티는 동안 다른 한 명이 먼 곳 수정 파괴

## 플레이어가 좋아하는 것

1. **진입 장벽이 낮음**: 조작이 단순해 게임을 잘 모르는 연인도 바로 참여 가능
2. **고양이 캐릭터 & 세계관**: 모든 NPC·지명이 고양이 말장난 (Purr-fect, Meowseum 등)
3. **장비 수집 재미**: 짧은 세션 안에도 드롭이 잦아 계속 조합을 바꾸는 즐거움
4. **짧고 굵은 세션**: 세이브 자동 저장이라 10~20분 단위로 끊어 할 수 있음
5. **2인 플레이 편의**: 한 명이 먼저 구매하고 다른 한 명이 따라오는 구조 허용

## 비판점

1. 단조로운 진행 (반복적인 던전 구조)
2. P2 역할이 상대적으로 수동적 — P1이 이동을 주도
3. 난이도 기복이 불규칙 (일부 보스가 지나치게 쉬움)
4. 아케인 스톤 조합이 앞 시리즈 대비 제한적

## OnionCat 적용 포인트

### 1. P1·P2 역할 피로도 균형

Cat Quest III는 P2가 쉽게 수동적이 된다는 비판을 받는다. OnionCat은 양파(P2)가
실드·패링·스킬·식물 심기까지 담당해 **P2가 더 바쁜 구간**이 분명히 있음 → 적극적으로 유지할 것.
단, P2의 역할이 "작물 관리 + 실드" 외에도 **"전장 통제"** 에 있다는 점을 UI·연출로 명확히 보여줄 것.

### 2. 장비 비교 툴팁 UX

Cat Quest III는 장비를 주웠을 때 현재 장비와 나란히 스탯 비교를 보여준다.
OnionCat의 `ItemTooltip`에서도 **같은 슬롯 현재 장비와 신규 장비를 나란히** 보여주되,
"효과 조합으로 세트가 켜지는지"도 미리 보여주면 선택이 훨씬 직관적이다.

### 3. 세트 보너스 시각화

Cat Quest III는 세트 이름과 진행 단계를 장비 아이콘 색 + HUD 측면 표시로 알려준다.
OnionCat의 HUD 오른쪽 아래 세트 진행도가 이미 이 역할을 하고 있으나,
**보상 선택 카드에서도 "이걸 고르면 세트 X가 켜진다"** 강조가 추가되면 결정에 도움이 됨.

### 4. "부활 타이밍 미니게임" 아이디어

Cat Quest III의 부활 미니게임(제한 시간 내 버튼 누르기)을 응용해:
OnionCat에서 고양이가 HP 0이 될 때 **양파의 패링 성공**으로 1HP 부활이 가능하면
두 플레이어 모두 집중하게 만드는 "절체절명 협동 순간"이 생긴다.

### 5. 아케인 스톤 → 마법서 슬롯 교훈

스톤 3개 고정 슬롯은 "선택과 집중"을 강제해 긍정적으로 평가받음.
OnionCat의 마법서 3칸도 동일 구조 — 단, Cat Quest III의 아쉬운 점인 **조합 다양성 부족**을
보완하려면 각 마법서의 **발동 조건·시너지 스킬**이 충분히 차별화되어야 함.

### 6. 접근성 있는 텔레그래프 디자인

Cat Quest III 보스전이 좋은 평가를 받는 핵심은 "예고 뒤 피하기" 패턴이 매우 명확하기 때문.
OnionCat의 노랑/빨강 텔레그래프 시스템을 유지하되, **첫 보스(성녀 궁수)의 텔레그래프 두께·색**을
한 번 더 플레이테스트해 "한 번 보면 확실히 읽힌다"를 확인할 것.
