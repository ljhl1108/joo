# Grim Guardians: Demon Purge

리서치 날짜: 2026-09-25

## 기본 정보

- **개발사**: Inti Creates
- **출시**: 2023-02-23
- **플랫폼**: PS4/PS5, Nintendo Switch, PC (Steam)
- **장르**: 2D 횡스크롤 액션 / 협동 액션
- **인원**: 1~2인 로컬 협동

- **공식 사이트**: https://grimguardians.com/

## 핵심 컨셉

악마에게 점령당한 학교를 두 자매(구가 시노비 + 쿠로오비 슈라)가 함께 탈환하는 2D 협동 액션.
Inti Creates의 Gal*Gun 세계관 스핀오프. 1인 플레이 시에는 캐릭터를 선택해 솔로 진행 가능.

## 두 캐릭터의 역할 분담

| 구분 | 구가 시노비 (Shinobi) | 쿠로오비 슈라 (Syura) |
|------|------|------|
| 전투 스타일 | 근접 검술 + 대시 | 원거리 마법 발사체 |
| 속도 | 빠름 | 느림 |
| 강점 | 빠른 연속 공격, 기동성 | 강력한 단타, 광역 공격 |
| 특수기 | 닌자 대시, 검기 | 마법 폭발, 유도탄 |

**두 캐릭터의 공격 방식이 전혀 다르며, 특정 적은 근접에만 / 원거리에만 약점**을 가진다.
→ OnionCat의 핵심 협력 강제 메카닉과 동일한 설계 원리.

## 주요 시스템

### 협동 콤보
- 두 플레이어가 같은 적을 동시에 공격하면 **SP 게이지**가 빠르게 충전
- 풀 충전 시 **협동 필살기** 발동 가능
- 솔로 플레이 시 스위치 버튼으로 캐릭터 교체하며 협동기 조건 충족

### 공유 자원 (Shared Resource)
- HP가 **공유 풀** — 두 캐릭터가 체력 바 하나를 나눠 씀
- 한 캐릭터가 쓰러지면 다른 캐릭터가 회복 아이템으로 부활 가능
- 부활 조건: 시간 제한(5초) 내 파트너가 쓰러진 위치에 도달

### 맵 구조
- 메트로이드바니아 구조: 문 잠금 + 백트래킹
- 협동 전용 패드: 둘이 동시에 올라야 열리는 문
- 2인 전용 구역 / 1인 전용 구역 혼재

### 적 설계
- **근접 면역체**: 마법 발사체만 피해 적용
- **원거리 반사체**: 물리 공격만 피해 적용
- **보스**: 페이즈별 약점 스왑 (1페이즈 원거리 약점 → 2페이즈 근접 약점)

## OnionCat 적용 포인트

### 1. 역할 분담 메카닉 검증
Grim Guardians는 "근접 vs 원거리 역할 강제"가 실제로 재미있게 동작함을 증명한다.
OnionCat은 **한 몸 공유**라는 추가 제약이 있어 더 즉각적인 협력이 필요 → 긴장감 더 높음.

### 2. 공유 HP 바
두 캐릭터가 HP를 공유하는 방식은 OnionCat과 동일 구조.
한 쪽이 무적(고양이 대시) + 다른 쪽이 원거리 지원하는 구도가 Grim Guardians의 공유 HP와 같은 긴장감 연출.

### 3. 협동 필살기 아이디어
- Cat의 근접 + Onion의 원거리를 동시에 일정 횟수 명중 시 SP 충전
- 연출: 화면 일시정지 → 줌인 → 양쪽 동시 공격 CG 연출
- 구현: `CoopSPMeter` 컴포넌트로 두 캐릭터의 히트 이벤트를 구독, 동시 히트 조건 체크

### 4. 보스 페이즈 약점 스왑
페이즈 전환마다 근접/원거리 약점이 바뀌면 두 플레이어가 교대로 "주인공"이 되는 구조.
OnionCat 보스에 도입 시: `Boss.ChangePhase()` 에서 `DamageType.weakTo` 토글.

### 5. 협동 전용 트리거
"둘 다 올라야 열리는 버튼" 메카닉 → OnionCat에서는 한 몸이므로 '양쪽 입력 동시' 개념으로 변형:
Cat 공격 + Onion 발사 동시 입력 → 특수 문 열기 / 숨겨진 방 진입.
