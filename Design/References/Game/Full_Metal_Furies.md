## 핵심 메카닉

### 클래스 기반 역할 분담 (핵심)
4명의 플레이어는 완전히 다른 클래스를 선택:

| 클래스 | 역할 | 대표 특기 |
|--------|------|-----------|
| Warrior | 근접 딜러/브레이커 | 방어막 파괴, 폭발 연계 |
| Tech | 원거리 지원 | 로봇 소환, 전기 데미지 |
| Ranger | 원거리 딜러 | 저격, 이동 속도 우위 |
| Tank | 탱커/어그로 | 팀원 보호, 실드 배리어 |

### 적 약점 시스템 (OnionCat 핵심 참고 대상)
- **모든 적에게 특정 공격 유형 약점이 존재** — 적 머리 위 아이콘으로 상시 표시
- 약점 유형: 물리 충격, 불꽃, 전기, 방어막 파괴 등
- **약점 외 데미지는 크게 감소** → 팀원 조율 없이는 클리어 불가
- 예: 장갑 적 → Warrior의 방어막 파괴 공격이 필수, Warrior 없으면 사실상 처치 불가
- 이 설계 하나가 "역할 분담을 게임플레이로 강제"하는 핵심

### 콤보 & 시너지 시스템
- 클래스 간 연계 공격: Tech가 적 감전 → Warrior가 충격파 → 시너지 피해 폭발
- **협동 필살기**: 특정 조건 충족 시 팀 합체 공격 발동 (연출 + 대폭발)
- 기절(Stagger) → 추가 타격 → 체인 피해 구조

### RPG 성장 & 장비
- 레벨업, 장비 드롭, 강화
- 지역별 퀘스트 구조 (오버월드 선택 이동)
- 파벌 시스템: 어느 세력 편을 드느냐에 따라 적/아군 구성 달라짐

## 플레이어들이 사랑하는 것
1. **전략적 협동** — 약점 시스템이 "각자 알아서" 플레이를 원천 차단
2. **콤보의 카타르시스** — 팀 연계 성공 시 화면이 터지는 쾌감
3. **Cellar Door Games 밸런스** — Rogue Legacy 제작사다운 치밀한 조율
4. **유머러스한 세계관** — 병맛 시나리오와 깊은 전략의 공존
5. **도전적 난이도** — 뇌사 플레이 불가, 소통과 역할 이해 강요

## OnionCat 적용 포인트

### 1. 약점 아이콘 표시 시스템 (최우선 적용)
FMF에서 적 머리 위 약점 아이콘 하나가 **모든 전략적 결정을 유도**함.
→ OnionCat에서:
- 근접 전용 약점 적 = **칼 아이콘** (빨간색)
- 원거리 전용 약점 적 = **씨앗/물방울 아이콘** (파란/초록색)
- 처음 만날 때 = **"???" 표시** → 처치 후 도감에서 공개 (발견 루프 연동)
→ 아이콘은 픽셀아트 8×8 크기로 충분, 색상 대비만 선명하면 OK.

### 2. 2인 특화 역할 설계 원칙
FMF가 4클래스를 서로 보완하도록 설계한 것처럼 Cat + Crop도:
- **Cat(근접)**: 장갑·방어막이 높은 적의 약점 담당, 근접 접근 전담
- **Crop(원거리)**: 날아다니거나 원거리 파괴가 필요한 적 담당, 지원 사격
→ "Cat 없으면 해결 안 되는 적", "Crop 없으면 해결 안 되는 적" 각 2~3종씩 설계
→ 두 역할이 **모두 필수인 방**이 핵심 긴장감 제공

### 3. 협동 시너지 보상
FMF의 클래스 간 연계 콤보처럼 OnionCat도:
- Cat이 적을 스턴(근접 강타) → Crop이 그 직후 원거리 공격 명중 → **"협동 크리" 발동**
- 협동 크리: 피해 ×1.5 + 특수 파티클 이펙트 + HUD 시너지 게이지 충전
- 시너지 게이지 만땅 → 협동 필살기 사용 가능

### 4. "팀 없으면 불가" 방 설계
FMF는 뇌사 플레이 차단을 시스템으로 구현.
→ OnionCat 방 중 일부:
- 동시에 두 스위치를 밟아야 문이 열리는 퍼즐 방 (각 플레이어 전담)
- 근접 + 원거리 동시 약점 적이 같이 나오는 방
→ 너무 많으면 피로감 → 전체 방 중 20~30%에만 적용 권장

### 5. HUD — 역할 정보 명확성
FMF는 4명이 동시에 싸워도 HP바·약점·쿨다운이 명확히 보임.
→ OnionCat HUD 배치 제안:
- **P1 (Cat)**: 화면 좌하단 — HP바 + 근접 쿨다운
- **P2 (Crop)**: 화면 우하단 — HP바 + 원거리 쿨다운 + 방어막 게이지
- 약점 아이콘은 적 개체에 직접 부착 (HUD 분리 불필요)
