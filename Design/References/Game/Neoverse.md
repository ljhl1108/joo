# Neoverse

리서치 날짜: 2026-11-10

## 기본 정보

- **장르**: 액션 로그라이크 + 덱빌딩 하이브리드
- **개발사**: Team Panther (한국 인디)
- **출시**: 2020년 4월 (얼리 액세스) → 2020년 11월 (정식)
- **한국어 정식 지원**
- **Steam**: https://store.steampowered.com/app/1140790/NEOVERSE/
- **공식 사이트**: https://www.neoverse.co.kr/

## 핵심 메카닉

### 하이브리드 전투 — 덱빌딩 + 실시간 액션

턴제도 실시간도 아닌 독자적 하이브리드:
- 카드를 "액션 큐"에 넣어 순서 결정
- **실시간으로 적의 예고 공격을 보면서 카드 순서를 재배치**
- 카드 발동은 애니메이션과 함께 순차 실행
- 각 카드에 쿨다운·에너지 비용 없음 — 대신 "턴당 사용 가능 슬롯" 제한

### 영웅 & 직업 시스템

- 3명의 영웅(전사·마법사·아처) 각자 고유 카드 풀
- 영웅마다 고유 패시브 "특성"이 카드 조합 방향을 결정
- 런 중 카드 획득·강화·제거 가능 (Slay the Spire 방식)

### 덱 구성 & 시너지

- 카드 태그: 공격/방어/강화/디버프 4계열
- **같은 태그 카드 3장 이상이면 콤보 보너스** 발동
- 적 체력 바 위에 "다음 행동 예고"가 항상 표시 — 모든 위험은 사전에 알 수 있음
- 보스마다 고유 "특성 카드" 획득 (스토리 연동 강화)

### 성장 & 보상

- 방 클리어 → 카드 3장 중 1장 선택 (또는 패스 후 골드)
- 상점: 카드 구매·강화·제거, 유물 구매
- **유물(Relic)**: 패시브 아이템, 덱 방향에 맞춰 시너지
- 엘리트 방·보물방·이벤트 방이 무작위로 등장

### 적 AI 설계 — 완전한 예고제

OnionCat에서 중요: Neoverse의 모든 적 행동이 미리 공개됨.
- 적 머리 위에 "다음 2행동" 아이콘 표시
- 패턴이 복잡해도 플레이어가 항상 대응 가능
- "예고를 읽고 최적 카드 배치"가 핵심 스킬 표현

## 협동 요소

싱글플레이 전용. 그러나 디자인 측면에서 참고할 점:
- **완전 정보 공개** — 불공정한 기습 없음
- **예고와 대응의 반복 루프**가 게임의 모든 긴장감을 만듦
- 한국어 UX가 세밀하게 최적화됨 (텍스트 배치, 아이콘 직관성)

## 한국 인디 개발 관점

Team Panther의 개발 여정:
- 2인 소규모 팀 → 얼리 액세스로 출시 후 1년에 걸쳐 콘텐츠 추가
- 메타크리틱 72점 — 완성도는 평범하지만 아이디어 독창성 호평
- 한국어 로컬라이제이션을 처음부터 완벽히 지원
- **Steam 넥스트 페스트 참가 → 위시리스트 대폭 증가** 경험

플레이어들이 가장 좋아하는 점:
1. 카드+액션 하이브리드의 신선함
2. 완전 예고 시스템으로 "억울한 죽음"이 없음
3. 덱 방향에 따른 다양한 빌드

## OnionCat 적용 포인트

### 1. 완전 예고 → OnionCat 디자인 기둥과 일치

Neoverse의 핵심 철학 "모든 위험은 사전에 알 수 있다"가 OnionCat의 디자인 기둥(노란=막기 가능, 빨간=피하기)과 완전히 동일.

**적용**: 예고 연출 품질 올리기 — 현재 경고 색(노란/빨간) 외에 **예고 지속 시간을 적 위험도별로 차등** 적용. 강한 공격일수록 더 오래 보여줘서 2인 플레이어가 대응 협의 시간을 확보.

### 2. 카드 선택 UI ↔ OnionCat 업그레이드 선택

Neoverse의 카드 선택 화면(3장 중 1장, 패스 가능)이 OnionCat의 `UpgradeSelectUI`와 구조적으로 동일.

**적용**: 고양이·작물이 동시에 각자 선택하는 현행 방식의 UX 개선. Neoverse처럼 선택지에 "이 카드를 고르면 어떤 플레이가 가능해지는지" 한 줄 설명 추가. 특히 세트 미리보기 — "지금 고르면 세트 2착 완성" 표시.

### 3. 덱 방향 태그 → 장비 계열 연계

Neoverse에서 카드 태그(공격/방어/강화/디버프)가 콤보 보너스를 형성하듯, OnionCat 장비도 계열(태양/바람 등)로 묶여 세트 보너스.

**적용**: 업그레이드 선택 시 현재 장비 계열 현황을 미니 아이콘으로 표시. "태양 세트 2착 중 — 1개 더 고르면 보너스" 힌트 UX.

### 4. 한국 인디 얼리 액세스 전략

Team Panther처럼 2인 소규모 팀이 얼리 액세스로 출시 → 피드백 수렴 → 정식 출시. OnionCat도 같은 경로가 현실적.

**적용**: 얼리 액세스 출시 전 "1스테이지 + 보스 + 기본 장비 15종"으로 최소 완성 체험 가능한 버티컬 슬라이스 구성.
