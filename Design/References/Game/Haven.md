# Haven

리서치 날짜: 2026-07-21

## 기본 정보

- **개발사**: The Game Bakers (프랑스)
- **출시**: 2020년 12월 (Steam, Switch, PS4/5, Xbox)
- **장르**: 2인 협동 액션 RPG / 어드벤처
- **Steam**: https://store.steampowered.com/app/1240380/Haven/
- **공식 사이트**: https://www.thegamebakers.com/haven/

## 핵심 메카닉

### 두 캐릭터가 하나처럼 움직이는 구조
- **Yu & Kay**: 두 플레이어가 항상 같은 화면에, 같은 공간에 존재
- **이동 연동**: 혼자 플레이 시 두 캐릭터를 동시에 조작 (왼쪽 스틱 = Yu, 오른쪽 스틱 = Kay 동시 제어)
- **활공 이동**: 부유한 행성 표면을 활공(glide)으로 탐험 — 일반 이동보다 빠르고 우아
- **장애물 청소**: 필드 곳곳의 "녹"을 제거하며 경로 개척 → 청소 자체가 진행 메커니즘

### 전투 시스템
- **실시간 협동 전투**: 두 캐릭터 각각 독립 행동 가능
- **방어(Shield)**: 한 캐릭터가 방패를 들면 적 공격 흡수 → 상대방 공격 기회 창출
- **동시 공격 (Break)**: 두 플레이어가 같은 적에게 동시에 공격하면 즉시 "Break" 발생 → 큰 데미지
- **공격 속성**: Rust(기본), Spark, Blaze, Surge — 각 적마다 약점 속성 존재
- **상태 이상**: Boost(강화), Rust(약화) 등 상태 효과 연계

### 관계 기반 진행
- **Food System**: 함께 요리하고 밥을 먹으면 캐릭터 스탯 강화 (체력, 방어력 등)
- **대화/선택지**: 두 캐릭터가 대화를 나누며 관계가 발전 → 스탯/능력에 영향
- **Nest**: 두 사람의 "집"(우주선) → 여기서 요리/휴식/대화하며 관계 관리
- **코-op 특별 이벤트**: 2인 플레이 시 한 명이 대화 선택지를 고르면 상대방도 반응

### 로컬/온라인 코-op
- **로컬 코-op**: 한 화면, 두 컨트롤러 → OnionCat과 동일한 세팅
- **온라인 코-op**: 별도 화면으로도 플레이 가능
- **싱글 플레이**: 두 캐릭터를 혼자 조작 (오른손·왼손 분담)

## 플레이어가 좋아하는 것

- 두 연인이 하나로 움직이는 감각 — "함께함"의 물리적 표현
- Break 시스템의 자연스러운 협동 유도 (강요가 아닌 포상)
- 전투보다 관계에 집중하는 서사 — 戰鬪게임에서 감정적 깊이
- 요리/대화/휴식이 스탯에 영향 → 일상 행위가 게임 메커니즘
- 픽셀아트 + 고퀄리티 음악으로 감성적 분위기

## OnionCat 적용 포인트

### 1. 동시 공격 Break → 협력 필수 설계
Haven의 핵심 아이디어: **두 플레이어가 동시에 공격할 때 특별 효과** 발생.
- OnionCat에 적용: Cat의 근접 슬래시 + Crop의 원거리 투사체가 같은 프레임(또는 짧은 윈도우 내)에 적에 맞을 때 "협공 보너스" 발동
- 구현: `OnHit` 이벤트 시 `SynergyChecker`가 최근 0.3초 내 다른 플레이어 히트 여부 확인 → 협공 파티클 + 추가 데미지

### 2. 방어/공격 역할 교환 전투
Haven에서 한 명이 방어하면 나머지가 공격:
- Crop의 방향 방패(DirectionalShield)가 적 공격을 막는 동안 Cat이 안전하게 근접 공격 가능
- 방패 패링 성공 시 잠깐의 "스턴 윈도우" → Cat 공격 기회 → Haven Break과 유사한 구조

### 3. "함께함"의 시각적 표현
두 캐릭터가 항상 같은 공간에 있어야 한다는 것을 게임플레이 언어로 표현:
- OnionCat은 문자 그대로 하나의 몸 → 이 제약이 Haven의 "항상 같이"를 더 극단적으로 구현한 버전
- Haven처럼 "같은 화면" 제약이 아니라 "물리적으로 같은 위치" 제약 → 근접/원거리 역할이 충돌하는 재미

### 4. 소소한 감정 연출 참고
Haven의 Nest(집)에서 밥 먹고 대화하는 시스템:
- OnionCat의 방 클리어 후 "쉼터 방" 개념에 응용 가능
- 쉼터 방에서 두 플레이어가 짧은 인터랙션 (Cat이 Crop에게 물 주기 등) → 체력 회복 + 감정 연출
