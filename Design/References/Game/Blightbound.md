## 핵심 메카닉

### 1. 고정 역할 삼각형 (Role Lock Triangle)
- 파티는 반드시 **전사(Warrior) + 마법사(Mage) + 도적(Rogue)** 3역할 중 각 1명씩 구성
- 역할 교체 불가 — 런 내내 고정
- 각 역할이 서로 다른 **피해 유형**을 담당:
  - 전사: 근거리 물리 피해 (방어 + 탱킹)
  - 마법사: 마법 광역 피해 (폭발/군중 제어)
  - 도적: 민첩 단일 피해 (빠른 연사, 치명타)

### 2. 역할 카운터 적 (Role Counter Enemies)
- 특정 적은 **특정 역할 공격에만 취약** (또는 면역)
  - 갑옷 적 → 전사 타격에 스턴, 도적 공격은 튕김
  - 마법 방어막 적 → 마법사 마법에만 방어막 파괴
  - 빠른 그림자 적 → 도적 연속 공격으로 처치 효율 극대화
- 결과: 팀원이 죽으면 특정 적을 **처치 불가** → 팀 전멸 가속

### 3. 공유 목숨 / 부활 시스템
- 팀 공유 목숨 풀 (예: 총 9목숨 → 1명 사망 시 3목숨 차감)
- 목숨이 남아 있으면 쓰러진 플레이어는 일정 시간 내 소생 가능
- 목숨 소진 시 팀 전멸 = 런 종료

### 4. 룬 제작 업그레이드 (Rune Crafting)
- 적 처치 시 **룬 조각** 드롭
- 룬을 조합해 역할별 특수 스킬 언락
- 런 종료 후에도 일부 룬 효과 메타 진행으로 영구 보유

### 5. 안개 탐험 (Fog of Exploration)
- 던전 방이 안개로 덮여 있음 → 이동하면서 탐험 공개
- 각 플레이어의 시야 원이 독립적 → 떨어질수록 팀원 시야 공유 중요

---

## 플레이어가 좋아하는 요소

1. **역할의 명확한 차별성** — 같은 키보드 키를 눌러도 역할마다 완전히 다른 게임을 하는 느낌
2. **적 카운터 설계** — "이 적은 내 차례야/네 차례야" 자연스럽게 소통 유도
3. **픽셀아트 + 다크 판타지 비주얼** — 손으로 그린 느낌의 세밀한 애니메이션
4. **부활 긴장감** — "한 명이 죽으면 다 같이 위험해"라는 집단 책임감

## OnionCat 적용 포인트

### A. 역할 고정 = 협동 강제의 가장 단순하고 강력한 설계
- Blightbound는 "역할을 아예 교체 못하게" 함으로써 협동 필요성을 시스템 레벨에서 강제
- OnionCat는 P1=근접, P2=원거리로 이미 이 구조 완성 → **절대 무너지면 안 되는 핵심 기둥**
- 추가 아이디어: 일부 업그레이드가 역할을 흐리려 하면 저항할 설계 철학 필요

### B. 적 카운터 시스템 구현 참고
- `EnemyWeaknessType` enum: `MeleeOnly`, `RangedOnly`, `Both`
- 해당 타입 외 공격 시 `DamageMultiplier = 0` 또는 `0.1f` 적용
- 스크린에 "이 적은 근접으로!" / "이 적은 원거리로!" 아이콘 표시 → 자연 소통 유도

### C. 공유 HP 공유 목숨 디자인 직접 참고
- OnionCat는 "하나의 몸 공유" → 자연스럽게 HP 1개 풀
- Blightbound의 "목숨 풀 차감" 방식 → **런 내 총 부활 횟수 제한**으로 응용 가능
- 예: 총 3번 부활 가능 → 부활 시 HP 50%로 재시작

### D. 역할별 업그레이드 트리 설계
- Blightbound: 전사/마법사/도적 각자 완전히 다른 룬 트리
- OnionCat 응용: P1 전용 업그레이드(근접 강화)와 P2 전용 업그레이드(원거리 강화)를 완전 분리
- 구현: `UpgradeItem.targetPlayer: PlayerRole.P1 | P2 | Both`

### E. 안개 탐험 → "정보 안개 방" 레벨 디자인
- Blightbound의 방 단위 안개 공개 → OnionCat의 특수 방 아이디어로 응용
- P1 시야(근거리 원형)와 P2 시야(마우스 커서 방향 원뿔)가 다르게 설계하면 정보 공유 소통 자연 발생
