## 핵심 메카닉

### 전투 시스템
- **무기 다양성**: 검, 활, 낫, 권투 등 근/원거리 혼재. 각 무기마다 고유 공격 패턴.
- **스킬 트리 (Powers)**: 런 중 획득하는 패시브 스킬. 같은 무기라도 스킬 조합으로 완전히 다른 빌드.
- **원소 시스템**: 화염/냉기/번개 속성 부여 아이템. 적에게 원소 상태 이상 축적.
- **무기 스윙 판정**: 넉넉한 히트박스 + 범위 공격 강조 → 적이 많아도 클리어감 있음

### 협동 메카닉
- **4인 동시 협동**: 같은 화면 공유 (로컬) 또는 각자 화면 (온라인)
- **부활 시스템**: 쓰러진 플레이어를 동료가 달려가 부활. 부활하는 동안 무방비 상태.
- **공유 자원은 없음**: 각자 독립 체력/자원. 협동은 전략적 역할 분담으로.
- **역할 분담 자연 발생**: 한 명이 근접 탱킹, 다른 한 명이 원거리 딜링 — 강제 아님, 자연스럽게 형성.

### 진행 구조
- **바이옴 구조**: 3개 구역 (숲 → 화산 → 고대 신전) + 각 구역 끝 보스
- **방 단위 진행**: Enter the Gungeon처럼 방 입장 → 클리어 → 출구 선택
- **업그레이드 선택**: 방 클리어 후 3개 중 1개 스킬 선택 (런 중 누적)
- **메타 진행**: 영구 해금 무기, 스킬, 보스 변형 등

## 플레이어가 사랑하는 것

1. **스킬 시너지**: 스킬 조합이 기대 이상의 상호작용을 일으킬 때의 쾌감 ("broken build" 발견)
2. **협동 자유도**: "도와야 한다"는 압박 없이 자연스럽게 협력하게 되는 설계
3. **픽셀아트 + 이펙트**: 타격감 있는 SFX + 파티클이 조화로운 시각적 만족감
4. **로컬 co-op 최적화**: 소파 co-op 게임으로 극찬 — 초보자도 바로 진입 가능

## OnionCat 적용 포인트

### 1. 역할 분담 "자연 발생" 설계 원칙
Ember Knights는 역할을 강제하지 않는데도 자연스럽게 분담이 생김. OnionCat은 **구조적으로** 고양이=근접, 양파=원거리를 강제하지만, 그 안에서:
- 특정 방에 "근접 면역 적"이 있으면 고양이가 양파를 보호하며 이동
- 특정 방에 "원거리 면역 적"이 있으면 양파가 고양이를 앞세움
→ 역할 분담이 맵/적 배치로 자연스럽게 드러나야 함

### 2. 스킬 획득 타이밍 (방 클리어 후)
Ember Knights 방식: 방 클리어 → 화면 전환 → 3선택지. OnionCat 적용:
- 방 클리어 → 작은 UI 팝업으로 선택지 등장 (씬 전환 없이)
- 선택지가 고양이용/양파용/공용으로 구분됨
- 협동 결정: 둘 다 동의해야 선택 (혹은 한 명이 선택권 가짐, 교대)

### 3. 원소/속성 약점 시스템
Ember Knights의 원소 상태이상을 참고해 OnionCat 적 약점 설계 구체화:
- 근접 약점 적: 갑옷으로 원거리 무효화 (발사체가 튕겨나옴)
- 원거리 약점 적: 근접 반격 가시(스파이크) → 근접 공격 위험
- 속성 혼합: 양파 발사체가 고양이 슬래시에 "화염 코팅" 후 불 데미지 추가

### 4. 부활 상황의 긴장감 활용
OnionCat은 한 몸이라 "부활"이 없음. 대신:
- 고양이와 양파 각각 독립 체력 → 양파 체력 소진 시 "실명 상태" (원거리 공격 불가)
- 고양이 체력 소진 시 "마비 상태" (이동 속도 반감, 슬래시 불가)
- 두 체력 모두 소진 → 런 종료 (퍼머데스)
→ 한 쪽이 위기일 때 다른 쪽이 대신 버티는 협력 상황 생성
