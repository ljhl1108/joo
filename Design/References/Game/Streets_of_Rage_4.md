# Streets of Rage 4

리서치 날짜: 2026-08-27

## 기본 정보

- **개발사**: Dotemu, Lizardcube, Guard Crush Games  
- **출시일**: 2020년 4월  
- **장르**: 협동 Beat-'em-up 액션  
- **공식 사이트**: https://www.streetsofrageofficial.com/  
- **Steam**: https://store.steampowered.com/app/985890/Streets_of_Rage_4/  
- **메타크리틱**: 82/100

## 한 줄 요약

레트로 IP를 현대적으로 부활시킨 협동 beat-em-up. 각 캐릭터가 독자적인 전투 철학을 가지며, 협동 시 콤보 시너지가 두드러짐.

## 핵심 메커니즘

### 캐릭터 다양성 (비대칭 역할)
각 플레이어블 캐릭터가 완전히 다른 전투 스타일:
- **Axel**: 강력한 파워형 근접 전사, 짧은 도달 거리
- **Blaze**: 균형형, 잡기와 스트라이크 병행
- **Cherry**: 고속 경량형, 기타 공격으로 빠른 타격
- **Floyd**: 느리지만 압도적 도달 거리, 잡기 특화

→ OnionCat의 Cat(근접)/Onion(원거리) 이분법과 직접 비교 가능

### 특수 공격 시스템
- **별 아이템 공격**: 필살기, HP 소모 없이 사용
- **블리츠 어택**: 달리다가 강공격, 돌진 타격
- **백어택**: 뒤를 향한 반격 (Cat의 180° 슬래시와 유사)

### 체력 회복 메커니즘 (Star Move)
- 특수 공격 사용 시 HP 일부가 주황색 게이지로 전환
- 주황색 HP는 이후 일반 공격으로 적을 때리면 회복
- 위험을 감수한 공격이 보상으로 돌아오는 구조 → 공격적 플레이 장려

### 협동 시너지
- 한 플레이어가 적을 잡으면 다른 플레이어가 확정 공격 가능
- 스타 아이템: 아군 옆에서 사용하면 범위 확대
- 아군 피격 없음 → 위치 겹침 전략 가능

### 콤보 & 타격감
- 공중 띄우기 후 연속 타격
- 무기 줍기(파이프, 나이프)로 임시 강화
- 피격 시 무기 드롭 → 적도 무기 줍기 가능

## 플레이어가 열광하는 이유

1. **타격감** — 픽셀아트 + 사운드 디자인이 완벽히 조화, 때릴 때 만족감 극대화
2. **캐릭터 개성** — 12명 이상의 플레이어블 캐릭터, 각자 고유한 느낌
3. **레트로 + 현대** — 올드 팬과 신규 유저 모두 만족하는 균형
4. **DLC 확장** — "Mr. X Nightmare" DLC로 생존 모드, 새 캐릭터 추가
5. **반응형 적** — 각 적이 고유한 패턴과 약점을 가져 학습 보람

## OnionCat 적용 포인트

### 1. 타격감 레시피 (픽셀아트 기준)
SoR4의 타격감 공식을 OnionCat에 직접 적용:
- 피격 시 적이 약간 뒤로 밀림 (1~2프레임 피격 모션)
- 히트스톱 2~4프레임 (게임 일시 멈춤)
- 히트 사운드 레이어 2개 (임팩트 + 육체 타격음)
- 적 피격 플래시 (흰색 스프라이트 1프레임)

### 2. 블리츠 어택 → Cat 대시 강화
SoR4의 블리츠 어택(달리다가 강공격)처럼 Cat 대시 중 슬래시 입력 시 "돌진 슬래시"로 강화:
- 대시 방향으로 히트박스 연장
- 기본 슬래시보다 30% 데미지 증가
- 무적 프레임 유지 상태로 적 관통
- 구현 힌트: `CatAttack.cs`에서 `isDashing` bool 체크 후 `SlashVariant` enum 분기

### 3. "잡기-후속타" 협력 패턴
Cat이 적을 잡기(근접 그래플) 상태로 붙들면 → Onion이 조준해서 확정 원거리 공격:
- 잡힌 적은 일정 시간 움직임 불가
- Onion 공격이 크리티컬 판정
- 적 약점 부위(등) 노출 → 추가 데미지
- 두 플레이어 협력에 대한 직접적 보상 구조

### 4. 주황 HP 시스템 응용
SoR4의 "주황 HP" 메커니즘:
- Cat 무적 대시 사용 시 HP의 10%가 임시 상태로 전환
- 이후 슬래시 공격 성공 시 임시 HP 회복
- 소극적 플레이(대시만 계속 사용) 방지
- 구현 힌트: `PlayerHealth`에 `temporaryHP float` 필드, 대시 시 전환

### 5. 비대칭 캐릭터 디자인 원칙
SoR4가 보여주는 비대칭 협동의 핵심:
- 두 캐릭터가 서로 다른 방식으로 문제를 해결
- 어느 한 쪽이 막히면 다른 쪽이 자연스럽게 솔루션을 제공
- Cat(근접/기동성) + Onion(원거리/정밀성)의 조합이 이 철학과 완벽히 일치
