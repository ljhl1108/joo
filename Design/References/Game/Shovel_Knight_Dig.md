## 핵심 메커니즘

### 게임 구조
- **수직 하강 플랫포머**: 위에서 아래로 땅을 파며 내려가는 고유 방향성
- **로그라이트 구조**: 죽으면 처음부터, 런마다 다른 아이템 구성
- **랜덤 레벨 생성**: 청크(Chunk) 기반 절차적 생성 — 사전 설계된 방 조각들을 조합
- **4개 월드**: 각 월드마다 테마(흙/용암/기계/독)와 보스 보유
- **2개 플레이어블 캐릭터**: Shovel Knight(기본), Plague Knight(DLC)

### 전투 & 이동
- **삽 공격 (Shovel Drop)**: 점프 후 아래 방향 공격 — Shovel Knight 시리즈 고유 액션
- **차지 공격**: 버튼 홀드 후 강화 공격
- **무기 배리언트**: 런 중 발견한 배리언트로 기본 무기 교체 (예: 점프력 높은 삽, 폭발 효과 삽)
- **릴릭 (Relic)**: 패시브 아이템, 런마다 다른 조합으로 빌드 다양성 창출

### 아이템 & 업그레이드 시스템
- **기어 (Gear)**: 헬멧/갑옷/신발 3슬롯, 스탯 수정
- **릴릭**: 런 중 획득, 서로 시너지 발동
  - 예: "적을 삽 드롭으로 처치 시 체력 회복" + "삽 드롭 쿨타임 제거" = 강력 콤보
- **상점**: 코인으로 구매, 런 내 경제 시스템
- **비밀 영역**: 레벨 내 숨겨진 방, 보너스 아이템

### 절차적 생성의 철학
- **청크(Chunk) 시스템**: 6x6 타일 정사각형 방 조각을 규칙에 따라 배치
  - "아래에 땅이 있어야 함", "위에 입구가 있어야 함" 같은 제약 조건
  - 각 청크는 수작업으로 디자인 → 랜덤 배치로 신선함 유지
- **Nitrome의 노하우**: 플랫포머 특화 미니게임 수십 개 개발 경험

### 폴리시 & 게임 필 (Game Feel)
- **픽셀아트 품질**: 캐릭터마다 12~16 프레임 애니메이션, 섬세한 표정/이펙트
- **사운드 디자인**: 삽질할 때 흙/돌/금속 재질별 다른 소리
- **히트스톱**: 피격/공격 시 수 프레임 프리즈
- **먼지/파티클**: 착지, 벽 충돌, 아이템 획득 시 파티클 폭발

## 플레이어들이 사랑하는 것

1. **완벽한 게임 필** — Yacht Club Games의 높은 폴리시 기준, 조작 응답이 즉각적
2. **릴릭 시너지의 재미** — 런마다 다른 빌드가 완성되는 발견의 쾌감
3. **청크 생성의 공정함** — 절차적이지만 "불가능한 구간"이 없음
4. **쇼트 런** — 30~60분 클리어, 짧고 밀도 있는 로그라이트
5. **Shovel Knight 원작 팬서비스** — 보스와 배경이 원작과 연결

## OnionCat 적용 포인트

### 1. 청크 기반 방 생성 시스템
Shovel Knight: Dig의 청크 접근법은 OnionCat의 방 생성에 직접 적용 가능:
- 방을 "입구/출구 위치"로 분류하고, 규칙에 맞는 방만 이어 붙임
- `RoomChunk` ScriptableObject에 입구 방향(상/하/좌/우)을 비트마스크로 저장
- **핵심**: 수작업 방 + 랜덤 배치 = 신선하지만 공정한 레벨

### 2. 게임 필 체크리스트
Dig에서 배운 "폴리시 기준"을 OnionCat에 적용:
- [ ] 모든 공격에 히트스톱 (2~4프레임 타임스케일 0.1)
- [ ] 재질별 다른 충돌 사운드 (바닥 타일 종류로 분기)
- [ ] 착지 먼지 파티클
- [ ] 아이템 획득 시 팝업 + 사운드 + 일시 정지

### 3. 아이템 시너지 설계 방법
릴릭 시너지처럼 OnionCat 업그레이드도 "2개 조합 시 특수 효과" 설계 가능:
```
("대시 거리 증가" + "대시 중 무적") → "폭발 대시": 대시 종료 지점에 폭발
("실드 강화" + "패리 판정 확대") → "완벽한 방패": 패리 성공 시 자동 반격
```
→ `UpgradeSynergyTable` ScriptableObject로 2개 업그레이드 조합 → 시너지 효과 정의

### 4. 픽셀아트 색상 팔레트 일관성
Dig처럼 월드별 색상 팔레트를 고정하면 시각적 통일감 유지:
- 지상 1층: 초록/갈색 계열 (흙/풀)
- 지하 2층: 회색/파란 계열 (바위/물)
- 지하 3층: 빨강/주황 계열 (용암)
- 각 층마다 3~4색으로 제한 → URP Pixel Perfect Camera 사용

### 5. 비밀 영역 / 숨겨진 방
Dig의 숨겨진 방처럼, OnionCat의 방에도 약한 벽(부수기 가능)이나 숨겨진 입구 배치:
- 타일 레이어에 "부수기 가능 벽" 레이어 별도 설정
- Cat의 슬래시로만 부술 수 있는 벽 → 협력의 또 다른 요소
