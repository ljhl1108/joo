## 핵심 메카닉

### 전투 시스템
- **패리(Timed Parry)**: 적 공격 직전 방패/갈고리로 막으면 적 스턴 + 순간 무적. 타이밍 기반 고위험-고보상 시스템
- **구르기(Dodge Roll)**: i-frame(무적 프레임) 내장. 적 공격 통과 가능
- **무기 다양성**: 검, 도끼, 활, 마법, 수류탄, 방패 등 100종 이상. 각 무기 고유한 공격 패턴과 콤보
- **킬-타이머**: 특정 구역에서 적을 연속으로 죽이면 다음 구역 문이 열리는 타임 챌린지 존재
- **히트스톱**: 타격마다 짧은 프리즈 프레임 → 타격감 극대화

### 이동 시스템
- **벽 점프**: 어떤 벽이든 타고 올라갈 수 있음
- **갈고리(Hookshot)**: 일부 조각상에 거는 이동 기술
- **낙하 공격**: 공중에서 아래로 강습
- 빠르고 유연한 이동 → 전투 리듬에 직접 기여

### 절차적 생성
- **방 청크(Chunk) 방식**: 미리 제작된 방 조각을 랜덤 배치 → 매 런마다 다른 레이아웃
- 순수 무작위가 아닌 큐레이션된 청크 → 공정한 난이도 유지
- 비밀 방, 루트 분기점이 항상 포함

### 메타 진행 (Meta-Progression)
- **세포(Cells)**: 적 처치 시 드롭, 런 중 소비 or 런 종료 후 영구 해금 재화
- **블루프린트**: 던전에서 발견한 아이템 설계도 → 이후 런에서 해당 아이템 출현 가능
- **콜렉터(The Collector)**: 마을(거점)에서 세포로 영구 업그레이드 해금
- **돌연변이(Mutations)**: 런 중 레벨업 시 세 가지 계열 중 선택
  - **잔혹(Brutality, 빨강)**: 근접 공격 위주
  - **전술(Tactics, 보라)**: 함정·스킬 위주
  - **생존(Survival, 초록)**: 방어·회복 위주

### 적 설계
- 각 적마다 명확한 공격 예고 모션 존재 → 학습 가능
- 일부 적은 방패로 정면을 막음 → 측면/등 공격 강제
- 보스는 페이즈 전환 구조

## 플레이어가 사랑하는 것

1. **타격감**: 업계 최고 수준의 반응성. 모든 타격에 히트스톱·파티클·사운드 삼위일체
2. **다양한 빌드 조합**: 300회 이상 플레이해도 새로운 무기 시너지 발견
3. **공정한 사망**: "내 실력 부족 때문에 죽었다"는 느낌 유지 → 욕구 불만보다 학습 욕구 유발
4. **진행감**: 런마다 점점 더 많은 아이템이 해금되어 세계가 넓어지는 느낌
5. **장애물 극복 리듬**: 처음엔 막혔던 구역/보스를 나중엔 가볍게 클리어 → 성장감

## OnionCat 적용 포인트

| Dead Cells 요소 | OnionCat 적용 |
|----------------|---------------|
| **패리 → 특수 보상** | Onion(P2) 방패 패리 성공 시 → 적 스턴 + Cat(P1) 공격 데미지 증폭 1.5× 연동. 협력 시너지 연출 |
| **무기 시너지 조합** | 근접 전용 약점 적 + 원거리 전용 약점 적이 동시 등장할 때, Dead Cells처럼 "상황이 전략 강제" |
| **블루프린트 해금 구조** | 런 중 발견한 능력을 다음 런에서 출현 가능하게 → 세포 대신 "씨앗(Seed)" 통화 |
| **히트스톱** | 근접 타격 시 0.05~0.08초 프리즈 → 중요 타격감 요소, 반드시 구현 |
| **청크 방식 방 생성** | Unity에서 Room Prefab 리스트를 무작위 조합 → Dead Cells 방식과 동일 |
| **돌연변이 3계열** | Cat(근접)/Onion(원거리)/공유(협력) 세 트리로 업그레이드 설계 가능 |
