## 핵심 메카닉

### 전투 시스템 — "즉각 반응"이 최우선
- **무기 Alteration**: 무기 2개를 장비하고 두 번째 무기가 첫 번째에 특성 부여 (ex. 도끼 + 부메랑 → 도끼에 반사 속성 추가). 시너지 중심 빌드.
- **Reaction 보너스**: 적 공격 직후 일정 프레임 안에 반격 시 데미지 1.5× 상승. 위험을 감수할 수록 더 큰 보상.
- **회피 i-프레임**: 완전 프레임 퍼펙트는 아니지만 무적 판정 있음 — 공격 직전 회피 시 Reaction 보너스에 준하는 보상.
- **입력 지연 제로 정책**: Dead Cells에서 이어받은 철학. 가속/관성 없이 즉각 방향 전환.

### 무기 시스템 (정식 출시 기준)
- **근접 6종 카테고리**: 단검(속도), 검(밸런스), 도끼(범위), 대검(파워), 낫(사거리), 창(돌진)
- **원거리 4종 카테고리**: 활(정밀), 완드(속사), 총(파워), 부메랑(반사)
- **Alteration 매트릭스**: 근접×원거리 조합 24가지 — 실질 빌드 다양성 수백 가지
- **정식 출시 추가**: "Surge" 메카닉 — 아이템으로 Alt 공격에 에너지 충전 → 챠지 방출

### 협동 시스템
- **최대 3인** 온라인+로컬 혼합 지원 (정식 출시에 넷코드 대폭 개선)
- **공유 체력 바**: 팀 풀(pool). 한 명이 죽으면 부활 가능 — 시간 제한 없음 단 무방비 상태
- **개인 화면 없음**: 분리 이동 시 카메라가 최소 박스 확장으로 모두 포함
- **아이템 귀속**: 런 중 무기/아이템은 먼저 집은 사람 소유. 드롭 시 다른 플레이어가 획득 가능.

### 진행 구조
- **The Vortex**: 부유 군도를 순서대로 탈출하는 구조
- **섬 기반 맵**: 방 단위가 아닌 연속 지형 — 한 섬을 완전 클리어해야 다음 섬 포털 개방
- **업그레이드 시스템**: 런 중 무기 교체 + "Alteration 잠금" (현재 조합 유지 옵션)
- **메타 진행**: 영구 해금 무기 슬롯, 시작 세팅, 보조 스탯 뼈대

## 플레이어가 사랑하는 것

1. **Combat Feel**: "그 어떤 탑다운보다 손에 붙는 조작감" — Steam 리뷰 최다 언급
2. **Alteration 빌드 만들기**: 조합 실험의 즐거움. 근접+원거리 시너지 발견 순간의 만족감
3. **Reaction 도박**: "겁나지만 일부러 맞으러 들어가게 됨" — 위험감수 플레이 장려
4. **협동 자유도**: 각자 스타일로 싸워도 되고 조율해도 됨 — 강요 없는 협동
5. **정식 출시 개선**: EA 대비 밸런스, 버그, 카메라 처리 모두 개선됨

## 설계 철학 분석

### "즉각성 퍼스트" 전투 설계
```
느낌 계층:
  1. 입력 지연 <1프레임 (물리 / 애니메이션 즉각)
  2. 타격 히트스톱 8-12프레임 (적만 멈춤, 플레이어 계속)
  3. 화면 소량 흔들림 (카메라 shake < 0.1초)
  4. 사운드 펀치 + 파티클 분출 동시

→ Dead Cells 팀의 공식 원칙: "Game feel은 작업 순서가 있다.
   먼저 입력 즉각성, 그 다음 애니메이션, 마지막이 파티클"
```

### Alteration의 게임 디자인 패턴
- **비대칭 강화**: A 무기가 B 무기를 버프 → 두 무기를 교차 사용하게 만드는 동기 부여
- **시너지 발견**: 플레이어가 "이 조합 최강이다" 를 발견하는 순간 → 소유감 발생
- **빌드 정체성**: 아이템이 아닌 "무기 조합"이 런의 성격을 결정 → 단순하지만 강력한 빌드 시스템

## OnionCat 적용 포인트

### 1. Alteration → 고양이-양파 시너지 시스템
Windblown Alteration의 핵심인 "A가 B를 강화" 패턴을 OnionCat 협동에 직접 적용:
- **시나리오 A**: 고양이 할퀴기(근접) → 양파 씨앗(원거리) 에 화염 속성 부여 (양파가 불 업그레이드 보유 시)
- **시나리오 B**: 양파 방패 패리 성공 → 다음 3초간 고양이 슬래시 범위 1.5× 확장
- **시나리오 C**: 고양이 킥으로 날려진 적 → 양파 씨앗이 에어본 보너스 데미지 적용
- **구현 힌트**: `CombatEvent.OnParrySuccess`, `CombatEvent.OnKick` 이벤트를 리스닝하여 버프 타이머 적용

### 2. Reaction 보너스 → 패리-슬래시 콤보 강화
양파 패리 직후 고양이 슬래시 윈도우 (1-2초) 내 공격 시 보너스:
- 적용하면 "위험 감수 → 더 큰 보상" 루프 → 협동 긴장감 증가
- 타이밍이 맞으면 협동 피니셔 연출 가능 (히트스톱 + 화면 효과)

### 3. 입력 즉각성 기준점
Windblown의 "느낌 계층" 접근법을 OnionCat에 그대로 적용:
- 고양이 이동/슬래시: 입력 다음 프레임 즉각 반응 (이징/관성 없이)
- 양파 마우스 에임: 크로스헤어와 실제 씨앗 발사 방향 일치 (지연 0)
- 히트스톱: 적이 피격 시 6-10프레임 멈춤 (플레이어 계속 이동 가능)

### 4. 카메라 (단일 바디 이점)
Windblown은 3인 분리 처리로 복잡한 카메라를 요구하지만, OnionCat은 **단일 바디**라 처리 단순:
- 고양이 위치 중심으로 카메라 → 방 경계 클램프
- 양파 마우스 커서는 화면 내 자유 이동 → 카메라와 무관
- 방 전환 시 카메라 슬라이드만 구현하면 충분

### 5. 아이템 귀속 규칙 참고
OnionCat에서 업그레이드 카드를 각자 선택하는 구조와 유사. Windblown의 "먼저 집은 사람 소유" 대신:
- **OnionCat**: 동시에 각자 3장 중 1장 선택 (`UpgradeSelectUI` 이미 구현됨) → 중복 선택 시 둘 다 적용 or 추가 효과?
