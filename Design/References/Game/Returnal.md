## 핵심 시스템 분석

### 1. 루프 구조: 죽음 = 이야기
- 플레이어가 죽으면 다시 행성에 추락하는 장면으로 복귀 → **죽음이 내러티브의 일부**
- 반복 속에서 새로운 정보(파편적 단서, 텍스트 로그)가 밝혀지며 스토리가 전개됨
- 죽음을 설계 결함이 아닌 "의도된 게임플레이 리듬"으로 만든 대표 사례

### 2. 바이옴 기반 진행
- 6개의 바이옴(Biome)으로 구성된 선형 진행
- 각 바이옴마다 고유한 적, 환경 위험, 미적 테마
- 바이옴 클리어 후 이후 바이옴에서 시작하는 **단축키 숏컷 없음** → 처음부터 다시 시작
  - 단, 일부 영구 업그레이드(Parasites, Keys)는 런 간 유지
- OnionCat 참고: 던전 층마다 환경 테마 + 적 세트를 명확히 분리

### 3. 사이클로피언 탄막 전투
- 전방위 탄막(bullet hell) + 대시 무적 조합
- 적들의 투사체가 **예측 가능한 패턴**을 가지지만 화면이 가득 참 → 읽기 + 반응 동시 요구
- 히트박스: **적에게는 너그럽고, 플레이어에게는 정확**

### 4. 아드레날린 멀티플라이어
- 죽지 않고 적을 연속 처치할수록 아드레날린 레벨 1→5 상승
- 레벨에 따라 다양한 버프(자동 회복, 위력 증가 등) 적용
- 피격 시 아드레날린 초기화 → **리스크-리워드 루프** 강화
- OnionCat 적용: 연속 협동 처치 시 콤보 게이지 → 협동 능력 강화

### 5. 무기 시너지 시스템 (Ether / Parasites / Malignant)
- **Parasite**: 패시브 효과 but 부작용(디버프) 동반 → 빌드 딜레마
- **Malignant 아이템**: 저주받은 아이템, 해제하면 보상 but 해제 전까지 패널티
- **Ether**: 영구 재화, 저주 해제 또는 Fabricator(제조기) 활성화에 사용
- 세 요소가 서로 연결된 의사결정 네트워크 구성

### 6. 분위기와 공포 연출
- 사이언스 픽션 + 코스믹 호러 (H.P. Lovecraft 영향)
- 적은 정보 → 플레이어가 직접 추론 → **발견의 공포감**
- 비선형적 스토리텔링: 죽을 때마다 조각 정보가 추가됨

## 플레이어들이 좋아하는 것

1. **탁월한 게임 피드백**: 타격감, 파티클, 컨트롤러 진동(DualSense) → 전투가 "물리적"으로 느껴짐
2. **중독적인 루프**: 죽어도 다시 시작하고 싶은 욕구 → 게임플레이 핵심에서 비롯됨
3. **점진적 스토리 개방**: 한 런에 모든 것을 주지 않고, 반복이 이야기를 완성
4. **다양한 빌드 가능성**: 동일한 무기도 Parasite 조합에 따라 완전히 다른 플레이
5. **시각적 쾌감**: 탄막 사이를 파고드는 움직임이 시각적으로 아름다움

## OnionCat 적용 포인트

### A. 협동 콤보 게이지 (아드레날린 시스템 참고)
- 고양이(P1)와 작물(P2)이 번갈아 처치하면 **협동 콤보** 스택 증가
- 스택에 따라 협동 필살기 충전 → 쓰면 리셋
- 한 명이 피격 시 스택 초기화 → 역할 분담 강화

### B. 바이옴별 적 세트 분리
- 1층: 근접 취약 적 위주 (P1 고양이 메인)
- 2층: 원거리 취약 적 위주 (P2 작물 메인)
- 3층: 혼합 → 두 플레이어 동등하게 중요
- 층마다 시각 테마(색상 팔레트) 명확히 구분

### C. 피격 없이 클리어 보너스
- 방 클리어 시 피격 없으면 "퍼펙트 클리어" 보너스 아이템 추가
- 두 플레이어 모두 무피격이어야 발동 → 서로 엄호하는 동기 강화

### D. 패시브 부작용 아이템
- 강력하지만 단점이 있는 업그레이드 (Parasite 개념)
- 예: "P1 공격력 +50% but 방어력 -30%" → 플레이어가 직접 위험 감수

### E. 단편 스토리 텔링
- 각 방 클리어 시 1~2줄의 로그 텍스트 보상
- 많은 런을 할수록 스토리 전체가 퍼즐처럼 완성
- 죽음 자체를 내러티브로 활용 ("고양이가 또 지다…")

## 디자인 철학 요약

> "루프는 죄악이 아니다. 죽음이 이야기가 된다면."  
> — Housemarque 디자이너 인터뷰

- **의도적 난이도**: 쉽게 해결 안 됨 → 숙련도 상승의 쾌감
- **감각적 피드백 우선**: 게임플레이는 먼저 "느껴져야" 함
- **반복의 의미**: 죽음이 단순 리셋이 아닌 정보 축적
