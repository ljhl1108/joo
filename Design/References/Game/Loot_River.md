## 핵심 메카닉

### 1. 테트리스 블록 + 실시간 전투 융합
Loot River의 가장 독창적인 메카닉: 던전 방들이 물 위에 떠 있는 **슬라이딩 블록(Tetris 모양)**으로 구성되어 있음. 플레이어는 발판 블록을 좌우로 밀어 이동시키면서 동시에 적과 전투를 수행함. 이동(전략)과 전투(실시간)가 분리되지 않고 하나의 레이어에서 진행.
- 왼쪽 스틱: 블록 슬라이딩 (블록과 캐릭터 동시 이동)
- 오른쪽 스틱: 캐릭터 공격 방향
- 블록을 정렬해 건너가거나, 빈 물 공간으로 적을 밀어 떨어뜨리는 전술

### 2. 어두운 픽셀 아트 미학
Dark fantasy pixel art — 물의 반사, 블록 그림자, 파티클 이펙트가 단순한 픽셀 그래픽에 시각적 깊이를 줌. 빛 연출(URP 2D Light)로 음습한 던전 분위기 표현.

### 3. 무기 시스템 — 스탯 루팅
디아블로식 장비 루팅: 무기마다 고유 스탯(공격 속도, 범위, 데미지, 특수 효과) 조합이 랜덤. 같은 칼도 회득 시마다 다른 수치. 전형적 로그라이트 런간 변화.

### 4. Dark Souls 영향 — 복잡한 전투 리듬
경직, 패리, 무기 스탯 간의 궁합. 스탯 요구치가 충족되지 않으면 패널티. 단순 스펙 로그라이트가 아닌 "조작 실력 + 빌드"의 복합 요구.

### 5. 절차적 던전 생성
블록 크기와 모양이 랜덤 조합으로 맞물려 새로운 배치 형성. 방의 연결보다 **공간 자체가 퍼즐 + 전투장이 되는 구조**. 플레이어는 도달 가능한 블록 경로를 즉흥 계산하며 이동.

## 플레이어들이 좋아하는 것

- **독창적인 공간 이동 메카닉**: 어디서도 본 적 없는 블록 슬라이딩 + 전투 융합. 적을 물에 빠뜨리거나 블록을 이용해 거리를 조절하는 전술성.
- **유려한 비주얼**: 물 반사 + 어두운 던전 분위기의 픽셀 아트 연출.
- **Dark Souls 느낌의 전투 무게감**: 단순한 클리커 로그라이트가 아닌 리듬감 있는 전투.
- **무한한 빌드 변주**: 무기 스탯 조합의 다양성.

## OnionCat 적용 포인트

### 1. 공간 조작으로 협력 유도
Loot River처럼 맵 자체를 조작 요소로 활용: OnionCat에서 Cat이 근접으로 적을 특정 방향으로 밀어내고 Crop이 원거리로 마무리하는 패턴에서, 방 안에 **이동 가능한 발판/장애물**을 추가하면 공간 전략 레이어 생성. 예시: 방 중앙에 밀 수 있는 상자 → Cat 슬래시로 상자를 밀어 적을 구석으로 몰기.

### 2. 물/심연으로 추락 판정
Loot River의 물 + 블록 개념을 OnionCat 방 시스템에 적용: 일부 방에 낙사 구역(심연, 전류 웅덩이)을 배치. Cat의 대시로 적을 낙사 구역으로 밀어넣거나, Crop의 투사체 넉백으로 적을 밀어내는 전술적 공간 활용.

### 3. 픽셀 아트 물 반사 연출 참고
URP 2D Light + Screen Space Reflection 비스무리한 효과로 방 안에 물 표면 표현. Shader_Effects.md 참고. 시각적 깊이감 UP.

### 4. 블록형 방 레이아웃 — 불규칙 방 모양
정사각형 방만이 아닌 **L자, T자, 계단형** 방 프리팹 추가. Loot River 블록처럼 방 자체의 외형이 전술적 엄폐물 역할. Room_System.md의 방 프리팹 구조에 다각형 방 타입 추가.

### 5. 무기 스탯 루팅 — OnionCat 아이템 시스템
현재 OnionCat 업그레이드 카드 시스템에 "발견형 장비 루팅" 추가 고려. 방 안에 드롭된 무기/화분(Crop 전용 장비)에 랜덤 스탯 조합. Loot_Rarity_Tier_System.md + Upgrade_Item_System.md 조합으로 구현 가능.
