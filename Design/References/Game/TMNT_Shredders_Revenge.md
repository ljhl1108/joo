# TMNT: Shredder's Revenge

리서치 날짜: 2026-10-20

## 기본 정보

- **공식 사이트**: https://www.tribute.games/shredders-revenge/

## 핵심 시스템

### 로컬 협동 최대 6인
- **1~6명** 동시 플레이. 각 캐릭터 고유 능력 보유
- 화면에 모든 플레이어를 담는 **동적 카메라**: 멀리 가면 함께 끌려옴, 너무 멀면 화면 끝에서 대기
- **1~2인에 최적화된 설계**지만 다인 플레이도 혼돈 속 재미. 화면이 좁아지는 건 의도적 난이도

### 캐릭터 개성화
- **7명** 플레이어블 캐릭터: 레오·라파·미켈·도나텔·에이프릴·스플린터·케이시
- 공통 기본기(점프·공격·수퍼 어택) + 고유 특수기 1~2개
- 스탯 차이: 에이프릴은 빠르고 도나텔은 리치 길고 라파는 느리지만 데미지 높음
- **핵심**: "같은 게임인데 캐릭터마다 다른 느낌" — 반드시 다시 하게 만드는 설계

### 특수 게이지 시스템
- 공격을 맞추거나 맞으면 **특수 게이지 충전**
- 가득 차면 **수퍼 어택** 발동 (캐릭터마다 다른 연출과 범위)
- 게이지를 빠르게 쓰면 작은 수퍼 어택 여러 번 vs. 모아서 대형 수퍼 어택 선택
- **파티 수퍼 어택**: 일정 게이지에서 두 캐릭터가 동시에 발동하면 합체기 → 협동 보상이 극적으로 연출됨

### 콤보 & 리듬
- 적을 쓰러뜨리지 않고 공중 재우기 + 계속 때리기로 **콤보 연장**
- 보조 플레이어가 공중에 올린 적을 받아 치는 협동 콤보 → 체계적으로 설계되진 않았지만 자연스럽게 발생
- 드라이브(돌진) + 슈퍼 어택 + 던지기 조합이 복잡해 보이지만 **버튼 2~3개로 직관적**

### 진행 구조
- **16 스테이지** 선형 진행 + 각 스테이지 랭크 (D~S)
- 스테이지마다 비밀 아이템, NPC 구출, 도전 과제
- **월드맵**: 스테이지 사이에 잠금 해제되는 비밀 스테이지 연결
- **퍼펙트 클리어 보너스**: 피격 없이 클리어 시 추가 점수

### 성장 시스템 (단순하지만 효과적)
- 적을 처치하면 **경험치 → 레벨업 → 체력·특수 게이지 상한 증가**
- 진행 중 **버프 아이템** 줍기 (속도·무적·공격력 임시 강화)
- 복잡한 장비 시스템 없음 — "전투 그 자체"가 핵심

## 협동 설계 특이점

### 부활 시스템
- 플레이어가 죽으면 **동료 옆에 노란 아이콘 표시** → 다른 플레이어가 그 위치에서 버튼 입력하면 즉시 부활
- 제한: 부활 개수(가지고 있는 생명) 차감
- **협동 압박 설계**: 혼자 죽지 않기 위해 서로 위치를 신경 쓰게 됨

### 투척 협동
- 한 플레이어가 적을 잡아서 던지면 → 다른 플레이어가 **날아오는 적에게 추가 공격** 가능
- 시스템으로 강제하지 않지만 자연스럽게 발생하는 협동 순간

### 동적 난이도
- 혼자 플레이 시 적이 적게 나옴, 2인이면 더 많이, 6인이면 엄청난 혼돈
- 화면 꽉 차는 적 + 모든 플레이어 유지 = "같은 게임 다른 경험"

## 플레이어가 좋아하는 것

1. **화려한 협동 연출**: 합체기, 투척 협동 등 "같이 하는 게 더 재밌다"는 느낌 강화
2. **진입 장벽 낮음**: 버튼 1~2개만 써도 플레이 가능 → 게임 생소한 친구와도 즐김
3. **향수와 새로움**: 옛날 아케이드 게임 감성 + 현대적 감각의 연출
4. **리플레이 가치**: 전 캐릭터 해보기, S랭크 도전, 비밀 스테이지 발견

## OnionCat 적용 포인트

### 1. 특수 게이지 발동 연출 강화 (야성 게이지 참고)
- TMNT의 수퍼 어택은 단순히 큰 피해가 아니라 **화면이 잠깐 멈추고 캐릭터만 남는 연출**
- OnionCat의 야성 게이지 특수 공격도: 발동 순간 히트스톱 0.3초 + 카메라 살짝 당겼다 놓기 + 특수 사운드 = 체감 강화 가능
- 이미 `HitFeelSettings.asset`에 히트스톱 조정 가능 — 특수 공격에만 큰 값 사용

### 2. 파티 합동기 연출 참고
- TMNT 합체기는 두 캐릭터가 화면 가운데 모여 함께 동작 — 위치와 타이밍이 맞아야 성공
- OnionCat의 합동기(ONION STORM)도 현재 "둘이 1.5초 안에 버튼" 구조인데, **성공 시 작은 컷씬 연출(고양이+양파가 합체 자세)** 추가하면 기억에 남는 순간이 됨
- Unity `Animator`의 Override Controller로 합동기 전용 애니메이션 트리거 가능

### 3. 부활 상호작용 → 협동 의존 강화
- TMNT의 동료 부활 시스템: "내가 죽어도 상대가 있으면 이어서 싸울 수 있다"는 안도감
- OnionCat은 공유 HP라 한 명이 죽는 개념이 없지만, **패닉 상황 협동 보상**으로 응용 가능
  - HP 10% 이하 + 패링 성공 = 협동 게이지 대폭 충전(+30) → "위기를 기회로" 
  - CLAUDE.md에도 "부활 패링"이 아이디어 풀에 있음(2026-10-19) — 이 방향성과 일치

### 4. 캐릭터 개성 → 장비에 의한 플레이스타일 분화
- TMNT는 캐릭터를 고르는 것만으로 플레이스타일이 결정됨
- OnionCat은 장비 선택이 그 역할 — **장비 조합으로 "오늘의 캐릭터"가 다름** 
- 5가지 할퀴기 변형 × 마법서 조합이 실질적으로 다른 플레이스타일을 만드는지 확인 필요
- "오늘 특수는 회오리라서 끌어당기는 걸 노렸다" 같은 후기가 나오면 성공

### 5. 투척 협동 → 걷어차기 협동 강화
- TMNT에서 A가 적을 공중에 던지면 B가 쳐서 더 강한 타격
- OnionCat: 고양이 걷어차기로 날아가는 적이 → 양파 씨앗에 맞으면 추가 히트 판정 + "BOUNCE SHOT!" 텍스트
- 현재 걷어차기 적이 벽에 박히면 CRASH, 구덩이 낙사 → **날아가는 중 피격으로도 추가 효과** 확장 가능

### 6. 진입 장벽 관리 (2인 게임 특이사항)
- TMNT는 P2가 버튼 1개만 눌러도 함께 즐길 수 있게 설계됨
- OnionCat: 양파 P2가 "마우스만 클릭해도 씨앗 발사"처럼 최소한의 조작으로 참여 가능한 입문 모드 고려
  - 지금도 마우스 클릭이 씨앗 발사라 이미 어느 정도 달성 — 스킬(Q/W/E)은 선택사항임을 튜토리얼에서 명확히
