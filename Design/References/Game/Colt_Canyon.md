## 핵심 메커니즘

### 1. 미니멀 조작 철학
Colt Canyon의 가장 큰 특징은 **극도로 단순한 입력으로 깊이 있는 전투**를 만든다는 점:
- 이동 + 에임 + 발사 + 구르기(회피) — 이것이 전부
- UI는 거의 없고 체력 표시도 피격 시 깜빡임으로만 표현
- 총소리·적 움직임·지형 파괴로 상황 파악 → 소음으로 적 위치 인지

### 2. 2가지 무기 타입 동시 운용
- **주 무기**: 연사 소총류 (원거리·빠른 발사)
- **보조 무기**: 권총·산탄총류 (가까운 거리·높은 데미지)
- 두 무기를 상황에 따라 번갈아 사용
- **일부 적은 원거리로만, 일부는 근거리로만 효율적 처치** → OnionCat 약점 시스템 참고

### 3. 인질 구출 시스템
- 오버월드 곳곳에 포박된 인질(보안관, NPC) 존재
- 구출 시 런 내 버프 제공 (체력 회복, 무기 강화, 임시 동료)
- 인질 구출을 우선할지 적을 제거할지 → 전략적 선택 부여

### 4. 지형 파괴 활용
- 나무 상자, 드럼통 등 폭발 가능
- 폭발 범위로 여러 적 한번에 처치 가능
- 적도 지형 이용해 엄폐 → 순수 정면승부 외의 전술

### 5. 로그라이트 구조
- 랜덤 맵 생성 (서부 황야 → 광산 → 요새 → 보스)
- 적에게서 무기 드롭
- 런 중 체력 회복 수단 극히 제한 → 긴장감 유지
- 사망 시 처음부터 (퍼마데스)

## 플레이어가 좋아하는 것

1. **극도의 긴장감**: 체력 회복이 거의 없어 한 번의 실수가 치명적
2. **단순하지만 깊은 전투**: 2가지 무기만으로 다양한 전투 상황 연출
3. **미니멀 픽셀아트**: 서부 분위기를 2~3색으로 표현하는 절제된 아트
4. **빠른 런 사이클**: 한 런이 20~30분 → 반복 플레이 용이
5. **총소리 피드백**: 사운드만으로 상황 인지 가능한 설계

## OnionCat 적용 포인트

### A. 2가지 공격 타입으로 각기 다른 상황 커버 (핵심)
Colt Canyon의 주/보조 무기 분업이 OnionCat의 Cat(근접)/Crop(원거리)와 정확히 대응:
- **주 무기(Cat 근접)**: 근접 적, 근접 약점 몬스터
- **보조 무기(Crop 원거리)**: 원거리 적, 원거리 약점 몬스터
- Colt Canyon의 교훈: 두 무기가 **언제나 유용한 상황**을 만들어야 함. 어느 하나만으로 클리어 가능하면 협력 의미가 없다.

### B. 미니멀 UI 설계 교훈
체력 표시를 피격 깜빡임으로 표현하는 방식:
- OnionCat HUD에서도 숫자 HP 대신 고양이 아이콘이 다치는 시각적 표현 고려
- 화면 테두리 붉은 flash 등으로 피격 인지 → UI 공간 최소화

### C. 인질 구출 = 서브 오브젝티브
방 클리어 외에 선택적 서브 목표로 인질/NPC 구출:
- OnionCat에서 "선택적 구출 NPC" → 구출 시 1회성 버프 제공 미션 아이디어로 응용
- 위험을 감수하고 추가 보상을 노리는 전략적 선택 부여

### D. 지형 파괴 전술 → 환경 상호작용
폭발 드럼통, 파괴 가능 엄폐물:
- OnionCat 방에도 파괴 가능 오브젝트 배치 → 전략적 맵 활용 유도
- Cat의 대시로 폭발물을 적에게 밀치는 등 두 플레이어 협력 콤보 가능
