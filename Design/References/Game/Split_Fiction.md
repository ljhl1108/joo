## 핵심 개요

2인 전용 협동 게임. 해커 Mio와 소설가 Zoe가 출판사의 AI 이야기 추출 기계에 갇혀 그들의 이야기 세계를 탈출하는 서사.

### 특이점
- **2인 전용 (no single player)**. Friend Pass 지원 — 한 명만 구매해도 친구 초대 가능.
- **챕터마다 장르가 바뀜**: 사이버펑크 → 판타지 → SF → 서부극 → 생체공학 등. 매 챕터가 완전히 다른 메커닉을 가진 별개의 미니게임처럼 작동.
- **능력 비대칭**: Mio는 테크(해킹·사이버네틱), Zoe는 마법·자연 친화. 두 능력이 겹치지 않아 반드시 협력해야 풀리는 퍼즐.
- **역할 교환 없음**: 챕터 내내 각자의 캐릭터 유지. 상대방 능력 없이는 진행 불가.

## 협동 메커닉 심층 분석

### 1. 비대칭 능력 설계
```
Mio (해커)           Zoe (작가/마법사)
─────────────────    ─────────────────
전기 충격 방출       식물 덩굴 생성
해킹 포털 열기       마법 방어막
드론 제어            동물 소환/조종
사이버 대시          중력 조작
```
→ **각 퍼즐은 두 능력을 동시에 사용해야 해결**됨.
예: Mio가 전기로 문 해킹 유지 → Zoe가 그 틈에 덩굴로 플랫폼 생성.

### 2. 순간적 역할 전환 (Contextual Role Swap)
특정 구간에서 두 플레이어의 역할이 갑자기 뒤집힘 (Mio가 보호, Zoe가 공격 등). 고정 역할에 익숙해질 무렵 뒤집어 신선함 유지.

### 3. 화면 분리 / 합류 카메라
기본은 동일 화면. 두 캐릭터가 멀어지면 **화면이 수직/수평으로 분할**됨. 다시 가까워지면 부드럽게 합쳐짐.

### 4. 챕터별 전용 메커닉 (Mechanic-of-the-Chapter)
각 챕터에는 그 챕터에서만 쓰이는 독특한 공유 메커닉이 1개씩 있음.
예: 두 플레이어가 동시에 같은 버튼을 누르는 "싱크 퍼즐", 한 명이 메트로놈 박자를 맞추는 동안 다른 한 명이 전투하는 구간.

### 5. 협동 공격 / 시너지 콤보
특정 보스전에서 두 플레이어가 같은 약점을 **동시에 공격**하면 슈퍼 피해 발동. 화면에 "COMBINE!" 표시.

## 보스전 구조

- **2페이즈 이상 구성**: 각 페이즈마다 다른 약점(Mio 전담 vs Zoe 전담 vs 동시).
- **역할 강제 분리**: "Mio는 위쪽 기어를 돌리는 동안 Zoe는 아래 적을 막아라" 식의 공간 분리.
- **양자 동시 행동 필요**: 두 버튼을 동시에 눌러야만 발동되는 피니셔.

## 리듬 / 페이싱

| 구간 | 내용 |
|------|------|
| 챕터 시작 | 새 메커닉 안전하게 소개 (도전 없이 탐험) |
| 챕터 중반 | 메커닉 조합 퍼즐, 전투 적용 |
| 챕터 클라이맥스 | 보스 or 대형 세트피스 |
| 챕터 간 | 스토리 컷씬, 휴식 공간 |

→ **"소개 → 응용 → 절정"** 3단계 학습 곡선이 챕터마다 반복.

## 플레이어가 사랑하는 요소 (Steam 리뷰 분석)

1. **다양성**: "질리기 전에 메커닉이 바뀐다." 챕터마다 신선함.
2. **진정한 협동**: "혼자서는 아무것도 못 한다. 상대 없이는 멈춰버린다."
3. **Friend Pass**: "친구가 구매 안 해도 초대해서 같이 함. 진입 장벽 제거."
4. **비주얼 다양성**: 각 챕터가 완전히 다른 아트 스타일.
5. **감정적 서사**: 캐릭터 성장 서사가 협동 구조와 맞물림.

---

## 비판적 관점

- **리플레이 가치 낮음**: 퍼즐 답을 알면 재미 반감. 로그라이크 구조 없음.
- **챕터 불균형**: 일부 챕터(예: 서부극)가 다른 챕터보다 현저히 짧거나 약함.
- **솔로 불가**: 친구 없으면 플레이 자체가 불가. 네트워크 의존.

## OnionCat 적용 포인트

### 1. 챕터별 메커닉 → 방 유형별 특수 규칙
Split Fiction의 "챕터마다 다른 메커닉" 개념을 OnionCat의 "방 타입별 특수 조건"으로 차용:
- **방화 방**: 고양이 이동 속도 감소, 양파 물 투사체 데미지 2배
- **어둠 방**: 시야 제한, 양파 조명 투사체 없으면 고양이가 약해짐
- **침묵 방**: 투사체 사용 불가, 고양이 근거리만 허용 → 강제 근접전
→ 구현 힌트: `RoomModifier ScriptableObject`에 조건 필드 추가, 방 진입 시 `GameManager.ApplyRoomModifier()` 호출

### 2. 동시 공격 시너지 (Combine Attack)
두 플레이어가 동일 프레임(±0.2초 이내)에 같은 적에게 피해를 가하면 "COOPERATION!" 이펙트 + 보너스 데미지.
→ `TakeDamage()`에서 `lastAttackTime[Attacker.Cat]`과 `lastAttackTime[Attacker.Onion]`의 시간 차를 체크, 임계값 이내이면 시너지 배수 적용

### 3. 페이즈별 약점 교대 보스
보스 페이즈마다 "근거리 취약 → 원거리 취약 → 동시 공격 필요" 순환:
- 고양이만 딜 가능 페이즈 → 양파가 방어 유지
- 양파만 딜 가능 페이즈 → 고양이가 적 처리
- 피니셔: 두 플레이어 동시 입력 → Split Fiction의 "Combine" 시스템 참고

### 4. "소개 → 응용 → 절정" 방 시퀀스
현재 랜덤 방 배치에 **방 카테고리 태그** 추가:
- `RoomType.Tutorial`: 새 메커닉(방 특수 규칙) 안전하게 소개
- `RoomType.Challenge`: 메커닉 응용 전투
- `RoomType.Boss`: 절정
→ `DungeonManager`에서 "Tutorial 1개 → Challenge 2~3개 → Boss" 순서 보장

### 5. 챕터 전환 컷씬 → 층 클리어 연출
Split Fiction의 챕터 간 숨 고르기 구간을 OnionCat의 층 클리어 후 짧은 연출로:
- 고양이와 양파의 포즈/대사 (애니메이션 클립)
- 다음 층 힌트 ("다음 방은 불 방이야...")
→ `FloorClearPresenter`에 간단한 대화 이벤트 추가 고려
