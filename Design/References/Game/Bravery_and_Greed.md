## 핵심 메카닉

### 클래스 시스템
4개의 플레이어블 클래스, 각각 뚜렷한 역할 차이:

| 클래스 | 역할 | 특기 |
|--------|------|------|
| Warrior | 탱커/근접 | 방패 블록, 강력한 근접 타격 |
| Rogue | 이동기/버스트 | 은신, 백스텝, 콤보 |
| Wizard | 원거리/AoE | 마법 투사체, 원소 폭발 |
| Amazon | 하이브리드 | 창 투척, 돌진, 중거리 |

각 클래스는 완전히 다른 조작감 → **역할 강제 협력** 자연 발생

### 비트업 + 로그라이트 융합
- 스테이지 클리어형이 아닌 방 단위 순환 구조
- 방 클리어 → 골드 획득 → 중간 상점/업그레이드 선택
- 죽으면 런 종료(퍼머데스), 소량의 메타 해금 존재
- 5개 던전 레이어 + 최종 보스로 구성된 런 구조

### 협동 고유 메카닉
- **클래스 시너지**: Warrior 스턴 → Rogue 백어택 데미지 2배
- **공유 골드**: 모든 플레이어가 동일 골드 풀 사용 → 소비 우선순위 협의 필요
- **부활 시스템**: 아군이 쓰러진 플레이어 곁에서 특정 시간 행동 → 부활
- **공동 상점**: 업그레이드 하나 구입 시 전체 의견 반영 필요 (구매 후 후회 없도록)

### 골드/경제 시스템
- 적 처치 + 파괴 가능 오브젝트에서 골드 드롭
- 파밍 욕심과 빠른 방 진행 사이 트레이드오프
- 상점 가격이 플레이어 수 비례 → 솔로 vs 멀티 밸런스

## 로그라이트 루프 구조

```
런 시작
  └── 클래스 선택 (각 플레이어)
       └── 던전 레이어 1~5
            ├── 전투 방: 적 처치 → 골드
            ├── 보물 방: 골드 → 장비 구입
            ├── 상점 방: 업그레이드 선택
            └── 보스 방: 레이어 보스 격파
                 └── 다음 레이어 또는 최종 보스
런 종료 → 메타 화폐 해금 (신규 클래스, 던전 요소)
```

## 플레이어들이 사랑하는 것

1. **클래스별 확실한 역할 차이** — 4인 플레이 시 각자 맡은 역할이 명확해 협동의 쾌감이 큼
2. **빠른 템포** — 방 하나 클리어에 30초~2분, 런 전체가 1~2시간 내로 끝남
3. **골드 파밍의 재미** — 파괴 가능 오브젝트가 많아 탐욕 플레이의 보상이 확실함
4. **격정적인 타격감** — 히트스톱 + 타격 이펙트가 비트업 장르 기대치 충족
5. **로컬 협동** — 소파 co-op을 제대로 지원하는 흔치 않은 게임

## OnionCat 적용 포인트

### 1. 역할 강제 협력 설계
Bravery and Greed의 클래스 시너지처럼 OnionCat도 **자동으로 협력이 강요되는 순간**을 기획:
- 특정 적: Cat 근접만 유효, Onion 원거리만 유효 (이미 기획됨)
- 추가로: Onion의 방어막 패리 성공 → Cat에게 "슬래시 강화" 버프 일시 부여 → 콤보 협력 유도

### 2. 공유 자원 / 업그레이드 협의 장치
공유 골드 풀처럼 OnionCat의 업그레이드 선택 화면을:
- "Cat 전용 / Onion 전용 / 공유" 3개 슬롯으로 구분
- 매 층 클리어 후 각자 1개 선택권 + 공유 1개 협의 선택 → 소통 필수화

### 3. 부활 메카닉 참고
OnionCat은 한 몸이지만 HP를 Cat/Onion 독립 구조로 만들 경우:
- 한쪽 HP 0 → "위기 상태" (이동 속도 50% 감소, 공격 제한)
- 상대 역할을 빠르게 수행해 HP 일부 회복하면 탈출 → 위기 해소 루프

### 4. 빠른 방 클리어 템포
Bravery and Greed처럼 방 하나의 클리어 시간을 20~90초로 설계:
- 적 과다 배치보다는 **소수 정예 + 협력 필수 적 구성** 권장
- 방 클리어 보상을 명확히 시각화 (골드 팡팡 / 업그레이드 UI 등장)

### 5. 파괴 가능 오브젝트 파밍 레이어
단순 적 처치 외에 방 내 항아리, 선반 등 파괴 오브젝트에서 추가 재화 드롭:
- Cat의 슬래시로 한번에 많이 파괴 가능 → 근접 캐릭터 유용성 상시 존재
