## 핵심 시스템 — 장비 & 세트 중심

### 1. 장비 슬롯 구조 (Head / Chest / Arms / Waist / Legs + Weapon)
- 각 슬롯에 방어구를 착용, **세트 보너스(Set Bonus)**는 같은 시리즈 2~5개 조합 시 발동
- 장비마다 **스킬 포인트** 1~3이 붙어 있고, 포인트가 쌓이면 스킬 레벨이 올라감
- 장식주(Decoration)로 원하는 스킬을 추가 — 장비 슬롯에 박는 보석
- **OnionCat 대응**: `GearItem` = 방어구 한 조각. `CombatModifiers`의 세트 보너스 = MHW Set Bonus. `PassiveHost.Recalculate` = 스킬 포인트 합산

### 2. 세트 보너스 설계 — 단계별 발동
```
레우스 시리즈 2개: 번개 속성 내성 +10
레우스 시리즈 4개: 번개 무효화
레우스 시리즈 6개: 번개 흡수
```
- 2단계 보너스는 쉽게 달성 가능 → 항상 뭔가 발동되는 느낌
- 4단계 이상은 한 종류 올인 → 고위험·고보상 빌드 선택
- **중요**: 세트를 "맞추는 재미"와 "섞는 재미" 둘 다 존재

### 3. 무기 14종 — 역할 분담이 아닌 플레이스타일 분담
- 대검(큰 대미지, 느린 연속성), 쌍검(빠른 타격, 낮은 단타), 활(원거리), 헤비보우건(지원)
- 같은 몬스터를 다른 무기로 싸우면 **완전히 다른 게임**이 됨
- **OnionCat 적용**: 고양이 무기 타입이 전투 리듬 자체를 바꾸는 설계 → 각 무기에 고유한 "플레이 루프" 부여 (클로 → 타격형, 창 → 찌르기+거리 유지형)

### 4. 헌팅 사이클 — 강요 없는 준비
- 사냥 전: 함정 세팅, 폭탄 준비, 속성 맞추기 → 선택 사항이지만 효율 차이가 큼
- 사냥 중: 환경 활용(독웅덩이, 돌무더기), 몬스터 부위 파괴
- 사냥 후: 소재 획득 → 장비 제작 사이클
- **OnionCat 적용**: 양파가 R키로 씨앗 심기(Planting) → 전장 설치형 오브젝트 활용 → MHW의 "준비한 사람이 더 잘 싸운다" 원칙과 동일

### 5. 협동 (최대 4인)
- 혼자 하다가 힘들면 플레어를 쏘면 다른 플레이어가 합류 가능 (SOS 시스템)
- 협동에서 적 체력이 증가하지만 대미지 딜링도 증가 → 쉬워지는 느낌
- 각자 무기가 달라 역할이 자연스럽게 분화됨 (방패형, 원거리, 보조)
- **OnionCat 적용**: 2인 비대칭 역할(근접 고양이 + 원거리 양파)은 MHW의 역할 분화와 동일 원리. 같이 싸우면 혼자보다 잘 싸운다는 느낌을 주는 콤보 보상 체계 중요

### 6. 장비 비교 & 빌드 계산기 문화
- 커뮤니티에서 spreadsheet 기반 빌드 계산기 자체 제작
- 게임 안에서는 **장비 비교 화면 UI**가 핵심: 어떤 스킬이 추가·제거되는지 한눈에
- **OnionCat 적용**: `Equipment_Comparison_Tooltip_UI`의 설계에서 "+스킬명" / "-스킬명" 형식 표시 중요

## 세트 보너스 설계 원칙 (OnionCat에 직접 적용)

### "Threshold Activation" 원칙
```
세트 2개(Sun) → 소극적 보너스 (스탯 소량 증가)
세트 4개(Sun) → 적극적 보너스 (새 효과 발동)
```
- **2개 보너스는 항상 뭔가 발동** → 슬롯 1개 비워도 OK라는 심리적 여유
- **4개 보너스는 올인 보상** → 플레이어가 스스로 선택

### "Cross-Set" 빌드의 재미
```
Sun 2개 + Wind 2개 → 두 세트 보너스 동시 발동
```
- 세트를 완성하지 않아도 가치가 있음 → 최적화 이전의 중간 단계에서도 재미

### OnionCat `CombatModifiers` 적용 제안
```csharp
// 현재 구조
CombatModifiers.Has(SetType.Sun, 2)  // 2단계 보너스
CombatModifiers.Has(SetType.Sun, 4)  // 4단계 보너스

// MHW 스타일 추가 아이디어:
// Cat이 Sun 2개 + Onion이 Wind 2개 → "크로스 세트" 보너스 발동
CombatModifiers.HasCross(SetType.Sun, SetType.Wind)
```

## 플레이어들이 사랑하는 것

1. **빌드 최적화의 재미** — 세트 보너스 조합, 장식주 세팅이 무한 조합
2. **각 무기의 완전히 다른 게임성** — 14종 중 주무기를 고르는 게 첫 번째 선택
3. **혼자 해도 협동 해도 재미있음** — 협동이 선택 사항인 설계
4. **몬스터의 디테일한 행동 패턴** — 패턴을 외우는 게 성취감

## OnionCat 직접 적용 포인트

| MHW 시스템 | OnionCat 현재 상태 | 적용 방향 |
|---|---|---|
| 2단계 세트 보너스 항상 발동 | Sun/Wind 등 세트 | 2개짜리 보너스가 너무 약하면 "세트 의식 안 함" 발생 → 최소 보너스도 느껴지게 |
| 크로스 세트 (두 세트 2+2) | 미구현 | 고양이+양파가 다른 세트를 각각 2개씩 갖는 조합 보너스 추가 → 협동 느낌 강화 |
| 장식주로 스킬 미세 조정 | 미구현 | 나중에 "소켓 아이템"으로 추가 가능한 설계 여지 남겨두기 |
| 준비-전투-보상 사이클 | 가방·심기 시스템 | 사냥 전 "심기" 단계(씨앗 준비)가 MHW 함정 세팅과 동일 역할 |
| 무기별 플레이스타일 분화 | 고양이 무기 여러 종 | 각 무기가 "빠른 콤보형" vs "한 방형" vs "거리 유지형" 등 리듬이 달라야 함 |

## 소규모 팀을 위한 적용 힌트

- **세트 보너스 2단계/4단계는 최소 단위**: 복잡하게 6종 보너스 만들지 말고 2레벨만으로 충분
- **세트 개수는 5~8개**: 너무 많으면 플레이어가 외울 수 없음
- **각 세트에 "컨셉"을 하나**: Sun=불꽃 대미지, Wind=이동 속도, Moon=방어력 → 외우기 쉬운 테마
