## 핵심 메카닉

### 공유 몸체 시스템
두 플레이어가 하나의 길게 늘어나는 개 몸체를 공유: P1은 빨간 머리(왼쪽), P2는 파란 머리(오른쪽)를 각각 제어. 몸체는 물리적으로 연결되어 탄성 있게 늘어남.

- 한 플레이어가 당기면 다른 플레이어가 끌려옴 → 상대 위치 인식 필수
- 양쪽 머리를 같은 방향으로 움직여야 빠르게 이동
- 퍼즐 예시: 한 머리가 스위치를 누른 채 버티고, 다른 머리가 통과

### 각 머리의 역할 비대칭
- 파란 머리: 물/기포 뿜기
- 빨간 머리: 불꽃/빛 뿜기
- 각자 환경과 다르게 상호작용 → OnionCat의 근접(Cat) vs 원거리(Onion) 분업 구조와 동일

### 솔로 모드
한 명이 두 개의 조이스틱(또는 키보드+마우스)을 동시에 조작하는 1인 플레이 지원.

## 플레이어들이 사랑하는 이유
- **귀여운 아트**: 부드러운 애니메이션, 밝은 색상, 동글동글한 캐릭터
- **진입 장벽 낮음**: 복잡한 조작 없이 자연스럽게 협동 유도
- **물리 기반 코미디**: 몸이 꼬이고 당겨지는 상황에서 자연 발생적 웃음
- **독립 조작**: 각 플레이어가 자신의 머리만 제어하지만 결과는 공유

## OnionCat 적용 포인트

### 1. 공유 몸체 입력 설계
Phogs!처럼 Cat(P1)과 Onion(P2)이 각자 독립적으로 조작하되 하나의 캐릭터로 렌더링. Cat이 이동할 때 화분(Onion)이 자연스럽게 따라오는 물리 연동 표현 참고.

### 2. "역할 비대칭" 설계 검증
Phogs!의 빨간/파란 머리처럼 OnionCat도 캐릭터가 서로 다른 역할을 가짐. 핵심 원칙:
- 각 역할이 **필수적**이어야 함 (한 명만으로는 모든 적 처리 불가)
- 전환 없이 두 역할을 동시에 독립 수행 가능

### 3. 몸체 흔들림 피드백
Cat이 이동할 때 화분이 관성으로 흔들리는 시각 피드백 → Secondary Motion / 본 애니메이션으로 구현 가능 (기존 `Secondary_Motion_System.md` 참고).

### 4. 1인 솔로 플레이 고려
Phogs!는 한 사람이 좌우 조이스틱을 동시에 조작하는 솔로 모드 지원. OnionCat도 1인 모드(WASD P1 이동 + 마우스 P2 조준 동시 조작) 기획 시 직접 참고 가능.
