## 핵심 메커니즘

### 1. 덱 빌더 + 보드 게임 전투

- 4레인 보드에 카드를 놓고 적과 싸움. 5점 차이가 나면 승리 (점수를 채워 반대쪽 대저울을 기울이는 방식)
- **희생 비용**: 카드를 내려면 다른 카드를 희생해야 함. 0코스트 다람쥐 카드가 기본 연료
- 죽은 카드는 **뼈** 를 남기고, 뼈로 다른 종류의 카드를 소환
- **시길(Sigil)**: 카드에 붙은 특수 능력. "오른쪽에 충격 전달", "죽으면 소환" 등 — 시너지가 핵심
- 아이템(1회용)으로 판을 뒤집는 긴장감

### 2. 오두막 메타 레이어 (1장)

- 덱 빌더 패배 시 오두막 테이블로 돌아옴 — 완전한 게임 오버가 아님
- **오두막 탈출 퍼즐**: 금고·시계·그림 등 환경 오브젝트가 덱 빌더에 영향을 줌
  - 퍼즐 풀면 → 카드 능력치 보정, 특수 카드 획득, 레이스의 눈 훔치기 등
- 메타 레이어와 게임 레이어가 서로 맞물려 "패배도 이야기의 일부"가 됨

### 3. 3막 구조 — 완전히 다른 게임이 되는 방식

| 막 | 내용 |
|---|---|
| 1막 | 오두막 + 로그라이크 덱 빌더 (레이스와의 카드 게임) |
| 2막 | 포켓몬 풍 GB 화면 — 세계를 돌아다니며 카드 수집, 세 명의 적과 대결 |
| 3막 | 테이블 위로 돌아온 카드들 — 모든 덱의 메커니즘이 합쳐진 최종 대결 |

- 각 막마다 **UI·규칙·카드 세트가 완전히 달라짐**
- 모든 비밀과 ARG 요소가 최종적으로 하나의 답으로 수렴

### 4. 동적 덱 조정 메커니즘

- 카드에 이빨을 뽑아 붙여 능력치를 올리는 "치아 거래"
- 발톱으로 카드를 조각해 체력·공격력 커스터마이징
- 카드를 불에 태워 덱을 얇게 만드는 선택 (로그라이크의 클래식 딜레마)

---

## 협동 요소

- 기본적으로 싱글플레이어. 협동 없음.
- 단, **두 플레이어가 번갈아 조작하는 "패스 앤 플레이"** 로 즐기는 비공식 방식이 커뮤니티에 존재
- 카드 수집 + 덱 구성을 두 사람이 나눠서 하는 협동 감각이 생김

---

## 플레이어들이 열광하는 것

1. **"게임인 줄 알았는데 다른 게임이 됨"** — 1막에서 2막으로 넘어갈 때의 충격
2. **패배가 답답하지 않음** — 오두막 탈출 퍼즐이 계속 뭔가를 발견하게 함
3. **카드 시너지 조합** — 단순해 보이는 규칙에서 무한한 콤보
4. **ARG (대체 현실 게임)** — 게임 내 숨겨진 코드, 커뮤니티 협력 풀이
5. **분위기** — 어둡고 공포스럽지만 유머러스. 압박감 있는 적 캐릭터

## OnionCat 적용 포인트

### 1. "패배도 이야기다" — 오두막 구조 → OnionCat 메타 화면

- Inscryption은 패배 → 오두막 귀환 → 새 단서 발견 흐름으로 패배를 보람 있게 만듦
- **OnionCat 적용**: 런 실패 후 "언덕 위 농장"으로 돌아와 말하는 책이 새 대사를 하거나, 화분에 흔적이 남는 연출. 실패를 메타 진행의 일부로 연결

### 2. 덱 조정의 "능동적 약화" — 씨앗 가방 소비 선택

- 카드를 태워 덱을 얇게 만드는 선택 = 단기 약화 → 장기 강화
- **OnionCat 적용**: 가방 아이템 소비 vs 보관 딜레마 강화. "지금 쓰면 약해지지만 보상이 더 좋아지는" 방 이벤트 설계에 활용

### 3. 3막 구조 → OnionCat 이야기 단계별 규칙 변화

- 각 막마다 메커니즘이 달라지는 충격 = 3단계가 지날 때마다 "게임의 색이 달라지는" 느낌
- **OnionCat 적용**: `MetaProgress.Chapter` 1~4 각 단계에서 작은 규칙 추가 또는 연출 변화. 예: 2단계부터 등불이 켜지며 마을에 NPC가 추가되거나 새 작물 색이 등장

### 4. 시길 → 장비 효과 조합 설계 참고

- Inscryption의 시길(카드 특수 능력)은 조합 시 완전히 새로운 효과를 만들어냄
- **OnionCat 적용**: `GearEffect` 조합 시 세트 보너스 외에 "두 효과가 같이 있으면 추가 발동" 같은 시너지 힌트를 아이템 설명에 넣으면 발견의 즐거움 증가

### 5. 1회용 아이템으로 판 뒤집기 — 가방 긴장감

- 절체절명의 순간에 1회용 아이템 사용 = 극적 역전 감각
- **OnionCat 적용**: 가방 소모품(씨앗·폭탄·물약)의 쿨다운 없는 즉발 효과를 보스전에서 활용하도록 UI에서 강조
