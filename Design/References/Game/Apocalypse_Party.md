# Apocalypse Party

리서치 날짜: 2026-11-01

## 기본 정보

- **장르**: 탑다운 슈터 로그라이크 / 로컬 협동 (1~4인)
- **개발사**: Galvanic Games (한국 스튜디오)
- **출시**: 2024년 (Steam Early Access → 1.0)
- **공식 사이트**: https://store.steampowered.com/app/1599530/Apocalypse_Party/
- **위키**: Steam 커뮤니티 가이드 참고

## 게임 개요

좀비 아포칼립스 배경의 탑다운 협동 로그라이크. Enter the Gungeon × Binding of Isaac 느낌이며, 한국 스튜디오가 만든 게임이라 국내 플레이어의 공략 커뮤니티가 활발하다. OnionCat과 **장르·시점·협동 방식**이 가장 유사한 레퍼런스 중 하나.

## 핵심 시스템

### 1. 협동 구조
- **비대칭 역할 없음** — 모든 플레이어가 같은 캐릭터 풀에서 선택. 단, 각 캐릭터마다 고유 스킬
- 1~4인 로컬 협동, 각자 독립적인 체력 바 + 공유 파워업은 없음
- 죽은 플레이어는 생존자가 부활 아이템을 찾거나 특정 방에서 되살릴 수 있음
- **OnionCat 대비**: OnionCat은 '1캐릭터를 2인이 조작'하는 더 밀착된 구조. Apocalypse Party는 독립 캐릭터 방식

### 2. 캐릭터 시스템
- 캐릭터마다 **기본 무기 + 고유 패시브 + 1개 고유 스킬**
- 고양이·닌자·군인·마법사 등 다양한 아케이드 아류형 캐릭터
- 런 중 캐릭터 변경 없음, 시작 시 선택

### 3. 성장 시스템
- 방 클리어 → 레벨업 → 3장 카드 중 1장 선택 (Binding of Isaac 방식)
- 카드: 무기 업그레이드 / 패시브 스탯 / 고유 스킬 강화
- **세트 효과 없음** — 단순 스탯 누적 방식
- 무기는 단일 줄기(분기 없음), 장비 칸 방식이 아님
- 씨앗(화폐) 없음 — 카드만으로 성장

### 4. 방·런 구조
- 방마다 배경 고정 타일 + 랜덤 적 스폰
- 방 클리어 → 레벨업 선택 → 다음 방으로
- 보스 방이 구간마다 있음
- 사망 시 런 종료, 메타 진행(캐릭터 해금)은 분리

### 5. 전투
- **4방향 이동 + 전방향 조준 사격** (조이스틱 or 마우스)
- 근접 없음 — 모든 캐릭터가 원거리 기반
- 스킬 쿨다운 방식 (타이머 회복)
- 회피 대신 **이동 속도·방어막** 기반의 생존

## 플레이어가 사랑하는 것

- **코-옵 난이도 밸런스**: 혼자보다 여럿이 더 쉬워지는 구조 (적 HP 스케일링 있지만 4인이 압도)
- **빠른 런 시간**: 한 런이 20~30분으로 짧아 부담 없는 협동
- **캐릭터별 개성**: 플레이 스타일이 달라서 역할 분담이 자연스럽게 일어남
- **한국산 인디 특유의 아기자기한 픽셀 아트**

## 비판점

- 런 후반부 밸런스가 무너져 너무 쉬워짐 (카드가 쌓이면 무적)
- 세트·시너지 없이 단순 스탯 누적이라 전략 깊이가 얕음
- 협동 시너지가 '같이 쏘기'에만 그쳐 협동 특화 메커닉이 부족

## OnionCat 적용 포인트

### 협동 디자인 교훈
1. **공유 체력이 협동 긴장감을 만든다** — Apocalypse Party는 독립 HP라 '각자도생'이 됨. OnionCat의 공유 HP 1개 구조는 협동 의존도를 훨씬 높여준다. 이 차별점을 살릴 것
2. **빠른 런 템포는 협동 피로를 줄임** — 20~30분 런. OnionCat도 1시간 이내로 설계하되, 방 클리어 시간(적 처치 속도)이 늘어지지 않게 보상 밸런스를 맞출 것
3. **비대칭 역할의 가능성** — Apocalypse Party는 같은 역할 n명이라 '각자 알아서'. OnionCat의 고양이+작물 비대칭은 진정한 협동 퍼즐을 만들 수 있는 구조. 적 디자인에서 '고양이가 접근·작물이 약점 사격' 패턴을 의도적으로 만들 것

### 전투 피드백
4. **탑다운 슈터의 탄 가시성** — Apocalypse Party는 적탄이 크고 색이 명확해 회피 판단이 쉬움. OnionCat도 적탄(빨강)과 아군탄(초록) 색 대비를 유지할 것
5. **스킬 쿨다운 UI** — 원형 진행 표시가 직관적. OnionCat의 마법서 스킬 쿨다운 표시 방식 참고

### 성장 시스템
6. **세트 없는 단순 스탯 누적의 한계** — Apocalypse Party의 비판: "후반에 너무 강해져서 재미없음". OnionCat의 세트 보너스 시스템은 이 문제를 해결할 수 있는 구조. 세트 완성 난이도 조절이 중요
7. **카드 3장 선택** — 고양이·작물이 **동시에** 각자 카드 3장 고르는 OnionCat 방식이 독특함. Apocalypse Party의 1인 1선택에서 진화한 협동 선택 UI

### 메타 진행
8. **캐릭터 해금 분리** — Apocalypse Party는 런 결과와 무관하게 메타에서 캐릭터 해금. OnionCat의 온실(장비 해금)도 유사 구조. 해금 조건을 단순하고 명확하게 유지할 것
