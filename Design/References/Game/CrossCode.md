# CrossCode

리서치 날짜: 2026-10-27

## 기본 정보

- **장르**: 2D 탑다운 액션 RPG
- **개발/출시**: Radical Fish Games, 2018 (정식) / 2015 (얼리액세스)
- **플랫폼**: PC (Steam), PS4/5, Switch, Xbox
- 공식 사이트: https://www.cross-code.com
- Steam: https://store.steampowered.com/app/368340/CrossCode/
- 위키: https://crosscode.fandom.com

## 핵심 시스템

### 전투

- **근접 + 원거리 통합**: 주인공 Lea는 근거리 코어를 직접 던지거나 에너지볼을 원거리로 발사. 근거리 시전 후 즉시 원거리로 전환 가능 — 두 공격이 유기적으로 이어짐
- **4원소 시스템**: 중립·불·물·번개·냉기 총 5개. 전투 중 즉시 전환. 적마다 원소 강약이 있어 "정답 원소"를 찾는 퍼즐적 재미
- **가드/패링**: 버튼을 누르면 전방위 가드 → 타이밍이 맞으면 완전 반사(Deflect). 스태미나 없음, 패링 성공 시 적이 잠깐 경직
- **대시**: 무적 시간 있는 구르기. 쿨다운 있지만 짧음
- **콤보 시스템**: 타격이 쌓이면 게이지가 올라 특수기(SP 스킬) 발동 가능

### 텔레그래프(예고)

- 대부분의 보스 공격에 **빨간 히트박스 미리보기** 표시 (OnionCat과 동일 철학)
- 플레이어가 패닉이 아니라 "읽고 반응"하게 설계
- 광역기 → 핵심 도피 경로를 남겨둠 (막혀있는 느낌 없음)

### 장비 시스템

| 항목 | 내용 |
|------|------|
| 장비 종류 | 무기·방어구 각 1개 + 장신구 2개 |
| 스탯 구조 | ATK / DEF / HP / MP + 원소 보정치 |
| 모드(Mod) 슬롯 | 아이템마다 슬롯이 있어 수집한 모드(소형 ScriptableObject 같은 것)를 끼움 |
| 세트 보너스 | 같은 시리즈 3~4개 착용 시 세트 효과 발동 (예: 불 세트 → 화상 데미지 +30%) |
| 등급 | 일반 → 강화 → 레어 → 유니크 (드롭 및 제작) |

### 퍼즐 설계

- 각 던전은 전투 + 퍼즐이 70:30 비율 (일부 던전은 퍼즐이 더 많음)
- 퍼즐: 물리 법칙 이용 + 원소 속성 조합. 공을 벽에 튀겨 스위치 맞추기 등
- **시간 제한 퍼즐**: 제한 시간 안에 여러 스위치를 순서대로 — 반복 연습 후 패턴 숙지
- 모든 퍼즐은 **"실패해도 아프지 않다"** — 리셋이 빠르고 패널티 없음

### 레벨 디자인

- 던전마다 독특한 테마 + 전용 원소/퍼즐 메커닉
- 중심 테마를 가르쳐주는 "튜토리얼 방" → 점점 복잡하게 응용하는 구조
- 보스는 해당 던전의 테마를 집대성 (퍼즐 + 전투를 동시에 요구)

## 플레이어가 사랑하는 이유

1. **읽을 수 있는 전투**: 예고가 명확해서 "내 실수"임을 느낌
2. **장비 조합의 깊이**: 수천 개의 모드 조합 → 장기적 목표
3. **퍼즐과 액션의 조화**: 지적 만족과 반응 속도 둘 다 요구
4. **세계관의 메타적 재미**: 게임 속 게임(CrossWorlds)이라는 설정

## OnionCat 적용 포인트

### 1. 텔레그래프 철학 검증

CrossCode가 증명: 히트박스를 미리 보여줘도 게임이 쉬워지지 않음. 오히려 "읽었는데도 피 못했다" → 다음엔 성공 → 성취감. OnionCat의 노랑/빨강 텔레그래프 시스템이 올바른 방향.

### 2. 원소 시스템의 깊이와 비용

CrossCode는 5원소에 전환 UI까지 만들었다. OnionCat의 속성(불·얼음·전기) 3개는 딱 적당한 규모. **속성 스택과 콤보(젖음+전기→감전, 냉기+격파 등)** 가 CrossCode 원소 교호 작용과 유사 — 이 복잡도가 플레이어가 "발견"하는 재미를 주므로 UI 설명은 최소화해도 됨.

### 3. 모드 슬롯 → 효과 슬롯 대응

CrossCode의 모드 시스템(아이템에 작은 효과 슬롯)은 OnionCat v4 장비의 효과 조합과 구조가 같음. 핵심 차이: CrossCode는 파밍·제작 기반, OnionCat은 런 기반 드래프트. **세트 보너스 발동 임계값(3~4개)** 은 2/4/6/8단계를 쓰는 OnionCat보다 낮음 → 짧은 런에서 세트를 "느끼게" 하려면 2단계 첫 보너스가 체감되어야 함을 시사.

### 4. 퍼즐 실패 패널티 없음

CrossCode의 퍼즐은 실패해도 바로 리셋. OnionCat의 쌍둥이 스위치 같은 2인 기믹도 실패 시 즉시 재시도 가능 + 패널티 없음이 좋음. 향후 기믹을 추가할 때 "실패 → 빠른 재시도 → 학습" 사이클 유지.

### 5. 던전 테마 = 능력 교육

CrossCode 각 던전이 새 원소/메커닉을 가르치는 구조. OnionCat의 각 스테이지(정원·도시·탑 등)도 **해당 스테이지에서만 나오는 장비/적 패턴** 을 중심으로 설계하면 자연스러운 학습 곡선이 생김.
