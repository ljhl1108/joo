## 핵심 메카닉

### 1. 네일(Nail) 근접 전투 시스템
- 기본 공격: 좌/우/위/아래 4방향 슬래시 (방향키 + 공격 입력)
- 에너지(Soul) 시스템: 적 타격 시 Soul 충전 → 힐링 또는 스펠에 소비
- **탄력 점프**: 적을 아래로 내리치면 자동 바운스 → 이동과 공격이 일체화

### 2. 게임 감각 (Game Feel)
- **히트스톱**: 적 타격 시 2~4프레임 정지 → 임팩트 극대화
- **사운드 레이어링**: 히트 효과음 3개를 랜덤 피치로 재생 → 단조롭지 않은 타격감
- **화면 흔들림**: 강한 적 피격/보스 등장 시 Cinemachine 기반 트라우마 쉐이크
- **먼지 파티클**: 이동, 착지, 공격마다 백색 먼지 파티클 → 움직임 가독성 향상

### 3. 침묵의 내러티브 (환경 스토리텔링)
- 대화 최소화: NPC는 몇 마디만 함, 세계관은 아이템 설명·환경으로 전달
- 고독감과 신비로움이 핵심 감정 → 시각 디자인과 사운드가 스토리를 대체

### 4. 보스 전투 설계 원칙
- 보스별 완전히 다른 공격 패턴 (총 47개 이상의 보스)
- **텔레그래프 명확성**: 붉은 빛, 자세 변화, 사운드로 예고 → 플레이어가 반응할 시간
- **2페이즈 이상**: 보스 체력 특정 구간 돌입 시 패턴 변화 → 긴장 유지
- **공정한 죽음**: 패턴을 익히면 무조건 클리어 가능한 설계 (RNG 의존 최소화)

### 5. 참신한 이동 메카닉
- 더블 점프 (모나크 날개): 기본 이동에 깊이 추가
- 대시: 짧은 무적 시간 포함 → 패리 대체 탈출기
- 월슬라이드/월점프: 수직 이동 표현력 확장

## 플레이어들이 사랑하는 요소

1. **타이트한 조작감**: 입력 즉시 반응, 지연 없음
2. **보스 디자인**: 각 보스마다 고유 음악·비주얼·스토리 → 기억에 남는 존재감
3. **분위기**: 우울하고 고독한 세계, 픽셀 아트의 완성도
4. **발견의 기쁨**: 숨겨진 방, 비밀 보스, 예상 못 한 연결
5. **Charm 시스템**: 수십 개의 참 중 4개만 장착 → 매 런마다 빌드 다양성

## OnionCat 적용 포인트

### 근접 타격감 레퍼런스 (Cat 캐릭터)
- **네일 바운스 → OnionCat 슬래시 리바운드**: Cat이 180도 슬래시를 적에 맞히면 작은 킥백으로 뒤로 밀림. 타격감과 동시에 이동 리듬 생성.
- **히트스톱 값**: Hollow Knight 수준의 3~5프레임 히트스톱이 픽셀아트 2D에 최적. OnionCat도 동일 범위 목표.
- **방향 슬래시 설계**: Cat의 180도 슬래시가 Up/Left/Right 3방향으로 나뉘는 것과 유사 구조. 방향키 입력에 따라 판정 위치 이동.

### 보스 전투 설계 (Enemy 적용)
- **2페이즈 보스 필수**: HP 50% 이하에서 패턴 변화. 근접 약점 보스가 2페이즈에서 원거리 약점으로 전환 → 두 플레이어 역할 교체 요구.
- **텔레그래프 명확성**: 근접 약점 적은 붉은 오라, 원거리 약점 적은 파란 오라로 약점 타입 시각 표시.

### 참 시스템 → 업그레이드 선택 UI
- Hollow Knight의 Charm 슬롯 시스템: 제한된 슬롯에 다양한 조합 → OnionCat의 업그레이드 선택에서 "Cat 전용 슬롯 2개 + Onion 전용 슬롯 2개 + 공유 슬롯 1개" 구조 참고 가능.

### 환경 스토리텔링
- 대화 없이 고양이 표정 변화 + 소리로만 스토리 전달하는 Hollow Knight 방식이 OnionCat의 "고양이와 양파 대화 없이 협동" 컨셉과 정확히 일치.
