## 핵심 메커니즘

### 세 자아 시스템 (Three Parallel Selves)
- 플레이어는 **다른 평행 세계의 Maya** 3명을 동시에 운용
- 각 Maya는 자신만의 세계(바이옴)·무기·능력을 보유
- **Fusion**: 셋 중 둘을 합치면 혼합 캐릭터 탄생 → 각자의 능력 조합
  - 예: Kera(근거리 런처, 공중 콤보) + Naira = 합친 플레이스타일
- 한 번에 하나의 Maya로 플레이, 나머지는 대기

### 전투 구조
- 슬래시 + 회피 + 특수기 기반 근접/원거리 혼합
- 개발사 Brawlout 경험을 살린 콤보·히트스톱 감각
- 공중 콤보: 소형 적을 공중으로 띄워 추가 타격

### 성장 (Amplifiers)
- 런 중 획득하는 강화 아이템 = **Amplifiers**
- 세 Maya 각각 독립 강화 → 세 명의 빌드가 달라짐
- 허브에서 영구 업그레이드 해금

### 로그라이트 구조
- 각 런의 시작점(세계)이 다를 수 있음
- 중간에 죽어도 허브 업그레이드는 유지

## 플레이어들이 열광하는 것

- **합치기의 재미**: 어떤 두 Maya를 합칠지 선택하는 메타 게임
- **세 가지 플레이스타일**: 한 판에 세 종류의 전투를 경험
- **콤보 타격감**: Brawlout DNA의 반응성 있는 공격 느낌
- **빌드 다양성**: 세 캐릭터가 각자 다르게 성장하는 조합

## OnionCat 적용 포인트

| 아이디어 | 설명 |
|---------|------|
| **하나의 몸, 두 가지 역할** | Trinity Fusion은 셋이 "한 번에 하나"만 활성화. OnionCat은 고양이+작물이 "동시에" 활성화 → 항상 협동이 필요한 더 강한 결합. 차별점을 명확히 보여주는 비교 사례 |
| **Fusion 개념** | 두 플레이어가 "합동기"로 하나의 대형 공격을 내는 현재 메커니즘이 Trinity Fusion의 Fusion과 의미적으로 같음 → 연출을 더 "합체" 느낌으로 강화할 여지 |
| **능력 합성** | 고양이 장비 + 작물 장비 조합에서 "세트 보너스"가 발동하는 것이 Amplifier 조합과 유사. 세트 보너스 UI에서 "고양이 ♥ 작물" 연결 시각화 가능 |
| **캐릭터별 성장 독립성** | 고양이·작물 각자 다른 장비 슬롯을 가지는 현재 구조가 이미 올바름. 단, 보상 선택 시 "지금 어느 쪽이 더 약한가"를 보여주는 UI 힌트 → Trinity Fusion 허브처럼 |
| **Brawlout 타격감** | 적을 공중에 띄워 추가 타격하는 콤보 → OnionCat 고양이 특수 공격(도약 덮치기·착지 기절)과 같은 맥락. 띄우기 → 추가 히트 → 낙하 충격의 타격감 연출에 집중 가능 |
