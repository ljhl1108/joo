# Post Void

리서치 날짜: 2026-10-03

- **장르**: 극단적 미니멀리즘 FPS 로그라이트
- **개발사**: YCJY Games (스웨덴 인디)
- **출시**: 2021

- **플랫폼**: PC

## 핵심 시스템

### 게임 루프
- **목표**: 각 방 안의 모든 적을 죽이기 전에 Idol(머리 위 체력계)이 0이 되면 즉사
- Idol은 시간이 지남에 따라 자동으로 감소 — 적을 죽이면 충전
- **살해 속도가 곧 생존** — 멈추는 순간 죽는다

### 미니멀 디자인 철학
- 전체 게임이 약 **20~30분** 런으로 완료
- 해상도: 512×288 픽셀, 극도로 low-fi 비주얼
- 색상은 극단적으로 제한되고 사이키델릭 — 판독성이 아니라 **혼돈감이 의도적**
- 총기는 단순, 업그레이드는 런 중 무기 교체뿐
- 적 디자인: 빨간 실루엣, 하얀 배경 — 읽기 쉽게

### 게임 피드백
- 적 피격 시 전체 화면 붉은 플래시
- 총격 시 화면 전체가 흔들림
- 아이돌 체력 낮으면 붉은 비네트 → 위기감 전달
- 사운드: 반복적이고 강박적인 루프 — 심리적 압박

## 플레이어가 사랑하는 것

1. **극단적 흐름(Flow State)**: 멈추면 죽으므로 반사적으로 움직이게 됨
2. **3달러에 완전한 경험**: 가격 대비 완성도
3. **시각적 독창성**: 아무도 이런 식으로 만들지 않음 — 기억에 남는 비주얼
4. **빠른 런**: 죽어도 30초 만에 새 런 시작
5. **규칙의 명확함**: 아이돌을 채워라, 이게 전부

## OnionCat 적용 포인트

### 1. "죽을 것 같은 느낌"이 핵심 재미
Post Void는 항상 위기감을 준다. OnionCat에서 적이 많을 때 체력이 위험 수준이면:
- 화면 비네트 효과 (HitFeelSettings.asset에 추가)
- BGM 필터 변경 (저역대 부스트)
- Cat 아이들 애니메이션을 부상 버전으로 교체

### 2. 적 처치로 자원 회복 → 전진 강제
Post Void의 "적 처치 = 생명 연장" 구조는 플레이어를 자연히 위험 속으로 끌어당긴다. OnionCat에서도:
- 적 처치 시 소량 HP 회복
- 또는 적 처치 시 스킬 쿨다운 감소 → "적극적 교전이 이득"

### 3. 미니멀 비주얼과 판독성
Post Void는 미니멀하지만 적(빨간 실루엣)과 배경(흰색)은 항상 구분된다. 픽셀아트 게임에서 **판독성 > 디테일**. OnionCat도 32PPU 환경에서 적이 배경에 묻히지 않도록 레이어/아웃라인 처리 필수.

### 4. 작은 규칙 + 큰 위기감
게임의 규칙은 단순하지만 위기감은 최대. OnionCat도 "특정 적은 근접만, 특정 적은 원거리만"이라는 단순 규칙을 **시각적 피드백**(색, 아이콘, 이펙트)으로 극대화하면 판단하는 재미 생성.

### 5. 빠른 런 사이클
Post Void는 한 런이 5~10분. OnionCat 목표 런 시간을 15~20분으로 잡으면:
- 죽어도 심리적 부담이 적음
- 일과 후 빠르게 즐기는 게임으로 포지셔닝 가능
- 업그레이드 선택 수를 3~4회로 맞추면 적당한 빌드 성취감
