# Deep Rock Galactic

리서치 날짜: 2026-09-30

## 기본 정보

- **개발사**: Ghost Ship Games (덴마크)
- **장르**: 협동 1인칭 슈터 / 액션
- **플레이어 수**: 1~4인 로컬/온라인 협동
- **출시**: Early Access 2018-02, Full Release 2020-05
- **공식 사이트**: https://www.deeprockgalactic.com/
- **Steam**: https://store.steampowered.com/app/548430/Deep_Rock_Galactic/
- **위키**: https://deeprockgalactic.wiki.gg/

## 핵심 메카닉

### 비대칭 클래스 시스템 (4종)
| 클래스 | 역할 | 고유 도구 |
|--------|------|-----------|
| Driller | 근거리/터널 굴착 | 드릴, 화염방사기 |
| Engineer | 진지 구축/지원 | 플랫폼 건, 포탑 |
| Gunner | 화력 지원 | 미니건, 집라인 |
| Scout | 정찰/조명 | 훅샷, 플레어건 |

- **역할 의존성**: 스카우트 없이는 자원이 안 보임, 드릴러 없이는 통로 못 뚫음 → 혼자서 모든 역할 수행 불가
- **수직 이동**: 클래스마다 이동 방식이 다름 (집라인/훅샷/드릴)
- **공통 목표 + 개별 기여**: 광물 채굴 목표는 동일, 기여 방식은 다름

### 절차적 동굴 생성
- 매 미션마다 다른 레이아웃 (재플레이성 핵심)
- 어둠 + 지형 파괴가 전술적 선택지 생성
- 3D 환경에서의 적 군집 → 모든 방향 경계 필요

### 적 웨이브 / 감염 시스템
- 미션 진행도에 따라 적 스폰 주기가 빨라짐
- 일부 적은 특정 클래스만 효과적으로 대응 가능
- 구조물 파괴 적(나나이트 스워머) vs 원거리 적(글루팟)

### 협동 강제 메카닉
- **소생(Revive)**: 혼자 부활 불가, 팀원만 가능
- **자원 공유**: 채굴된 광물은 팀 전체 카운터
- **양손 작업**: 자원 들고 있으면 무기 사용 불가 → 호위 필요
- **포탄 재보급**: 엔지니어 보급 플랫폼 필요

## 플레이어가 사랑하는 것

1. **Rock and Stone 문화**: `V` 키 "Rock and Stone!" 외침 → 실질적 커뮤니케이션 대체
2. **각 클래스 숙련감**: 드릴 각도 계산, 훅샷 궤적 등 숙련도 상승이 체감됨
3. **운영 협력**: "내가 집라인 깔게, 너 먼저 건너" 같은 즉흥 협력 유발
4. **절차 생성 + 어둠**: 매번 새로운 공간 탐색 느낌
5. **DRG = "for Karl"**: 유머 있는 게임 문화 (팬덤 참여감)

## OnionCat 적용 포인트

### 역할 분담 설계 힌트
- DRG는 "클래스가 서로 없으면 안 되는 구조"를 만들어 협동을 강제함
- OnionCat: 고양이(근접)가 없으면 방패형 적 못 뚫고, 양파(원거리)가 없으면 날아다니는 적 못 잡는 구조 → **적 설계로 협동 강제**가 핵심
- "일부 적은 근접에만 약하고, 일부는 원거리에만 약하다" 규칙이 DRG의 클래스 의존성과 같은 원리

### 역할별 이동 차별화
- DRG에서 Scout은 훅샷으로 수직 이동, Driller은 뚫고 지나감
- OnionCat에서 고양이는 대쉬(무적)로 적 군중 통과, 양파는 방패로 투사체 막기
- 이동 + 생존 수단이 클래스마다 다를수록 플레이 감각 차별화됨

### "혼자 완결되지 않는" 상황 설계
- DRG: 자원 집어들면 총을 못 씀 → 반드시 다른 플레이어가 커버
- OnionCat에 적용: 고양이 대쉬 쿨다운 중 양파 방패가 커버, 양파 조준 중 고양이가 이동 → **쿨다운 타이밍을 맞추는 협동 리듬**

### 픽셀아트 게임에서의 미니맵
- DRG: 3D 공간이어도 팀원 위치 공유가 매우 중요
- OnionCat: 방 탐색 시 고양이(이동)와 양파(원거리 엄호) 역할 분리 → 미니맵이나 방 구조가 이 역할 분리를 지원하도록 설계

### 소생 시스템 힌트
- DRG의 소생 메카닉은 "팀원을 버리면 안 된다"는 긴장감 제공
- OnionCat: 한 명이 쓰러지면 나머지로 살려야 하는 `Coop_Revival_System` 이미 설계됨 → 이 순간의 "혼자 생존" 위기감이 DRG와 동일한 드라마
