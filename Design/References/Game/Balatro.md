## 핵심 메카닉

### 런 구조 — Antes & Blinds
- 1런 = 8개의 **Ante(막)** 로 구성
- 각 Ante = 3개의 **Blind**: Small Blind → Big Blind → Boss Blind
- Boss Blind마다 **특수 패널티** 존재 (특정 패 점수 0, 카드 거꾸로 보임 등)
- 각 Blind에서 **목표 점수 이상**을 내야 통과
- Ante 8 클리어 = 런 성공

### 점수 공식
```
점수 = Chips × Multiplier
```
- 패 유형(페어, 플러시 등)이 기본 Chips + Mult 결정
- 카드 강화, Joker 조합으로 폭발적으로 증가 가능
- 최고 점수가 수백만, 수억까지 오름

### Joker 시스템 — 핵심
- 최대 5개의 Joker 슬롯 보유
- Joker: 조건 충족 시 점수 보너스를 주는 패시브 카드 (150종 이상)
- 예: "페어 낼 때마다 Mult +4", "첫 핸드가 하이카드면 Chips ×10"
- Joker들이 **서로 시너지**를 이룰 때 극적인 폭발 발생
- 같은 Joker 조합도 덱 구성에 따라 완전히 다른 플레이

### 소모품 시스템
- **Tarot Cards**: 덱 카드 강화, Joker 복사, 슬롯 확장 등
- **Planet Cards**: 특정 패 유형의 기본 Chips/Mult 영구 강화
- **Spectral Cards**: 희귀 특수 효과 (카드 파괴 후 강화 등)

### 샵 구조
- 각 Blind 통과 후 샵에서 구매 가능
- Joker, 소모품, 바우처(영구 업그레이드), 부스터 팩 판매
- 금화 관리가 중요 (이자 시스템: 남은 금화 5개당 $1 이자)

## 플레이어가 좋아하는 것

1. **"빌드가 터지는 순간"**: 이전까지 낮은 점수 → 특정 시너지 완성 → 억 점수 폭발
2. **극도로 간단한 규칙**: 포커 패를 내는 것 뿐인데 무한한 깊이
3. **런마다 완전히 다른 전략**: 어떤 Joker를 만나느냐에 따라 덱 방향이 달라짐
4. **FOMO 없는 페이스**: 시간제한 없음, 천천히 생각하고 결정 가능
5. **1인 개발자의 작품**이라는 감동 요소 (완성도 대비 팀 규모)

## 핵심 게임 디자인 원칙

### 1. 조합의 폭발성 vs 예측 가능성
- 시너지 발생이 예측 가능하게 설계됨 (텍스트 설명이 명확)
- 플레이어가 "아 이 두 개 합치면 터지겠다" 예측하고 실행하면 실제로 터짐
- **"느껴지는 실력"** 설계의 교과서

### 2. Ante 별 난이도 곡선
- Ante 1~3: 학습 구간 (Joker 몇 개, 기본 파악)
- Ante 4~6: 빌드 완성 구간 (시너지 확정)
- Ante 7~8: 실력 검증 구간 (보스 패널티 대응)
- 매 Ante마다 목표 점수가 기하급수적으로 증가 → 반드시 빌드 업 필요

### 3. "가중치 랜덤" 설계
- Joker 희귀도(Common/Uncommon/Rare/Legendary) 가중치 샘플링
- 샵 콘텐츠가 랜덤이지만 완전 랜덤이 아닌 가중치로 조절
- 희귀 Joker는 적게 나오되 나올 때 큰 보상 → 텐션 유지

### 4. 패배가 의미있는 설계
- 런 실패 후 발견한 "이 조합 좋았는데" → 다음 런에 적용
- 영구 해금이 없어도 **지식과 경험**이 축적됨
- "다시 한 판만"을 유발하는 핵심 루프

## OnionCat 적용 포인트

### 1. 업그레이드 시너지 설계
Balatro의 Joker처럼, OnionCat 아이템도 단독 효과보다 **조합 시너지**가 핵심이 되게 설계.
- Cat 아이템 A + Crop 아이템 B = 특수 시너지 발동
- 예: "Cat이 대시 후 슬래시 시 Crop의 다음 투사체가 2배 데미지" 시너지 아이템
- 단순 스탯 업 아이템보다 "둘이 맞추면 터지는" 조합 아이템이 기억에 남음

### 2. Antes처럼 난이도 곡선 설계
각 던전 층마다 요구 조건 (방 수, 보스 난이도)을 **기하급수적으로** 증가시키되,
플레이어의 빌드도 층이 올라갈수록 강해지는 균형 유지. Ante 1~3 = 층 1, Ante 4~6 = 층 2 등 대응.

### 3. Boss Blind 패널티 → 보스방 변형 규칙
보스마다 고유 패널티를 추가. 예:
- "이 방에서는 Cat의 대시가 비활성화" → Crop이 방어 주도
- "적이 모두 근접 면역" → Cat 슬래시 의미없음, Crop 원거리 집중
- 규칙이 명확하게 사전 고지되어야 불공평감 없음 (Balatro처럼 텍스트로 명시)

### 4. 이자 시스템 → 골드 관리
샵에서 골드를 남기면 이자 받는 시스템. OnionCat 상점에서도:
- 남은 골드 x개당 다음 상점에서 보너스 아이템 등장
- "지금 살 것인가 vs 아껴서 나중에 선택지 늘릴 것인가" 전략 선택

### 5. 1인 개발의 교훈
- **핵심 메카닉 1개를 극도로 다듬기**: 포커 패를 내는 것 하나로 모든 것을 표현
- OnionCat도 "Cat 슬래시 + Crop 사격"이라는 핵심 2가지만 극도로 다듬는 것이 먼저
- 콘텐츠 양보다 **조합의 깊이**가 리플레이성의 열쇠

### 6. 명확한 텍스트 UI
Balatro는 모든 Joker 효과가 텍스트로 명확히 설명됨 ("조건 충족 시 Mult +X").
OnionCat 아이템도 효과 설명이 직관적이어야 함: "Cat이 슬래시할 때마다 Crop 투사체 크기 +10%"
