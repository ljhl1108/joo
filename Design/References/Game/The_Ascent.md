# The Ascent

리서치 날짜: 2026-10-26

## 기본 정보

- **개발**: Neon Giant (스웨덴, 12인 소규모 팀)
- **장르**: 쌍포신 슈터(twin-stick shooter) + 액션 RPG
- **출시**: 2021년 7월 (PC/Xbox), 2022년 3월 (PS)
- **공식 사이트**: https://www.theascent.game/
- **Steam**: https://store.steampowered.com/app/979690/The_Ascent/

## 핵심 시스템

### 쌍포신 슈터 + 레벨 기반 RPG 혼합

- WASD(왼쪽 스틱)으로 이동, 마우스(오른쪽 스틱)로 조준 — OnionCat의 양파와 거의 동일한 입력 구조
- 레벨업 시 능력치 포인트 자유 배분 (몸통, 팔, 다리, 뇌 등)
- 다양한 무기 타입: 피스톨/소총/샷건/에너지/헤비 → 각각 적 취약점이 다름

### 커버 시스템 (3-line shooting)

- **낮은 조준**: 기본 이동 높이에서 사격 (장애물 뒤에서 쪼그린 상태)
- **높은 조준**: 오른쪽 트리거 (RT)를 누르면 캐릭터가 일어서 장애물 위로 사격
- 실제로는 높은 조준을 하면 적에게도 더 많이 노출됨 → 위험과 이득의 균형
- 단순한 2D 탑다운인데 "올라서기" 하나로 전투 깊이를 크게 늘림

### 코옵 (1-4인 로컬/온라인)

- 4인 코옵까지 지원, 각자가 완전히 독립된 캐릭터 (OnionCat의 1인 공유와는 다름)
- 호스트 기준 레벨이 조정되지만, 레벨 차이가 커지면 언더레벨 플레이어가 상당히 힘듦
- 로컬 코옵은 분할화면 대신 화면을 공유하며 서로 가까이 있어야 함
- 코옵 경험의 핵심은 "서로 다른 빌드가 시너지를 내는 순간"

### 타격감 (게임 필)

The Ascent가 특히 호평을 받는 부분:

- **임팩트 프레임**: 총기 반동, 화면 흔들림, 적 히트 리액션이 정밀하게 조율됨
- **피해 숫자**: 크고 다양한 색상의 피해 표시 (크리티컬이면 더 큼)
- **분위기 밀도**: 네온 조명, 비, 군중, 광고판 — 전투 외 배경이 전투감을 높임
- **사운드 레이어링**: 총성 + 환경음 + 적 반응음이 겹쳐 "세계가 살아있다"는 느낌

## 무엇이 플레이어를 열광하게 만드는가

1. **아름다운 세계관**: 소규모 팀(12인)이 만든 것으로 믿기 어려울 정도의 시각적 밀도
2. **즉각적이고 쾌감 있는 전투**: 총기마다 완전히 다른 타격감, 적이 날아가고 피가 튀는 연출
3. **코옵의 카오스**: 4인이 모두 다른 총을 쏘는 화면의 폭발적 시각 경험
4. **루트루프**: 전리품이 끊임없이 나오고, 새 장비를 끼면 즉시 변화를 체감

## OnionCat 적용 포인트

### 1. 높이 차이를 활용한 2D 탑다운 전투 깊이

The Ascent의 "높은 조준(RT)" 메카닉은 2D 탑다운 게임에서 Z축 없이도 높이를 활용한 사례.
OnionCat에서:

- 현재 "구덩이(Pit)" 시스템이 이미 높이 차이를 활용 중
- 추가로 "장애물을 넘어 쏘기" 메카닉을 고려 가능 — 양파 씨앗이 낮은 벽은 통과, 높은 벽은 막힘 식
- 고양이 대쉬로 장애물 너머로 이동 후 측면 공격 — 전술적 포지셔닝의 깊이

### 2. 타격감 체크리스트 (The Ascent 기준)

OnionCat의 HitFeelSettings를 보완할 때 참고:

| 요소 | The Ascent | OnionCat 현재 | 개선 방향 |
|------|-----------|-------------|---------|
| 적 히트 리액션 | 몸이 방향에 따라 밀림 | Directional_Hit_Response ✓ | 각도별 튕김 방향 개선 |
| 피해 숫자 크기 | 크리티컬 시 더 큼 | Floating_Damage_Numbers ✓ | 크리티컬 숫자 크기 강조 |
| 총기 반동 | 발사마다 화면 미세 흔들림 | Cinemachine_Screen_Shake ✓ | 할퀴기 타격 시 미세 진동 |
| 적 피격 파티클 | 혈흔 + 파편 | Pixel_Art_VFX ✓ | 적 종류별 파티클 차별화 |

### 3. 코옵 장비 전략의 다양성

The Ascent에서 4인 코옵이 재미있는 이유는 각자 다른 빌드가 상호 보완.
OnionCat에서는 고양이·양파가 이미 완전히 다른 역할을 하지만, 이를 더 강조할 수 있음:

- "고양이가 냉기 세트, 양파가 감전 세트" → 젖음 상태에서 감전 2배 + 냉기 시너지
- 세트 조합이 "의도적으로 보완 관계를 형성"하도록 `CombatModifiers` 설계 점검
- 장비 화면에서 상대방 장비의 세트를 함께 보여주는 UI → "우리가 뭘 만들고 있나" 시각화

### 4. 소규모 팀 AAA 품질의 비결 — 집중

The Ascent는 12인 팀이 만든 작품인데, 비결은 "세계관 밀도 + 전투 타격감" 딱 두 가지에 집중.
OnionCat 개발 원칙으로 채택 가능:

- "협동 콤보" + "명확한 예고"의 두 기둥에 집중
- 시각적 밀도보다 "순간 순간의 결정이 의미있다"는 감각 우선

### 5. 피해 유형과 취약점 시각화

The Ascent는 적 유형마다 취약 피해 유형이 있고, UI 아이콘으로 표시.
OnionCat도 근접/원거리/속성 취약점이 있으므로:

- 적 체력 바 옆에 현재 상태이상 아이콘 + 취약점 아이콘을 작게 표시
- "이 적은 냉기에 약하다"를 암시하는 스프라이트/색상 디자인
