## 핵심 메커니즘

### 1. 리마스터링 (변신)
- 플레이어가 몬스터의 카세트 테이프를 모아 그 모습으로 변신
- 포켓몬처럼 "몬스터를 수집"하는 대신 **플레이어 자신이 몬스터가 됨**
- 사람 형태(자신)와 몬스터 형태(변신)를 오가며 전투
- 변신 중에도 "안쪽의 나"는 살아있고 고유 기술 존재

### 2. 퓨전 (Fusion) ★ OnionCat 핵심 참고
- 파티 2명이 **합체하여 하나의 몬스터**가 됨
- 합체 형태 = 두 몬스터의 모습이 섞인 하이브리드 외형
- **기술은 두 몬스터의 기술을 합산**: 각자가 보유한 기술에서 선택 가능
- **속성도 혼합**: 두 타입의 중간 속성이 적용됨 (불 + 물 = 증기)
- 합체 중 HP는 두 캐릭터의 HP를 합산 → **"공유 체력"**
- 합체 해제 시 HP가 다시 나뉨
- 2인 협동 모드: 두 플레이어가 각각 한 명씩 조종하다가 퓨전하면 **한 화면에서 한 캐릭터를 두 플레이어가 조종**

### 3. 속성 반응 시스템
- 12가지 속성 (불·물·공기·땅·전기·얼음·독·금속·나무·괴이·별·자성)
- 두 속성이 충돌하면 연쇄 반응 발생 — 예: 불 + 공기 = 폭발 (추가 피해), 물 + 전기 = 감전 (스턴)
- 단순 약점/저항을 넘어 **조합으로 새 효과 발생** → 전략 깊이

### 4. 전투 구조
- 턴제 전투 (실시간 아님)
- 각 캐릭터는 매 턴 "AP(행동력)"를 소비해 기술 사용
- AP는 기다리기/방어로 회복 — 타이밍 관리가 핵심
- 기술에 "공격·방어·버프·디버프·소환" 등 역할 분화

### 5. 세계관 & 스토리
- 현실 세계에서 이상한 섬으로 차원 이동된 사람들의 이야기
- 1950~70년대 감성 (레트로 카세트 테이프, 오래된 음악)
- **등장인물이 각자의 목적으로 같은 섬에 갇혀 협력**
- NPC들이 파티를 이루고, 각자 개성 있는 대사와 감정선 존재

### 6. 2인 협동 모드
- 로컬 / 온라인 협동 (2명)
- 한 명이 주인공, 다른 한 명이 파티원으로 플레이
- 퓨전 시 두 플레이어가 **동시에 조종** (P1은 왼쪽 기술, P2는 오른쪽 기술)
- 화면은 하나 — 카메라가 두 캐릭터를 같이 보여주거나 주인공 중심

## 플레이어들이 좋아하는 것

1. **퓨전 외형의 다양성** — 2마리의 조합이 수백 가지라 늘 새로운 모습
2. **속성 반응의 전략성** — "어떤 속성 조합이 이 적에게 효과적인가" 계산
3. **스토리 감성** — 레트로 감성 + 감정선 있는 캐릭터들
4. **2인 개발팀의 완성도** — 2명이 만들었다는 사실이 인디 개발자에게 특히 인상적
5. **퓨전이 "치트"처럼 강력하지 않음** — 단점(AP 소비 2배)도 있어 균형 유지

## OnionCat 적용 포인트

### A. 공유 체력의 "의미" — Cassette Beasts에서 배우기
- Cassette Beasts의 퓨전은 **HP 합산 + 하나처럼 행동** = OnionCat의 고양이+작물 구조와 동일
- 차이: Cassette Beasts는 퓨전/해제를 선택할 수 있음 → OnionCat은 항상 합체 상태
- **"합체 상태가 기본인 게임"**에서 플레이어들이 느끼는 것:
  - 한 플레이어가 실수하면 둘 다 다침 → 긴장감
  - 하지만 이것이 "이건 우리 함께의 캐릭터"라는 소속감을 만듦

### B. 비대칭 역할의 명확성
- Cassette Beasts 퓨전: P1 = 왼쪽 기술(주로 공격), P2 = 오른쪽 기술(주로 보조/방어)
- **역할 분화가 명확할수록 "내가 무엇을 해야 하는지" 초보도 알 수 있음**
- OnionCat: 고양이(이동·근접) vs 작물(원거리·스킬) — 이 분화가 직관적인지 계속 테스트 필요

### C. 퓨전 외형 → 장비에 의한 시각적 변화
- Cassette Beasts: 장비(카세트 조합)에 따라 외형이 완전히 달라짐 → 강한 "아이덴티티 감"
- OnionCat: 장비에 따라 고양이 무기·머리·몸이 바뀌고, 작물 종류가 바뀜
- **장비 교체 시 외형 변화를 더 뚜렷하게** 만들면 Cassette Beasts 같은 성취감 → 아트 과제

### D. 속성 반응 → 협동 콤보
- Cassette Beasts: 속성 조합으로 새 효과 발생 (1+1=새것)
- OnionCat: 고양이 + 작물 번갈아 치면 협동 콤보 → "1+1=새것"의 같은 개념
- **"번갈아 치기"가 얼마나 명확하게 보이는가?** 콤보 카운터나 시각 효과로 더 강조 가능

### E. 2인 개발팀 완성도 참고
- Bytten Studio 2명이 완성한 게임 → 작지만 완성된 게임의 좋은 롤모델
- 핵심 시스템(퓨전·속성·전투)에 집중하고 나머지는 과감히 쳐냄
- **OnionCat도 "핵심 2인 협동 느낌"을 완성하고 나머지 콘텐츠는 나중에**

### F. 세계관 접근법
- Cassette Beasts: 현실인들이 이상한 섬에 갇혀 → 각자 사연 있는 사람들의 연대
- OnionCat: 고양이와 작물이 함께 여행 → 이 조합이 왜 같이 있는지 감성적으로 설명할 여지

## 기술 메모

- Unity 2D 기반으로 제작된 것으로 추정 (2인 팀 고려)
- 퓨전 외형은 런타임 스프라이트 합성 — 두 몬스터 스프라이트를 레이어별로 합성
- 속성 반응 계산: 비트마스크로 간단히 구현 가능 (각 속성 = 1비트)
