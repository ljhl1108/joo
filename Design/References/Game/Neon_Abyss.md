## 핵심 시스템

### 전투 시스템
- 단일 무기 + 무제한 아이템 중첩 (이중 무장 없음)
- 무기 60종 — 유도 레이저, 부메랑, 폭발탄 등 예측 불가 패턴
- 회피+사격 중심, 빠른 페이스, 높은 스킬 상한선
- 탑다운 런앤건: 조작이 단순하지만 시너지로 깊이 창출

### 아이템 시너지 (핵심 설계 기둥)
- **무제한 중첩**: 패시브 아이템 상한 없음 → 시너지 폭발
- **명명 시너지 세트**: 특정 아이템 조합으로 발동 (예: Violent Suit, Forbidden Library)
- **예시**: 팝콘(폭발 총알) + 탄성 젤(반사 총알) = 튕기는 폭발
- **시각 피드백**: 아이템 누적에 따라 캐릭터 외형 변화
- 시너지 발견의 도파민 루프가 핵심 재미

### 해치몬 동반자 시스템
- 적 처치 시 알 드롭 → 5색 해치몬으로 부화 (핑키, 라이미, 틸리, 퍼플리, 아이보리)
- 자율 추종자: 패시브 피해 + 고유 능력 (눈덩이 스턴, 돈 수집, 하트 드롭 등)
- **진화**: 색당 4~8종, 특정 조합으로 23종 슈퍼 해치몬 해제
- 진화 레시피 학습 가능 → 장기 목표 제공, 포켓몬식 수집 욕구 자극

### 방/던전 구조
- 텔레포터 룸(연결 허브), 전투 룸, 보스 룸, 아이템 룸, 상점, 챌린지 룸
- 7개 메인 층 + 잠금 해제 가능한 비밀 층 (악마/천사 방 등)
- 환경 위험 요소: 가시, 반사 플랫폼, 사라지는 발판
- 미니게임 방 (클로 머신, 선물 방)

### 보스 설계
- **2페이즈**: 체력 40~60% 지점에서 패턴 진화
- 페이즈 2: 속도 증가 + 공격 조합 변화
- 현대 집착(테마별 고유 메커닉) + 유머 요소
- 잠금 해제로 고난이도 변형 보스 및 새 최종 보스(아레스, 아테나, 프로메테우스) 추가

### 로그라이크 & 메타 진행
- 사망 시 아비스 바로 리스폰, 런 중 획득한 모든 것 소실
- **Faith Gems**: 런 간 영구 통화 → 6페이지 해금 트리 (새 아이템/방/보스)
- 잠금 해제 콘텐츠가 던전 아이템 풀과 방 로테이션 변화
- 런 실패도 메타 진행 → "실패 = 진전" 마인드셋

## 플레이어가 좋아하는 점
1. **시너지 도파민 루프**: 아이템 조합 발견과 "말도 안 되는 무기" 만들기의 쾌감
2. **동반자 기대감**: 포켓몬식 해치몬 부화 흥분감, 진화 레시피 학습 동기
3. **증분 메타 진행**: 런이 실패해도 Faith Gems로 콘텐츠 해금 → 목적의식 있는 런

## OnionCat 적용 포인트

### 1. 이중 캐릭터 시너지 = 아이템 시너지
Neon Abyss의 무제한 중첩+시너지 발상을 듀오 협동에 확장:
- **듀오 시너지**: Cat이 "실드 오라" + Crop이 "투사체 증폭" 보유 시 → Crop 투사체가 Cat 방패에 반사되어 강화
- **타이밍 시너지**: Cat 대쉬 직후 Crop 조준사격 적중 = 양쪽 2배 피해
- 시너지 발견의 재미를 2인 협력 코디네이션으로 이식

### 2. 비대칭 동반자 시스템
해치몬 아이디어를 역할별 분리로 재해석:
- **Cat 동반자**: 근접 특화 (대쉬 시 공격, 온히트 디버프 적용)
- **Crop 동반자**: 원거리 특화 (발사 시 추가 공격, 유도 효과 부여)
- **듀오 진화**: 두 캐릭터 시너지 아이템 보유 시 파트너 공격 발동하는 협동 변형 진화
- 동반자는 기계적 필수품이 아닌 "획득 보상" 감각 유지

### 3. 방 구성으로 협력 강제
Neon Abyss의 층별 적 구성+메타 해금 구조를 OnionCat에 적용:
- 근접 약점 적이 Crop의 시야선 안으로 Cat이 유인해야 하는 방 배치
- 보스 페이즈 1 = Cat의 180° 슬래시 범위 활용, 페이즈 2 = Cat 수비+Crop 견제 분리 포지셔닝
- 방이 협력을 가르치고, 보스가 숙련도를 테스트

### 4. 퍼마데스 완화 = 공동 메타 진행
Faith Gems 시스템의 "실패 = 진전" 감각이 2인 협동에서 더 중요:
- 두 플레이어 공유 메타 통화 → 런 실패에도 함께 성장
- 해금으로 새 아이템/방/보스 추가 → 매 런이 다른 경험
- 퍼마데스의 감정적 무게를 파트너와 함께 나누는 진전으로 상쇄

## 핵심 인사이트
Neon Abyss의 성공 공식: **시너지 발견 = 핵심 재미**(부가 콘텐츠 아님). OnionCat은 이를 _듀오 시너지_ 로 이식 — 아이템 빌드 조율과 타이밍 협동으로 도파민 루프 구현. 또한 단일 무기+아이템 중첩 설계가 복잡한 무기고보다 효과적임을 증명 → OnionCat의 비대칭 입력(Cat 슬래시, Crop 마우스 조준)도 충분히 복잡하므로, 추가 입력 버튼 대신 시너지 아이템과 방 설계로 전략적 깊이 추가할 것.
