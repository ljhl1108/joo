## 핵심 시스템

### 무기 = 클래스

Victor Vran의 가장 큰 특징: **플레이어가 클래스를 "고르는" 게 아니라 무기를 들면 그게 클래스**다.

- 무기 2개를 슬롯에 장착하고 실시간으로 교체
- 각 무기는 고유한 기본 공격, 특수 공격, 최대 충전 공격을 가짐
- 무기 타입: 대검, 망치, 채찍, 拳총, 샷건, 번개 망치, 낫 등
- 같은 캐릭터인데 무기를 바꾸면 완전히 다른 조작감 → "빌드 다양성"이 클래스 선택 없이도 성립

### Fate Cards (페이트 카드) — 리스크/리워드

- 플레이어가 **자발적으로 단점을 추가**하는 카드 슬롯 (최대 3개)
- 예: "근접 적에게 50% 더 받음" → 대신 경험치 +30%
- 아무 카드도 안 써도 됨 — 선택지가 늘어날수록 단점이 커지는 대신 보상 증가
- 효과: 도전 욕구 자극. 초보는 카드 없이, 숙련자는 여러 장으로 더 빠른 성장

### Destiny System (데스티니)

- 런타임에 목표를 완수하면 영구 보너스 획득 ("오늘 첫 플레이에 보스 처치", "연속으로 100킬" 등)
- 로그라이트식 메타 성장 — 클리어와 무관하게 목표를 달성하며 조금씩 강해짐

### Overdrive (오버드라이브)

- 연속으로 적을 처치하거나 받은 피해 없이 싸우면 쌓이는 게이지
- 최대 적중 시 공격력·이동속도 대폭 상승
- 맞으면 초기화 — 위험 없는 플레이를 보상하는 구조

### 협동 2인 플레이

- 완전히 같은 캐릭터를 각자 조작 (비대칭 없음)
- 각자 무기·장비를 독립적으로 고름
- 체력을 공유하지 않고 각자 체력 — 사망 시 파트너가 부활 가능

## 플레이어들이 좋아하는 점

1. **무기 바꾸면 플레이가 확 달라짐** — 망치로 쾅쾅 치다가 채찍으로 적을 묶는 플레이로 전환
2. **페이트 카드로 도전 조절 가능** — 쉬운 클리어냐 도전적 클리어냐를 플레이어가 직접 결정
3. **이동이 중요한 전투** — 모든 공격을 피하면서 좋은 타이밍에 반격하는 패턴 명확
4. **많은 아이템인데 외우기 쉬운 구조** — 무기 타입만 알면 어떤 플레이인지 직감

## OnionCat 적용 포인트

### 1. 마법서 슬롯 차별화

Victor Vran에서 무기마다 고유 Q스킬·특수스킬이 있듯, **OnionCat 작물의 마법서(Q·W·E) 각각 발동 방식이 완전히 달라야 의미 있음**.
지금 쿨타임·범위 차이만 있다면:
- 1번 마법서: "즉발(빠름·범위 좁음)"
- 2번 마법서: "차지형(느림·강함)"
- 3번 마법서: "지속 배치형(설치 후 작동)"
→ 선택이 취향 문제가 되어 세트 보너스가 없어도 고르는 재미 생김

### 2. Fate Card → 물음표 방 패널티 디자인

OnionCat에 이미 있는 물음표 방 "일시적 손해 + 보상" 구조가 Fate Card와 같은 원리.
Victor Vran이 잘 된 이유: **플레이어가 직접 선택** → 억울함 없음.
OnionCat 물음표 방도 "피해 선택지(여기에 들어가면 이 패널티)"처럼 사전 고지 디자인 권장.

### 3. Overdrive → 협동 콤보 게이지 가속 구조

Overdrive는 "안 맞을수록 더 강해짐" 구조. OnionCat 협동 콤보는 "번갈아 때릴수록 게이지 오름".
맞지 않고 콤보를 이어가면 게이지 충전 속도 보너스(예: +20%)를 추가하면 Overdrive 느낌 가능.
숙련자는 무적 대쉬를 더 쓰고 더 빠른 합동기를 발동하는 플레이가 성립.

### 4. 무기 2슬롯 교체 → 고양이 무기 "서브 무기" 아이디어

지금 고양이는 무기 1개만. Victor Vran처럼 무기 2개를 교체 가능하게 하면 빌드 다양성 폭발적 증가.
단, 조작이 복잡해질 수 있으므로 **"서브 무기 = 특수 공격 형태 변경"** 정도의 제한된 적용도 가능.
