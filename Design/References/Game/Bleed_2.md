# Bleed 2

리서치 날짜: 2026-11-22

## 기본 정보

- **개발/퍼블리셔**: Bootdisk Revolution (Ian Campbell)
- **출시**: 2017년 2월
- **플랫폼**: Steam, PS4, Xbox One
- **공식**: https://store.steampowered.com/app/396350/Bleed_2/
- **장르**: 아케이드 액션 플랫포머, 불릿헬 요소
- **플레이어**: 1~2인 로컬 코-옵 (스토리·아케이드·챌린지 전 모드)

## 핵심 메커니즘

### 전투 3요소
1. **8방향 사격** — 이동과 완전히 독립. 뛰면서 뒤로 쏘기, 점프하며 아래로 쏘기 가능
2. **공중 대쉬 (Air Dodge)** — 무적 프레임이 붙은 대쉬. 불릿헬 패턴 회피 핵심
3. **반사 (Reflect)** — Wryn의 카타나로 적 투사체를 튕겨 돌려보냄. "파리"가 아니라 반사 궤적이 생기는 적극적 공격 수단

### 슬로우 모션
- 짧은 시간 동안 발동, 고밀도 패턴을 읽고 반응하는 여유 제공
- 쿨다운 방식, 남용 불가
- 초심자 보조 + 숙련자 고득점 도구로 이중 활용

### 반사 시스템 세부
- 적 투사체가 **색상**으로 구분 — 자신의 색에 맞는 투사체만 반사 가능 (코-옵에서 플레이어별 색 다름)
- 반사한 탄은 적에게 그대로 피해를 줌 → 보스 역이용의 쾌감
- 뮤테이터로 반사를 꺼서 난이도 상승 가능

### 보스 중심 설계
- 7개 스테이지 × 약 25보스 (일반 보스 + 미니보스)
- 스테이지마다 고정 보스 + 무작위 중간 보스
- 보스 패턴은 "여러 발 + 슬로우모션으로 반사 타이밍"을 염두에 두고 설계

### 코-옵
- 조이패드 1개 이상 필수
- 두 플레이어가 **다른 캐릭터** (Wryn + 해금 캐릭터)를 조종
- 각자 독립적인 대쉬와 반사를 사용 → 패턴 분담 가능
- 공유 HP 없음 — 개별 체력, 한 명이 죽어도 계속 진행 (부활 존재)

### 성장 / 해금
- 클리어 시 새 캐릭터 해금 (각자 다른 무기·능력)
- 데일리 챌린지, 아케이드 모드 (랜덤 레벨)
- 점수 랭크 시스템 — 피격 시 2단계 하락

## 플레이어들이 열광하는 것

- **반사의 타격감**: 아슬아슬하게 튕겨낸 탄이 보스를 맞추는 순간의 쾌감
- **빠른 판 구성**: 보스 하나가 2~3분, 짧고 집중적인 긴장감
- **슬로우 + 반사 콤보**: 슬로우를 걸며 반사를 성공시키는 숙련 표현
- **코-옵에서의 역할 분담**: 한 명이 회피 집중, 한 명이 반사 담당하는 자연스러운 협동

## OnionCat 적용 포인트

| 아이디어 | 설명 |
|---------|------|
| **패리 → 반사 쾌감 차이** | Bleed 2는 "막기"가 아니라 "돌려보내기"라 훨씬 적극적. OnionCat 패시브 실드도 단순 방어보다 반격 효과를 붙이면 쾌감 증가 |
| **색상 기반 패리** | 작물이 쏜 씨앗 색, 고양이 할퀴기 색을 적 약점 색에 맞추는 시각적 힌트로 활용 가능 |
| **코-옵 역할 분담** | Bleed 2는 "한 명은 근접, 한 명은 원거리"를 자연스럽게 강요. OnionCat도 고양이(근접)·작물(원거리)이 이미 이 구조 → 보스 패턴에 "근거리만 반사 가능한 탄", "원거리만 맞출 수 있는 약점" 추가 가능 |
| **슬로우 모션 활용** | 고난도 협동 타이밍을 맞출 때 짧은 슬로우(합동기 발동 직전 등) → 긴장·보람 |
| **보스 색상 텔레그래프** | 반사 불가 = 빨간 경고, 반사 가능 = 노란 경고 → OnionCat 텔레그래프 색체계(현재 노랑/빨강)와 의미 맞춤 가능 |
