# Deadlink

리서치 날짜: 2026-08-05

## 기본 정보

- **장르**: 사이버펑크 FPS 로그라이트
- **개발사**: Gruby Entertainment
- **출시 연도**: 2022 (얼리 엑세스) → 2023 (정식 출시)
- **공식 사이트**: https://deadlinkgame.com/
- **Steam**: https://store.steampowered.com/app/1676050/Deadlink/
- **장르 분류**: 1인칭 슈터 로그라이트 (3D FPS 관점이지만 2D 로그라이트 철학 완전 적용)

## 핵심 메카닉

### 1. 빠른 이동 + 사이버펑크 캐릭터
4명의 특수 요원 캐릭터, 각자 고유 궁극기와 어빌리티를 보유. Doom Eternal과 Risk of Rain 2의 교차점: 항상 이동하며 싸워야 생존. 정지 시 즉사에 가까운 난이도.
- 빠른 스트레이프 이동
- 대시 + 슬라이딩
- 이중 점프
- 벽 반사 이동

### 2. 피드백 시스템의 교과서
Deadlink의 가장 높은 평가 포인트: **타격감**과 **피드백**. 총알 히트 시 파티클, 사운드, 히트마크의 삼위일체. 적 처치 시 육중한 사망 애니메이션, 폭발 효과, 드롭 아이템 흩뿌리기. "이 게임의 총 쏘는 느낌이 AAA급"이라는 평가가 많음.
- 히트마크: 위치별 색상 변화 (일반/치명타)
- 적 사망: 사이버네틱 부품 흩뿌림 파티클
- 총기 반동: 화면 킥 + 카메라 흔들림 (CinemachineImpulse급)
- 폭발: 시간이 약간 늘어나는 히트스톱 적용

### 3. 업그레이드 시스템 — 무기 시너지 특화
런마다 무기 업그레이드 + 패시브 카드 조합. 특정 업그레이드 조합 시 시너지 발동 — Item_Synergy_System.md의 실제 상용 구현 사례. 탄약 유형 + 무기 종류 + 캐릭터 어빌리티 3종 조합으로 빌드 폭이 매우 넓음.

### 4. 적 다양성 — 역할 특화 적
원거리 저격 적, 근접 돌격 적, 방패 적, 자폭 적, 지원 적(힐러) 등 역할이 명확히 구분됨. **역할 기반 우선순위 결정**을 자연스럽게 유도 — "지금 누구를 먼저 죽여야 하는가?" 교전 계산을 플레이어에게 맡기는 구조.

### 5. 웨이브 + 이벤트 룸 구조
일반 전투룸 → 이벤트룸(상점/업그레이드/파쿠르 챌린지) → 보스룸 순환. 전투 외 룸에서 긴장감 해소 + 빌드 전략 수립. 
- 파쿠르 챌린지 룸: 이동 스킬을 테스트하는 선택지 룸
- 상인 룸: 크레딧으로 특수 업그레이드 구매

## 플레이어들이 좋아하는 것

- **타격감이 최고**: 총기 피드백이 FPS 장르 기준으로도 손에 꼽힘. 많은 리뷰가 "느낌" 위주로 호평.
- **빠른 페이스**: 생각할 틈 없는 초고속 전투가 중독성 있음.
- **4캐릭터 개성**: 각 캐릭터마다 완전히 다른 플레이스타일 → 리플레이성 보장.
- **사이버펑크 미학**: 비주얼 + BGM의 시너지. 로그라이트에 장르 테마 잘 녹임.

## OnionCat 적용 포인트

### 1. 타격감 공식 — 3중 피드백 법칙
Deadlink를 통해 배울 핵심: 히트 피드백은 반드시 **시각 + 청각 + 물리(카메라/히트스톱)** 세 가지가 동시에 발생해야 함. OnionCat 적용:
- Cat 슬래시 히트: 히트스톱(0.05s) + 금속음 SFX + 스파크 파티클 + 카메라 미세 흔들
- Crop 투사체 히트: 명중 파티클 + 피격 SFX + 적 스프라이트 플래시
- Feedback_System.md + Knockback_Stagger_System.md 동시 활용

### 2. 역할 기반 적 우선순위 → 협력 전술 강화
Deadlink의 역할 분리 적 디자인을 OnionCat에 적용: 
- **방패 적**: Cat 슬래시만 방패 파괴 가능 → Crop이 Cat에게 타깃을 알려줌
- **힐러 적**: 원거리 지원 위치 → Crop이 먼저 처리, Cat은 근접 적 차단
- **자폭 적**: 근거리 위험 → Cat 대시로 도주, Crop이 원거리 격퇴
- 역할 분담이 자연스럽게 언어로 이루어지게 유도

### 3. 파쿠르 챌린지 룸 → OnionCat 스킬 챌린지 방
Deadlink의 이동 테스트 룸 컨셉: OnionCat에서도 전투 없는 "협력 챌린지 방" 추가. Cat 대시 + Crop 쉴드를 동시에 사용해 장애물 통과하는 방. 보상: 희귀 업그레이드 또는 체력 회복.

### 4. 웨이브 시간 경쟁 — 클리어 등급 시스템
Deadlink처럼 룸 클리어 속도에 따른 등급(S/A/B/C) 표시. 빠른 클리어 시 추가 재화 보상. InGame_Timer_System의 룸 타이머 활용 + Run_Result_Screen에 클리어 등급 통계.

### 5. 적 처치 시 아이템 흩뿌리기 연출
Deadlink의 적 사망 시 부품 흩뿌림 파티클 → OnionCat 적 사망 시 씨앗/열매 파티클 흩뿌리기. Item_Drop_Pickup_System.md + Destructible_Props_System.md에 Burst 파티클 연동.
