# Heave Ho

리서치 날짜: 2026-11-28

## 기본 정보

- 개발사: Le Cartel Studio
- 출시: 2019년 8월 (PC)
- 공식 사이트: https://lecartelstudio.com/heavelho/
- Steam: https://store.steampowered.com/app/1051360/Heave_Ho/
- 게임플레이: 1~4인 로컬 협동 플랫포머

## 핵심 메카닉

### 공유 조작 / 분할 조작
- 각 플레이어는 자신의 **캐릭터 한 명**을 조작
- **L 트리거 = 왼손 잡기 / R 트리거 = 오른손 잡기**
- 아날로그 스틱으로 몸을 흔들어 동력 발생
- **핵심**: 혼자는 절대 목적지까지 못 감. 반드시 서로의 몸을 잡고 이어져야 함

### 물리 기반 협동
- 모든 캐릭터는 Ragdoll 물리 적용
- "잡기 → 흔들기 → 놓기"로 운동량 전달
- 한 명이 고정점에 매달리고 나머지가 그 몸을 잡고 스윙
- **연쇄 고리**: 플레이어 A → B → C → D가 고리처럼 연결되어 흔들리며 목표에 도달

### 목표와 실패
- 각 스테이지에 하나의 목표 위치가 있고, 모든 플레이어가 그곳에 도달해야 클리어
- 한 명이라도 추락하면 그 플레이어 사망 (부활은 체크포인트에서)
- 실패가 너무 치명적이지 않고 빠른 재시도 가능 → 웃음 유발 형 실패

### 커스터마이징
- 캐릭터 스킨 대량: 의상·모자·얼굴 등 수십 가지
- 처음부터 개방 (언락 없음) → 플레이 전 꾸미는 재미 즉시 제공
- 협동 로비 화면에서 같이 꾸미는 것 자체가 재미

### 스테이지 디자인
- 짧은 스테이지들 (1~3분): 성취감 사이클 빠름
- 고정점(쇠막대, 나무 등)이 명확히 보임 → 계획 세우기 쉬움
- 멀티플레이 인원이 많을수록 더 긴 체인 필요 → 인원별 난이도 자연 조절

## 플레이어들이 사랑하는 것

1. **즉각적 웃음**: 조작이 직관적이지 않아서 실패 자체가 웃김
2. **진짜 협동 필요**: 혼자서는 물리적으로 불가능한 구간 존재 → 협동이 형식적이 아님
3. **빠른 사이클**: 죽어도 금방 재시도, 클리어해도 금방 다음 스테이지
4. **소파 협동의 정수**: 같은 화면을 보며 소리치고 웃는 경험 집중 설계
5. **진입 장벽 없음**: 조작 버튼 2개 + 스틱 — 비게이머도 즉시 참여 가능

## 비교 분석: 공유 조작 접근법

## OnionCat 적용 포인트

### 1. "물리적으로 불가능한 혼자서" 느낌 강화
Heave Ho의 핵심 가치: 한 명이 절대로 못 하는 것을 둘이서 한다.
OnionCat도 이 원칙 유지 중이지만, 더 강조할 수 있는 순간들:
- 보스의 큰 공격 범위를 고양이가 막으면서 작물이 약점을 노리는 패턴
- 고양이가 근처에 없으면 작물 씨앗 사거리 밖인 적이 있는 방 배치
- 협동기가 없으면 절대 뚫을 수 없는 쉴드 보스

### 2. 실패 연출의 재미
Heave Ho는 실패(추락)가 아름다운 Ragdoll 연출로 웃기게 연출.
OnionCat에서 HP가 0이 되는 순간의 연출을 "처참하지만 귀엽게":
- 화분이 굴러 떨어지는 장면
- 고양이가 쓰러지며 작물이 "앗!" 하는 말풍선
- Game Over 직전 슬로우모션으로 마지막 순간 보여주기

### 3. 조작 단순화의 미학
Heave Ho는 버튼 2개로 모든 것. 비게이머도 참여 가능.
OnionCat에서 작물 조작(마우스+키보드)이 비게이머에게 복잡하게 느껴질 수 있음.
→ 양파의 기본 발사는 "마우스 클릭"만으로 완전히 작동하게 보장
→ Q/W/E 스킬은 추가 깊이지, 없어도 플레이 가능해야 함

### 4. 커스터마이징을 성취 보상 말고 초반부터
Heave Ho는 모든 스킨이 처음부터 개방됨 → 플레이 시작 전에 함께 꾸미는 재미.
OnionCat에서 현재 작물은 2단계·3단계에서 해금 — 이건 성취 보상으로 좋음.
하지만 고양이 외형(모자·리본·색깔)은 처음부터 여러 개 주면 첫 세션 경험 개선.
온실에서 선택하는 것 외에 "오늘의 고양이" 무작위 색깔만으로도 소소한 재미 가능.

### 5. 짧은 스테이지 → 짧은 방 단위
Heave Ho 스테이지 1~3분의 쾌감.
OnionCat 방도 하나하나가 짧은 도전이어야 함 (3~5분 이내 클리어).
특히 그려진 방에서 너무 긴 전투는 피로감 → 적 수 조절 (한 화면짜리 4~6마리 원칙 유지)

### 6. 잡기 → 조합기의 느낌
Heave Ho에서 연결 고리처럼 한 명이 다음 명을 잡아서 함께 움직이는 느낌.
OnionCat 협동기(합동기)를 발동하는 순간 — 고양이 등의 작물이 "함께 움직이는" 연출 강조.
예: 합동기 발동 시 작물이 고양이 쪽으로 몸 기울이는 짧은 애니메이션
