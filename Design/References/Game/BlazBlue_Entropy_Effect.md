# BlazBlue: Entropy Effect

리서치 날짜: 2026-10-25

## 기본 정보

- 개발사: 91Act (중국)
- 장르: 액션 로그라이트
- 공식 사이트: https://store.steampowered.com/app/2103470/BlazBlue_Entropy_Effect/
- Steam: https://store.steampowered.com/app/2103470
- 출시: Early Access 2022 → 정식 1.0 출시 2024년 2월 14일
- 플랫폼: PC (Steam), iOS/Android, Xbox Series X/S (BlazBlue: Entropy Effect X)
- 플레이어: 1인 또는 2인 협동 (온라인·로컬 코옵, 로컬은 2025년 코드명 Dead Cells 협업 업데이트에서 추가)

## 핵심 시스템

### 캐릭터 기반 액션
- BlazBlue 격투 게임 시리즈 캐릭터들 (Ragna, Noel, Jin 등)이 각자 고유 무브셋으로 등장
- 격투 게임 출신이라 캐릭터 간 조작감 차이가 매우 큼 — 로그라이트 안에서 "캐릭터 픽" 경험 제공
- HP와 SP(스킬 게이지)를 분리 관리: SP 소진 없이 기본기만으로도 진행 가능하지만 스킬을 효율적으로 쓰는 게 핵심

### 업그레이드 시스템
- 스테이지 사이 보상 선택: **3가지 중 1가지** (능력 트리, 패시브, 스탯 강화 등)
- 스테이지 내 이벤트 구역: HP 베팅으로 버프 획득 또는 포인트로 아이템·스탯 구매
- 강화가 빠르게 쌓이고 시너지가 폭발적 — "이 조합이 이렇게 강해?" 순간이 자주 옴

### 협동
- 2인 협동은 처음에 잠겨 있음 → "Pass The Torch" 퀘스트 완료 후 해금
- 지원 모드: Mind Training(일반 협동)과 Mind Trial(보스 러쉬)에서 2인 플레이 가능
- 리뷰어들은 협동이 자연스럽게 작동한다고 평가: "아이디어 자체가 잘 구현됨"
- 한 명이 쓰러지면 다른 플레이어가 구출하는 리바이벌 메카닉 존재

### 전투 디자인
- 리뷰어들이 공통적으로 꼽는 최강점: **전투 자체의 타격감과 액션성**
- 무적 프레임(i-frame) 활용이 중요 — 격투 게임 감각이 살아 있음
- 적의 공격 패턴을 읽고 파고드는 리듬이 명확

## 플레이어가 사랑하는 것

1. **캐릭터 개성** — 격투 게임 팬이라면 "그 캐릭터"를 로그라이트로 즐기는 팬서비스
2. **전투의 타격감** — 액션 중심 로그라이트 중 최상위권 전투 피드백
3. **빠른 런** — 단기간 집중 플레이에 적합한 런 길이
4. **강화 콤보 폭발** — 무작위 강화가 시너지를 이룰 때 강해지는 쾌감
5. **Dead Cells 협업** — 유명 로그라이트와의 크로스오버로 신규 캐릭터·스킨 추가

## OnionCat 적용 포인트

### 1. "일찍 잠그기" 협동 해금 설계
- 협동을 처음부터 열어주지 않고 퀘스트 조건(솔로 클리어)으로 해금한 것은 **싱글 플레이어 경험 보호** 목적
- OnionCat은 처음부터 2인 전제지만, "협동 기믹 방"처럼 단계적으로 고급 협동 요소를 해금하는 아이디어에 적용 가능
- **단계별 협동 튜토리얼**: 첫 런에서는 쌍둥이 스위치(2인 기믹) 방이 안 나오고, n번째 런 이후부터 등장하도록 하면 입문 부하를 줄일 수 있음

### 2. HP / 리소스 분리 설계
- HP와 SP(쿨다운 자원)를 분리하면 "지속성"과 "폭발력"이 각각 독립적 전략 변수가 됨
- OnionCat의 실드(패시브 보호막)와 합동 게이지는 이미 분리된 리소스 — BlazBlue처럼 한 리소스를 아끼면 다른 전략이 열리는 구조를 장비 효과로 강화 가능
- 예: "HP가 80% 이상이면 씨앗 관통" 같은 조건부 효과 장비

### 3. 이벤트 구역에서 HP 베팅
- 통행 중 HP를 소비해 버프를 얻는 선택지는 "위험 vs 보상" 결정을 런 중간에 풍성하게 만듦
- OnionCat의 **물음표 방** 이벤트(도박꾼의 상자, 피의 제단 등)와 완전히 같은 방향 — BlazBlue의 구현 방식 참고로 추가 이벤트 설계 시 HP 베팅 이벤트의 비율 조정

### 4. 캐릭터 조합으로 런 다양성
- 같은 캐릭터로도 업그레이드 선택에 따라 전혀 다른 빌드가 나오는 것이 재플레이를 유발
- OnionCat은 고양이와 양파가 각자 보상을 고르므로 "두 빌드의 합산 시너지"가 이미 BlazBlue보다 복잡한 구조 — 세트 효과 합산 방향성을 런 초반부터 HUD에 더 잘 표시하면 방향 잡기가 쉬워짐

### 5. 격투 게임적 무적 프레임 활용
- 대쉬 무적 프레임이 존재하고 이를 잘 써야 고난이도를 극복할 수 있는 설계
- OnionCat 고양이의 대쉬도 무적 이동 — i-frame을 의식적으로 사용하도록 유도하는 방 설계(좁은 공간에서의 궁지 탈출 등)를 강화할 수 있음
