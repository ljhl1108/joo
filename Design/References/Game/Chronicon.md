## 핵심 메커니즘

### 클래스 시스템
- 4개 클래스: Templar(근접 탱크), Warlock(원거리 저주), Ranger(원거리 물리), Berserker(근접 브루트)
- 각 클래스마다 **3개의 스킬 트리** — 기본 전투 스타일을 트리 조합으로 수십 가지로 변형
- 스킬 포인트는 레벨업과 특정 아이템으로 획득. 런마다 리셋

### 장비/세트 아이템 시스템
- **세트 보너스**: 같은 세트 2/4/6개 착용 시 시너지 보너스 발동
  - 예: "Darkstone Set" 2세트 → 크리 확률 +15%, 4세트 → 크리 피해 +50%, 6세트 → 크리 시 번개 소환
- **아이템 등급**: Normal → Magic → Rare → Epic → Legendary → Mythic (6단계)
- Legendary/Mythic은 고유 효과(unique affix)가 붙어 플레이스타일을 통째로 바꿈
- 아이템 생성기(Crafting) 없음 → 순수 드롭 기반이라 RNG 의존성 높음

### 영구 메타 진행
- **Artifacts**: 런 간 영구적으로 기본 스탯 올려주는 강화 시스템
  - 몬스터 처치 시 "Shards" 획득 → 사후 Artifact 슬롯에 투자
- **봉인된 던전(Sealed Dungeons)**: 클리어 시 영구 버프 해금
- **뉴게임 플러스(NG+)**: 지정된 횟수만큼 반복 가능. 매 NG+ 마다 난이도+적 강화+새 아이템 등장

### 건 필 & 전투
- 히트스톱 0, 타격감은 약한 편 → 빠른 이동+대량 몬스터 쫄개 소탕 스타일
- 스킬은 모두 클릭/단축키 활성화 → 타이밍보다 빌드 시너지가 중요
- 마우스 우클릭: 이동. 좌클릭: 기본 공격

## 협동 시스템

- **로컬 및 온라인 2인 코옵** 지원 (캐릭터 완전 독립)
- 두 플레이어가 화면 공유 → 한 명이 너무 멀어지면 자동 텔레포트
- 공유 자원 없음 (각자 골드, 아이템)
- 파티 버프: 근처에 있을 때 일부 클래스 스킬이 파티원에게도 효과 적용

---

## 플레이어들이 좋아하는 것

1. **빌드 다양성**: 클래스 × 스킬 트리 × 세트 아이템 조합으로 수백 가지 빌드
2. **만족스러운 성장 곡선**: 처음에는 약하지만 한 런 내에서도 눈에 띄게 강해지는 설계
3. **장시간 플레이 지원**: 15~30시간짜리 싱글 런도 가능한 층 구조
4. **레트로 이소메트릭 비주얼**: Diablo 1/2 향수 자극

---

## 단점 / 비판

- 타격감(주인공이 때리는 느낌)이 약함 → 피격 효과와 넉백 부족
- 초반 설명이 부족해 빌드 방향이 막막함
- 아이템 식별/정렬이 불편 (아이템 숫자 과부하)
- 그래픽이 스타일은 있지만 해상도가 낮아 적과 배경이 섞임

## OnionCat 적용 포인트

### 1. 업그레이드 시너지 설계 원칙
Chronicon의 **세트 보너스 디자인**(2/4/6 임계값)은 OnionCat에 그대로 적용 가능:
- 예: "발사체" 관련 업그레이드 2개 획득 → "탄속 +20%", 4개 → "관통 추가"
- 코드 힌트: `UpgradeManager`에서 `CountByTag("Projectile")` 후 임계값 체크

### 2. 클래스 특화 스킬 트리 vs OnionCat의 Cat/Crop 분화
- Cat = Templar/Berserker 계열: 근접, 내구, 대시 강화
- Crop = Warlock/Ranger 계열: 투사체, 탄환 개수, 실드 강화
- 런 중 Cat 업그레이드 3개를 먼저 가져가면 Crop이 불리해지는 균형 문제 → **Chronicon은 이를 "클래스가 다르면 아이템이 다르게 드롭"으로 해결**
  - OnionCat 적용: 업그레이드 카드를 Cat용/Crop용/공용으로 태깅, 드롭 풀 분리

### 3. 메타 진행 Artifacts 시스템 참고
- OnionCat의 영구 해금 시스템 설계 시, "런마다 조금씩 성장 → 진입 장벽 완화" 구조 채택 권장
- Shards(런 내 수집) → 메타 화폐 → 영구 버프 임계값 구조

### 4. 타격감 반면교사
- Chronicon의 타격감 약점 → OnionCat은 히트스톱, 파티클 풍부하게 보완해야
- 슬래시 히트 시 0.05~0.08초 히트스톱 + 화면 약한 흔들림 + 피격체 플래시

### 5. 아이템 과부하 문제 예방
- Chronicon은 아이템이 너무 많이 쌓여 비교 피로도가 큼
- OnionCat은 런당 업그레이드 선택지를 **3개 카드 중 1개 픽** 방식으로 유지 → 결정 피로 최소화
