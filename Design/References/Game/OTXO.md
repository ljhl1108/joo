## 핵심 메커닉

### 1. Focus 시스템 (슬로우모션)
- 처치 연속으로 "Focus" 게이지 충전
- 게이지 사용 시 시간이 느려지고 조준이 쉬워짐
- John Wick 스타일 총격전: 빠른 반응 → 슬로우 → 빠른 이동의 리듬
- **핵심 루프**: 적 처치 → 게이지 축적 → 슬로우모 발동 → 더 많은 처치

### 2. 무기 시스템
- 100개 이상의 무기 종류 (권총, 소총, 산탄총, 근접무기)
- 각 방에서 새 무기 드롭, 무기 교체가 전략적 선택
- 근접 공격 (펀치): 적 기절 + 처치 = Focus 게이지 대량 획득
- 무기 내구도 없음 → 탄약 관리만 중요

### 3. 절차적 레벨 구조
- 각 층(Floor)은 여러 방(Room)으로 구성
- 방 타입: 전투방, 바 (상점), 보스방, 이벤트방
- "바" 시스템: 처치로 얻은 코인으로 업그레이드 구매

### 4. 퍼머데스 + 메타 진행
- 사망 시 처음부터 재시작
- 메타 업그레이드 없음 (순수 로그라이크)
- 실력 기반 진행 → 숙련도가 올라갈수록 더 깊이 진입

### 5. 픽셀아트 스타일
- 흑백 + 붉은 피/강조색 팔레트
- 고강도 피드백: 히트스톱, 혈흔, 화면 흔들림
- 빠른 애니메이션으로 액션감 극대화

## 플레이어가 열광하는 요소

1. **컨트롤 반응성** — 딜레이 없는 이동/사격, 즉각적인 피드백
2. **처치 느낌(Kill Feel)** — 히트스톱 + 피 튀김 + 사운드 삼위일체
3. **Focus 리듬** — 빠름과 느림의 전환이 주는 전략적 흥분감
4. **짧은 런** — 한 런이 20~40분, 실패해도 부담 없이 재시작
5. **솔로 개발의 완성도** — 작은 팀도 퀄리티 높은 게임 가능하다는 증거

## OnionCat 적용 포인트

### 처치 연동 리소스 게이지
- OTXO의 Focus처럼, 처치 시 두 플레이어 공유 게이지 충전
- 게이지 사용: Player 2(Crop)가 특수 발사체 모드 발동 OR Player 1(Cat)이 강화 대시

### 근접/원거리 분업의 보상 차별화
- 근접(Cat) 처치 → 메근접 보상 드롭 증가
- 원거리(Crop) 처치 → 원거리/방패 보상 드롭 증가
- 처치 방식이 전략 선택에 영향

### 픽셀아트 피드백 레퍼런스
- OTXO 수준의 히트스톱(0.05~0.1초), 혈흔 파티클, 화면 진동이 목표값
- "처치 느낌"은 개발 초기부터 튜닝해야 하는 최우선 피드백

### 방 당 전투 시간 목표
- OTXO: 방 당 15~45초 (빠름)
- OnionCat 목표: 방 당 30~90초 (협력 조율 시간 포함)

### 무기/어빌리티 드롭 설계 참고
- OTXO처럼 "방 클리어 후 바로 선택" 구조 채택 가능
- 이중 선택지 표시 (Cat용 업그레이드 / Crop용 업그레이드)
