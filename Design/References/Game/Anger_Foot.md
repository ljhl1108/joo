## 핵심 메카닉

### 1. 발차기 우선 전투 철학
모든 공격의 기본이 "킥(Kick)". 총기는 보조 수단이며, 문을 발로 차서 열기 + 적에게 발차기 + 날아오는 물체를 되차기까지 하나의 단일 입력으로 연결.  
→ **Feel-First 디자인**: 단 하나의 입력 동사가 모든 상호작용을 포괄.

### 2. 원-히트 킬 / 원-히트 데스
플레이어도 적도 한 방에 죽는다. 반사 신경과 공간 인식이 전부.  
Hotline Miami와 동일한 "즉사 + 즉시 리스타트" 루프.  
→ 죽음이 패널티가 아닌 "정보"로 작용 — 어디서 뭐가 죽였는지 배움.

### 3. 룸 클리어 → 자동 다음 방 진행
방을 클리어하면 문이 열리고 자동으로 다음 방으로 달려 들어감. 정지 없이 운동량(momentum)을 유지하는 레벨 구조.  
→ **Momentum Design**: 클리어 후 멈추지 않고 바로 다음 위협으로 진입.

### 4. 신발(Shoe) 수집 시스템
런마다 새로운 "신발"을 획득 — 각 신발은 패시브 효과를 부여 (예: 킥 후 이속 증가, 적 폭발 등).  
아이템이 하나지만 매 런 조합이 달라지는 단순 + 강력한 빌드 시스템.

### 5. 운동 패턴
빠른 횡이동, 슬라이딩, 문 킥으로 공간을 장악. 마우스 에임 + WASD 이동 구조 (탑다운).  
→ 공간 인식 → 킥 → 이동 → 다음 공간 인식의 짧은 루프.

## 게임이 인정받는 포인트

1. **즉각적 피드백**: 킥 한 번에 문 폭파, 적 날아가기, BGM 리듬과 연동되는 타격감
2. **짧고 강렬한 런**: 한 런이 5-15분, 부담 없는 진입 장벽
3. **Free Lives 특유의 유머/음악**: 메탈/힙합 BGM과 과장된 물리 연출
4. **단순한 입력 깊이**: 버튼 2개(이동+킥)로 표현되는 폭넓은 상황 대응

## OnionCat 적용 포인트

### 적용 1: 단일 입력 다중 기능 설계
Anger Foot의 "킥" = OnionCat의 "P1 슬래시". 슬래시 한 번이 몬스터 공격 + 투사체 반격 + 환경 오브젝트 파괴까지 처리하도록 설계하면 조작 단순성과 전술 깊이를 동시에 확보.

**구현 힌트**: `OnTriggerEnter2D` 에서 tag 분류 → `Projectile` 태그면 반격, `Enemy`면 피해, `Destructible`이면 파괴. 하나의 슬래시 히트박스로 모든 상호작용 처리.

### 적용 2: 즉사 시스템과 난이도 밸런스
고난이도 모드에서 OnionCat도 "1~2 히트 데스" 옵션을 고려. Anger Foot에서 확인된 것처럼, 즉사 + 즉시 재시도 루프는 좌절보다 재미를 주려면 **리스타트 속도**가 핵심.  
→ 방 재진입 시간 < 1초가 목표. 씬 리로드 없이 방 내 오브젝트만 리셋.

### 적용 3: 모멘텀 유지 방 전환
방 클리어 후 멈추지 않고 바로 다음 방으로 달려 들어가는 흐름은 OnionCat의 코옵 리듬에도 적용 가능.  
→ "방 클리어 + 짧은 환경 연출 (0.5초) + 자동 문 열림"으로 탄력 유지.  
P2(Crop)가 원거리로 마지막 적 처리 → 팡파르 없이 문 열림 → 두 플레이어 같이 다음 방 돌진.

### 적용 4: 신발 = OnionCat의 비대칭 패시브 아이템
Anger Foot의 "신발" 아이템은 단순하지만 런마다 달라진다. OnionCat에서도 "P1 전용 발톱 업그레이드", "P2 전용 씨앗 업그레이드" 한 개씩만 획득해도 런 정체성이 생김.  
→ 아이템 수를 줄이고 각 아이템의 임팩트를 크게 만드는 것이 핵심.

### 적용 5: 킥 = 반격 메카닉 힌트
날아오는 물체를 발로 되차는 시스템은 OnionCat P2의 방패 패리와 동일한 구조.  
Anger Foot에서 패리 타이밍 윈도우는 넓지 않지만 예측 가능한 탄도 덕분에 직관적.  
→ P2 패리의 판정 윈도우를 0.15초 내외로 유지하되, **적의 투사체 발사 전 0.3초 예고 이펙트** 필수.
