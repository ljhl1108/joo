# Crab Champions

리서치 날짜: 2026-11-16

## 기본 정보

- **개발사**: Noisestorm (1인 개발)
- **출시**: 2024-05-14 (Early Access 2022)
- **플랫폼**: PC (Steam)
- **장르**: 로그라이트 3인칭 슈터, 협동 (최대 4인)
- **공식 사이트**: https://crabchampions.com/

## 핵심 시스템

### 1. 무기 시스템 (Weapon Loot)
- 적 처치 → 무기 드롭 (희귀도: Common → Rare → Epic → Legendary)
- 무기마다 고유 발사 패턴 (버스트, 연사, 단발, 산탄 등)
- 무기를 2개 소지 → 빠른 전환으로 콤보
- 같은 무기 중복 획득 → **자동 레벨업 (강화)**
- 성능 차이가 뚜렷해 "지금 이 무기 버려야 하나?"가 핵심 판단

### 2. 모디파이어 시스템 (Modifier Cards)
- 방 클리어마다 모디파이어 3개 선택 (로그라이트 카드 선택)
- 카테고리: 이동/공격/방어/탄약/특수
- 조합 시너지: 같은 색 카드 모으면 추가 효과 (세트 보너스)
- 부정적 모디파이어(저주)는 선택 시 더 강한 보상 → "위험-보상" 설계

### 3. 협동 설계
- 1~4인 온라인 협동 (동일 화면 아님, 개별 카메라)
- 각자 무기와 모디파이어 독립 관리
- 아군 부활: 쓰러진 아군 옆에서 일정 시간 → 부활
- 적 체력이 플레이어 수에 비례해 증가 (스케일링)
- **공유 풀**: 무기 드롭은 땅에 떨어지면 누구나 가져갈 수 있음

### 4. 아일랜드 & 웨이브 구조 (Island Progression)
- 여러 "섬"을 순서대로 클리어
- 섬마다 고유 환경 테마와 보스
- 섬 사이 "상점 섬"에서 무기 교환·강화
- 보스 처치 후 다음 섬 난이도 선택 (3개 중) → 위험도에 따른 보상 차등

### 5. 적 디자인
- 모든 공격 텔레그래프: 색상 원/선으로 범위 표시 (빨강)
- 적 유형: 근접돌진 / 원거리투사체 / 폭발 / 소환 / 엘리트
- 엘리트 적: 더 큰 체력 + 개인 모디파이어 1~3개 보유
- 보스: 여러 단계, 각 단계마다 다른 패턴

## 플레이어들이 사랑하는 점

- 1인 개발임에도 완성도 높은 게임플레이 루프
- 로그라이트 무기 수집의 중독성 — 드롭 한 번이 판을 바꿈
- 텔레그래프가 명확해 죽어도 "내 실수"로 느껴짐
- 협동 시 아군이 없어도 솔로가 가능한 균형 설계
- Crab Rave 감성의 경쾌한 분위기 (스트레스 없는 로그라이트)

## OnionCat 적용 포인트

### A. 중복 무기 → 레벨업 메커니즘
Crab Champions처럼 같은 장비 중복 → 강화는 OnionCat에 이미 구현됨.
배울 점: 강화 단계를 **시각적으로 명확히** 표현 (별 개수, 무기 색상 변화)
- 현재 OnionCat의 중복 처리 → seeds 획득. 추가로 강화 단계 아이콘 표시 고려

### B. 색상별 카드 세트 보너스
OnionCat의 세트 시스템과 유사. Crab Champions에서 배울 점:
- 세트 카드 선택 시 UI에서 "현재 세트 진행 상황"을 명확히 표시
- 예: "Sun 세트 2/3 — 1개 더 모으면 보너스!" 같은 텍스트 힌트 → 선택 유도

### C. 위험-보상 저주 카드 설계
Crab Champions의 "저주를 선택하면 더 강한 보상"은 OnionCat 물음표 방에 그대로 적용 가능
- 현재 물음표 이벤트에 "불리한 조건을 받고 더 좋은 장비를 얻는" 옵션 추가
- 단, CLAUDE.md 규칙: 능력치 영구 손해 금지 → `TimedEffects`로 "방 N개 동안" 조건만

### D. 아군 부활 시스템
OnionCat은 공유 체력이므로 "부활"보다는 "위기 협동" 설계가 맞음.
배울 점: 위기 상황에서 두 플레이어가 **함께 반응해야 하는 순간**을 만드는 것이 협동감을 강화함
- 예: 체력이 위험 수준일 때 고양이가 양파를 등에 태우고 방어 모드 진입 같은 특수 상태

### E. 엘리트 적 모디파이어 시스템
적이 개인 모디파이어를 가지는 Crab Champions 시스템은 OnionCat의 엘리트 적에 적용 가능
- 현재 `ModularEnemy` 조합형 적 → 엘리트 변종에 "추가 특성" 플래그 추가
- 예: "방패 보유" "빠른 이동" "자기 주변 적 버프" 등
