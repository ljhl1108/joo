## 핵심 메카닉

### 주사위 기반 전투
- 매 턴 일정 수의 주사위를 굴림 → 나온 숫자를 장비 슬롯에 배치
- 각 장비는 "6이상 필요", "짝수만 사용 가능" 등 주사위 요구 조건이 다름
- **공격, 방어, 특수 효과** 모두 같은 주사위 풀에서 경쟁

### 6가지 캐릭터 = 6가지 다른 게임
Dicey Dungeons의 핵심 설계 철학: 같은 시스템으로 완전히 다른 경험 제공.

| 캐릭터 | 주사위 사용 방식 |
|--------|----------------|
| Warrior (전사) | 기본적 주사위 배치, 장비 위주 |
| Robot (로봇) | 정확히 목표 숫자를 맞춰야 함 (다르면 0 데미지) |
| Inventor (발명가) | 장비를 즉석에서 crafting, 주사위 소모 |
| Witch (마녀) | 주문서로 적 주사위를 직접 조작 |
| Jester (광대) | 카드 뽑기 + 주사위 조합 |
| Witch Redux | 마녀의 규칙을 완전히 뒤집음 |

### 에피소드 시스템
- 6 캐릭터 모두 해금 후 각 캐릭터에 "에피소드 2, 3..." 추가 등장
- 에피소드마다 기존 캐릭터에 새 규칙/제약 추가 → 익숙함 + 새로움 공존
- 예: "이 에피소드에서는 장비를 복사 불가", "주사위 결과가 항상 반전"

### 적 AI의 주사위화
- 적도 자체 주사위를 굴려 행동 결정 → 적 행동이 예측 가능하고 학습 가능
- "이 적은 4가 나오면 강공격, 1~3은 방어" 같은 패턴을 파악하는 재미

## 플레이어가 사랑하는 것

1. **캐릭터별 완전히 다른 게임성** - 6명을 다 플레이하면 6가지 게임을 한 것 같은 느낌
2. **빠른 런** - 한 런 20~30분, 반복 플레이가 부담 없음
3. **읽기 쉬운 디자인** - 복잡한 시스템이지만 시각적 표현이 명확해 직관적
4. **음악** - Chipzel의 신나는 칩튠 OST가 게임 분위기와 완벽하게 매칭
5. **Terry Cavanagh의 철학** - 1인 개발임에도 버그 적고 완성도 높음
6. **무료 접근성** - Apple Arcade 런칭, 많은 플레이어가 무료로 첫 경험

## OnionCat 적용 포인트

### 1. Cat과 Crop의 비대칭 조작 철학
Dicey Dungeons의 가장 중요한 교훈: **같은 적/같은 방에서 두 캐릭터가 근본적으로 다른 방식으로 상호작용**하는 것이 재미.
- **직접 적용**: 
  - Cat은 근접 슬래시 → 적에게 직접 닿아야 효과
  - Crop은 마우스 에임 투사체 → 적을 봐야 효과
  - **근접 약점 적** vs **원거리 약점 적** 시스템이 Dicey Dungeons의 "캐릭터마다 다른 방식으로 해결" 철학 그대로

### 2. 공유 자원 경제 설계
주사위가 공유 자원처럼 작동 (이 턴엔 공격에, 다음 턴엔 방어에 써야 함).
- **직용**: OnionCat에서 대시 무적 프레임, 방패 에너지를 공유 쿨다운으로 설계 시 두 플레이어의 협업 결정이 필요해짐

### 3. 적 행동의 가시화
적이 "이번 턴에 무엇을 할지" 텔레그래프를 주사위 형태로 보여줌 → 플레이어가 반응할 수 있음.
- **적용**: OnionCat 적의 어택 텔레그래프 → "이 적은 Cat에게만 돌진", "이 적은 Crop의 방패를 부수려 함"을 명확한 시각 신호로 표시

### 4. 에피소드 = 잠금 해제 게임 변형
기존 시스템에 새 규칙을 얹어 재미의 깊이를 늘리는 방식.
- **적용**: OnionCat에서 메타 진행으로 "이 런에서는 Cat이 못 걷고 Crop이 이동 조작도 맡음" 같은 극단적 변형 도전 모드

### 5. 소규모 팀 완성도의 비결
Terry Cavanagh가 1인 개발로 90%+ 긍정 평점 달성한 비결:
- **핵심 루프 완벽히 다듬기**
- **시스템보다 캐릭터 고유성에 집중**
- **빠른 런으로 반복 플레이 유도**
- OnionCat 초기 개발 전략으로 그대로 적용 가능
