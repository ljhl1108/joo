## 핵심 시스템

### 1. 아이템 등급 & 어피스 (Affix) 시스템

- 등급 4단계: 일반(흰색) → 마법(파랑, 1~2 어피스) → 레어(노랑, 3~6 어피스) → 고유(황금, 고정 효과)
- **어피스 = 전치사 + 후치사 (각 3개씩, 최대 6줄)**
  - 각 어피스는 독립 효과: "물리 피해 +X", "공격 속도 +X%", "냉기 저항 +X%"
  - 조합이 빌드를 만든다 — 어떤 어피스를 고르냐에 따라 완전히 다른 캐릭터가 됨
- **고유 아이템**: 한 가지에 특화된 강력한 고정 효과 조합. "이 아이템을 기반으로 빌드를 짜는" 플레이스타일을 만듦

### 2. 패시브 스킬 트리 (Passive Tree)

- 1,300개 이상의 노드로 구성된 거대한 거미줄 그래프
- 모든 클래스가 같은 트리를 공유하되 시작 위치만 다름
- **Keystone (핵심 패시브)**: 빌드를 완전히 바꾸는 대형 노드
  - 예: "Chaos Inoculation = 카오스 데미지 면역, 대신 체력이 1"
  - 예: "Pain Attunement = 낮은 체력일수록 주문 피해 30% 증가"
- **Cluster Jewel**: 패시브 트리에 새 가지를 추가하는 보석 아이템 → 트리 자체를 확장

### 3. 소켓 & 스킬 젬 시스템

- 장비에는 소켓이 있고, 소켓에 스킬 젬을 꽂아 능력을 부여
- **링크 소켓**: 연결된 소켓끼리 서포트 젬이 적용됨
  - 예: 화염구 젬 + 다중 투사체 젬 + 빠른 시전 젬 → 화염구가 다중으로 빠르게 날아감
- 같은 스킬이라도 서포트 조합에 따라 완전히 다른 느낌

### 4. 통화 아이템 & 제작

- PoE에는 골드가 없다. **소비형 재화가 곧 제작 재료**
  - Orb of Alteration: 마법 아이템 어피스 재롤
  - Chaos Orb: 레어 아이템 전체 재롤
  - Exalted Orb: 레어 아이템에 어피스 1개 추가
- "통화 = 자원 = 제작 재료"라는 삼중 역할이 경제를 만든다

### 5. 리그 (League) 시스템

- 3개월마다 시즌 리셋, 새 메커닉 추가
- 리그마다 새 시작 → 성장의 재미를 반복 제공
- 기존 캐릭터는 Standard 리그로 이전 (영구 플레이 가능)

## 협동 & 소셜

- 최대 6인 파티 플레이 (드랍은 개인 귀속)
- 레이드 개념은 없고 일반 맵을 함께 클리어
- 트레이드: 경제 중심, 플레이어 간 물물교환

---

## 플레이어가 좋아하는 것

1. **빌드 다양성**: 같은 스킬도 수십 가지 방식으로 완성 가능 → 커뮤니티에 빌드 가이드 수천 개
2. **어피스 롤링의 도박 쾌감**: 좋은 어피스 조합이 나올 때의 성취감
3. **시즌 콘텐츠**: 매번 새로운 메커닉을 빠르게 배우고 적응하는 재미
4. **경제 플레이**: 아이템 트레이드 자체를 즐기는 층

## OnionCat 적용 포인트

### 장비 v4와의 대응

| PoE | OnionCat |
|-----|---------|
| 어피스 조합 (전치사+후치사) | 장비 효과 + 세트 귀속 |
| 등급 4단계 (일반/마법/레어/고유) | 일반/희귀/에픽/전설 |
| 고유 아이템 = 빌드 정의 아이템 | 전설 장비 3종 (아홉 목숨 등) |
| 소켓 링크 = 서포트 조합 | 마법서 3칸 = 스킬 조합 |
| 통화 = 제작 재료 | 씨앗 = 상점 화폐 + 리롤 화폐 |

### 즉시 적용 가능한 인사이트

1. **어피스 조합의 놀라움**: 두 장비 효과가 시너지를 낼 때 팝업 힌트 표시
   - PoE는 이걸 플레이어가 스스로 발견하게 두지만 OnionCat은 힌트를 줘도 좋음
   - `GearItem.synergyHint` 필드 (어제 IdeaPool에서 제안됨)

2. **Keystone 개념 → 전설 장비**: OnionCat의 전설 장비(아홉 목숨·그림자 분신·황금 양파)처럼
   - "빌드를 완전히 바꾸는" 단 하나의 아이템. 나머지 장비 선택을 종속시키는 강력한 축
   - 추가 전설 장비 설계 시 "이 아이템을 중심으로 빌드가 돌아간다"는 컨셉 추천

3. **제작 리롤의 단계**: 상점 리롤 비용이 5씩 오르는 현재 시스템에 PoE식 제한 추가 가능
   - 예: "씨앗을 50개 쓰면 한 번만 효과를 '잠금' 가능" → 아이템 제작 느낌
   - 단, 너무 복잡해지면 초보 플레이어가 어려워할 수 있음

4. **소켓 링크 → 마법서 조합**: Q·W·E 마법서의 순서/조합에 따라 시너지 발동
   - 예: Q(폭발)·W(산탄)가 함께 있으면 "연사 종료 시 작은 폭발" 효과 추가
   - 현재 마법서는 독립 스킬이므로, 2~3개 조합 효과를 GearEffect로 구현 가능

5. **League = 런**: 로그라이크의 런이 PoE의 리그와 동일한 역할
   - 매 런의 "이번 런은 어떤 빌드로?"라는 질문을 더 뚜렷하게 만드는 것이 핵심
   - 런 시작 시 "이번 런의 특성" (예: 이번 주는 특정 세트가 더 많이 드랍) 추가 가능
