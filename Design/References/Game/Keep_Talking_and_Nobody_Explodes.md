## 핵심 메카닉

### 1. 완전한 정보 비대칭 (Perfect Information Asymmetry)
KT&NE의 핵심 설계:
- **폭탄 해제자(Defuser)**: 화면 속 폭탄을 직접 보고 조작할 수 있지만, **해결 방법을 모른다**
- **전문가(Expert)**: 폭탄 해제 매뉴얼을 보지만, **폭탄 화면을 볼 수 없다**
- 두 플레이어는 절대로 서로의 화면을 공유하지 않음 → **언어/음성 소통만으로 협동**

이 구조가 만드는 것:
- "빨간 선이 홀수 위치에 있으면 마지막 선을 잘라" → 정보를 언어로 정확히 전달하는 능력이 게임플레이
- 소통 자체가 도전이 됨

### 2. 시간 압박 (Time Pressure)
- 폭탄에 카운트다운 타이머
- 실수마다 시간 페널티 (보통 1~2분 감소)
- 압박 속에서도 **명확하게 소통해야** 하는 스킬 테스트

### 3. 모듈 다양성 (Module Variety)
초반부터 후반까지 점진적으로 복잡해지는 퍼즐 모듈:
- **Wires**: 색상/위치 기반 와이어 절단
- **Button**: 버튼 색상과 텍스트에 따라 누르거나 홀드
- **Simon Says**: 색상 순서 기억 후 반복 (매뉴얼과 대조 필요)
- **Morse Code**: SFX로 모스 부호 듣고 단어 식별
- **Memory**: 이전 입력 기억 필요한 퍼즐

### 4. 매뉴얼 설계 (Manual Design)
- 공식 웹사이트에 공개된 오픈 매뉴얼
- 텍스트와 표로 이루어진 복잡한 참고서
- 전문가는 빠르게 **해당 모듈 섹션을 찾아** 해제자에게 전달해야 함
- 매뉴얼 탐색 속도 자체도 학습 곡선

## 플레이어들이 사랑하는 것
1. **소통이 게임플레이 자체**: 대화 실력이 곧 게임 실력
2. **실패의 유머**: "왜 내 말대로 안 했어?!" → 실패 후 웃음과 다음 시도 동기 부여
3. **역할 분업의 숙련**: 반복할수록 소통 방식이 최적화되는 성장감
4. **파티 게임성**: 구경꾼도 전문가 역할로 참여 가능, 그룹 활동에 이상적

## OnionCat 적용 포인트

### 1. OnionCat = Keep Talking의 실시간 액션 버전
KT&NE와 OnionCat의 구조는 **동일한 비대칭 정보 협동**:

| Keep Talking | OnionCat |
|---|---|
| 폭탄 해제자: 폭탄을 봄, 조작 가능 | P1(고양이): 이동/근접, 전방 시야 |
| 전문가: 매뉴얼을 봄, 해결책 제시 | P2(파): 조준/원거리, 360° 마우스 시야 |
| "저 선 무슨 색이야?" → "파란색!" | "왼쪽에 빛나는 적 있어!" → "원거리로 쏴!" |
| 시간 제한 하에서 소통 | 전투 압박 속에서 소통 |

### 2. 역할 독점이 협동감을 만든다
KT&NE의 핵심 교훈: **각 플레이어가 상대방이 절대 할 수 없는 것을 독점**해야 한다.
- P1이 마우스 조준도 할 수 있다면 → P2 필요성 감소 → 협동감 희석
- P2가 이동도 할 수 있다면 → P1 필요성 감소 → 분업 붕괴
- **역할을 명확히 제한할수록** 파트너의 존재가 절실해지고, 협동의 쾌감이 극대화됨

### 3. 명확한 언어 코드 (Visual Communication Code) 설계
KT&NE에서 "보라색 선이 3번 위치에 있으면" 같은 명확한 식별 언어가 핵심.
OnionCat에서도:
- 적 약점을 **색상/아이콘**으로 즉각 식별 가능하게
- "파란 적!" = 근접 약점, "빨간 적!" = 원거리 약점 같은 직관적 코드
- 플레이어가 자연스럽게 짧은 언어로 소통하도록 유도하는 시각 설계

### 4. 관찰자 → 참여자 전환
KT&NE는 구경꾼이 전문가로 참여 가능. OnionCat에서:
- 화면을 보는 모든 사람이 P2 역할로 마우스 조준 가능
- 스트리밍/공동 시청 환경에서 채팅이 P2 역할 힌트 제공 가능 (미래 확장)
- 다인 파티에서 P2를 교대로 맡는 방식도 가능

### 5. 소통 자체가 스킬이 되는 적 디자인
KT&NE의 재미는 소통의 정확도를 테스트하는 것. OnionCat에서:
- **P1만 볼 수 있는 정보** (근처 적의 움직임 패턴) + **P2만 볼 수 있는 정보** (원거리 적 위치)를 화면에 분리
- 예: P1은 근접 적의 공격 텔레그래프를 크게 봄, P2는 전체 맵 적 배치를 봄
- 두 플레이어가 가진 정보를 합쳐야 최적 전략이 나오는 구조
