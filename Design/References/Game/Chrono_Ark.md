## 핵심 메카닉

### 수사-전투 이중 루프
탐험 페이즈와 전투 페이즈가 명확히 분리:
1. **수사 (Investigation)**: 던전 방을 탐색, 단서/아이템 수집, NPC 대화
2. **전투 (Battle)**: 턴제 카드 배틀 — 영웅별 카드 덱, AP(행동 포인트) 소모로 카드 사용
- 수사 도중 퍼즐이나 함정 발견 → 선택지로 리소스 소모/획득
- "탐정 게임 + 로그라이크 + 카드배틀" 조합

### 파티 영웅 시스템
- 최대 4명 영웅으로 구성된 파티 운영
- 각 영웅은 **고유 카드 풀** — 같은 영웅이라도 런마다 다른 카드 조합
- 영웅 사망 시 해당 영웅의 카드 모두 덱에서 제거 → 파티 구성이 전략의 핵심
- **알루(Allu)**: 탐정 주인공, 시간 조작 카드 보유
- 런 도중 영웅 영입 or 영웅 사망 → 파티 구성이 동적으로 변화

### 스토리 연동 로그라이크
- 반복 런을 통해 **스토리 단편이 점진적 해금**
- 죽어도 주인공의 기억이 남아 이야기가 축적됨 (Hades 방식과 유사)
- 각 런에서 선택한 대화가 나중 런의 스토리에 영향
- 진 엔딩 조건: 여러 런에 걸쳐 모은 단서 조합

### 카드 시너지와 덱 구축
- 카드 등급 시스템: 일반/희귀/영웅급 카드
- 카드 업그레이드: 동일 카드 여러 장 모으면 강화 가능
- 영웅 간 **교차 시너지**: A 영웅의 카드가 B 영웅의 패시브 발동 조건
- 결함(Defect) 카드: 덱에 쌓이는 부정 효과 카드 → 리스크/리워드 설계

## 적 디자인
- 적도 카드/스킬 시스템으로 행동 패턴 결정
- 적의 다음 행동이 **미리 표시** (인텐트 시스템) — Slay the Spire 스타일
- 엘리트 적: 중간 보스급, 강력하지만 희귀 카드 드롭
- 보스: 페이즈 전환, 특수 카드 드롭, 스토리 연결

## 한국 인디 개발 특징
- 한국어 시나리오 퀄리티가 높아 국내 유저 호평
- 영어권 진출 후 긍정 반응 — 번역 품질 우수
- 소규모 팀(2~4인)이 스팀 출시까지 이른 성공 사례
- 개발 기간: 약 3년 (얼리 액세스 포함)

## 플레이어들이 사랑하는 이유
- **스토리와 로그라이크의 결합**: 반복 플레이에서 이야기가 쌓이는 만족감
- **파티 조합의 다양성**: 영웅 조합마다 완전히 다른 플레이 경험
- **한국적 감성**: 국내 사용자 감성에 맞는 캐릭터와 스토리
- **적절한 난이도 곡선**: 입문자도 접근 가능하되 하드코어 도전도 제공

## OnionCat 적용 포인트

### 1. 스토리 연동 런 구조
크로노 아크처럼 런마다 대화 단편을 해금하고, 여러 번 플레이하면 전체 스토리가 완성되는 구조. OnionCat의 Cat과 Onion이 서로에게 하는 한 마디 대사를 런마다 추가해 정서적 연결 강화.

### 2. 영웅 사망 → 패널티 설계
파티 영웅 사망 시 카드 풀 축소처럼, OnionCat에서 P1(Cat)이 먼저 쓰러지면 P2(Onion)의 공격 옵션이 줄어드는 비대칭 패널티. 협력 동기 강화.

### 3. 카드 등급 → 업그레이드 등급 시스템
크로노 아크의 카드 등급(일반/희귀/영웅급)을 OnionCat의 능력 업그레이드 등급 체계로 직접 참고. `Design/References/Tech/Loot_Rarity_Tier_System.md` 설계 시 활용.

### 4. 인텐트 시스템 → 적 예고
턴제지만 적의 다음 행동을 미리 보여주는 방식은 OnionCat의 실시간 액션에서도 적용 가능. 적의 공격 전조(Telegraph)를 아이콘으로 표시 → 플레이어가 전략적 판단 가능.

### 5. 소규모 팀 개발 참고
NLIM Games의 2~4인 팀이 스팀 출시 성공한 사례 — 기능 범위를 좁게 잡고 폴리싱에 집중하는 전략. OnionCat 개발 규모 설정 시 참고.
