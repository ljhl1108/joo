## 핵심 메카닉

### 1. 근접 + 원거리 조합 전투
- 기본: 근접 3연속 콤보 (검)
- 보조: **원거리 주문(Spells)** 4가지 중 하나 장착 — 화살, 폭탄, 불꽃, 파이어볼 등
- 원거리는 **마나 없음** → 근접 공격 적중 시 원거리 탄수 회복
- 핵심 루프: 근접으로 탄 충전 → 원거리로 약점 공격 / 먼 적 처리

### 2. 스태미나/구르기 시스템
- 무제한 구르기(i-frame 짧음) → 반격 기회를 적극적으로 만들어야 함
- 체력 회복 없음 (아이템으로만) → 전투 집중도 높음

### 3. 약점 활용
- 일부 적 / 보스는 특정 공격에만 반응
- 예: 돌 갑옷 적 → 폭발 주문으로만 갑옷 제거 → 이후 근접 가능
- 플레이어가 상황에 맞는 무기/주문을 선택하도록 강제

### 4. 탐색과 전투 밸런스
- 전투 > 탐색보다 둘이 균형 — 수수께끼, 숨겨진 경로, 비밀 보스
- 비선형적 월드 — 왔다갔다 가능

### 5. 보스 디자인
- 3페이즈 구성 보스들 → 각 페이즈마다 공격 패턴 추가
- 체력바 페이즈 전환 시 명확한 연출 (화면 전체 이펙트)

## 플레이어가 좋아하는 것

1. **전투의 리듬감**: 근접-원거리 교차가 자연스럽고 유동적
2. **적 다양성**: 각 지역마다 완전히 다른 적 세트 + 약점
3. **분위기**: 어둡지만 귀여운 픽셀아트 & 음악
4. **2인 개발의 완성도**: "이게 2인이 만든 거라고?" 수준의 폴리시
5. **적 공격 예고**: 모든 공격에 뚜렷한 예고 모션 → 배울 수 있는 게임

## OnionCat 적용 포인트

### 1. 근접으로 원거리 충전 → 협력 시너지 메카닉
- Death's Door: 근접 맞추면 원거리 탄 충전
- OnionCat: **Cat(Player 1)이 적 근접 공격** → **Crop(Player 2) 원거리 강화탄 충전**
  ```
  Cat 근접 적중 1회 → Crop 다음 원거리 공격 데미지 +50% (1발)
  ```
- 두 플레이어 협력이 자연스럽게 강화됨

### 2. 약점 시스템 시각적 신호
- Death's Door: 돌 갑옷 = 갑옷 표면이 빛남 → "여기를 때려라" 명확
- OnionCat 적 약점 표시:
  - 근접 전용: 적 몸에 **발톱 아이콘** 떠있음
  - 원거리 전용: 적 몸에 **새싹 아이콘** 떠있음
  - 무적 상태: 적 몸 반짝이는 실드 이펙트

### 3. 보스 페이즈 전환 연출
- 체력 특정 % 도달 시 전투 잠깐 정지 + 연출
- Unity 구현: `OnHealthThreshold(0.5f)` → Coroutine으로 히트스톱 + 애니메이터 트리거

### 4. 2인 소규모 개발 철학
- 2인이 만든 게임이 이 수준 → OnionCat도 1인 개발로 충분히 이 퀄리티 목표 가능
- 핵심: 적 종류 줄이고, 각 적의 공격 패턴을 풍부하게

### 5. 적 공격 예고(Telegraph) 디자인
- 모든 공격 전 예고 모션 0.3~0.5초 → 플레이어가 반응할 수 있는 공정한 게임
- 예고 없는 원샷은 절대 금지 → 테스트 원칙으로 채택 권장

## 기술적 참고 사항
- 탑뷰 + 약간의 원근감 표현: 스프라이트 정렬 및 높이 정렬(Y-sorting) 필수
- 원거리 탄 충전 시스템: `int spellCharges` 변수 + `OnMeleeHit()` 이벤트
- 보스 페이즈: `Animator` 상태머신 + 페이즈별 `Phase enum` 관리
