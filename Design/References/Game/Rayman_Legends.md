## 핵심 메커니즘

### 기본 조작 (Rayman)
- **달리기·점프·공격**: 반응성 높은 플랫포머 기본기. 적에게 주먹을 날리거나 헬리콥터 킥으로 공격
- **글라이딩**: 짧은 체공 시간으로 플랫폼 간 이동
- **수중 이동**: 별도 조작 체계 (느림, 적 회피 위주)

### Murphy(머피) — 비대칭 협동의 핵심
Wii U 버전에서 2번째 플레이어가 태블릿으로 Murphy를 직접 조작:
- **환경 조작**: 밧줄 움켜쥐기, 플랫폼 이동, 가시 비활성화, 선풍기 작동
- **독립 행동**: Rayman이 달리는 동안 Murphy는 화면을 가로질러 이동하며 길을 만든다
- **1P는 움직이고, 2P는 환경을 바꾼다** — 두 역할이 완전히 다른 입력 장치를 쓴다
  - Rayman = 조이스틱 (캐릭터 이동)
  - Murphy = 터치스크린 (환경 직접 조작)
- PC·콘솔 버전에서는 Murphy가 AI로 대신 처리, 2인 협동 시엔 두 Rayman을 조작

### 최대 4인 로컬 협동
- Rayman, Globox, Teensie × 2 조작 가능
- 같은 화면 공유, 한 명이 화면 밖으로 나가면 다른 플레이어 옆에 복귀
- 협동 필수 구간 없음 — 혼자서도 클리어 가능하나 더 쉬워짐

### 음악 스테이지 (Living Paintings)
- BGM 비트에 맞춰 적·장애물이 나타남
- 클리어 조건: 박자에 맞는 타이밍 + 협동 이동
- 리듬감과 협동을 한 번에 가르쳐 주는 "쇼케이스" 레벨

### 도전 과제 · 메타 진행
- **럼zyste 모으기**: 스테이지마다 숨겨진 보물 → 캐릭터 해금
- **데일리/위클리 챌린지**: 무한 달리기·버블 슈팅 등 미니게임 (글로벌 랭킹 포함)
- **레전드 카드**: 특정 조건 달성 시 보상 → 추가 콘텐츠 해금

## 플레이어들이 좋아하는 것

1. **즉각적인 피드백**: 점프·공격 모두 한 프레임 내 반응, 입력 지연 최소화
2. **Murphy 비대칭 메커닉**: "조수 역할"이 주인공만큼 재미있다 — 길을 뚫는 느낌
3. **음악 레벨**: BGM과 환경이 완벽하게 싱크되는 쾌감
4. **캐릭터 다양성**: 같은 조작이지만 외형·소리 다름 → 소유감
5. **난이도 조절의 자연스러움**: 도전 구간은 있으나 체력 패널티가 관대함

## OnionCat 적용 포인트

### 1. Murphy = Onion 역할의 선례
Murphy의 역할 구조가 OnionCat의 Onion과 거의 같다:

| 항목 | Rayman Legends (Murphy) | OnionCat (Onion) |
|------|------------------------|------------------|
| 조작 장치 | 터치스크린 (별개) | 마우스 + 키보드 (별개) |
| 이동 | Rayman을 따라다님 (화면 고정) | Cat 등에 앉음 (이동 없음) |
| 역할 | 환경 조작 · 길 개척 | 원거리 공격 · 스킬 지원 |
| "주인공" 여부 | Rayman이 직접 뛰고 싸움 | Cat이 직접 이동·근접 |
| 비대칭 | 완전 다른 입력 · 완전 다른 행동 | 완전 다른 입력 · 완전 다른 행동 |

Murphy가 "조수지만 없으면 클리어 불가"인 것처럼, Onion도 "지원하지만 없으면 전투가 훨씬 힘든" 구조를 목표로 삼을 수 있다.

### 2. "조수 역할이 아이들에게도 재미있다"는 증명
Murphy 역할을 비게이머(부모·아이)에게 주면 쉽게 참여할 수 있다는 평가 多 → OnionCat의 Onion도 "게임을 덜 아는 플레이어에게 주기 좋은 역할"로 설계 가능. Onion은 조준이 쉽고(마우스 에임 보조), 실수해도 Cat이 버텨 주는 완충재.

### 3. 협동 필수 구간 vs. 선택 구간 비율
Legends는 Murphy 없어도 클리어 가능하나, Murphy가 도와주면 훨씬 쉬운 구간이 많음 → "협동하면 쉬워지지만 혼자도 가능" 균형. OnionCat의 1인 플레이 모드(`Solo_Coop_Fallback`)를 설계할 때 같은 원칙 적용. Cat/Onion 중 한 명 없어도 클리어 가능하되, 협동 시 콤보·스킬 활용으로 더 빠르고 쉬워야 한다.

### 4. 음악 스테이지 → 협동 타이밍 가르치기
Legends의 음악 스테이지는 플레이어가 명시적으로 "지금 함께 행동해야 한다"고 가르친다 → OnionCat 합동기 발동 조건(둘 다 버튼 누르기)을 처음 배우는 튜토리얼 순간에 비슷한 연출 도입 고려. 게이지가 차면 HUD가 깜빡이고 양쪽에 프롬프트가 뜨는 형태.

### 5. 같은 화면 복귀 메커닉
Legends는 한 명이 너무 뒤처지면 다른 플레이어 옆에 자동 복귀 → OnionCat에서 Cat이 죽으면 Onion도 같이 죽는 구조라 복귀 개념이 없지만, **고양이가 아찔한 위치(구덩이 직전)에서 Onion의 씨앗이 적을 처리해주면 살아남는** 구조가 같은 "구제" 느낌을 만든다.
