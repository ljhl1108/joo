# Grim Dawn

리서치 날짜: 2026-10-18

## 기본 정보

- **개발사**: Crate Entertainment
- **출시**: 2016년 2월 (Steam Early Access 2013)
- **확장팩**: Ashes of Malmouth (2017), Forgotten Gods (2019), Crucible (DLC)
- **장르**: 다크 판타지 액션 RPG (핵앤슬래시)
- **공식 사이트**: https://www.grimdawn.com
- **Steam**: https://store.steampowered.com/app/219990/Grim_Dawn/
- **위키**: https://grimdawn.fandom.com/wiki/Grim_Dawn_Wiki
- **협동**: 온라인 멀티 2~4인

## 핵심 시스템

### 마스터리 조합 시스템
9개 마스터리(직업 계열) 중 2개를 조합해 36가지 하이브리드 클래스 생성.
- Soldier, Demolitionist, Occultist, Nightblade, Arcanist, Shaman, Inquisitor, Necromancer, Oathkeeper
- 두 마스터리의 스킬 트리를 동시에 올릴 수 있어 독특한 빌드 자유도
- 예: Soldier + Demolitionist = "Commando" (방패 + 폭탄), Arcanist + Occultist = "Spellbinder" (빙결 + 소환)

### 세트 아이템 시스템 (OnionCat에 가장 직접 참고 가능)
- **2/3/4/5피스 단계 보너스**: 세트마다 각 단계에서 다른 효과 활성화
- **빌드 완성도**: 특정 스킬의 데미지를 크게 바꾸거나, 아예 새로운 메커니즘 추가
  - 예: "Ulzuin's Chosen" 세트 4피스 → 그레네이드 스킬이 3개를 동시에 던짐
  - 예: "Ultos' Stormseeker" 세트 → 벼락 스킬이 연쇄로 2개 적 추가 공격
- **세트 정체성(set identity)**: 세트마다 "이 스킬을 강화한다"는 명확한 목적이 있음
- **세트 = 빌드 완성**: 세트를 맞추면 해당 스킬이 완전히 변형되는 수준의 강화 → 플레이어가 목표를 갖게 됨

### 헌신(Devotion) 시스템
- 별자리 모양의 패시브 트리: 55개 별자리, 각 별자리에 3~8개 노드
- "헌신 포인트" 소모해 별자리 활성화 → 패시브 보너스 + 스킬 발동형 효과
- 발동형 효과 예: "내가 적을 죽이면 주변에 불꽃 산탄 발사", "공격 받을 때 15% 확률로 즉시 반격"
- **스킬이 없어도 헌신으로 독특한 효과를 얻음** → 아이템 + 헌신으로 빌드 다양성 폭발적 증가

### 아이템 시스템
- **등급**: Normal → Magic(파랑) → Rare(초록) → Epic(보라) → Legendary(주황) → Mythical Legendary
- **이중 희귀(Double Rare)**: 두 접두사/접미사가 모두 높으면 단일 아이템이 강력해짐
- **컴포넌트**: 아이템에 끼워 넣는 보석류. 세트 효과 없이도 빌드 커스텀 가능
- **오거먼트**: 장비를 강화하는 특수 아이템, 진영(팩션) 평판으로 구매

### 팩션(세력) 시스템
- 8개 세력 — 각 세력과 평판을 쌓으면 전용 상점·제작도면·장비 접근 가능
- **서로 적대적인 세력**: 하나와 친하면 다른 하나와 적대 → 런 단위 의사결정
- 플레이어가 세계관에 참여한다는 느낌

## 플레이어들이 좋아하는 것

1. **빌드 다양성**: 같은 스킬이라도 세트+헌신+마스터리 조합으로 완전히 다른 느낌
2. **세트 수집의 만족감**: "이 세트 마지막 1개만 더 모으면 빌드 완성"의 긴장감
3. **어두운 분위기와 깊은 세계관**: 에서 달하는 장문 NPC 대사, 메모, 로어 아이템
4. **오프라인 가능 + 수정 가능**: 모드가 매우 활발
5. **명확한 빌드 목표**: 세트를 보면 "이건 X 스킬을 위한 빌드"임을 즉시 파악 가능

## OnionCat 적용 포인트

### 1. 세트 정체성 설계 원칙
Grim Dawn 세트는 "이 스킬/플레이 스타일을 강화한다"는 정체성이 명확.
→ OnionCat의 10개 세트도 각각 "이 세트는 X 상황/전략에 강하다"가 한 줄로 설명돼야 함.
- 햇살 세트 → 원소 누적/속성 시너지
- 바람 세트 → 이동·회피·대쉬 강화
- 번개 세트 → 연쇄·속성 시너지
- 각 세트 정체성이 불명확하면 플레이어가 "왜 이 세트?" 를 묻게 됨

### 2. 2/4/6/8 단계 보너스의 점프 포인트
Grim Dawn은 2피스 보너스는 가볍고, 4피스부터 눈에 띄게 강하고, 세트 완성(5피스)은 스킬 변형 수준.
→ OnionCat도 2단계는 "조금 더 강해짐", 4단계는 "확실히 다른 느낌", 6+단계는 "새로운 메커니즘 추가"가 이상적.
  8단계 보너스가 최고 보상이 되려면 "이 세트 모두 모으면 이게 된다"는 구체적 약속 필요.

### 3. 빌드 완성의 이정표로서의 세트
Grim Dawn에서 세트 마지막 조각을 얻는 순간은 핵심 게임플레이 루프의 클라이맥스.
→ OnionCat에서 고양이 3칸 + 양파 3칸이 같은 세트일 때 → "세트 완성!" 연출 강화.
  현재 HUD의 세트 진행도에 "1개 남음" 깜빡임 + 완성 시 별도 효과음/이펙트 추가 검토.

### 4. 적대적 선택지 설계
팩션 시스템처럼, 장비 선택에서 "A를 고르면 B를 못 쓴다"는 트레이드오프가 몰입을 만듦.
→ 같은 칸의 장비를 선택할 때 단순히 "더 좋은 것"이 아니라 "세트 방향"을 선택하게 설계.
  예: 에픽 장비 A(햇살 세트) vs 에픽 장비 B(바람 세트) → 방향의 선택

### 5. 헌신 시스템 → OnionCat 패시브 방향
발동형 조건("적 처치 시", "피격 시 X% 확률로") 패시브가 전투를 생동감 있게 만듦.
→ 현재 OnionCat 패시브가 주로 수치 강화(+X%)라면, 발동형 효과("킥 후 0.5초 안에 씨앗 맞추면 협동 게이지 +5") 추가로 체감 강화 가능.
