## 핵심 메카닉

### 캐릭터 시스템 (4종)
| 캐릭터 | 주무기 | 특수 능력 | 플레이 스타일 |
|--------|--------|-----------|---------------|
| Anna Conda | SMG (빠른 연사) | 구르기 회피 | 기동성 위주 |
| John Sawyer | Shotgun (근거리 폭발) | 투척 도끼 | 근거리 폭발형 |
| Mow Mow | Minigun (지속 딜) | 방패 슬라이딩 | 방어적 화력형 |
| Hector Delgado | Sniper (원거리 단발) | 텔레포트 | 사거리 위주 |

- 캐릭터마다 고정 주무기 + 고정 특수기 → **개성이 확실한 플레이 차별화**
- 주무기와 별개로 **바닥 아이템 픽업** 가능 (한시적 무기 교체)
- 픽업 무기 소진 시 기본 주무기로 자동 복귀

### 전투 시스템
- **커버 & 근접 공격**: 적 근처에서 근접 공격으로 총알 회피 + 추가 피해
- **투척물**: 수류탄·폭탄·다이너마이트 등 환경 파괴형 아이템 다수
- **환경 파괴**: 폭발물·배럴·차량 등 레벨 내 위험 요소가 전투에 통합됨
- **히트스톱**: 근접 공격/처치 시 짧은 히트스톱 → 타격감 극대화
- **혈흔·파편 연출**: 픽셀아트 수준에서 최고급 타격 피드백

### 적 설계
- 적마다 명확한 **무장 유형과 행동 패턴** 있음
  - 총잡이: 사거리 유지, 엄폐 사용
  - 근접형: 돌진, 점프 공격
  - 방패형: 정면 방어, 측면 공격 필요
  - 자폭형: 느리게 접근 → 폭발
- **보스 패턴 3단계**: 피통 감소에 따라 패턴 전환, 각 보스는 대형 스프라이트 + 독특한 공격

### 레벨 구조
- 4챕터 × 3스테이지 + 보스 = 총 16레벨
- 각 스테이지는 **좌→우 선형 진행** (로그라이크 아님)
- 레벨 내 비밀 루트, 숨겨진 아이템

## 코옵 시스템

- **로컬 2인 코옵** (화면 분할 없음, 같은 화면 공유)
- 서로 **다른 캐릭터 선택** 가능 → 각자 주무기/특수기 보유
- **공유 목숨 시스템**: 죽어도 파트너가 구출하면 부활 가능
- 협력 전술: 한 명이 근접 교란, 다른 한 명이 원거리 딜
- 화면 공유로 인해 **같이 이동해야 하는 공간적 제약** 자연스럽게 생성

---

## 플레이어가 사랑하는 것

1. **조작감 (게임필)**: 픽셀아트 게임 중 손꼽히는 반응성과 타격감
2. **레트로 미래 세계관**: 사이버펑크 + 80년대 B급 영화 감성
3. **적 버라이어티**: 같은 스테이지에서도 조합이 다양해 단조롭지 않음
4. **코옵 밸런스**: 두 캐릭터 조합마다 서로 다른 팀 시너지
5. **보스 디자인**: 패턴이 명확해 "읽는 재미"가 있음
6. **픽셀아트 퀄리티**: 각 챕터마다 완전히 다른 팔레트·분위기

## OnionCat 적용 포인트

### 1. 코옵 무기 역할 분담 (핵심)
Huntdown의 Conda(기동성) + Sawyer(근거리 폭발) 조합처럼  
→ **Cat(근접 슬래시)과 Crop(원거리 투사체)의 역할을 레벨 단위에서 명확히 갈라야 한다**  
→ 근접만 통하는 적 + 원거리만 통하는 적이 같은 방에 존재할 때 가장 재미있는 코옵 모멘트 발생

### 2. 픽업 무기 임시 전환
Huntdown의 바닥 아이템 픽업처럼  
→ Crop이 일시적으로 다른 투사체 유형(산탄·유도탄)을 획득하는 **임시 무장 교체** 시스템 고려  
→ 탄약 소진 후 기본 투사체 자동 복귀

### 3. 환경 파괴 전투
폭발 배럴, 다이너마이트처럼  
→ **OnionCat 방 내 환경 위험 요소** (폭발 허브, 가시 구역)를 전투 판도 뒤집기 요소로 활용  
→ Cat이 근접으로 배럴을 타격 → 연쇄 폭발 패턴 고려

### 4. 보스 체력 단계별 패턴 전환
Huntdown의 3단계 보스 패턴에서  
→ OnionCat 보스도 **체력 1/3, 2/3 임계값에서 패턴 전환** + 시각 연출 변화  
→ 근접 약점 보스 → 체력 감소 후 원거리 약점으로 전환 = 코옵 역할 강제 전환

### 5. 근접 커버 메카닉
근접 공격이 총알 회피 역할을 하는 Huntdown의 시스템처럼  
→ Cat의 슬래시에 **일부 투사체 튕겨내기(Deflect)** 효과 추가 고려  
→ Crop의 방패와 별개로, Cat도 타이밍 기반 방어 수단 가질 수 있음
