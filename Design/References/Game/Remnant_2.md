## 핵심 메카닉

### 절차적 세계 생성 (World Generation)
- **레벨 전체**가 플레이마다 다르게 생성됨 — 퀘스트, NPC 위치, 비밀 구역 배치가 모두 랜덤
- 고정된 방 타일셋 + 랜덤 이벤트 조합 방식(템플릿 + 시드)
- "Adventure Mode": 단일 레벨만 재생성하여 재탐색 가능

### 아키타입 시스템 (Archetype)
- 9종 클래스(헌터, 챌린저, 메딕, 알케미스트 등) 각각 고유 패시브/액티브/스킬
- **듀얼 아키타입**: 레벨업 후 두 번째 클래스 조합 가능 → 수백 가지 빌드
- 같은 팀에서 서로 다른 역할 강요 → 협동 시너지 자연스럽게 발생

### 보스 구조
- 씬마다 "어드벤처 보스"와 "필수 보스" 분리
- 같은 보스도 **World Tier(난이도)**에 따라 패턴 변화, 체력/피해 배율 달라짐
- 보스가 둘 이상 존재하는 방(다중 보스 인카운터) 존재

### 공략 불가 처리 (Soft Locks 방지)
- 협동 중 한 명 사망 시 나머지가 부활 결정 — Remnant 2는 자동 리스폰 석 존재
- 솔로 플레이 시 적 체력/수 자동 조정 (AI Director 스케일링)

### 피해/내성 시스템
- 상태이상: 출혈, 화염, 독, 부식, 쇼크 등 → 적마다 취약/내성 다름
- **속성 특화 빌드** 강요 → 팀이 서로 다른 속성 커버 가능

## 협동 요소

- 솔로/2인/3인 모두 지원, 스케일 자동 조정
- **역할 분담 강제**: 힐러 아키타입 없으면 회복 어려움
- 아이템/보상은 각자 인스턴싱 → 분쟁 없이 협동
- 트레이트 포인트 공유 X → 각자 성장

## 플레이어가 좋아하는 점

1. "매 런마다 다른 세계" — 재플레이 가치 극대화
2. 빌드 조합의 다양성 (아키타입 × 무기 × 반지 × 특성)
3. 보스 디자인이 정교하고 기억에 남음
4. 솔로/코옵 모두 밸런스 유지
5. 씬 탐색 시 "숨겨진 이벤트/아이템"의 발견 재미

## 비판점

- 제작/업그레이드 재료 파밍이 반복적
- 세계 티어가 너무 일찍 고정되어 후반부 재미가 줄어듦
- 멀티 플레이 레이턴시 이슈 (클라이언트 측 히트 판정)

## OnionCat 적용 포인트

### 1. 방 생성 방식 참고
- 고정된 방 형태 + 랜덤 이벤트/배치 조합 → OnionCat의 RoomLayout 시스템과 유사한 접근
- "보장되는 보스 방 + 랜덤 전투 방 + 선택 보상 방" 구조 이미 DungeonManager에서 구현 중

### 2. 역할 분담 강화 아이디어
- Remnant 2처럼 아키타입별 팀 역할이 뚜렷하게 나뉘면 협동이 의미 있어짐
- OnionCat: 고양이(근접/탱킹) + 양파(원거리/디버프)의 역할이 선명한 적 설계로 강화 가능
- **취약 축**: 특정 적은 특정 공격 유형에만 피해 감소 없이 터짐 → 이미 OnionCat 핵심 필라

### 3. 난이도 스케일링
- 솔로 플레이 시 "고양이/양파 한 명 봇 제어 모드" 나중에 추가할 때 Remnant 2의 1인 스케일링 참고 가능

### 4. 이중 클래스 시스템 → 할퀴기 스타일 + 양파 스킬 조합
- Remnant 2의 듀얼 아키타입처럼 고양이의 ClawStyle과 양파의 OnionSkill이 시너지 노드를 형성하면 빌드 다양성 증가

### 5. 보스 페이즈 설계
- 보스가 체력 구간마다 패턴을 바꾸는 구조 → Boss_Pattern_Design.md와 연계
- "2페이즈에서 약점이 바뀜" → 고양이/양파 중 한 명의 역할이 역전되는 보스 아이디어 가능
