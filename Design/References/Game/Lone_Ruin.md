## 핵심 메카닉

### 기본 구조
- 단일 플레이어 마법사 캐릭터
- 각 런마다 **하나의 마법 스펠** 선택 후 시작
- 스펠은 수십 가지 — 투사체, 근접, 광역, 유도 등 다양
- 방마다 적 웨이브 클리어 → 선택지(업그레이드/새 스펠) 제공
- 보스 4개 → 최종 보스 구조

### 전투 시스템
- **주 공격**: 선택한 스펠을 마우스 방향으로 발사
- **대시**: 무적 프레임 포함한 짧은 순간 이동
- **HP 시스템**: 최대 HP 제한적, 치유 아이템 드랍
- **탄막 회피**가 핵심 — 적 투사체 패턴 읽기

### 스펠 시스템
- 각 스펠마다 고유한 투사체 형태와 발사 패턴
- 업그레이드 시스템: 스펠 강화 → 범위/속도/데미지 증가
- "시너지" 없이 단일 스펠 집중 강화 방식
- 예시 스펠: 직선 투사체, 360도 산탄, 벽 반사탄, 유도탄, 근접 폭발

### 방 구조
- **방**: 작은 단일 화면 아레나
- 적 웨이브 등장 → 전부 처치 → 문 열림
- 방마다 **다양한 함정과 장애물** 배치 (가시, 용암, 이동 플랫폼)
- 이동 패턴과 함정 조합으로 난이도 조절

## 플레이어들이 사랑하는 요소

1. **명확한 게임 루프**: 스펠 선택 → 강화 → 보스, 심플하고 군더더기 없음
2. **뛰어난 게임 피드백**: 히트스톱, 파티클, 사운드가 정교하게 조화
3. **다양한 스펠 빌드**: 40+ 스펠로 매 런이 다르게 느껴짐
4. **픽셀아트 비주얼**: 어두운 던전 분위기, 밝은 마법 이펙트 대비
5. **짧은 런 시간**: 완주 시 ~30분 → 부담 없이 반복 플레이

### 비판점
- 싱글 플레이어 전용으로 협동 없음
- 런 간 메타 진행(영구 업그레이드) 부재
- 스토리 요소 거의 없음

## OnionCat 적용 포인트

### 1. 스펠 = Player 2(Crop/Onion) 발사 패턴 레퍼런스
Lone Ruin의 스펠 다양성은 OnionCat의 Onion 플레이어 능력 설계에 직접 적용 가능:
- **직선 단발**: 기본 투사체 (빠르고 정확)
- **부채꼴 산탄**: 근거리 범위 공격
- **벽 반사탄**: 좁은 방에서 유리한 특수 탄
- **충전 후 발사**: Cat의 슬래시와 타이밍 맞추는 협동 유발 패턴

### 2. 단일 아레나 방 설계
OnionCat의 방 설계에 Lone Ruin 방식 참고:
```
방 크기: 화면 1배수 (스크롤 없음)
함정 배치: 이동 경로 제한 → 자연스럽게 두 플레이어 협력 유도
적 스폰: 방 가장자리에서 등장 → 중앙 확보 전투
```

### 3. 히트피드백 품질
Lone Ruin의 게임 피드백은 인디 1인 개발 기준 최고 수준:
- 피격 시 0.05~0.1초 히트스톱 (TimeScale 조절)
- 피격 파티클 방향성 (공격 방향으로 산란)
- 사운드 피치 랜덤화 (같은 소리도 조금씩 다르게)
→ OnionCat도 동일한 3요소 구현 목표

### 4. 스펠 선택 UI
런 시작 시 스펠 선택 화면 → OnionCat의 런 시작 시 능력 선택 화면 레퍼런스:
- 3~4개 선택지 카드 형태 표시
- 각 카드에 능력 아이콘 + 짧은 설명
- 마우스 또는 패드로 선택

### 5. 1인 개발 가능한 범위 벤치마크
Lone Ruin은 **1인 개발 2년** 프로젝트:
- 적 종류: 15~20종
- 스펠: 40+
- 보스: 4개 + 최종 보스
→ OnionCat MVP 범위 설정 시 참고 기준

## 기술 노트 (Unity 구현 관점)

```
투사체 풀링: 40+ 스펠 × 다수 발사 → ObjectPool 필수
스펠 데이터: ScriptableObject으로 스펠 정의
  - ProjectileSpeed, Damage, Pattern(enum), UpgradeTree
방 클리어 감지: EnemyCount == 0 → 문 열기 이벤트
히트스톱: Time.timeScale = 0.1f → 0.05초 후 1f 복구
```
