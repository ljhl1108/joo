## 핵심 메카닉

### 독특한 카드 드로우 시스템
- 카드 덱이 **플레이어 덱 + 적 덱** 두 개가 섞여 있음
- 매 턴 드로우 시 적의 카드가 손패에 들어올 수 있음 → 적 카드는 쓸 수 없고, 손패를 막음
- 적을 처치하면 적 덱이 사라지고 손패가 깨끗해짐 → 적을 빠르게 처치할수록 패가 좋아지는 구조

### 전투 흐름
- 턴제 1:1 배틀
- 플레이어 카드: 공격·방어·스킬·마법 4가지 타입
- 카드를 내면 다음 라운드에 적용되는 효과도 있음 → 예측과 선 계획 중요
- 공격 카드의 대부분에 "조건부 추가 효과" 있음 (상태이상일 때 더 강함 등)

### 성장 시스템
- 런마다 새로운 카드 선택 (3장 중 1장)
- 보스 처치 후 특별 보상 카드 (강력하지만 조건 있음)
- 덱 압축 전략: 약한 카드를 삭제하여 좋은 카드 드로우 확률 올리기

### 분위기와 스토리
- 로즈가 유령이 된 자신을 구하러 저택을 탐험
- 픽셀아트 비주얼 + 호러 분위기 + 애니메이션 카드 이펙트
- 짧고 집중적인 플레이 타임 (런 30~60분)

## 유저들이 사랑하는 것

1. **독창적인 드로우 시스템**: 적의 카드가 내 손패를 막는다는 컨셉이 완전히 새로움
2. **1인 개발의 완성도**: 그래픽·사운드·시스템 모두 한 사람이 만들었다는 게 믿기지 않는 수준
3. **카드 조합의 발견**: 의외의 카드 콤보가 강력할 때의 보상감
4. **적당한 난이도**: Slay the Spire보다 접근하기 쉬우면서도 전략적

## OnionCat 적용 포인트

### 1인 개발 퀄리티 벤치마크
- makaroll이 혼자 이 퀄리티를 만들었다는 사실 자체가 OnionCat 개발자에게 중요한 참고점
- 핵심: **시스템 1개를 완전히 새롭게** 만들면 나머지가 평범해도 히트 가능
- OnionCat의 "2인 1캐릭터 + 공유 체력"이 바로 그 역할을 할 수 있음

### 보상 선택 UX 참고
- Phantom Rose의 3장 중 1장 선택은 OnionCat의 `UpgradeSelectUI`와 동일한 구조
- 차이점: Phantom Rose는 카드 각각을 크게 보여주고 효과 설명을 충분히 제공
- 적용: OnionCat 카드 선택 화면에서 마우스 오버 시 세트 현황·레벨업 효과가 한눈에 보이도록 개선 가능

### 덱 압축 = 장비 슬롯 관리
- Phantom Rose의 "약한 카드 삭제 → 좋은 카드 확률 상승" 전략은
  OnionCat의 "같은 칸에 다른 장비 → 기존 장비 분해 → 씨앗"과 같은 심리 구조
- 사용자가 "어떤 장비를 버릴지" 결정할 때 명확한 기준을 주면 좋음 (예: 현재 세트 현황 강조)

### 보스 카드 시스템 → 보스 보상 장비
- Phantom Rose에서 보스 처치 후 특별 카드(강력하지만 조건 있음)를 주는 것처럼
- OnionCat 보스 처치 후 에픽 이상 장비 확정 + "이 장비는 조건부 강화 효과 있음" 명시

### 적 카드 = 적의 행동 예고
- Phantom Rose의 "적 카드가 내 손패를 막음"은 적이 플레이어 자원에 직접 개입하는 디자인
- OnionCat에서 비슷한 개입: 특정 적이 "도발" → 양파의 다음 씨앗이 자동으로 자신에게 날아옴 (아이디어)
