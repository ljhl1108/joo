# Sephiria (세피리아)

리서치 날짜: 2026-08-28

## 기본 정보

- **장르**: 탑다운 픽셀아트 액션 로그라이크
- **개발사**: Eastasiasoft / 한국 개발자
- **출시**: 2023년
- **플랫폼**: PC (Steam), Nintendo Switch, PS4/5
- **Steam**: https://store.steampowered.com/app/2103130/Sephiria/
- **특징**: 한국산 로그라이크, 픽셀아트 스타일, 완성도 높은 소규모 작품

---

## 핵심 메커니즘

### 1. 캐릭터 클래스와 고유 플레이 스타일
- 다수의 언락 가능한 캐릭터 클래스
- 각 클래스마다 완전히 다른 이동 방식, 공격 방식, 패시브 특성
- **무기 + 캐릭터 조합**이 런의 정체성을 결정

### 2. 탑다운 전투 시스템
- 8방향 이동 + 근접/원거리 혼합 전투
- **회피(Dodge)** 중요 — 적 공격 예고 및 회피 타이밍
- 근접 공격: 범위와 속도의 밸런스
- 원거리 공격: 무기 탄약/재장전 개념

### 3. 던전 구조
- **방(Room) 기반 절차적 생성**
- 층(Floor)을 내려갈수록 난이도 상승
- 특수 방: 상점, 보물 방, 이벤트 방, 보스 방
- 방 클리어 → 출구 열림 → 다음 방 선택

### 4. 아이템 및 업그레이드 시스템
- 패시브 아이템 수집으로 빌드 구성
- 아이템 간 시너지: 특정 조합이 강력한 빌드 완성
- **Shop**: 골드로 아이템 구매, 런마다 상점 구성 다름

### 5. 보스 디자인
- 각 층 보스: 고유 패턴 + 다중 페이즈
- **보스 패턴 학습** 중요 — 초기에는 패턴 파악이 사망 원인
- 보스 처치 후 강력한 아이템 드롭

---

## 한국 인디 로그라이크로서의 특징

### 픽셀아트 스타일
- 세밀한 캐릭터 애니메이션
- 다크 판타지 + 아케이드 감성 혼합
- 한국 인디 특유의 **감성적인 색감** (어두운 배경 + 포인트 색상)

### 한국어 완전 지원
- 원어민 개발팀 → 스토리 텍스트 자연스러움
- 한국 플레이어 첫 진입 장벽 낮음

### 컨트롤러 우선 설계
- 패드 플레이 최적화 → 콘솔 포팅 성공
- 키보드/마우스도 지원하나 패드가 더 직관적

---

## 플레이어들이 좋아하는 것

1. **깔끔한 조작감**: 반응성 높은 이동, 히트박스 명확
2. **빌드 다양성**: 캐릭터 × 아이템 조합으로 매 런이 다른 경험
3. **접근성**: 진입 난이도가 적절 — 완전 초보도 1시간 내 보스 처치 경험 가능
4. **픽셀아트 퀄리티**: 한국 인디 중 높은 수준의 아트
5. **볼륨 대비 가격**: 소규모 팀 작품으로 가성비 좋다는 평가

---

## OnionCat 적용 포인트

### A. 소규모 팀 완성도의 벤치마크
- 세피리아는 소규모 팀이 **"완성된" 로그라이크**를 만든 사례
- **OnionCat 교훈**: 특성 없이 넓게 만들기보다, 한 가지 메커니즘(냥이+작물 공생)을 완성도 있게
- MVP(최소 기능 제품) → 완성도 → 확장 순서 중요

### B. 층(Floor) 기반 던전 구조 레퍼런스
- 세피리아의 방 선택 흐름이 OnionCat 레이아웃에 직접 적용 가능
- 방 클리어 → 출구 2~3개 → 다음 방 선택 → 층 끝 보스
- 초보 개발자에게: 이 선형 구조가 완전 랜덤 배치보다 구현 난이도 낮음

### C. 보스 다중 페이즈 패턴 레퍼런스
- 페이즈 1: 기본 패턴 → 체력 50% 이하: 페이즈 2 (속도/패턴 추가)
- **OnionCat 응용**: 보스가 체력 절반 이하에서 "근접 전용 공격" 추가 → 냥이(Player 1) 활약 필수
- 협동 요소를 보스 페이즈로 자연스럽게 강제

### D. 컨트롤러 + 키보드 혼합 지원 구조
- 세피리아: 패드 우선, 키보드도 지원
- **OnionCat**: Player 1 = 패드, Player 2 = 키보드+마우스 조합
  - Unity New Input System의 Multi-Device Input 활용
  - 세피리아가 이 구조를 성공적으로 구현한 레퍼런스

### E. 픽셀아트 다크 판타지 → OnionCat 스타일 방향성
- 세피리아의 어두운 배경 + 포인트 색상 구성은 시인성이 높음
- **OnionCat 응용**: 적 색상 = 차가운 계열(원거리 약점), 뜨거운 계열(근접 약점)으로 구분하면 색상만으로 전략 정보 전달 가능

# 세피리아 (Sephiria: Sword and Alchemy)

## 기본 정보
- **장르**: 탑다운 액션 로그라이크 (2D)
- **개발사**: Studio HG (한국 인디)
- **출시**: 2023년 (Steam Early Access)
- **공식 사이트 / Steam**: https://store.steampowered.com/app/2374190/Sephiria_Sword_and_Alchemy/
- **개발자 SNS**: 한국 인디 커뮤니티(인디크래프트, itch.io) 활동

---

## 핵심 메카닉

### 1. 무기 + 마법 조합 시스템
- 검(근접)과 연금술(원거리/마법)을 병행하는 하이브리드 전투
- 같은 캐릭터가 두 가지 스타일을 전환 — OnionCat의 "두 플레이어 = 두 역할"과 구조적 유사점
- 무기 티어와 마법 조합이 런마다 달라지는 빌드 다양성

### 2. 픽셀아트 탑다운 전투
- 한국 인디 특유의 섬세한 픽셀아트 — 작은 화면에 많은 정보 압축
- 무기 공격 모션의 시각적 명확성 (슬래시 이펙트, 타격감)
- 적 종류마다 다른 AI 패턴 — 근접 돌진형, 원거리 포격형, 지원형

### 3. 런 구조
- 층(Floor) 기반 진행 — 각 층에서 전투 + 이벤트 + 상점
- 층 보스 → 다음 구역 해금
- 런 사이 영구 해금 시스템 (연금술 재료 축적)

### 4. 연금술 크래프팅
- 런 중 재료 획득 → 현재 런 내에서 아이템/물약 제작
- 아이템 조합으로 시너지 빌드 구성
- 제작 레시피를 먼저 연구(영구 해금)하는 메타 진행

### 5. 한국식 난이도 곡선
- 입문 난이도 낮음 → 중반부터 급격히 상승
- "직접 만든 빌드로 보스를 쓰러뜨리는 성취감" 집중 설계
- 설명 텍스트가 상세하여 초보자 친화적

---

## 플레이어들이 사랑하는 점
1. **한국어 완벽 지원** — UI, 스토리, 아이템 설명 모두 자연스러운 한국어
2. **조합 재미** — 무기+마법 시너지 발견이 핵심 즐거움
3. **픽셀아트 퀄리티** — 한국 인디 특유의 세밀한 작업
4. **적당한 런 길이** — 1~2시간 내 1런 완주 가능한 볼륨
5. **친절한 난이도 입문** — 첫 시간에 기본 빌드 경험 가능

---

## OnionCat 적용 포인트

### A. 근접+원거리 역할 분리의 게임적 정당화
- 세피리아는 한 캐릭터가 두 역할을 하지만, OnionCat은 두 플레이어가 각각 전담
- 세피리아의 "검+마법 시너지" 개념을 **고양이+양파 시너지**로 확장
  - 고양이 근접 슬래시가 적에게 "취약" 디버프 → 양파의 원거리 데미지 증폭
  - 양파 방패 패리 성공 → 고양이 다음 슬래시에 크리티컬 판정

### B. 빌드 아이덴티티 시스템
- 세피리아처럼 "이번 런의 빌드 정체성"이 느껴지도록
  - 업그레이드 선택지가 하나의 방향성을 제시 (근접 강화 트리 / 원거리 강화 트리 / 시너지 트리)
  - 두 플레이어의 업그레이드가 서로 연결: P1 선택이 P2의 선택지에 영향

### C. 한국어 우선 개발 참고
- 세피리아는 한국어 우선 개발 + 영어 추가 방식
- OnionCat도 동일 전략 고려: 한국 인디 커뮤니티(인디크래프트, 버튜버 한국 시장)가 초기 타겟으로 유효

### D. 크래프팅 미니 버전
- 런 중 재료 수집 → 업그레이드 제작 방식
- OnionCat: 전투 중 "씨앗(양파 재료)" 드롭 → 런 내 성장 아이템으로 활용
  - 씨앗을 모아 화분에 심으면 일시적 버프 (양파 강화, 꽃 폭발 공격 등)

### E. 층 기반 진행 UX
- 세피리아 방식: 층 번호 표시, 각 층 클리어 후 보상 선택
- OnionCat 방 구조에 "층 번호 + 현재 층 미니맵 표시" 참고 가능
