## 핵심 메카닉

### 즉사 & 빠른 재시작
- 플레이어(Wrenault)와 적 **모두 단 한 방에 죽는다**
- 사망 시 0.3초 안에 해당 스테이지 처음부터 재시작 — 패널티 없음
- 이 디자인 덕분에 반복 플레이가 좌절이 아닌 "퍼즐 재시도" 느낌

### 오브젝트 = 무기
- 화면의 모든 오브젝트가 집어 들어 무기로 쓸 수 있다
  - 통나무 → 광역 돌려치기
  - 당근 → 빠른 단타
  - 사다리 → 찌르기 + 올라타기
  - 보트 → 슬라이딩 이동 + 충격
  - 투창 → 장거리 관통
- 각 무기는 **한 번 휘두르면 파괴**. 연속 무기 체인이 핵심 기술
- 무기마다 이동 방향이 결정되므로, "무기 선택 = 이동 경로 선택"

### 레벨 = 무기 퍼즐
- 각 방은 배치된 오브젝트 조합으로 "최선의 무기 루트"가 존재
- 고수는 무기 체인 순서를 미리 계획해 전체 방을 유동적으로 클리어
- 적들도 배치 위치가 고정 — 반복 플레이로 패턴을 학습

### 콤보 점수
- 연속 처치 + 빠른 처치로 배율 상승
- "완벽한 방 클리어" 보너스 존재

## 협력 요소

Bloodroots는 **싱글 플레이** 전용이다.  
그러나 다음 설계 철학이 공동 작업(OnionCat)에 직접 이식 가능하다:

| Bloodroots 디자인 | OnionCat 이식 방향 |
|---|---|
| 각 무기가 고유 역할 & 느낌 | Cat(근접)과 Crop(원거리)이 각각 고유한 "전담 상황"을 갖도록 |
| 무기 없는 상태는 느리고 취약 | 두 플레이어 중 한 명이 쿨다운이면 나머지가 위기 커버 |
| 오브젝트 → 무기 맥락성 | 씬에 있는 파괴물/소품을 임시 무기로 활용하는 이벤트 룸 |
| 레벨이 전략을 강제 | 방 배치로 협력 역할을 강제 (근접 전용 약점 + 원거리 전용 약점 동시 등장) |

---

## 플레이어가 좋아하는 것

1. **높은 스킬 천장** — 기본은 쉬운데 마스터하면 무기 체인이 예술
2. **즉각적인 리스폰** — 죽음에 대한 좌절감 최소화, 학습 루프가 부드러움
3. **환경 독해력** — 처음에는 몰랐던 "이 오브젝트도 무기였어?" 의 발견감
4. **만화적 폭력** — 과장된 피 / 비주얼이 코믹-처절하게 조화

## OnionCat 적용 포인트

### 1. 즉사 고위험 구역
- 특정 방에 "즉사 타일" or "즉사 적" 도입 가능  
- 단, OnionCat은 공유 HP이므로 "즉사 → 부활 쿨다운 + HP 대폭 감소"로 변환

### 2. 소품 무기 이벤트 룸
- "방에 무기 소품이 가득 한 방" — Cat이 통나무를 차면 적 방향으로 날아감  
- Crop은 원거리로 소품을 조준해 Cat이 근접하지 않고도 소품 활성화  
- 협력 레버리지를 환경으로 확장

### 3. "마지막 무기" 위기감
- 상점에서 구매하는 "일회용 강력 아이템" 개념  
- Bloodroots의 "무기 한 번 쓰면 파괴" 패턴을 아이템 시스템에 응용  
- 예: 1회용 폭죽(범위 폭발) → 사용 후 파괴

### 4. 위기 상황 빠른 리커버리 느낌
- Bloodroots처럼 "죽어도 금방 돌아온다" 리듬감  
- OnionCat의 부활 쿨다운을 짧게(3~5초) 설계해 리듬을 유지

### 5. 무기 = 이동 수단 원칙
- Cat 슬래시 방향 = 이동 방향의 부스트  
- Crop 원거리 = 밀어내기(knockback) 로 적에게 방향성 강제  
- 두 능력이 이동 메카닉과 결합되어야 전략적 깊이 생김
