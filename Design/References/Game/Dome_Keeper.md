## 핵심 메카닉

### 비대칭 페이즈 루프 (Asymmetric Phase Loop)
게임의 핵심은 두 활동 사이의 지속적인 전환이다.

**굴착 페이즈 (Dig Phase)**
- 지하를 파고 내려가 보석과 특수 유물(Relic) 수집
- 블록을 제거하며 경로를 개척 → 광부 감각 + 탐색
- 시간이 곧 압박: 지표면 돔에 웨이브가 곧 도착함

**방어 페이즈 (Wave Phase)**
- 지표면 돔으로 귀환 → 돔 무기(건)를 이용해 적 격퇴
- 웨이브를 버티는 동안 수집한 보석으로 업그레이드 구매
- 웨이브 종료 후 다시 지하로

### 업그레이드 시스템
- 돔 무기, 방패, 가젯을 보석으로 업그레이드
- **돔 유형 3가지**: Dome Keeper(기본 건), Witch Dome(마법), Robot Dome(자동화) → 근본적으로 다른 플레이 스타일
- 업그레이드 트리가 달라 매 런이 다른 빌드

### 유물(Relic) 시스템
- 깊은 곳에 숨겨진 특별 아이템 → 런 전체를 바꾸는 패시브 효과
- 런마다 어떤 유물이 스폰되는지 랜덤 → 로그라이크 재플레이성

### 모드
- **Dome Keeper 모드**: 계속 웨이브가 올 때까지 버티는 방어전
- **Rogue Mode**: 층마다 보스를 처치하고 다음 층으로 → 고전 로그라이크 구조
- **협동 모드**: 2인 로컬 협동 지원 (한 명이 굴착, 한 명이 방어 담당 분리 가능)

## 플레이어가 사랑하는 것

1. **"한 번만 더 파자" 긴장감** - 웨이브 카운터가 줄어드는 걸 보면서 더 파야 할지 올라가야 할지의 끊임없는 결정
2. **시각적 명료성** - 복잡한 시스템임에도 한눈에 상황 파악이 가능한 UI/UX
3. **빌드 다양성** - 업그레이드 조합이 수십 가지, 같은 돔 유형도 매 런 달라짐
4. **픽셀 아트 완성도** - 2인 팀이 만들었다고 믿기 어려운 수준의 아트 품질
5. **짧은 런** - 1런이 약 30~60분, 부담 없이 도전 반복 가능

## OnionCat 적용 포인트

### 1. 페이즈 전환 디자인 → 방 클리어 리듬
Dome Keeper의 "굴착 → 방어 → 굴착" 루프는 OnionCat의 "방 탐색 → 전투 → 보상 선택"과 구조적으로 유사하다.
- **적용**: 방 진입 시 명확한 준비 구간(적 스폰 전 2~3초) → 플레이어가 포지셔닝 결정하는 짧은 "굴착 페이즈" 느낌

### 2. 비대칭 역할 분담 → Cat vs Crop 시너지
협동 모드에서 한 명이 굴착, 한 명이 방어하는 방식이 OnionCat의 Cat(근접/이동)과 Crop(원거리/방패)과 동일한 구조다.
- **적용**: 특정 방에서 Cat이 적을 끌어당기는 동안 Crop이 집중 사격하는 "역할 분리 전술" 강화

### 3. 시간 압박 = 의사결정의 재미
"언제 돌아가야 하나"의 긴장감이 핵심. 정보가 완전하지 않은 상태의 결정.
- **적용**: 업그레이드 선택 타이머, 다음 방 공개 전 선택 제한 등 시간 압박 요소 도입 고려

### 4. 2인 팀 개발의 롤모델
Bippinbits 2인 팀이 상업적 성공 달성. 기능을 줄이고 핵심 루프의 완성도를 극한까지 올린 전략.
- **적용**: OnionCat도 "방 진입 → 전투 → 보상" 핵심 루프를 먼저 재미있게 만드는 것이 최우선

### 5. 명료한 정보 표시
웨이브 카운터, 보석 수량, 업그레이드 비용이 항상 명확히 표시됨.
- **적용**: OnionCat HUD - 두 플레이어가 한 화면을 보기 때문에 정보 밀도와 가독성이 특히 중요
