## 핵심 시스템

### 캐릭터 시스템 (13종)
각 캐릭터가 완전히 다른 플레이 스타일을 제공:
- **Fish**: 특수 능력으로 롤(회피), 총기 특화
- **Crystal**: 방어막 생성, 초보자 친화
- **Eyes**: 원거리 정신 공격, 유리 대포
- **Melting**: 매 레벨 HP -1, 대신 강력한 변이

각 캐릭터마다 고유 패시브 + 액티브 스킬 1개 → **OnionCat처럼 역할 분담 강제**

### 변이(Mutation) 시스템
- 레벨업마다 4개 중 1개 선택
- 200개 이상의 변이 카드
- 변이끼리 시너지 발생 (예: "Stress" + "Bloodlust")
- 카테고리별 분류: Red(공격), Green(기동), Yellow(총기), Purple(특수), Blue(원거리)

### 무기 시스템
- 피스톨, 샷건, 에너지건, 근접무기, 폭발물 등 100종 이상
- 무기는 바닥에서 줍는 방식 (인벤토리 없음, 2슬롯만)
- 탄약 관리: 방사선(Rads)은 XP, 탄약은 별도 자원

### 레벨 구조
- 7개 월드 (Sewers → Desert → Jungle → Frozen City → Labs → Crystal Caves → Nuclear Throne)
- 각 월드 2~3 레벨 + 보스
- 완전 절차생성: 방 배치, 적 조합, 무기 드롭 모두 랜덤

### 2인 협동
- 로컬 2인 코업 지원
- 각자 독립적으로 행동 (같은 화면 공유)
- 한 명이 죽으면 기다리다가 다음 방에서 부활 가능
- 둘이 다른 역할로 플레이 가능 (근접 캐릭터 + 원거리 캐릭터)

## 플레이어가 사랑하는 것

1. **Juicy 피드백**: 히트스톱, 카메라 흔들림, 파티클이 매우 과장됨 → 타격감 극강
2. **단계적 난이도 상승**: 초반엔 쉽다가 후반부에 급격히 어려워짐
3. **캐릭터 개성**: 13캐릭터가 전혀 다른 게임처럼 느껴짐
4. **빠른 런 길이**: 1런 = 15~30분 (초보) / 5~10분 (숙련)
5. **B.U.T.T.S 시스템**: Daily Challenge, Throne Butt (뉴게임+ 개념)

## OnionCat 적용 포인트

### 1. 역할 강제 메커니즘 참고
Nuclear Throne에서 근접 캐릭터(Crystal, Rebel)와 원거리 캐릭터(Eyes, Rogue)는 자연스럽게 역할 분담이 된다. OnionCat은 **시스템으로 강제**한다는 점이 차별점:
- 특정 적은 근접(Cat)만 처치 가능
- 특정 적은 원거리(Crop)만 처치 가능
→ 2인 협력이 선택이 아닌 **필수**가 되는 설계

### 2. 변이 시스템 응용
Nuclear Throne의 변이 분류(근접/원거리/기동/방어)처럼 OnionCat도 Cat 전용 변이 / Crop 전용 변이 / 공용 변이로 분류하면 빌드 다양성이 생김

### 3. 피드백 강도 참고
Vlambeer의 "Game Feel" 철학:
- 총알이 없어도 발사 소리가 먼저 들림 (오디오 선행)
- 히트 시 0.05초 히트스톱
- 적 피격 시 흰색 플래시 + 소량 넉백
→ OnionCat 전투 피드백 설계의 기준점으로 삼기

### 4. 2인 부활 시스템
죽은 플레이어가 다음 방 진입 시 부활하는 방식 → Coop_Revival_System.md 참고하여 OnionCat에 맞게 변형 (공유 몸이므로 한 명이 죽으면 런 종료가 맞음)

### 5. 무기 드롭 밸런스
2슬롯 무기 시스템으로 선택의 강요가 발생함. OnionCat은 Cat의 근접 + Crop의 원거리가 고정이므로, 업그레이드 아이템이 이 역할에 맞게 설계되어야 함.

## 핵심 시스템

### 1. 이동 및 캐릭터 스킬

- **WASD 이동 + 마우스 조준** — 이동 방향과 조준 방향이 완전히 독립적
- 캐릭터별 고유 액티브 스킬 (8종):

| 캐릭터 | 스킬 |
|--------|------|
| Fish | 구르기 대시 + 탄약 25% 보너스 |
| Crystal | 크리스탈 실드 (초록 탄 차단, 빨간 탄 반사) |
| Eyes | 염력 (아이템 당기기 + 적 밀어내기) |
| Robot | 무기 분해 → 탄약/HP 획득 |
| Chicken | 무기 투척 + 머리 잘려도 1회 부활 |
| Steroids | 양손 무기 동시 사용 |

- **근접 무기**: 짧은 범위 호 형태 공격 → 적 투사체를 **튕겨내어 반격** 가능

### 2. 무기 시스템

- **120종 이상** 무기, 동시 2개 장비 (메인/서브 슬롯)
- **5가지 탄약 유형**:

| 탄약 | 특징 |
|------|------|
| Bullet | 범용적, 탄약 공급 가장 많음 |
| Shell | 산탄, 벽 튕김 |
| Bolt | 관통형, 사살 시 다음 적까지 관통 |
| Explosive | 폭발, 환경 파괴 |
| Energy | 레이저/플라즈마, 다중 히트 |
| Melee | 탄약 소모 없음, 투사체 반사 |

- **핫스왑 테크닉**: 장전 중 바닥 무기를 집으면 장전 딜레이 스킵
- **탄약 드롭 보정**: 잔탄 20% 미만 시 드롭률 +80% — 긴박한 상황에서 자연스럽게 탄약이 더 나옴

### 3. 뮤테이션(Mutation) 시스템

- 레벨업마다 **4개 중 1개** 선택하는 영구 업그레이드
- 한 런에 최대 9개, 총 **29종**
- 예시:
  - Rhino Skin: 최대 HP +4
  - Trigger Fingers: 발사 속도 20% 증가
  - Eagle Eyes: 탄속 20% 증가 + 사거리 연장
  - Bloodlust: 적 처치 시 HP 1 회복
  - Throne Butt: Ultra Mutation (레벨 10 고유 스킬 업그레이드)
- **뮤테이션 시너지**가 빌드의 핵심 — 예: Trigger Fingers + Eagle Eyes + 볼트 무기 = 저격 빌드

### 4. 구역(Area) 구성 및 레벨 디자인

| 구역 | 특징 |
|------|------|
| Desert (1) | 입문, 개방적 지형 |
| Sewers (2) | 인터미션 — 어두움, 좁은 복도 |
| Scrapyard (3) | 좁은 골목 구조, 신중한 이동 필요 |
| Crystal Caves (4) | 인터미션 — 어두움 |
| Frozen City (5) | 네크로맨서 등장, 부활하는 적 |
| Lab (6) | 인터미션 — 레이저 함정 |
| The Palace (7) | 최종 구역, 최강 적 |

- 맵 생성: **워커(Walker) 알고리즘** — 시작점에서 무작위 이동하며 타일·아이템 배치
- **픽업 페이드아웃**: 경험치(Rads)가 일정 시간 후 사라짐 → 위험을 감수하고 수거할지 결정 강요

## OnionCat 적용 포인트

### 1. 공유 레벨·개별 역할 구조의 검증
NT Co-op에서 뮤테이션은 완전 공유, 무기/HP는 개별이다. OnionCat의 "하나의 몸 공유" 컨셉과 직결된다 — 체력·상태는 공유, 스킬 집행은 각자 담당. NT Co-op의 뮤테이션 선택 갈등 문제는 OnionCat이 두 플레이어가 항상 같은 위치이므로 자연스럽게 해소됨.

### 2. 적 타입별 무기 강요 → 협동 필수화
NT에서 Shielder(정면 방패 → 측면 접근 필요), Scorpion(근접 위험 → 원거리 유리) 등 상황에 따라 근접/원거리 판단을 강요한다. OnionCat은 이를 "근접에만 약한 적 vs 원거리에만 약한 적"으로 강화해 **협동 자체를 게임플레이 메카닉**으로 내재화할 수 있다.

### 3. 타격감(Juiciness) 설계
- P1 근접 180° 슬래시: 큰 화면 흔들림 + 둔탁한 타격음
- P2 원거리 투사체: 발사 빈도감, 패링 성공 시 별도 이펙트
- 패링 후 반사 투사체가 적을 처치할 때 보너스 연출 (NT 근접무기 반사 효과 참고)

### 4. 공유 카메라 문제 → OnionCat은 구조적으로 해결됨
NT Co-op 최대 불만: 카메라가 두 플레이어 사이 중간 고정 → 화면 복잡. OnionCat은 두 플레이어가 **물리적으로 같은 위치**이므로 이 문제 없음. 단, P2 마우스 조준 방향 UI(크로스헤어/방향선)를 명확히 표시해야 P1이 이동 방향을 결정할 수 있다.

### 5. Rads 타임아웃 → 자원 수거 역할 분업
NT에서 Rads가 페이드아웃 → 위험 감수 결정 강요. OnionCat에서: P2가 원거리 안전선에서 사격하는 동안 P1이 근접 필드에서 자원 수거하는 **역할 분업 시너지** 연출 가능. 수거 아이템에 페이드아웃 타이머 적용 권장.

### 6. 뮤테이션 → P1/P2/공유 업그레이드 분류
NT에서 뮤테이션 갈등이 발생한 이유는 구분이 없었기 때문. OnionCat에서는 "P1 전용 강화 / P2 전용 강화 / 공유 강화(이동속도·HP 등)"로 명시적 분류 후 합의 선택 구조 추천.

### 7. 루프 시스템 → 엔드게임 콘텐츠
첫 보스 클리어 후 **New Game+ 루프** 구조 — 적 HP 증가, 원거리 무적 적 비율 증가 등 숙련자 전용 챌린지 제공.
