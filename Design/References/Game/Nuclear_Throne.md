## 핵심 메카닉

### 빠른 사격과 탄환 물리
- 모든 총기에 실제 탄환 물리(속도, 튕김, 관통) 적용
- 리코셋(튕기는 탄)이 기본 메카닉의 하나 — 벽을 이용한 플레이 장려
- 탄환이 한 프레임에 여러 격자를 이동할 수 있어 고속 이동 탄 처리에 `Physics2D.Raycast` 계열 필요

### 짧고 강렬한 런
- 런 하나가 10~30분 → 실패해도 금방 재도전
- 총 7개 레벨 구역(Area), 구역마다 보스
- 완주 시 루프(2회차 이상) 가능

### 무기 체계
- 총 100+ 무기, 세 가지 희귀도 없음 — **모든 무기 평등하게 드롭**
- 현재 들고 있는 두 무기 중 하나만 사용 (선택이 핵심)
- 소지 탄약이 곧 HP 수준의 자원 — 탄 관리가 생존과 직결

### 돌연변이(Mutation) 시스템
- 적 처치 → 방사선 수집 → 레벨업 → **5개 중 1개** 골라서 영구 강화
- 각 캐릭터별 고유 패시브 + 돌연변이 조합으로 빌드 다양성 확보
- 돌연변이는 스크롤박스 없이 화면에 바로 표시 → UX 간결

### 캐릭터 다양성
- 12개 캐릭터, 각각 고유 패시브+스킬
- 예: Crystal = 방어막 / Yung Venuz = 탄환 수 2배 / Plant = 회복 / Robot = 무기 먹어서 HP 획득
- **어떤 캐릭터도 특정 상황에서 최강 → 선택에 의미**

### 적 설계
- 모든 적 공격에 **예고 모션(telegraph)** 존재
- 근거리 적, 원거리 적, 돌진 적, 집단 적이 혼재
- 탄 색깔로 위험도 구분 (빨간 = 고위험)

## 협력 요소 (Local Co-op)

- 2인 로컬 쿱 지원
- 두 플레이어가 각각 독립적인 캐릭터 선택
- 한 명 사망 시 → **상대방이 처치 후 부활 가능** (타이머 있음)
- 핵심 긴장감: 한 명이 죽으면 상대가 몰려드는 적들을 홀로 버텨야 함

---

## 플레이어가 좋아하는 점

- **최고의 게임 감각(game feel)**: 총기 반동, 히트스톱, 파티클이 완벽 조화
- 캐릭터 고유성: 각 캐릭터가 완전히 다른 플레이스타일 강요
- 진입 장벽 낮음 → 숙련도 천장 매우 높음 (스피드런 커뮤니티 활성)
- 동글동글한 픽셀아트 스타일과 극도로 격렬한 전투의 대비감

## OnionCat 적용 포인트

### 1. 무기/취약점 시스템 설계 참고
Nuclear Throne의 캐릭터-무기 조합처럼 **"이 적은 근접만, 저 적은 원거리만"** 룰을 명확한 시각적 단서로 표현해야 한다:
- 바위 갑옷 적 → 발톱 긁힘 이펙트 + 투사체 튕김 파티클로 "원거리 무효" 전달
- 빛 방어막 적 → 방패로 막히는 VFX + 근접 "클링" 사운드로 전달

### 2. 레벨업 UI 참고
업그레이드 선택 화면을 **카드 3~4장 → 1장 선택** 패턴이 아닌, Nuclear Throne처럼 간결하게 보여주는 방식 검토. OnionCat은 2인이므로 Cat/Onion 각각의 업그레이드가 분리되어야 함.

### 3. 탄약 관리 메카닉
현재 OnionCat의 Onion 플레이어는 씨앗 투사체를 사용. Nuclear Throne처럼 **탄약이 곧 전략 자원**이 되도록 씨앗 보충 메카닉 설계 가능 (특정 적 처치 시 씨앗 드랍).

### 4. 부활 메카닉 (쿱 관련)
Nuclear Throne 쿱의 **타이머 부활** 시스템은 OnionCat에서 그대로 활용 가능 — Cat이 죽으면 Onion이 일정 시간 내 특정 행동(파리 쫓기 등)을 해서 부활 가능.

### 5. 게임 감각 (Game Feel)
- 총기 반동: Onion의 씨앗 발사 시 반동 모션 + 카메라 소폭 흔들림
- 히트스톱: 적 처치 시 0.05~0.1초 멈춤 (Vlambeer 특허 수준의 기법)
- 사망 파티클: 적 처치 시 풍성한 혈흔/파편 파티클
