## 핵심 메카닉

### 게임플레이 구조
- 절차적으로 생성된 다층 던전(Floor)을 탐험
- 각 층에서 여러 방을 순서 없이 클리어 → 보스 방 개방
- 보스 처치 후 다음 층 진입 (총 5층 구조)
- 퍼머데스: 사망 시 처음부터, 메타 통화(Sphere)만 유지

### 무기 및 파워업 시스템
- 방 클리어 시 무기 또는 파워업 아이템 등장
- **무기**: 발사 속도·패턴·방향이 제각각 (단발, 산탄, 레이저, 회전 등)
- **파워업**: 관통, 탄속 증가, 폭발, 홈잉(유도) 등 탄막 변형 효과
- 파워업 스택 가능 → 런마다 완전히 다른 빌드 탄생
- 무기와 파워업의 궁합이 플레이스타일을 결정

### 불릿 헬 전투
- 듀얼스틱: 왼쪽 이동 / 오른쪽 조준·발사 분리
- 별도 대시 없음 → 순수 이동 회피 실력 요구
- 적 탄막이 화면을 채울 정도로 밀도 높음
- **플레이어 히트박스는 스프라이트보다 훨씬 작게** (너그러운 히트박스 철학)
- 흑백+네온 색상으로 적 탄막을 배경에서 즉시 구분

### 시각 명확성 (Visual Clarity)
- 배경: 매우 어두운 저채도
- 플레이어 탄막: 밝은 청록(Cyan)
- 적 탄막: 밝은 분홍/빨강
- 파워업·아이템: 노란색 계열
- 색상만으로 모든 요소를 즉시 구분 가능

### 메타 진행
- 런 중 Sphere(통화) 획득 → 런 종료 후 영구 업그레이드 구매
- 새 시작 무기·파워업 해금으로 초반 빌드 다양성 확대
- 도전 조건(특정 보스 처치, X층 클리어 등) 달성 시 콘텐츠 추가 언락

---

## 보스 설계 철학

- 각 층 보스마다 완전히 다른 탄막 패턴과 이동 방식
- 체력 단계(Phase)에 따라 패턴 전환 → 긴장감 유지
- 패턴을 외우고 다음 런에서 대응하는 학습 루프
- 보스 패턴은 *공정*하게 설계: 반응 가능한 속도와 회피 공간 보장

---

## 플레이어가 좋아하는 것

1. **빠른 피드백 루프**: 런 1회 20~40분, 죽어도 바로 재도전 의욕 생김
2. **빌드 다양성**: 무기+파워업 조합이 수십 가지 → 매 런이 다른 경험
3. **시각 명확성**: 탄막이 많아도 눈이 피로하지 않음
4. **보스 패턴 파악의 성취감**: 처음엔 어렵다가 패턴 외우면 클리어 가능
5. **저가격 고만족**: 콘텐츠 밀도 대비 합리적 가격

---

## 협동 요소

- 싱글플레이어 전용 (온라인/로컬 멀티플레이 없음)
- 하지만 탄막 게임 특성상 옆에서 같이 보며 조언하는 비공식 협력 문화 존재
- **OnionCat과의 대비**: 혼자서는 이런 밀도의 탄막을 다루기 벅차다는 것이 곧 2인 분업의 근거

## OnionCat 적용 포인트

### 1. 색상 기반 시각 명확성
- Monolith의 배색 전략 직접 차용 가능
  - 배경 타일: 저채도 어두운 색상
  - **양파 탄막**: 청록 또는 파랑 계열 (아군 탄)
  - **적 탄막**: 빨강/분홍 계열 (적 탄)
  - 아이템·업그레이드 박스: 노란색/금색
- 픽셀아트 팔레트 설계 단계에서 색 역할 고정

### 2. 히트박스 관대함 철학
- 탄막 밀도 높은 장면에서 분노 방지
- 고양이+화분 몸통의 실제 히트박스를 스프라이트보다 30~40% 축소
- Monolith처럼 "탄막이 스치는 느낌 = 회피 성공"으로 유도

### 3. 파워업 선택 UX
- 방 클리어 후 3개 카드 중 1개 선택 방식 (Monolith 스타일)
- OnionCat은 **고양이 전용 / 양파 전용 / 공유** 세 카테고리로 업그레이드 분류
- 두 플레이어가 상의해서 선택하는 사회적 순간 설계

### 4. 보스 취약 구조
- 원거리 약점 보스: 탄막이 비교적 적고 근접거리 공격이 강함 → 양파가 원거리 딜, 고양이는 회피에 집중
- 근접 약점 보스: 탄막 밀도 높음, 특정 핵심 부위만 근접 공격으로 피격 가능 → 고양이가 뚫고 들어가야 함
- 보스 Phase 전환 시 조명·색상 변화로 패턴 전환 알림

### 5. 빠른 런 길이 설계
- Monolith의 20~40분 런 길이 참고
- OnionCat 목표: 첫 클리어 기준 30분 이내 런 설계
- 방 수, 적 밀도, 보스 체력 밸런싱 기준으로 활용
