# Cobalt Core

리서치 날짜: 2026-10-10

- **개발사**: Rocket Rat Games
- **출시일**: 2023년 11월 8일
- **플랫폼**: PC (Steam)

- **스팀 평가**: 압도적으로 긍정적 (96%, 약 4,200개 리뷰)

## 핵심 메커니즘

### 우주선 전투 시스템
- 횡스크롤 우주선 vs 우주선 전투. 양쪽 모두 6개 레인 중 하나를 점유
- 매 턴 카드를 플레이해 **이동, 공격, 방어** 중 선택
- 적 우주선의 "무기 파트"를 조준 파괴 → 화력 감소
- 양쪽 우주선 모두 체력 고갈 = 전투 종료

### 크루(승무원) 시스템
- **3인 크루 구성**으로 운영. 해금 가능한 캐릭터 8명 중 3명을 선택
- 각 크루원은 **고유한 카드 덱 파트**를 가짐 — 한 덱에 세 사람의 카드가 섞임
- 크루원마다 역할이 다름:
  - **공격형**: 높은 피해, 낮은 생존력
  - **방어형**: 방어막·회피 전문
  - **지원형**: 팀 전체 버프, 드로우 가속
- 3인 조합이 시너지를 만들거나 방해할 수 있음 → **조합 탐구가 핵심 재미**

### 덱 구축 & 장비
- 전투 후 카드 3장 중 1장 선택 (Slay the Spire 방식)
- **아티팩트**(영구 패시브 아이템): 크루 시너지를 크게 바꾸는 핵심 보상
- 카드 업그레이드 시스템: 기존 카드를 강화하거나 특수 변형으로 교체

### 런 구조
- 4~5스테이지, 1런 = 약 45~60분
- 스테이지마다 전투 → 보상 → 이벤트 → 엘리트 → 보스 흐름
- **상점**: 씨드(통화)로 카드·아티팩트 구매, 리롤 가능
- 런 종료 후 영구 해금 (새 크루원, 스타터 덱 변형)

### 난이도 시스템 (Seraph Zone)
- 클리어 후 점진적으로 해금되는 추가 도전 레이어 (하데스 Pact of Punishment 유사)
- 각 레이어는 독립 모듈 형태로 조합 가능

## 플레이어가 사랑하는 것

1. **세 캐릭터의 유기적 시너지** — "이 조합이 이렇게 맞아떨어질 줄이야" 순간
2. **우주선 전투의 공간적 퍼즐** — 같은 레인 겹치기를 피하면서 공격하는 긴장감
3. **아티팩트 한 개가 덱의 방향을 바꿈** — 예측 불가능한 빌드 가능성
4. **캐릭터 성격·대사** — 8명 각자 개성 있는 리액션으로 운영 스토리가 생김
5. **빠른 런 속도** — Slay the Spire보다 템포가 빨라 부담 없음

## OnionCat 적용 포인트

### 1. 역할 분담 + 합산 시너지 설계
Cobalt Core는 "3개의 덱이 1개로 합쳐진다"는 구조. OnionCat은 "2명이 1개의 몸을 공유"이지만 **각자의 행동이 한 결과에 합산**된다는 점이 동일.
→ Cat 장비 + Onion 장비의 세트 보너스를 "공유 덱에서 시너지 카드 뽑기"처럼 느끼게 만들기: 세트 조합 선택이 곧 빌드 방향 결정.

### 2. 3장 선택 카드 UX
Cobalt Core는 카드 선택 시 **각 크루원의 카드를 같이 제시** — 어떤 캐릭터를 강화할지 선택하는 구조.
OnionCat의 `UpgradeSelectUI`가 고양이·양파가 동시에 각자 3장을 고르는 방식인데, 이 "둘이 동시에 고른다"는 협상 과정이 Cobalt Core의 "팀 구성 강화 방향 토론"과 같은 재미를 만들 수 있음.

### 3. 아티팩트 = 세트 방향 전환자
Cobalt Core에서 아티팩트 하나가 덱 방향을 바꾸듯, OnionCat의 **희귀/에픽/전설 장비 1개**가 "이 런의 세트 방향을 정한다"는 느낌을 강화할 것.
→ 전설 장비 설계 시 "이 장비가 있으면 햇살/바람 방향이 강제된다" 수준의 임팩트를 목표로.

### 4. 크루원 시너지 = 합동기 트리거 조건 확장
서로 다른 크루원의 카드를 조합할 때 보너스가 발생하는 Cobalt Core 아티팩트처럼, OnionCat의 협동 콤보·합동기를 트리거하는 **추가 장비 효과** 아이디어:
- "Cat가 걷어차기 후 Onion가 쏘면 씨앗이 관통" (바람 4세트 확장 아이디어)
- "합동기 게이지가 꽉 차면 Cat 패시브 방어막 2칸 즉시 회복" (햇살 6세트 후보)

### 5. 런 종료 후 영구 해금 리듬
Cobalt Core는 각 런이 끝나면 "새 캐릭터 하나 해금" 수준의 작은 성취를 준다. OnionCat 메타 진행 설계 시 참고 — 한 번에 너무 많이 열리면 압도됨, 너무 적으면 허전함. **런당 1~2개의 명확한 해금**이 적정선.
