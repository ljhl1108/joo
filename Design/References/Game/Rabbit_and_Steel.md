## 핵심 컨셉

한 마리의 **토끼** 전사와 **강철 기계(Steel)** 지원기로 이루어진 2인 비대칭 협동 게임.  
두 캐릭터는 역할이 완전히 다르다:

| 역할 | 토끼(Rabbit) | 강철(Steel) |
|------|-------------|------------|
| 이동 | 빠른 근접 격투 + 8방향 대쉬 | 느리지만 방어막·포탑 배치 |
| 공격 | 근접 콤보 + 차지 | 원거리 포격 + 장판 |
| 특수 | 쿨다운 기반 스킬 3종 | 에너지 관리 기반 스킬 3종 |
| 역할 요약 | **딜러 · 이동 담당** | **서포터 · 탄막 제어 담당** |

## 주요 시스템

### 1. 비대칭 보스 패턴 대응
- 보스는 "토끼를 겨냥한 패턴"과 "Steel을 겨냥한 패턴"을 **동시에** 섞어 쏜다
- 토끼가 처리하는 공격 따로, Steel이 처리하는 공격 따로 존재 → 각자 역할 분명
- 두 플레이어가 서로 다른 화면 위치를 봐야 하므로 **소통이 핵심**

### 2. 업그레이드 카드 시스템
- 보스 클리어 후 각자 3장 중 1장 선택 (캐릭터별 분리 덱)
- **크로스 시너지 카드**: 토끼가 고르면 Steel에게도 효과가 생기는 카드 (혹은 반대)
- 시너지를 의식적으로 조합하면 훨씬 강해짐 → "같이 상의하고 고르는" 경험 설계

### 3. 히트 박자 시스템
- 공격이 **박자**에 맞으면 보너스 데미지 / 리소스 회수
- 강제 리듬은 아니지만 "박자를 타면 보상"이라는 레이어가 숙련도에 깊이를 더함

### 4. 공유 자원 관리
- **공동 HP 바** + 개인 실드
- 보스 데미지 일부는 "둘 중 한 명"을 겨냥 → 누가 맞으면 되는지 협의 필요
- HP 회복 아이템은 풀 공유

### 5. 탄막 난이도 커브
- 1~4인 인원에 따라 탄막 밀도 자동 조정 (2인 최적 설계, 1인은 어려움)
- 탄막은 **색상 구분**: 흰색 = 무적, 빨강 = 데미지, 노랑 = 패링 가능

---

## 플레이어들이 좋아하는 요소

1. **역할 명확성**: 누가 뭘 해야 하는지 항상 분명 → 서로 방해 안 됨
2. **공동 전략**: 업그레이드 선택을 서로 상의하는 메타게임이 재미있음
3. **짧은 런**: 보스 한 판 30분 내외 → 부담 없이 여러 번 시도
4. **비주얼 선명도**: 탄막이 많아도 색상 코딩으로 "나한테 위험한 것"이 명확
5. **혼자도 가능**: 1인 플레이 시 양 캐릭터 전환 조작 (고난이도지만 가능)

## OnionCat 적용 포인트

### 1. 비대칭 패턴 설계 레퍼런스
- OnionCat도 Cat(근접)과 Onion(원거리)이 동시에 다른 역할을 함
- 적이나 보스가 "고양이 전용 위협"과 "양파 전용 위협"을 **동시 발사**하면?
  - 예: 보스가 근접 진입을 유도하는 "어그로 패턴" + 원거리를 겨냥한 "탄막 패턴"을 동시에
  - 지금은 적이 Cat/Onion을 구분하지 않음 → 이 레이어를 추가하면 협동감 폭발

### 2. 크로스 시너지 장비
- 현재 세트 보너스는 고양이·양파 합산이지만, **크로스 장비** 개념은 없음
- "Onion이 마법서 X를 들면 Cat의 특수 공격이 강화" 같은 직접 연동 장비 추가 가능
- ContentBuilder.cs에 `crossRef` 필드 추가로 구현 가능

### 3. 공유 체력 + 개인 실드 설계 확인
- Rabbit and Steel의 "공동 HP + 개인 실드" 구조와 OnionCat이 동일함
- OnionCat의 방어막 1칸 시스템과 같은 맥락 → 실드 패시브 설계 시 이 게임 참고

### 4. 협동 강제 패턴: "둘 다 동시에 행동"
- 현재 합동기는 "1.5초 안에 둘 다 버튼"
- 보스 특정 페이즈에서 "Cat이 보스 왼쪽 약점 공격 + Onion이 오른쪽 약점 동시 사격"처럼 위치 기반 동시 협동 기믹 추가 검토

### 5. 색상 기반 탄막 구분
- 현재 OnionCat 예고 색: 노랑(막기 가능) / 빨강(회피 필수)
- Rabbit and Steel처럼 "흰색 = 피할 수 없는 피해"(수치 딜) 같은 세 번째 카테고리 추가 검토
- 또는 "Cat만 막을 수 있는" vs "Onion만 막을 수 있는" 탄막 색 구분
