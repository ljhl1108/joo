## 핵심 메카닉

### 1. 드릴 이동 (Core Mechanic)
- Pepper는 **드릴로 지면을 파고들어 이동**할 수 있음
- 지면 안에 있을 때 속도/방향을 유지하며 "서핑"하는 느낌
- 나올 때 발사체처럼 튀어오름 → 이동 + 공격 동시 표현
- 단일 메카닉으로 이동·전투·퍼즐을 모두 해결

### 2. 모멘텀 기반 이동
- 입력에 즉각 반응하지만 **드릴 궤적은 물리 기반으로 자연스럽게 흘러감**
- 잘못 입력하면 원하는 곳에 못 나옴 → 숙련도의 느낌이 뚜렷함
- 게임패드 + 키보드 모두 자연스럽게 느껴지도록 조율

### 3. 레벨 디자인과의 통합
- 모든 레벨이 드릴 이동을 전제로 설계됨
- 지면·벽·천장이 전부 이동 경로 → "어디든 갈 수 있다"는 해방감
- 적은 드릴로 지나치면 피해, 지면 위로 나와 착지하면 다른 공격

### 4. 픽셀아트 + 게임 필(Game Feel)
- 32PPU 픽셀아트, 화면흔들림, 히트스톱, 파티클
- 타격감과 이동감을 "과장된 픽셀 표현"으로 전달
- 사운드 디자인이 이동 피드백에 완전히 동기화됨

### 5. 짧은 레벨, 빠른 재시도
- 레벨이 짧고 체크포인트가 잦음 → 실패해도 바로 재시도
- 시간 기록 시스템 → 스피드런 친화적
- 한 판이 30초~3분 → 완성도 높은 짧은 경험의 반복

## 플레이어들이 사랑하는 것

1. **단일 메카닉의 완성도** — 드릴 하나로 세계 전체와 상호작용
2. **숙련의 즐거움** — 처음엔 어색하지만 익숙해지면 유려하게 흐름
3. **픽셀아트의 아름다움** — 1인 개발이지만 상업 수준 이상의 비주얼
4. **짧고 집중된 경험** — 부담 없이 한 레벨씩 즐길 수 있음

## OnionCat 적용 포인트

### "단일 메카닉 완성" 철학
- Pepper Grinder는 드릴 하나를 10시간 동안 파고들도록 레벨이 설계됨
- OnionCat도 **Cat의 180° 슬래시 + Onion의 마우스 조준**이라는 단순한 코어를 먼저 완성해야 한다
- 복잡한 능력보다 기본 행동을 "완성도 있게" 느껴지도록 폴리싱할 것

### 즉각적 피드백
- 드릴 이동의 즉각적 반응 + 물리적 궤적 → Cat의 대쉬, Onion의 투사체도 입력즉시 반응
- 타격 히트스톱 + 화면흔들림은 선택이 아닌 필수임을 Pepper Grinder가 증명

### 짧은 재시도 루프
- 로그라이크의 "빠른 재시작"과 동일한 원칙 — 실패 후 5초 이내에 다시 플레이 가능해야 함
- OnionCat: 게임오버 → 재시작 흐름을 가능한 마찰 없이 설계

### 1인 개발의 완성도
- Ahr Ech는 1인으로 6년 개발 → 스코프 조절 + 폴리싱 집중
- OnionCat도 초보 개발자 → "적게, 완성도 높게"가 핵심 교훈
