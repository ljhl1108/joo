## 핵심 개요

Metal Slug + Contra에서 직접 영감을 받은 픽셀아트 런앤건. 인류와 기계의 전쟁을 배경으로 2인 협동 또는 단독 플레이를 지원한다. 두 캐릭터(Mavra, Doyle)가 서로 다른 플레이스타일을 가지며, "OnionCat의 비대칭 협동" 구조와 가장 직접적으로 비교 가능한 타이틀이다.

---

## 핵심 메커닉

### 1. 비대칭 캐릭터 설계 (Asymmetric Character Design)
| 캐릭터 | 특성 | 장점 |
|--------|------|------|
| **Mavra** | 일반 전투 병사 | 다양한 총기, 그레네이드, 높은 범용성 |
| **Doyle** | 사이보그 로봇 | 변신(롤러 형태), 근접 방패, 근거리 특화 |

- Mavra는 원거리 전투 중심, Doyle은 근접 및 돌진 중심
- 두 캐릭터를 합치면 "원거리 + 근접"의 완전한 전투 조합
- **→ OnionCat: Cat(근접) + Crop(원거리)** 비대칭 구조와 정확히 대응

### 2. 협동 시너지 설계
- 동일한 화면(공유 카메라)에서 2인 동시 플레이
- 특정 적/보스는 근접과 원거리 조합 없이 상대하면 훨씬 어렵게 설계
- 캐릭터 간 "보완 역할"이 자연스럽게 도출됨
- 한 명이 죽으면 다른 플레이어가 계속 진행 가능

### 3. 적 설계 철학
- 방패를 든 적: 정면 원거리 공격 무효, 측면/근접 공격 필요
- 장갑차/기계 보스: 약점 부위 존재, 근접으로 약점 노출 후 원거리로 처리
- "이 적은 근접으로만/원거리로만" 약점 시스템의 좋은 레퍼런스
- **→ OnionCat의 "원거리 전용 약점 적 / 근접 전용 약점 적"** 설계 직접 참고 가능

### 4. 조작감 (Game Feel)
- 점프 높이 & 낙하 곡선: 조이스틱 기울기에 민감하게 반응
- 총기 사격: 이펙트, 사운드, 반동 연출이 즉각적이고 강렬함
- 피격: 히트스톱 + 무적시간 + 밀려남 애니메이션 3종 세트
- 사망: 폭발 이펙트 + 느린 낙하 연출로 "죽음이 아프게" 느껴짐

### 5. 레벨 디자인
- 총 6스테이지, 각각 다른 환경 테마
- 스테이지 내 서브 경로 존재 (비밀 루트로 보너스 획득)
- 보스 입장 연출이 인상적 (Telegraph → 입장 → 패턴 전환)
- 보스 약점 부위가 시각적으로 명확히 표시됨

## 협동 요소 분석

| 요소 | 내용 |
|------|------|
| 입력 | 두 플레이어 각각 독립 입력장치 |
| 카메라 | 공유 카메라, 한쪽이 뒤처지면 부드럽게 스크롤 제한 |
| 부활 | 한 명 사망 시 다른 플레이어 진행 계속, 특정 지점에서 부활 |
| 탄약 공유 | 탄약은 각자 관리, 무기 드롭 공유 가능 |
| 보스 공략 | 두 플레이어가 다른 방향에서 협공 가능 |

---

## 플레이어들이 사랑하는 것

1. **조작감**: Metal Slug 수준의 쫄깃한 피드백 — 격발, 폭발, 피격 전부 만족감
2. **비주얼**: 픽셀아트 + 팔레트 제한으로 복고 느낌 완벽 재현
3. **협동 재미**: 두 캐릭터가 달라 협동이 진짜 의미있게 느껴짐
4. **보스 디자인**: 각 보스가 고유 패턴 2~3단계로 변화, 학습 곡선 적절
5. **접근성**: 어렵지만 불공평하지 않음, 체크포인트 시스템 적절

## OnionCat 적용 포인트

### 1. 비대칭 캐릭터의 균형 공식
Doyle(근접)과 Mavra(원거리)는 각자 단독으로도 클리어 가능하되, 협동 시 명확한 시너지가 있다. OnionCat도 동일 원칙 적용:
- Cat 단독 → 원거리 적 상대 어렵지만 불가능하지 않게
- Crop 단독 → 근접 적 위험하지만 방패+패리로 버틸 수 있게
- 두 플레이어 협동 시 → 역할 분리로 현저히 쉬워지는 구간 설계

### 2. "적의 공격 방향 = 협동 유도"
Blazing Chrome에서 보스는 좌우 동시 공격을 자주 사용. 자연스럽게 플레이어들이 나뉘어 위치를 잡게 된다. OnionCat 보스 설계 시:
- 정면 원거리 공격 → Cat이 대시로 회피하며 근접 접근
- 측면 근접 돌격 → Crop이 방패로 막거나 조준해 원거리 처리

### 3. 픽셀아트 피격 연출 참고
명확한 히트스톱(0.08~0.12초) + 흰색 히트 플래시 + 넉백이 조합되어 모든 타격이 묵직하게 느껴짐. OnionCat 피격 시스템에서 직접 참고 가능.

### 4. 보스 약점 시각화
보스의 약점 부위에 시각적 마커(발광, 다른 색상, 깜박임)를 사용해 플레이어가 "어디를 공격해야 하는지" 직관적으로 파악. OnionCat의 "근접 약점 / 원거리 약점" 적을 시각적으로 구분할 때 참고.
