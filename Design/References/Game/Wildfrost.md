## 핵심 시스템

### 1. 리더 + 컴패니언 구조
- 플레이어는 **리더(Snowdweller)** 1명을 선택하고, 런 중 **컴패니언**들을 영입
- 리더는 고유한 패시브/액티브 스킬을 가짐
- 컴패니언은 각각 독립적인 HP와 공격력을 보유하며, 죽으면 **런 내 영구 소실**
- 덱 카드는 유닛(리더/컴패니언)에 "장착"되어 해당 유닛의 행동에 영향을 미침

### 2. 카운터 기반 전투
- 유닛마다 **공격 카운터**(숫자)가 있어 매 턴 1씩 감소
- 0이 되면 자동으로 공격
- 카드는 카운터를 올리거나 내리는 방식으로 타이밍을 조절
- **소비형(Consume) 카드**와 **재사용(Recall) 카드** 구분

### 3. 시너지 + 태그 시스템
- 카드와 유닛에 **태그**(눈 결정, 독, 잉크 등)가 붙음
- 같은 태그끼리 **시너지**가 발생하여 콤보 형성
- 어떤 유닛도 혼자 최강이 아니라 **2~3개 유닛의 조합**으로 강력해짐
- 예: A 유닛이 눈 결정을 쌓으면 B 유닛이 그것을 폭발시키는 구조

### 4. 마을 메타 진행 (Snowdweller Camp)
- 런 사이에 **마을(Camp)**을 업그레이드 — 상점 해금, 새 카드 추가, 새 캐릭터 잠금 해제
- 단, 업그레이드는 **조금씩** 이루어져 플레이어가 점차 강해지는 느낌을 줌
- 완전한 빌드보다 **이번 런의 최선**을 찾는 것이 핵심

### 5. 보스 디자인
- 각 층의 보스는 계절 영주(Season Lords)
- 보스마다 **특수한 환경 효과**(눈보라, 폭풍 등)를 활성화해 전투 규칙을 바꿈
- 보스 전 "클링커" 미니보스가 체력/자원 소모 판단을 강요

## 플레이어가 사랑하는 것

1. **동료 유닛이 죽을 때의 감정** — 아무 이름 없는 캐릭터라도 여러 번 런을 함께 하다 보면 애착이 생김
2. **시너지 발견의 쾌감** — 두 카드가 완벽하게 맞아떨어질 때 "오!"하는 순간
3. **다양한 리더로 달라지는 플레이스타일** — 리더만 바꿔도 완전히 다른 게임이 됨
4. **비주얼/세계관** — 눈 덮인 세계, 귀여운 캐릭터 디자인, 따뜻한 색감 대비

## OnionCat 적용 포인트

### 공유 캐릭터 ↔ 리더+컴패니언 구조
- OnionCat의 Cat(P1) + Onion(P2)은 Wildfrost의 리더+컴패니언과 유사
- **한 플레이어가 다른 플레이어를 죽게 만들 수 없도록** 시스템 설계가 중요
- Wildfrost처럼 두 캐릭터가 **각각의 행동 타이밍**을 가져도 됨 (대신 공유 쿨다운)

### 태그 기반 업그레이드 시너지
- 업그레이드 아이템에 **태그**(화염, 전기, 독 등)를 붙이고
- Cat 업그레이드 + Onion 업그레이드가 같은 태그일 때 보너스 시너지 발생
- "메인 메뉴에서 이번 런의 시너지 조합 미리보기" 기능도 고려

### 컴패니언 영구 소실 감정 → OnionCat 배리언트
- 런 중 Onion/Cat 중 하나가 기절하면 **혼자 남은 상태** 플레이 가능하도록 설계
- 기절한 파트너를 부활시키는 리바이벌 아이템 또는 방(Coop_Revival_System.md 참고)

### 보스 환경 효과
- 각 보스 방에서 **전투 규칙 변경**(중력 변화, 시야 제한, 탄환 가속 등)을 도입하면
  Cat과 Onion이 강점을 바꿔가며 사용해야 하는 상황 연출 가능
