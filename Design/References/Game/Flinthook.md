## 핵심 메카닉

### 갈고리 + 슬로우 이중 메카닉
Flinthook의 핵심은 두 가지 능력의 결합이다:

1. **갈고리(Hookshot)**: 고리 모양 고정점에 갈고리를 걸어 스윙·이동. 타이밍에 따라 위·아래·옆으로 방향 전환 가능. 무한 사용 (쿨다운 없음).
2. **유령 총알(Blasma Pistol)**: 기본 총기. 빠른 연사.
3. **타임슬로우**: 버튼을 누르면 시간이 0.2배속으로 느려짐. 이 상태에서 갈고리 조준·총격 조준 가능. 에너지 소모 없음, 사용 빈도 무제한이지만 지속 시간 제한.

이 세 가지가 유기적으로 결합 → "매달려서 슬로우, 적 위치 파악, 갈고리 옮기며 사격"의 리듬감 있는 전투

### 절차적 방 배치 + 손수 제작 방
- 각 함선(Ship)은 여러 **손수 제작된 방(Hand-crafted Room)**들을 **절차적으로 배치**한 구조
- 방마다 적 배치·장애물·지형이 다름
- 방과 방 사이 짧은 복도 없이 문을 통해 직접 이동 → 빠른 게임 템포
- 각 함선 끝에 보스 전투

### 아이템 / 빌드 시스템
- **링(Ring)**: 패시브 능력 (탄약 증가, 이동속도 증가 등) — 최대 3개 장착
- **참(Charm)**: 특수 발동 아이템 (사용 시 효과)
- **퍽(Perk)**: 게임 시작 전 선택하는 기본 능력
- 아이템 풀이 방대하여 매 런마다 다른 빌드

### 영구 잠금 해제 (메타 진행)
- 새로운 함선 유형, 퍽, 적 등을 런 완료 또는 특정 조건으로 잠금 해제
- **저주(Curse)** 시스템: 더 어렵게 플레이하면 잠금 해제 속도 증가 — 자발적 난이도 상승 유도

## 협동/경쟁 요소

Flinthook은 싱글플레이어 전용이지만, **타이밍 기반 리듬 전투**는 2인 협동 설계에 유용한 레퍼런스다:
- 갈고리 이동 = 운동량(Momentum) 기반 → 플레이어가 능동적으로 이동 경로를 결정
- 타임슬로우 = 전략적 "판단 창" — 협동 게임에서 한 플레이어가 슬로우를 쓰면 다른 플레이어도 혜택을 받는 구조 가능

---

## 플레이어들이 사랑하는 것

1. **이동의 쾌감** — 갈고리 스윙의 유동적 모션이 중독성 있음. 잘 할수록 우아해지는 이동
2. **타임슬로우의 전략성** — "잠깐 멈추고 생각" vs "빠르게 반사" 선택의 재미
3. **픽셀아트 퀄리티** — 60fps 애니메이션, 선명한 실루엣, 우주 해적 분위기
4. **빌드 다양성** — 같은 함선이라도 아이템 조합에 따라 전혀 다른 플레이 스타일
5. **방 디자인** — 각 방이 독립적 퍼즐처럼 느껴지면서도 빠르게 진행됨

## OnionCat 적용 포인트

### 1. 이동 쾌감의 핵심 — 운동량(Momentum) 보존
Flinthook의 갈고리 스윙은 운동량을 보존한다. 기세를 유지하며 방을 가로질러 이동할 때의 쾌감이 핵심. OnionCat의 Cat 대시에도 적용 가능:
- 대시 후 이동 방향에 약간의 가속도(+20%) 부여 → "흐름"이 생김
- `Rigidbody2D.velocity`를 갑자기 0으로 초기화하지 말고 `MovePosition`으로 부드럽게 제동

### 2. 손수 제작 방 + 절차적 배치
Flinthook식 방 배치 전략:
- 전투 방, 보상 방, 가게 방 등 **유형별 방 프리팹** 제작
- 각 층에서 유형별 방 개수를 가중치로 결정 후 랜덤 선택
- 한 층 = 5~8개 방, 마지막 = 보스 방 → OnionCat의 룸 시스템에 직접 적용 가능

### 3. 타임슬로우 → OnionCat의 협력 느린 시간 능력
Flinthook의 타임슬로우 = OnionCat의 잠재 협력 스킬:
- **Crop 업그레이드 아이디어**: 쉴드 패리 성공 시 0.5초 타임슬로우 발동
- 이 창에서 Cat이 슬래시 연계 가능 → "슬로우 → 필살 근접" 2인 콤비 루틴
- `Time.timeScale = 0.3f`와 `Time.fixedDeltaTime = Time.timeScale * 0.02f` 같이 조정

### 4. 아이템 시스템 구조 — 링(패시브) + 참(액티브) 분리
OnionCat 업그레이드 시스템 설계에 적용:
- **Cat 전용 패시브** (링 대응): 슬래시 범위 확장, 대시 거리 증가
- **Crop 전용 패시브** (링 대응): 투사체 속도 증가, 쉴드 반사 각도 개선
- **공유 패시브** (참 대응): 둘 다 혜택, 예) "첫 피격 시 1초 무적"

### 5. 적 연출 — 명확한 피격 가능 실루엣
Flinthook의 적들은 실루엣만으로도 공격 방식이 파악된다. OnionCat도 적 디자인 시 "실루엣 테스트" 권장:
- 근접 전용 적: 뚱뚱하고 짧은 팔 → 가까이 가야 함
- 원거리 전용 적: 길고 뾰족한 촉수/눈 → 떨어져야 함
