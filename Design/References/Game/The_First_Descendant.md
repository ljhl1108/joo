# The First Descendant

리서치 날짜: 2026-10-31

## 기본 정보

- **장르**: 3인칭 협동 루터 슈터 (Co-op Looter Shooter)
- **개발사**: Nexon Games (한국)
- **출시**: 2024년 7월 (얼리 액세스 → 정식 출시)
- **플랫폼**: PC (Steam), PS5, Xbox Series X
- **공식 사이트**: https://www.nexon.com/firstdescendant/
- **Steam**: https://store.steampowered.com/app/2074920/The_First_Descendant/
- **가격**: 무료 플레이 (아이템 과금)

## 게임 개요

넥슨 게임즈가 개발한 한국산 3인칭 루터 슈터. 최대 4인 협동으로 워프레임·디아블로 스타일의 빌드 시스템과 방대한 모듈(장비) 수집 시스템이 특징. 스킬 기반의 고유 캐릭터(디센던트) + 무기 + 외장 장비 + 모듈로 빌드를 구성하며, 세트 효과·시너지가 핵심.

## 핵심 시스템

### 1. 디센던트 (캐릭터) 시스템
- 30종 이상의 고유 캐릭터, 각자 고유 스킬 4개
- 일반·얼티메이트 버전이 있음 (얼티는 외형 + 모듈 슬롯 수 다름)
- 기본 무기와 조합하여 플레이 스타일 결정

### 2. 모듈 시스템 (OnionCat 핵심 참고)
```
슬롯 구성:
[캐릭터 모듈 슬롯 12개]
  - 일반 슬롯 8개 (스탯·스킬 강화)
  - 세트 슬롯 4개 (세트 효과 발동)
[무기 모듈 슬롯 6개]

모듈 속성:
  - 레어도: 일반(회색) / 특수(파랑) / 희귀(보라) / 궁극(황금)
  - 수용량(Cost): 슬롯 용량 내에서 자유 조합
  - 트랜센던트 모듈: 슬롯 당 1개, 강력한 고유 효과
```

**세트 효과**:
- 세트 슬롯에 같은 세트 번호 모듈을 2·3·4개 장착하면 세트 효과 발동
- 세트마다 2/3/4개 단계 보너스가 다름
- 캐릭터·무기 세트가 분리됨

### 3. 중복 처리 시스템
```
중복 모듈 처리:
  - 같은 모듈 여러 개 → 합성해서 강화 (레벨 업)
  - 강화 레벨에 따라 스탯 증가 + 수용량(Cost) 감소
  
중복 무기 처리:
  - 같은 무기 여러 개 → "사이온 합성" (무기 특수 옵션 강화)
```

→ **OnionCat 유사점**: 같은 장비 = 레벨업, 다른 장비 = 분해(씨앗)

### 4. 외장 방어구
- 머리/몸통/손/발 4부위
- 각 부위마다 랜덤 세트+옵션 조합
- 세트 4개 = 세트 효과 발동 (2/4종류)
- 디아블로식 랜덤 롤, 스탯 수치 범위 존재

### 5. 드롭 시스템
```
드롭 경로:
  - 특정 보스·지역에서 특정 아이템 드롭 (투명 드롭 테이블)
  - "연구 조제" = 파밍한 재료로 제작
  - 패스·상점에서 직접 구매 가능 (과금)
  
드롭 강조:
  - 레어도 색깔 빛기둥 (회색·파랑·보라·황금)
  - 전용 드롭 연출 (카메라 팬)
```

→ **OnionCat 유사점**: 등급 색 빛기둥(GearLoot), 방 클리어 후 드롭

### 6. 협동 시스템
- 4인 실시간 협동 (온라인)
- 부활 시스템: 팀원이 쓰러지면 구해주거나 3카운트 후 사망
- 역할 분담보다는 개인 딜링 위주
- 힐러 캐릭터 있음 (버니/빌레, Bia 등)

## 전투 설계

```
패턴 구성:
  - 일반 몹: 단순 돌진·사격, 예고 없음
  - 네임드 몹: 약점(노랑 부위) + 특수 패턴
  - 보스: 다단계 페이즈, 결계 파괴 메커니즘
    (예: 무적 쉴드 → 수정 파괴 → 취약 시간)
    
무기 타입:
  - 돌격소총·저격·권총·산탄·레일건·로켓런처
  - 각 타입별 특화 빌드 가능 (모듈로 강화)
```

## 플레이어가 좋아하는 점

1. **빌드 다양성** — 수백 개 모듈·캐릭터 조합으로 매우 다양한 빌드 가능
2. **세트 효과 조합** — "어떤 세트를 조합해야 강해질까"를 탐구하는 재미
3. **협동의 흥미** — 각자 빌드로 보스를 협력 처치하는 쾌감
4. **투명한 드롭 테이블** — 어디서 무엇이 나오는지 공개됨 (목표 설정 용이)
5. **한국 개발사 감성** — 빠른 업데이트, 이벤트, 스토리 확장

## 비판

1. **과금 구조** — 얼티메이트 캐릭터·외형이 과금. "예쁜 것만 돈" 논란
2. **파밍 반복** — 확률이 낮아 같은 보스를 수십 번 돌아야 함
3. **가이드 없음** — 빌드 시스템이 복잡해 초보가 어려움
4. **온라인 전용** — 솔로 플레이 힘듦

## OnionCat 적용 포인트

### 1. 세트 슬롯 분리 (고양이/작물 전용 세트)
```
현재 OnionCat:
  - 세트 효과: 고양이+작물 장비 합산

First Descendant 참고:
  - "캐릭터 세트 슬롯"과 "무기 세트 슬롯" 분리
  - OnionCat에서도 [고양이 전용 세트]와 [작물 전용 세트]를 분리하면
    각자 독립적인 빌드 방향이 생김
  - 지금은 합산이므로 둘이 협력하지 않으면 세트가 안 모임 → 이게 더 OnionCat다운 설계
```

### 2. 모듈 수용량 시스템 → 패시브 무게 제한
```
First Descendant:
  - 슬롯마다 "수용량"이 있고 모듈 Cost가 다름
  - 강화하면 Cost 감소

OnionCat 응용:
  - 패시브 6개 제한 대신 "무게(weight)" 제한으로 바꾸면
    희귀 패시브는 무겁고(3) / 일반 패시브는 가벼움(1~2)
  - 더 흥미로운 선택이 생길 수 있음 (아직 설계 중인 부분)
```

### 3. 투명한 드롭 테이블
```
First Descendant:
  - 어떤 보스에서 어떤 아이템이 나오는지 명시
  - 목표 아이템을 위해 특정 콘텐츠를 반복하는 동기 생김

OnionCat 응용:
  - 온실 해금 조건(fragments 수집)도 "어떤 조건에서 파편이 나오는지" 명시
  - 특정 방 타입·보스 처치 시 특정 파편 드롭 → 목표 지향 플레이
```

### 4. 결계 파괴 메커니즘
```
First Descendant:
  - 보스 무적 쉴드 → 수정(Crystal) 파괴 → 취약 시간

OnionCat:
  - 현자 마법사 보스가 이미 이 패턴 구현함
    (결계: 수정 4개 파괴 → 3초 무방비)
  - 새 보스 설계 시 "둘이 함께" 결계를 깨는 메커니즘으로 확장 가능
    예: 고양이가 쉴드를 잡고 있는 동안 양파가 약점 사격
```

### 5. 레벨 업 vs 분해 선택의 가중감
```
First Descendant:
  - 중복 드롭 시 "합성해서 강화" vs "연구 재료" 선택
  - 선택에 따라 빌드 방향이 달라짐

OnionCat:
  - 현재: 같은 장비=레벨업, 다른 장비=분해
  - 개선 가능: 같은 장비도 "레벨업 OR 효과 이전용 분해" 선택 제공?
    (장비 간 효과 이식 시스템의 기초)
```
