## 핵심 시스템

### 1. 협동 사냥 구조
- 최대 4인 온라인 / 2인 로컬 협동
- 각 플레이어가 독립적인 캐릭터로 같은 몬스터를 사냥
- 목표: 몬스터를 쓰러뜨리거나 포획 → 소재 획득 → 더 강한 장비 제작
- **사냥 1회 = 약 10~20분**, 명확한 단위 구조

### 2. 14종 무기 시스템
각 무기는 완전히 다른 조작감과 역할:
- 대검(Great Sword): 묵직한 차지 공격, 단타 고데미지
- 쌍검(Dual Blades): 빠른 연타, 상태이상 누적
- 기관창(Gunlance): 방어 + 폭발, 고정 포지션
- 활(Bow): 원거리, 범위 약점 집중
→ 무기마다 플레이어에게 완전히 다른 역할과 경험을 줌

### 3. 방어구 세트 스킬 시스템 ⭐
OnionCat 장비 시스템과 가장 유사한 부분:

```
방어구 파츠: 머리/가슴/팔/허리/다리 (5칸)
각 파츠마다 스킬 포인트 부여
같은 세트 조각을 모을수록 세트 효과 활성화

예시) 나루가크루가 세트
- 2조각: 회피 강화 Lv1 (회피 거리 증가)
- 4조각: 회피 성능 Lv1 (회피 중 피격 판정 감소)

스킬 포인트는 다른 세트 파츠와 혼합해도 합산
→ "2세트 + 2세트 혼합"으로 두 가지 세트 효과 동시 획득 가능
```

**세트 설계 원칙:**
- 각 세트는 특정 플레이 스타일을 지원 (회피형 / 카운터형 / 상태이상형 / 원소형)
- 세트 2조각 효과는 비교적 약하게, 4조각 이상부터 강력한 시너지
- 장신구(데코레이션) 슬롯으로 개별 스킬 보충 가능

### 4. 몬스터 텔레그래프 시스템
- 모든 공격 전 예비 동작(telegraph)이 명확히 설계됨
- 빨간 발광 → 강공격(회피 필수)
- 분노 상태(붉어지는 눈) → 패턴 변화 예고
- **이미 알려진 패턴 → 익숙해지면 파훼 가능 → 성취감**

### 5. 부위 파괴 시스템
- 머리, 꼬리, 날개 등 각 부위를 집중 공격해 파괴 가능
- 파괴 성공 → 소재 드롭 변화 + 패턴 약화
- 플레이어에게 "어디를 공격할지"에 대한 지속적 결정 요소 제공

### 6. 동반자(오토모/멜냐) 시스템
- AI 동반자 2마리가 함께 출격 (솔로 플레이 지원)
- 힐링, 방해, 상태이상 등 지원 역할
- 협동의 "쉬운 버전"을 항상 제공

### 7. 마리오네트 와이어 (Rise 신시스템)
- 실 조각으로 지형 이동, 적 타기, 공중 전투
- 수직 이동성 추가 → 입체적 전투
- 기존 MH의 "무거운 발판" 이미지를 완전히 바꿈

## 플레이어가 사랑하는 것

1. **장비 제작 루프**: 몬스터 사냥 → 소재 → 새 장비 → 더 강한 몬스터 사냥의 명확한 사이클
2. **세트 빌드 실험**: 어떤 조합이 자신의 플레이 스타일에 맞는지 탐색하는 재미
3. **몬스터 학습 곡선**: 처음엔 무섭지만 익혀갈수록 패턴이 보이는 성취감
4. **협동 시너지**: 4인이 같은 몬스터에 집중할 때의 혼돈과 쾌감
5. **외형 자유도**: 원하는 스탯의 장비 + 원하는 외형 장비 따로 (전환 기능)

## OnionCat 적용 포인트

### A. 세트 효과 설계 참고
```
MH Rise 방식:
- 세트 2/4조각 효과 단계 구분
- 서로 다른 세트를 혼합해 두 가지 효과 동시 획득 가능
- 각 세트가 특정 플레이 스타일을 명확히 지원

OnionCat 현재:
- 10개 세트 × 2/4/6/8단계
- 고양이+양파 효과 합산
→ MH Rise처럼 "어느 세트를 몇 개 모을지" 조합이 빌드의 핵심 결정이 됨
→ 세트마다 "이 세트는 걷어차기 스타일" "이 세트는 원소 누적 스타일"로 명확한 정체성 부여 중요
```

### B. 텔레그래프 원칙 강화
```
MH Rise: 모든 공격에 명확한 예비 동작, 색상 구분
OnionCat 현재: 노랑(막기 가능) / 빨강(피하기)

MH의 세 가지 텔레그래프 레이어 참고:
1. 적의 자세 변화 (공격 방향 예고)
2. 색상/발광 변화 (강도 예고)
3. 사운드 큐 (청각적 예고)
→ 보스전에서 특히 세 레이어 모두 활용할 것
```

### C. 부위 파괴 → 적 파츠 개념
```
슬라임 같은 단순한 적이 아닌 복합 적에게:
- 방패 파괴 (현재 방패 근위병이 구현)
- 갑옷 파괴 → 약점 노출
- 수정 실드 파괴 → 조합형 적의 'ModularEnemy' 특성으로 이미 일부 구현됨
→ 이 메커니즘을 더 확장하면 MH-스타일 "학습 성취감"을 줄 수 있음
```

### D. "솔로 가능하지만 협동이 더 쉬운" 설계
```
MH: AI 동반자로 솔로도 가능 + 4인 협동은 훨씬 여유로움
OnionCat: 2인 필수이지만 1인 연습 모드 고려
→ P2(양파) AI 보조 모드: 자동으로 쏘고 스킬 쓰는 낮은 수준 AI
→ 1인도 게임을 경험할 수 있게 하는 접근성 확보 방법
```

### E. 유니트 사이클 명확성
```
MH: 한 사냥 = 10~20분, 명확한 시작·중간·끝
OnionCat: 방 클리어가 자연스러운 단위
→ 방에 입장할 때 "이 방의 목표와 위험도"를 미리 암시하는 UI/연출
→ 방 클리어 순간의 보상 연출을 더 풍성하게 (Room_Clear_Celebration_VFX처럼)
```

## 기타 메모

- **Sunbreak DLC**: 새 스킬 시스템 "스위치 스킬 교체" 추가 → 같은 무기도 두 가지 스타일로 플레이 가능 → OnionCat 할퀴기 변형(ClawStyle) 개념과 유사
- 세계관: 일본 판타지 + 닌자/오토모 미학 → 동양적 미학이 잘 먹히는 협동 게임 증명
- 몬스터 헌터 시리즈 전체적으로 "패턴 암기 + 빌드 최적화"의 양 축이 장기 플레이를 지탱함
