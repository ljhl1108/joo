## 개요
Voidigo는 스웨덴 1인 개발자 Steve Isaacs가 개발하고 Raw Fury가 퍼블리싱한 탑다운 액션 로그라이트다. 동물 주인공이 우주적 공포(Void) 몬스터들과 싸우는 코믹하고 혼돈스러운 세계관. **공유 체력 풀을 사용하는 2인 로컬 협동**을 지원하며, 세트/태그 기반 아이템 시너지 시스템을 갖춘 점이 OnionCat과 구조적으로 매우 유사하다.

주요 특징:
- 무기가 실제 몬스터 형태 — 던지면 폭발하거나 자율 행동하는 생체 무기
- 모든 적이 고유한 패턴·시각적 예고를 가짐
- 태그(set) 기반 아이템 시너지 시스템
- 2인 협동 드롭인/드롭아웃 (공유 체력 풀)

## 핵심 시스템

### 1. 생체 무기 (Living Weapon)
- 무기 자체가 Void 몬스터의 변형 — 생김새가 공격 패턴을 암시
- 근접 사용 · 던지기 · 특수기 세 가지 사용법
- 바닥에 던지면 잠깐 "자율 행동" 후 사라지거나 폭발
- 무기를 팔면 코인 환불 → 빠른 경제 루프 형성

**OnionCat 적용**: 고양이 무기 아이콘이 특수 공격 형태를 직관적으로 암시하도록 통일 (회오리 무기 = 회오리 아이콘 + 회오리 특수 공격).

### 2. 태그 시너지 (Tag Synergy)
- 각 무기에 1~3개 태그(불꽃·전기·독·냉기 등)
- 같은 태그를 2개 이상 보유 시 세트 효과 자동 발동
- HUD에 현재 태그 개수를 항상 표시 — 선택 화면에서 시너지 예측 가능
- 시너지가 생기는 무기는 강조 표시

**OnionCat 적용**: OnionCat의 세트 시스템(햇살·바람 등 10개)과 동일 설계. 태그 누적 현황을 HUD에 더 직관적으로 보여주는 UI 개선 참고.

### 3. 공유 체력 협동
- 2인 플레이 시 체력 풀 공유 (OnionCat과 동일 구조)
- 한 명이 다운되면 → 팀 체력 감소 + 짧은 시간 후 부활
- 드롭인/아웃 — 방 전환 시 자유롭게 합류·이탈 가능
- 협동 전용 기믹 방 존재 (수정 파괴, 체중 스위치 등)

**OnionCat 적용**: 이미 동일 구조 구현 ✅. 부활 시스템(Coop_Revival_System) 추가 시 Voidigo의 "잠깐 후 자동 부활" 패턴 참고.

### 4. 적 텔레그래프 설계
- 모든 공격 예고가 독특: 색상 + 소리 + 애니메이션 조합
- 혼돈스러운 화면에서도 각 공격이 구분 가능한 대비
- 보스는 패턴마다 다른 색의 포탈로 소환 위치 예고
- "느린 예고 = 더 강한 공격" 일관 규칙

**OnionCat 적용**: 현재 노랑(막기)/빨강(피하기) 2색에 더해, 보스 패턴마다 고유한 소리(SfxId)와 선입력 애니메이션을 추가하면 암기 없이 읽히는 전투 구현 가능.

### 5. 런 경제
- 현재 방에서 드롭되는 코인으로 즉시 상점 이용
- 무기를 버리면 일부 환불 → 적극적 아이템 교체 유도
- 미래 투자보다 현재 강화 우선, 결정 속도 빠름
- 한 판 30~45분으로 짧은 런 루프

**OnionCat 적용**: 씨앗 경제의 흐름 속도 조절 참고. "안 주우면 씨앗으로 자동 변환" 현재 구조와 잘 맞음.

## 플레이어가 사랑하는 것
1. **무기 다양성** — 모든 무기가 완전히 다른 플레이스타일 제공
2. **높은 판독성** — 혼돈 속에서도 무엇이 일어나는지 파악 가능
3. **짧은 런 길이** — 한 판 30~45분, 부담 없는 세션
4. **협동의 자연스러움** — 공유 체력으로 한 명도 소외되지 않음
5. **적의 개성** — 각 Voider가 고유한 이동·공격 패턴, 기억하기 쉬운 실루엣
