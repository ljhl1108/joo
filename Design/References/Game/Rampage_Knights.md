## 게임 개요

무작위로 생성되는 던전을 2인 로컬/온라인 협력으로 돌파하는 2D 픽셀아트 액션 로그라이트. 빠른 근접 전투, 랜덤 아이템, 퍼머데스로 구성된 클래식 로그라이크 루프에 코옵 요소를 더한 게임. **OnionCat과 동일한 장르(2D 코옵 액션 로그라이트)**이므로 직접 비교 분석이 가능하다.

## 핵심 메커니즘

### 랜덤 아이템 & 빌드 시스템
- 각 방 클리어 후 랜덤 아이템 드롭 또는 상점 방 등장
- 아이템 수백 종: 패시브 버프, 활성 스킬, 저주 아이템(강력하지만 페널티 동반)
- 두 플레이어가 각자 독립적인 인벤토리를 가짐
- 공유 골드 vs 개인 골드 구분 없이 두 플레이어 모두 같은 풀에서 드랍 경쟁

### 2인 코옵 구조
- 로컬 및 온라인 2인 코옵 모두 지원
- 한 플레이어가 죽으면 다른 플레이어가 구출하거나 체크포인트 방에서 부활
- 두 플레이어가 같은 화면을 공유 (카메라 분할 없음)
- 캐릭터 클래스 선택: 각자 다른 클래스 선택 가능 → 역할 분담 자연스럽게 유도

### 절차적 던전 구조
- 방 기반 탐색: 각 방이 무작위로 배치되는 구조
- 트랩, 적 그룹, 보상 방, 상점, 보스 방으로 구성
- 방 클리어 시 문이 열리는 전통적 로그라이크 방 설계

### 전투 시스템
- 가볍고 빠른 근접 공격 기반
- 구르기/회피로 적 공격 회피
- 일부 아이템으로 원거리 공격 추가 가능
- 근접과 원거리의 혼합은 아이템 운에 의존 (역할이 고정되지 않음)

## 플레이어들이 사랑하는 점

1. **즉각적인 코옵 진입**: 빠른 런 사이클 덕분에 죽어도 부담 없이 재시작
2. **아이템 조합의 재미**: "이 아이템 받을까 말까" 즉석 판단의 재미
3. **클래스 다양성**: 클래스마다 플레이스타일이 달라 반복 플레이 유인
4. **캐주얼 코옵**: 복잡한 협력 퍼즐 없이 함께 싸우는 단순한 재미
5. **저주 아이템(Cursed Items)**: 강력하지만 위험한 아이템의 도박적 재미

## OnionCat과의 비교 분석

| 항목 | Rampage Knights | OnionCat |
|------|----------------|----------|
| 코옵 형태 | 두 캐릭터가 독립 이동 | 두 캐릭터가 하나의 몸 공유 |
| 역할 분담 | 아이템으로 유동적 결정 | 근접(Cat) / 원거리(Crop)로 고정 |
| 카메라 | 공유 단일 화면 | 공유 단일 화면 (동일 과제) |
| 부활 시스템 | 파트너가 구출 | 하나의 몸이므로 동시 사망 |
| 아이템 소유 | 개인 인벤토리 | 공유 업그레이드 or 역할별 분리 |
| 진입 장벽 | 낮음 (단순 조작) | 낮음 (각자 단일 역할) |

### 배울 점

1. **저주 아이템 개념**: 강력하지만 페널티가 있는 업그레이드는 OnionCat에도 적용 가능
   - 예: "Cat 공격력 +50%, Crop 실드 쿨다운 +100%"
   - 위험한 선택을 하는 재미 → 런마다 다른 경험

2. **동일 화면 코옵 카메라**: Rampage Knights가 두 플레이어를 하나의 카메라에 담는 방식 참고
   - 두 플레이어가 너무 멀리 이동하면 카메라가 중간 지점으로 고정 (OnionCat은 이 문제가 없음 - 한 몸이므로)

3. **빠른 런 사이클**: 한 런이 20~40분 내외로 짧아 코옵 부담 감소
   - OnionCat도 짧은 런 길이(15~30분) 목표로 설계 권장

4. **클래스 선택 다양성**: 캐릭터 변형을 고정하지 않고 런마다 Cat과 Crop의 "스타일"을 변형 가능하도록 설계 가능
   - 예: Cat을 "돌진형/방어형/속도형"으로, Crop을 "단발/연사/광역형"으로 런 시작 전 선택

5. **아이템 드랍 후 빠른 결정 유도**: Rampage Knights는 아이템 설명이 간결해 빠르게 판단 가능
   - OnionCat 업그레이드 선택 카드도 핵심 수치 1~2개만 강조하는 UI 설계 권장
