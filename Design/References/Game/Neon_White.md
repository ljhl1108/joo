## 핵심 시스템

### 이중 사용 카드 메커닉 (Dual-Use Cards)

Neon White의 핵심 아이디어: **모든 카드는 두 가지로 쓸 수 있다**.

- **보유 상태**: 총·검·폭발물 등 무기로 사용 (공격)
- **버리기**: 카드를 소모해 이동 기술 발동 (이중 점프, 대시, 폭발 점프 등)

예:
| 카드 | 공격 사용 | 버리기 (이동) |
|---|---|---|
| Godkiller | 권총 2발 | 이중 점프 |
| Elevate | 샷건 | 공중 도약 |
| Fireball | 유도 폭발 | 블래스트 점프 |
| Purify | 적 바라보며 순간이동 | 적에게 도약 |

**결과**: 플레이어는 항상 "공격에 쓸 것인가, 이동에 쓸 것인가"를 선택해야 한다. 자원이 곧 판단이다.

### 시간 공격 / 랭크 시스템

- 각 레벨은 60초 내외. 목표 시간에 따라 F~S 랭크 부여
- 레벨당 숨겨진 선물(Gift) 1개 → NPC에게 주면 캐릭터 관계 심화 + 배경 이야기
- 선물을 찾으려면 최단 경로에서 벗어나야 하므로 **"최고 시간 vs 숨겨진 보물"** 선택

### 빠른 재시작 문화

- R 키 하나로 즉시 레벨 처음으로. 죽어도 0.5초 이내 재시작
- 실패 패널티가 거의 없어 "또 해봐야지"가 자연스럽게 반복됨

### 시각적 명료성

- 보유 카드가 HUD에 크게 표시 (현재 손에 뭐가 있는지 항상 인지)
- 버리기 가능 상태를 시각적으로 강조
- 배경이 깔끔해 적·탄환·플랫폼이 항상 잘 보임

### 비주얼 노벨 + 메타 스토리

- 스테이지 사이에 캐릭터 대화 (에이스, 레드, 바이올렛 등) — 짧고 위트 있음
- "천국으로 가기 위해 악마를 처치하는 영혼들"이라는 설정이 빠른 재시도 루프를 서사적으로 정당화
- 러브 스토리와 경쟁 구도가 플레이 동기 보조

## 플레이어가 좋아하는 이유

1. **즉각적인 피드백 루프**: 잘 플레이하면 빨라지는 느낌이 실시간으로 온다
2. **이중 사용 딜레마**: 단순한 규칙(두 가지 용도) 하나가 모든 결정을 흥미롭게 만든다
3. **짧은 레벨**: 한 레벨이 20~60초라 완주감이 자주 온다
4. **점층적 난이도**: 새 카드 = 새 기술 = 새 레벨 구조. 조금씩 배우고 즉시 적용
5. **수집 요소**: 선물 찾기가 탐험 동기를 제공 (클리어 이후도 즐길 거리)

## OnionCat 적용 포인트

### 1. 자원의 이중 사용 원칙

Neon White의 "공격 or 이동" 선택처럼, OnionCat도 **자원이 곧 판단**이 되는 구조를 강화할 수 있다.

- **씨앗의 이중 용도**: 씨앗을 쏘는 것(공격) vs 씨앗을 심는 것(방어·지형 제어). 현재 별도 버튼이지만, 이 선택이 더 의식적으로 느껴지게 할 수 있다.
- **장비 효과의 조건 비용**: "이 효과를 발동하려면 대쉬 충전을 1 소비" 같은 이중 사용 패턴 — 예를 들어 `발동: OnDash, 행동: 주변 불꽃`은 대쉬 기동력을 공격으로 전환하는 Neon White식 선택.

### 2. 빠른 재시도 UX

Neon White는 죽음의 속도감을 재시작 속도로 극복한다.
- OnionCat의 **죽음 → 다음 런 시작** 경로가 5초 이내인지 확인 권장
- 런 결과 화면에서 즉시 "같은 설정으로 재시작" 버튼 추가 고려

### 3. 선물/수집 시스템 → 메타 해금 연결

- 선물을 주면 스토리가 열리는 구조 → OnionCat의 **기억 파편 + 온실 NPC 대화**에 직접 적용
- 방 안의 숨겨진 수집 아이템(지금 없음) → 이를 찾으면 온실 오브젝트 해금이라는 흐름

### 4. 시각적 HUD 명료성

- 보유 자원(대쉬 충전·털뭉치·합동 게이지)이 항상 화면에 보여야 함. 현재 `CatPips`가 발밑에 있는데 전투 중 시야 중심에서 멀다 → 포지션 검토 필요
- 양파의 현재 스킬 쿨다운 상태가 한눈에 보이는지 확인
