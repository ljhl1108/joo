## 핵심 메카닉

### 기본 구조
- 최대 3인 협동 (솔로 + AI 동료 가능)
- 턴 기반 카드 전투: 플레이어 턴에 손패에서 카드를 사용 → 적 턴
- Diablo 스타일의 절차 생성 던전을 내려가는 구조

### 카드 시스템
- 각 플레이어가 독립적인 덱을 소유
- 영웅 직업별 덱 구성 (전사, 마법사, 도적 등)
- 런마다 덱을 성장시키며 내려감
- 중복 카드 = 레벨업(강화) 또는 분해

### 협동 요소
- **위치 배치**: 몬스터 줄(열) 위치가 중요 — 특정 위치 집중 공격 가능
- 공격 순서, 누가 어떤 적을 처리할지 팀 조율이 핵심
- 보호(방어) 카드를 동료에게 쓸 수 있음
- 특수 콤보: 같은 적을 여러 플레이어가 연달아 공격하면 추가 효과

### 전략 깊이
- 덱 건강 관리: 손패 너무 많으면 discarding 강제
- 에너지(마나) 시스템: 각 카드마다 소비량 다름
- 유물(Relics): 런마다 획득하는 패시브 아이템 — 덱 시너지 극대화 목표
- 몬스터 의도(Intent) 표시: 적이 다음에 뭘 할지 미리 공개

## 레벨/던전 구조
- 층별로 방을 선택해 내려가는 분기 지도 (Slay the Spire 스타일)
- 전투방, 보물방, 이벤트방, 상점방
- 엘리트 몬스터: 더 강하지만 더 좋은 보상
- 보스: 각 층마다 독특한 패턴

## 비주얼 스타일
- **종이 공예 / 팝업북** 미학 (Book of Demons에서 이어짐)
- 두꺼운 외곽선, 평면적인 색상 — 독특한 아이덴티티
- 카드 = 실제 카드처럼 물리감 있는 애니메이션
- 몬스터 = 종이 오려붙인 듯한 그래픽

## OnionCat 적용 포인트

### 1. 적의 의도(Intent) 시스템
Hellcard는 몬스터가 "다음에 무엇을 할지" 아이콘으로 공개.
OnionCat의 텔레그래프 시스템(노랑=막기, 빨강=피하기)과 철학적으로 같음.
→ **적의 다음 행동을 예고하는 것**이 "불공평하다"는 느낌 없이 어렵게 만드는 핵심 설계.

### 2. 협동 콤보 설계의 레퍼런스
Hellcard: 같은 대상에 여러 플레이어가 연달아 공격 → 추가 효과.
OnionCat의 협동 콤보(번갈아 맞히면 ×1.5)와 같은 원리.
→ 콤보 트리거 조건을 더 다양하게 확장 가능: "같은 프레임에 동시 공격" "세 번 연속 번갈아" 등.

### 3. 덱/풀 관리 UX
Hellcard는 덱이 넘치거나 너무 적어도 문제 — 적당한 크기 관리가 전략.
OnionCat의 가방 시스템에 유사한 긴장감 추가 가능:
- 가방이 꽉 찼을 때 새 아이템을 주우면 즉각 결정 강요
- 분해 vs 장착 선택이 콤보·세트 전략에 영향

### 4. 직업별 덱 정체성 → OnionCat의 역할 정체성
Hellcard: 각 영웅 직업마다 덱 성격이 다름 (공격형/방어형/지원형).
OnionCat: 고양이는 근접 장비로, 양파는 마법서 3권으로 역할을 특화.
→ "이번 런은 고양이 집중 빌드 / 양파 집중 빌드 / 균형 빌드" 같은 런마다 다른 방향성 유도.

### 5. 종이 공예 스타일 → 픽셀아트에서 "재질감" 표현
Hellcard의 종이 아트 스타일은 게임을 즉각 식별 가능하게 만듦.
OnionCat도 픽셀아트 안에서 일관된 재질감(흙·이끼·식물·돌)을 유지하면 아이덴티티 형성.
