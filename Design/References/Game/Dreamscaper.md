## 핵심 컨셉

주인공 Cassidy는 매일 밤 꿈속에서 무의식의 악마들과 싸운다. 낮에는 현실 세계(Waking World)에서 NPC들과 관계를 맺고 영구 업그레이드를 얻는다. 꿈속에서 죽으면 다음 날 밤 다시 시작 — 로그라이트 루프.

핵심 차별점: **"꿈 = 런, 현실 = 허브"** 구조로 스토리와 로그라이트가 자연스럽게 결합.

---

## 핵심 시스템

### 1. 전투 콤보 시스템 (Lucid Combat)

- **근접 무기** 5종류 (검, 도끼, 둔기 등) + **원거리 무기** 5종류 (총, 마법 등) + **보조 스킬** + **보조 스킬 2** 4슬롯 구성
- 근접↔원거리 전환이 전투의 핵심: 적에게 원거리로 스턴 → 근접으로 콤보 → 보조기로 마무리
- 플레이어가 두 가지 공격 유형을 반드시 번갈아 쓰게 설계 → **OnionCat과 구조적으로 동일**

### 2. 친화력 시스템 (Affinity System)

- 속성: 불, 얼음, 번개, 자연, 어둠, 신성
- 런 중 행동에 따라 친화력이 쌓이고, 특정 임계값 도달 시 패시브 보너스 발동
- 카드 뽑기가 아닌 **자연스러운 행동에서 성장**하는 방식 → 덱빌딩 없이 빌드감 제공

### 3. 현실/꿈 이중 루프

| 꿈속 (런) | 현실 (허브) |
|----------|------------|
| 절차적 생성 던전 | NPC 대화·관계 성장 |
| 사망 시 초기화 | 영구 업그레이드 해금 |
| 런 내 아이템 획득 | 능력 확장 |
| 악몽 보스 처치 | 스토리 진행 |

### 4. 무기 페어링

- 근접 무기와 원거리 무기를 **각각 독립 선택**해 조합
- 무기마다 고유 에임 패턴, 공격 범위, 쿨다운
- 런마다 다른 조합 → 플레이스타일 다양화

### 5. 보스 설계

- 보스마다 특정 속성 약점 또는 특정 공격 타입 면역
- "이 보스는 원거리로만 피격 가능한 약점이 있다" 식 구성
- 페이즈 전환 시 새 패턴 추가 + 속성 변화

---

## 플레이어가 좋아하는 점

1. **근접+원거리 전투의 리듬감** — 두 가지 무기를 번갈아 쓰는 것이 자연스럽고 만족스럽다
2. **꿈과 현실의 연결감** — 낮에 NPC와 나눈 대화가 밤의 던전에 영향을 미친다
3. **시각적 다양성** — 던전마다 다른 꿈의 테마 (해변, 도서관, 지하실 등)
4. **느린 메타 성장** — 죽어도 조금씩 강해지는 만족감
5. **다양한 빌드** — 무기 조합 × 속성 친화력 × 아이템 시너지

## OnionCat 적용 포인트

### 1. 근접+원거리 강제 협력의 밸런스 참고

Dreamscaper는 솔로 게임이지만 **한 캐릭터가 근접과 원거리를 번갈아 써야** 하도록 설계됐다. OnionCat은 이를 두 플레이어로 분리했다. Dreamscaper의 전투 리듬 (원거리 견제 → 근접 추격 → 원거리 마무리)이 Cat+Onion 협력 패턴 설계에 직접 활용 가능.

### 2. 보스의 "단계별 취약점 전환" 아이디어

- Dreamscaper 보스는 페이즈마다 약점 속성이 바뀐다
- OnionCat 응용: 1페이즈 = Cat만 타격 가능 → 2페이즈 = Onion만 타격 가능 → 3페이즈 = 둘 다 필요
- 협력을 **강제**하는 보스 설계의 근거

### 3. 속성/친화력 → OnionCat 시너지 시스템

- Cat+Onion의 연속 공격이 "콤보 친화력"을 쌓고, 특정 스택에서 특수 효과 발동하는 방식 참고
- `CombatModifiers`의 패시브 세트 보너스와 연결 가능

### 4. 무기 페어링 → 업그레이드 조합 설계

- Cat의 ClawStyle + Onion의 OnionSkill 각각 선택 구조가 Dreamscaper 무기 페어링과 유사
- "이번 런은 빠른 Cat + 폭발 Onion 조합"처럼 런마다 조합이 달라지게 유도

### 5. 허브 씬 NPC 시스템 → 런 간 스토리 연결

- 현재 OnionCat은 허브 씬이 미구현. Dreamscaper처럼 캐릭터(Cat, Onion)의 과거 이야기를 허브에서 풀어나가는 구조 참고 가능
