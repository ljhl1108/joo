## 핵심 메커니즘

### 전투 시스템
- **대시 + 슬래시 콤보**: 대시 중 공격 입력 시 돌진 베기 발동. 대시 자체에 무적 프레임 내장
- **에너지탄(총)**: 탄창 유한, 근접 처치로 탄환 회복 → 근거리·원거리 혼합 강제
- **연속 콤보**: 슬래시 4타 → 에너지 방전 폭발. 콤보 유지가 생존 핵심
- **무적 대시**: 정확한 프레임 타이밍이 보스 공략의 열쇠 (소울류적 감각)

### 세계관 & 아트
- **텍스트 없는 스토리텔링**: 대화 UI 전혀 없음. 픽셀 아트 컷신 + 환경 오브젝트로만 서사 전달
- **네온 팔레트 + 어두운 실루엣**: 형광 보라·분홍·파랑 계열 + 어두운 배경 → 가독성과 분위기 동시 확보
- **4방향 오픈 월드**: 4개 지역(숲·화산·수중·유적) 순서 자유. 각 지역마다 테마 적 + 보스 1마리

### 협동 (Director's Cut)
- 2인 로컬 협동: 한 명이 쓰러지면 다른 명이 부활 가능 (무적 시간 내 부활)
- 화면 공유: 두 플레이어가 같은 화면 내에 있어야 함 → 행동 조율 필요

---

## 플레이어가 사랑하는 이유

1. **타격감**: 히트스톱 0.05~0.1초 + 화면 진동 + 파티클 → 몇 번만 쳐도 "쿵" 느낌
2. **이동 유동성**: 대시 거리가 넉넉해 화면이 춤추듯 움직임. 이동 자체가 재미
3. **미스터리한 세계관**: 설명 없이 남겨진 단서들 → 팬덤 분석 문화 형성
4. **적절한 난이도**: 어렵지만 체크포인트 관대 → 입문 소울라이크 느낌

## OnionCat 적용 포인트

### 직접 적용 가능
| HLD 메커니즘 | OnionCat 적용 |
|---|---|
| 대시 무적 프레임 | Cat 대시 이미 설계됨 — 무적 프레임 수치 HLD 참고 (약 0.2초) |
| 대시+공격 돌진베기 | Cat 대시 중 슬래시 → 전방 넓은 공격 판정 추가 콤보 |
| 근접 처치로 탄환 회복 | Onion 투사체 탄환 → Cat 근접 처치 시 보충 (협력 강제) |
| 텍스트 없는 스토리 | 픽셀 컷신 + 환경 오브젝트로만 서사 전달 → 현지화 비용 0 |
| 네온 팔레트 | 배경 어둡게, 캐릭터/적에 형광 계열 강조색 사용 |

### 아트 레퍼런스
- 배경: 회색·검정 계열 + 오브젝트 형광 강조 (보라, 민트, 주황)
- 캐릭터: 단순화된 픽셀 실루엣, 메인 색상 1~2개로 식별
- 파티클: 대시 잔상 (alpha fading trail), 피격 시 색상 burst

### 협력 설계 교훈
- HLD Director's Cut은 협동이 사후 추가라 메커니즘 연동 약함
- OnionCat은 설계 단계부터 협력 → HLD보다 훨씬 유기적 협동 가능
- "한 명 쓰러지면 부활 가능" 메커니즘 → OnionCat에서 Cat 기절 시 Onion이 회복 아이템 투척 아이디어
