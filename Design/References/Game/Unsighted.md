# Unsighted

리서치 날짜: 2026-07-21

## 기본 정보

- **개발사**: Studio Pixel Punk (브라질)
- **출시**: 2021년 9월 (Steam, Switch)
- **장르**: 탑다운 픽셀아트 액션 어드벤처 (로그라이트 요소)
- **Steam**: https://store.steampowered.com/app/1051910/UNSIGHTED/
- **Wiki**: https://unsighted.fandom.com/wiki/UNSIGHTED_Wiki

## 핵심 메카닉

### Anima 타이머 — 공유 자원 압박
- **모든 자동인형(Automaton)에게 Anima(생명력)가 존재** — 플레이어, NPC, 동료 모두 포함
- **Anima 소진 시 "Unsighted" 상태**: 적대적으로 변하거나 사망 → 영구 소실
- **타이머를 늦추는 방법**: 상점 구매, 퀘스트 완료, 특정 아이템 사용
- **플레이어 선택**: 누구의 Anima를 먼저 채울지 → 도덕적 딜레마 + 전략적 자원 배분
- **난이도 설정**: 타이머 속도 조절 가능 (접근성 배려)

### 전투 시스템
- **빠른 근접 + 원거리 혼합**: 칼, 도끼, 총, 스피너 등 다양한 무기 조합
- **패링 시스템**: 정확한 타이밍에 무기로 적 공격 튕겨내기 → 스턴 + 반격 기회
- **Grinder**: 적을 쓰러뜨린 후 실행하는 처형 무브 → 빠른 킬 + 아이템 드롭 증가
- **약점 시스템**: 적마다 약한 무기 타입 존재 → 무기 교환 전략 필요
- **보스**: 패턴 기반, 패링이 핵심 열쇠

### 업그레이드 & 제작
- **Cogs(톱니바퀴)**: 주요 자원 — 무기 업그레이드, Anima 연장, 스탯 강화
- **크래프팅**: 무기/방어구를 직접 제작 가능
- **Chips**: 패시브 효과 슬롯 장착 시스템 (속도 증가, 데미지 보너스 등)

### 로컬 코-op
- **2인 동시 협동**: 한 화면, 두 컨트롤러
- **공유 Anima 풀**: 두 플레이어가 같은 Anima 자원을 공유 → 협력 & 자원 압박 동시
- **부활 시스템**: 파트너가 죽으면 쓰러진 위치에서 부활 가능 (Anima 소모)

## 플레이어가 좋아하는 것

- Anima 타이머가 만드는 "살아있는 세계" 감각 — 내가 늦으면 NPC가 정말 죽음
- 패링이 핵심인 전투 — 반응형 스킬 플레이의 만족감
- 짧은 런타임(10-15h)에 밀도 높은 경험
- 픽셀아트 품질이 매우 높음 — 애니메이션, 라이팅, 이펙트 모두 수준급
- 코-op에서 Anima 공유 + 공동 전략 필요 → 진정한 협력감

## OnionCat 적용 포인트

### 1. 공유 자원 압박 = 협력의 필연성
Unsighted의 핵심: Anima라는 **공유 자원을 두 플레이어가 함께 관리**:
- OnionCat에 적용: 두 플레이어가 공유하는 체력(HP) 풀 → 어느 한쪽이 무리하면 둘 다 위험
- 추가 아이디어: 런 내 "협력 게이지(Synergy Gauge)"를 두 플레이어가 함께 채우면 강화 이펙트 — 개인 플레이보다 협력 플레이에 보상

### 2. 패링 시스템 심화 참고
Unsighted의 패링은 OnionCat의 Crop 방향 방패 + 패링과 동일한 역할:
- 타이밍 윈도우(프레임 수) 설계 참고: 너무 좁으면 좌절, 너무 넓으면 재미 없음
- Unsighted는 패링 후 Grinder(처형)로 이어지는 흐름 → OnionCat은 패링 후 Cat의 강화 슬래시로 연결되는 콤보 설계 가능

### 3. 적 약점 + 무기 교환 → OnionCat의 역할 전환
적마다 약한 무기가 다른 설계:
- OnionCat: 근접약점 적(Cat 담당) vs 원거리약점 적(Crop 담당)의 구분을 Unsighted처럼 명확히 시각화
- 적 상태바에 아이콘으로 약점 표시 (검 아이콘 = 근접, 씨앗 아이콘 = 원거리)

### 4. Chips 슬롯 → 업그레이드 슬롯 구조
Unsighted의 Chips 시스템: 제한된 슬롯에 패시브 효과 장착:
- OnionCat 런 업그레이드에 "슬롯 제한" 도입 가능 → 무한 누적이 아닌 선택의 압박
- Cat 전용 슬롯 / Crop 전용 슬롯 / 공유 슬롯으로 분리 → 자원 배분 협의 필요
