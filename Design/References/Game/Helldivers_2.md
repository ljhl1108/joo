## 핵심 메카닉

### 1. 전략적 비대칭 협동 (Stratagem System)
- 각 플레이어가 **다른 스트라타젬(무기 세트, 서포트 장비)** 를 들고 나옴
- 팀 전체가 조합을 맞춰 시너지를 만들어야 함 — 한 명이 장갑관통, 한 명이 무리 클리어
- 스트라타젬 호출 = 방향키 입력 시퀀스 → 독특한 "스킬 입력" 경험

### 2. 프렌들리 파이어 (항상 ON)
- 아군을 오폭할 수 있음 — **실수로 팀을 날려버리는 것이 의도된 재미**
- 플레이어가 책임감을 갖고 사격 방향을 고려해야 함
- 실수 → 사망 → 웃음 → 재시도 루프가 게임의 소셜 접착제 역할

### 3. 공유 목숨 / 소환 시스템
- 팀에 공유 Reinforce 횟수가 있음 → 소진되면 실패
- 사망한 팀원을 살아있는 팀원이 소환 → 협력의 긴장감
- 소환 위치를 전략적으로 선택 (안전한 곳에 드롭)

### 4. 절차적 임무 구조
- 메인 목표 + 부목표로 구성 → 팀이 분업 가능
- 시간 제한 있음 → 결정을 빨리 내려야 함
- 메타 진행: 전쟁 기여도가 글로벌 서버에 반영됨 (사회적 소속감)

### 5. 무기/장비 다양성
- 강력한 무기일수록 아군 피해 위험도 높음
- Eruptor 스나이퍼, 로켓포 등은 근접 사용 시 자폭 위험
- 위험과 보상의 균형이 플레이어의 능동적 선택을 요구

---

## 플레이어들이 사랑하는 것

1. **실수가 재미있다** — 프렌들리 파이어, 자폭, 잘못된 스트라타젬 호출이 패배보다 웃음을 만든다
2. **각자가 중요하다** — 한 명이 장갑 파괴, 한 명이 잡몹 처리처럼 역할이 분명함
3. **압박감 속의 협력** — 의사소통 없이 직관적으로 협력해야 하는 순간이 생김
4. **다양한 빌드 조합** — 수십 개의 스트라타젬 + 개인 무기 = 매 판 다른 팀 구성

## OnionCat 적용 포인트

### 역할 분업의 명확성
- Helldivers 2처럼 **Cat = 근접 클리어 / Onion = 원거리 + 지원**이라는 역할이 명확할수록 "내가 필요한 순간"이 만들어진다
- 적 타입별로 Cat만 처치 가능/Onion만 처치 가능하게 설계 → 서로 의존성 확보

### 공유 자원으로 만드는 긴장감
- Cat과 Onion이 **공유 HP를 가진 한 몸**이라는 컨셉이 Helldivers의 공유 목숨과 유사
- "실수"의 시각화 → 잘못된 방향 실드, 의도치 않은 쿨다운 낭비 = 웃음 유발 가능

### 스트라타젬 → 조합 업그레이드
- 런마다 Cat-Onion 조합 업그레이드를 서로 다르게 고르도록 설계
- 시너지 조합이 있는 업그레이드 쌍 → Helldivers의 팀 빌드처럼 매 런마다 다른 최적 전략

### 프렌들리 파이어 아이디어
- Onion 투사체가 Cat에게 맞으면 피해 (혹은 특수 효과) → 두 플레이어가 서로를 의식해야 함
- 또는: Cat의 대쉬가 Onion의 조준을 흔든다 → 실제로 한 몸임을 실감
