## 핵심 메커니즘

### 4가지 직업 클래스
| 클래스 | 무기 | 역할 |
|---|---|---|
| 워리어 | 검+방패 | 탱커, 근접 주력 |
| 로그 | 단검 | 기습, 도망 특화 |
| 마법사 | 지팡이 | 원거리 광역 |
| 궁수 | 활 | 원거리 단발 정밀 |

- 런 시작 시 클래스 선택 → 장비는 드롭으로 교체 (클래스 중립 아이템도 존재)

### 퍼마데스 + 부활 메커니즘
- 사망 시 그 자리에 영혼 잔류 → 팀원이 영혼에 접근하면 즉시 부활
- 부활 창 시간 제한 있음 → 팀원이 적과 싸우며 부활 구조하는 긴장감
- 전원 사망 시 런 종료, 일부 골드/재료만 영구 보존

### 장비 드롭 시스템
- 적·보상 상자에서 무기·방어구 드롭 (접두 + 접미 조합의 랜덤 스탯)
- 팀원 간 장비 공유: 바닥에 버려두면 누구든 줍기 가능
- 인챈트 테이블: 골드 소모로 장비 강화, 런 내 지속

### 방 구조
- 테마별 구역 3단계 (유적 → 지하 감옥 → 마왕 성)
- 각 구역 마지막에 보스 방
- 중간에 상점 방, 무기고 방, 이벤트 방 랜덤 삽입

### 협동 특화 설계
- **연계 공격**: 워리어 공중 발사 → 다른 플레이어 공중 추격기 연결
- **어그로 분산**: 적이 팀원 각각을 별도 타겟팅 → 협력 안 하면 각개격파 당함
- **공유 자원**: 보스 처치 후 팀 전체 체력 회복 오브 드롭 (인원 비례)

## 플레이어가 사랑하는 이유

1. **친구와 함께 쉽고 재밌다**: 어려운 조작 없이 콘트롤러 꽂으면 바로 협동 가능
2. **"그 장비 나 줘!"**: 팀 내 장비 분배 논쟁이 오히려 재미 포인트
3. **부활 구조 드라마**: 쓰러진 팀원 구하러 가는 순간이 하이라이트
4. **다양한 빌드**: 드롭 랜덤성으로 런마다 다른 빌드 경험

## OnionCat 적용 포인트

### 협동 부활 메커니즘 → OnionCat 변형
- Cat 기절 시 영혼 상태 → Onion이 꽃에서 씨앗 발사해 Cat 부활
- 시간 제한(10초) 내 Onion이 적을 막으며 부활 → 긴장감 극대화
- 구현: Cat에 `isDowned` 상태 추가, Onion 부활 투사체 별도 로직

### 클래스 분화 → Cat + Onion 역할 강제
- Lost Castle은 선택적 역할 분담
- OnionCat은 구조적 역할 분리: Cat = 근접 전용, Onion = 원거리 + 방어
- "근접만 통하는 적 / 원거리만 통하는 적" → Lost Castle의 어그로 분산보다 훨씬 명확한 협력 필수 설계

### 장비 공유 결정 → 업그레이드 선택 드라마
- Lost Castle의 장비 논쟁 재미 → OnionCat: 런 중 업그레이드 선택지 나올 때 "Cat 강화 vs Onion 강화" 선택
- ScriptableObject `UpgradeData`에 `targetCharacter: Cat | Onion | Both` 필드 추가

### 방 구성 레퍼런스
- 상점 방 + 이벤트 방 + 전투 방의 비율: Lost Castle은 약 6:2:2
- OnionCat 참고 비율: 전투 60%, 상점 15%, 이벤트 15%, 보스 10%

### 구현 우선순위 힌트
- 부활 메커니즘은 협동감 핵심 → MVP 이후 1순위 추가 기능으로 적합
- "전원 사망 = 런 종료"는 퍼마데스 감각 완성에 필수
