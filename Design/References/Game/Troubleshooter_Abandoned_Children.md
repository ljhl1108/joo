# Troubleshooter: Abandoned Children

리서치 날짜: 2026-10-27

## 기본 정보

- **장르**: 한국 인디 턴제 전술 RPG (XCOM 스타일 + 깊은 커스터마이징)
- **개발/출시**: Dandylion, 2020 (얼리액세스) / 2023 (정식 1.0)
- **플랫폼**: PC (Steam)
- Steam: https://store.steampowered.com/app/800290/Troubleshooter_Abandoned_Children/
- 나무위키: https://namu.wiki/w/트러블슈터%3A%20어밴던드%20칠드런

## 장르/스타일

- 턴제 전술 + 캐릭터 수집 + 아이템 제작 + **마스터리 트리**
- 한국 인디 최고 스팀 평점 중 하나 (압도적 긍정적)
- 스토리: 한국 근미래 배경, 청소년 주인공이 불법 기업과 싸움

## 핵심 시스템

### 마스터리 (Mastery) 시스템

이 게임의 핵심. **모든 능력에 방대한 숙련도 트리가 달려있음**.

| 구성 | 내용 |
|------|------|
| 스킬 마스터리 | 스킬 하나에 수십 개의 강화 노드. 공격 범위·횟수·부가효과·쿨다운 등 |
| 반응 마스터리 | 특정 조건(적이 가까워지면, 아군이 피격되면 등)에 자동 반응 설정 |
| 특성 마스터리 | 캐릭터 기본 능력치와 패시브 강화 |
| 연계 마스터리 | 두 캐릭터 간 협동기 전용 강화 트리 |

마스터리 포인트는 레벨업과 퀘스트로 획득. 한 빌드를 완성하는 데 수백 시간이 걸림.

### 장비 시스템

- **5개 슬롯**: 무기·갑옷·헬멧·신발·악세서리
- 아이템마다 **수정(Modifier)** 3~5개 랜덤 부여
- 수정 예시: "스킬X 피해 +15%", "이동 후 공격 시 치명타율 +8%"
- **세트 아이템**: 3~6개 착용 시 강력한 세트 효과
- 아이템 제작: 소재 수집 → 원하는 스탯을 가진 아이템 제작

### 전투

- **XCOM식 타일 맵**: 커버 시스템, 고지대 유리, 시야선
- 한 턴에 이동 + 행동 1회
- 과부하(Overload): 연속 피격 시 상태이상 축적 → 에 따른 페널티
- **협동 반응**: 조건이 맞으면 A가 공격할 때 B가 자동으로 지원

### 캐릭터 & 스토리

- 약 20명의 고정 캐릭터 (가챠 없음!)
- 각 캐릭터마다 **고유한 마스터리 클래스** + **보조 클래스** 조합 선택
- 스토리와 캐릭터 개발이 분리: 메인 스토리 + 각자 서브스토리

## 플레이어가 사랑하는 이유

1. **마스터리 트리의 무한한 깊이**: 같은 캐릭터도 빌드에 따라 역할이 완전히 달라짐
2. **가챠 없음, 페이투윈 없음**: 한 번 구매로 전체 콘텐츠
3. **협동 공격의 연쇄 반응**: 잘 세팅하면 한 번의 공격이 연쇄 반응으로 이어지는 카타르시스
4. **한국 배경 + 성숙한 스토리**: 국내 플레이어에게 특히 공감

## OnionCat 적용 포인트

### 1. 세트 아이템 발동 임계값 설계

Troubleshooter의 세트는 3~6개 착용. OnionCat은 2/4/6/8단계 보너스. **핵심 질문: 플레이어가 1시간 런에서 세트를 몇 단계까지 올릴 수 있나?**

전형적인 런 흐름 (전투방 16개 × 카드 2장 + 바닥 아이템 약 10개 ≈ 42장 중 선택):
- 세트 아이템 비중이 장당 ~40% → 런 1번에 세트 아이템 10~15개 획득 가능
- 한 세트에 8개 다 채우긴 힘듦 → **2단계(빠른 첫 보너스)가 '느끼는 시작점'** 이어야 함
- 6단계 이상은 전략적으로 집중했을 때만 달성 → 고난도 플레이어의 목표

교훈: **2단계 보너스가 임팩트 있어야 세트 시스템이 "살아있다"는 느낌**.

### 2. 협동 연계 = 자동 반응 트리거

Troubleshooter의 "반응 마스터리"는 "B가 공격하면 A가 자동으로 추가타"를 세팅. OnionCat의 **협동 콤보(1초 안에 번갈아 때리면 ×1.5)** 와 구조가 유사. 차이점: OnionCat은 수동 타이밍 / Troubleshooter는 세팅 기반 자동.

**아이디어**: 장비 효과 중 "아군이 공격한 직후 내가 공격하면 보너스" 형태의 효과를 만들면 Troubleshooter의 협동 세팅 재미가 생김. 현재 협동 콤보가 이 역할을 하지만, 장비 효과로 이 콤보 보너스를 강화하거나 특화하는 방향.

### 3. 보조 클래스 = 마법서 + 화분 자리

Troubleshooter는 메인 클래스 + 보조 클래스 선택으로 역할이 바뀜. OnionCat의 마법서 3칸(Q·W·E 스킬)이 유사한 역할. 마법서 조합이 양파의 "빌드 정체성"을 만들어야 함. 예: 심기×2+돌봄 → 지속 피해형 / 사격×3 → 화력 극대형.

### 4. 한국 배경 게임의 성공 공식

Troubleshooter는 한국 근미래 + 10대 주인공 + 사회비판적 스토리가 강점. 국내 플레이어에게 익숙한 정서. **OnionCat의 "고양이가 등에 화분을 짊어진다"는 컨셉도 한국적 정서(새싹, 봄, 가족적 유대)와 연결**할 수 있음 — 스토리를 추가할 때 이 방향이 한국 플레이어 공감대를 높임.

### 5. 가챠 없음 = 드래프트 선택의 진정성

Troubleshooter가 "가챠 없음"을 강조하는 것처럼, OnionCat도 "조작이 없는 선택"을 강조할 수 있음. 런마다 드래프트로 받는 아이템이 완전히 무작위이지만 **선택지 3개가 항상 제공**되어 플레이어에게 에이전시가 있음. 이 점을 마케팅 포인트로 쓸 수 있음.
