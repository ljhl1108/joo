## 핵심 메카닉

### 캐릭터 시스템 — "Bro" 로테이션
- 레벨 곳곳에 **포로로 잡힌 Bros를 구출**하면 즉시 그 캐릭터로 교체됨
- 80~90년대 액션 영화 패러디 캐릭터 40종 이상: Rambro, Broforce One, B.A. Broracus, Brobocop 등
- 각 Bro는 **주무기 + 보조무기 + 특수 능력** 세 가지 조합이 완전히 다름
- 근접형(권투, 칼), 원거리형(소총, 로켓), 폭발형(수류탄, 폭탄) 자연스러운 역할 변화

### 완전 파괴 가능 지형 (Destructible Terrain)
- 흙·나무·금속 등 소재별 내구도, 거의 모든 지형 파괴 가능
- 폭발 → 연쇄 반응 → 지형 붕괴 → 레벨 구조 실시간 변화
- 파괴 범위가 전략적 요소: 벽을 허물어 지름길 생성 or 적을 묻어버리기

### 협동 플레이 (로컬/온라인, 2~4인)
- 팀원이 사망해도 생존자가 포로 구출 시 사망자가 그 Bro로 부활
- 화면 공유 뷰 — 플레이어들이 멀어지면 자동 줌아웃
- Friendly Fire 옵션: 서로의 폭발에 사망 가능 (카오스 모드)

### 로그라이트 요소
- Bro-op 모드: 무작위 레벨 구성, 제한 목숨
- 캠페인 모드: 고정 맵, 지역(Act) 단위 진행
- 사망 → 해당 Bro 교체 (영구 사망 아님), 구출한 Bro 풀이 소진되면 게임 오버

### 적 설계
- 돌진형, 폭발형, 방어형, 공중 이동형 등 단순하지만 조합이 다양
- 보스전: 헬기, 전차, 거대 로봇 등 환경 파괴와 결합한 연출형 보스
- 일부 적은 특정 무기(폭발, 근접)에만 확실히 대처 가능

## 플레이어들이 사랑하는 것
1. **압도적인 캐릭터 수** — 40+ Bro, 계속 새 캐릭터를 발견하는 수집 재미
2. **폭발과 파괴의 쾌감** — 지형이 무너지는 카오스가 리얼타임 레벨 변형
3. **레퍼런스 유머** — 영화 패러디의 개그, 비개이머도 웃을 수 있음
4. **즉각 리듬** — 사망 → 2초 내 재시작, 레벨 30초~2분 단위
5. **협동 시너지** — 서로 다른 Bro 조합으로 상황 해결하는 즉흥 협동

## OnionCat 적용 포인트

### 1. 역할 차별화의 시각적 명확성
Broforce는 각 Bro의 아이콘과 이름만 봐도 역할을 즉시 파악할 수 있도록 설계됨.
→ OnionCat에서 Cat(근접)/Crop(원거리) 역할도 **아이콘과 색상으로 즉시 구분** 가능해야 함.
→ Cat = 칼 아이콘(빨간 계열), Crop = 씨앗 아이콘(초록 계열) 일관 적용.

### 2. 취약점 기반 적 설계 구체화
Broforce의 일부 적이 특정 공격에 취약한 구조를 OnionCat에 직접 적용:
→ 적 머리 위 **약점 아이콘 상시 표시** (칼 = 근접 필요, 씨앗 = 원거리 필요).
→ 약점 외 데미지는 회색 숫자 + 방어막 튕기는 이펙트로 "소용없음" 시각 피드백.
→ 처음 만날 때 아이콘은 "???" → 처치 후 도감에서 공개 (발견 재미 연동).

### 3. 즉각적 업그레이드 체감
Broforce의 "포로 구출 → 새 Bro 획득 → 즉시 플레이 스타일 변화" 루프:
→ OnionCat 업그레이드도 **수치 강화보다 행동 변화**가 우선. 새 탄 패턴, 새 대시 궤적, 공격 범위 형태 변화 등 눈으로 즉시 확인 가능한 변화.

### 4. 협동 속 가독성 확보
4명이 동시에 폭발을 터뜨려도 자기 캐릭터를 잃지 않는 이유 — **아웃라인 렌더링** + **깜빡이는 무적 상태 표시**.
→ OnionCat에서 공유 몸체가 적과 뒤섞일 때 **외곽선 색상(P1=파랑, P2=초록)** 으로 즉시 인식 가능하게.

### 5. 빠른 재시작 리듬 목표
사망 → 2초 내 재시작, 레벨 30초~2분 단위.
→ OnionCat 방(Room) 설계 시 **단일 방 30초~90초 내 클리어 가능** 템포 목표.
→ 실패해도 "다시 해보고 싶다"는 느낌을 위해 로딩 없이 방 리셋.
