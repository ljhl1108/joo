# Tiny Rogues

리서치 날짜: 2026-06-11

## 기본 정보
- **개발사**: RubyDev (1인 인디 개발)
- **출시**: 2022년 9월 얼리 액세스
- **장르**: 탑다운 불릿헬 던전 크롤러 로그라이크 RPG
- **공식 사이트 / Steam**: https://store.steampowered.com/app/2088570/Tiny_Rogues/
- **Steam 평가**: 압도적으로 긍정적 (96%, 7,500+ 리뷰)
- **특이점**: 1인 개발자가 400+ 무기, 500+ 아이템, 34 클래스를 만들어낸 콘텐츠 볼륨

---

## 핵심 메카닉

### 1. 방 기반 진행 구조
- 한 플로어 = 10개 랜덤 방
- 20+ 고유 플로어 (각 플로어마다 고유한 적 세트)
- 40+ 보스 전투 (복수의 최종 보스 포함)

### 2. 도어 선택 → 보상 예고 시스템
- 방 클리어 후 여러 문 중 하나 선택
- 각 문에 다음 방의 보상 타입 표시 (무기방, 아이템방, 상점방, 챌린지방 등)
- 완전 무작위가 아닌 "예측 가능한 선택" → 전략적 빌드 플래닝 가능

### 3. 34개 캐릭터 클래스
- 전사(Warrior), 도적(Rogue), 마법사(Wizard), 성직자(Cleric), 레인저(Ranger) 계열
- 각 클래스 고유 패시브 능력 보유
- 같은 클래스도 장비/무기에 따라 완전히 다른 빌드 가능

### 4. 무기 융합 시스템
- 제단(Altar)에서 두 무기를 합체 → 두 무기의 속성을 가진 하이브리드 무기 생성
- 빌드 독창성의 핵심 — 예상치 못한 조합에서 OP 빌드 탄생
- "이번 런의 발견" 경험을 극대화하는 장치

### 5. 스탯 기반 시너지
- 힘(STR), 민첩(DEX), 지능(INT) 등 RPG 스탯 체계
- 무기/장비에 "이 스탯 특화" 태그 → 스탯 집중 투자 시 시너지 발동
- 100개 이상의 런 획득 가능 특성(Trait)

## 메타 진행
- 캠프파이어(Campfire) 시스템: 런 완료 후 메타 퍽(Perk) 해금
- 난이도 확장: 부정적 게임 효과를 추가하면 메타 XP 증가 → 도전적 플레이 보상

---

## 플레이어가 좋아하는 것
1. **압도적인 콘텐츠 볼륨** — 1인 개발 게임이라 믿기 힘든 분량
2. **매 런마다 다른 빌드** — 40회 플레이해도 새로운 조합 발견
3. **무기 융합의 창의성** — "이 두 개를 합치면?" 실험 욕구 자극
4. **도어 선택의 전략성** — 다음 보상 미리 알고 루트 계획
5. **개발자 철학** — 개발 일지에 모든 설계 결정 투명하게 공유

## OnionCat 적용 포인트

1. **도어 선택 + 보상 예고** — 방 전환 시 다음 방 타입 아이콘 표시 (검 = 근접 적 강화, 총알 = 원거리 적 강화). 두 플레이어가 입장 전 전략 논의 → 협력 게임플레이 강화

2. **무기 융합 → 협력 스킬 합성** — 특정 방에서 고양이 스킬 + 작물 스킬을 "합성" → 두 플레이어의 능력이 합쳐진 고유 협력기 1개 생성

3. **10방 구조** — OnionCat도 플로어당 5~8개 방 → 보스 구조 채택. 방 수가 명확해야 플레이어가 자원 관리 (언제 업그레이드?, 언제 아끼?) 판단 가능

4. **클래스 선택 → 런별 페르소나** — 런 시작 시 고양이는 "공격형/방어형/속도형" 선택, 작물은 "연사형/단발형/지원형" 선택 → 매 런 다른 역할 분담 경험

5. **1인 개발 전략** — Tiny Rogues의 성공 공식: 핵심 루프 소수(이동+전투+레벨업) × 콘텐츠 다양성(400+ 무기). OnionCat도 핵심 루프를 먼저 완성한 후 적/업그레이드 수량으로 다양성 확장
