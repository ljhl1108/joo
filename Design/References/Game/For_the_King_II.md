## 핵심 게임 메카닉

### 기본 구조
- 턴제 이동 + 실시간 전투 혼합 형식
- 절차적 생성 월드맵에서 퀘스트, 던전, 이벤트 탐험
- **1~3인 협동**, 한 명이 호스트/모든 플레이어가 각자 영웅 조종
- 모든 플레이어가 전멸하면 런 실패 (진정한 퍼마데스)

### 공유 결정 시스템 (OnionCat에 가장 관련성 높음)
- **Lore Store**: 런 간 영구 해금 시스템 — 팀이 함께 점수(Lore) 쌓아 새 직업/아이템 해금
- **공유 인벤토리 슬롯**: 일부 아이템은 개인 소유, 일부는 파티 공유 (누가 들지 결정)
- **퀘스트 분기**: 팀 전원 동의해야 특정 경로 선택 가능한 이벤트 존재
- **턴 순서**: 모든 플레이어가 번갈아 행동 → 상대방 턴 동안 전략 논의

### 직업 및 역할 시스템
- Herbalist (힐러), Treasure Hunter (탐색), Hunter (원거리), Blacksmith (탱커) 등
- 각 직업은 완전히 다른 플레이스타일 → 역할 분업이 자연스럽게 형성
- 직업별 고유 패시브와 특수 액션 (턴 내 1회 사용)

### 전투 시스템
- 턴 내에서 이동 → 공격 → 스킬 사용 순서
- 주사위 굴림 기반 명중/회피 → 확률적 긴장감
- **Focus 시스템**: Focus 포인트 소모 시 주사위 재굴림 가능 (공유 자원)

## 플레이어가 좋아하는 것

1. **"We decided together"** — 잘못된 결정도 함께해서 웃으며 넘김
2. **간결한 시각적 스타일** — 타일 기반 월드맵 + 미니멀 전투 UI, 가독성 좋음
3. **런 간 성장감** — Lore Store를 통해 점진적으로 세계 확장
4. **다양한 조합** — 직업 3개 조합으로 완전히 다른 협력 스타일
5. **입문 장벽 낮음** — 전략성은 깊지만 기본 조작은 쉬움

### 자주 언급되는 불만
- 턴제라 액션감 부족
- 온라인 동기화 딜레이
- 후반 난이도 밸런스

## OnionCat 적용 포인트

### 1. "공유 자원 배분" 긴장감
For the King II의 Focus(공유 자원)는 팀이 "누가 재굴림할지" 실시간으로 소통하게 만든다. OnionCat에서:
- **공유 HP 바** 대신 **공유 MP(마나)** 도입 — Cat의 대시와 Onion의 방패 충전이 같은 풀 사용
- 한 플레이어가 너무 많이 쓰면 다른 플레이어 기능 제한 → 자연스러운 자제와 소통 유도
- 협력 보상: 두 플레이어가 동시에 낮게 유지하면 폭발적 보너스 발동

### 2. Lore Store → OnionCat 런 간 해금 시스템
For the King II처럼 팀이 함께 모은 포인트로 새 캐릭터/모드 해금:
- 런 클리어마다 "정원 포인트" 획득
- 메뉴 화면 "정원"에서 새 적/방 타입/코스튬 해금
- 실패해도 일부 포인트 적립 → 보상감 유지

### 3. "역할 비대칭 + 협력 필수" 직업 구조
For the King II의 직업 시스템처럼 OnionCat 캐릭터 성장 방향 분기:
- Cat 성장 트리: 근접 특화 (슬래시 범위) / 기동 특화 (대시 거리) / 탱커 특화 (피해 감소)
- Onion 성장 트리: 투사체 특화 (발사 패턴) / 방어 특화 (파리 판정) / 지원 특화 (Cat 버프)
- 두 트리가 서로 시너지 있을 때 "연금술" 이펙트 발동

### 4. 이벤트 분기 + 양측 확인 시스템
For the King II에서 중요 이벤트는 팀 전원 동의 필요. OnionCat에서:
- 특수 방(상점/보스 전 선택지)에서 양 플레이어 버튼 동시 입력으로 선택 확정
- 한 명이 거부하면 다른 선택지로 전환 → 갈등 없이 의견 조율
- "혼자 결정할 수 없는 순간"이 협력의 핵심 경험으로 작동
