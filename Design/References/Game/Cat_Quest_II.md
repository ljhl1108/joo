## 핵심 메카닉

### 1. 2인 코업 구조
- 플레이어 1은 고양이(Cat), 플레이어 2는 개(Dog)로 역할 분담
- **역할 비대칭**: 고양이는 근접 특화, 개는 일부 마법 특화 — 서로 다른 성격의 주인공이 협력
- **공유 화면**: 두 캐릭터가 멀어지면 카메라가 자동으로 줌아웃해 두 캐릭터를 포함
- 1인 플레이 시 NPC 캐릭터가 따라다니며 기본 공격 보조

### 2. 전투 시스템
- **자동 공격(Auto-Attack)**: 범위 내 적에게 자동 근접 타격 (타이밍 기반 연타 콤보 없음)
- **스킬/마법(Active Skills)**: 쿨다운 기반 스킬 6개 장착 슬롯 — 버튼 누르면 즉시 시전
- **구르기 회피(Roll/Dodge)**: 단순 방향 구르기, 짧은 무적 프레임
- **무기/방어구 장착**: 아이템 스탯에 따라 스킬이 달라짐 (장비 = 스킬 언락)

### 3. 탐험 & 던전
- **오픈월드 오버맵**: 격자 기반이 아닌 자유 이동 세계 지도
- **던전 방 구조**: 던전 내부는 방으로 나뉘어 적 클리어 후 다음 방 이동
- **퀘스트 마커**: 맵에 아이콘으로 퀘스트/던전 위치 표시 — 길 찾기 쉬움

### 4. 성장 시스템
- **레벨업**: 경험치로 HP/ATK/MAG 스탯 자동 증가
- **장비 드롭**: 적·보물상자에서 랜덤 장비 드롭, 스탯 비교 후 장착
- **골드 상점**: 마을에서 특정 장비 구매 가능

## 협력 플레이 포인트

| 요소 | Cat Quest II 구현 | OnionCat 참고 포인트 |
|------|-----------------|-------------------|
| 역할 비대칭 | 고양이(근접)/개(마법) | Cat(근접)/Onion(원거리) — 이미 유사 구조 |
| 공유 화면 카메라 | 두 캐릭터 거리에 따라 줌 자동 조절 | OnionCat은 1몸이라 불필요, 하지만 분리 시 참고 |
| 어시스트 부활 | 쓰러진 팀원을 살릴 수 있는 부활 인터랙션 | 공유 체력이 0이면 동시 사망이지만, 다운 → 부활 페이즈 고려 |
| 공동 스킬 | 특별 조합 공격 없음 | OnionCat은 두 플레이어 협력 공격이 핵심 차별점 |

## 플레이어들이 사랑하는 요소

1. **접근성**: 자동공격 + 쿨다운 스킬로 입력이 단순 → 초보자도 쉽게 플레이
2. **귀여운 비주얼**: 픽셀/chibi 스타일 고양이 세계관 — 유머 가득한 다이얼로그
3. **금방 끝나는 로컬 코업**: 4~6시간 클리어 가능한 볼륨, 부담 없는 협력
4. **장비 수집 재미**: 다양한 장비가 스킬을 바꾸므로 장비 뽑기가 재미있음
5. **반응성 좋은 전투**: 몬스터 공격에 빨간 원 경고가 표시되어 피할 수 있음

## OnionCat 적용 포인트

### A. 공격 예고 시스템 (Telegraph)
- Cat Quest II는 **적 공격 직전에 빨간 원 또는 선으로 공격 범위를 표시**
- OnionCat도 적 공격 0.5~0.8초 전에 바닥 경고 마커 → 협력으로 피하거나 방어하는 루프 강화

### B. 장비 = 능력 변경 구조
- 장비를 바꾸면 스킬 슬롯에 들어오는 능력이 달라짐
- OnionCat의 업그레이드 아이템 설계 시 "획득 아이템 = 능력 추가/교체" 방식으로 참고
- 예: Onion이 방패 업그레이드 획득 → 패리 윈도우 확장 + 카운터 투사체 추가

### C. 적 근접/원거리 비율
- 근접형 적 다수 + 원거리 적 소수 조합이 기본
- 근접형은 고양이가 처리, 원거리는 어니언이 처리 → OnionCat에서도 **전투 역할 분담 명확화**를 위한 적 배치에 직접 적용

### D. 단순하지만 협력 필요한 몬스터 설계
- 실드를 든 적: 방패 방향에서 공격해야 데미지 → 다른 플레이어가 반대편 유인
- OnionCat: 특정 약점 방향(Cat 근접 only / Onion 원거리 only)으로 강화하면 자연스럽게 협력 강제

### E. 귀여운 세계관 & 분위기
- 고양이/식물 테마, 유머러스한 나레이션 → OnionCat도 어두운 세계관보다 **밝고 귀여운 피그마 스타일** 고수
- NPC 대사에 고양이 말장난("fur real?", "paw-some") 같은 언어유희 → 한국어 양파/고양이 언어유희 검토

## 경쟁/차별점 분석

| 항목 | Cat Quest II | OnionCat |
|------|-------------|---------|
| 협력 방식 | 별개 몸, 공유 화면 | 하나의 몸 공유 — 훨씬 독특 |
| 전투 깊이 | 얕음(자동공격) | 깊음(Cat 슬래시 타이밍 + Onion 조준 + 패리) |
| 로그라이크 요소 | 없음(선형 진행) | 있음(랜덤 룸, 런 업그레이드) |
| 난이도 | 낮음 | 중간~높음 (협력 학습 필요) |
| 플레이 시간 | 4~6시간 | 런당 30~60분 목표 |

→ **OnionCat은 Cat Quest II보다 협력 깊이가 훨씬 깊고 로그라이크 구조로 리플레이 가치 높음**
