## 핵심 시스템

### 파친코 전투 메커닉

전투가 일반 공격이 아닌 **핀볼/파친코 패널**로 이루어진다:
- 화면 아래쪽에 적, 화면에 핀과 페그(오브 — 마법 구슬)가 박혀 있음
- 플레이어가 구슬을 위에서 조준해 발사 → 핀에 튕기며 적에게 피해
- **오브(Orb)**: 구슬 자체가 카드 덱. 다양한 종류의 오브를 드로우해 발사
  - 기본 오브: 튕길 때마다 피해 1회
  - 폭발 오브: 마지막 튕김에 폭발 피해
  - 독 오브: 맞은 적에게 독 적용
  - 포탄 오브: 직선 관통
- **페그(Peg)**: 핀 = 피해 증폭 포인트. 같은 오브가 같은 페그를 맞출수록 콤보 배율 증가

### 유물(Relic) 아이템 시스템

Hades/Slay the Spire식 아이템 수집 시스템이지만, **물리 법칙과 상호작용**이 핵심:
- "구슬이 튕길 때마다 15 피해 추가" → 튕김이 많을수록 유리
- "오브가 적을 맞힐 때마다 1골드 획득" → 플레이 스타일이 돈벌이 방식으로 바뀜
- "독 상태 적이 받는 피해 2배" → 독 오브 중심 덱 구성 유도

유물들이 서로 시너지를 일으켜 **개발자도 예상 못한 무한 콤보**가 종종 발생한다.

### 덱 빌딩 요소

- 오브(Orb)가 덱. 전투 전에 무작위 드로우
- 보상으로 오브 추가 또는 유물 획득
- 덱이 작을수록 원하는 오브가 자주 나오지만, 다양성이 없어 적응력 떨어짐
- 덱 제거 메커닉 없음 (Slay the Spire와 달리) → 덱이 점점 커짐

### 맵 구조

- Slay the Spire식 분기 지도
- 전투 / 엘리트 / 상점 / 보물 / 이벤트 / 보스 분포
- 스테이지마다 다른 적 구성

## 플레이어가 좋아하는 이유

1. **물리 만족감**: 구슬이 핀에 튕기며 큰 피해를 내는 순간의 쾌감이 즉각적
2. **간접 조작의 긴장감**: 정확한 조준이지만 물리 법칙이 개입 → 약간의 불확실성이 흥미를 유지
3. **시너지 발견**: "이 유물 + 저 오브가 이렇게 상호작용한다니!" 발견의 즐거움
4. **관람 친화성**: 플레이 영상이 직관적으로 재미있어 보임 → 입소문 확산에 유리
5. **접근성**: 전통 로그라이트보다 조작이 단순 (조준 + 발사 하나)

## OnionCat 적용 포인트

### 1. 아이템 시너지 설계 원칙

Peglin의 아이템은 **물리 법칙 위에 레이어를 추가**하는 방식으로 설계된다. 각 유물이 독립적으로 단순하지만 합쳐지면 복잡해진다.

OnionCat 장비도 같은 원칙을 적용할 수 있다:
- "패링 성공 시 다음 씨앗 관통" + "관통 씨앗이 적중한 적 수만큼 합동 게이지 충전" = 두 효과 조합이 패링-원거리-게이지 루프를 만듦
- 각 `GearEffect`는 단독으로 단순해야 하지만, 조합 시 창발적 플레이가 나와야 한다
- **장비 163종 중 시너지 조합 테스트**가 밸런스의 핵심 — Peglin은 이걸 얼리 액세스 기간 내내 했다

### 2. 쿨타임 없는 핵심 행동

Peglin의 구슬 발사는 쿨타임이 없다 (오브가 소진되면 다시 드로우). OnionCat에서:
- 고양이 할퀴기도 쿨타임 없이 빠르게 칠 수 있어야 함 (현재 그럼)
- 쿨타임이 있는 것(걷어차기·대쉬·스킬)은 **분명한 가치**가 있어야 하며, 쿨타임이 없는 것과 체감 차이가 명확해야 함

### 3. 빌드 방향성의 시각화

Peglin은 덱에 어떤 오브가 있는지, 유물이 뭔지 항상 보인다.
- OnionCat 장비 화면에서 현재 세트 진행도·보너스가 직관적으로 보이는지 확인
- "다음 세트 효과까지 X개 더 필요"를 HUD 어딘가에서 힌트로 주는 것 고려

### 4. 물리 기반 판정의 만족감

Peglin은 피해가 "물리적으로 납득 가능"하다 — 더 많이 튕길수록 더 많이 아프다.
OnionCat에서:
- 걷어차기 CRASH 피해는 날아간 거리에 비례 (현재 고정?) → 거리 비례 피해로 바꾸면 더 자연스럽게 느껴질 수 있음
- 벽에 세게 박히면 기절 시간이 더 길어지는 식의 **물리 기반 결과**를 강화
