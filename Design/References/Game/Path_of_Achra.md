## 핵심 메커니즘

### 1. 압도적인 패시브 트레이트 스태킹 시스템
Path of Achra의 가장 독보적인 특징: **수백 개의 패시브 트레이트가 조합되어 완전히 새로운 플레이스타일을 만든다.**

- 캐릭터마다 고유 트레이트 목록이 있지만, 선택지는 런마다 무작위
- 각 트레이트는 단독으로는 평범하지만 **조합 시 시너지가 폭발적**
- 예: "공격마다 독 1 중첩" + "독이 있는 적 공격 시 2배 피해" + "독 중첩 소모 시 HP 회복" → 독 기반 완전히 다른 빌드
- 트레이트 간 연쇄 반응이 가능하여 플레이어가 직접 콤보를 발견하는 재미

### 2. 직업과 신앙 시스템
- **직업(Class)**: 초기 스탯과 시작 트레이트 결정 (10종 이상)
- **신앙(Faith)**: 별도 트레이트 풀을 제공, 일부 신앙은 상충되어 한 번에 하나만 가능
- 직업 × 신앙 × 트레이트 조합으로 경우의 수가 사실상 무한

### 3. 보상 선택의 명확한 규칙
- 레벨업마다 **3개 중 1개** 트레이트 선택
- 선택지는 완전 무작위가 아니라 **현재 빌드 방향에 맞는 트레이트가 가중치** 적용
- 플레이어가 어떤 방향으로 가고 싶은지 명확히 알 수 있도록 트레이트 카테고리와 태그 표시

### 4. 전투 시스템
- 턴제 그리드 이동 + 위치전략
- 공격마다 트레이트 효과가 체이닝되어 처리
- 사망 시 로그에서 **"무엇이 나를 죽였는지"** 명확히 표시 → 개선 방향을 플레이어가 직접 추론

---

## 플레이어들이 사랑하는 점

1. **빌드 발견의 쾌감**: 직접 시너지를 발견할 때의 "유레카" 순간
2. **극단적인 다양성**: 100판을 해도 같은 빌드가 나오지 않는다
3. **단순한 UI에 복잡한 내용**: 카드나 아이콘 없이 텍스트 기반이지만 오히려 가독성이 높음
4. **공정한 패배감**: 죽었을 때 "빌드가 약해서" vs "플레이가 나빠서"를 구분할 수 있음
5. **빠른 런 시간**: 한 판 15~30분, 반복 플레이에 최적화

## OnionCat 적용 포인트

### 1. 세트 보너스 설계에 직접 적용
Path of Achra의 트레이트 연쇄가 보여주는 것: **단일 세트 보너스보다 세트들 간의 상호작용이 더 큰 재미를 만든다.**

현재 OnionCat의 세트(햇살·바람 등)는 각자 독립적인 보너스를 준다. Path of Achra 스타일로 발전시키면:
- 햇살 3단계 보너스 "불꽃" 상태이상 적용
- 바람 세트 "불꽃인 적 공격 시 쿨다운 감소"
- 두 세트를 합치면 연속 공격 사이클이 형성되는 구조

```
햇살 → 불꽃 적용 → 바람이 연쇄 → 쿨다운 단축 → 더 빠른 햇살 발동
```

### 2. 보상 선택지 가중치 알고리즘
현재 OnionCat은 완전 무작위 3장 선택. Path of Achra의 "빌드 방향 가중치"를 도입하면:
- 플레이어가 햇살 세트를 2개 이상 모으면 → 햇살 아이템 출현 확률 +30%
- 단, 너무 강하게 가중치를 주면 다양성이 사라짐 → 60% 가중 + 40% 순수 무작위 혼합 추천

OnionCat 구현: `RewardTable.Pool()`에 현재 `RunData.catGear/cropGear`의 세트 카운트 기반 가중치 추가

### 3. "왜 죽었는지" 사후 분석 화면
Path of Achra는 로그에서 마지막 10개 행동과 각각 어느 트레이트가 발동했는지 표시.
OnionCat 사망 화면에 추가할 수 있는 것:
- 마지막으로 받은 피해 소스 (어느 적의 어느 공격)
- 가장 많은 피해를 준 아이템/세트
- 가장 많이 발동된 효과

### 4. 패시브 트레이트 태그 시스템
Path of Achra는 각 트레이트에 `[독][공격마다][위치]` 같은 태그 표시. OnionCat 아이템 카드에 적용:
- `[햇살][공격마다][불꽃]` → 한눈에 어떤 세트/상황에 발동되는지 파악
- 현재 `GearEffect`의 `EffectTrigger/EffectAction`을 태그로 노출

### 5. 극단적인 빌드를 허용하는 밸런스 철학
Path of Achra는 "지나치게 강한 빌드"를 금지하지 않는다. 오히려 그것을 목표로 삼는다.
OnionCat도 "황금 조합"이 존재하되 그것을 발견하는 과정 자체가 재미가 되어야 함:
- 너무 강한 세트 조합은 에픽/레전더리 희귀도로 접근 난이도를 높임
- 완전히 막는 것보다 발견하기 어렵게 만드는 것이 플레이어 경험에 좋음
