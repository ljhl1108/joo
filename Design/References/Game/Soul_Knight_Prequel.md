# Soul Knight Prequel

리서치 날짜: 2026-11-27

## 기본 정보

- **장르**: 액션 로그라이트 / 협동 RPG
- **개발사**: ChillyRoom (중국)
- **출시**: 2023년 11월 (iOS/Android), PC 미출시
- **공식 사이트**: https://soulknightgame.com/prequel
- **플레이어 수**: 1~4인 협동 (온라인/로컬)
- **Soul Knight와의 관계**: 프리퀄 — Soul Knight 세계관의 과거를 다룸

---

## 핵심 메커니즘

### 클래스 시스템
- 약 30+ 클래스 (기사·마법사·궁수·암살자 등) — 각 클래스마다 고유 스킬 트리
- 클래스별 무기 타입 제한 있음 (기사: 근접, 마법사: 스태프 등)
- 같은 클래스를 계속 올리면 **클래스 마스터리** 보너스 획득
- **클래스 전직**: 특정 조건 달성 시 더 강한 클래스로 발전 가능

### 장비 & 세트 시스템
- 무기/방어구/악세서리 슬롯 (클래스마다 슬롯 구성 차이)
- **세트 보너스**: 같은 테마 장비 2~4개 모으면 추가 효과 발동
  - 예: "용사 세트 2개" → 공격력 +15%, "용사 세트 4개" → 쿨다운 -20% 추가
- 장비 희귀도: 일반·희귀·에픽·레전더리·신화
- 중복 장비: 분해 → 강화 재료로 사용

### 비대칭 협동
- 1인: 혼자 모든 역할 담당
- 2~4인: 클래스 간 역할 분담 (탱커·딜러·힐러·서포터)
- **협동 콤보**: 특정 클래스 조합이 "팀 시너지 보너스" 발동
  - 예: 기사 + 성직자 조합 → "성전사 콤보" → 기도 스킬 강화
- **공유 자원 없음** — 각자 HP, 각자 MP, 각자 아이템 (온라인 협동)
  - 로컬 협동에서 공유 아이템 가방 옵션 있음

### 던전 구조
- 각 스테이지: 10~15개 방 → 보스
- 방 타입: 전투 / 엘리트 / 보물 / 상점 / 쉬어가기
- 보스 클리어 → 다음 스테이지 (총 6개 스테이지, 최종 보스)
- 중간 세이브: 없음 (한 판에 완주 or 처음부터 — 모바일 특성)

### 성장 (런 간 메타 진행)
- **고대의 흔적**: 판마다 얻는 화폐 → 영구 패시브 해금
- 클래스 마스터리 레벨업 → 해당 클래스 고유 장비 풀 확대
- 첫 완주 후 "심연 모드" 해금 (로그라이크 도전 모드)

## 플레이어들이 좋아하는 것

1. **클래스 다양성** — 30+ 클래스의 조합 탐색이 재플레이 동기
2. **팀 시너지 발견** — 예상 못 한 조합이 폭발적인 성능을 낼 때
3. **세트 완성의 보람** — 4피스 세트 완성 순간의 성능 도약
4. **Soul Knight IP 연속성** — 전작 팬들이 익숙한 세계관에서 새 경험

## OnionCat 적용 포인트

### 비대칭 협동 클래스 비교
| Soul Knight Prequel | OnionCat |
|---|---|
| 기사 = 근접·탱크 | 고양이 = 근접·충돌 |
| 마법사 = 원거리·MP 관리 | 양파 = 원거리·씨앗·스킬 |
| 팀 시너지 콤보 | 협동 콤보 게이지 |
| 클래스 조합 보너스 | 세트 보너스 (고양이+양파 합산) |

### 세트 시스템 단계 설계 힌트
- Soul Knight Prequel의 2피스/4피스 단계 나누기가 검증된 패턴
- OnionCat도 세트 1단계(2개) / 2단계(4개) 구조가 현재 설계
- **핵심 차이**: SoKP는 한 플레이어 혼자 세트를 완성, OnionCat은 **고양이+양파 합산** → 협동을 필수로 만드는 고유한 메커니즘

### 모바일 세이브 없는 모델의 단점
- SoKP는 세이브 없이 한 판에 완주해야 → 1~2시간 한 번에 해야 함 → 이탈률 높음
- OnionCat은 중간 세이브(`MidRun_Save_Resume_UX.md`) 필수 → 30분 단위 플레이 가능하게

### 클래스 마스터리 → 온실 연결
- SoKP의 "클래스 마스터리 레벨 → 해당 클래스 장비 풀 확대"
- OnionCat 온실(`GreenhouseScreen`)과 구조 동일: 메타 화폐로 장비 해금 → 보상 풀에 추가

### 협동 콤보 UX
- SoKP는 팀 시너지를 **팝업 배너**로 알림 ("성전사 콤보 발동!")
- OnionCat도 세트 보너스 2단계 달성 시 짧은 배너 or 플래시 연출 추가 고려
