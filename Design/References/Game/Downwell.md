## 핵심 메카닉

### 건부츠 (Gunboots)
- 아래로 뛰어내리면 총알이 발사됨 — 이동과 공격이 완전히 통합
- 적 또는 장애물에 착지하면 탄창 자동 리필 (공중에서 재장전 불가)
- 이 단일 메카닉이 "공격 → 착지 → 재장전 → 공격" 루프를 완성함

### 콤보 시스템
- 땅에 발 닿지 않고 연속 처치 시 콤보 증가
- 콤보가 높을수록 젬 보너스, 체력 드롭 확률 상승
- 위험 감수 vs 안전 착지의 긴장감 생성

### 컬러 팔레트
- 게임 내에서 팔레트를 수집해 적용 가능
- 팔레트는 화면 색상만 바꾸는 게 아니라 **게임플레이 가시성**에 영향
- 일부 팔레트는 다른 색으로 표현돼 난이도가 바뀜 — 슬라이딩 난이도 시스템

### 스타일 (업그레이드 계열)
- 샷건 / 기관총 / 폭탄 등 건부츠 모드 3종 선택
- 각 스타일이 플레이 패턴을 근본적으로 바꿈
- 런 시작 시 선택 → 해당 런의 방향성을 즉시 결정

### 방 구조
- 세로 스크롤 절차 생성
- 가게 → 도전 방 → 보스 → 반복
- 방은 단순하지만 오브젝트 조합(스파이크, 이동 플랫폼, 물, 어둠)이 난이도 생성

## 플레이어가 좋아하는 점

1. **극도로 심플한 컨트롤** — 방향키 + 점프/사격 1버튼, 누구나 즉시 이해
2. **이동 = 공격 = 전략** — 세 가지가 하나로 묶인 우아한 디자인
3. **짧은 런** — 한 런이 10~20분, 반복 플레이 부담 없음
4. **픽셀아트의 완성도** — 2색 컬러팔레트가 주는 강렬한 미적 정체성
5. **발견의 쾌감** — 숨겨진 방, 비밀 아이템이 탐험 동기 부여

## 특기 사항: 스코프 제약의 교훈

Downwell은 **1인 개발자가 3개월 만에 만든 게임**이다.  
- 색 팔레트를 2색으로 제한 → 아트 작업량 90% 절감
- 이동 방향을 '아래'로만 제한 → 설계 복잡도 대폭 감소
- 적 타입을 최소화하고 배치 조합으로 다양성 창출

**초보 개발자 교훈**: 제약이 창의성을 만든다.  
스코프를 줄일수록 완성도가 올라간다.

## OnionCat 적용 포인트

### 1. 이동-공격 통합 철학
고양이의 대시와 파(P2)의 방어막이 별개 버튼인 현재 설계를 점검.  
"이동 자체가 공격/방어가 되는 순간"을 OnionCat에도 만들 수 있을까?  
예: 대시 중 적 관통 시 대미지 → 단순히 이동하면서 공격이 발생

### 2. 짧은 런 설계
Downwell의 10~20분 런 구조를 OnionCat 목표 런 시간의 기준점으로 활용.  
초보 개발자가 집중해야 할 체감 길이: "한 번 해봐야지"가 나오는 길이.

### 3. 콤보 × 협동 연계
Downwell의 콤보 시스템처럼, OnionCat도 연속 처치 시  
P1(근접) + P2(원거리)가 교대로 킬을 이어가면 콤보 보너스를 주는 시스템 검토.  
→ 협동 플레이 인센티브가 생기는 자연스러운 설계

### 4. 2-3색 픽셀아트 스타일 참고
컬러팔레트 시스템의 "색 수 제한" 접근은 OnionCat 아트 방향성에 직접 적용 가능.  
적은 색으로 선명한 캐릭터 실루엣 → 전투 가독성 향상

### 5. 적 다양성 접근법
적 유형을 최소화하되 **배치와 조합**으로 다양한 전투 상황을 만드는 방식.  
OnionCat 초기 버전에서 적 수를 5~7종으로 제한하고 배치 조합에 집중.
