## 핵심 메카닉

### 1. 패리 중심 전투 시스템
- 모든 적 공격에 **정확한 타이밍 패리** 가능
- 패리 성공 시: 적 스턴 + 반격 기회 + **스피릿 게이지 충전**
- 패리 실패 시 데미지 받음 — 리스크/리워드가 명확
- "파악 → 패리 → 반격" 루프가 전투의 핵심 흐름

### 2. 스피릿 시스템 (Spirit)
- 패리와 적 처치로 스피릿 게이지 채움
- 스피릿으로 **특수기(Blessings)** 발동 → 강력한 광역 공격, 회복, 버프
- 게이지 관리가 전략의 핵심

### 3. 로그라이크 업그레이드 구조
- 런마다 **Blessings** (능력) 선택: 10개 이상의 신적 속성 카테고리
- 각 Blessing은 **패리, 근접, 원거리, 이동** 등 역할 분류
- Blessing 조합이 런 빌드를 결정 (Hades의 Boon 시스템과 유사)
- **아티팩트**: 런 시작 전 선택하는 영구 아이템 (패시브 효과)

### 4. 플랫포머 + 공중 전투
- 높은 이동성: 더블 점프, 공중 대시, 공중 패리 모두 가능
- 적도 공중에서 공격 → 2D 플랫포머 공간 완전 활용
- 공중 콤보와 지상 콤보 다름

### 5. 무기 시스템
- 기본 근접 무기(칼, 망치 등) + 원거리 투사체(활 등) 조합
- 런 중 무기 교체 가능
- 무기 유형에 따라 Blessing 효과 달라짐

## 플레이어가 좋아하는 것

1. **패리 피드백**: 성공 시 사운드+비주얼 임팩트가 매우 만족스러움
2. **빠른 런 속도**: 30~40분 내 완주 가능 → "한 판만 더" 중독성
3. **Blessing 조합 다양성**: 매 런마다 다른 빌드 가능
4. **공중 액션의 유연함**: 전투가 평면에서 벗어나 입체적으로 전개

## OnionCat 적용 포인트

### 1. 패리 피드백 디자인 → Player 2 방패/패리 시스템
- Spiritfall의 패리 성공 연출: 짧은 히트스톱 + 반짝임 이펙트 + 튕기는 사운드
- OnionCat Player 2 패리 성공 시 동일한 3중 피드백 구현 목표:
  ```
  패리 성공 →
    1. 히트스톱 0.1초
    2. 방패 + 적 공격 교차점에 파티클
    3. 반격 창구 0.5초 하이라이트 (적 몸 깜빡임)
  ```

### 2. 스피릿 게이지 → OnionCat "합체 게이지"
- 패리/처치로 채우는 공유 게이지 → "합체 필살기" 발동 조건으로 활용
- Player 1(근접 처치) + Player 2(패리 성공) 둘 다 게이지 기여 → 협력 보상

### 3. Blessing 카테고리 → 업그레이드 분류 체계
- 근접(Cat) 전용 / 원거리(Crop) 전용 / 공용(공유 몸) 3개 카테고리로 분류
- 카테고리 간 시너지 Blessing 존재 → 협력 유도

### 4. 무기 전환 개념 → 약점 시스템 보강
- Spiritfall처럼 근접/원거리 중 적 약점에 맞는 쪽 선택
- OnionCat의 "일부 적은 근접만, 일부는 원거리만 데미지" 필러를 강화하는 시각적 신호 설계

## 기술적 참고 사항
- 1인 개발 Unity 프로젝트 → 소규모 팀도 이 수준 달성 가능
- 패리 히트스톱: `Time.timeScale = 0` + `StartCoroutine` 조합으로 구현
- Blessing 시스템: ScriptableObject 기반 추천 (각 Blessing을 SO로 정의)
