# Nine Parchments

리서치 날짜: 2026-09-19

## 기본 정보

- **개발사**: Frozenbyte (Trine 시리즈 제작사)
- **출시**: 2017년 12월
- **장르**: 협동 액션 RPG (로그라이크 요소 없음)
- **플랫폼**: PC, PS4, Xbox One, Switch
- **공식 사이트**: https://nineparchments.com/
- **Steam**: https://store.steampowered.com/app/432300/Nine_Parchments/

## 핵심 메카닉

### 마법사 학교 탈출 스토리
- 학교에서 강력한 마법책 9권이 탈출, 견습 마법사들이 되찾으러 감
- 각 캐릭터는 원소 친화 마법사 (불, 물, 얼음, 번개 등)
- 각자 고유한 스킬셋 6개 + 개인 패시브

### 프렌들리 파이어 (가장 핵심적인 메카닉)
- **팀원의 마법도 피아를 가리지 않음**: 동료에게 맞으면 데미지
- 이로 인해 자연스러운 협동 강요: "지금 내가 쏴도 돼?" 소통 필수
- 적을 도망치게 하는 대신 불 기둥으로 막을 때 팀원이 지나가면 타버림
- 실수 유발 = 웃음 포인트 (casual co-op 관점에서 장점)

### 원소 조합 시스템
- 서로 다른 원소가 만나면 추가 효과:
  - 물 + 얼음 = 빙결(Freeze) 범위 확장
  - 물 + 번개 = 전격(감전 범위 확산)
  - 불 + 얼음 = 수증기/미스트 (시야 차단)
  - 바람 + 불 = 화염 토네이도
- 상대방 역할 보완을 자연스럽게 유도

### 마나 관리
- 마나는 자동 회복이 아닌 마나 풀로부터 수동 흡수
- 난전 중 마나 관리 = 전략 요소

## 협동 요소 분석

### 강점
- **원소 조합이 시각적으로 명확**: 플레이어가 직관적으로 시너지 파악
- **프렌들리 파이어 = 협동 소통 강제**: 캐주얼 멀티에서도 팀 플레이 발생
- **역할이 명확히 다름**: CC기 역할 vs 딜 역할이 자연스럽게 구분
- **보스 연출 훌륭**: 보스마다 속성 약점이 있어 팀 빌드 중요

### 약점
- 로그라이크 요소 없어 리플레이성 부족 → 후에 추가 DLC로 보완 시도
- 프렌들리 파이어가 때로는 게임을 너무 어렵게 만들어 casual 경험 저해
- 단독 플레이 시 밸런스 무너짐

## OnionCat 적용 포인트

### 프렌들리 파이어 대신 "시너지 피아 구분"
- Nine Parchments는 프렌들리 파이어로 협동 유도
- OnionCat은 한 몸이라 프렌들리 파이어 없음 → 대신 "적만 피아 구분하는 원소 콤보"로 구현
- Cat의 슬래시 → 근접 적 약화 (Expose) → Crop 투사체 배율 증가

### 원소 콤보 시각화
- 콤보가 발생했을 때 **명확한 시각적 피드백** 중요
- 아이콘 + 컬러 VFX로 어떤 시너지가 발동됐는지 즉시 인지
- 예: Cat 슬래시 + Crop 물 → 화면에 "진흙 속도감소" 아이콘 팝업

### 캐릭터별 역할 명확화
- Nine Parchments 성공 요인: 캐릭터별 역할이 뚜렷함
- OnionCat: Cat = 근접/기동, Crop = 원거리/방어가 명확하게 분리되어 있음
- 업그레이드 설계 시 각 역할이 더 강해지는 방향으로 (역할 모호화 금지)

### 보스 약점 시스템
- 보스마다 특정 공격 타입에 취약점 설정
- "이 보스는 Cat 단독으론 못 잡아, Crop 원거리 필요" 상황 연출
- 보스 약점을 시각적으로 힌트 제공 (약점 부위 색상 변화)

### 소통 필요성 설계
- Nine Parchments: 프렌들리 파이어로 소통 유도
- OnionCat: 한 몸이라 P1(이동), P2(조준)가 항상 소통 중
- 업그레이드 선택 화면에서 두 플레이어 모두 이해하도록 UI 설계 필요

### 원소 속성 테마
- Nine Parchments에서 배울 수 있는 원소 시너지 표:
  - "공격 디버프(Cat) + 투사체(Crop)" 조합으로 확장 가능
  - Cat 슬래시로 "출혈" → Crop 투사체 추가 피해
  - Crop 물 투사체로 "젖음" → Cat 슬래시로 "감전"

## 플레이어들이 좋아하는 것

1. 원소 조합이 만들어내는 예상치 못한 콤보 발견
2. 프렌들리 파이어로 인한 웃음 포인트 (캐주얼 co-op)
3. 캐릭터별 플레이 스타일 차이
4. Trine과 같은 퀄리티의 시각적 아름다움
