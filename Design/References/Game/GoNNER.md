## 핵심 메카닉

### 절차적 생성 + 극단적 랜덤성
- 월드, 적, 환경 오브젝트 전부 런마다 새롭게 생성
- **지형이 매우 비정형적** — 불규칙한 섬 모양 플랫폼, 예측 불가 구조
- 색상 팔레트조차 런마다 바뀜 (시각적 정체성 자체가 랜덤)

### 로드아웃 시스템 (런 시작 전)
- **머리** / **무기** / **배낭** 세 슬롯을 조합
  - 머리: 특수 능력 부여 (투명화, 관통탄, 점프 강화 등)
  - 무기: 슈팅 방식 결정 (단발, 샷건, 폭발, 레이저 등)
  - 배낭: 추가 탄약 or 보조 패시브
- 각 슬롯 언락은 런 내 수집 → 메타 진행
- **슬롯 조합이 시너지를 이루거나 반발하는 느낌** → 고민이 생김

### 이동과 물리
- **모멘텀 기반 이동** — 공중에서 방향 전환이 묵직함
- 점프 후 관성이 남아 있어 지형 파악이 중요
- 낙사 = 즉사 (아래 지형 없으면 그대로 죽음)
- 대시 없음 — **순수 이동 스킬로 생존**해야 함

### 탄약 / 에너지 관리
- 무기마다 탄약 제한 — 탄약 없으면 근접 공격(점프 + 찍기)만 가능
- 탄약은 적 처치 또는 아이템으로 보충
- 자원 관리 압박이 즉각적인 위기감을 만듦

### 사망과 부활
- **완전 퍼마데스** — 사망하면 처음부터 (장비 포함 전부 리셋)
- 낮은 HP (기본 3~5개의 '머리') → 게임이 매우 짧고 강렬
- 숙련도가 오르면 한 런이 15~30분 안에 끝남

---

## 협동/경쟁 요소

- GoNNER는 **싱글 전용**
- GoNNER2에서 **로컬 2인 협동 추가** (동일 씬, 서로 부활 가능)
- 파트너가 죽으면 부활 아이템을 찾아야 함 → **상호의존성** 발생

---

## 플레이어들이 사랑하는 것

1. **비주얼 아이덴티티** — 검은 배경, 흰 선 아트, 런마다 바뀌는 색상 포인트
2. **짧고 강렬한 런** — 사망 후 빠르게 다음 시도로 진입
3. **유니크한 적 디자인** — 기이하고 불규칙한 움직임의 적들
4. **허들과 마스터리** — 처음엔 어렵지만 익숙해지면 유려해지는 조작감
5. **아트 방향성** — 음악과 시각이 하나의 감성으로 통일

## OnionCat 적용 포인트

| 항목 | GoNNER 방식 | OnionCat 적용 |
|------|-------------|----------------|
| 로드아웃 | 머리/무기/배낭 3슬롯 | Cat 어빌리티 슬롯 + Crop 탄약/방어 슬롯 |
| 모멘텀 이동 | 관성이 남는 이동 | Cat 대시 후 관성 0.2초 유지 → 조작감 차별화 |
| 시각 정체성 | 런마다 팔레트 변경 | 룸 테마별 색상 톤 변경으로 분위기 전환 |
| 자원 관리 | 탄약 제한 | Crop의 투사체 쿨다운 or 에너지 게이지 |
| 짧은 런 | 20분 내 완주 가능 | 레이어 3개 × 3룸 = 30분 목표 런 길이 |
| 부활 (GoNNER2) | 상대방이 아이템으로 부활 | 상대 쓰러짐 → 시체 위치에서 3초 부활 액션 가능 |
