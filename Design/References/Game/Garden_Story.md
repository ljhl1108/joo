# Garden Story

리서치 날짜: 2026-11-14

## 기본 정보

- **개발사**: Picogram (1인 개발, 미국)
- **퍼블리셔**: Rose City Games
- **출시**: 2021-08-11
- **플랫폼**: PC (Steam), Nintendo Switch
- **장르**: 액션 RPG, 코지 / 로컬 협동
- **Steam**: https://store.steampowered.com/app/1062140/
- **공식 사이트**: https://www.gardenstory.game

## 핵심 메커니즘

### 기본 구조
포도 "콩코드"가 되어 균(rot)에 오염된 정원 마을을 복구하는 액션 RPG.  
마을 주민 NPC들과 관계를 쌓고, 자원을 모아 시설을 고치고, 지역을 탐험·정화.

### 전투
- 단순한 근접 공격 (곤봉) + 화면 가득 퍼지는 버블 아이템
- 적은 균에 감염된 작물·곤충 — 약하지만 군집
- **히트스캔보다 패턴 회피** 중심 — 뒤로 물러나면서 아이템으로 돕는 구조
- 도전도가 낮아 전투 자체보다 **탐험과 복구 흐름**이 메인

### 자원 수집 & 마을 복구
- 적 처치·채집으로 소재 획득
- 주민 의뢰 완료 → 시설·건물 복구
- 복구된 시설이 플레이어에게 새 도구·정보를 제공

### 계절 순환
- 봄·여름·가을·겨울 순환 — 계절마다 출현 적, 채집 소재, NPC 대사가 달라짐
- 계절이 지나면 의뢰 기회를 놓침 → 가벼운 타임 프레셔

### 로컬 협동
- 2인 로컬 협동 지원 (추가 업데이트)
- P2는 버블 형태로 P1을 지원 — P1이 없으면 혼자서는 의미 없는 보조 역할
- 화면 공유 · P1 고정 카메라

## 세계관 & 테마

### 식물 캐릭터들
- 주인공: 포도 (어리고 의욕 넘침)
- 주민: 버섯, 올리브, 감, 도라지 등 작물 캐릭터
- 적: 균에 감염된 존재들 — 적도 원래는 정원의 일부

### 복구의 서사
"부서진 것을 고치는" 테마가 게임 전체를 관통.  
작은 의뢰 → 가시적인 마을 변화 → 플레이어가 직접 성과를 볼 수 있음.

### 색상 · 분위기
풀잎 초록 + 흙갈색 + 계절색의 파스텔 팔레트. 적도 붉은 균이 뒤덮인 형태로 명확히 구분.

## 플레이어들이 좋아하는 것

- "그림책 같은 비주얼"
- NPC 대사가 계절마다 바뀌는 세심함
- 전투 없이도 채집·의뢰만으로 느긋하게 즐길 수 있음
- 복구한 건물이 실제로 마을에 생기는 직접적 피드백

## 비판 포인트

- 전투 단조로움 — 반복 패턴, 적 종류 적음
- 중반 이후 의뢰가 비슷하게 반복
- 협동 P2 역할이 너무 약함 → "보조 버블"은 단순 체험용

## OnionCat 적용 포인트

### 작물 캐릭터 아이덴티티
Garden Story는 작물 캐릭터가 가진 *온기*를 잘 표현함.  
→ OnionCat 양파·해바라기·버섯도 각자의 성격을 가시적으로 — 색, 탄 궤적, 스킬 연출에서 개성 차별화.

### "복구의 보람" 메타 흐름
- 런 → 보상 → 온실/마을 개선 → 다음 런이 더 나아짐
- Garden Story의 복구 감정선을 **OnionCat 메타 성장**(온실 해금)에 적용 가능:
  마을 등불을 밝힐 때마다 "세상이 조금 나아지는" 연출 강조.

### 계절 → 스테이지 테마 전환
Garden Story의 계절별 분위기 전환처럼, OnionCat의 스테이지 1→6도  
밀밭(봄 느낌) → 등대(겨울 폭풍) 식으로 **색조·음악·적 성격을 단계적으로 바꾸면** 긴 런에서도 지루하지 않음.

### 작물 조연 → 협동 주연
Garden Story P2는 "버블 보조"에 그쳐 혼자선 무의미.  
→ OnionCat 작물은 고양이 없이도 의미 있는 역할(씨앗 화력, R 스킬 전략)을 가져야.  
두 플레이어 모두 "주인공 느낌"을 받도록.

### 적도 원래는 정원 일부
적이 단순한 몬스터가 아니라 세계의 일부가 오염된 존재 → 정서적 거리가 생김.  
→ OnionCat 적들도 단순 "몬스터"가 아니라 등대탑 마녀가 보낸 존재, 혹은 세계의 그림자로 연출하면 이야기에 깊이 추가.
