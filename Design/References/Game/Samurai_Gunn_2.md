## 핵심 메카닉

### 총알 제한 + 칼 반사

- 각 플레이어는 **총알 3발**만 가짐. 발사 후 총알 회수 또는 적 격파로 재충전
- 칼로 **총알 반사** 가능 — 타이밍 맞추면 상대 총알을 되돌림
- 원거리(총) vs 근거리(칼) 이분법을 한 캐릭터 안에 모두 담음

### 빠른 TTK (Time to Kill)

- 한 방 또는 두 방으로 사망 — 장기전 없음
- 리스폰이 빠르므로 전투 사이클이 매우 짧음
- "죽고 배우고 다시 시도" 루프 강화

### 스테이지 기반 로그라이크 요소 (2편 추가)

- 지형 변화가 있는 스테이지 선택
- 일부 런 특성 잠금 해제 (영구 진행 아님, 런 단위 변화)
- 적 AI 존재 → 싱글플레이어도 가능

### 물리 기반 이동

- 점프·대시·구르기 없이 **달리기 + 점프**만으로 이동
- 격하고 단순한 입력 → 읽기 쉽고 배우기 쉬운 레이아웃
- 총알 반사와 이동의 조합이 깊이를 만듦

## 플레이어 반응 (좋아하는 점)

1. **단순한 컨트롤, 높은 숙련 천장** — 3버튼(이동·점프·사격) → 메타 깊이 폭발
2. **읽기 쉬운 피드백** — 총알 수, 반사 타이밍이 명확한 시각 표현
3. **스킬 표현의 선명함** — 칼 반사 성공 시 즉각 역전, 실수 시 즉사 → 결과가 명확
4. **짧은 판 → 높은 반복성** — 한 판 10–30초, 반복이 고통스럽지 않음

## OnionCat 적용 포인트

### 1. 총알 제한 = 탄약 관리

- Onion의 발사를 **제한된 탄약** 또는 **충전 게이지**로 설계하면?
  - "다 쏘고 나서 Cat이 근접으로 막아줘야 하는" 협동 구조 강화
  - Samurai Gunn의 3발 → OnionCat에선 5발 + 씨앗 자원 소모로 변형 가능

### 2. 즉각 피드백 (총알 반사 → 패리)

- Onion의 **방패 패리**가 Samurai Gunn의 칼 반사와 구조적으로 동일
- 성공 시 투사체가 적에게 돌아가는 연출 → 이미 구현된 파리 시스템 강화 힌트
- 패리 효과음·이펙트를 총알 반사만큼 선명하게 → 숙련감 상승

### 3. 빠른 TTK → 대시 무적이 핵심

- OnionCat에서도 한두 번 실수로 위협받는 구조 유지 (너무 긴 체력은 긴장감 저하)
- Cat의 무적 대시 = Samurai Gunn의 긴급 탈출 도구와 유사한 리듬

### 4. 읽기 쉬운 총알 수 UI

- 발사체 남은 수를 화면에 명확히 표시 → OnionCat Onion 탄약 HUD 설계 참고
- 화면 가득 적이 있어도 탄약 상태가 항상 보여야 함

### 5. 아군 오사 고려

- 4인 코옵에서 팀파이어 → 2인 OnionCat는 동체이므로 해당 없지만
  **Cat이 근접 중 Onion이 쏘면 Cat을 다치게 하지 않는 규칙** 설계 시 참고 (Hitbox 공유 구역 처리)
