# Trigger Witch

리서치 날짜: 2026-11-25

## 기본 정보

- **장르**: 트윈스틱 슈터 + 어드벤처 RPG
- **개발사/출시**: Rainbite (뉴질랜드 소규모 팀), 2021-07-28
- **플랫폼**: PC(Steam), Switch, Xbox
- **공식 링크**: https://store.steampowered.com/app/1880230/Trigger_Witch/
- **플레이 시간**: 메인 약 7~10시간 + New Game+

## 핵심 메카닉

### 세계관 & 세팅
- 총이 마법을 대체한 판타지 세계. 마녀가 총을 쓴다는 반전 설정
- 탑다운 시점, 셀 에니메이션 느낌의 2D 그래픽, 고어 연출(모탈 컴뱃 수준)

### 트윈스틱 전투
- 왼쪽 스틱: 이동, 오른쪽 스틱: 조준·사격
- 여러 종류의 총기 무기를 획득·교체하며 진행
- **독특한 탄약 시스템**: 총마다 탄약 타입과 용량이 다름, 환경에서 보충
- 근거리 돌진(Dash Attack)으로 적을 넘어뜨리거나 탄환을 튕겨낼 수 있음

### 환경 파괴 & 물리 상호작용
- 벽·오브젝트 일부가 파괴 가능 → 숨겨진 아이템이나 지름길 발견
- 물, 불 등의 환경 요소가 전투에 영향(물웅덩이 + 전기 = 광역 감전)
- 적을 날려보내 환경 오브젝트에 충돌시키는 연쇄 반응

### 성장 시스템
- 마을 허브로 돌아와 무기 업그레이드, 새 능력 해금
- New Game+: 무기와 업그레이드를 유지한 채 더 강한 적 재도전

### 로컬 2인 협동
- **드롭인/드롭아웃**: 2P가 언제든 합류·이탈 가능
- 같은 화면에서 두 명이 각자 완전한 캐릭터로 플레이
- 협동 전략보다는 "화력 2배" 형태 — 역할 분담보다 화면 커버
- 몬스터 HP는 2인 모드에서 조정됨

## 플레이어 반응 (Steam 리뷰 정리)

**좋아하는 점**
- 쾌감 있는 트윈스틱 타격감
- 친구와 함께하는 로컬 협동이 재밌음
- 환경 파괴와 상호작용의 발견 쾌감

**아쉬운 점**
- 던전 디자인이 반복적이고 단조로움
- 10시간이면 끝나는 짧은 분량
- 장르 정체성이 모호함(어드벤처인지 슈터인지 RPG인지)

## OnionCat 적용 포인트

### 1. 로컬 협동 드롭인 UX
- Trigger Witch의 드롭인/드롭아웃은 "언제든 P2가 참여" 편의성을 보여줌
- OnionCat은 1고양이+1작물 고정이지만, **솔로 플레이 시 작물 AI** 또는 **P1이 양쪽 조작**을 위한 흐름 참고 가능
- 게임 시작 화면에서 "P1 패드 연결 → P2 마우스로 합류" 흐름을 Trigger Witch처럼 매끄럽게

### 2. 환경 오브젝트 상호작용
- 물 + 전기, 가스 + 불 같은 **원소 조합 반응**은 OnionCat의 불/얼음/전기 상태이상 시스템에 직접 적용 가능
- 예: 얼음 상태 적에게 강타 → 빙결 파편 광역 / 불 상태 적에게 물 씨앗 → 증기 화면 가림

### 3. 탄약 → 씨앗 경제
- Trigger Witch의 탄약 관리(총마다 용량 다름, 환경 보충)는 OnionCat 씨앗의 "방마다 소비 → 부족하면 적 근접 처리" 긴장감과 유사
- 씨앗 종류별 특성(빠른 씨앗/폭발 씨앗/유도 씨앗)이 탄약 다양성처럼 플레이 스타일을 바꿈

### 4. 환경 파괴로 숨겨진 보상
- 방 안의 특정 오브젝트를 파괴하면 추가 보상 등장
- OnionCat에서 "항아리를 발로 차면 씨앗 보충", "풀숲을 태우면 비밀 출구" 같은 발견의 즐거움 추가 가능
