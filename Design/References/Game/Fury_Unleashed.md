# Fury Unleashed

리서치 날짜: 2026-07-01

## 기본 정보

- **개발사**: Awesome Games Studio (폴란드 인디)
- **출시**: 2020년 5월 (PC/콘솔), 2021년 닌텐도 스위치
- **공식 사이트**: https://awesomegamesstudio.com/fury-unleashed/
- **Steam**: https://store.steampowered.com/app/465200/Fury_Unleashed/
- **장르**: 2D 액션 로그라이트, 2인 로컬 코-op
- **플랫폼**: PC, PS4, Xbox One, Nintendo Switch

---

## 핵심 컨셉

**"만화책 세계관"**: 게임 속 세계 자체가 만화책 페이지 위에서 펼쳐진다. 주인공 Fury는 자신이 만화 캐릭터임을 알고 있으며, 작가가 창작 슬럼프를 극복하도록 돕는 것이 내러티브 골자. 판 자체가 플레이 공간이 되는 독특한 메타적 아트 연출.

---

## 게임 시스템 분석

### 1. 콤보 시스템 (핵심 차별점)

**콤보 카운터가 곧 파워**: 적을 연속으로 처치하거나 데미지를 주면 콤보가 쌓이고, 일정 수치를 넘으면 "콤보 버프" 상태가 활성화된다.

- 콤보 10 → 데미지 보너스 10%
- 콤보 25 → 추가 버프 (속도, 재장전 등)
- 콤보 50+ → 폭발적 데미지 및 특수 이펙트

**콤보 유지의 긴장감**: 피격 또는 일정 시간 전투 공백 시 콤보 초기화. 공격적 플레이를 강요하는 설계.

### 2. 캐릭터 클래스

| 캐릭터 | 특성 |
|--------|------|
| Fury | 기본 균형형, 근거리+원거리 혼합 |
| Kommandant Ursus | 탱커형, 근거리 특화 |
| Yuki | 원거리 특화, 빠른 기동 |

각 캐릭터마다 고유 패시브와 시작 무기 차이.

### 3. 무기 시스템

- 근거리 무기: 검, 해머, 도끼 등
- 원거리 무기: 권총, 샷건, SMG, 스나이퍼 등
- 동시에 근거리+원거리 각 1개 장착 가능
- 방 내 랜덤 드롭, 상자, 상점에서 획득

### 4. 절차적 생성

- 챕터(4개) → 각 챕터 내 방(8-12개) → 챕터 끝 보스
- 방 유형: 전투방, 상점방, 비밀방, 도전방
- 업그레이드 선택: 전투방 클리어 시 3개 카드 중 선택

### 5. 영구 메타 진행 (잉크 시스템)

- 런 중 수집한 "잉크"로 허브에서 영구 업그레이드 해금
- 시작 무기 선택지 확장, 패시브 버프 잠금 해제 등
- 로그라이트 특유의 "첫 런=패배지만 조금씩 강해지는" 구조

### 6. 2인 로컬 코-op

- **전체 캠페인 코-op 지원**: 솔로와 동일한 스테이지를 2인이 함께 진행
- **독립 체력**: 각 플레이어가 별도의 HP 관리
- **부활 시스템**: 한 플레이어가 쓰러지면 다른 플레이어가 옆에 서서 부활 가능 (부활 중 무적 아님, 위험 감수 필요)
- **콤보 공유**: 두 플레이어의 공격이 모두 콤보 카운터에 기여 → 협력 플레이 시 더 빠른 콤보 스택
- **아이템 경쟁/협력**: 같은 방에서 나온 아이템을 누가 가져갈지 암묵적으로 조율

## 플레이어들이 좋아하는 것

1. **콤보 시스템의 쾌감**: 숫자가 올라갈수록 강해지고 화면이 화려해지는 피드백
2. **만화책 아트 스타일**: 독특한 비주얼로 차별화, 셀 쉐이딩+만화 패널 효과
3. **빠른 런 템포**: 한 런이 30-40분 내외로 부담 없음
4. **다양한 무기 빌드**: 근거리+원거리 조합으로 빌드 다양성 확보
5. **코-op의 즐거움**: 전체 게임을 친구와 함께할 수 있는 완성도 높은 코-op

## 비판점 / 아쉬운 점

- 적 AI 패턴이 단조롭다는 평
- 챕터 4개로 컨텐츠가 적다고 느끼는 유저도 있음
- 콤보 시스템이 후반 밸런스를 무너뜨리는 경우 있음 (콤보 빌드 시 너무 강해짐)

## OnionCat 적용 포인트

### 1. 콤보 빌드 → 협력 시너지 강화

Fury Unleashed에서 두 플레이어가 모두 콤보에 기여하는 것처럼, OnionCat에서도 고양이(근거리)와 양파(원거리)가 **교대로 공격**하면 "협력 콤보"가 쌓여 추가 효과 발동하는 설계 가능.

예: 근거리 히트 → 원거리 히트 → 근거리 히트 순서로 "협공 콤보" 3단 달성 시 데미지 20% 증가

### 2. 부활 메커니즘 적용

OnionCat의 "공유 몸체"라는 컨셉에서는 한 플레이어가 기절 상태에 빠지면 다른 플레이어가 특정 행동으로 복구하는 형태로 응용 가능. (예: 고양이가 데미지 과다 → 양파가 방패로 3번 막으면 "회복 타이밍" 창 열림)

### 3. 챕터 구조 + 보스

4챕터 구조는 OnionCat 초기 버전에 딱 맞는 분량. 각 챕터마다:
- 5-8개 전투방
- 1개 상점방
- 1개 보스방
작은 스케일부터 시작해 확장하는 방식.

### 4. 근거리+원거리 무기 동시 장착

OnionCat의 고양이는 근거리 전용, 양파는 원거리 전용이지만, 업그레이드로 각자의 공격 패턴에 변화를 주는 방식으로 응용 가능.

### 5. 잉크(영구재화) → 메타 진행

Fury Unleashed의 잉크처럼 OnionCat에서도 런마다 소량의 영구재화를 수집해 시작 업그레이드 선택지 확장 등 메타 진행 시스템에 활용.
