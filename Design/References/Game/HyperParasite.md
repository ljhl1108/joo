## 핵심 메커니즘

### 빙의(Possession) 시스템
- 플레이어는 뇌 기생충(parasite)을 조종
- 적에게 달라붙어 그 몸을 빼앗을 수 있음
- 빙의 중인 몸이 죽으면 기생충 상태로 탈출 → 새 숙주 필요
- 기생충 상태(노출 상태)에서 맞으면 즉사 → 고위험 순간
- 빙의한 캐릭터마다 고유 무기/능력 → 30종 이상의 캐릭터 타입

### 2인 코옵
- 두 플레이어 모두 독립적인 기생충으로 플레이
- 같은 화면(로컬 코옵), 각자 다른 숙주를 빙의 가능
- 팀원이 죽으면 나머지 혼자 계속 → 협력 없이도 생존 가능
- 동일한 능력 풀 공유 (비대칭 아님)

### 룸 구조
- 절차적 룸 배치, 각 룸 클리어 후 다음 이동
- 다양한 룸 타입: 전투, 상점, 이벤트, 보스
- 파밍: 기생충 능력 업그레이드 아이템

### 적 다양성
- 30종 이상 빙의 가능한 적 캐릭터
- 적마다 고유 공격 패턴 + 이동 방식
- 일부 적은 근거리, 일부는 원거리 → 상황별 숙주 선택 전략

## 플레이어가 좋아하는 점

- 빙의 메커니즘 자체의 참신함과 순간적 긴장감
- 숙주를 바꿀 때마다 달라지는 플레이 스타일
- 레트로 아케이드 비주얼과 신스팝 사운드트랙의 조화
- 코옵 시 각자 다른 숙주로 콤비 플레이 재미

## 비판점

- 게임 밸런스 불안정 (이른 출시)
- 일부 숙주 캐릭터 간 성능 격차 큼
- 로그라이크 깊이 부족 (런 간 다양성 제한)

## OnionCat 적용 포인트

### 1. "몸 공유" 컨셉의 레퍼런스
HyperParasite는 "기생충이 몸을 빌린다"는 OnionCat의 "화분 위 채소가 고양이를 탄다"는 컨셉과 구조적으로 유사.
- **기생충 = Onion(양파)**: 숙주 없이는 취약, 숙주에 올라타야 능력 발휘
- **숙주 = Cat(고양이)**: 이동과 근접을 담당, 기생충 없인 원거리 없음
- HyperParasite에서 "기생충 탈출 → 새 숙주 찾는 긴장감"을 OnionCat에서
  "양파가 화분에서 이탈할 수 없다"는 제약으로 다르게 표현한 것

### 2. 근거리/원거리 조합 강제 메커니즘
- HyperParasite: 숙주마다 근/원거리 능력 고정 → 상황에 맞는 숙주 선택
- OnionCat: 고양이(근접)와 양파(원거리)가 고정 → **적 약점 설계로 동일 효과**
- 구현 힌트: HyperParasite처럼 "이 적은 오직 이 속성으로만 처치 가능" UI 피드백을
  명확히 줄 것 (저항 표시, 히트이펙트 색상 차이 등)

### 3. 기생충 "노출 취약 상태" → OnionCat의 위기 연출
- HyperParasite에서 기생충 상태(숙주 없음) = 극도로 취약한 고위험 상태
- OnionCat에서 유사한 위기 연출 아이디어:
  - 고양이가 기절/스턴됐을 때 양파 혼자 무방비 → 협력 강제
  - 혹은 일부 적이 "화분을 노린다" → 고양이가 방어 포지셔닝 필요

### 4. 캐릭터 다양성을 런 중에 느끼는 방식
- HyperParasite: 숙주 갈아타기로 런마다 플레이감 달라짐
- OnionCat: 업그레이드 조합으로 런마다 달라지는 빌드 → 업그레이드 설계 시
  "근접 특화 / 원거리 특화 / 하이브리드" 트리를 명확히 분리할 것

### 5. 코옵 밸런스 주의사항
- HyperParasite 비판: 혼자도 클리어 가능 → 코옵 필요성 약화
- OnionCat은 애초에 1인 플레이 불가 설계 → 이 함정 없음
- 단, "특정 플레이어가 계속 죽을 때의 부담" 설계는 배울 것:
  HyperParasite는 파트너가 죽어도 계속 진행 → OnionCat은 **동반 사망/부활 메커니즘** 필요
