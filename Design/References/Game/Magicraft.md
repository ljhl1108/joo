## 핵심 시스템

### 1. 모듈형 주문 제작 (Node-Graph Spell Crafting)

게임의 핵심. 주문을 "노드"를 연결해 직접 만든다.

- **소스 노드**: 발사체 / 폭발 / 레이저 / 소환 — 공격의 기본 형태 결정
- **원소 노드**: 불 / 얼음 / 번개 / 독 / 신성 — 피해 속성 부여
- **행동 노드**: 관통 / 분열 / 추적 / 반사 / 연쇄 / 회전 — 발사체 동작 변경
- **증폭 노드**: 크기 / 속도 / 피해 / 개수 — 수치 배율 조정

노드를 드래그로 연결하면 조합 결과가 실시간 미리보기된다.  
예: `발사체 → 불꽃 → 분열 → 추적` = 자동 추적 불꽃 분열탄

### 2. 노드 경제

- 적 처치 / 상자 개봉 시 랜덤 노드 드롭
- 상점에서 씨드(통화)로 구매, 리롤 가능
- 보스 처치 시 특수 노드 (전설 등급) 획득
- 장착 슬롯은 제한적 → 보유한 모든 노드를 다 쓸 수 없어 선택과 집중 필요

### 3. 복수 주문 슬롯

런 중 최대 3~4개의 서로 다른 "완성된 주문"을 번갈아 발사할 수 있다.  
각 슬롯을 특화하는 전략이 생김 (단일 강화 / 광역 청소 / 보스용 집중 딜).

### 4. 메타 진행

- 런 클리어 시 해금 포인트 획득 → 시작 노드 종류 추가 / 특수 패시브 해금
- 특정 적 처치 기록 → 새 노드 타입 발견
- 덱 빌딩 로그라이크와 달리 "조합 방식" 자체가 학습 대상

## 플레이어가 사랑하는 것

1. **"내가 만든 주문"의 소유감** — 프리셋을 고르는 게 아니라 직접 설계했기에 애착이 강함
2. **예상 못한 조합의 쾌감** — 노드 조합 결과가 상상을 초과할 때의 발견 경험
3. **런마다 완전히 다른 빌드** — 드롭이 같더라도 연결 방식이 달라짐
4. **즉각적인 피드백** — 드래그로 연결하는 순간 미리보기가 바뀌어 실험 비용이 낮음
5. **깊은 상호작용** — 노드 조합이 수십~수백 가지라 수백 시간 플레이에도 새 발견 존재

## 비판받는 것

- 초반 노드 풀이 빈약해 단조롭다는 느낌
- 주문 편집기 UI가 복잡해 진입 장벽 존재
- 발사체 중심이라 근접 빌드 선택지가 좁음
- 방 배치가 단조롭고 환경 상호작용이 적음

## OnionCat 적용 포인트

### A. `GearEffect` 조합과 동일한 설계 철학

Magicraft의 노드 그래프 = OnionCat의 `GearEffect` 조합 (`발동 → 행동 → 대상`).  
차이점은 Magicraft는 플레이어가 런타임에 직접 배선하고, OnionCat은 장비 에셋에 미리 정의된다.  
교훈: **미리 조합된 결과물이더라도, 플레이어에게 "조합 구조"가 보이면 소유감이 올라간다**.  
→ 장비 툴팁에 "트리거 → 행동 → 대상" 흐름을 시각화하면 효과 이해도와 빌드 방향성 모두 향상.

### B. 노드 드롭 = 장비 드롭의 경제 참고

- Magicraft: 노드를 차곡차곡 모아 조합 → 드롭마다 가능성이 쌓이는 느낌
- OnionCat: 바닥 장비 드롭(`GearLoot`) + 씨앗 경제
- 교훈: 드롭이 "그것 자체로 완성된 강화"가 아니라 "조합 재료"처럼 느껴지면 선택의 무게가 달라짐  
  → 현재 분해 씨앗 + 효과 목록 등록(`Dismantle`) 구조는 이 방향과 일치. 분해 장면의 연출이 중요.

### C. 복수 주문 슬롯 = 마법서 3칸 병행 구성

- Magicraft: 단거리 폭발 + 장거리 추적 + 보스 집중 딜, 3슬롯 각자 특화
- OnionCat: Q·W·E 마법서 3칸이 각각 독립 스킬
- 교훈: 슬롯마다 역할 분담이 명확해지도록 마법서 설계 시 "청소 / 강화 / 특수" 셋으로 역할 구분 의식

### D. 조합 실험 비용을 낮추는 UI

- Magicraft: 드래그 연결 즉시 미리보기 → 실험 비용 거의 0
- OnionCat: 효과 갈아끼우기(`상점·휴식 정원에서만`) → 실험 기회가 제한됨
- 교훈: 장비 화면에서 "이 장비를 장착하면 어떤 효과가 발동되는지" 미리 보여주는 "시뮬레이션 프리뷰"가 있으면 의사결정 속도 상승

### E. 메타 해금 = 온실 (Greenhouse) 시스템

- Magicraft: 런 클리어 → 포인트 → 시작 노드 해금
- OnionCat: 온실 `MetaProgress` → 해금 비용(`GearItem.UnlockCost`) → `RewardTable.Pool`에 추가
- 교훈: 해금된 새 노드(장비)가 드롭되면 "이거 처음 보는 건데?" 효과가 강함 → 첫 드롭 시 "신규 장비!" 마커를 붙이면 발견 경험이 더 선명해짐
