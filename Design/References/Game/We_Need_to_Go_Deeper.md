# We Need to Go Deeper

리서치 날짜: 2026-11-14

## 기본 정보

- **개발사**: Draconis Entertainment (캐나다 인디)
- **출시**: 2019 (Early Access 2016)
- **플랫폼**: PC (Steam)
- **장르**: 로컬/온라인 협동 로그라이크
- **공식 사이트**: https://www.wentdeeper.com
- **Steam**: https://store.steampowered.com/app/418590/

## 핵심 메커니즘

### 기본 구조
1~4명이 빅토리아 시대 잠수함을 타고 미지의 해저를 탐험하는 로그라이크.  
각자가 **잠수함의 다른 부분을 담당**하며, 소통과 역할 분배가 생존 열쇠.

### 역할 분담 (비대칭 협동)
| 위치 | 역할 | 조작 |
|------|------|------|
| 조종석 (Helm) | 방향 조종 · 깊이 조절 | 1인 전담 |
| 왼쪽 대포 | 외부 적 공격 | 조준·발사 |
| 오른쪽 대포 | 외부 적 공격 | 조준·발사 |
| 의무실 | 선원 치료 · 내부 적 처치 | |

인원 부족 시 한 사람이 여러 자리를 뛰어다니며 담당.  
→ **같은 화면을 공유하지 않아도** 역할이 자연스럽게 분리됨.

### 내부 위기 / 외부 위기 동시 처리
- **외부**: 해저 생물 · 장애물 → 대포로 처리
- **내부**: 선체 균열 수리 · 산소 · 화재 · 적 침입 → 직접 뛰어다녀 처리
- 두 위기가 **동시에** 터져야 진짜 긴장감 형성

### 절차적 생성 구조
- 7개 바이옴 (일반 → 특수 → 보스 패턴)
- 각 바이옴에 고유 적·장애물·보스
- 런마다 순서·내용이 달라지는 로그라이크 구조

### 메타 성장
- 런 클리어 → 해금 콘텐츠 (새 무기·장비·잠수함 업그레이드)
- 영구 해금이 플레이어 적응 속도를 조절

## 협동 요소 분석

### "소통 없이는 죽는다"
가장 강력한 디자인 원칙. 조종사는 외부 적이 안 보이고, 포수는 방향을 바꿀 수 없다.  
→ 말로 하거나 소리로 알려야 → **소통 자체가 게임플레이**

### 역할 간 의존성
한 역할의 실패가 다른 역할을 직접 방해. (조종사가 벽에 부딪히면 포수가 적을 못 맞춤)

### 카오스 허용
4명이 각자 다른 일을 할 때 발생하는 혼란이 **재미 요소**로 작동.  
실수도 웃기게 느껴지도록 → 패배해도 재미있는 경험 설계

## 플레이어들이 좋아하는 것

- "역할이 달라서 같이 있는데 각자 다른 게임을 하는 느낌"
- 보스 처치 전 대화의 절박함
- 2인도 4인 못지않게 긴장감 있는 협동
- 빅토리아 시대 그림체 + 귀여운 캐릭터가 가혹한 로그라이크와 대비

## OnionCat 적용 포인트

### 역할별 "다른 게임" 경험
고양이(P1)와 작물(P2)이 같은 화면에 있어도 **완전히 다른 조작과 목표**를 가짐.  
→ P1은 "근접 생존 게임", P2는 "원거리 조준 게임" 느낌이 나도록 강조할 것.  
→ 고양이가 위험에 처했을 때 작물 플레이어가 긴급 지원을 "의식적으로 선택"하게 설계.

### 내부/외부 위기 동시 처리 패턴
- 고양이: 접근전으로 적 처리 (=외부)
- 작물: 씨앗·스킬 준비 + 고양이 지원 (=내부 역할)
- **보스전에서 단계별로 역할 비중을 바꾸는 연출** 가능.  
  예: 보스 1페이즈 고양이 집중, 2페이즈 작물 R스킬 필수

### 소통 의존 디자인
두 플레이어가 "지금 무엇을 하고 있는지" 서로 명확히 알 수 있게 UI/연출로 보조.  
→ 예: 작물이 R 스킬을 심을 때 고양이 화면에 타이머나 표식 표시

### "카오스 허용" 플로우
실수로 인한 위기도 웃기게 연출 → 패배 화면을 가볍게.  
→ 게임오버 대신 "함께 쓰러지는 짧은 연출" (파트너 로그라이크 공통 디자인)
