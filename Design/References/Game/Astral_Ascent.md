## 핵심 메카닉

### 캐릭터 시스템
- 4명의 플레이어블 캐릭터 (각각 고유 이동/전투 스타일)
  - **Ayla**: 빠른 근접, 콤보 위주
  - **Calie**: 원거리 마법
  - **Kiran**: 투사체 + 화살
  - **Aleks**: 원거리 레이저
- 각 캐릭터는 **스킬 슬롯 3개** — 런마다 랜덤 선택
- 스킬마다 고유 쿨다운, 탄환 타입, 원소 속성

### 마법 / 스킬 시스템
- **스펠(Spell)**: 공격 스킬. 스킬은 3개 슬롯 중 하나를 차지
- **패시브(Passive) 업그레이드**: 스펠 강화 or 스탯 향상
- **원소 속성**: 불, 번개, 냉기, 독 — 원소 콤보가 추가 효과 유발
- 쿨다운 관리가 핵심 전투 리듬

### 적과 보스
- **황도 12궁(Zodiac Bosses)**: 12개 별자리 기반 보스 각 구역마다 등장
- 보스마다 **고유 패턴 페이즈** 2~3단계
- 적도 원소 약점/내성을 가짐 → 스킬 선택에 전략성 부여

### 로그라이크 구조
- 3개 월드(정원, 동굴, 우주) 순서대로 진행
- 방마다 전투/이벤트/상점 랜덤 배치
- 런 중 스킬 선택 → 시너지 조합 탐색
- **영구 업그레이드(메타 프로그레션)**: 골드로 기지 NPC에게 영구 스탯 강화

### 협동 (Co-op) 시스템
- **로컬/온라인 2인 협동** 지원
- 각 플레이어가 **다른 캐릭터** 선택 → 역할 분담
- 공유 체력 없음, 각자 체력 독립
- 한 명이 다운되면 다른 플레이어가 부활 아이템으로 살릴 수 있음
- 스킬 원소 조합으로 **2인 원소 콤보** 발동 가능

## 플레이어가 사랑하는 것

1. **비주얼 퀄리티** — 소규모 팀이 만들었다고 믿기 어려운 애니메이션 품질
2. **캐릭터 개성** — 각 캐릭터 이동/전투 감각이 완전히 다름
3. **스킬 시너지 탐색** — 매 런마다 다른 스펠 조합이 "오늘의 빌드" 느낌
4. **보스 디자인** — 별자리 테마 + 2~3페이즈 패턴, 외울 맛이 있음
5. **2인 협동 완성도** — 온라인 동기화가 안정적, 역할 분담이 자연스러움

## OnionCat 적용 포인트

### 1. "두 캐릭터 = 두 가지 강점" 디자인
Astral Ascent는 2인 플레이 시 서로 다른 캐릭터를 골라 원소 콤보를 유발한다. OnionCat도 고양이(근접)와 작물(원거리)이 각각 다른 유형의 적에게 효과적 → **"시너지를 유발하는 협동 전투"** 방향을 강화할 참고.

### 2. 원소/속성 약점 → 적 타입 약점으로 응용
원소 속성 대신 OnionCat은 **"근접 전용 약점" vs "원거리 전용 약점"** 적으로 이 아이디어를 이미 구현. Astral Ascent처럼 시각적 표시(적 몸에 아이콘)로 약점을 명확히 보여주면 협동 필요성이 자연스럽게 전달됨.

### 3. 스킬 슬롯 구조 → 업그레이드 슬롯 설계
3개 스킬 슬롯이 런마다 채워지는 구조. OnionCat에서 고양이/작물 각각에 **능력 슬롯 2~3개**를 주고, 방 클리어마다 슬롯을 채우는 방식 적용 가능.

### 4. 부활 메카닉
2인 협동에서 한 명이 죽으면 다른 한 명이 살릴 수 있음. OnionCat은 한 몸이라 "부활" 개념은 없지만, **고양이 or 작물 기절 → 제한 시간 내 회복 아이템 먹으면 회복** 같은 구조로 응용 가능.

### 5. 소규모 팀 개발 참고
Hibernian Workshop은 2인 팀. 픽셀아트 퀄리티와 시스템 깊이를 유지하면서도 범위를 조절한 방식 — OnionCat 개발 범위 결정에 좋은 벤치마크.
