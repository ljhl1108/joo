# Patch Quest

리서치 날짜: 2026-10-25

## 기본 정보

- 개발사: Lychee Game Labs
- 장르: 로그라이트 + 몬스터 포획 + 탄막 슈팅
- 공식/Steam: https://store.steampowered.com/app/1347970/Patch_Quest/
- 위키: 별도 팬 위키 없음 (Steam 커뮤니티 가이드 참고)
- 출시: 2023년 3월 정식 출시 (이전 Early Access)
- 플랫폼: PC (Steam)
- 플레이어: 1인 또는 **로컬 2인 협동**
- 난이도: 귀여운 외형이지만 실제로는 난이도 높은 탄막 — 카주얼 모드 제공

## 핵심 시스템

### 몬스터 포획 & 라이딩
- 라소(Lasso)로 **모든 몬스터** 포획 가능 → 즉시 마운트로 사용
- 각 몬스터 종마다 **고유 스킬** 보유 — 탄막 패턴이 완전히 다름
- 탑승 중인 몬스터에 따라 **BGM도 변화** → 게임플레이와 음악의 즉각적 연결
- 마운트가 쓰러지면 플레이어는 맨몸으로 탈출 → 다음 몬스터를 포획해야 함
- 라이딩 메카닉이 무기 교체 + 이동 수단을 동시에 담당

### 로그라이트 구조
- 스테이지 사이 퍽(perk)과 레벨업 선택
- 런마다 랜덤 몬스터 배치와 레이아웃
- 다양한 환경 퍼즐과 장애물
- 메트로이드바니아적 요소: 런 중 새 능력으로 이전에 막혔던 길을 열기도 함

### 탄막(Bullet-Hell)
- 탑승 몬스터에 따라 플레이어가 쏘는 탄막 패턴 완전히 변화
- 적의 공격도 탄막 패턴 — 회피 기술이 중요
- 주요 비판: 몬스터 간 탄막이 비슷해져 중후반부에 단조로움

### 협동
- 로컬 2인 플레이 지원
- 각자 독립적으로 몬스터 포획 가능
- 함께 보스를 공략하는 협공 스타일

## 플레이어가 사랑하는 것

1. **포획→라이딩 루프**: 강한 몬스터를 잡아 탑승하는 순간의 흥분
2. **BGM 연동**: 탑승 몬스터마다 음악이 달라지는 몰입감
3. **높은 재플레이성**: 몬스터 종류와 퍽 조합으로 런마다 다른 느낌
4. **귀여운 비주얼**: 외형과 실제 난이도의 괴리가 발견의 재미 ("겉보기엔 귀여운데 실제로는 어렵다")
5. **협동의 자연스러움**: 각자 역할이 다르지 않아 진입 장벽 낮음

## OnionCat 적용 포인트

### 1. "타는 것이 곧 무기" 메카닉과 OnionCat의 공명
- Patch Quest에서 탑승 몬스터 = 이동 + 무기 + 스킬
- OnionCat의 **고양이(이동·근접) + 양파(무기·스킬)**가 이미 이 역할 분담의 비대칭 버전
- 핵심 인사이트: 플레이어가 "지금 내 전투 스타일이 뭔지"를 즉각 느끼는 것이 중요 — 마운트/장비 교체 시 시각적·청각적 즉각 피드백이 필요
- OnionCat 적용: **장비 교체 시 고양이 외형 변화** (무기 아이콘이 달린 스프라이트 변화) + **할퀴기 효과음 변화** — 이미 무기 장비에 따라 할퀴기 형태가 바뀌므로 사운드와 시각 효과만 추가하면 됨

### 2. BGM 연동 — 전투 상황 반응형 음악
- 탑승 몬스터마다 BGM이 변화 → 플레이어가 게임 상태를 청각으로도 인식
- OnionCat 적용: **스테이지별 BGM 레이어 시스템** — 기본 BGM에 "긴장 레이어"를 엘리트 방·보스 입장 시 추가 (`Music.Play(MusicId.BossIntro)` + 레이어 ON). 현재 칩튠 BGM 5곡의 변주로 구현 가능
- 더 나아가: 세트 조합이 갖춰질수록 (2단계→4단계→6단계) 배경 음악에 미세한 악기 레이어 추가 — 강해지는 느낌을 청각으로도

### 3. 포획 실패가 전략 리소스 관리
- 라소 포획에 실패하면 라소를 써버린 것 — 자원 관리 긴장감
- OnionCat의 **털뭉치** 회수 메카닉과 구조적으로 동일 (던짐 → 붙음 → 줍기로 재충전)
- 인사이트: "던지기" 행동에 **위험/보상** 구조를 명확히 하면 흥미가 올라감 — 털뭉치 던지기가 빗나갈 경우 "잠시 무방비"가 되는 패널티 강화를 고려

### 4. 탑승 몬스터 별 탄막 다양성 → 마법서별 스킬 다양성
- Patch Quest의 핵심 재미: "어떤 몬스터를 타느냐"에 따라 내 공격 패턴이 완전히 달라짐
- OnionCat의 **마법서 3칸** 시스템이 동일한 역할 — 마법서 조합에 따라 양파 플레이어의 탄막 패턴이 완전히 달라져야 재미
- 주요 비판(몬스터 간 탄막 유사) → OnionCat에서 피해야 할 점: 마법서 스킬들이 결국 "쏜다" 하나로 수렴되지 않도록 **비탄막형 스킬** (설치·돌봄·방해) 비중 확보 — 현재 설계(터지는 박·산탄·회복·포자 구름)가 이미 다양성 추구

### 5. 귀여운 비주얼 + 실제 어려움의 격차 활용
- "귀여워서 쉬울 것 같은데 실제로는 어렵다" — 발견의 재미로 바이럴 마케팅에 도움
- OnionCat도 귀여운 고양이+양파 콘셉트 + 실제 도전적 적 패턴 구조로 이미 이 방향
- 적용: 스팀 상점 페이지·트레일러에서 귀여운 면을 앞세우고, 실제 플레이에서 예고 패턴의 압박감을 확실히 전달하는 전략 유효
