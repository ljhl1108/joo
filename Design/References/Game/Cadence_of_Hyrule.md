## 핵심 메커니즘

### 듀오 캐릭터 시스템 (OnionCat에 가장 직접적인 참고)

**링크와 젤다가 각각 독립된 역할**을 가지며, 협동 플레이 시 두 캐릭터를 각자 조종한다.

| | 링크 | 젤다 |
|---|---|---|
| 기본기 | 근접 무기 (칼·방패) | 원거리 마법 (인도의 파이어볼·보조 마법) |
| 대쉬 | 없음 (Pegasus Boots 획득 후) | 없음 |
| 고유 도구 | 화살·폭탄·창 등 아이템 중심 | 마법 주문 (Nayru's Love 실드 등) |
| 체력 | 별도 하트 | 별도 하트 |

- **싱글 플레이** 시 둘 중 한 명을 고르고, **협동 플레이** 시 각자 조종
- 협동에서 한 명이 죽어도 살아 있는 쪽이 계속 → 완전한 게임오버는 둘 다 죽어야

### 리듬 기반 액션

- 비트에 맞춰 행동하면 보너스(다이아몬드 × 2), 그냥 움직여도 플레이 가능
- **자유 이동 모드**가 DLC로 추가돼 리듬 강요 없이 플레이 가능
- "리듬은 선택지, 강제가 아님" → OnionCat의 "패링은 보조 수단" 원칙과 동일한 접근

### 오픈 월드 + 절차적 혼합

- 하이랄 맵 전체가 로그라이크식으로 무작위 생성
- 고정 위치(던전·마을·상점)는 항상 같은 자리, 사이 지역이 무작위
- **한 번 클리어한 방은 비트 조건이 없어짐** → "익숙해지면 더 쉬워지는" 설계

### 장비 시스템

- 무기 10+ 종: 각 무기마다 공격 패턴이 완전히 다름 (창 = 2칸 직선, 망치 = 무조건 넉백 등)
- 소비 아이템 슬롯 (폭탄·방패·화살 등) 별도 관리
- 장비 조합으로 빌드가 달라짐 (토치 + 화염 무기 등)

## 협동 요소 분석

### 역할 비대칭이 만드는 협동

- 링크가 근접으로 뚫고, 젤다가 뒤에서 마법으로 지원하는 구도
- 젤다의 Nayru's Love는 링크도 보호 → **실드가 파트너에게도 작용**
- 한 명이 함정 역할의 버튼을 밟고 다른 명이 적을 처리하는 퍼즐

### 체력 분리의 장단점

- 각자 체력이 있어 한 명이 무적이 되는 버그 없음
- 반면 한 명이 죽어 계속 부활하는 "짐 되는 플레이어" 문제 발생
- OnionCat이 **공유 체력**을 선택한 이유와 반대 사례 → 공유 체력이 협동 의식 강화에 더 효과적

### 위치 의존성

- 두 캐릭터가 너무 멀리 떨어지면 카메라 분리 or 한 명이 갇힘
- **같이 움직이게 강제하는 디자인** vs OnionCat의 "고양이가 항상 같이 움직이고 작물은 고정" 방식

## 플레이어들이 좋아하는 것

1. **링크·젤다라는 아이콘** — 기존 IP의 익숙함이 접근성 보장
2. **리듬 보너스가 선택** — 하고 싶으면 더 잘하고, 아니어도 클리어 가능
3. **협동의 자연스러운 역할 분리** — 근접/마법이라 겹치지 않음
4. **짧은 판** — 한 번 플레이에 1~2시간, 사망 후 재시작이 부담 없음
5. **원더풀한 OST** — 게임 조각 느낌의 비트 맞춤 리믹스

## OnionCat 적용 포인트

### 1. 역할 분리의 명확성 — 겹치지 않는 것의 힘
- 링크=근접 / 젤다=마법은 "어떤 역할인지" 한눈에 보임
- OnionCat도 고양이=이동+근접 / 작물=고정+원거리로 동일 원칙
- **새 작물/장비 추가 시 역할이 명확히 구분되는지 체크**해야 함
- 고양이 장비가 원거리를 주면, 작물 장비가 근접을 주면 → 역할 경계 흐릿해짐

### 2. 죽음 처리 — "완전한 실패" 조건의 중요성
- Cadence of Hyrule: 한 명이 죽어도 계속 (부활 아이템), 둘 다 죽으면 게임오버
- OnionCat: 공유 체력 → 한 쪽 실수가 "공동의 손해"로 즉각 체감
- 단, OnionCat은 패시브 실드가 완충재 → 협동을 강요하되 한 번 실수에 판 끝나지 않음

### 3. "리듬 선택제" → OnionCat의 "패링 선택제"
- 리듬에 맞추면 보너스, 안 맞춰도 클리어 가능 = 패링 맞추면 보너스, 안 해도 클리어 가능
- **추가 보상을 주는 선택적 고기술** 설계 패턴
- 패링 성공 시 반사 대미지 or 협동 콤보 보너스를 더 주는 방향 고려 가능

### 4. 협동 퍼즐 방 아이디어
- 한 명이 버튼·트리거를 밟고 있으면 다른 명이 무언가 할 수 있는 방
- OnionCat: 고양이가 특정 위치에 서 있으면 작물의 사거리/방향이 열리는 구조
- 또는: 고양이가 적에게 근접하고 있을 때 작물이 조준하면 뒤쪽 약점 노출

### 5. 오픈 월드 방 재방문 없음
- 클리어한 방은 돌아오지 않음 → 긴장감 유지
- OnionCat의 방 하나씩 클리어하는 선형 구조와 동일한 효과
- 중간 저장 지점(마을) = Cadence의 마을 세이브와 같은 역할

### 6. 무기별 공격 패턴 차별화
- 망치: 무조건 넉백 / 창: 직선 2칸 / 댄서: 범위 등
- OnionCat의 고양이 무기별 할퀴기 변형 (회전·도약·3타·연타·특수) 같은 방향
- 작물 마법서도 "쿨타임 긴 대신 범위" / "짧은 쿨타임 단일" 등 패턴으로 차별화 추천
