## 핵심 시스템

### Vault Breaker (캐릭터 선택)
- 각 런에서 플레이어가 고르는 고유 용병 메크
- 고유 기본 능력 1개 + 패시브 특성
- 현재 10종 이상 — 각각 역할(탱크·딜러·지원·기동)이 다름
- 같은 Vault Breaker를 여러 명이 쓸 수 있음 (차별화는 장비와 임플란트)
- **OnionCat 참고**: 비대칭 역할 없이 같은 캐릭터를 여럿이 쓰는 방식 — OnionCat처럼 서로 다른 역할이 고정될 때의 차이를 비교하기 좋은 사례

### Ark (메타 성장 트리)
- 런 사이 영구 해금 트리 (경험치로 Ark 노드 구매)
- 각 Vault Breaker마다 별도 트리
- 런 내 임플란트·장비를 더 강하게 만드는 기반 스탯 제공
- **OnionCat 참고**: 영구 성장 → 온실/해금 시스템과 유사. 장비 해금과 Ark 성장을 분리한 점이 인상적

### 임플란트 & 시너지 시스템 (장비 핵심)
- 런 중 드롭·상점에서 획득하는 **임플란트** (수동 보너스 칩)
- 슬롯이 제한되어 있어 조합 선택이 중요
- **시너지**: 같은 계열 임플란트 여러 개 → 추가 효과 발동
- 시너지 종류: 화염·냉기·전기·독 속성 계열, 공격 속도 계열, 방어 계열 등
- 같은 시너지 2개 보유 시 "부분 효과", 4개 → "완전 효과" 식의 단계형 보너스
- **OnionCat 참고**: OnionCat의 세트 효과(2/4/6/8단계) 구조와 거의 동일한 발상. ANVIL은 임플란트 슬롯 수가 더 적어 선택의 집중도가 높음

### 무기 시스템
- 근거리·원거리 무기 각 1슬롯
- 같은 무기의 티어 업그레이드(★1~★3) 존재
- 특수 발동형 무기 효과: 적 처치 시 폭발, 임플란트 발동 조건 되기도 함
- **OnionCat 참고**: 무기와 임플란트를 분리한 구조. OnionCat의 "무기+효과" 조합과 비교할 때 무기 자체의 발동 효과가 더 간단함

### 협동 시너지
- **공동 화력**: 같은 적에 집중 사격 시 약점 노출
- **부활**: 쓰러진 플레이어를 1명이 살리는 동안 나머지가 엄호
- **장비 공유**: 임플란트는 개인 소유지만 보스 보상 등 일부 공유 선택 존재
- **OnionCat 참고**: OnionCat처럼 명시적 협동 보상(콤보·게이지)보다 암묵적 협력(엄호·집중) 중심 — 두 접근의 장단점

### 적·방 구조
- 웨이브식 클리어: 방에 입장 → 적 모두 처치 → 출구 개방
- 방마다 1~3개의 웨이브 (스테이지 후반으로 갈수록 복잡)
- 보스 방은 각 스테이지 마지막에 고정 등장
- 엘리트 방(모디파이어 붙은 강화 적) 존재
- **OnionCat 참고**: 방 클리어 → 보상 → 다음 방 흐름이 같음. ANVIL은 선택지 없는 선형 구조, OnionCat은 분기 지도

## 플레이어들이 좋아하는 것

1. **빠른 액션과 명확한 피드백** — 적 사망 이펙트, 히트감, 무기별 개성이 뚜렷
2. **임플란트 조합 발견** — "이 두 개를 같이 쓰면 미침!"의 순간이 반복 플레이 동기
3. **멀티플레이 카오스** — 4명이 화면을 가득 채우는 탄환 속 생존감
4. **한국 개발사 감성** — 아트 스타일과 연출이 세련됨 (특히 Vault Breaker 소개 애니메이션)

## OnionCat 적용 포인트

| 주제 | ANVIL 접근 | OnionCat 적용 |
|------|-----------|--------------|
| 세트 효과 | 임플란트 계열 2·4개 단계형 | 10개 세트 2/4/6/8단계 — 단계 발동 임계치 UI 힌트 개선 참고 |
| 협동 역할 | 플레이어가 조합 결정, 고정 역할 없음 | 고양이·양파 역할 고정 — ANVIL보다 초보자 진입 쉬움 |
| 메타 성장 | Ark 트리(캐릭터별) + 런 내 임플란트 | 온실 해금(영구) + 런 내 장비(일시) — 유사 구조 |
| 보스 설계 | 단계 없음, 대형 HP바 + 판 전체 패턴 | 보스 페이즈 존재 — ANVIL처럼 "페이즈 없이 HP 구간별 패턴 강화"도 고려 가능 |
| 한국 감성 | 웹툰풍 연출, 셀 애니 효과 | 픽셀 아트이지만 임팩트 프레임 강조, 타격 이펙트에 반영 |
| 적 엘리트 | 모디파이어(빠름·방패·폭발 등) | EliteVariant 시스템으로 이미 구현 — ANVIL의 모디파이어 종류 참고 |
