## 핵심 시스템

### 완전 비대칭 화면

두 플레이어는 **완전히 다른 화면**을 본다:

| Agent (현장 요원) | Hacker (해커) |
|---|---|
| 3D 현장 | 2D 인터페이스 |
| 적, 카메라, 물리 장애물 | 코드, 데이터 맵, 시스템 화면 |
| 직접 행동 (문 열기, 적 회피) | 원격 지원 (카메라 해제, 비밀번호 제공) |
| 현장 화면만 보임 | 현장이 보이지 않음 |

예시 미션: Agent가 금고 앞에 선다 → Hacker의 화면에 비밀번호 힌트가 보임 → Hacker가 말로 알려줌 → Agent가 입력. 둘 다 각자 화면 정보가 없으면 불가능.

### 소통이 메커니즘

구두 소통이 게임의 핵심 입력이다:
- 버튼이나 UI가 아닌 **말로 정보를 전달**
- "지금 보이는 색깔이 뭐야?" "파란색, 빨간색, 노란색 순서야" "파-빨-노 눌렀어" 같은 소통이 퍼즐 풀이
- 한 명이라도 말하지 않으면 클리어 불가 → 조용한 플레이어를 강제로 참여시킴

### 역할 비대칭이지만 무게감은 균등

- Agent는 직접 행동 → 긴장감
- Hacker는 Agent의 성공을 위한 정보 제공 → "내가 뒤를 커버한다"는 역할감
- 어느 쪽도 "조연"이 아님 — Hacker 없이는 Agent가 아무것도 못 함

### 세션 구조

- 각 미션은 15~25분 — 짧고 완결성 있음
- 미션마다 새로운 메커니즘 도입 (지문 인식, 위성 추적, 암호 해독 등)
- 한 쌍이 한 번씩 역할을 바꿔서 플레이하면 2~3시간으로 전체 경험

## 플레이어들이 좋아하는 점

1. **실제로 소통하는 느낌** — 버튼을 같이 누르는 게 아니라 대화로 협력
2. **내가 없으면 파트너가 못 함** — 역할감과 책임감
3. **새로운 메커니즘이 계속 나옴** — 지루하지 않고 "다음엔 뭐가 나올까" 기대감
4. **화면이 달라서 착각이 생김** — "지금 뭐가 보여?" "아 그거 왼쪽에 있잖아" 오해가 웃음 포인트

## OnionCat 적용 포인트

### 1. 고양이-작물 화면 정보 비대칭 강화

지금 OnionCat은 두 플레이어가 같은 화면을 봄. Operation Tango처럼 **완전히 다른 화면**을 주긴 어렵지만:
- 고양이 HUD에만 보이는 정보: 발밑 쿨타임(CatPips), 야성 게이지
- 작물 HUD에만 보이는 정보: 마법서 쿨타임, 씨앗 탄 수
→ 각자 "내 화면을 보고 파트너에게 알려야" 하는 순간을 만들면 소통 필요성 생김

### 2. "한 명만 볼 수 있는" 보스 패턴 경고

Operation Tango 미션에서 Hacker만 적의 위치 패턴을 볼 수 있듯:
- 보스 패턴이 "작물 화면에만 경고 아이콘이 먼저 뜨는" 디자인
- 작물이 "오른쪽 위에서 탄 온다!" 고양이가 "알았어 피할게" → 말 안 해도 됐던 조작이 소통으로 변환
- 이미 말풍선 대화 시스템(`Dialogue.Play`)이 있으므로 적 도발 대사도 이 방향으로 활용 가능

### 3. 역할의 "무게"를 균등하게 유지

Operation Tango가 성공한 이유: Hacker가 "도와주는 역할"이 아니라 "없으면 안 되는 역할".
OnionCat에서 작물(P2)이 "더 쉬운 쪽"처럼 느껴지지 않게:
- 작물 고유기 R이 없으면 불가능한 적/장애물 (예: 버섯밭으로만 무력화 가능한 적)
- "작물이 먼저 약점 타격 → 고양이 추가 타격 가능" 같은 콤보 구조
→ 고양이가 작물을 기다려야 하는 순간이 반드시 있어야 함

### 4. 비대칭 퍼즐 방 아이디어

마을 방(`Room_Special`)에 Operation Tango식 퍼즐 추가 가능:
- "고양이 화면에 보이는 그림 순서를 작물이 UI에서 맞추는" 간단 퍼즐
- 클리어 시 보너스 씨앗 또는 체력 회복
- 대화 없이 클리어 불가 → 짧은 소통 미니게임 역할

### 5. 파트너 위험 인식 시스템

Operation Tango에서 Hacker가 Agent의 위험을 항상 인식하지 못하는 긴장감처럼:
- 고양이가 피격될 때 작물 화면에만 테두리 경고 (반대로 작물 쪽에서 위험 감지 역할)
- 작물: "야 맞는 거 보여, 대쉬해!" 고양이: "알아!" — 말 없이도 비슷한 역학
