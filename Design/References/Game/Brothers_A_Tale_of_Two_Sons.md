## 핵심 메카닉

### 1. 하나의 컨트롤러 = 두 캐릭터
- **좌측 스틱 + LT/LB** → 형(큰 형제) 제어
- **우측 스틱 + RT/RB** → 동생(작은 형제) 제어
- 한 플레이어가 좌우 뇌를 동시에 쓰는 듯한 체험
- 키보드로도 가능 (WASD + 방향키), 하지만 게임패드 권장

### 2. 비대칭 능력
| 형 (큰 형제) | 동생 (작은 형제) |
|---|---|
| 힘이 세다 | 빠르고 민첩 |
| 문/레버 조작 | 좁은 틈 통과 |
| NPC 대화 시 강압적 | NPC 대화 시 귀엽게 설득 |

### 3. 협력 퍼즐 구조
- 두 형제 모두 필요한 퍼즐 (A가 스위치 누르는 동안 B가 통과)
- 한 명이 불가능한 상황을 다른 형제가 보완
- 단독 행동 불가 → 협력 강제

### 4. 죽음과 감정 연출
- 한 형제가 위험에 처하면 다른 형제가 구해야 함
- [스포일러] 게임 후반 핵심 스토리 반전: 혼자 두 스틱을 쓰는 행위가 감정적 의미를 가짐
- 기계적 메카닉과 감정적 스토리텔링의 완벽한 통합 사례

## 플레이어가 사랑하는 요소

1. **인풋 방식 자체가 스토리** — 컨트롤 스킴이 감정 전달 도구
2. **대사 없이 감정 전달** — 모든 NPC가 외계어를 말하지만 제스처와 맥락으로 이해
3. **협력감** — 실제로 두 손이 협력하는 물리적 체험
4. **아름다운 환경** — 동화적 풍경, 각 챕터마다 완전히 다른 바이옴
5. **독특한 클라이맥스** — 게임 메카닉이 감정 해소의 도구

## OnionCat 적용 포인트

### A. 공유 바디 컨셉의 철학적 원형
- OnionCat은 "두 플레이어가 하나의 몸"을 공유 → Brothers는 "한 플레이어가 두 몸"을 조작
- 반대 방향이지만 **"분리될 수 없는 두 존재"** 라는 감정적 코어는 동일
- **적용**: OnionCat의 Cat과 Crop이 서로 없으면 불완전하다는 설계 철학 강화

### B. 비대칭 능력이 서로를 보완하는 퍼즐/전투 설계
- 형은 힘, 동생은 민첩 → Cat은 근접, Crop은 원거리/방어
- **적용**: Cat만으로 못 뚫는 적(실드형 원거리 적)과 Crop만으로 못 대처하는 적(빠른 근접 적) 설계
- 둘이 함께일 때만 모든 상황을 해결 가능한 조합

### C. "비대칭 입력" UX 학습
- 좌/우 스틱이 다른 역할 → OnionCat도 P1(Cat)과 P2(Crop)이 완전히 다른 버튼 레이아웃
- **적용**: 게임패드 UI에서 P1 버튼 프롬프트와 P2 버튼 프롬프트를 명확하게 분리 표시

### D. 서사적 바인딩
- "둘 다 죽으면 게임오버" 대신 한 명이 죽으면 다른 한 명이 부활시켜야 하는 메카닉도 고려 가능
- **적용**: OnionCat에서 Cat 또는 Crop이 스턴/다운됐을 때 상대가 회복시키는 협력 구조
