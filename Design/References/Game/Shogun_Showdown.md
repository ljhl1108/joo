# Shogun Showdown

리서치 날짜: 2026-10-01

## 기본 정보

- **개발사**: Roboatino (아르헨티나 인디)
- **출시**: 2023년 (Early Access 2022)
- **Steam**: https://store.steampowered.com/app/1824070/Shogun_Showdown/
- **장르**: 전술 로그라이크, 턴 기반 + 실시간 혼합
- **플레이어 수**: 싱글플레이어

## 핵심 메카닉

### 1. 미리 보이는 적 의도 (Enemy Intent / Telegraph)
게임의 핵심 차별점. 적이 다음 턴에 무엇을 할지 항상 **아이콘으로 표시**됨.
- 공격할 방향, 거리, 피해량을 플레이어가 미리 알 수 있음
- "정보를 주되 실행은 플레이어가 해야 함" — 알면서도 실수하는 재미

### 2. 턴 기반 실시간 혼합 (Turn-on-Move)
- 플레이어가 이동/공격 입력을 하는 순간 한 턴이 소비됨
- 가만히 있으면 시간이 멈춤 (숙고 허용)
- 이동과 공격이 행동 포인트를 소비 → 자원 관리

### 3. 무기 슬롯 + 업그레이드 시스템
- 좌우 손에 각각 무기 장착 (칼, 활, 창, 특수 무기 등)
- 각 무기마다 고유 쿨다운과 범위
- 런마다 새 무기 획득, 업그레이드 선택

### 4. 포지셔닝 퍼즐
- 작은 격자(1D 라인 + 약간의 2D 이동)에서 적 여러 마리 처리
- "다음 공격을 받지 않으면서 모두 처치하는 루트 찾기"가 매 전투의 핵심

### 5. 스킬 트리
- 런 중 획득하는 패시브 스킬
- 특정 무기를 강화하거나 이동 범위를 늘리는 등 빌드 다양성

## 플레이어가 좋아하는 것

- **예측 가능성 + 실행 난이도의 균형**: 모든 정보가 공개돼 있어 죽으면 내 실수임을 알 수 있음
- **짧은 런 + 빠른 템포**: 한 런이 30분~1시간, 실패해도 아깝지 않음
- **빌드 다양성**: 무기 조합에 따라 플레이 스타일이 크게 달라짐
- **낮은 가격 대비 높은 완성도**: 소규모 팀의 집중된 디자인

## OnionCat 적용 포인트

### 적 의도 표시 → 근거리/원거리 약점 표시 연계
```
OnionCat 핵심 규칙: 일부 적은 근거리에만, 일부는 원거리에만 피해를 받음
Shogun Showdown처럼 적 머리 위에 아이콘으로 다음 행동 + 약점 타입을 동시에 표시하면:
  - 플레이어가 "이 적은 고양이가 근접해야 함"을 직관적으로 파악
  - 협동 판단이 빠르게 이루어짐
```

**구현 힌트**:
```csharp
// 적 머리 위 Canvas(World Space)에 아이콘 표시
// 약점 타입: MeleeOnly 아이콘(칼), RangedOnly 아이콘(화살)
// 다음 행동: 공격 예고(빨간 화살표), 이동 예고(발자국)
public enum DamageType { Any, MeleeOnly, RangedOnly }
public DamageType weaknessType; // Enemy 컴포넌트에 추가
```

### 포지셔닝 기반 협동 → OnionCat 이동 설계
- 고양이가 앞에서 근접하고 양파가 뒤에서 원거리 지원하는 최적 포지션이 자연스럽게 생김
- 적 의도 표시로 "이 적이 곧 돌진함 → 양파가 쉴드 준비" 같은 협동 시그널 가능

### 무기 좌우 분리 → Cat/Onion 역할 분리 참고
- 좌손/우손 무기가 다른 쿨다운과 범위를 가짐
- OnionCat: 고양이 공격(F키 슬래시)과 양파 발사(마우스)가 완전히 독립된 쿨다운과 로직을 가지는 구조와 같음
- 두 액션이 서로를 방해하지 않고 시너지를 만드는 설계

### 적 의도 UI 구현 (OnionCat 직접 응용)
```
TelegraphIndicator 컴포넌트:
  - 공격 예정 방향: 빨간 화살표 오버레이
  - 약점 타입: 칼/화살 아이콘 (Enemy 머리 위 WorldSpace Canvas)
  - 행동 쿨다운: 원형 진행 바 (행동하기까지 N턴/N초)
```

### 짧은 런 철학
- Shogun Showdown의 30~60분 런 → OnionCat의 방 수를 8~12개로 제한하면 같은 체감 달성
- 죽었을 때 "한 번 더"가 나오는 길이 설계
