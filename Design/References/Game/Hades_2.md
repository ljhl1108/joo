## 핵심 메커니즘

### 기본 시스템
- **주인공**: 멜리노에(Melinoe) — 자그레우스의 여동생, 마법과 근접 혼합 전투
- **목표**: 크로노스(시간의 신)를 물리치기 위해 지하세계와 지상 두 루트를 공략
- **두 가지 루트**: 지하세계(타르타로스 방향) + 지상(올림포스 방향) — 각각 다른 에리어, 보스, 전략 필요

### 무기 시스템 (Nocturnal Arms)
- 6종 이상의 무기, 각 무기마다 **Aspect(측면)** 4가지
- Aspect = 무기의 성격을 바꾸는 영구 업그레이드 (최초 선택 후 해금 필요)
- 예: 지팡이 → 기본/원거리/근접 강화/도트 데미지 Aspect

### 아르카나 카드 시스템 (Arcana Cards)
- 룬 통화(Psyche)로 해금하는 **메타 진행 카드 덱**
- 각 카드는 고유 패시브 효과 (HP 상승, 쿨타임 감소 등)
- **Grasp 제한**: 동시에 장착 가능한 카드 수 제한 → 빌드 선택의 깊이 창출
- 카드들 사이에 **시너지 조합**이 존재 → 빌드 다양성

### Boon(신의 축복) 시스템
- 전작 대비 올림포스 신 수 증가 + **새 신들**(헤파이스토스, 헤스티아, 크로노스의 타이탄들)
- **Duo Boon**: 두 신의 축복이 결합한 특수 효과 — 시너지 빌드의 핵심
- **Legendary Boon**: 단일 신의 최강 버전, 특정 조건 충족 시 등장

### 소환 시스템 (Summons)
- 일부 Boon이 보조 소환물(유령, 동물 등)을 필드에 배치
- 소환물은 자동 공격 or 버프 제공 → 간접 플레이어 조작 레이어 추가

### 마법 캐스트 시스템
- 멜리노에는 마법 오브를 필드에 배치 가능
- Boon에 따라 오브가 폭발, 지속 데미지, 버프 등 다양하게 변화
- **투사체 + 즉각 사용**의 혼합 → 공간 배치 전략 요소

### 낮/밤 사이클 (Surface 한정)
- 지상 구역에서는 시간이 경과 → 밤이 되면 적이 강해짐
- **시간 압박 요소**: 무한정 탐험 불가, 효율적 루트 계획 필요
- 낮 동안 특정 자원 수집, 밤이 되기 전 보스 처치가 이상적

### 제작/농사 시스템 (Gathering)
- 루트 중 허브·광석·생선 등 재료 수집 가능
- 캠프(헤카테의 집)에서 재료로 **인캔테이션(Incantation)** 제작
- 인캔테이션 = 새 무기 해금, 새 NPC 조건 해금, 게임 시스템 확장 등

## 협동 요소

Hades 2는 **싱글플레이어** 게임이지만 협동 설계 참고 포인트:
- **NPC 조력자 시스템**: 특정 보스에서 NPC 동료가 일시 참전 → "임시 파트너" 감각 연출
- **역할 분리**: 멜리노에의 마법(원거리) + 근접 무기 → OnionCat의 캣(근접) + 어니언(원거리)와 구조적 유사

---

## 플레이어들이 사랑하는 것

1. **빌드 다양성**: Boon × Arcana × Aspect 조합으로 매 런 완전히 다른 플레이
2. **내러티브 통합**: 죽음도 스토리의 일부 → 실패가 곧 진행
3. **점진적 세계 해금**: 인캔테이션이 게임 내 세계를 유기적으로 확장
4. **Grasp 딜레마**: 아르카나 카드 선택 제한 → "이것도 쓰고 싶은데 공간이 없어" 의사결정
5. **멜리노에 마법 빌드**: 전작과 전혀 다른 원거리+소환 플레이스타일

## OnionCat 적용 포인트

### 1. Grasp 시스템 → 업그레이드 슬롯 제한
```
런 중 획득 업그레이드에 슬롯 제한 도입
- 캣 슬롯 3 + 어니언 슬롯 3 = 공유 슬롯 6개
- "강한 업그레이드지만 다른 걸 내려놔야 한다"는 선택의 고통 → 로그라이크 깊이
```

### 2. 인캔테이션 → 제작 기반 메타 해금
```
런 중 수집한 씨앗/재료로 허브(홈베이스)에서 새 능력 제작
- "씨앗 10개 + 철광석 5개 = 새 능력 해금"
- OnionCat의 농업 테마와 완벽히 맞는 메타 진행 방식
```

### 3. Duo Boon → 캣+어니언 시너지 업그레이드
```
캣이 특정 업그레이드 A 보유 + 어니언이 업그레이드 B 보유 시
→ 특수 시너지 효과 발동
예: 캣의 "대쉬 후 강화 공격" + 어니언의 "대쉬 중 투사체 분산" = "대쉬 연계 난사"
```

### 4. 낮/밤 사이클 → 턴/조건 기반 난이도 상승
```
방 진입 횟수가 쌓일수록 적 강화 (퍼마데스 압박)
또는 특정 이벤트 룸에서 시간 제한 전투 도입
```

### 5. Aspect 시스템 → 무기 전문화
```
같은 무기(예: 꽃잎 투사체)도 Aspect에 따라 성격이 다름
- Aspect A: 범위형 폭발
- Aspect B: 관통형 직선
런 시작 시 Aspect 선택 = 플레이 스타일 선언
```
