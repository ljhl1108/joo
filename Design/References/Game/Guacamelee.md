# Guacamelee!

리서치 날짜: 2026-07-30

- **공식 사이트**: https://www.drinkboxstudios.com/games/guacamelee/

- **장르**: 메트로이드바니아, 2인 협동 액션 플랫포머

## 핵심 메카닉

### 2인 협동 시스템
- P1과 P2가 화면에 동시 존재, 각자 독립 체력 + 공유 진행 상태
- 한 플레이어가 사망 시 소울 형태로 이동 → 상대가 접근해 부활 가능
- 특정 공격: 상대 플레이어를 잡아 투척무기처럼 사용하는 협동 기술

### 차원 전환 메카닉
- 빛의 세계 ↔ 어두운 세계 순간 전환 (특정 구역에서)
- 일부 적은 특정 차원에서만 공격 가능 → **OnionCat의 "근접 취약 적 / 원거리 취약 적" 개념과 구조적으로 동일**

### 전투 시스템 (레슬링 기반 근접)
- 잡기, 던지기, 지상 스매시, 챠지 공격, 슈퍼 콤보
- **적의 색상 코드로 약점 표시**: 특정 색상 적 = 해당 공격 유형에만 피격 가능
- 히트스톱, 이펙트, 사운드가 조화롭게 설계됨

### 메트로이드바니아 구조
- 능력 해금 → 이전 구역 재탐험 가능
- 비선형 진행, 숨겨진 보물/NPC

## 플레이어들이 사랑하는 이유
- **두둑한 유머**: 멕시코 루차 리브레 문화 패러디, 재미있는 대사
- **유연한 협동**: 2인 협동이 강요가 아닌 자연스러운 보너스처럼 느껴짐
- **색상 코딩 적**: 직관적인 약점 시스템이 전략성 부여
- **탄탄한 전투감**: 히트스톱, 이펙트, 사운드의 완성도

## OnionCat 적용 포인트

### 1. 색상 코딩 약점 시스템
Guacamelee!의 "이 색 공격만 통함" → OnionCat의 "근접 전용 적 / 원거리 전용 적" UI 표현에 직접 응용.
- 발톱 아이콘 = Cat 근접 공격만 유효
- 씨앗/구슬 아이콘 = Onion 원거리 공격만 유효
- 적 머리 위 아이콘으로 즉시 인식, 잘못된 공격엔 "무효!" 이펙트

### 2. 파트너 부활 → OnionCat 임계 상태로 변환
Guacamelee!는 독립 HP로 상대가 부활시키지만, OnionCat은 공유 HP이므로:
- 공유 HP 15% 이하 진입 시 "임계 상태(Critical State)" → 짧은 무적 + 회복 기회
- "고양이 목숨" 아이템으로 런당 1~3회 즉사 방지 (데스 디파이언스 참고)

### 3. 레슬링 스타일 협동 콤보
Cat이 근접 공격으로 적을 기절 상태로 만들면, Onion이 원거리 공격으로 홈런 타격 → 적이 날아가 다른 적과 충돌해 범위 피해. 협동 필수 콤보로 시너지 강화.

### 4. 유머 톤 참고
Guacamelee!처럼 게임 내 텍스트, NPC 대사, 아이템 설명에 유머를 녹여 넣어 픽셀아트 무드를 가볍고 즐겁게 유지.
