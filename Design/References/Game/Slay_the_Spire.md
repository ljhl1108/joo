## 핵심 메카닉

### 덱빌딩 전투 루프
- 매 전투마다 덱에서 5장 드로우 → 에너지(기본 3)를 소비해 카드 사용 → 적 공격
- **전투 종료 후 카드 1장 선택** (3가지 후보) → 덱에 영구 추가
- 덱은 런 내내 누적 성장 → 런 종료(사망 또는 클리어)까지 유지
- 카드 '업그레이드'가 가능 (불꽃 조각상에서) → 동일 카드지만 수치/효과 강화

### 캐릭터 클래스 (비대칭 카드풀)
| 클래스 | 키워드 | 플레이 스타일 |
|--------|--------|--------------|
| Ironclad (전사) | 소모(Exhaust), 힘(Strength) | 근접 위주, 희생 빌드 |
| Silent (도적) | 독(Poison), 에너지 생성 | 다타 콤보, DoT 누적 |
| Defect (결함) | 오브(Orb) 채널링 | 에너지 엔진, 수동 스케일링 |
| Watcher (관찰자) | 자세 전환(Stance) | 공격/방어 모드 스위칭 |

### 맵 경로 선택 시스템
- 각 층은 **분기 경로** — 플레이어가 방 유형을 보고 선택
- 방 유형: 일반 전투 🗡️ / 엘리트 💀 / 이벤트 ❓ / 상점 💰 / 휴식 🔥 / 보물 📦 / 보스 👑
- **엘리트 처치** = 강력한 렐릭 보장 → 고위험-고보상 선택
- **휴식 장소**: HP 회복 또는 카드 업그레이드 선택 강제 딜레마

### 렐릭 시스템 (패시브 영구 효과)
- 렐릭 = 영구 보유 패시브 아이템, 100개 이상 존재
- 효과 예시: "카드 드로우 +1", "선공 보너스", "죽음에서 한 번 부활"
- **렐릭 중심 빌드**: 어떤 렐릭을 먼저 얻느냐가 그 런의 방향을 결정
- 렐릭 간 시너지 존재 → 시스템이 스스로 스토리를 만드는 느낌

### 저주(Curse) 카드 시스템
- 일부 이벤트/상점에서 강제로 '저주 카드'를 덱에 추가
- 저주 카드는 드로우 시 공간만 차지하고 부정적 효과 or 아무 효과 없음
- 리스크-리워드 교환: 좋은 보상 대신 덱 오염 감수

### 포션 시스템
- 전투 중 1회용 소비 아이템 → 공격/방어/버프
- 최대 3개 소지 가능 → 언제 쓸지 판단력 테스트

### 어센션 모드 (難이도 단계)
- 클리어 후 다음 난이도 해금 (총 20단계)
- 단계마다 새 패널티 추가: "초반 엘리트 등장", "저주 카드 추가", "보스 HP 증가"
- **신규 플레이어도 진입 가능, 숙련자도 도전할 수 있는 난이도 스케일링**

---

## 플레이어가 사랑하는 것

1. **빌드가 스스로 완성되는 느낌**: 카드와 렐릭 조합으로 뜻밖의 OP 빌드가 생기는 순간의 쾌감
2. **매 런의 독립성**: 렐릭/카드 조합이 달라서 매 런이 전략적으로 다름
3. **짧은 런**: 한 런이 1~2시간 내 완결 → 부담 없는 진입
4. **투명한 정보**: 적의 다음 행동이 항상 표시 → 완벽한 플레이가 가능한 느낌, 실패는 내 탓
5. **모드 지원**: 수백 개의 커뮤니티 모드 → 장수 요인

## OnionCat 적용 포인트

### 1. 업그레이드 3선택 메커니즘
- Slay the Spire: 전투 후 카드 3장 중 1장 선택 → Cat/Onion 각각 업그레이드 3가지 제시
- **P1(Cat) 전용 업그레이드 3개 + P2(Onion) 전용 3개를 동시에 화면에 제시**
- 두 플레이어가 서로 상의하며 선택 → 협동 긴장감 유지
- 구현: `UpgradeSelectionUI` — `PlayerRole.Cat` / `PlayerRole.Onion` 필터

### 2. 렐릭 = 패시브 시너지 아이템
- Slay the Spire의 렐릭처럼 **보물방에서 획득하는 영구 패시브 아이템** 도입
- 렐릭 예시: "Cat이 대시 후 2초 내 공격 시 데미지 +50%", "Onion 투사체가 벽에 1회 반사"
- 렐릭은 Cat/Onion/공유 3종류로 분류
- 구현: `RelicSO : ScriptableObject` → `OnEquip(RuntimeData data)` 이벤트 구독

### 3. 맵 경로 선택 → InRun Branch Map
- Slay the Spire 맵처럼 다음 방 유형을 미리 보여주고 선택
- `InRun_Branch_Map_System.md` 이미 리서치됨 → 해당 파일과 연동
- **핵심 딜레마**: "상점(아이템 구매) vs 엘리트(강한 보상) vs 휴식(HP 회복)" 선택

### 4. 저주 아이템 / 리스크-리워드 교환
- 강력한 아이템 대신 "Cat이 대시 쿨타임 2배" 저주를 덱에 추가
- 런이 갈수록 선택의 누적 결과가 나타나는 느낌
- 구현: `NegativeModifier` ScriptableObject 리스트 → `RunState.activeDebuffs`

### 5. 투명한 정보 설계 (적 행동 예고)
- Slay the Spire처럼 적의 **다음 행동을 아이콘으로 미리 표시**
- Cat 플레이어는 "적이 근접 공격 예정" → 대시로 피하거나 반격 준비
- Onion 플레이어는 "적이 원거리 공격 예정" → 방패 준비
- 구현: `Enemy_Telegraph_System.md` 이미 리서치됨 → 아이콘 표시 강화

### 6. 어센션 = 신규/숙련 모두를 위한 난이도
- 클리어 후 다음 어센션 해금, 최초 플레이는 기본 난이도
- OnionCat: 첫 클리어 후 "어센션 1" 해금 → 더 빠른 적, 추가 보스 어택 패턴 등
- 구현: `AscensionLevel` int → 적 HP/속도 배율 + 추가 패턴 플래그 참조
