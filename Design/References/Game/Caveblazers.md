## 핵심 메카닉

### 1. 액션 & 전투
- 근접(검), 원거리(활·마법), 점프 타격 등 다양한 공격 패턴
- 공중 콤보, 벽 점프, 더블 점프 — 이동 자체가 전투의 일부
- 피격 시 넉백이 크고 죽음이 빠름 → 학습 곡선이 가파르다

### 2. 아이템 & 시너지 시스템
- 각 런에서 아이템(무기·액세서리·아티팩트) 랜덤 드롭
- 아이템 간 시너지가 핵심: 예) "독 화살 + 폭발 화살 → 독 폭발"
- 아이템 수가 적어도 조합이 강력해지면 런이 순식간에 달라짐
- **비율이 낮은 OP 조합** 발굴이 메타의 즐거움

### 3. 협동 플레이
- 2인 이상 시 체력 공유 없이 각자 독립 HP — 죽어도 부활 아이템으로 살릴 수 있음
- 같은 화면을 공유 (스크롤 고정 카메라), 한 명이 너무 앞서면 다른 플레이어 당겨옴
- 아이템 경쟁: 두 플레이어가 같은 아이템 선택지를 공유 → 협의가 중요
- 역할 분담 자연 발생: 한 명이 탱커, 다른 한 명이 원거리 딜러로 자리잡기 쉬움

### 4. 절차적 생성
- 타일 기반 방 생성: 방 프리팹 + 연결 규칙
- 각 스테이지마다 보스 등장, 보스 격파 시 다음 스테이지 열림
- 엘리트 룸, 상점 룸, 보물 룸 등 특수 방 종류 다양

### 5. 사망 & 영구 데이터
- 완전 퍼마데스 — 런 종료 시 아이템 전부 초기화
- 메타 진행 없음 (대부분), 순수 플레이어 실력 성장
- 죽음 직후 통계(처치 수, 스테이지 등) 간단히 표시

## 플레이어가 좋아하는 이유

- 아이템 조합 발굴이 매 런마다 신선함
- 빠른 게임 템포 (한 런 20~40분)
- 협동 시 "같이 살아남기"의 긴장감과 성취감
- 픽셀아트 특유의 귀엽고 코믹한 분위기

---

## 비판 & 단점

- 후반 균형 조절이 미흡 (일부 조합이 압도적으로 강함)
- 콘텐츠 볼륨이 적음 (스테이지 수, 보스 수)
- 아이템 설명이 부족해 시너지 파악이 어려움
- 초반 난이도가 너무 가파름 → 진입 장벽

## OnionCat 적용 포인트

### A. 공유 화면 + 2인 이동 제약
Caveblazers는 카메라가 두 플레이어를 모두 담으려 확장/이동.  
OnionCat은 "두 플레이어가 한 몸"이므로 반대로 카메라 제약이 없음.  
대신 **고양이가 이동하면 양파도 함께 움직임** → 역할 분담 설계 시 고양이의 이동이 양파의 사격 각도를 결정함. 이를 의도적으로 게임플레이 요소로 활용 가능.

### B. 아이템 시너지 설계 철학
- Caveblazers: 아이템 수 적어도 조합 다양 → OnionCat도 적은 수의 업그레이드로 시너지 만들기
- 예시: "고양이 슬래시 범위 +50%" + "양파 투사체 바운스 → 슬래시 후 투사체 발사"
- 업그레이드를 단일 효과 아닌 "두 캐릭터 연계 업그레이드" 종류로 분류 가능

### C. 빠른 사망 & 간결한 게임 오버
- Caveblazers: 죽으면 간단한 스탯 화면 → 즉시 재시작
- OnionCat 초기 버전도 복잡한 결과 화면보다 "처치 수 + 도달 방 + 재시작 버튼" 간결 구조 추천

### D. 근접/원거리 역할 분담 자연 발생
- Caveblazers co-op에서 자연스럽게 역할이 나뉘듯, OnionCat은 **구조적으로** 한 명이 근접, 한 명이 원거리
- 약점 시스템(근접에만 약한 적, 원거리에만 약한 적) 구현 시 Caveblazers의 "전투 역할 분담" 재미를 의도적으로 설계 가능

### E. 퍼미팅한 진입 장벽 해결책
- Caveblazers 단점: 초반 너무 어려움 → 튜토리얼 룸에서 기본기 강제 학습
- OnionCat: 두 플레이어 조작을 동시에 익혀야 하므로 **첫 번째 방 = 강제 튜토리얼 방** 설계 추천
