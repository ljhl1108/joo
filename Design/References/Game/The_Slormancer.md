# The Slormancer

리서치 날짜: 2026-10-18

## 기본 정보

- **개발사**: Slormite Studios (프랑스 인디 2인팀)
- **출시**: Early Access 2021년 4월 (Steam)
- **장르**: 탑다운 핵앤슬래시 액션 RPG + 로그라이트 요소
- **공식 사이트**: https://www.slormitestudios.com/the-slormancer
- **Steam**: https://store.steampowered.com/app/1104890/The_Slormancer/
- **위키**: https://the-slormancer.fandom.com/wiki/The_Slormancer_Wiki
- **협동**: 로컬 + 온라인 협동 2~3인 (Early Access 추가)

## 핵심 시스템

### 3개 직업 + 스킬 진화 시스템
- **Knight**: 근접 전사, 방패와 공격 병행, 방어형
- **Mage**: 원거리 마법사, 원소 폭발, 광역형
- **Huntress**: 궁수, 발사체와 함정, 트릭형

각 직업마다:
- **8개 액티브 스킬** → 각 스킬마다 **독립된 레벨링 트리** (15~20개 업그레이드 노드)
- 같은 스킬을 반복 사용하거나 스킬 책을 구해 해당 스킬 레벨업
- 스킬 노드 예: "화살 1발 → 3발로 분기", "명중 시 불 상태이상 추가", "쿨다운 -0.5초" 등
- → **같은 직업이라도 스킬 빌드가 전혀 다른 캐릭터처럼 느껴짐**

### 장비 시스템
- **장비 슬롯**: 무기, 보조무기, 머리, 가슴, 장갑, 다리, 신발, 허리, 반지(2), 목걸이, 어깨 = 총 12~13칸
- **접두사/접미사**: 각 아이템에 랜덤 접사 1~3개 붙음
- **고대 세트(Ancient Sets)**: 2/3/5피스 보너스 (특정 스킬 변형 포함)
- **전설 장비(Legendary)**: 각 아이템마다 고유 특수 효과 1개, 특정 스킬과 강하게 연계

### Reaper 무기 시스템
- 각 직업마다 특수 범주의 전설 무기 "Reaper" 존재
- Reaper를 들면 전용 패시브 스킬 트리 추가 해금
- 무기 자체가 빌드의 방향성을 결정함
- → 아이템이 단순히 숫자 강화가 아니라 **새로운 플레이 방식을 열어주는 열쇠**

### 슬럼 사원(Slorm Temple) — 로그라이트 던전
- 메인 스토리 외 반복 플레이 가능한 절차적 생성 던전
- 층마다 랜덤 수정자(modifier) 적용
- 특수 방에서 강화 아이템 선택 (로그라이트의 "보상 선택" 구조)
- 보스마다 고유 패턴

### 슬럼라이트(Slormite) 강화
- 채굴 가능한 보석 아이템 "슬럼라이트"를 장비에 끼워 능력치 강화
- 슬럼라이트 자체도 레벨업 가능 → 장기 목표 제공

## 플레이어들이 좋아하는 것

1. **스킬 성장의 체감**: 같은 스킬이 레벨업되며 눈에 띄게 변하는 시각적 쾌감
2. **빌드 표현의 자유**: 같은 직업 내에서 완전히 다른 방향으로 갈 수 있음
3. **"완성형" 빌드 찾기**: 스킬 트리 + 장비 + 세트가 맞물릴 때의 시너지 발견
4. **얼리 액세스 개발 투명성**: 두 개발자가 커뮤니티와 적극 소통, 패치 빠름
5. **로컬 협동**: 같은 화면에서 친구와 플레이 가능

## OnionCat 적용 포인트

### 1. 스킬 노드 트리 → 양파 스킬(Q/W/E) 강화 방향
The Slormancer의 스킬 레벨업 트리처럼, OnionCat의 마법서(Q/W/E)도 단계적 변형 가능.
현재는 마법서 자체가 장비로 교체되는 방식이지만:
- **마법서 레벨업 시 노드 선택**: "씨앗 산탄 → 더 많은 수, 더 느리게, 관통 추가 중 1개 선택"
- → 마법서 레벨업이 단순 숫자 강화가 아니라 **방향 선택**이 됨
- 구현 복잡도가 높아 후반 작업이지만, 방향성으로 참고 가치 있음

### 2. Reaper 무기 → 고양이 무기 아이덴티티 강화
"무기가 새로운 플레이 방식을 열어준다"는 Reaper 개념이 OnionCat 고양이 무기에 이미 적용됨 (회전 할퀴기, 도약 할퀴기 등 ClawStyle이 무기로 결정).
- **확인 포인트**: 각 고양이 무기가 "이 무기를 들면 이렇게 싸운다"는 아이덴티티가 명확한가?
- 무기 변형이 단순히 ClawStyle만 바꾸는 게 아니라, 부가 스탯(달리기 속도, 쿨다운 등)도 개성 있게 설계하면 좋음

### 3. 인디 2인팀의 얼리 액세스 전략
Slormite Studios는 2명이 약 2.5년간 Early Access 운영, 꾸준한 업데이트로 긍정적 평가 유지.
- 핵심: 시작할 때 콘텐츠가 적어도 **코어 루프가 재미있으면 충분**
- 업데이트 로드맵을 공개하고 패치 빠르게 → 커뮤니티 신뢰 구축
- OnionCat도 itch.io Early Access 계획 시 참고 가능

### 4. 소규모 팀의 장비 콘텐츠 생성 전략
The Slormancer처럼 "조합형 어픽스(접사) + 전설 고유 효과" 구조를 채택.
OnionCat의 `GearEffect` 시스템(발동 → 행동 → 대상)과 유사 → 조합 가짓수를 늘리면서 제작 비용 낮춤.
- 현재 163개 장비로 시작했지만, 효과 조합 수를 체계화하면 콘텐츠 추가가 쉬워짐
- **접사 DB**: 발동 조건 10개 × 행동 15개 × 대상 5개 = 750가지 이상 조합 가능

### 5. 스킬 체감 강화 — 레벨업 노드 선택 UI
The Slormancer는 스킬 레벨업 시 간단한 팝업으로 노드 선택.
OnionCat에서 마법서 레벨업(같은 마법서 중복 획득) 시 즉각적인 선택 UI가 있다면,
레벨업이 단순 숫자 증가보다 훨씬 의미 있게 느껴짐.
