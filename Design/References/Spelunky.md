## 핵심 메카닉

### 절차적 레벨 생성 — "템플릿 방 + 패스 보장"
Spelunky의 레벨 생성은 그리드 기반의 "가이드 경로(critical path)" 알고리즘이 핵심이다.

1. **그리드 분할**: 맵을 N×M 격자로 나눔 (예: 4×4)
2. **경로 확보**: 왼쪽 위 → 오른쪽 아래까지 반드시 통과 가능한 경로를 먼저 결정
3. **방 템플릿 선택**: 경로 방향(아래/오른쪽/왼쪽)에 맞는 미리 만든 방 템플릿 중 랜덤 선택
4. **사이드 방 채우기**: 경로 외 방은 별도 템플릿(막힌 방, 보물 방 등)으로 채움

이 방식의 장점: 항상 클리어 가능한 레벨을 보장하면서도 랜덤성 유지.

### 물리 기반 파급 효과 (Cascading Consequences)
- 바위가 굴러서 적을 죽이고, 그 충격으로 보물이 떨어지고, 소리를 들은 다른 적이 달려오는 연쇄 반응
- 플레이어가 의도하지 않은 상황이 발생 → 매번 다른 경험
- **OnionCat 적용**: 고양이 대쉬가 화분을 흔들어 주변 아이템/적에 영향을 주는 연쇄 효과 가능

### 리소스 기반 플레이 (Resource Management)
- 밧줄(Rope), 폭탄(Bomb)이 주요 자원 — 절약 vs 사용의 딜레마
- 한 번의 실수가 자원 낭비로 이어져 이후 구간이 어려워짐

### 멀티플레이어 (Co-op & Competitive)
- 2~4인 로컬 코옵: 한 명이 죽어도 나머지 플레이어가 살아있으면 계속 진행
- 고스트 부활: 다른 플레이어가 상자를 찾으면 죽은 플레이어 부활
- 경쟁 모드: 서로 방해 가능 (의도치 않은 팀킬 등)

### 퍼마데스 & "완료" 조건
- 기본 목표: 마지막 보스 격파
- 트루 엔딩: 복잡한 숨겨진 조건 달성 (Spelunky 2의 경우 7단계 연쇄 미션)
- 단기 목표와 장기 목표의 층위 구분 → 초보자와 고수 모두 만족

## 플레이어들이 사랑하는 점

1. **"항상 배울 수 있다"**: 죽어도 "내 실수"라는 느낌 — 불합리한 죽음이 거의 없음
2. **비밀과 발견**: 숨겨진 방, NPC, 아이템 조합이 수백 시간의 발견을 제공
3. **게임플레이의 일관성**: 모든 물리 법칙이 플레이어에게도 적용됨 → "공평함" 느낌
4. **코옵의 카오스**: 실수로 동료를 죽이는 웃음 포인트

## OnionCat 적용 포인트

### 1. 방 템플릿 + 경로 보장 레벨 생성
```
OnionCat도 동일한 방식 추천:
- 5×5 그리드로 던전 구성
- 시작방 → 보스방까지 반드시 통과 가능한 경로 먼저 확보
- 경로 방: 전투 집중 / 사이드 방: 보물, 상점, 이벤트
- 각 방은 Unity 프리팹으로 미리 제작 → 런타임에 조립
```

### 2. "항상 클리어 가능" 설계 원칙
- 두 플레이어(고양이 + 작물)가 모두 없어도 한 명으로 돌파할 방법을 반드시 남길 것
- 근접 전용 적 구역에도 원거리 우회 경로를, 원거리 전용 구역에도 근접 루트 존재

### 3. 연쇄 효과 시스템
- 고양이 무적 대쉬 → 적 충돌 → 넉백 → 다른 적에게 피해 연쇄
- 작물 실드 패리 → 반사 투사체 → 근처 적 여러 명 동시 피격
- 이런 "의도하지 않은 클리어"가 쾌감을 만들어냄

### 4. 자원 딜레마 설계
- 업그레이드/소모품을 "아껴야 할 것"으로 설계
- 매 선택에 트레이드오프: "지금 쓰면 편하지만 보스전에서 없을 수도"
