## 핵심 메카닉

### 1. 캐릭터 & 어빌리티 구조
- 각 Survivor는 4가지 고정 스킬(기본 공격, 스킬1~3)을 보유
- 아이템이 빌드를 만들지, 스킬을 바꾸지는 않음 → **캐릭터 자체가 플레이스타일**
- 일부 캐릭터는 조준 사격(Commando), 일부는 근접(Mercenary), 일부는 탱크(Loader)
- 각 스킬에 쿨타임 또는 스톡(탄약) 시스템 적용

### 2. 아이템 스태킹 & 시너지
- 같은 아이템 여러 개 → 효과 배율 증가 (Ukulele 3개 = 번개 확률 3배)
- 아이템 간 비직관적 시너지가 핵심 재미: "이 조합이 이렇게 강하다고?"
- **Lunar 아이템**: 강력하지만 단점 포함 (위험한 선택지)
- **Equipment**: 쿨타임 있는 액티브 아이템 1개 슬롯

### 3. 텔레포터 시스템 (위험/보상 루프의 핵심)
- 각 스테이지의 텔레포터를 활성화 → 보스 소환 + 주변에 적 계속 스폰
- 텔레포터 100% 충전 완료 시 다음 스테이지로 이동
- **아이템 파밍 시간 vs 텔레포터 활성화 타이밍** — 플레이어가 선택
- 오래 파밍할수록 강해지지만, 시간이 지날수록 적 난이도 상승 (Monsoon 스케일링)

### 4. 시간 기반 난이도 스케일링
- 게임 시작 후 경과 시간에 비례해 모든 적의 체력/데미지 증가
- 무한정 파밍은 불가능 → 자연스러운 시간 압박 생성
- 빠른 런: 쉽게 클리어 / 긴 런: 강력하지만 적도 강해짐

### 5. 협력 메카닉
- 아이템은 **각자 수집** (공유 아님) → 개별 빌드 형성
- 서로 다른 캐릭터 조합 시너지 (예: Engineer 터렛 + REX 힐링)
- 한 명이 죽으면 남은 플레이어가 계속 진행 (자동 부활 없음, 특정 아이템으로만 부활)
- 협력이지만 각자의 역할과 빌드가 뚜렷이 분리됨

### 6. 메타 진행
- **Unlockable**: 도전과제 달성 시 새 캐릭터/스킬/아이템 해금
- **Logbook**: 몬스터/아이템 정보 수집 → 콘텐츠 탐색 동기
- **Eclipse 모드**: 클리어할수록 누적 패널티 (NG+ 개념)

## 플레이어가 사랑하는 이유
- 빌드가 폭발적으로 성장하는 **스케일링의 쾌감** ("God Run" 달성)
- 캐릭터마다 완전히 다른 조작감 → 재플레이 가치
- 4인 협력 시 역할 분담의 자연스러운 발생
- 아이템 시너지 발견의 즐거움 (커뮤니티 공유)
- 뛰어난 BGM (Chris Christodoulou) — 게임 분위기와 완벽히 맞음

## OnionCat 적용 포인트

### A. 위험/보상 루프 — "압박 방" 개념
텔레포터처럼 OnionCat에도 방 내 목표물(크리스탈, 제단 등)을 활성화하면 적 웨이브 시작되는 방 유형 추가:
- 활성화 중: 적 계속 스폰
- 완료 시: 보상(아이템/업그레이드) 획득
- Cat은 방어, Onion은 원거리 제압하는 협력 구도 자연 발생

### B. 시간 스케일링 → 방 스케일링
RoR2처럼 실시간 시간 스케일링 대신, **클리어한 방 수에 비례해 적 스탯 증가** — 초보 개발자에게 더 쉬운 구현:
```csharp
enemyHp = baseHp * (1f + roomsCleared * 0.1f);
```

### C. 아이템 시너지 → OnionCat 시너지 시스템
- "Cat 슬래시 적중 시 Onion 다음 투사체 강화" 같은 **캐릭터 간 시너지 아이템**
- 각 아이템이 단독으로도 좋지만, 두 캐릭터가 조합할 때 더 강력해지는 설계

### D. 사운드트랙 참고
크리스처럼 OnionCat도 **층별 다른 BGM** — 안전한 방(조용)→ 적 등장(긴장감 상승) → 보스(풀 오케스트라) 다이나믹 뮤직 전환 고려.
