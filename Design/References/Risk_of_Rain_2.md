## 핵심 시스템

### 1. 이동

- **기본 이동속도:** 7m/s, 스프린트 시 ×1.45 (≈10.15m/s)
- 스프린트가 기본 상태 — 대부분 스킬을 스프린트 중 사용 가능
- 점프: 근접 공격 완전 회피, 발사체 궤도 피하기에 활용
- **이동 아이템:** Paul's Goat Hoof (+14% 이동속도/스택), Energy Drink (+25% 스프린트 속도/스택)
- **핵심 원칙 "Going Fast Recommended"**: 스테이지 오래 머물수록 난이도가 올라가므로 빠른 의사결정 필수

### 2. 생존자 시스템

**19명 생존자** (기본 10명 + DLC), 각각 완전히 다른 플레이 스타일:

| 생존자 | 특징 |
|--------|------|
| Commando | 범용, 두 발 연사 |
| Huntress | 고기동, 취약, 스프린트 중 사격 가능 |
| MUL-T | 탱커, 이중 무기 전환 |
| Engineer | 포탑 설치, 방어형 |
| Mercenary | 근접, 공중 연속 회피 |
| Loader | 갈고리+주먹 근접 파워하우스 |
| Railgunner (DLC) | 단일 표적 저격, 즉사 크리티컬 |
| Void Fiend (DLC) | 오염/정제 이중 전환 형태 |

각 생존자는 고유한 Primary / Secondary / Utility / Special 4슬롯 스킬 보유.

### 3. 아이템 시스템

**110개 이상** 아이템, 제한 없이 중복 획득 가능.

| 등급 | 특징 |
|------|------|
| Common (흰색) | 기본 강화, 선형 스택 |
| Uncommon (녹색) | 텔레포터 보상 주력 |
| Legendary (빨간색) | 강력한 효과, 희귀 |
| Lunar (파란색) | 강력한 효과 + 심각한 단점 |
| Void (보라색) | 기존 아이템을 변환하는 DLC 아이템 |

**Proc Coefficient (발동 계수):**
- 각 공격의 on-hit 아이템 발동 확률에 곱해지는 계수
- 빠른 다단히트(계수 0.6) vs 느린 강타(계수 1.0) → 아이템 파워가 공격 빈도에 관계없이 균형 유지
- **Proc Chain:** 아이템이 다른 아이템을 트리거하는 연쇄 발동 가능

**대표 시너지:** Ukulele(번개) + AtG Missile → 번개 발동 시 2% 확률로 미사일 발사 → 미사일이 다시 번개 트리거

### 4. 난이도 스케일링 — 시간 자체가 적

RoR2의 가장 독보적인 설계. **경과 시간이 실시간으로 난이도를 올린다.**

- **Difficulty Coefficient**: 선택 난이도 + 경과 시간 + 완료 스테이지 수로 실시간 재계산
- 이 계수가 적 HP, 대미지, 스폰 크레딧, 엘리트 등장 빈도 전부를 결정
- 적 레벨당 HP +30%, 대미지 +20% 증가
- 멀티플레이어 1명당 스케일링 속도 **+31.95% 가속**

**난이도 선택:**

| 난이도 | 스케일링 속도 | 특징 |
|--------|------------|------|
| Drizzle | 50% | 아머 +70, 체력 재생 ×1.5 |
| Rainstorm | 100% | 기본값 |
| Monsoon | 150% | 체력 재생 ×0.6 |
| Eclipse | 150%+ | 추가 페널티 |

### 5. 스테이지 & 텔레포터 이벤트

**스테이지 구조:** 각 번호마다 3개 중 1개가 랜덤 선택 → 매 플레이가 다른 환경

| 스테이지 | 선택지 |
|----------|--------|
| 1 | Distant Roost / Titanic Plains / Siphoned Forest |
| 2 | Abandoned Aqueduct / Wetland Aspect / Aphelian Sanctuary |
| 5 | Sky Meadow (고정) → 최종 보스 또는 루프 분기 |

**텔레포터 이벤트 (핵심 목표):**
1. 맵에서 텔레포터 탐색
2. 활성화 → 빨간 돔 범위 출현
3. 플레이어가 돔 안에 있는 비율만큼 충전 속도 결정 (최소 90초)
4. 동시에 보스 + 대량 잡몹 스폰
5. 완료 시 보상 (녹색/보스 아이템) + 다음 스테이지 이동

**텔레포터의 압박 구조:** 공간 제약(돔 안 유지) + 시간 압박 + 적 대량 출현 삼중 압박

### 6. Elite(엘리트) 어픽스 시스템

| 엘리트 유형 | 속성 | 스폰 비용 배율 |
|-----------|------|-------------|
| Blazing | 불 흔적, 피격 시 화상 | ×6 |
| Overloading | 폭발 공격, HP의 50% 실드화 | ×6 |
| Glacial | 사망 시 빙결 폭발, 80% 감속 | ×6 |
| Malachite | 독침 투사체, 방어막 생성 | ×36 |
| Celestine | 아군 버프/투명화 부여 | ×36 |
| Perfected | 이동속도 +35%, HP 전부 실드화 | ×36 |

## 플레이어가 좋아하는 것

1. **"딱 한 판 더" 루프**: 아이템 조합이 매 런마다 달라 중독성 강함
2. **시간 기반 압박**: "탐색해서 강해질까 vs 텔레포터로 바로 갈까"의 능동적 딜레마
3. **아이템 시너지 발견의 쾌감**: 예상치 못한 Proc Chain 발생 시 화면을 가득 채우는 폭발·번개·미사일
4. **생존자 다양성**: 19명의 생존자 각각이 사실상 다른 게임처럼 느껴짐
5. **방대한 모드 생태계**: Thunderstore를 통한 새 생존자, 아이템, 멀티플레이 보정 모드

## 협동 요소

### 기본 멀티플레이
- **최대 4인 온라인 코옵** (Steam/콘솔)
- 각 플레이어 독립 생존자 선택, 공유 스테이지 타이머

**멀티플레이 스케일링:**

| 항목 | 증가 방식 |
|------|---------|
| Director 스폰 크레딧 | 플레이어 1명당 +50% |
| 보스 HP | 플레이어 수 비례 배증 |
| 전체 난이도 가속 | 플레이어당 +31.95% |
| 보스 드롭 아이템 수 | 플레이어 수 비례 |

**주의:** 플레이어 도중 이탈해도 최초 인원수 기준 스케일링 유지.

### 아이템 분배 문제 & 해결책
- **바닐라 기본값:** 선착순 개인 획득 → 탐색 집중 플레이어와 전투 집중 플레이어 간 아이템 격차 발생
- **커뮤니티 해결책:** `ShareSuite` 모드 (돈/아이템 공유) → 코옵 필수 모드로 인식

### 자연 발생하는 역할 분담
- Captain(지원 힐링) + 고딜러: 텔레포터 이벤트 안정화
- Acrid(독) + Artificer(광역): 독 상태 군중에게 폭발 광역 연계
- Railgunner(단일 순살) + 광역 생존자: 보스/엘리트 즉시 제거 + 잡몹 분담

## OnionCat 적용 포인트

### 1. 시간 압박 = "탐색 vs 전진" 딜레마 → 스테이지 타이머 도입
RoR2처럼 스테이지마다 보이는 난이도 타이머 적용. 시간이 지날수록 (a) 적 체력/공격력 증가, (b) 새 엘리트 유형 등장. 두 플레이어가 "지금 아이템 더 줍고 갈까 vs 보스로 바로 갈까"를 실시간으로 협의하게 만들어 **코옵 소통 자연 촉진**.

### 2. Proc Coefficient → Cat/Crop 공격 계수 분리
Cat의 180° 근접 슬래시(단발 강타, 계수 1.0)와 Crop의 투사체(연사, 계수 0.5~0.7)에 서로 다른 계수 적용. 같은 아이템이라도 두 캐릭터에서 다르게 발동 → "이건 Cat용인가, Crop용인가" 판단으로 협동 의사결정 강화.

### 3. Elite 어픽스 → 역할 분배 자동화
- "실드 어픽스" 적 → Cat 슬래시 실드 관통 불가, Crop 투사체만 유효
- "반사 어픽스" 적 → Crop 투사체 반사, Cat 슬래시만 유효. Crop이 실드로 방어하며 Cat이 접근
- 어픽스가 자동으로 "누가 처리하냐"의 코옵 역할 분배 대화를 생성.

### 4. 텔레포터 이벤트 → "보스 챔버 충전" 메카닉
보스 룸에서 "코어 충전" 도입. 한 명이 코어 근처에 고정(충전) → 나머지가 엄호. Cat이 충전 중이면 Crop이 원거리 엄호, Crop이 실드로 방어 중이면 Cat이 기동 근접 처리 → **역할 고착 → 협동 필요성 자연 증가**.

### 5. 아이템 시너지 → "두 플레이어 연계 아이템" 설계
- "Cat 대시 후 Crop 투사체 분열" 아이템
- "Crop 패리 성공 시 Cat 다음 슬래시 2배 대미지" 아이템
- "Cat 슬래시 명중 → 2초 내 Crop 투사체 명중 시 폭발" 체인 아이템

RoR2의 Proc Chain처럼, 두 플레이어의 **상호 행동 체인**이 아이템 시너지의 축.

### 6. 루프 시스템 → 자발적 어려움 선택
각 스테이지 클리어 후 "탈출 경로 vs 심층 탐험 경로" 분기. 심층 경로 = 강한 적 + 희귀 아이템. 두 플레이어가 합의해야 결정 → 코옵 소통 클라이맥스.

### 7. 난이도 게이지 가시화 → 위협 레벨 UI
화면에 현재 위협 레벨 게이지 상시 노출. 게이지 증가 시 근접 전용/원거리 전용 적 비율 급증 → 두 역할의 균형 플레이가 더 중요해짐을 예측 가능.
