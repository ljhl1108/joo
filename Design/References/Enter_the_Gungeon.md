## 장르 / 플랫폼
탑다운 슈터 로그라이크 / PC·콘솔 (2인 로컬 협동 지원)

## 핵심 시스템

### 총기·아이템 시너지
- 총기 + 패시브 아이템 조합 시 예상치 못한 효과 발동
- 저주(Curse) 수치: 특정 아이템 획득 시 증가 → 난이도↑ but 보상↑

### Blank (투사체 소거)
- 플레이어 주변 투사체 전체 소거 기술
- 방당 제한 횟수 → 극한 위기 전용

### 협력 요소
- 2인 시 한 명 사망 → 나머지가 부활 아이템 찾아야 부활
- 문 개방: 두 플레이어 동시 접촉 필요한 구간 존재

### 적 설계
- Bullet Kin 계열: 총알이 의인화된 적 → 코믹한 세계관
- 각 층마다 전용 적 구성 + 보스

## OnionCat 적용 포인트
- Blank → 협동 폭발 기술 (P1+P2 동시 입력)
- Curse 시스템 → 저주받은 화분 리스크/리워드
- 아이템 시너지 → 화분 내구도·균열 메카닉
- 2인 협력 문 개방 → 이중 잠금 출구
- 적 개성 설계 → 총알 인형·대포 화분 보스
