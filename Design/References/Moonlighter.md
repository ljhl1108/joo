## 핵심 시스템

### 전투 시스템
- 무기 5종: 검+방패(올라운드), 대검(고데미지+차지), 창(긴 사정거리), 글러브(빠른 연타), 활(원거리)
- 3히트 콤보 (3번째 타격: 2배 피해 + 넉백)
- 차지 특수공격 (검+방패 제외)
- 롤링/회피 (자원 소모 없음, 자유 연속 사용)
- 적마다 다른 전략 요구 → 전술적 무기/능력 전환 강제

### 던전 진행 시스템
- 절차 생성 던전 5종 테마, 각 3층 구조
- 방 기반 이동 (상하좌우 4방향 출구)
- 비밀 방 (층당 1~2개, 미니맵으로 발견)
- 안전 지점: 버려진 야영지(적 없음), 치유 웅덩이(다음 층으로 가는 길목에 항상 배치)
- 인벤토리 1행 아이템만 런 실패 시 보존 ("포켓 시스템")

### 상점 경영 시스템
- 기본값 × 4.5 = 권장 소매가
- 수요/공급 기반 동적 가격 조정
- 고객 반응 5단계 (황홀함→행복→무표정→불만→구매거부)
- 고객 반응으로 최적 가격대 탐색 → 이익 극대화

### 로그라이크 진행
- 런 = 던전 탐험 → 전리품 수집 → 마을 귀환 → 상점 판매 → 업그레이드
- 런 실패 시 전리품 손실, 상점/마을 업그레이드 영구 유지
- 런 실패도 포켓 아이템 판매로 부분적 진행 가능

## 플레이어가 좋아하는 점
1. **중독적인 게임 루프**: 던전→전리품→판매→업그레이드→반복 사이클의 만족감
2. **상점 경영의 재미**: 가격 설정, 고객 반응 읽기, 이익 극대화 — 로그라이크에 없는 독특한 경제 레이어
3. **시각/청각적 완성도**: 매력적인 픽셀아트, 인상적인 폭발 이펙트, 독특한 액체 효과

## OnionCat 적용 포인트

### 1. 비대칭 무기 특화 → 강제 협력
Moonlighter는 단일 플레이어가 적에 맞는 무기를 바꿔야 함. OnionCat에서는 두 플레이어 자체가 '무기 분담'을 구현:
- **근접만 약한 적 + 원거리만 약한 적 조합**으로 방 구성
- Cat(180° 슬래시)과 Crop(원거리)이 각자의 적을 담당해야 방 클리어 가능
- 단일 플레이어 지배 방지 → 두 플레이어 모두 항상 역할이 있는 설계

### 2. 포켓 시스템 → 협동 무적 포켓
Moonlighter의 "인벤토리 1행만 생존" 개념을 OnionCat에 적용:
- Cat/Crop 각자 소규모 "안전 파우치" — 런 실패 시에도 보존
- 런 실패 = 전리품 일부 손실이지만 진행 감각 유지
- 한 플레이어의 실수가 파트너를 완전히 처벌하지 않는 구조

### 3. 절차 생성 방 + 적 구성으로 난이도 스케일링
- 근접 특화, 원거리 특화, 혼합 필요 방을 절차적으로 배치
- 미니맵 + 비밀 방으로 고위험/고보상 공간 선택지 제공
- 층마다 치유 포인트 배치로 RNG 극단적 난이도 완화

### 4. 라이트 퍼마데스 + 런 기반 메타 성장
- 마을/상점 건물 = 런 간 영구 진행 (자금으로 업그레이드)
- 런 실패도 일부 자원 확보 → 처벌보다 동기 부여 중심
- 협동 플레이에서 두 플레이어 모두 앞으로 나아가는 느낌 유지

## 핵심 인사이트
Moonlighter의 핵심은 **상점을 던전만큼 재미있게** 만든 것. OnionCat의 대응 훅은 **Cat+Crop의 협력을 전투의 핵심으로** 설계하는 것 — 근접/원거리 약점 시스템으로 두 플레이어를 항상 전략적으로 필요한 존재로 만들기.
