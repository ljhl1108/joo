## 핵심 메카닉

### 비트 기반 이동
- 모든 행동(이동, 공격, 아이템 사용)이 음악의 박자에 맞춰 실행됨
- 박자를 놓치면 콤보 멀티플라이어 초기화 → 골드 수집량 감소
- 박자를 맞출수록 더 많은 골드 → 능력 강화 순환

### 턴 기반 × 실시간 혼합
- 겉보기엔 실시간이지만 사실상 음악 템포에 맞춘 "스텝" 방식
- 플레이어가 행동할 때 적도 함께 움직임 (적 AI가 비트 기반)
- 다양한 적마다 고유한 이동/공격 패턴 (1박, 2박, 1/2박 등)

### 캐릭터 다양성
- **Cadence**: 기본 캐릭터, 비트 기반
- **Aria**: 피격 즉사 (최고 난이도)
- **Dorian**: 이동 방향 제한
- **Bard**: 비트 없이 자유 이동 (리듬 제거)
- 각 캐릭터가 완전히 다른 게임플레이 경험 제공

### 협동 모드 (2인)
- 동일한 던전을 함께 탐험
- 두 플레이어 각자 독립적인 체력/인벤토리
- 한 명이 죽어도 다른 한 명이 계속 진행 가능
- 화면 공유: 두 플레이어 모두 화면 내에 있어야 함

### 음악과 페이스
- 배경음악 BPM = 게임 진행 속도
- 보스 룸에서 음악 변화 → 페이스 가속
- Danny Baranowsky 작곡 → 음악 자체가 게임의 핵심 자산

## 로그라이크 시스템

- **층 구조**: Zone 1~4, 각 Zone 끝에 보스
- **영구 사망**: 죽으면 처음부터
- **골드 시스템**: 룸 클리어 → 골드 → 상점 → 임시 강화
- **다이아몬드**: 런 간 영구 해금 (캐릭터, 음악 등)
- **랜덤 아이템**: 무기, 갑옷, 신발, 반지 등 슬롯별 장비

## 플레이어가 좋아하는 요소

1. **리듬과 게임플레이의 완벽한 통합**: 음악이 단순 배경이 아닌 코어 메카닉
2. **캐릭터 간 극단적 난이도 차이**: 같은 게임을 다르게 즐길 수 있음
3. **긴장감 있는 학습 곡선**: 각 적의 패턴 파악 → 춤추듯 처리
4. **협동의 자연스러운 분업**: 두 명이 서로 다른 역할로 협력
5. **모드/DLC 확장성**: AMPLIFIED DLC, Cadence of Hyrule 외전

## OnionCat 적용 포인트

### 1. 적 다양성 × 취약점
NecroDancer의 "각 적마다 다른 공격 타이밍"처럼, OnionCat의 "근접 약점 적 vs 원거리 약점 적"을 더 세분화:
- 근접만 약점 → 고양이(P1)가 처리
- 원거리만 약점 → 양파(P2)가 처리
- 특정 타이밍에만 피격 가능한 적 → 두 플레이어 조율 필요

### 2. 리듬감 피드백 시스템
비트에 맞춘 공격에 보너스 부여 아이디어:
- 고양이 대시 후 연속 공격 타이밍에 히트스톱 강화
- 양파 패리 성공 시 "퍼펙트" 판정 → 특수 효과

### 3. 협동 유지 메카닉
NecroDancer의 "화면 분리 불가" 시스템에서 영감:
- OnionCat은 한 몸이라 이미 해결됨 (P1이 몸체를 직접 이동)
- 하지만 "화면 밖 포인터" UI (P2 마우스 조준선)로 화면 범위 의식 필요

### 4. 협동 전용 적 패턴
- 두 플레이어를 동시에 요구하는 "협동 필수" 적 설계
- 예: 방패 적 → P2 파괴 후 P1 근접 처치

### 5. 음악 연동 피드백
- 보스전 BGM 변화 시 카메라/이펙트 강조
- 적 처치 시 SFX가 BGM 리듬에 맞춰 타이밍 조정

- 리듬 메카닉 자체는 OnionCat에 직접 도입하기 어려움 (2인 조작 복잡도 증가)
- 하지만 "패턴 기반 적 AI" 설계 철학은 매우 참고할 만함
