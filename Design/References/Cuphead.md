## 핵심 시스템

### 전투 메카닉

| 요소 | 설명 |
|------|------|
| **무기(Shot)** | 6종 — Peashooter(기본), Spread(산탄), Charge(차지), Roundabout(부메랑), Chaser(추적탄), Lobber(포물선) |
| **패리(Parry)** | 분홍 오브젝트를 공중 점프로 쳐서 슈퍼 게이지 충전 + 추가 점수 |
| **슈퍼 아트(Super Art)** | 패리 포인트 5개 모으면 발동 가능한 강력한 필살기 |
| **참(Charm)** | 패시브 아이템 — 체력 업, 스모크 대시(무적), 파리잡이 등 |
| **HP** | 기본 3, Charm으로 최대 5까지 — 단 한 대에 죽는 즉사 없음 (탄 맞으면 1HP) |

### 2인 협동 구조

- **공유 화면**: 두 플레이어가 같은 카메라 뷰 — 화면 밖으로 나가면 즉사
- **부활 시스템 (Ghost Mechanic)**:
  1. 한 플레이어 사망 → 즉시 유령(ghost) 상태로 하늘 위로 떠오름
  2. 생존 플레이어가 유령을 패리(분홍 터치)하면 부활
  3. 부활 시 HP 1로 재진입
  4. 둘 다 사망하면 라이프 1 소모 후 처음부터 재도전
- **개별 빌드**: 두 플레이어 각자 무기·참을 따로 선택
- **2인 시 보스 HP 증가**: 난이도 보정 (1.5~2배)

### 보스 단계 설계 철학

```
등장 → [페이즈 1: 기본 패턴 파악] → HP 임계값 도달
→ [전환 연출(화면 효과)] → [페이즈 2: 패턴 변화 + 속도↑]
→ 반복 (최대 3~4페이즈) → 격파 → 결과 화면(등급 A/B/C/S/P)
```

- **텔레그래프(Telegraph)**: 모든 공격에 예비 동작(예: 손 들기 → 발사)
- **안전지대(Safe Zone)**: 각 패턴마다 회피 가능한 위치가 반드시 존재
- **시각적 피드백**: 애니메이션 자체가 공격의 타이밍을 알려줌 (UI 없이도 읽힘)
- **페이즈 전환 연출**: 보스가 폭발하며 다른 형태로 변신 → 플레이어에게 숨 쉴 틈

### 등급 시스템 (Grading)

| 항목 | 가중치 |
|------|--------|
| 패리 횟수 | 높음 |
| 슈퍼 아트 발동 횟수 | 중간 |
| 피격 없이 클리어(P랭크) | 특별 |
| 클리어 시간 | 낮음 |

- P랭크(Perfect): 피격 0회 + 특정 Charm 미사용

## OnionCat 적용 포인트

### 1. 유령 부활 메카닉 → 협동 구조 설계 힌트

Cuphead의 Ghost→Parry-to-Revive는 OnionCat에 직접 응용 가능:
- **OnionCat 변형안**: 특정 피격 임계치 도달 시 Cat 또는 Crop이 "기절" 상태
  - 기절한 쪽은 능력 사용 불가 (Cat 기절 → 이동 느림+근접 불가, Crop 기절 → 사격/방어 불가)
  - 상대 파트너의 특정 행동으로 회복 (Cat이 대시하면 Crop 회복 vs Crop이 방어막 치면 Cat 회복)
- 이 구조는 **"두 플레이어가 서로를 신경 써야 하는 진짜 협동"** 을 만듦

### 2. 보스 텔레그래프 + 페이즈 설계

- 보스 공격 전 0.3~0.5초 "예비 동작" 애니메이션 → 플레이어가 배울 수 있는 패턴
- 페이즈 전환 시 짧은 **무적 연출 타임** 제공 (플레이어 포지셔닝 재정비)
- OnionCat 보스: 근접 취약 vs 원거리 취약 패턴을 페이즈별로 교차

### 3. 패리 시스템 → Crop의 방어막 파생

- Cuphead 패리: 분홍 오브젝트를 쳐야 함 (조건부 상호작용)
- OnionCat Crop의 방어막: **"정확한 타이밍에 방어막 차지"** 시 패리 발동 → 탄환 흡수·반사
- 방어막 패리 성공 시 슈퍼 게이지 충전 → 협동 공격 발동 (Cuphead의 슈퍼 아트와 유사한 보상 루프)

### 4. 개별 빌드 선택 → 협동 시너지

- Cuphead: 두 플레이어가 각자 다른 무기·Charm 선택
- OnionCat: Cat(근접 특화), Crop(원거리 특화) 업그레이드 트리를 **분리**하되 조합 시 시너지 발생
  - 예: Cat이 "공격 속도↑" 업그레이드 + Crop이 "탄 관통" 업그레이드 → 연계 공격 강화

### 5. 등급 시스템 → 런 결과 화면

- 단순 클리어 여부가 아닌 **등급**으로 도전 욕구 자극
- OnionCat 런 결과: 피격 횟수, 패리 성공률, 두 플레이어 협동 발동 횟수 → 등급 산출
- P랭크 상당: 특정 조건(피격 3회 이하 클리어 등) 시 숨겨진 칭호/해금 아이템
