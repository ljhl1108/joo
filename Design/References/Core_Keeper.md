## 핵심 메커닉

### 1. 협력 구조 (2~8인)
- 모든 플레이어가 같은 월드를 공유
- 역할 분담 자연 발생: 채굴자, 전투원, 파머, 건축가
- 공유 자원 (창고 시스템): 모든 플레이어가 공동 창고에 아이템 보관
- 부활 시스템: 다른 플레이어가 죽은 플레이어 부활 가능

### 2. 보스 전투
- 각 구역 끝에 보스 존재
- 보스 처치 → 새 구역 개방 (진행 키)
- 협력 전투: 탱커/딜러 역할 자연 발생
- 보스 HP는 플레이어 수에 따라 스케일링

### 3. 절차적 생성 월드
- 무한한 지하 세계 절차적 생성
- 생체군계(Biome): 흙, 수정 동굴, 정글, 사막, 바다 등
- 씨앗(Seed) 기반 생성 → 재현 가능

### 4. 파밍 + 크래프팅
- 지하에서 작물 재배 가능 (인공 조명 필요)
- 제작대로 장비, 도구, 음식 제작
- 음식 → 버프 → 전투 유리

### 5. 진행 구조
- 로그라이크가 아닌 영구 월드 (세이브 있음)
- 하지만 아이템 획득/보스 처치의 감각은 로그라이크와 유사
- 메타 진행 없음 (월드별 완전 독립)

## 협력 요소 심층 분석

### 역할 분화의 자연 발생
- 강제하지 않지만, 효율을 위해 역할 분담이 생김
- 한 명이 보스 aggro 잡는 동안 다른 명이 DPS
- OnionCat처럼 "강제 분업"은 아니지만, 자발적 분업의 재미 참고

### 공간 협력
- 같은 보스 방에서 위치 선점이 중요
- 원거리 플레이어는 뒤에서 지원, 근접 플레이어는 전면 압박
- OnionCat 적 설계에 직접 적용 가능: "원거리에서만 안전한 보스"

### 부활 메커닉
- 죽은 플레이어를 살리려면 생존 플레이어가 시체에 다가가야 함
- 부활 시 일시적으로 취약해지는 리스크 ↔ 파트너 구하는 협력감

## 플레이어가 열광하는 요소

1. **자유로운 협력** — 강요 없이 자연스럽게 팀워크가 생기는 설계
2. **탐험의 흥분감** — 새 구역 발견, 보스 발견의 서프라이즈
3. **크래프팅 사이클** — 재료 수집 → 장비 제작 → 더 강한 적 처치의 피드백 루프
4. **비주얼 스타일** — 고해상도 픽셀아트, 다채로운 생체군계

## OnionCat 적용 포인트

### 보스 HP 스케일링
- Core Keeper처럼 보스 HP를 플레이어 수에 맞게 조정
- OnionCat: 솔로 모드(AI 파트너) vs 2인 모드 HP 차이를 약 30~40% 로 설정

### 위치 기반 역할 자연 발생
- 보스/적 패턴 설계 시 "근접이 앞에서 방패, 원거리가 뒤에서 딜" 자연스럽게 유도
- 강제하지 않아도 Cat은 앞, Crop은 뒤 → 이 포지션 자체가 공략법

### 공유 자원 UI
- Core Keeper의 공유 창고처럼, OnionCat의 업그레이드 선택도 "공유 화폐" 방식
- 두 플레이어가 동의해야 업그레이드 구매 가능한 "공동 동의 UI" 아이디어

### 부활/위기 회복 시스템
- 한 플레이어 HP 위기 시, 파트너가 특정 행동으로 회복 지원
- Cat이 Crop의 방패로 막아주면 회복 → "상호 의존" 피드백 강화

### 픽셀아트 생체군계 레퍼런스
- Core Keeper의 생체군계별 타일셋/색감 변화 → OnionCat 층별 테마에 적용
- 층 1: 숲, 층 2: 동굴, 층 3: 불의 신전 등으로 시각적 다양성 제공
