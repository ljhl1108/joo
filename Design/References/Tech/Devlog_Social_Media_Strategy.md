# 인디 게임 개발 로그 & SNS 전략

리서치 날짜: 2026-11-03

## 개요

출시 전 게임의 인지도를 쌓고 Steam 위시리스트를 모으기 위한 전략.
처음 게임을 출시하는 개발자는 **게임을 만들면서 동시에 커뮤니티를 쌓아야** 한다.
"출시 전날 SNS 계정 만들기"는 너무 늦다.

**OnionCat에서 왜 중요한가?**
- 출시 전 위시리스트 수가 초기 판매량을 결정
- 2인 협동 게임은 "같이 하면 재밌다"는 영상이 강력한 바이럴 소재
- 고양이 + 식물 조합, 독특한 2인 1체 컨셉은 SNS에서 눈길을 끌기 좋음

---

## 플랫폼별 특성

### TikTok / YouTube Shorts (추천 1순위)
- **유기적 도달(organic reach)** 가장 높음 (2026 기준)
- 알고리즘이 팔로워 없어도 노출시킴 → 제로에서 시작 가능
- 15~60초 클립 최적
- 성공 사례: 개발자 한 명이 TikTok 영상 하나로 400 → 23,000 위시리스트
- 콘텐츠 전략:
  - **웃긴 버그** / **깜짝 놀라는 순간** / **before vs after** 비교
  - "2인 협동 중 서로 탓하는 순간" → Struggling 같은 갈등 클립

### Twitter / X (개발자 커뮤니티)
- 인디 개발자, 게임 저널리스트, 퍼블리셔 집결지
- 팔로워가 없어도 게임 관련 태그 (#screenshotsaturday, #gamedev, #indiegame) 활용
- **#ScreenshotSaturday**: 매주 토요일, 개발 중 스크린샷 공유 문화
- 기사 쓰는 저널리스트들이 여기서 게임 발굴함

### Reddit
- r/indiegaming, r/gamedev, r/roguelikes
- 규칙이 엄격한 커뮤니티지만 진성 유저 많음
- "We made this game, thoughts?" 스타일 글 효과적
- 한국: r/korea, 루리웹, 네이버 카페 (인디게임 커뮤니티)

### YouTube (긴 영상)
- 개발 과정 Devlog 영상 (10~20분)
- 장기 구독자 형성, 검색 유입
- 유지 비용 높음 → 짧은 클립이 효과적일 때 먼저 시작

### Discord
- 게임 관련 Discord 서버에 참여하거나 자체 서버 개설
- 얼리어답터와 직접 소통, 플레이테스트 모집
- 한국 인디 게임 Discord 커뮤니티 적극 활용

## 콘텐츠 전략

### "Build in Public" 원칙
- 완성된 게임이 아니어도 과정을 공유
- 오늘 만든 새 기능, 해결한 버그, 막힌 문제까지 공유
- 독자가 "이 게임이 어떻게 만들어지는지"를 함께 경험하게 됨

### OnionCat에 특히 효과적인 콘텐츠
```
1. 2인 협동 플레이 클립 — 웃긴 실패 + 극적인 성공
2. 적 AI 새로운 패턴 첫 테스트 영상
3. 픽셀아트 스프라이트 제작 과정 (애니메이션 before/after)
4. "고양이가 양파 화분 등에 지고 다니는" 독특한 비주얼 클로즈업
5. 세트 아이템 콤보 발견 순간 ("이거 조합하면 미쳐버림")
6. 신기한 물리 상호작용 (걷어차기로 적이 날아가 벽에 CRASH)
```

### 게시 빈도
- TikTok/Shorts: 주 2~3회 (짧은 클립이므로 부담 적음)
- Twitter: 매일 또는 격일 (#ScreenshotSaturday는 고정)
- Reddit: 주요 업데이트마다 1회
- YouTube Devlog: 월 1회 (완성도 높게)

## Steam 위시리스트 전략

### Steam 페이지 먼저 열기
- 개발 초기부터 "Coming Soon" 페이지 오픈
- 모든 SNS 링크에 Steam 페이지 연결
- 위시리스트는 출시 알림 받는 수단 → 1,000개 넘으면 Steam 알고리즘에 노출 증가

### Next Fest 참여
- Steam Next Fest: 연 2회(2월, 6월) — 데모 공개 후 위시리스트 폭발
- 데모를 준비할 수 있는 시점이 되면 반드시 참여
- Next Fest 기간에 TikTok/Twitter 집중 활동

### 전환율 참고 수치
- TikTok 바이럴 영상 → Steam 위시리스트 전환율: 약 0.3~0.5%
- 위시리스트 → 구매 전환율: 약 10~20% (장르와 가격에 따라 다름)
- 결론: 위시리스트 10,000개 = 출시 초기 1,000~2,000명 구매 기대

## 실수하면 안 되는 것

### 1. 너무 많은 플랫폼 동시 운영
- 솔로 개발자는 게임 만들 시간이 최우선
- 1~2개 플랫폼 잘 하는 게 5개 못 하는 것보다 낫다

### 2. "게임 준비되면 마케팅 시작"
- Steam 알고리즘은 위시리스트 누적이 핵심 → 출시 6개월~1년 전부터 시작
- 늦게 시작할수록 불리

### 3. 위시리스트 숫자에만 집착
- 위시리스트 = 관심, 구매 보장 아님
- 진짜 팬(Discord, Reddit 커뮤니티)을 만드는 게 더 가치 있음

### 4. 유료 광고 의존
- 인디 게임에 TikTok 유료 광고는 ROI가 낮음 (전환 퍼널이 길어서)
- 유기적 콘텐츠에 집중

## Unity에서 SNS용 클립 만들기

```csharp
// 게임 중 특정 순간 자동 GIF/영상 캡처 (개발 중 클립 소재 수집용)
// Unity Recorder 패키지 활용
// Window → General → Recorder → Add Recorder → Movie/GIF
```

실용 팁:
- **Unity Recorder**: 게임 실행 중 특정 키로 30초 클립 녹화
- **OBS Studio**: 무료 방송 소프트웨어, 화면 캡처 + 클립 저장
- 영상에 자막 자동 생성 → CapCut, DaVinci Resolve(무료)

## 한국 인디 시장 특수성

- **부산 인디 커넥트 페스티벌 (BIC)**: 연 1회, 인디 개발자 필참 이벤트
- **Global Game Jam 한국 지부**: 참여하면 커뮤니티 형성
- **네이버 게임 카페, 루리웹**: 스크린샷 공유 + 반응 수집
- **인디게임스 잡지**: 한국 인디 게임 소개 미디어
- 영문 + 한글 병행 SNS 운영 추천 (해외 플레이어도 2인 협동 게임 타겟)
