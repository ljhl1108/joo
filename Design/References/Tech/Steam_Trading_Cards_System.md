# Steam 트레이딩 카드 & 배지 시스템

리서치 날짜: 2026-11-25

## 개요

Steam 트레이딩 카드는 게임 플레이 시간에 따라 드롭되는 수집형 카드. 카드 세트를 완성하면 프로필 배지를 제작할 수 있고, 카드는 Steam 커뮤니티 마켓에서 거래 가능.

**OnionCat에 필요한 이유**:
- Steam 출시 시 커뮤니티 활성화의 핵심 기능
- 카드 아트가 게임 홍보물로도 작용 → 추가 마케팅 효과
- 플레이어 Steam 프로필에 OnionCat 배지 등장 → 바이럴 효과
- 개발 비용 대비 커뮤니티 참여도 상승

## 에셋 요구사항

### 필수 에셋

| 에셋 | 수량 | 크기 | 비고 |
|------|------|------|------|
| 트레이딩 카드 이미지 | 5~15장 | 206×184px | 각 카드마다 고유 아트 |
| 카드 배경 | 1장 | 1920×1080px | 카드 뒷면 배경 |
| 배지 (5단계) | 5개 | 80×80px | 카드 1장→5장 세트당 1~5레벨 |
| 포일 배지 | 1개 | 80×80px | 포일 카드 세트용, 자동 생성 |
| 프로필 배경 | 최소 1개 | 1920×1080px | 배지 제작 시 보상 |
| 이모티콘 | 최소 5개 | 54×54px (28×28 표시) | 배지 제작 시 보상 |

### 카드 개수 가이드라인
- **5장**: 최소 요건, 세트 완성 쉬움
- **8~10장**: 중간 균형 — 완성 적당히 어렵고 거래 활발
- **15장**: 최대, 완성 어려움 → 마켓 카드 거래 증가

## Steamworks 등록 절차

### 1단계: 등록 자격 확인
- Valve가 판매 성과·플레이어 참여도를 기준으로 자격 부여
- **출시 후 일정 기간·판매량 도달 시** 자동 또는 신청 가능
- Steamworks 대시보드 → "Profile Features (Trading Cards)" 메뉴가 보이면 등록 가능

### 2단계: 에셋 업로드
```
Steamworks 로그인 → 앱 선택
→ Edit Steamworks Settings
→ Community 탭
→ Community Items (e.g. Trading Cards)
→ 각 에셋 유형별 업로드
```

### 3단계: 카드 메타데이터 설정
- 각 카드에 이름, 설명, 시리즈 번호 입력 (한글 가능)
- 카드 테마 결정: 캐릭터별, 적별, 스테이지별 등

### 4단계: Valve 검토 → 출판
- 제출 후 Valve가 아트 품질·저작권 검토 (보통 1~2주)
- 승인 후 개발자가 직접 "Publish" 버튼으로 활성화
- 활성화 전까지 플레이어에게 비노출

## 카드 디자인 가이드

### OnionCat 카드 아이디어 (5장 기본 세트)

| 번호 | 제목 | 내용 |
|------|------|------|
| 1 | 새벽 (고양이) | 고양이 전신 일러스트, 황금빛 배경 |
| 2 | 양파 | 화분 위 양파 클로즈업, 빨간 빛 |
| 3 | 슬라임 군주 | 보스 슬라임, 어두운 던전 배경 |
| 4 | 그리모 (낡은 책) | 반전 후 마녀 모습, 보라색 |
| 5 | 세 작물 | 양파·해바라기·버섯 나란히, 등대 배경 |

### 아트 스타일 주의사항
- 픽셀 아트 카드는 206×184에서 작아 보임 → 업스케일된 아트나 노픽셀 일러스트 사용 권장
- 배지는 80×80으로 작아 단순한 아이콘 형태가 적합 (고양이 얼굴 / 양파 등)

## 카드 드롭 메커니즘

```
게임 플레이 시간에 비례해 카드 드롭
→ 플레이어가 받을 수 있는 카드 수 = ceil(전체 카드 수 / 2)
→ 나머지는 마켓에서 구매 or 다른 플레이어와 교환
→ 전체 세트 완성 → 배지 제작 (카드 소각, 경험치 획득)
```

**포일 카드**: 일반 카드와 별개로 무작위 드롭 (매우 희귀), 별도 포일 배지 세트

## 게임 코드 측 작업

**없음!** 트레이딩 카드 시스템은 Steamworks 웹 패널에서만 설정 — Unity 코드 변경 불필요.

단, Steam Stats/Achievements가 카드 드롭 트리거와 연동될 수 있으므로 Steamworks_Integration이 먼저 구현되어 있어야 함.

## OnionCat 출시 타임라인

```
출시 전: 카드 아트 준비 (사람이 그림)
         → 에셋 사이즈/포맷 맞추기
         → Steamworks에 초안 업로드

출시 후: Valve 자격 검토 대기
         → 자격 부여 시 최종 에셋 제출
         → 검토 통과 후 Publish
         → 커뮤니티 공지 "트레이딩 카드 추가!"
```

## 인디 개발자 주의사항

- 트레이딩 카드 시스템은 **출시 후 추가 작업**이므로 론칭 블로커가 아님
- 카드 아트는 게임 내 완성도 높은 아트를 재활용하면 추가 비용 최소화
- 카드 아트 품질이 낮으면 Steam 커뮤니티 허브 이미지로 무기한 노출 → 최소한의 품질은 유지
- 포일 배지는 Valve가 자동 생성 (개발자가 별도로 만들 필요 없음)
