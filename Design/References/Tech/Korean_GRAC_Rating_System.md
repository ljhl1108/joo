# Korean GRAC Rating System (한국 게임물관리위원회 등급 분류)

리서치 날짜: 2026-11-04

## 개요

한국 내 게임 유통·판매를 위해 반드시 거쳐야 하는 **게임물관리위원회(GRAC)** 등급 분류 절차. Steam 한국 출시, 모바일 국내 앱 스토어(Google Play KR, App Store KR), 콘솔 한국판 모두 해당. 인디 개발자는 "자체등급분류" 또는 "오픈마켓 게임물" 간소화 절차를 활용하면 비용·기간을 크게 줄일 수 있다.

---

## 등급 체계

| 등급 | 기호 | 대상 |
|------|-----|------|
| 전체이용가 | ALL | 모든 연령 |
| 12세 이용가 | 12 | 12세 이상 |
| 15세 이용가 | 15 | 15세 이상 |
| 청소년이용불가 | 18+ | 성인만 |
| 등급거부 | — | 유통 불가 판정 |

**OnionCat 예상 등급**: 폭력·선정성 없는 귀여운 고양이+작물 게임 → **전체이용가** 가능성 높음.

---

## 등급 분류 방법 3가지

### 1. 오픈마켓 게임물 자체 등급 분류 (가장 빠름)

**대상**: 스마트폰·태블릿 앱 스토어(Google Play, App Store) 유통 게임  
**조건**: 도박·사행성·성인 내용 없음, 유료 아이템 없거나 국내 기준 충족  
**절차**: 플랫폼(Google Play, Apple) 쪽에서 직접 등급 선택 → GRAC 신고  
**비용**: 무료  
**기간**: 즉시 (사후 검증)  
**Steam에는 해당 없음** — Steam은 별도 절차 필요

### 2. 소규모 게임 간소화 등급 분류

**대상**: PC·콘솔 게임 중 아래 조건 모두 충족:
- 개발비 1억 원 미만
- 국내 판매 예정 금액 연 1억 원 미만
- 사행성·성인물 아님

**절차**:
1. GRAC 홈페이지(grac.or.kr) 회원가입
2. 간소화 신청서 작성 (게임 소개, 스크린샷, 영상, 개발 비용 증빙 불필요)
3. 수수료 납부: 10,000원 (2024년 기준)
4. 심의 후 등급 통보

**기간**: 약 2~4주 (공휴일 제외)  
**비용**: 10,000원  
**Steam 출시 가능**: 등급 통보 후 Steam에 등급 정보 입력

### 3. 일반 등급 분류 (표준 절차)

**대상**: 대형 타이틀, 조건 미충족 게임  
**절차**: 전문 심의위원이 직접 플레이·심사  
**비용**: 10만~500만 원 (게임 규모, 등급에 따라 차등)  
**기간**: 1~2개월  
**OnionCat**: 소규모 간소화로 충분할 가능성 높음

## Steam 한국 출시를 위한 실질 절차

```
1. GRAC 소규모 간소화 신청 접수 (grac.or.kr)
   - 필요 서류: 게임 소개서, 스크린샷 5장 이상, 플레이 영상 (1~3분)
   - 등급 추천 작성: 본인이 생각하는 적합 등급 + 이유

2. 심의 대기 (2~4주)
   - 추가 자료 요청 올 수 있음 → grac 이메일 확인 필수

3. 등급 결정서 수령
   - 게임명, 등급, 등급 번호, 유효기간 명시
   - 유효기간: 보통 3년 (내용 변경 시 재심의)

4. Steam 파트너 대시보드에 등급 입력
   - Store Page → Edit Store Page → Ratings → Korea
   - GRAC 등급 번호 입력

5. Steam 한국 스토어에 등급 표시 완료
```

## 주의사항

### 내용 변경 시 재심의 필요
- 대규모 DLC, 성인 내용 추가, 게임명 변경 시 재신청
- 소규모 버그픽스·밸런스 패치는 재심의 불필요

### 등급 없이 판매 시 처벌
- 게임산업진흥에 관한 법률 위반
- 과태료 500만 원 이하 또는 영업정지
- Steam 국내 서비스 차단 가능

### 한국어 지원과 등급은 별개
- 등급 분류는 언어와 무관 — 영문 게임도 신청 가능
- 단, 심의 서류 및 소통은 한국어로

### "게임 내 결제" 관련 추가 규제
- 확률형 아이템이 있으면 **확률 공시 의무** (게임법 개정, 2023년~)
- OnionCat에 뽑기·가챠가 없으면 해당 없음
- 상점·리롤 같은 "고정 가격 구매"는 무관

## OnionCat 적용 계획

| 단계 | 시기 | 할 일 |
|------|------|-------|
| 얼리 준비 | 출시 3~4개월 전 | GRAC 계정 생성, 간소화 대상 여부 확인 |
| 신청 | 출시 2개월 전 | 소규모 간소화 신청, 스크린샷·영상 준비 |
| 심의 대기 | 출시 1~2개월 전 | Steam 페이지 준비, 등급 필드만 비워두기 |
| 등급 수령 | 출시 직전 | Steam 대시보드에 등급 번호 입력 |
| 출시 후 | 필요 시 | 큰 콘텐츠 업데이트 시 재심의 여부 확인 |

**예상 비용**: 10,000원 (소규모 간소화)  
**예상 기간**: 3~4주  
**예상 등급**: 전체이용가 (ALL) — 고양이+작물, 판타지 폭력, 선정성 없음
