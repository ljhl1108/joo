# Blazing Beaks

리서치 날짜: 2026-06-27

## 기본 정보
- **장르**: 탑다운 로그라이크 슈터 (2D 픽셀아트)
- **개발사**: ARTillery (슬로바키아 소규모 스튜디오)
- **플랫폼**: PC(Steam), Nintendo Switch, PS4/5, Xbox
- **출시**: 2019년 8월 (Steam)
- **공식 사이트**: https://blazingbeaks.com
- **Steam**: https://store.steampowered.com/app/736990/Blazing_Beaks/
- **주요 특징**: 1~2인 로컬 협동, 위험-보상 아이템 시스템, 짧고 빠른 런

---

## 핵심 메카닉

### 1. 리스크-리워드 아이템 시스템 (가장 독특한 점)
- 모든 아이템에는 **긍정 효과**와 **부정 효과**가 동시에 있음
  - 예: "탄속 +50%, 하지만 이동속도 -20%"
  - 예: "킬할 때마다 탄약 회복, 하지만 체력 최대치 -1"
- 아이템 설명을 읽고 "이 런에 맞는 조합인지" 판단하는 것이 핵심 재미
- 나쁜 조합을 선택하면 런을 망치는 높은 리스크

### 2. 로컬 2인 협동
- 동일 화면에서 2인 동시 플레이
- 한 명이 죽으면 다른 한 명이 픽업 아이템으로 부활 가능
- 아이템을 공유하지 않고 각자 독립적으로 수집 → 서로 다른 빌드 구성
- 협동 시 화면 분할 없이 하나의 카메라로 두 캐릭터 동시 추적 (카메라가 두 플레이어를 모두 포함하도록 줌 조정)

### 3. 캐릭터 다양성
- 여러 오리(Duck) 캐릭터 중 선택, 각각 기본 무기/능력 다름
- 예: 빠른 이동 오리, 방어막 오리, 폭발 공격 오리 등
- 런 시작 전 캐릭터 선택 → 빌드 방향성 결정

### 4. 무기 & 전투 시스템
- 주무기(메인 공격) + 부무기(특수 공격)
- 무기도 아이템처럼 리스크-리워드 조합 존재
- 총알이 아닌 근접 무기도 일부 존재
- 방 클리어 후 아이템 선택지 2~3개 중 1개 선택

### 5. 런 구조
- 짧은 런: 5~10분 내 완주 가능한 설계
- 레벨이 짧고 빠름 — 죽어도 부담이 적어 반복 플레이 유도
- 층 구조: 각 층 = 여러 방 + 상점 + 보스

## 플레이어들이 사랑하는 점
1. **빠른 런 길이** — 한 번에 5~15분, 부담 없이 반복 가능
2. **리스크-리워드 깊이** — 아이템 조합 실험의 재미가 높음
3. **2인 협동의 캐주얼함** — 진입 장벽 낮고 같이 웃으며 플레이 가능
4. **낮은 가격** — 소규모 스튜디오치고 높은 가성비
5. **픽셀아트 감성** — 귀엽고 통통 튀는 비주얼이 친근함

## OnionCat 적용 포인트

### A. 리스크-리워드 업그레이드 → OnionCat 협동 업그레이드에 적용
- 업그레이드 선택지에 "한 플레이어는 강해지지만 다른 플레이어는 약해지는" 트레이드오프 추가
  - 예: "Cat 슬래시 범위 +50%, Crop 방패 쿨타임 +1초"
  - 예: "Crop 투사체 3발 동시 발사, Cat 대시 거리 -30%"
- 두 플레이어가 상의하며 선택하는 협동 요소 자체가 게임플레이

### B. 부활 메카닉 설계 참고
- Blazing Beaks: 파트너 근처에서 아이템 드롭 후 픽업하면 부활
- OnionCat 적용: 한 명이 쓰러지면 다른 한 명이 10초 내에 "살리기 액션"(버튼 홀드)으로 부활
  - Cat이 쓰러지면 이동 불가 → Crop이 혼자 버티며 살리기
  - Crop이 쓰러지면 공격력 반감 → Cat이 위험 속 버티기

### C. 카메라 줌 아웃 시스템
- 두 플레이어 거리가 멀어지면 카메라가 자동 줌 아웃해 둘 다 화면에 포함
- OnionCat은 Cat과 Crop이 분리 불가이므로 이 메카닉은 직접 적용 X
- 그러나 **보스 방에서 줌 아웃**하는 연출 참고 가능 (일반 방보다 넓으므로 고정 줌 아웃)

### D. 짧은 런 설계 철학
- Blazing Beaks의 "10분 런" 설계 → 초보 개발자에게 첫 완주 허들 낮춤
- OnionCat MVP: 3~5개 방 + 미니 보스 1개 = 10분 플레이 볼륨으로 먼저 완성
- 런이 짧으면 빠른 피드백 루프 → 밸런스 조정이 쉬워짐

### E. 아이템 설명 UI
- 아이템 효과를 색상으로 구분: 초록 = 긍정 효과, 빨간 = 부정 효과
- OnionCat 업그레이드 카드 UI에 동일 패턴 적용
  - 예: Cat 아이콘 옆에 초록 "슬래시 +1 히트", 옆에 빨간 "쿨타임 +0.5초"
