# 고양이 픽셀아트 레퍼런스

2026-10-04 수집. 고양이 캐릭터 방향(두 발/네 발, 크기, 등신)을 정하기 위한 자료. 총 116건, ★ = 먼저 볼 것.

- **이미지 갤러리**: `Design/References/Art/cat_gallery/index.html`을 브라우저로 열기
  (**로컬 전용** — 타사 이미지라 공개 저장소에 올리지 않도록 git에서 제외)
- 가격은 수집 시점 itch.io 표기. 무료·PWYW라도 **상업 사용 조건은 구매 전에 각 페이지 라이선스 확인**
- 수집 경로: itch.io 태그 목록(cats·pixel art·free) / itch.io 컬렉션 "cats only" / OpenGameArt / Steam 검색(cat + Pixel Graphics) / 웹 검색
- 픽셀아트가 아닌 3D·일러스트 게임은 제외: Kitaria Fables, Calico, Cat Quest, Mewgenics, Cats are Liquid, Paws of Coal, Nekomancer 등

## OnionCat 기준으로 본 요약

| 질문 | 참고할 자료 |
|---|---|
| 탑다운 4방향 고양이는 어떻게 생겼나 | Cattails(게임), Pixel Cats Collection, Revouger 시리즈, Pipoya Nekonin |
| 32px 한 칸에 고양이가 들어가나 | Pixel Cats Collection·Revouger·ToffeeCraft가 전부 32×32 — 충분히 알아볼 수 있음 |
| 두 발 전투 고양이 | Super Catboy, Cat Warrior, Cute Legends, OboroPixel |
| 할퀴기·덮치기 동작 | girlypixels(공격 2종), Carysaurus(Pounce), Catset(움직임) |
| 탑다운 고양이 액션 로그라이트 화면 | Cat Bait, Beef Cat Ultra, Cat Girl Survivor |

- **두 발 vs 네 발**: 탑다운 4방향 에셋은 네 발이 대부분이고, 두 발은 Pipoya(걷기만)·Cute Legends(16px 횡)뿐.
  두 발로 가면 공격 동작은 사실상 직접 그려야 한다. 네 발로 가면 Pixel Cats Collection처럼 공격·피격까지 있는 기성품이 있다.
- **바로 쓸 수 있는 후보**: Pixel Cats Collection($12) — 32px·4방향·공격/피격/사망. 걷어차기·대쉬는 추가 제작 필요

> ⚠️ **Steam에 "CAT & ONION"이라는 게임이 이미 있음** (2024, 고양이 + 날아다니는 양파 어드벤처, Karl Zylinski).
