## 핵심 메커니즘

### 1. 픽셀 물리 시뮬레이션 (Falling Sand Engine)
- 게임 내 모든 픽셀이 물리적으로 시뮬레이션됨
- 물, 불, 기름, 산(acid), 용암 등이 실제처럼 흘러다님
- 총알 한 발이 물리적으로 액체를 튀김
- 환경이 완전 파괴 가능 (destructible environment)
- **핵심 필러**: "모든 것이 시뮬레이션된다 (Every pixel matters)"

### 2. 완드(Wand) 시스템 — 로그라이크 핵심
- 플레이어는 완드를 장착하고, 완드에 "스펠(Spell)" 카드를 조합
- 스펠 조합 방식:
  - `Explode + Bounce + Triple Scatter` → 폭발하는 튕기는 3발 탄
  - 같은 스펠이라도 순서에 따라 완전히 다른 결과
- 완드 자체에 속성: 발사 속도, 마나 재충전, 홀드 가능 스펠 수
- 조합 발견이 플레이어 성장의 핵심 재미

### 3. 죽음의 영구성과 세계 영구성
- **퍼마데스** + 하지만 **세계 씨드는 고정**
- 같은 월드에서 다시 시작 → 이전 런에서 무언가를 놓고 와도 그 자리에 있음
- 이전 런의 시체가 남음 (다른 플레이어의 유령도 볼 수 있음)
- 죽은 이유를 분석하고 다음 런에 전략을 바꾸는 구조

### 4. 평행 세계(Parallel Worlds) 시스템
- 세계 경계 밖으로 나가면 평행 세계로 진입
- 평행 세계는 기본 세계와 동일하지만 난이도가 올라감
- 숨겨진 비밀, 보스, 엔딩이 평행 세계에 존재

### 5. 비선형 탐험 구조
- 정해진 룸 순서 없음 — 원하면 최종 보스 근처로 바로 파고 내려갈 수 있음
- 레이어별 바이옴: 숲 → 광산 → 정글 → 빙하 → 지옥
- 탐험 vs. 최적화 경로 선택이 플레이어에게 있음

## 협동 요소

- **Noita는 싱글플레이 전용** — 공식 코옵 없음
- 그러나 **모드로 코옵 구현** (Noita Together 모드 등)
  - 두 플레이어가 같은 픽셀 세계를 공유
  - 물리 시뮬레이션이 공유 → 한 플레이어가 산(acid)을 쏘면 상대방도 위험
  - **우발적 배신(Friendly Fire)이 메인 콘텐츠**가 됨

## 플레이어들이 사랑하는 것

1. **발견의 쾌감**: 스펠 조합 → 완전히 예상 못한 효과 발견
2. **물리 상호작용**: 불을 붙여서 기름 호수에 튀기면 폭발 → 의도치 않은 연쇄 반응
3. **깊은 비밀**: 공식 위키도 완전히 정리 못한 숨겨진 시스템 (퀀텀 엔티티, 신성 선물 등)
4. **죽음의 재미**: "어떻게 죽었는지"가 재미있는 게임 — 자신의 폭발에 죽기, 중력이 뒤집혀서 죽기
5. **커뮤니티 탐험**: 4년이 지나도 새로운 비밀이 발견됨

## OnionCat 적용 포인트

### A. 환경 상호작용으로 취약점 체계 확장
- Noita: 물 + 전기 = 감전 피해
- **OnionCat 응용**: 특정 적이 "물 웅덩이" 위에 있으면 레인지 공격 연쇄, 특정 지형에서 냥이(고양이)의 대시가 추가 효과
- 취약점을 "단순 무기 타입"을 넘어 **환경 조건**으로 확장 가능

### B. 스펠 조합 → 업그레이드 조합 시스템
- Noita의 스펠 조합처럼 **런 업그레이드를 조합하면 예상 밖의 시너지** 발생
- 예: "공격력 +30%" + "모든 공격 관통" → 범위가 넓어질수록 강해짐
- 초보 개발자에게: 조합 로직 없이 단순 곱연산으로도 의도치 않은 시너지 발생 → 그것도 재미

### C. 예상 못한 죽음 → 학습 루프
- Noita의 "왜 죽었지?"가 다음 런 동기 부여
- **OnionCat**: 게임 오버 화면에 "마지막 피해 발생 원인" 표시 (근접 적/원거리 적/함정)
- 두 플레이어가 죽음 원인을 분석해서 다음 런 역할 분담 조정

### D. 씨드 고정 + 퍼마데스 구조
- Noita처럼 동일 씨드에서 재시작 → **"이번엔 다른 경로로"** 학습 가능
- OnionCat: 첫 런은 씨드 고정 → 2번째부터 완전 랜덤 옵션 고려

### E. 소규모 팀 물리 → 성능 교훈
- 3인 팀이 픽셀 물리 엔진 직접 제작 → C/C++ 코어, GPU 활용
- **OnionCat 교훈**: Unity 물리는 픽셀 단위 시뮬레이션에 부적합 → 파티클 이펙트로 "시뮬레이션처럼 보이게" 연출하는 것이 현실적
