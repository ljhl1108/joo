## 핵심 메카닉

### 곡괭이 이중 용도 시스템
- **근접**: 짧게 버튼 → 근접 휘두르기
- **투사체**: 길게 누르고 조준 → 투척 (다시 손으로 돌아옴)
- 동일한 도구가 상황에 따라 근접/원거리 역할 전환
- OnionCat과 구조적 유사성: 단일 오브젝트가 다중 역할

### 물리 기반 폭탄 시스템
- 폭탄이 중력에 의해 경사면을 굴러내려감
- 연쇄 폭발: 폭탄이 다른 폭탄에 닿으면 터짐
- 적 캐릭터를 폭발로 공중에 띄울 수 있음
- 픽셀아트 게임에서 간단한 물리 시뮬레이션의 게임플레이 깊이 증명

### 골드 순환 시스템
- **런 내 골드**: 사망 시 전부 손실 (고위험 수집)
- **상인 소비 골드**: 런 도중 상인에게 지불 → 사망해도 효과 유지
- **메타 업그레이드**: Sho 상인에게 지불 → 영구 해금
- 수집 자체가 긴장감을 가짐 — 골드가 살포되면 재수집해야 함

### Peasant(소작농) 동행 시스템
- 적을 때리면 소작농이 떨어져 나옴
- 소작농을 보호하며 출구로 데려가면 성수(Holy Water) 보상
- 성수: 능력 강화 또는 특수 효과 아이템
- NPC 보호 목표가 전투 중 부가 목적 추가

### 친숙한 동반자(Familiar) 시스템
- 런 도중 발견/해금하는 영구 동반자
- 각 Familiar는 고유한 패시브/액티브 능력 보유
- 런 시작 시 원하는 Familiar 선택 (최대 3개 동시 장착)
- 예: Mudge — 기절 시 폭탄 드롭 / Imber — 주기적으로 번개 발사

### 렐릭 & 저주 상호작용
- 렐릭: 강력한 런 수정자 (BoI 아이템과 유사)
- 저주: 렐릭 획득 시 함께 붙는 부정적 효과
- 강한 렐릭일수록 강한 저주 → 위험-보상 균형

## 메타 진행 구조

| 단계 | 내용 |
|------|------|
| 런 시작 | 영구 스탯(HP/공격력 등) 적용 후 던전 진입 |
| 런 중 | 렐릭 수집, Perk 선택, 상인 거래 |
| 사망/클리어 | 지출한 골드 기반 메타 포인트 적립 |
| 런 간 | Sho에게 영구 업그레이드 구매 |

## 협동 요소 (Co-op)

- 2인 로컬 Co-op 지원
- 두 번째 플레이어는 **Beatrice(마녀)** 캐릭터로 플레이
- Beatrice: 다른 공격 패턴, 원거리 마법 중심
- 서로 다른 무기 타입 → 적에 따른 역할 분담 자연 발생
- 아이템 공유 / 부활 메카닉 존재

---

## 적 다양성

- 근접 전용 적: 충돌 피해, 갑옷 적
- 원거리 전용 적: 원거리 공격, 근접 시 도망
- 특수 적: 폭발 반응, 반사탄, 면역 타입
- 약점 시스템(명시적이진 않으나 상황별 최적 무기 존재)

---

## 게임 필 (Game Feel) 특징

- **곡괭이 무게감**: 스윙 시 약간의 딜레이 → 타이밍 기반 전투
- **골드 물리**: 수집 가능한 골드가 실제로 튀고 굴러다님
- **히트스탑**: 근접 타격 시 프레임 정지 효과
- **피격 리액션**: 적들이 타격 방향으로 넉백
- **진동 카메라**: 폭발/보스 등장 시 화면 흔들림

## OnionCat 적용 포인트

### 1. 단일 도구 이중 용도 철학
- 곡괭이처럼 Cat의 슬래시도 근접 모드와 투척 모드로 분리 가능
- "고양이가 발톱을 날리는" 원거리 변형 기술로 응용 가능
- 같은 버튼 → 다른 입력 길이 → 다른 행동: OnionCat 조작 확장에 참고

### 2. 골드 긴장감 → 영혼(Soul) 아이템에 응용
- OnionCat 런 내 소모성 자원이 사망 시 일부 손실되도록 설계하면 긴장감 UP
- 상인에서 소비한 자원은 보존 → 위험 감수할 이유 존재

### 3. NPC 보호 서브목표
- 방에 구출 대상 NPC 배치 → 보호 성공 시 보너스
- OnionCat: 동물 NPC를 보호하며 방 탈출하면 특수 아이템 보상

### 4. 저주-렐릭 균형
- OnionCat 업그레이드 시스템에 "강력한 아이템 = 부작용" 패턴 도입
- 예: "양파가 독 구름 생성(강함) + Cat 이동 속도 감소(저주)"

### 5. Familiar → OnionCat 동반 식물
- 등짝의 화분에서 추가 식물(Familiar)이 자라 패시브 능력 부여
- 런마다 다른 식물 선택 → 빌드 다양성 확보

### 6. Co-op 캐릭터 분리 설계
- Beatrice처럼 P2(Onion)도 독자적인 조작 세트를 가진 "별개 캐릭터"처럼 느껴지게 설계
- 폼팩터는 하나이지만 조작 감각은 두 캐릭터가 독립적으로 존재
