## 핵심 메카닉

### 두개골 교체 시스템 (캐릭터 스위칭)
- 플레이어 캐릭터 Skul은 적의 두개골을 수집해 장착
- 두개골마다 완전히 다른 공격 패턴, 이동 능력, 스킬 보유
- **최대 2개 동시 장착** → Q키로 두 두개골 사이를 실시간 전환
- 두개골 조합(시너지)이 핵심 빌드 메카닉
- 이 시스템이 OnionCat의 "Cat + Crop 두 역할" 구조와 가장 닮은 국내 사례

### 빠른 페이스 + 다양한 이동 옵션
- 대시, 이중 점프, 두개골별 고유 이동기 (예: 텔레포트, 글라이드)
- 적 투사체가 많고 패턴이 강함 → 회피 중심 플레이

### 아이템 / 능력치 강화
- 런마다 장신구, 스킬 강화 옵션을 선택
- 두개골 강화로 기존 기술이 상위 기술로 업그레이드
- 아이템 등급: 노말 → 매직 → 레어 → 유니크 → 레전더리

### 내러티브와 세계관
- 역할 반전 설정: 마왕 군단의 작은 해골 병사가 주인공
- 인간 영웅들이 악당, 마왕성을 지키는 것이 목표
- 가볍고 유머러스한 픽셀 아트 + 캐릭터 개성이 강함

### 룸 구성
- 선형 스크롤 + 랜덤 배치 적
- 챌린지 룸, 상점, 강화 NPC, 보스 룸으로 구성된 루프

## 플레이어가 좋아하는 요소

1. **두개골 스위칭의 재미** — 두 캐릭터를 능숙하게 교체하는 숙련도 표현
2. **다양한 빌드 가능성** — 100개 이상의 두개골 × 조합 시너지
3. **한국 정서에 맞는 유머** — 로컬라이징 없이도 글로벌 흥행
4. **빠른 전투 속도** — Dead Cells와 유사한 쾌속 전투감

## OnionCat 적용 포인트

| Skul 요소 | OnionCat 적용 방법 |
|---|---|
| 두개골 전환 (2캐릭터 실시간 스위칭) | Cat(근접)과 Crop(원거리)의 역할 전환 아이디어 — 일시적 역할 교환 업그레이드로 응용 가능 |
| 두개골 시너지 | Cat 업그레이드 + Crop 업그레이드 간 시너지 테이블 설계 레퍼런스 |
| 역할 반전 내러티브 | OnionCat의 세계관: 고양이가 채소를 지키는 구도 → "영웅을 막는 자" 구도 응용 가능 |
| 두개골 등급 시스템 | 업그레이드/능력 아이템의 등급화 (일반/레어/전설) → 드롭 테이블 설계에 활용 |
| 가볍고 귀여운 픽셀 아트 | OnionCat의 아트 방향성 레퍼런스 — 적 디자인에서 유머 요소 허용 |

## 개발자 참고 — 기술적 포인트

- **두개골 교체 = ScriptableObject 기반 능력 컴포넌트 교체**: 각 두개골을 `SkullData : ScriptableObject`로 정의하고, 플레이어 GameObject에 능력 컴포넌트를 동적으로 교체(Add/Remove Component)
- **시너지 시스템**: 두 두개골 ID 조합을 Dictionary<(int, int), SynergyEffect>로 룩업
- **두 개 장착 + Q 전환**: OnionCat에서 "임시 역할 교환" 파워업으로 응용 — 예를 들어 특정 아이템 획득 시 Cat이 잠시 원거리 공격 가능
