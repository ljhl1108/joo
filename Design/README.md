# Design 폴더 구조

```
Design/
├── 00_Implemented.md     ← ✅ 구현 완료 목록 (지금 게임에 들어간 것만)
├── 01_Characters.md      ← 고양이·작물 종류, 기본기, 마법서 스킬, 조작 설계
├── 02_Enemies.md         ← 텔레그래프 규칙, 적·보스
├── 03_Maps.md            ← 진행 방식, 런 구조(방 종류), 스테이지, 방 만들기
├── 04_Combat.md          ← 전투 원칙, 협동(콤보·합동기·세트·가방), 2인 기믹
├── 05_Items.md           ← 런 안의 성장: 장비 아이템 v4 규칙 (칸·등급·세트·분해·중간 저장)
├── 05_Items_Content.md   ← 장비 효과·세트·패시브·양파 스킬 목록 (아이디어 → 채택하면 구현)
├── 06_FeelParameters.md  ← 타격감·조작감 조절 수치 목록 (점검용)
├── 07_StoryMeta.md       ← 세계관, 런 간 성장(온실), 이야기 전달
│
├── IdeaPool/             ← 일일 루틴이 매일 1개씩 생성
│   ├── (YYYY-MM-DD.md — 이번 달 파일은 루트에 쌓임)
│   └── 2026-05/ … 2026-09/   ← 월별 아카이브
│
└── References/
    ├── Game/             ← 게임 레퍼런스
    ├── Tech/             ← 기술 레퍼런스
    └── Art/              ← 아트 레퍼런스
```

## 운영 규칙

1. **완료와 계획을 나눈다** — 구현이 끝난 것은 `00_Implemented.md`에 수치·커밋과 함께 적는다.
   `01~07`은 **규칙(왜 이렇게 하나)과 아직 안 만든 것**만. 구현된 항목은 ✅ 표시 + 00 문서를 가리킨다
2. 표시: ✅ 구현됨·결정됨 / 🔶 잠정 (해 보고 조정) / 📝 계획 / ❓ 결정 대기
3. **설계가 바뀌면 옛 내용은 지운다** (git 기록에 남음). 무엇이 바뀌었는지는 `00_Implemented.md` 끝 "바뀌거나 버린 설계" 표에 한 줄
4. **IdeaPool은 받은 편지함** — 루틴이 매일 아이디어를 쌓는다. 채택할 것은 `01~07`에 옮겨 적고, 월이 끝나면 그 달 파일을 `YYYY-MM/`로 이동
5. 루틴이 `References/` 루트에 게임 파일을 만들면 `Game/`으로 이동
6. 전체 컨셉 요약은 저장소 루트 `GameConcept.md`, 할 일은 `TODO.md` / `TODO_Art.md`
