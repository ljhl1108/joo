## 캐릭터 (01_Characters)

- **탄성 씨앗 업그레이드** — Blightbound 역할 분리 + 반사탄 참고: P2 업그레이드 "탄성 씨앗" 획득 시 투사체가 벽 2회 반사. 벽 뒤에 숨은 적이나 코너 뒤 적도 맞출 수 있어 P2의 전술 범위 확장. 구현 힌트: `ProjectileRicochet` 컴포넌트 `maxBounces = 2` + `UpgradeManager`에서 동적 부착.

- **관통 발톱 슬래시** — Rogue Stormers 시너지 시스템 참고: P1의 슬래시가 특정 업그레이드 후 적 1명을 통과해 뒤 적에게도 대미지. 반원형 슬래시를 `Physics2D.OverlapCircleAll`로 범위 내 적 전부 처리 → `hitEnemyIds` 없이 관통 표현. 구현 힌트: `MeleeSlash.hitAll = true` 플래그로 전환.

- **고무 파 특수 모드** — 반사탄 업그레이드 심화: P2가 특수 버튼 홀드 시 3초간 모든 투사체가 "고무 파" 모드 전환 — 벽 3회 반사 + 적 2명 관통. 게이지 소모형. 구현 힌트: `AbilityGauge` 소모 시 `ProjectileConfig.SwitchPreset("rubber")` 호출.

## 적 (02_Enemies)

- **반사방패 적** — Blightbound 방패 직업 참고: 전면에 금속 방패를 들어 원거리 투사체를 정확히 반사시키는 적. 반사된 탄이 P1·P2를 향해 되돌아옴. 반드시 P1이 측면으로 우회해 근접 공격. 구현 힌트: 방패 Collider2D에 `ProjectileReflector` 컴포넌트 — 충돌 시 `Vector2.Reflect`로 탄 방향 반전.

- **관통 면역 적** — 관통 시스템 역이용: 특수 "강화 갑옷" 적은 관통 탄을 흡수해 HP 회복. P2의 관통 업그레이드가 오히려 독이 되는 상황 → P1 근접 전담 필요. 구현 힌트: `EnemyHealth.OnPierceHit()` 이벤트에서 데미지 대신 `Heal(damage * 0.5f)` 처리.

- **블라이트 포자 적** — Blightbound 독 구역 참고: 처치 시 주변에 독 가스 구역을 생성하는 적. 처치 순서가 중요해지는 전략층 추가. P2가 원거리로 먼저 독 발생기 적을 처리 → P1이 안전하게 근접 전투. 구현 힌트: EnemyDeath 이벤트에서 `PoisonZone` 프리팹 Instantiate, 5초 후 소멸.

## 맵 (03_Maps)

- **반사탄 퍼즐 방** — 투사체 반사 시스템 참고: 방 중앙에 크리스탈 반사판이 배치. P2가 특정 각도로 조준해 반사시켜 숨은 스위치를 맞춰야 문이 열리는 구조. P1이 반사판을 보호하는 동안 P2가 각도를 조준. 구현 힌트: 크리스탈 Collider에 `ProjectileReflector` + `TriggerSwitch.OnProjectileHit()` 구독.

- **독 가스 통로** — Blightbound 블라이트 존 참고: 공유 HP가 지속 감소하는 독 가스 통로. 통로 끝 발생기를 P1이 근접 파괴 시 가스 소멸. 빠르게 돌진하거나 P2의 원거리 지원을 받으며 진입. 구현 힌트: Trigger Stay2D → `SharedHealth.TakeDamage(3f * Time.deltaTime)`.

- **메아리 방** — 반사탄 전략 극대화: 모든 벽이 매끄러운 금속으로 돼 있어 투사체가 무한 반사. 단, 반사 횟수 초과 시 소멸. P2의 반사 업그레이드 빌드에서 클리어 보너스가 주어지는 특수 방. 구현 힌트: 방 진입 시 `ProjectileConfig.bounceBonus += 3` 임시 적용.

## 전투 (04_Combat)

- **코너 샷 협동** — 반사탄 + Blightbound 역할 참고: P1이 적을 벽 코너 쪽으로 유도(근접 압박) → P2가 반사탄으로 코너 뒤 숨은 적 처치. "P1 포지셔닝 + P2 정밀 조준"의 협동 플레이 다양화. 구현 힌트: 별도 게임플레이 유도보다 맵 레이아웃으로 자연스럽게 코너 전투 상황 조성.

- **꿰뚫기 지뢰** — 관통 시스템 + Rogue Stormers 시너지 참고: 특정 업그레이드 조합 시 P2 투사체가 땅에 박혀 지뢰가 됨. 적이 밟으면 폭발 + 관통 파편 4방향 발사. P1이 적을 지뢰 위로 유도. 구현 힌트: 투사체 Timer 만료 시 지뢰 GameObject로 교체, `Physics2D.OverlapCircle`로 발동.

- **연쇄 관통 피버** — 관통 시스템 심화: 관통 탄이 적을 3명 이상 연속으로 맞추면 "연쇄 피버" 상태 — 다음 투사체의 관통 횟수 +2 버프 (5초). 협동 포지셔닝으로 적을 일렬로 세우는 전략 보상. 구현 힌트: `PierceCounter` 컴포넌트가 연속 관통 수 트래킹, 임계값 도달 시 `PlayerP2.ApplyFeverBuff()`.

## 스토리 (05_Story)

- **블라이트의 기원** — Blightbound 세계관 참고: OnionCat 세계에서 독 가스(독 구역) 적들의 기원은 "양파밭을 지키던 수호자들이 오염된 것". 원래 P2(파)와 같은 종류의 생명체였으나 변질. 처치 시 "미안해... 나도 원래는..." 짧은 대화 조각 드롭.

- **보스 타이틀 카드 세계관** — 보스 입장 연출 참고: 각 보스는 한국어 이름 + 영문 서브타이틀 병기. 예: "뿌리의 지배자 — The Root Sovereign", "녹슨 정원사 — The Rusted Gardener". 이름 자체가 세계관 힌트를 담아야 함.

- **용병 시스템** — Rogue Stormers 클래스 다양성 참고: 런 시작 시 "동행 동물 용병" 한 마리를 선택 (자동 이동, 단순 공격 보조). 예: 참새(원거리 보조), 두더지(근접 돌진), 달팽이(방어막). 초반에는 고양이+파로 충분하지만 고급 런에서 전략층 추가.

## 기술 메모

- **투사체 반사 & 관통 시스템**: OnionCat 핵심 구현 순서 — ① 기본 직선 투사체부터 안정화 → ② `ProjectilePierce`(관통) 추가 (Trigger 사용) → ③ `ProjectileRicochet`(반사) 추가 (Collision 사용). 레이어 매트릭스 설정이 핵심: `Projectile ↔ Wall = Collision ON`, `Projectile ↔ Enemy = Trigger ON`. 반사와 관통을 동시에 쓰는 탄환은 두 컴포넌트를 함께 부착하면 됨.

- **보스 입장 연출 시스템**: 초보자는 "카메라 팬" 없이 먼저 구현해도 충분. 최소 구현: ① 문 봉인 → ② 타이틀 카드 표시 → ③ 보스 `Entrance` 트리거 → ④ 조작 재활성화. 전체 시퀀스는 하나의 Coroutine(`PlayEntrance`)에서 `yield return` 체인으로 관리하면 순서 보장이 쉬움. `PlayerInput.SetActive(false/true)` 깜빡 잊지 말 것.
