## 캐릭터 (01_Characters)

- **패배 귀환 연출** — Inscryption 참고: 런 실패 후 농장으로 돌아올 때 말하는 책이 새 대사를 추가 ("이번엔 3방까지 갔군. 지난번보다 낫네"). `MetaProgress`에 "최대 도달 방"을 기록해 두면 비교 대사 가능. `StoryLines.cs`에 패배 맥락 대사 추가 여부 검토
- **고양이 무기별 특수공격 연출** — Panzer Paladin 참고: 무기 종류마다 주문 발동 연출이 다름. OnionCat도 무기 슬롯에 따라 야성 게이지 특수공격의 타격음·이펙트 색을 다르게 하면 장비 개성이 살아남 (`CatSpecial` 발동 시 `GearItem.vfxColor` 참고)

## 적 (02_Enemies)

- **속성 연쇄 반응** — Panzer Paladin의 무기 삼각형 참고: 불 상태 적에게 얼음 공격 → "증발(Vaporize)" 추가 피해 같은 연쇄 반응. `ApplyBurn` / `ApplySlow` 가 겹칠 때 `EffectTrigger.StatusCombo` 발동하는 패시브 장비 효과로 구현 가능. 세트 보너스로 넣으면 조합 의식을 자연스럽게 유도
- **보스 "취약 창구" 명시** — Panzer Paladin처럼 보스 패턴에 "고양이만 접근 가능한 타이밍"과 "원거리로만 맞출 수 있는 타이밍"을 의도적으로 배분. 그림자 마녀 보스에 `CombatPhase.OnlyMelee` / `CombatPhase.OnlyRanged` 플래그를 두어 역할 분담 강제

## 맵·런 구조 (03_Maps)

- **보상 선택 타이머와 "일부러 소비" 선택지** — Inscryption의 카드 불태우기 + Panzer Paladin의 무기 부수기 참고: 현재 보상 선택 화면에 "이 장비를 버리면 씨앗 +3" 옵션 추가. 덱을 얇게 만드는 선택이 의미 있으면 각 런이 더 다양해짐. `RewardTable` 보상 연출에 "버리기" 버튼과 씨앗 보상 추가 가능
- **고정 장소 성장 시각화** — Inscryption의 오두막 오브젝트 변화 참고: 런을 거듭할수록 농장 화분 개수나 온실 식물이 조금씩 늘어나는 시각적 메타 성장. `MetaProgress.fragmentsEarned` 기준으로 화분 수를 조절하는 방식 — `GreenhouseScreen` 화분 개수를 단계별로 증가

## 전투·협동 (04_Combat)

- **소모품 "의도적 소진" 보너스** — Panzer Paladin의 무기 부수기 주문 참고: 가방 소모품을 현재 방에서 사용 시 추가 효과 (예: 씨앗 폭탄 → 방 클리어 보상 +1씨앗). 장비 `GearEffect` "소모품 사용 시 발동" 계열로 구현. 현재 `EffectTrigger`에 `ConsumableUsed` 트리거 추가 필요 여부 확인
- **패링 성공 시 무기 속성 흡수** — Panzer Paladin의 무기 수집 참고: 작물이 패링으로 적의 투사체를 막으면 그 투사체의 속성(불·얼음)을 다음 씨앗탄에 1발 부여. `Parry_Shield_System` + `Projectile.element` 필드로 구현 가능. 패링을 "소극적 방어" 에서 "능동적 자원 수집"으로 격상

## 아이템·세트 (05_Items)

- **세트 조합 힌트 — 시길 발견의 즐거움** — Inscryption의 시길 시너지 참고: 장비 설명에 "이 효과와 ○○가 같이 있으면..." 힌트 한 줄 추가. `GearItem.effectHint` 필드 (에디터에서만 보이는 설명용) → `Equipment_Effect_Runtime_Cache_System`의 툴팁에 연결. 조합을 직접 써주지 않고 추측하게 만드는 것이 핵심
- **"쓰다 버리는" 1회 강화 소모품** — Inscryption의 1회용 아이템 참고: "다음 할퀴기 무조건 치명타" 같이 한 번 쓰면 사라지는 소모품 계열 추가. 현재 가방 `ItemBag`에 `consumable` 타입이 있으므로 `ItemEffect.OneShot` 계열 추가. 보스 직전 비상구 역할

## 스토리·메타 (07_StoryMeta)

- **이야기 단계별 작은 규칙 추가** — Inscryption의 3막 구조 참고: `MetaProgress.Chapter` 2단계부터 등불이 켜지며 마을에 대사가 1개씩 추가됨. 3단계에서 말하는 책의 이름이 바뀌기 전까지 미묘한 말투 변화. 기술적으로는 `StoryLines.cs`의 대사 조건에 Chapter 체크 추가로 간단히 가능
- **런 실패 귀환 연출 1장면** — Inscryption 오두막 귀환 참고: 현재 구현 없는 "런 실패" 흐름에 짧은 연출 추가. 고양이가 쓰러진 채로 농장에 돌아와 말하는 책이 "어서 와" 한 마디. `GameOver` → `GreenhouseScreen` 전환 시 `Dialogue.Play` 1줄. `StoryLines.FailReturn` 함수 신설

## 기술 메모

- **런타임 절차적 2D 메시**: 현재 `RoomShape.Apply`가 이미 이 패턴을 사용 중. 버그가 생기면 외곽선 꼭짓점 순서(반시계)와 귀 잘라내기 최소 변 길이를 먼저 확인. `Collider2D.CreateMesh()`(Unity 6 신규)로 판정→그림 동기화 단순화 가능
- **Unity Cloud Diagnostics**: 베타 출시 전에 패키지 추가 + Services 활성화만 하면 무료 25건/일로 크래시 자동 수집 시작. 주요 맥락으로 `chapter`, `current_room`, `run_time_sec` 커스텀 키 5개 세팅 권장. IL2CPP 빌드 시 `.sym` 파일 업로드 잊지 말 것
