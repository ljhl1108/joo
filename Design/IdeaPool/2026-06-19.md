## 캐릭터 (01_Characters)

- **박자에 맞는 대시** — NecroDancer 참고: P1(고양이) 대시가 특정 리듬 타이밍에 발동되면 대시 쿨다운이 30% 감소. 달리기 SFX와 BGM 비트를 맞춰 구현 (AudioSource.time 활용)
- **양파의 상태이상 수확** — Status Effect 참고: 상태이상(독/화상) 걸린 적을 P1이 근접 처치 시 특별 드롭 보너스. 협동 시너지의 핵심 — "P2가 약화, P1이 마무리"
- **클래스별 상태이상 면역** — Streets of Rogue 참고: 런 업그레이드로 "화염 면역", "독 면역" 선택 가능. 업그레이드 선택의 전략적 깊이 추가 (현재 보스가 독 사용 → 독 면역 선택)

## 적 (02_Enemies)

- **비트 추적 적** — NecroDancer 참고: 특정 적이 일정 주기(ex. 2초마다)에만 이동함. 이동 패턴이 리듬처럼 예측 가능해서 초보자도 학습 가능한 적 설계
- **상태이상 전파 적** — Status Effect 참고: 주변 적에게 버프(강화)를 전파하는 "사제형 적". P2가 원거리로 먼저 처치해야 P1이 나머지를 처리 가능 → 우선 처치 순서 협의 필요
- **역할 분담 강제 적** — Streets of Rogue + NecroDancer 참고: 앞면은 근접 무적(방패), 뒷면은 원거리 무적. P2가 원거리로 뒤를 공격하는 동안 P1이 앞에서 어그로 유지 → 정확한 포지셔닝 협동 필요

## 맵 (03_Maps)

- **미니맵 방 색상 코드** — Minimap 참고: 방 유형을 미니맵 색상으로 직관적으로 표시. 일반(회색) / 보스(빨강) / 상점(노랑) / 보물(파랑) / 현재(초록). BindingOfIsaac 방식 차용
- **역할별 탐색 영역** — Streets of Rogue 참고: 일부 방은 "원거리 최적 지형"(긴 복도, 엄폐물 부재), 일부는 "근접 최적 지형"(밀집 공간). 방 구조 자체가 두 플레이어의 역할 교대를 유도
- **미니맵 발견 애니메이션** — Minimap 참고: 새 방 진입 시 미니맵에 방 아이콘이 scale 0→1로 팝인. 탐험의 쾌감 강조. DOTween으로 0.1초 튀어나오는 효과

## 전투 (04_Combat)

- **파리 → 상태이상 반사** — NecroDancer + Status Effect 참고: P2가 파리 성공 시 투사체를 반사하며, 원래 투사체에 붙어 있던 상태이상도 함께 반사. 예: 독 투사체 파리 → 적에게 독 반사. 구현: OnionShield.cs에서 파리 판정 시 projectile.onHitEffect를 적 StatusEffectHandler에 ApplyEffect()
- **상태이상 콤보 시너지** — Status Effect 참고: 두 상태이상 조합 시 특수 효과 발동. 예: 감속 + 화상 동시 = "용해" (데미지 2배). 협동 공격의 보상 구조 — P2 감속, P1 화상 → 폭발 데미지
- **리듬 공격 판정 강화** — NecroDancer 참고: P1의 근접 공격이 BGM 비트와 타이밍이 일치할 때(±0.1초) 크리티컬 판정. 사운드 피드백(타악기 강조)으로 타이밍 학습 가능. AudioSettings.dspTime으로 정밀 측정

## 스토리 (05_Story)

- **리듬과 세계관** — NecroDancer 참고: 던전에 흐르는 "마법 음악"이 모든 몬스터를 지배한다는 설정. OnionCat 세계관에서 악당이 "공포의 음악"으로 마을을 지배 → 고양이와 양파가 이를 끊기 위해 탑(던전)을 오른다는 서사
- **자유의 도시** — Streets of Rogue 참고: 던전 클리어 후 마을(허브)에 새 NPC가 추가되는 구조. 구해낸 NPC가 마을에 정착 → 상점 확장, 대화 추가. 런 후 서사적 보상
- **역할 교대 전설** — Streets of Rogue 클래스 다양성 참고: 과거 "온전한 고양이"와 "온전한 양파"가 싸웠던 전설 → 지금은 하나의 몸으로 공존해야 한다는 강제 협동의 세계관적 이유. P1/P2 협동을 서사로 정당화

## 기술 메모

- **상태이상 시스템**: 가장 먼저 구현할 것은 `StatusEffectData` ScriptableObject + `StatusEffectHandler` 컴포넌트. 투사체(OnionProjectile)에 `[SerializeField] StatusEffectData onHitEffect` 필드만 추가하면 기존 코드 변경 없이 상태이상 적용 가능. 감속 구현 시 `EnemyMovement.GetSpeedMultiplier()` 호출 패턴으로 기존 이동 코드와 분리.
- **미니맵 시스템**: 방 생성 완료 시점에 `MinimapManager.RegisterRoom()` 일괄 호출, 방 진입 이벤트에서 `RevealRoom()` + `SetCurrentRoom()` 호출로 연동. UI는 Canvas의 MinimapPanel → Mask → MinimapContainer 계층 구조. 방 아이콘 프리팹에 `MinimapRoomIcon` 컴포넌트 + 상태별 스프라이트를 Inspector에서 설정.
