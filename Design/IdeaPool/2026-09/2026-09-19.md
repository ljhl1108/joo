## 캐릭터 (01_Characters)

- **원소 친화 업그레이드 트리** — Wizard of Legend 2 참고: Cat은 불/번개 속성 슬래시 업그레이드, Crop은 물/얼음 속성 투사체 업그레이드로 분화. 런 중 같은 속성 아이템 2개 이상 획득 시 "속성 공명" 보너스 발동 (구현 힌트: ScriptableObject에 ElementType 필드 추가, UnlockManager에서 2개 이상 확인)

- **역할 시각화 — 포즈/색상으로 즉시 구분** — Nine Parchments 참고: Nine Parchments는 캐릭터 실루엣만 봐도 역할이 명확. Cat은 앞발이 날카롭고 공격적 포즈, Crop은 화분 위에서 아이를 내밀듯 조준하는 포즈. 색상: Cat = 주황/붉은 따뜻한 팔레트, Crop = 파란/초록 차가운 팔레트 (구현 힌트: 캐릭터별 ColorPalette ScriptableObject, Runtime Palette Swap 적용)

- **피격 무적 시각 표현** — 애니메이션 인터럽트 리서치 참고: Cat의 대시 무적 기간(iFrame)을 시각적으로 표현. 대시 중 Cat 스프라이트가 반투명하게 깜빡이거나 잔상 효과 발생. Crop은 Cat 등에 있으므로 같이 깜빡임. (구현 힌트: SpriteRenderer.color.a를 대시 레이어 Weight와 연동, 0.15초 간격으로 깜빡)

## 적 (02_Enemies)

- **원소 반응 약점 적** — Wizard of Legend 2 + Nine Parchments 참고: 특정 적은 Cat 근접 슬래시로 "출혈" 상태이상 → Crop 물 투사체가 맞으면 "감전+출혈" 배율 피해 발생. 약점 반응 시 적 위에 반응 아이콘(⚡+💧) 팝업. (구현 힌트: Enemy에 StatusEffectList 유지, Hit 시 두 가지 StatusEffect 보유 여부 체크)

- **애니메이션 인터럽트 불가 적** — 애니메이션 시스템 참고: 일부 중간 보스급 적은 공격 모션 중 슈퍼아머(SuperArmor) 상태 — 경직이 없고 애니메이션이 캔슬되지 않음. Cat 혼자 근접 공격이 통하지 않아 Crop 투사체로 "슈퍼아머 파괴" 게이지를 먼저 깎아야 경직 가능. (구현 힌트: Enemy에 superArmorGauge 추가, Crop 투사체 히트 시 게이지 감소, 0이 되면 Stagger 상태로 전환)

- **이중 약점 유도 적** — Nine Parchments 참고: Nine Parchments의 원소 조합처럼, 특정 적은 첫 번째 공격 타입으로 "디버프" → 두 번째 타입으로 "폭발"하는 2단계 약점 설계. 예: 얼음 결정 적 — Crop 물 투사체로 "얼음 균열" 상태 → Cat 슬래시로 "파쇄" (배율 피해 + 범위 파편). (구현 힌트: EnemyStateFlag에 "IceCracked" 플래그, Cat 근접 히트 시 플래그 체크 후 분기)

## 맵 (03_Maps)

- **원소 테마 방** — Wizard of Legend 2 참고: 방마다 원소 테마 설정 가능. 불 방: 바닥에 화염 함정, 적들이 화염 속성 강화. 물 방: 바닥에 웅덩이 슬로우, Crop 투사체 사거리 증가 보너스. 방 테마는 현재 런의 원소 조합과 시너지 → 빌드 방향성 강화. (구현 힌트: RoomData ScriptableObject에 ElementTheme 필드, 방 진입 시 적 속성 오버라이드)

- **잠금해제된 방 유형 표시** — 잠금해제 연출 시스템 참고: 메타 진행으로 새 방 유형(보스 방, 상점 방, 비밀 방) 해제 시 런 결과 화면에서 "새 방 잠금해제!" 연출. 다음 런 시작 화면 미니맵 미리보기에 새 방 아이콘 강조. (구현 힌트: RoomType ScriptableObject에 unlockId 연동, UnlockManager 체크)

- **공간 기억 보상** — Nine Parchments 참고: Nine Parchments는 맵이 고정이라 공간을 외우는 것이 중요했음. OnionCat은 절차적이지만, 클리어된 방 구조를 런 중 미니맵에 기록 → 같은 방 유형을 나중에 만나면 "전에 봤던 방!" 힌트 표시. (구현 힌트: RoomTemplate ID를 런 히스토리에 저장, 미니맵에 아이콘으로 구분)

## 전투 (04_Combat)

- **연속 콤보 인터럽트 규칙** — 애니메이션 인터럽트 시스템 참고: Cat의 3단 슬래시 콤보에서 1·2타는 캔슬 가능(Interrupt Source = Current State), 3타는 캔슬 불가(Has Exit Time = true). 단, 3타 중에도 사망/경직은 최우선 인터럽트. 이 설계로 3타 마지막에 쫄병 사이에 갇히는 위험 발생 → 의도적 긴장감. (구현 힌트: AnimationEvent로 OnAttackCancellable() / OnAttackNoCancelStart() 타이밍 표시)

- **원소 콤보 발동 시각화** — Wizard of Legend 2 + Nine Parchments 참고: Cat + Crop 원소 시너지 발동 시 화면 중앙 상단에 0.8초간 콤보 아이콘 + 이름 팝업. 예: "물+근접 → 진흙 폭탄!" 텍스트 + 슬로우 이펙트 파티클. 첫 런에서 처음 발동하면 튜토리얼 팝업으로 시스템 설명. (구현 힌트: ComboPair ScriptableObject 배열, Hit 시 P1+P2 최근 히트 타입 체크 → 매칭 시 Combo 이벤트)

- **방패 패리 창 시각화** — Nine Parchments 원소 타이밍 참고: Crop의 방패 패리 타이밍 창을 시각적으로 명확히 표시. 방패를 드는 순간 0.2초간 방패 주변에 흰색 반짝임 → 이 구간에 맞으면 패리. 타이밍 놓치면 그냥 블록. 성공 패리 시 큰 반짝임 + 히트스톱 0.15초. (구현 힌트: ParryAbility에 parryWindowDuration 필드, 코루틴으로 창 관리, VFX는 ParryWindowVFX 오브젝트 On/Off)

## 스토리 (05_Story)

- **마법 학교 탈출 모티브 변용** — Nine Parchments 참고: Nine Parchments의 "수업 빼먹은 마법사 학생들" 컨셉처럼, OnionCat도 "농장에서 탈출한 고양이가 화분 속 작물을 지키며 던전에서 탈출" 서사 강화. 각 보스 처치 후 짧은 1컷 만화 스타일 컷씬으로 Cat과 Crop의 관계 발전. (구현 힌트: 보스 처치 후 Ingame_Cutscene_System 활용, 최대 3컷 정지화면 + 대사 버블)

- **잠금해제 스토리 조각** — 잠금해제 연출 시스템 참고: 영구 잠금해제 연출에서 새 캐릭터/아이템 해제 시 "이 아이템의 출처" 한 줄 설명 추가. 예: "잡초씨 투사체 — 옛날 농장 정원에서 가져온 씨앗. Cat이 몰래 챙겼다." → 세계관 떡밥을 잠금해제 연출에 녹임. (구현 힌트: UnlockCondition ScriptableObject에 loreText 필드 추가)

- **협동으로만 해금되는 스토리** — Wizard of Legend 2 협동 시너지 참고: 특정 스토리 컷씬은 두 플레이어가 동시에 특정 콤보 공격을 성공시킬 때 해금. 예: 보스전에서 Cat+Crop 원소 콤보 3회 성공 → "진짜 파트너" 엔딩 분기. 이를 통해 싱글 플레이와 듀오 플레이의 스토리 경험 차별화. (구현 힌트: RunStats에 coPairComboCount 추적, 엔딩 조건 평가 시 체크)

## 기술 메모

- **Animation Interrupt Priority**: Unity Animator에서 AnyState → Death/Hit 트랜지션에 `Interrupt Source = Current State`, `Has Exit Time = false` 설정이 핵심. 대시 무적 중 Hit를 막으려면 코드에서 `if (dashAbility.IsInvincible) return;`으로 트리거 전송 자체를 차단하는 방법이 Animator 설정만으로 하는 것보다 신뢰성 높음.

- **Unlock Reward Ceremony**: `UnlockManager.CheckNewUnlocks()`를 `RunResultScreen.Start()`에서 호출해 런 종료 직후 감지. 연출 중 씬 전환 버튼 비활성화 필수. UniTask 없으면 코루틴으로 구현 가능하나, 여러 잠금해제가 큐로 쌓이는 경우 코루틴 체이닝이 복잡해지므로 UniTask `async/await` 도입을 초기부터 고려할 것.
