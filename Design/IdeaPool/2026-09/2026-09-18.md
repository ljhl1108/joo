## 캐릭터 (01_Characters)

- **무기 체인 어시스트** — Bloodroots "무기 연속 사용" 참고: Cat이 근접 슬래시로 소품을 날리면, 날아가는 소품이 임시 투사체가 되어 Crop이 "공중 소품 터치"로 2차 공격 가능. 두 플레이어가 오브젝트를 연달아 다루는 짧은 체인 협력. 구현 힌트: `ProjectileWithPickup` 태그, Crop의 AttackRange 내 통과 시 `OnChainHit()` 발동
- **즉사 회피 상호 경고** — Bloodroots의 즉사 설계 참고: 특수 적(빨간 아우라)은 Cat이 닿으면 즉시 HP 절반 감소. Crop이 먼저 원거리로 아우라를 지워줘야 Cat이 안전 접근 가능. "내가 먼저 갈게" 신호 역할. 구현: `DangerAura` 컴포넌트 → Crop 원거리 피격 시 `ClearAura()`, Cat 접촉 시 `OnInstantPenalty()`
- **Crop 원거리 = 환경 기폭제** — Bloodroots 오브젝트 활성화 참고: Crop 투사체가 씬에 있는 폭발 통을 맞추면 폭발 발생 → Cat 이동 경로를 폭발로 정리. Crop이 먼저 시야 확보 후 Cat이 진입하는 공간 분업. 구현: `ExplosiveBarrel.OnHit()` → `AreaExplosion(radius, damage)`, LayerMask에 Enemy만 포함

## 적 (02_Enemies)

- **1회용 방패 적** — Bloodroots "무기 한 번 쓰면 파괴" 원칙 참고: 이 적은 거대 방패를 들고 있어 정면에서 근접/원거리 모두 막음. 단, Cat의 돌진 대시가 방패를 깨면 그 후 3초간 완전 취약. "방패 파괴 → Crop이 폭딜"의 역할 분업. 구현: `ShieldEnemy`의 `OnDashCollision()` → `BreakShield()`, 파괴 후 `vulnerableTimer = 3f`
- **오브젝트 소환 적** — Bloodroots 환경 무기 참고: 적이 주변 소품(통나무, 화분)을 집어 Cat에게 던짐. Crop이 원거리로 날아오는 소품을 격추해 막아야 Cat이 안전. 소품 격추 시 폭발 파편으로 되려 다른 적에게 피해. 구현: `ObjectThrowAI` → `ThrowPickup(target)`, Crop이 투사체 충돌 시 `DeflectPickup()`
- **무기 흡수 적** — Bloodroots "특수 무기 연출" 참고: 이 적은 Cat의 슬래시를 흡수해 일시적으로 이동 능력을 얻음 (Cat처럼 빠르게 이동). Crop이 얼리거나 슬로우를 걸어 기동력을 제거한 후 Cat이 재공격. "Crop이 디버프 → Cat이 딜" 순서 강제. 구현: `AbsorbSlashAI` → `AbsorbHit()` 후 `SpeedMultiplier *= 2`, Crop의 슬로우 투사체(`StatusEffect.Slow`) 피격 시 `CancelAbsorb()`

## 맵 (03_Maps)

- **소품 무기 퍼즐 방** — Bloodroots 레벨 = 무기 퍼즐 참고: 방에 이동 불가 장애물이 많고, 폭발 통과 Cat 슬래시 소품이 전략적으로 배치. Cat이 소품으로 길을 열고 Crop이 원거리로 적을 유인 분산. 두 플레이어가 협력해야 효율적인 클리어 가능. 구현: Room에 `PuzzleElement` 컴포넌트 배치, 각 요소는 `RequiresPlayerType(Melee/Ranged)` 속성
- **Addressables 기반 층 테마 방** — Addressables 시스템 참고: Floor1=이끼 던전(초록 팔레트), Floor2=결정 동굴(파랑), Floor3=화염 신전(주황). 각 층 진입 시 해당 층 방 프리팹 라벨(`Floor1Rooms`, `Floor2Rooms`) 로드 → 이전 층 언로드. 씬 전환이 매끄럽고 메모리 효율적. 구현: `FloorManager.OnFloorChanged()` → `Addressables.LoadResourceLocationsAsync(floorLabel)`
- **빠른 재진입 방** — Bloodroots 즉시 재시작 참고: 특정 방에 "리트라이 게이트" 설치. 해당 방 진입 후 30초 내 클리어 실패 시 HP 패널티 없이 방 입구에서 재시작. 초보자 친화적이면서 고수는 "완벽 클리어" 도전 가능. 구현: `RoomClearTimer` 30초 → 초과 시 `RespawnAtDoor(HPpenalty: 0)`

## 전투 (04_Combat)

- **소품 던지기 Cat 어빌리티** — Bloodroots "집어 들어 던지기" 참고: Cat이 주변 소품(Props 레이어)을 집어 들고 던지는 특수 능력. 소품마다 던진 후 다른 효과: 화분=독 구름, 폭발통=범위 폭발, 통나무=관통 데미지. Crop과 "던질 방향 지정 + 기폭" 협력 가능. 구현: `Cat.ThrowAction()` → 가장 가까운 `Props` 레이어 오브젝트 탐색 → `PropThrowable.Throw(direction)`
- **Addressables 업그레이드 선택** — Addressables 시스템 참고: 업그레이드 아이템 ScriptableObject를 Addressables로 관리, 선택 화면 오픈 시 랜덤 5개만 비동기 로드. 미선택 아이템은 즉시 Release → 불필요한 메모리 점유 없음. 구현: `UpgradeSelectScreen.Open()` → `Addressables.LoadAssetAsync<UpgradeItemData>(randomKeys[0..4])`
- **체인 격파 피드백** — Bloodroots 콤보 느낌 참고: Cat→Crop 연속 공격으로 적을 처치 시(0.5초 이내) "CHAIN!" 화면 텍스트 + 골드 1.5배 드롭. 두 플레이어 협력 = 즉각적인 보상 피드백. 구현: `CombatEventBus.OnKill()` → 직전 0.5초 이내 양쪽 히트 있으면 `ChainKillBonus()`, DOTween으로 "CHAIN!" 텍스트 펀치 스케일

## 스토리 (05_Story)

- **소품에 얽힌 기억** — Bloodroots 환경 서사 참고: 각 방에 있는 소품(낡은 화분, 깨진 씨앗 용기)이 터치 시 짧은 대사 표시. "이 씨앗을 심던 날 기억해." Cat/Crop의 과거 공동 기억을 소품으로 파편적으로 전달. 구현: `PropMemory` 컴포넌트, Crop의 원거리 투사체 충돌 시 `ShowMemoryPopup(dialogueKey)`
- **Gold Master 기념 엔딩** — 출시 체크리스트 참고: 클리어 화면 후 크레딧 마지막에 "개발 기록" 짧은 컷씬. Cat과 Crop이 화분을 다시 심는 장면 + 실제 개발 기간/커밋 수를 픽셀 텍스트로 표시. "우리가 완성했어" 의미. 구현: 크레딧 끝에 `TimelineAsset` 컷씬 1개, `GitInfo.CommitCount` 런타임 조회
- **즉사 설계 세계관** — Bloodroots 즉사 참고: OnionCat 세계관에서 Cat이 치명상을 입으면 Crop(화분)이 치유 물을 뿌려 부활. 이 설정으로 "우리는 함께여서 살아남는다"는 테마를 게임플레이 메카닉과 연결. 부활 모션 + 짧은 감탄사("괜찮아!")가 매 런마다 감정선 형성

## 기술 메모

- **Unity Addressables**: 초기 프로젝트에서 `Resources` 폴더 쓰지 말고 처음부터 Addressables로 에셋 관리 시작 권장. 나중에 마이그레이션하면 참조 깨짐 리스크 있음. `AssetReference` 필드 + `InstantiateAsync` 패턴이 OnionCat 방 로딩에 가장 적합. **Floor별 라벨 분리**는 메모리 관리의 핵심 — 구현 우선순위: 방 프리팹 > 적 프리팹 > 업그레이드 아이템.

- **Gold Master Launch Checklist**: "게임오버 → 재시작 → 메인 메뉴" 흐름과 "최초 실행 (세이브 없음)" 시나리오를 **스프린트 마다 1회 직접 통과 테스트**하는 습관이 출시 전 파국 방지의 핵심. Debug 치트 격리(`#if UNITY_EDITOR || DEVELOPMENT_BUILD`)는 코드 작성 시점부터 적용할 것 — 출시 직전에 하면 놓치기 쉬움.
