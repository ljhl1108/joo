## 캐릭터 (01_Characters)

- **속성 공명 업그레이드** — Chronicon 세트 보너스 참고: Cat과 Crop이 같은 "속성" 계열 업그레이드를 각각 하나씩 가져가면 "공명" 보너스 발동. 예: Cat이 "화염 슬래시"를, Crop이 "화염 탄환"을 획득하면 모든 화염 피해 +30% (구현 힌트: 업그레이드 SO에 `ElementTag` 필드 추가, 런 종료 시 `GameManager.Run`에서 태그 집계)

- **Cat 전담 캐릭터 강화 분기** — Monster Train 챔피언 업그레이드 참고: 매 Floor 클리어 시 Cat에게 성장 분기 선택지 1개 (예: "슬래시 쿨타임 20% 감소" / "대쉬 무적 시간 +0.2초" / "슬래시 후 다음 투사체 속도 +50%"). Crop도 동일하게 별도 분기 선택. 두 플레이어가 각자 고유한 결정을 내리는 협동감 강화 (구현 힌트: `UpgradeSelectionUI`를 2개로 분리해 Cat 전용 풀 / Crop 전용 풀 드로우)

- **Crop의 식물 파워 티어** — Chronicon 아이템 등급 체계 참고: Crop의 씨앗 투사체가 런 중 "씨앗 → 새싹 → 꽃 → 열매" 4단계로 티어업 가능. 각 티어에서 시각적 변화 + 능력 강화. 첫 씨앗은 단순 직선 투사체, 열매 단계에서는 폭발 또는 다중 분열 (구현 힌트: `ProjectileStats`에 `tier` 필드, 티어업 이벤트 발생 시 이펙트 교체 + 스탯 보정치 변경)

## 적 (02_Enemies)

- **돌진 예고 슬라임 (근접 전용)** — Enemy Pattern Composition System 참고: `TelegraphAction` (0.4초 빨간 선 표시) → `MoveTowardPlayerAction` (고속 돌진 0.3초) → `MeleeHitCheckAction` (반경 0.5) → `WaitAction` (회복 0.5초) 조합. 예고 선을 보고 옆으로 빠지는 "읽기 → 회피" 루프가 핵심. 근접 면역이므로 Cat 슬래시에만 피해를 입음 (구현 힌트: `EnemyController.resistance = ImmuneToRanged`)

- **꽃잎 세례 꽃 (원거리 전용)** — Enemy Pattern Composition System 참고: 제자리에서 5방향 씨앗을 360° 로테이션하며 발사. `ShootProjectileAction(count=5, spreadAngle=60)` + `RotateByAction(30deg)` + `WaitAction(0.5s)` 무한 반복. 투사체 면역이라 Cat이 슬래시로만 처치해야 함 → Cat이 근접해야 하므로 Crop이 투사체를 파괴/블록하며 Cat의 진입을 엄호하는 협동 시나리오 강제 (구현 힌트: `resistance = ImmuneToMelee`, 단 꽃 투사체는 Crop 실드로 패리 가능)

- **HP 임계값 패턴 전환 보스** — Monster Train 페이즈 설계 참고: HP 100%→50% 구간에는 근접 패턴만 사용 (Cat이 위협), HP 50% 미만부터 원거리+근접 혼합 패턴으로 전환하며 Crop도 바빠짐. 두 플레이어가 1페이즈는 Cat 중심, 2페이즈는 Crop 중심으로 역할이 자연스럽게 바뀜 (구현 힌트: `EnemyController.OnHealthChanged` → HP < 50% 시 `ExecutePattern(1)` 호출)

## 맵 (03_Maps)

- **Floor-기반 층 구조 맵** — Monster Train 참고: 방을 "층(Floor)"으로 묶어 표시. Floor 1(안전: 전투 2개), Floor 2(선택 분기: 상점/이벤트/보너스 전투 중 택1), Floor 3(엘리트), Floor 4(보스). 40분 런 목표 시 Floor 4개 × 방 3~4개 = 총 12~16개 방이 적절 (구현 힌트: `DungeonGenerator`에 `floorConfigs` 배열, 각 Floor에 `roomPool` 지정)

- **분기 노드 선택 화면** — Monster Train 노드 맵 참고: 엘리트 방 이전에 "전투(검 아이콘) / 상점(금화 아이콘) / 이벤트(물음표 아이콘)" 세 방 중 1개 선택 UI. 두 플레이어가 화면을 보며 합의하는 사회적 순간 → 협동감 강화. 이 선택도 협동 게임의 "공동 결정" 재미를 만듦 (구현 힌트: `InRun_Branch_Map_System` 참조, 선택지는 `RoomType` SO 3개 드로우)

- **속성 테마 방 (Floor별 비주얼 구분)** — Chronicon 던전 층 참고: Floor 1 = 풀밭(초록), Floor 2 = 석굴(회색), Floor 3 = 화염(주황), Floor 4 = 보스 아레나(어두운 배경). Tilemap Rule Tile을 Floor별로 교체. 단 PPU 32 통일, 각 Floor 타일셋 크기 32px (구현 힌트: `RoomPrefab`에 `FloorTheme` enum 필드, 방 생성 시 해당 타일맵 팔레트 활성화)

## 전투 (04_Combat)

- **IMMUNE 텍스트 팝업** — Enemy Pattern Composition System 면역 시스템 참고: 면역 적에게 엉뚱한 공격을 했을 때 노란색 "IMMUNE!" 팝업 텍스트 표시 + 맞힌 적 몸에 회색 플래시. 3~4번 반복하면 플레이어가 자연스럽게 역할 분담을 배움. 튜토리얼 문구보다 강력한 학습 피드백 (구현 힌트: `FloatingTextManager.Show("IMMUNE!", pos, Color.yellow)`, `DamageSystem.ApplyDamage`에서 `IsImmuneTo` 체크 후 분기)

- **패리 타이밍 연동 연속 공격** — Enemy Pattern Composition System 전조 예고 참고: 적의 `TelegraphAction` 중 Crop이 실드 패리에 성공하면 Cat의 슬래시 쿨타임이 즉시 리셋되는 "파트너 시너지" 발동. 두 플레이어가 타이밍을 맞추면 강해지는 협동 강화 루프 (구현 힌트: `ParrySuccessEvent` 발생 시 `PlayerMelee.ResetCooldown()` 호출, GameManager.OnStateChanged 구독 패턴 활용)

- **2인 동시 궁극기 (합체기)** — Monster Train 클랜 시너지 참고: Cat과 Crop이 각자 "게이지"를 채우면 합체 버튼(두 플레이어 동시 입력)으로 "붉은 비 투사체 + 슬래시 난무" 연출 발동. 2명이 동시 버튼을 눌러야 하므로 소통 없이는 발동 불가 → 오프라인 코옵의 고함치는 순간 창출 (구현 힌트: `PlayerInputManager`에서 양쪽 `UltimateInput` 동시 입력 감지, 0.2초 허용 창)

## 스토리 (05_Story)

- **기차로 이동하는 세계관** — Monster Train 구조 직접 차용 아이디어: "OnionCat이 채소 왕국을 침략하는 육식 군단을 막기 위해 기관차를 타고 최전선으로 이동"하는 설정. 방이 기차 칸으로 표현되고, Floor 클리어 시 기관차가 조금씩 앞으로 달리는 연출. 진행감과 긴장감을 공간으로 표현 (구현 힌트: 씬 전환 시 기차 애니메이션 cutscene, `SceneTransition` 활용)

- **Chronicon식 "인류 최후의 역사가"** — Chronicon의 세계관 설정 참고: 게임 시작 시 "OnionCat은 채소 왕국의 마지막 기록자"라는 내레이션. 런마다 Cat이 발견한 아이템 이름에 짧은 플레이버 텍스트 추가 (예: "낡은 씨앗 — '아무도 이 씨앗이 어디서 왔는지 모른다'"). Chronicon처럼 텍스트 기반 세계관 구축, 아트 코스트 0 (구현 힌트: `UpgradeSO`에 `flavorText` 필드, 획득 팝업에 작은 글씨로 표시)

- **런 결과 = 기록 한 페이지** — 런 종료 화면을 "한 장의 페이지"처럼 디자인: 처치한 적 이름, 획득한 업그레이드, 생존 시간이 마치 일지처럼 적힌 텍스처. "Cat과 Crop은 오늘도 기록을 남겼다"는 마무리 문구로 죽음도 내러티브로 전환 (구현 힌트: `Run_Result_Screen` 커스텀 레이아웃, 배경에 양피지 texture overlay 적용)

## 기술 메모

- **Enemy Pattern Composition System**: 오늘 배운 것 중 바로 적용할 핵심 → `EnemyActionSO` 추상 클래스 + `AttackPatternSO` 시퀀스 구조로 모든 적을 데이터 주도(Inspector)로 설계할 수 있다. 새 적을 추가할 때 코드 수정 없이 SO 에셋 조합만으로 가능. 특히 `ImmuneToMelee` / `ImmuneToRanged` 플래그와 "IMMUNE!" 팝업 조합이 OnionCat의 핵심 피아 구분 메커니즘을 직관적으로 가르쳐줌.

- **Itch.io Release Preparation**: 첫 배포 시 주의할 점 → WebGL 빌드에서 마우스 우클릭(Crop 실드)이 브라우저 contextmenu 이벤트와 충돌하는 문제를 반드시 사전 테스트할 것. 해결책은 itch.io의 WebGL 임베드 설정에서 "Mouse lock" 활성화. 구현 순서: Windows 빌드로 먼저 로컬 검증 → WebGL 빌드 별도 테스트 → itch.io "Restricted" 공개 → 소규모 피드백 수집 → "Public" 전환.
