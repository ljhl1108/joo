## 캐릭터 (01_Characters)

- **Cat 슬래시 모션 진화** — Animator Override Controller 참고: 업그레이드 획득 시 `AnimatorOverrideController`로 슬래시 클립 교체. 기본: 짧고 빠른 45도 모션 → 업그레이드: 크고 느린 180도 아크 모션. 같은 상태머신, 다른 느낌. `UpgradeItem SO`에 `AnimatorOverrideController overrideController` 필드 추가
- **Crop의 역할 정체성 강조** — Nightreign Nightfarer 참고: Crop은 단순 "보조"가 아닌 "포병 역할(Ironeye)" 같은 명확한 클래스 정체성 부여. 보스전에서 "지금 Crop 화력 집중 구간"이 명확히 존재해야 두 플레이어 모두 주인공감
- **Balatro LocalThunk 교훈** — Balatro 1인 개발 참고: Cat(근접) + Crop(원거리)이라는 핵심 2가지를 먼저 완벽하게 만들고 확장. 초보 개발자로서 기능 추가보다 **기존 핵심의 느낌 극대화**가 우선

## 적 (02_Enemies)

- **보스 패널티 조건 적** — Balatro Boss Blind 참고: 일부 보스방에 "이 방에서는 Cat 대시 불가" 또는 "Crop 투사체가 적 방향으로만 발사 가능" 같은 추가 제약 공지. 방 진입 전 텍스트로 명확히 안내 후 전투 시작 → 불공평감 없음
- **서클 수축 에리어 보스** — Nightreign Encroachment 참고: 특정 보스가 "독 구역"을 점차 확장. Cat과 Crop이 같은 작은 안전 구역 안에 있어야 함 → 물리적 협력 강제. 보스가 독 구역을 활용한 몰아넣기 패턴 사용
- **Joker형 복합 능력 미니보스** — Balatro Joker 조합 참고: 미니보스가 "패시브 능력 2~3개 조합"으로 행동. 예: "근접 피해 반사(Cat 위험) + 원거리 흡수(Crop 위험)" → 둘 다 평소 방식이 통하지 않아 전략 전환 필요

## 맵 (03_Maps)

- **Night 1/2/3 층 구조 채택** — Nightreign 3 Nights 참고: 던전을 3개의 층(Night)으로 구분. Night 1: 소형 적 + 아이템 수집, Night 2: 중형 적 + 시너지 확정, Night 3: 보스. 각 Night는 독립된 맵 세트로 구성
- **Coming Soon 페이지용 방 스크린샷** — Steam 스토어 참고: 현재 구현된 방 중 가장 볼거리 있는 장면 5장을 스크린샷으로 캡처. 미완성이어도 게임플레이 느낌 전달이 목표 → 최우선 폴리싱 대상 방을 먼저 선정
- **탐험방/전투방 리듬 명시화** — Nightreign 낮/밤 구조 참고: 방 타입을 "자유방(Free)" 과 "전투방(Combat)"으로 명확히 분리. 자유방: 이동·탐험·아이템, 전투방: 문이 잠기고 웨이브 클리어 필요. 두 타입이 교차 배치되어 리듬 형성

## 전투 (04_Combat)

- **아이템 시너지 쌍 시스템** — Balatro Joker 조합 참고: 아이템 A(Cat 전용)와 아이템 B(Crop 전용)를 동시에 보유하면 "시너지 텍스트"가 HUD에 표시되고 특수 효과 발동. 예: "Cat의 대시 직후 → Crop의 다음 탄 2배 데미지". 아이템 설명에 시너지 가능 파트너 명시
- **전투 리듬 Ante 스케일링** — Balatro Ante 난이도 참고: 층 1(Ante 1~2): 적 HP·속도 보통, 층 2(Ante 3~5): HP +50%, 속도 +20%, 층 3(Ante 6~8): HP ×2, 특수 패턴 추가. 기하급수적 강화이므로 플레이어 빌드도 그에 맞게 강해져야 함 → 업그레이드 파워를 역산하여 설계
- **부활 협력 미니게임** — Nightreign Revival 참고: 한 플레이어가 쓰러지면 상대가 "부활 오브젝트" 위치로 이동해 3초 유지해야 부활. 부활 시도 중 쓰러진 플레이어가 주변 소형 적을 막아주는 시스템 → 부활 중에도 두 플레이어 모두 역할 있음

## 스토리 (05_Story)

- **Steam Coming Soon 페이지 스토리 카피** — Steam 스토어 참고: Short Description 300자에 "고양이는 달리고, 양파는 쏜다. 단, 둘은 한 몸" 같은 한 줄 훅을 먼저 완성. 스토리 완성 전에도 세계관 분위기를 전달하는 카피라이팅 우선 작업
- **Nightreign 세계관 편입 방식** — Nightreign 참고: 기존 세계관(Elden Ring)의 번외 이야기로 구성해 기존 팬을 흡수하면서도 신규 유저도 즐길 수 있게 설계. OnionCat도 짧은 배경 설정(고양이가 왜 화분을 들고 다니는가)만 확립하면 스토리 없이도 캐릭터에 애착 생김
- **클리어 후 Remembrance 연출** — Nightreign 영구 해금 참고: 보스 처치 후 "기억 조각(플래시백)" 단막 픽셀 컷씬 1장. Cat과 Crop의 과거 혹은 적의 사연. 텍스트 최소, 그림 1장으로 감정 전달 → 리소스 부담 없이 스토리 누적

## 기술 메모

- **Animator Override Controller**: `AnimatorOverrideController` 에셋 생성 후 기준 Controller 연결, 교체할 클립만 슬롯에 할당. 런타임 전환은 `animator.runtimeAnimatorController = overrideController` 한 줄로 처리. **런 재시작 시 `Start()`에서 기본 Controller로 반드시 초기화** — 퍼머데스 게임에서 이전 런 상태 잔류 버그 방지. `new AnimatorOverrideController()` 호출은 런 시작 시 1회만.
- **Steam 스토어 페이지**: 지금 당장 Steam Direct $100 결제 → App ID 획득 → Coming Soon 페이지 등록 가능. 스크린샷 5장(실제 플레이 화면)과 짧은 설명만 있으면 충분. Wishlist 1,000개가 Early Access 진입 신호 — 개발 중에 마케팅 시작이 정답. 출시 2주 전 Steam이 Wishlist 보유자에게 이메일을 자동 발송하므로, 페이지 등록 시점이 빠를수록 유리.
