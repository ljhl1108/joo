## 캐릭터 (01_Characters)

- **"취약 노출" 상태 연출** — HyperParasite 참고: 고양이가 스턴됐을 때 양파가 혼자 남는 0.5~1초 구간. 이 순간 양파의 방패가 자동으로 활성화되거나 고양이가 반짝이는 연출을 줘서 "위기 신호"를 명확히 전달. 구현 힌트: `OnStunBegin` 이벤트 → 양파 HUD에 빨간 테두리 + 방패 쿨다운 무시
- **고양이-양파 케미 연출** — HyperParasite의 "기생충↔숙주" 관계처럼 두 캐릭터가 서로를 의식하는 소소한 리액션 애니메이션. 예: 고양이가 대시할 때 양파가 화분 가장자리를 붙잡는 포즈 전환. 구현 힌트: 대시 `OnEnable` 시 Onion 오브젝트에 `grip_pose` 트리거
- **양파 성장 단계 스킨** — 런 진행에 따라 양파가 시각적으로 자라는 3단계 스프라이트 변화 (새싹→중간→완전히 자란 양파). 코스메틱이지만 "우리가 성장했다" 느낌을 줌. 구현 힌트: `RunData.roomsCleared` 기준 threshold로 Onion의 `SpriteRenderer.sprite` 교체

## 적 (02_Enemies)

- **"화분 타겟팅" 적** — HyperParasite에서 기생충을 숙주로부터 강제 분리하는 적처럼, OnionCat에서 화분을 향해 돌진하는 적 타입. 맞으면 고양이가 아니라 양파의 MP/쿨다운을 감소. 근접 고양이가 인터셉트해야 함 → 협력 강제. Encounter Budget 비용: 3포인트
- **"Melee-only 약점 + 빠른 이동" 슬라임 변종** — 원거리 공격에는 피가 안 깎이고 근접에만 약한 스피드 슬라임. 양파가 발사하면 화면에 "면역" 이펙트 표시. Encounter Budget 비용: 2포인트. 구현 힌트: `EnemyHealth.TakeDamage(WeaknessType)` 분기
- **"예산 오버" 엘리트 적** — 그 층 기본 예산보다 비싸지만 드물게 등장하는 예외 적. 이 적만 처치하면 추가 보상 드롭. 룸 생성 시 10% 확률로 예산×1.5를 소비하는 단일 엘리트로 대체. 구현 힌트: `RoomEncounterSpawner`에 `eliteChance` 필드 추가

## 맵 (03_Maps)

- **전환 효과로 층(Floor) 분위기 구분** — 1층→2층 이동 시 수평 스윕 + 컬러 팔레트 페이드로 다른 분위기 암시. 예: 1층=초록 숲 느낌, 2층=붉은 동굴 느낌. 셰이더 전환의 `_Tint` 파라미터로 다음 층 컬러를 미리 흘려보냄. 구현 힌트: Scene_Transition_Shader_Effects의 Full Screen Pass에 `_TintColor` 유니폼 추가
- **"조용한 룸" 배치 규칙** — Encounter Budget으로 빽빽한 전투 룸이 연속 3개 이상 오지 않도록 강제. 전투룸 3개 후 반드시 상점/이벤트/휴식룸 1개. 구현 힌트: `RoomManager`에 `consecutiveCombatCount` 카운터, 3 초과 시 다음 룸을 non-combat으로 고정
- **예산 힌트 UI** — 문 앞에 미리 빨간(위험)/노란(보통)/초록(쉬움) 색상 표시. Encounter Budget 비용에 따라 분류. HyperParasite처럼 방 진입 전 긴장감 조성. 구현 힌트: `DoorController.SetDifficulty(budget)` → 문 스프라이트 색상 오버라이드

## 전투 (04_Combat)

- **근/원거리 약점 강제 구성 보장** — Encounter Budget System의 "OnionCat 적용 포인트" 직접 구현: `spawner.SpawnEncounter()` 결과에서 Melee 약점 적이 없으면 가장 싼 Melee 약점 적 1마리를 강제로 리스트에 추가. 양파 플레이어가 "할 일 없는 룸"이 생기지 않도록 보장
- **전환 셰이더 연계 히트스톱** — 보스 처치 시 화이트아웃 플래시 0.1s + 히트스톱 0.15s + 아이리스 와이프 0.8s 순서로 연결. 각각 독립 코루틴으로 `yield return` 체이닝. 구현 힌트: `BossDeath → StartCoroutine(BossDeathSequence())`
- **예산 초과 보상** — 플레이어가 빠른 시간(예산 적에 비해 짧은 시간) 안에 룸을 클리어하면 추가 보상. "클리어 타임 < 기대 시간의 70%" 조건 달성 시 코인 보너스. 구현 힌트: `RoomManager`에서 `expectedClearTime = budget * 2.5f` 설정 후 실제 시간 비교

## 스토리 (05_Story)

- **"처음 만난 이유" 짧은 인트로** — HyperParasite처럼 기생 관계의 처음 설정을 짧게. "고양이가 화분을 업다가 양파가 말을 걸었다" 식의 5초짜리 인트로 컷신. 구현 힌트: `Ingame_Cutscene_System.md` 참고, RunData.isFirstRun 플래그로 최초 1회만 재생
- **적들의 "약점 감지" 반응** — 자신의 약점 공격에 맞으면 적이 울부짖는 특수 SFX + 부서지는 이펙트. "이 공격이 효과적이다"는 서사적 피드백. 구현 힌트: `EnemyHealth.TakeDamage()`에서 `isWeakness=true` 시 특수 이벤트 발동
- **화분 일지** — 런이 끝날 때마다 "오늘 처치한 적 수", "같이 살아남은 시간"을 짧은 한 줄로 요약해 메뉴 화면에 표시. HyperParasite의 "함께한 숙주들" 기록처럼 유대감 조성. 구현 힌트: RunData에 `killCount`, `survivalTime` 저장 → 런 결과 화면에 표시

## 기술 메모

- **Encounter Budget**: `EncounterPool` ScriptableObject + `GetRoomBudget(floor, roomIdx)` 함수 조합으로 구현 시작. 핵심은 Melee/Ranged 약점 적을 반드시 1마리씩 포함하는 보장 로직. OnionCat에서는 이것이 없으면 한 플레이어가 할 일이 없는 룸이 생긴다.
- **Scene Transition Shader**: 가장 빠른 시작은 UI Canvas 위 `RawImage` + 커스텀 머티리얼 방식 (Full Screen Pass보다 설정 쉬움). `Time.unscaledDeltaTime` 사용 필수 — 일시정지 상태에서도 전환이 재생되어야 한다. 픽셀아트 느낌 유지를 위해 노이즈 텍스처는 Point Filter 64×64 Bayer 패턴 사용.
