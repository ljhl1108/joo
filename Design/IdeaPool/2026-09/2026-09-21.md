## 캐릭터 (01_Characters)

- **Cat의 "탄막 흡수 대쉬"** — Nuclear Throne의 Crystal 방어막 참고: 대쉬 중 적 투사체에 닿으면 흡수해서 Onion의 탄약으로 전환. 두 플레이어가 협력할 이유를 물리적으로 묶는 메카닉. 구현 힌트: 대쉬 IFrame 동안 `Physics2D.OverlapCircle`로 ProjectileLayer 오브젝트 감지 → `PoolManager.Despawn` + `RunData.OnionAmmo++`
- **Onion의 "씨앗 은행" 자원 시스템** — Nuclear Throne의 탄약=전략자원 참고: 씨앗 최대 보유량을 낮게 설정(예: 30발)하고 특정 적 처치 시 씨앗 드롭. Cat이 적을 처치해야 Onion 탄약 보충 → 근거리/원거리 협력 구조 강화. 구현 힌트: `LootTable`에 씨앗 드롭 항목 추가, `PlayerStats.Current`의 MaxAmmo 스탯 연동
- **Onion의 "돋보기 조준" 집중 모드** — 우클릭 홀드 시 이동 속도 감소 대신 투사체 데미지 +50%, 투사체 속도 +30%. Spelunky의 "느리게 조준할수록 정확한 창 던지기" 참고. 구현 힌트: `PlayerInput`의 `AimHeld` 액션 → `PlayerStats.Modify(StatType.ProjectileDamageMultiplier, 1.5f)` 조건부 적용

## 적 (02_Enemies)

- **"갑옷 분리형" 슬라임** — Nuclear Throne의 탄색=위험도 표현 참고: 갑옷을 입은 슬라임은 근접 공격으로 갑옷을 먼저 깨야 원거리가 먹히는 2단계 적. Cat이 갑옷 파괴 → Onion이 본체 처치의 역할 분담 강요. 구현 힌트: `EnemyHealth` 컴포넌트에 `armorLayer` 추가, 갑옷 HP 0 시 스프라이트 교체 + Layer 변경
- **"예고 이동 적" 크로스보우맨** — Spelunky의 "반드시 피할 수 있는 공격" 원칙: 발사 2초 전 빨간 조준선 표시, 발사 후 관통탄. 플레이어가 직선을 피하기 위해 자연스럽게 움직임 유도. 구현 힌트: `LineRenderer`로 조준선 표현, `EnemyTelegraph` 시스템의 `warningDuration = 2f`
- **"데일리 챌린지 전용 엘리트"** — 씨드 기반 생성 참고: 당일 씨드에 따라 특수 엘리트 적이 일반 적 스폰 풀에 혼합. 매일 달라지는 조합으로 데일리 챌린지의 신선함 보장. 구현 힌트: `RunData.enemyRng`로 엘리트 출현 여부 결정, `EnemyEliteVariant` 시스템 연동

## 맵 (03_Maps)

- **"크리티컬 패스 보장 던전"** — Spelunky의 4×4 격자 + 경로 보장 참고: OnionCat 방 배치를 3×3 슬롯으로 구성하고 시작→출구 경로를 먼저 확보한 뒤 나머지 방 채우기. 초보자도 항상 클리어 가능한 구조 보장. 구현 힌트: `DungeonGenerator`에서 BFS/DFS로 크리티컬 패스 먼저 생성, 남은 슬롯에 선택적 방 배치
- **"씨드 공유 숨겨진 방"** — 특정 씨드에서만 나타나는 숨겨진 보물방 (패스워드 방 개념). 커뮤니티 공유로 "오늘 이 씨드 입력하면 OP 방 나와" 밈 생성. 구현 힌트: `if (seed % 1337 == 0)` 같은 특수 조건으로 희귀 방 삽입
- **"Spelunky식 카르마 방"** — 상점 오브젝트 파괴 시 이후 방에서 분노한 상인 적 추가 스폰. 행동-결과 피드백으로 세계가 살아있다는 느낌. 구현 힌트: `RunData`에 `karmaFlags` 딕셔너리 추가, 방 생성 시 플래그 체크하여 추가 스폰

## 전투 (04_Combat)

- **"리코셋 씨앗"** — Spelunky의 물리 튕김 참고: 특정 업그레이드 획득 시 씨앗 투사체가 벽에 1회 반사. 코너 공격 가능 → 전략 깊이 추가. 구현 힌트: `ProjectileRicochet` 컴포넌트, `Physics2D.Bounce` PhysicsMaterial로 반사각 계산, `remainingBounces` 카운터
- **"히트스톱 체감 강화"** — Nuclear Throne의 게임 감각 참고: 근접 처치(Cat 발톱)와 원거리 처치(Onion 씨앗) 히트스톱 시간을 다르게. 근접=0.12초, 원거리=0.06초. 근접이 더 "묵직한" 느낌. 구현 힌트: `HitstopSystem.Trigger(duration)` 호출 시 처치 수단에 따라 duration 분기
- **"쿱 연계 처치 보너스"** — Cat이 적을 스턴시키면 Onion의 다음 발사 데미지 +30% (또는 역할 반대). Nuclear Throne의 캐릭터 시너지 참고. 결과 화면에서 "Synergy Kills: X"로 표시. 구현 힌트: Cat 스턴 시 `RunData.result.synergyKillsActive = true` → Onion 발사 데미지 계수 한시적 상승

## 스토리 (05_Story)

- **"씨드가 곧 세계의 기억"** — 씨드 기반 생성 참고: 게임 내 세계관에서 "씨앗 코드"는 고양이가 같은 악몽을 다시 꾸는 주문. 메인 메뉴에서 씨드 입력 = "그날의 꿈으로 돌아가기" 내러티브. 구현 힌트: 씨드 입력 UI에 "Enter a Dream Code" 텍스트로 네이밍
- **"런 결과 화면 = 고양이의 일기"** — 런 결과를 숫자 통계가 아니라 고양이가 일기 쓰는 형식으로 표현: "Today I slashed 23 slimes. The Onion threw seeds 54 times." 구현 힌트: `RunResult`의 각 수치를 TMP_Text 템플릿 문자열에 삽입하는 방식
- **"Spelunky식 세계의 누적 기억"** — 런마다 특정 행동(특수 아이템 사용, 비밀방 발견)이 "세계 기억"에 누적되어 후속 런에 영향. 예: 3런 연속으로 보스 처치 시 보스가 새로운 대사 추가. 구현 힌트: `MetaProgression`에 `worldMemoryFlags` 저장, 보스 대사 선택 로직에서 플래그 체크

## 기술 메모

- **씨드 기반 생성**: `System.Random` 인스턴스를 `GameManager.Run.roomRng / enemyRng / lootRng`로 분리해서 관리하면 용도별로 독립된 무작위 스트림 확보. 현재 `Random.Range` 호출부터 하나씩 교체 시작하면 충분. 가장 먼저 교체할 곳: 방 배치 → 아이템 드롭 → 적 스폰 순.
- **쿱 런 결과 화면**: 초보자는 별도 씬 대신 **캔버스 오버레이**로 먼저 구현 권장. `GameManager.OnStateChanged`에서 `GameOver/Victory` 상태 감지 → 캔버스 `SetActive(true)`. 두 플레이어 중 어느 쪽 버튼 입력도 받으려면 `PlayerInput` 2개 모두 Retry 액션에 연결.
