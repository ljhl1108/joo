## 캐릭터 (01_Characters)

- **저주 형태 변신 (Curse Transformation)** — Curse of the Dead Gods 저주 시스템 참고: OnionCat에서 Cat이 5번 이상 피격당하면 "야성화(Feral Mode)" 발동 → 슬래시 범위 1.5배, 대신 이동속도 20% 감소, 스프라이트 눈이 붉게 변함. 위험한 상황에서 오히려 강해지는 역전 설계. 구현: `PlayerStatus.HitCount` >= 5일 때 `AbilityModifier` 이벤트로 슬래시 레인지 배율 적용.
- **런마다 달라지는 특성 (Trait) 시스템** — Rogue Legacy 2 특성 참고: 런 시작 시 Cat과 Onion이 각각 1개의 무작위 특성 부여. 예: "Cat - 거대화(크기 1.5배, 피격 판정 살짝 증가)", "Onion - 근시(조준 거리 -30%, 하지만 투사체 속도 +50%)". 단점이지만 플레이 스타일 다양화. 구현: `TraitScriptableObject[]` 배열에서 `Random.Range`로 2개 선택 후 `CharacterStatModifier` 적용.
- **히트스톱으로 역할 차별화** — Hitstop System 참고: P1(Cat) 슬래시 → 전역 히트스톱 0.06초(무게감 있는 근접), P2(Onion) 투사체 → 적 개별 히트스톱 0.03초(경쾌한 원거리). 같은 게임 안에서 두 캐릭터의 공격 '질감'이 뚜렷이 달라져 역할 차별화가 촉각적으로도 느껴짐.

## 적 (02_Enemies)

- **챔피언 변형 시스템 (Champion Modifier)** — Curse of the Dead Gods 챔피언 참고: 일반 적의 10% 확률로 "챔피언" 버전 생성. 예: "화염 저항(근접 타격 피해 50% 감소, 원거리에만 취약)", "넉백 반격(넉백 시 즉각 돌진)". 이 챔피언이 근접/원거리 취약 시스템을 더 복잡하게 만들어 협력 전술 깊이 증가. 구현: `EnemyModifierScriptableObject` 리스트에서 Spawn 시 랜덤 적용.
- **부패 게이지 적 (Corruption Enemy)** — Curse of the Dead Gods 부패 참고: 일부 적이 처치되지 않고 방에 오래 남아있으면 "부패 오라" 방출 → 접촉 시 Cat의 야성화 게이지 빠르게 상승. P1이 빨리 접근-처치(근접)하거나 P2가 원거리로 먼저 억제해야 하는 압박 상황 생성. 구현: `EnemyCorruptionAura.cs` 범위 내 플레이어에 `CorruptionManager.AddCorruption(float)` 호출.
- **세대 적응 적 (Legacy Enemy)** — Rogue Legacy 2 보스 학습 곡선 참고: 같은 적이 런 횟수가 늘어날 수록 패턴이 추가되는 "적응형 적". 1~5런: 기본 패턴, 6~10런: 돌진 추가, 11런+: 원거리 투사체 추가. MetaProgress.TotalRunCount 참조. 플레이어가 실제로 학습-숙달하는 경험 제공.

## 맵 (03_Maps)

- **어둠/빛 구역 방 (Dark/Light Zone Room)** — Curse of the Dead Gods 어둠 관리 참고: 일부 방에 어두운 구역과 밝은 구역이 공존. 어두운 구역에서는 근접 전용 적이 투명화(원거리 무효), 밝은 구역에서는 원거리 전용 적이 방어막 생성. P1이 어둠 속에서 슬래시, P2가 밝은 곳에서 투사체 — 자연스럽게 분리 포지셔닝 유발. 구현: 타일맵 레이어로 Light/Dark Zone 구분, 적 스폰 위치를 ZoneType에 따라 분기.
- **영구 업그레이드 허브 방 (Legacy Hub)** — Rogue Legacy 2 성 업그레이드 참고: 런 사이 메타 허브(화단/정원)에서 이전 런에서 모은 씨앗으로 "영구 체력 +5", "시작 능력 해금" 등 구매. 화분에 심을수록 정원이 시각적으로 풍성해짐 → 메타 진행을 시각적으로 보여주는 공간.
- **길 선택 방 (Path Selection Room)** — Rogue Legacy 2 바이옴 선택 참고: 매 층 클리어 후 2~3개 다음 방 선택지(문) 제시. 각 문에 아이콘으로 방 타입 힌트 표시(칼=전투, 씨앗=보상, 해골=보스). 전투 방 중에서도 "근접 위험" / "원거리 위험" 태그 표시 → 현재 빌드에 맞는 방 선택 전략.

## 전투 (04_Combat)

- **취약 타격 히트스톱 강화** — Hitstop System + Curse of the Dead Gods 참고: 일반 타격 히트스톱 0.05초, 취약점(근접 전용 적에 P1 슬래시 적중) 타격 히트스톱 0.1초 + 화면 흔들림 강화. "이 적의 약점을 제대로 건드렸다"는 피드백을 순수한 시간 정지로 전달. `HitstopManager.TriggerWeaknessHit()` 별도 메서드로 구분.
- **저주 조건부 강화 패리** — Curse of the Dead Gods 저주+리워드 구조 참고: Cat이 야성화(저주) 상태에서 P2의 패리가 성공하면 "분노 패리" 발동 → 패리 히트스톱 0.2초 + 반사 투사체 3방향 발사. 두 플레이어의 상태가 시너지를 일으키는 협력 순간. 구현: `ParryShieldController.OnParrySuccess += CheckFeralMode`.
- **씬 흐름 연동 런 재시작** — Full Scene Flow Architecture 참고: 게임 오버 시 `RunData.ResetForNewRun()` 호출 후 `SceneFlowController.RestartGame()` → Game Scene 새로 로드. 버튼 하나로 완전히 초기화된 새 런 시작. Pause Menu에서도 동일 흐름 적용. P1+P2 모두 HP=0일 때만 Game Over 전환 (단독 사망은 부활 시스템으로).

## 스토리 (05_Story)

- **저주 = 세계관 연결** — Curse of the Dead Gods 저주 시스템 참고: 고양이가 너무 많은 전투를 거치면 "야성의 기억"이 깨어난다는 설정. Cat의 야성화는 단순 게임 메카닉이 아닌, 고양이가 원래 들고양이였다는 세계관 단서. 야성화 3회 이상 달성 시 엔딩에서 추가 대사 해금.
- **가계 = 작물의 성장 기록** — Rogue Legacy 2 가계 시스템 참고: OnionCat에서 Onion(작물 P2)이 런을 거칠수록 "씨앗 → 새싹 → 양파 → 꽃" 단계로 성장. 메타 업그레이드 수에 따라 P2 스프라이트 성장 단계 변화. 많이 플레이할수록 Onion이 시각적으로 풍성해지는 영구 변화.
- **씬 전환이 내러티브** — Full Scene Flow Architecture 참고: 게임 오버 씬의 배경을 "화단 비가 내리는 장면"으로 연출. 런 결과 화면의 배경은 "씨앗을 세는 고양이". Main Menu 복귀 시 페이드 전환과 함께 "다시 일어서는 고양이" 짧은 애니메이션 재생. SceneFlowController의 페이드 타이밍에 이 연출 삽입.

## 기술 메모

- **히트스톱**: 반드시 `WaitForSecondsRealtime` 사용 (TimeScale=0 중에도 동작). 발동 순서: ①데미지 → ②SFX → ③TimeScale=0 → ④RealTime 대기 → ⑤TimeScale=1 → ⑥CinemachineImpulse → ⑦파티클. 이 순서 어긋나면 화면 흔들림이 히트스톱 중 동결되는 버그 발생. P1 근접은 전역 TimeScale=0, P2 원거리는 적 Animator.speed=0으로 차별화.
- **씬 전체 흐름 통합**: BootstrapScene → SplashScene → MainMenuScene 순서를 Build Settings에 등록. `SceneNames.cs` 상수 클래스로 문자열 오타 방지. RunData, SceneFlowController, AudioManager를 DontDestroyOnLoad로 유지. Pause는 별도 씬이 아닌 Game Scene 내 UI Panel로 구현 (TimeScale=0으로 처리). 씬 전환 시 `RunData.ResetForNewRun()` 호출 타이밍 반드시 확인.
