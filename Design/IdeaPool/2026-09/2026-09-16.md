## 캐릭터 (01_Characters)

- **Focus 연동 슬로우모 발동 포즈** — OTXO 참고: Cat이 Focus 게이지를 소모할 때 Crop이 조준 자세를 취하는 쌍 애니메이션. 두 캐릭터가 동시에 반응하는 시각적 일체감 강화. 구현 힌트: Animator 공유 파라미터 "FocusActive" 불리언으로 상체 레이어 전환
- **부활 역할 교환 연출** — Core Keeper 부활 시스템 참고: Cat의 HP가 0이 되면 Crop이 잠시 독립 행동(Cat 위에서 물 뿌리기 애니메이션)하며 회복. "식물이 고양이를 살린다"는 관계성 강조. 구현: Cat HP=0 → CropHealRoutine 코루틴 발동
- **마우스 조준 시 Crop 기울기** — Player 2가 마우스로 조준하는 방향에 따라 화분(Crop)이 반대 방향으로 살짝 기운 연출. 물리적 무게감 + 코믹함. 구현: CropAimController의 AimDirection으로 Crop 스프라이트 회전 오프셋 적용

## 적 (02_Enemies)

- **Focus 흡수형 적** — OTXO Focus 시스템 역발상: 이 적을 근접(Cat)으로 처치하면 Focus 게이지가 오히려 소모됨. 원거리로 처치해야 정상 게이지 획득. 강제 역할 분업 + Focus 관리 압박. 구현: OnDeath 이벤트에서 isMeleeKill 체크
- **공유 HP 스케일링 미니보스** — Core Keeper 보스 HP 스케일링 참고: 2인 플레이 시 HP 40% 추가, 패턴 하나 추가 발생. 솔로/코옵 난이도 자동 조절. 구현: BossController.Awake()에서 CoopManager.IsCoopMode로 HP 배수 결정
- **위치 기반 분업 강제 적** — Core Keeper "근접 앞/원거리 뒤" 자연 발생 설계 참고: 이 적은 근거리에 있으면 가시로 Cat을 밀어내고, 원거리에 있는 Crop에게만 약점 노출. Cat이 떨어져 방어선 역할, Crop이 DPS 담당하도록 강제. 구현: 적 중심에서 1.5m 이내 Cat 감지 → Knockback + 약점 닫기

## 맵 (03_Maps)

- **Focus 충전 방** — OTXO의 바(Bar) 방 컨셉 응용: 처치할 적이 매우 많지만 HP가 낮은 "파밍 방". 다음 보스 전 Focus 게이지를 가득 채우는 전략적 선택지. 구현: 방 타입 Enum에 FocusFarm 추가, 저HP 적 대량 스폰
- **Core Keeper 스타일 생체군계 층 테마** — 층 1=숲(초록), 층 2=결정 동굴(파랑), 층 3=불의 신전(주황). 층 전환 시 타일셋+배경+적 색상 팔레트 전체 교체. 구현: Runtime Palette Swap 또는 층별 다른 Tilemap Asset 사용
- **공유 공간 협력 방** — 두 플레이어가 각자 다른 구역의 스위치를 동시에 밟아야 문이 열리는 방. "동시 활성화" 메커닉으로 협력 필요성 직접 체험. 구현: TriggerCount 2개 → 모두 활성화 시 DoorController.Open()

## 전투 (04_Combat)

- **처치 방식 보상 분기** — OTXO 근접처치 특화 보상 참고: Cat(근접) 처치 시 방어 아이템, Crop(원거리) 처치 시 투사체 아이템 드롭 확률 증가. 런 진행에 따라 두 플레이어가 자연스럽게 전문화. 구현: DamageSource enum(Melee/Ranged)으로 드롭 테이블 가중치 분기
- **비대칭 패리 리워드** — Crop 방패로 적 공격 패리 성공 시 → Cat에게 0.5초 공격력 150% 버프 부여. 방패(수비)와 근접(공격)의 콤보 시너지 강화. 구현: CropShieldController.OnParrySuccess 이벤트 → CatMeleeController.ApplyBuff()
- **Focus 공유 슬로우** — OTXO Focus를 2인용으로 변환: Crop이 특정 버튼(L2)으로 Focus 발동 → 화면이 느려지고 Cat의 근접 공격이 0.3초간 무적 적용. Cat은 느려진 화면에서 대시+슬래시 가능. 구현: TimeScale.Set(0.3f) + Cat IFrame 코루틴

## 스토리 (05_Story)

- **이유 있는 공생** — OTXO 솔로 서사 vs Core Keeper 협력 탐험의 중간: 고양이가 화분을 등에 진 이유 = "식물이 고양이의 부상을 치유해 주기 때문". 고양이는 이동/전투, 식물은 치유/지원. 세계관 설정의 출발점
- **Core Keeper 지하 세계 응용** — 지하 던전 설정: 세계의 어둠을 없애기 위해 지하 신전 깊은 곳의 "빛의 씨앗"을 찾아 내려가는 서사. 각 층은 과거 문명의 흔적. Crop(식물)이 지하에서 점점 강해지는 이유가 됨
- **보스 처치 후 회상 장면** — 보스를 물리칠 때마다 짧은(3~5초) 픽셀아트 컷씬. "이 적은 과거에 고양이의 마을을 공격했던 존재". 처치에 의미를 부여. 구현: Boss OnDeath → CutsceneManager.Play(bossId)

## 기술 메모

- **Asymmetric Co-op Input**: `SharedBodyInputRouter`에서 Action Map 2개(CatPlayer/CropPlayer)를 동시에 활성화하는 방식이 OnionCat의 핵심 입력 구조. 각 컨트롤러 컴포넌트가 자신의 Action만 구독 → 나중에 AI 파트너로 교체할 때 해당 컴포넌트만 swap하면 됨. **가장 먼저 구현해야 할 시스템**.

- **Steam Deck Compatibility**: Canvas Scaler를 Scale With Screen Size (Match 0.5)로 설정하고, 모든 UI 버튼에 Explicit Navigation을 연결하는 것이 최우선. 1280×800 게임 뷰 해상도로 테스트하는 습관을 초기부터 들일 것. 파일 경로 대소문자 일관성은 나중에 고치면 버그가 광범위하게 퍼지므로 지금부터 주의.
