## 캐릭터 (01_Characters)

- **Doyle형 Cat 스킬** — Blazing Chrome 참고: Cat이 일정 쿨다운 이후 "변형 대시"를 사용하면 짧게 무적 + 근접 타격을 동시에 하는 기술 추가. 현재 무적 대시에 데미지 판정을 옵션으로 부여하는 방식으로 구현 가능 (`Physics2D.OverlapCircle` 으로 대시 경로 타격 판정).
- **피격 연출 개선** — Blazing Chrome의 "히트스톱 0.1초 + 흰 플래시 + 넉백" 3중 연출 적용. 현재 OnionCat 피격이 시각적으로 약하다면 `SpriteHitFlash` + `Time.timeScale = 0.05f` 0.08초로 강화.
- **방 진입 무적 시간** — 새 방 진입 0.5초 동안 무적 부여. 문 바로 앞에 적이 없는 방 설계라도 안전망으로 필요. `RoomEntryInvincibility` 코루틴으로 구현.

## 적 (02_Enemies)

- **방향 지정 약점 적** — Blazing Chrome에서 방패 적은 정면만 막고 측면/후방은 무방비. OnionCat에서 "정면 원거리 면역 + 측면 근접 취약" 적 추가. Cat이 측면 이동 → Crop이 원거리 약점 노출 후 처리 → 협동 시너지 유발.
- **문 앞 배치 금지 규칙** — Player_Spawn_Room_Entry_System 참고: 방 진입 직후 플레이어 스폰 포인트 반경 2 유닛 내에는 적 스폰 금지. `Physics2D.OverlapCircle`로 스폰 전 체크.
- **입장 연출 에너미** — 보스 방 입장 시 보스가 입장하는 연출(문이 잠기고 보스가 등장하는 3초 연출) 추가. 이때 플레이어는 무적 + 입력 잠금. 긴장감 조성과 동시에 보스 패턴 첫 번째 Telegraph 역할.

## 맵 (03_Maps)

- **문 방향별 스폰 오프셋 표준화** — 모든 방의 Door에 `SpawnPoint` 자식 오브젝트 배치. 북/남/동/서 방향에 따라 오프셋 (1.5 유닛) 고정. 방 제작 시 체크리스트 항목으로 추가.
- **재방문 방 처리** — 이미 클리어한 방 재방문 시: 적 없음 + 문 열림 + 보상 없음. `Room.isCleared` 플래그로 구현. 클리어 방에는 환경 오브젝트가 파손된 상태로 유지(전투 흔적 표현).
- **방 전환 슬라이드 카메라** — Hades 스타일의 카메라 슬라이드 전환 구현. 페이드보다 공간감을 잘 전달. `CinemachineConfiner`로 방 경계를 설정하고, 방 전환 시 `SmoothStep`으로 카메라 이동.

## 전투 (04_Combat)

- **협동 협공 패턴 설계 원칙** — Blazing Chrome 참고: 보스가 정면 광역 공격 → Cat이 회피 이동 → Crop이 약점에 원거리 집중. 보스 패턴을 설계할 때 "Cat이 이동해야만 Crop이 안전한 공격 각도를 확보" 구조를 의도적으로 삽입.
- **런 포기 시 전투 데이터 저장** — Game_Exit_Confirm_Dialog 참고: 런 포기 시에도 "이번 런에서 처치한 적 수 / 받은 데미지 / 클리어한 방 수"를 통계에 기록. `RunManager.AbandonRun()`에서 `StatsManager.RecordRunAbandoned()` 호출.
- **피격 무적 시간 시각화** — 피격 무적 시간(I-Frame) 동안 캐릭터 스프라이트가 깜박이는 연출. 0.1초 간격 `SpriteRenderer.enabled` 토글로 구현. 이미 `DashIFrameSystem` 참고해 동일 방식 적용.

## 스토리 (05_Story)

- **런 포기의 내러티브** — Blazing Chrome에서 실패는 "전선에서 쓰러진 것"으로 처리. OnionCat에서 런 포기/실패 시 나타나는 짧은 텍스트("고양이는 다시 씨앗을 심었다...") → 메타 스토리 조각 제공. 게임 종료 확인 다이얼로그 하단에 소소한 플레이버 텍스트 표시.
- **Co-op 종료 확인 문구** — 두 플레이어 로컬 협동 중 종료 시: "고양이와 파(또는 양파)가 함께 집으로 돌아갑니다. 이번 런은 끝납니다." 식의 캐릭터 페르소나가 담긴 종료 확인 문구. 딱딱한 "진행상황 손실" 경고보다 게임 세계관에 어울리는 표현.
- **방 진입 나레이션** — 특정 방(보스방, 비밀 방, 상점 방) 입장 시 Cat이 짧게 반응하는 텍스트 팝업. Crop도 반응. 이 대화가 두 캐릭터의 관계를 자연스럽게 전달. 구현: `Room.OnEnter` 이벤트 → `DialogueManager.PlayRoomReaction(roomType)`.

## 기술 메모

- **Player Spawn Room Entry System**: `Application.wantsToQuit`보다 중요한 것은 **Room.Initialize() 호출 타이밍**이다. 페이드 아웃 완료 후, 플레이어 이동 후, 카메라 스냅 후 순서로 초기화해야 플레이어가 적에게 즉시 피격되는 상황을 방지할 수 있다.
- **Game Exit Confirm Dialog**: `Time.timeScale = 0f` 사용 시 모든 Animator와 코루틴이 멈춘다. 다이얼로그 UI 애니메이션은 반드시 `Animator.updateMode = AnimatorUpdateMode.UnscaledTime`으로 설정해야 다이얼로그 자체가 멈추지 않는다.
