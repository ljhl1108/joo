## 캐릭터 (01_Characters)

- **고양이 "Rock and Stone" 대사** — DRG 참고: 고양이가 적을 처치할 때 랜덤 "야옹!" 효과음(pitch 랜덤) + 양파가 파티클로 꽃잎 날리는 연동 연출 → 협동 처치 시 팀워크 보상 느낌 강화. 구현: `AudioSource.pitch = Random.Range(0.9f, 1.2f)` + `deathVFXPrefab` 교체
- **고양이 대쉬 궤적 VFX** — DRG Scout 훅샷 궤적에서 착안: 무적 대쉬 중 발자국 파티클 + 잔상 스프라이트(SpriteRenderer alpha fade) → 대쉬 방향과 거리 시각화. `EnemyDeathConfig` 패턴처럼 `DashFXConfig ScriptableObject`로 분리
- **양파 방패 파괴 연출** — 패링 성공 시 충격파 파티클 + 화면 흔들림 0.08초: 근접/원거리 역할 분담에서 "막아냈다"는 피드백이 고양이만큼 강해야 함. `Cinemachine Impulse` + `Shield_ParryVFX` 풀 스폰

## 적 (02_Enemies)

- **방패 기사 (근접 필수 적)** — DRG에서 특정 클래스만 대응하는 적 설계 차용: 앞면 방패로 원거리 100% 막음 → 고양이 근접 슬래시로만 처치 가능. 사망 연출: 방패 스프라이트 교체(부서진 방패) → 기사 dissolve 파티클. `EnemyDeathConfig`에 `shieldBreakVFX` 필드 추가
- **허공 날벌레 (원거리 필수 적)** — 공중 부유 + 낮은 HP이지만 근접 판정이 닿지 않는 고도. 양파 씨앗 탄환으로만 격추. 사망: 추락 + 날개 깃털 파티클 burst. 히트스톱 0.03초 (작은 적)
- **감염 점액체 (소환 적)** — DRG 나나이트 스워머 오마주: 처치되면 자식 슬라임 2마리 스폰. `PoolManager.Spawn` × 2 호출. 무한 증식 방지: 자식에게는 소환 능력 없음(플래그로 구분)

## 맵 (03_Maps)

- **어둠 방 (랜턴 협동 방)** — DRG 어둠 동굴 오마주: 일부 방의 조명이 꺼진 상태로 시작 → 고양이가 이동하면서 횃불 오브젝트에 접촉해야 켜짐. 양파는 원거리로 횃불 점화도 가능 → 역할 분담 자연스럽게 유도. URP 2D Point Light 활성화 트리거
- **일방통행 터널 방** — 고양이 대쉬로만 통과 가능한 좁은 통로가 있는 방 레이아웃. 양파는 포트 입구에서 커버, 고양이가 돌파구를 여는 구조. 방 프리팹에 "DashOnlyPath" 레이어 콜라이더 추가
- **DRG 광물 채굴 오마주: 씨앗 결정 방** — 방 곳곳에 결정 오브젝트가 있고 양파 탄환을 맞추면 골드 드롭. 고양이 근접으로는 오브젝트 파괴 불가 → 양파에게만 있는 "환경 상호작용" 롤 강화

## 전투 (04_Combat)

- **협동 처치 판정 시스템** — DRG 팀 킬 카운터 오마주: 고양이와 양파가 함께 처치하면 "Teamwork Kill" 특수 이펙트 + 추가 골드. `RunData.AddKill()` 호출 시 마지막 공격자 태그 기록, 둘 다 공격한 경우 TeamKill 플래그 설정
- **적 사망 히트스톱 등급화** — 잡몹 0.03초 / 엘리트 0.08초 / 미니보스 0.12초 / 보스 0.18초 + 카메라 흔들림. `HitFeelSettings.asset`에 `deathHitstopByTier float[]` 배열 추가. 처치 "무게감" 차등 제공
- **연속 처치 콤보 트리거** — 1.5초 내 적 3마리 연속 처치 시 고양이 슬래시 범위 +20% + 양파 발사 속도 +30% 3초간. DRG의 "Kill streak" 암묵적 피드백 구조. `ComboKillChain` 기존 시스템 활용, 버프 적용만 추가

## 스토리 (05_Story)

- **광산 행성 임시 배경 설정** — DRG 우주 광산 오마주: 고양이와 양파가 자원 조달 임무로 던전에 내려간다는 in-world 이유 부여 → "다음 층도 캐야 한다"는 진행 동기. 런 시작 화면에 1줄 플레이버 텍스트로 연결
- **DRG 스타일 캐릭터 간 짧은 리액션** — 고양이가 피격 시 양파가 "조심해!" 타입의 짧은 TMP 말풍선(0.8초 후 소멸). 풀링으로 스폰/디스폰. 협동감 강화 + 캐릭터 성격 표현
- **런 실패 원인 기록** — 어떤 적에게, 어떤 상태에서 죽었는지 기록 → 런 결과 화면에 표시("슬라임에게 처치됨 - 3층"). `RunData.deathCause` + `Error_Log` 패턴처럼 씬/상태 스냅샷 저장

## 기술 메모

- **Enemy Death Sequence System**: `isDying` 플래그로 중복 실행 방지, `Collider2D.enabled = false` 로 유령 상태 만들기, `AutoDespawnParticle` 컴포넌트를 VFX 프리팹에 달아 풀 자동 반환 — OnionCat에서 Instantiate/Destroy 대신 `PoolManager.Spawn/Despawn` 사용 규칙과 완벽히 맞는 패턴.
- **Error Log & Crash Report System**: Bootstrap 씬에 `GameLogger` 컴포넌트 하나만 추가하면 빌드 후 플레이어 오류를 로컬 파일로 수집 가능. 2인 협동 특성상 NullRef가 자주 나는 입력/상태 분기에서 `씬명 + GameManager.State`를 함께 로깅하면 재현 속도가 크게 향상됨. 베타 출시 전 Firebase Crashlytics 추가 검토.
