## 캐릭터 (01_Characters)

- **슬래시 리바운드 운동** — Hollow Knight 참고: Cat의 슬래시가 적에 명중하면 공격 반대방향으로 0.15m 작은 킥백. 타격감 + 이동 리듬 동시 해결. `rb.AddForce(-attackDir * 120f, ForceMode2D.Impulse)` Cat의 Combat 컴포넌트에 추가. 이 킥백이 다음 대시 방향을 자연스럽게 유도.
- **트라우마 차별화 느낌** — Weapon Feel 참고: Cat 슬래시 trauma=0.15(묵직), Onion 투사체 trauma=0.10(가볍고 빠름)으로 분리. 두 캐릭터가 같은 화면에서 공격해도 각자의 "무게감"이 다르게 느껴짐 → 역할 분담이 감각에서 먼저 읽힘.
- **Charm → 개성 업그레이드 구조** — Hollow Knight Charm 시스템 참고: 업그레이드 선택 화면을 "Cat 슬롯 2 + Onion 슬롯 2 + 공유 슬롯 1" 총 5슬롯으로 구성. 공유 슬롯 업그레이드는 두 캐릭터 모두 혜택 → 선택 의미 강화. ScriptableObject 기반 UpgradeData에 `UpgradeTarget` 열거형(Cat/Onion/Both) 필드 추가.

## 적 (02_Enemies)

- **2레이어 HP 적 (Furi 핵심 구현)** — Furi 직접 적용: `float shield + float hp` 구조. `shield>0`이면 근접 피해 무효(Cat 공격 튕김), 원거리로만 shield 제거. shield=0 되면 Cat 공격 가능해지고 일정 시간 후 shield 재생성. 시각 표시: shield 있을 때 파란 오라, 없을 때 주황 오라. EnemyBase 상속 구조로 `ShieldedEnemy` 서브클래스로 구현.
- **색상 약점 표시 적** — Furi 탄막 색상 시스템 참고: 근접 약점 적 → 캐릭터/탄막 주황색 계열, 원거리 약점 적 → 파란색 계열. `SpriteRenderer.color` 또는 URP 머티리얼 색상 tint로 즉각 시각화. 색맹 배려: 색 외에 아이콘(검/화살표)도 적 머리 위에 표시.
- **2페이즈 전환 보스** — Hollow Knight 참고: 보스 HP 50% 이하 진입 시 패턴 전환. 근접 약점이던 보스가 2페이즈에서 원거리 약점으로 바뀜 → Cat과 Onion의 주도권이 전환. 연출: HP 50% 시 히트스톱 0.3초 + 카메라 trauma 0.6f + 연막 파티클 + BGM 전환.

## 맵 (03_Maps)

- **약점 전환 방** — Furi 컨셉 응용: 방 진입 시 모든 적의 약점이 반전되는 특수 방. 평소 근접 약점 적이 이 방에서는 원거리 약점으로 변함 → P1, P2 역할이 잠깐 반대로. 천장에 색상 표시등(주황/파란)으로 현재 방 약점 타입 시각 안내. 한 번만 등장하는 희귀 방으로 설정.
- **어두운 방 (침묵 서사)** — Hollow Knight 환경 스토리텔링 참고: 특정 방에 조명 없음. URP 2D 라이트를 꺼서 적 실루엣만 보임. 고양이의 눈이 빛나는 이미지로 Cat만 약하게 발광. Onion은 완전 어둠. 긴장감 극대화 + 두 캐릭터 관계의 시각적 표현(Cat이 길을 비춤).
- **분석 기반 난이도 조정 방** — Analytics 참고: 플레이 데이터에서 "사망률 높은 방 번호"를 분석해 해당 방 이전에 힐링 방이나 낮은 위험 방을 배치. 절차적 생성 가중치를 `DeathRoomHeatmap.json`에서 읽어 자동 보정. 초기 플레이테스트 후 밸런스 개선에 활용.

## 전투 (04_Combat)

- **패리 완벽 성공 쿨다운 보너스** — Furi 패리 + Hollow Knight Soul 참고: Onion이 퍼펙트 패리(0.1초 이내) 성공 시 Cat의 슬래시 쿨다운 즉시 초기화. "Onion이 막아줬으니 Cat이 바로 반격할 수 있다"는 협동 흐름이 직관적으로 생성. `CombatSynergy` 이벤트 버스로 Onion→Cat 신호 전달.
- **타격감 5요소 동기화** — Weapon Feel Tuning 참고: 슬래시 명중 순간 히트스톱(0.05초) + 카메라 trauma(0.15) + 사운드(랜덤 피치 0.9~1.1) + 파티클(오렌지 스파크) + 넉백이 **같은 프레임**에 발동. 초보자 구현 순서: ①히트스톱 → ②사운드 피치 → ③파티클 → ④카메라. 단계별로 추가하며 효과 체감.
- **Analytics 기반 패리 난이도 조정** — Analytics + Parry 참고: 패리 성공률을 누적 로깅. 30% 이하이면 패리 윈도우를 0.05초씩 늘리는 자동/수동 조정 루틴 도입. 데이터 기반 밸런스 → "느낌으로 조정"하는 함정 회피. 개발 빌드에서만 작동하는 AnalyticsDebugPanel UI 추가.

## 스토리 (05_Story)

- **고독과 동반 — Hollow Knight 감성** — 고독한 분위기 참고: OnionCat 세계관에서 고양이는 원래 혼자 다니는 존재. Onion이 등에 올라탄 이유는 "고양이만 들어갈 수 있는 던전에 Onion의 뿌리가 닿아있기 때문". 말 없이 목적이 같아서 함께하는 관계 — 우정이 아닌 필요. 런이 거듭될수록 말 없이 호흡이 맞아가는 Hollow Knight식 감정선.
- **보스들의 유언 코덱스** — Hollow Knight 보스 스토리 참고: 보스 처치 후 짧은 텍스트 팝업 (2~3줄). 보스가 왜 여기 있었는지, 무엇을 지키려 했는지. 수집형 코덱스로 런 결과 화면에서 확인 가능. 픽셀아트 보스 초상화 + 이름 + 3줄 텍스트. ScriptableObject `BossLoreData`로 관리.
- **Furi 역설 — 감금자와 죄수** — Furi 스토리 구조 참고: OnionCat의 최종 보스는 사실 고양이의 "전 주인"인 존재. 처음엔 적으로 등장하지만 클리어 후 Onion이 화분에서 꽃을 피우며 두 존재가 화해. "싸워야 연결되는" 역설적 관계. 멀티 엔딩: 모든 보스 처치 후 클리어 시 진엔딩, 중간 도망 시 배드엔딩.

## 기술 메모

- **Weapon Feel Tuning System**: 구현 핵심은 **동기화 타이밍** — 히트스톱, 카메라, 사운드, 파티클이 `OnTriggerEnter2D` 같은 프레임에 시작해야 함. 가장 먼저 히트스톱(3~5프레임, timeScale=0.05f)만 넣어도 타격감이 즉각 개선됨. Cat(묵직)과 Onion(가볍고 빠름) 수치를 다르게 설정해 캐릭터 개성 차별화. `WeaponFeelManager.Instance.OnMeleeHit(pos, dir)` 단 한 줄 호출로 전체 발동되도록 통합 관리자 패턴 추천.
- **InGame Analytics Event Tracker**: 구현 순서: ①`CAT_DEATH` + `ROOM_CLEAR` 2개 이벤트만 먼저 → ②`OnApplicationQuit()`에서 JSON 저장 → ③몇 번 플레이테스트 후 파일 열어서 수동 분석 → ④이후 `UPGRADE_SELECTED`, `ONION_PARRY_SUCCESS/FAIL` 추가. `Dictionary<string, string>` metadata로 자유롭게 추가 정보 첨부. 패리 성공률이 30% 이하면 윈도우 늘리기, 70% 이상이면 줄이기가 데이터 기반 밸런스의 첫 걸음.
