## 캐릭터 (01_Characters)

- **슬래시 튕김 이동 (Slash Dash)** — ScourgeBringer 타격 이동 참고: P1(Cat)이 슬래시 히트 시 타격 방향으로 0.3미터 즉각 돌진 (Rigidbody2D.AddForce). 공격이 동시에 이동이 되어 Cat이 "타격하며 파고드는" 플레이스타일 완성. 좁은 방에서 포위된 적들 사이를 슬래시로 누비는 시각적 쾌감.
- **협력 콤보 게이지 (Synergy Meter)** — ScourgeBringer 근접→원거리 시너지 참고: Cat이 근접 슬래시 3회 연속 히트 → Synergy Meter 충전 → P2 Onion의 투사체 대미지 1.5배로 일시 강화. HUD에 연두색 게이지로 표시. `CombatSynergyCounter.OnMeleeHit()` 이벤트로 구현.
- **퍼펙트 타이밍 패리 창 시각화** — ScourgeBringer 퍼펙트 닷지 참고: 적 탄환 발사 0.15초 전 Onion 방패 주변에 흰 링 이펙트가 잠깐 번쩍임(패리 윈도우 힌트). 이 타이밍에 패리 성공 시 슬로우 모션 0.1초 + 탄 반사 + 시너지 게이지 25% 충전. 패리의 진입 장벽 낮추면서 보상 강화.

## 적 (02_Enemies)

- **포위 조율 엘리트 (Formation Leader)** — Enemy Flanking AI 참고: 방마다 1마리의 엘리트 적이 "조율자" 역할. 주변 일반 적들에게 각도를 배분해 플레이어 포위망 형성. 엘리트 처치 시 나머지 적이 직선 추격으로 전환 → "보스 먼저 잡아야" 전술 자연 발생. 구현: `EnemyGroupCoordinator.cs` + 엘리트 사망 시 `coordinator.Dissolve()` 호출.
- **측면 기습 유형 적 (Flanker)** — Enemy Flanking AI 후방 우선 배치 참고: 특정 적 타입이 플레이어 시선 반대편(뒤쪽 180도)으로만 포위 접근. Cat이 앞쪽을 슬래시하는 동안 뒤에서 접근 → Onion이 뒤를 커버해야 함. 근접에 취약하도록 설정 → 뒤로 와야 Cat이 처치 → 두 플레이어가 완전히 다른 방향 커버.
- **포위 완성 시 특수 공격 적** — 포위 조합 참고: 3마리가 삼각형 포위를 완성하면 "집중 공격 (Volley)" 발동 → 세 방향에서 동시에 투사체 발사. 포위 완성 전에 한 마리를 먼저 처치해야 회피 가능. P1+P2 협력으로 분산 처리하도록 유도하는 자연스러운 협력 강요.

## 맵 (03_Maps)

- **소형 집중 방 설계** — ScourgeBringer 방 크기 철학 참고: 방 크기를 화면의 60%로 고정 (약 12×9 타일). 회피 공간 제한 → 적 포위 AI가 실제로 위협이 됨. 도망치지 못하는 밀도감 있는 전투. 단, Cat 슬래시 튕김 이동 거리(0.3m)만큼은 장애물 없는 공간 보장.
- **장애물 포위 방 (Pillar Room)** — Flanking AI + 장애물 참고: 방 중앙에 기둥 3~4개 배치. 적들이 기둥을 돌아서 포위 접근. 플레이어도 기둥 뒤로 숨어 패리 타이밍 노릴 수 있음. Cat은 기둥에 막혀 슬래시가 짧게 차단되므로 방향 선택이 중요.
- **화분 선반 허브 방 (Trophy Room Scene)** — Trophy Screen 참고: 런 사이 허브 씬에 "선반 방"이 있어 발견된 유물들이 화분에 전시됨. 새 런 시작 전 이 방에서 컬렉션 확인 후 출발. 유물 화분이 많을수록 선반이 풍성해지는 시각적 성장감 제공.

## 전투 (04_Combat)

- **포위 해제 피버 타임** — Flanking AI + ScourgeBringer 연속 타격 참고: 3마리 포위 중 Cat이 1초 이내에 2마리 연속 슬래시 처치 → "포위 해제 피버" 발동 → 남은 적 3초간 기절 + Onion 시너지 게이지 MAX. 팀 협력으로 위기를 기회로 전환하는 극적인 역전 순간.
- **전설 유물 발견 = 전투 중 연출** — Trophy Screen 참고: 런 중 처음 보는 전설 유물 획득 시 전투 일시 정지 (TimeScale=0.2 슬로우) + 유물 스프라이트 확대 + 황금 파티클. 즉시 `RelicDiscoveryManager.MarkDiscovered()` 호출로 영구 저장. 발견의 특별함을 전투 중에도 확실히 전달.
- **패리-포위 콤보** — Flanking AI + ScourgeBringer 퍼펙트 닷지 참고: 포위된 상태(3마리 이상)에서 Onion 패리 성공 시 반사 탄이 3방향으로 분산 발사 → 포위 중 한 마리 자동 처치 + Cat 슬래시 쿨다운 즉시 리셋. 위기 상황을 패리 하나로 역전하는 고위험-고보상 전략.

## 스토리 (05_Story)

- **선반의 기억** — Trophy Room 참고: 유물 각각에 짧은 로어 텍스트. 예: "녹슨 방울 — 오래된 고양이 목걸이. 누가 달아줬는지 기억나지 않는다." 컬렉션을 통해 OnionCat 세계관의 단편들이 퍼즐처럼 조각조각 드러남. 전체 유물 발견 시 마지막 조각이 맞춰져 세계관 완성.
- **포위의 기억** — Flanking AI + 스토리 연결: Cat과 Onion이 처음 만난 날, 다수의 적에게 포위됐다는 설정. 특정 포위 상황에서 게임 내 대사 트리거 ("또 이 상황이야…"). 전술적 메카닉이 내러티브의 일부가 되는 세계관 연결.
- **수집이 곧 여정** — ScourgeBringer + Trophy Room 참고: 각 런에서 새로 발견한 유물들이 허브 선반에 추가될 때마다 Cat이 짧은 독백 ("이건 뭘까", "잘 보관해야지"). 컬렉션 완성도가 곧 스토리 진행도이자 세계관 탐험 깊이를 나타냄.

## 기술 메모

- **Enemy Flanking AI**: 방에 적이 3마리 이상일 때만 포위 모드 활성화, 2마리 이하는 직선 추격. `EnemyGroupCoordinator.RegisterEnemy()` 호출 시 자동 각도 배분 (360 / member.Count). 적 사망 시 `UnregisterEnemy()`로 즉각 재배분. 포위 반지름은 방 크기의 25~30%로 설정해야 효과적. 장애물이 있으면 `Physics2D.Linecast`로 감지 후 15도씩 회전해 우회 경로 탐색.
- **Trophy Relic Showcase Screen**: `RelicData ScriptableObject` + `PlayerPrefs` 저장이 핵심 골격. 구현 순서: ①RelicData SO 목록 작성 → ②RelicDiscoveryManager 저장 로직 → ③RelicSlot UI (발견/미발견 분기) → ④런 결과 화면에 신규 발견 연출 연동 → ⑤메인 메뉴 진입 버튼. 유물 슬롯이 많아지면 ScrollRect + 가상 리스트(ObjectPool 재활용) 고려.
