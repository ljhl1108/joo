## 캐릭터 (01_Characters)

- **패리 폭발 고양이** — Cryptark 패리 반격 메카닉 참고: Onion의 방어막이 패리 성공 시 소형 AoE 폭발로 반격. `AoEHelper.ExplodeAoE()`를 패리 성공 이벤트에 연결. 반경 2.5유닛, 피해 = 막은 투사체 피해의 150%. 근접 적에게 강한 패리 인센티브 부여.

- **충격파 슬래시** — Cryptark 무기 조합 아이디어 참고: Cat의 업그레이드 중 하나로 슬래시 시 전방 반원형 AoE 충격파 추가. `Physics2D.OverlapCircleAll` + 전방 벡터 내적 필터링으로 180° 범위 적용. 고비용 업그레이드(포인트 3 소모)로 설정해 밸런스 유지.

- **예산 기반 업그레이드 시스템** — Cryptark Pre-run Loadout 참고: 런 시작 전 Cat/Onion 각자 "업그레이드 포인트 5" 배분. 강력한 업그레이드일수록 포인트 ↑ → 약한 업그레이드 여러 개 vs 강한 업그레이드 하나 선택지. 두 플레이어 포인트를 독립 운영해 개성 차별화.

## 적 (02_Enemies)

- **알람 봇** — Cryptark 알람/증원 메카닉 참고: 도망다니는 작은 적으로, 잡지 않으면 주기적으로 증원 적 소환. Cat이 추격(근접), Onion이 원거리 지원 역할 자연스럽게 분담. 구현: `coroutine`으로 일정 간격마다 `EnemySpawner.SpawnWave()` 호출.

- **자폭 슬라임** — AoE 데미지 존 참고: 플레이어에게 달려들다 근접 시 AoE 폭발로 자폭. 사망 시 `ExplodeAoE(radius: 3f, damage: 40f)` 호출. Cat의 대시로 피할 수 있고 Onion이 원거리로 미리 처치 가능 → 협력 필요 상황.

- **방어막 수호자** — Cryptark 방어 시스템 참고: 주변 아군에게 방어막을 부여하는 적. Onion의 원거리 공격으로 방어막 파괴 → Cat이 근접 처치. 방어막 파괴 전 Cat 공격 무효 → 자연스러운 역할 분담 강제. `ShieldProvider` 컴포넌트로 구현.

## 맵 (03_Maps)

- **AoE 트랩 방** — AoE 데미지 존 참고: 바닥에 지속 데미지 타일(화염, 독) 배치. Cat이 대시로 통과 경로 확인 후 Onion 이동 가이드. `TriggerDamageZone` 컴포넌트로 구현. 안전 통로가 좁을수록 협력 밀도 ↑.

- **알람 방** — Cryptark 알람 시스템 참고: 방 입장 시 알람 장치가 있고, 일정 시간 내 파괴하지 않으면 강화 적 소환. 시간 압박 + 알람 위치 파악(Onion 조준) + 이동 방어(Cat 슬래시) 동시 요구.

- **보물 요새 방** — Cryptark 리스크-보상 참고: 일반 방보다 적이 많고 위험 환경(AoE 트랩 + 강적)이지만 업그레이드 보상이 2개. 플레이어가 자발적으로 난이도를 선택하는 흥미로운 선택지.

---

## 전투 (04_Combat)

- **협력 강제 취약점 시스템** — Cryptark 취약점 메카닉 직접 적용: 근접형 적 → 방어막 있어 Onion 원거리만 파괴 가능, 파괴 후 Cat 근접 처치. 원거리형 적 → 반사 방어막으로 원거리 반사, Cat 근접으로만 처치 가능. 기획 레벨에서 이 규칙을 명확히 정의해야 게임 핵심 재미 완성.

- **패리 AoE 콤보 체인** — Cryptark + AoE 참고: Onion 패리 성공 → AoE 폭발 → 주변 적 스턴 → Cat이 스턴된 적 연속 슬래시. 두 플레이어의 타이밍 협력이 만드는 "콤보 순간". 스턴 지속 시간 0.8초로 제한해 긴장감 유지.

- **범위 공격 예고 시스템** — AoE 구현 참고: 자폭 적이나 보스 AoE 전에 반경 표시 원형 경고 UI (빨간 테두리 원 0.5초 표시 후 폭발). `AnimationCurve`로 경고 원 스케일 증가 후 폭발. 플레이어가 위치 파악하고 대피할 수 있어야 "불공평한 피해" 없음.

## 스토리 (05_Story)

- **점령된 정원 던전** — Cryptark 우주 요새 분위기 참고: 적이 정원/농장을 점령하고 요새화. 방마다 적의 방어 시스템(알람, 가시 덫, 폭발 씨앗)이 배치. 고양이+식물 콤비가 잠입해 되찾는 서사. "우리의 정원을 돌려받아라" → 감정적 동기 명확.

- **언어 설정 인트로 연출** — 언어 선택 화면 참고: 최초 실행 시 Cat과 Onion이 등장해 각자 언어로 인사하는 짧은 애니메이션 후 언어 선택 버튼 표시. "안녕!" / "Hello!" 두 버튼이 각 캐릭터의 말풍선으로 표현. 언어 선택에 캐릭터 서사 자연스럽게 연결.

- **전 세계 언어 달성 도전** — 언어 시스템 + 업적 참고: "영문 버전으로 10런 클리어" 업적. 개발자 본인도 영어 실력 동기부여 겸, 글로벌 출시 목표 게임 내 반영. 작은 이스터에그로 개발자 정체성 표현.

## 기술 메모

- **AoE 데미지 존**: Trigger 기반(`TriggerDamageZone`) 방식이 `OverlapCircleAll` 매 프레임 호출보다 성능 우수. 지속 존에는 Trigger, 순간 폭발에는 `Physics2D.OverlapCircleAll` 혼용이 최적. Onion 패리 반격 폭발은 `AoEHelper.ExplodeAoE()` 정적 유틸 함수 하나로 관리 추천.

- **언어 선택 화면**: `PlayerPrefs.HasKey("SelectedLanguage")` 체크로 최초 실행만 표시. 한국어 픽셀폰트 지원은 글리프 수 문제로 어렵고 — 개발 중에는 시스템폰트 사용, 출시 전 전용 한국어 픽셀폰트로 교체하는 2단계 전략이 현실적. `LanguageManager.OnLanguageChanged` 이벤트 하나로 모든 `LocalizedText` 컴포넌트 자동 갱신 가능.
