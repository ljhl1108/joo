## 캐릭터 (01_Characters)

- **이동 관성 개성 차별화** — TopDown Movement Polish 참고: Cat의 최대속도를 5.5m/s로, 대시 발동 시 0.12초 입력 버퍼 적용. 반면 Onion의 방패 방향은 0.08초 보간으로 느리게 전환 → Cat은 "민첩한 고양이", Onion은 "무게 있는 식물" 느낌 물리적으로 차별화. 조작 느낌에서 두 캐릭터의 성격이 드러남.
- **체력 위기 보이스 행동 변화** — Voice Event System + Pico Park 협동 설계 참고: Cat HP 25% 이하 시 야옹 소리가 작고 약해지고 + 이동 최대속도 10% 증가 (위기 탈출 본능). 동시에 Onion도 시든 소리 + 방패 쿨다운 0.5초 감소. 플레이어가 "지금 위기"임을 청각+촉각으로 즉시 감지.
- **패리 성공 시 보이스+물리 연계** — Voice + Movement Polish 참고: Onion 패리 성공 순간 Cat에게 `AddForce`로 패리 반대방향 0.2m 반동 + Cat 자신감 있는 보이스. 패리가 단순 방어가 아닌 "두 캐릭터가 함께 반격하는" 역동적 순간으로 연출.

## 적 (02_Enemies)

- **동시 타격 요구 적 (SyncShield Enemy)** — Pico Park 동시 입력 메카닉 참고: 방패를 두 방향에 가진 적. 앞면은 근접에만 취약(Cat), 뒷면은 원거리에만 취약(Onion). 두 플레이어가 동시에 각각 히트해야 기절. 한 명이 먼저 치면 방패가 회전해 다른 면이 바뀜 → 타이밍 맞추지 않으면 무한 반복. 완벽한 OnionCat 협동 강요.
- **보이스 반응 적 (Sound Aggro)** — Voice Event System 역용: Cat의 보이스 소리에 반응해 추적하는 "귀 먹은 적" 타입. Cat이 피격 보이스를 내면 이 적이 소리 방향으로 일시 달려옴. 위기 상황에서 소리가 더 큰 위기를 부름 → 체력 관리 긴장감 증폭.
- **이동 방해 발판 적 (Friction Enemy)** — Movement Polish + 방 설계 참고: 죽으면 바닥에 끈적한 오일을 퍼트리는 적. 오일 영역에서 Cat의 가속도가 절반 → 방향전환이 느려짐. Onion의 방패는 영향 없음 → P2가 주도권을 가지는 특수 상황 연출.

## 맵 (03_Maps)

- **동시 발판 방 (Pico Park 방 디자인)** — Pico Park 강제 협동 패턴 참고: 방 중앙 문이 Cat과 Onion이 각각 다른 버튼을 0.3초 이내에 같이 누를 때만 열림. Cat은 근접 공격(슬래시)으로, Onion은 투사체로 각자 버튼 활성화. 두 버튼이 방 양쪽 끝에 배치 → 물리적으로 혼자 둘 다 누를 수 없음.
- **이동 난이도 방 (Sliding Floor)** — Movement Polish 응용: 특정 방 바닥에 얼음 효과 → 감속도가 5로 떨어짐 (기본 18). Cat이 미끄러지며 조작이 어려워짐. Onion의 마우스 에임은 영향 없음 → P2가 주 화력 담당 역할 전환 방. 보조 잠금 해제 방으로 도전적인 경험 제공.
- **보이스 트랩 방 (Silent Room)** — Voice System 역용: 특정 방에 들어가면 "침묵 지대" 효과. Cat 보이스 없음 + 발소리 없음 + BGM 무음. 정적 속에서 적들이 소리 없이 움직임 → 심리적 긴장감 극대화. 방 탈출 시 보이스와 BGM이 다시 터지는 대비 효과.

## 전투 (04_Combat)

- **입력 버퍼 활용 콤보** — Movement Polish 입력 버퍼 참고: Cat의 슬래시 쿨다운 마지막 0.12초 내에 다시 슬래시 입력 시 콤보 발동 (일반 슬래시 → 강화 회전 슬래시). 타이밍을 리듬감 있게 맞추면 자연스럽게 강화 공격 연속. `InputBuffer.Consume()` 패턴 그대로 적용.
- **보이스 시너지 게이지** — Voice Event + Synergy System 연계: Cat 피격 보이스 후 0.5초 이내에 Onion 패리 성공 시 시너지 게이지 +30% 보너스 추가. "Cat이 당했을 때 Onion이 바로 막아줬다"는 내러티브가 메카닉으로 연결. 두 플레이어가 서로의 보이스에 주의를 기울이게 만드는 청각적 큐.
- **감속 활용 패리 타이밍** — Movement Polish + Parry 참고: 적의 돌진 직전 Cat이 일부러 멈추면(입력 없음) Onion의 패리 판정이 1.2배 넓어지는 패시브. Cat의 이동 관성 컨트롤이 Onion의 방어 성능에 영향 → 두 플레이어의 움직임이 서로 연결됨. "Cat이 멈춰야 Onion이 패리 창이 넓어진다"는 직관적 규칙.

## 스토리 (05_Story)

- **침묵의 언어** — Pico Park 대화 없는 협동 + Voice 시스템 참고: Cat과 Onion은 말을 하지 않지만 소리로 소통. 보이스 이벤트들이 쌓여서 두 캐릭터가 서로를 얼마나 이해하는지 보여주는 관계 발전. 첫 런: Cat의 보이스에 Onion이 늦게 반응. 후반 런: Onion이 Cat의 피격 소리 0.3초 전에 먼저 방패를 들어올림 (예측 패리). 시간이 지날수록 말 없이 호흡이 맞아가는 관계 표현.
- **보이스 아카이브** — Voice Event System + Story 연계: 게임 오버 화면이나 런 결과 화면에서 "이번 런에서 들은 소리" 목록 표시. 예: "피격 12회 (끄아 소리), 패리 성공 7회 (자신있는 냥), 위기 탈출 3회". 수치가 아닌 소리로 런을 기억하게 하는 독특한 회고 방식.
- **보이스로 찾는 Onion의 기원** — 스토리 연결: Cat의 냥 소리에 특정 주파수가 있어서 Onion만 인식할 수 있음 (설정). 이 특별한 주파수가 Cat과 Onion이 처음 만났을 때 연결된 이유. 런 클리어 보상 코덱스에 "주파수 기록 #7 — 고양이의 목소리가 땅속에 스며들면..." 같은 단편 스토리.

## 기술 메모

- **TopDown Movement Polish**: 구현 우선순위: ①입력 버퍼(0.12초) → ②가속/감속 곡선(accel=14, decel=18) → ③방향전환 가속(oppositeDir 시 ×2) → ④대시 후 EaseIn 감속 → ⑤스쿼시&스트레치. 처음부터 다 넣지 말고 기본 이동 완성 후 순서대로 추가. 각 단계마다 실제로 게임을 플레이해보며 숫자 조정 필수.
- **Character Voice Event System**: 구현 순서: ①AudioSource 두 개 설정 → ②VoiceEventData ScriptableObject 생성 → ③VoiceEventManager 싱글턴 → ④피격/사망 이벤트 먼저 연결 → ⑤쿨다운 튜닝. 에디터에서 `VoiceEventData`마다 AudioClip 배열 드래그 앤 드롭 설정 필요. 처음엔 효과음 없이 Debug.Log로 이벤트 발화 확인 후 실제 클립 연결 권장.
