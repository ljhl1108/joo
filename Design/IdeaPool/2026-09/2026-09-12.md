## 캐릭터 (01_Characters)

- **Cat의 문 알림 귀 세우기** — Archvale 방 클리어 연출 참고: 방 클리어 후 Cat 스프라이트가 귀를 세우는 1프레임 애니메이션 재생 → 방향을 읽는 것처럼 보임. 아이들 상태에서 `DoorUnlocked` 이벤트 수신 시 Animator trigger "EarPerk" 발화. 작은 연출이지만 캐릭터에 생명력 부여.
- **Onion의 승리 포즈 (흔들기)** — Moonlighter 클리어 연출 참고: 방 클리어 시 Onion이 줄기를 흔드는 짧은 모션(0.4초). Cat 등 위에서 화분이 흔들리는 Secondary Motion으로 구현. `OnRoomCleared` → Onion Animator "Victory" trigger → 스프링 물리로 자연스러운 흔들림.
- **두 캐릭터의 클리어 보너스 분담** — Archvale 링 시스템 참고: Cat이 마지막 적을 처치 → Cat 방향 업그레이드 선택권 +1 / Onion이 마지막 처치 → Onion 방향 선택권 +1. "누가 마무리했나"에 따른 미세 보너스로 각자의 기여를 인정.

## 적 (02_Enemies)

- **방 클리어 직전 헛돌기 적** — Moonlighter 던전 설계 참고: 마지막 1~2마리 적이 체력이 낮아지면 패닉 상태에서 빠르게 도망다님. 처치하기 어렵지 않지만 공간을 넓게 이용하게 만들어 방 클리어 직전의 긴장감을 연장. `EnemyState.Fleeing`: 플레이어 반대 방향으로 최고 속도 이동.
- **문 블로커 적** — Door_Room_Transition 참고: 방 입구(문 앞)를 막고 서있는 대형 적. 처치하지 않으면 문이 열려있어도 통과 불가(몸이 막힘). 클리어 후에도 사체가 잠깐 문을 막는 픽셀아트 연출. Collider가 `isTrigger=false`인 EnemyCarcass 오브젝트로 처리.
- **페이즈 전환 보스 약점 스왑** — Archvale 보스 패턴 참고: 보스 1페이즈(원거리 약점) → HP 50% → 2페이즈(근접 약점). 전환 순간: 히트스톱 0.3초 + 보스 색상 팔레트 변경(파랑→주황) + 탄막 패턴 완전 교체. `Boss.OnPhaseChange(int phase)` → `SpriteRenderer.material` swap + `PatternController.SetPattern(phase)`.

## 맵 (03_Maps)

- **방 클리어 연출 기반 보상 방 UX** — Archvale + Moonlighter 참고: 방 클리어 후 문이 열리면 다음 방 유형 아이콘이 문 위에 표시됨 (전투🗡 / 상점💰 / 힐링💚 / 이벤트❓). 플레이어가 다음 방 방향을 결정할 수 있는 최소한의 정보 제공 → "어느 문을 열까?" 의사결정.
- **치유 방 배치 공식** — Moonlighter 치유 웅덩이 설계 참고: OnionCat 규칙: 매 3번째 방마다 힐링 방 1개 보장. `RoomSequence[i]`: `(i % 3 == 2)` 이면 `RoomType.Healing`으로 강제 고정. 나머지 2개는 전투/이벤트 중 랜덤. 두 플레이어의 공유 체력 구조에서 필수적인 안전망.
- **문 방향 = 난이도 표시** — Door_Room_Transition 참고: 위쪽 문 = 더 어려운 방(높은 보상), 아래쪽 문 = 안전한 방(낮은 보상). Cat의 자연스러운 이동 방향을 이용해 의사결정을 공간적으로 표현. 미니맵에 방 난이도를 색상 원으로 표시(붉음=위험).

## 전투 (04_Combat)

- **팀워크 클리어 보너스** — Archvale 코옵 + Room_Clear_Celebration 참고: Cat 근접과 Onion 원거리가 **같은 프레임(±2프레임)에 마지막 적에 명중**하면 "TEAMWORK!" 팝업 + 황금 파티클 + 골드 1.5배. `CombatEventBus`에서 마지막 히트 타임스탬프 비교: `Mathf.Abs(catLastHit - onionLastHit) < 0.033f`.
- **올바른 약점 처치 = 클리어 파티클 색 변화** — Archvale 약점 시스템 참고: 적의 약점(`WeakTo`)에 맞는 공격으로 처치 시 클리어 파티클이 황금색. 강행(피해는 입히지만 약점 아님)으로 처치 시 흰색. 즉각적인 시각 피드백으로 "올바른 플레이"를 긍정강화.
- **문 열림 속도 = 클리어 시간에 따른 보상** — Moonlighter 경쟁 요소 참고: 방을 빠르게 클리어할수록 문이 "활짝" 열리며 추가 골드 드롭. 느리게 클리어하면 기본 보상만. `clearTime < threshold ? ExtraLoot() : NormalLoot()`. 빠른 플레이에 대한 보상으로 반복 플레이 동기 강화.

## 스토리 (05_Story)

- **방 문이 기억하는 서사** — Moonlighter 마을 영구 성장 참고: 특정 보스 처치 후 그 층의 문이 영구적으로 열린 채 유지(다음 런에도). "이 방은 저번에 클리어했어" 라는 흔적이 세계에 남음. 고양이가 익숙하게 문을 뛰어넘는 짧은 모션 추가 → 성장의 시각적 표현.
- **Onion의 씨앗 뿌리기 흔적** — Archvale 오버월드 탐색 참고: Cat이 지나간 방의 바닥에 Onion이 작은 씨앗을 떨어뜨림(랜덤 확률). 클리어한 방에 식물이 자라는 비주얼 — 세계가 조금씩 변해가는 부드러운 서사. `OnRoomCleared` → 5% 확률 씨앗 스프라이트 바닥에 배치.
- **마지막 방의 문 연출 차별화** — Door_Room_Transition 참고: 보스 방 문은 일반 방 문과 다른 스프라이트(더 크고 화려함). 보스 방 입장 시 카메라 살짝 줌인 후 문 열림 → 진입하는 순간의 긴장감. `BossRoom.OnDoorEnter()` → CinemachineVirtualCamera Priority 변경 → 줌인 연출.

## 기술 메모

- **Door_Room_Transition_System**: OnionCat의 핵심 구현 순서: ①`DoorController.Unlock()` — 방 클리어 이벤트 연결 ②`CanvasGroup` 페이드 인/아웃으로 부드러운 방 전환 ③`CameraController.SetRoomBounds()`로 방 경계 잠금. Cat이 Onion을 등에 태우므로 **단일 플레이어 오브젝트가 문을 통과하면 둘 다 이동** — 복잡한 2인 통과 판정 불필요.

- **Room_Clear_Celebration_VFX**: 구현 순서: ①SFX 한 줄 ②파티클 Instantiate ③히트스톱(Time.timeScale 0.05초) ④카메라 쉐이크 trauma=0.2. **총 연출 시간 0.7~0.8초 이내**로 유지해야 게임 리듬을 깨지 않음. "팀워크 클리어" 판정(±2프레임)을 추가하면 OnionCat의 협동 핵심 필러와 직결되는 보상 시스템이 완성됨.
