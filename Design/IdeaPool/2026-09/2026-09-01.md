## 캐릭터 (01_Characters)

- **취약점 색상 팔레트 연동** — The Last Spell 참고: P1(고양이)이 근접 전용 적에게 가까이 접근 시 고양이 귀·꼬리가 붉게 빛나는 시각 피드백. "이 적은 내가 처리해야 해"를 텍스트 없이 전달. 구현 힌트: `OnTriggerEnter2D`에서 적 `DamageType` 확인 후 `MaterialPropertyBlock`으로 팔레트 Row 교체.
- **공명 충전 게이지** — 시너지 스킬 참고: P1 슬래시 + P2 투사체가 같은 적에게 0.5초 내 모두 맞으면 "공명 게이지" 1 충전. 게이지 3 소모 시 화면 전체 폭발 필살기 발동. HUD에 공유 게이지 바 표시 → 협동의 시각적 보상.
- **성장 도감 (Beast Log)** — The Last Spell 적 다양성 참고: 처치한 적 종류를 코덱스에 등록. 등록 시 해당 적의 취약 타입·능력치 열람 가능. 처음 만나는 적의 취약점을 모르는 상태를 유지해 탐색 재미 부여, 재도전 시 지식 기반 전략.

## 적 (02_Enemies)

- **마법 면역 중장갑 적** — The Last Spell 물리 면역 적 참고: 방패를 두른 근접형 적(근접 데미지 95% 감소). P2의 원거리 공격만으로만 처치 가능 → P2가 우선 처리해야 P1이 안전히 다른 적 공략. 시각 표시: 갑옷 질감 스프라이트 + HP바 위 방패 아이콘.
- **웨이브 분리형 스포너** — 방 내부 랜덤 배치 참고: 방 입장 시 즉시 스폰하지 않고 2파로 분리. 1파 처치 완료 3초 후 2파 스폰 → 플레이어가 숨 고를 시간 확보 후 긴장감 재상승. 연출: 문 위 균열 이펙트 → 2파 등장 예고.
- **취약점 이중 적 (Mixed Guard)** — 응용 아이디어: 일부 적에게 P1+P2 동시 공격만 유효한 "공명 취약점" 부여. 한 명만 공격하면 50% 데미지, 동시 공격 시 250% 데미지. 자연스러운 협동 강제 + 고위험·고보상 전투 순간 생성.

## 맵 (03_Maps)

- **낮/밤 방 교대 배치** — The Last Spell 루프 참고: 전투 방(Battle Room) → 안전 방(Upgrade Room) 교대 배치를 층 구조에 고정. 전투 방에서 긴장감 소모 후 안전 방에서 업그레이드·회복 → 감정 리듬 조절. 안전 방에는 배경 BGM 다운템포 전환 연출 추가.
- **방 내 구역 분리 (P1 Zone / P2 Zone)** — 방 내부 랜덤 배치 참고: 방 내부를 좌/우로 나눠 근접 전용 적 스폰 포인트는 좌측, 원거리 전용 적 스폰 포인트는 우측 배치. 두 플레이어의 물리적 공간 분리로 화면 혼잡 감소 + 역할 분담 직관화.
- **마지막 방 웨이브 대규모 연출** — The Last Spell 밤 클라이맥스 참고: 보스 방 전 일반 방에서 적 수가 평소의 2배 스폰. 스폰 완료 전까지 출구 문 잠금. 클리어 시 문 개방 + 팡파레 → 클라이맥스-카타르시스 리듬.

## 전투 (04_Combat)

- **공명 폭발 (Resonance Burst)** — The Last Spell 시너지 스킬 참고: P1 슬래시로 기절 적에게 P2 투사체 명중 시 "공명 폭발" 발동 — 기절 적 중심 3타일 범위 AOE. 기절 유발 타이밍·조준이 두 플레이어의 의사소통을 필요로 함. 구현: 적 `Stunned` 상태 플래그 + 투사체 충돌 시 체크.
- **취약점 첫 발견 보너스** — The Last Spell 정보 전략 참고: 런 중 처음으로 새로운 적 유형의 취약점을 발견(올바른 타입으로 처치)하면 보너스 골드 +10 지급. 발견 연출: "WEAKNESS FOUND!" 팝업 + 황금 파티클. 학습과 보상을 연결해 탐색 유도.
- **AP 개념 응용 — 슬래시 콤보 쿨다운** — The Last Spell AP 시스템 참고: P1의 슬래시를 "1번 슬래시 = AP 1 소모" 방식으로 연속 사용에 짧은 글로벌 쿨다운 부여. 연속 3회 슬래시 후 0.3초 회복 대기 → 무한 도배 방지 + 리듬감 있는 전투 템포.

## 스토리 (05_Story)

- **거점(화분)의 HP = 세계 존속** — The Last Spell 타운 HP 참고: P2가 타고 있는 화분이 단순히 P2의 이동 수단이 아니라 "마지막 씨앗"이라는 설정. 화분의 체력이 곧 세계의 희망. 화분 HP 낮아질수록 배경 색이 탈색되고, 회복하면 꽃이 피어나는 시각 서사.
- **낮/밤 구조 → 런 내 서사** — 루프 구조 참고: 전투 방 클리어 후 안전 방에서 NPC(작은 동물 피난민)의 단편 대화 한 줄 등장. 매 런마다 다른 NPC, 다른 대사 → 반복 플레이에도 새로운 세계관 파편 발견 가능. 100개 대사 풀 → 플레이테스트 로그로 노출률 측정.
- **밸런스 로그가 드러내는 스토리** — 플레이테스트 로그 참고: 개발자가 "어느 적에게 주로 죽는지" 데이터를 보고 해당 적에게 서사적 이름·배경 부여. 데이터 기반 캐릭터 설계 → 실제로 위협적인 적이 스토리상 중요한 존재가 됨.

## 기술 메모

- **방 내부 콘텐츠 랜덤 배치**: `ScriptableObject`로 방 유형별 테이블을 분리하면 코드 수정 없이 에디터에서 밸런스 조정 가능. `GetWeightedRandom()`의 가중치 합산-롤 방식은 어느 수의 항목에도 O(n)으로 동작해 런타임 부담 없음. 스폰 포인트는 방 프리팹에 직접 배치하고 `GetComponentsInChildren<RoomContentPoint>()`로 자동 수집 — 수동 List 관리 불필요.
- **플레이테스트 세션 로그**: `Application.persistentDataPath`는 빌드 플랫폼에 관계없이 올바른 쓰기 가능 경로를 반환하므로 별도 경로 하드코딩 불필요. `enableLogging` 토글 또는 `Debug.isDebugBuild` 조건을 초기 Awake에서 확인해 릴리즈 빌드에서 자동 비활성화 — 파일 시스템 접근 비용 제거. meleeKills / rangedKills를 분리 기록해두면 P1·P2 밸런스 검증이 데이터로 가능.
