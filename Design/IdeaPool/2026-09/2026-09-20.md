## 캐릭터 (01_Characters)

- **프렌들리 파이어 버전 패널티** — Helldivers 2 참고: Onion의 투사체가 Cat에게 맞으면 피해 대신 "일시 혼란"(대쉬 불가 1초) → 사고를 치면 폭소가 나는 협력 실수 구현 힌트: `PlayerHealth.TakeFriendlyFire()` 별도 메서드로 처리
- **Cat 지치기 표현** — Pepper Grinder 참고: 체력이 낮을 때 Cat 스프라이트에 땀·헐떡임 애니메이션 추가 → 플레이어가 HUD를 안 봐도 상태를 직관적으로 파악 가능
- **Onion 조준 자세 변화** — 실드 활성 중에는 Onion 스프라이트가 "방어 자세" 프레임으로 전환 → 두 캐릭터의 상태가 비주얼로 구분됨

## 적 (02_Enemies)

- **역할 강제 적 — "Shielder"** — Helldivers 2의 역할 분업 참고: 정면에서 방어막을 들고 서 있는 적 → Onion의 투사체는 막히지만 Cat이 옆으로 돌아가 슬래시 가능, 협력 필수
- **드릴형 적** — Pepper Grinder의 드릴 이동 참고: 땅속을 파고 이동하다 Cat 발아래서 튀어오르는 적 → 예측 불가 등장으로 긴장감 유발, 이동 경로 예고 파티클 필요
- **Stratagem 소환형 보스** — Helldivers 2의 소환 스트라타젬 참고: 보스가 일정 HP마다 증원을 부름 → Cat과 Onion이 "보스 vs 잡몹"을 나눠 처리해야 하는 분업 페이즈

## 맵 (03_Maps)

- **역할 통로 분리 방** — Helldivers 2의 팀 분업 참고: 방 안에 좁은 통로가 두 갈래 → 한쪽은 근접만 통과, 다른 쪽은 원거리만 커버 가능한 구조로 플레이어 협력 강제
- **드릴 가능 벽 (미래 아이디어)** — Pepper Grinder 참고: 특정 벽은 Cat 발톱으로 긁으면 부서지는 비밀 통로 → 레벨 디자인 깊이 추가
- **짧은 챌린지 방** — Pepper Grinder의 짧은 레벨 철학: 방 하나의 전투 시간을 30초~1분 이내로 목표 설정 → 긴장감 유지, 피로감 감소

## 전투 (04_Combat)

- **Stratagem 코드 업그레이드** — Helldivers 2의 스트라타젬 참고: 런마다 Cat-Onion 전용 "콤보 스킬"을 선택 → 예: "Cat이 대쉬 직후 Onion이 사격하면 데미지 2배" 같은 연계기
- **드릴 돌진** — Pepper Grinder 참고: Cat의 대쉬를 "드릴 돌진"으로 리스킨 가능성 → 대쉬 중 충돌 시 데미지 + 관통 → 이동기가 곧 공격기로 기능
- **패리 → Onion 특수탄 연계** — Pepper Grinder의 단일 메카닉 완성 철학: 패리 성공 시 Onion이 일정 시간 동안 관통탄 발사 → 패리를 더 능동적으로 노리게 만드는 보상 설계

## 스토리 (05_Story)

- **분리된 자아** — 한 몸에 두 의식이 공존하는 설정: Cat은 직진 본능, Onion은 계획적 성격 → 대화 로그에서 두 캐릭터가 서로 말다툼하는 장면으로 서사 전달
- **Onion의 고향으로** — 적군이 농장에서 Onion을 납치해 Cat이 구출 → "같은 몸이 된 이유"가 사고가 아닌 Cat의 선택 → 감정적 연대감
- **프렌들리 파이어 죄책감** — Helldivers 2에서 팀원 오폭이 웃음이 되듯: 게임오버 화면에 Cat과 Onion의 코믹한 말싸움 대사 삽입 → 패배도 유쾌한 경험으로

## 기술 메모

- **Shared Body Camera Framing**: `aimWeight = 0.35f`, `maxOffset = 3f` 수치를 CameraAimAnchor 컴포넌트에 직접 넣고 Cinemachine Follow 타겟으로 사용. 일시정지 중엔 앵커를 캐릭터 위치로 고정하는 것을 잊지 말 것. Cinemachine Confiner2D로 방 경계 동시 설정.
- **Asymmetric HUD Layout**: Cat 정보(HP, 대쉬)는 왼쪽 하단, Onion 정보(씨앗, 실드)는 오른쪽 하단. 씨앗은 숫자 대신 아이콘 5개 나열이 직관적. Canvas Scaler Reference = 640×360 (Pixel Perfect Camera와 동일), 모든 HUD 스프라이트 PPU 32 / Point Filter 필수.
