## 캐릭터 (01_Characters)

- **JoyCon 자동 배분 모드** — Switch porting 참고: Switch에서 JoyCon이 분리되면 자동으로 Cat = JoyCon L / Onion = JoyCon R에 배정하는 "Switch 협동 모드" 지원. `CoopInputLayout`에 JoyCon 가로 컨트롤 스킴만 추가하면 구현 가능. 플레이어가 따로 설정할 필요 없이 JoyCon을 나눠 가지면 바로 시작되는 경험이 핵심

- **역할 특화 보스 반응** — Rabbit and Steel 참고: 특정 보스가 "Cat을 향한 패턴"과 "Onion을 향한 패턴"을 **동시에** 섞어 내보냄. 예) 보스가 가운데에서 Cat 쪽으로 돌진 예고 + 동시에 Onion 쪽으로 탄막 발사 → 양쪽 모두 각자 처리해야 함. 현재 보스 패턴은 비구분 — 이 레이어 추가 시 협동 긴장감 폭발. `EnemyAttack`에 `TargetPreference.Cat/Onion/Any` 필드 추가

- **1인 플레이 지원 힌트** — Rabbit and Steel 참고: 1인이 고양이+양파 모두 제어하는 솔로 모드 (Tab으로 제어 전환). 보스 패턴이 1인일 때 양쪽 위협을 혼자 처리해야 하므로 난이도가 올라가지만 불가능하지는 않음. `CoopInputLayout`에 "Solo" 모드 추가 → 한 플레이어가 두 캐릭터 입력 모두 처리

## 적 (02_Enemies)

- **역할 지정 추적 적** — Rabbit and Steel 참고: 일부 적이 "Cat만 추적"하거나 "Onion만 추적"하는 특성 추가. Cat이 Onion을 지키러 달려가야 하는 상황 창출. `ModularEnemy` 특성에 `TargetPreference` 추가, `EnemyBuilder.cs` 표 한 줄로 지정 가능

- **세트 방해 적** — 세트 알고리즘 참고: 장비 효과를 **N초 동안 봉인**하는 특성 (세트 카운트는 그대로, 효과만 차단). 예) "마법사 봉인" 적이 Onion에게 노란 탄을 맞히면 마법서 스킬 15초 사용 불가. 장비 효과가 막힌 상태가 HUD에 아이콘으로 표시. `RunData`에 `sealedEffects` 타이머 딕셔너리 추가

- **페어 수호 적** — 세트 알고리즘 참고: "두 마리가 함께 있으면 서로에게 방어막" 특성. 한 마리씩 따로 죽여야 함 → Cat이 한 마리를 멀리 유인하는 동안 Onion이 다른 마리를 처리하는 협동 패턴 유도. 기존 `GrantWard` 특성을 "범위 내 같은 종류 적에게 실드 부여"로 확장

## 맵·런 구조 (03_Maps)

- **세트 테마 보물방** — 세트 알고리즘 참고: 특정 세트의 아이템만 나오는 "테마 보물방" 추가. 입구에 세트 아이콘이 표시되어 "들어가면 Flame 세트 아이템 3장 중 1장"임을 예고. 의도적인 세트 빌드를 구성하도록 유도. `ChestRewardRoom`에 `forcedSetFilter` 옵션 추가

- **Switch 단말 1대 협동** — Switch porting 참고: JoyCon 분리 후 화면을 좌/우로 **소프트 스플릿**하거나 (좁은 화면에서), 혹은 현재처럼 전체 화면 공유하되 각자 조이스틱/버튼이 분리. OnionCat의 공유 뷰는 Switch 단말 1대로 2인 플레이에 이미 적합 → 설정 화면에서 "Switch 단말 공유 모드" 토글만 추가

- **스테이지 간 도전 목표** — Rabbit and Steel 참고: 런 시작 시 "이번 런 도전: Sun 세트 6단계 달성" 같은 선택적 도전 목표 제시 (달성 시 파편 +3 보너스). 강제가 아니므로 기존 자유 빌드 방해 안 함. `RunChallenge.cs` 신규, `DungeonManager`가 런 시작 시 랜덤 1개 뽑아 제시

## 전투·협동 (04_Combat)

- **동시 공격 보너스 "합동 타격"** — Rabbit and Steel 참고: Cat과 Onion이 **0.3초 안에 동일한 적을 동시에** 공격하면 그 공격이 "합동 타격"으로 판정, 데미지 ×1.8 + 합동 게이지 +20. 현재 협동 콤보(1초 안에 번갈아 = ×1.5)와 구분되는 더 좁은 동시성을 요구하는 고급 기법으로 포지셔닝

- **색상 탄막 3분류 확장** — Rabbit and Steel 참고: 현재 노랑(패링)/빨강(회피) 외에 **주황색 탄막** 추가 ("어느 한 명만 막으면 됨" — 둘 중 누가 처리해도 OK, 하지만 혼자 감당 불가). Cat이 대쉬로 통과하면서 Onion이 실드로 막는 식의 역할 분담 유도. `TelegraphColor.OrangeShared` 추가

- **세트 동기화 합동기** — 세트 알고리즘 참고: Cat과 Onion이 **같은 세트 아이템을 각자 1개 이상** 들고 있으면 합동기 효과가 그 세트에 맞게 변형. 예) 둘 다 Flame 세트 아이템 보유 → 합동기가 화염 폭풍으로 바뀜. 세트 테마 빌드를 의식적으로 맞추는 동기 추가. `JointUltimate.cs`에 `dominantSet` 감지 로직

## 아이템·세트 (05_Items)

- **크로스 페어 장비** — Rabbit and Steel + 세트 알고리즘 참고: "이 아이템과 동일 세트의 상대방 장비를 들고 있을 때 효과 발동" 장비 추가. 예) Cat의 Sun 무기 + Onion의 Sun 마법서 → "한 명이 공격할 때 상대방도 +5 데미지 추가". 두 플레이어가 의식적으로 세트를 맞추도록 유도. `GearEffect`에 `requiresPartnerSameSet` 조건 추가

- **레벨 집중 세트 가속기** — 세트 알고리즘 참고: 장비 효과 중 "같은 세트 아이템을 레벨업할 때마다 세트 카운트 +0.5 추가 인정" 패시브 추가. 중복을 강화하는 플레이 스타일에 보상 → 넓게 모으기 vs 집중 강화 선택지

- **파괴 가능 세트 링크** — 세트 알고리즘 참고: 전설 등급 장비 "세트 앵커" — 이 아이템이 분해되면 같은 세트의 다른 장비도 효과 레벨이 1 떨어짐. 리스크가 있는 대신 보유 중에는 세트 전체 효과 +1단계 보너스. 분해 전 경고 UI 필수

## 스토리·메타 (07_StoryMeta)

- **세트 해금 퀘스트** — 세트 알고리즘 참고: 온실에서 "Sun 세트 4단계 보너스를 받고 보스 처치" 같은 세트 집중 도전 퀘스트 추가. 클리어 시 해당 세트 관련 장비 1종 온실에서 해금. 특정 빌드를 경험해 보게 유도

- **Switch 첫 접속 협동 튜토리얼** — Switch porting 참고: Switch에서 게임을 처음 시작할 때 "JoyCon을 나눠 가지세요" 안내 화면 + JoyCon 분리 감지 시 자동으로 2인 모드 진입 안내. 혼자 하는 줄 알고 시작하다가 2인이 됐을 때 자연스러운 온보딩

- **세트 여정 런 결과 화면** — 세트 알고리즘 + Rabbit and Steel 참고: 런 결과 화면에 "이번 런 주요 세트" 파이 차트 또는 바 그래프 추가. "Sun 4 · Frost 2 · Wind 2" 같은 요약 표시 → 자기 빌드가 어떤 세트 중심이었는지 한눈에. 다음 런에서 의도적으로 다른 세트를 시도하게 유도

## 기술 메모

- **세트 보너스 집계**: `CombatModifiers.Has(세트, 단계)`는 이미 구현됨. 레벨 가중치(`count += item.level`) 적용 여부는 플레이테스트 필요 — 레벨업에 세트 가속 효과가 생기는 것이 재미있는지 확인. 크로스 시너지(`Has(SetA, 2) && Has(SetB, 2)`)는 if 조건만 추가하면 즉시 구현 가능

- **Nintendo Switch 포팅**: 지금 당장 할 일은 아니지만 **IL2CPP 빌드 확인** 하나만 주기적으로 체크해 두면 나중에 큰 수고가 없음. Reflection을 사용하는 디버그 코드(`typeof(...).GetProperty(...)`)가 런타임 빌드에 포함되지 않도록 `#if UNITY_EDITOR` 가드 확인
