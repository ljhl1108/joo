## 캐릭터 (01_Characters)

- **"Crop 패리 등급 시스템 (3단계 판정)"** — Eldest Souls Shatter 참고: 패리 타이밍을 3단계로 구분. Early(0.1초 앞)=실패, Normal(±0.05초)=일반 패리(투사체 반사만), Perfect(±0.025초)=퍼펙트 패리(투사체 반사 + 에너지 충전 + 반격탄 강화). 타이밍 판정은 `ParryWindowData` ScriptableObject에 적별로 설정 → 보스 추가 시 값만 변경.
- **"적 어그로 수신 표시 — Cat/Crop 색상 핀"** — 인지 시각화 시스템 참고: 적이 Cat을 쫓는 중이면 머리 위 주황 화살표, Crop을 쫓는 중이면 하늘색 화살표 표시. 두 플레이어가 서로 "저 적 나 쫓아!" 라고 외치지 않아도 UI로 파악 → 소통 부담 감소. 화살표는 WorldSpace Canvas, `SortingLayer = "EnemyUI"`.
- **"Cat 대시 방향 예측 표시"** — Eldest Souls 카메라 줌 참고 + 인지 시각화 응용: Cat이 대시 버튼을 꾹 누르면 대시 예정 방향에 0.12초간 반투명 고스트 이미지 표시. 대시 방향 선택을 Crop도 볼 수 있어 협력 포지셔닝 가능. `DashPreviewGhost.cs`: 스프라이트 알파 0.3 + 이동 방향으로 0.5유닛 오프셋.

## 적 (02_Enemies)

- **"보스 2인 역할 분담 페이즈 전환"** — Eldest Souls 페이즈 전환 직접 참고: 보스 HP 66% 시 2페이즈 전환 연출(화면 암전 1초). 2페이즈에서는 보스 전면에 Cat 슬래시 불가 투명 갑옷 생성 — Crop이 원거리로 갑옷 브레이크 후 Cat 근접 가능. HP 33%에서 3페이즈: 전방 원거리 결계 생성 — Cat이 보스에게 달라붙어야 Crop이 안전하게 사격. 각 페이즈 전환 시 캐릭터 힌트 대사 자동 출력.
- **"인지 상태별 다른 행동 패턴"** — 인지 시각화 시스템 참고: Idle 상태의 적은 느리게 순찰, Suspicious 상태에선 이동 속도 +30%, Alerted("!") 직후 0.3초 경직(플레이어에게 전술적 창문 제공), Chasing 상태에선 최고 속도. 이 경직 0.3초가 Cat의 카운터 공격 타이밍. `EnemyAwarenessState`와 `EnemyStateMachine`을 이벤트 버스로 연결.
- **"패리 가능 투사체 시각 차별화"** — Eldest Souls 패리 윈도우 색상 참고: 일반 투사체=흰색, 패리 가능 투사체=파란색 글로우 테두리. Crop 플레이어는 파란 투사체를 보면 자동으로 패리 준비 → 학습 곡선 완만화. `ProjectileType.Parriable` 열거형에 따라 `SpriteOutline` 색상 동적 변경.

## 맵 (03_Maps)

- **"리더보드 방 — 거울 속 세계"** — UGS 리더보드 + 스토리 결합: 특수 방 중 "리더보드 거울방"이 런 중 1~2번 등장. 거울 앞에 과거 최고기록 플레이어의 고스트(흰 실루엣)가 서 있음. 고스트를 따라잡으면 현재 런이 개인 최고기록 페이스임을 시각화. `RunGhostReplay`: 이전 런 위치를 JSON으로 저장 → 재생.
- **"보스 전투방 사전 경고 구조"** — Eldest Souls 보스 진입 구조 참고: 보스 방 직전 방에는 항상 의자 2개(Cat용 큰 의자, Crop/화분용 작은 의자)가 있고, 두 플레이어가 각 의자에 접촉하면 보스 문이 열림. 의자에 앉으면 체력 소량 회복 + 업그레이드 리마인드 팝업. 보스 진입 전 준비 의식 → 긴장감 조성.
- **"층별 인지 거리 변화"** — 인지 시각화 + 던전 구조 결합: 얕은 층(1~2층)에서는 적의 인지 거리가 짧아 스텔스 접근 가능. 깊은 층(5층+)에서는 인지 거리가 2배 → 방 입장 즉시 전투. 이 변화를 게임 내 환경 설명으로 표현(어두운 조명 → 적이 더 날카로워졌다). `FloorDifficultyConfig.awarenessMultiplier`.

## 전투 (04_Combat)

- **"보스 약점 타이밍 창 (Vulnerability Window)"** — Eldest Souls Shatter 후 반격 참고: 패리 성공 시 보스가 0.5초 무력화. 이 시간 동안 Cat 슬래시 데미지 3배, Crop 투사체 2배. 무력화 표시: 보스 전신 흰색 플래시 + 타이머 링 UI. 두 플레이어가 동시에 집중 공격하는 협력의 절정 순간을 자연스럽게 만듦.
- **"어그로 스위칭 전술 — 도발 기술"** — 인지 시각화 응용: Crop에게 "도발 투사체" 스킬 (업그레이드). 발사 시 맞은 적의 어그로가 Crop으로 강제 전환 + 인지 게이지 즉시 MAX. Cat이 보스 뒤를 도는 동안 Crop이 어그로를 붙잡는 전술적 협력을 명시적으로 지원. 쿨다운 6초.
- **"사망 연출 + 리더보드 제출 통합"** — UGS 리더보드 참고: 보스 처치 성공 시 화면 암전 후 "클리어! XX:XX.XXX" 표시와 동시에 백그라운드에서 UGS 제출. 2~3초 후 "세계 순위: OO위" 자연스럽게 페이드인. 실패 시 제출하지 않음. 이 흐름으로 리더보드 UI가 방해 요소가 아닌 성취 강화 요소가 됨.

## 스토리 (05_Story)

- **"보스 처치 후 능력 흡수 대사"** — Eldest Souls 흡수 개념 + OnionCat 세계관 결합: 보스 처치 시 Crop(양파)이 보스의 에너지를 흡수해 성장. 보스 유형에 따라 다른 대사: 불 속성 보스 → "따뜻해졌어... 이파리가 붉게 물들고 있어", 얼음 속성 → "차갑지만 맑아. 뿌리가 단단해졌어". 픽셀아트에서 Crop 스프라이트 색상 팔레트 일부 변경으로 시각적 성장 표현.
- **"글로벌 리더보드 속 세계 — 메타 내러티브"** — UGS 리더보드 세계관 통합: 게임 내 리더보드를 "다른 차원의 OnionCat들이 달린 기록"으로 설명. 로딩 화면 팁: "어느 평행 세계에선 고양이와 양파가 이 던전을 8분 21초 만에 클리어했다고 한다." → 리더보드 1위 기록을 세계관으로 편입. 세계관 몰입을 깨지 않으면서 온라인 기능을 자연스럽게 소개.
- **"패리 횟수에 따른 Crop 성장 일지"** — Eldest Souls 빌드 다양성 참고: 런 클리어 후 결과 화면에 Crop의 성장 일지 1줄 출력. 패리 0~5회: "오늘도 살아남았다", 6~15회: "방어를 배우고 있어", 16+회: "이제 두렵지 않아. 나는 방패가 되었다". 패리 숙련도가 내러티브로 연결 → 반복 플레이 동기 강화.

## 기술 메모

- **Enemy Awareness Alert Visual**: MVP는 단 3줄이면 된다: `if(canSeePlayer) _awareness += fillSpeed * dt; else _awareness -= decaySpeed * dt;` + `if(_awareness >= 1f) ShowExclamation(); else if(_awareness > 0.1f) ShowQuestion();`. WorldSpace Canvas로 "!" / "?" 텍스트만 띄우는 것부터 시작. 이것만 해도 전투 명확성이 크게 올라간다. OnionCat에서 가장 먼저 추가할 적 UI 기능.
- **Online Leaderboard UGS**: 구현 순서가 중요하다. (1) UGS 대시보드에서 프로젝트+리더보드 생성 → (2) Package Manager에서 패키지 설치 → (3) `UnityServices.InitializeAsync()` + `SignInAnonymouslyAsync()` → (4) 클리어 시 `AddPlayerScoreAsync()` 한 줄. 이 4단계면 최소 동작한다. UI는 나중에. 주의: 인터넷 없을 때 예외 처리(`try-catch`) 필수, 안 하면 게임이 멈춤.
