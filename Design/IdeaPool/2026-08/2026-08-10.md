## 캐릭터 (01_Characters)

- **"퍼펙트 패리 에너지 축적"** — GRIME 흡수 패리 참고: Crop이 일반 패리(투사체 반사)에 성공하면 "패리 에너지" 소량 충전, 퍼펙트 타이밍 패리 성공 시 대량 충전. 에너지가 꽉 차면 다음 투사체가 2~3배 강화된 "반격탄"으로 발사. `ParryEnergyMeter`로 UI에 막대 표시. 두 플레이어가 "Crop 에너지 찼어!" 소통을 자연스럽게 유도.
- **"Cat 슬래시 방향 표시 화살표"** — 방향 스프라이트 시스템 참고: Cat이 슬래시를 준비하는 0.15초 동안 슬래시 예정 반원 방향에 반투명 화살표 표시. Cat은 이동 방향 기반 4방향으로만 슬래시 → 화살표가 어느 방향인지 Crop 플레이어도 보고 조준 협력 가능. `SlashPreviewArc` 스크립트로 LineRenderer 4개 사전 렌더링.
- **"상하반신 독립 방향 — 유기적 캐릭터 표현"** — AvatarMask 기반 레이어 분리 참고: Cat의 다리(하반신)는 이동 방향, Crop의 상체(작물/이파리)는 마우스 방향으로 각각 독립 회전. 한 몸에서 두 의지가 따로 움직이는 시각적 표현이 "한 몸 두 플레이어" 컨셉을 직관적으로 전달. 애니메이터 UpperBody 레이어 분리로 구현.

## 적 (02_Enemies)

- **"색깔 테두리 약점 표식 적"** — GRIME 흡수 가능 표식 참고: 근접 전용 약점 적은 빨간 스프라이트 아웃라인, 원거리 전용 약점 적은 파란 아웃라인. 색맹 접근성을 위해 아웃라인 외에 아이콘(주먹/투사체)을 머리 위에 소형 표시. `EnemyWeaknessIndicator.cs`가 `EnemyWeaknessType` 열거형에 따라 자동으로 아웃라인 색 변경.
- **"패리 가능 공격 예비 동작 적"** — GRIME 패리 윈도우 설계 참고: 일부 원거리 적이 발사 직전 0.3초 동안 투사체를 "충전"하는 글로우 이펙트 표시. Crop이 이 타이밍을 보고 실드를 올리면 패리 성공 가능. "충전 → 발사" 2단계 텔레그래프로 패리 타이밍 학습 곡선 완만하게 유지.
- **"방향별 약점 적 (등을 보여야 처치 가능)"** — 방향 스프라이트 + GRIME 방향성 참고: 전면에 갑옷을 두른 적으로, Cat의 슬래시가 정면에서 맞으면 0 데미지. Crop이 원거리 투사체로 어그로를 끌어 등을 돌리게 만든 뒤 Cat이 후면을 슬래시로 처치. 협력 필수 적의 고전적 패턴을 방향 스프라이트 시스템과 결합.

## 맵 (03_Maps)

- **"런 시작 방 — 항상 안전한 연습방"** — Run Start Screen + 협력 준비 참고: 매 런의 첫 번째 방은 적이 없고, 목재 허수아비 2개(Cat 근접용 / Crop 원거리용)만 있는 연습방. 두 플레이어가 각자 컨트롤 감각을 5초 맞추고 출구 문을 통과. 로딩 시간 없이 즉시 입장 가능하도록 RunStart 씬과 별도로 첫 방 씬을 미리 로드.
- **"방향별 위험 지형 방"** — 방향 스프라이트 참고: 스파이크가 특정 방향으로만 작동하는 방 (위에서 아래로 내려오는 스파이크, 오른쪽에서 왼쪽으로 튀어나오는 창). 이동 방향을 고려하지 않으면 맞는 구조 → Cat의 방향 선택이 단순 이동 이상의 전술적 의미를 가짐.
- **"흡수 제단방 — Crop 패리 특화"** — GRIME 흡수 개념 참고: 특수 방에 "에너지 제단"이 있고, 이 방에서 Crop이 퍼펙트 패리를 5회 성공하면 런 한정 특수 업그레이드를 제공. 패리 플레이를 적극적으로 장려하는 방 타입. 방 완료 조건: `ParryEnergyMeter.PerfectParryCount >= 5`.

## 전투 (04_Combat)

- **"패리 흡수 → 임시 특성 (1방 한정)"** — GRIME 흡수 특성 소규모 버전: Crop이 퍼펙트 패리 성공 시, 흡수한 투사체 유형에 따라 이번 방 한정 버프 발동. 독 투사체 패리 → 다음 투사체에 독 추가, 불 투사체 패리 → 다음 투사체 스플래시. 복잡한 흡수 시스템을 "한 방 한정"으로 단순화해 초보자도 이해하기 쉽게.
- **"4방향 슬래시 방향 잠금 + 코어 룰"** — 방향 스프라이트 기반 Cat 조작 설계: Cat의 슬래시는 이동 방향 기반 4방향으로 잠금. 복잡한 360° 회전 없이 심플하게 "어디로 이동하냐가 어디를 공격하냐"와 일치. 단, 슬래시 발동 0.1초간 이동 방향이 고정되어 실수 가능성 방지 (`lockDirectionOnSlash`).
- **"적 등 방향 체크 — 후면 보너스 데미지"** — 방향 스프라이트 + GRIME 방향성 적용: 적의 `FacingDir`을 런타임으로 추적. Cat이 공격 시 적의 뒤 방향이면 데미지 1.5배 + 반드시 넉백. 등 방향 = (적 facing + 2) % 4 로 계산. 협력 없이도 개인 기술로 보너스를 노릴 수 있는 단독 플레이 보상.

## 스토리 (05_Story)

- **"런 시작 플레이버 텍스트 — 런 번호 반영"** — Run Start Screen 참고: 런 1~3회는 "첫 걸음", 10회 이후는 "이제 익숙해졌나", 50회 이후는 "이젠 전설의 고양이". 런 누적 횟수(SaveData)에 따라 플레이버 텍스트가 변화. 많이 죽을수록 더 성숙해지는 내러티브 — 퍼마데스의 고통을 유머로 승화.
- **"GRIME 세계관 역참조 — 흡수하는 세계의 생물들"** — GRIME의 유기체+광물 혼합 세계관 참고: OnionCat 세계에서 양파는 단순 채소가 아닌 "대지의 감정을 흡수해 자란 식물". 각 런의 보스를 쓰러뜨리면 Crop이 그 에너지를 흡수해 새로운 이파리/색상으로 성장 → 메타 진행의 시각적 표현.
- **"방향을 잃은 고양이"** — 방향 스프라이트 시스템에서 영감: 처음 시작은 동쪽(오른쪽)을 바라보는 Cat. 매 런 처음 Cat이 왼쪽으로 이동하면 "하지만 양파는 오른쪽을 바라본다" 같은 소소한 대사. 메카닉과 스토리가 일치하는 소소한 세계관 일치 포인트.

## 기술 메모

- **TopDown Directional Sprite System**: OnionCat에서 가장 먼저 구현할 것은 Cat 4방향 + `DirectionalAnimator.cs`의 정지 시 마지막 방향 유지 로직. `_lastDir`을 저장해 이동 입력이 0이 되어도 마지막 바라보던 방향의 Idle 애니메이션이 유지되도록 해야 슬래시 방향이 의도대로 나옴. 그 다음 Crop 상반신 AvatarMask 레이어 분리 적용.
- **Run Start Screen**: 백그라운드 `LoadSceneAsync` + `allowSceneActivation = false` 패턴이 핵심. BeginRun 버튼 누르기 전까지 씬이 완전히 로드되어 있어야 즉각 전환 가능. MVP는 4단계(페이드인 → 스프라이트 표시 → 버튼 → 페이드아웃)로 구현하고, P1/P2 Ready Check는 기본 멀티플레이어 플로우 테스트 후 추가.
