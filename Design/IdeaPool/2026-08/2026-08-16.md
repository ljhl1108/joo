## 캐릭터 (01_Characters)

- **역할 전용 패시브 잠금** — Blightbound 역할 고정 참고: P1(고양이) 업그레이드 선택지에는 원거리 강화 항목이 아예 등장하지 않음. P2(파/양파) 선택지에는 대시·근접 강화 없음. "역할을 강화하되 역할을 벗어날 수 없게" → 런 후반부에도 P1=근접 전문가, P2=원거리 전문가 정체성 유지. 구현 힌트: `UpgradePool.FilterByPlayerRole(PlayerRole.P1)` → P1 전용 선택지만 반환.

- **콤보 감지 수동 능력** — 콤보 킬체인 참고: 특정 업그레이드 획득 시 "콤보 감지" 스킬 활성화 — 현재 콤보가 5 이상이면 P1 공격에 붉은 잔상 이펙트, P2 투사체에 전기 아크 이펙트 자동 추가. 플레이어가 "콤보가 터지고 있구나"를 시각적으로 체감. 구현 힌트: `ComboKillChainManager.GetCurrentTier() >= 2` 판정 → 파티클 이펙트 활성화.

- **안개 적응 체질** — 안개 시스템 참고: 안개 방에서만 발동하는 P1 특수 패시브 업그레이드. "야간 시각" — P1의 시야 반경이 안개 방에서 5 유닛으로 확장 (기본 3.5). 안개 방을 자주 만나면 이 업그레이드가 매우 강해지는 빌드 경로. 구현 힌트: `FogRoomManager.OnEnterFogRoom` 이벤트 → `PlayerVisionLight.visionRadius += 1.5f`.

## 적 (02_Enemies)

- **역할 면역 방패병** — Blightbound 역할 카운터 참고: 정면에 방패를 든 적. P2(원거리) 투사체는 방패에 막혀 0 피해. P1(근접) 근접 공격으로만 방패 파괴 가능 → 파괴 후 P2 마무리 딜. 자연스러운 근접→원거리 순서 강요. 구현 힌트: `ShieldEnemy.shieldActive` 상태 시 `DamageType.Ranged` 피해 = 0, `DamageType.Melee` 피해로만 `shieldActive = false` 전환.

- **안개 은신 정찰병** — 안개 시스템 참고: 안개 방에서만 등장하는 특수 적. 플레이어 시야 바깥에 있을 때 투명(알파 0). 시야 원 안에 들어오면 점점 불투명해지며 모습 드러냄. 먼저 "소리(발소리 SFX)"로 위치를 알려주고, P2가 커서로 조준해 시야에 잡아야 P1이 공격 가능. 구현 힌트: `SpriteRenderer.color.a` = `VisionOverlapRatio` (0~1), 방 외부에서는 스폰 안 함.

- **콤보 붕괴자** — 콤보 시스템 참고: 체력이 많지 않지만 처치에 3초 이상 걸리면 팀 콤보를 강제 리셋하는 "디버퍼 적". 빠르게 처치하지 않으면 쌓아 올린 콤보가 날아감 → 우선순위 판단 소통 유발. "이거 빨리 잡아야 해!" 구현 힌트: `ComboDisruptorEnemy`: `OnSurviveDuration(3f)` → `ComboKillChainManager.Instance.ResetCombo()`.

## 맵 (03_Maps)

- **역할 분리 복도** — Blightbound 역할 분업 참고: 복도가 좌우로 갈라지는 Y자 구조. 왼쪽 통로에는 근접 약점 적, 오른쪽 통로에는 원거리 약점 적만 스폰. P1은 왼쪽, P2는 오른쪽 담당 → 동시에 각자 클리어 후 합류. "같이 가는 로그라이크"가 아닌 "잠깐 나뉘는 협동"의 긴장감. 구현 힌트: 방 프리팹 내 `LeftSpawnGroup`(MeleeWeakEnemy), `RightSpawnGroup`(RangedWeakEnemy) 별도 배치.

- **안개 탐험 보물방** — 안개 + 탐험 참고: 완전히 어두운 방. 두 플레이어가 각자 시야를 넓혀가며 탐험해야 보물 상자 위치를 발견. 상자는 항상 플레이어 시야가 닿지 않는 구석에 배치 → "저기 뭔가 있어!" 소통 필수. 방 클리어 조건: 상자 획득이 아니라 일정 면적 탐험 (%). 구현 힌트: `FogRoom.revealedTiles / totalTiles >= 0.7f` 시 클리어 판정.

- **콤보 챌린지 방** — 콤보 시스템 참고: 방 입구에 "이 방의 도전: 콤보 10 달성 시 보너스 보상" 현수막 텍스트. 적이 파도로 밀려오되 파도 간격이 짧아 콤보 유지 가능한 설계. 협동 처치 유도를 위해 적 반수는 근접 약점, 반수는 원거리 약점으로 섞어 스폰. 달성 시 골드+25%짜리 특수 상자 등장. 구현 힌트: `ChallengeRoomController.targetCombo = 10` → `ComboKillChainManager.OnComboUpdated` 구독.

## 전투 (04_Combat)

- **협동 콤보 특수 이펙트** — Blightbound 공동 처치 + 콤보 시스템 참고: P1 근접 + P2 원거리 둘 다 피격에 기여한 "협동 처치" 판정 시 일반 콤보보다 더 화려한 이펙트. 특수 폭발 파티클 + 짧은 슬로모션(0.1초) + "TEAMWORK!" 텍스트 팝업. 협동을 게임이 직접 칭찬하는 구조. 구현 힌트: `EnemyHealth.OnCoopKill` 이벤트 → `CoopKillVFX.Trigger(position)` + `Time.timeScale = 0.1f` (0.1초 후 복구).

- **콤보 티어 임계 스킬** — 콤보 킬체인 참고: 특정 업그레이드 장착 시 콤보 10 달성 순간 P1 다음 근접 공격이 자동으로 "회전 참격"(360도, 주변 전체 피해) 발동. 콤보를 쌓는 것 자체가 다음 강공격 준비 단계가 됨 → 전투 리듬 생성. 구현 힌트: `ComboKillChainManager.OnComboTierReached(tier >= 3)` → `P1MeleeController.NextAttackIsAOE = true`.

- **안개 방 회피 패널티** — 안개 + 전투 참고: 안개 방에서 시야 바깥의 적에게 피격 시 피해 1.5배 적용 ("어둠 속 기습"). "시야를 확보하지 않으면 더 위험하다"는 강력한 동기 부여. P2가 커서 시야로 적극적으로 주변 확인하는 행동이 생존에 직결됨. 구현 힌트: `PlayerHealth.TakeDamage()` 내 `FogRoomManager.isInFogRoom && !IsInPlayerVision(attackerPos)` 판정 시 `damage *= 1.5f`.

## 스토리 (05_Story)

- **빛과 어둠의 기억** — 안개 + 스토리 참고: 안개 방에서 가끔 과거 기억 플래시백 텍스트 팝업 연출. "이 어둠은 익숙해... 예전에도 이런 곳이 있었어." — 고양이(P1)의 독백. 파(P2)는 같은 순간 "나는 여기가 싫어. 빨리 지나가자." → 같은 공간, 다른 감정 반응. 이야기 없이도 캐릭터 개성 전달. 구현 힌트: `FogRoomManager.OnEnterFogRoom` → 랜덤 대사 하나 `DialoguePopup.Show(duration: 3s)`.

- **콤보와 숙련의 서사** — 콤보 시스템 + 스토리 참고: 게임 오버 화면에서 "최고 콤보" 통계 표시. 초반 런에서 콤보 3~5가 최고였던 플레이어가 런을 거듭해 콤보 20+ 달성 시 오프닝 대사 변경. "처음엔 서툴렀지만... 이제 우리 사이엔 말이 필요 없어." → 콤보 수치가 관계 발전의 증거.

- **역할 집착 빌런** — Blightbound 역할 고정 참고: 최종 보스는 "역할을 넘어서려는 자"를 상징. 근접도 원거리도 모두 혼자 하려다 실패한 존재 → 둘이 나눠서 역할을 지키는 P1+P2와 대비. "하나가 되어도, 하나가 하려 하면 안 돼." 테마 연결. 보스 공격 패턴: 전 방향 무차별 공격 → 역할 없이 무분별한 폭력의 표현.

## 기술 메모

- **Fog of War System**: OnionCat 구현 순서 → ① `URP Global Light 2D` Intensity를 0.05f로 내리는 것만으로 기본 어두운 방 완성 ② P1/P2 각각에 `Light 2D` 컴포넌트 부착 (P1=Point, P2=Spot+마우스 회전) ③ `FogRoomManager.EnterFogRoom()` / `ExitFogRoom()` 이벤트 연결 ④ 런당 최대 2회 안개 방 등장 제한. 가장 중요한 포인트: **URP가 이미 설치되어 있으므로 추가 에셋 없이 Light 2D만으로 전체 구현 가능** → 초보자도 빠르게 적용 가능한 시스템.

- **Combo Kill Chain System**: 초보자를 위한 **최소 구현 순서** → ① `ComboKillChainManager` 싱글턴 빈 오브젝트에 배치 ② `EnemyHealth.OnDeath()` 마지막 줄에 `ComboKillChainManager.Instance.RegisterKill()` 한 줄 추가 ③ 텍스트 하나짜리 `ComboUI` 만들어 콤보 숫자만 표시 ④ 나중에 협동 처치 감지(`wasHitByP1 && wasHitByP2`)와 골드 배율 추가. 콤보 유지 시간은 2.5초에서 시작 → 플레이테스트 후 조정.
