## 캐릭터 (01_Characters)

- **해골 교체 → 스탠스 교체 업그레이드** — Skul의 해골 교체 참고: 런 중 특정 아이템 획득 시 Cat이 "공세 모드"와 "수비 모드"를 R 키로 전환 가능. 공세 모드는 이동속도+10%, 수비 모드는 대시 쿨타임 -30%. Onion 방어막은 수비 모드에서만 파리 범위가 넓어짐. 구현 힌트: 업그레이드 ScriptableObject에 `enablesStanceSwitch` bool 플래그.

- **Blend Tree 방향 유지 Idle 포즈** — 탑다운 Blend Tree 구현 시: Cat이 이동 멈추면 마지막 이동 방향을 바라보는 Idle 유지 (`_lastFacingDir` 캐싱). 이를 활용해 슬래시 예비 자세(공격 직전 짧은 준비 애니메이션)를 마지막 방향 기준으로 재생. 구현 힌트: `CatAnimator.UpdateAnimationDirection()` 호출 후 Attack 레이어에서 Override.

- **Onion 등장 애니메이션 — Cat과 독립 레이어** — Cat 몸통은 이동 Blend Tree, Onion 새싹은 별도 Animator Layer (Override). 흔들리는 새싹 애니메이션(Secondary Motion 느낌)을 독립적으로 재생하면 "등에 올라탄" 느낌 강화. 구현 힌트: Animator 레이어 분리, Onion용 본 별도 마스크.

## 적 (02_Enemies)

- **"위험/보상" 함정 적 — RoR2 텔레포터 오마주** — 방 중앙에 "봉인된 보물상자"가 있고, 건드리면 적이 웨이브로 스폰. 클리어하면 보상(희귀 아이템). Cat이 근접 웨이브 처리, Onion이 원거리 지원. RoR2 텔레포터의 위험/보상 선택 재미를 방 단위로 재현. 구현 힌트: TreasureRoomTrigger 컴포넌트, 오브젝트 활성화 이벤트로 웨이브 스폰 시작.

- **"스탯 스케일링" 적 — RoR2 시간 스케일 참고** — 클리어 방 수에 비례해 적 HP/데미지 증가 (`roomsCleared * 0.1f` 배율). Skul의 층 진행처럼 5방 클리어마다 적 등급 상승 (일반→엘리트→미니보스). 구현 힌트: EnemySpawner가 RunDataManager의 roomsCleared를 참조, StatScale 계산 후 Enemy.Initialize(scale) 호출.

- **"해골 교체형" 변형 적** — Skul의 해골 교체에서 착안: 적이 죽으면 다른 형태로 부활(예: 마법사→좀비 전사). 처음엔 Onion 원거리가 약점, 부활 후엔 Cat 근접이 약점. 두 번 죽여야 완전히 제거. 협력 강제 패턴이 자연스럽게 발생. 구현 힌트: EnemyBase에 `List<EnemyPhaseData>` 페이즈 목록, 사망 시 다음 페이즈 오브젝트로 교체.

## 맵 (03_Maps)

- **"페이드 씬 전환 = 던전 층 이동 연출"** — Async 씬 로딩의 페이드 인/아웃을 층 이동 연출로 활용: 화면이 검게 페이드되는 동안 짧은 플레이버 텍스트 표시 ("지하 3층으로 내려간다..."). 로딩 시간 없애고 몰입감 유지. 구현 힌트: SceneLoader에 `loadingHintText` 파라미터 추가, 페이드 아웃 완료 후 텍스트 표시.

- **"위험 표지" 방 입구 아이콘 시스템** — RoR2의 아이템/방 정보 표시처럼 각 방 입구 위에 아이콘 표시: 해골(전투 방), 별(보물 방), 보라색 물음표(이벤트 방). 플레이어가 어느 방을 먼저 갈지 전략 선택. 구현 힌트: RoomData ScriptableObject에 `RoomType enum`, 방 입구 오브젝트에 아이콘 SpriteRenderer 추가.

- **"허브 화원" 층간 휴식 씬** — Skul의 마을 + RoR2의 스테이지 간 이동에서 착안: 층 클리어 후 짧은 "화원 씬"으로 전환 (비동기 로딩). Cat과 Onion이 쉬는 짧은 일러스트 + 업그레이드 선택. 씬을 분리하면 메모리도 정리되고 다음 던전 씬 로딩 시간 숨길 수 있음. 구현 힌트: HubScene을 별도 씬으로 분리, SceneLoader로 전환.

## 전투 (04_Combat)

- **"스케일링 아이템 시너지" 시스템** — RoR2의 아이템 스태킹처럼 OnionCat도 동일 아이템을 두 번 획득하면 효과 배율 상승: "이중 투사체" 1개(+1발) → 2개(+2발, 크기도 커짐) → 3개(+2발 + 관통). 선형 성장보다 지수 성장이 빌드 쾌감을 더 줌. 구현 힌트: ItemEffect ScriptableObject에 `perStackMultiplier float`, RunDataManager에서 스택 수 추적.

- **"모드 전환 무적 프레임"** — Skul의 해골 교체 무적처럼, 스탠스 전환 시 0.15초 무적 프레임 부여. 적의 공격 타이밍에 맞춰 전환하면 회피 효과. 초보 플레이어에게는 실수를 구제하는 쿠션, 숙련자에게는 전술적 도구. 구현 힌트: DashIFrame 시스템과 동일 패턴 재활용, `StartIFrame(0.15f)` 호출.

- **8방향 슬래시 방향 — Blend Tree 활용** — Cat의 슬래시가 마지막 이동 방향(Blend Tree `_lastFacingDir`)을 기준으로 발동. 이동 중 방향 전환 즉시 슬래시 → 적의 측면 공격 가능. 구현 힌트: `SlashHitbox.transform.rotation`을 `Mathf.Atan2(_lastFacingDir.y, _lastFacingDir.x)` 기반으로 설정.

## 스토리 (05_Story)

- **"페이드 텍스트 스토리텔링"** — 층 이동 페이드 인/아웃 시 간단한 내레이션 텍스트 표시: 층 1→2 전환 시 "냄새가 더 강해진다. 무언가 기다리고 있다." Skul의 마을 NPC 대사 + RoR2의 아이템 설명 처럼 텍스트로 세계관 전달. 구현 힌트: List<string> flavorTexts, 층 번호 기반으로 인덱싱.

- **"스케일링 위협" 내러티브** — RoR2처럼 시간이 지날수록 강해지는 적 = 게임 내 적이 플레이어를 추적하는 "사냥꾼" 존재. 각 층 클리어마다 사냥꾼의 대사 팝업: "조금 더 가까워졌다." 이것이 스케일링의 서사적 이유가 됨. 구현 힌트: 방 클리어 카운트에 따라 EventBus로 "HunterClose" 이벤트 발행, HUD에 경고 표시.

- **"해골 수집 = Onion 성장 기록"** — Skul의 해골 수집처럼 OnionCat에서 처치한 보스 수/종류를 기록 → 게임 오버 화면에서 표시. "이번 런에서 Onion은 17발을 쐈고, Cat은 43번 슬래시했다." 협력 통계로 두 캐릭터의 관계 서사 강화. 구현 힌트: RunDataManager에 catSlashCount, onionShotCount 추적.

## 기술 메모

- **Blend Tree 2D**: OnionCat Cat 캐릭터에는 `MoveX` / `MoveY` float 파라미터 + `IsMoving` bool 3개만으로 충분. 픽셀아트라면 8방향 스프라이트 없이 4방향 클립으로도 Blend Tree 사용 가능 — 대각 입력 시 가장 가까운 클립이 자동 선택됨. 슬래시 애니메이션은 별도 Override 레이어로 분리해야 이동 중 슬래시가 자연스럽게 재생됨.

- **비동기 씬 전환**: `allowSceneActivation = false`로 로딩 완료 후 페이드 아웃 시간 확보, `Time.unscaledDeltaTime` 사용으로 일시정지 중에도 페이드 동작. OnionCat 기준 씬은 MainMenu/GameScene/GameOver 3개로 최소화, 층 이동은 GameScene 재로드로 처리. 씬 전환 시작과 동시에 양 플레이어 입력 비활성화 필수 (`PlayerInput.enabled = false`).
