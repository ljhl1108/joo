## 캐릭터 (01_Characters)

- **렐릭 중심 빌드 방향성** — Slay the Spire 렐릭 참고: 첫 번째 보물방에서 얻는 렐릭이 그 런의 방향을 결정. 예: "Cat의 대시 후 공격 데미지 +50%" 렐릭을 얻으면 이후 업그레이드를 대시 콤보 위주로 선택하게 됨. 매 런마다 다른 "정체성" 형성. 구현: `RelicSO : ScriptableObject` → `OnEquip()` 이벤트 구독으로 Cat/Onion 스탯 수정.

- **어센션 성장 커브** — Slay the Spire 어센션 참고: 첫 클리어 = 일반 난이도, 이후 어센션 1~5 단계적 해금. 단계마다 "적 HP+10%", "초반 엘리트 방 강제 등장", "방 사이 체력 회복 없음" 등 패널티 추가. 초보자 = 기본 클리어로도 성취감, 숙련자 = 어센션 5 도전. 구현: `AscensionLevel` int (RunDataSO에 저장), 게임 시작 시 배율 적용.

- **저주 아이템 선택 딜레마** — Slay the Spire 저주 카드 참고: 강력한 업그레이드 대신 "런 내 Cat 대시 쿨타임 +2초" 저주를 받는 이벤트 등장. 팀 협의로 "감수할 만한가?" 결정. 구현: `NegativeModifierSO` 리스트 → `RunDataSO.activeDebuffs`, 매 방 시작 시 PlayerController에 적용.

## 적 (02_Enemies)

- **정보 공개형 적 (Slay the Spire 적 의도 표시)** — Slay the Spire 참고: 적의 다음 행동을 아이콘으로 미리 표시. "이 적 다음 턴 원거리 공격" → Onion이 방패 준비, "근접 돌진 예정" → Cat이 대시 타이밍 잡기. 협동 전략 심화. 구현: `Enemy_Telegraph_System.md` 이미 있음 → 아이콘 머리 위 말풍선 형태로 표시.

- **엘리트 + 렐릭 드롭 보장 적** — Slay the Spire 엘리트 참고: 특정 방에 엘리트 적 등장, 처치 시 렐릭 1개 보장. 일반 방보다 훨씬 강하지만 그만큼 리워드가 큼. 플레이어가 엘리트 방에 도전할지 우회할지 선택(InRun_Branch_Map_System 연동). 구현: `EnemySpawner`에 `EliteFlag` → 처치 시 `RelicDropper.DropRelic()`.

- **저주 이벤트 적 (협박형 적)** — Slay the Spire 이벤트 변형: 전투 시작 전 협박 팝업 "나를 10초 내에 처치하지 못하면 Cat에게 저주 부여!" → 플레이어가 공격적으로 플레이하도록 유도. 구현: `ThreateningEnemy` → 타이머 만료 시 `RunDataSO.activeDebuffs.Add(curseId)`.

## 맵 (03_Maps)

- **방 유형 사전 공개 분기 맵** — Slay the Spire 맵 참고: 다음 층에 진입하기 전 분기 경로 지도 표시 — 전투 방 🗡️ / 엘리트 방 💀 / 이벤트 방 ❓ / 상점 💰 / 휴식 🔥 / 보물 📦. 플레이어가 경로를 전략적으로 선택. 구현: `InRun_Branch_Map_System.md` 이미 있음 → 아이콘 종류만 추가.

- **휴식 방 딜레마 — 회복 vs 업그레이드** — Slay the Spire 휴식 장소 참고: 휴식 방에서 "HP 30% 회복" 또는 "업그레이드 카드 1장 레벨업" 중 선택. OnionCat 버전: "HP 20 회복" vs "Cat/Onion 중 하나의 기존 스킬 업그레이드". HP가 충분하면 업그레이드 선택 유인 → 상황 읽기 능력 테스트. 구현: `RestRoomUI` — 두 버튼 표시, 확정 시 각 효과 적용.

- **보스 방 진입 전 미리 보기** — Slay the Spire 보스 타입 예고 참고: 층 선택 화면에서 이번 층 보스가 누구인지 미리 공개. 플레이어가 보스 속성(근접 특화, 원거리 특화, 혼합)을 알고 업그레이드 선택 가능. 구현: `FloorData.bossType` → 층 진입 전 보스 프리뷰 팝업.

## 전투 (04_Combat)

- **협의 업그레이드 선택 시 보너스** — Coop Upgrade UI 참고: 두 플레이어가 30초 내에 모두 선택 확정하면 "빠른 결정 보너스" 골드 +10 또는 HP +5 지급. 빠른 커뮤니케이션과 협력 보상. 구현: `UpgradeSelectionUI.timeRemaining > 15f` 일 때 TryFinalize() 성공 시 `RunDataSO.gold += 10`.

- **공유 업그레이드 중복 호버 = 금색 빛남** — Coop Upgrade UI 참고: Cat과 Onion이 동시에 같은 카드에 커서 올리면 금색 테두리 + 파티클 이펙트 → "우리 둘 다 이거 원해!" 신호. 협동감 연출 강화. 구현: `UpgradeCard.SetHighlight(isP1, isP2, bothHover)` → `bothHover` 시 DOTween으로 scale pulse 0.95→1.05 루프.

- **저주 수락 시 공유 결정 필요** — Slay the Spire 저주 + Coop UI 참고: 저주 아이템 이벤트 등장 시 "수락/거부" 투표 UI — Cat(P1)과 Onion(P2) 모두 동의해야 수락. 한 명이라도 거부하면 이벤트 스킵. 협동 의사결정 강화. 구현: `VoteUI` — 두 플레이어 각 yes/no 입력, 30초 타임아웃 시 자동 거부.

## 스토리 (05_Story)

- **렐릭 획득 시 짧은 대사** — Slay the Spire 렐릭 설명 텍스트 참고: 렐릭 획득 시 Cat과 Onion 간 짧은 한 줄 대사. 예: (고양이 발 렐릭 획득) Cat: "발이 더 빠른 것 같아..." Onion: "기분 탓이야." → 렐릭으로 캐릭터 개성 표현. 구현: `RelicSO.onPickupDialogue` `DialoguePair[]` → `DialogueEventSystem.md` 연동.

- **어센션 달성 시 엔딩 변화** — Slay the Spire 엔딩 다양성 참고: 기본 클리어 = A엔딩(도망 성공), 어센션 3 이상 클리어 = B엔딩(진짜 적 격파), 어센션 5 클리어 = C엔딩(숨겨진 비화 공개). 게임 재도전 동기 부여. 구현: `Multiple_Endings_System.md` 이미 있음 → `RunDataSO.ascensionLevel` 조건 추가.

- **런 종료 통계 = 스토리 단편** — Slay the Spire 종료 화면 참고: 런 결과 화면에 통계(처치 수, 클리어 시간, 획득 렐릭) 외에 "Cat과 Onion이 함께 싸운 이야기 한 줄 요약" 표시. 예: "고양이는 오늘도 양파를 지켰다. 처치 수: 47." → 런 결과가 감정적으로 기억됨. 구현: `RunResultScreen`에 `StoryLineGenerator.GetLine(runData)` → killCount/floorNumber 기반 랜덤 선택.

## 기술 메모

- **런 내 씬 간 데이터 공유**: `RunDataSO : ScriptableObject` 에셋 1개를 `Assets/Data/RunData.asset`으로 생성. Cat 업그레이드(`catUpgradeIds`), Onion 업그레이드(`onionUpgradeIds`), 렐릭 목록(`relicIds`), 현재 HP 등 모든 런 상태를 여기에 저장. 씬 전환 시 자동으로 유지됨. 에디터 종료 후 값이 남을 수 있으므로 게임 시작(MainMenu)에서 `runData.ResetForNewRun()` 호출 필수.
- **협동 업그레이드 선택 UI**: Cat 전용(주황), Onion 전용(초록), 공유(흰색/금색) 3종류로 카드 분류. P1(컨트롤러 스틱)과 P2(마우스)가 각자 호버 → 둘 다 같은 카드 선택 시 금색 글로우 연출. 30초 타임아웃 → 미선택 시 자동 랜덤 확정. 두 플레이어 모두 확정(`p1Confirmed && p2Confirmed`)해야만 업그레이드 적용 및 UI 닫힘.
