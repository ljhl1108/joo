## 캐릭터 (01_Characters)

- **건부츠 고양이 업그레이드** — Downwell 참고: 고양이의 대시가 특정 업그레이드 후 "대시 자체가 근접 공격"이 되는 변환. 이동 = 공격 통합 철학 적용. 구현 힌트: Dash 코루틴에 CirclecastNonAlloc 추가해 범위 데미지 처리.

- **파의 팔 분리 특수기** — Helheim Hassle 참고: 파(P2)의 투사체가 일정 업그레이드 후 발사 후에도 화면에 남아 P2가 마우스로 조종 가능한 "유도 파 투사체". 구현 힌트: 발사 후 Rigidbody2D.velocity를 P2 입력 방향으로 매 프레임 수정.

- **콤보 협동 보너스** — Downwell 콤보 시스템 참고: P1 근접 → P2 원거리 → P1 근접 순서로 킬을 이어가면 "협동 콤보" 카운트 증가, 일정 콤보 시 공유 HP 소량 회복. 구현 힌트: 마지막 킬 플레이어 인덱스를 저장해 교대 여부 감지.

## 적 (02_Enemies)

- **신호 요구 적** — Coop Proximity Interaction 참고: P1이 해당 적을 근접 공격하는 동안 P2가 동시에 조준·발사해야만 처치 가능한 적. 평소엔 P1 근접에 면역. 구현 힌트: Enemy에 `requireSimultaneous` 플래그 추가, 두 입력 0.3초 내 발생 확인.

- **우물 괴물** — Downwell 참고: 천장에서 아래로 떨어지며 등장하는 적. 낙하 중에는 무적, 착지 순간에만 피격 가능. 협동 타이밍 공격이 필요한 적. 구현 힌트: Rigidbody2D.gravityScale 큰 값 + OnCollisionEnter2D에서 취약 상태 전환.

- **부활 적** — Helheim Hassle의 신체 재결합 참고: 처치해도 일정 시간 후 다시 일어나는 적. 두 번째 처치가 필요하며, P1과 P2가 동시에 공격해야 완전 처치. 구현 힌트: 첫 HP 0 시 `isReviving` 상태로 전환, 3초 후 HP 일부 회복 → `requireBothPlayers` 플래그 활성화.

## 맵 (03_Maps)

- **협동 자물쇠 방** — Coop Proximity Interaction 참고: 방 중앙 큰 문이 있고, P1이 왼쪽 버튼, P2가 오른쪽 인장을 동시에 활성화해야 열리는 방. 양쪽 중 하나를 누르면 적이 소환되어 방해. 구현 힌트: 두 Interactable이 CoopInteractable에 같이 연결.

- **성장하는 텃밭 허브** — Between-Run Hub 참고: 런 횟수에 따라 변하는 허브. 초기엔 황폐한 토지, 5런마다 새 채소·오브젝트 출현. 파(양파)의 특성과 연결되는 세계관. 구현 힌트: `HubManager.UpdateGardenVisual(runCount)` 에서 GameObject 배열 순차 활성화.

- **Downwell식 수직 낙하 방** — Downwell 참고: 위에서 아래로 카메라가 따라가는 특수 방. 낙하 자체가 이동 수단이며 아래 적이 착지 대기. 구현 힌트: 해당 방 진입 시 Camera confiner Y축 제한 해제, 플레이어 gravity scale 일시 증가.

## 전투 (04_Combat)

- **이동=공격 대시** — Downwell 건부츠 철학 참고: 고양이의 대시 도중 적에 접촉하면 자동으로 근접 대미지. "이동 자체가 공격"인 순간을 만들어 협동 전략 다양화. 구현 힌트: Dash 중 Rigidbody2D.velocity 방향으로 BoxCast 추가.

- **채널링 협동 처치** — Coop Proximity Interaction 참고: 보스 등 강한 적의 특수 취약 페이즈에서 P1이 특정 부위를 잡고 있는 동안 P2가 마우스로 2초간 집중 조준하면 추가 대미지 발생. 구현 힌트: `CoopChannelInteractable` 컴포넌트를 보스 특정 콜라이더에 부착.

- **신체 분리 특수 공격** — Helheim Hassle 참고: 특정 업그레이드 획득 시 P2가 파를 "임시 분리"해 독립 투사체로 발사. 발사된 파는 5초간 자동 탐색 후 복귀. 구현 힌트: P2 버튼 홀드 시 Rigidbody2D.bodyType을 Dynamic으로 전환 + 별도 이동 스크립트 활성화.

## 스토리 (05_Story)

- **텃밭의 기억** — Between-Run Hub 참고: 고양이가 처음 파(양파 화분)를 등에 이고 집을 떠나는 이유가 텃밭의 위기(침략자, 가뭄, 저주 등). 허브 텃밭을 복구하는 것이 런의 최종 목표와 연결. 런 클리어마다 텃밭 한 칸씩 복구.

- **분리된 기억 조각** — Helheim Hassle 신체 분리 참고: 파(양파)가 과거 몸통에서 "분리"된 존재라는 설정. 원래 완전한 하나의 생명체였는데 어떤 사건으로 고양이와 양파로 나뉨. 이를 기억하는 NPC 대화가 런마다 하나씩 공개.

- **우물 아래 세계** — Downwell 참고: 던전이 실제로 고양이 마을 아래 깊은 우물 속 세계. 각 층이 다른 테마 세계 (뿌리 세계, 돌 세계, 불 세계). 허브에서 발견한 "우물 지도"가 스토리 내러티브 역할.

## 기술 메모

- **Coop Proximity Interaction System**: OnionCat는 한 몸이므로 근접 감지보다 "P1 버튼 홀드 + P2 조준 방향"의 조합 체크가 핵심. `Vector2.Angle(aimDir, toObject) < threshold`로 조준 감지, `UnityEvent`로 트리거 연결하면 재사용 가능한 컴포넌트 완성.

- **Between-Run Hub Scene**: 초보자에게 가장 중요한 Phase 1: "허브 씬 → 게임 씬 → 허브 씬" 순환 루프만 만들면 이후 내용 추가 쉬움. `SceneManager.LoadScene("HubScene")`이 런 종료 모든 경로의 최종 목적지가 되도록 설계. 시각적 성장(텃밭 오브젝트 배열)은 Phase 3에서 추가.
