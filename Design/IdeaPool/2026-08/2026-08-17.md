## 캐릭터 (01_Characters)

- **Cat-Crop 합체기 진화 시스템** — Vampire Survivors 무기 진화 참고: Cat이 근접 3연타 후 Crop이 동일 타겟에 투사체 적중 시 "**합체 슬래시·샷**" 발동. 데미지는 두 공격의 합산 × 1.5. 구현 힌트: Cat의 콤보 카운터 + Crop의 최근 피격 대상 버퍼를 동기화하면 됨.
- **Cat 업그레이드: 잔상 대시** — 대시 시 파티클 잔상 3~5개 생성, 잔상은 근접 대미지는 없지만 적을 밀어내는 효과. Vampire Survivors의 돌진 계열 무기에서 영감. 구현 힌트: Dash 코루틴 내에서 `PixelVFXPool.Instance.PlayDashVFX()`를 0.05초 간격으로 호출.
- **Crop 업그레이드: 관통 투사체** — 기본 투사체가 최초 1명 관통 후 소멸. VS의 관통(Pierce) 아이템 참고. 구현 힌트: `Projectile.cs`에 `pierceCount` 필드 추가, `OnTriggerEnter2D`에서 감소시키며 0이 되면 `pool.Release()`.

## 적 (02_Enemies)

- **자동 추적 군중형 적 (Mob Chaser)** — VS의 기본 적처럼 플레이어 방향으로 직선 이동만 하는 적. 개수가 많을수록 위협. OnionCat에서 원거리 약점으로 설정 → P2 Crop에 부담 집중. 구현 힌트: `Transform.position = Vector2.MoveTowards(...)` 한 줄로 구현, NavMesh 불필요.
- **회전 포탑 적 (Turret Enemy)** — VS의 고정형 적처럼 이동하지 않고 360° 회전하며 일정 각도마다 투사체 발사. 근접에만 약하므로 Cat이 돌격해야 함. 구현 힌트: `Mathf.Repeat(Time.time * rotSpeed, 360f)`로 회전 각도 계산, `Physics2D.OverlapCircle`로 근접 피격 처리.
- **XP 흡수 방해 적 (Leech Enemy)** — VS에서 영감: 플레이어 주변을 선회하며 드롭된 파워업 아이템을 빨아들여 사라지게 함. 빠른 처리가 필요한 우선 타겟 역할. 구현 힌트: `PickupItem`과 `LeechEnemy` 간 반경 체크 + 흡수 카운트다운 코루틴.

## 맵 (03_Maps)

- **시간 압박 방 (Timed Room)** — VS의 시간 기반 난이도 증가를 방 단위로 적용: 방 입장 후 60초 내 클리어 못하면 강화 적 추가 스폰. 시각 피드백으로 벽/바닥이 점점 붉게 물들도록 색조 변화. 구현 힌트: 코루틴으로 타이머, `Material.SetColor("_Tint", ...)` 또는 Post Processing 볼륨 가중치 조절.
- **XP 밀도 높은 방 (Gem Room)** — 일반 적보다 XP 아이템 드롭률이 3배인 방. 대신 적의 이동 속도가 빠름. VS의 경험치 보석 수집 쾌감을 OnionCat에 국소적으로 적용. 구현 힌트: 방 입장 시 `EnemySpawner.dropRateMultiplier = 3f` 설정.
- **두 구역 분리 방 (Split Room)** — 방이 벽으로 분리, 각 구역에 P1 약점 적 / P2 약점 적이 배치. 두 플레이어가 각자의 구역에 집중하다 합류하는 협력 구조. 구현 힌트: 방 중앙 장벽에 트리거 콜라이더 추가, 특정 적 제거 시 장벽 오픈.

## 전투 (04_Combat)

- **자동 공격 옵션 (Cat 근접 자동화)** — VS처럼 Cat의 근접 공격을 반자동으로: 적이 일정 범위 내 진입 시 자동으로 슬래시 발동 (수동 입력도 가능). 난이도 옵션 또는 접근성 설정으로 제공. 구현 힌트: `Physics2D.OverlapCircle`로 근접 범위 내 적 감지 + 쿨다운 타이머.
- **패링 쾌감 VFX 강화** — Crop 패링 성공 시 `VFX_CropParry` 파티클 + 히트스톱(Time.timeScale = 0.05f, 0.15초) + 화면 진동 동시 트리거. VS 보스 처치 연출에서 영감. 구현 힌트: `ParrySystem.OnParrySuccess += () => { HitStop.Trigger(0.15f); CameraShake.Trigger(0.1f); VFXPool.PlayParry(pos); }`.
- **합체 공격 쿨다운 피드백** — 합체기 사용 후 쿨다운 중 두 캐릭터의 색조가 살짝 회색으로 변하는 시각 피드백. VS의 무기 쿨다운 표시에서 영감. 구현 힌트: `SpriteRenderer.material.SetFloat("_Saturation", 0.3f)` 또는 URP 2D Light 색조 조절.

## 스토리 (05_Story)

- **공생 시작 이유 — VS 로어 형식 참고** — VS처럼 짧은 캐릭터 설명으로 세계관 암시: "수백 년 된 마법 저주로 양파가 고양이 등에 봉인됨. 함께 탈출하지 않으면 둘 다 사라진다." FTUE 오프닝 텍스트로 활용.
- **업그레이드 아이템 로어 텍스트** — VS의 아이템 설명처럼 각 업그레이드에 1~2줄 플레이버 텍스트 추가. "마늘 방패: 양파가 마늘 농도를 높이자 방패가 더 매워졌다." 구현 힌트: `UpgradeItemSO.flavorText` 필드 추가, 업그레이드 선택 UI에 작은 이탤릭 텍스트로 표시.
- **런 종료 후 짧은 코멘트** — VS 게임오버 화면처럼 랜덤 코멘트 출력: "양파가 조금 더 울었다." / "고양이는 역시 고양이." / "그래도 잘 싸웠어!" 5~10개 준비, Random.Range로 출력.

## 기술 메모

- **픽셀아트 VFX 파티클**: 가장 중요한 설정은 `Filter Mode: Point (no filter)`. 별도 머티리얼을 만들어야 URP에서 Point 필터가 적용됨. `PixelSnapParticleSystem` 스크립트로 LateUpdate에서 파티클 위치를 픽셀 격자에 스냅하면 완벽한 도트 느낌. Unity Object Pool API와 연동해 성능 확보.
- **FTUE 온보딩 흐름**: `PlayerPrefs.GetInt("ftue_complete", 0)` 체크 한 줄로 첫 실행 여부 판단 가능. 가장 중요한 FTUE 포인트는 "두 플레이어가 하나의 몸을 공유한다"는 개념을 시각적으로 보여주는 것 — 텍스트만으론 부족하고, 두 캐릭터가 같이 이동하는 5초 시연이 필요. FTUE 씬을 별도로 만들고 Bootstrap 씬에서 첫 실행 여부에 따라 라우팅하는 것이 깔끔한 구조.
