## 캐릭터 (01_Characters)

- **시스템 분담형 능력** — FTL 코옵 참고: P1과 P2 각자가 "전용 쿨다운 능력"을 1개씩 가지도록 설계. 서로의 스킬을 복사하거나 공유할 수 없어 두 플레이어 모두 자신의 역할이 중요하다는 감각을 유지. 예: P1은 대쉬 무적 타이밍에 파생 능력을 사용하고, P2는 방패 패리 이후 반격 능력을 발동.
- **공유 위기 반응 스킬** — FTL의 "화재+선체균열" 동시 위기 참고: 두 플레이어가 동시에 특정 입력을 맞추면 발동하는 **공명 스킬(Resonance Skill)** 추가. 예: P1이 슬래시 후 P2가 0.3초 내 방패 사용 시 "공명 폭발" 발동. 구현 힌트: 타이밍 윈도우를 코루틴 또는 플래그+타이머로 처리.
- **역할 고정 해제 아이템** — 특정 아이템 획득 시 P2가 일시적으로 근접 공격 가능 (또는 P1이 방향 지시 원거리 가능). FTL의 승무원 종족 특수 능력처럼 런 중 역할이 부분적으로 바뀌는 변화 요소. 남용 방지를 위해 쿨타임 60초 이상.

## 적 (02_Enemies)

- **파리 군집(Fly Swarm) 적** — Boids 참고: 단독으로는 데미지가 낮지만 군집 상태에서는 지속 독 피해를 입힘. P1의 슬래시로 분산시키면 P2가 흩어진 개체를 각개격파하는 2단계 전투 흐름. 구현: 군집 중심에서 반경 1m 이내 개체 수 카운팅 → 임계치 초과 시 독 데미지 활성화.
- **도주 군집(Scatter Mob)** — 체력 30% 이하 적이 Boids Separation 가중치를 크게 높여 흩어지는 행동 변화. 흩어지면 강해지는 반전 설계 (빠른 속도 + 독립 공격 패턴 전환). P2 원거리가 흩어지기 전 집중 사격을 유도.
- **우주선 포격 드론 (FTL 오마주)** — 공중에 떠서 레이저 예고선 표시 후 1초 뒤 발사. 근접 불가, 원거리만 파괴 가능. P1이 방패 뒤에서 대기, P2가 파괴하는 "엄호 시나리오" 자연 발생. 예고선 = 빨간 점선으로 표시 (Telegraph System 활용).

## 맵 (03_Maps)

- **구역별 환경 위험** — FTL의 "산소 누출" 참고: 맵 일부 지역에서 독가스가 채워지는 구역 추가. P1이 빠르게 이동해 독가스 발생기를 파괴하고, P2가 원거리로 적을 제압. 시간 제한 방 클리어 느낌.
- **군집 소환 방** — 방 한쪽에 "둥지(Hive)" 오브젝트 배치, 매 5초마다 소형 군집 적 소환. 둥지 파괴 전까지 무한 리스폰. 둥지는 원거리 공격만 타격 가능 → P2 집중 역할 부여. P1은 접근하는 군집 처리 담당.
- **비대칭 접근 구역** — 방의 절반은 천장이 낮아 원거리 투사체가 벽에 맞는 구역, 나머지 절반은 원거리 자유. P1이 천장 낮은 쪽, P2가 개방된 쪽을 담당하는 자연스러운 공간 분리.

## 전투 (04_Combat)

- **군집 분산 슬래시** — Boids Separation 참고: P1 슬래시에 "분산 효과" 속성 추가. 히트 시 적의 Separation 가중치를 3초간 대폭 높여 무리가 강제로 흩어짐. 흩어진 후 P2의 개별 격파로 이어지는 전투 콤보 흐름 설계.
- **FTL 공명 전략 응용 — 취약 시스템 노출** — 엘리트 적은 정면 방어막 보유 → P1이 슬래시로 방어막을 "밀어낸" 직후 0.5초 P2 원거리 공격이 100% 크리티컬. 구현: 방어막 객체에 히트 시 ShieldBreakEvent 발행, P2 ProjectileSystem에서 구독해 크리티컬 배율 적용.
- **정지 중 협력 강화 아이템** — 일시정지 확인창 아이디어에서 파생: 업그레이드 선택 화면(런 중 멈추는 순간)에서 "협력 업그레이드" 아이템 풀 추가. P1 혼자 쓸 수 없고 두 플레이어가 모두 해당 아이템의 조건을 만족해야 효과 발동. 코옵 긴밀함 증가.

## 스토리 (05_Story)

- **FTL 오마주 - "긴급 탈출 씬"** — 마지막 방을 클리어한 직후 "적의 자폭 카운트다운" 연출 삽입. 이동하면서 도중 소환되는 적을 처리하며 탈출구까지 이동하는 짧은 도주 시퀀스. BGM 전환 + 화면 주변 빨간 플래시 효과로 긴박감 연출.
- **공생 기원 이야기** — 왜 고양이 등에 화분이 달려 있는가: 고대 주술사가 작물에 영혼을 불어넣어 두 존재를 하나로 봉인. 둘이 함께할 때만 봉인의 힘을 쓸 수 있음. 고양이는 기동력, 작물은 마법 에너지를 담당하는 설정으로 메카닉과 서사가 일치.
- **서브시스템 의인화** — 작물(P2)이 사용하는 방패/원거리 능력을 "꽃잎 날리기", "씨앗 투사" 등으로 식물 모티프로 명명. 고양이(P1)의 슬래시를 "발톱 바람", "격류 발차기"로 불러 두 캐릭터의 세계관 질감을 대화/설명 없이 행동 명칭만으로 전달.

## 기술 메모

- **Boids 군집 행동**: `Physics2D.OverlapCircleNonAlloc`으로 이웃 탐색 시 GC Alloc 0 유지 가능. 무리형 적이 20마리 이상이면 프레임 오프셋(`GetInstanceID() % 3`)으로 업데이트 분산. 가중치 3개(Separation/Alignment/Cohesion)를 Inspector로 노출해 두면 디자이너가 런타임에 튜닝 가능.
- **Coop Pause Menu**: `Time.timeScale = 0f` 직후 반드시 두 PlayerInput 모두 `SwitchCurrentActionMap("UI")`로 전환해야 게임플레이 입력이 차단됨. "런 포기" 같은 되돌릴 수 없는 행동은 두 단계 확인창 필수. Pause 오버레이 애니메이션은 `Animator.updateMode = UnscaledTime` 또는 DOTween `.SetUpdate(true)` 사용.
