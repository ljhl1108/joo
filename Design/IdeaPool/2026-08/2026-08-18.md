## 캐릭터 (01_Characters)

- **Cat 업그레이드: 집어던지기 (Grab & Throw)** — Going Under 물리 투척 참고: Cat이 소형 적을 잡아 Crop이 겨냥 중인 방향으로 투척, 투척된 적은 충돌 시 다른 적에게 피해. 구현 힌트: Cat `AttackState`에 `Physics2D.OverlapCircle` 근접 체크 → `Rigidbody2D.AddForce` 투척, 투척 대상에 `ThrownTag` 설정해 충돌 피해 처리.
- **Crop 업그레이드: 원소 씨앗** — Wizard with a Gun 총알 조합 참고: 기본 씨앗이 방에서 획득한 원소(화염/얼음/번개)와 합쳐져 속성 변환. 예: 화염 씨앗은 적중 시 DoT 2초. 구현 힌트: `ProjectileSO`에 `ElementType` 필드 추가, `OnTriggerEnter2D`에서 원소별 StatusEffect 적용.
- **엘리트 집착형 Cat 전용 위협** — 엘리트 변형 참고: 한 플레이어(Cat)만 추적하는 집착형 엘리트 등장. Cat이 유인책 역할, Crop이 원거리 처치 담당. 역할 고정 없는 OnionCat에서 상황적으로 역할이 생기는 구조. 구현 힌트: `EnemyEliteController`의 `Fixated` 모디파이어 → AI 타겟을 항상 `CatController.transform`으로 고정.

## 적 (02_Enemies)

- **오피스 서플라이 적 (Supply Golem)** — Going Under 임시 무기 시스템 참고: 방 안에 있는 도구(화분, 상자)를 몸에 붙이고 방어로 사용하는 적. Cat 근접 공격으로 붙은 도구를 분리해야 피해. 구현 힌트: 적 오브젝트에 `ArmorPiece[]` 배열, 근접 히트 시 ArmorPiece 개별 분리 + 방 안에 물리 오브젝트로 스폰.
- **분열 엘리트 변종 (Split Elite)** — 엘리트 시스템 참고: 처치 시 소형 2마리로 분열, 소형체는 원거리 약점. 대형은 근접만 통함 → Cat이 대형 처치, Crop이 분열체 정리. 구현 힌트: `SplitOnDeath` 이벤트 + `WeaknessType = Ranged`인 미니 버전 별도 프리팹.
- **마나 잠식 카오스 적 (Corruption Imp)** — Wizard with a Gun 시간 압박 참고: 시간이 지날수록 방의 "오염 게이지"를 채우는 소형 적. 무시하면 방 전체에 피해 구역 생성. 구현 힌트: `CorruptionImp`는 적 처치 AI 없이 방 중앙 향해 이동만, 도달 시 `RoomCorruptionManager.AddCorruption(10f)`.

## 맵 (03_Maps)

- **컬렉션 방 (Gallery Room)** — 갤러리 시스템 참고: 특수 방에서 갤러리 아이템(스토리 파편, 아트워크) 획득 가능. 방 입장 시 "수집품 발견!" 팝업 + 런 종료 후 갤러리 화면에서 확인. 구현 힌트: 방 프리팹에 `GalleryRoomTag` → 방 클리어 시 `UnlockManager.Instance.Unlock(itemId)`.
- **원소 지형 방 (Elemental Terrain Room)** — Wizard 원소 시스템 참고: 방 바닥 일부가 화염/얼음 타일 → Crop 원소 씨앗과 시너지. 화염 씨앗이 얼음 타일 위 적에게 증기 폭발. 구현 힌트: Tilemap에 `ElementalTile`(ScriptableObject) 추가, 접촉 시 적/투사체에 원소 상태 적용.
- **임시 무기 방 (Armory Room)** — Going Under 임시 무기 참고: 방에 다양한 투척 가능 오브젝트 스폰. Cat이 오브젝트를 집어 투척해 적 처치하면 보너스 XP. 구현 힌트: 방 시작 시 `ThrowableProps[]` 풀에서 랜덤 3~5개 스폰, `IThrowable` 인터페이스로 Cat이 집을 수 있게.

## 전투 (04_Combat)

- **엘리트 등장 예고 연출** — 엘리트 시스템 참고: 엘리트 적 스폰 시 화면에 잠깐 "! 엘리트 등장 !" 텍스트 + 카메라 줌인 0.5초. 플레이어가 위협 인지 후 대응 준비 가능. 구현 힌트: `EliteAnnouncementUI` 코루틴 → `DOTween.Sequence()`로 텍스트 등장/퇴장 애니메이션.
- **약점역전 엘리트 전술 반전** — 엘리트 변형 참고: 평소 Crop이 처치하던 원거리약 적이 엘리트가 되면 갑자기 근접약으로 전환. Cat이 급히 전방으로 뛰어야 하는 긴박한 상황. 구현 힌트: `EliteModifierSO.invertWeakness = true` + 아이콘 색상 변경으로 플레이어에게 시각 신호.
- **협력 투척 콤보 (Cooperative Throw Combo)** — Going Under + OnionCat 융합: Cat이 적을 집어 던지는 순간 Crop의 투사체가 동일 적에 적중 시 "공중 콤보" 판정 → 피해 × 2. 구현 힌트: `ThrownEnemy` 컴포넌트 활성화 상태에서 Crop 투사체 `OnTriggerEnter2D` → `ComboMultiplier = 2f`.

## 스토리 (05_Story)

- **층별 보스 = 실패한 마법사의 혼령** — Going Under 스타트업 풍자 + OnionCat 세계관: 각 층의 보스는 예전에 "고양이-식물 공생 실험"에 실패한 마법사의 혼령. 보스 처치 시 혼령이 "이번엔 성공할 수 있을 거야..."라는 한 마디 남기고 사라짐. 구현 힌트: 보스 사망 이벤트 → `DialogueEvent.TriggerBossDeathLine(bossId)`.
- **갤러리 스토리 파편 서사** — 갤러리 시스템 참고: 런마다 방에서 수집하는 "마법 일지 조각"으로 세계관 구성. 조각 15개 모으면 완전한 이야기 하나 완성. 구현 힌트: `LoreFragmentSO` 15개 제작, 수집 완료 시 `UnlockManager.Unlock("lore_complete_01")` → 갤러리 아트워크 해금.
- **Wizard 세계관 융합: 마법 오염** — Wizard with a Gun 카오스 잠식 참고: OnionCat 세계관에서 "마법 오염(Mana Blight)"이 왕국을 잠식 중. Cat과 Crop이 공생체로 오염에 면역인 유일한 존재. 매 런은 "오염된 층을 정화하는 여정". 스토리 이유로 퍼머데스를 설명할 수 있음 (정화 실패 → 리셋 → 재도전).

## 기술 메모

- **엘리트 변형 적 시스템**: 가장 빠른 구현은 `hpMultiplier`, `speedMultiplier`, `tintColor` 세 가지만으로 시작. `EliteModifierSO` ScriptableObject 하나 만들면 Inspector에서 즉시 새 변종 추가 가능. 협력 게임에서는 `invertWeakness` 플래그가 역할 역전 순간을 만들어내는 핵심 — 이것만 추가해도 전술 깊이가 크게 높아짐.
- **잠금 해제 갤러리 화면**: `PlayerPrefs.GetString("UnlockedItems", "")` 로 CSV 저장 → 파싱이 핵심. 처음엔 업그레이드 아이템 도감만 만들고, 나중에 스킨/로어 탭 추가하는 점진적 구현 추천. "NEW" 뱃지 처리는 `PlayerPrefs.HasKey("seen_" + itemId)` 패턴이 단순하고 효과적.
