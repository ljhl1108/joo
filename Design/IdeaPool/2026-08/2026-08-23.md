## 캐릭터 (01_Characters)

- **Cat "시너지 슬래시" 업그레이드** — Wildfrost 참고: Cat의 근접 공격에 **태그(예: 불꽃)**가 붙고, Onion이 같은 태그 업그레이드를 들었을 때 공동 공격력이 1.5배로 증폭되는 시너지 조합 시스템 도입. 두 플레이어가 업그레이드 선택을 조율해야 하는 협력 요소.
- **Onion "컴패니언 버프 덩굴" 패시브** — Wildfrost 컴패니언 구조 참고: Onion이 Cat 주위에서 일정 거리 이내에 있을 때 Cat의 이동 속도 +10% 패시브 적용. 두 캐릭터가 **붙어 다닐 이유**를 설계에 내장. 구현: FixedUpdate에서 거리 체크 후 Cat SpeedMultiplier 변수 조정.
- **Cat "파트너 충전" 궁극기** — Wildfrost의 카운터 시스템 참고: Cat의 대시를 연속 3회 사용하면 Onion의 다음 투사체가 자동으로 관통+2배 데미지로 충전되는 연계 기술. Cat의 액션이 Onion의 화력을 높이는 명확한 협력 구조.

## 적 (02_Enemies)

- **"얼음 포자" 적 (태그 반응 적)** — Wildfrost 참고: 근접 공격에는 면역이지만, 원거리 피격 시 주변 2칸에 **얼음 결정**을 뿌리는 적. 팀이 Cat → 위치 강제 → Onion 투사체 → 결정 폭발의 순서로 처리해야 최대 효율. 구현: OnTakeMeleeDamage 이벤트에 스폰 콜백.
- **"거울 방패 병사"** — Wildfrost 보스 환경 변화 참고: 정면 원거리 공격만 100% 반사, 근접 및 측면 공격은 통과. 두 플레이어가 역할을 즉흥적으로 교체해야 하는 상황 강제. Cat이 측면 슬래시로 방패를 부순 뒤 Onion이 마무리.
- **"군집 공명 슬라임"** — Wildfrost 시너지 시스템 참고: 3마리 이상 같은 공간에 있을 때 서로 HP를 공유해 회복하는 군집 적. 개별 처리보다 **동시 집중 공격**이 강요됨. Cat이 한 곳에 몰고 Onion이 광역 투사체로 마무리하는 협력 패턴.

## 맵 (03_Maps)

- **"시너지 보상 방"** — Wildfrost 태그 시스템 참고: Cat 업그레이드 태그와 Onion 업그레이드 태그가 동일할 때만 열리는 **숨겨진 보너스 방**. 두 플레이어가 업그레이드를 선택할 때 협의를 강요하는 구조. 맵 배치: 매 층 1개, InRun_Branch_Map_System.md 연계.
- **"포그 오브 워 방"** — 기즈모 디버그 참고 (역발상): 화면에 시야가 제한되어 Cat은 근거리 시야, Onion은 원거리(마우스 방향) 시야를 각각 담당. 두 캐릭터의 정보를 합쳐야 맵을 탐색할 수 있는 협력 구조. Fog_of_War_System.md 참고.
- **"계절 보스 방" 테마** — Wildfrost 계절 영주 참고: 각 층 보스 방을 봄/여름/가을/겨울 테마로 구분. 겨울 방은 바닥이 미끄러워 Cat 이동이 어렵지만 Onion의 투사체가 얼음에 반사됨. 테마별로 강점 캐릭터가 달라져 매 런 협력 방식이 바뀜.

## 전투 (04_Combat)

- **"2인 연계 필살기" 시스템** — Wildfrost 카운터+시너지 참고: Cat이 근접 공격을 3회 적중시키면 **연계 게이지** 충전 → Onion이 이 상태에서 투사체를 쏘면 Cat의 마지막 타격 지점에 Onion 탄환이 자동 유도. 분리된 두 공격이 하나의 콤보로 연결되는 경험. 구현: EventBus로 MeleeHitCount 이벤트 전달.
- **"파티 타임" 업그레이드 라인** — Wildfrost 시너지 태그 참고: 업그레이드를 **Cat 전용 / Onion 전용 / 공유** 3개 슬롯으로 구분. 공유 슬롯 업그레이드는 양 캐릭터에 동시 적용되지만 개인 슬롯보다 효과가 약함. 두 플레이어가 전략을 맞출 이유를 만드는 설계.
- **"파트너 기절 한계" 기믹** — Wildfrost 컴패니언 죽음 감정 참고: 런 중 Cat이나 Onion 중 하나가 기절했을 때 혼자 남은 캐릭터가 **오버드라이브 모드** 진입(피해 +30%, 이동 속도 +20%, 하지만 시간 경과 HP 감소). 위기 상황의 감정적 긴장감 극대화.

## 스토리 (05_Story)

- **"공유된 기억" 메타 내러티브** — Wildfrost 반복 구조 참고: 각 런 클리어 후 Cat과 Onion이 짧은 대화를 나누며 이전 런의 기억 파편을 회상. 게임 플레이 자체가 "같은 날을 반복하며 기억을 모으는" 스토리로 포장됨. Hades의 메타 내러티브 방식과 동일하게 구현.
- **"계절 전설" 보스 백스토리** — Wildfrost 계절 영주 참고: 각 보스에게 1~2줄짜리 짧은 전설(lore)을 붙임. 예: "여름의 사자왕은 한때 Cat과 같은 마을을 지키던 수호자였다." 런 시작 전 로딩 화면 팁으로 표시 → 게임에 세계관 깊이를 추가. 코드: Loading_Screen_Hint_System.md 참고.
- **"두 영혼, 하나의 몸" 오프닝** — Wildfrost 리더+컴패니언 구조 참고: 첫 런 시작 전 짧은 컷씬에서 Cat의 등에 달린 화분에서 갑자기 Onion이 눈을 뜨는 장면. "너 누구야?" → "나도 몰라, 근데 같이 가야 할 것 같아." 단 2줄로 공유 캐릭터의 설정을 자연스럽게 전달.

## 기술 메모

- **Custom Gizmos**: `OnDrawGizmosSelected()`에 `Handles.DrawSolidArc()`를 추가하면 Cat의 180° 슬래시 범위를 씬 뷰에서 바로 확인 가능. `Assets/Editor/` 폴더에 `[CustomEditor(typeof(MeleeAttack))]` 스크립트를 만들어 공격 범위 슬라이더와 "테스트 공격 실행" 버튼을 Inspector에 추가하면 Play 없이 히트박스 조정 가능. → **OnionCat 개발 시 가장 먼저 적용할 디버그 도구 1순위**.

- **Screenshot & Share**: `RunResultScreen.Start()`에서 `StartCoroutine(CaptureWithUI(OnCaptured))`를 호출하면 결과 화면 진입 즉시 자동 스크린샷 저장. UI는 반드시 `WaitForEndOfFrame()` 이후 캡처해야 UI 요소가 포함됨. 저장 경로는 `Application.persistentDataPath + "/Screenshots/"`. 공유는 초기에는 Twitter URL Intent 방식으로 충분 (외부 라이브러리 불필요).
