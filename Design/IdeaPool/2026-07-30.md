## 캐릭터 (01_Characters)
- **1인 솔로 모드** — Phogs! 참고: 한 명이 WASD(Cat 이동) + 마우스(Onion 조준/방어)를 동시에 조작하는 솔로 플레이 모드. 협동 파트너가 없어도 플레이 가능하도록 설계해 접근성 향상
- **고양이 목숨 토큰** — Guacamelee! Death Defiance + 임계 상태 참고: 런 내 아이템으로 즉사 방지 1~3회 획득. HUD에 고양이 발바닥 아이콘으로 남은 횟수 표시. "고양이 9목숨" 테마 살리기
- **몸체 흔들림 피드백** — Phogs! 물리 참고: Cat이 급정지/대시 시 화분(Onion)이 관성으로 흔들리는 Secondary Motion 효과. 단순한 위치 이동이 아닌 탄성 있는 연동 표현으로 "공유 몸체" 감각 강화

## 적 (02_Enemies)
- **색상 코드 약점 아이콘** — Guacamelee! 참고: 적 머리 위에 발톱 아이콘(근접 전용) 또는 씨앗 아이콘(원거리 전용) 표시. 잘못된 공격 히트 시 "무효!" 텍스트 팝업 + 적이 튕겨나가는 연출로 즉각 피드백
- **임계 상태 반응 적** — Coop Revival 참고: 플레이어가 HP 15% 이하 임계 상태일 때 일부 적이 "조심하는" 행동 패턴으로 전환(공격 속도 감소, 거리 유지) → 간접적으로 플레이어에게 회복 기회 제공
- **몸통 조준 특수 공격 적** — Phogs! 공유 몸체 참고: Cat(앞)과 Onion(뒤) 사이 몸통 영역을 정확히 조준해 타격하는 특수 패턴 적. 히트박스 설계 시 몸통 구간을 별도 처리할지 결정 필요

## 맵 (03_Maps)
- **던전 테마별 패럴랙스 세트** — Parallax 참고: 방 타입마다 배경 레이어 에셋 세트 교체. 지하 동굴(암벽/안개/버섯), 식물 온실(유리창/덩굴/꽃가루), 유적 폐허(건물 실루엣/낙엽) 각 3레이어로 시각 다양성 확보
- **배경 서사 단서** — Parallax + 스토리 결합: 보스 방에 가까울수록 배경 중간 레이어에 피 자국, 부서진 화분, 불씨 등이 점진적으로 등장 → 대사 없이 긴장감 상승
- **중간 레이어 파괴 오브젝트** — Parallax 중간 레이어에 파괴 가능한 소품(횃불, 결정체) 배치. 배경처럼 보이지만 실제로 상호작용 가능 → 숨겨진 자원 획득 장치

## 전투 (04_Combat)
- **기절-투척 협동 콤보** — Guacamelee! 레슬링 참고: Cat의 차지 베기로 적을 기절시키면, Onion이 원거리 공격으로 날려 다른 적과 충돌해 범위 피해 발생. 둘이 연계해야만 가능한 전용 콤보
- **임계 상태 역전 버프** — Coop Revival + 임계 상태 참고: HP 15% 이하 돌입 시 Cat의 베기 대미지 1.5배 + 빨간 잔상 이펙트 자동 발동. 위기 상황에서 역전을 노리는 하이리스크-하이리워드 구조
- **패리 생존 연동** — Guacamelee! + Coop Revival 결합 업그레이드: Onion 패리 성공 시 임계 상태 타이머 +1초 연장. 방어(P2)가 생존에 직결되는 구조로 역할 분업 의미 강화

## 스토리 (05_Story)
- **공유 몸체의 기원** — Phogs! 참고: Cat과 Onion이 왜 하나의 몸에 묶였는지 배경 서사. 예: 마법사의 실험 실패로 고양이와 화분이 합쳐짐 → 저주인지 운명인지 모호하게 남겨두어 플레이어가 상상하도록
- **임계 상태 독백** — Coop Revival 참고: HP 15% 이하 임계 상태 진입 시 Cat의 짧은 대사 출력("포기하지 마...!"). 과하지 않게 1~2줄 텍스트 팝업으로 가볍게 감정 몰입
- **차원 이중성 세계관** — Guacamelee! 차원 전환 참고: OnionCat 스토리에 "현실 정원 ↔ 어두운 지하" 이중 세계관 도입. 현실에서는 약해 보이는 적들이 지하에서는 본래 강한 모습으로 나타나는 서사 장치

## 기술 메모
- **패럴랙스 배경 시스템**: 방 프리팹에 `ParallaxLayer` 컴포넌트를 가진 자식 오브젝트 2~3개 추가하는 것만으로 구현 완료. 방 전환(활성화) 시 반드시 `ResetLastPosition()` 호출 필요 — 미호출 시 카메라 순간 이동으로 배경이 크게 튀는 버그 발생. 픽셀아트에선 transform을 픽셀 그리드로 스냅하거나 Pixel Perfect Camera 패키지 사용 권장.
- **협동 부활/임계 상태 시스템**: OnionCat은 공유 HP이므로 "파트너 부활" 대신 "임계 상태(Critical State)" 설계. HP 15% 이하 진입 → 3초 무적 + 회복 기회 부여. "고양이 목숨" 런 아이템(즉사 방지 1~3회)으로 로그라이크 느낌 유지. 기술 구현은 `SharedBodyHP.TakeDamage` 내부에서 `DeathDefianceToken.TryConsume()` 호출 순서 주의.
