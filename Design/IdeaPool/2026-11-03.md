## 캐릭터 (01_Characters)

- **화분 관성 기울기** — 2D IK 참고: 고양이가 빠르게 달리거나 방향을 바꿀 때 등의 화분이 관성으로 반대 방향으로 살짝 기울어지는 비주얼. IK가 아니어도 `Transform.rotation = Quaternion.Lerp(...)` + velocity 기반 각도 계산으로 구현 가능. 코드 1~2줄이지만 생동감이 크게 오름.

- **고양이 두 눈이 양파 상태를 반영** — Struggling의 "신체 언어가 명확해야 협동이 쉽다" 참고: 고양이 눈이 양파의 씨앗 잔탄 수나 스킬 쿨다운을 간접 표현. 씨앗 0개 = 눈이 X 표시로 바뀜, 스킬 준비 완료 = 눈이 빛남. P1이 화면을 못 봐도 캐릭터 자체로 P2 상태 파악 가능.

- **달리기 중 할퀴기 방향 힌트** — Struggling의 팔 방향 시각화 참고: 고양이가 이동 중일 때 발 밑 또는 공격 방향 쪽에 작은 발톱 아이콘이 0.2초 표시 → 다음 할퀴기가 어디 적을 노리는지 양파 플레이어도 알 수 있게 됨.

## 적 (02_Enemies)

- **협동 콤보 유도 적** — Hellcard 협동 콤보 참고: "혼자서는 절반 데미지, 두 명이 1초 안에 번갈아 치면 정상 데미지"를 가진 특수 몬스터. 딱딱한 껍질(고양이 공격만 튕김)을 가지고 있지만 씨앗탄에 약점이 노출되는 구조 → 자연스럽게 콤보를 유도. 구현: `InterceptDamage`에서 `Attacker.Cat`이면 0.5배, 협동 콤보 버프가 있으면 정상.

- **분신 혼란 적** — Hellcard 의도 표시 시스템 참고: 진짜 본체와 그림자 분신이 함께 돌아다니고 분신은 노란 텔레그래프만 보임(막아도 피해 없음), 진짜는 빨간 텔레그래프(피해야 함). 처음 보면 헷갈리지만 텔레그래프 색만 보면 풀 수 있는 "읽기 퍼즐". 이미 있는 텔레그래프 시스템으로 구현 가능.

- **서로 버프하는 쌍둥이 적** — Hellcard의 팀 시너지 참고: 두 마리가 같은 방에 있으면 서로 공격력 1.5배 or 재생 버프. 한 마리를 먼저 처치하면 버프 해제. "누굴 먼저 처리할까" 우선순위 판단을 강제함. 기존 `EnemyBase.Status`에 "쌍둥이 버프" 상태이상 추가하면 구현 가능.

## 맵·런 구조 (03_Maps)

- **협동 기믹 방 추가 아이디어: 강 건너기** — Struggling의 물리 협동 참고: 두 발판이 서로 연결된 시소 위에서 고양이가 한쪽을 밟고 버티면 양파가 높아진 발판에서 수정을 쏘는 기믹. 기존 쌍둥이 스위치 기믹의 변형으로 구현 가능 (`Room_Special` 재활용).

- **물음표 방: 카드 게임 도전** — Hellcard 턴제 덱빌더 참고: 한 방 동안 OnionCat의 전투를 "턴제"로 바꾸는 저주. "매 3초마다 행동 1번"으로 플레이어가 생각할 시간을 주되, 적도 느려짐. 성공 보상 = 에픽 이상 장비. OnionCat 전투 속도를 의도적으로 늦춰보는 것 자체가 신선한 경험.

- **보상 방향 예고 더 명확하게** — Hellcard 분기 지도 참고: 출구 표식(다음 방 중점 축) 외에 "대략 어떤 적이 나오는지"도 힌트로. 지금 출구에는 RewardAxis 아이콘만 → 추가로 스테이지 테마 아이콘 작게 표시하면 전략적 선택이 쉬워짐.

## 전투·협동 (04_Combat)

- **협동 필살기 다양화** — Struggling의 "둘이 해야만 가능한 것" 참고: 지금 합동기(ONION STORM)는 1종. 장비 세트에 따라 합동기 연출이 바뀌는 것 추가 가능. 예: 해바라기 세트 4단계 = "SUNFLOWER STORM" (넓은 범위 빛 폭발). `RunData.JointUltimate` 필드 + 세트 보너스에 합동기 종류 변경 파라미터 추가.

- **패링 연계 특수 효과** — Hellcard 카드 콤보 참고: 양파의 패링(0.25초 완전 막기) 성공 시, 다음 고양이 할퀴기가 강화됨 (0.5초 안에). 이미 `EffectTrigger.Parry` 시스템이 있으니 "패링 성공 후 버프" 장비 효과를 추가하면 자연스러운 협동 리듬이 생김.

- **위치 기반 적 약점** — Hellcard 위치 배치 전략 참고: 현재는 적 방향(정면=차단, 등=약점)만 있는 방패 근위병 스타일. 일부 적에게 "벽 쪽으로 몰면 기절" 또는 "구덩이 옆에 있으면 낙사 1방" 같은 위치 기반 추가 피해를 줌. 환경 활용 장려 → `Environmental_Kill_Chain` 시스템으로 이미 일부 구현.

## 아이템·세트 (05_Items)

- **"합동" 세트 추가 아이디어** — Struggling 협동 필수 설계 참고: 고양이·양파 장비 합산으로 세트를 쌓되, 효과가 모두 "두 명이 같이 해야 발동". 예: 2단계 = 협동 콤보 데미지 +30% / 4단계 = 합동기 게이지가 협동 콤보에서 더 빠르게 참 / 6단계 = 합동기 사용 후 5초간 모든 공격 협동 콤보 판정. 이미 세트 시스템 완성이어서 에셋 데이터만 추가하면 됨.

- **분해된 장비의 "기억" 효과** — Hellcard 중복 카드 강화 참고: 같은 장비를 분해할 때마다 해당 장비의 효과가 "파편 기억"으로 RunData에 쌓임. 최대 3개까지 누적된 파편 기억이 있으면 다음에 같은 장비를 얻을 때 자동으로 레벨 +1 보너스. 빌드를 일관되게 유지하는 플레이어에게 보상.

- **조작법 숙련 패시브** — Struggling의 "점점 익숙해지는 협동" 참고: 한 런에서 협동 콤보를 N회 달성할 때마다 스택이 쌓이는 패시브. 런 내 협동 숙련도가 높아질수록 보너스가 늘어남 (최대 5스택). 처음에 어색하다가 나중에 능숙해지는 Struggling의 감성을 OnionCat에 옮김.

## 스토리·메타 (07_StoryMeta)

- **책(그리모)의 Hellcard 오마주 대사** — Hellcard와 Book of Demons 세계관 참고: 지금 낡은 책이 "깐깐한 존댓말"을 씀. 마녀 해방 이후 그리모로 이름이 바뀔 때 "나는 오랫동안 많은 모험가를 도왔다"는 내레이션 추가. Book of Demons → 그리모라는 묵직한 역사감이 이야기에 깊이를 더함.

- **Struggling 감성: 첫 런 시작 씬** — 두 명이 처음 만나 어색하게 협동하는 연출: 고양이가 처음에는 화분을 어색하게 들고 비틀비틀 걷다가 균형을 잡는 짧은 컷신. 15초 이내, 스킵 가능. 현재 Dialogue.Play()로 대사만 하는 시작 → 비주얼 연출 한 줄 추가.

- **SNS 소재용 메타 요소** — SNS 전략 참고: 게임 안에 "스크린샷 모드" 단축키 추가 (HUD 숨김 + 카메라 줌). 멋진 클립을 만들기 쉽게 → 플레이어가 자발적으로 바이럴 소재를 만들어 줌. `Photo_Mode_HUD_Toggle_System.md`에 이미 관련 내용 있음 → HUD 토글 키 추가 먼저.

## 기술 메모

- **2D IK**: 지금 당장 구현할 것은 없지만, 화분 기울기만큼은 IK 없이 `Transform.localRotation` Lerp로 1~2줄에 구현 가능. `OnionController`에서 `rb.velocity.x`에 비례해 화분 `pivot.localEulerAngles.z`를 조정하면 됨. 이후 애니메이션 리그 재작업 시 Limb 솔버 도입 검토.

- **SNS 전략**: 지금 당장 할 수 있는 것 — ① 2인 플레이 클립 10초 하나 만들어서 Twitter #ScreenshotSaturday에 올리기 ② Steam "Coming Soon" 페이지 개설 (위시리스트 수집 시작). 이 두 가지가 가장 ROI 높은 첫 발걸음.
