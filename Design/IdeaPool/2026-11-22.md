## 캐릭터 (01_Characters)

- **반사 쾌감 강화** — Bleed 2 참고: 패시브 실드가 막을 때 단순 "막음" 대신 반사체를 돌려보내는 "튕기기" 효과 옵션. 텔레그래프 노란 탄을 실드로 튕기면 적에게 되돌아감 → 방어가 공격 기회가 되는 쾌감
- **합동기 연출 "합체 느낌"** — Trinity Fusion의 Fusion 개념 참고: 합동기 발동 시 고양이+화분이 잠깐 겹쳐지는 연출(SortingGroup을 한 덩어리로, 고양이가 화분을 감싸는 모션) → "우리가 하나가 됐다" 시각적 강조
- **조준선 색 = 작물 빛 색** — 현재 조준선이 단색. 작물 빛 색(빨강/노랑/파랑)으로 조준선을 물들이면 "어떤 작물을 들고 있는지" UI 없이도 식별 가능

## 적 (02_Enemies)

- **색상 약점 텔레그래프** — Bleed 2 참고: 반사 가능한 탄 = 노란 경고(현재 텔레그래프와 일치), 반사 불가 = 빨간 경고. 추가로 "작물 씨앗만 맞히는 약점(원거리 전용)"을 가진 적에게 파란 약점 표시 → 고양이·작물 역할 분담 강요
- **띄우기 콤보 적 타입** — Trinity Fusion의 공중 콤보 참고: 소형 적이 할퀴기에 맞으면 살짝 공중으로 뜨고, 뜬 상태에서 씨앗 추가 타격 시 보너스 피해 → 고양이(근접 띄우기) + 작물(원거리 추격) 협동 콤보 흐름 자연스럽게 유도
- **반사 면역 보스 페이즈** — 보스 2페이즈에서 패시브 실드 반사가 통하지 않는 붉은 탄만 쏘는 국면 추가 → 작물이 씨앗으로 약점을 직접 맞춰야 하는 협동 필요 순간

## 맵·런 구조 (03_Maps)

- **합동기 필요 장애물 방** — 특정 방에 합동기로만 열리는 잠긴 보물상자 or 비밀 통로: 두 플레이어가 타이밍을 맞춰야 하는 "협동 퍼즐" 방 하나 → 긴장감 없이 소통 유도
- **튜토리얼 방 농장 시작점** — 현재 첫 방(언덕 위 농장)을 첫 런에만 튜토리얼 오버레이가 덮는 방식. 별도 씬 없이 TutorialOverlay 컴포넌트를 Room_Special에 붙이면 충분
- **솔로 플레이 힌트 방** — 패드 없이 싱글 모드로 들어오면 첫 방에 "지금 혼자 조종 중. WASD + 마우스를 같이 써봐" 안내 → `CoopInputLayout` 감지 후 분기

## 전투·협동 (04_Combat)

- **Proc 우선순위 테이블 도입** — 현재 여러 장비 효과가 동시 발동할 때 순서 보장 없음. Equipment_Proc_Pipeline_System.md의 Priority 테이블(0=데미지, 5=콤보, 10=상태이상, 15=흡혈, 30=VFX) 도입 → 흡혈이 데미지 계산 전에 실행되는 버그 예방
- **VFX 큐 최대 3개/프레임** — 세트 보너스 여러 개가 동시 발동할 때 이펙트를 1~2프레임에 걸쳐 최대 3개씩 출력. 화면이 번쩍이는 느낌 대신 "콤보처럼 차례로 터지는" 느낌
- **협동 콤보 판정을 Priority=5에 고정** — `RecordAttacker`(Priority=0) → 콤보 평가(Priority=5) 순서 보장으로, 피해 계산 도중 콤보 카운트가 초기화되는 엣지 케이스 방지

## 아이템·세트 (05_Items)

- **반사 세트 "거울 세트"** — Bleed 2 반사 시스템 참고: 패시브 실드 반사 발동 시 추가 효과를 주는 세트. 예: "거울 2세트 — 반사 시 씨앗 1발 자동 발사", "거울 4세트 — 반사탄 피해 ×2". 현재 텔레그래프 노란 탄 = 막을 수 있는 탄 → 반사 발동과 의미 일치
- **장비 보상 UI에 "현재 더 약한 쪽" 힌트** — Trinity Fusion 허브 UI 참고: 고양이/작물 중 현재 장비 점수가 낮은 쪽에 작은 ↓ 아이콘 표시 → 플레이어가 약한 쪽을 의식적으로 채울 수 있도록 넛지

## 스토리·메타 (07_StoryMeta)

- **농장 튜토리얼 대사 — 책의 첫 가르침** — 말하는 책이 고양이에게 처음 대쉬를 가르치는 장면. "도망치는 법을 먼저 배우는 거야." → 성격 확립 + 튜토리얼 자연스럽게 연결. 반전 전이므로 책의 정체 힌트 없이 "까다롭지만 친절한 선생님" 느낌만
- **엔딩 Fusion 연출** — Trinity Fusion의 Fusion 개념 오마주: 최종 보스 처치 직전 고양이+작물 합동기 연출에서 둘이 눈빛을 마주치는 1초 정지 컷 → "우리가 하나여서 이겼다"는 메시지 시각화

## 기술 메모

- **장비 발동 파이프라인**: 지금 당장 버그가 없더라도 장비가 늘수록 타이밍 버그가 잠재됨. `GearEffect.TryProc`에 priority 필드 하나 추가하고 `PassiveHost.RaiseEvent`에서 정렬 후 실행하는 것만으로 적용 가능. VFX 큐는 `EffectQueuePlayer` 별도 컴포넌트로 분리
- **비대칭 튜토리얼**: 별도 씬 없이 첫 방 `Room_Special`에 `TutorialOverlay` 컴포넌트 부착 + `MetaProgress.tutorialDone` 플래그로 충분. `Dialogue.Say()`가 이미 있으므로 추가 UI 없이 말풍선만으로 단계 안내 가능. 솔로/코-옵 분기는 `CoopInputLayout.IsSolo` 조건으로
