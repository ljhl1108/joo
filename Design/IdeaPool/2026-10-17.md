## 캐릭터 (01_Characters)

- **할퀴기 변형 플레이 스타일 명확화** — DNF 직업 정체성 참고: 각 ClawStyle이 "이런 상황에 강하다"는 기능적 차이를 명확히 설계해야 선택에 의미 생김. 예: 회전 할퀴기=범위 우수·단일 낮음, 도약 할퀴기=이동+공격·점프 넘기기. 현재는 변형 간 우열이 애매한지 점검 필요
- **걷어차기 콤보 즉각 보상 강화** — DNF 에어리얼 콤보 참고: 킥 직후 0.5초 안에 양파가 씨앗으로 맞추면 협동 콤보 게이지 추가 보너스(+5~10). 시각 피드백 "AERIAL COMBO!" 별도 텍스트 표시 → 킥이 협동 시너지의 시작임을 직관적으로 인식
- **양파 AI 보조 모드(1인용 접근성)** — MH Rise의 AI 오토모 참고: P2 없을 때 양파가 자동으로 기본 씨앗 발사 + Q스킬 자동 사용하는 간단한 AI. 솔로 플레이로 기본 경험 제공 가능. 협동 콤보 보너스는 적용 안 됨으로 강도 조정

## 적 (02_Enemies)

- **포위 AI 대형 개선** — Influence Map 적용: EnemyPresence 값 추가로 현재 적들의 "플레이어 앞 뭉침" 현상 해소 가능. 4마리가 동서남북 방향에서 접근하면 난이도와 시각적 긴장감 모두 상승. 방 크기 40×20 = 800셀로 구현 부담 낮음
- **장판 회피 적 행동** — Influence Map Danger 값 연동: EnemyHazard가 활성화되면 해당 셀 dangerMap 상승 → 적이 자기 장판으로 걸어 들어가지 않음. 플레이어가 장판으로 적 이동 경로를 차단하는 전략 레이어 추가
- **공격 직전 자세 예고 레이어 추가** — MH Rise 세 겹 텔레그래프 참고: (1) 자세 변화 → (2) 색상/발광 → (3) 사운드 큐. 현재 OnionCat은 색상(노랑/빨강)만 사용 중. 보스 패턴에 "자세 변화(이동 정지·전조 모션)" 레이어를 추가하면 예고의 가독성이 올라감

## 맵·런 구조 (03_Maps)

- **방 입장 직전 예고 연출** — DFO의 문 잠금 연출 참고: 보스방 입장 전 문이 잠기고 BGM 전환. 현재 OnionCat도 페이드 전환이 있지만 "이 방은 보스방"임을 입장 직전에 더 극적으로 알리는 연출 고려 (문 틈 사이로 보스 그림자 등)
- **방 위험도 암시 UI** — 출구 옆 표식에 방 위험도 표시: 현재 [A/B]로 다음 방 보상 유형을 고르지만, 추가로 "난이도 높음" 아이콘 표시 가능. 보물방=선물 아이콘, 엘리트=해골 아이콘, 일반=검 아이콘 등
- **런 중반 요약 화면** — MH Rise의 퀘스트 사이 결과 참고: 휴식 정원(중간 저장 포인트) 입장 시 "여기까지의 런 요약" 화면 표시 (처치 수, 콤보 횟수, 획득 장비 목록). 중간 저장과 자연스럽게 연결되는 플로

## 전투·협동 (04_Combat)

- **세트 보너스 "조각 하나 남았을 때" 강조 피드백** — DNF 세트 파밍 심리학 참고: HUD 세트 진행도에서 다음 단계까지 조각이 1개 남았을 때 깜빡임 효과 + "1개 남음!" 힌트 텍스트. 목표 의식을 강화해 장비 선택 시 세트를 의식적으로 추구하게 유도
- **에어리얼 타격 전용 피드백** — 걷어차기로 날아가는 적을 양파가 맞출 때: 노란 스파크 이펙트 + "AERIAL!" 텍스트. 협동 콤보와 별도로 이 순간 자체의 시각적 임팩트 강화 → 두 플레이어의 "우리가 맞춰냈다" 감각 증폭
- **킥 CRASH 데미지 전파 범위 시각화** — 적이 벽에 부딪혀 CRASH 시 주변 적들도 약간의 피해를 받는 경우(현재 구현) 피해 범위를 원형 리플 이펙트로 표시. "저 적을 이쪽 방향으로 차면 저 둘도 같이 맞는다"는 전략 정보 제공

## 아이템·세트 (05_Items)

- **세트 정체성 재점검** — MH Rise 세트 설계 원칙 참고: 현재 10개 세트가 각각 "이 세트는 어떤 플레이 스타일을 위한 것인가"가 명확한지 검토. 예: 햇살 세트=원소 누적형, 바람 세트=이동/회피형, 폭풍 세트=협동 콤보 중심형 등. 설명 한 줄로 정체성 표현 가능하면 좋음
- **장비 진화/성장 경로 암시** — DNF 세트 등급 시스템 참고: 일반→희귀→에픽→전설로 같은 이름의 장비가 강화될 때 "이 장비의 레전더리 버전은 이런 효과"라는 힌트를 에픽 버전 툴팁에 표시. 플레이어에게 장기 목표 암시
- **분해 씨앗 피드백 강화** — 장비 분해 시 씨앗 획득 연출을 더 명확히: 분해 칸에 놓으면 씨앗이 HUD 게이지로 날아오는 애니메이션. 현재 즉시 적용되는지 연출이 있는지 확인 필요

## 스토리·메타 (07_StoryMeta)

- **런 결과 "협동 하이라이트"** — MH Rise 퀘스트 결과 화면 참고: 런 결과 화면에 "이 런의 베스트 협동 모멘트"를 1~2개 표시. 예: "걷어차기 → 에어리얼 콤보 최장 체인: 5타", "패링 성공 횟수: 3회". 두 플레이어가 함께한 기억 강화
- **스테이지 테마 내러티브** — DFO의 던전 배경 스토리 참고: 각 스테이지가 왜 이 구역인지 짧은 배경 설명(한 줄~두 줄). 시작 배너에 스테이지 이름 + 한 줄 설명 추가. "슬라임 숲: 비가 내린 뒤 슬라임들이 넘쳐났다" 같은 느낌
- **장비 분류 용어집(크레딧 화면 활용)** — 1인 개발 로컬라이제이션 참고: 영어 출시 시 번역자 이름을 크레딧에 넣는 관행 준비. 지금부터 "커뮤니티 번역: [이름]" 섹션을 크레딧 화면 구조에 포함해두면 나중에 추가 쉬움

## 기술 메모

- **Influence Map 2D AI**: 방 크기 40×20 = 800셀로 부담 없음. 업데이트 주기 0.15초면 충분. 벽 셀을 `-999` 선호도로 마킹해야 벽 통과 방지. `EnemyBase.Active` 루프를 재활용해 `enemyPresence` 업데이트 가능. 먼저 원거리 슬라임 1종에 파일럿으로 적용해 효과 확인 후 전체 확대

- **Localization Workflow**: 지금 당장 코드 변경 없이 할 수 있는 것 = `ContentBuilder.cs` 장비 이름/설명을 구글 시트로 복사 + `en` 열 추가. Key 규칙은 `item.gear.{id}.name` 형태로 시작. Unity Localization 패키지는 영어 출시 결정 후에 설치해도 충분하지만, 코드에서 문자열 하드코딩을 지금부터 피하는 것이 나중 마이그레이션 비용을 크게 줄임
