## 캐릭터 (01_Characters)

- **패리 충전 시너지** — Spiritfall 참고: Cat(Player 1)이 근접 공격을 적중할 때마다 Crop(Player 2)의 다음 원거리 탄이 강화(데미지 +50%)되는 수동 연계. 두 플레이어 간 자연스러운 역할 분업 강화. 구현: `OnMeleeHit` 이벤트 → `CropChargeCount++`

- **합체 게이지(Unity Gauge)** — Spiritfall의 Spirit 게이지 참고: Cat 처치 + Crop 패리 성공이 공유 게이지를 채우고, 가득 차면 일정 시간 두 캐릭터 모두 강화 상태 진입. 협력 보상 메카닉으로 솔로 플레이보다 2인 플레이가 명확히 강해지는 근거.

- **캐릭터 선택 화면 개성 표현** — Character Select Screen 참고: 준비 완료 시 Cat은 "야옹~" 울음소리 + 꼬리 흔들기 애니메이션, Crop은 잎이 빛나는 이펙트. 소소하지만 캐릭터 개성을 처음부터 심어줌.

## 적 (02_Enemies)

- **갑옷형 약점 적** — Death's Door 참고: 근접에 무적인 갑옷 적이 있되, Crop의 특정 원거리(예: 폭발 씨앗)로만 갑옷 제거 가능. 제거 후 Cat 근접 공격 취약 상태. 2인 협력이 필수인 적 유형.

- **패리 유도형 적** — Spiritfall 참고: 특정 공격 전 "실드 자세"를 취하는 적. 이 공격은 Crop이 패리해야만 스턴 걸림. Cat 혼자 근접 돌진 시 카운터 데미지. 패리 메카닉을 자연스럽게 가르치는 교육용 적.

- **분신형 적** — 두 타겟 중 '진짜'를 근접/원거리 중 올바른 공격으로 구별해야 함. 예: 진짜 적은 Cat 슬래시에 피격 반응, 가짜는 Crop 투사체에 피격 반응. 두 플레이어가 서로 정보를 공유해야 하는 사회적 협력 요소.

## 맵 (03_Maps)

- **패리 트리거 문** — Spiritfall 패리 시스템 참고: 특정 방에 진입하면 실드 형태의 장벽이 생기고, Crop이 날아오는 에너지 볼을 패리해야만 문이 열림. Cat 혼자로는 진행 불가.

- **2레인 전투 방** — Death's Door 구성 참고: 방 상단 레인(원거리 적 배치) + 하단 레인(근접 적 배치). Crop은 상단 처리, Cat은 하단 처리로 자연스럽게 공간 분할. 같은 화면 안에서 두 플레이어가 각자 역할 수행.

- **시간 제한 강화방** — 일정 시간 내 모든 적 처치 시 추가 업그레이드. 합체 게이지를 채워 강화 상태를 적시에 쓰는 압박 훈련. 시간 초과 시 벌칙 없이 그냥 진행 가능 (초보 친화성 유지).

## 전투 (04_Combat)

- **약점 아이콘 시스템** — Death's Door 시각 언어 참고: 근접 전용 적에 발톱 아이콘, 원거리 전용 적에 새싹 아이콘 상시 표시. 색맹 대비로 아이콘+색 이중 표시. 플레이어가 UI 설명 없이 직관적으로 파악 가능.

- **패리 폭발 능력** — Spiritfall Blessing 참고 + AbilitySystem 구현: Crop 패리 성공 시 주변 반경 2칸 적에게 데미지. `ParryExplosionAbility` ScriptableObject로 구현, 업그레이드 선택지로 등장. 패리를 "공격 회피" 에서 "공격 기회"로 격상.

- **보스 페이즈 전환 연출** — Death's Door 참고: 보스 체력 50% 도달 시 전투 2초 정지 + 화면 전체 이펙트 + BGM 전환. Unity 구현: `OnHealthThreshold(0.5f)` 이벤트 → Coroutine으로 `Time.timeScale = 0` 2초 후 페이즈 2 돌입.

## 스토리 (05_Story)

- **선택 화면 속 세계관 암시** — Character Select Screen 참고: 선택 화면 배경이 단순 UI가 아닌 고양이가 화분을 들고 모험을 떠나기 직전 집 문 앞 모습. 게임 시작 전부터 세계관 몰입 유도.

- **합체 게이지 = 두 생명의 유대** — 게이지가 가득 찰 때 Cat과 Crop이 서로를 바라보는 짧은 이펙트 삽입. 기계적 메카닉에 감정선 연결. "우리가 함께 싸울 때 가장 강하다"는 주제 표현.

- **각 적 유형의 배경 설명** — 약점 아이콘 시스템과 연계: 근접 전용 적은 "갑옷 생물", 원거리 전용 적은 "영체(幽體)" 등 설정 부여. 왜 그 공격만 통하는지 세계관으로 설명 가능.

## 기술 메모

- **Ability System Architecture**: `AbilityBase : ScriptableObject` 추상 클래스 + `AbilityHolder` 컴포넌트 조합이 OnionCat 능력 시스템의 핵심 골격. 런 시작 시 `AbilityHolder.ClearAbilities()` → 업그레이드 획득마다 `AddAbility()` 호출. Cat용 / Crop용 / 공유용 3개 `AbilityHolder`를 각각 GameObject에 부착.

- **Character Select Screen**: 최소 구현 우선 — Player 1(키보드) / Player 2(마우스) 각각 `SpaceBar` / `LMB`로 "준비 완료" 토글 → 둘 다 Ready면 시작 버튼 활성화. `PlayerInputManager`의 자동 조인 기능으로 컨트롤러 핫플러그 대응. 씬 전환 전 반드시 `DisableJoining()` 호출할 것.
