## 캐릭터 (01_Characters)

- **CRASH 속력 반영 피해** — 환경 킬 체인 시스템 참고: 현재 CRASH는 고정 피해인지 확인 필요. 날아간 속력(`relativeVelocity.magnitude`)에 비례하여 피해가 달라지면 "강하게 차면 더 아프다"는 물리 쾌감이 생김. `HitFeelSettings.asset`의 `crashDamageMin/Max/SpeedRange` 값만 추가하면 구현 가능
- **킥 체인 카운터 레이블** — Anger Foot 체인 참고: 1번 CRASH 후 연쇄 킥 콤보가 이어지면 "CHAIN ×2, ×3" 레이블을 화면 중앙에 누적 표시. 현재 "KICK COMBO!"가 뜨는 HUD 레이블에 카운터만 추가하면 됨. `GameManager.Run`에 현재 체인 카운트 저장

## 적 (02_Enemies)

- **벽 반사 적** — 환경 킬 체인 응용: 날아간 고양이 투사체(털뭉치)나 양파 씨앗이 벽에 부딪힌 적에게 다시 튕겨 나와 추가 적을 맞히는 "탄 반사 CRASH" 패턴. 적이 벽에 충돌할 때 `OnCrash` 이벤트를 발생시키고, 해당 이벤트에 구독한 `GearEffect`(장비 효과)가 반사탄을 생성. 구현 진입점 쉬움
- **구덩이 수호자** — 구덩이를 전투 자원으로 쓰는 방 기믹: 방 중앙에 구덩이가 있고 적들이 가장자리를 지나 돌진. 고양이가 이동하다 보면 자연스럽게 적을 구덩이 방향으로 유도하게 됨. 기믹방이 아닌 일반 전투방에도 배치 가능 — 방 레이아웃에 구덩이 구간 추가

## 맵·런 구조 (03_Maps)

- **킥 특화 방 레이아웃 추가** — 현재 12개 방 중 구덩이가 중요한 역할을 하는 방이 몇 개인지 확인 필요. 구덩이를 방 가운데 배치하고 사방이 짧은 벽으로 막힌 "킥 아레나" 레이아웃 1~2개 추가 시 킥 메카닉의 가치를 더 느낄 수 있음. `RoomLayouts/*.asset` 파일 추가로 바로 구현 가능
- **출구 표식 보상 힌트 강화** — Last Epoch Monolith 에코 선택 참고: 현재 출구 표식은 다음 방 보상 축(RewardAxis)만 알려줌. "등급 힌트(에픽 이상 확정)" 또는 "세트 아이콘(Sun 아이템 포함)" 같은 추가 정보를 표식 옆에 작은 아이콘으로 표시하면 플레이어가 방향을 전략적으로 선택할 수 있음. `RoomExitMarker` 컴포넌트 확장

## 전투·협동 (04_Combat)

- **폭탄 예고 연동 킥 타이밍 힌트** — 환경 킬 체인 참고: 양파가 박(BouncingBomb)을 심으면 박 위에 작은 화살표 아이콘이 생겨 "이 방향으로 킥하면 박에 닿는다"는 힌트를 줌. 양파는 이미 박을 심고, 고양이는 킥 방향을 조준하는 협동 플레이가 자연스럽게 유도됨. 구현: 심긴 박 주변 감지 + Raycast로 킥 방향 선이 박 방향과 일치하면 아이콘 표시
- **걷어차기 충전 게이지** — 킥이 많이 쓰일수록 (CRASH, KICK COMBO 달성 시) 걷어차기 쿨다운이 소폭 단축되는 "킥 피버(Kick Fever)" 시스템. 구현: CRASH/KICK COMBO 발생 시 `StatType.KickCooldownBonus` 일시 증가, 3초 후 감소. 현재 쿨 4초가 최대 2.5초까지 단축되는 느낌

## 아이템·세트 (05_Items)

- **장비 등급 보조 아이콘** — 색맹 접근성 모드 참고: 색약 모드 유무와 무관하게 장비 슬롯 테두리에 등급 아이콘(★/◆/왕관)을 항상 표시하는 옵션 추가. 현재 등급은 테두리 색으로만 구분되는데, 아이콘이 추가되면 빠른 인식 속도가 향상됨 (컬러가 안 보여도, 작은 화면에서도). `GearScreen`·`ItemSlotUI`에 간단한 스프라이트 레이어 추가
- **Last Epoch 스타일 세트 보너스 팝업 개선** — 현재 세트 아이템에 커서를 올리면 팝업이 뜨지만, 팝업 내 "현재 보유 2개 → 다음 단계까지 2개 더"처럼 진행 상황을 수치로 보여주면 더 명확. `SetBonusPopup`의 각 단계 라벨에 `(n/4 보유)` 같은 서브텍스트 추가. UI 줄 하나 추가로 구현 가능

## 스토리·메타 (07_StoryMeta)

- **색맹 접근성 설정** — 색맹 접근성 모드 참고: 현재 설정 메뉴에 음량·화면 흔들림 외에 시각 접근성 항목 없음. 최소한 "등급 아이콘 항상 표시", "예고 패턴 보조" 두 가지 옵션을 ESC 설정 메뉴에 추가하면 접근성이 크게 향상됨. 실 개발 비용 작음 (스프라이트 추가 + PlayerPrefs 저장)
- **런 통계에 CRASH/킥 콤보 횟수 추가** — 런 결과 화면(이미 구현됨)에 환경 킬 수(CRASH·낙사·KICK COMBO) 카운터 표시. Last Epoch의 런 후 통계처럼 "얼마나 킥을 잘 썼나"를 수치로 확인하면 플레이어가 킥 메카닉의 재미를 인식하게 됨. `RunData`에 카운터 3개 추가 + `RunResultScreen`에 라벨 추가

## 기술 메모

- **환경 킬 체인 시스템**: CRASH가 현재 속력 기반인지 고정 피해인지 확인 후, `col.relativeVelocity.magnitude`를 이용한 스케일링 피해 추가 고려. `HitFeelSettings.asset`에 파라미터 추가 → 플레이 중 실시간 튜닝 가능. 가장 중요한 추가: CRASH 후 기절 시간 동안 적이 벽에 붙어있는 연출(`AddForce(-normal * pushbackForce)`) — 현재 맞고 튕겨나와 빈 공간으로 나오면 어색함
- **색맹 접근성 모드**: 포스트프로세싱 색 변환 행렬보다 **아이콘+패턴** 방식이 픽셀아트 팔레트를 깨드리지 않아 더 적합. 당장 할 수 있는 것: 장비 등급 아이콘 스프라이트 4개(`Assets/Sprites/UI/RarityIcon_Common/Rare/Epic/Legendary.aseprite`) 제작 + `ItemSlotUI`에서 `RarityIcon` 서브 SpriteRenderer 추가. 1~2시간 작업으로 완성
