## 캐릭터 (01_Characters)

- **Crop의 독백 시스템** — Transistor 참고: Transistor가 Red에게 실시간 해설을 주듯, Crop(양파)도 전투 중 짧은 대사를 중얼거림. "조심해, 오른쪽!" / "이 녀석은 내가 맡을게." 등. 별도 보이스 없이 말풍선 픽셀 텍스트만으로도 캐릭터 생동감↑
- **Cat과 Crop의 비대칭 성장** — 20XX Nina/Ace 참고: 런 업그레이드가 Cat 전용(대시 거리, 슬래시 범위)과 Crop 전용(투사체 수, 실드 내구도)으로 분리. 플레이어가 각자 원하는 방향으로 캐릭터를 특화시켜 회차마다 다른 느낌
- **'무기가 캐릭터' 컨셉 강화** — Transistor 참고: Crop을 단순 투사체 발사기가 아닌 "의지가 있는 동반자"로 표현. 보스 처치 후 Crop의 특별 반응 대사, 죽음 직전 "같이 버텨보자" 같은 긴박한 상호작용 연출

## 적 (02_Enemies)

- **역할 강제 분업 적 — 근접 실드 + 원거리 코어** — 20XX 참고: 전면에 메탈 실드(Cat 슬래시만 파괴), 실드 뒤에 취약 코어(Crop 원거리 공격 필요). 두 플레이어가 동시에 다른 행동을 해야만 처치 가능 → 협력 강제
- **Transistor Process형 적 — 상태 복사** — Transistor 참고: 처치하지 않고 두면 쓰러진 적을 "흡수"해 강화 복사본 생성. OnionCat에서는 처치 타이밍을 놓치면 적이 아군 스킬 중 하나를 무효화하는 변종이 됨
- **턴제 패턴 경고 적** — Transistor Turn() 참고: 일부 보스가 "준비 모션 3초" 후 강력한 공격 실행. 이 3초 동안 Cat은 이동 포지셔닝, Crop은 연속 사격으로 역할 분담 → Transistor의 계획-실행 루프를 실시간에 녹임

## 맵 (03_Maps)

- **방 타일 조각 분류 태그** — 20XX 참고: 방을 "전투 구간 / 이동 구간 / 보상 구간" 세 종류 타일 조각으로 분류. 조합 알고리즘이 각 타입을 순서 있게 배치해 층이 너무 쉽거나 너무 복잡해지지 않도록 조절
- **버전별 방 고정 시드** — 버전 표시 기능 참고: `v0.1.0` 빌드에서 특정 씨드 방을 고정 제공 → 플레이테스터가 같은 방을 경험하고 동일 조건 피드백 가능. `Application.version`을 씨드 생성에 포함
- **에디터 전용 방 미리보기 도구** — 커스텀 에디터 참고: Inspector에서 방 타입(전투/이동/보상)을 선택하면 씬 뷰에 해당 방 레이아웃을 Gizmos로 즉시 미리보기. 방 배치 설계 반복 속도↑

## 전투 (04_Combat)

- **Function 슬롯 업그레이드** — Transistor 참고: 런 중 획득한 아이템을 "Active / Upgrade / Passive" 세 슬롯 중 하나에 꽂음. 같은 아이템도 Active에 넣으면 새 공격기술, Upgrade에 넣으면 기존 기술 강화, Passive면 지속 버프 — 아이템 수는 적게 유지하면서 조합 다양성 폭발적 증가
- **근거리/원거리 동시 처리 콤보** — 20XX 참고: Cat이 슬래시로 적을 스턴시키는 순간 Crop이 강화 투사체를 발사하면 크리티컬 발동. 협력 타이밍 맞춤에 보상 부여로 "같이 하면 더 강하다" 체감 강화
- **Limit(핸디캡) 자발 선택** — Transistor Recursion 참고: 런 시작 전 자발적 핸디캡 선택(예: "Cat 대시 제거", "Crop 투사체 수 -2") 대신 경험치/골드 2배. 도전적인 플레이어에게 선택지 제공

## 스토리 (05_Story)

- **Crop의 과거 기억 파편** — Transistor 참고: Transistor가 회로 속 기억을 조각조각 전달하듯, Crop도 특정 방에서 플래시백 환영을 보여줌. "나는 원래 어떤 밭에서 자랐는지..." → 말없이 픽셀 아트 컷씬 1~2장으로 표현
- **Cat이 모르는 Crop의 비밀** — Transistor 내러티브 참고: Red는 Transistor의 진짜 정체를 처음에 모름. OnionCat도 Cat은 Crop을 단순한 화분 식물로 알지만, 스토리 중반 Crop이 고대 마법 씨앗임이 드러나는 반전
- **엔딩 분기 — Crop 분리 vs 함께** — Transistor 엔딩 참고: 모든 런을 클리어하면 두 가지 엔딩 분기. ① Crop이 Cat의 등에서 내려와 독립적으로 살게 됨(해피 엔딩), ② 함께 더 강한 세계로 나아감(진 엔딩) — 플레이어 선택

## 기술 메모

- **커스텀 에디터**: `[ContextMenu]` + `OnDrawGizmos`만으로 방 스폰 포인트 배치 속도를 크게 높일 수 있음. 지금 당장 `EnemySpawner`와 `RoomConfig`에 추가해볼 것. `CustomEditor` 클래스는 방 수 10개 넘어갈 때 고려.
- **버전 표시**: `VersionDisplay.cs` 하나 만들어 `Application.version` 읽어 TMP_Text에 표시 — 30분 작업. `Player Settings → Version`을 `0.1.0`으로 설정하는 것부터 시작. 플레이테스트 전에 반드시 처리할 것.
