## 캐릭터 (01_Characters)

- **업그레이드 색상 코딩** — Brotato 참고: Cat 전용 업그레이드는 주황색, Crop 전용은 초록색, 공유는 흰색으로 카드 색상을 분류. 선택 화면에서 플레이어 역할과 연결되어 직관적으로 자신의 업그레이드를 인식할 수 있음. 구현 힌트: 업그레이드 ScriptableObject에 `OwnerType` enum(Cat/Crop/Shared) 필드 추가 후 UI 카드 배경색 바인딩.

- **스탯 투명성 UI** — Brotato 참고: 업그레이드 선택 시 현재 수치 → 변화 후 수치를 나란히 표시 (예: "슬래시 데미지 10 → 14"). 플레이어가 업그레이드 효과를 예측할 수 있어 선택의 재미 증가. 구현 힌트: InRun_Build_Viewer_UI.md의 스탯 표시 컴포넌트에 "미리보기 모드" 추가.

- **변이 카테고리 분류** — Nuclear Throne 참고: Red(공격)/Green(기동)/Yellow(원거리)/Blue(방어) 같은 컬러 카테고리로 업그레이드를 분류. OnionCat에서는 Cat 공격 / Cat 기동 / Crop 공격 / Crop 방어 / 공유로 5분류. 구현 힌트: Upgrade ScriptableObject에 `UpgradeCategory` enum 추가, 업그레이드 풀 생성 시 카테고리 가중치 적용.

## 적 (02_Enemies)

- **역할 강제 적 — 방어막 적** — Nuclear Throne + OnionCat 컨셉 참고: 전방에 방어막을 두른 적이 등장. Cat의 근접 슬래시는 정면에서 막히고 후방은 취약. Crop의 원거리 투사체는 방어막을 관통하지 못함 → Cat이 전방에서 방어막을 찢어주고(slash), Crop이 후방을 공격하는 협력 유도. 구현 힌트: 방향 기반 히트박스 + Damage_System의 저항 시스템 활용.

- **Brotato식 웨이브 미니보스** — Brotato 참고: 웨이브 10, 20 등 특정 웨이브마다 강화 미니보스 등장. OnionCat에서 방 클리어 5번마다 엘리트 적 1마리 추가. 엘리트 적은 일반 적 능력치 × 3 + 고유 패턴 1개. 구현 힌트: Enemy_Spawner_Wave_System.md의 웨이브 카운터에 엘리트 스폰 트리거 추가.

- **방사선(Radiation) 유형 — 자기장 적** — Nuclear Throne 참고: 자기장을 생성하여 Cat의 이동을 끌어당기는 적. Crop의 투사체는 경로가 휘어짐. 두 플레이어 모두에게 직접적인 영향을 주는 환경형 위협. 구현 힌트: 자기장 반경 내 Rigidbody2D에 AddForce() 적용, 투사체에는 Physics2D.OverlapCircle로 방향 보정.

## 맵 (03_Maps)

- **재화 드롭 밀도 조정 방** — Brotato 경제 시스템 참고: "부자 방" (재화가 2배 드롭하지만 적이 없음)과 "위험 방" (재화 없음, 적만 있음) 교차 배치. 플레이어가 효율적인 경로를 선택하는 전략성 추가. 구현 힌트: Room ScriptableObject에 `RoomType` 필드 (Combat/Treasure/Elite/Rest) 추가, 절차 생성 시 가중치 랜덤으로 배치.

- **Nuclear Throne식 레이어 진행** — Nuclear Throne 참고: 테마가 다른 7개 월드 구조를 OnionCat에 적용. 온이온캣 테마 예시: 텃밭(튜토리얼) → 창고 → 도시 공원 → 지하철 → 옥상 → 연구소 → 탑 꼭대기(보스). 각 레이어마다 고유 타일셋 + 고유 적 1~2종 추가. 구현 힌트: Tilemap_Rule_Tile_System.md + 레이어별 Enemy ScriptableObject 풀 분리.

- **비밀 방 조건** — Nuclear Throne + Enter the Gungeon 참고: 런 중 특정 조건(같은 방에서 적 전멸 + 30초 내)을 달성하면 숨겨진 문이 열림. 비밀 방에는 희귀 업그레이드 또는 스토리 힌트. 구현 힌트: 방 클리어 시간 측정 타이머 + 조건 달성 시 비활성화된 Door 오브젝트 활성화.

## 전투 (04_Combat)

- **오브젝트 풀 기반 탄막 최적화** — Unity Object Pool API 참고: Crop의 기본 투사체를 ObjectPool<Projectile>로 전환. 초당 5발 기준 60fps 유지 목표. 탄막 패턴 (부채꼴 3발, 전방 집중 5발) 모두 동일 풀에서 꺼내 방향만 다르게 설정. 구현 힌트: ProjectilePool 싱글톤 → CropShooter에서 pool.Get() 호출, 충돌/화면 이탈 시 pool.Release().

- **Brotato식 무기 티어 시스템** — Brotato 참고: 같은 업그레이드 카드 3개 선택 시 자동으로 강화 버전 획득. OnionCat 적용: Cat 슬래시 업그레이드 3회 → "강화 슬래시" (범위 2배, 쿨타임 -30%). Crop 투사체 3회 → "에너지 탄" (관통 + 폭발). 구현 힌트: 업그레이드 카운터 dict + 임계값 도달 시 UpgradeManager가 강화 카드로 교체.

- **Nuclear Throne 히트스톱 구현** — Nuclear Throne 피드백 참고: 근접 히트 시 0.05초 Time.timeScale = 0.05, 원거리 히트 시 0.03초. Vlambeer 철학: "과장된 피드백이 타격감을 만든다". OnionCat에서 Cat 슬래시가 히트했을 때 히트스톱 + 카메라 흔들림 동시 적용. 구현 힌트: TimeScale_BulletTime_System.md + Feedback_System.md 조합, Crop 투사체는 히트스톱 없이 파티클만.

## 스토리 (05_Story)

- **캐릭터 해금 스토리** — Brotato + Nuclear Throne 참고: 런을 성공할수록 화분 위 작물이 변한다 (씨앗 → 새싹 → 꽃 → 열매). 각 단계마다 고양이와 작물의 짧은 대화가 추가. "열매"가 되면 최종 엔딩 해금 조건 달성. 구현 힌트: 런 클리어 횟수를 세이브 데이터에 저장, 임계값마다 Dialogue_Event_System으로 짧은 컷씬 트리거.

- **세계관 — 방사능 텃밭** — Nuclear Throne 방사선 테마 참고: OnionCat 세계에서는 이상한 비료 때문에 작물들이 의식을 갖게 됨. 고양이는 우연히 화분을 들게 된 길고양이. 엔딩: 작물이 마침내 꽃을 피워 씨앗을 날려 보내고, 고양이는 홀가분하게 어딘가로 사라짐. 구현 힌트: 엔딩 컷씬은 Ingame_Cutscene_System.md 활용, 배경 픽셀아트 스크롤링.

- **런 사이 스토리 단편** — Brotato 참고: 런 결과 화면에 짧은 텍스트 (3~5줄) 표시. "오늘도 고양이는 화분을 들고 돌아다녔다. 양파는 조용히 투덜댔다." 수십 가지 랜덤 문장 풀에서 선택. 구현 힌트: Run_Result_Screen.md에 랜덤 텍스트 표시 컴포넌트 추가, 문장 리스트는 ScriptableObject 또는 JSON 관리.

## 기술 메모

- **Unity Object Pool API**: `UnityEngine.Pool.ObjectPool<T>`를 Crop 투사체에 즉시 적용 가능. 핵심은 `createFunc` / `actionOnGet` / `actionOnRelease` 세 람다, `collectionCheck: true`는 개발 중만 사용. Projectile 컴포넌트가 풀 참조를 `Init(IObjectPool<Projectile>)`으로 받아 스스로 `Release()` 호출하는 패턴이 깔끔.

- **App Boot Sequence**: OnionCat은 `BootScene(index 0) → MainMenu → Game` 구조를 권장. BootScene의 BootManager에서 GameManager → AudioManager → InputManager 순 초기화 후 씬 전환. Editor 직접 테스트 시 싱글톤 null 체크 필수. `[DefaultExecutionOrder(-1000)]` 어트리뷰트로 Script Execution Order를 코드로도 지정 가능.
