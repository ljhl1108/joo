## 캐릭터 (01_Characters)

- **"조작이 항상 재밌어야" 점검** — Towerborne "All buttons lead to awesome" 원칙: 고양이·양파 각 행동을 별도로 플레이테스트해 "안 쓰고 싶어지는 버튼"이 없는지 확인. 특히 Z/X 가방 순환, Q 던지기가 단독으로도 보람 있는지 확인 필요.
- **장비 세트 보너스 HUD 힌트** — Towerborne처럼 현재 세트 진행 상태("태양 2/4")를 HUD에 작게 표시. `CombatModifiers.Has()` 결과를 보상 선택 화면과 HUD 한 귀퉁이에 연동하면 "다음에 뭘 고를지" 목표감 생김.
- **장비 분해 환원 체감** — Towerborne Spirit Dust처럼, 중복 장비 분해 시 씨앗이 돌아오는 연출(씨앗이 튀어나오는 파티클)로 "버려진 아이템"이 아니라 "투자 자원"으로 느끼게 개선 가능.

## 적 (02_Enemies)

- **조건부 버프 적** — Towerborne Aspect "공중에 뜬 적에게 추가 피해" 역으로 적에게도 적용: 공중 상태(날아가는 중)인 적은 피해를 더 받는 약점 창 → 고양이가 날려보내고 양파가 이어서 쏘는 협동 콤보 보상 강화. 현재 `EffectTrigger.WallCrash` + 공중 피해를 연계하면 구현 가능.
- **조합형 적에 Aspect 개념 도입** — 현재 EnemyBuilder의 "움직임 + 공격 + 특성" 조합에서 "특성"을 Towerborne Aspect처럼 조건부 행동으로 세밀화: "HP 50% 이하면 공격 속도 1.5×", "플레이어 근접 시 뒤로 물러서며 발사" 등 → `EnemyPattern_Composition_System.md` 패턴 활용.
- **엘리트 적 전조 색상** — Towerborne의 클래스별 색상 구별처럼, OnionCat 엘리트 적은 기본 적과 같은 종류라도 색이나 외곽선이 달라서 "이건 강한 것"임을 즉시 인식. `Enemy_Elite_Variant_System.md` + `Sprite_Outline_Highlight_System.md` 조합으로 가능.

## 맵·런 구조 (03_Maps)

- **가판대 방 리롤 경제 조정** — 현재 씨앗 획득량 대비 리롤 비용이 없는 상태. 에스컬레이션 테이블 추가 (첫 리롤 씨앗 8→16→30→50 상한). 두 플레이어가 합의해야 하는 긴장감 → 협동 경험 강화. `Shop_Reroll_Economy_System.md` 구현 그대로 사용 가능.
- **스테이지별 가판대 테마** — 2단계 마을 가판대는 "떠돌이 상인" 풍, 등대 근처는 "어부 창고" 풍으로 아이콘·배경만 교체. 같은 코드, 다른 느낌 → `Room_Special` 재사용에 테마만 넣으면 됨.
- **보상 선택 화면에 세트 진행 표시** — 현재 `UpgradeSelectUI`에서 각 장비 카드 아래에 "세트 O: 현재 1→이 카드 고르면 2" 표시. 선택 직전에 세트 시너지를 볼 수 있으면 의사결정이 더 의미 있어짐.

## 전투·협동 (04_Combat)

- **Tab 조작 도움말 오버레이 추가** — 비대칭 조작 혼동을 줄이기 위한 최소 비용 UX. `InGame_Control_Help_Overlay.md` 그대로 구현. 첫 번째 방 입장 시 1회성 "Tab 눌러보세요" 토스트 추가로 발견 가능성 확보.
- **합동기 힌트 연출** — 합동기 게이지가 100%가 됐을 때 두 플레이어 모두에게 버튼이 깜빡이는 시각 힌트 (새 플레이어에게 "지금이야!" 타이밍 안내). 오버레이에서 합동기 조작법을 하이라이트해서 보여줘도 좋음.
- **패리 성공 → 세트 발동 연계** — Towerborne Aspect "적시 회피 → 추가 방어력"처럼, OnionCat 패리 성공 시 특정 세트 효과가 발동하는 장비 추가. 기존 `EffectTrigger.ParryHit` + `GearEffect` 연동으로 구현 가능.

## 아이템·세트 (05_Items)

- **세트 보너스 Aspect 조합 장비** — Towerborne의 Aspect 슬롯 아이디어: 장비에 "조건부 발동" 효과를 1개씩 붙임 (현재 `GearEffect`와 거의 같음). 단, Aspect 조건을 더 다양하게 — "합동 콤보 중에 맞으면", "패리 직후 5초 안에", "대쉬 중에 적에게 맞히면" 등 타이밍 조건 추가.
- **클래스 비차별 장비 → 양쪽이 보완** — Towerborne처럼 고양이 장비 / 양파 장비를 완전히 분리하지 않고, 일부 장비는 "한쪽이 갖고 있으면 다른 쪽도 혜택" 형태 가능. 예: "양파가 화염 세트 2개 → 고양이 슬래시에 화염 추가" → 협동이 세트 보너스에서 보이게.
- **장비 조합 힌트 UI** — 보상 선택 화면에서 같은 세트 장비를 고르면 "세트 2단계 완성!" 뱃지 표시. Towerborne의 세트 가시성 UX → `InRun_Build_Viewer_UI.md` 패턴 활용.

## 스토리·메타 (07_StoryMeta)

- **1.0 출시 전 Early Access 전략 참고** — Towerborne은 EA에서 플레이어 피드백으로 클래스 마스터리 시스템을 추가. OnionCat도 itch.io 베타 → 피드백 → 세트 보너스 UI·리롤 경제 조정 순서로 반복 가능. `Closed_Beta_Management_System.md` 참고.
- **첫 판 10분 경험 설계** — Towerborne 1.0 비판 중 "첫 플레이가 헷갈린다"는 의견. OnionCat도 첫 판에서: ① 오버레이 힌트 ② 고양이·양파 조작 1줄 소개 대사 ③ 합동기 발동 순간 "함께 눌러요!" 가이드 → `First_Run_FTUE_Onboarding.md` 참고.
- **세트 보너스 해금 순간 연출** — 세트 단계가 올라가는 순간 (1→2→3) 작은 팡파레 연출 추가. Towerborne의 "장비가 늘수록 강해지는 느낌"이 시각적으로 느껴지게. `Unlock_Reward_Ceremony_System.md` 참고.

## 기술 메모

- **Shop Reroll Economy**: 에스컬레이션 테이블 (8→16→30→50)을 `ShopManager`에 `int[]`로 넣으면 됨. 첫 리롤까지는 "살짝 아깝다" 정도, 세 번째부터는 "포기하는 게 낫겠다" 느낌이 나야 함. 씨앗 한 판 획득량과 비교해서 비율 조정 필수.
- **In-Game Control Overlay**: Tab 토글 + `GameState.Paused` 연동 + `Time.unscaledDeltaTime` 주의. 비대칭 2인 조작 때문에 고양이/양파 탭 분리가 필수. HUD "?" 버튼 + 첫 방 1회 토스트로 발견 가능성 확보.
