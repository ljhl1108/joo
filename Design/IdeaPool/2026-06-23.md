## 캐릭터 (01_Characters)

- **에너지 공유 업그레이드** — Soul Knight 참고: Cat 대시 성공 시 Crop의 투사체 에너지 일부 충전되는 패시브 업그레이드. 두 플레이어가 서로의 플레이를 의식하게 만드는 협동 강화 메커니즘. C#에서 이벤트 시스템(`Action<float>`)으로 Cat → Crop 에너지 전달 구현 가능.
- **Cat 대시 무적 시각화** — Shader Effects 참고: 대시 중 Cat 스프라이트에 Outline Shader + 반투명(alpha 0.6f) 적용. MaterialPropertyBlock으로 제어하여 배칭 유지. 플레이어 2(Crop)가 Cat의 무적 타이밍을 눈으로 확인 가능 → 더 적극적인 패리 타이밍 계획 가능.
- **Cat & Crop 티격태격 보이스** — Dialogue Event System 참고: 보스 방 진입, 첫 피격, 체력 위기 시 자동 트리거되는 짧은 대화 (2~3줄). ScriptableObject로 상황별 대화 묶음 관리. 예: 체력 20% 이하 → "Cat: 힘들어... Crop: 조금만 더!"

## 적 (02_Enemies)

- **단계별 취약 적 (방패기사)** — Soul Knight 참고: 정면에 방패를 든 적. Cat의 대시로 방패 내구도 감소, 방패 파괴 후 Crop의 원거리로만 처치 가능. "준비 → 파괴 → 마무리" 3단계로 두 플레이어의 순서 있는 협력 강제. 방패 내구도는 체력바 위에 별도 파란 바로 표시.
- **투명 유령 적** — 원거리 투사체를 통과시키는 유령. 오직 Cat의 근접 슬래시만 타격 가능. Soul Knight의 원소 취약 시스템을 OnionCat의 이분법으로 변환. 유령은 이동 경로가 불규칙(사인파)하여 Cat이 대시로 따라가야 하는 상황 연출.
- **피격 시 도주 적 (겁쟁이)** — 원거리 공격받으면 도주하고 근접하면 폭발. Crop이 쏘면 도망가고 Cat이 쫓아야 하는 상황. 대화 이벤트와 연동 가능: 처음 만나면 "Crop: 쏴볼게! Cat: 잠깐!!"

## 맵 (03_Maps)

- **랜덤 이벤트 방 (씨앗 방)** — Dialogue Event System 참고: 특수 방 입장 시 대화창 팝업. 선택지: "씨앗을 심는다(HP 회복)" vs "씨앗을 먹는다(공격력 +1런)" vs "무시한다". onChoose UnityEvent로 게임 효과 연동. 세계관(농사/고양이)과 일치하는 이벤트 연출.
- **에너지 공유 방** — Soul Knight 에너지 공유 참고: 방 중앙에 에너지 오브(구체)가 있고, Cat과 Crop이 동시에 닿으면 각자 에너지 만충. 둘이 협력해야만 얻는 보상 → 협동 강제 방. 방에 들어가면 Cat 플레이어만 닿을 수 없는 영역 + Crop 플레이어만 닿을 수 없는 장애물 배치.
- **아웃라인 힌트 방** — Shader Effects 참고: 숨겨진 비밀 방 입구에 있는 벽이 특정 조건(근접/원거리 공격)에 반응하여 아웃라인 Glow. Cat이 공격하면 빨간 글로우, Crop이 공격하면 파란 글로우, 동시 공격 시 황금 글로우 → 문 개방. 두 플레이어가 동시에 해야 열리는 비밀 방.

## 전투 (04_Combat)

- **패리 성공 Shader 피드백** — Shader Effects 참고: Crop 패리 성공 시 황금색 Hit Flash + 0.2초 Outline Glow. `_FlashColor`를 황금색으로 오버라이드하는 별도 패리 플래시 코루틴 추가. 패리 성공 순간 히트스톱(timeScale 0.1f, 0.05초)과 조합하면 최강의 피드백.
- **Soul Knight식 속성 탄환** — Soul Knight 무기 속성 참고: Crop의 투사체가 런 업그레이드로 속성(불/냉기/독) 부여 가능. 불 투사체는 식물형 적 데미지 2배, 냉기는 이동속도 50% 감소. 속성은 투사체 색상 + 파티클로 구분. 기본 구조: `ProjectileData.DamageType` enum + `Enemy.Resistances` 배열.
- **연속 패리 보너스** — 같은 런에서 패리를 3회 이상 성공하면 Cat 공격력 일시 강화(10초). Soul Knight의 콤보 시스템에서 영감. UI에 패리 카운터 표시. Crop 플레이어가 적극적으로 패리를 노리게 만드는 인센티브.

## 스토리 (05_Story)

- **Cat & Crop의 첫 만남 대화** — Dialogue Event System 참고: 게임 시작 전 자동 대화 연출 (10줄 이내). "화분이 등에 떨어진다 → Cat 놀람 → Crop이 말 건넴". ScriptableObject DialogueData로 제작. 첫 런 한 번만 재생하고 PlayerPrefs로 "튜토리얼 완료" 플래그 저장.
- **NPC 농부 캐릭터** — Soul Knight 상점 시스템 참고: 각 층마다 만날 수 있는 랜덤 NPC 농부. 아이템 판매 + 세계관 힌트 대화 1~2줄. "이 씨앗을 심으면... 아마도 꽃이 필 거야. 아마도." 대화 후 선택지 "구매(골드 소모)" / "거절". 매 런 랜덤으로 4~5가지 대사 풀 중 1개 선택.
- **보스 사망 이벤트 대화** — 보스 처치 후 짧은 대화 자동 재생. "Cat이 자신의 발톱을 본다 → Crop: 잘했어, Cat." 층 클리어 보람을 강화. 보스별 다른 대화 에셋 (DialogueData ScriptableObject 4~5개) 적용.

## 기술 메모

- **Shader Effects**: `MaterialPropertyBlock` 사용이 핵심 — 같은 머티리얼을 공유하는 모든 적이 각자 독립된 Hit Flash 타이밍을 가질 수 있으면서 드로우콜 배칭도 유지됨. `material.SetFloat` 직접 호출은 인스턴스 복사본 생성으로 드로우콜 폭발. 피격 시 `GetPropertyBlock → Set → SetPropertyBlock` 3단계 순서 반드시 지킬 것.
- **Dialogue Event System**: `Time.timeScale = 0` 중 코루틴 내부에서 반드시 `WaitForSecondsRealtime` 사용. 타이핑 효과가 멈추는 버그 방지. New Input System Action Map 전환(`SwitchCurrentActionMap("Dialogue")`)으로 대화 중 캐릭터 조작 차단 필수. ScriptableObject DialogueData에 대화 내용 분리 → 코드 수정 없이 기획 변경 가능.
