## 캐릭터 (01_Characters)

- **신의 축복 비대칭 선택** — Hades Boon 시스템 참고: 방 클리어 후 "Cat 전용 Boon 3개"와 "Onion 전용 Boon 3개"를 동시에 제시. 두 플레이어가 각자 고르되 서로 보여주며 협의하는 구조. 구현: `UpgradeOfferUI` 에 `PlayerRole` 필터 적용, P1/P2 각자 UI 패널 분리.

- **Gungeon 스타일 캐릭터 고유 시작 무기** — Enter the Gungeon 참고: 런 시작 시 Cat은 항상 "기본 발톱 참"으로, Onion은 "씨앗 3발 기본 발사체"로 시작. 서로 다른 기본 성능이므로 초반 전략 자체가 매 런마다 동일한 베이스에서 출발. 이후 Boon으로 변주. 구현: `RunInitializer.SetStartingAbilities(catDefault, onionDefault)`.

- **Death Defiance → 공유 부활 토큰** — Hades 참고: 런 내 최대 3개의 공유 부활 토큰. HP가 0이 되면 토큰 1개 소모 후 그 자리에서 HP 30% 회복. 둘 다 동시에 쓰러지거나 토큰 소진 시 런 종료. 구현: `SharedReviveTokens` int, 처치 시 `Coop_Revival_System.md` 연동.

## 적 (02_Enemies)

- **탄막 특화 적 (Gungeon 스타일)** — Enter the Gungeon 참고: 화면을 가득 채우는 규칙적 탄막을 발사하는 적. Cat은 대시로 탄막을 꿰뚫고 Onion은 파리 방패로 일부 반사. 적 체력은 낮지만 탄막 밀도로 위협. 구현: `DanmakuEnemy` — `Danmaku_Pattern_System.md` 기반 패턴 데이터 ScriptableObject.

- **엘리트 버전 일반 적 (Hades 엘리트방)** — Hades 참고: 특정 방에서 같은 적이 체력 1.5배 + 추가 특수 공격을 가진 엘리트 버전으로 등장. 처치 시 Legendary 업그레이드 1개 보장. 구현: `EnemySpawner`에 `EliteModifier` 컴포넌트 → HP/Speed 배율 + 보상 풀 변경.

- **방패 방향 적 + Gungeon 테이블 차폐물 조합** — Gungeon 테이블 차폐물 + 방패 적 조합: 적이 주기적으로 차폐물 뒤에 숨으며 안전하게 탄막 발사. Cat이 뒤로 돌아가야 하고 Onion은 궤적을 계산해 각도 공격. 구현: `CoverSeekingEnemy` — `NavMesh2D`로 가장 가까운 차폐물 오브젝트 탐색 후 이동.

## 맵 (03_Maps)

- **Gungeon 보물방 키 시스템** — Enter the Gungeon 참고: 런 내에서 "열쇠(Key)"를 획득해야만 보물방 입장 가능. 열쇠는 적 처치 드롭 또는 상점 구매. 열쇠를 쓸지 아끼며 상점 갈지 선택. 구현: `RunInventory.Keys` int, 보물방 입장 시 `Keys > 0` 조건 확인.

- **Hades 방 유형 분류 + 코스트 선택** — Hades 코스트 선택 방 참고: 방 진입 전 아이콘으로 방 유형 표시(전투/보물/상점/휴식). 일부 방은 현재 HP를 소모해야 입장 가능하지만 보상이 큼. 구현: `FloorGenerator`에서 방 배치 후 UI에 `RoomType` 아이콘 표시, 코스트 방은 `HPCostGate` 컴포넌트.

- **비밀 방 (Gungeon 스타일)** — Enter the Gungeon 참고: 폭발물 아이템(또는 Cat의 강화 대시)으로 특정 벽을 파괴하면 숨겨진 비밀 방 등장. 비밀 방에는 Legendary 아이템 또는 스토리 단편. 구현: `BreakableWall` — `OnAttackHit(DamageType.Explosion)` 시 비활성화, 뒤의 방 오브젝트 활성화.

## 전투 (04_Combat)

- **오브젝트 풀링 기반 탄막 연사 패턴** — Object Pooling + Danmaku 참고: Onion이 아이템으로 "3연사 모드" 획득 시, 풀링된 투사체 3발을 0.05초 간격으로 빠르게 발사. GC 스파이크 없이 빠른 연사 구현. 구현: `PoolManager.Spawn("onion_triple")` × 3, `StartCoroutine(BurstFire(3, 0.05f))`.

- **Blank(전체 탄막 제거) 협동 기술** — Enter the Gungeon Blank 참고: Cat 대시 + Onion 방패를 동시에 사용하면 화면 내 모든 투사체 소멸 + 근처 적 0.5초 스턴. 공유 쿨다운 20초. 구현: `CoopBlankAbility` — 양쪽 입력 0.2초 내 동시 감지 시 발동, `PoolManager`에서 활성 투사체 일괄 Despawn.

- **히트스톱 + 풀링 피격 이펙트 조합** — Hades 타격감 + Object Pooling: 근접 타격 성공 시 0.06초 히트스톱 + 풀링된 히트 파티클 Spawn + 카메라 진동. 타격감 3종 세트를 한 번에 처리. 구현: `HitEffectCombo.cs` — `Feedback_System.md` 연동, `PoolManager.Spawn("hit_melee")`.

## 스토리 (05_Story)

- **죽음 대화 런 카운터 기반** — Hades 참고: 런 종료(사망 또는 클리어) 시 Cat과 Onion이 번갈아 대사. 첫 10번은 어색함, 10~30번은 신뢰 구축, 30번 이상은 파트너십 확립 대사 풀로 전환. 구현: `RunEndDialogue` ScriptableObject 배열, `runCount` 범위별 랜덤 선택.

- **Gungeon 과거 챕터 → 보스 클리어 시 비화 해금** — Enter the Gungeon 과거 클리어 참고: 특정 보스를 처음 클리어하면 Cat과 Onion이 왜 함께 싸우는지에 대한 짧은 배경 이야기 팝업. 보스마다 서로 다른 에피소드. 구현: `BossDefeatedFlag` ScriptableObject, 첫 처치 시 `StoryPopup.Show(bossId)`.

- **자동 저장 시 스토리 진행도 보존** — App Lifecycle 참고: 런 재개 팝업에서 "지난번 런에서 새 대사를 발견했어요!" 식으로 저장된 스토리 단편 수를 표시. 저장 파일에 해금된 대사 인덱스 포함. 구현: `RunState.unlockedDialogueIds = List<string>`, 자동 저장 시 포함.

## 기술 메모

- **오브젝트 풀링**: `UnityEngine.Pool.ObjectPool<T>` (Unity 2021+)로 `PoolManager` 싱글턴 구성. 투사체·히트 이펙트·드롭 아이템 세 카테고리 풀 분리 권장. 핵심은 `Get()` 시 상태 완전 초기화, `Release()` 전 코루틴/이벤트 정리. `[DefaultExecutionOrder(-100)]`으로 Awake 우선순위 보장.
- **앱 라이프사이클 & 자동 저장**: 방 클리어마다 `AutoSaveManager.MarkDirty()` 호출 → 60초 인터벌 또는 `OnApplicationPause`/`OnApplicationQuit` 시 즉시 저장. `AppStateTracker.SetDirtyFlag()`를 런 시작 시 켜고 런 종료 시 꺼서 비정상 종료 감지. 재실행 시 `WasAbnormallyTerminated()` true면 "이어하기" 팝업 표시. 저장 파일은 임시 파일(.tmp) 경유 원자적 쓰기로 손상 방지.
