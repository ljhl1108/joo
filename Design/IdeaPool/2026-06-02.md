## 캐릭터 (01_Characters)

- **패리 시너지 버프** — Dead Cells 패리 참고: Onion(P2)이 방패 패리 성공 시 Cat(P1)의 다음 근접 공격 데미지 1.5× 증폭. 화면에 짧은 금빛 플래시로 시각 피드백. 두 플레이어가 타이밍 맞출 때 발생하는 협동의 짜릿함 구현
- **씨앗(Seed) 메타 통화** — Vampire Survivors 골드 시스템 참고: 런 실패해도 적 처치 수에 비례해 씨앗 획득. 메뉴에서 씨앗으로 Cat/Onion 기본 스탯(HP, 이동속도, 투사체 속도) 소폭 영구 업그레이드. 실패 런도 성취감 부여
- **협동 진화 기술** — Vampire Survivors 무기 진화 참고: Cat 근접 능력 + Onion 원거리 능력 MAX 조합 시 "합체기" 해금. 예: [갈퀴 슬래시 LV3] + [관통 투사체 LV3] → [회오리 사이클론] 발동. 15초 쿨다운

## 적 (02_Enemies)

- **방패 근위병 (ShieldGuard)** — Dead Cells 방패 적 참고: 정면 근접 공격 완전 무효. Cat이 측면/후면으로 이동해야 데미지. 원거리 완전 무효(원거리 약점 없음) → Onion이 먼저 스턴 후 Cat이 뒤를 공격하는 협동 패턴 강제. 상태머신: Idle → Chase → BlockStance → Attack
- **포탑 (TurretPlant)** — 원거리 약점 전용 고정 적: Idle에서 감지 범위 진입 시 즉시 3방향 투사체 발사, Chase 없음. 근접 공격 면역(딱딱한 껍질). Onion의 집중 사격으로만 처치. 원거리 플레이어의 역할 부각
- **분열 슬라임 (SplitSlime)** — Vampire Survivors 대군 참고: 처치 시 소형 2마리로 분열. 소형은 근접만 유효. 소형이 너무 많아지면 화면이 혼잡해지므로 Cat의 광역 슬래시로 정리 → 역할 분담 명확화. 분열 최대 1회

## 맵 (03_Maps)

- **청크 기반 방 생성** — Dead Cells 절차적 생성 참고: 미리 제작한 Room Prefab 10~15종을 런 시작 시 무작위 배치. 시작·보스·상점 방은 고정, 나머지 랜덤. 모든 방 내부엔 최소 하나의 근접형·원거리형 적 혼합 배치 규칙
- **비밀 방 조건** — Vampire Survivors 비밀 발견 참고: 특정 적(예: 처음 보는 희귀 적) 최초 처치 시 런 내 한 번만 등장하는 비밀 방 문 해금. 비밀 방 안에 강력한 능력 카드 1장. 발견 시 화면 이펙트 + 메시지
- **파워 판타지 방** — Vampire Survivors 후반 압도감 참고: 던전 후반부(3층+)에 "대군 방" 배치. 이 방은 약한 적 15~20마리가 한꺼번에 등장. 클리어 시 특수 능력 카드. "우리가 강해졌다"는 성장 곡선 체감 포인트

## 전투 (04_Combat)

- **히트스톱 구현** — Dead Cells 타격감 참고: Cat 근접 공격이 적에 명중 시 0.06초 Time.timeScale = 0.05로 감소 후 복구. Onion 원거리 헤드샷(크리티컬) 시 동일 효과. `HitStopManager.cs`에 코루틴으로 구현
- **약점 면역 이펙트** — Dead Cells 방패 시스템 참고: 약점 아닌 공격이 적에 닿을 때 "IMMUNE" 텍스트 + 쨍 소리 + 노란 파티클. 플레이어가 자연스럽게 "이 적은 이걸로 못 죽이는구나" 학습
- **패리 판정창** — Dead Cells Timed Parry 참고: Onion 방패 올린 상태에서 적 공격 0.15초 이내에 맞으면 패리 성공. 성공 시 적 스턴 1.5초 + Cat에 버프 알림 UI. 창이 너무 엄격하면 초보자 좌절 → 0.2초로 넉넉하게 시작

## 스토리 (05_Story)

- **소개 씬 — 달밤의 사고** — 고양이(Cat)가 텃밭을 달리다 발을 헛디뎌 양파 화분(Onion)과 엉켜 하나의 몸이 됨. 짧은 픽셀아트 컷씬 3~4프레임으로 표현. 메인 메뉴 → 게임 시작 버튼 → 이 컷씬 → 첫 방 시작 흐름
- **Vampire Survivors식 비밀 서사** — 적 도감(Bestiary) 추가: 특정 적 10회 처치 시 적의 배경 이야기 1줄 해금. 세계관 파편화 전달. 플레이어가 모으고 싶어 하도록 설계
- **런 실패 대사** — 게임 오버 시 Cat/Onion 번갈아 위로 대사. Dead Cells "다시 살아났다" 분위기처럼 "또 해보자" 낙관적 톤. 예: Onion: "…물이나 줘." Cat: "알았어, 꼭 클리어하자."

## 기술 메모

- **적 AI 상태머신**: `EnemyBase.cs`를 추상 기반으로 `MeleeEnemy`, `RangedEnemy`, `BossEnemy` 상속 구조 확정. **Awake()에서 Player 태그로 참조 캐싱** — Update 내 Find 절대 금지. 약점 타입(`WeaknessType` enum)을 EnemyBase에 `[SerializeField]`로 선언해 Inspector에서 근접/원거리 설정.

- **메인 메뉴 씬**: Build Settings에서 MainMenu를 인덱스 0으로 등록하는 것이 첫 번째 필수 단계. `CanvasGroup`을 FadePanel에 달고 `blocksRaycasts = true`로 설정해야 페이드 중 버튼 중복 클릭 방지. `Application.Quit()`은 에디터에서 동작 안 하므로 `#if UNITY_EDITOR` 분기 반드시 추가.
