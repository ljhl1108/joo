## 캐릭터 (01_Characters)

- **체인 관성 Secondary Motion** — Chained Together 참고: Cat이 대시 후 급정지 시 Onion 화분이 관성으로 앞으로 기울었다 원위치. 정지 직후 0.1초 흔들림. 구현 힌트: `Secondary_Motion_System.md` 참고, Onion 스프라이트 부모 오브젝트에 SimpleSpring 컴포넌트 적용.

- **스탠스별 Idle 포즈** — SoR4 캐릭터 개성 참고: Cat Idle 시 마지막 이동 방향에 따라 다른 포즈. 왼쪽 Idle: 할퀴기 준비 자세, 오른쪽 Idle: 앞발 올리기. Onion Idle: 마지막 조준 방향 총구 고정. 구현 힌트: Idle Blend Tree에 방향 파라미터 추가, 4방향 각각 별도 Idle 클립.

- **체인 장력 업그레이드** — Chained Together 응용: 특정 업그레이드 획득 시 Cat 대시가 "체인 당기기"로 강화 — 대시 중 Onion 조준 방향이 대시 방향으로 0.2초 고정. 기동 중에도 정확한 Onion 조준 가능. 구현 힌트: `DashSystem`에서 대시 시작 시 `OnionAimController.LockDirection(dashDir, 0.2f)` 호출.

## 적 (02_Enemies)

- **갑옷 기사 — 방향 약점 협력 퍼즐**: 정면은 Cat 슬래시 튕김(무적), 등은 2배 데미지. Onion이 정면에서 투사체로 기사의 방향 전환 방해 → Cat이 뒤로 돌아가 슬래시. 협력 없이는 사실상 처치 불가. 구현 힌트: `DirectionalWeakPoint` 컴포넌트, `backstabMultiplier = 2.0f`, 정면 콜라이더에 `isImmune = true`.

- **체인 골렘 쌍 — Chained Together 참고**: 두 마리가 체인으로 연결되어 동시에 등장. 한 마리 공격 시 다른 한 마리도 반응. Cat이 한 마리, Onion이 다른 마리를 **동시에** 타격하면 체인 절단 + 둘 다 스턴. 구현 힌트: `ChainedEnemyPair` 스크립트, 양측 HP가 동시에 0이 되면 특수 처치 이벤트.

- **도감 등록 미니보스** — Unlock Notification 활용: 처음 조우하는 미니보스를 처치하면 즉시 "적 도감 등록" 팝업 표시. 팝업에 해당 보스 약점 힌트 포함: "이 적은 등 공격에 취약합니다." 첫 조우 시 교육적 역할 수행. 구현 힌트: `BossEnemy.OnDeath()`에서 `UnlockManager.Instance.Unlock(bossUnlockData)` 호출.

## 맵 (03_Maps)

- **비밀 방 해금 알림** — Unlock Notification 응용: 숨겨진 벽을 Cat 슬래시로 파괴 시 비밀 방 발견 팝업 + 서사 텍스트. 이미 발견한 비밀 방은 미니맵에 특수 아이콘 표시. 구현 힌트: `HiddenWall` 컴포넌트, 파괴 시 `UnlockManager.Unlock(secretRoomData)` 호출.

- **체인 장벽 방** — Chained Together 참고: 체인 골렘 두 마리가 방 중앙을 가로막는 특수 방. 체인이 Cat/Onion 이동 경로를 방해하는 장애물 역할도 겸함. Cat이 체인 아래 대시로 통과하는 동안 Onion은 위에서 조준. 구현 힌트: `ChainBarrier` 오브젝트, 두 골렘 `Transform` 위치를 잇는 `LineRenderer`.

- **SoR4 수평 스크롤 도주 방**: 특수 방 유형으로 왼쪽→오른쪽 수평 진행. 카메라가 오른쪽으로 이동하며 새 적 등장. 방 끝에서 탈출 성공 시 보상. 구현 힌트: `CameraRail` 컴포넌트, 적 처치 수에 따라 카메라 이동 허용.

## 전투 (04_Combat)

- **SoR4 주황 HP → Cat 대시 패널티**: Cat 무적 대시 사용 시 최대 HP의 5%가 임시 상태(주황) 전환. 이후 슬래시 공격 성공 시 임시 HP 회복. 대시만 계속 쓰는 소극적 플레이 자연스럽게 억제. 구현 힌트: `PlayerHealth`에 `temporaryHP float` 필드, 대시 시 `currentHP * 0.05f` 전환.

- **방향 약점 × Onion 협력 조합**: Cat이 적 측면에 붙으면 적이 Cat을 바라봄 → 적의 등이 Onion 쪽으로 노출. 등 노출 시 적 등에 빨간 약점 인디케이터 아이콘 표시 → Onion 조준 힌트. 구현 힌트: `WeakPointIndicator` 컴포넌트, Cat 위치 추적해서 등 방향 노출 시 아이콘 활성화.

- **블리츠 슬래시 — SoR4 응용**: Cat 대시 중 슬래시 입력 시 "돌진 슬래시" 발동 — 히트박스가 대시 방향으로 2배 연장, 적 2명 관통. 기본 슬래시보다 쿨타임 1.5배. 구현 힌트: `CatAttack.cs`에서 `isDashing` bool 체크 후 `SlashVariant.Blitz` 분기.

## 스토리 (05_Story)

- **해금 알림 = 서사 발견**: 비밀 방 해금 팝업에 짧은 플레이버 텍스트 추가: "냥이가 오래된 탑의 균열을 발견했다. 새싹이 냄새를 맡는다." 기계적 해금이 스토리 단서가 되는 구조. 구현 힌트: `UnlockData` ScriptableObject에 `loreText` 필드 추가, 팝업 하단에 표시.

- **SoR4 캐릭터 관계 오마주**: SoR4의 캐릭터들이 서로를 돕는 협동처럼, Cat과 Onion의 협동 통계를 런 결과 화면에 표시. "이번 런: Cat이 43번 슬래시, Onion이 17발 발사, 함께 12.3미터를 전진했다." 구현 힌트: `RunDataManager`에 `catSlashCount`, `onionShotCount`, `progressDistance` 추적.

- **체인 연결 = 신뢰 서사**: Chained Together의 "연결된 존재" 철학 반영. Cat이 치명타를 맞을 위기에서 Onion의 파리(Parry) 버퍼가 있으면 자동 발동 + 짧은 이벤트 텍스트: "작은 새싹이 큰 고양이를 지켰다." 구현 힌트: `damage > cat.HP` 조건에서 Onion 파리 버퍼 확인, 있으면 자동 발동.

## 기술 메모

- **Enemy Directional Weak Point**: `Vector2.Dot(enemy.right, toAttacker)` 하나로 등(-1)/측면(0)/정면(+1) 구분 가능. OnionCat은 적 유형마다 ScriptableObject로 약점 규칙 정의 — 디자이너가 코드 수정 없이 약점 조정 가능. 협력 퍼즐 적 설계의 핵심 도구. 갑옷 기사처럼 "정면 무적 + 등 약점" 조합이 협력을 자연스럽게 강제한다.

- **Content Unlock Notification**: `Queue<UnlockData>`로 동시 해금 발생 시 순차 표시. `Time.unscaledDeltaTime` 필수 — 일시정지 중 팝업이 사라지는 버그 방지. OnionCat 구현 시 최우선 해금 이벤트: 새 적 첫 처치 → 도감 등록 팝업 + 약점 힌트 표시. 첫 조우 교육적 효과 탁월.
