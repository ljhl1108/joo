## 캐릭터 (01_Characters)

- **"협동 필살기 — 붙잡고 집중 사격"** — Tunche의 팀 특수기(짐살라빔) 참고: Cat이 적을 그랩으로 붙잡는 동안 Crop이 연속 투사체를 집중 발사. 두 버튼을 동시에 누르면 발동. `CoopSkillManager`에서 양쪽 입력 타이밍 체크로 구현. 강력하지만 Cat이 이동 불가라는 리스크 존재.
- **"공격 색상 분리"** — Tunche의 캐릭터 색상 정체성 참고: Cat의 슬래시 이펙트는 주황/빨강 계열, Crop의 투사체·실드는 초록/노랑 계열로 고정. 화면이 혼잡할 때도 어느 공격이 누구 것인지 즉시 구분 가능 → VFX 파티클 컬러만 변경하면 됨.
- **"단독 콤보 보너스"** — Tunche의 콤보 미터 참고: Cat이 기절시킨 적을 Crop이 3초 안에 처치하면 "협력 처치" 카운트 증가, 특정 업그레이드 활성화 조건으로 활용. `KillTracker`에서 마지막 공격자와 기절 여부 추적.

## 적 (02_Enemies)

- **"LOS 차단 의존 적 — 매복 스나이퍼"** — Raycast LOS 시스템 참고: 벽 뒤에 숨어있다가 플레이어가 시야에 들어오는 순간 단 한 발의 강력한 저격을 날리는 원거리 적. LOS가 0.5초 이상 유지될 때만 발사 → 플레이어가 빠르게 이동하거나 벽 뒤로 숨으면 회피 가능.
- **"벽 뒤 감지 불가 몬스터"** — LOS 시스템 활용: LOS 체크를 통과해야만 어그로가 걸리는 기본 적들. 플레이어가 기둥 뒤에 숨으면 적이 마지막 위치로 이동 후 Idle로 복귀 → "숨기" 전술의 실용성을 높임. 모든 적에게 기본 적용 권장.
- **"스텔스 어사신"** — LOS + 청크 생성 참고 (Shovel Knight: Dig의 트랩 방): 천장/바닥에 붙어 있다가 플레이어가 LOS 안에 2초 이상 있으면 고속 돌진. 선제 공격 시 Cat만 감지(근접 담당), 원거리는 감지 못함 → 근접/원거리 역할 분담을 자연스럽게 강요.

## 맵 (03_Maps)

- **"청크(Chunk) 기반 방 생성"** — Shovel Knight: Dig 참고: 방을 6×6 타일 청크로 분할하고, 각 청크에 "입구 방향" 비트마스크를 태그. 랜덤 배치 시 입구/출구가 이어지는 청크만 선택 → 수작업 품질 + 절차적 신선함. `RoomChunk` ScriptableObject에 방향 플래그 저장.
- **"비밀 벽 — Cat 전용 파괴"** — Shovel Knight: Dig의 숨겨진 방 + 협력 요소 결합: 방 벽 중 일부를 Cat의 슬래시로만 부술 수 있는 "금이 간 벽" 타일로 설정. 숨겨진 방에는 추가 업그레이드 또는 골드 존재. Crop은 절대 못 부숨 → Cat 플레이어의 능동적 탐색 동기 부여.
- **"층별 색상 팔레트 고정"** — Shovel Knight: Dig의 월드별 팔레트 참고: 1층 = 초록/갈색(풀밭), 2층 = 회색/파랑(동굴), 3층 = 빨강/주황(화산). 각 층의 타일·배경·적 색상을 3~4색 팔레트로 제한 → 일관된 픽셀아트 비주얼. URP Pixel Perfect Camera와 함께 적용.

## 전투 (04_Combat)

- **"벽 뒤 안전 포지셔닝 전술"** — LOS 시스템이 활성화된 협력 전술: Cat이 적들의 시선을 끌며 어그로를 유지하는 동안, Crop은 벽 뒤에서 재장전·실드 충전. 원거리 적들이 Crop을 LOS 차단으로 무시 → 자연스러운 역할 분담이 발생.
- **"릴릭 시너지 — 2개 조합 특수 효과"** — Shovel Knight: Dig 참고: 업그레이드 두 개를 동시에 보유 시 추가 효과 발동. 예: "대시 거리 증가" + "대시 중 무적" = "폭발 대시"(착지 지점 폭발). `UpgradeSynergyTable` ScriptableObject로 2개 업그레이드 키 → 시너지 효과 매핑.
- **"처치 색상 피드백 분리"** — Tunche의 캐릭터 구분 + 협력 처치 표시: Cat이 최종 타격한 적은 주황 소멸 이펙트, Crop이 최종 타격하면 초록 이펙트. "협동 처치" 시 두 색상 혼합 폭발 이펙트. 시각적 기여도 분리로 두 플레이어 각자의 성취감 강화.

## 스토리 (05_Story)

- **"런 히스토리 속 서사 — 역대 영웅의 기록"** — Run History Viewer UI 참고: 히스토리 화면에서 각 런을 영웅의 이야기로 표현. "제7대 양파 고양이 — 2층 보스에서 전사함 (2분 14초, 15마리 처치)". 런 기록이 단순 숫자가 아닌 짧은 무용담으로 읽힘.
- **"처치 수에 따라 달라지는 사망 대사"** — 런 히스토리 데이터 활용: 처치 수 0~5마리면 "첫 걸음이었지만 용감했다", 20마리 이상이면 "전설의 용사에 가까웠다" 등 런 성과에 맞는 대사가 게임 오버 화면에 표시.
- **"페루·아마존 신화 영감"** — Tunche의 배경 참고: Tunche처럼 OnionCat도 특정 문화 신화를 배경으로 설정 가능. 예: 고양이를 신성시하는 이집트 신화 — 파라오 고양이 Cat, 나일강 신의 작물 Crop. 픽셀아트 이집트풍 배경과 조합하면 독특한 세계관 구축.

## 기술 메모

- **Raycast LOS System**: 가장 흔한 실수는 레이캐스트 발사 위치를 발 기준으로 설정하는 것. 반드시 눈 높이(`transform.position + Vector2.up * 0.5f`)에서 발사해야 기둥 뒤 플레이어를 정확히 감지. `checkInterval = 0.1f`로 프레임마다 체크하지 말고, 10Hz 타이머로 성능 절약. 먼저 거리 체크 후 Raycast 호출(싼 연산 → 비싼 연산 순서).
- **Run History Viewer UI**: `Application.persistentDataPath + "/run_history.json"` 경로에 JSON 저장. `Vertical Layout Group` + `Content Size Fitter`로 ScrollRect 내 동적 리스트 구현. 최대 50개 기록만 유지(오래된 것 삭제)해 파일 크기 제한. Cat/Crop 처치 수 분리 집계는 `KillTracker.cs`에서 런 중 카운팅, 런 종료 시 `RunRecord`에 저장.
