## 캐릭터 (01_Characters)
- **협력 시너지 특성** — 20 Minutes Till Dawn 시너지 참고: 런 시작 시 고양이/작물 각각 특성 카드 1개 선택, 두 특성이 조합되면 강화된 "협력 시너지" 발동 (예: 고양이 "회오리 슬래시" + 작물 "번개 탄환" → 타격 시마다 번개 연쇄 추가 발동)
- **런별 클래스 선택** — Tiny Rogues 클래스 시스템 참고: 런 시작 전 고양이는 "공격형/방어형/속도형" 중 선택, 작물은 "연사형/단발형/지원형" 중 선택 → 매 런 다른 역할 분담 조합 경험
- **20분 여명 캐릭터 변종** — 20 Minutes Till Dawn 타이머 참고: 던전 런에 시간 제한 설정 → 두 플레이어가 협력 콤보(근접 타격 직후 원거리 명중)를 유지해야 타이머가 늘어나는 "여명 생존" 모드 캐릭터 변형

## 적 (02_Enemies)
- **레이어 전용 내성 적** — 성능 최적화 레이어 매트릭스 참고: 물리 레이어로 "근접만 피격 가능 적(EnemyMelee Layer)"과 "원거리만 피격 가능 적(EnemyRanged Layer)"을 완전히 구분 → 협력 필수 상황을 시스템 수준에서 하드코딩
- **융합 보스** — Tiny Rogues 무기 융합 참고: 보스 2페이즈에서 두 개의 약한 소환수가 합체 → 근접+원거리 복합 내성을 가진 강화 형태로 변신. 두 플레이어가 동시에 공격해야 약점 노출
- **도어 예고 적** — Tiny Rogues 도어 선택 시스템 참고: 방 입장 전 문에 적 타입 아이콘 표시 (방패 = 근접만 피격, 번개 = 원거리만 피격, 해골 = 둘 다 필요). 두 플레이어가 전략 상의 후 입장

## 맵 (03_Maps)
- **10방 구조 채택** — Tiny Rogues 참고: 플로어당 방 8개 → 보스방 1개. 각 방 클리어 후 두 문 중 하나 선택(보상 타입 예고). 가시적인 진행도로 협력 자원 관리 논의("다음 방은 상점, 지금 회복 아껴야 해")
- **생존 타이머 룸** — 20 Minutes Till Dawn 참고: 특정 방은 "N초 생존"이 클리어 조건. 근접 전용 적과 원거리 전용 적이 동시에 쏟아져 자연스러운 역할 분담 강요
- **협력 합성 방** — Tiny Rogues 제단 참고: 플로어마다 1개 "합성 방" 등장. 두 플레이어 업그레이드 카드 각 1개를 소모해 협력 스킬 1개 생성 → 희귀 보상으로 협력 참여 동기 강화

## 전투 (04_Combat)
- **협력 콤보 게이지** — 20 Minutes Till Dawn 시너지 참고: 고양이 근접 공격 직후 1초 내 작물 원거리 명중 시 "콤보" 카운트 누적. 10콤보 달성 시 공동 궁극기(화면 전체 공격) 발동 → 두 플레이어가 타이밍 맞춰 공격하는 메커닉
- **투사체 전체 풀링** — 성능 최적화 참고: 작물 투사체, 적 투사체, 파티클 이펙트 모두 `ObjectPool<T>`로 관리. 동시 100발 환경에서도 GC 스파이크 없는 구조 → 불릿헬 요소 추가 시 선제 대비
- **무기 융합 합동 스킬** — Tiny Rogues 융합 참고: 합성 방에서 생성된 협력 스킬은 두 플레이어가 동시 입력 시 발동 → "고양이 슬래시 + 작물 탄막"이 합쳐진 반원형 연쇄 공격

## 스토리 (05_Story)
- **20분 여명 내러티브** — 20 Minutes Till Dawn 참고: 각 런은 "해가 뜨기 전 던전 탈출"이라는 명확한 시간 내러티브. 타이머가 단순 게임 기믹이 아닌 스토리의 긴박감으로 작동
- **작물의 성장 서사** — Tiny Rogues 메타 진행 참고: 메인 메뉴 화면에서 작물(양파)이 메타 진행도에 따라 시각적으로 성장 (씨앗 → 새싹 → 꽃 → 열매) → 런 횟수와 연결된 스토리 성장
- **런별 크레딧 다이어리** — 크레딧 화면 참고: 엔딩 크레딧에 "이번 런에서 획득한 업그레이드들"이 "함께한 동료들"로 나열 → 매 런마다 다른 크레딧 → 반복 플레이 유도 + 서사 개성

## 기술 메모
- **성능 최적화**: `ObjectPool<T>` (UnityEngine.Pool 네임스페이스)는 작물 투사체에 즉시 적용 가능. 레이어 충돌 매트릭스에서 `EnemyBullet ↔ Enemy` OFF, `PlayerBullet ↔ Player` OFF만으로도 적 밀집 상황에서 체감 성능 개선 기대. 스프라이트 아틀라스 4개(Player/Enemy/UI/Environment)로 드로우콜 목표 30 이하.
- **크레딧 화면**: 방법 1(CreditsContainer RectTransform Y축 애니메이션)이 코딩 최소화로 30분 내 완성 가능. New Input System 사용 중이므로 ESC 스킵은 `Keyboard.current.escapeKey.wasPressedThisFrame` 사용. 메인 메뉴 버튼 + 엔딩 클리어 후 자동 전환 두 경로 모두 연결.
