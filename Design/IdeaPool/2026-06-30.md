## 캐릭터 (01_Characters)

- **Just-Reload 연사 시스템** — Synthetik 참고: Crop(양파)의 투사체 발사 후 쿨타임 바가 나타나고, 정확한 타이밍에 재발사 버튼을 누르면 쿨타임 30% 단축. "기술적으로 잘 플레이하면 더 빠르다"는 느낌 구현. Unity에선 슬라이더 UI로 타이밍 바 표현, Coroutine으로 판정 윈도우 처리.

- **대시 - 공격 연결 콤보** — Rogue Prince of Persia 참고: Cat(고양이)의 무적 대시 종료 직후 0.15초 내 공격 입력 시 슬래시 판정 범위 15% 확대 + 경직 시간 연장. 이동과 전투를 연결하는 스킬 천장(skill ceiling) 형성. New Input System의 Interaction → Hold/Tap으로 구현.

- **공용 부활 코인** — Rogue Prince of Persia 시간 역행 메카닉 참고: 상점에서 "부활 동전" 구매 가능. 둘 중 하나가 죽었을 때 자동 발동, 상대방 HP 절반 차감하며 소생. "나 살리려고 네 HP 깎였잖아" → 희생 감각 강화.

## 적 (02_Enemies)

- **탄피 흩어지는 적 (Gunner-Type)** — Synthetik 참고: 원거리 사격 적이 사망 시 탄피 파티클 흩뿌림 이펙트. 게임 느낌(game feel) 강화에 비용 낮음. Unity ParticleSystem에 탄피 스프라이트 시트 + 중력 적용으로 구현.

- **벽달리기 추격 적 (Parkour Ghost)** — Rogue Prince of Persia 이동 참고: 일반 지형을 따라 달리는 기본 적이 아닌, 벽과 플랫폼을 타고 플레이어를 우회하는 적. 사거리가 짧고 빠름. Cat 전용 약점(근접만 데미지). OnionCat 방 타일맵에서 특정 레이어 태그를 벽 등반 허용으로 설정.

- **상점 방 지키는 상인 경비원 (Shop Guard)** — 상점 시스템 연동 아이디어: 상점 방 입장 전 작은 전투방에 강화된 경비 적 1명 등장. 처치하면 상점 입장 + 골드 보너스 드롭. 상점 방을 단순 휴식 공간이 아닌 선택지로 만드는 방법.

## 맵 (03_Maps)

- **상점 방 시각 디자인** — 상점 시스템 참고: 전투방과 구분되는 따뜻한 조명(노란-주황 팔레트), 행상 카트, 천막 장식 타일. GameState.ShopOpen 진입 시 배경 음악 자동 전환 (전투 BGM → 상점 BGM). Unity AudioMixer의 Snapshot 전환으로 구현.

- **골드 드롭 밀도 조절** — 상점 시스템 경제 설계 참고: 초반 방(1~3번)은 골드 드롭 낮게 → 상점 직전 방(4번)에서 미니 보스 처치 시 골드 폭발 드롭. 긴장-해소 리듬 형성. EnemyDropTable ScriptableObject의 roomIndex 파라미터로 가중치 조절.

- **런 상태 지속성** — Game State Manager 참고: InRun → 방 전환 → InRun 상태 유지. DontDestroyOnLoad GameManager가 런 진행도(현재 층, 방 번호, 골드)를 보관. 씬 재로드 없이 방만 교체하는 Single Scene 방식이 상태 관리에 유리.

## 전투 (04_Combat)

- **총기 피드백 삼위일체 즉시 적용** — Synthetik 참고: Crop 투사체 발사에 ① 발사 사운드 + ② 총구 파티클(Muzzle Flash 2~3프레임) + ③ CinemachineImpulse 0.05초 미세 흔들림을 세트로 적용. 비용 낮고 타격감 체감이 즉각적임.

- **파리 & 상점 연계 시스템** — Parry_Shield_System + Shop_System 참고: Crop의 방패 패리 성공 시 적이 드롭하는 골드 +50% 보너스. "패리 잘 쓰면 상점에서 더 살 수 있다" → 방어 메카닉에 경제적 인센티브 부여.

- **GameState.UpgradeSelect 활용** — Game State Manager 참고: 방 클리어 시 GameState를 UpgradeSelect로 변경 → Time.timeScale = 0 + 업그레이드 UI 표시. 선택 완료 시 InRun 복귀. 이 상태에서는 플레이어 입력 차단 (PlayerInputHandler가 UpgradeSelect 상태 감지).

## 스토리 (05_Story)

- **상인 NPC 대사 시스템** — 상점 시스템 + Rogue Prince of Persia 분위기 참고: 상점 방 상인이 방문할 때마다 랜덤 대사 1줄 출력. 예: "오늘도 살아남았군요... 잠깐, 혹시 고양이가 화분을 들고 있어요?" → 세계관 자연스럽게 전달. DialogueEventSystem에 ShopDialogue 리스트 추가.

- **런 횟수 카운트 대사** — Game State Manager + Meta 시스템 참고: GameManager가 총 런 횟수 기록 → 10회 달성 시 상인 대사 변경 "이번이 열 번째군요, 이쯤 되면 단골이네요." 소소한 보상감. PlayerPrefs에 `totalRunCount` 정수로 저장.

- **게임오버 화면 짧은 서사** — GameState.GameOver 참고: 게임오버 화면에 짧은 플레이버 텍스트 표시. 예: "양파가 세상 빛을 못 봤다...", "화분이 산산조각났다..." 런마다 랜덤으로 하나 선택. 로그라이크 특유의 허무한 유머 연출.

## 기술 메모

- **Game State Manager**: `GameManager.Instance.ChangeState(GameState.Paused)` 한 줄로 `Time.timeScale = 0` + 입력 차단 + 일시정지 UI 표시가 동시에 처리됨. 상태 의존 시스템들이 `OnStateChanged` 이벤트만 구독하면 되므로 GameManager를 직접 참조하는 코드가 줄어든다. **첫 구현 순서**: GameState enum 정의 → GameManager 싱글톤 → PauseMenuUI 구독 → PlayerInputHandler 구독 순으로 점진적 추가.

- **상점 시스템**: 공용 골드 풀(두 플레이어 합산)로 운영하면 "함께 돈 모아서 뭐 살까" 협력 대화가 자연스럽게 생긴다. 구현 우선순위: `RunCurrencyManager` → `ShopItemSO` 3개 제작 → `ShopManager.TryPurchase()` → UI 슬롯. ScriptableObject 아이템은 드래그앤드롭으로 상점 아이템 풀에 추가하면 되므로 데이터 관리가 편하다.
