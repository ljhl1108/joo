## 캐릭터 (01_Characters)

- **야성 게이지 발동 연출 강화** — TMNT 수퍼 어택 참고: 현재 특수 발동 시 히트스톱이 없음. `HitFeelSettings.asset`에 `specialActivateHitstop: 0.15f` + 카메라 FOV +5 → 0.1초 추가하면 발동 체감이 크게 달라짐. `CatSpecial.cs` 발동 코루틴 첫 줄에 `HitFeelManager.TriggerSpecialActivate()` 한 줄 추가로 완성
- **할퀴기 변형 선택 이정표** — SPD 서브클래스 선택에서 착안: 현재 `ClawStyle`은 장비에서 자동 변경됨. "1스테이지 보스 클리어 → 현재 무기 잠금 해제 + 변형 스킬 선택 팝업" 이벤트를 추가하면 런에 명확한 방향성 이정표가 생김. `UpgradeSelectUI` 재사용 가능 (카드 1장을 ClawStyle 카드로 대체)

## 적 (02_Enemies)

- **보스 2차 형태 전환 연출** — TMNT가 보스 상체만 두고 하반신이 변하는 연출처럼: 성녀 궁수 66% 페이즈 전환 시 현재 패턴만 바뀌는데, **0.5초 무적 + 화면 전체 플래시 + BGM 필터 변경**으로 "페이즈 전환됐다"는 신호를 강화. `EnemyBase.OnPhaseTransition()` 훅에 연결하면 다른 보스에도 공통 적용
- **저주받은 장판 적** — SPD 저주 기믹에서 착안: 새로운 적 `CursedSlime` — 죽을 때 반경 3칸에 음수 효과 장판을 남김 (예: 5초간 씨앗 발사 불가). `EnemyHazard` 확장, `EnemyBuilder.cs` 표에 한 줄 추가. 현재 장판은 고양이에게 피해만 주는데, 이런 기능성 디버프 장판이 있으면 양파 플레이어가 위치를 적극 고려하게 됨

## 맵·런 구조 (03_Maps)

- **보스 러시 모드 MVP 구현** — 보스 러시 완성 기능 파일 기준 최소 구현: `BossRushConfig` ScriptableObject + `BossRushManager` 스크립트 2개, `GameManager.StartNewRun(bossRushMode: true)` 분기, 메인 메뉴 버튼 1개(MetaProgress 1퀘스트 클리어 후 해금). 예상 반나절. 숙련 플레이어가 "장비 조합 연습" 용도로 곧바로 쓸 수 있음
- **스테이지 환경 기믹 추가** — SPD 구역별 환경 차별화에서 착안: 탑(마지막 스테이지)에 **중력 장판**(특정 구역에서 대쉬 거리 절반) 또는 늪에 **젖음 바닥**(방 진입 시 자동 젖음 상태이상 = 화상 꺼짐·감전 2배). `Room.OnPlayerEnter()`에서 `EnemyBase.Status.ApplyWet()` 일괄 적용. 임시 색 오버레이와 별개로 플레이 방식 자체를 바꾸는 첫 번째 환경 기믹이 됨

## 전투·협동 (04_Combat)

- **날아가는 중 씨앗 명중 = BOUNCE SHOT** — TMNT 투척 협동 응용: 고양이 걷어차기로 날아가는 적이 양파 씨앗에 맞으면 **추가 피해 × 1.5 + "BOUNCE SHOT!" 텍스트 + 협동 게이지 +10**. 현재 걷어차기-CRASH, 걷어차기-낙사에 이어 세 번째 킥 콤보 유형. `Projectile_Seed` OnTriggerEnter2D에서 피격 적의 `isLaunching` 플래그 확인으로 구현 가능
- **야성 게이지 × 합동기 교차 보상** — 야성 게이지 가득 상태에서 합동기 발동 시 "BEAST STORM" 강화: ONION STORM 범위 1.5배 + 야성 게이지 50% 유지. 현재 두 게이지가 완전히 독립적인데, 이 교차 보상이 있으면 "먼저 야성 채우고 합동기 써야지"라는 메타 전략이 생김

## 아이템·세트 (05_Items)

- **저주받은 장비 (Cursed Gear)** — SPD 저주 시스템에서 착안: 강한 효과지만 단점이 있는 보라·주황 등급 장비. 예: "공격력 +40%, 하지만 방 클리어 후 씨앗 0개 획득". `GearItem`에 `isCursed` 플래그 + `GearEffect`에 저주 발동 조건 추가. 게임 후반 베테랑이 의도적으로 선택하는 고위험-고수익 옵션
- **세트 × 야성 게이지 연동** — Wind 세트 2단계: "야성 게이지 충전량 +25%" / Sun 세트 4단계: "특수 발동 시 HP 15 회복". `ContentBuilder.cs` 세트 보너스 표에 `StatType.WildGaugeChargeRate` / `StatType.WildSpecialHeal` 2개 추가. 장비 선택이 야성 게이지 활용 전략에 영향을 미치도록 연결하는 가장 빠른 방법

## 스토리·메타 (07_StoryMeta)

- **보스 러시 스피드런 기록 저장** — 보스 러시 클리어 시 보스별 시간 + 총 시간을 `meta.json`에 저장 (`BossRushBestTimes`). 런 결과 화면에 "최고 기록" 비교 표시. 타이머 UI는 `InGame_Timer_System.md` 참고. 별도 리더보드 없이도 자체 기록 갱신 의욕을 제공
- **아이템 도감 (Bestiary + Gear Encyclopedia)** — SPD의 아이템 식별 시스템에서 착안: OnionCat은 획득한 장비를 런 결과 화면 "획득 목록"에만 표시하는데, **게임 전체에서 한 번이라도 획득한 장비가 메뉴에 도감으로 쌓임**. 처음 보는 장비는 이름만, 획득 이후엔 효과 전체 공개. `MetaProgress`에 `discoveredGear HashSet<string>` 추가. 163종 장비를 모으는 수집 의욕 제공

## 기술 메모

- **야성 게이지 즉시 개선 순서**: ① 발동 히트스톱 0.15초 추가 → ② 게이지 가득 찼을 때 깜빡임 애니메이션 → ③ 방 클리어 시 50% 감쇠 테스트 → ④ `SfxId.WildGaugeFull` / `WildGaugeActivate` 효과음 추가. 각 항목이 독립적이라 하나씩 플레이 테스트하며 진행 가능
- **보스 러시 MVP 구현 순서**: `RunData.isBossRush` 플래그 추가 → `BossRushConfig` ScriptableObject 생성(보스 3개 설정) → `BossRushManager` 스크립트 → `GameManager.StartNewRun` 분기 → 메인 메뉴 버튼 → 플레이 테스트. `DungeonManager`를 꺼야 하니 `enabled = false`보다 내부 `if (RunData.isBossRush) return;` 분기가 충돌 적음
