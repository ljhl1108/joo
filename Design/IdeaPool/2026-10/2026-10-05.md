## 캐릭터 (01_Characters)

- **아키타입 확장 — 고양이 발톱 유파 × 양파 스킬 시너지 노드** — Remnant 2 듀얼 아키타입 참고: 고양이의 ClawStyle 유파(예: "공격적" 유파)가 양파 특정 OnionSkill(예: "화염 씨앗")과 조합되면 폭발 범위가 늘어나는 "시너지 노드" 추가. 구현 힌트: PassiveHost.Recalculate에서 (ClawStyle ∩ OnionSkill) 조합 체크
- **양파 파생형 — "검은 양파" 엘리트 코스튬** — Remnant 2 아키타입 시각 분기 참고: 런 중 특정 조건(협동 콤보 50회) 달성 시 양파가 일시적으로 외형 바뀌는 스킨 이벤트. 구현 힌트: Cosmetic_Skin_System + Runtime_Palette_Swap_System
- **플레이어 체력 회복 역할 분리** — Remnant 2에서 힐러 아키타입이 없으면 회복 어려운 점 참고: 양파가 특정 패시브 조합 시 "수확물 치유" 스킬 잠금 해제 (근처 아군 초당 0.5 회복). 구현 힌트: OnionSkill + 범위 내 PlayerHealth.Heal()

## 적 (02_Enemies)

- **속성 취약 적 — "철갑 달팽이"** — Remnant 2 속성 취약/내성 시스템 참고: 물리 피해에 면역이지만 화염 씨앗(양파 스킬)에만 등딱지가 녹아 약점 노출 → 고양이가 그 후 근접 마무리. 구현 힌트: Enemy_Weakness_Resistance_System + Attacker.Onion으로 약점 개방 플래그 설정
- **2페이즈 약점 역전 보스** — Remnant 2 보스 페이즈 설계 참고: 1페이즈는 고양이 근접만 유효, 2페이즈(체력 50% 미만)에서 방어막 생성 → 양파 원거리만 뚫을 수 있음. 역할이 역전되어 협동이 강제됨. 구현 힌트: Boss 페이즈 체력 임계값 + EnemyWeaknessSystem
- **엘리트 "분열 슬라임" 강화판** — 경제 설계의 "후반 엘리트 드롭" 참고: 7방 이후 등장하는 황금 슬라임은 처치 시 Epic 카드 1장 드롭 보장. 희귀도를 시각화(황금 테두리 스프라이트). 구현 힌트: Enemy_Elite_Variant_System + Loot_Rarity_Tier_System

## 맵 (03_Maps)

- **템플릿 방 + 랜덤 이벤트 방 구분** — Remnant 2 절차적 생성 참고: RoomLayout에 "이벤트 방" 타입 추가. 이 방에는 랜덤으로 "NPC 상인 등장 / 함정 도전 / 협동 퍼즐" 중 하나 배치. DungeonManager가 런 당 1~2회만 이벤트 방 삽입. 구현 힌트: RoomLayoutType 열거형 + 이벤트 풀 WeightedRoll
- **"함정 방" 골드 보상 도전** — 경제 설계의 위험 vs 보상 Sink 참고: 특수 방에 입장 시 "함정 있음, 클리어하면 카드 3장 중 1장" 알림. 고위험 고보상. 구현 힌트: RoomClearCondition 추가 + UpgradeSelectUI 트리거 조건 분기
- **보스 방 연출 강화** — Remnant 2 보스 입장 연출 참고: 보스 방 문을 열 때 카메라 패닝 + BGM 페이드 인 연출 (3~4초). 스트리밍 클립용 명장면. 구현 힌트: Boss_Entrance_Presentation_System + Shared_Body_Camera_Framing_System

## 전투 (04_Combat)

- **업그레이드 카드 등급별 후반 가중치 상승** — 경제 설계의 "방 번호별 가중치 보정" 참고: RewardTable.Roll에 roomIndex 파라미터 추가, 후반 방일수록 Epic 가중치 증가(2→20). 플레이어가 후반 갈수록 강해지는 느낌. 구현 힌트: Roguelike_Economy_Design.md의 GetTierBonus 코드 적용
- **피티 보장 시스템 도입** — 같은 축(Axis)에서 2회 연속 Common 카드 뽑으면 3번째는 Rare 이상 보장. badPickCount 변수를 RunData에 저장. 구현 힌트: VoteManager 패턴처럼 badPickCount를 RunData 필드로 추가
- **시청자 투표 업그레이드 선택 (스트리머 모드)** — Streaming Integration 참고: UpgradeSelectUI에 "스트리머 모드 ON 시 15초 타이머 + 채팅 !1 !2 !3 투표" 표시. 투표 수 실시간 표시. 구현 힌트: TwitchChatListener + VoteManager + UpgradeSelectUI 타이머 코루틴

## 스토리 (05_Story)

- **아키타입 기반 런 내러티브** — Remnant 2의 "매 런 다른 세계" 참고: 고양이와 양파가 선택한 스킬 조합에 따라 런 시작 시 1~2줄 내러티브 텍스트 변경. 예: ClawStyle="맹공" → "오늘은 발톱으로 이긴다.", OnionSkill="불꽃" → "양파의 화기가 타오른다." 구현 힌트: Dialogue_Event_System + RunData.clawStyle/onionSkill 조회
- **보스 처치 후 로그 기록** — 스트리밍 하이라이트 구간 강화 참고: 보스 사망 시 게임 내 일지에 한 줄 기록 ("Day X: 화염 철갑 달팽이를 쓰러뜨렸다"). Run_Result_Screen에 런 일지 탭 추가. 구현 힌트: RunData에 log List<string> 추가
- **"스트리머가 시청자와 함께 클리어" 연출** — Streaming Integration 참고: 시청자 투표로 업그레이드를 선택해서 클리어한 경우 런 결과 화면에 "시청자와 함께 클리어!" 특별 문구 표시. 구현 힌트: RunData.streamerModeUsed bool + Run_Result_Screen 분기 텍스트

## 기술 메모

- **Roguelike Economy Design**: OnionCat의 카드 선택은 재화 없는 직접 선택 방식이라 전통 경제보다 단순하지만, **카드 등급 가중치 + 방 번호별 보정 + 피티 시스템** 3가지가 핵심. RewardTable에 roomIndex 파라미터와 badPickCount(RunData 저장) 추가하는 것이 가장 즉각적인 적용 가능 구현.

- **Streaming Integration**: 가장 먼저 해야 할 것은 **코드 없는 스트리머 친화 설계** — 런 결과 화면 충분히 긴 체류 시간, CC0 음악 유지, 보스 처치 연출 강화. Twitch IRC 투표는 Settings_Menu에 "스트리머 모드" 토글 추가 후 v1.1 이후에 구현 가능. NativeWebSocket 패키지 사용으로 Unity 6에서 async WebSocket이 가능하지만 WebGL 빌드에서는 별도 처리 필요.
