## 캐릭터 (01_Characters)

- **트레이드오프 전설 장비** — Undermine 저주 유물 참고: 현재 OnionCat 장비는 모두 순수 버프인데, 전설 장비 1~2종에 "단점 있는 강력 버프"를 달면 빌드 다양성이 폭발한다. 예: "할퀴기가 전방 3연타로 바뀜 + 대쉬 충전 1개 감소", "씨앗 탄 자동 추적 + 실드 재사용 대기 +1초". 전설 등급 공용 패시브 3개(아홉 목숨·그림자 분신·황금 양파) 외에 역할별 전설 1~2개 추가 시 이 원칙 적용 고려.
- **HP 비례 비주얼 피드백** — Post-Processing 참고: 공유 HP가 20% 이하로 떨어지면 화면 가장자리에 빨간 비네트가 심박수처럼 맥박 쳐야 한다. 현재 CoreHUD는 HP바만 보여줌 → `PostProcessGameFeel` 컴포넌트를 씬에 추가하고 `PlayerHealth.OnHPChanged`에 연결하면 3~4시간 작업으로 완성 가능.

## 적 (02_Enemies)

- **숨겨진 방 유도 적 배치** — Undermine 비밀 방 참고: 특정 벽을 걷어차거나 양파가 특정 수정을 쏘면 열리는 숨겨진 공간 개념 도입 검토. 예: 방패 근위병 뒤쪽 벽이 사실 부술 수 있는 벽 → CRASH로 날리면 비밀 통로 개방. 현재 CRASH 메카닉을 탐험 보상으로 연결하는 아이디어.
- **킥 콤보 Chromatic Aberration** — Post-Processing 참고: KICK COMBO 판정 시 0.1초간 색수차(Chromatic Aberration 0.8)를 터뜨리면 타격감이 크게 올라간다. `Hitstop_System`과 함께 사용 시 시너지. 구현 난이도 낮음 (Volume 컴포넌트 오버라이드 한 줄).

## 맵·런 구조 (03_Maps)

- **공유 씨앗 긴장 경영** — Undermine 공유 금 참고: 상점에서 두 플레이어가 원하는 아이템이 겹칠 때 "네가 사면 나는 못 사" 긴장감을 UI로 강조할 수 있다. 예: 상점 UI에서 현재 씨앗 잔고와 두 진열 목록을 나란히 보여주면 자연스럽게 협의가 발생. 현재 상점 UI 구현이 있다면 씨앗 잔고 표시 위치만 조정해도 효과 있음.
- **EA 로드맵 방 확장 계획** — Early Access 참고: EA 진입 시 방 15개 → 월별 5개씩 추가하는 목표를 명시적으로 세우면 개발 속도가 관리된다. 현재 방 12개이므로 3개 더 만들면 EA 준비 조건 충족. `RoomLayouts/` 에셋 방식이라 추가 비용이 낮음.

## 전투·협동 (04_Combat)

- **합동기 블룸 서지** — Post-Processing 참고: ONION STORM 발동 시 블룸 임계값을 0.5초간 높이고 약한 슬로모션(0.3배 → 0.5초에 걸쳐 1.0배 복귀)을 추가하면 "대장면"이 된다. `Time.timeScale`을 직접 바꾸는 것이므로 `GameManager` 규칙과 충돌 여부 확인 필요 — 연출용 단기 timeScale 조작은 예외로 허용하거나 `PostProcessGameFeel`이 독자 관리.
- **회복 아이템 초록 플래시** — Post-Processing 참고: 가방 회복 열매 사용 시 0.25초간 초록 컬러 필터를 입히면 "좋아졌다"는 신호를 즉각 전달한다. 현재 회복 팝업 숫자가 있지만 화면 전체 반응이 없어 느낌이 약함. `HitFeelSettings.asset`에 강도 수치를 노출해두면 밸런스 조정 쉬움.

## 아이템·세트 (05_Items)

- **EA 입장 전 장비 60종 마일스톤** — Early Access 참고: 현재 장비 163종(설계 기준)이지만 "구현 완료" 수는 다르다. EA 진입 전 실제 플레이에서 드롭되는 장비가 최소 60종(고양이·양파 각 30)이어야 "런마다 다른 느낌"이 보장된다. `05_Items_Content.md`에서 구현 완료 수 확인 필요.
- **장비 GUID 긴급 작업** — 어제 아이디어에서 이어짐: EA 오픈 전에 각 `GearItem`에 고유 ID를 달고 세이브에 이름 대신 ID로 저장하면 EA 중 파일 이름이 바뀌어도 기존 플레이어 세이브가 깨지지 않는다. EA 진입 전 30분 작업으로 나중에 수백 명의 세이브를 지키는 투자.

## 스토리·메타 (07_StoryMeta)

- **EA 환영 팝업** — Early Access 참고: 첫 실행 시 "이 게임은 얼리 액세스입니다. 피드백은 F12로 Discord로 오세요" 팝업을 띄우면 초기 플레이어들이 자연스럽게 커뮤니티로 유입된다. `PlayerPrefs`로 한 번만 표시하도록 설정. 개발 비용: 1~2시간.
- **런 요약 로그 저장** — Early Access 참고: 개발자가 직접 플레이하며 `run_logs.json`에 런 당 클리어 시간·처치 수·사용 장비를 쌓아두면, 10~20런 후 "어느 장비가 너무 강한가", "평균 클리어 시간"을 데이터로 보면서 밸런스를 잡을 수 있다. 서버 없이 로컬 파일로도 충분.

## 기술 메모

- **URP 2D Post-Processing**: 즉시 구현 가능 우선순위 → ① 피격 빨간 비네트 펄스 (CoreHUD·PlayerHealth 연결, 1~2시간) → ② HP 20% 이하 심박수 비네트 → ③ 합동기 블룸 서지. Bloom 임계값은 픽셀아트에서 0.8+ 유지 필수.
- **Early Access Strategy**: OnionCat EA 입장 체크리스트 — 런 1 클리어 가능 ✅, 중간 저장 ✅, 방 15개 (현재 12개, 3개 부족), 장비 60종 구현 완료 (요확인), 장비 GUID 세이브 (미완). 이 3가지를 완성하면 기술적 EA 준비는 됨.
