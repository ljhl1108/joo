## 캐릭터 (01_Characters)

- **콤보 윈도우 시각화** — 협동 콤보 시스템 참고: 마지막 공격자가 Cat이면 Onion 커서 주변에, Onion이면 고양이 발 아래에 1초짜리 반투명 원이 점점 작아지는 UI 추가. "지금 내가 치면 콤보!" 를 직관적으로 알 수 있어 신규 플레이어 협동 학습 속도 향상. `EnemyComboState`의 남은 윈도우 시간을 `CoopComboHintUI`가 읽어서 표시

- **합동기 입력 타이밍 피드백** — 합동 게이지 참고: 한 플레이어가 합동기 버튼을 누르면 상대방 HUD에 "합동기 누르세요!" 배너 + 1.5초 카운트다운 아치형 바. 현재는 둘 다 눌러도 조용히 넘어가거나 놓침 — 명확한 "누르라는 신호"가 없으면 2인이 함께 타이밍 맞추기 어려움

- **야성 게이지 × 합동 게이지 연동** — The First Descendant 참고: 특수 공격(야성 게이지 만땅) 도중 양파의 씨앗이 맞으면 "합동 연계" 발동 → 합동 게이지 +25. 고양이 특수 공격의 8연타 도중 양파가 지원 사격하는 자연스러운 협동 연출 유도. `CatSpecial.OnEnemyHit`에서 양파 최근 공격 여부 확인 후 `CoopComboManager.OnKickCombo()` 호출

## 적 (02_Enemies)

- **모듈 수용량 스타일 어픽스 제한** — The First Descendant 참고: 엘리트 어픽스 시스템 설계 시 "어픽스 하나가 해당 적의 비용(Cost)을 올린다"는 개념 도입. 낮은 등급 방(±0)에는 어픽스 없음, 중간 방에는 1개, 높은 방에는 2개. 어픽스 조합이 너무 강해지는 것을 방지하는 내재적 균형. `EnemyBuilder.cs` 표 "어픽스 가중치" 열로 관리

- **약점 부위 파괴 메커니즘** — The First Descendant 결계 참고: 보스 2단계 진입 조건으로 "노란색 수정 갑옷 4개를 파괴" 추가. 근접 공격(Cat)과 원거리(Onion)가 각자 다른 위치의 수정을 담당해야 하는 자연스러운 역할 분담. 기존 현자 마법사의 결계와 비슷하지만 **위치가 4방향 분산**되어 둘이 동시에 처리해야 함. `EnemyBoss.OnPhaseChange`에서 수정 오브젝트 소환

- **적 드롭 씨앗 등급 표시** — The First Descendant 빛기둥 참고: 현재 바닥 장비(`GearLoot`)는 등급 색 빛기둥이 있지만 씨앗 드롭에는 없음. 적이 죽을 때 씨앗 개수에 따라 "작은 씨앗(1개)" vs "큰 씨앗 뭉치(3~5개)"를 시각적으로 구분 (크기·반짝임). 많은 씨앗이 나오는 엘리트 처치의 보람 강조

## 맵·런 구조 (03_Maps)

- **파밍 목표 방 예고** — The First Descendant 드롭 테이블 참고: 지도 UI에서 특정 방에 "여기서 [장비 이름] 드롭 확률 높음" 아이콘 표시 (런마다 1~2개의 방). 목표를 정하고 플레이하는 방향성이 생겨 "어차피 랜덤이니 아무 방이나"에서 벗어남. `DungeonManager`가 런 시작 시 1개 방에 보너스 드롭 플래그 설정

- **연계 방 보너스** — 협동 콤보 참고: 연속 전투방 2개를 넘어가면 **콤보 체인이 이어짐** — 직전 방의 합동 게이지가 0으로 리셋되지 않고 절반을 유지. "방을 빠르게 연속으로 클리어하면 합동 게이지가 쌓인 채 다음 방에 들어가는" 플레이 스타일 보상. 휴식 방 진입 시 리셋

- **보물방 예고 힌트 말풍선** — 말풍선 UI 참고: 지도 화면에서 커서가 보물방 노드 위에 오면 그 노드 위치에 작은 말풍선이 뜨며 다음 방 장비 세트를 힌트 제공. "햇살 세트 아이템이 들어 있어요" 같은 한 줄. `MapScreen`의 노드 클릭/호버 이벤트에서 `Dialogue.Say()` 호출

## 전투·협동 (04_Combat)

- **콤보 배율 표시 타이머** — 협동 콤보 참고: "COMBO!" 배너 옆에 남은 콤보 윈도우(1초) 숫자 표시. 0.X초를 눈으로 보면서 "서둘러야 해!" 하는 긴장감. 숫자가 0에 가까워질수록 텍스트 색이 금색 → 빨간색으로 변화. `FloatingComboBanner.Show()`에 잔여 시간 파라미터 추가

- **합동 게이지 "낭비" 방지 안전장치** — 합동 게이지 참고: 합동기 발동 가능 상태에서 게이지가 꽉 찬 채로 **다음 방에 들어가도** 게이지 유지 (지금 동작 맞는지 확인 필요). 단, 보스방 입장 시에는 자동 발동 옵션 토글 추가 → "보스방 입장 = 합동기 자동 사용" 전략 선택지

- **패링 + 콤보 연계 보너스** — The First Descendant 참고: 실드 패링 직후 1.5초 안에 고양이가 할퀴기를 날리면 강제 협동 콤보 판정 (평소 1초 윈도우 관계없이). 패링을 "기회 창"으로 쓰는 고급 플레이를 보상. `ShieldParry.OnParry`에서 Cat의 다음 공격에 `forceCombo` 플래그 설정

## 아이템·세트 (05_Items)

- **모듈 Cost 스타일 장비 무게 실험** — The First Descendant 참고: 현재 패시브 6개 슬롯을 "무게 한도 10" 방식으로 바꾸는 실험 아이디어. 전설 패시브 weight=4, 에픽=3, 희귀=2, 일반=1. "강한 패시브 2개 + 일반 4개" vs "일반 패시브 10개" 빌드 다양성. `ContentBuilder.BuildPassives()`에서 weight 필드 추가 후 `RunData.PassiveWeight` 제한 검사

- **듀얼 세트 연동 효과** — The First Descendant 크로스 빌드 참고: Cat이 Sun 4개, Onion이 Wind 4개를 가졌을 때 발동하는 **크로스 세트 보너스** 추가. 예) "고양이의 불꽃 + 양파의 바람 = 이동하는 불꽃 소용돌이 15초". 두 플레이어가 서로 다른 세트를 의도적으로 맞추는 메타 전략 유도. `CombatModifiers`에 `CrossSetBonus` 체크 추가

- **세트 진행도 HUD 확장** — 합동 게이지 UI 참고: 현재 "가장 많이 모은 세트 2개" 표시를 개선 → 세트 아이콘 옆에 "현재/다음 단계 개수" 표시. 예) "☀ 3/4" → "4개 모으면 4단계 보너스" 직관화. 플레이어가 장비 선택 시 세트 효율을 더 쉽게 계산 가능. `SetProgressHUD` 컴포넌트 신규

## 스토리·메타 (07_StoryMeta)

- **말풍선 스타일 NPC별 개성** — 말풍선 UI 참고: 등장인물마다 말풍선 스타일 다르게 설정. 책 = 양피지 배경·천천히 타이핑, 고양이 = 밝은 둥근 말풍선·빠른 타이핑, 마녀(반전 후) = 보라 테두리·보통 속도. 이름표 색을 `MetaProgress.WitchFreed`에 따라 회색→보라색으로 전환. 현재 `Dialogue.Say()` API에 `stylePreset` 파라미터 추가로 구현 가능

- **파편 드롭 연출 개선** — The First Descendant 빛기둥 참고: 기억 파편이 드롭될 때 장비 등급 빛기둥과 구분되는 **보라+흰색 반짝이는 파편 이펙트** 추가. 등대탑 이야기와 연계된 파편이므로 "별빛 조각" 느낌. 씨앗(초록)·장비(등급색)·파편(보라)으로 바닥 드롭 색 체계 정리

- **온실 말풍선 해금 연출** — 말풍선 UI 참고: 온실에서 새 장비 해금 시 말풍선이 뜨며 "새 장비가 추가됐어요!" + 해금된 장비 이름 표시. 책 캐릭터가 말하는 형식으로 이야기와 연결. 현재 단순 팝업보다 세계관 안에서 자연스러운 해금 연출 가능. `GreenhouseScreen.OnUnlock()`에서 `Dialogue.Say(bookTransform, ...)` 호출

## 기술 메모

- **협동 콤보 시스템**: `EnemyComboState.IsCombo()`에서 1초 윈도우가 실제 플레이에서 맞는지 확인 필요. 너무 짧으면 콤보가 거의 안 나고, 너무 길면 전략성 없음. `HitFeelSettings.asset`에 `coopComboWindow: 1.0f`를 노출해 조율 가능하게 하는 것을 권장

- **말풍선 UI**: `WaitForSecondsRealtime` 사용 필수 (`Time.timeScale`이 0인 일시정지 상태에서도 타이핑 진행 여부는 의도에 따라 선택). OnionCat에서는 게임이 멈추면 말풍선 자체를 숨기므로 `WaitForSecondsRealtime`이 맞음. World Space Canvas를 쓸 경우 `Canvas.worldCamera`를 Main Camera로 지정해야 정렬이 맞음
