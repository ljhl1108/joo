## 캐릭터 (01_Characters)
- **고양이-양파 Alteration 버프** — Windblown 참고: 고양이 할퀴기가 양파 씨앗에 "마지막으로 획득한 원소 속성" 을 부여하는 업그레이드 카드 추가. 패시브 카드 1장으로 두 캐릭터 모두 변화 → 시너지 체감 극대화. 구현: `CombatEvent.OnSlashHit` 시 다음 씨앗 발사에 원소 버프 타이머 세팅
- **양파 Shield Stance 애니메이션** — 방패 올리기(4프레임) → 방패 루프(2프레임) → 방패 내리기(4프레임) 3단계 애니메이션 분리. 현재 단순 토글이라면 `shield_up` / `shield_loop` / `shield_down` 3개 클립으로 분리하면 타격감 향상. Animator에서 Bool "IsShielding" + Shield_Up은 has-exit-time 트랜지션
- **캐릭터 바디 공유 YSort 시각화** — 고양이가 벽 뒤(낮은 Y)에 있을 때 양파 스프라이트도 같이 사라지는 이슈 가능성. Onion 스프라이트의 Sorting Order를 Cat보다 +2 고정하되 Cat이 벽 뒤일 때도 양파만 살짝 보이게 처리? → 역으로 이 현상이 "완전 단일 바디" 느낌을 줄 수 있음. 의도적으로 유지하는 것도 디자인

## 적 (02_Enemies)
- **Reaction 카운터 약점 적** — Windblown Reaction 메카닉 참고: 특정 적이 "반격 타이밍" 직전 1초에 붉게 빛나는 이펙트 표시 → 이 순간 양파 패리 성공 시 적이 기절 + 고양이 다음 공격 2배. "협동 Reaction" 이 일어날 수 있는 적 패턴. 패리 타이밍을 "보이게" 만들면 난이도 유연 조절 가능
- **Alteration 면역 적** — 근접 또는 원거리 단독으로는 약점이 없는 적: "시너지 데미지(근접+원거리 콤보 직후)"로만 관통되는 방어막. 고양이 슬래시 → 0.5초 이내 양파 씨앗 → 방어막 깨짐. 협동 강요 적 디자인 강화
- **패턴 전환형 적** — 체력 50% 이하에서 "Surge" 페이즈 돌입: 공격 속도 1.5×, 이동 경로 변경, 색상 변화. Windblown 정식 출시 Surge 메카닉 참고. 고양이가 도망가고 양파가 원거리로 체력 녹이는 2단 페이즈 전략 유발

## 맵 (03_Maps)
- **부유 플랫폼 방** — Windblown "부유 군도" 분위기를 방 1개에 적용: 바닥이 여러 섬 조각으로 분리된 방. 구덩이가 섬 사이에 있음 → 고양이 킥으로 적을 구덩이로 떨어트리는 전략 공간. `RoomLayouts` 글자 지도의 `P` (Pit) 활용 극대화
- **이동 발판 방** — 일정 주기로 바닥 타일 일부가 내려앉는 방. 양파는 마우스 에임이라 발판보다 방어에 집중하고 고양이가 발판 사이를 이동하며 근접. `Trap_Hazard_System.md` 참고
- **제한 시간 방** — 방 진입 후 60초 이내 적 전멸 목표. 달성 시 "Surge 보너스 카드" 추가 제공 (실패해도 클리어는 됨). Windblown의 도전적 선택 구조 참고. `RewardAxis` 에 "time_bonus" 출구 타입 추가

## 전투 (04_Combat)
- **Reaction 협동 연출** — 양파 패리 성공 후 고양이 슬래시가 1.5초 내 히트 시: 일반 타격 파티클 대신 "합동기 이펙트" (두 색상 혼합 빛 폭발) + 히트스톱 12프레임. 협동 보상을 시각/청각으로 강화. `HitFeelSettings.asset`에 `coopReactionHitstop` 항목 추가
- **씨앗 Alteration 원소** — 양파 씨앗이 "마지막 고양이 할퀴기 원소"를 흡수: 불꽃 씨앗(DoT), 얼음 씨앗(슬로우), 전기 씨앗(연쇄) 3종. 업그레이드 카드로 잠금 해제. 구현: `ProjectileSeed` 에 `ElementType` 필드, 할퀴기 히트 시 `OnionAbilityManager.SetNextSeedElement(cat.LastElement)`
- **킥-에어본-원거리 콤보** — 고양이 킥으로 에어본 → 양파 씨앗이 에어본 타겟에 1.5× 보너스 데미지. `TakeDamage` 에서 `IsAirborne` 체크. Launch 상태 적의 `isAirborne = true` 세팅 필요. 가이드: `Coop_Hit_Synergy_System.md`

## 스토리 (05_Story)
- **공생 계약 에필로그** — 보스 클리어 후 짧은 3컷 연출: 양파가 꽃을 피움 → 고양이가 처음으로 웃음 → "다음 던전으로" 텍스트. Windblown의 "탈출 → 또 다른 섬" 구조처럼 런이 끝나도 다음이 있다는 느낌. `Ingame_Cutscene_System.md` 참고
- **적의 두려움** — 던전의 슬라임들이 "꽃 냄새에 끌린다" 는 세계관 설정: 양파(향기)가 주의를 끌고 고양이(발톱)가 처리하는 역할 분담을 스토리로 정당화. 아이템 설명 플레이버 텍스트에 반영 가능
- **화분의 비밀** — 양파가 자라는 화분이 고양이 등에 고정된 이유: 옛 마법사가 "전투하는 생명체와 공생해야만 성장하는 식물" 을 만들었다는 설정. 업그레이드 카드 텍스트에 조각조각 공개 (Hades의 이야기 파편 방식). 스토리 우선순위 낮지만 텍스트 플레이버로 충분

## 기술 메모
- **Aseprite 파이프라인**: `com.unity.2d.aseprite` 임포터를 쓰면 태그 이름 = 클립 이름이 자동 생성됨. OnionCat에서 가장 중요한 것은 **PPU 32, Filter Mode = Point (no filter)** 임포트 설정 — 안 맞으면 픽셀이 흐려짐. 고양이 Attack 애니메이션에는 `AnimationEvent` 로 히트박스 활성/비활성을 제어해야 프레임 정확한 타이밍 가능
- **세션 흐름**: OnionCat은 `GameManager.ChangeState()` 기반으로 이미 세션 흐름이 설계되어 있음. 재시작 시 **RunData 초기화 + PoolManager.ReturnAll() + EnemyBase.Active.Clear()** 세 가지를 반드시 해야 이전 런 잔존이 없음. Bootstrap 씬 없다면 GamePlay 씬에서 서비스 Lazy Init으로 대체 가능
