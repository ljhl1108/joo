## 캐릭터 (01_Characters)

- **식물 사이드킥 파생** — Dungeon Munchies 미니언 참고: 양파가 심은 식물이 단순 정적 오브젝트를 넘어 근처 적에게 자율 반응(씨앗 발사, 독 구름 뿜기)하는 **능동 사이드킥**으로 성장. 마법서 레벨업 시 식물 AI가 개선되는 빌드 방향 가능. 구현 힌트: `PlantBase`에 `AIState`(Idle/Alert/Attack) 추가, 일정 범위 내 `EnemyBase.Active` 감지 시 전환
- **양파 개성 강화 — 재배 장인** — 현재 R 스킬(매운 양파)이 심기 계열의 유일한 고유기. 화분 장비 업그레이드로 "동시 식물 최대 개수 +1", "식물 생존 시간 +4초", "식물 회복 아우라 범위 확장" 같은 **화분 특화 빌드 경로**를 추가하면 양파 캐릭터성이 뚜렷해짐. 구현 힌트: `StatType`에 `PlantMaxCount`, `PlantDuration` 추가 → `PlantManager`에서 읽어 적용

## 적 (02_Enemies)

- **요리사 미믹** — Dungeon Munchies의 '재료가 되는 몬스터' 분위기 참고: 바닥에 아이템처럼 숨어있다 플레이어가 접근하면 활성화되는 함정형 적. 보물방·상점방에 한 두 개 배치하면 기대와 반전의 장력 형성. 텔레그래프: 변신 직전 0.5초 흔들림(노란 예고). 구현 힌트: `EnemyBase` 상속, `Idle` 상태에서 `SpriteRenderer`를 아이템 스프라이트로 교체
- **식물 면역 적** — 양파의 심기 스킬 카운터: 특정 적이 식물의 효과를 무시하거나(독성 내성 슬라임), 심어진 식물을 먼저 파괴하러 달려오는 행동 패턴 추가 → 고양이가 식물을 지키는 방어 협동 플레이 유도. 구현 힌트: `EnemyBase`에 `bool immuneToPlants` + `PlantBase`를 우선 타겟 삼는 AI 분기

## 맵·런 구조 (03_Maps)

- **연습 방 언락 흐름** — 첫 런 완료(or 사망) 후 메인 메뉴에 TRAINING 버튼 언락 → "기본기를 연습할 수 있습니다" 알림. 첫 런 전에는 숨겨두어 첫 경험이 런 흐름 자체임을 유지. 구현 힌트: `MetaProgress` 플래그 `firstRunAttempted` → 메인 메뉴 버튼 `SetActive`
- **식물 퍼즐 방** — 현재 2인 기믹(쌍둥이 스위치)처럼, "양파가 심은 특정 식물이 벽을 열어야 고양이가 진행 가능"한 협동 퍼즐 특수방 추가. 식물 생존 12초 제한이 자연스러운 시간 압박이 됨. 구현 힌트: 식물 오브젝트에 `UnityEvent OnFullyGrown` → 문·장벽 오브젝트 비활성화

## 전투·협동 (04_Combat)

- **콤보 유지 리워드** — 협동 콤보가 일정 횟수 연속 유지되면 **잠깐 적들 느려짐(0.7배속, 2초)** 연출. 합동 게이지가 꽉 차지 않아도 중간 보상이 생겨 협동 유도가 강해짐. 구현 힌트: `CombatModifiers`에 글로벌 적 속도 배율 추가 + `ComboCounter`에서 임계값 감지 → `TimeScale_BulletTime`과 별개로 적 `NavMesh` 속도만 조정
- **세트 달성 시각 피드백** — 장비 비교 툴팁 UI 참고: 상점·보상 화면에서 새 장비 선택 시 세트 수가 달성 임계값을 넘으면 카드 테두리에 **황금 펄스 애니메이션**. "이걸 고르면 햇살 4세트!" 즉각 전달. 구현 힌트: `UpgradeSelectUI` 카드에 `SetBonusTrigger` 컴포넌트 → `Animator.SetTrigger("SetAchieved")`

## 아이템·세트 (05_Items)

- **화분 전설 장비 — 씨앗 나무** — 현재 전설 장비 0개. 화분 전설 1호 아이디어: 식물 심기 즉시 씨앗 +3 보상 + 식물이 시들 때 자동으로 같은 종류 씨앗 심기(최대 1개). 영구 식물 밭 운영 빌드 완성. 구현 힌트: `GearItem` 에셋 생성 → `OnPlantSpawn` 이벤트 구독 + `GearEffect` 서브클래스 `SeedTreeEffect`
- **비교 툴팁 즉시 적용** — 장비 비교 툴팁 UI 문서의 구현 순서: ① `GearComparer.Compare()` 정적 함수 작성 → ② 보상 카드 `OnPointerEnter` 훅 → ③ 세트 변화 강조 한 줄 추가. 상점 팝업에도 동일 함수 재사용. 이미 `GearScreen`이 있으므로 기존 스탯 계산 로직 재활용 가능

## 스토리·메타 (07_StoryMeta)

- **런 간 식물 일지** — Dungeon Munchies의 요리책처럼, 런에서 처음 심은 식물 종류 기록(양파 씨앗, 박, 허브 등)을 해금 일지로 모음. 작은 코덱스 역할 + 식물 종류 확장 시 자연스러운 수집 컨텐츠. 구현 힌트: `MetaProgress.discoveredPlants` 해시셋 → `LoreCodex` 화면에 식물 섹션 추가
- **연습 방 NPC — 쉐프 고양이** — Dungeon Munchies의 요리사 NPC처럼, 트레이닝 룸에 말을 건네는 NPC 배치. "이 식물을 공략에 써보는 건 어때?" 같은 힌트 제공. 튜토리얼 대화창 없이도 맥락적 도움말 전달. 구현 힌트: `Dialogue_Event_System` 활용, 이벤트 트리거는 특정 장비 첫 장착 시

## 기술 메모

- **장비 비교 툴팁 UI**: OnionCat에 가장 빠르게 적용 가능한 구현 순서 — `GearComparer.Compare()` 정적 함수 → 보상 카드 hover 이벤트 → ContentSizeFitter 동적 레이아웃 → 세트 달성 강조. `GearScreen`의 스탯 계산 코드를 그대로 재사용해 중복 없이 구현 가능
- **트레이닝 모드**: `Room_Special` 씬 기반으로 시작해 배경만 교체하면 빌드 비용 최소화. Debug 메뉴(`OnionCat > Debug`)의 버튼 집합을 런타임 UI로 이식하는 방식이 핵심. 첫 런 사망 후 언락되도록 `MetaProgress` 플래그 하나만 추가하면 완성
