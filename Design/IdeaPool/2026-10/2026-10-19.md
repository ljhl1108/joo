## 캐릭터 (01_Characters)

- **부활 패링** — Cat Quest III 부활 미니게임 참고: 고양이 HP 0 직전, 양파가 0.3초 이내 패링에 성공하면 1HP로 부활. 일반 패링과 구분해 보라색 파티클 + "CLUTCH!" 표시. 실패하면 그냥 사망 → 극적인 협동 순간을 의도적으로 만들 수 있음
- **작물 종류별 고유기 강화** — 지금 양파만 구현됨. 당근(R = 방어막 씌우기) / 마늘(R = 넉백 폭발) / 부추(R = 분신 생성) 방향 구체화. Cat Quest III 아케인 스톤처럼 "고유기가 캐릭터의 정체성을 결정"하는 구조로 발전 가능

## 적 (02_Enemies)

- **세트 반응 적** — Cat Quest III 보스가 P2 스킬 콤보에 반응하듯, 특정 상태이상(예: 빙결 + 걷어차기 = 산산조각)을 적 프리팹 변수로 노출해 **어떤 조합에 취약한지 방 입장 전 아이콘으로 힌트** 제공. 전략적 사전 준비 의식을 심어줌
- **부활하는 적 (Re-emerge)** — 잡은 줄 알았던 적이 다시 기어나오는 패턴. Cat Quest III 물 속 보스에서 착안. 구현: `EnemyBase`에 `reviveOnce` 플래그 → HP 0 시 `stunDuration` 동안 땅바닥에 쓰러졌다가 HP 30%로 기어 일어남. 한 번만 발동

## 맵·런 구조 (03_Maps)

- **스테이지 테마 즉시 적용** — 현재 임시 색 오버레이를 `StageTheme` ScriptableObject로 교체. `Stage_Theme_Asset_Pipeline.md` 1단계 구현만 해도 에디터에서 색을 관리 가능하고 코드 하드코딩 제거. 타일셋 에셋이 완성되는 대로 floorTile / wallTile 교체로 자연스럽게 확장됨
- **스테이지 분기 선택 화면 강화** — 가운데 스테이지(늪·온실·서리)를 고를 때 지금은 이름만 나옴. Cat Quest III의 섬 탐험 미리보기처럼, 각 스테이지 선택지에 **대표 적 아이콘 2~3개 + 특이 환경 한 줄 설명** 표시 → "서리는 빙결 적이 많음" 같은 사전 정보 제공

## 전투·협동 (04_Combat)

- **동시 스킬 폭발** — Cat Quest III의 "두 명이 동시에 스킬을 쓰면 콤보 폭발" 아이디어 응용: 고양이 걷어차기와 양파 Q스킬(터지는 박)을 **0.5초 이내에 연속 사용**하면 킥 콤보 게이지 +30 + 폭발 범위 확대. 지금 `coopCombo` 판정과 겹치지 않게 "근접+원거리 동시기" 로 구분
- **텔레그래프 시인성 점검** — Cat Quest III가 좋은 평가를 받은 핵심은 매우 명확한 예고선. 현재 성녀 궁수의 빛의 나선 패턴이 화면에 너무 많은 예고선이 동시에 뜰 때 읽히는지 확인 필요. 보스 첫 플레이 신규 유저 테스트 권장

## 아이템·세트 (05_Items)

- **장비 비교 UI 강화** — Cat Quest III 벤치마킹: 바닥 드롭 장비를 주울 때 현재 장착 장비와 나란히 스탯+효과 비교. 추가로 "이 장비를 착용하면 Sun 세트 2단계가 켜진다" 같은 **세트 켜짐 미리보기** 표시. 기존 `ItemTooltip`에 `willActivateSet` 필드 추가로 구현 가능
- **전설 장비 발견 연출** — Cat Quest III의 황금빛 아이템 드롭 연출 참고. 현재 등급 색 빛기둥이 있지만 전설(주황) 드롭 시 **화면 전체에 0.3초 플래시 + 전용 드롭 사운드**로 더 특별하게. HitFeelSettings에 `legendaryDropFlashColor` 추가하면 조정 가능

## 스토리·메타 (07_StoryMeta)

- **스테이지 배너 강화** — 지금 스테이지 진입 시 이름 배너만 뜸. Cat Quest III의 지역 이름 연출처럼 **짧은 배경 설명 한 줄 + 스테이지 대표 색 테두리**를 2~3초 표시. Dialogue_Event_System과 연동해 같은 프레임워크 재사용 가능
- **물음표 이벤트 로그** — 런 결과 화면에 "이번 런에서 만난 이벤트" 목록 표시. Cat Quest III의 항해 일지 개념 차용. 현재 `RunData`에 `encounteredEvents` 리스트를 추가해 저장하면 구현 가능. 반복 런에서 "이번엔 낮잠 방이 있었다" 발견의 재미

## 기술 메모

- **스테이지 테마 파이프라인**: 코드 수정 없이 색·타일·BGM을 한 ScriptableObject에서 관리하는 1단계 구현이 가장 빠른 임시 오버레이 제거 방법. `Room.ResetForReuse()` 안에서 `StageThemeApplier.Apply(DungeonManager.Instance.CurrentTheme)` 한 줄 추가로 연결 가능. 타일 일괄 교체 시 `SetTiles` 배치 API 사용 권장(개별 루프보다 ~10배 빠름)
- **콘텐츠 무결성 검사**: `GameDatabase Rebuild`를 까먹었을 때 런타임 크래시 대신 게임 시작 직후 Console 에러로 발견하도록. `#if UNITY_EDITOR || DEVELOPMENT_BUILD` 안에 넣어 릴리즈 빌드 오버헤드 제로. 첫 번째로 `GearDatabaseCheck` 하나만 만들어 연결하면 이후 확장이 쉬움
