## 캐릭터 (01_Characters)

- **야성 게이지 → 팀 자원화** — Stolen Realm 서포터 스킬 참고: 고양이가 야성 게이지를 다 채웠을 때 특수 공격 대신 "양파에게 게이지 전달" 옵션을 장비 효과로 추가. 전달하면 양파 스킬 쿨다운 전체 초기화. 자원을 희생해 팀을 강화하는 비대칭 플레이 설계
- **양파 "도발" 씨앗** — Phantom Rose 적 카드 개입 컨셉: 특정 스킬이 씨앗을 쏘면 맞은 적이 다음 공격을 반드시 양파 방향으로 발사 → 양파가 패링 타이밍을 알고 있는 상황에서 의도적으로 도발 → 반사 데미지. 양파의 능동적 역할 강화
- **고양이 크기별 특수 반응** — Stolen Realm 육각 그리드의 위치 보너스 참고: 적 크기 4등급(`EnemyBuilder.SizeOf`)에 따라 고양이 할퀴기 히트 리액션이 다름 — 작음은 날아가고, 큼은 경직만 주고, 보스는 히트스톱만. 이미 어느 정도 구현된 것처럼 보이지만 연출 강화 여지 있음

## 적 (02_Enemies)

- **소환 지연 Aggro** — 적 경보 설계 참고: `EnemySpawner`로 소환된 적이 등장 직후 0.5초 Idle을 유지한 뒤 Aggro 전환. 현재는 소환과 동시에 달려오는 것 같은 느낌 → 등장 모션 재생 시간 동안 잠깐 멈춰 있으면 플레이어가 준비할 시간이 생김. `SpawnDelay`를 `EnemyBuilder` 기본값으로 추가
- **경보 전파 패턴 다양화** — 방 입장 시 전체 즉발 Aggro가 기본이지만, 일부 "보초" 타입 적은 플레이어가 먼저 공격해야 전투 시작 → 다가오는 고양이를 양파가 먼저 쐈을 때 싸움이 터지는 상황. 방 진입이 더 긴장감 있어짐
- **그룹 조율 공격 타이밍** — Stolen Realm 연계 콤보 디자인 참고: 근거리 적 2마리가 동시에 달려오는 대신 0.3초 교대 공격. 플레이어가 두 방향을 동시에 막아야 하는 상황 줄이고, "첫 번째를 막으면 두 번째가 오는" 리듬감 → `EnemyGroup`에 `staggerInterval` 값 추가 고려

## 맵·런 구조 (03_Maps)

- **방 타입별 배경 조명 색** — Stolen Realm 방 종류 다양화 참고: 전투방(기본), 보물방(황금 노란빛), 엘리트방(빨간 불길), 휴식방(파란 달빛). URP 2D Global Light의 색상을 방 진입 시 코루틴으로 전환. 지금도 구별은 되지만 색 분위기 차이가 추가되면 방 타입을 눈으로 바로 알 수 있음
- **베타 테스트용 단축 런 옵션** — 클로즈드 베타 운영 참고: 베타 빌드에서 "빠른 테스트 모드" 선택 시 스테이지 1개짜리 단축 런 제공. 풀 런(1시간)을 여러 번 할 여건이 안 되는 테스터도 장비·전투 피드백 가능. `DungeonManager.stagePlan`에 단축 플랜 추가 (`Debug_Cheat_System` 연계)
- **물음표 방 적 드롭 예고** — 물음표 이벤트가 "매복"이면 진입 전에 힌트(방 입구 발자국 이펙트 등)를 제공. Phantom Rose의 "이번 전투가 어떤 느낌일지 미리 알 수 있는 카드 미리보기"에서 착안

## 전투·협동 (04_Combat)

- **협동 콤보 달성 시 경보 전파 중단** — 적 경보 설계 참고: `COMBO!` 텍스트가 뜨는 순간(교대 타격 성공) 주변 적의 Aggro가 0.3초 중단됨 — "화려한 연계가 적을 잠깐 주눅들게 함". 연출과 게임플레이를 연결하는 효과. `OnCombatCombo` 이벤트에서 `EnemyBase.Active`에 짧은 stunInterval 주입
- **패링 성공 → 팀 경보 초기화** — 패링 성공 시 가장 가까운 적 1마리가 Alert 상태로 잠깐 복귀 (공격 캔슬). 현재는 패링이 반사 데미지에 그치는데, 전투 흐름을 리셋하는 역할도 추가하면 패링의 전략적 가치 상승
- **야성 게이지 협동 공유** — Stolen Realm 팀 버프 참고: 특정 세트 보너스로 "야성 게이지가 50% 채워질 때마다 합동 게이지 +5". 야성 게이지와 합동 게이지가 연결되면 고양이가 열심히 싸울수록 합동기가 빨리 쌓임 → 협동 콤보 다음으로 두 번째 협동 피드백 루프

## 아이템·세트 (05_Items)

- **보스 처치 전용 에픽+ 장비** — Phantom Rose 보스 카드 참고: 보스 처치 보상에서 에픽 이상 확정 외에 "보스 전용 장비"(조건부 효과 있음) 1개 추가 등장. 예: "처음 피격받은 뒤 5초간 공격력 2배" — 강하지만 발동 조건이 까다로워 전략적 선택 요소
- **세트 달성 알림 강화** — Stolen Realm HUD 참고: 세트가 새 단계에 진입할 때 HUD의 세트 아이콘이 잠깐 펄스(빛나며 커짐) + "햇살 4단계!" 플로팅 텍스트. `CombatModifiers` 변경 이벤트에 연결 가능
- **장비 분해 씨앗 → 팀 공유 확인 UI** — 장비를 분해할 때 "공유 씨앗 +N개" 텍스트가 두 플레이어의 HUD 모두에 표시됨. 현재는 씨앗 카운터만 바뀌는 것 같은데, 분해 피드백이 양파 플레이어에게도 보여야 팀 자원이라는 느낌 강화

## 스토리·메타 (07_StoryMeta)

- **베타 테스터 전용 메달** — 클로즈드 베타 운영 참고: `MetaProgress`에 `isBetaTester` 플래그 추가. 베타 기간 플레이 기록이 있으면 온실에서 "초기 지지자" 코스메틱 화분 해금. 베타 참가자들이 자신의 기여를 게임 안에서 확인할 수 있음
- **스토리 진행에 따른 등불 연출 변화** — 빛 색깔 퀘스트의 등불이 현재 모인 빛 색을 섞어서 반짝임. 예: 양파 빛만 있으면 초록, 나중에 토마토 빛이 더해지면 노란빛으로 변화. 이야기 진행이 화면에서 시각적으로 누적되는 느낌
- **물음표 방 결과 회고** — 런 결과 화면에 "이번 런의 물음표 방 결과" 요약 추가: 어떤 이벤트를 만났고 좋았는지/나빴는지 아이콘으로 표시. Phantom Rose의 런 요약 카드처럼 짧고 임팩트 있게

## 기술 메모

- **적 경보 상태 설계**: OnionCat에서 가장 빠른 개선은 소환 적의 `SpawnDelay` 0.5초 추가. `EnemyBase.cs`의 `Start()`에서 `StartCoroutine(AggroAfterDelay(0.5f))` 형태로 간단히 구현 가능. 방 진입 시 즉발 Aggro는 유지 (로그라이크 템포)
- **클로즈드 베타**: 출시 전 핵심 질문 3개 — (1) 협동 콤보를 발견하는가, (2) 장비 세트를 인식하는가, (3) 런 길이가 적당한가. `meta.json` 초기화 후 배포, 베타 종료 후 반드시 되돌리기
