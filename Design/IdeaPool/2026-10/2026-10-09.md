## 캐릭터 (01_Characters)

- **고양이·양파 관계 게이지** — DD2 어피니티 시스템 참고: 협동 타격/생존 시 게이지 증가, 어려운 상황(연속 피격)에서 감소 → 최고조 시 합동기 강화, 최저 시 특수 디버프 대사 이벤트 발동. `RunData`에 `synergy float` 추가, HUD에 가는 게이지 바로 표시
- **양파의 리듬 사격 콤보** — Metal Hellsinger 참고: 투사체를 일정 간격으로 3발 연속 발사하면 4번째 발에 특수 효과(관통·폭발) 추가. 타이밍 UI 없이 **타격음 강도 변화**로만 피드백 → 숙련자에게 보람, 초보자도 무시하고 즐길 수 있음
- **캐릭터 Path 선택 화면** — DD2 영웅 경로 참고: 런 시작 전 고양이/양파 각각 3가지 Path(예: 공격형·방어형·지원형) 선택. `ClawStyle`, `OnionSkill` 시작 세트를 Path로 묶어 선택지 단순화 → 초보자 접근성 향상

## 적 (02_Enemies)

- **위치 특화 적** — DD2 포지션 시스템 참고: 전방 캐릭터(고양이)에게만 공격 가능한 "돌진 슬라임"과 후방 캐릭터(양파)에게만 공격 가능한 "저격 꽃씨" 구분. 공략하려면 반드시 두 플레이어가 역할을 유지해야 함
- **박자 방패 적** — Metal Hellsinger 참고: 일정 간격으로 방패가 열리는 적, 방패가 열리는 순간에만 피해. 양파의 투사체 타이밍을 요구 → "기다렸다 쏘는" 긴장감 부여. 방패 개폐 주기를 사운드로만 알려줌
- **분기 소환 보스 미니언** — 보스 아레나 설계 참고: 보스 체력 50%에서 미니언 2마리를 아레나 양쪽 가장자리에 소환. 고양이는 전방 미니언 처리, 양파는 원거리로 후방 미니언 처리해야 보스 취약점 노출 → 분할 목표 원칙 적용

## 맵 (03_Maps)

- **분기 지도 선택 UI** — DD2 포크 로드 참고: 방 이동 전 다음 방 2~3가지 선택지 아이콘 표시 (전투 집중🗡, 상점💰, 고위험 고보상⚠). `DungeonManager`에 분기 선택 단계 추가. 구현 참고: `InRun_Branch_Map_System.md`
- **보스 아레나 Phase 변형 방** — 보스 아레나 설계 참고: 보스 체력 구간별로 방 레이아웃이 변함. Phase 1: 기본 공간, Phase 2: 장애물 소환(고양이 엄폐 활용), Phase 3: 구덩이(Pit) 활성화 → 압박 증가. `Boss_Arena_Spatial_Design.md` 구현 패턴 참고
- **NPC 허브 방** — DD2 여관 + Hades 지하 참고: 런 사이 공간에 NPC 1~2명 배치. 이전 런 결과에 반응하는 대사 1줄 표시 (짧게). 큰 스토리 씬 없이도 세계관 밀도를 높이는 저비용 방법. 첫 구현은 텍스트 팝업만으로 충분

## 전투 (04_Combat)

- **박자 콤보 타격음** — Metal Hellsinger 참고: 고양이가 0.8초 이내 연속 3회 타격 시 마지막 타격에 `SfxId.CatComboFinisher` 재생. 별도 UI 없이 소리만으로 콤보 인식. `Sfx.Play` 트리거 조건은 타격 간격 타이머로 관리
- **협력 취약 타이밍 윈도우** — DD2 시너지 시스템 참고: 고양이 할퀴기로 적이 경직(Stun) 상태일 때 2초간 양파 투사체 피해량 1.5배. 현재 `ApplyStun` 후 `CombatModifiers`에 임시 승수 추가. HUD에 아이콘 깜빡임으로 타이밍 알림
- **분할 보스 취약점** — 보스 아레나 설계 참고: 보스 몸 양쪽에 빛나는 약점 오브젝트 배치. 두 약점을 0.5초 이내 동시 공격해야 대미지 반영. 고양이가 근거리 약점, 양파가 원거리 약점 담당 → 협력 필수 메커닉

## 스토리 (05_Story)

- **런 히스토리 반응 NPC 대사** — DD2 관계 시스템 + Hades 참고: 마을 NPC가 이전 런 결과를 기억. "또 슬라임에게 당했군요" / "이번엔 2층까지 갔네요!" 등 짧은 한 줄 대사. `RunHistoryData` ScriptableObject에 이벤트 기록 → `DialogueSelector`가 조건 체크 후 최적 대사 선택
- **허브 귀환 씬 짧은 연출** — DD2 여관 참고: 런 종료 후 허브 씬 귀환 시 고양이와 양파가 지쳐 쓰러지는 짧은 애니메이션 + NPC 한마디 대사. 실패를 부정적 이벤트가 아닌 **다음 런으로 연결되는 서사**로 전환
- **첫 보스 격파 특수 이벤트** — DD2 언락 구조 참고: 처음 보스 격파 시 NPC가 새로운 선택지를 열어주는 특수 대사 이벤트. `RunHistoryData.HasEvent("boss_defeated")`가 처음 true가 되는 순간 일회성 cutscene 재생. 기술 구현: `oneTimeOnly = true` 대사 라인

## 기술 메모

- **Boss Arena Spatial Design**: 분할 목표(두 스위치 동시 활성화), 안전지대 로테이션, Phase 변형의 3가지 패턴이 OnionCat 보스에 가장 즉시 적용 가능. 아레나 크기는 24×14 타일 이내로 두 캐릭터가 서로 보이도록 제한할 것. `BossArena.cs` + 체력 이벤트 훅으로 구현 시작
- **NPC Run History Dialogue System**: `RunHistoryData` ScriptableObject 하나로 시작하면 충분. 런 종료 시 `AddEvent()` 호출 추가부터 → NPC 대사 5개 작성 → 저장/로드는 마지막에. 완전한 대화 시스템 없이도 **텍스트 팝업 1줄**만으로 기능 구현 가능
