## 캐릭터 (01_Characters)

- **장비 비주얼 오버레이** — Wildermyth 참고: 슬롯별 장비 장착 시 고양이 외형에 그림이 덧씌워지는 방식. 현재 `CatArtRenderer`의 `attachment_config.json` 소켓 구조가 이미 있으므로 슬롯마다 비주얼 소켓 하나 추가로 구현 가능. 예: "화염 발톱" 장비 → 발에 불꽃 스프라이트. 아트 비용이 크므로 1~2종 시험 먼저.

- **세트 발동 시 고양이+양파 색조 변화** — Wildermyth의 변신 조합 색상처럼, `CombatModifiers.Has(세트, 단계)`가 true일 때 고양이·양파 스프라이트에 짧은 색상 플래시(0.3초) 추가. 플레이어가 "세트가 완성됐구나"를 UI 없이도 감지 가능. `PassiveHost.Recalculate` 이후에 호출.

- **장비 획득 직후 "능력 미리 보기"** — Crab Champions처럼 선택 화면에서 장비 아이콘 호버 시 고양이/양파 외형에 미리 비주얼 반영. 현재 `UpgradeSelectUI`에서 선택 전 프리뷰 패널 추가. 첫 구현은 텍스트 설명만으로도 충분.

## 적 (02_Enemies)

- **대형 슬라임 분열** — Enemy_Split_Clone_System 참고: ST1 밀밭 적 "대형 슬라임"이 처치 시 소형 슬라임 2마리로 분열. 고양이가 발로 날린 대형 슬라임이 벽에 부딪혀 분열하면 연쇄 혼전. `EnemyBuilder.cs` 테이블에 `split` 필드 추가 → 메뉴 Build Enemies. `maxDepth = 1`로 소형 슬라임은 더 분열 안 하게.

- **엘리트 적 개인 모디파이어** — Crab Champions 참고: 엘리트 변종 적이 1~2개의 특성을 추가로 보유. 현재 `ModularEnemy` 조합에 "엘리트 플래그" 추가 → 체력 ×1.5, 개인 버프(빠른 이동/방어막/아군 버프 중 1개). EnemyBuilder의 `EnemyEntry`에 `eliteModifiers` 배열 추가.

- **거품 적 (사망 후 환경 위험)** — 분열 시스템 변형: ST3 적이 처치될 때 1초 뒤 터지는 거품 2~3개 소환. 거품은 Wall 레이어에 막혀 돌아다님. 반드시 처치하되 사방에 흩어지면 양파가 씨앗으로 각개 격파해야 → 역할 분담 유도. `EnemyHazard`로 구현, 체력 1짜리 작은 오브젝트.

## 맵·런 구조 (03_Maps)

- **저주-보상 물음표 옵션 추가** — Crab Champions의 저주 카드처럼, 물음표 방 이벤트 중 "불리한 조건을 받고 더 좋은 장비를 얻는" 선택지 추가. 예: "다음 방까지 씨앗 획득 금지 (대신 에픽 장비 1개)". `TimedEffects`로 "방 N개 동안"만 적용, 영구 손해 금지 규칙 준수.

- **방 클리어 보상 타이밍 개선** — Crab Champions처럼 방 클리어 → 무기(장비) 드롭이 즉각적으로 나타남. 현재 OnionCat은 클리어 후 선택 화면으로 전환. 대안: 방 클리어 연출(VFX) + 1.5초 후 UI 등장 사이에 플레이어가 잠깐 "와, 클리어했다" 느끼는 타이밍을 의도적으로 삽입 (현재 너무 즉각적이면 긴장감이 없을 수 있음).

- **섬-상점 구조 참고한 보스 사이 휴식** — Crab Champions의 "상점 섬"처럼, 스테이지 보스 처치 후 마을(현재 구현됨)에 "장비 교환 NPC" 1명 추가. 가방에 있는 장비를 seeds로 팔거나 더 나은 것으로 교환. `StoryRoute`의 마을 단계와 연동, `Shop_System.md` 참고.

## 전투·협동 (04_Combat)

- **고양이 특수 공격으로 대형 적 강제 분열** — `CatSpecial` 히트 이벤트 감지 → `SplitData`가 있는 적에게 `maxDepth` 무시하고 즉시 분열 트리거. 위험하지만 "빠르게 처리하면 강점"이 되는 고리스크 선택. 고양이 플레이어에게 "지금 써야 하나?" 판단 순간 추가.

- **공유 체력 위기 협동 연출** — Crab Champions의 아군 부활을 OnionCat 버전으로: HP가 20% 이하일 때 고양이가 양파를 더 단단히 감싸는 모션(방어 모드) + 패시브 실드 회복 속도 2배. 고양이 혼자 발동되지 않고 "P2가 방향키 위를 누르면 발동" → 위기 상황 협동 커뮤니케이션 유도.

- **동시 타격 콤보 시각화** — Wildermyth의 협동 공격 보너스처럼, 고양이 할퀴기와 양파 씨앗이 같은 적에게 0.3초 이내로 맞을 때 "CO-OP HIT!" 텍스트 + 작은 반짝임. 현재 협동 콤보 게이지가 있지만 각 타격이 "기여"하는 느낌이 약함 → 개별 타격마다 소소한 피드백 추가.

## 아이템·세트 (05_Items)

- **세트 색상 카드 UI 힌트** — Crab Champions의 색상 세트 보너스 UI처럼, 보상 선택 화면에서 현재 보유 세트 단계를 작은 아이콘으로 표시. 예: "☀️ Sun 세트 2개 보유 중 — 1개 더 모으면 보너스!". `UpgradeSelectUI`의 카드 하단에 한 줄 텍스트 추가, `RunData.RecomputeGear` 후 세트 카운트 읽기.

- **같은 장비 중복 → 강화 단계 아이콘** — Wildermyth 변신처럼 강화된 장비는 외형이 바뀜. OnionCat에서는 현재 중복 획득 시 seeds로 전환. 추가 아이디어: 강화 1단계는 아이콘에 ★ 하나, 2단계는 ★★ 등 단계 표시. `GearItem`에 `upgradeLevel` 필드 + `UpgradeSelectUI`에서 표시.

- **해금 비용 표시 개선 (온실)** — Crab Champions의 상점에서 가격이 명확히 표시되는 것처럼, 온실 화면에서 해금되지 않은 장비에 "파편 N개 필요"를 아이콘+숫자로 표시. 현재 `MetaProgress.fragmentsEarned`와 `GearItem.UnlockCost`를 비교해 "충분함 / 부족함" 색상 구분.

## 스토리·메타 (07_StoryMeta)

- **레거시 에셋 힌트 (Wildermyth 세대 시스템 참고)** — 메타 진행에서 "지난 런에서 쓴 장비"가 온실에 흔적을 남기는 감성 추가. 예: 이전 런에서 클리어한 고양이 이름(또는 무기명)이 온실 한켠에 작은 비석으로 표시. `MetaProgress`에 `runHistory` 배열 추가, 최근 3회 기록 보존. 아트 비용 최소화: 텍스트 레이블만으로 충분.

- **등불 색깔 쌓이는 시각화** — Wildermyth의 레거시 외형처럼, 마을 등불에 쌓인 빛의 색이 실제로 등불 색상을 바꾸는 연출. 현재 `LightColor`가 쌓이는 로직은 있으나 등불 그림에 반영 여부 확인 필요. 여러 색이 섞이면 흰빛에 가까워지도록.

## 기술 메모

- **Enemy_Split_Clone_System**: `EnemyBase.OnDied()` 훅에 `SplitManager.Spawn()` 한 줄 추가로 구현 가능. 핵심은 `maxDepth` 필드로 재귀 분열 방지 + `PoolManager.Spawn`으로 성능 보호. 첫 적용 대상은 ST1 대형 슬라임 — 적 조합이 가장 단순해 테스트하기 좋음.

- **Platform_Submission_Certification_Process**: GRAC 심사는 출시 60일 전에 신청해야 여유가 있음. Steam Direct $100은 Steamworks 계정 등록 즉시 가능 → AppID 발급 후 개발 중 테스트 가능. **지금 당장 할 일**: Steamworks 파트너 계정 등록 + AppID 발급 (상점 페이지는 나중에). IL2CPP 빌드 테스트도 출시 전 반드시 확인.
