## 캐릭터 (01_Characters)

- **Cat 유인 & 귀환 쿨다운 연계** — Enemy Leash + Vagante 유인 전술 참고: Cat이 적을 방 중앙으로 유인한 뒤 대시로 이탈하면, 리시로 귀환하는 적이 무방비 상태(귀환 중 공격력 없음)로 Onion의 사거리 안으로 진입. "Cat이 유인 → Onion이 사격" 시퀀스가 자연스럽게 완성되는 전술 루프. Cat Awake()에서 `EnemyLeash` 레퍼런스 없이 행동하지 않도록 `null 체크` 추가 주의.
- **쿨다운 기반 조준 리듬 (P2)** — Has-Been Heroes 쿨다운 교대 구조 참고: Onion의 일반 투사체 쿨다운(0.8초) 동안 Cat이 근접으로 연결, 쿨다운 끝나면 Onion이 다시 사격. 두 캐릭터의 쿨다운이 완벽히 교대되면 빈 틈이 없는 "절묘한 박자" 연출. `HUDController`에서 Onion 쿨다운 UI 게이지를 P1도 볼 수 있게 배치 → P1이 타이밍 인식.
- **체력 감소에 따른 약화 (Has-Been Heroes 영웅 감소 응용)** — 영웅이 줄어들수록 선택지 감소 구조 참고: Cat HP 25% 이하 → 대시 거리 20% 감소, Onion HP 25% 이하 → 투사체 속도 15% 감소. 위기 상황에서 능력이 줄어드는 긴장감. 반대로 "역전의 명수" 업그레이드: 체력 낮을수록 공격력 +10% 보상.

## 적 (02_Enemies)

- **귀환 중 무방비 적 = 취약점 윈도우** — Enemy Leash Return System 직접 적용: 근접 약점 적이 리시로 귀환하는 중(회색 상태) Cat의 슬래시에 데미지 2배 판정. "적이 도망갈 때가 기회"라는 직관적 메카닉. 귀환 시 `SpriteRenderer.color = gray`로 시각 표시. 원거리 약점 적 귀환 중엔 반대로 Onion 사격에 2배 → 약점 유형에 따른 귀환 처치 전략 분기.
- **Has-Been Heroes식 3레인 미니보스** — 레인 포지셔닝 메카닉 참고: 방 중앙에 3레인 구조로 세 위치 중 하나에 있는 적만 공격 가능. 근접 레인(가까움)은 Cat만, 원거리 레인(멀리)은 Onion만 공격 가능. 미니보스가 레인 사이를 이동 → Cat과 Onion이 미니보스 위치를 보고 즉각 역할 전환. `MidBoss.MoveToLane(int lane)` → `EnemyWeakness.SetCurrentWeaknessType()` 동기화.
- **귀환 후 강화 적** — Leash Return + 리스크/리워드 설계 참고: 일부 적은 스폰 위치로 귀환 완료 시 체력 회복 + 공격력 1.2배로 강화. 플레이어가 귀환을 막기 위해 공격적으로 따라가야 함. Cat의 대시로 귀환 경로를 막거나 Onion이 귀환 도중 원거리 처치. "도망치면 더 강해진다"는 위협감.

## 맵 (03_Maps)

- **리시 반경 가시화 방 (비밀 힌트)** — Enemy Leash + Vagante 비밀 발견 참고: 방 초입에 바닥에 옅은 원형 문양이 그려짐 (적 스폰+리시 반경을 아트로 표시). 고급 플레이어는 이 원을 보고 "여기까지 유인하면 적이 돌아간다"를 인식. 초보는 그냥 장식으로 보는 레이어드 정보 설계.
- **레인 분리 방 (Has-Been Heroes 레인 참고)** — 방 중간에 파괴 가능한 낮은 벽으로 상단/하단 레인 분리. 상단 레인: 근접 약점 적 / 하단 레인: 원거리 약점 적. Cat이 상단을, Onion이 하단을 커버. 낮은 벽은 Cat 슬래시 3회로 파괴 → 한쪽이 위기 시 벽 파괴해서 역할 교환 가능.
- **귀환 트랩 방** — Leash + Trap/Hazard 연계 응용: 스폰 위치 주변에만 가시 함정이 배치된 방. 적이 귀환하면 가시를 밟아 자멸. Cat이 적을 유인해 귀환 경로로 몰아넣는 전략. "함정을 역이용" 고급 전술 방. `EnemyLeash.OnReturnStart` 이벤트로 스폰 구역 함정 활성화 연결.

## 전투 (04_Combat)

- **유인 달성 시 팀 보너스** — Vagante 협동 + Leash Return 참고: Cat이 적을 리시 범위 밖으로 유인한 후 귀환하는 적을 Onion이 처치 시 "LURE KILL!" 팝업 + 추가 골드. `CombatEventBus`에서 "유인 시작" → "귀환 중 원거리 처치" 시퀀스 감지. 의도하지 않아도 나중에 발견하는 숨은 시스템.
- **커서 정밀도 = Onion 스킬 레벨 표현** — Cursor System + P2 조준 참고: Onion 업그레이드 "정밀 조준" 획득 시 커서가 십자선에서 작은 원 조준경으로 변경. 커서 모양 자체가 업그레이드 상태를 시각화. `CursorManager.Instance.SetGameplayCursor(upgradedTexture)`. 인벤토리 확인 없이 커서로 즉시 업그레이드 인식.
- **Has-Been Heroes 쿨다운 교대 = 넉백 연속** — 쿨다운 교대 리듬 참고: Cat 슬래시 → 적 넉백 → 넉백 중 Onion 투사체 명중 (넉백 상태에서 데미지 1.3배). 두 쿨다운의 교대 타이밍을 맞추면 시너지 보너스 발동. 타이밍: Cat 슬래시 후 0.3초 윈도우 내 Onion 투사체 명중 판정. `KnockbackState.IsActive()` 플래그로 데미지 배수 적용.

## 스토리 (05_Story)

- **Vagante의 부활 서사** — Vagante 협동 부활 메카닉 참고: 던전에서 죽은 용사들이 돌아오는 전설처럼, OnionCat 세계관에 "이 던전은 죽어도 돌아오는 자들의 전장"이라는 설정. 런 시작 시 짧은 텍스트: "또 왔군, 고양이. 몇 번째야?" 런 횟수가 쌓이면 NPC 대사가 달라지는 메타 서사. `RunManager.RunCount`를 저장해 첫 런 / 3회 / 10회 / 100회 분기.
- **Has-Been Heroes 서사 반전 적용** — "전성기 지난 영웅" 콘셉트 참고: OnionCat 세계관에서 Cat은 한때 전설적인 던전 클리어러였지만 어떤 이유로 기억을 잃었다는 설정 추가. 런이 반복될수록 Cat의 기억 파편이 코덱스에 쌓이는 구조. "나 여기 왔던 것 같은데..." Onion은 기억이 없는 Cat을 등에서 조용히 안내하는 존재.
- **리시로 표현하는 귀속의 서사** — Leash Return 메타포 응용: 적들이 스폰 위치로 귀환하는 행동을 "이 던전의 모든 존재들은 자기 자리로 돌아가려 한다"는 세계관 설정으로 승화. Cat과 Onion만이 자기 자리가 없어서 계속 앞으로 나아갈 수 있는 자들. 보스 처치 유언: "...넌 왜 돌아가지 않는거냐."

## 기술 메모

- **Enemy Leash Return System**: 구현 핵심은 `_spawnPosition`을 `Start()`에서 캐싱하는 것. `Awake()`가 아닌 `Start()`에서 해야 생성 위치가 확정된 후 저장됨. 리시 반경(8f)과 귀환 판정 반경(1.5f)을 `OnDrawGizmosSelected()`로 에디터에서 시각화하면 방 설계 시 설정이 훨씬 쉬워짐. OnionCat 권장: **무적 없는 귀환 + 귀환 중 데미지 2배** 조합이 "유인 전술"을 보상하는 최적 설계.

- **Cursor Lock & Visibility System**: 구현 순서: ①`CursorManager` 싱글턴 생성 (DontDestroyOnLoad) → ②게임플레이 씬 진입 시 `SetGameplayCursor()` 호출 → ③ESC 일시정지와 `SetMenuCursor()` 연결 → ④`OnApplicationFocus()` 포커스 복원. **주의**: 에디터와 빌드에서 `Confined` 동작이 다름 — 반드시 빌드 테스트로 확인. P2 조준 커서는 32×32 PNG, Texture Type=Cursor로 임포트 후 `CursorManager.gameplayCursor`에 드래그 앤 드롭 설정 필요 (유니티 에디터에서 설정).
