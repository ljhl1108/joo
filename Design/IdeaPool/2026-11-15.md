## 캐릭터 (01_Characters)

- **역할 경계 체크 항목** — Cadence of Hyrule 참고: 고양이 장비가 "원거리 추가", 작물 장비가 "근접 추가"되면 역할 경계가 흐려짐. 새 장비 추가 시 "이게 원래 역할 범위인가?" 체크리스트 필요. 고양이=이동+근접+내구, 작물=거리+스킬+지원 범위 유지를 의식적으로 지킬 것
- **공유 체력의 협동 체감 강화** — Cadence of Hyrule은 체력이 분리되어 "짐 되는 플레이어" 문제 발생. OnionCat 공유 체력은 반대 — 그런데 "누가 맞았는지 명확히 보이지 않으면" 협동 체감이 사라짐. 피격 시 화면 테두리를 플레이어 쪽 색(고양이=주황, 작물=초록)으로 번뜩이는 방향 색 vignette 추가 고려
- **패링 보상 강화** — Cadence의 "리듬 보너스는 선택제" = OnionCat의 "패링은 선택제". 지금 패링 반사 대미지만 있는데, 패링 성공 시 협동 콤보 게이지 보너스(+15%) 추가하면 "안 해도 되지만 하면 보람 있는" 느낌 강화

## 적 (02_Enemies)

- **커브 탄 보스 패턴** — Bezier 참고: 그림자 마녀 2페이즈에서 현재 직선/방사형 탄에 s자 커브 탄 추가 가능. `BezierUtil.Quadratic(spawnPos, controlPoint, playerPos + offset, t)` — 제어점을 플레이어 90° 측면에 두면 탄이 옆에서 꺾여 들어오는 느낌. 플레이어가 패턴을 읽기 더 어렵고 흥미롭게 됨
- **호를 그리며 착지하는 적 등장** — 보스 등장 연출: 화면 위 멀리서 적이 2차 베지어 경로로 호를 그리며 중앙에 착지하는 연출. 1초 내외, `IEnumerator MoveAlongCurve` 적용. 단순한 위→아래 대신 화면 밖 옆에서 호를 그려 중앙으로 들어오면 더 역동적
- **추적 커브 소형 적** — 작은 적이 직선 추적 대신 s자로 흔들리며 접근하는 패턴. `controlPoint = midpoint + perp * sin(Time.time * 2f) * 1.5f`처럼 제어점을 흔들면 같은 베지어인데 계속 다른 궤적 → 회피 패턴이 단조롭지 않음

## 맵·런 구조 (03_Maps)

- **방 입장 연출 카메라 베지어** — 그려진 방(PaintedRoom)에 들어갈 때 카메라가 출입구 위치에서 방 중앙으로 호를 그리며 이동. `BezierUtil.Quadratic(doorPos, midpoint + Vector3.up, roomCenter, t)` 0.4초. 직선보다 "안으로 들어가는 느낌" 강화
- **처음 방문 vs. 재방문 힌트 분리** — Tutorial Seen-State 참고: 첫 판에만 갈림길 지도 사용법 힌트 표시, 두 번째 판부터는 조용히. `TutorialManager.TryShow(TutorialHintId.MapIntro, "상의해서 길을 고르세요")` RunFlowManager에서 지도 첫 열림 시
- **등대탑 방에서 카메라 올라가기** — 등대탑은 위로 올라가는 구조인데, 방 전환 시 카메라가 베지어 경로로 "위쪽으로 호를 그리며" 이동하면 "탑을 오른다"는 느낌 강화. `controlPoint = mid + Vector3.right * 3f` 처럼 약간 가로로 흔들어서

## 전투·협동 (04_Combat)

- **처음 세트 보너스 활성화 힌트** — Tutorial Seen-State 참고: 세트 보너스 2단계 첫 충족 시 `TutorialManager.TryShow(TutorialHintId.SetBonusActivatedFirst, "같은 세트 2개! 세트 효과가 활성화됩니다")`. 말하는 책이 말풍선으로 알려주는 연출. 단 한 번만 나오고 다음 판부터는 조용히
- **커브 씨앗 탄 장비 효과** — Bezier 참고: `GearEffect` 중 "씨앗 탄이 목표를 추적해 꺾임" 효과 — `CurvingProjectile.Init(start, controlPoint, enemyPos, 0.4f)` 한 줄로 구현 가능. 발사 시 제어점은 플레이어와 적의 중간에서 90° 오프셋. 작물 마법서 효과로 적합
- **합동기 첫 발동 힌트** — 합동기 게이지 100% 첫 도달 시 양쪽 플레이어에게 버튼 프롬프트 말풍선 (런 내 1회). "게이지 가득! 고양이 RB, 작물 Space를 같이 누르세요". 이후 판부터는 HUD의 버튼 아이콘만

## 아이템·세트 (05_Items)

- **커브 탄 작물 고유기** — 새 작물 고유기 R 아이디어: "씨앗을 최대 3개까지 충전해 한꺼번에 커브 궤적으로 발사". 베지어 경로 3개가 같은 목표를 다른 각도로 감싸서 들어감 — 범위 넓은 대신 단발보다 느림
- **작물 소개 힌트 카드** — 첫 판에서 작물 고르기 화면에서 "이번 판 처음 고르는 작물" 선택 시 한 줄 소개 말풍선 (런 내 1회). 해바라기: "빛 탄, R=햇빛 회복". 이미 본 작물은 말풍선 없음. TutorialSeenData 런 내 세트로 관리
- **Cadence 무기별 패턴 → 마법서 패턴 차별화** — Cadence에서 망치=무조건 넉백, 창=직선 2칸처럼 무기마다 패턴이 완전히 다름. OnionCat 마법서도 쿨타임/범위 외에 발동 방식이 달라야 함. 예: 1번 마법서는 "클릭 즉시 발동(빠르지만 범위 좁음)" / 2번은 "0.3초 차지 후 발동(느리지만 넓음)" / 3번은 "쓸 때마다 위치 옮김"

## 스토리·메타 (07_StoryMeta)

- **말하는 책이 튜토리얼 힌트 전달자** — Tutorial Seen-State 참고: 튜토리얼 힌트를 "말풍선으로 된 책의 말"로 전달. "낡은 책: 패링에 성공했군! 반사하면 적이 더 아파진다" 형식. 등불 옆에 서 있던 책이 힌트를 주는 연출 — 세계관과 자연스럽게 연결
- **처음 판 vs. 반복 판 대사 분기** — 책이 처음 판에만 긴 소개를 하고, 두 번째 판부터는 짧게 바꾸는 대사 분기. `MetaProgress.RunCount`를 보고 조건 분기. "처음 오는군... 이 땅은 밤에 먹혔다" vs. "다시 왔군. 이번엔 더 멀리 갈 수 있을까?"
- **Cadence 스타일 오픈 월드 느낌** — Cadence에서 고정 위치(던전·마을)는 항상 같고 사이가 무작위. OnionCat에서 고정 장소(농장·마을·등대)는 항상 같고 사이 전투방이 무작위 — 이미 같은 구조. 더 나아가 "마을 등불의 위치를 항상 같은 자리에" 고정하면 플레이어가 익숙해질수록 길 찾기가 편해짐 → 성장감 강화

## 기술 메모

- **Bezier Spline Path**: 그림자 마녀 2페이즈 패턴 추가에 즉시 적용 가능. `BezierUtil` 정적 클래스 하나만 추가하면 됨 (의존성 없음). 가장 쉬운 적용: `CurvingProjectile` 컴포넌트를 보스 패턴 하나에 써보고 느낌 확인 후 확장
- **Tutorial Seen-State Persistence**: `MetaProgress.data`에 `List<string> tutorialSeen` 필드 하나 추가, `TutorialManager` 싱글턴 추가 — 이틀 작업. 힌트 ID는 enum으로 관리해 오탈자 방지. 반드시 `meta.json` 테스트 전 백업 (기존 주의사항과 동일)
