## 캐릭터 (01_Characters)

- **인벤토리 배낭 비주얼** — Backpack Hero 참고: Onion이 등에 달린 화분 속 씨앗 슬롯을 시각적으로 표시하는 UI 추가. 런 중 최대 3개 씨앗 타입 장착 가능, 배치 순서에 따라 조합 보너스 발동 (구현: ScriptableObject 씨앗 슬롯 배열 + 인접 시너지 딕셔너리)
- **루프 기반 고양이 능력** — Loop Hero 참고: Cat이 같은 구역을 두 번 지나갈 때 "순환 강화" 발동 (동선을 인식하는 타이머로 구현, 시계방향 순환 시 공격 속도 +20%)
- **Ghost 리플레이 Cat** — Run Replay 참고: 게임오버 화면에서 반투명 고양이/어니언 ghost가 마지막 10초를 재연. 두 플레이어가 자신의 실수를 함께 보며 웃는 경험 → 게임 재구동 동기 부여

## 적 (02_Enemies)

- **박격포 고블린** — 포물선 투사체 참고: 멀리서 포물선 폭탄을 던지는 적. 착탄 0.5초 전 바닥에 빨간 원 경고 표시. 근접 공격 무효(투명 방어막), 폭탄 자체는 Onion의 원거리로 공중에서 요격 가능 → 두 플레이어 역할 강제 분담
- **벽 뒤 저격수** — 포물선 투사체 참고: 낮은 벽(반타일 높이) 뒤에 숨어 포물선 화살을 날리는 적. Cat이 달려가서 벽을 파괴하거나 Onion이 포물선 씨앗으로 벽 너머 타격 필요. 메카닉 약점: 포물선 원거리에만 적중
- **루프 추적자** — Loop Hero 참고: 플레이어 동선을 기억해 이전에 플레이어가 있었던 위치를 반복적으로 순찰하는 적. "플레이어가 자주 다니는 길목 차단" 패턴. AI: 최근 5초 플레이어 위치 로그 기록 후 그 경로를 역방향 순찰

## 맵 (03_Maps)

- **타일 인접 보너스 방** — Loop Hero 참고: 상점 방과 치유 방을 인접 배치하면 "공생 구역" 보너스 발동 → 치유량 +30%, 상품 할인 10%. 플레이어가 의식적으로 방 탐색 순서를 전략적으로 고르게 유도
- **씨앗 밭 바이옴** — Backpack Hero + 포물선 참고: Onion의 씨앗이 바닥에 떨어지면 자라는 식물 장애물 생성. 특정 방에서는 이미 식물이 자라 있어 근접 이동 방해 → Cat이 베면 치유 효과, Onion의 물 씨앗이 닿으면 덩굴로 적 속박
- **루프 복도** — Loop Hero 참고: 하나의 긴 복도가 원형으로 이어지는 특수 방. 한 바퀴 돌 때마다 적 강도 상승 + 드롭 보너스 상승. 탈출구는 중앙에 있는 문 → 언제 탈출할지 결정하는 리스크/리워드 판단

## 전투 (04_Combat)

- **포물선 패리** — 포물선 투사체 + 패리 참고: Onion의 방어막(Shield)이 포물선 투사체도 패리 가능. 일반 직선 투사체보다 타이밍이 1.5배 넉넉 (더 느리게 날아오므로). 패리 성공 시 되돌아가는 포물선이 적 위에서 폭발하여 광역 피해
- **씨앗 배치 → 근접 연계** — Backpack Hero 인접 시너지 참고: Onion이 독 씨앗을 바닥에 심고, Cat이 그 씨앗을 밟고 지나가면 Cat의 다음 공격에 독 추가 피해 부여. 두 플레이어의 물리적 동선이 시너지를 만드는 메카닉
- **리플레이 보너스** — Run Replay 참고: 이전 런에서 사망한 정확한 패턴(적 타입, 방 번호) 데이터를 저장하고, 다음 런에서 같은 방 진입 시 "지난번에 여기서 죽었어요" 힌트 표시. 학습 루프 강화

## 스토리 (05_Story)

- **야영지 성장 서사** — Loop Hero 메타진행 참고: Onion이 씨앗을 모아 게임 기지(화분 마을)를 키우는 메타 스토리. 건물마다 NPC가 생기고 짧은 대사로 세계관 전달. 첫 빌드: 텃밭 → 주민 등장 → "예전엔 이 땅에 어니언들이 가득했는데…"
- **배낭 속 편지** — Backpack Hero 인벤토리 참고: Cat의 배낭(화분) 속에 숨겨진 메모 조각을 런마다 하나씩 발견. 퍼즐 조각처럼 모이면 Onion과 Cat이 어떻게 하나의 몸이 됐는지 과거 서사 완성
- **리플레이 유령** — Run Replay 참고: 죽은 런의 고양이 ghost가 다음 런에 잠깐 나타나 선행 정보를 줌 ("저 방에서 조심해!"). 메타-내러티브로 로그라이크 반복성에 스토리 의미 부여

## 기술 메모

- **포물선 투사체**: 초보 개발자에게는 Rigidbody2D + 물리 방식보다 **Lerp + Sin 아치** 방식을 강력 권장. 물리 없이도 자연스럽고 제어가 예측 가능. `arcHeight * Mathf.Sin(Mathf.PI * t)` 한 줄이 핵심. LineRenderer 미리보기까지 구현하면 협동 커뮤니케이션 도구로도 활용 가능.

- **런 리플레이 시스템**: 입력 로그 방식은 피하고 **오브젝트 위치 스냅샷** 방식으로 구현. 0.1초 간격 × 15초 = 150개 구조체 → 메모리 부담 거의 없음. 구현 순서: ① Recorder 클래스로 Queue에 스냅샷 쌓기 → ② 게임오버 시 배열로 보관 → ③ ghost 오브젝트 위치 Lerp 재생. 파티클/사운드 재현은 선택사항.
