## 캐릭터 (01_Characters)

- **봇 솔로 모드** — Tandem 참고: 2인 플레이어가 없을 때 고양이 AI가 단순 추적(가장 가까운 적으로 이동 + 주기적 할퀴기)으로 혼자 플레이 가능하도록 구현. 완전히 새 모드 추가 아니어도 "봇 플레이어 Cat" 클래스를 `BotPlayerCat`으로 만들면 솔로 플레이 가능성 + 밸런스 테스트 양쪽에 활용
- **해금 캐릭터 티저** — Fight'N Rage처럼 클리어 보상으로 작물 종류가 하나씩 해금되는 것 외에, 나중에 "고양이 스킨/종류" 추가 시 처음 클리어한 플레이어에게 특별 태그 부여 → 메타 진행 `MetaProgress`에 `catVariantsUnlocked` 목록 추가로 준비 가능
- **쌍둥이 캐릭터 조합** — Fight'N Rage의 1P·2P가 같은 캐릭터를 고를 수 있는 것처럼, 미래에 작물을 양파/해바라기/버섯으로 고르면 각 작물의 고유기 R이 달라지는 것에 더해 "고양이 + 같은 작물 2회 고르면 보너스" 세트 효과 아이디어

## 적 (02_Enemies)

- **동적 엘리트 등장 — AI Director 연동** — 현재 `EnemyRoster.ResolveRoom`이 고정 로직. `DirectorMetrics.StressLevel`을 추가해 "최근 2방에서 무대미지 클리어했으면 다음 방에 엘리트 1마리 추가" 규칙 적용. `GameManager.Run`에 RunData 접근 가능하니 HP%만 써도 단순 버전 구현 가능
- **패링 보상 적** — Tandem의 "빛이 없으면 위험" + Fight'N Rage의 "패링 하면 적 무방비" 조합: 특정 적은 정면 공격이 반사(노란 불빛), 양파가 패링하거나 고양이가 등에 접근해야 대미지 가능 → 기존 방패 근위병 `Shield Guard`의 변형으로 "전방위 반사 버블 → 패링 or 등공격" 로 간단히 추가
- **그림자 적 — 감지 불가 연출** — Tandem의 그림자 역학에서 힌트: 등장 시 화면을 어둡게 하고 실루엣만 보이다가 갑자기 나타나는 연출을 가진 적. `ShadowWitch` 보스 전에 등장하는 소형 그림자 하수인 → `EnemyBuilder`에 `isShadowType` 플래그로 임포트 설정 조절

## 맵·런 구조 (03_Maps)

- **방 난이도 버퍼 — Stress 기반 조절** — AI Director 개념: `DungeonManager.stagePlan`의 방 tier가 현재 고정. 최근 2방에서 대미지 50 이상이면 다음 방의 tier를 1 낮추는 간단한 완충 로직. `RunData`에 `recentRoomDamage` 슬라이딩 평균 2~3줄로 추가 가능
- **휴식 방 보장 간격** — Fight'N Rage는 긴 스테이지 중간에 체력 아이템이 흩어짐. OnionCat에서 3방 연속 전투방이면 휴식·보물방 1개를 보장 삽입 (`DungeonManager.stagePlan` 생성 로직에 `forcedRestInterval` 조건 추가)
- **경로 분기 선택 UI** — Fight'N Rage의 "상·하 경로 선택 화면"처럼, 다음 방이 여러 테마 중 하나를 고를 수 있는 갈림길 노드를 `RunMap`에 추가. 현재 `RunMap`은 이미 갈림길 지도를 구현해 있으므로, 선택지 2개의 "다음 방 테마 미리보기 아이콘"만 UI에 추가하면 됨

## 전투·협동 (04_Combat)

- **저글·공중 콤보 창 보정** — Fight'N Rage의 저글 시스템 참고: 고양이 할퀴기로 적을 소형이면 약간 뜨게(Launch 작은 버전) → 양파가 씨앗으로 공중에서 추가 타격 → 협동 콤보 판정. `Launch` 함수에 `isJuggle` 플래그 추가, 공중 상태에서 양파 씨앗이 맞으면 협동 콤보 보너스 2배 → "저글 콤보" 연출
- **쌍둥이 스위치 → 빛 기믹 퍼즐** — Tandem의 "Emma가 빛으로 발판 만들기" → OnionCat 2인 기믹 방 아이디어: 양파가 씨앗으로 "조명 오브젝트"를 쏴 그림자가 생기고, 고양이가 그림자 발판 위로 이동해 높은 곳의 스위치에 접근. 현재 쌍둥이 스위치보다 양파 조준 역할이 강조되는 비대칭 기믹
- **패링 연쇄 보너스** — Fight'N Rage의 패링→무방비 창을 연속 2회 이상 패링하면 "PERFECT PARRY" + 협동 게이지 추가 충전. 현재 `Parry +10` 고정인 것을 "연속 패링 횟수 × 5" 보너스로 변경 (최대 25) → 패링에 대한 고숙련자 보상

## 아이템·세트 (05_Items)

- **봇 테스트용 장비 조합 고정 세트** — 밸런스 시뮬레이션 적용: `OnionCat > Debug > Run Simulation`에서 특정 장비 조합을 100회 돌려 클리어율 확인하는 에디터 메뉴. `ContentBuilder`에서 세트 10개를 순회하며 클리어율 비교 → "풍력 세트 8단계가 OP다"를 수치로 확인
- **저글 연동 장비 효과** — Fight'N Rage의 저글 콤보에서 힌트: "공중에 뜬 적을 때리면 추가 대미지" `GearEffect` 추가. `EnemyBase.isAirborne` 플래그 → `OnDamage`에서 체크 → 대미지 1.5×. `EnemyBuilder`에 `supportsJuggle: true` 플래그로 소형 적에만 적용
- **패링 반응 세트 연동** — Fight'N Rage의 패링 무방비 창과 현재 Wind 세트의 "패링 후 공격력 상승"을 더 직접적으로: "패링 성공 시 2초간 적 받는 대미지 +30%" 효과가 있는 장신구 추가 → 협동에서 양파가 패링 → 고양이가 집중 공격하는 역할 분담 강화

## 스토리·메타 (07_StoryMeta)

- **동적 대사 — 플레이 스타일 감지** — AI Director 개념 응용: 패링을 많이 한 런이면 "낡은 책"이 "용감하게 막아냈구나" 대사, 대미지를 많이 받으면 "많이 힘들었겠어" 대사. `MetaProgress` 혹은 `RunData`의 통계를 보고 `StoryLines.cs`가 대사 선택 → 플레이 경험이 대사에 반영되는 느낌
- **보스 도움 이벤트 — 그림자 마녀 복선** — Tandem의 "빛이 없는 위험 공간" 모티프: 그림자 마녀 `ShadowWitch` 등장 전 1~2개 방에서 화면 가장자리가 조금씩 어두워지는 연출(URP 2D global light intensity 감소) → 보스 등장을 직관적으로 예고. 플레이에 영향 없는 순수 연출, Shader 대신 간단히 `GlobalLight2D.intensity`를 `Coroutine`으로 조절
- **클리어 후 Director 리포트** — 개발자 전용 디버그 화면: 런 종료 후 `OnionCat > Debug > Show Run Director Report`로 "이번 런에서 Director가 몇 번 개입했나, 평균 Stress 최고점" 표시 → 플레이어 경험 품질을 수치로 확인

## 기술 메모

- **AI Director**: 즉시 적용 가능 범위 — `EnemyRoster.ResolveRoom`에 `currentHpPercent < 0.4f`이면 엘리트 등장 확률 절반으로 낮추기 (5줄 이내). 본격 Director는 `DirectorMetrics` 클래스 추가 후 `DungeonManager`에서 호출
- **자동화 밸런스 시뮬레이션**: 구현 순서 — ① 런 종료 시 `Debug.Log` 한 줄 (HP%, cleared, time) → ② 에디터 메뉴 "10회 반복 + CSV 출력" → ③ Python으로 장비별 클리어율 분석. ①은 하루면 가능, ③은 첫 100회 데이터가 나온 뒤 필요 시 작성
