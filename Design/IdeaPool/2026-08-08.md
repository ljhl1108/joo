## 캐릭터 (01_Characters)

- **"분노의 일격" 저주 능력** — Curse System 참고: Cat의 체력이 20% 이하일 때 근접 데미지 3배가 되지만 체력 회복 불가. 고위험 플레이 스타일을 선택하는 재미 + 역전의 카타르시스 제공. Cat 전용 저주 업그레이드로 구현.
- **"관통의 가시" 저주 탄환** — Colt Canyon + Curse System 참고: Crop의 탄환이 벽과 적을 관통하지만 탄속 50% 감소. 플레이어가 적 이동 예측 사격을 연습하게 만드는 고급 업그레이드. 탄환 속도 값을 ScriptableObject에서 조절.
- **"교대 충전" 공유 저주** — Curse System 참고: Cat이 적을 처치하면 Crop의 실드가 충전되고, Crop이 처치하면 Cat의 대시가 충전됨. 두 플레이어의 분업을 기계적으로 강제하는 저주 → 협력 시너지를 만드는 디자인 실험.

## 적 (02_Enemies)

- **"방어막 적" — 근접 전용 파괴** — Colt Canyon의 무기 타입 분업 참고: 원거리 탄환을 튕겨내는 방어막을 두른 적. Cat이 근접 슬래시로만 방어막 파괴 가능, 파괴 후 Crop이 원거리로 마무리. 두 플레이어의 협력 시퀀스를 자연스럽게 유도.
- **"세계 부패 적" (커럽트 몬스터)** — Swords of Ditto의 세계 영속성 참고: 런 결과에 따라 다음 런에서 더 강해지는 적 변종. 이전 런에서 처치하지 못한 엘리트 적이 다음 런에서 강화 버전으로 등장하는 메타 진행 요소.
- **"폭발 드럼통 운반 적"** — Colt Canyon의 환경 상호작용 참고: 폭발물을 들고 돌진하는 적. Cat이 대시로 적을 쳐서 돌진 방향을 바꾸거나, Crop이 원거리로 폭발물을 미리 터뜨릴 수 있음. 두 플레이어가 전술적으로 처리해야 하는 복합 적.

## 맵 (03_Maps)

- **"미니멀 UI 방"** — Colt Canyon의 미니멀 디자인 참고: 특정 챌린지 방에서 HUD가 숨겨지는 모디파이어 조건. 적 HP 바, 플레이어 HP 숫자가 사라지고 피격 시 화면 flash만으로 상황 파악. 긴장감과 몰입감 극대화.
- **"세계 상태 변화 비주얼"** — Swords of Ditto의 세계 영속성 참고: 런 클리어 횟수에 따라 배경 타일·조명이 변화하는 시각적 피드백. 초반 런은 황폐한 색감, 클리어 후 런은 채도 높은 색감 → URP 2D Light로 전체 조명 색조 제어.
- **"파괴 가능 오브젝트 방"** — Colt Canyon의 지형 파괴 참고: 방에 배치된 폭발 드럼통, 독가스 항아리 등 파괴 가능 오브젝트. Cat이 대시로 밀치거나 Crop이 투사체로 폭파. 전략적 공간 활용과 방 레이아웃 다양성 증가.

## 전투 (04_Combat)

- **"저주 업그레이드 선택의 고민"** — Curse System 핵심: 업그레이드 선택 화면에서 강력하지만 페널티 있는 저주 카드를 빨간/보라 틴트로 명확히 구분. "이 저주를 받을 만큼 이 혜택이 가치 있는가?"라는 전략적 결정 순간. 초보자에게는 일반 업그레이드만, 고급자는 저주 카드 선택.
- **"Pact of Punishment 방식 챌린지"** — Custom Run Modifier 참고: 런 시작 전 "대시 봉인", "실드 봉인", "적 체력 2배" 중 선택하면 클리어 시 추가 보상(특수 코인, 스킨)을 얻는 시스템. 메타 진행의 후반 동력으로 활용.
- **"무기 타입 약점 시각화"** — Colt Canyon + Swords of Ditto 참고: 근접 약점 적 머리 위에 검 아이콘(빨강), 원거리 약점 적에 화살 아이콘(파랑) 표시. 플레이어가 즉시 어느 역할이 공격해야 할지 파악. 아이콘은 월드 스페이스 Canvas로 구현.

## 스토리 (05_Story)

- **"이전 영웅의 무덤"** — Swords of Ditto의 세계 영속성 참고: 이전 런에서 사망한 위치에 작은 묘비 오브젝트가 생성. 묘비에는 "고양이 #7 — 3번 방에서 쓰러짐" 같은 메시지. 죽음을 서사로 만들어 퍼마데스의 무게감을 부여.
- **"세계를 구하는 영웅의 계보"** — Swords of Ditto 참고: 매 런마다 다른 Cat&Crop 듀오가 Mormo(최종 보스)에 도전한다는 설정. 메인 메뉴 화면에 현재 영웅 이름과 이전 런 영웅 이름이 기록되는 "명예의 전당" 미니 기능.
- **"저주받은 유물의 전설"** — Curse System 스토리 연계: 강력하지만 저주받은 업그레이드 아이템에 개별 로어(배경 스토리) 텍스트 추가. "옛 전사가 이 발톱을 끼었을 때 무적이 되었지만 스스로를 다치게 했다." → 아이템이 단순 스탯이 아닌 세계관의 일부가 됨.

## 기술 메모

- **Curse/Downside System**: `CursedUpgradeData`는 기존 `UpgradeData`를 상속만 하면 되어 구현이 쉬움. 핵심은 선택 UI에서 저주 카드를 **빨간/보라 틴트 + ⚠ 아이콘**으로 명확히 구분해 플레이어가 의식적 선택을 내리게 하는 것. 저주 효과를 `StatModifier` 패턴으로 처리하면 기존 스탯 시스템과 자연스럽게 연동됨.
- **Custom Run Modifier System**: `RunSessionManager`를 `DontDestroyOnLoad`로 만들어 씬 전환 후에도 선택된 모디파이어 목록이 유지되게 하는 것이 핵심. 모디파이어 효과는 게임씬 진입 후 각 시스템(PlayerController, EnemySpawner 등)에서 `RunSessionManager.Instance.HasModifier(type)` 체크로 분기 처리. 처음에는 2~3개 단순 모디파이어("대시 봉인", "적 체력 2배")부터 시작해 점차 늘릴 것.
