## 캐릭터 (01_Characters)

- **"협동 전용 강화" 패시브 장비** — Across the Obelisk 크로스 시너지 참고: "고양이가 이 런에 걷어차기를 N번 성공하면 양파 씨앗 데미지 +X%" 같이 두 플레이어가 모두 잘 해야 발동하는 장비 효과. 혼자 하는 것보다 둘이 하는 게 명확히 강해지는 인센티브
- **할퀴기 변형 × 마법서 시너지 아이템** — 특정 ClawStyle(예: 도약 할퀴기)과 특정 OnionSkill(예: 포자 구름)이 함께 있을 때 발동하는 세트 효과. 빌드마다 전혀 다른 플레이 스타일이 나오도록 유도
- **레벨업 연출 개선** — 같은 장비 2번째 획득(레벨업) 시 "LEVEL UP!" 팝업이 더 크게 터지도록. 레벨이 높을수록 연출 강도 증가 → 성장감 직접 전달

## 적 (02_Enemies)

- **"셋업-트리거" 적 쌍** — Across the Obelisk의 크로스 히어로 시너지에서 영감: 한 적이 필드에 폭발 지뢰를 심고, 다른 적이 고양이를 그쪽으로 밀어내는 패턴. 두 적 사이의 연계를 끊는 것이 전략 포인트
- **방패 근위병 변형: "방패 회전" 패턴** — 현재 방패병은 정면 차단. 변형으로 "360° 방패를 빠르게 회전시키다가 짧은 순간 등이 노출"되는 패턴 추가. 팀워크로 타이밍을 잡는 재미
- **적 소환사** — 슬라임을 3~4마리 소환하고 자신은 필드 끝에서 버티는 적. 먼저 소환사를 잡으려면 슬라임을 헤치고 들어가야 함 → 고양이 돌진 + 양파 원거리의 역할 분리가 자연스럽게 유도됨

## 맵·런 구조 (03_Maps)

- **"공동 의사결정" 이벤트 방** — Across the Obelisk의 비전투 결정 메커니즘 참고: 방 안에 선택지 2~3개 아이콘이 떠 있고, **고양이가 발판을 밟아 하이라이트하면 양파가 클릭해서 선택**하는 방. 둘이 동의해야 선택이 확정 → 소통 강화
- **런 내 "보스 사전 정보" 방** — 보스 방 직전에 보스의 공격 패턴 1~2개가 미리 표시되는 짧은 컷씬/UI. Across the Obelisk의 "이벤트 정보 공유" 방식에서 영감. 처음 보는 보스를 첫 시도에 맞닥뜨리는 피로감 감소
- **방 난이도 표식 개선** — 현재 다음 방을 고르는 표식에 RewardAxis만 표시. 거기에 "적 종류 아이콘 1~2개"도 함께 표시하면 전략적 선택이 가능해짐

## 전투·협동 (04_Combat)

- **"콤보 킬 보너스"** — 협동 콤보 상태(COMBO! 표시 중)에서 적을 처치하면 합동 게이지 추가 충전. Across the Obelisk에서 파티 시너지로 적을 처치할 때 보너스가 쌓이는 것처럼, 팀플레이 보상을 더 명시적으로
- **박(gourd) × 기절 상태 시너지** — 기절한 적에게 박이 닿으면 일반 폭발보다 큰 "SUPER EXPLOSION" + 추가 데미지. 양파가 포자 구름(기절)을 깔고, 고양이가 적을 박 쪽으로 차는 2단 콤보가 더 강해짐
- **패링 성공 시 "준비 시간 제공"** — 패링 직후 0.3초간 합동 게이지 충전 속도 2배 또는 고양이의 다음 공격력 +50%. 패링 성공에 대한 즉각적 보상 → 양파 플레이어가 패링을 더 적극적으로 시도하게 유도

## 아이템·세트 (05_Items)

- **"전설 장비" 첫 번째 후보: "화합의 리본"** — 장착 플레이어 무관, 둘이 동시에 버튼을 누를 때(합동기 입력 타이밍) 성공하면 합동 게이지가 100%에서 시작. 협동의 상징적 아이템
- **GearEffect ScriptableObject 시스템 도입** — 현재 장비 효과가 코드에 하드코딩돼 있다면, 각 효과를 독립 SO 자산으로 분리. 새 장비를 코드 수정 없이 Inspector에서 조립 가능 → 빠른 컨텐츠 추가
- **"분해 씨앗 활용" 상점 아이템** — 현재 분해된 효과를 휴식 정원에서 갈아끼는 것 외에, **상점에서 씨앗 30개로 효과 1개를 다른 효과로 교환**하는 옵션 추가. 빌드 유연성 향상, 씨앗 소비처 추가

## 스토리·메타 (07_StoryMeta)

- **Steam Remote Play Together 태그 활성화** — 스토어 페이지에 "Remote Play Together" 추가. "친구가 게임을 안 사도 같이 플레이 가능"을 마케팅 포인트로 활용. 패드 2개 조합 권장, 마우스 조작 제한 사항 UI 안내 추가
- **"첫 런 완주 도전과제"** — 처음 보스를 클리어하면 잠금 해제되는 코스메틱(고양이 모자 색상 등). Across the Obelisk의 "첫 클리어 보상" 구조에서 영감. 목표 의식 부여
- **런 결과 화면에 "협동 기여도"** — 런 결과에 "고양이 딜 기여 X% / 양파 딜 기여 X% / 협동 콤보 N회" 표시. 이미 `Coop_Contribution_Stats_Screen.md`에 기술이 정리돼 있음 → 구현 우선순위 올리기 검토

## 기술 메모

- **장비 효과 런타임 캐싱**: `PlayerStats.Current`에 더티 플래그 패턴 적용이 핵심. 장비 변경 시 `Invalidate()` 호출, 스탯 접근 시에만 재계산. Flat → Additive % → Multiplicative 순서를 코드 한 곳에 고정해두면 기획 조정이 쉬워짐. `GearEffect` 추상 ScriptableObject 도입으로 새 효과를 코드 수정 없이 추가 가능
- **Steam Remote Play Together**: Unity New Input System과 호환 미지원이 핵심 장애물. OnionCat의 마우스 기반 양파 조작이 Remote Play에서 작동 안 할 가능성 높음. 단기적으로는 Steamworks 포털 체크박스만 활성화하고, 패드 2개 조합만 공식 지원으로 안내. New Input System 호환 패치 나오면 재검토
