## 캐릭터 (01_Characters)

- **전설 장비: 런 방향 강제자** — Cobalt Core의 아티팩트가 덱 방향을 정해주듯, 전설 장비 1종이 "이 런은 무조건 햇살/바람 세트로 가야 한다"는 신호를 줄 것. 예: "불꽃 가죽 (전설) — 모든 공격이 화상을 부여하며, 햇살 세트 효과 단계가 +1 상승". 구현: `GearItem` 에셋에 `setStageBonus` 필드 추가, `PassiveHost.Recalculate`에서 합산.

- **Onion 무기: 공명 씨앗탄** — Cobalt Core의 크루원들이 같은 레인 공격을 겹쳐서 시너지를 내듯, Cat의 할퀴기 범위 안에 있는 적에게 Onion 씨앗탄이 명중하면 추가 피해(+50%). 협동을 의도적으로 유도하는 장비 효과. `GearItem` 효과로 구현, `TakeDamage` 시 `Attacker.Cat` 최근 피격 여부 체크.

## 적 (02_Enemies)

- **파워 스파이크 대응 적: 갑옷 슬라임** — 런 중반 이후에만 등장하는 변종. 방어막 2칸 보유, 할퀴기는 1칸씩만 깎음. "Cat가 먼저 방어막 깎고 → Onion이 약점 탄 쏘기" 협동을 자연스럽게 강제. 런 페이싱에서 전투방 2~3번차에 등장시켜 파워 스파이크 테스트 역할. `EnemyBase` 상속, `ShieldSlot` 컴포넌트 추가.

- **런 3스테이지 전용 엘리트: 이중 방패병** — 현재 방패병의 강화판. 방패 2개로 전면+측면 차단. 걷어차기로 먼저 방패 하나를 날려야 취약점 생김. "킥이 전략적으로 중요해지는" 엘리트. 구덩이 근처 방에서 등장 시 "날려서 낙사"가 가능해 CRASH → 낙사 순간이 극적.

- **Onion 스킬 퍼즐 적: 뿌리 수호자** — 이동 불가이지만 주변 3칸 범위 가시를 생성해 Cat를 못 다가가게 막음. Onion의 씨앗탄으로만 피해 가능 (Cat 근접 불가). "Onion이 주도하는 전투"를 가끔 만들어 역할 반전 경험 제공.

## 맵·런 구조 (03_Maps)

- **3스테이지 런 페이싱 확장** — 현재 1스테이지 구조를 3스테이지로 늘릴 때: 스테이지 1(습득기) → 스테이지 2(파워 스파이크+엘리트) → 스테이지 3(클라이맥스+보스). 각 스테이지 종료 시 "미니 보스 또는 난관 방" 삽입 → Roguelike_Run_Pacing_Design의 긴장-이완 곡선 유지. `DungeonManager.stagePlan` 문자열을 3세트로 확장.

- **긴장 고조 방: 봉쇄 방** — 입장 즉시 문이 잠기고 "N초 버텨라" 타이머가 생성되는 방 (무한 스폰). 방어 중심 플레이 유도. 런 페이싱에서 "보스 전 마지막 전투방"으로 배치하면 보스 진입 전 긴장 최고조. `RoomLayout`에 타입 플래그 추가, 타이머 전용 UI 구성.

- **이완 포인트 강화: 방 탐험 보너스** — 전투방 클리어 후 씨앗 드롭 외에, 방 구석에 숨겨진 "유물 단지" (파괴 시 랜덤 아이템 또는 씨앗 5~10개) 5% 확률로 배치. 탐험 동기 부여, 이완 포인트에서 "더 찾아볼 것"이 생김.

## 전투·협동 (04_Combat)

- **합동기 트리거 조건 확장: 세트별 합동기 효과** — Cobalt Core의 "아티팩트가 덱 시너지를 정한다"에서 영감. 세트별로 합동기 발동 시 추가 효과:
  - 햇살 4세트 달성 런: ONION STORM 중 화상 지속 시간 2배
  - 바람 4세트 달성 런: ONION STORM 종료 후 Cat 대쉬 칸 즉시 전부 회복
  구현: `RunData`에 현재 세트 달성 여부 캐싱, `JointUltimate` 발동 시 체크.

- **파워 스파이크 시각화: 세트 발동 연출** — 세트 2단계/4단계 달성 순간 화면 테두리가 잠깐 빛남 + HUD 세트 아이콘에 파티클. 런 페이싱에서 "내가 강해지는 순간"을 플레이어가 인식하게 해야 다음 전투에 임하는 자세가 달라짐. `PassiveHost.Recalculate` 후 이벤트 발행.

## 아이템·세트 (05_Items)

- **전설 장비 1호 후보: 공생의 꽃** (Onion 화분 슬롯) — "Cat와 Onion이 1초 안에 번갈아 공격할 때마다 화분에서 꽃잎이 생성, 10개 쌓이면 전체 적에게 자동 씨앗탄 발사." Cobalt Core의 "조합 보상" 개념. 협동 콤보를 적극 추구하는 플레이 스타일 강화. `GearItem` legendaryEffect로 구현.

- **세트 확장: 바람 6세트 아이디어** — 바람 세트가 현재 2/4단계만 있음. 6단계: "걷어차기 쿨다운이 2.5초로 단축되고, CRASH 피해가 2배." 바람 세트를 Cat 공격 특화 세트로 명확하게 정체성 부여. `PassiveHost`에 `windTier6` 케이스 추가, `KickAbility`에서 쿨다운 오버라이드.

- **장비 비교 힌트 UI** — 장비 선택 화면에서 현재 장착 중인 장비와의 수치 비교 (↑↓ 화살표). 선택 시 "이게 더 좋은지"를 직관적으로 파악하기 어려운 초반 문제 해결. `UpgradeSelectUI`에 현재 장착 중인 같은 슬롯 장비 수치와 diff 계산 로직 추가.

## 스토리·메타 (07_StoryMeta)

- **런 해금 리듬 설계: 첫 5런 계획** — Cobalt Core처럼 "런마다 하나씩 열리는" 해금 리듬. 초안:
  - 런 1: 기본 시작 (해금 없음, 게임 배우기)
  - 런 2 클리어: 바람 2단계 세트 해금 (야옹이 귀 머리 장비)
  - 런 3 클리어: 마법서 추가 해금 (포자 구름 → 새 책)
  - 런 5 클리어: 보스 변형 패턴 + 새 방 레이아웃
  단, 메타 진행 시스템(`Meta_Progression_System.md`) 구현 후에 추가.

- **Press Kit 체크리스트** — 개발 마무리 단계에 필요한 마케팅 산출물 목록:
  - [ ] 게임 로고 (투명 배경 PNG)
  - [ ] 스크린샷 8장 이상 (CRASH, 합동기, 장비 선택 포함 필수)
  - [ ] 60초 이하 트레일러 (OBS + DaVinci Resolve)
  - [ ] presskit() 페이지 구축
  - [ ] Steam 캡슐 아트 3종
  개발 완료 6개월 전부터 플레이테스트 때마다 좋은 장면 스크린샷 찍어두기.

## 기술 메모

- **Roguelike Run Pacing**: OnionCat의 현재 런 순서(시작→전투×4→이완×3→보스)는 구조적으로 건강함. 가장 빠른 개선은 **세트 발동 순간 연출** 추가 — 파워 스파이크를 시각적으로 보여줘야 플레이어가 "강해졌다"를 인식한다.

- **Press Kit**: 출시 전 최소 **스크린샷 8장 + OBS 클립 적립**이 목표. 지금부터 플레이테스트마다 "capture_game_view"로 좋은 장면 적립 권장. 트레일러는 알파 완성 후 DaVinci Resolve 무료 버전으로 충분히 제작 가능.
