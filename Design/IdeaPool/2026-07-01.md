## 캐릭터 (01_Characters)

- **협공 콤보 게이지** — Fury Unleashed 참고: 고양이(근거리)와 양파(원거리)가 교대로 적을 타격하면 "협공 콤보 카운터"가 증가, 50 달성 시 잠시 두 플레이어 모두 공격력 +30% 버프 발동. 혼자만 공격하면 카운터가 천천히 감소 → 협력 플레이를 자연스럽게 강요
- **기절 상태 부활 메커니즘** — Fury Unleashed 부활 시스템 참고: 한 플레이어가 HP 0 → 5초 내 다른 플레이어가 옆에서 특정 버튼을 길게 눌러 부활 가능. 부활 중 무적 아님(적이 방해 가능). 쉬운 난이도에서만 허용하는 설계로 차별화
- **쿨다운 공유 업그레이드** — 쿨다운 시스템 참고: "공명 인장" 업그레이드 — 고양이가 대시 쿨다운 중일 때 양파의 패링 쿨다운도 30% 감소(서로의 위기를 보완해주는 협력 아이템). 구현: 각 CooldownTimer에 이벤트 연결

## 적 (02_Enemies)

- **콤보 브레이커 적** — Fury Unleashed 콤보 시스템 대응: 협공 콤보 카운터를 특별히 빠르게 감소시키는 "방해꾼" 적 타입. 이 적이 살아있는 한 콤보 유지가 어려움 → 최우선 처치 대상이 되어 전투 우선순위 결정을 강제
- **난이도별 변종** — 난이도 시스템 참고: 어려운 난이도에서는 일부 기본 적이 추가 행동 패턴을 가짐 (예: 기본 근육맨 → 어려움에서는 쿨다운 없이 연속 돌격 2회). 별도 AI가 아니라 multiplier + 행동 플래그로 제어
- **부활 방해 적** — 부활 메커니즘과 연계: "기생충" 적 — 기절한 플레이어 주변에 붙어 부활을 방해하는 적. 제거하지 않으면 부활 불가. 협력 긴장감 극대화

## 맵 (03_Maps)

- **챕터 구조 차용** — Fury Unleashed 4챕터 구조 참고: OnionCat MVP 맵 구성안 = 3챕터 × (5전투방+1상점+1보스). 총 21방. 이보다 크게 시작하면 밸런싱 지옥 → 작은 스케일로 완성도를 먼저 확보
- **협공 전용 방** — Fury Unleashed 도전방 참고: 일반 전투방과 별도로 "협력 시험" 특수방 등장 (1~2개/챕터). 이 방에서는 근거리만 닿는 적과 원거리만 닿는 적이 동시에 스폰 → 클리어 시 고급 아이템 보상
- **난이도별 방 수 조정** — 난이도 시스템 참고: 쉬운 난이도는 전투방 4개 → 보스로 바로 이동, 보통은 5개, 어려움은 7개. 긴 런은 더 위험하지만 드롭 아이템도 더 많은 리스크-보상 균형

## 전투 (04_Combat)

- **대시 쿨다운 시각화** — 쿨다운 시스템 참고: 고양이 발 아이콘 UI에 원형 fillAmount 쿨다운 표시. 쿨다운 완료 시 아이콘이 잠깐 빛나는 이펙트 + 짧은 사운드로 "이제 쓸 수 있어!"를 직관적으로 전달 → 구현: Image(Filled) + DOTween 펄스 효과
- **패링 타이밍 창 연장 업그레이드** — 쿨다운+패링 시스템 결합: "양파의 집중력" 업그레이드 — 패링 무적 판정 시간 0.15초 → 0.25초로 연장, 대신 패링 쿨다운 +0.3초. 초보 플레이어가 선택하기 좋은 옵션
- **콤보 카운터 UI** — Fury Unleashed 참고: 화면 중앙 하단에 작은 콤보 숫자 표시. 평소에는 투명, 콤보가 5 이상 쌓이면 나타나고 50+ 시 빛남. Unity UI CanvasGroup 알파값으로 페이드 인/아웃

## 스토리 (05_Story)

- **만화책 메타 서사 응용** — Fury Unleashed 참고: OnionCat도 "양파와 고양이가 사실 게임 속 캐릭터임을 알고 있다"는 메타 연출 고려. 보스 대사: "넌 플레이어가 조종하는 게 느껴지지 않아?" → 4회차+ 플레이어에게 특별한 대사 공개. 초기 구현은 단순 텍스트 이벤트로 충분
- **난이도와 연동된 스토리 분기** — 난이도 시스템 참고: 어려움 모드 클리어 시 추가 엔딩 컷씬 해금. "진짜 위협을 이겨낸 이들만 보는 진실". 단, MVP에서는 텍스트 변경 수준으로만 구현
- **챕터 별 배경 이야기** — Fury Unleashed 챕터 구조 참고: 각 챕터 시작 시 짧은 텍스트 카드 (3-5줄). "2챕터: 지하 동굴 — 이곳은 빛을 잃은 지 오래된 땅. 양파는 씨앗을 찾아야 한다." DOTween으로 페이드 인/아웃 연출, 씬 전환 로딩 중 표시

## 기술 메모

- **쿨다운 & 타이머 시스템**: `CooldownTimer` 독립 클래스를 `Scripts/Utils/`에 먼저 만들고, PlayerCat/PlayerOnion 양쪽에 `private readonly CooldownTimer`로 붙이는 것이 핵심. `Progress` 프로퍼티를 UI Image.fillAmount에 바로 연결하면 쿨다운 UI가 1줄 코드로 끝남.
- **난이도 선택 화면**: ScriptableObject로 난이도 데이터를 분리하면 디자이너(또는 혼자 작업하는 개발자)가 코드 없이 밸런스 조정 가능. GameManager에 `DontDestroyOnLoad`로 선택값 유지하고, `EnemyBase.Start()`에서 GameManager 참조로 스탯 적용 — 구현 순서 그대로 따라가면 2-3시간 내 완성 가능.
