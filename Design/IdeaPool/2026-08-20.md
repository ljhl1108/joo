## 캐릭터 (01_Characters)

- **동시 행동 특수기 (Sync Skill)** — Ibb & Obb 참고: Cat과 Onion이 0.1초 이내에 동시에 기술 버튼 입력 시 특수 연계기 발동. 예: Cat 슬래시 + Onion 씨앗 동시 → "회오리 씨앗 폭풍" (전방 부채꼴 대미지). 구현: `InputManager`에서 두 플레이어 입력 타임스탬프 비교, 차이 ≤ 0.1f 이면 SyncEvent 발동
- **양파 눈물 산성 탄** — Turnip Boy 참고: Onion의 기본 투사체를 "양파 눈물(Onion Tear)"로 명명 + 시각화. 맞은 적에게 짧은 시간 슬로우 효과 (산성 눈물이 발을 잡음). 귀여운 시각 이펙트(눈물방울 파티클) + 기능적 가치. 구현: ProjectileData에 `slowOnHit: true`, `slowDuration: 0.5f` 필드 추가
- **색상 코딩 역할 표시** — Ibb & Obb 미니멀 UI에서 착안: Cat은 주황색, Onion은 초록색으로 모든 HUD 요소를 통일. 체력바 색, 쿨다운 링, 피격 플래시 색까지 동일 색상 사용 → 초보 플레이어도 즉시 "내 것" 구분 가능

## 적 (02_Enemies)

- **소환 마녀 (Summon Witch)** — Enemy Summon System 참고: 체력 75%, 50%, 25% 구간마다 소환 발동. 75%: 근접 전용 취약 병사 2마리 → Cat이 처리해야 함, 50%: 원거리 전용 저격수 1마리 → Onion이 처리해야 함, 25%: 두 종류 동시 소환 → 진정한 협력 테스트. 구현: `BossWithSummon.cs` 적용, `summonThresholds = {0.75f, 0.5f, 0.25f}`
- **채소 방패병 (Veggie Shield Guard)** — Turnip Boy 채소 테마 참고: 당근으로 만든 방패를 앞에 들고 있음. Cat의 슬래시가 정면에서 막힘 (Onion의 씨앗으로 뒤를 공격하거나, Cat이 돌아가야 처치 가능). 귀엽지만 위협적인 비주얼 → 세계관 통일성
- **분열 씨앗 (Split Seed)** — 소환 + 분열 복합 패턴: 처치하면 2개의 작은 씨앗으로 분열, 소형 씨앗은 원거리 전용 취약. Cat이 어그로 유인 + Onion이 소형 씨앗 처리하는 협력 구도. 구현: `OnDeath()` 에서 소형 씨앗 Instantiate 2개, `DamageType.Ranged`만 피해 받도록 설정

## 맵 (03_Maps)

- **동기화 문 (Sync Door)** — Ibb & Obb 두 플레이어 동시 조건 참고: 방에 버튼 2개가 양쪽에 있고, Cat과 Onion이 동시에 밟아야만 열리는 문. 한 명만 밟으면 안 열림 → 자연스럽게 소통과 이동 조율 필요. 구현: `DoorTrigger` 컴포넌트에 `requireBothPlayers: true` 옵션
- **소환진 방 (Summoning Circle Room)** — Enemy Summon System 참고: 방 바닥에 붉은 소환진이 있고, Cat이 슬래시로 소환진을 파괴하거나 Onion이 씨앗으로 막지 않으면 일정 시간 후 대량 소환 발동. 시각적 카운트다운(소환진이 서서히 밝아짐) → 긴장감 극대화
- **좁은 보호 통로** — Ibb & Obb 공간 분리 개념 참고: 통로 폭이 Cat만 들어갈 수 있는 구역 + 넓은 Onion 안전지대 구분. Cat이 좁은 통로에서 근접 처리, Onion이 넓은 곳에서 원거리 커버하는 공간 배치. 방 프리팹 타입 추가

## 전투 (04_Combat)

- **소환 저지 패리** — 패리 + 소환 시스템 연계: 적이 소환 모션 시작 시 0.5초 예고 연출 → 이 타이밍에 Onion이 패리(쉴드 올리기) 성공 시 소환 취소. "소환 방해 패리" → 협력의 보람을 극대화. 구현: SummonWithTelegraph 코루틴 중간에 ParryDetectedEvent 확인
- **채소 무기 테마** — Turnip Boy 참고: 런 중 획득 무기에 채소 테마 이름 적용. "마늘 폭탄 (Garlic Bomb)" = 범위 폭발 아이템, "고추 대시 (Chili Dash)" = 대시 강화, "당근 방어구 (Carrot Armor)" = 피해 감소 업그레이드. 귀여운 네이밍이 게임 분위기를 일관되게 유지
- **소환 카운터 킬** — 적이 소환한 하수인을 처치하면 보스에게 "반사 피해" 부여 (하수인이 보스와 연결된 마법진으로 연결된 설정). Cat/Onion이 하수인을 빠르게 처치할수록 보스 HP가 추가로 깎임 → 하수인 처치 동기 강화. 구현: `Minion.OnDeath()` → 소환자에게 `reflectDamage` 이벤트 발생

## 스토리 (05_Story)

- **처음 만남의 사고** — Turnip Boy의 황당한 세계관 + Ibb & Obb의 협력 필연성에서 착안: Cat이 가든 센터에서 양파 화분을 실수로 건드려 등에 달라붙는 바람에 동행이 시작됨. Onion은 처음엔 "날 내려놔!" 하지만, 던전을 헤쳐나가며 점점 파트너십을 인정.
- **채소 왕국의 비밀** — Turnip Boy의 채소 세계관 참고: OnionCat 세계에서 채소/식물이 의식을 가진 존재. 양파(Onion)는 사실 오래된 식물 왕국 왕족의 후예. Cat은 그 사실을 알면서도 처음엔 말 안 함 → 중반 이후 진실 공개로 서사 반전
- **소환 보스의 집착** — 소환 패턴과 스토리 연결: 소환 마녀 보스가 Cat과 Onion을 분리시키려는 동기를 가짐. "둘이 함께 있어서 강한 거야. 따로 떼어놓으면…" 대사 → 게임의 핵심 메카닉(공유 몸)이 스토리적으로 위협받는 구조

## 기술 메모

- **Enemy Summon System**: 소환 직전 1초 예고 이펙트가 핵심. 없으면 플레이어가 소환을 인식 못 해 협력 의미가 사라짐. `BossWithSummon.cs`의 `summonThresholds` = HP 25% 단위로 설정하면 자연스러운 페이즈 전환 느낌. 오브젝트 풀링 적용해야 소환 잦은 후반에 버벅임 없음.
- **Discord Rich Presence**: MVP에는 필수 아님. 게임이 어느 정도 완성된 후 마지막에 추가. 구현 순서: 개발자 포털 앱 생성 → SDK DLL을 `Assets/Plugins/`에 복사 → `DiscordManager.cs` 작성 → `DontDestroyOnLoad`로 씬 간 유지. 가장 중요한 것은 Discord 없는 환경 `try-catch` 처리.
