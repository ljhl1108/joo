## 캐릭터 (01_Characters)

- **합체 의식 강화 — 공유 HP 연출** — Cassette Beasts 참고: 퓨전 중 두 HP가 합산되는 시각 연출(HP바가 하나로 합쳐지는 애니메이션)이 "우리는 하나"라는 감각을 강화함. OnionCat에서 HP바 위에 고양이·작물 초상화를 함께 두어 "이건 둘의 체력"임을 명시하면 단순한 연속 사망 느낌을 줄일 수 있음. 구현: 체력바 UI에 고양이+작물 아이콘을 나란히 배치.

- **장비 교체 → 외형 변화 강조** — Cassette Beasts 참고: 카세트 조합이 바뀌면 외형이 완전히 달라져 "내 캐릭터"감이 강함. OnionCat에서 무기 장비 교체 시 무기 스프라이트만 바뀌는데, **머리 장비(모자/마스크)도 착용 아이템에 따라 뚜렷하게 달라지면** 성취감이 증가. 아트 과제 — 현재 머리 슬롯 장비 비주얼이 얼마나 뚜렷하게 차이나는지 확인 필요.

- **대쉬 스트레치 적용** — 스쿼시 앤 스트레치 참고: 고양이 대쉬 시작 프레임에 이동 방향으로 1.3~1.4× 스트레치를 0.08초 적용. 현재 대쉬는 무적 이동인데 발동 타이밍의 "빠져나가는 느낌"이 약함. `HitFeelSettings`에 `dashStretch` 항목 추가 후 조절. `CatArtRenderer`의 spriteRoot에 `SquashStretch` 컴포넌트 연결.

## 적 (02_Enemies)

- **속성 반응 콤보 → 협동 필요성 강화** — Cassette Beasts 참고: 불+공기=폭발처럼 두 속성이 조합되면 새 효과가 나왔음. OnionCat에서 **고양이의 "털뭉치(둔화)" + 작물의 "양파 심기(공격 지연)" 두 개가 같은 적에 동시에 걸리면 추가 효과**(예: 적이 얼어붙어 2초 완전 스턴)를 주면 "둘이 협력해야 나오는 콤보"가 생김. 현재 협동 콤보는 번갈아 치기뿐 — 상태이상 조합 콤보를 하나 추가하는 것이 협동 의미를 넓힘.

- **피격 squash 연출 개선** — 스쿼시 앤 스트레치 참고: 적이 맞을 때 현재는 hit flash(하얀 빛)만 있는데, 충격 방향으로 squash(0.65, 0.12s)를 추가하면 타격감이 증가. 특히 보스에게 큰 피해를 줄 때 더 강한 squash(0.4, 0.2s)를 주면 "이게 먹혔다"는 피드백이 명확해짐. `EnemyBase.OnDamaged`에서 `SquashStretch.OnHit(dir)` 호출.

- **보스 경직 연출** — Cassette Beasts 참고: 큰 피해를 입은 몬스터가 흔들리며 "충격받음" 연출을 함. 보스에게 한 번에 큰 피해가 들어갈 때(야성 특수공격 등) **전신 squash + 흔들림 + 화면 진동**을 조합하면 "하이라이트 순간"이 됨. 현재 보스는 Hitstop만 있음 — squash를 추가하면 더 강렬.

## 맵·런 구조 (03_Maps)

- **보스 클리어 squash-stretch 연출** — 보스 HP 0이 되는 순간 보스 스프라이트가 커졌다 작아지며(1.4×→0, 0.3s) 사라지면 "명확한 사망 연출"이 됨. 현재 보스 사망이 어떤 연출인지 확인 필요 — 단순 Fade면 squash 추가로 쉽게 개선 가능.

- **방 클리어 후 플레이어 설문 타이밍** — 설문 시스템 참고: 보스방 클리어가 자연스러운 "감정 고조" 타이밍. "이 보스 어려웠나요? (매우 쉬움~매우 어려움)" 한 문항을 보스 클리어 화면에 띄우면 밸런스 데이터가 자동으로 모임. 스테이지 1·2·3 보스별로 다른 `questionId` 사용.

- **런 경로 선택 squash 피드백** — 갈림길 지도에서 방향을 선택할 때 선택한 버튼이 squash(납작해졌다 복원)되면 "눌렸다"는 촉각적 피드백. 현재 `MapScreen` UI 버튼에 DOTween DOPunchScale을 연결하면 한 줄로 가능.

## 전투·협동 (04_Combat)

- **패링 성공 squash** — 패링 성공은 가장 "잘했다!"는 순간. 작물 스프라이트가 가로로 squash(X 0.5, Y 1.5, 0.15s)되면 "튕겨냄"이 시각적으로 느껴짐. 반사탄이 나가는 방향으로 stretch를 추가해도 좋음.

- **협동 콤보 카운터 squash** — 협동 콤보 카운터 UI 숫자가 올라갈 때 숫자 TMP_Text에 DOPunchScale을 걸면 "지금 콤보 중"임을 더 뚜렷하게 전달. 콤보가 끊기면 숫자가 squash되며 사라지는 연출.

- **NPS 질문 "함께 하는 느낌"** — 설문 시스템 참고: 첫 엔딩 클리어 후 "두 명이 함께 조종하는 게 재미있었나요? (1~5)"를 물어보면 협동 메커니즘의 핵심 가치를 직접 측정 가능. 1~2 답변이 많으면 비대칭 조작 튜토리얼 강화 신호.

## 아이템·세트 (05_Items)

- **아이템 획득 stretch** — 장비 아이템을 집었을 때(또는 UpgradeSelectUI에서 선택했을 때) 아이템 스프라이트가 위로 살짝 stretch(0.08s)되면 "흡수됨"의 시각 피드백. 현재 선택 직후에 어떤 연출이 있는지 확인 필요.

- **세트 보너스 발동 연출** — Cassette Beasts에서 속성 반응이 발동할 때 명확한 이펙트가 나왔음. OnionCat에서 세트 보너스(햇살·바람 N단계) 발동 시 고양이+작물 모두에 squash-flash 연출을 주면 "지금 세트 발동 중"임을 알 수 있음.

- **장비 중복(레벨업) squash** — 같은 장비 카드를 중복으로 받아 레벨업할 때 아이콘이 커졌다 작아지는(scale punch) 연출을 주면 성장감 강화.

## 스토리·메타 (07_StoryMeta)

- **그리모의 감정 반응 squash** — 대사 말풍선이 등장할 때 말풍선이 작은 squash로 "튀어나오는" 느낌을 주면 더 살아있어 보임. `Dialogue.Say()` 내부에 말풍선 `transform.DOPunchScale(0.1, 0.15s)` 추가 가능.

- **이야기 단계 클리어 squash** — 마을 등불을 밝히는 순간(이야기 진행) 등불 스프라이트 + 화면 주변 발광 효과 + 등불 squash로 "챕터 넘어감"의 중요성을 연출. 현재 등불 발광 연출이 어떤 수준인지 확인 필요.

- **설문: 스토리 이해도 측정** — 설문 시스템 참고: "말하는 책이 어떤 존재인지 알겠나요?" (예/아니요)를 첫 보스 처치 후 물어보면 스토리 전달력을 측정 가능. 반전 전에 정체가 드러나면 안 되는데, 플레이어들이 너무 일찍 눈치채는지 확인하는 도구.

## 기술 메모

- **스쿼시 앤 스트레치**: `HitFeelSettings.asset`에 squash/stretch 수치 항목 추가 → `SquashStretch.cs` 컴포넌트를 `CatArtRenderer` spriteRoot에 연결 → `OnDamaged`, `Dash.Begin`, `Parry.Success` 이벤트에서 각각 호출. DOTween의 `DOPunchScale`로 10줄 이내 구현 가능. 주의: 고양이는 여러 스프라이트 레이어이므로 공통 부모 Transform에만 적용.

- **게임 내 플레이어 설문**: `SurveyManager.cs` + `SurveyQuestionAsset.cs` ScriptableObject 구조로 질문을 에셋으로 관리. 응답은 `Application.persistentDataPath/survey_responses.json`에 저장. 한 세션에 최대 2개, 같은 질문은 한 번만. 플레이테스트 후 `python survey_read.py`로 집계. 첫 적용 시 `run_difficulty` + `nps` 2개 질문부터 시작 권장.
