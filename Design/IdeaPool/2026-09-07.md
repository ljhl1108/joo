## 캐릭터 (01_Characters)

- **협력 무기 진화 시스템** — Vampire Survivors 무기 진화 참고: P1 근접 능력(갈퀴 슬래시)과 P2 원거리 능력(관통 투사체)을 동시에 MAX로 올리면 "공명 결합(Resonance Merge)" 발동 → 화면 전체를 덮는 회오리+투사체 기술. 두 플레이어가 모두 역할을 다할 때만 해금 → 협력 동기 강화. 구현 힌트: `AbilityManager.OnBothPlayersMaxLevel()` 이벤트 → 공명 결합 오브젝트 Instantiate.
- **런별 성장 색상 변화 강조** — Halls of Torment 클래스 시스템 참고: P1이 런 내 업그레이드를 3단계 획득할 때마다 고양이 스프라이트 눈 색상이 변화(기본→황금→붉은). 업그레이드 누적 수를 PlayerRunData에 저장, `OnUpgradeCount(3)` 이벤트에서 팔레트 LUT 인덱스 변경. 시각적으로 "강해지는 느낌" 즉각 전달.
- **카메라 흔들림으로 역할 표현** — CinemachineImpulse 참고: P1 슬래시 히트 = 강한 수직 방향 흔들림(근접=밀어붙이는 느낌), P2 투사체 히트 = 약한 수평 흔들림(발사 반동 느낌). 같은 화면 흔들림이지만 방향성으로 두 캐릭터의 존재감을 차별화.

## 적 (02_Enemies)

- **취약 표시 + 화면 흔들림 페어링** — Halls of Torment 취약 시스템 + CinemachineImpulse 참고: 근접 전용 적을 P2 투사체로 맞히면 "튕김" 이펙트 + 미세 흔들림 없음 (효과 없음 암시). P1 슬래시로 맞히면 강한 흔들림 + 처치 이펙트. 흔들림 유무가 취약점 정보를 촉각적으로 전달.
- **생존 시간 증가 적 (Survivor-like 변형)** — Vampire Survivors 타이머 압박 참고: 특정 "생존형 적"은 30초 생존 시 주변에 소환 폭풍 발동 → 방을 나가지 않으면 피해 불가피. P1이 근접으로 빠르게 처치해야 하므로 P2의 원거리 방해(원거리에 약한 보호막 적)와 조합하면 자연스럽게 역할 분담 발생.
- **진화 형태 보스** — Vampire Survivors 무기 진화 구조 참고: 보스가 런 중 플레이어가 획득한 업그레이드 수에 비례해 형태 진화. 업그레이드 5개 미만 → 1페이즈. 5~10개 → 2페이즈(추가 공격 패턴). 10개 이상 → 3페이즈 보스. 강해질수록 보스도 강해지는 동적 밸런스.

## 맵 (03_Maps)

- **서바이버 라이크 보상 방** — Vampire Survivors 골드 보석 드롭 참고: 전투 방 외에 30초 동안 끊임없이 소환되는 소형 잡몹을 처치해 씨앗(메타 재화) 최대한 모으는 "보상 방" 추가. 이동만 하면서 P1이 슬래시, P2가 투사체로 각자 처치 — 협력 없이도 자연스럽게 진행 가능한 완화 방.
- **Halls of Torment 스테이지 선택 → 층 분기** — 매 층 클리어 후 2가지 다음 층 선택지 제시 (예: 독 안개 던전 vs 불 지형 던전). 각 던전 테마별로 특정 적 타입이 더 많이 등장 → 근접/원거리 비율이 달라짐 → 플레이어가 전략 구성. 선택 UI는 방 문 2개로 표현.
- **흔들림 강도 구역 (Shake Zone Room)** — CinemachineImpulse 적용: 특정 방에 "진동 지뢰" 타일 배치. 적이 밟으면 강한 화면 흔들림 + 광역 피해 → P2가 마우스로 조준해 투사체로 지뢰 폭발 유도. P1은 흔들림으로 방향 판단 어려우므로 P2 주도 방. 역할 전환 유도 공간.

## 전투 (04_Combat)

- **흔들림-히트스톱-파티클 삼위일체 타이밍** — CinemachineImpulse + Feedback_System 참고: ① 히트 감지 → ② timeScale=0 (0.05초) → ③ timeScale=1 → ④ CinemachineImpulse 발동 → ⑤ 파티클 스폰 순서로 타이밍을 고정. 이 순서가 어긋나면 흔들림이 히트스톱 중에 멈춰버리는 버그 발생. `HitEventSequencer.cs` 싱글톤으로 이 순서를 강제 관리.
- **패리 성공 = 방향성 흔들림** — Halls of Torment 충격 물리 + P2 패리 참고: P2 방향 패리 성공 시 적탄 방향 반대로 강한 수평 흔들림 발동. 적도 반대 방향으로 날아감. 흔들림이 "파워"를 시각화 → 패리 성공 판정 확실히 인식 가능. `GenerateImpulse(-incoming.direction * 1.0f)` 방향성 벡터 사용.
- **접근성 흔들림 설정** — Settings Menu 참고: 설정 메뉴에 "화면 흔들림 강도" 슬라이더(0%/50%/100%) 추가. `ScreenShaker.shakeMultiplier` 값에 반영. 멀미 방지 옵션으로 진입 장벽 낮춤. PlayerPrefs로 저장해 런 사이에도 유지.

## 스토리 (05_Story)

- **씨앗 = 세계관 메타 재화** — Vampire Survivors 골드 시스템 참고: 고양이가 꽃밭에서 씨앗을 모아 런 종료 후 화분에 심음 → 영구 성장(작물 P2가 강해짐). 메타 진행 재화가 "고양이가 작물을 돌보는" 세계관과 자연스럽게 연결. 런 결과 화면에 "오늘 얻은 씨앗" 시각화.
- **진동으로 전하는 세계관** — CinemachineImpulse 연결: 게임 내 설정 상 P1(고양이) 발구름의 에너지가 P2(작물) 뿌리에 전해져 대지를 뒤흔드는 것. 화면 흔들림이 단순 피드백 이상의 내러티브 의미를 가짐. 보스 처치 시 "온기가 대지에 퍼진다" 텍스트와 흔들림 동시 발동.
- **설정 메뉴 = 고양이의 집 내부** — Settings Menu 비주얼 참고: 설정 화면 배경을 고양이 집 안 (벽에 걸린 그림들 = 각 설정 항목)으로 디자인. 멀미 방지 설정 → "흔들리지 않는 의자", BGM 설정 → "소형 라디오" 오브젝트 클릭 방식. 기능적 UI를 세계관 안으로 통합.

## 기술 메모

- **CinemachineImpulse**: 흔들림은 히트스톱 해제 후에 발동해야 함 — `timeScale=0` 상태에서 `GenerateImpulse` 호출 시 Cinemachine 업데이트가 멈춰 흔들림이 동결됨. `WaitForSecondsRealtime`으로 히트스톱 대기 후 발동. `shakeMultiplier`를 Settings와 연동해 접근성 옵션 반드시 추가.
- **설정 메뉴**: OnionCat은 2인 플레이이므로 "화면 흔들림 강도" 외에 P1(게임패드) 진동 강도, P2(마우스) 감도 조절이 핵심 항목. `PlayerPrefs.SetFloat(key, value)` + `PlayerPrefs.Save()` 를 설정 변경 즉시 호출해 씬 전환 없이 반영. 설정 씬은 인게임 Pause 메뉴에서도 접근 가능하도록 설계.
