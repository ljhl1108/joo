## 캐릭터 (01_Characters)

- **협동 필살기 게이지** — Lovers 참고: Cat과 Crop이 동시에 특정 행동(Cat 슬래시 + Crop 투사체 동시 명중)을 할 때 협동 게이지 충전. 게이지 풀 시 두 플레이어가 함께 강력한 합동 기술 발동. 구현 힌트: `float syncGauge` 공유 변수, 두 입력 동시 감지 → 게이지 +1.

- **Cat 무적 대시 성장형 업그레이드** — 데미지 시스템 참고: 기본 대시는 단순 무적이지만, 업그레이드 시 "대시 중 적 통과 시 데미지" 또는 "대시 종점에서 작은 폭발" 효과 추가. `CatDash.cs`에 업그레이드 플래그로 구현.

- **Crop 패리 연속 성공 보너스** — 데미지 시스템 참고: 패리를 연속으로 성공할 때마다 반사 투사체 위력 상승 (최대 3단계). 사운드 피치가 연속 횟수마다 올라가 긴장감 연출. 구현: `int consecutiveParries` 카운터 + 타이머 리셋.

## 적 (02_Enemies)

- **역할 의존형 미믹 적** — Lovers 참고: 외형이 아이템 상자처럼 생긴 미믹 적으로, 근접으로 열려고 하면 근접 면역(방어막 생성), 원거리로 쏘면 막 없이 피해 받음. 플레이어가 먼저 "어떤 타입인지 확인"해야 하는 정보 플레이 강제. `DamageType.Melee` → `TakeDamage` 에서 면역 반환.

- **분열형 소환 적 (원거리 전용 약점)** — 데미지 시스템 참고: 근접으로 치면 두 마리로 분열하고, 원거리 투사체만 완전히 처치 가능. 분열 시 자녀 적은 `weakness = DamageType.Ranged` 설정, Cat이 실수로 치면 문제가 커지는 구조 → Crop 집중 요구.

- **사운드 기반 적 — 청각 포식자** — 사운드 시스템 참고: 주변 소음에 반응하는 적. 투사체(시끄러움) 사용 시 집결하고, Cat의 무소음 근접 슬래시에는 반응 안 함. 구현: 투사체 발사 시 `EventManager.TriggerNoise(position, radius)` 신호 발생 → 해당 반경 내 청각 적 어그로.

## 맵 (03_Maps)

- **스테이션 방 (함선 격납고 테마)** — Lovers 참고: Lovers의 스테이션 전환 개념을 방 디자인으로. "엔진 방" → 이동 제한 구역(Cat 느려짐), "무기 방" → 투사체 강화 구역(Crop 화력 2배), "방어막 방" → 패리 판정 시간 2배 확장. 방 입장 시 해당 역할이 더 중요해짐.

- **지형지물 데미지 타입 영역** — 데미지 시스템 참고: 맵 내 특정 타일은 근접만 가능(너무 좁은 통로 — 투사체 벽 막힘), 다른 구역은 원거리만 가능(유리 바닥 — 근접 충격파로 바닥 부숨 위험). 물리적 제약으로 자연스럽게 역할 분담 강제.

- **협동 문 (둘 다 눌러야 열림)** — Lovers 참고: 두 개의 버튼이 떨어져 있어 Cat과 Crop 조작 플레이어가 동시에 서야 문이 열리는 구조. 협동 퍼즐 방으로 활용. 구현: 두 `ButtonTrigger` 컴포넌트가 모두 `isPressed == true`일 때 문 오픈.

## 전투 (04_Combat)

- **데미지 타입 시각화 — 색상 코딩** — 데미지 시스템 참고: 근접 데미지 숫자는 주황색, 원거리는 하늘색, 크리티컬은 노란+대형 폰트, 무효는 회색 "IMMUNE" 텍스트. 플레이어가 약점 여부를 눈으로 즉시 인지. `DamageNumberSpawner.Spawn(pos, damage, color)` 구현.

- **패리 후 히트스톱 + BGM 덕킹** — 사운드 시스템 참고: 패리 성공 시 0.07초 히트스톱 + BGM 볼륨 -6dB 덕킹(0.3초) + 금속 충격음 + 화면 흰색 플래시. 이 조합이 "패리 = 극적인 순간" 인식을 강화. `AudioManager.DuckBGM()` + `HitStop 코루틴` 동시 호출.

- **근접/원거리 연계 콤보 보너스** — Lovers 스테이션 연계 참고: Cat 슬래시 직후 1초 이내에 Crop 투사체가 같은 적에 명중하면 "콤보 보너스" 데미지 적용 (×1.5). 협동 플레이를 기계적으로 보상하는 시스템. 구현: 적에 타임스탬프 저장, 투사체 명중 시 체크.

## 스토리 (05_Story)

- **Cat과 Crop의 기억 불일치** — Lovers 공유 몸체 테마 참고: 같은 사건을 Cat(몸)과 Crop(화분 식물)이 다르게 기억. 방 클리어 후 짧은 대화에서 Cat은 "우리가 해냈다"고, Crop은 "내가 다 막았다"고 주장. 유머와 캐릭터 개성을 동시에 부여.

- **사운드 기반 세계관 단서** — 사운드 시스템 참고: BGM이 단순 배경음악이 아닌 세계관 요소. 던전 깊이 내려갈수록 BGM에 "속삭이는 목소리"가 섞이기 시작. 최종 보스 방 BGM은 Cat이 처음 달리던 평화로운 마을 노래의 왜곡 버전 → 감정적 연결.

- **패리 성공 = 기억 회수** — 데미지 시스템(패리) + 스토리 결합: 패리를 성공할 때마다 Crop이 과거 기억 파편을 회수 (짧은 플래시백 이미지). 전투 기술과 스토리 진행이 연동. 패리 N회 누적 시 숨겨진 스토리 언락.

---

## 기술 메모

- **데미지 시스템**: `IDamageable` 인터페이스 + `DamageType` enum이 핵심 뼈대. 가장 먼저 구현하고, 이후 모든 적·투사체·함정이 이 인터페이스를 통해 피해를 줌. Cat 무적 대시는 `HealthComponent.SetInvincible(true/false)`로 연동. 적 약점 타입은 `[SerializeField] DamageType weakness`로 에디터에서 설정 가능하게 분리.

- **사운드 시스템**: 가장 먼저 할 것 — AudioMixer 생성 후 BGMVolume / SFXVolume 파라미터 노출, AudioManager 싱글턴 씬에 배치. SFX 풀 size는 8~12개면 충분. `Mathf.Log10(sliderValue) * 20f`로 슬라이더 → dB 변환 공식 반드시 사용 (선형 변환 쓰면 볼륨이 자연스럽지 않음).
