## 캐릭터 (01_Characters)

- **원소 특화 업그레이드 슬롯** — Wizard of Legend 참고: 고양이와 양파 각자 4개의 업그레이드 슬롯(공격/방어/이동/패시브) 운영 → 매 런마다 빌드 방향이 달라지는 조합 자유도 추가
- **무기 변신 스킨** — Dungreed 참고: Cat의 근접 무기를 런마다 다른 형태로 변환 (발톱/단검/낫/망치) → 공격 모션과 히트박스 범위가 달라져 플레이 다양성 증가
- **공생 레벨업** — Dungreed 영구 업그레이드 참고: 두 플레이어가 함께 있는 시간이 길수록 "공생 게이지" 충전 → 가득 차면 두 플레이어 동시 스탯 버프 획득 (분리 금지 메카닉 강화)

## 적 (02_Enemies)

- **원소 저항 적** — Wizard of Legend 참고: 일부 적이 근접 공격에 가시 반격(Cat 위험) 또는 원거리를 완전 흡수(Crop 무효) → 두 플레이어가 반드시 역할 교환하며 협동해야 하는 설계
- **던전 주민 포획자** — Dungreed 마을 재건 참고: 잡지 않으면 도망가는 적이 맵 한쪽 끝에 NPC를 납치해 끌고 다님 → 처치 시 NPC 구출 + 마을 발전 포인트 획득
- **복제 슬라임** — Wizard of Legend 다수 전투 참고: 공격받을수록 분열하는 적 (근접은 분열 촉진, 원거리는 한 번에 정리 가능) → 양파 원거리 관통탄으로 일렬 처리하는 전략 유도

## 맵 (03_Maps)

- **마을 귀환 허브** — Dungreed 마을 재건 참고: 런 종료 시마다 돌아오는 고양이 마을 허브 씬 → 구출한 NPC 수에 따라 건물 추가, 각 건물이 새 시작 업그레이드 or 패시브 제공
- **원소 테마 던전 층** — Wizard of Legend 원소 시스템 참고: 각 층마다 특정 원소 테마 (불 층 = 화염 트랩 많음, 물 층 = 미끄러운 바닥 + 투사체 굴절) → 해당 원소 약점 적 집중 등장
- **비밀 훈련방** — Dungreed 훈련 시스템 참고: 던전 내 숨겨진 방에서 임시 스탯 강화 미니게임 (정해진 시간 내 타겟 처치) → 성공 시 런 종료 후에도 영구 스탯 소량 상승

## 전투 (04_Combat)

- **180° 슬래시 업그레이드 트리** — Melee Combat System 참고: 기본 180° 슬래시가 업그레이드로 "관통 슬래시(벽 제외 직선)", "회오리 슬래시(360°)", "연속 3타 콤보"로 분기 → Cat 플레이어 고유 빌드 분화
- **대시 공격 연계** — Melee Combat System 무적 대시 + Wizard of Legend Dash Arcana 참고: 대시 중 공격 버튼 입력 시 "대시 슬래시" 발동 (더 넓은 범위, 더 짧은 선딜) → 대시가 단순 회피를 넘어 공격 옵션이 됨
- **채소 씨앗 드롭 버스트** — Item Drop System 참고: 양파(Crop)가 특정 조건(10개 연속 픽업, 보스 처치 등)에서 씨앗 탄약 폭발 드롭 → 자원 관리 텐션 + 보상감 강화

## 스토리 (05_Story)

- **마을 복원 내러티브** — Dungreed 참고: 던전에 끌려들어간 마을 주민들이 사실은 마왕에게 세뇌된 상태 → 고양이와 양파가 그들을 구출하며 마왕의 음모를 역추적하는 서사
- **원소의 탑** — Wizard of Legend 보스 구조 참고: 마왕이 지배하는 탑은 각 층마다 원소 수호자(불, 물, 흙, 바람)가 지킴 → 각 수호자를 이기면 해당 원소 힘을 고양이와 양파가 나눠 흡수
- **공생의 저주** — OnionCat 테마 심화: 원래 고양이와 양파는 원수지간이었지만 마왕의 저주로 강제 합체됨 → 런을 클리어할수록 두 존재가 서로를 이해해 가는 관계 성장 스토리

## 기술 메모

- **근접전 시스템**: `Physics2D.OverlapCircleAll` + 각도 필터(≤90°)로 180° 슬래시 구현 가능. AnimationEvent 2개(ActivateHitbox, EndAttack)로 판정 프레임 정확히 제어. 대시 무적은 `Physics2D.IgnoreLayerCollision`으로 EnemyProjectile 레이어만 선택적 비활성화하면 충분.
- **아이템 드롭 & 픽업**: `LootTable` ScriptableObject에 가중치 배열 보관 → `Roll()` 메서드 하나로 드롭 아이템 결정. `OnTriggerEnter2D` + `IItemReceiver` 인터페이스로 픽업 처리. 아이템 수가 많아지기 전까지는 Instantiate/Destroy 방식으로 시작해도 충분, 나중에 오브젝트 풀 전환.
