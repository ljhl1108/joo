## 캐릭터 (01_Characters)

- **"베기 후 여운" 이펙트** — Katana ZERO 참고: 고양이의 180도 슬래시 이후 2~4프레임 히트스탑 추가. 베기 궤적에 색상 트레일 + 끝에 작은 에너지 방출 입자. 구현 힌트: SpriteRenderer DoTween 흰색 플래시 + TrailRenderer 설정
- **작물 냄비 관성 흔들림** — Katana ZERO 공유 신체 feel 참고: 고양이가 방향을 급전환할 때 냄비가 물리적으로 약간 흔들리는 애니메이션. 실제 Rigidbody2D 물리 불필요, 애니메이터 보조 레이어에서 흔들림 처리. 구현 힌트: `Animator.SetFloat("TurnSpeed", ...)`로 흔들림 세기 제어
- **패리 성공 시 "냄비 뚜껑 효과"** — 작물 플레이어가 패리 성공 시 냄비 뚜껑이 순간 열리며 작물이 승리 포즈를 취하는 1~2프레임 애니메이션. 피드백 만족감 강화. 구현 힌트: AnimationEvent로 파티클 + 소리 동시 트리거

## 적 (02_Enemies)

- **"메이즈 어웨어" 적** — 절차적 던전 생성 참고: 던전이 생성될 때 방 연결 그래프를 읽어 가장 짧은 경로를 추적하는 적. 일반 추적과 달리 복도 막힘을 미리 예측하고 우회. 구현 힌트: DungeonMap의 BFS 결과를 적 AI Pathfinding에 공유
- **"원거리 전용 약점" 적** — Katana ZERO 일격 필살 구조 참고: 단단한 갑주를 입고 있어 근접 슬래시로는 데미지가 없고 작물의 투사체만 통함. 화면에서 작물 플레이어의 적극적인 조준을 강제하는 설계. 구현 힌트: EnemyData에 `WeakToRanged` 플래그, DamageSystem에서 분기
- **"시야 추적 + 청각 반응" 복합 적** — BSP 던전 생성과 시야각 AI의 결합: 시야 밖에서 소리(투사체 발사음)로 플레이어 위치를 추측, 예측 경로로 이동. 구현 힌트: 기존 Enemy_AI_FOV_Patrol_Flocking.md의 시야각 시스템에 AudioEvent 수신 레이어 추가

## 맵 (03_Maps)

- **"보스방 예고 방"** — 절차적 생성 특수방 규칙 참고: 보스방 바로 직전 방에는 항상 고요한 분위기(배경음악 없음 + 은은한 조명)와 함께 휴식/업그레이드 선택이 제공됨. Hades의 "Boon 방 → 보스" 패턴과 동일. 구현 힌트: DungeonMap.AssignSpecialRooms()에서 보스 직전 방 탐색 후 RoomType.PreBoss 설정
- **"루프백 비밀 통로"** — BSP 특성 상 완전 트리 구조이지만 일부 막다른 방끼리 단방향 비밀문으로 연결. 맵 탐색에 선택지를 주고 지름길 전략이 생김. 구현 힌트: DungeonMap 생성 완료 후 Dead-end 방 목록에서 무작위 2개를 SecretDoor로 연결
- **"색각이상 친화 방 디자인"** — 접근성 참고: 방 내 위험 요소(함정, 특정 적의 약점)를 색상만으로 구분하지 않음. 함정은 색상 + 기하학적 패턴(줄무늬, 점선), 약점 적은 색상 + 아이콘(방패/검 심볼). 구현 힌트: 스프라이트 레이어에 아이콘 오버레이 추가, 색각이상 모드일 때 채도 낮추고 아이콘 크기 확대

## 전투 (04_Combat)

- **"베기 체인 가속"** — Katana ZERO 연속 베기 리듬 참고: 고양이가 0.8초 이내 연속으로 3번 슬래시하면 4번째 슬래시부터 속도 20% 증가 + 트레일 색상 변화. 구현 힌트: `float lastSlashTime`과 `int slashComboCount`로 추적, 연속 여부 판단
- **"협동 패리 카운터"** — Katana ZERO 메타 서사 + 패리 참고: 작물이 방어막으로 투사체를 패리한 직후 0.5초 내에 고양이가 슬래시하면 "합동 반격" 발동 — 적에게 평소의 2배 데미지. 두 플레이어의 실시간 협력 강제. 구현 힌트: `ShieldParryEvent` 발생 시 타이머 시작, `MeleeSlash` 입력 감지 후 콤보 데미지 처리
- **"시간 감속 버스트"** — Katana ZERO 시간 조작 참고: OnionCat 특수 능력 — 두 플레이어가 동시에 특정 버튼을 누르면 1.5초간 적만 느려짐(플레이어 속도 유지). 쿨다운 30초. 구현 힌트: New Input System 멀티 플레이어 입력 동시 감지, `Time.timeScale`이 아닌 적 Animator.speed + Rigidbody2D.velocity 직접 조작

## 스토리 (05_Story)

- **"실패 기억 조각"** — Katana ZERO 재시도 내러티브 참고: 런 실패 시 메뉴로 돌아갈 때 고양이와 작물이 짧은 대화 한 줄("다시 해볼까?", "이번엔 왼쪽으로 가자"). 런마다 랜덤으로 다른 대사. 구현 힌트: `string[] runFailDialogues` 배열에서 랜덤 픽, GameOver 화면에 텍스트 표시
- **"던전 기억 전설"** — BSP 시드 기반 생성 참고: 특정 씨드로 생성된 던전은 NPC가 "전설의 던전" 이라고 언급. 플레이어가 씨드 코드를 공유하며 같은 경험을 반복할 수 있는 커뮤니티 기능. 구현 힌트: 런 시작 시 시드 표시, 클리어 화면에 씨드 복사 버튼
- **"작물의 성장 스토리"** — 접근성 Assist Mode + 캐릭터 내러티브 통합: 첫 번째 런 실패 시 작물이 "아직 완전히 자라지 않았어"라는 대사와 함께 Assist Mode 안내 팝업 자연스럽게 제시. 난이도 안내를 서사 속에 녹임. 구현 힌트: `RunCount == 1 && isDead`일 때 커스텀 GameOver 씬 분기

## 기술 메모

- **절차적 던전 생성**: OnionCat에 가장 실용적인 방법은 **격자 기반 BFS 방 배치** — DungeonMap 클래스에 격자 좌표와 연결 방향(상/하/좌/우)만 저장하면 기존 RoomController와 바로 연동 가능. 구현 시작점: `PlaceRoomsBFS()` → `AssignBossRoom()` → `InstantiateDungeon()` 순서
- **접근성 옵션 시스템**: 가장 빠른 가치: **화면 흔들림 강도 슬라이더**. 기존 FeedbackSystem의 `TriggerShake()` 호출부에 `* AccessibilityManager.Instance.ScreenShakeIntensity` 한 줄만 추가하면 즉시 구현 완료. 색각이상 필터는 GitHub SOHNE/Colorblindness 패키지로 5분 내 적용 가능 (URP 지원)
