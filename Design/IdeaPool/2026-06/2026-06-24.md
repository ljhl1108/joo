## 캐릭터 (01_Characters)

- **텃밭 성장 시스템** — Rogue Heroes 마을 건설 참고: 런 클리어 시 고양이의 화분이 조금씩 업그레이드(새 작물 등장, 화분 장식 변경)되어 시각적 성장감 부여. 화분 모양 = 현재 메타 진행 단계를 직관적으로 표시.
- **대시-슬래시 연계 모션** — Input 버퍼링 참고: 대시 끝에 슬래시가 자동 이어지면 전용 연계 애니메이션 재생(대시 슬래시). 단순 공격과 시각적으로 구분하여 콤보 성취감 강화.
- **작물 품종별 사격 스타일** — Rogue Heroes 클래스 다양성 참고: 런 시작 시 작물 품종(양파→직선, 토마토→산탄, 허브→관통) 선택 가능. 고양이(Player 1)는 고정, 작물(Player 2)만 선택.

## 적 (02_Enemies)

- **이중 내성 엘리트 적** — Rogue Heroes 역할 분담 참고: 근접과 원거리 둘 다 특정 조건 없이는 튕겨내는 엘리트 적 도입. 패리(Player 2)로 방어막을 깨야 근접(Player 1)이 대미지를 줄 수 있는 구조로 긴밀한 협동 강제.
- **스플래시 화면 깜짝 등장 적** — 인트로 씬 참고: 첫 런 시 스플래시가 끝나고 메인 메뉴가 뜰 때, 화면 구석에서 적 하나가 지나가는 이스터에그 연출. 세계관 분위기 전달.
- **콤보 감지 적** — Input 버퍼링 참고: 특정 적은 같은 공격을 연속으로 맞으면 면역이 생겨 다른 공격 유형으로 전환해야 하는 강제. 버퍼링된 연속 슬래시만으로는 돌파 불가한 적 유형.

## 맵 (03_Maps)

- **텃밭 허브 씬** — Rogue Heroes 마을 참고: 런 사이에 고양이의 텃밭(허브 공간) 구현. 런마다 영구 업그레이드 시각화(심어진 작물 수, 화분 크기). 텃밭 배경에서 다음 런 시작 버튼 클릭.
- **콤보 연습 방** — 버퍼링 시스템 참고: 특정 방에서 콤보 입력 성공 시 보너스 보상 지급하는 선택 도전 방. "15초 내에 10콤보 달성" 같은 조건. 조작 숙달 유도.
- **협동 잠금 문** — Rogue Heroes 협동 참고: Player 1과 Player 2가 동시에 스위치를 눌러야 열리는 방 구조. 두 플레이어가 다른 위치에서 동시 조작 → 한 몸이지만 버튼 두 개 → 이동 제약 퍼즐.

## 전투 (04_Combat)

- **패리 버퍼 시각화** — Input 버퍼 패리 참고: 패리 입력 시 일시적으로 방어막 윤곽선이 하이라이트됨으로써 "지금 패리 윈도우다"를 시각 피드백으로 전달. 스플래시 화면에서도 쉴드 이미지 활용 가능.
- **대시-슬래시 콤보 대미지 보너스** — 버퍼링 + Rogue Heroes 클래스 참고: 버퍼링으로 연계된 대시-슬래시는 일반 슬래시보다 대미지 20% 추가. 능숙한 플레이에 보상 구조 삽입.
- **패리 카운터 공격** — Rogue Heroes Ninja 참고: 성공적인 패리 직후 0.3초 내 슬래시 입력 시 패리 카운터 발동 (대미지 2배 + 넉백). 버퍼에 슬래시 예약이 있으면 자동 트리거.

## 스토리 (05_Story)

- **텃밭의 기억** — Rogue Heroes 마을 재건 참고: 매 런 클리어 시 파괴된 텃밭의 기억 조각(비화)이 1개 복원됨. 10조각 모두 모이면 최종 엔딩 추가 씬 해금. 수집 욕구와 스토리 동기 동시 제공.
- **스플래시 로고의 비밀** — 인트로 씬 참고: 게임 내 비밀 콤보 입력(메인 메뉴에서 특정 시퀀스) 시 스플래시 로고가 변형되며 숨겨진 스토리 힌트 또는 보너스 씬 재생. 하드코어 팬을 위한 이스터에그.
- **협동 전설** — Rogue Heroes 파티 스토리 참고: 고양이와 작물은 원래 다른 존재였으나, 마왕의 마법에 의해 한 몸이 됨. 각 보스 처치마다 봉인이 하나씩 풀리고, 최종 보스 처치 시 분리 여부를 선택하는 결말.

## 기술 메모

- **Input 버퍼링**: OnionCat 즉시 적용 포인트 — Player 1의 대시(`bufferWindow = 0.15f`) 중 슬래시 예약 저장, 대시 완료 직후 `ConsumeInput("Slash")` 체크하여 실행. Player 2의 패리는 피격 판정 시점 기준 ±0.1초 윈도우로 관용도 제공. `InputBuffer` 컴포넌트 하나를 각 플레이어 오브젝트에 붙이는 것으로 충분.

- **인트로/스플래시 화면**: 구현 우선순위 — ① Build Settings에서 SplashScene을 0번 씬으로 등록, ② 검정 배경 + OnionCat PNG + 페이드 코루틴 (30분 내 완성 가능), ③ `AsyncOperation.allowSceneActivation = false`로 MainMenu 미리 로드하여 전환 지연 방지. Unity Personal 라이선스 사용 시 "Made with Unity" 로고가 자동 삽입되므로 커스텀 로고는 그 이후에 표시됨.
