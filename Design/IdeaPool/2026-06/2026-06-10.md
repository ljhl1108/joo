## 캐릭터 (01_Characters)

- **저주받은 Cat** — Curse of the Dead Gods 참고: Cat이 누적 피격 횟수에 따라 "저주 단계" 진입, 단계마다 외형 애니메이션이 변하고(털 색 반전, 눈 빛남) 슬래시 범위는 증가하지만 이동 속도는 감소. 구현 힌트: Animator에 `curseLevel`(int 0~3) 파라미터, 각 레벨별 Blend Tree 분기.

- **조준 연동 Onion 스프라이트** — 애니메이션 시스템 참고: Onion은 마우스 조준 방향에 따라 8방향 스프라이트로 전환되어야 함. `aimAngle` float 파라미터를 Animator에 전달, 0~360도를 8구간으로 나눠 각 방향 Idle 스프라이트 표시. 구현 힌트: `Mathf.Atan2` → 각도 변환 → animator.SetFloat.

- **공유 몸 시각화** — Archvale 코옵 디자인 참고: Cat이 달리면 화분(Onion)도 흔들리는 종속 애니메이션. Cat Animator의 Move 상태에 AnimationEvent로 `OnionPot.Sway()` 호출. 화분이 관성으로 좌우로 약간 기울어지는 연출로 "하나의 몸" 느낌 강화.

## 적 (02_Enemies)

- **챔피언 모디파이어 적** — Curse of the Dead Gods 참고: 일반 슬라임·거미에 1~2개 태그 랜덤 부여. 예: "방패형"(Cat 근접 무적), "고속형"(이동속도 1.5배), "독가시"(근접 공격 시 반격). 태그에 따라 머리 위 아이콘 표시로 플레이어에게 사전 정보 제공. 구현: `EnemyBase`에 `List<EnemyModifier>` + `ApplyModifier()` 추상 메서드.

- **약점 전환 보스** — Archvale 보스 페이즈 참고: 보스 HP 50% 이하에서 약점 타입 전환. 1페이즈: 원거리(Onion)만 데미지 인정, 2페이즈: 근접(Cat)만 데미지 인정. 약점 타입은 보스 몸 색상(파란=원거리, 빨간=근접)으로 직관적으로 표시. 구현: `DamageType weakTo` 필드, HP 50% 이벤트에서 값 변경 + 색상 Material 교체.

- **어둠 속 적** — Curse of the Dead Gods 어둠 메커닉 참고: 특정 방에 "암흑" 모디파이어 부여, 시야 반경 제한(URP 2D Light Point Light로 Cat 주변만 밝음). 이 방에 등장하는 적은 어둠 속에서 이동 속도 증가, 빛 안에선 감소. Cat 근접이 유리한 상황 → 역할 강화.

## 맵 (03_Maps)

- **경로 선택 카드** — Curse of the Dead Gods Path 시스템 참고: 런 시작 전 3개 경로 카드 제시. 각 카드는 "적 타입(근접형/원거리형/혼합)", "보상 유형(공격 업그레이드/방어 업그레이드)", "난이도 아이콘" 표시. 두 플레이어가 3초 이내 입력으로 합의해야 선택됨 → 협력 소통 강제. 구현: RunStartManager에서 3개 PathData ScriptableObject 랜덤 선택 후 UI 표시.

- **함정 방 모디파이어** — Curse of the Dead Gods 트랩 참고: 일부 방에 "함정 방" 태그. 바닥 가시, 회전 블레이드, 떨어지는 돌기둥 중 1~2개 배치. 적은 함정 피해 없음, 플레이어만 피해. 방 클리어 보상 1.3배. 구현: 방 프리팹에 TrapVariant 오브젝트 풀 + 방 스폰 시 랜덤 활성화.

- **비밀 방 연결 힌트** — Archvale 숨겨진 방 참고: 특정 벽에 금이 간 타일 텍스처 사용. Cat의 슬래시가 해당 벽에 닿으면 비밀 방 입구 개방. 비밀 방엔 보장 업그레이드 1개. 구현: 벽 Collider에 `SecretWall` 컴포넌트 + OnTriggerEnter에서 Cat 슬래시 태그 체크.

## 전투 (04_Combat)

- **패리 업적 연동 시각 피드백** — 업적 시스템 + 애니메이션 참고: 패리 성공 50회 달성 시 Onion 방패에 골드 테두리 이펙트 영구 추가. 런 시작 시 `AchievementManager`에서 잠금 해제 여부 확인 → `OnionShield` 머테리얼 교체. 업적이 시각적 차별화로 이어지는 구조.

- **AnimationEvent 기반 히트박스** — 애니메이션 시스템 핵심 참고: Cat 슬래시 히트박스를 코드가 아닌 AnimationEvent로 ON/OFF. 슬래시 애니메이션 3번째 프레임에 `OnSlashHitboxStart()`, 7번째 프레임에 `OnSlashHitboxEnd()` 이벤트 추가. 이렇게 하면 공격 선딜-후딜을 애니메이션 프레임 조정만으로 제어 가능.

- **저주 받은 슬래시 — 리스크 리워드** — Curse of the Dead Gods 저주 시스템 참고: Cat HP 25% 이하 돌입 시 "절박 상태" 진입. 슬래시 범위 1.5배, 쿨다운 0.3배 단축 → 공격적 플레이 보상. 단, 피격 1회에 사망(원히트킬). 조건부 발동이라 플레이어가 선택 가능. 구현: CatAttack에서 `HPRatio < 0.25f` 체크 + 히트박스 크기 조절.

## 스토리 (05_Story)

- **저주받은 모험의 흔적** — Curse of the Dead Gods 세계관 참고: 런 사이 로비 화면에 이전 런의 "묘비"가 하나씩 추가됨. 묘비에는 처치 수, 도달 층, 죽은 방법이 짧게 새겨짐(예: "3층 보스에게 패배, 처치 12"). 플레이어의 역사가 시각적으로 누적되는 내러티브 연출. 구현: 런 종료 시 RunRecord 저장, 로비 씬에서 묘비 오브젝트 스폰.

- **Onion의 성장 일지** — 업적 시스템 참고: 특정 업적 해금 시 Onion의 독백 메시지 추가. "패리를 50번 성공했을 때: '이 정도면 나도 전사라 할 수 있을까?'" 업적이 단순 달성 보상을 넘어 캐릭터 서사로 이어지는 구조. 구현: 업적 ID마다 대응하는 LocalizedString 매핑.

- **시너지 킬 카운터 스토리** — Archvale 코옵 + 통계 참고: 협력 공격으로 처치한 수가 100을 넘으면 엔딩 이후 특별 씬 추가. "Cat과 Onion이 서로를 처음으로 이름으로 부르는" 짧은 CG 컷씬. 협력 플레이에 대한 서사적 보상.

## 기술 메모

- **애니메이션 시스템**: AnimationEvent로 히트박스를 ON/OFF하는 패턴이 OnionCat에 즉시 적용 가능. `CatAnimationEventHandler` 컴포넌트를 Cat GameObject에 붙이고, Animator의 슬래시 애니메이션 3번째/7번째 프레임에 이벤트 추가. 이렇게 하면 히트박스 타이밍을 코드 수정 없이 애니메이션 에디터에서 직접 조정 가능 → 프로토타입 단계에서 밸런싱 매우 편리.

- **업적/통계 시스템**: `StatsManager`를 DontDestroyOnLoad 싱글턴으로 만들고 각 이벤트 발생 지점에서 `StatsManager.Instance?.Record...()` (null 조건 연산자)로 호출하는 것이 씬 전환 중 크래시를 막는 핵심. 구현 순서: Stats 구조체 → StatsManager → 이벤트 호출 포인트 → AchievementManager → PopupUI 순으로 하나씩 추가.
