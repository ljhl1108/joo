## 캐릭터 (01_Characters)

- **아르카나 슬롯 제한** — Hades 2 Grasp 시스템 참고: 런 중 장착 가능한 업그레이드 카드에 슬롯 제한(예: 최대 6슬롯) 도입. 강한 카드를 쓰려면 기존 카드를 내려놔야 해서 선택의 고통과 빌드 정체성이 생김. 구현 힌트: `PlayerStats`에 `List<UpgradeCardData> equippedCards` + 최대 사이즈 체크.

- **어니언 시들음 게이지** — Ravenswatch 공포 게이지 참고: 어니언이 물을 받지 못하면 점점 약해지는 "시들음 게이지" 추가. 물 아이템 수집 또는 특정 적 처치 시 게이지 회복. 게이지가 비면 어니언 투사체 데미지 -50%. 농업 테마 + 생존 압박 동시 구현. 구현 힌트: `Update()`에서 `wiltGauge -= Time.deltaTime * wiltRate` + 아이템 픽업 시 회복.

- **Aspect 시스템 (무기 전문화)** — Hades 2 참고: 런 시작 전 어니언 투사체의 "Aspect" 선택. A: 범위형 포탄(느리고 광역), B: 관통형 화살(빠르고 직선), C: 유도형 씨앗(느리지만 추적). 스타트에 플레이스타일 선언 → 그에 맞는 업그레이드 카드가 더 자주 등장하도록 가중치 조정.

## 적 (02_Enemies)

- **공동 처치 전용 적 (Duo-Kill Enemy)** — Ravenswatch 협동 카드 시너지 참고: 캣과 어니언이 동시에 공격할 때만 데미지를 받는 적 타입. 예: "방패 연대 슬라임" — 앞면은 근접 무적(캣 공격 차단), 뒷면은 원거리 무적(어니언 공격 차단). 두 방향에서 동시 협력 공격 필요. `EnemyData`에 `requireSyncAttack` 플래그로 구현.

- **씨앗 도둑 (Seed Stealer)** — 메타 진행 시스템 참고: 처치하지 않으면 시간이 지나 필드의 씨앗(메타 통화)을 빨아먹고 도망치는 적. 플레이어에게 "이 적은 꼭 잡아야 해"라는 즉각적 동기 부여. 처치 시 훔친 씨앗을 돌려줌 + 보너스 드롭.

- **탈주형 보스 (Fleeing Mini-Boss)** — Hades 2 낮/밤 사이클 시간 압박 참고: 방 진입 후 일정 시간(30초)이 지나면 도망치는 엘리트 적. 처치 성공 시 희귀 업그레이드 카드 드롭, 실패 시 다음 방에서 더 강해진 상태로 재등장. 빠른 협동 처치를 유도.

## 맵 (03_Maps)

- **인캔테이션 방 (Incantation Room)** — Hades 2 인캔테이션 시스템 참고: 런 도중 특정 재료(식물 조각, 광물 등)를 모으면 즉석에서 제작할 수 있는 특수 방. 제작 아이템은 그 런에만 사용 가능한 1회용 소비 아이템. "30초 동안 전체 화면 화염 지대" 같은 강력한 효과. 구현 힌트: `RoomConfig`에 `craftingAvailable` 플래그 + 재료 수집 카운터.

- **협동 잠금 방 (Sync Room)** — Ravenswatch 협동 카드 공동 선택 참고: 방 입구에 두 개의 버튼. 캣과 어니언이 동시에 버튼을 눌러야 문이 열림. 내부에는 고가치 보상. 협동 액션을 공간적으로 강제하는 맵 장치.

- **씨앗 밭 방 (Seed Field Room)** — 메타 통화 시스템 참고: 모든 씨앗이 식물 형태로 자라고 있는 방. 전투 없이 수집만 가능하지만 수집할수록 방어막이 줄어드는 역설 (보상 vs 리스크 선택). 또는 전투 완료 후 씨앗 밭이 자라는 연출로 보상 극대화.

## 전투 (04_Combat)

- **Duo Boon 업그레이드** — Hades 2 Duo Boon 참고: 캣이 업그레이드 A, 어니언이 업그레이드 B를 보유한 상태로 선택지에서 "시너지 카드"가 등장. 둘 다 선택 시 두 능력이 합쳐진 강화 효과 발동. 예: 캣 "대쉬 강화" + 어니언 "대쉬 중 투사체 분산" → "대쉬 연계 산탄 난사". `UpgradeManager`에서 두 플레이어 업그레이드 목록 교차 체크 로직 필요.

- **파리 → 쓰러짐 시스템 (Down State)** — Ravenswatch 부활 시스템 참고: 체력 0이 되면 즉사 대신 "화분 넘어짐" 애니메이션 + 다운 상태 3초. 어니언이 살아 있으면 어니언이 주변에서 행동으로 부활 가능. 이 3초가 극적 협동 레스큐 순간을 만들고 즉사보다 온화한 퍼마데스 루프 형성.

- **ScriptableObject 약점 시스템** — 기술 리서치 참고: `EnemyData`의 `weakToMelee` / `weakToRanged` 플래그로 적 약점을 에디터에서 설정. 코드 수정 없이 새 적 추가 가능. 약점 없는 적(양쪽 다 무효)은 등장하지 않게 설계 → 항상 하나의 역할이 필수.

## 스토리 (05_Story)

- **홈베이스 = 화분 집** — 메타 진행 홈베이스 참고: 런 사이에 돌아오는 거점을 "캣과 어니언이 사는 화분 집"으로 설정. 씨앗으로 집을 업그레이드하면 화분 집 비주얼이 변화 (화분이 커지고, 꽃이 피고, 영구 NPC가 등장). 메타 진행의 시각적 성장이 스토리와 통합.

- **악몽의 원예사 (Nightmare Gardener)** — Hades 2 크로노스 참고: 최종 빌런을 "화분 집을 파괴하려는 악몽의 원예사"로 설정. 매 런마다 NPC 대화를 통해 그의 목적이 드러남. 죽음 = 홈으로 돌아옴 → "다시 도전할 이유"가 내러티브로 제공됨.

- **씨앗 기억 (Seed Memory)** — Hades 2 인캔테이션 내러티브 참고: 특정 씨앗을 모으면 과거 캣과 어니언의 모험 기억 조각이 담긴 "씨앗 일기" 해금. 수집 동기 + 세계관 전달을 씨앗 메타 통화에 묶어 일거양득.

## 기술 메모

- **ScriptableObject 데이터 시스템**: OnionCat에 당장 적용할 것 — `EnemyData`에 `weakToMelee/weakToRanged` 플래그를 추가하는 것만으로 협동 강요 시스템의 기초 완성. `[CreateAssetMenu]` 추가 후 에디터에서 새 적을 코드 수정 없이 생성 가능. **런타임에 ScriptableObject 필드 직접 수정 금지** — 반드시 지역변수로 복사 후 사용.

- **메타 진행 시스템**: 씬 구성 순서: ① `MetaProgressManager` DontDestroyOnLoad 싱글톤 먼저 구현, ② 런 종료 시 씨앗 전달 로직, ③ HomeBase 씬에 업그레이드 구매 UI. 가장 먼저 만들 업그레이드는 "최대 체력 +10%"처럼 즉시 체감되는 것 — 초기 플레이어 리텐션에 직결.
