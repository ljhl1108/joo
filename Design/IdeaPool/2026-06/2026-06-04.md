## 캐릭터 (01_Characters)

- **두개골 코스튬 시스템** — Skul 참고: Cat이 특정 방에서 "적 두개골 헬멧"을 일시 착용해 해당 적 종족에게 근접 데미지 +50%를 받는 위장 버프. 착용 중 적이 먼저 공격하지 않는 패시브 효과 포함. 구현 힌트: `CatState`에 `WearingDisguise` 플래그 + 감지 반경 제외 로직.
- **Crop 눈물 색상 변환** — Isaac 참고: 업그레이드에 따라 Crop의 투사체 비주얼이 변화 (노란 씨앗 → 불꽃 씨앗 → 독 씨앗). `ProjectileData` ScriptableObject를 교체하는 것만으로 외형+효과 동시 변경. 플레이어에게 빌드의 시각적 피드백 제공.
- **일시 역할 교환 업그레이드** — Skul 두개골 전환 참고: 특정 아이템 획득 시 10초간 Cat이 원거리 공격, Crop이 근접 슬래시를 담당하는 역할 교환 상태. 두 플레이어 간 소통이 폭발적으로 필요해지는 순간을 의도적으로 만들어냄.

## 적 (02_Enemies)

- **방패 적 (Shield-Only Weak)** — Isaac "특정 방법으로만 처치" 참고: 전신 갑옷을 두른 적으로, 일반 투사체는 튕겨냄. Crop의 패리 성공 시에만 방어구가 잠깐 벗겨져 Cat의 근접 슬래시 타이밍 창이 생김. Cat+Crop 완벽한 연계 필수.
- **거울 마법사** — 투사체 반사탄 참고: 자신을 향해 날아오는 투사체를 반사하는 필드를 생성. Crop의 탄환은 반사되어 역으로 날아옴. Cat의 근접 또는 패리한 투사체만 통과 가능. 구현: `EnemyBullet` → `PlayerBullet` 레이어 전환 로직.
- **탄막 보스 — 씨앗 마녀** — 탄막 패턴 참고: 원형 탄막(8방향) → 나선형 탄막 → 조준 산탄 순으로 패턴 교체. 각 패턴이 "Cat 전용 회피 구간" / "Crop 패리 구간"으로 나뉘어 두 플레이어가 번갈아 집중. `BulletPatternShooter` 컴포넌트로 패턴 전환 구현.

## 맵 (03_Maps)

- **비밀 연구실 방** — Isaac 비밀방 참고: 특정 벽에 Cat의 슬래시를 3회 가하면 균열이 생기며 숨겨진 방이 열림. 내부에 고급 업그레이드 1개 보장. 벽의 균열 상태를 `RoomWall` 컴포넌트의 `hitCount` 변수로 관리.
- **씬 전환 연출 — 방 문 통과 시 페이드** — 씬 전환 참고: 방 이동 시 카메라 즉시 이동 대신, 문 통과 시 0.3초 페이드 아웃 → 카메라 위치 이동 → 0.3초 페이드 인. `SceneLoader`의 `FadeRoutine`을 방 전환에도 재사용. 이동 감각이 훨씬 세련되어짐.
- **탄막 지뢰밭 방** — 탄막 패턴 참고: 적이 없고 바닥 타일에 일정 간격으로 탄막 발사 장치가 고정 배치됨. Cat이 근접으로 발사 장치를 파괴하거나, Crop이 투사체 사이 틈새로 통과 경로를 만드는 협력 퍼즐 방.

## 전투 (04_Combat)

- **투사체 충전 샷** — 투사체 시스템 참고: Crop이 마우스 버튼을 길게 누르면 투사체가 충전되어 크기 3배 + 데미지 5배인 대형 씨앗 발사. 충전 중 Crop은 방향 전환 불가 → Cat이 Crop을 보호해야 하는 협력 상황 자연 발생. 구현: `holdTime` 누적 후 `ProjectileData` 파라미터 스케일 적용.
- **패리 유도탄** — 유도탄 + 패리 참고: Crop이 패리 성공 시 반사된 투사체가 자동으로 가장 가까운 적을 추적하는 유도탄이 됨. `HomingProjectile.InitHoming(dir, nearestEnemy)`으로 구현. 패리의 보상 가치를 대폭 상승시켜 패리 도전 의지를 높임.
- **Cat 슬래시 투사체 강화 시너지** — Isaac 아이템 시너지 참고: "Cat이 근접 처치 시 Crop의 다음 투사체가 관통탄이 됨" 같은 크로스 캐릭터 시너지. `GameEventBus`로 Cat 처치 이벤트를 Crop이 구독. 두 플레이어의 플레이가 서로 강화되는 루프 형성.

## 스토리 (05_Story)

- **역할 반전 세계관** — Skul 참고: OnionCat 세계관에서 "인간 모험가 파티"가 진짜 악당. Cat과 Crop은 마법사의 정원을 지키는 수호자. 적으로 등장하는 "영웅 기사", "성녀 궁수", "현자 마법사"가 각 보스. 역할 반전이 주는 아이러니한 유머가 스토리 전체 톤.
- **Crop의 기억 회복 서사** — 런 진행에 따라 Crop(양파)이 자신이 왜 Cat과 함께 다니는지 조각조각 기억을 회복. 각 보스 처치 후 짧은 대화 이벤트로 서사 전달. 게임 오버 씬 전환 시 마지막으로 회복한 기억 조각을 한 줄 텍스트로 표시.
- **씬 전환으로 서사 강화** — 씬 전환 참고: 게임 오버 화면으로 전환 시 단순 페이드 블랙이 아닌, Cat이 쓰러지는 스프라이트 애니메이션 0.5초 후 페이드. 메인 메뉴로 복귀 시 Crop이 혼자 남겨진 배경 이미지로 전환. 씬 전환 자체가 스토리텔링.

## 기술 메모

- **투사체 시스템**: `ObjectPool<Projectile>` 하나만 있어도 GC 문제 80% 해결. 먼저 단일 직선 투사체 + 풀링부터 구현하고, 나중에 `ProjectileData` ScriptableObject로 유형을 늘리는 순서 권장. 패리 연계는 레이어(`EnemyBullet` → `PlayerBullet`) 전환으로 구현 가능.
- **씬 전환**: `SceneLoader` 싱글톤 + `DontDestroyOnLoad` 구조가 핵심. CanvasGroup의 alpha 보간만으로 페이드 구현 완료. `Time.timeScale = 0`인 일시정지 상태에서는 `WaitForSecondsRealtime` 사용 주의. 방 전환은 씬 전환이 아닌 카메라 이동으로 처리하되, 동일한 `FadeRoutine` 코루틴을 재사용해서 일관된 연출 가능.
