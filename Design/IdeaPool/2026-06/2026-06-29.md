## 캐릭터 (01_Characters)

- **작물 교체 캐릭터 시스템** — One Step From Eden의 8캐릭터 풀 참고: 양파 외에 당근(빠른 직선 투사체), 마늘(독+AoE 방패), 고추(폭발 투사체)를 잠금 해제 캐릭터로 추가. 각 작물마다 P2 플레이스타일이 완전히 달라져 재플레이 가치 증가. 구현 힌트: `CharacterData` ScriptableObject에 `attackPattern` 필드 추가, 투사체 프리팹 교체로 구현 가능.

- **색상 코딩 캐릭터 구분** — One Step From Eden의 스펠 타입 색상 체계 참고: 고양이는 파란색/흰색, 작물은 초록색/노란색으로 UI·이펙트·텔레그래프까지 일관된 색상 코딩 적용. 2P 화면에서 "내 캐릭터가 뭔지" 즉시 인지 가능. 구현 힌트: `CharacterColorProfile` ScriptableObject로 색상 일괄 관리.

- **잠금 해제 조건 네러티브화** — Character Unlock 참고: 단순 "n번 런 완료" 대신 "어둠의 군주에게 3번 패배한 고양이" 같은 스토리 힌트로 조건 제시. 해금 팝업에 짧은 1~2줄 배경 설명 추가 → 세계관 자연스럽게 전달. 구현 힌트: `CharacterData.unlockHint`에 스토리 문장 작성.

## 적 (02_Enemies)

- **텔레그래프 색상 = 약점 힌트** — Enemy Telegraph System 적용: 근접에만 약한 적의 공격 예고는 고양이 색(파란색), 원거리에만 약한 적은 양파 색(초록색)으로 오버레이 표시. 텍스트 없이도 "이 적은 고양이가 처리해야 한다"는 것을 직관적으로 전달. 구현 힌트: `WarningZone` 프리팹에 `SpriteRenderer.color` 파라미터로 색상 제어.

- **2단계 텔레그래프 적** — One Step From Eden 보스 디자인 참고: 일반 예고 (노란색, 1초) → 직전 경고 (빨간색 깜빡임, 0.2초) 2단계 경고 시스템. 보스 또는 엘리트 적에게 적용해 긴장감 강화. 구현 힌트: `AttackSequence` 코루틴에서 windupTime의 80% 지점에서 색상 전환.

- **범위 예고 적** — Enemy Telegraph System 경고 오버레이 참고: 일정 범위를 AoE 공격하는 적(예: 땅 내려치기)이 공격 전 원형 붉은 오버레이를 스케일 인 애니메이션으로 표시. 원의 크기가 커질수록 "이제 터진다"는 압박감 증가. 구현 힌트: `warningZone.transform.DOScale(targetScale, windupTime)` 으로 구현.

## 맵 (03_Maps)

- **텔레그래프 색상 테마 방** — One Step From Eden의 스펠 타입 + 지역 연계 참고: 각 던전 테마 방마다 등장하는 적의 약점 유형이 치우쳐 있음. "불꽃 동굴" 방에는 원거리 약점 적만 등장 → 양파 집중 방. "얼음 숲" 방에는 근접 약점 적만 → 고양이 집중 방. 플레이어가 방 진입 전 "이 방은 누가 담당"을 합의하는 협력 요소 추가.

- **잠금 해제 전용 비밀 방** — Character Unlock System 참고: 특정 잠금 해제 조건(예: 마늘 10번 수확)을 채우면 열리는 숨겨진 방 추가. 방 안에는 새 작물 캐릭터를 만날 수 있는 NPC 또는 이벤트 배치. 스토리와 해금을 공간으로 연결.

- **압박 방 (텔레그래프 훈련)** — Enemy Telegraph System 교육 설계 참고: 첫 던전에 "느린 적만 등장하는 방"을 의도적으로 배치. 긴 텔레그래프(1.5초)로 회피 연습 유도 → 자연스러운 튜토리얼. 이후 방에서 텔레그래프 시간이 짧아지며 난이도 상승.

## 전투 (04_Combat)

- **파리 연동 텔레그래프** — Enemy Telegraph System + OnionCat 파리 메카닉 연계: 적이 Windup 상태(텔레그래프 중)일 때만 양파의 방패 파리가 성공하면 피해량이 2배. "텔레그래프를 읽고 정확히 막으면 역공"이라는 고위험·고보상 메카닉. 구현 힌트: `EnemyBase._state == EnemyState.Windup`일 때 파리 성공 이벤트에 배수 적용.

- **캐릭터별 텔레그래프 반응 차별화** — Character Unlock System + Enemy Telegraph System 연계: 해금된 특수 작물(마늘)은 텔레그래프 중인 적에게 자동으로 독 상태 부여. 해금 캐릭터가 단순 스탯 차이가 아닌 전투 메카닉 차이를 가짐 → 선택의 의미 증가.

- **원거리↔근접 공략 유도 텔레그래프** — One Step From Eden Combine Mode 참고: 근접 약점 적은 Windup 중 "방어 자세"(투사체 반사)를 취함 → 양파가 쏘면 역피해. 원거리 약점 적은 Windup 중 "근접 반격 자세"를 취함 → 고양이가 들어가면 역피해. 텔레그래프가 단순 "피해라"가 아닌 "누가 공격해라"를 알려주는 정보로 승격.

## 스토리 (05_Story)

- **작물 해금 = 여정의 기억** — One Step From Eden 캐릭터 배경 참고: 각 해금 작물은 이전 런에서 만났다 사라진 동료의 "씨앗"으로 설명. "마지막 런에서 당신을 지키다 쓰러진 마늘이 씨앗을 남겼습니다"처럼 퍼마데스와 해금을 스토리로 연결. 구현 힌트: 해금 팝업에 짧은 플레이버 텍스트 1줄 추가.

- **텔레그래프 = 감정 표현** — Enemy Telegraph System을 세계관 요소로 활용: 적의 공격 예고가 단순 붉은 오버레이가 아닌 적의 감정 표현으로 연출. "분노한 적은 화염 오라", "겁먹은 적은 파란 떨림"처럼 색상과 이펙트에 감정을 부여 → 세계관 몰입도 증가.

- **잠금 해제 = 고양이의 기억** — Character Unlock System 스토리 연계: 게임 내 고양이가 여러 런을 겪으며 새 친구(작물)를 기억하고 다음 런에서 데려올 수 있게 된다는 설정. 메인 메뉴 캐릭터 선택 화면을 "고양이의 일기" 형태로 연출 → 캐릭터 선택이 스토리 요소로 승격.

## 기술 메모

- **Enemy Telegraph System**: `EnemyState.Windup` 상태를 적 상태머신에 추가하고 코루틴으로 `ShowWarningVFX → WaitForSeconds → ExecuteAttack` 순서로 구현. OnionCat 핵심 메카닉인 "약점 구분"과 연계하려면 `WarningZone`의 색상을 적 타입(`MeleeWeakEnemy`, `RangedWeakEnemy`)에 따라 다르게 설정 — 이것만 해도 텍스트 없는 직관적 정보 전달 가능.

- **Character Unlock System**: `CharacterData` ScriptableObject + `PlayerPrefs` 저장으로 최소 구현 가능. 핵심은 `RunStats` 누적 통계를 런 종료 시마다 저장하고, 해금 조건 체크를 `UnlockConditionChecker`에서 일괄 처리하는 것. 개발 초기에는 2~3개 캐릭터만 만들고, 해금 팝업 UI에 공들여 "발견의 기쁨"을 만들어주는 것이 선순위.
