## 캐릭터 (01_Characters)

- **Crop 냉동 시너지** — Noita의 "Lukki는 냉동 후 근접만 약함" 참고: Crop이 얼음 투사체를 맞혀 적을 동결 → Cat의 근접 공격이 2배 대미지 + 즉사 판정. 근거리-원거리 역할 분담의 극적인 협력 순간을 만들 수 있음 (구현 힌트: Frozen 상태 이펙트 → Cat 공격 판정 시 데미지 멀티플라이어 체크)
- **조준 방향 캐릭터 기울기** — 카메라 오프셋 연구에서 착안: Crop이 마우스로 조준하는 방향에 따라 화분 스프라이트가 살짝 기우는 애니메이션 추가. "화분이 조준한다"는 느낌으로 시각적 일체감 강화 (구현 힌트: aimDirection 벡터 → 스프라이트 rotation 보간)
- **Cat 무게감 표현** — 픽셀 퍼펙트 카메라 연구에서 착안: 대시 후 착지 시 카메라가 0.1초 미세하게 아래로 흔들림 (강도 0.3). "화분을 지고 달리는 고양이"의 묵직함을 카메라로 표현 (구현 힌트: 대시 종료 이벤트 → ImpulseSource 방향성 진동)

## 적 (02_Enemies)

- **원소 면역 적 + 조합 약점** — Noita의 피해 유형 시스템 참고: "금속 갑주 적"은 근접·원거리 단독 공격에 면역이지만, Crop의 전기 탄환으로 감전 → Cat의 근접으로 도전 연타 시 도전이 작동. 두 플레이어가 "순서대로" 행동해야만 처치 가능한 적 (구현 힌트: 상태 스택 [감전] → 다음 근접 타격에 취약 플래그)
- **카메라를 이용한 적 등장 연출** — 방 전환 카메라 연구에서 착안: 방에 진입하면 카메라가 살짝 줌아웃하며 대형 적 등장을 보여줌. 보스급 적은 입장 시 CinemachineImpulse 강도 2.0으로 바닥 충격 표현 (구현 힌트: 방 입장 이벤트 → 일시적 Orthographic Size 증가 코루틴)
- **시야각 기반 잠복 적** — Noita의 정보 비대칭 디자인 참고: 적이 벽 뒤에 숨어 Cat의 이동 소리에 반응. Cat은 접근하다가 기습당하고, Crop은 원거리 시야로 먼저 발견 가능. 두 플레이어 간 정보 공유 소통이 핵심 (구현 힌트: 적 감지 범위를 Cat/Crop 위치 기준 분리 계산)

## 맵 (03_Maps)

- **Holy Mountain 방 (Noita 차용)** — 바이옴 사이 안식처 구조: 전투 방 3~5개마다 "안식처 방" 등장. 이 방에서 Crop이 완드 업그레이드, Cat이 퍼크 선택. 적이 없고 조명이 따뜻한 색으로 자동 전환 → 플레이어가 심리적 안도감 느낌 (구현 힌트: 방 타입 Enum에 [SafeRoom] 추가 → 적 스포너 비활성, 조명 색 전환)
- **카메라 경계로 방 규모 표현** — Confiner2D 연구에서 착안: 보스 방은 일반 방의 2배 크기 Confiner → 카메라가 멀리까지 보임. 작은 방(함정 방)은 Confiner가 좁아 답답한 느낌 유발. 방 크기 자체가 긴장감의 조절 도구 (구현 힌트: 방 타입 → Confiner 크기 프리셋 설정)
- **부수기 가능한 벽 (Noita 영감)** — 완전 파괴 가능 지형 철학에서 간소화: 일부 벽에 "약한 벽" 태그. Crop의 폭발 탄환으로 파괴하면 숨겨진 통로나 보물 방 발견. 복잡한 물리 없이도 탐험 보상의 재미 구현 (구현 힌트: BreakableWall 컴포넌트 → 폭발 피해 수신 시 Destroy + 통로 활성화)

## 전투 (04_Combat)

- **패리 성공 시 방향성 카메라 진동** — CinemachineImpulse 방향성 진동 연구에서 착안: Crop이 방어막으로 탄환을 패리하면 탄환이 날아온 방향 반대로 카메라가 0.2초 흔들림. "막아냈다"는 피드백을 카메라로 강조 (구현 힌트: 패리 이벤트 → `impulseSource.GenerateImpulse(-hitDirection * 1.2f)`)
- **퍼크 선택 긴장감 — 리롤 비용 체계** — Noita 퍼크 시스템 참고: 안식처에서 퍼크 3개 중 1개 선택. 리롤은 가능하지만 골드 비용이 100 → 200 → 400으로 배가. 첫 런엔 그냥 선택, 숙련될수록 리롤 가치 계산하게 됨 (구현 힌트: PerkShop에 rerollCost 변수, 클릭마다 *2)
- **일시정지 중 런 전략 검토** — Pause Menu 기능에서 착안: 일시정지 화면에 "현재 취득 퍼크 목록"과 "처치한 적 종류"가 표시됨. 플레이어가 현재 빌드 방향을 파악하고 다음 퍼크 선택 전략을 세울 수 있음 (구현 힌트: PauseUI에 RunSummaryPanel 추가 → 퍼크 아이콘 리스트 렌더링)

## 스토리 (05_Story)

- **Noita식 지식 숨기기** — "게임이 목적·가이드·퀘스트를 알려주지 않는다" 철학 참고: OnionCat의 세계관 설명은 UI 텍스트가 아닌 환경으로만. 안식처 방 벽에 낡은 그림이 있고, 여러 런을 통해 Cat과 Crop의 관계를 조각 조각 파악하게 됨 (구현 힌트: 방 타입별 환경 스프라이트 풀 → 런마다 랜덤 조합)
- **일시정지 = 메타 내러티브 순간** — Pause Menu 연구에서 착안: 일시정지 화면 배경이 단순 어둠이 아니라 Cat과 Crop이 쉬는 모습의 픽셀아트 일러스트. "한 몸 두 의지"라는 테마를 UI 연출로 표현 (구현 힌트: PauseMenuPanel 배경 Image를 정적 일러스트 스프라이트로)
- **런 종료 시 회상 대사** — Noita의 "죽음 = 런 종료" 구조에서 착안: 게임 오버 화면에 Cat 또는 Crop의 짧은 독백. 예: "다음엔 네가 방어를 맡아." "함께라면 더 멀리 갈 수 있어." 매 런마다 풀에서 랜덤 출력 (구현 힌트: GameOver 씬에 string[] dialoguePool, 인덱스 Random.Range)

## 기술 메모

- **카메라 시스템**: Cinemachine Confiner2D의 `InvalidateCache()` 호출 필수. 방 전환 시 잊으면 카메라가 이전 방 경계를 유지하는 버그 발생. 또한 Pixel Perfect Camera + Cinemachine 함께 쓸 때 `upscaleRT = true` 설정이 핵심 — 안 하면 픽셀아트가 흐려짐.
- **일시정지 메뉴**: `Time.timeScale = 1f` 복원을 `ResumeGame()`, `RestartLevel()`, `QuitToMainMenu()` 세 곳 모두에 작성해야 한다. 하나라도 빠지면 특정 경로에서만 얼어있는 버그가 발생하고 디버깅이 어려움. New Input System 액션 맵 전환(Gameplay ↔ UI)은 ESC 더블 트리거 버그의 유일한 해결책.
