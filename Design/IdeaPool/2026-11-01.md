## 캐릭터 (01_Characters)

- **"관계 표시" 공유 UI** — Apocalypse Party 비교: 독립 HP 방식은 협동 의존도가 낮다. OnionCat의 공유 HP가 핵심 차별점인 만큼, 고양이와 양파의 "연결 상태"를 HUD에 시각화하는 아이디어 — 예: 화분 끈이 팽팽해지거나 불빛이 깜빡이는 연출로 HP 위기 상황을 강조. 구현 힌트: CoreHUD 안 CatPips 옆에 작은 끈 스프라이트 추가

- **작물 고유기 R "성장 연출"** — 매운 양파 고유기 사용 시 화분에서 양파가 잠깐 더 크게 자라는 스프라이트 애니메이션 삽입. 타격감 연출이면서 작물이 화분에 실제로 있다는 것을 재차 인지시킴. 구현 힌트: 양파 스프라이트에 DOTween Punch Scale 0.5초

- **배경 Attract 캐릭터 뒷모습** — 메인 메뉴 배경에 고양이 등에 화분 탄 실루엣이 천천히 걷는 루프 애니메이션 (어트랙트 모드 진입 전부터). 게임 컨셉을 메뉴에서 즉각 전달. 구현 힌트: MainMenu 씬 배경 레이어에 루프 Timeline

## 적 (02_Enemies)

- **"협동 전용 약점" 적 패턴** — Apocalypse Party에 없는 OnionCat만의 강점: 특정 적이 고양이 근접 후 양파 사격 순으로만 취약해지는 패턴 (근접 때리면 약점 등 노출 → 작물이 쏴야 큰 피해). `EnemyBase.Status`에 `BackExposed` 상태 추가 + `Attacker.Cat` 피격 후 1초간 `Attacker.Onion`에 약점 배율 적용 가능

- **느린 대형 적 + 빠른 소형 적 조합** — 대형 적이 고양이를 끌어당기는 동안 소형 적이 사각에서 사격. Apocalypse Party의 "같이 쏘기"만으로 해결 가능한 설계와 달리, OnionCat은 고양이가 근접에 묶이고 양파가 소형 처리해야 하는 역할 분담 강제 상황. 전투방 스쿼드 설계에 활용

- **피격 시 실명 적** — 씨앗탄 연속 3발에 적이 1.5초간 랜덤 이동하는 시각 혼란 상태이상. "눈을 맞추면 흔들린다"는 직관적 피드백 + 고양이의 킥/할퀴기 연계 포인트. `EnemyBase.Status`에 `Dazed` 상태 추가, 이동 방향에 sin 노이즈 적용

## 맵·런 구조 (03_Maps)

- **협동 전시 전용 방** — Apocalypse Party가 단순 전투만 있는 것과 달리, OnionCat은 "고양이가 발판 밟고 양파가 수정 쏘는" 2인 기믹 방이 있다. 이 방 유형을 각 스테이지당 1개 보장 배치. `DungeonManager.stagePlan`에 `?coop` 토큰 추가 → `RunEvents.cs`에서 협동 기믹 이벤트로 매핑

- **방 구조 "함정 구역"** — 구덩이(Pit)를 특정 방에 집중 배치해 걷어차기 꺼진 현재 구조에서도 장애물 다양성 제공. 구덩이 없는 방 80% + 구덩이 집중 방 20%로 비중 조절. `RoomLayouts`에 pit-heavy 방 모양 추가

- **런 도중 지도 공개** — 현재 `RunMap.cs` 8층 갈림길 지도가 있지만, 이미 클리어한 방의 내용(적 종류, 획득 아이템)을 아이콘으로 기록해 복기 가능하게. 기억과 전략을 강화. `RunMap`의 방 노드에 `clearedWith: EnemyType[]`, `rewardGiven: GearId` 필드 추가

## 전투·협동 (04_Combat)

- **패링 → 즉시 협동 게이지 +15** — 현재 패링이 +10인데, 성공적 패링이 리스크 있는 행동이므로 보상 강화. Apocalypse Party는 패링이 없어 OnionCat의 패링이 큰 차별점. 패링 성공 시 금색 "PARRY!" + 합동 게이지 즉시 찰 경우 합동기 자동 대기 UI 점멸

- **고양이 특수 공격 → 합동 게이지 폭발 소비 옵션** — 야성 게이지가 가득 찰 때, 합동 게이지도 80% 이상이면 "합동 특수"로 변환되어 둘 다 소모하지만 효과가 2배. 타이밍 맞추기의 도전감 + 둘이 함께하는 절정감. `CatSpecial`에서 합동 게이지 80% 체크 → `GameManager.TryJointSpecial()` 분기

- **방 클리어 후 "협동 점수 평가"** — Apocalypse Party의 단순 "다 잡음" 완료와 달리, 방 클리어 시 협동 콤보 횟수 / 패링 성공 / 부상 없이 클리어 여부에 따라 별 1~3개 표시. 시각적 보람 + 씨앗 보너스 +5/+10. 구현은 전투 중 통계 수집 → `BattleResult` 구조체 → 클리어 시 팝업

## 아이템·세트 (05_Items)

- **세트 4단계 달성 연출 강화** — 현재 세트 달성 시 HUD 아이콘 밝아짐 정도인데, Apocalypse Party의 레벨업 카드 선택처럼 보상감이 큰 연출이 필요. 4단계 완성 시 화면 가장자리 해당 세트 색 플래시 0.5초 + "SUN BONUS!" 뜨는 팝업. `CombatModifiers.Has` 호출 지점 근처에서 이전 단계 → 신규 단계 전환 감지 후 이벤트 발행

- **분해 씨앗 → 부분 효과 기억 시스템** — 분해한 장비의 효과를 "효과 파편"으로 보관해 나중에 상점·휴식에서 50% 가격으로 다른 장비에 이식. Apocalypse Party는 카드 선택뿐 아무것도 남지 않는 구조와 대비되는 깊이. 이미 "분해로 모은 효과 중 고르기" 구조가 있으므로 가격 할인 로직만 추가

- **작물 마법서 3칸 조합 효과** — 같은 세트 마법서 3권을 모두 채웠을 때 숨겨진 4번 스킬 슬롯 활성화 (패드 없을 때 5번 키). Apocalypse Party의 단순 스탯 누적과 차별화되는 빌드 심화. `RunData.SpellbookSlots` 3칸이 모두 같은 세트 마법서일 때 `UnlockBonusSkill(set)` 호출

## 스토리·메타 (07_StoryMeta)

- **Attract Mode 농장 뒷마당 컷씬** — 메인 메뉴 30초 어트랙트 시퀀스: 처음에 고양이가 화분을 들고 문 밖으로 나가는 장면 → 전투 하이라이트 → 등대탑 실루엣 → "두 명이서 떠나는 이야기" 타이틀 재등장. Attract Mode 기술 파일의 Timeline 방법 1 활용. 대화 없이 순수 비주얼로 컨셉 전달

- **온실 "구매 전 미리보기"** — 온실 화면에서 잠긴 장비에 마우스를 올리면 "어떤 적이 사용하는지" 또는 "언제 처음 보게 되는지"를 흐릿한 텍스트로 표시 (스포일러 주의). 해금 동기 강화. `GearItem.UnlockHint` 문자열 필드 추가 (선택 입력)

- **마녀 대사 단계별 이름 변화** — `MetaProgress.WitchFreed` 전: 낡은 책(깐깐한 존댓말), 후: "그리모". 이미 구현 예정이지만, 추가로 반전 직전 마지막 대화에서 "낡은 책"이 갑자기 문어체가 흔들리는 연출(글자 색 점멸 0.2초)을 삽입. `Dialogue.Say` 호출 시 특수 플래그 `isBreaking: true` → TMP 텍스트 색 트윈

## 기술 메모

- **Tilemap Composite Collider**: Wall 타일맵에 `CompositeCollider2D` + `Rigidbody2D(Static)` 추가 후 `TilemapCollider2D` → Used By Composite 체크. `Room.ResetForReuse` 끝에 `compositeCollider.GenerateGeometry()` 한 줄 추가. 현재 40×20 방 기준 충돌 수 80% 이상 감소 기대 — 이미 실행 중인 방 타일맵에 적용 가능

- **Attract Mode**: 전시 직전 구현. MainMenu 씬에 `AttractModeManager.cs` 추가 → 25초 idle 감지 → Timeline PlayableDirector 재생. 고양이+양파 협동 장면 30초 루프. 메뉴 UI CanvasGroup 페이드 처리. 키/패드 입력 시 즉시 복귀. WebGL도 지원 가능(VideoPlayer 방식 제외)
