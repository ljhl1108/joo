## 캐릭터 (01_Characters)

- **빌드 심화 비주얼** — Inkbound 참고: 런 중반부터 Cat과 Onion의 외형에 미세한 변화를 주어 빌드 방향을 시각화. 예: 공격 스택 축복을 3개 이상 가지면 고양이 발톱 이펙트가 커짐, 양파가 불 속성 스킬을 보유하면 머리 불꽃 파티클 추가
- **공격성 강제 상태** — Post Void 참고: 고양이 체력이 30% 미만이면 "분노" 상태 — 이동 속도+15%, 공격 판정+10%, 하지만 양파 방어막이 비활성화. 두 플레이어 모두에게 위기감 부여
- **Onion의 "차지 포즈" 모션** — 마우스를 오래 누르고 있으면 양파가 몸을 웅크리는 모션 추가 → 방어-공격 전환의 타이밍을 상대(적)에게도 읽히게 함. 비대칭 역할 강화

## 적 (02_Enemies)

- **의도 아이콘 적** — Inkbound 참고: 다음 공격 타입(근접/원거리/범위)을 머리 위 아이콘으로 2~3초 전에 표시하는 적. 색상 코드: 주황=Cat 처리 필요, 파랑=Onion 처리 필요. 코어 시스템의 비대칭 약점을 자연스럽게 가르치는 적
- **속도 압박 군집체** — Post Void 참고: 빠르게 쏟아지지만 체력이 낮은 군집 적. 처치하지 않으면 화면 가득 채움 → "처치 속도 = 생존"이라는 긴장감 조성. `Enemy_Swarm_Optimization.md` + `UpdateManager` 패턴으로 최적화
- **역할 강제 교관 적** — 근접 공격은 실드로 막고, 원거리만 피해를 입는 "방어전사형" 적. Cat 혼자로는 절대 못 잡음. 둘이 아니면 진행 불가한 방 디자인의 핵심 적

## 맵 (03_Maps)

- **로비 시각화 방** — Coop Pre-Run Lobby 참고: 첫 번째 방을 "연습 방"으로 — 적은 없고 마네킹과 간단한 장애물만 있어 두 플레이어가 조작을 익히고 자연스럽게 "준비 완료"가 됨. 첫 번째 문을 통과하는 것이 곧 READY
- **좁아지는 방** — Post Void 참고: 시간이 지남에 따라 벽이 서서히 좁아지는 방. 빠르게 처치하지 않으면 이동 공간이 없어짐. 근접 고양이에게 특히 불리 → 양파의 원거리 속공이 유리한 상황 연출
- **의도 공개 방** — Inkbound 참고: 방 입장 직전 이 방에 나올 적들의 종류를 간판/홀로그램으로 미리 보여주는 방. 두 플레이어가 전략 논의 → 협동의 언어가 생김

## 전투 (04_Combat)

- **협동 콤보 충전 게이지** — Inkbound 콤보 시스템 참고: Cat이 적을 때리면 "Co-op 게이지"가 차고, Onion이 같은 적을 이어 때리면 게이지가 폭발하여 화면 전체 피해. 기존 코어 시스템 `Attacker.Cat/Onion` 구분을 활용
- **처치 시 체력 미세 회복** — Post Void 참고: 매 적 처치 시 Cat/Onion 공유 체력의 1~2% 회복. 공격적으로 싸울수록 생존율이 높아지는 "보상 루프" 구축
- **UpdateManager 기반 탄막 방** — 투사체 100개 이상이 쏟아지는 방. UpdateManager 패턴 적용 시 20개 이상의 적 + 각 적당 발사체 5개 = 100개+ 투사체도 프레임 유지. 기술 검증 겸 게임플레이 특색 방으로 사용

## 스토리 (05_Story)

- **시작 로비의 대화** — Coop Lobby 참고: 런 시작 전 로비 화면에서 Cat과 Onion이 짧은 대사를 주고받음. "준비됐어?" / "항상." → 이미 둘이 오래된 파트너임을 암시하는 1~2줄 대화 (런마다 랜덤)
- **고양이의 지쳐감** — Post Void의 "멈추면 죽는다" 테마 참고: 런이 길어질수록 Cat의 주석 대사가 지쳐가는 내용으로 바뀜. "조금만 더..." "등이 무겁다..." → 양파라는 존재의 무게감을 내러티브로
- **처음 만난 기억** — 런 첫 번째 방에서 Cat이 혼자 들어오다가 화분 양파를 우연히 등에 태우게 되는 짧은 연출 (첫 런에만 재생). Lobby Screen에서 자연스럽게 이어지는 도입부

## 기술 메모

- **Custom MonoBehaviour UpdateManager**: `IUpdatable` 인터페이스 + 중앙 `UpdateManager`로 적/투사체 수백 개의 Update 오버헤드를 C# 브리지 1회로 줄일 수 있다. `EnemyBase`와 `Projectile`의 `OnEnable/OnDisable`에서 Register/Unregister 연동. `PoolManager`와 함께 쓰면 추가 코드 없이 자동 동작. **투사체가 20개 이상 화면에 존재하는 방을 만들 계획이라면 지금 설계에 포함할 것.**

- **Co-op Pre-Run Lobby Screen**: "시작 버튼 → 던전 입장" 사이 화면. Cat은 Space/패드 South, Onion은 좌클릭으로 READY 토글. 둘 다 READY가 되면 3초 카운트다운 후 씬 전환. 구현 순서: ① PlayerReadyPanel UI 제작 → ② 각 플레이어 InputAction 연결 → ③ CountdownCoroutine → ④ GameManager.ChangeState(Loading) 호출. **컨트롤 미리보기를 여기서 보여주면 튜토리얼 씬 없이도 첫 진입 장벽을 낮출 수 있다.**
