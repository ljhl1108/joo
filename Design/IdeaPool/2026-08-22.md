## 캐릭터 (01_Characters)

- **줄기 연결 표시** — Rusted Moss 참고: 고양이와 화분 사이에 반투명 덩굴 LineRenderer를 연결. 두 플레이어 간 거리가 가까울수록 덩굴이 초록색·굵게, 멀어질수록 갈색·얇게 시각 변화 → 연결 상태를 직관적으로 전달
- **화분 흔들림 리액션** — Rope_Tether_System 참고: 고양이가 급격히 방향 전환·대시 시 화분이 물리 SpringJoint처럼 살짝 반응 (Rotation 트위닝). Player 2 조준이 일시적으로 어려워지는 패널티 겸 귀여운 연출
- **양파 "뿌리 닿기" 상태** — Rusted Moss의 로프로 적 묶기에서 착안: 화분의 뿌리가 바닥에 닿으면 Player 2의 발사 쿨다운 감소 버프. 고양이가 정지해줘야 발동 → 순간적 협력 의존 창출

---

## 적 (02_Enemies)

- **로프 감기형 적** — Rusted Moss 참고: 긴 넝쿨·체인을 가진 적이 고양이에게 달라붙어 이동 속도를 줄임. 양파가 원거리로 넝쿨을 잘라줘야만 해제 — 근접 혼자서는 해결 불가
- **타이머 가속 적** — Speedrun Timer 참고: "저주받은 시계" 적이 등장하면 인게임 타이머가 1.5배 속도로 진행. 빠르게 처치할수록 시간 페널티 최소화 → 플레이어에게 시간 압박을 주는 새로운 피해 유형
- **분리 강요 보스** — Rusted Moss의 "두 플레이어 분리 불가" 역발상: 보스가 두 플레이어를 특정 거리 이상 억지로 밀어내는 파동 공격. 거리가 너무 벌어지면 약점 노출. 거리 유지가 핵심인 페이즈

---

## 맵 (03_Maps)

- **덩굴 통로 방** — Rusted Moss 로프 이동 착안: 덩굴/줄기에 달린 고리를 고양이가 대시로 붙잡으면 빠른 이동 가능한 특수 방. 양파 조준이 흔들리므로 이동 전 교통 정리 필요
- **협소 복도 방** — 화분 폭 때문에 단독 이동이 어려운 좁은 통로. 고양이가 먼저 진입해 적 제거 → 양파 안전 통과를 위한 역할 분담 강제 구역
- **타이머 챌린지 방** — 방 입장 시 카운트다운 타이머 발동. 제한 시간 안에 모든 적 처치 시 보너스 아이템. 실패 시 패널티 없음 → 리스크 없는 도전 콘텐츠로 부담 없이 즐길 수 있음

---

## 전투 (04_Combat)

- **텐션 게이지 차징** — Rope_Tether_System 텐션 감지 착안: 두 플레이어가 서로 반대 방향으로 이동하면 "텐션 게이지" 충전. 만충 시 고양이는 초강력 돌진, 양파는 차지샷 해금 → 협동 콤보의 보상 기전
- **스플릿 클리어 기록** — Speedrun Timer 스플릿 착안: 각 방 클리어 시 소요 시간을 표시. "이 방 최고기록 3.2초" vs "현재 7.1초" 비교로 자연스럽게 도전 의욕 자극
- **파리 패리-카운터 체인** — Rusted Moss 적 묶기 + OnionCat 패리 결합: 양파가 패리 성공 → 고양이에게 "카운터 윈도우" 신호 → 고양이가 윈도우 안에 슬래시 시 두 배 피해. 시각·청각 신호가 동기화되어야 하므로 높은 수준의 협력 요구

---

## 스토리 (05_Story)

- **두 존재의 계약** — Rusted Moss의 두 캐릭터가 로프로 운명 공유하는 것 착안: 고양이와 양파(채소)는 고대 식물 정령과의 계약으로 묶인 파트너. 채소가 죽으면 고양이도 힘을 잃고, 고양이가 쓰러지면 채소도 시든다 → 공유 체력 바의 내러티브 근거
- **시계탑의 저주** — Speedrun Timer 테마 착안: 게임 세계에 "런이 길어질수록 더 강해지는 최종 보스"가 있다는 전설. 플레이어가 빠르게 진행할 동기를 스토리로 뒷받침
- **덩굴의 기억** — 화분에 담긴 양파 채소는 전 런에서 죽은 양파의 후계. 각 런마다 새로운 채소가 자라며 전 런의 기억을 희미하게 계승 → 퍼마데스의 슬픔을 완화하는 내러티브 메타포

## 기술 메모

- **Rope_Tether_System**: OnionCat에 즉시 적용 가능한 핵심은 `DistanceJoint2D + LineRenderer` 조합. 두 플레이어 사이 거리 제한을 물리로 강제하고, LineRenderer로 덩굴 연결선을 시각화. `TensionRatio`로 거리 경고 UI까지 연동하면 플레이어 소통 도구가 됨. 세그먼트 방식 체인은 성능 비용이 있으므로 시각 전용으로 LineRenderer만 사용하는 게 초보 개발자에게 현실적.

- **Speedrun_Timer_System**: 구현 순서가 중요. RunTimerManager 싱글톤 → GameManager 연동 → PauseMenu 연동 → RunResultScreen 표시 순서로 단계적으로 붙이면 된다. 최우선은 IGT 정확성 (Time.deltaTime 기반 누적 + 일시정지 시 자동 정지). PlayerPrefs 저장은 3줄이면 충분하므로 개인 최고기록도 함께 구현할 것.
