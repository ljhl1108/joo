## 캐릭터 (01_Characters)

- **트레이드오프 업그레이드** — Blazing Beaks 참고: 업그레이드 선택지 중 일부를 "Cat 강화 + Crop 약화" 혹은 그 반대로 설계. 두 플레이어가 상의하며 양보하는 협동 경험 자체가 게임플레이. 구현: `UpgradeData`에 `catEffect`와 `cropEffect` 필드 분리, 카드 UI에 두 아이콘으로 각 효과 표시
- **위기 시 Crop 시들기 애니메이션** — 공유 HP 30% 이하 시 DOTween으로 Crop 스프라이트 색상을 `DOColor(new Color(0.6f, 0.9f, 0.4f, 1f), 1.5f).SetLoops(-1, LoopType.Yoyo)`로 서서히 시들어 보이게 연출. Animator 없이 코드 한 줄로 생사 긴장감 전달
- **업그레이드 카드 희귀도 색상 구분** — 카드 테두리를 Common(흰색) / Rare(파란색) / Epic(보라색)으로 DOTween으로 glow 펄스 처리. Epic 카드는 `DOColor`로 보라 ↔ 밝은 보라를 반복해 희귀함 강조. 픽셀아트 스타일과도 어울리는 단순한 연출

## 적 (02_Enemies)

- **리스크 투사체 적** — Blazing Beaks 아이템 철학 응용: "패리하면 3배 반사, 하지만 실패 시 2배 대미지"인 특수 투사체를 쏘는 적. 황금색 발광 투사체로 시각 구분. DOTween으로 투사체 이동 경로를 포물선 트윈(DOPath)으로 연출
- **업그레이드 방해 적 — 선택 강요** — 방 클리어 직전에 "업그레이드 도둑" 소형 적이 등장, 처치하지 않으면 다음 업그레이드 선택지 수가 3 → 2로 줄어듦. 협동해서 빠르게 처치해야 하는 압박 연출. DOTween으로 도둑 적 위에 카운트다운 원형 UI 표시
- **쌍둥이 적 (스플릿 약점)** — 근접형과 원거리형이 쌍으로 등장, 서로 연결된 실(LineRenderer)로 묶여 있음. 한 마리를 먼저 처치하면 나머지가 강해짐 → Cat이 근접형을, Crop이 원거리형을 동시에 처치해야 함. Blazing Beaks의 "빌드 시너지 요구" 적 설계 응용

## 맵 (03_Maps)

- **업그레이드 선택 전용 방** — 방 클리어 후 별도 "선택 방" 씬으로 이동하는 대신, 현재 방 안에서 DOTween으로 화면 어둡게 + 카드 3장 슬라이드 인 연출. 씬 전환 로딩 없이 자연스러운 흐름. `upgradePanel`을 World Space Canvas로 전장 중앙에 띄우는 방식도 검토
- **짧은 스프린트 맵 구조** — Blazing Beaks의 "10분 런" 철학: OnionCat MVP는 3-방-미니보스 구조로 시작. 방 1개 = 1~2분, 전체 런 = 7~10분. 개발 및 밸런스 검증 주기가 빨라져 완성 속도 향상
- **비밀 방 표시 연출** — 방 미니맵에서 비밀 방 인접 시 DOTween으로 해당 방 아이콘을 살짝 흔들기(`DOShakePosition(0.5f, 0.05f)`). UI에만 적용하므로 게임플레이에 영향 없음. 탐험 욕구 유도

## 전투 (04_Combat)

- **업그레이드 적용 시 캐릭터 반응** — 업그레이드 선택 완료 시 Cat은 DOTween으로 위로 점프(`DOLocalMoveY(+0.3f, 0.1f).SetLoops(2, LoopType.Yoyo)`), Crop은 잎이 활짝 피는 스케일 업 연출. 선택이 "보상"처럼 느껴지게 함
- **DOTween 히트스톱** — 적 처치 시 `Time.timeScale = 0f`를 0.05초 유지 후 `DOTween.To(() => Time.timeScale, x => Time.timeScale = x, 1f, 0.1f).SetUpdate(true)`로 서서히 복구. Animator 없이 히트감 극대화
- **체력바 지연 감소 (붉은 잔상)** — 피격 시 초록 게이지는 즉시 감소, 빨간 잔상 게이지는 `DOFillAmount(target, 0.5f).SetEase(Ease.InOutSine)`으로 0.5초 후 따라옴. 플레이어가 "얼마나 맞았는지" 직관적으로 인지. Upgrade_Selection_Screen.md 코드 예시 참고

## 스토리 (05_Story)

- **업그레이드의 세계관 설명** — 업그레이드 카드 제목을 "양파 요정의 축복: 슬래시 강화" 형태로 명명. Crop(양파 요정)이 Cat에게 능력을 부여하는 스토리적 당위성 확보. 카드 상단에 Crop이 작은 마법을 거는 2프레임 픽셀 아이콘 삽입
- **리스크 업그레이드 거절 대사** — "다음에" 버튼(업그레이드 스킵)을 누를 경우 Cat이 "흥, 필요 없어"라는 짧은 말풍선 표시. Blazing Beaks의 가볍고 통통 튀는 분위기 참고. DOTween으로 0.5초 후 자동 사라짐
- **선택 연출이 곧 스토리** — 업그레이드 선택 화면에 각 카드 설명을 "Crop이 말하는 형식"으로 작성. "이 씨앗을 심으면 더 강해질 수 있어요!" 같은 1인칭 대사. UI 텍스트이지만 세계관 몰입을 높이는 내러티브 레이어

## 기술 메모

- **DOTween & 트위닝**: `Time.timeScale = 0f` 상태에서 반드시 `.SetUpdate(true)` 필수. 업그레이드 화면, 히트스톱, 씬 전환 페이드 등 모두 이 패턴을 씀. `OnDestroy()`에서 `DOTween.Kill(transform)` 호출 습관화 — 오브젝트 파괴 후 트윈이 남아 `MissingReferenceException` 발생하는 흔한 버그 방지.
- **업그레이드 선택 화면**: `UpgradeData` ScriptableObject를 먼저 만들고, `UpgradeDatabase`에 모두 등록한 다음 `UpgradeSelectionManager`를 붙이는 순서로 구현. `Time.timeScale = 1f` 복구를 `OnComplete()` 콜백 안에 넣는 것을 잊으면 게임이 영구 정지하는 버그 발생 — 방어 코드로 `OnDestroy`에도 `Time.timeScale = 1f` 추가.
