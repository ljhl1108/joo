## 캐릭터 (01_Characters)

- **고양이 행동 반응 나레이션** — Bastion 참고: 특정 행동(적을 불로 태움, 구덩이에 떨어뜨림, 첫 보스 처치)에 "낡은 책"이 짧게 반응하는 대사 추가. 대사는 `StoryLines.cs`에 등록, `Dialogue.Say` 한 줄로 처리 가능. 반복 방지를 위해 행동당 2~3개 중 무작위 선택
- **고양이 실루엣** — 큰 소품·문 뒤에 고양이가 완전히 가려질 때 반투명 흰색 실루엣으로 위치 표시. URP Render Objects Feature + ZTest Greater로 구현. `SortingGroup`이 묶여 있으므로 고양이 파츠 전체를 같은 레이어로 묶으면 됨

## 적 (02_Enemies)

- **적 실루엣** — 장애물 뒤 적 위치 힌트용 옅은 붉은 실루엣. 고양이 실루엣과 같은 Render Objects 패스를 활용, 적 레이어용 패스 추가. 투명도를 고양이(90%)보다 낮게(50%) → 적은 "있는 것 같다" 힌트 수준으로
- **환경 반응 적** — Trigger Witch 참고: 얼음 상태 적이 불/강타에 맞으면 빙결 파편 광역 / 불 상태 적이 물 씨앗에 맞으면 증기 화면 가림. `EnemyBase.ApplyBurn`·`ApplyStun` 조합 훅으로 처리 가능

## 맵·런 구조 (03_Maps)

- **허브 건물 역할 명확화** — Bastion 참고: 각 건물(온실·등불·가판대·샘물)이 하는 일을 아이콘·짧은 설명으로 처음 방문 시 1회 튜토리얼. 플레이어가 마을에서 뭘 해야 할지 직관적으로 파악. `StoryLines.cs`에 첫 방문 감지 → 말풍선 한 줄
- **그려진 방 카메라 오클루전** — 한 화면보다 큰 방에서 카메라가 이동할 때, 화면 가장자리 외 영역의 소품도 고양이를 가릴 수 있음. 실루엣 시스템을 적용하면 카메라 뷰 밖에서 걸어오는 고양이도 Wall 레이어에 가려지는 구간 처리 가능

## 전투·협동 (04_Combat)

- **셀프 핸디캡 선택 이벤트** — Bastion God Shrine 참고: 물음표 방에서 "난이도 올리고 보상 증가" 이벤트 추가. 예: "이 방부터 적 HP +50%지만 다음 방 장비 1개 추가." 현행 `RunEvents.cs` 이벤트 목록에 추가, `TimedEffects`로 N방 동안 적용
- **환경 상호작용 연쇄** — Trigger Witch 참고: 불 항아리를 발로 차면 넓은 범위 화염, 얼음 덩이를 쳐서 미끄러지게. 물질 충돌 연쇄를 `EffectZone` + `EnemyBase.Status` 조합으로 — 개발 비용은 중간, 발견의 재미는 큼

## 아이템·세트 (05_Items)

- **무기 콤보 시너지 명시** — Bastion 참고: 고양이 무기와 작물 씨앗이 함께 쓸 때 시너지를 `GearItem` 설명에 한 줄로 힌트. 예: "불꽃 할퀴기 + 얼음 씨앗 = 증기 폭발" → 콤보 발견을 유도. 아이템 툴팁에 "○○와 함께 쓰면 좋아요" 한 줄 추가
- **New Game+ 무기 유지** — Bastion NG+처럼 "철인 모드: 장비를 유지한 채 처음부터" 해금 조건 추가. `MetaProgress`에 `ironRunUnlocked` 플래그, 온실 해금 조건으로. 실제 구현은 런 시작 시 `RunData`에 이전 런 장비를 복사하는 것으로 충분

## 스토리·메타 (07_StoryMeta)

- **트레이딩 카드 아트 계획** — Steam 출시 준비로 고양이·양파·해바라기·버섯·그리모 5장 카드 세트 기획. 카드 아트는 게임 내 완성도 높은 Final 그림 재활용으로 추가 비용 최소화. 배지는 고양이 얼굴 아이콘(80×80) 5단계 — 귀 색만 바뀌는 식으로 단순하게
- **나레이터 행동 목록 선정** — 말하는 책이 반응할 "특별한 순간" 10개 선정 목록 작성. 예: 첫 적 처치, 첫 보스, 고양이가 구덩이 근처에 있을 때(경고), 모든 씨앗 소진, 완벽 클리어(데미지 0). `Design/StoryLines.cs` 작성 전에 목록을 `Design/01_Characters.md`에 추가

## 기술 메모

- **Sprite 실루엣**: URP Render Objects Feature를 활용. 패스 1(정상 렌더) + 패스 2(ZTest Greater로 가려진 부분만 실루엣 머티리얼). 고양이의 `SortingGroup`이 묶여 있어 파츠 전체가 함께 실루엣됨 — 별도 처리 없음. 그려진 방의 Wall 레이어 오클루더와 판정이 일치해 별도 마스크 오브젝트 불필요
- **Steam 트레이딩 카드**: 게임 코드 변경 없음 — Steamworks 웹 패널에서만 설정. 출시 후 Valve 자격 부여 대기 → 에셋 준비 → 제출 순서. 카드 아트는 206×184px, 픽셀 아트보다 업스케일 일러스트 or 노픽셀 버전 권장 (너무 작아 보임)
