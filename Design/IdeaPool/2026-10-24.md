## 캐릭터 (01_Characters)
- **세트 태그 HUD 상시 표시 개선** — Voidigo 참고: 현재 오른쪽 아래에 가장 많이 모은 세트 2개만 표시하는 것에서, 보유한 모든 세트를 작은 아이콘 + 숫자로 나열하는 방식으로 확장. "햇살 2/4 ○○●●" 진행 바 형태면 장비 선택 시 전략성이 즉시 보임.
- **무기 외형 ↔ 특수 공격 일관성** — Voidigo의 생체 무기에서 영감: 고양이 무기 아이콘이 해당 특수 공격 형태를 직관적으로 암시하도록 통일 검토. 회오리 무기 = 소용돌이 아이콘 + 회오리 특수, 도약 무기 = 발톱 도약 아이콘 + 덮치기 특수. 이미 5가지 특수 구현 ✅, 아이콘 일관성만 확인.
- **마법서 키 힌트 UI** — 스킬 키(Q·W·E)에 해당 마법서 아이콘과 쿨다운 상태를 항상 표시. Voidigo 무기 슬롯 디스플레이 참고. HUD 양파 측 아래 배치.

## 적 (02_Enemies)
- **AoE 탐지 공간 해싱 교체** — 공간 해싱 참고: 포자 구름·박 폭발·합동기의 `Physics2D.OverlapCircle`을 `SpatialHash2D<EnemyBase>.Query`로 교체. `EnemyBase.Active` 목록으로 매 프레임 Clear+재삽입 구현 가능. 현재 방당 적 수(~20)에선 성능 차이 없으나 코드가 Physics 레이어 의존에서 독립됨.
- **적 전술 콤비 태그** — Voidigo의 적 역할 명확성에서 영감: 스쿼드 시스템에 "원거리+방패" "소환형+돌격형" 같은 공식 콤비 구성을 몇 가지 더 정의. 플레이어가 방에 들어서자마자 적 역할 분담을 직관적으로 읽도록.
- **씨앗 폭발 드롭 연출** — 다수 적 처치 후 씨앗이 폭발적으로 튀어 나오는 연출 (현재는 드롭 후 대기). 씨앗 수집 장면을 흥겹게 만들고 전투 클리어 만족감 강화. PoolManager로 씨앗 튀기기 이펙트 추가.

## 맵·런 구조 (03_Maps)
- **스프린트 런 모드** — Voidigo의 짧은 런 루프에서 영감: `DungeonManager.stagePlan`을 짧게 설정한 "빠른 런" 옵션(2 스테이지 × 3~4 방, 20~30분). 메인 메뉴 난이도 선택 화면에 추가. 구현 비용 낮고 가벼운 플레이세션 수요 충족.
- **밸런스 외부화 파일** — 모드 지원 참고: `Application.persistentDataPath/balance_override.json`으로 적 체력 배수·씨앗 드롭률·상점 가격 등을 빌드 후에도 조정 가능하게 외부화. 플레이테스트 피드백 반영 주기 단축.
- **방 내 오브젝트 공간 해싱** — 식물(박·포자 구름)의 적 근접 감지, 씨앗 자석 흡수 반경에 SpatialHash2D 활용. 방에 파티클+이펙트 오브젝트가 50개 이상일 때 Trigger 콜라이더 수 감소 효과.

## 전투·협동 (04_Combat)
- **붙은 적 콤보 (Stuck Combo)** — 고양이가 던진 털뭉치에 둔화된 적을 양파가 직격하면 "STUCK COMBO" 추가 배율(×1.7, 현재 콤보 ×1.5보다 높게). Voidigo의 무기 던지기 후 연계 공격에서 영감. `Projectile_Seed` 피격 시 플래그 + 1초 내 털뭉치 둔화 적에게 히트 감지로 구현.
- **패링 세트 시너지** — Voidigo 태그 시너지 참고: "패링 성공 = 협동 콤보 1회로 계산" 또는 "패링 후 0.5초간 다음 씨앗 관통" 세트 효과 추가. 양파가 방어를 공격적으로 활용하는 유인 강화.
- **보스 패턴 소리 다양화** — Voidigo의 패턴마다 다른 소리+색 조합에서 영감: 현재 노랑·빨강 색상에 더해 보스 패턴별 고유 SfxId 할당. 패턴 예고 시작 시 독특한 소리가 나면 화면을 안 봐도 대피 타이밍을 파악 가능.

## 아이템·세트 (05_Items)
- **던지기 트리거 세트** — Voidigo 던지기 무기에서 영감: "털뭉치 투척 적중 시 세트 효과 발동", "던진 물건이 벽에 충돌 시 폭발" 등 투척 액션을 GearEffect 발동 트리거로 쓰는 장비군 제안. 걷어차기가 꺼진 지금 던지기 액션의 전략적 비중을 올릴 기회.
- **중복 드롭 선택 미니게임** — Voidigo의 아이템 레벨업 방식에서 영감: 현재 중복=자동 레벨업에서, 중복 발생 시 "공격력 +15% / 새 효과 추가 / 다음 세트 단계 즉시 달성" 3선택으로 교체하면 중복 드롭도 흥미로운 결정 순간이 됨.
- **balance_override.json 장비 수치 덮어쓰기** — 모드 지원 참고: `GearItem`의 `attackBonus`, `cooldown` 등 수치를 JSON에서 ID 기준으로 덮어쓰는 기능을 개발 도구로 추가. 출시 후 핫픽스 또는 이벤트 기간 임시 버프를 코드 변경 없이 적용 가능.

## 스토리·메타 (07_StoryMeta)
- **온실 해금 간결화** — Voidigo가 메타 진행을 최소화한 것처럼, 온실 해금 비용 표를 "조건 1개 달성 → 즉시 해금" 원칙으로 리뷰. 조건이 2단계 이상이면 플레이어가 "아직 멀었다"고 느낌. GearItem.UnlockCost 조건을 단순화.
- **엔딩 후 커뮤니티 티저** — 클리어 화면 또는 크레딧에 "향후 Steam Workshop 모드 지원 예정" 한 줄 추가. 커뮤니티 기대감 조성 + 모드 생태계 씨앗 심기.

## 기술 메모
- **2D 공간 해싱**: `SpatialHash2D<EnemyBase>` 하나를 EnemyManager에서 관리하고 LateUpdate에 Clear + 재삽입. `EnemyBase.Active` 리스트가 이미 있으므로 10줄 이내 구현 가능. AoE 데미지와 씨앗 자석 반경에 먼저 적용. 성능 이점은 적 수 30+ 또는 AoE가 초당 10회 이상일 때 체감.
- **모드 지원**: `ContentBuilder.cs` 기존 구조 덕분에 JSON → ScriptableObject 변환 레이어만 추가하면 기본 장비 모드 지원 가능. 단기적으론 `balance_override.json` 외부 파일로 수치 조정 편의성을 먼저 확보하는 것이 현실적. AssetBundle 모드는 Unity 버전 종속 문제가 있으므로 버전 관리 정책 먼저 결정.
