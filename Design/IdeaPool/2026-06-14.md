## 캐릭터 (01_Characters)

- **스킬 슬롯 성장** — Astral Ascent 참고: 고양이와 작물 각각 스킬 슬롯 2개를 처음에 1개로 잠금 → 런 중 특정 방 클리어 시 2번째 슬롯 해금. 성장감 제공 + 빌드 복잡도를 점진적으로 높임
- **원소 시너지 힌트** — Astral Ascent 참고: 고양이 슬래시(불꽃 속성) + 작물 투사체(냉기 속성) 조합 시 폭발 이펙트 발동. 두 플레이어가 의도적으로 타이밍을 맞춰야 발동되도록 설계
- **부활 씨앗** — Astral Ascent 부활 메카닉 응용: 작물(Player2)이 "부활 씨앗"을 한 번 보유. 공유 체력이 0이 되기 직전 Player2가 버튼 입력 시 씨앗을 소모해 체력 20% 회복. 단 런당 1회 한정

## 적 (02_Enemies)

- **방어막 거북이** — 보스 패턴 설계 참고: 원거리 투사체에 완전 무적인 거북이형 적. 등껍질 방어막 파괴는 근접 슬래시만 가능 → 고양이(Player1)가 달려가서 파괴, 그 동안 작물(Player2)이 커버
- **사거리 저격수** — 보스 패턴 설계 참고: 멀리서 레이저를 조준하는 적. 레이저 준비 모션(1초) 동안 작물의 방패로 반사하거나 고양이 대시로 돌진해 근접 처치 가능. 원거리 투사체로는 피해 없음
- **분열 슬라임** — Astral Ascent 미니언 소환 참고: 보스가 죽기 전 분열해 작은 슬라임 4마리 생성. 각 슬라임은 근접 약점 or 원거리 약점이 랜덤 배정 → 두 플레이어가 빠르게 역할 분담해야 함

## 맵 (03_Maps)

- **보스 아레나 구조** — 보스 패턴 설계 참고: 보스 방은 일반 방보다 50% 넓고, 중앙에 기둥 2개 배치. 기둥은 원거리 투사체를 막지만 근접은 통과 가능 → 고양이가 기둥 뒤 보스를 칠 때 작물이 기둥 너머로 조준
- **협동 스위치 방** — Astral Ascent 원소 콤보 응용: 방 안에 두 개의 스위치가 있고 동시에 눌러야 문이 열림. 한 스위치는 근접 공격으로만 활성화, 다른 하나는 원거리 투사체로만 활성화 → 동시 입력 퍼즐
- **위험 지형 방** — HUD 시스템 참고: 독 웅덩이 방. 서 있으면 체력이 초당 감소. HUD 체력바를 잘 보면서 빨리 적 처치 + 회복 아이템 수거. 잔상 체력바(ghost bar)로 데미지 시각화

## 전투 (04_Combat)

- **페이즈 전환 협동 퍼즐** — 보스 패턴 설계 참고: 보스 Phase2 전환 시 5초 무적. 이 5초 동안 화면에 나타나는 "방어막 코어"를 근접(고양이) + 원거리(작물) 동시 타격해야만 무적 해제. 협동 강제 순간
- **패리 반사 탄막** — 보스 패턴 설계 원형 탄막 + 작물 방패 조합: 보스의 원형 탄막을 작물이 방패 패리 성공 시 탄막이 역방향으로 반사되어 보스에게 큰 피해. 위험한 패턴을 역이용하는 쾌감
- **쿨다운 최적화 보상** — HUD 쿨다운 표시 참고: 쿨다운이 정확히 0이 되는 순간 스킬 사용 시 "퍼펙트 타이밍" 판정 → 다음 쿨다운 20% 단축. HUD에 쿨다운 완료 직전 반짝임 이펙트로 힌트

---

## 스토리 (05_Story)

- **양파 왕국의 12 별자리 수호자** — Astral Ascent 황도 12궁 보스 참고: 악당이 12개 별자리 보스를 소환해 왕국을 점령. 각 구역 보스는 별자리 테마 외형(전갈 모양 근접 보스, 물병자리 원거리 보스 등). 12개 보스 격파 = 엔딩
- **고양이와 작물의 계약** — 왜 고양이가 작물 화분을 등에 지는가: 고양이가 마법사에게 속아 작물과 융합된 저주를 받음. 작물은 고양이를 증오하지만 살아남으려면 협력해야 함 → 런 사이 대화로 관계가 발전하는 스토리
- **페이즈마다 보스 대사** — 보스 패턴 설계 참고: 보스 Phase2/3 전환 시 짧은 대사 출력 ("이제 진심을 보여주지!"). 픽셀아트 말풍선으로 연출. 보스에게 개성 부여 + 전투 연출 강화

---

## 기술 메모

- **보스 패턴 설계**: 코루틴 기반 페이즈 전환이 핵심. `StopAllCoroutines()` 후 새 코루틴 시작하는 패턴으로 페이즈 전환을 깔끔하게 구현. 히트스톱(`Time.timeScale = 0.1f` + `WaitForSecondsRealtime`)은 페이즈 전환 느낌을 극적으로 높여줌. OnionCat 첫 보스는 Phase1만으로 시작하고, Phase2 이상은 나중에 추가하는 방식으로 점진적 개발 권장.

- **인게임 HUD**: 이벤트 기반 업데이트(`event Action<float, float> OnHealthChanged`)로 구현하면 매 Update() 갱신보다 성능이 좋음. 픽셀아트 게임이면 Canvas Scaler를 `Scale With Screen Size`, Reference Resolution 320×180으로 설정하고 2D Pixel Perfect 패키지 병행 사용. 체력바 잔상(ghost bar) 효과는 구현 난이도 대비 "게임 같은 느낌"을 크게 올려줌 — 초기 버전에 꼭 넣기.
