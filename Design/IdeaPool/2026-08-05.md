## 캐릭터 (01_Characters)

- **Cat 대시 방향 예측 시각화** — Enemy_Charge_Attack_Pattern 참고: 적 돌진 텔레그래프 라인(LineRenderer)처럼, Cat의 대시 방향도 짧은 화살표로 미리 표시(0.1초). 협력 상황에서 Crop 플레이어가 "Cat이 어디로 대시할지" 예측하여 쉴드 방향 맞추기 용이. 구현 힌트: Cat 대시 버튼 입력 감지 시 LineRenderer 0.1초 활성화 후 대시 실행.

- **Crop 쉴드 반사 퍼커션** — Deadlink 타격감 참고: Crop의 방향 쉴드가 돌진 적을 막을 때 3중 피드백(파란 파장 파티클 + 쇳소리 SFX + 카메라 강한 흔들림) 적용. 패리 성공의 쾌감을 극대화. 구현 힌트: Parry_Shield_System.md에 CinemachineImpulse + 파티클 트리거 추가, 패리 성공 조건은 `EnemyState.Charge` 중 충돌 여부.

- **공유 몸체 충격 연출** — Loot River 물 반사 참고: Cat + Crop이 강한 공격을 받을 때 화분이 흔들리며 작물이 잠깐 뒤로 젖혀지는 Secondary Motion. 피해 인지 강화 + 캐릭터 생동감. 구현 힌트: Secondary_Motion_System.md의 스프링 본 흔들림을 화분 오브젝트에 적용, 데미지 수신 이벤트에서 트리거.

## 적 (02_Enemies)

- **돌진형 적 — 멧돼지 잡초** — Enemy_Charge_Attack_Pattern 직접 적용: 텔레그래프(빨간 눈 점멸 1초) → 직선 돌진 → 벽 충돌 시 기절. Cat 대시로 피하거나 Crop 쉴드로 패리. 벽에 충돌하면 0.8초 경직 → Cat 반격 창. 구현 힌트: ChargeEnemy.cs 구현 후 SpawnTable에 Floor 2부터 등장 설정.

- **광역 돌진형 — 회오리 민들레** — 돌진 경로 양옆으로 씨앗 파편을 흩뿌리며 달려오는 적. Cat은 대시로 메인 돌진을 피해도 측면 파편에 맞을 수 있음 → Crop이 쉴드로 파편 차단하거나 Crop이 먼저 원거리 격파 필요. 구현 힌트: ChargeEnemy의 OnWallHit()에서 Danmaku_Pattern_System.md 부채꼴 투사체 발사.

- **타임 어택 전용 적 — 순간이동 벌레** — 시간 제한 챌린지 방 전용: 일정 시간마다 랜덤 텔레포트하며 협력 조준을 방해. 단독 원거리는 추적하기 어렵고, Cat이 근접 위치를 잡는 동안 Crop이 예측 사격. 구현 힌트: `InvokeRepeating("Teleport", 2f, 2f)`로 주기 텔레포트, Physics2D.OverlapCircle로 벽/플레이어 위치 제외 후 랜덤 좌표 선택.

## 맵 (03_Maps)

- **슬라이딩 장애물 방** — Loot River 블록 이동 참고: 방 안에 밀 수 있는 상자(Rigidbody2D, Kinematic) 3~4개 배치. Cat 슬래시 힘으로 상자를 밀어 적 이동 경로 차단, Crop은 상자 뒤에서 원거리 사격. 구현 힌트: 상자에 OnCollisionEnter2D로 Cat의 Knockback 벡터 받아 AddForce() 적용, 상자 무게(mass)로 밀림 강도 조정.

- **시간 제한 챌린지 방** — InGame Timer + Deadlink 참고: 특수 방(황금 테두리) 진입 시 30초 카운트다운 시작. 모든 적 처치 시 "챌린지 성공" → 희귀 업그레이드 1개 선택. 시간 초과 시 방 잠금 해제만 됨(보상 없음). 구현 힌트: RoomChallengeTimer.cs를 방 트리거(OnTriggerEnter2D)에 연결.

- **낙사 구역 방** — Loot River 물 블록 참고: 방 중앙에 구멍(낙사 존) 배치. Cat의 대시로 적을 밀어서 떨어뜨리거나, Crop의 넉백 투사체로 밀어내기. 낙사 처리된 적은 즉사. 구현 힌트: 낙사 존에 Trigger 콜라이더, OnTriggerEnter2D에서 적 체력 즉시 0 처리 + 빠져드는 파티클 연출.

## 전투 (04_Combat)

- **3중 피드백 히트 반응** — Deadlink 타격감 공식 직접 적용: Cat 슬래시 히트 시 히트스톱(0.05s) + 금속 충격음 SFX + 스파크 파티클 + 카메라 0.05s 쉐이크. Crop 투사체 히트 시 파열 파티클 + 명중음 + 적 스프라이트 1프레임 흰색 플래시. Feedback_System.md를 기반으로 두 공격 유형에 맞는 피드백 프리셋 2종 제작.

- **패리 성공 → 클로즈업 슬로우** — Enemy_Charge_Attack_Pattern 패리 연동 참고: Crop이 돌진 적을 패리 성공 시 0.3초 타임스케일 0.2 슬로우 + 줌인 연출. 패리의 쾌감과 "지금 Cat이 반격할 차례"라는 신호 전달. 구현 힌트: TimeScale_BulletTime_System.md의 BulletTime(0.2f, 0.3f) 호출 + CinemachineImpulse.

- **방 클리어 등급 표시** — Deadlink + InGame Timer 참고: 방 클리어 시 걸린 시간으로 S/A/B/C 등급 계산 후 0.5초 팝업 표시. S: 15초 이내(황금), A: 30초(은색), B: 60초(동색), C: 초과(회색). 등급별 재화 보너스. 구현 힌트: InGameTimer의 RoomChallengeTimer를 각 방에 배치, 방 클리어 이벤트에서 등급 계산 후 Toast_Notification_System.md로 팝업.

## 스토리 (05_Story)

- **돌진하는 적의 회고록** — Loot River 어두운 세계관 참고: 런 결과 화면에 처치한 특정 적(예: 멧돼지 잡초)의 짧은 독백 표시. "나는 그저 달리고 싶었을 뿐이다. 그 화분을 든 고양이가 길을 막지만 않았다면." 적에게 개성 부여 + 세계관 깊이감. 구현 힌트: 처치 적 종류를 RunData에 기록, Run_Result_Screen에 랜덤 선택한 적 독백 표시.

- **스피드런 엔딩** — InGame Timer + 완성 기능 참고: 30분 이내 클리어 시 특수 결말 해금 — 고양이가 너무 빠르게 달려서 화분 속 양파가 멀미로 힘들어하는 만화 컷씬 2장. 가벼운 유머 엔딩. 구현 힌트: 런 클리어 시 타이머 값 확인 → Multiple_Endings_System.md로 분기.

- **Loot River식 장비 회고** — Loot River 무기 루팅 참고: 런 중 처음으로 새로운 아이템을 획득했을 때 짧은 1줄 텍스트 플레이버. "양파가 이 씨앗을 보며 중얼거렸다: '이건... 친척 같기도 하고.'" 세계관에 온기를 불어넣는 작은 대사들. 구현 힌트: Upgrade ScriptableObject에 `flavorText` 필드 추가, 첫 획득 시 Contextual_Hint_Popup_System.md 활용 팝업.

## 기술 메모

- **Enemy Charge Attack Pattern**: 핵심은 방향 확정 시점 — 텔레그래프 시작 시 `chargeDirection`을 고정해야 플레이어가 텔레그래프를 읽고 피할 수 있음. 벽 충돌 레이캐스트는 `Update`보다 Coroutine 내 매 프레임 체크가 깔끔. OnionCat에서 가장 먼저 구현할 적 공격 패턴으로 추천 — Cat 대시(무적)와 Crop 패리가 바로 연동되어 협력 메카닉의 핵심이 드러남.

- **InGame Timer System**: `Time.unscaledDeltaTime` 사용 필수 (히트스톱 타임스케일에 영향받지 않기 위해). 전역 런 타이머(DontDestroyOnLoad 싱글톤)와 방별 카운트다운 타이머(RoomChallengeTimer)를 분리 구현하는 것이 구조적으로 깔끔. 런 결과 화면 연동은 `RunResultData` 정적 클래스에 float 값 저장 후 씬 전환 시 읽는 방식으로 간단히 처리 가능.
