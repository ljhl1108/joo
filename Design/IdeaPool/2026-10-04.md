## 캐릭터 (01_Characters)

- **양파의 "결합 폭발" 기술** — Split Fiction Combine 참고: 고양이와 양파가 동시에 같은 적을 공격하는 순간 양파가 짧은 에너지 구체를 발사, 착탄 시 소규모 폭발 — 시너지 윈도우 0.25초 이내 교차 공격이 트리거. 코드: `TakeDamage(attacker)` 교차 감지 + 별도 `ExplosionProjectile` 생성
- **고양이의 "연계 대시"** — 시너지 발동 직후 0.5초간 고양이 대시 거리 30% 증가 + 대시 경로에 남기는 불꽃 자국. 협동 전투를 더 역동적으로 만드는 시각적 보상. `SynergyEffect`에서 임시 `StatModifier` 적용
- **생애 통계 기반 "베테랑 고양이" 보정** — TotalRuns > 30 이후 첫 번째 런에서 고양이 기본 HP +10%. 숫자가 아니라 경험이 쌓이는 느낌. `LifetimeStats.TotalRuns` 체크 후 런 시작 시 `PlayerStats.Modify` 적용

## 적 (02_Enemies)

- **시너지 방어막 슬라임** — Split Fiction 보스 약점 교대 참고: 파란 보호막이 걸린 슬라임은 고양이 근거리 + 양파 원거리가 거의 동시(0.3초)에 타격해야만 방어막 제거. 혼자서는 절대 못 깸. `BossShield.requiresSynergy = true` 필드 추가
- **"역할 뒤집기 적" (역할교환 젤리)** — Split Fiction의 챕터 내 역할 교환 개념: 이 적에게 맞으면 일시적으로 고양이와 양파의 입력이 교환됨(10초). 당황을 유도하는 파티 트릭용 적. `CoopInputLayout`에서 `SwapControllers(duration: 10)` 구현
- **협동 약점 표식 붙이는 적** — 적이 플레이어 한 명에게 "표식"을 붙임. 표식이 붙은 플레이어가 아닌 다른 플레이어만 표식 해제 공격 가능. 강제 협동의 심화 버전. `MarkDebuff` 상태이상 + `TakeDamage`에서 공격자가 표식 대상이 아닐 때만 피해 인정

## 맵 (03_Maps)

- **특수 규칙 방: "침묵 방"** — Split Fiction 챕터별 메커닉 변환 참고: 투사체가 완전히 침묵하는 방. 양파는 투사체 대신 양파 껍질을 근거리 투척(새 임시 스킬). 고양이 전담 방이 아니라 양파도 적응해야 함. `RoomModifier.Silent` 플래그 → `ProjectileBase.OnEnable`에서 체크
- **시너지 충전 방** — 방 입장 시 시너지 게이지가 50으로 시작하는 특수 방. 방 중앙에 두 플레이어가 서야 활성화되는 "공명 제단" 오브젝트. 스테이지 다양성 추가. `SynergyResonanceAltar` 오브젝트 배치
- **기록 경쟁 방** — "이 방 최단 클리어 기록: 0:42" 표시판이 있는 방. 런 중 클리어 시간을 `LifetimeStats`에 저장, 다음 런에 도전 기록으로 표시. 자기 기록과 경쟁하는 재미

## 전투 (04_Combat)

- **시너지 콤보 카운터 HUD** — 연속 시너지 발동 횟수를 화면 중앙 하단에 "SYNERGY x3!" 형태로 표시. 콤보가 끊기면(5초 이상 시너지 없음) 리셋. 콤보 3 이상이면 게이지 충전 속도 2배. `SynergyComboTracker` 컴포넌트 추가
- **"합동 피니셔" 시스템** — 적 HP가 15% 이하일 때 두 플레이어가 동시에 공격 입력을 누르면(0.1초 이내) 즉사 + 특수 피니셔 애니메이션. Mortal Kombat 피니셔의 협동 버전. `EnemyBase`에서 HP 임계값 체크 + 양쪽 입력 동시 감지
- **시너지 발동 적 사망 시 보너스 드롭** — 시너지 타격으로 처치한 적은 일반 드롭 외 추가로 "협동 코인" 1개 드롭. 이 코인은 방 클리어 후 업그레이드 선택 시 추가 카드 1장 제공. `EnemyBase.Die(bool wasSynergyKill)` 파라미터 추가

## 스토리 (05_Story)

- **생애 통계 기반 도입부 대사 변형** — TotalRuns 0이면 "첫 모험이군요, 고양이!" / TotalRuns > 20이면 "또 왔군... 이번엔 성공할 수 있을까?" 숫자가 아닌 이야기로 통계를 표현. 런 시작 연출에서 `LifetimeStats.TotalRuns` 분기 처리
- **"처음 시너지를 발동한 날" 기념 대사** — 생애 최초 시너지 발동 시 특별 팝업: "처음으로 우리가 하나가 됐어!" + 1회성 보너스(예: 이번 런 시너지 윈도우 +0.1초). `LifetimeStats.TotalSynergyActivations == 1` 체크
- **죽은 적 기억** — MostFrequentKiller(가장 많이 죽인 적) 통계를 런 시작 전 대사에 활용: "파란 슬라임에 23번이나 죽었다고... 이번엔 다르다." 사망 원인 통계를 내러티브 동기로 전환

## 기술 메모

- **Coop Hit Synergy System**: OnionCat 핵심 구현 포인트 — `TakeDamage(float, Attacker)`에 이미 Attacker 파라미터가 있으므로 추가 변경 없이 `_lastAttacker`와 `_lastHitTime` 필드 2개만 추가하면 기본 시너지 감지 완성. SynergyWindow는 0.25초 기본값, 플레이테스트 후 튜닝.
- **Lifetime Stats Display**: `PlayerPrefs + JsonUtility` 조합으로 충분. `CommitRun()`은 런 종료 GameState 전환 시 한 번만 호출, 절대 런 내에서 중간 저장하지 말 것(부정확한 누적 방지). 화면은 메인 메뉴 → "Records" 버튼 1개로 충분, 화려한 UI 후순위.
