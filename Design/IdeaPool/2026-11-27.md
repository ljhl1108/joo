## 캐릭터 (01_Characters)

- **작물 마스터리** — Soul Knight Prequel 참고: 같은 작물로 N판 클리어하면 해당 작물 전용 보너스 해금 (예: 양파 3판 완주 → 양파 전용 에픽 장비 슬롯 1개 추가 해금). 현재 `MetaProgress.LastCrop`이 있으므로 판 수 카운터 추가만으로 구현 가능. `crops.csv`에 "마스터리 조건" 열 추가
- **세트 진행도 미니 HUD** — Card-en-Ciel 참고: "현재 세트 계열별 개수 / 다음 단계까지 N개" 를 HUD 한쪽에 항상 표시. 고양이+양파 합산 세트 수를 아이콘으로 보여줘 "앞으로 2개만 더 모으면 2단계!" 를 플레이 중 항상 의식하게 → 보상 선택 의사결정 도움. 구현: `CombatModifiers`에서 계열별 카운트 읽어 `CoreHUD`에 소형 아이콘 행 추가

## 적 (02_Enemies)

- **적 타입 조합 시너지** — Soul Knight Prequel의 클래스 조합 보너스 참고: 특정 적이 2종 이상 같은 방에 함께 있으면 연계 패턴 발동. 예: "원거리 적 + 방패 적"이 함께 있을 때 원거리 적이 방패 뒤에 숨어 쏘는 AI 추가. `EnemyRoster.squads`에 "조합 태그"를 붙여 `EnemyBase`가 같은 방의 다른 적 타입을 감지하게. 비교적 구현 간단(방의 적 목록에서 타입 확인)하지만 연출 효과 큼
- **카운터 적 (장비 카운터)** — Card-en-Ciel 참고: 특정 스테이지 후반에 플레이어가 가진 세트를 직접 카운터하는 적 등장 (예: 불꽃 세트 2단계 → 얼음 갑옷 적 + 1). 현재 `EnemyRoster.ResolveRoom`이 스테이지 테마로 적을 교체하므로 세트 카운터 교체 규칙 추가 가능. 무리하면 느껴지므로 선택 구현

## 맵·런 구조 (03_Maps)

- **재방문 방 소품 보존** — Room Prefab Reuse 참고: `Room.ResetForReuse()`가 현재 소품도 초기화하는지 확인. 클리어된 방을 다시 지나갈 때 깨진 항아리·짓밟힌 꽃이 그대로면 "내가 여기 왔었구나" 체감. 클리어 여부를 `DungeonNode.isCleared`로 이미 추적하므로: 클리어된 방 재방문 시 소품 초기화 스킵 가능. 아주 작은 디테일이지만 세계 연속성 느낌
- **스테이지별 엘리트 전용 보상** — Soul Knight Prequel 참고: 엘리트 방(현재 없음)을 스테이지마다 1~2개 배치, 일반 보상 대신 해당 스테이지 테마 전용 에픽 장비 보장 (예: 밀밭 스테이지 엘리트 → "밀바람 세트" 에픽 확률↑). `RoomKind` 열거형에 `Elite` 추가 + `RewardTable.RollFor` 분기 추가로 구현 가능

---

## 전투·협동 (04_Combat)

- **발동 체인: 도화선 효과** — Card-en-Ciel의 슬롯 순서 콤보 참고: 고양이가 "불꽃" 계열 장비로 적에게 불을 붙이면(Burns 상태이상), 양파의 씨앗이 그 적에 맞을 때 폭발 보너스. 현재 `ApplyBurn` + `TakeDamage(Attacker.Onion)` 가 공존하므로 피해 계산 단계에서 "피격 직전에 Burns AND Attacker.Onion" 조건 추가로 구현. 협동의 필요성을 메커닉으로 강화
- **컨트롤러 끊김 자동 일시정지** — Controller Hot-plug 참고: 고양이 게임패드가 끊기면 `GameManager.ChangeState(GameState.Paused)` + "컨트롤러를 다시 연결해 주세요" UI. `CoopInputLayout`에서 `InputSystem.onDeviceChange` 구독 여부 확인. 미구현 시 버그로 고양이가 멈추고 게임은 계속되는 최악 상황 발생 가능

---

## 아이템·세트 (05_Items)

- **세트 완성 알림 배너** — Soul Knight Prequel, Card-en-Ciel 공통: 세트 1단계 / 2단계 달성 순간 짧은 화면 중앙 배너 (예: "☀ 태양 세트 1단계 발동!"). 현재 `PassiveHost.Recalculate`가 세트를 다시 계산하므로 여기서 단계 변화 감지 → `Toast_Notification_System.md` 참고해 토스트로 표시. 플레이어가 "이제 세트 보너스 받았구나"를 명시적으로 알 수 있음
- **세트 완성 힌트: 보상 선택 화면** — Card-en-Ciel의 "다음 완성까지 N개" UI 참고: `UpgradeSelectUI`에서 각 보상 카드에 "이 장비 선택 시 태양 세트 2단계 완성!" 뱃지를 작게 표시. `CombatModifiers`에서 미리 계산 가능. 보상 선택이 훨씬 의미 있어짐

## 스토리·메타 (07_StoryMeta)

- **농장 주민 모음** — Card-en-Ciel의 NPC 게스트 수집 참고: 판마다 만나는 NPC(말하는 책·그리모·마을 상인·샘물 정령 등)가 클리어 후 농장(메인 메뉴 화면 배경)에 모임. 현재 `MetaProgress` 구조에 "만난 NPC 목록" 필드 추가 + 메인 메뉴 농장 씬에 NPC 오브젝트 배치로 구현 가능. 판을 거듭할수록 농장이 북적이는 성장감 / 가볍지만 강력한 메타 연속성
- **작물 조합 도감** — Soul Knight Prequel의 클래스 마스터리 로그 참고: 플레이 중 쓴 작물·장비 조합 기록 화면 (온실 한쪽). "지금까지 가장 강했던 조합" "총 판 수" "작물별 클리어 수" 등. `MetaProgress`에 이미 판 수 데이터가 있으므로 UI 추가만으로 구현 가능. 도전 목표 역할도 겸함

---

## 기술 메모

- **Room Prefab Reuse**: `Room.ResetForReuse()`가 `OnEnable` 패턴으로 동작하는지 확인. 적 풀 반환→문 잠금→소품 리셋 순서 보장이 핵심. 클리어 방 재방문 시 `node.isCleared` 체크로 적 스폰 스킵하는 코드가 있는지 확인할 것
- **Controller Hot-plug**: `CoopInputLayout.cs`에서 `InputSystem.onDeviceChange` 구독이 없다면 추가 필요. 게임패드 연결 끊김 → `GameState.Paused` + 한글 재연결 UI가 최우선. 모바일 게임(Soul Knight Prequel)이 세이브 없이 완주를 강요해 이탈률 높은 반면, OnionCat은 `MidRun_Save_Resume_UX.md` 구현으로 차별화 중 — 재연결 처리와 함께 유지할 것
