## 캐릭터 (01_Characters)

- **고양이 배후 강타 패시브** — Blade Assault 방패병 참고: 적의 등 뒤(방향성 판정 dot < -0.5)에서 할퀴기 성공 시 추가 피해 +30% + 짧은 스턴. ClawStyle 카드 "Backstab Claw"로 구현 가능. 구현 힌트: `Vector2.Dot(attackDir, enemy.transform.right) < -0.5f` 조건
- **양파 패링 카운터** — 패링 성공 직후 0.3초 내 다음 투사체가 2배 피해 상태로 반사되는 패시브. OnionSkill "Riposte Seed"로 구현. 구현 힌트: `OnionShield.OnParrySuccess` 이벤트 → `_nextShotDamageMultiplier = 2f` 설정
- **"공유 체력" 난이도 모드** — 고양이와 양파가 HP를 공유하는 상급 선택지. 한 명이 맞으면 둘 다 HP 감소. 진짜 한 몸 느낌 극대화. 구현 힌트: PlayerHealth를 공유 ScriptableObject로 교체하는 런 모디파이어

## 적 (02_Enemies)

- **방향 전환 방패병 (Rotating Shield Soldier)** — Blade Assault 방패병 참고: 기본은 전면 방어, 피격 없으면 30초마다 방패 방향 변경. 방패 방향이 바뀌는 순간 짧은 무방비 상태(0.4초) 발생 → 그 타이밍 노리기. 구현 힌트: `ShieldEnemy`에 방향 전환 코루틴 추가
- **협동 콤보 전용 약점 적** — 근접(고양이)이 맞추면 "Exposed" 상태, 이 상태에서 원거리(양파)가 맞추면 추가 폭발 피해 발동하는 새 적 타입. RunData의 `coopComboCount` 증가 트리거로 활용. 구현 힌트: `EnemyBase`에 `ExposedState` bool 추가, `TakeDamage`에서 어태커가 Onion이고 `IsExposed`이면 폭발
- **반사 방패 투사체 적** — 적이 작은 방패를 들고 날아오는 투사체를 반사함. 반사된 투사체는 플레이어에게 돌아와 맞음. 양파 패링으로 재반사 가능. 구현 힌트: `Projectile`에 `bouncesRemaining` 카운터, 방패 적의 콜라이더에 반사 레이어 설정

## 맵 (03_Maps)

- **사각지대 방 (Blind Spot Room)** — 방 중앙에 큰 기둥 그룹 배치. 기둥 뒤 적에게 근접은 접근 불가, 원거리만 돌아서 쏠 수 있는 상황 연출. 고양이가 기둥 주변을 돌아 측면 공략. 구현 힌트: RoomLayout 글자맵에 X(벽덩어리) 기둥 배치, 3×3 크기
- **경사로 방 (Elevated Platform Room)** — 방 중앙에 높이 차이 있는 플랫폼(실제 이동 가능 구역이 아닌 시각적 높낮이). 방패병이 높은 위치에 있어 근접 접근 경로가 제한, 양파 위에서 사격이 유리. 구현 힌트: 정렬 레이어 구간(바닥 -1000~-900)을 활용한 시각적 층위 표현
- **추격 방 (Pursuit Room)** — 방에 입장하면 자동으로 문이 잠기고, 일정 시간(15초) 내 모든 적 처치 시 보너스 보상. 실패해도 패널티 없음(그냥 클리어). 구현 힌트: `RoomManager`에 타이머 추가, `InGame_Timer_System.md` 참고

## 전투 (04_Combat)

- **배후 공격 시각 표시** — 방패병의 방패 방어 범위를 호(arc) 형태로 표시. 플레이어가 방패 범위 밖(배후/측면)에 있으면 적 발밑에 "공격 가능" 초록 표시. 구현 힌트: `Custom_Gizmos_Debug_Visualization.md` 참고, 런타임 `LineRenderer` 호(arc)로 구현
- **런 종료 기여도 기반 보너스 시작** — 직전 런 결과 화면 데이터를 다음 런 시작 시 활용. 예: 이전 런 명중률 90% 이상이면 다음 런 첫 방 보상에 원거리 카드 확률 +20%. 구현 힌트: `CombatStats`를 `PlayerPrefs`에 저장 후 다음 런 시작 시 읽어 RewardTable 가중치 보정
- **협동 콤보 게이지 방향 표시** — 협동 콤보 게이지가 일정 이상 쌓이면 "다음 공격이 콤보 발동" 알림. 고양이의 발밑 `CatPips` 옆에 작은 게이지 표시. 구현 힌트: `CoreHUD`에 콤보 게이지 추가, 기존 CatPips 배치 로직 참고

## 스토리 (05_Story)

- **화분 기원 스토리** — 왜 고양이 등에 화분이 달려있나? 세계관에 함께 사는 존재들이 오랜 전쟁을 끝내기 위해 양파 마법사가 "공생 결속 주문"을 사용했고, 두 사람은 분리될 수 없는 몸이 됨. 이 설정이 던전 탈출 동기 제공
- **각 방 클리어 후 짧은 양파 독백** — 적을 처치하거나 보상을 선택할 때 양파(Onion)가 짧은 한마디 나레이션. "I can smell the exit." / "Your claws did the work. My aim just helped." 런마다 랜덤 문구. 구현 힌트: `Dialogue_Event_System.md`, 문구 SO 파일
- **보스가 예전 아군이었다는 반전** — 각 던전 보스는 이전에 같은 처지였던 "공생 결속 실험체". 보스 처치 후 짧은 컷신에서 한마디 유언. 감성적 여운 + 재플레이 시 다른 시각으로 보이는 효과. 구현 힌트: `Ingame_Cutscene_System.md` 보스 사망 이벤트 연결

## 기술 메모

- **방향성 피격 반응 시스템**: OnionCat에 바로 적용 가능한 핵심은 **양파 방패의 패링 판정** (`Vector2.Dot(-projectileDir, shieldFacing) > cos(45°)`)과 **방패병의 방어 판정** (`Vector2.Dot(incomingDir, enemy.transform.right) > cos(60°)`). 두 판정 모두 `transform.right`가 적/플레이어 회전을 자동 반영하므로 별도 각도 계산 불필요.
- **협동 기여도 통계 화면**: `RunData`에 `CombatStats` 내부 클래스 추가 → 각 시스템에 static 이벤트 추가 → `RunStatsTracker`가 구독. 기존 코드 수정 최소화. 결과 화면 UI는 비대칭 설계(고양이/양파 각자 다른 지표)가 핵심 — 같은 수치로 비교하면 협동 게임 느낌이 깨짐.
