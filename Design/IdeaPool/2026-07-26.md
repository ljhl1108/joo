## 캐릭터 (01_Characters)

- **Onion 방어막 방향 시각화** — Line Renderer 참고: 방어막 원형 외곽선에서 현재 방어 방향에 해당하는 호(Arc)만 밝게 강조 표시. 플레이어 2가 어느 방향을 막고 있는지 Player 1도 한눈에 파악 가능 → 협력 시너지 증가. 구현: 전체 원 32점 중 방향에 해당하는 섹터만 startColor를 밝게 설정.
- **Cat 슬래시 이펙트 강화** — Cat Quest II 참고: 근접 슬래시 시 Arc 모양의 Line Renderer 이펙트(짧게 남았다 사라짐). 일반 파티클보다 방향감이 명확하고 픽셀아트와 어울림. 구현: 0.1초 동안 표시 후 alpha fade out.
- **언어유희 양파 캐릭터명** — Cat Quest II 언어유희 방식 참고: Onion 캐릭터에게 "레이어(Layer)" 기반 대사("내 방어막은 양파처럼 겹겹이!", "눈물이 무기야!") → 세계관 몰입도 상승. 컷신/대화창 없이 전투 중 짧은 팝업 대사로.

## 적 (02_Enemies)

- **방어막 방향 적** — Cat Quest II 방향 방어 참고: 방패를 앞에 든 적 — 정면에서는 데미지 0, 뒤나 옆에서 공격해야 피해. Onion의 원거리로 주의를 끌고 Cat이 뒤로 돌아 슬래시. 자연스러운 협력 유도 패턴.
- **번개 체인 적 (Chain Zapper)** — Line Renderer Lightning 참고: 두 플레이어 사이에 전기 체인을 걸어 두 사람이 일정 거리 이상 벌어지면 지속 데미지. 반대로 두 사람이 붙어 있으면 무력화 가능 → 거리 관리 협력 메카닉. 시각화: LightningEffect 컴포넌트.
- **레이저 포탑 (Laser Turret)** — Line Renderer Laser Sight 참고: 일정 방향으로 레이저 조준선을 표시 후 일정 시간 뒤 발사. 플레이어들이 선을 보고 피하거나 Onion의 방어막으로 반사 가능. Onion 전담 처리 적.

## 맵 (03_Maps)

- **방어막 색 오브젝트** — Line Renderer + 씬 오브젝트 활용: 방 안에 컬러 장벽이 있고, Onion의 방어막을 해당 색으로 맞춰야만 통과 가능한 특수 방. 퍼즐 요소로 전투 외 협력 메카닉 다양화.
- **좁은 통로 강제 밀착 방** — Cat Quest II 공유 화면 참고: 두 플레이어(=OnionCat은 한 몸이라 자동 해결)가 좁은 통로를 지나는 레이아웃. 한 몸 컨셉을 더 부각: 좁은 길에서 이동 컨트롤 충돌 → 의사소통 필요.
- **경고선 함정 방** — Line Renderer 레이저 트랩 참고: 바닥에 선이 표시된 방향으로 레이저가 주기적으로 발사되는 함정. 플레이어들이 선을 기억하고 타이밍에 맞춰 이동. Cat의 대시 무적으로 통과 또는 Onion 방어막으로 반사.

## 전투 (04_Combat)

- **패리 펄스 이펙트** — Line Renderer ShieldRenderer 참고: 패리 성공 시 방어막 외곽선이 순간 확장(1.2→1.8 반지름)했다가 축소. 0.3초 내 빠른 애니메이션 + 흰색 플래시 → 패리 성공 피드백이 극적으로 향상. 구현: `ParryFlash()` 코루틴 호출.
- **조준선 색상 피드백** — Line Renderer Laser Sight + Cat Quest II 공격 예고 참고: Onion 조준선이 적에게 닿으면 흰색→빨간색으로 변경 ("지금 맞는다" 피드백). 적의 공격 예고도 동일 방식 — 빨간 선이 플레이어 위치를 향하면 위험 신호. 일관된 색상 언어.
- **2P 업그레이드 투표 시스템** — Gamepad UI Navigation + Cat Quest II 협력 참고: 런 업그레이드 선택 시 Cat(1P)과 Onion(2P)이 각자 1표씩 행사. 다른 카드를 고르면 표시 후 3초 내 재선택 또는 다수결(Onion 2표가 아닌 동등 1표). 협력 대화 유도 메카닉.

## 스토리 (05_Story)

- **양파와 고양이의 첫 만남** — Cat Quest II 세계관 참고: 고양이(전사)와 양파 작물(마법사)이 우연히 같은 화분에서 자라 하나의 몸이 된 기원 이야기. 튜토리얼 씬에 짧은 3~4컷 픽셀아트 애니메이션으로 표현.
- **적 보스 = 비료 중독 식물** — Cat Quest II 귀여운 적 컨셉 참고: 과도한 비료를 맞아 변이한 거대 식물 보스들. "비료의 저주를 끊어라"는 쉬운 이해의 메인 퀘스트. 보스마다 다른 비료 타입(질소=파란색, 인=빨간색) → 약점 색상 코딩.
- **NPC 씨앗 상인** — Cat Quest II 마을 NPC 참고: 던전 중간에 씨앗 상인 NPC 등장 → 씨앗(=업그레이드 재화)으로 특수 아이템 구매. NPC가 Cat을 보고 "아, 화분 고양이!" 라는 인식 → 세계관 속 OnionCat이 특별한 존재임을 암시.

## 기술 메모

- **Line Renderer 2D 시각 이펙트**: OnionCat에 바로 적용 가능한 핵심 2가지 — ① Onion 방어막 원형 외곽선(ShieldRenderer, 32점 원 + loop = true) ② 적 공격 예고선(Raycast2D 방향으로 LineRenderer SetPosition). 두 가지 모두 URP Bloom + HDR 머티리얼 조합 시 글로우 효과 자동 적용. `Sorting Layer` 설정 필수 (스프라이트와 레이어 충돌 주의).
- **게임패드 UI 탐색 시스템**: 구현 순서 — ① EventSystem에서 StandaloneInputModule 제거 → InputSystemUIInputModule 추가 ② 각 패널의 첫 버튼에 `OnEnable()`에서 `SetSelectedGameObject()` 호출 ③ 업그레이드 선택 카드 3개에 Explicit Navigation으로 좌우 연결 ④ 패널 전환 시 항상 `yield return null` 후 SetSelected. 주의: P1만 UI Action Map으로 전환, P2는 게임 중 마우스 유지.
