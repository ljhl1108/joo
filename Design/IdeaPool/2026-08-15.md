## 캐릭터 (01_Characters)

- **유령 런 메모리 업그레이드** — Phantom Abyss 고스트 시스템 참고: 특정 업그레이드 획득 시 이전 런에서 자신이 죽은 지점에 반투명 "고스트 고양이" 표시. "이 방에서 3번 죽었음" 카운터를 방 진입 시 HUD에 잠깐 노출 → 난이도 인지 + 스토리 감성 동시 달성. 구현 힌트: `RunHistory` ScriptableObject에 `deathsByRoom[roomId]` 정수 저장, 방 진입 이벤트에서 `UIManager.ShowGhostCount(count)` 호출.

- **역할 전담 패시브 트리** — KT&NE 역할 비대칭 참고: P1과 P2가 런 시작 시 **완전히 분리된 패시브 업그레이드 트리**를 선택. P1 트리: 이동속도·대시·근접 공격력만 포함. P2 트리: 조준 정밀도·투사체 수·방패 지속시간만 포함. 상대방 트리는 선택 불가 → 역할 이탈 방지, 협동 필요성 강화. 구현 힌트: `UpgradeItem.allowedPlayer` enum 필드로 표시 제한.

- **정보 특권 스킬** — KT&NE 정보 비대칭 참고: P1 전용 업그레이드 "레이더 후각" — P1 HUD에만 방 안의 적 수·타입을 텍스트로 미리 표시. P2는 볼 수 없음. "오른쪽 방에 원거리 약점 적 2마리야" 소통 자연 유도. 구현 힌트: P1 전용 Canvas 레이어에만 렌더링되는 `EnemyRadarUI` 컴포넌트, `Camera.cullingMask`로 P2 화면에서 제외.

## 적 (02_Enemies)

- **압박-지원 콤비 적** — 적 그룹 협동 패턴 참고: "갑옷 창병(Pressure)"과 "독화살 궁수(Support)"가 쌍으로 스폰. 창병은 P1 고양이에게 정면 돌진(근접 약점 = P1 전담), 궁수는 안전 거리 유지하며 P2 파를 조준(원거리 약점 = P2 전담). 창병을 먼저 막지 않으면 궁수를 처리할 틈이 없는 자연스러운 역할 강요. 구현 힌트: `EnemyGroup.AssignRoles()` → Pressure(창병), Support(궁수).

- **동기화 돌진 군단** — 그룹 싱크 공격 참고: 방 진입 시 작은 적 4마리가 2초간 빨간 텔레그래프(경고 이펙트) 후 **동시 돌진**. 4방향 중 하나를 막으려면 P1 대시 + P2 방패 협동 필수. 구현 힌트: `GroupAttackCoordinator.TriggerSyncAttack()` → `telegraphDuration = 2f` → 동시 `ExecuteAttack()`.

- **포위 척후병 트리오** — 플랭킹 패턴 참고: 3마리가 스폰 직후 120도 간격으로 분산 포위 이동. 정면 1마리에 시선이 쏠리면 측면 2마리가 파고드는 구조. P1이 하나씩 처리하는 동안 P2가 측면을 원거리 견제하지 않으면 협공에 당함. 구현 힌트: `FlankCoordinator.CalculateFlankPosition(i, 3)` → 목표 위치 도달 후 일제 공격 전환.

## 맵 (03_Maps)

- **고스트 무덤 방** — Phantom Abyss 유령 참고: 이전 런에서 3회 이상 사망한 방에는 런 시작 시 반투명 고스트 고양이들이 배회. 아무 게임플레이 효과 없이 분위기로만 존재 → "이 방이 위험하다"는 자연스러운 힌트이자 감성 연출. 구현 힌트: `RunHistory.GetDeathCount(roomId) >= 3`이면 `GhostCatPrefab` 1~3마리 스폰 (NavMesh없이 랜덤 Waypoint 이동).

- **정보 안개 방** — KT&NE 정보 비대칭 참고: 어두운 방에서 P1은 근처 적만 식별 가능, P2는 마우스 커서 주변만 밝음. "12시 방향에 이상한 거 있어!" 소통이 핵심 퍼즐. 주기적으로 등장하는 특수 방으로 설계. 구현 힌트: `FogOfWar` 렌더 텍스처 + P1·P2 각각의 SpotLight2D 반경 3~4 유닛.

- **교대 압박 복도** — 교대 공격 패턴 참고: 좁은 복도 좌우에서 적이 교대로 돌진. 공격 간격(0.5초)에 P1이 대시 통과, P2가 원거리 지원으로 다음 공격자를 미리 처치. 리듬감 있는 협동 구간 역할. 구현 힌트: `AlternatingAttackLoop` Coroutine, `attackDuration = 1.5f`, 교대 간격 `0.5f`.

## 전투 (04_Combat)

- **역할 색상 코드 표시** — KT&NE 명확한 소통 언어 참고: 적의 약점 타입을 화면상 색상으로 분리 표시. P1 화면에서 근접 약점 적 = **파란색 테두리**, P2 화면에서 원거리 약점 적 = **빨간색 테두리**. "파란색 가!", "빨간색 내가 쏠게!" 짧은 소통 코드 자연 형성. 구현 힌트: `EnemyOutline` 컴포넌트, P1·P2 각각의 RenderTexture에 다른 색상 OutlineShader 적용.

- **협동 피니쉬** — 적 그룹 패턴 + 폴리싱 참고: P1이 근접으로 적을 스턴 시킨 직후 **0.3초 이내** P2 투사체 명중 시 "협동 처치(Co-op Finish)" 판정. 슬로우 모션 0.1초 + 광선 이펙트 + 특수 SFX + 골드 1.5배 드롭. 협동을 보상으로 직접 유도. 구현 힌트: `EnemyHealth.OnStun` 이벤트 → 0.3초 타임윈도 내 `OnRangedHit` 발생 시 `CoopFinishManager.Trigger()`.

- **위험 학습 시스템** — Phantom Abyss 고스트 학습 참고: 처음 당한 공격 패턴(예: 천장 낙석)에 사망 시 해당 패턴 ID를 `RunHistory`에 기록. 다음 런 시작 로딩 화면에 "지난 런에서 천장 낙석으로 사망. 경고 이펙트를 놓치지 마세요." 짧은 힌트 표시. 구현 힌트: `RunHistory.RegisterCauseOfDeath(patternId)` → `LoadingHintSystem`에서 매핑 후 표시.

## 스토리 (05_Story)

- **고스트들의 속삭임** — Phantom Abyss 유령 감성 참고: 고스트 고양이들이 배회하는 방에서 가끔 짧은 텍스트 팝업. "이 방에서 갑자기 바닥이 열렸어...", "오른쪽 화분 조심해". 스포일러 없이 분위기와 힌트를 동시 전달. 프리팹 내 Trigger 콜라이더 진입 시 무작위 1개 문장 표시.

- **P1과 P2의 시점 차이** — KT&NE 정보 비대칭 감성 참고: 스토리 컷씬에서 P1(고양이)이 앞을 보고 달리는 동안 P2(파/양파)는 화분 위에서 360도 주변을 감시. P1은 몰랐지만 P2는 알고 있었던 위협 or 사실 → 관계의 긴장과 신뢰 형성에 활용. "너 그때 오른쪽에 뭔가 있었잖아?" "...알고 있었어."

- **소통의 진화** — KT&NE 협동 성장 참고: 초반 런과 후반 런에서 P1↔P2 대화 스타일 변화. 초반: "야! 왼쪽! 왼쪽이라니까!" (격앙, 길게). 중반: "왼쪽." (간결). 후반: 말 없이 이미 움직이고 있음. 텍스트 대화량 자체가 런 진행도를 반영 → 성숙한 협동 표현.

## 기술 메모

- **적 그룹 협동 공격 패턴**: OnionCat 구현 순서 → ① 단일 `EnemyAI` 상태머신 안정화 → ② `EnemyGroup` 컴포넌트 추가 및 역할(Pressure/Support) 배분 → ③ 멤버 사망 시 `OnMemberDied()` 역할 재조정. 가장 중요한 포인트: **Pressure = P1 타겟(근접 약점), Support = P2 타겟(원거리 약점)** 으로 고정하면 역할 강요가 게임플레이에 자연스럽게 녹아든다. 복잡한 AI 없이 이 역할 배분만으로도 "영리한 적" 인상을 줄 수 있음.

- **게임 폴리싱 체크리스트**: 초보자를 위한 **최소 주스 3종 세트** — `SpriteHitFlash(0.1초)` + `CinemachineImpulse` + `AudioRandomPitch(0.9~1.1f)`. 이 세 가지만 모든 피격/타격에 적용해도 게임 체감이 크게 달라짐. DOTween은 에셋스토어 무료판으로 시작하고 버튼 hover 애니메이션부터 적용 → 익숙해지면 히트 이펙트로 확장. 출시 전 **비개발자 플레이테스트 1회**가 UI 문제를 가장 빨리 발견하는 방법.
