## 캐릭터 (01_Characters)

- **Crop의 탄약 유형 분화** — Nuclear Throne 참고: Crop이 총 3종의 투사체를 전환할 수 있도록 설계. 예: 직선 관통탄(Bolt), 폭발탄(Explosive), 표준탄(Bullet). Cat이 근접 약점 적을 처리하는 동안 Crop은 상황에 맞는 탄종으로 원거리 지원. 구현: `CropShooter.cs`에 `ProjectileType` enum + 전환 입력 Action 추가.

- **Cat의 Ultra 대시 업그레이드** — Nuclear Throne Ultra Mutation 참고: 런 내 레벨 최대치 도달 시 Cat의 대시가 "폭발 대시"로 업그레이드 — 대시 경로에 AoE 피해 발생. Hitbox_Design.md의 `OverlapCircleAll` + 대시 코루틴 결합으로 구현. 대시 중 경로에 원형 히트박스를 프레임마다 검사.

- **공유 뮤테이션 선택 UI** — RoR2 Proc Coefficient 참고: 업그레이드 선택 화면을 Cat 전용 / Crop 전용 / 공유(이동속도·HP) 세 카테고리로 명시 분류. 두 플레이어가 동시에 조이스틱으로 카테고리를 가리킬 때 합의된 항목만 선택 가능 — 강제적 협의 UI.

## 적 (02_Enemies)

- **실드 어픽스 적** — RoR2 Elite 어픽스 참고: 앞면에 반짝이는 투명 실드를 가진 적 등장. Cat의 슬래시는 실드를 통과 불가(레이어 설정으로 Hitbox vs Shield 충돌 차단), Crop의 투사체만 실드를 파괴 가능. 실드 파괴 후 Cat 근접 공격에만 약점 공개 — 자연스러운 2페이즈 협동 요구.

- **반사 어픽스 적** — Nuclear Throne Crystal 스킬 참고: 빨간 발광 외형의 적이 투사체를 반사하는 버블 보유. Crop의 투사체가 반사되어 플레이어에게 되돌아옴. Cat이 먼저 근접으로 버블을 터트려야 Crop이 안전 사격 가능. 히트박스: 버블 = `EnemyHitbox` + `Shield` 레이어 동시 부여 → Cat 슬래시에만 반응.

- **Rads 타임아웃 보상 적** — Nuclear Throne 경험치 페이드아웃 참고: 처치 후 5초간 빛나는 코어(경험치)를 떨어뜨리는 적. 코어는 5초 후 소멸. Cat이 근처에서 수거하는 동안 Crop이 원거리에서 엄호하는 역할 분업 긴장감을 자연스럽게 유도.

## 맵 (03_Maps)

- **코어 충전 보스 룸** — RoR2 텔레포터 이벤트 참고: 보스 룸 중앙에 충전 코어 배치. 플레이어 중 한 명이 코어 반경 안에 있어야 충전 속도가 최대화됨. Cat이 충전 중 고정되면 Crop이 엄호, Crop이 실드로 방어하는 동안 Cat이 기동 처리. 구현: `BossCoreCharger.cs`에서 플레이어 거리 체크 + 충전 비율 표시 UI.

- **난이도 타이머 스테이지** — RoR2 시간 기반 난이도 참고: 각 스테이지 입장 후 UI 좌상단에 위협 레벨 게이지 표시. 2분 경과 시 엘리트 적 등장, 4분 경과 시 원거리 전용 적 비율 30%→60% 급증. 두 플레이어가 "지금 아이템 더 줍고 갈까 vs 보스로 바로 갈까"를 실시간 협의하게 만드는 능동적 압박.

- **분기 포탈 시스템** — RoR2 루프 vs 최종 보스 분기 참고: 스테이지 클리어 후 포탈 두 개 등장. 왼쪽(탈출 포탈): 안전하지만 적은 보상. 오른쪽(심층 포탈): 더 강한 적 + 희귀 아이템. 두 플레이어가 각자 포탈 앞에 서야만 진행 가능 → 합의 강제 메카닉.

## 전투 (04_Combat)

- **Cat/Crop 연계 체인 아이템** — RoR2 Proc Chain 참고: "Cat 슬래시 명중 → 2초 내 Crop 투사체 명중 시 전기 폭발 발동" 아이템 설계. 두 플레이어의 행동이 시너지를 만드는 구조. 히트박스 구현: Cat `Hitbox.cs`에서 명중 시 `RecentlySlahed` 타이머 설정 → Crop 투사체 `OnTriggerEnter2D`에서 타이머 확인 후 폭발 이펙트 Instantiate.

- **패리 반격 카운터 시스템** — Nuclear Throne 근접무기 투사체 반사 참고: Crop이 패리 성공 시 적의 투사체가 반사되어 즉시 적을 공격. 추가로 "패리 성공 시 다음 3초간 Cat 슬래시 대미지 ×2" 버프 부여 → 패리 성공이 Cat에게도 직접 이득. 구현: `ShieldController.cs`의 `TriggerParryEffect()`에서 Cat 참조 후 버프 코루틴 시작.

- **너그러운 히트박스 + 시각 피드백** — Hitbox_Design.md 참고: Cat 슬래시 판정 반경은 스프라이트보다 약간 넓게, 플레이어 Hurtbox는 스프라이트의 70%. 슬래시 미스라도 "아슬아슬하게 닿은" 시각 이펙트(흰 점멸 파티클)를 판정 반경 경계에서 재생 → 타격감과 회피의 명확한 피드백 모두 확보.

## 스토리 (05_Story)

- **게임 오버 화면 세계관 통합** — GameOver_Screen.md 참고: 게임 오버 시 단순 통계 나열이 아닌 Cat의 독백 한 줄 표시. 런 시간대별로 다른 독백 ("처음이라 많이 배웠어", "오늘은 여기까지..."), 처치 수가 높을수록 자신감 있는 대사. `RunStats.elapsedTime`과 `enemiesKilled` 값에 따라 대사 분기 → 퍼마데스를 감정적으로 완화하는 내러티브 피드백.

- **RoR2 귀환 구조 차용** — Risk of Rain 2 스토리 구조 참고: 매 런을 "오늘의 탈출 시도"로 프레이밍. 성공(보스 클리어) = 탈출 엔딩, 실패(게임 오버) = "다음 시도"로 자연스럽게 연결. 스테이지 진입 시 Cat과 Crop의 짧은 대화 한 줄이 표시되어 세계관 조각을 전달 — 실패를 스토리의 일부로 만들기.

- **Nuclear Throne 개발 공개 방식 참고** — 디자인 과정 자체를 기록: Nuclear Throne은 전 개발 과정을 스트리밍으로 공개해 커뮤니티 형성. OnionCat도 주요 시스템 완성 시마다 GIF/영상을 기록해두면 나중에 인디 데브로그 콘텐츠로 활용 가능. 지금 당장의 히트박스 시각화(Gizmos) 장면부터 시작.

## 기술 메모

- **히트박스 설계**: 가장 먼저 `IDamageable` 인터페이스와 `Hurtbox.cs` 기반 구조를 잡는 것이 핵심. 이후 Cat 슬래시(`OverlapCircleAll` + 각도 필터)와 Crop 투사체(`OnTriggerEnter2D` + Destroy) 순서로 구현. Layer Collision Matrix를 잘못 설정하면 피해가 전혀 들어가지 않으므로 설정 직후 `OnDrawGizmosSelected`로 Scene 뷰에서 반드시 시각 확인.

- **게임 오버 화면**: `GameManager` 싱글턴에 `DontDestroyOnLoad` 적용이 핵심 — 씬을 재로드해도 RunStats가 사라지지 않도록. `OnGameOver` C# event를 사용해 GameManager와 UI를 느슨하게 연결(직접 참조 금지). `Time.unscaledDeltaTime`으로 페이드인 구현하면 게임 일시정지 중에도 동작.
