## 캐릭터 (01_Characters)

- **빌드 편향(Build Bias)** — Nova Drift 참고: 고양이가 1~2번째 보상에서 근접 무기를 선택하면 이후 보상 풀의 근접/야성 계열 비중을 10~20% 올려주는 편향. `RuntimeRewardPoolFiltering`의 세트 가중치 조정으로 구현. 플레이어가 방향을 잡았다는 느낌을 강화
- **클로우 스타일 힌트 UI** — Monster Sanctuary 참고: 보상 카드 위에 현재 클로우 스타일과 시너지되는 무기에 작은 아이콘(예: 발톱 모양) 표시. `ClawStyle` 타입과 `GearItem.compatibleStyles` 필드로 구현 가능
- **새벽(고양이) 성격 힌트** — 이스터에그 참고: 특정 아이템 조합(털뭉치+대쉬 계열)을 모으면 그리모가 "예전에도 이렇게 뛰어다니던 고양이가 있었지"라는 대사를 함. 고양이 이름 "새벽"과 연결되는 로어 힌트

## 적 (02_Enemies)

- **교차 약점 체인** — Monster Sanctuary 링크 시스템 참고: 고양이가 "등 노출" 상태이상을 붙인 적에게 양파가 맞히면 추가 씨앗 2발 자동 발사. `Attacker.Cat/Onion` 판별 + `EnemyBase.Status`의 등 노출 체크로 구현 가능. 협동 콤보의 구체적 보상 사례
- **엘리트 적 OP 조합 의도 설계** — Nova Drift처럼 "이 두 적이 같이 나오면 말도 안 됨"을 의도적으로 설계. 예: 방패 근위병 + 등불 관리인(보호막) 조합. 플레이어가 조합을 발견하고 공략하는 재미. `EnemyRoster.squads`에 "hard" 등급으로 추가
- **비밀 적** — 이스터에그 참고: 한 판에서 100콤보 이상 달성 시 황금 슬라임(체력 1, 처치 시 씨앗 50 + 전설 장비 드롭)이 다음 방에 짧게 등장했다가 도망감. `MetaProgress`에 "golden_slime_seen" 플래그로 처음 발견 시 토스트 메시지

## 맵·런 구조 (03_Maps)

- **빌드 방향 표시 갈림길** — Nova Drift 참고: 출구 선택 화면에서 각 길의 "다음 방 보상 축(RewardAxis)" 표시 외에 "이 길에 이미 가진 세트 계열 보상 확률 ↑" 힌트를 추가. 현재 RunData의 세트 보유 현황 기반 계산
- **숨겨진 방 조건** — 이스터에그 참고: 한 스테이지에서 엘리트 방 3개를 연속 클리어 시 보스 방 직전에 "고요한 정원" 비밀 방 등장. 회복 샘물 + 숨겨진 대사 조각. `DungeonManager`에서 연속 엘리트 카운터 추적
- **빌드 아카이브 화면** — Nova Drift 커뮤니티 문화 참고: 런 종료 화면에 이번 판의 주요 아이템 조합 스크린샷 가능 버튼 추가. `Screenshot_Share_System` 연계. 나중에 Steam 커뮤니티 공유 문화 형성에 기여

## 전투·협동 (04_Combat)

- **질적 세트 변화** — Monster Sanctuary 고단계 보너스 참고: 햇살 세트 8단계에서 단순 수치가 아닌 "씨앗이 맞으면 꽃이 피어 주변 적을 느리게 함" 등 새 오브젝트 생성 효과. `CombatModifiers.Has(SetType.Sun, 8)` 조건 + `PoolManager.Spawn`으로 꽃 오브젝트 생성
- **안티시너지 도입 (장기 고민)** — Nova Drift 참고: 방어+공격 계열 세트를 동시에 쌓으면 "불안정 효과" (소폭 패널티). 현재는 모든 조합이 중립 — 선택에 긴장감 추가. 장르 경험이 더 쌓인 후 도입 권장
- **합동기 시각 연출 강화** — Nova Drift "빌드 발현 연출" 참고: ONION STORM 발동 시 화면 주변부에 세트 색깔의 에너지 테두리가 잠깐 번쩍이는 효과. 현재 세트 계열(`CombatModifiers`)에서 색상을 읽어 URP 2D의 Global Volume Post-Processing으로 프레임 Flash

## 아이템·세트 (05_Items)

- **세트 간 교차 보너스** — Nova Drift Affinity 시스템 참고: 햇살 세트 4단계 + 바람 세트 4단계를 동시에 보유 시 "광합성 폭풍" 보너스 (두 세트 효과가 합쳐진 새 효과). `CombatModifiers`에 복합 조건 추가. 보너스 발동 시 HUD에 별도 세트 아이콘 표시
- **아이템 설명 로어 텍스트** — 이스터에그 참고: 모든 장비의 `description`에 짧은 이야기를 추가. "기본 발톱 — 손잡이 안쪽에 작은 글씨: '새벽에게, 돌아와.'" 별도 구현 없이 텍스트 작업만으로 콘텐츠 깊이 증가
- **비밀 전설 아이템** — 이스터에그 참고: 특정 조건(같은 세트를 8단계 완성)으로만 얻을 수 있는 4번째 전설 아이템 "세트의 정수". 현재 전설 3개(아홉 목숨·그림자 분신·황금 양파) 외 비밀 전설 1개를 `RewardTable`에 조건부로 추가

## 스토리·메타 (07_StoryMeta)

- **그리모의 과거 힌트 대화** — 이스터에그 참고: `MetaProgress.WitchFreed` 이후, 특정 아이템 조합 보유 시 그리모가 마녀와의 과거 이야기를 짧게 언급. `StoryLines.cs`에 아이템 보유 조건 추가. 반전 전에는 "오래된 마법서" 같은 간접 표현만
- **빛 색깔 퀘스트 힌트 시스템** — Monster Sanctuary 발견 가이드 참고: 마을 등불 앞에서 현재 보유 중인 작물의 빛 색과 필요한 빛 색을 시각적으로 비교할 수 있는 UI. 현재 `LightColor` 혼합 결과와 `StoryRoute.NeedOf` 비교를 색 원으로 표시
- **1인 개발 완성 전략** — Monster Sanctuary 개발사 참고: "2스테이지 완성 → 출시 → 3스테이지 DLC" 전략을 구체적으로 고려. 전체 6스테이지 계획 대신 3스테이지 완성품을 얼리 액세스로 출시하고 커뮤니티 반응을 보며 추가. CLAUDE.md의 로드맵과 연결해서 TODO.md에 명시 권장

## 기술 메모

- **GC-Free Patterns**: OnionCat에서 가장 긴급한 적용 항목은 `EnemyBase.Active` 조회의 LINQ 제거와 HUD 텍스트 갱신 최적화. 방 입장 시 적 대량 스폰 직후 GC Spike가 있는지 Profiler로 확인 후 대응. `Coroutine`의 `new WaitForSeconds` 사용 패턴도 점검
- **이스터에그 시스템**: 별도 대형 구현 없이 시작 가능. 1단계: `GearItem.description`에 로어 텍스트 추가 (코드 없음). 2단계: `MetaProgress.unlockedSecrets` 리스트 필드 추가 + `Dialogue.Play` 조건 분기. 3단계: `DungeonManager`에 비밀 방 트리거 추가. 순서대로 진행하면 리스크 없이 콘텐츠 깊이 증가
