## 캐릭터 (01_Characters)

- **마법서 발동 방식 차별화** — Victor Vran 참고: 지금 마법서 Q·W·E가 쿨타임·범위만 다름. 무기별 패턴이 완전히 다른 Victor Vran처럼 발동 방식을 다르게 — Q 즉발·W 차지형·E 배치형으로. 선택 자체가 전략이 되어 세트 보너스가 없어도 고르는 재미 생김
- **대쉬 잔상** — Sprite Trail 참고: 대쉬 무적 중 옅은 파란 잔상(`new Color(0.5f, 0.7f, 1f, 0.8f)`, 간격 0.03s, 수명 0.2s)이 뒤에 남으면 "무적 상태"를 직관적으로 전달. `HitFeelSettings.asset`에 색·간격·수명을 넣어 플레이 중 조절. `PoolManager.Spawn`으로 풀에서 꺼내 드로우콜 최소화
- **야성 특수 돌진 주황 잔상** — 야성 게이지 색에 맞춘 주황 잔상(간격 0.02s, 수명 0.3s). 대쉬(파랑)와 색이 달라 "지금 뭐 하는 중인지" 화면만 봐도 구분 가능

## 적 (02_Enemies)

- **한 명만 볼 수 있는 경고** — Operation Tango 참고: 보스가 다음 패턴 준비할 때 경고 아이콘을 "작물 HUD에만" 먼저 표시. 작물이 "오른쪽 위에서 탄 온다!" 고양이가 반응하는 소통 유발. 말하지 않아도 됐던 조작이 대화 협력으로 바뀜
- **작물 없이는 못 쓰러뜨리는 적** — 특정 엘리트에 "고양이 근접은 튕겨냄, 씨앗 탄 맞으면 약점 노출 → 그때 고양이 할퀴기 가능" 패턴. 작물이 먼저 타격하지 않으면 고양이만으로 처리 불가 → P2 역할감 강화
- **패링 → 협동 콤보 게이지 가속** — Victor Vran Overdrive 참고: 패링 성공 시 협동 콤보 게이지 +15% 추가. "안 해도 되지만 하면 보람 있는" 선택 보상 구조. 패링이 단순 반사 피해에서 협동 전략의 한 축으로 성장

## 맵·런 구조 (03_Maps)

- **비대칭 퍼즐 방** — Operation Tango 참고: 마을 특수 방에 "고양이 화면에 보이는 그림 순서를 작물이 UI에서 맞추는" 간단 퍼즐 추가. 말로 알려주지 않으면 클리어 불가. 클리어 시 소규모 보상(체력 회복·씨앗). `Room_Special` 재활용으로 추가 씬 불필요
- **런 결과 화면에서 리뷰 요청 토스트** — Review Request 참고: 첫 보스 클리어 직후 런 결과 화면 하단에 작은 토스트. 전투가 끝나고 숨 돌리는 순간이 최적 타이밍. `MetaProgress.reviewRequested` bool 하나로 관리, 한 번만 표시
- **보스 처치 직후가 최고 감동 순간** — Review Request 설계 원칙: 보스 클리어 → 런 결과 화면이 가장 긍정적 감정 최고조. 이때 리뷰 요청을 하면 긍정 리뷰 비율이 올라감. 엔딩 크레딧 후 "감사합니다" 화면에도 리뷰 버튼 배치

## 전투·협동 (04_Combat)

- **Fate Card → 물음표 방 선택 사전 고지** — Victor Vran 참고: Fate Card는 플레이어가 "자발적"으로 단점을 추가하여 억울함 없음. OnionCat 물음표 방도 입장 전에 "이 방에 들어가면 O O 패널티" 사전 고지하면 플레이어가 선택하는 느낌. 갈림길 지도에서 물음표 방 아이콘에 마우스 오버 시 힌트 표시 가능
- **무적 상태 직관적 전달** — Sprite Trail 참고: 대쉬 무적은 현재 무적 여부를 화면만 보고 판단하기 어려움. 파란 잔상이 사라지는 순간 = 무적 끝 → 조작 타이밍 판단에 직접 도움
- **Overdrive → 맞지 않는 플레이 가속** — Victor Vran 참고: 패링과 대쉬 회피로 피해 없이 연속 공격 성공 시 협동 콤보 게이지 충전 속도 +20% 보너스. 숙련자는 더 빠른 합동기 발동, 초보도 "안 맞으면 뭔가 좋은 일이 생긴다"는 직관적 피드백

## 아이템·세트 (05_Items)

- **무기 2슬롯 교체 → 서브 무기 아이디어** — Victor Vran 참고: 고양이 무기 슬롯을 2개로 늘리는 대신 "서브 무기 = 특수 공격 형태 변경"으로 제한. 예: 메인 무기 도약 할퀴기 + 서브 무기 "회오리 특수"를 조합. 조작 복잡도 낮게 유지하면서 빌드 다양성 확장
- **가속 버프 장비 연두색 잔상** — Sprite Trail 참고: "이동속도 X초 증가" 효과 발동 시 연두색 잔상(간격 0.05s, 수명 0.15s). 버프가 발동 중인지 화면에서 바로 보임 → 타이밍 조절에 도움
- **리뷰 연동 보상 아이디어** — Steam 리뷰를 남기면 게임 내 특별 코스메틱 해금하는 방법은 Steam 정책 위반. 대신 "엔딩 도달" 플레이어에게만 비밀 콘텐츠 힌트를 보여주면 자연스러운 리뷰 유도 가능

## 스토리·메타 (07_StoryMeta)

- **말하는 책이 비대칭 정보 전달자** — Operation Tango 참고: 책이 고양이에게만 말하는 대사와 작물에게만 보이는 힌트를 각각 다르게 주면 "한 명이 다른 한 명에게 알려줘야 하는" 순간 연출 가능. 등대 미션에서 활용: 책이 양쪽에 절반씩만 알려주는 단서
- **엔딩 직후 리뷰 요청** — Review Request 참고: 엔딩 크레딧 후 "감사합니다 — 개발자 한 명이 만들었습니다. Steam 리뷰 하나가 큰 힘이 됩니다"라는 메시지 화면. 이 타이밍이 감정적으로 가장 울림이 크고 긍정 리뷰 전환율이 높음
- **판 횟수에 따른 메아리 대사** — Victor Vran Destiny System 참고: `MetaProgress.RunCount`에 따라 말하는 책 대사 분기 (5판 "익숙해졌군" / 10판 "이 길을 잘 아는 것 같다"). 세계관을 무너뜨리지 않으면서 성장감 전달

## 기술 메모

- **Sprite Trail Ghost Effect**: `PoolManager.Spawn`으로 TrailGhost 프리팹을 꺼내 `MaterialPropertyBlock`으로 색상 주입 → 드로우콜 최소화. 대쉬 시작/끝 각각 `StartTrail()`·`StopTrail()` 호출. `HitFeelSettings.asset`에 색·간격·수명 추가 (06_FeelParameters.md 업데이트 필요). 가장 먼저 적용할 곳: 고양이 대쉬 (CatController.PerformDash 주변 2줄)
- **Player Review Request System**: `MetaProgress.data`에 `bool reviewRequested` 추가 → meta.json에 저장. 호출 위치: 런 결과 화면 초기화 (`RunResultScreen.Init`) + 엔딩 화면. Steam API는 `SteamFriends.ActivateGameOverlayToWebPage`로 직접 Steam 상점 페이지 열기. 한 번만 묻고 "나중에" 눌러도 1회 더, 그 이후 조용히. 테스트 시 meta.json 백업 필수
