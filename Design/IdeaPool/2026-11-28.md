## 캐릭터 (01_Characters)

- **작물 시각적 성장 (보스 처치 단계)** — Stardew Valley 참고: 보스 처치마다 화분 작물이 한 단계씩 성장하는 비주얼. 보스 1마리 → 꽃봉오리, 2마리 → 꽃 핌, 3마리(최종 보스) → 열매 맺음. `CatArtRenderer`의 작물 소켓 스프라이트만 교체하면 되고 `RunData.CropGrowthStage`에 저장. 성장 시 짧은 파티클+소리로 "런이 쌓인다"는 느낌
- **고양이 첫 판 무작위 외형** — Heave Ho 참고: Heave Ho는 모든 스킨이 처음부터 개방. 고양이 귀 색·리본 색을 첫 판에 무작위로 선택해 보여주면 "오늘의 고양이"가 매판 조금씩 달라지는 느낌. 온실 해금 없이도 소소한 변화. `MetaProgress.dailyCatSeed` 하나면 구현 가능
- **합동기 발동 시 작물 기울기 연출** — Heave Ho에서 연쇄 연결 시 함께 기우는 느낌. 합동기(Space/RB 동시) 발동 시 작물이 고양이 진행 방향으로 살짝 기울었다가 돌아오는 0.2초 애니메이션. 현재 작물은 항상 수직 — 이 순간만큼은 "함께 돌진하는" 느낌 강조

## 적 (02_Enemies)

- **고양이 단독으로 뚫을 수 없는 적 패턴** — Heave Ho의 "혼자서는 절대 못함" 원칙. 양파 씨앗이 없으면 처치 불가능한 적 디자인 (예: 완전 방어막 보스 — 고양이 근접 무효, 씨앗으로 방어막 먼저 제거해야 함). 협동이 "선택"이 아닌 "필수"가 되는 패턴을 보스전에 하나씩 넣는 것 고려
- **작물 테마 적 (식물 공생형)** — Stardew Valley 참고: 작물에 반응하는 적. 예: "꽃 먹는 벌레" 적이 작물 꽃봉오리 단계에 반응해 고양이 쪽으로 돌진 (작물이 성장할수록 주의해야 하는 적). 던전 테마와 조합 — 밀밭 스테이지에 등장 시 자연스러운 세계관 연결
- **스테이지 테마 × 작물 조합 약점** — Stardew의 계절×작물 시너지. 푸른 버섯의 독 포자탄이 등대 테마(어두운 공간)에서 넓게 퍼지는 광역 약점 적 추가. `CombatModifiers`에 스테이지 조건 분기 추가 — 현재 구조에서 확장 가능

## 맵·런 구조 (03_Maps)

- **작물별 스테이지 테마 시너지 힌트** — Stardew의 계절 추천 작물처럼, 런 시작 화면에서 "이번 첫 스테이지는 밀밭 → 해바라기가 잘 맞아" 한 줄 힌트 (말하는 책이 말풍선으로). 단 강제는 아님. `StoryRoute.CurrentTheme`와 `CropData.favoredThemes[]` 비교로 체크
- **온실 작물 화분 비주얼** — 온실 화면(`GreenhouseScreen`)에서 해금된 작물을 화분에 실제로 자라는 모습으로 표시. 해금 전 = 흙뿐인 빈 화분. 해금 후 = 성장 단계 최고 스프라이트. 클릭으로 작물 선택 시 화분이 살짝 흔들리는 연출
- **빛 색깔 수량화** — Stardew의 가공품처럼 "더 많이 모을수록 더 강한 빛". 현재는 색깔만 추적하는데, `RunData.lightAmount`를 추가해 한 판에 많이 잡을수록 더 많은 빛. 등불 비출 때 양이 충분하면 더 빨리 단계 진행 (충분 조건: 연속 3판 모두 빛 50 이상 등)

## 전투·협동 (04_Combat)

- **실패 연출 귀엽게** — Heave Ho의 Ragdoll 연출처럼 죽음이 우습게 보이도록. 현재 HP 0 → 단순 GameOver 화면인데, 화분이 굴러 작물이 "앗!" 말풍선, 고양이가 뒤로 쓰러지는 0.5초 연출 추가. 슬로우모션(0.2→0배) 후 화면 페이드. "다시 하고 싶다"는 느낌
- **협동기 필수 패턴** — Heave Ho의 "연결 고리 없이 불가능한 구간"처럼, 보스 2페이즈에서 합동기 없이는 처치 불가능한 15초 무적 구간을 넣어 "합동기 적절히 아꼈다가 여기서 쓰자"는 전략성 부여
- **패링 시 작물 흔들림** — 고양이가 패링 성공 시 등의 작물이 충격으로 살짝 흔들리는 2차 모션. `Secondary_Motion_System.md` 참고. 패링의 존재감을 작물 쪽에서도 느낌. DOTween PunchRotation 0.1초면 충분

## 아이템·세트 (05_Items)

- **작물 성장 연동 장비 효과** — Crop Growth System 참고: "작물 성장 단계가 올라갈 때마다 씨앗 탄 대미지 +10%" 효과를 가진 장비. 런 내 보스 처치가 장비 강화로 이어지는 느낌. `GearEffect` 발동 조건에 `CropGrowthStageUp` 이벤트 추가
- **수확 부적 — 반복 수확 아이템** — Stardew의 반복 수확 작물처럼, "적 10마리 처치마다 씨앗 1개 자동 획득" 아이템. `Crop_Growth_Resource_System.md` 참고 코드 활용. 씨앗이 부족한 작물 플레이어에게 긴 전투방에서 도움
- **세트 활성화 시 작물 비주얼 변화** — Stardew의 가공품 가치 상승처럼 비선형적 강화감. 세트 보너스 2단계 활성화 시 작물 주변에 세트 색 미니 파티클이 맴도는 연출(파티클 10개 미만으로 가볍게). 협동하는 느낌과 "합쳐져서 더 강해졌다"는 시각 피드백

## 스토리·메타 (07_StoryMeta)

- **책의 대사 — 작물 성장 반응** — Stardew 주민 반응처럼, 보스 처치 후 성장한 작물을 보고 말하는 책이 한 마디. "꽃이 피었군... 기운이 모이고 있어." 판마다 처음 성장 단계가 올라갈 때 한 번만. `StoryLines.cs`에 `OnCropGrowth(stage)` 조건 분기
- **Heave Ho 스타일 첫 세션 경험** — Heave Ho는 조작 튜토리얼 없이 바로 게임으로 시작. OnionCat도 첫 판에 긴 튜토리얼 대신 "자연스러운 첫 방"으로. 첫 방에서 고양이가 적 1마리와 마주칠 때 책이 짧게 한 마디: "저걸 쓰러뜨리게" — 이게 전부. 나머지는 플레이어가 직접 발견
- **출시 전 법적 고지 준비** — Legal Notice 참고: Galmuri11 폰트 OFL 고지를 크레딧 화면에 추가해야 함. 오디오 출처도 `LICENSE_AUDIO.txt`에 이미 있으니 크레딧 화면에서 "효과음: freesound.org / opengameart.org" 한 줄 참조. 지금 당장 `Assets/Resources/LICENSES.txt` 파일 만들어 두는 것 권장

## 기술 메모

- **Crop Growth Resource System**: `RunData`에 `CropGrowthStage` int 하나 추가 → `CatArtRenderer`에서 구독하면 됨. 보스 처치 이벤트가 이미 있으니 연결만 하면 되는 1일 작업. DOTween.PunchScale로 성장 연출. 작물 스프라이트 단계는 기획이 그림 나오면 넣을 수 있도록 `CropData.growthSprites[]` 배열 자리만 미리 만들어둘 것
- **Legal Notice Screen**: 지금 당장 `Assets/Resources/LICENSES.txt` 파일 생성 — 내용은 Galmuri11 OFL 고지 한 줄로 충분. 크레딧 화면에서 `TextAsset`으로 읽어 표시. Steam 출시 전 연령 등급 self-rating (PEGI 또는 ESRB) 반드시 완료할 것 — 없으면 출시 불가
