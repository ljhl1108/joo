## 캐릭터 (01_Characters)

- **슬래시 만능 동사 설계** — Anger Foot '킥' 참고: P1 슬래시를 전투 이외 상황에도 활용 가능하게 확장. 슬래시 → 투사체 반격, 환경 오브젝트 파괴, 문 강제 돌파 3가지 모두 동일 입력으로 처리. 구현 힌트: `OnTriggerEnter2D` 내 tag 분기 (`Projectile`/`Enemy`/`Destructible`) 하나로 처리해 입력 단순성 유지.
- **팔레트로 읽는 강화 등급** — 런타임 팔레트 스왑 참고: P1이 업그레이드를 획득할수록 고양이 스프라이트 색상이 변화 (기본 주황 → Tier1 금색 → Tier2 붉은 화염 톤). P2(작물)는 독립 팔레트로 별도 변화. 코드 없이 LUT 행만 추가하면 신규 강화 등급 색상 추가 가능.
- **합류 보류 온보딩** — Hybrid Onboarding 참고: 첫 실행 시 P2(마우스)가 "역할 확인" 버튼을 누르기 전까지 P1이 혼자 샌드박스 방에서 이동/슬래시 연습 가능. P2가 나중에 합류해도 자연스럽게 이어서 진행 — 친구가 뒤늦게 앉아서 시작하는 현실적 시나리오 대응.

## 적 (02_Enemies)

- **즉사-리스타트 적 변형** — Anger Foot 원히트 킬 참고: 일반 적은 3~5히트로 처치하지만, 특정 "암살자형" 적은 감지되면 즉사 공격을 날림. 단, 사전 예고(발광 이펙트 0.5초)가 있어 패리 또는 대쉬로 회피 가능. 즉사 리스크로 긴장감을 주되 예고로 공정성 유지.
- **색상으로 취약점 표시하는 적** — 팔레트 스왑 참고: 근접 취약 적 = 붉은 팔레트, 원거리 취약 적 = 파란 팔레트. 적 스프라이트를 별도 제작하지 않고 팔레트 스왑으로 같은 스프라이트를 재색칠해 취약점을 직관적으로 표시. 색맹 지원은 형태/아이콘 오버레이 병행.
- **모멘텀 파괴자 (Stopper)** — Anger Foot 모멘텀 디자인 대비: 방 입장 시 P1의 이동 속도를 반으로 줄이는 "끈끈이 지형" 생성 적. 플레이어가 멈추지 않으면 불리해지므로 P2가 먼저 원거리로 제거해야 P1이 쾌속 진입 가능. 역할 분담 자연 발생.

## 맵 (03_Maps)

- **런 중 모멘텀 방 (Corridor Sprint Room)** — Anger Foot 방 전환 참고: 긴 복도형 방 하나를 매 층 고정 삽입 (보스방 직전). 좌→우로 달리면서 줄지어 나오는 적을 처치. 멈추면 뒤에서 새 적이 소환. BGM 업템포 전환으로 흥분감 극대화. 클리어 후 곧바로 문이 열려 보스방 진입.
- **색조 구분 바이옴** — 팔레트 스왑 참고: 각 던전 층의 타일 셋을 재사용하되 팔레트만 바꿔 분위기 차별화. 1층=초록/숲, 2층=주황/용암, 3층=파란/심해. 아티스트 작업량 감소 + 플레이어가 층을 직관적으로 구분.
- **입력 안내 방 (Tutorial Room Trigger)** — 온보딩 참고: 첫 런 한정으로 특정 방에 "힌트 오브젝트"를 배치. P1이 근처를 지나치면 해당 메카닉 팁 말풍선이 2초 표시. 강제 중단 없이 플레이 흐름 안에서 자연스럽게 학습. 2회차 이후엔 힌트 오브젝트 비활성화.

## 전투 (04_Combat)

- **발차기 체인 → 슬래시 피니셔** — Anger Foot 단일 입력 다중 기능 참고: P1이 3연속 슬래시 시 마지막 슬래시가 "피니셔 발차기"로 변환 → 적 날아가며 주변 소형 적 타격. 연타의 리듬감과 보상 피드백 제공. 구현: 슬래시 카운터 변수, 0.5초 내 3회 입력 시 피니셔 모션 재생.
- **팔레트 플래시 히트 확인** — Sprite Hit Flash + Palette Swap 연계: 피격 0.1초 동안 팔레트 Row 1(흰색 틴트)로 강제 전환 후 복귀. 기존 `Sprite_Hit_Flash_System.md`에 팔레트 기반 구현을 대체 방식으로 추가. `MaterialPropertyBlock` 사용으로 드로우콜 유지.
- **온보딩 협력 필살기 잠금 해제** — Hybrid Onboarding 완료 조건에서 파생: 튜토리얼에서 P1+P2 합동 공격을 처음 성공하면 "공명 폭발(Resonance Burst)" 스킬이 잠금 해제됨. 게임 시작 전부터 협력이 핵심임을 체험으로 전달. 업적 연동: "첫 공명 달성".

## 스토리 (05_Story)

- **입력 장치 = 세계관 오마주** — P1(게임패드)은 고양이의 발(직접 뛰어다님), P2(마우스)는 작물의 뿌리(땅에서 방향 감지). 조작 방식 자체가 캐릭터 특성과 일치하는 설정. 메뉴 화면 안내 문구에 이 서사를 한 줄로 녹임: "발로 뛰고, 뿌리로 감지하라."
- **색상 변화 = 성장 스토리** — 팔레트 스왑 강화 티어를 서사와 연결: 기본 주황 고양이 = 일반 마을 고양이. 금색 = 마법 꽃의 기운을 흡수 시작. 화염 붉은 = 완전 각성. 텍스트 설명 없이 시각적 색상 변화로 캐릭터 성장을 표현.
- **튜토리얼 내레이터 = 작물(P2) 목소리** — 온보딩 화면의 안내 텍스트 화자를 P2(양파)로 설정. P2가 P1에게 조작을 가르쳐주는 형식 → "야옹아, 스틱을 움직여. 내가 길을 볼게." 캐릭터 소개와 조작 안내를 동시에 처리.

## 기술 메모

- **Runtime Palette Swap**: `MaterialPropertyBlock`은 재질 인스턴스를 만들지 않아 SpriteAtlas 배칭을 유지함. 상태이상(독/화염/피격) 팔레트를 LUT 텍스처 행으로 미리 구워두면 런타임 비용 거의 없음. 아티스트와 색상 인덱스 규칙(R 채널=인덱스)을 공유하는 것이 가장 중요한 선결 조건.
- **Hybrid Split-Input Onboarding**: 첫 실행 여부는 `PlayerPrefs.GetInt("OnboardingComplete", 0)` 로 확인. 온보딩 씬은 별도 씬으로 분리하고 `SceneManager.LoadScene`으로 전환 — 메인 메뉴 씬 안에 패널로 넣으면 UI 상태 관리가 복잡해짐. New Input System의 `SwitchCurrentActionMap("UI"/"Gameplay")` 전환을 온보딩 각 단계마다 명시적으로 호출할 것.
