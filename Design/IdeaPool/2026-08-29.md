## 캐릭터 (01_Characters)

- **건우산식 대시-공격 연계** — Gunbrella의 "우산 후진 샷 추진" 참고: Player 1(냥이)이 대시 방향으로 이동하는 동안 슬래시 판정이 활성화되어, 단순 이동 + 공격이 아닌 "돌진 베기" 연출 구현, 구현 힌트: Dash 상태 진입 시 MeleeHitbox를 일시적으로 Enable하고 Dash 종료 시 Disable
- **퍼펙트 패리 강화 탄 — Player 2 전용** — Gunbrella 퍼펙트 패리 참고: 적 탄이 방패에 닿는 0.15초 이내(타이밍 윈도우)에 패리 버튼을 누르면 반사탄이 2배 데미지로 돌아감, 구현 힌트: `ShieldController`에 `float parryWindow = 0.15f`와 `bool isPerfectParry` 플래그 추가, 퍼펙트 패리 시 투사체의 `damage *= 2`
- **업그레이드 = 조작 변형** — Gunbrella의 단일 무기 철학 참고: 아이템 추가보다 기존 조작의 변형으로 업그레이드 설계 (예: "슬래시 범위 +30%", "대시 거리 +1칸", "패리 윈도우 +0.05초"), 구현 힌트: ScriptableObject `UpgradeData`에 `StatModifier` 리스트 형태로 관리, 조작 복잡성 최소화

## 적 (02_Enemies)

- **공간 해싱 감지 적 — 범위 탐색 적** — 적 최적화 리서치 참고: SpatialHashGrid를 활용하여 10칸 이내에 플레이어가 들어오면 일제히 추격 시작하는 군집형 졸개 적 ("슬라임 무리"), Player 1이 돌진할 때 사방에서 몰려드는 압박감 연출, 구현 힌트: 방 입장 시 SpatialHashGrid 초기화, 매 FixedUpdate에 플레이어 위치 등록 후 EnemyAI가 쿼리
- **패리 강요 적 — 방패 달린 마름모** — Gunbrella 퍼펙트 패리 참고: 정면에서 날아오는 고속 탄을 막으면 적의 방어막이 잠시 깨지고 근접 공격 가능한 "방패 적" 설계, Player 2가 패리 → Player 1이 공격하는 협동 흐름 강제, 구현 힌트: `ShieldedEnemyAI`에서 `isVulnerable` 플래그, Player 2 패리 성공 이벤트에서 `isVulnerable = true` + 코루틴 2초 후 복원
- **페이즈 별 약점 교체 적** — Gunbrella 보스 페이즈 참고: 체력 70% 이상(원거리 약점) → 70% 이하(근접 약점)으로 전환, 방 중반부에 등장하는 중형 정예 적에도 2단계 페이즈 적용하여 협동 전략 변화 유발, 구현 힌트: `EnemyHealth.OnHealthChanged`에서 threshold 감지 후 `EnemyWeaknessSystem.SetWeakness(WeaknessType.Melee)`

## 맵 (03_Maps)

- **챌린지 방 (도전 방)** — 챌린지 목표 시스템 참고: 일반 방과 달리 입구에 "패리 3회 챌린지" 표시가 뜨는 선택형 도전 방, 도전 수락 시 문이 잠기고 챌린지 시작, 성공하면 레어 아이템 보상, 실패해도 클리어는 가능하지만 보상 없음, 구현 힌트: `RoomType.Challenge` 추가, 입구에 도전 UI 팝업 → 플레이어 A 버튼으로 수락
- **탁 트인 군집 방 (최적화 시험 방)** — 적 군집 최적화 참고: 30마리 이상 소형 적이 등장하는 광활한 방, 공간 해싱 최적화 효과를 실감할 수 있는 디자인, Player 2 광역 탄막 + Player 1 대시 베기로 군중 정리하는 플레이 유도, 구현 힌트: 방 프리팹에 `WaveSpawner` 컴포넌트 추가, `EnemySwarmConfig ScriptableObject`로 개수/종류 조정
- **Gunbrella식 반(半)고정 바이옴 방** — 바이옴별 방 느낌 참고: 동굴 구역/정원 구역/창고 구역별로 타일셋 + 환경 오브젝트가 고정, 방 내 배치만 랜덤으로 바뀌어 "익숙하면서도 새로운" 느낌 유지, 구현 힌트: `BiomeType` enum으로 Tilemap 팔레트 교체, 방 프리팹은 바이옴별 폴더로 분리

## 전투 (04_Combat)

- **공간 해싱 기반 근접 판정 최적화** — 적 최적화 참고: Player 1 슬래시 판정 시 `Physics2D.OverlapCircle` 대신 `SpatialHashGrid.GetNeighbors(slashPos, slashRadius)`로 교체, 화면에 적이 많아도 슬래시 히트 판정이 안정적으로 60fps 유지, 구현 힌트: EnemyManager에 싱글턴 SpatialHashGrid 두고 MeleeAttackSystem에서 참조
- **협동 챌린지 → 보상 업그레이드** — 챌린지 목표 시스템 참고: "근접 3킬 + 패리 2회 동시 달성" 챌린지 성공 시 두 플레이어 모두에게 영향을 주는 협동 업그레이드 해금 (예: "연계기: Player 1 슬래시 후 2초 이내 Player 2 탄 적중 시 추가 피해 +50%"), 구현 힌트: `ChallengeGoalManager.OnChallengeCompleted`에서 `CoopUpgradeUnlocker` 호출
- **패리 타이밍 시각적 피드백** — Gunbrella 퍼펙트 패리 참고: 퍼펙트 패리 타이밍 윈도우(0.15초)를 플레이어가 익히도록 방패 테두리에 플래시 이펙트 + 화면 일시 정지(히트스톱 0.05초) 연출, 구현 힌트: `TimeScale.BulletTime(0.05f, 0.05f)` + 방패 `SpriteRenderer.color = perfectParryColor`

## 스토리 (05_Story)

- **챌린지 달성 시 대화** — 챌린지 시스템 참고: 패리 마스터 챌린지 성공 시 작물이 "완벽했어요!" 대사 출력, 무피격 클리어 시 냥이가 "훌륭해!" 한마디, 게임 플레이 성과를 서사와 연결, 구현 힌트: `ChallengeGoalManager.OnChallengeCompleted`에서 `DialogueEventTrigger.PlayChallengeDialogue(challengeType)` 호출
- **Gunbrella식 누아르 분위기** — 검은 과거를 가진 냥이: 챕터 1 보스를 클리어하면 냥이가 짧은 독백으로 과거 단편을 드러냄, "저 작물… 전에도 누군가를 잃은 적이 있다." 식의 미스터리한 서사 단서, 구현 힌트: `BossKilledEvent` 수신 후 Ingame Cutscene 1~2초짜리 독백 씬 트리거
- **챌린지 실패 시 작물 위로 대사** — 무피격 챌린지 실패(피격 발생) 시 작물이 "괜찮아요, 다음에 잘 하면 돼요"라고 위로, 실패 경험도 서사 안에서 흡수하여 게임 오버 느낌을 부드럽게 만듦, 구현 힌트: `ChallengeGoalManager.OnChallengeFailed`에서 소형 텍스트 버블 UI 트리거

## 기술 메모

- **적 다수 처리 최적화**: OnionCat에서 가장 먼저 할 것 → Enemy끼리 Physics Layer 충돌 OFF + Object Pool 적용. 공간 해싱은 방당 30마리 이상 등장하는 군집 방 설계 전에 필수 선행 구현. 핵심: `SpatialHashGrid.cellSize`는 방 너비의 1/8 정도(약 2~3 유닛)로 설정, FixedUpdate에서 매 프레임 Clear → Register 반복.

- **인게임 챌린지 목표 시스템**: 구현 순서 → ① `ChallengeGoalData` ScriptableObject 5개 제작 (KillCount, NoDamage, ParryCount, MeleeOnly, RangedOnly) → ② EventBus에 ChallengeFailed/Completed 이벤트 추가 → ③ HUD 우상단에 소형 챌린지 패널 배치 → ④ 방 입장 이벤트에서 `StartNewChallenge()` 호출. "피격 없이 클리어"는 RoomCleared까지 DamageTaken 이벤트가 없으면 성공으로 처리.
