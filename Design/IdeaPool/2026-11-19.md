## 캐릭터 (01_Characters)

- **무기별 플레이스타일 "리듬" 명확화** — Rotwood 참고: 고양이 무기 5종(기본·회전·도약·3타·연타)이 각각 다른 타이밍 리듬을 가지도록. 예: 도약형은 도착 직후 타격이 강력하니 "점프 후 즉시 공격"을 플레이어가 익히게. 훈련 구역(시작 농장)에서 무기별 연습 타겟을 2개씩 배치해 첫 런에 자연스럽게 감각 습득.

- **고양이 훈련 타겟** — 농장 시작 허브에 허수아비 3개 배치: 하나는 멀리 있어 대쉬로 접근 연습, 하나는 등이 보여 "등 타격 ×2 보너스"를 자연스럽게 발견, 하나는 느리게 움직여 추적 연습. 이미 농장 허브가 있으므로 씬에 소품만 추가. 허수아비는 EnemyBase 아닌 별도 Dummy 컴포넌트로 (피격 소리+숫자는 같이, 체력 무한).

- **작물 고유기 R의 "파지(Grip)" 커뮤니케이션** — 해바라기 햇빛 기둥, 양파 심기 등 배치형 R 고유기는 P2가 "어디에 놓는지"가 중요함. 고양이 발 아래가 아니라 P2 마우스 커서 위치에 프리뷰 고스트가 뜨면 더 직관적. R 버튼 홀드 중 고스트 표시, 떼는 순간 배치.

## 적 (02_Enemies)

- **배치 오브젝트를 피하는 적** — Rotwood 참고: 고급 적(방패병·분열형)이 필드에 놓인 양파를 인식하고 돌아가거나 파괴하려 하면 P2의 배치 판단이 더 중요해짐. 구현: `EnemyBehavior.Avoid`에 `LayerMask.fieldObjects` 추가, 반경 1.5칸 내 감지 시 조향 회피. 보스는 돌진으로 파괴 가능.

- **HoloCure의 소환형 Collab → 작물 소환 적 추가** — 적 중 하나가 "씨앗 소환 적"을 필드에 뿌리면 P1+P2가 함께 처리해야 하는 위협이 생김. 씨앗 소환 적의 씨앗은 일정 시간 후 작은 슬라임으로 성장. 작물 R기로 씨앗을 미리 없애면 성장 차단 보너스. 협동 역할 분담을 자연스럽게 강화하는 적 패턴.

- **무기 약점 시각화** — Rotwood처럼 적마다 약한 무기 타입이 있을 때 적 머리 위에 작은 아이콘으로 표시. OnionCat은 이미 근접/원거리 약점(×2 배율)이 있음. 적 체력바 또는 발 아래에 작은 아이콘(발톱 or 씨앗 모양)을 띄우면 플레이어가 역할 분담을 직감적으로 파악.

## 맵·런 구조 (03_Maps)

- **무기 훈련 방 → 고양이 첫 번째 장비 미리 체험** — Rotwood의 훈련 구역처럼 런 시작 시 획득한 첫 장비의 고유 콤보를 연습하는 "연습 방 한 칸"을 옵션으로. 적 없이 타겟만 있고 15초 후 자동으로 첫 전투방으로 이동. 선택지 형태로 "연습하러 가기 / 바로 시작"을 초반 갈림길 지도에 넣는 것도 가능.

- **HoloCure 허브(Holo House) → 농장 허브 2단계 발전** — 현재 농장(노트·온실·화분) 외에 2단계에서 "정원 꾸미기" 추가: 농장 소품(화분·울타리·팻말 등)을 메타 진행으로 해금해 배치. 기능 없이 순수 시각적 꾸미기지만 허브 공간에 대한 애착을 높임. 구현: `FarmDecor` ScriptableObject 목록 + `MetaProgress.decorItems` + 농장 씬에 소품 배치 UI.

- **런 중 Collab 목표 힌트 → 세트 진행 표시 개선** — HoloCure는 Collab 가능 조합을 발견하면 UI에 "조합 가능" 힌트가 뜸. OnionCat 보상 선택 화면에서 "지금 가진 장비와 세트를 이루는 장비"에 세트 아이콘 뱃지를 표시하면 세트 완성 목표 의식이 생김. 아직 없는 기능.

## 전투·협동 (04_Combat)

- **크로스 세트 본 (고양이+작물 혼합 세트)** — HoloCure의 Super Collab처럼 고양이 장비 1개 + 작물 장비 1개가 같은 세트일 때 발동하는 특수 보너스. 예: "태양 세트 2" = 고양이 화염 무기 + 작물 햇빛 기둥 → 햇빛 기둥이 적에게 화상 추가 적용. 협동의 "우리가 같이 세트를 맞췄다"는 느낌을 강화.

- **배치 오브젝트 × 협동 콤보** — 적이 양파 위에 있을 때 고양이가 타격하면 "협동 콤보" 발동 조건 추가. 현재 협동 콤보가 "번갈아 타격"인데, "배치 오브젝트 위의 적을 타격"도 콤보 카운터를 올리는 조건으로 추가하면 P2의 배치 행동이 전투 리듬에 직접 기여.

- **Rotwood 무기 연구 → 장비 중복 강화 UX** — 같은 장비를 다시 선택하면 레벨업하는 현재 시스템에서, 장비 선택지에 "이미 보유 중" 표시 + "레벨 2로 강화" 미리보기를 더 명확히 보여주면 좋음. 현재 UI가 이를 충분히 전달하는지 확인 필요.

## 아이템·세트 (05_Items)

- **세트 완성 시 시각 연출** — HoloCure Collab 완성처럼 세트 2→3 완성 시 고양이 발광 이펙트 + 사운드. 현재 세트 본이 조용히 적용되는데, 연출을 추가하면 "내가 강해졌다"는 성취감이 생김. 고양이 스프라이트에 1~2초 오라 이펙트 + 화면 가장자리 짧은 색 반짝임.

- **배치 오브젝트 강화 세트** — 작물 장비 세트 중 하나의 2세트 본을 "R 오브젝트 범위·지속시간 +50%", 3세트 본을 "R 오브젝트 위에서 적 사망 시 씨앗 한 발 추가 발사"로 설정. P2 플레이어가 배치 플레이에 집중하는 빌드 경로 형성.

- **Collab 발견 아이디어 → 가방 아이템 조합** — 소모품 2개를 조합하면 더 강한 소모품이 되는 "조합 레시피" 시스템. 예: 체력물약 + 씨앗 가방 → 치료씨앗(체력 회복하면서 주변 씨앗 발사). 가방이 복잡해지는 위험이 있으니 초반에 힌트 없이 발견하는 비밀 기능으로 먼저 테스트.

## 스토리·메타 (07_StoryMeta)

- **허브 성장 시각화** — HoloCure Holo House처럼 메타 진행(챕터 1→4)에 따라 농장 씬이 점점 꾸며짐. 챕터 2에서 온실 옆 화단에 꽃이 피고, 챕터 3에서 울타리가 생기는 등 작은 변화. 플레이어가 "농장이 자란다"는 느낌으로 메타 진행 의지 강화.

- **Rotwood 보스 보석 → 보스 처치 기념품** — 보스를 처음 처치하면 농장 허브에 작은 트로피/기념품 오브젝트가 생김. 그림자 마녀 처치 → 작은 마녀 모자 소품, 등대탑 최종 보스 처치 → 등대 모형. 기능 없는 순수 기록 아이템이지만 "내가 해냈다"는 성취 연결.

- **Rotwood 훈련 구역 → 그림자 마녀와의 사전 대화** — 그림자 마녀 보스전 직전 짧은 대화("정말로 여기까지 왔군... 준비됐나?") 후 작은 튜토리얼 힌트가 뜨면(예: "황금 발걸음 — 적의 등을 치면 2배") 보스전 긴장감과 함께 플레이 팁을 자연스럽게 전달.

## 기술 메모

- **전장 설치 오브젝트**: `PoolManager.Spawn`으로 배치 → `FieldObject_Timed / _Trigger / _Zone` 중 타입 선택 → `maxActive` 제한으로 운영 감각 추가. 먼저 R 버튼 홀드 시 고스트 프리뷰를 붙이면 P2 조작이 훨씬 직관적. 작물마다 R 고유기 프리팹을 `CropData`에 필드 추가하는 것이 가장 깔끔.

- **협동 UI 분할 소유권**: 장비 선택 화면에서 고양이/작물 각자 커서를 `SelectionCursor` 컴포넌트로 분리, 양쪽 `IsReady` 모두 `true` 시 화면 닫기. `MultiplayerEventSystem`은 기존 코드와 충돌 위험이 있으니 직접 Input 처리 방식(현재 방식)을 유지하되 Lock/Unlock 로직만 추가.
