## 캐릭터 (01_Characters)

- **흡착 대시 업그레이드** — Ruiner 와이어 참고: P1의 대시가 특정 업그레이드 후 "적을 향해 발사 시 흡착 + 순간 근접 공격"이 되는 변환. 이동 = 전투 일체화. 구현 힌트: Dash 방향 연산 중 `Physics2D.CircleCast`로 범위 내 적 감지 시 해당 적 위치로 강제 이동 후 데미지.

- **고양이 어그로 유인 스킬** — Enemy_Aggro_Threat_System 참고: 업그레이드로 P1이 "도발" 액션을 사용하면 주변 모든 적의 위협값이 P1에게 집중 (3초간). P2가 안전하게 원거리 공격 가능. 구현 힌트: `ThreatTracker.RegisterDamage(P1index, tauntValue)` 즉시 호출.

- **파의 분노 모드** — Ruiner 에너지 회복 시스템 참고: P2가 일정 시간 동안 맞지 않으면 "집중 상태" 게이지 충전, 게이지 풀 시 다음 투사체가 관통 + 2배 데미지. 구현 힌트: P2 피격 없는 시간 타이머를 `PlayerP2Controller`에서 관리, 임계값 초과 시 `isFocused = true` 플래그.

## 적 (02_Enemies)

- **어그로 전환 트릭스터 적** — Enemy_Aggro_Threat_System 참고: 기본적으로 P1을 향해 돌진하다가 P2가 조준하는 순간 P2 쪽으로 어그로 전환하는 적. 원거리 약점이지만 P2 조준을 감지해 회피하려 함. 구현 힌트: `ThreatTracker`의 타입 보너스에 "P2 조준 방향 내에 있으면 어그로 감소" 로직 추가.

- **사이버 방패 드론** — Ruiner 방패 적 참고: 전면 방패를 들고 있어 정면 원거리 공격을 모두 튕겨냄. 반드시 P1이 뒤로 우회해 근접 공격해야 처치 가능. 처치 후 방패가 맵에 잔존 → P2가 일시 사용 가능한 임시 방패. 구현 힌트: 방패 충돌 시 `Reflect()` 처리, 사망 이벤트에서 방패 오브젝트 DropShield().

- **군집 서포터** — Neon Chrome + 어그로 시스템 참고: 단독으로는 약하지만 주변 적의 위협값을 증폭시키는 "버프 지원형" 적. 처치 시 주변 적 어그로 리셋. 서포터를 먼저 잡는 우선순위 결정 협동 요소. 구현 힌트: `BuffAura` 컴포넌트, 주기적으로 주변 `ThreatTracker`들에게 `RegisterDamage(currentTarget, bonusValue)` 호출.

## 맵 (03_Maps)

- **어그로 유인 복도 방** — Neon Chrome 좁은 통로 참고: 좁은 통로 구조로 적이 P1 쪽에 자동 집중되는 방. P2는 통로 입구에서 원거리 공격 가능. "탱크 + 딜러" 협동 포지션이 자연스럽게 강제됨. 구현 힌트: 방 프리팹에 좁은 Y축 타일맵 + 측면 차단 벽 배치.

- **Enhancer 오브젝트 방** — Neon Chrome 참고: 방 내 특수 글로우 오브젝트 파괴 시 30초 한정 버프 (속도+50%, 데미지+30% 등). P1이 근접으로 파괴, P2가 원거리로 파괴 두 경우 다른 버프 발동. 구현 힌트: `RoomEnhancer.destroyedBy` 플레이어 인덱스 저장 후 분기.

- **사망 기념비 방** — Coop_Death_GameOver_Flow 참고: 이전 런에서 사망한 위치에 "비석" 오브젝트 생성. 비석 상호작용 시 그 런의 사인과 처치 수 표시. 세계관상 "고양이 용사의 무덤". 구현 힌트: `RunDataHolder.LastRunStats`에서 사망 방 ID 저장 → 다음 런 동일 방에서 GameObject 생성.

## 전투 (04_Combat)

- **타겟 마킹 어그로 공유** — Enemy_Aggro_Threat_System 참고: P2가 특정 적을 마우스 우클릭으로 "마킹"하면 P1이 해당 적에게 자동 이동 힌트(화살표 표시). 마킹된 적의 위협값을 P1에게 일시 고정. 협동 소통 최소화 메카닉. 구현 힌트: `InputSystem`의 Mouse.rightButton 감지 → 적 `ThreatTracker` 값 P1 강제 고정 2초.

- **처치 시 HP 회복** — Ruiner 에너지 회복 철학 참고: 적 처치 시 공유 HP 소량 회복 (기본 +3HP). 공격적 플레이가 수동적 플레이보다 유리한 구조 → 무한 회피만 하는 플레이 방지. 구현 힌트: EnemyDeath 이벤트에 `SharedHealth.Heal(3)` 구독.

- **사망 슬로우모션 파이널 킬** — Ruiner + Coop_Death_GameOver_Flow 참고: 방의 마지막 적 처치 시 OR 플레이어 사망 시 0.2초간 타임스케일 0.25 → 1.0 복구. 성공/실패 모두 "무게감 있는 순간" 연출. 구현 힌트: `DeathSequenceManager.RoomClearSlomo()` 코루틴 공통 사용.

## 스토리 (05_Story)

- **사이버 정원** — Ruiner 사이버펑크 + Neon Chrome 세계관 참고: OnionCat 세계관에 기술 문명의 침략 요소 추가. 적들이 "파의 생명력을 데이터화"하려는 기계 군단. 파(양파)가 유기적 생명력을 가진 마지막 종. 고양이는 그 수호자.

- **Enhancer의 기원** — Neon Chrome Enhancer 참고: 던전 곳곳에 흩어진 빛나는 오브젝트가 원래 "파의 씨앗". 적이 빼앗아 에너지로 가공 중. P1+P2가 파괴함으로써 씨앗을 "해방"하는 행위 = 버프 발동의 세계관적 이유.

- **런마다 사망 기록 나레이션** — Coop_Death_GameOver_Flow 참고: 게임오버 화면에서 고양이의 독백 텍스트 한 줄씩 표시 (랜덤). "이번엔 너무 욕심을 부렸어.", "파야, 미안해.", "다음엔 더 잘할게." 등. 구현 힌트: GameOverScreen에 `deathQuotes[]` 배열 추가, Random.Range로 선택.

## 기술 메모

- **적 어그로 & 위협 타겟 시스템**: OnionCat 핵심은 "거리 기반 어그로"만으론 P1=P2 위치가 같아 의미 없음. **최근 피해량 + 약점 타입 매칭**이 실질적 차별화. `ThreatTracker` 컴포넌트를 모든 Enemy Prefab에 부착하고 `EnemyHealth.OnTakeDamage`에서 `RegisterDamage(playerIndex, damage)` 호출하면 자동으로 동작. targetUpdateInterval을 0.5초로 설정해 매 프레임 재연산 방지.

- **협동 사망 & 게임오버 흐름**: 초보자에게 가장 중요한 것은 순서: ① `DeathSequenceManager` 씬에 배치 → ② `PlayerHealth.OnDeath` 이벤트에서 `TriggerDeathSequence(stats)` 호출 → ③ `RunDataHolder` DontDestroyOnLoad로 데이터 전달 → ④ GameOverScene에서 읽기. 사망 BGM 피치 저하(`AudioSource.pitch`)는 단 3줄 코루틴으로 극적 효과를 만드는 가성비 최고의 연출.
