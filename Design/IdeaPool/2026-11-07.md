## 캐릭터 (01_Characters)

- **빌드 방향 가중치 보상** — Path of Achra 참고: 플레이어가 햇살 세트 아이템을 2개 이상 모으면 다음 보상에서 햇살 아이템 출현 확률을 +30% 올린다 (60% 가중 + 40% 순수 무작위). 구현: `RewardTable.Pool()`에 `RunData.catGear/cropGear`의 세트 카운트 기반 가중치 로직 추가. 너무 강하게 가중하면 다양성 소멸 → 비율 조정이 중요.
- **고양이 솔로 모드 단순 조작** — 1인 플레이 시 한 명이 고양이+양파를 같이 조작할 때, 양파 Q~R 스킬은 간단한 버전으로 축소한다. 구현 힌트: `OnionInputKeys` 독립 InputAction이 이미 양파 조작을 패어링과 무관하게 분리해 두었으므로 1인도 사실상 현재 키 레이아웃으로 가능. 패드 없는 키보드 모드가 이미 "WASD(고양이) + 마우스/숫자키(양파)" 조합이다.
- **빌드 사후분석 화면** — Path of Achra 참고: 사망 시 "마지막 5개 행동 + 각각 발동된 장비 효과" 목록을 보여준다. OnionCat 런 결과 화면에 "가장 많이 발동된 세트 효과 Top 3"와 "최종 적중 소스"를 추가하면 플레이어가 다음 런에서 무엇을 고쳐야 할지 스스로 파악 가능.

## 적 (02_Enemies)

- **세트 연쇄 반응 적 패턴** — Path of Achra 참고: 플레이어 세트 보너스처럼 적에게도 "연쇄 반응" 패턴 하나. 예: "화상 적을 근접 공격하면 불꽃이 튀어 범위 피해" — 고양이 플레이어가 불꽃 적을 직접 때리는 행동을 처벌함으로써 양파의 역할을 강조. 구현: `EnemyBase.OnDamaged`에서 화상 상태 + 근접(Attacker.Cat) 조건 체크 후 `AoE` 발동.
- **1인 모드 적 조정** — 솔로 플레이 시 적 HP 70% / 피해 80% 적용. 단 협동 콤보 보너스(×1.5)가 없어서 실질 DPS는 오히려 낮으므로 HP만 줄이는 방향이 더 적절. 구현: `DifficultyScaler.EnemyHpMultiplier`를 `CoopSessionManager.CurrentMode`에 연동.
- **빌드 카운터 적 출현** — 플레이어 세트가 "쭉 쌓여있으면" 그 세트에 취약한 패턴을 가진 엘리트가 나오는 것. 예: 햇살(불꽃) 중심 빌드 → 화상 무효 갑옷 적이 등장 확률 상승. Path of Achra의 "빌드가 강해질수록 카운터가 등장" 디자인 차용. 구현: `EnemyRoster.ResolveRoom`에서 현재 RunData 세트 카운트 기반 엘리트 선택 가중치.

## 맵·런 구조 (03_Maps)

- **솔로 모드 단독 런 플래그** — 솔로 런과 코업 런의 `MetaProgress` 공유 여부 결정 필요. 추천: 세이브 파일 하나이지만 런 결과 화면에 "(솔로)" 태그 표시. 솔로 클리어를 코업 클리어와 별도로 집계 (통계 화면: 솔로 클리어 N회 / 코업 클리어 N회). 온실 해금은 공유.
- **보상 편향 감지 UI** — Path of Achra 참고: 현재 어떤 방향으로 아이템이 쏠리고 있는지를 작은 아이콘으로 보여주는 HUD. OnionCat에 적용하면: HUD 오른쪽 아래 세트 목록(현재 가장 많은 세트 2개 표시) 옆에 "다음 선택지 가중 세트" 작은 화살표 표시. 미리 보여줌으로써 플레이어가 의도적 빌드를 더 쉽게 계획 가능.
- **런 시작 화면 솔로/코업 선택** — `RunStartScreen`에 솔로/코업 선택 버튼 추가. 패드가 감지되면 "코업 모드" 기본, 없으면 "솔로(Auto-Onion)" 기본. 한 번 선택한 모드는 런 중간에 변경 불가.

## 전투·협동 (04_Combat)

- **세트 간 연쇄 보너스** — Path of Achra의 트레이트 연쇄를 세트 보너스에 적용: 햇살 2단계 보너스가 "불꽃" 적용 → 바람 세트 "불꽃인 적 공격 시 쿨다운 감소" → 햇살 더 빠른 발동의 사이클 형성. 현재 세트들이 독립적으로 동작하는 것보다 "세트가 서로를 강화하는 조합"이 발견의 재미를 준다. `CombatModifiers.Has(Set, Stage)` 체크 조건에 타 세트 체크를 추가하는 방식으로 구현 가능.
- **Auto-Onion 협동 콤보 비활성화** — 솔로 모드의 Auto-Onion은 고의적으로 협동 콤보(×1.5)를 채우지 않도록 한다. 이유: 솔로 모드가 코업보다 너무 쉬워지는 것을 방지 + "진짜 2인 플레이"에 대한 동기 유지. 구현: Auto-Onion의 공격에 `Attacker.OnionAuto` 별도 enum을 주고 `ComboChecker`에서 Auto 출처는 콤보 카운트에서 제외.
- **패링 AI 없음** — Auto-Onion은 절대 패링을 쓰지 않는다 (솔로 모드가 코업보다 명확히 어려운 지점으로 남겨둠). 패링은 "2인이 함께 하는 플레이"의 기술적 성취로 보존.

## 아이템·세트 (05_Items)

- **트레이트 태그 표시** — Path of Achra 참고: 아이템 카드에 `[햇살][공격마다][불꽃]` 같은 태그를 작은 글씨로 표시. 현재 `ItemTooltip`의 효과 텍스트 아래에 태그 한 줄 추가. `GearEffect`의 `EffectTrigger/EffectAction/EffectTarget`을 태그 형태로 노출. 직관성 대폭 향상.
- **중복 아이템 레벨업 시 세트 카운트 유지** — 현재 같은 아이템 중복 = 레벨업. Path of Achra처럼 레벨업 시 "추가 트레이트 선택지"를 주는 아이디어: 아이템 레벨업 2회 달성 시 같은 세트 아이템을 1장 추가로 보상 선택지에 포함 → 세트 세우기가 더 쉬워짐 (밸런스 체크 필요).
- **솔로 모드 전용 아이템 태그** — `[단독]` 태그가 붙은 아이템은 Auto-Onion을 강화하는 효과 (예: "자동 발사 간격 -30%", "자동 조준 범위 +3"). 솔로 모드에서만 보상 풀에 등장. 2인 플레이 시에는 아예 등장하지 않음. 구현: `GearItem.soloOnly` 플래그 + `RewardTable.Pool()`에서 필터.

## 스토리·메타 (07_StoryMeta)

- **Path of Achra 스타일 "런 사후분석 북"** — 런 결과 화면에 플레이가 끝난 뒤 낡은 책이 한마디 한다. 클리어면 칭찬 + 발견한 "황금 조합" 언급 / 사망이면 위로 + "다음번엔 이걸 보완해봐" 힌트. `StoryLines.cs`에 런 결과 대사 추가 (`RunData.winCondition`, `bestGearCombo` 기반 분기).
- **솔로 모드 스토리 텍스트 조정** — 솔로 모드 시 낡은 책의 대사 중 "너희 둘이" → "너 혼자" 등 맥락에 맞게 변경. 구현 범위: 고양이 이름("새벽")과 책 대사에서 2인 가정 대사만 조건부 변경. `StoryLines.cs`에 `PlayMode` 체크 분기.
- **세트 빌드 발견 시 별명 부여** — Path of Achra처럼 특정 세트 조합 완성 시 빌드 별명 표시. 예: 햇살 6단계 + 바람 4단계 = "불꽃 폭풍 빌드 달성". 런 결과 화면과 통계 화면에 최근 달성 빌드 목록. 구현: `CombatModifiers`의 활성 세트 목록을 순회해서 미리 정의한 조합 테이블과 대조.

## 기술 메모

- **ScriptableObject Event Channel**: 가장 먼저 `GameState_Changed.asset`과 `Room_Cleared.asset` 두 채널만 만들어 GameManager와 HUD에 적용해 보는 것으로 시작. 기존 C# event를 한 번에 모두 교체하지 않고 새로 만드는 UI 컴포넌트부터 SO 채널로 연결. 가장 큰 이점은 에디터에서 "어떤 오브젝트가 이 이벤트를 듣는지" 즉시 볼 수 있다는 것.
- **Solo Co-op Fallback**: 최소 구현은 `CoopSessionManager` 플래그 + `AutoOnionController` (가장 가까운 적 자동 발사) + 적 HP 70% 보정 세 가지뿐. 개발 초기에 넣어두면 1인 테스트가 훨씬 편해진다. 중요: Auto-Onion의 협동 콤보·패링은 의도적으로 비활성화해 2인 플레이 가치 보존.
