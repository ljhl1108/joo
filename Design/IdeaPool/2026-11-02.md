## 캐릭터 (01_Characters)

- **이중 리소스 동기화 장비** — Griftlands의 두 덱이 '같은 런의 다른 언어'이듯, 고양이 야성 게이지와 합동 게이지가 **같이 올라가는** 장비 효과 추가. 예: "특수 공격 발동 시 합동 게이지 +20". `CatSpecial` 발동 → `GameManager.AddJointGauge(20)`. 2인이 함께 클라이맥스를 만드는 리듬이 강화됨

- **장비 효과 발동 HUD 피드백** — Griftlands의 그래프트가 카드에 즉시 반응하듯, OnionCat 장비 효과 발동 시 해당 장비 아이콘이 0.3초간 밝아지는 피드백 추가. 현재는 효과 발동 시 플레이어가 인지하기 어려움. 구현: `GearEffect.Trigger()` 시 `CoreHUD.FlashGearIcon(gearId)`

- **소환 예고 → 2인 역할 분담 강화** — 소환 마커 위치에 양파가 식물을 미리 심고, 고양이는 현재 적을 처리하는 자연스러운 역할 분담. 소환 예고 1.2초와 식물 유지 12초가 잘 맞음 — 별도 코드 없이 두 시스템이 시너지

## 적 (02_Enemies)

- **동료 소환 예고 패턴** — 보스가 하수를 부를 때 보스 주변에 최대 3개 노란 마커 표시 → 1.2초 후 소환. "어디서 나올지는 알지만 보스는 계속 공격 중"이라는 긴장감. `ShadowWitch` 페이즈 2에 적용하면 전투 복잡도 자연 상승

- **근접 면역 원거리 필수 적** — Griftlands에서 협상 덱이 전투에 안 통하듯, 특정 적이 "근접에 완전 면역, 원거리에 약함". 가시 갑옷 적: `InterceptDamage`에서 `Attacker.Cat` 피해를 반사, `Attacker.Onion`은 정상. 고양이와 양파의 역할 분담 필수인 적 설계

- **소환 직후 짧은 무적** — 소환 즉시 0.25초간 반투명+무적 처리. 마커 위에 미리 심은 식물에 즉사 방지 + "이제 싸울 준비가 됐다"는 시각 신호. `OnEnable()`에서 `StartCoroutine(SpawnIframe(0.25f))` 패턴

## 맵·런 구조 (03_Maps)

- **기록 기반 런 화면 힌트** — 갈림길 지도 하단에 "이 작물로 이 경로 최고 기록: 방 14"처럼 작은 텍스트 표시. `RunArchiveManager.GetPersonalBest`로 현재 작물 + 경로 조합 최고 방 수 조회. 전략적 경로 선택에 정보 제공

- **소환 예고로 전투 방 적 수 +1 허용** — 예고 시스템이 있으면 플레이어 준비 시간이 생겨 같은 난이도에서 적 +1이 가능. `EnemyBuilder.BuildSquads`에서 "소환 예고 있음" 플래그 방은 적 수 1 추가. 밸런스 재테스트 권장

- **Ambush 개선** — `DungeonManager.StartAmbush` 호출 시 즉시 소환 대신 0.5초 예고 마커 선행. "기습이지만 완전히 기습은 아닌" 반응 가능한 서프라이즈 연출. `StartAmbush(count, callback)` 내부에서 `AnnounceAndSpawn(prefab, pos, 0.5f)` 호출로 변경

## 전투·협동 (04_Combat)

- **위기 역전 가방 아이템** — Griftlands 협상에서 불리할 때 꺼내는 예외 카드처럼, 공유 가방에 "위기 역전형" 아이템 추가. 예: "HP 30% 이하 상태에서 사용 시 피해 면역 2초 + 합동 게이지 50%". 현재 가방 3종 외에 4번째 아이템 타입으로 설계

- **패링 → 소환 예고 합동** — 패링 성공 시 주변 적 소환 마커가 있으면 해당 마커의 타이머를 +0.5초 연장 (패링이 소환을 잠깐 지연). 패링 강화 + 협동 플레이 의미 확장. `ParrySuccess` 이벤트 → `SpawnAnnouncement.AddDelay(0.5f)`

- **합동기 사용 시 기록 저장** — 합동기 발동 순간의 상황(남은 HP, 방 번호, 합동 횟수)을 `RunRecord`에 이벤트로 기록. "이번 런 최고 합동기 타이밍" 같은 하이라이트 표시 가능

## 아이템·세트 (05_Items)

- **동료 마법서 아이디어** — Griftlands의 동료 NPC 전용 카드처럼, 특정 마을 NPC 방문 시 그 NPC 전용 마법서가 보상 풀에 추가. `RewardTable.pool`에 `unlockCondition = RunData.VisitedNPC(npcId)` 필터 추가. 현재 마을 방(StepKind.Village)과 자연스럽게 연결

- **기록 기반 장비 해금** — `RunArchiveManager` 기록을 `Greenhouse` 해금 조건으로 연결. "협동 콤보 50번 달성 런이 있으면" 특정 장비 해금. `GearItem.UnlockCost`를 씨앗이 아닌 RunStat 조건으로 설정하는 방식. 플레이 방식 자체가 해금 키가 되는 구조

- **분해 장비 효과 기억** — 분해한 장비의 효과를 "효과 파편"으로 보관, 상점·휴식에서 50% 가격으로 다른 장비에 이식. Griftlands의 그래프트 카드처럼 단독으로도 강력한 효과. `RunData.SalvagedEffects` 리스트 + `ShopSystem`에서 이식 옵션 표시

## 스토리·메타 (07_StoryMeta)

- **스토리 영속성 확장** — Griftlands의 "죽인 NPC는 돌아오지 않음"처럼, 마녀 반전(`MetaProgress.WitchFreed`) 이후 마을 NPC 중 한 명의 대사가 영구히 달라지는 이정표 추가. 작은 연출이지만 "세계가 기억한다"는 감각. `StoryLines.cs`에 `WitchFreed` 조건 분기 대사 추가

- **개인 기록 → 온실 분위기 변화** — 기록이 쌓일수록 온실 배경 벽에 낙서/메모지가 하나씩 붙는 연출. "고양이와 양파의 여행 기록"으로서의 온실. `RunArchive.records.Count` 기준 0→5→15→30개에서 배경 레이어 교체

- **런 이야기 이정표 기록** — `RunRecord`에 `storyEvents: List<string>` 추가. MetaProgress 상태 변화 시 ("처음으로 마녀와 만났다", "해바라기 첫 선택") 이벤트 기록. 나중에 "내 OnionCat 이야기 되돌아보기" 기능의 기반

## 기술 메모

- **적 소환 예고 시스템**: `PoolManager.Spawn(spawnMarkerPrefab, pos)` → 타이머 후 실제 적 소환. 색상: 노랑→빨강 = 기존 공격 예고 코드 동일. 마커는 Pool 관리로 `Room.ResetForReuse` 시 자동 정리. `StartAmbush`와 `ShadowWitch` 페이즈 2에 즉시 적용 가능. 소환 후 0.25초 무적으로 마커 위 식물 즉사 방지

- **개인 기록 아카이브**: `Application.persistentDataPath/run_archive.json` (meta.json 완전 분리). `GameManager.OnRunEnd` 즉시 저장 — 씬 전환 전에 호출해야 강제 종료에도 보존. 최대 50개 순환 저장. 신기록 갱신 시 `RunResultScreen`에서 배너 표시. 해금 조건·온실 배경 변화 등과 연결하면 런 기록이 단순 통계를 넘어 게임의 일부가 됨
