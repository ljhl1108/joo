## 캐릭터 (01_Characters)

- **장비 장착 시 사운드·시각 즉각 피드백** — Patch Quest 라이딩 교체 참고: 마법서·무기 장착 시 장비 화면에서 나가는 순간 짧은 고유 효과음 + 해당 장비 아이콘이 화면 가운데를 스쳐 지나가는 0.3초 연출. "내 빌드가 바뀌었다"는 느낌을 직관적으로 전달. `GearScreen.OnEquip()` 콜백에 `Sfx.Play(SfxId.EquipItem)` + 간단한 UI 트윈 추가.
- **고양이 할퀴기 임팩트 홀드 프레임** — 픽셀아트 타이밍 참고: 현재 공격 클립에서 부채꼴 최대 펼침 프레임을 **150~200ms 홀드**로 늘리기. 이 타이밍에 히트박스 활성화 + 히트스톱이 정확히 맞물리면 "썰리는 느낌" 대폭 향상. Aseprite에서 해당 프레임 ms 수정 → `HitFeelSettings.hitStopDurationMedium` 값과 맞추기.
- **양파 발사 예비 동작** — 픽셀아트 타이밍 참고: 씨앗 발사 클립 앞에 **20~30ms 예비 프레임** 1개(화분이 발사 방향 반대로 살짝 기우는 모션). 딜레이 체감 거의 없이 발사감 향상. Aseprite 5분 작업.

## 적 (02_Enemies)

- **슬라임 돌진 예비 동작 추가** — 픽셀아트 타이밍 참고: 돌진 예고(빨간 선) 직전 1~2프레임에서 몸을 돌진 반대 방향으로 살짝 당기는 예비 모션. 현재 색상만으로 구분되는 예고를 시각적으로도 직관적으로 만들고 회피 타이밍 힌트 역할. 기존 `EnemyBuilder` 슬라임 스프라이트 수정.
- **마운트(장비)에 따른 BGM 레이어 반응** — Patch Quest BGM 연동 참고: 엘리트 방에 입장할 때 현재 장착한 세트 중 가장 높은 단계 세트에 맞는 "긴장 BGM 레이어"를 추가. 예: Sun 세트 4단계 → 따뜻한 타악기 레이어, Wind 세트 4단계 → 바람 음향 레이어. `Music.Play(MusicId.EliteX)` 확장으로 구현 가능.
- **보스 첫 등장 스포일러 경고 (스트리머 모드 연계)** — 스트리머 모드 참고: 최종 보스 현자 마법사 방 입장 전 "스포일러 포함 장면" 경고 팝업(스트리머 모드 활성 시). `DungeonManager`의 보스방 전환 트리거에 한 줄 추가.

## 맵·런 구조 (03_Maps)

- **런 단계별 협동 기믹 해금** — BlazBlue 협동 잠금 해제 설계 참고: 첫 런에서는 쌍둥이 스위치(2인 기믹 방)가 안 나오고, 2~3번째 런부터 등장하는 로직. `MetaProgress`의 `runCount` 값으로 `DungeonManager.stagePlan`에서 기믹 방 비율 조절. 입문자가 "한꺼번에 너무 많은 것"을 배우는 부담 감소.
- **빠른 런 프리셋** — Patch Quest 짧은 런 루프 참고: `DungeonManager.stagePlan`을 짧게 설정한 "빠른 런" 옵션 (2스테이지 × 3~4방, 약 20분). 메인 메뉴 시작 화면에 "정규 런 / 빠른 런" 선택 추가. 구현 비용 낮고 플레이 세션이 짧은 상황(퇴근 후 1판 등)에 대응.

## 전투·협동 (04_Combat)

- **HP 조건부 장비 효과 추가** — BlazBlue HP·SP 분리 설계 참고: "HP 80% 이상이면 씨앗 관통", "HP 50% 이하이면 할퀴기 범위 +30%" 같이 HP 비율을 발동 조건으로 쓰는 장비 효과 추가. `GearEffect` 발동 조건에 `triggerCondition: HPAbove(0.8f)` 형태 추가. 체력 관리를 전략 변수로 만듦.
- **느린 예비 + 폭발적 타격 대비 강화** — 픽셀아트 타이밍의 "느린 것 옆의 빠른 것" 원칙 적용: 할퀴기 예비 동작(적 쪽으로 방향 보정 직전)을 현재보다 살짝 더 느리게(50→80ms) 홀드한 후, 타격 프레임은 더 빠르게(40ms). 전체 공격 시간은 비슷하지만 "빠르다"는 체감이 향상됨. `HitFeelSettings` 수치 조정 + Aseprite 타이밍 수정.
- **라소 / 털뭉치 위험 보상 강화** — Patch Quest 라소 포획 실패 리스크 참고: 털뭉치가 빗나가면 0.5초 재충전 딜레이(현재는 즉시 던진 위치로 남아 있음). 빗나가면 "맨손" 상태가 더 명확해져 "신중히 던질까, 과감히 던질까" 판단 긴장감 증가.

## 아이템·세트 (05_Items)

- **장비 장착 시 BGM 미세 변화** — Patch Quest 탑승 몬스터별 BGM 연동 참고: 전설 등급 장비를 장착할 때 현재 BGM에 한 소절 짧은 화음 스팅어(1~2초) 재생. "전설 장비를 얻었다"는 특별함을 청각으로 강화. `SfxId.LegendaryEquip` 신규 추가 + `GearLoot.OnPickup`에서 등급 판정 후 재생.
- **세트 단계 변화 시 시각 홀드 프레임** — 픽셀아트 타이밍의 홀드 프레임 적용 범위 확장: 세트가 새 단계(2→4→6→8)에 도달할 때 화면 오른쪽 아래 세트 HUD에서 해당 세트 아이콘이 0.3초 크게 펄스하는 홀드 연출. DOTween `Sequence`로 Scale 1→1.4→1, 0.3초. 달성의 "임팩트 프레임"을 시각화.

## 스토리·메타 (07_StoryMeta)

- **F12 하이라이트 마커** — 스트리머 모드 참고: 스트리머 모드 ON 시 F12로 `session_highlight_timestamps.txt`에 타임스탬프+방 이름 기록. 구현 30분. 스트리머가 "이 보스 클리어 장면" 편집할 때 편리하게 써줌. `Sfx.Play(SfxId.UI_Confirm)` + 토스트 알림 "하이라이트 저장됨".
- **스트리머 모드 토글** — 스트리머 모드 참고: 설정 메뉴 하단에 "스트리머 모드" 토글 추가. 켜면 ① F12 하이라이트 마커 활성화 ② 보스 방 스포일러 경고 ③ BGM 볼륨 독립 조절. `StreamerSettings` 구조체를 `settings.json`에 추가, 총 구현 2시간 이내. Steam 출시 전 스트리머 키 배포 때 이 기능 언급하면 방송 장벽 낮춤.

## 기술 메모

- **픽셀아트 프레임 타이밍**: Aseprite에서 임팩트 프레임 ms를 150~200ms으로 늘리고, 예비 동작 프레임은 50~80ms로 짧게 — 이 비율(예비:타격:임팩트 = 1:0.5:2)이 타격감의 핵심. Unity Animator에서도 Sample Rate 올리면 더 세밀한 조정 가능. `HitFeelSettings.hitStopDurationMedium` ≈ 임팩트 홀드 ms 로 맞추는 것이 시각·물리 피드백 동기화의 핵심.
- **스트리머 모드 구현 우선순위**: F12 하이라이트 마커(30분) → 스포일러 경고(2시간) → BGM 볼륨 독립 조절(1시간) → HUD 심플 모드(반나절). CC0 오디오 저작권 문제가 없다면 BGM 대체 트랙 구현은 불필요. 먼저 `Assets/Audio/LICENSE_AUDIO.txt` 확인 필요.
