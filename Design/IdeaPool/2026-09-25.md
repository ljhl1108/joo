## 캐릭터 (01_Characters)

- **협동 SP 게이지 필살기** — Grim Guardians 협동 콤보 참고: Cat 근접 히트 + Onion 원거리 히트를 연속으로 감지해 SP 충전, 가득 차면 `CoopFinisher` 연출 발동 → 한 몸 컨셉을 강화하는 합체기
- **Onion 노말맵 발광 쉴드** — Normal Map 참고: 쉴드 활성 시 Onion 스프라이트에 Emission 노드 + Point Light2D 활성화 → 양파 주변이 빛나며 파리 방어막 시각화, 플레이어가 쉴드 범위를 직관적으로 인식
- **캐릭터 조명 방향 동기화** — Normal Map 참고: 방 클리어 후 이동 방향으로 Light2D 방향 전환, 복도 진행 느낌 강조 → 고양이가 밝은 쪽으로 달려가는 영웅적 실루엣

## 적 (02_Enemies)

- **페이즈 약점 스왑 보스** — Grim Guardians 보스 구조 참고: 1페이즈 원거리 약점(Onion이 주), 2페이즈 근접 약점(Cat이 주) → 두 플레이어가 교대로 "주인공"이 되는 경험. `Boss.ChangePhase()`에서 `weakTo` 필드 토글
- **근접 면역 + 원거리 탐지 적** — Grim Guardians 원거리 전용 적 참고: 물리 공격 면역막(Physics Layer = ignore PlayerAttack) + 원거리에만 피해 → 의사소통 없이도 Onion이 자동으로 역할 맡게 유도
- **보스 노말맵 등장 연출** — Normal Map + Grim Guardians 보스 입장 참고: 보스 방 진입 시 GlobalLight 어둡게 → BossLight Point2D 활성 → 노말맵 보스 실루엣이 드러나는 시네마틱 → `BossLightController` 스크립트로 구현

## 맵 (03_Maps)

- **협동 동시 입력 비밀 통로** — Grim Guardians 협동 패드 참고: Cat 공격키 + Onion 발사키 동시 3초 유지 시 숨겨진 보물 방 입구 열림 → 한 몸 컨셉에서 "두 역할 동시 수행"의 보상 경험
- **조명 변화로 방 분위기 구별** — Normal Map 참고: 일반 방=중간 조명, 보스 방=드라마틱 역광, 상점 방=따뜻한 노랑 → Light2D 색상·강도 조합으로 씬 전환 없이 분위기 전환
- **런 간 최고기록 스탬프 방** — Save Migration 참고: 해당 런에서 최고 기록(최고 층, 최다 처치 등)을 달성한 방 입구에 미묘한 이펙트 표시 → 플레이어가 자신의 기록과 경쟁하는 느낌

## 전투 (04_Combat)

- **근접+원거리 동시 히트 보너스** — Grim Guardians SP 충전 참고: 같은 프레임(±3프레임)에 Cat 근접 + Onion 원거리가 동일 적에 명중 시 처치 시 추가 골드/아이템 드롭 → 협동 플레이의 즉각적 보상
- **히트 라이트 플래시** — Normal Map 구현 참고: 적 피격 시 근처 Point Light2D를 순간 밝힘(`HitLightFlash` 코루틴) → 노말맵 있는 적에게 타격감이 배로 증가
- **필살기 SP 세이브 유지** — Save Migration 참고: 런 간 SP 게이지 최대 충전 횟수를 PersistentSaveData에 저장해 "평생 협동기 발동 X회" 업적 추적 → 플레이어 행동 통계화

## 스토리 (05_Story)

- **협동 엔딩 분기** — Grim Guardians 협동 필살기 참고: 최종 보스를 두 플레이어가 협동 필살기로 처치했을 때와 솔로 처치 시 엔딩 연출 차이 → "둘이 함께여야 완성되는" 클라이맥스 연출
- **최고기록 비석 NPC** — Save Data 참고: 허브 지역에 비석 오브젝트가 있어 "최고 클리어 시간", "총 처치 수" 등 기록이 새겨짐 → 성장감과 도전 의욕 부여
- **악당의 노말맵 사용 암시** — Normal Map 참고: 스토리 보스들은 전부 노말맵 적용, 잡몹은 플랫 스프라이트 → 시각적 위계로 서사 중요도를 암시

## 기술 메모

- **Sprite Normal Map**: 보스 스프라이트 우선 적용 → Sprite-Lit-Default 머티리얼, NormalMap Online(강도 낮게)으로 노말 텍스처 생성, Filter Mode = Point. 적용 전 아트 방향성 확인 필수.
- **Save Data Migration**: `PersistentSaveData.saveVersion` 필드를 지금 당장 추가해두면 나중에 필드 추가·이름 변경 시 마이그레이션 체인으로 안전하게 대응 가능. `try/catch + BackupCorruptedSave()` 패턴으로 세이브 파일 손상도 방어.
