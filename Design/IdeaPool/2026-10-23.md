## 캐릭터 (01_Characters)

- **효과 흐름 시각화 툴팁** — Magicraft 노드 그래프 참고: 장비 툴팁에 "발동 → 행동 → 대상" 흐름을 아이콘 3개로 시각화. 예: ⚡번개 할퀴기 장비 = [할퀴기 적중] → [감전 부여] → [인접 적 연쇄]. 현재 텍스트 설명만 있는 `ItemTooltip`에 GearEffect의 세 필드를 아이콘 행으로 추가. 플레이어가 "이 장비가 뭘 하는지" 보상 선택 화면에서 0.5초 안에 파악 가능
- **신규 해금 장비 마커** — Magicraft 메타 해금 경험 참고: 온실에서 처음 해금된 장비가 보상 풀에 처음 등장할 때 카드 왼쪽 위에 "NEW" 뱃지. `MetaProgress.justUnlocked` 집합에 이번 세션 해금 아이템 ID를 넣고, `UpgradeSelectUI`에서 확인 후 표시. 발견의 기쁨을 시각적으로 강화

## 적 (02_Enemies)

- **세트 감지형 Elite 패턴** — Magicraft "조합 결과가 예상을 초과"에서 착안: 특정 Elite 적이 플레이어의 우세 세트를 감지해 해당 세트의 약점 속성으로 추가 공격 패턴을 더함. 예: Sun 세트 4단계 이상 감지 → 추가 냉기 투사체 발사(화상 상태이상을 끔). `EnemyBase.OnRoomEnter()`에서 `CombatModifiers.Has(set, step)` 체크 → `attackPatterns.Add(coldShot)`. 고수 플레이어에게 메타 대응 도전
- **조합 시너지 폭발 트랩** — 방 안에 두 개의 "연결 크리스탈"(각각 불·얼음)을 배치, 고양이가 둘 중 하나에 데미지를 주면 폭발 연쇄. 양파가 한쪽 쏘고 고양이가 다른 쪽 할퀴면 COMBO 판정으로 합동 게이지 급상승. Magicraft의 "노드 조합 발견" 경험을 공간으로 구현

## 맵·런 구조 (03_Maps)

- **방마다 "보상 테마" 라벨 표시** — 런타임 필터링 참고: 지도 UI(`MapScreen`)에서 방 아이콘에 작은 아이콘 추가 — 세트 장비 위주, 고양이 전용, 양파 전용 등. `RewardAxis`(출구 표식)를 방 클리어 전에도 아이콘으로 미리 보여주는 것. 갈림길 선택에 전략성 부여
- **세트 완성 방향 유도 지도** — 런타임 보상 필터링의 "세트 상향 가중치"를 지도 UI와 연결: 현재 가장 가까운 세트 완성 단계를 지도 하단에 한 줄로 표시 ("Sun 세트: 3/4 — 다음 방향으로 가면 Sun 우선 드롭"). RunData에서 계산, MapScreen 하단 HUD에 작은 텍스트로

## 전투·협동 (04_Combat)

- **협동 콤보 × 보상 필터 연동** — 콤보 플레이를 장비 시스템과 직결: "이번 런에서 협동 콤보를 X회 달성하면 다음 보상 드로우에 '콤보 특화 장비' 가중치 1.5배". `RunData.coopComboCount`를 체크해 특정 임계치마다 보상 필터에 임시 부스터 추가. 잘 협력한 플레이어가 보상에서도 보람을 느끼게
- **Magicraft 노드 연결 → 스킬 체인 연출** — 양파 스킬 Q·W·E가 순서대로 발동될 때(Q→W→E를 3초 안에) "마법 체인" 연출 + 마지막 스킬 위력 1.5배. 현재 `OnionInputKeys` 타임스탬프를 추적해 체인 여부 판단. Magicraft의 "노드를 순서대로 연결"하는 느낌을 조작으로 표현

## 아이템·세트 (05_Items)

- **보상 드래프트 히스토리 표시** — 런타임 필터링의 "최근 본 장비 제외 큐" 연장: 이번 런에서 이미 선택지로 나왔던 장비를 보상 화면 한쪽에 "이번 런에 나왔던 장비들" 목록으로 표시 (작은 아이콘들). 정보 제공 목적 — "아까 그 장비 뭐였지?" 해소. `UpgradeSelectUI`에 가로 스크롤 히스토리 패널 추가 (선택 시에는 숨김)
- **분해 장비 재등장 방지 × 세트 완성 상향** — 현재 분해한 장비가 다시 드롭될 수 있음. 분해된 장비는 `RunData.dismantledItems`에 기록 → 보상 필터에서 동일 장비 재등장 제외 + 분해로 모은 효과가 많은 세트 방향으로 드롭 가중치 상향. 분해를 "포기"가 아니라 "방향 선택"으로 느끼게

## 스토리·메타 (07_StoryMeta)

- **피드백 기반 온실 업데이트 루프** — 인게임 피드백 수집과 온실(메타 해금) 연결: 플레이테스터 피드백에서 "이 장비가 너무 약함"이 반복되면 다음 빌드에서 해당 장비의 온실 해금 비용을 낮추거나 기본 능력치 상향. 피드백 JSON의 `freeText`를 장비 이름 키워드로 분류 → `items.csv` 수정 플로우. 작은 인디 팀의 빠른 이터레이션 루프
- **버전 기록 화면 (ChangePoster)** — 인게임 피드백 참고: 업데이트 시 메인 메뉴에 "이번 버전에서 바뀐 것" 팝업(세로 스크롤). Patch_Notes_Screen 기능과 같지만 플레이어 의견이 반영된 내용은 💬 아이콘으로 표시 ("여러분 의견으로 바꿨어요"). 플레이어가 "내 피드백이 반영됐다"는 소속감 형성

## 기술 메모

- **런타임 보상 필터링 즉시 적용 경로**: `RewardTable.DrawFor()` 내부에 필터 체인 3개만 추가 (세트 상향 × 1.5 / 분해 장비 제외 / 최근 3회 등장 장비 제외). 각각 30분 이내 구현 가능. 테스트: 같은 런에서 보상 화면을 연속으로 넘기며 다양성 확인
- **피드백 수집 최소 구현 순서**: ① `PlaytestFeedback` 클래스 + JSON 저장 (30분) → ② `FeedbackUI` Canvas + Slider 2개 + TMP_InputField (1시간) → ③ GameState.GameOver·Victory에 트리거 연결 (15분) → ④ `[MenuItem("OnionCat/Open Feedback Folder")]` 단축 메뉴 (5분). 총 2시간 안에 완성 가능
