## 캐릭터 (01_Characters)

- **P2 전용 시너지 팔찌** — Magic Survival의 "마법 스택" 참고: Crop(P2)이 같은 종류의 투사체 업그레이드를 3개 보유하면 "풍작의 기운" 상태 발동 — 연사 속도 +50%, 투사체에 식물 덩굴 이펙트 추가. 구현 힌트: SynergyManager에서 특정 아이템 3스택 감지 조건 추가.
- **고양이-새싹 공명 게이지** — P1과 P2가 각각 공격에 성공할 때마다 "공명 게이지"가 누적. 동시에 攻擊하면 게이지 2배 충전. 가득 차면 2인 합체기(전신 에너지 폭발, 화면 전체 범위) 발동. 구현 힌트: 공명 게이지는 InGame HUD에 고양이-새싹 아이콘 사이 공유 게이지 UI로 표시, 캔버스 하단 중앙 앵커.
- **새싹의 성장 단계** — 런이 진행될수록 P2 Crop의 외형 변화: 씨앗 → 새싹 → 꽃봉오리 → 완전 개화. 각 단계에 자동으로 패시브 버프(투사체 +1, 방패 회복속도 +10%). Magic Survival의 능력 스택 개념을 시각적으로 반영. 구현 힌트: SpriteRenderer 스왑 + 성장 단계 ScriptableObject.

## 적 (02_Enemies)

- **시너지 약점 적** — 특정 아이템 시너지를 활성화해야만 쉽게 처치 가능한 적. 예: "불꽃+범위" 시너지 없으면 재생성으로 쓰러뜨릴 수 없는 "가시덤불 골렘". 시너지 시스템과 적 설계를 연결하는 방식. 구현 힌트: Enemy에 requiredSynergyTag 필드 추가, SynergyManager로 현재 보유 시너지 확인 후 약점 판정.
- **해상도 감지 적** — 농담형 컨셉: 화면 가장자리에 숨어있다가 플레이어가 못 보는 위치에서 공격하는 적. 기술적으로 카메라 뷰포트 범위를 확인하고 Viewport 경계 바깥에서만 움직이는 AI. 구현 힌트: Camera.WorldToViewportPoint로 적 위치 판단, x<0 or x>1 or y<0 or y>1 일 때만 이동.
- **공생 쌍 적** — 항상 2마리 세트로 등장하는 적. 한 마리는 근접만 유효, 다른 마리는 원거리만 유효. 두 마리 모두 처치해야 방 클리어. OnionCat의 "역할 분담 강제" 핵심 메카닉을 적 단위에서도 구현. 구현 힌트: EnemyPair ScriptableObject로 두 적을 묶어서 생성.

## 맵 (03_Maps)

- **시너지 상점 방** — 일반 상점 대신 "시너지 잠금 해제 방" 등장. 현재 보유 업그레이드와 조합 가능한 시너지 업그레이드를 우선 제안. Magic Survival의 능력 선택 화면에서 가져온 개념. 구현 힌트: ShopSystem에서 SynergyManager.GetPotentialSynergies() 호출 후 결과 우선 표시.
- **해상도 기반 시야 방** — 어두운 방에서 화면 중앙만 밝고 주변이 어두운 조명 연출. 울트라와이드 모니터 플레이어는 시야가 더 넓어 유리 → 밸런스 고려 필요. URP 2D 포인트 라이트로 구현, 카메라 뷰포트에 따라 어둠 영역 조정.
- **시간 압박 방 (Magic Survival 오마주)** — 방 입장 후 30초 카운트다운 시작, 시간 내 클리어 못 하면 적 밀도가 급증. Magic Survival의 시간 기반 긴장감 차용. 구현 힌트: RoomManager에 TimeLimitMode bool 추가, Coroutine으로 카운트다운 후 EnemySpawner.IncreaseWave() 호출.

## 전투 (04_Combat)

- **P1+P2 크로스 시너지 "공동 수확"** — P1 참격으로 적을 넘어뜨리는 순간 P2의 투사체가 해당 적에게 명중하면 3배 데미지. 협력 플레이의 절정 순간을 만드는 시너지. 구현 힌트: Enemy에 knockdownState bool 추가, P2 투사체 OnTriggerEnter에서 knockdown 상태 확인 후 배율 적용.
- **시너지 콤보 카운터** — 시너지 효과로 처치한 연속 킬 수를 카운트. 3킬, 7킬, 15킬 달성 시 보너스 아이템/EXP 드롭. 화면 우상단 앵커 UI로 표시. 구현 힌트: SynergyManager에 lastSynergyKillTime 저장, 일정 시간 이내 연속 킬 판정.
- **방패 + 시너지 반사** — P2가 방패로 막은 투사체를 P1의 참격 범위 내에서 반사하면 시너지 효과(폭발 반사). 두 플레이어가 동시에 정확한 타이밍에 행동해야 함. 구현 힌트: P2의 ShieldParry 이벤트 + P1의 SlashRange 내 ProjectileDetect 조합.

## 스토리 (05_Story)

- **마법생존 오마주 서브플롯** — 고양이가 화분을 지고 달리는 이유: 마법의 힘이 깃든 씨앗을 심기 위해 던전 깊이 들어가는 여정. Magic Survival처럼 "살아남으면서 목표를 향해 나아간다"는 구조. 런 클리어 = 씨앗에 마법 에너지 축적.
- **시너지 각성 연출** — 처음으로 크로스플레이어 시너지가 발동되는 순간, 짧은 컷씬 재생: 고양이와 작물이 눈을 마주치며 빛나는 에너지가 연결되는 장면. 이후 시너지 시스템 언락 알림. 구현 힌트: SynergyManager의 첫 시너지 발동 시 PlayerPrefs로 "firstSynergy" 플래그 확인 후 컷씬 트리거.
- **성장 일기 UI** — 런 결과 화면에 "오늘의 새싹 성장" 섹션 추가. 사용한 시너지, 총 데미지, 처치 수를 새싹의 성장 일기 형식으로 표현. "오늘 당근 불꽃 시너지를 처음 발견했어요" 같은 캐주얼한 텍스트. 1920×1080 기준 하단 중앙 패널, TextMeshPro로 구현.

## 기술 메모

- **아이템 시너지 시스템**: OnionCat 초기 구현에서 가장 빠른 접근은 **명시적 페어 시너지 5개**부터 시작. SynergyData ScriptableObject를 만들고 requiredItemIds 배열에 2개 아이템 ID 지정 → SynergyManager에서 픽업 시 확인. 크로스플레이어 시너지(`isCrossPlayerSynergy = true`)는 P1 보유 아이템과 P2 보유 아이템 교차 검사 필요. 발동 연출은 EventBus로 분리해야 SynergyManager가 UI를 직접 참조하지 않아도 됨.

- **해상도 대응 UI**: **지금 당장 해야 할 가장 중요한 설정** — Canvas Scaler를 Scale with Screen Size / 1920×1080 / Match 0.5로 설정. 이것만 해도 대부분 해상도에서 UI가 올바르게 동작. 주의사항: HUD의 체력바는 반드시 좌상단 Anchor(0,1)로 고정, 스킬 쿨다운은 우상단(1,1) Anchor. 전체화면 전환은 `FullScreenWindow`(보더리스) 모드 권장. 게임 뷰에서 해상도 드롭다운을 1280×720, 2560×1440, 2560×1080(울트라와이드)로 각각 확인 필수.
