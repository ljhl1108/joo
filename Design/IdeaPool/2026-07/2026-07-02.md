## 캐릭터 (01_Characters)

- **대시 콤보 돌진베기** — Hyper Light Drifter 참고: Cat 대시 중 슬래시 입력 시 전방으로 돌진하며 넓은 부채꼴 범위 공격 발동. 일반 슬래시(180°)보다 범위 좁지만 돌진 거리로 포지셔닝 보완 (`CatController.OnDash + OnSlash` 콤보 타이밍 Coroutine으로 판정)
- **작물 에너지 게이지** — Lost Castle 참고: Onion 투사체에 에너지 게이지 도입. Cat이 근접 처치할 때마다 에너지 1 충전 → 가득 차면 다음 발사체 자동으로 관통·강화탄 전환 (`PlayerEventBus.OnEnemyKilled`로 Cat→Onion 에너지 충전 신호)
- **이벤트 기반 협동 자동 반응** — Event Bus 참고: Cat이 대시할 때 `PlayerEventBus.OnCatDash` 발행 → Onion이 0.15초 무적 자동 전개. 두 캐릭터 직접 참조 없이 협동 시너지 연출 가능 (OnionController의 `OnEnable/OnDisable`에서 구독 관리)

## 적 (02_Enemies)

- **방패 수비병** — Lost Castle 참고: 정면에 방패를 들고 있어 Cat 슬래시 무효, 원거리 탄환도 튕김. Cat이 대시로 후방 진입하거나 Onion이 패리로 방패 파괴 후 Cat 공격 → "둘 중 하나가 답" 협력 설계
- **분열 슬라임** — Hyper Light Drifter 참고: Cat 슬래시에 맞으면 2개로 분열, Onion 투사체에만 소멸. Cat이 막 치면 숫자 불어나는 패닉 상황 → Onion 원거리 제거 협력 필수 (단독 플레이 불가 디자인)
- **이벤트 반응 광전사** — Event Bus 참고: `PlayerEventBus.OnCatHit` 구독해 플레이어가 피격될 때마다 공격 속도 5% 증가하는 적. 피격을 줄여야 하는 추가 동기 부여 + 점점 빨라지는 긴장감 표현

## 맵 (03_Maps)

- **4테마 구역 구조** — Hyper Light Drifter 참고: 던전을 테마별 4구역(초원 → 동굴 → 유적 → 마왕 성)으로 구성. 각 구역 진입 시 적 종류가 바뀌어 "이 구역은 원거리 적 위주" 같은 자연스러운 난이도 곡선과 협력 패턴 학습 설계 가능
- **협동 잠금 문** — Lost Castle 참고: 방 안에 Cat 전용 버튼 + Onion 전용 버튼이 동시에 눌려야 열리는 문. `PlayerEventBus`에 `OnCatButtonPress`, `OnOnionButtonPress` 이벤트 추가, 두 신호 모두 수신 시 문 오픈
- **랜덤 이벤트 방** — Random Event Popup 참고: 전투 없는 이벤트 방 추가 (방 6개 중 1개 확률). 입장 시 선택지 팝업 → "낯선 씨앗을 심는다 (다음 방 아이템 드롭) / 무시한다". ScriptableObject `EventData` 에셋 5개로 시작

## 전투 (04_Combat)

- **에너지 방전 폭발 콤보** — Hyper Light Drifter 참고: Cat 슬래시 4연타 성공 시 마지막 타격에 에너지 폭발 이펙트 + 소규모 광역 데미지 추가. 콤보 완성 보상으로 리듬감 향상 (히트 카운터 int, 4타 달성 시 이벤트 발행 후 리셋)
- **협력 부활 시스템** — Lost Castle 참고: Cat이 쓰러지면 영혼 상태(10초 타이머) → Onion이 Cat에게 씨앗 탄환 발사해 부활. 타이머 내 실패 시 런 종료. `CatController.isDowned` 상태 + Onion 전용 `ReviveProjectile` 추가
- **패리 연쇄 버프** — Event Bus 참고: Onion 패리 성공 → `PlayerEventBus.PublishParry()` 발행 → CatController 수신 → 다음 슬래시 데미지 ×1.5. 코드 직접 참조 없이 협동 시너지 체인 구현. HUD에도 동일 이벤트로 "PARRY!" 텍스트 표시

## 스토리 (05_Story)

- **침묵의 세계관** — Hyper Light Drifter 참고: 일체 대화 UI 없이 환경 오브젝트와 픽셀 컷신만으로 서사 전달. 배경에 과거 전쟁 흔적(부서진 무기, 돌에 새겨진 Cat+Onion 문양), 첫 런과 10런째 배경 디테일이 달라지는 방식으로 스토리 심화 (현지화 비용 0)
- **부활의 서사** — Lost Castle 참고: Cat이 쓰러질 때 Onion이 뿌리로 심장을 감싸 되살리는 픽셀 연출 추가. "식물이 동물을 살린다"는 공생 테마를 게임플레이 메커니즘과 직결 → 기계적 메커니즘이 곧 스토리
- **선택이 세계 변화** — Random Event Popup 참고: 이벤트 선택지에 따라 전역 세계 변수(`WorldState`) 변경 → 이후 방의 NPC가 다른 픽셀 애니메이션 재생. 예: "낯선 씨앗을 심었다" 선택 시 이후 방 배경에 꽃 오브젝트 증가. 큰 서사 없이 선택의 흔적으로 개인화된 런 경험 제공

## 기술 메모

- **Event Bus**: `PlayerEventBus` static class에 `Action`/`Action<T>` 이벤트 선언 → `OnEnable`/`OnDisable`에서 구독/해제 반드시 쌍으로. Cat↔Onion 시스템 완전 분리하면서도 `OnCatDash → Onion 반응` 같은 협동 연동 구현 핵심 패턴. OnionCat 첫 적용은 `OnCatDash`→`OnParrySuccess`→`OnCatDowned` 3개로 시작
- **Random Event Popup**: `Time.timeScale = 0f`로 일시정지 후 팝업 표시. ScriptableObject `EventData`에 선택지·효과 정의 → Inspector에서 비개발자도 이벤트 추가 가능. MVP는 단일 선택자 팝업, 이후 Cat/Onion 각자 선택 후 조합 결과 시스템으로 확장
