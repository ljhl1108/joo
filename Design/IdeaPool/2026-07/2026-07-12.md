## 캐릭터 (01_Characters)

- **이동 즉각 반응 튜닝** — Windblown 참고: 고양이 이동에 관성 0, `Linear Drag = 0` + FixedUpdate에서 `linearVelocity` 직접 설정. 대시 후 미끄러짐 없이 즉시 정지. 전투 중 정밀 회피가 가능해져 "느껴지는 조작감" 향상.

- **이중 체력 상태 시스템** — Ember Knights 참고: 고양이/양파 각자 체력 바 보유. 어느 한 쪽이 0이 되면 사망이 아닌 "약화 상태" (고양이 체력 0 → 이동 반속, 슬래시 불가 / 양파 체력 0 → 조준 불가, 방패 불가). 둘 다 0이어야 런 종료 → 긴장감과 "마지막 발악" 플레이 가능.

- **클리어 시 승리 포즈 전환** — Floor Clear Transition 참고: 플로어 클리어 시 고양이가 앉아서 꼬리 흔드는 애니메이션 + 양파 잎 흔들림. 스프라이트 1장짜리 간단한 연출이지만 성취감 부여. Animator에서 `Trigger("FloorClear")` 하나로 처리.

## 적 (02_Enemies)

- **Reaction 유도형 적 — 반격 도발자** — Windblown Reaction 메카닉 참고: 공격 직후 0.3초 동안 "반격 창(window)" 표시 (노란 테두리 깜빡임). 이 타이밍에 근접 공격 시 2배 데미지. 플레이어가 리스크-보상 교환을 의식하게 만드는 어그로형 근접 적.

- **갑옷 원거리 면역형 적** — Ember Knights 원소 약점 참고: 전면에 금속 방패가 있어 발사체가 튕겨나옴 (반사). 고양이 근접 슬래시로만 방패를 깰 수 있음. 깨지면 양파 원거리 공격에 취약 상태로 전환. 근/원거리 협력 필수.

- **스파이크 근접 반격 적** — Ember Knights 참고: 몸에 가시가 있어 근접 공격 시 반사 데미지. 양파 원거리로만 안전하게 처치 가능. 고양이는 이 적 주변에서 회피+이동만 담당 → 고양이가 "탱킹 + 유인", 양파가 "딜링"하는 상황 자연 생성.

## 맵 (03_Maps)

- **플로어 클리어 안식처 방** — Floor Clear Transition 참고: 매 플로어 마지막 방은 "평화 구역". 적 없음, 상점 + 체력 회복 + 업그레이드 선택이 한 방에. 이 방 진입 시 배경 음악 바뀌고 환경광이 따뜻하게 변함 → 긴장 이후 숨 고르기.

- **Reaction 창 표시 아레나** — Windblown 전투 디자인 참고: 일부 방은 벽 없는 원형/육각형 공간 → 사방에서 적이 와도 회피 공간이 넉넉함. 반격 플레이를 유도하는 오픈 레이아웃. 기둥이 4개 있어 시야를 가리지만 이동 방해는 최소화.

- **방향성 입구 출구 설계** — Ember Knights 참고: 방 출구 2~3개 중 1개 선택 (좌/우/직진). 선택에 따라 다음 방 타입 힌트 아이콘 표시 (상점 아이콘, 보스 아이콘, 물음표). 탐험감 + 전략적 루트 선택.

## 전투 (04_Combat)

- **Alteration 시너지 — 양파→고양이 속성 전달** — Windblown 참고: 양파가 특정 업그레이드 아이템 획득 시 발사체에 화염 속성 부여. 고양이가 화염 발사체를 슬래시로 "가르면" 화염 범위 폭발 발생. 두 캐릭터 동작이 합쳐져 시너지 연출 → 협동의 시각적 보상.

- **합의 업그레이드 선택 시스템** — Ember Knights co-op 설계 참고: 플로어 클리어 후 업그레이드 3개 등장. P1(고양이)와 P2(양파)가 각자 커서로 원하는 것에 오버레이. 3초 후 더 많은 쪽 선택 확정 (또는 동시에 같은 것 선택 시 즉시 확정). 갈등과 협의가 메카닉화.

- **이동 속도 연동 슬래시 범위** — Player Movement System 참고: 고양이의 이동 속도가 높을수록 슬래시 이동 거리(돌진 범위)가 늘어남. 속도 업그레이드가 전투에도 영향 → "이동 빠른 빌드"가 공격적 의미도 갖게 됨. `slashRange = baseSweep + moveSpeed * 0.1f`

- **이동 중 패리 창** — Player Movement System + Parry 참고: 양파의 방패는 이동 중에도 유지 가능. 단 정지 상태에서만 "완전 패리" (튕겨내기). 이동 중 방패 = "반피 차단"만. 고양이의 이동 결정이 양파 방패 효율에 영향 → 더 깊은 협동 플레이.

## 스토리 (05_Story)

- **플로어 클리어 독백 시스템** — Floor Clear Transition + Windblown 세계관 참고: 플로어 클리어 배너가 사라진 후 양파가 짧은 독백 ("이 냄새... 다음 층은 뭔가 이상해"). 런마다 랜덤하게 3~5개 중 1개 선택. 대사 파일은 ScriptableObject로 관리해 쉽게 추가 가능.

- **약화 상태 시 바터 대사** — Ember Knights 캐릭터 매력 참고: 고양이 약화 시 양파가 "야 정신 차려!" / 양파 약화 시 고양이가 "야옹... (걱정 눈빛)" 애니메이션. 위기 상황에서 캐릭터 관계가 드러나 정서적 몰입 유발. 소리(SFX)만으로도 가능.

- **던전 벽 낙서 서사** — Windblown 세계관 표현 참고: 방 벽에 픽셀아트 낙서 스프라이트. "이 층까지 왔던 모험가 기록" 또는 "적이 남긴 표식". 클릭 불가, 그냥 배경에 있음. 스토리를 설명하지 않고 암시. 제작 비용 낮음 (스프라이트 5~10장이면 충분).

## 기술 메모

- **Player Movement System**: `Rigidbody2D.linearVelocity` 직접 설정 + `_moveInput.normalized` 정규화가 탑다운 이동의 핵심. `CanMove` 플래그 하나로 히트스톱/스턴/컷신 등 모든 이동 차단 상황을 통합 처리. OnionCat은 고양이만 이동 담당이므로 컴포넌트 1개면 충분.

- **Floor Clear Transition**: `Time.unscaledDeltaTime`으로 히트스톱 중 UI 애니메이션 작동. 씬 전환 대신 `RoomManager` 방 프리팹 교체 + 카메라 슬라이드 방식이 초보자에게 덜 복잡하고 안정적. 업그레이드 선택 UI 표시 전 `Time.timeScale = 0`으로 게임 정지.
