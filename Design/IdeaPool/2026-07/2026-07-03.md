## 캐릭터 (01_Characters)
- **작물 품종 로테이션** — Broforce 참고: 런마다 Crop(작물)의 품종이 달라지고 각 품종은 고유 원거리 특성 보유. 고추 = 관통탄, 양파 = 분열탄, 마늘 = 독탄 등. Cat은 고정이고 Crop만 바뀌는 구조로 매 런 신선함 제공. 구현: `CropData` ScriptableObject 목록에서 런 시작 시 무작위 선택.
- **협동 시너지 이펙트** — Full Metal Furies 참고: Cat이 근접 스턴 → Crop이 그 직후 원거리 공격 명중 시 "협동 크리" 판정. 피해 ×1.5 + 특수 파티클. HUD에 시너지 게이지 표시 → 만땅 시 협동 필살기 사용 가능. 구현: 스턴 상태 플래그 + 원거리 히트 타이밍 체크.
- **약점 아이콘 배지** — Full Metal Furies + Broforce 참고: Cat 능력치 카드에는 칼(⚔) 배지, Crop 능력치 카드에는 씨앗(🌱) 배지를 8×8 픽셀 아이콘으로 표시. 업그레이드 선택 화면, 도감, HUD 모두에서 동일한 아이콘 재사용 → 시각 언어 일관성.

## 적 (02_Enemies)
- **이중 약점 표시 + 발견 루프** — Full Metal Furies + Bestiary 참고: 적 머리 위에 약점 아이콘 상시 표시. 첫 조우 시 "???" → 처치 1회 후 도감에서 아이콘 공개. 약점 외 공격 시 피해 숫자 회색 + 방어막 튕기는 이펙트로 "소용없음" 즉시 피드백. 플레이어가 시행착오로 약점을 발견하는 재미 설계.
- **자폭 돌진형 적 (폭탄 버섯)** — Broforce 폭발 적 참고: 플레이어를 향해 돌진 후 폭발. Cat의 근접 선제 타격으로만 안전하게 처치 가능 (Crop 원거리 탄이 맞으면 즉시 폭발 → Cat도 위험). 소통이 자연스럽게 유도되는 패턴.
- **전방 방어막 적 (꽃잎 갑주)** — Full Metal Furies Tank 참고: 정면 방어막으로 직선 원거리 및 정면 근접 차단. Cat이 측면 파고들어 스턴 → Crop이 뒤쪽에서 원거리 공격으로 마무리. 2인 협동 측면 공략 패턴을 자연 강제.

## 맵 (03_Maps)
- **테마별 Rule Tile 교체** — Tilemap Rule Tile 참고: 층(Floor) 변경 시 `floorRuleTile` / `wallRuleTile` 에셋만 교체하면 전체 방 비주얼 자동 전환. 1~2층: 지하 흙 던전, 3~4층: 석재 성 내부, 보스 방: 뿌리 덮인 특수 구역. 추가 방 프리팹 없이 타일셋 ScriptableObject만 교체.
- **Random Tile 바닥 장식** — Tilemap Extras 참고: 바닥 타일맵에 Random Tile 적용해 크랙, 이끼, 핏자국 스프라이트를 무작위 배치. 동일 층 테마라도 방마다 바닥이 조금씩 달라 반복감 감소. 코드 추가 없이 Unity Tilemap Extras 패키지로 처리 가능.
- **파괴 가능 장식 타일** — Broforce 지형 파괴 참고: 일부 타일(나무 상자, 흙 더미)은 공격 시 파괴 가능. Rule Tile 대신 일반 타일 + Destroy 스크립트로 구현. 파괴 시 아이템 드롭 or 비밀 통로 개방. 방 탐색 동기 추가.

## 전투 (04_Combat)
- **협동 필살기 (Cat+Crop 합체기)** — Broforce + Full Metal Furies 참고: 두 플레이어가 동시에 특수 입력(각자 L1+R1) → Cat이 Crop을 위로 던지고 Crop이 공중에서 전방위 씨앗 폭탄 투하. 연출: 0.5초 슬로우모션 + 카메라 줌인 + 폭발 파티클. 쿨타임 45초. 구현: 동시 입력 판정 타이밍 윈도우 0.2초.
- **약점 공격 시너지 게이지** — Full Metal Furies 약점 시스템 참고: 올바른 플레이어가 약점을 공격할 때마다 게이지 충전. 만땅 시 적이 5초간 완전 무력화(Stunned) → 자유 딜 타임. HUD에 작은 게이지 표시. 협동 보상을 게임플레이 메커니즘으로 명시.
- **방 클리어 속도 보너스** — Broforce 빠른 리듬 참고: 방 입장 시 숨겨진 90초 타이머. 클리어 후에만 결과 표시 (압박감 없는 보너스 방식). 90초 이내 → 골드 +50%, 60초 이내 → "신속 클리어" 칭호 추가. HUD에 실시간 표시 없음 → 게임 흐름 방해 없이 플레이어 스킬 성장 반영.

## 스토리 (05_Story)
- **도감 속 적 배경 이야기 (Lore)** — Bestiary 참고: 각 적 도감에 처치 10회 후 공개되는 짧은 배경 이야기 삽입. 예: "뿌리 오염으로 정신을 잃은 두더지. 예전엔 정원사의 친구였다고 한다." 세계관과 연민을 동시에 전달. 적을 단순 장애물이 아닌 캐릭터로 만드는 장치.
- **Cat의 런 일지** — Broforce 코믹 톤 참고: 각 층 클리어 후 Cat 시점의 독백 텍스트 1~2줄 표시. "오늘도 무사히... 등에 탄 애가 좀 무겁긴 한데 뭐." 가벼운 유머로 협동의 불편함을 스토리로 승화. 구현: 층별 텍스트 배열에서 무작위 선택.
- **도감 완성 히든 요소** — Full Metal Furies 파벌 + Bestiary 참고: 도감의 모든 적을 발견(discovered=true)하면 특정 방에 숨겨진 변형 적이 등장. 일반 엔딩 외 "탐험가 엔딩" 조건으로 활용. 완성을 향한 수집 동기 + 비밀 보상.

## 기술 메모
- **Tilemap & Rule Tile**: `com.unity.2d.tilemap.extras` 패키지 먼저 설치 필수. `RoomPainter.PaintRoom(BoundsInt)` 패턴으로 방 생성 자동화. `CompositeCollider2D` + `TilemapCollider2D` 조합으로 벽 충돌 최적화. 층 테마 교체는 `RuleTile` 에셋 교체만으로 처리 가능.
- **도감/갤러리 시스템**: `EnemyData(ScriptableObject)` → `BestiaryManager(싱글톤)` → `Enemy.OnDeath()` 에서 `RegisterKill()` 연결. OnionCat 약점 발견 루프의 핵심: 첫 조우 시 약점 "???" → 처치 1회 후 도감에서 아이콘 공개. 런 반복 동기를 "약점 수집"으로 자연 연결.
