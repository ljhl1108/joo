## 캐릭터 (01_Characters)

- **협력도(Synergy) 게이지** — Darkest Dungeon 스트레스 시스템 참고: 두 플레이어가 함께 콤보를 넣을수록 협력도 증가 → 100% 시 "시너지 버스트" 특수 공격 발동. 떨어져 있으면 서서히 감소 (공유 몸 컨셉 강화). UI: 플라워팟 위 게이지 바.
- **Onion 감정 반응 시스템** — Crown Trick 크라운 동반자 참고: 방 입장, 위기, 클리어 상황별 Onion의 짧은 대사 출력. 텍스트 말풍선 1~2초 표시 후 자동 소멸. Cat이 주도하고 Onion이 반응하는 형태로 캐릭터 관계 표현.
- **Cat 무적 대시 넉백 강화** — 넉백 시스템 참고: 대시 도중 적과 충돌 시 강한 넉백(force 25~30) + 0.5초 경직 발생. 대시가 단순 회피가 아닌 공격 수단으로도 활용 가능 → Cat 플레이 깊이 증가.

## 적 (02_Enemies)

- **전조 필수화 + 타일 표시** — Crown Trick 적 전조 시스템 참고: 모든 적의 공격 전 0.4초 이상 붉은 이펙트/타일 표시 의무화. "억울한 죽음" 제거 원칙. 특히 강한 공격일수록 전조 시간을 길게 (0.4→0.6→0.8초).
- **넉백 저항 등급 적용** — 넉백 시스템 참고: 잡몹(저항 0), 엘리트(저항 0.5), 보스(저항 0.8~1.0) 3단계 구분. 보스는 밀리지 않지만 경직(0.2초)은 있어 공격 창이 열림 → 협력 콤보로 짧은 틈 노리는 재미.
- **스트레스형 적 — Darkest Dungeon 참고**: 직접 HP를 깎는 게 아니라 협력도 게이지를 감소시키는 적 타입. 예: "불협화 슬라임" — 두 플레이어를 반대 방향으로 끌어당기는 자기장 효과. 처치 안 하면 협력도 고갈.

## 맵 (03_Maps)

- **힌트 화면 플로어 이동** — 로딩 화면 시스템 참고: 플로어 간 이동 시 풀 로딩 화면 표시. 배경에 다음 플로어 테마 실루엣(어두운 숲→던전→화산). 진행 바 위에 "2층으로..." 텍스트.
- **포지션 기반 방 설계** — Darkest Dungeon 파티 포지션 참고: 좁은 복도 방(Cat이 앞, Onion이 뒤 고정), 넓은 광장 방(자유 이동), 다층 방(Cat은 아래, Onion은 위 플랫폼). 방 형태가 역할 분담을 자연스럽게 유도.
- **원소 콤보 방** — Crown Trick 원소 콤보 참고: 특정 방에 원소 버프 오브가 등장 → Onion이 흡수해 투사체에 원소 추가. Cat의 슬래시로 원소 상태 적을 타격하면 콤보 폭발. 방별 테마 원소 1종 지정으로 설계 단순화.

## 전투 (04_Combat)

- **근접/원거리 넉백 방향성 활용** — 넉백 시스템 참고: Cat 슬래시로 적을 Onion 쪽으로 밀기 → Onion 차지 샷으로 처치하는 "패스 플레이" 콤보. 넉백 방향이 공격자→피격자 방향이므로 플레이어가 위치를 조절해 방향 제어 가능.
- **패리 반사 + 강넉백** — 넉백 + Crown Trick 참고: Onion의 패리 성공 시 반사 투사체에 강한 넉백(force 20) + 0.6초 경직 부여. 일반 투사체보다 훨씬 강력 → 패리 마스터리 보상. 패리 반사 투사체는 별도 색상(금색)으로 시각적 구분.
- **히트스톱 + 넉백 시퀀스** — 넉백 시스템 참고: 강한 공격 적중 시 히트스톱(0.08초 슬로우) → 넉백 발동 → 파티클 이펙트 순서로 코루틴 구성. 히트스톱 없는 넉백은 타격감이 약함.

## 스토리 (05_Story)

- **Cat & Onion의 상황별 대화** — Darkest Dungeon 나레이터 참고: 나레이터 대신 두 캐릭터가 직접 대화. 보스 등장("저게 뭐야!", "침착해..."), 아이템 획득("씨앗이다!", "빨리 먹어"), 위기("못 버틸 것 같아", "포기하지 마"). 10~20개 짧은 대사 풀로 시작.
- **씨앗의 기억 — 메타 진행 스토리** — Darkest Dungeon 저택 발전 참고: 런 실패 시 "씨앗 포인트" 획득 → 메인 메뉴에서 Cat의 저택(화분 정원) 성장. 시각적으로 정원이 풍성해질수록 해금 콘텐츠 증가. 실패가 스토리 진행으로 연결.
- **적 세계관 메모** — Crown Trick 아이템 흡수 참고: 처치한 적에게서 "기억 조각" 아이템이 가끔 드롭 → 해당 적의 짧은 배경 설명(텍스트 1~2줄) 도감에 등록. 플레이하면서 자연스럽게 세계관 발견.

## 기술 메모

- **넉백 & 스태거 시스템**: OnionCat 전투의 핵심 구현 순서 — ① `KnockbackReceiver` 컴포넌트 제작 → ② `StaggerController`로 경직 상태 관리 → ③ 공격 히트박스에 `KnockbackData` 구조체 연결. **Cat 슬래시(force 15~20)와 Onion 투사체(force 5~8)를 반드시 수치 차별화해야 역할 구분이 명확해짐.** 보스에게는 `knockbackResistance = 0.8` 이상 적용.
- **로딩 화면 & 힌트 시스템**: Unity 구현 우선순위 — ① `Scene_Transition.md`의 페이드 인/아웃 먼저 구현 → ② `LoadSceneAsync` + `allowSceneActivation = false`로 전환 타이밍 제어 → ③ `TipDatabase` ScriptableObject에 힌트 텍스트 입력. **`minimumLoadTime = 1.5f`를 꼭 설정해야 씬이 너무 빨리 전환될 때 화면 번쩍임 방지됨.**
