## 캐릭터 (01_Characters)

- **그림자 만남 (Shadow Encounter)** — Moonscars Umbra 참고: 특정 방에서 Cat과 Crop의 부패한 그림자 버전이 보스로 등장. 그림자는 이 런에서 두 플레이어가 가장 많이 쓴 스킬 비율(근접 vs 원거리)을 반영해 패턴이 달라짐. 처치 시 런 내 강력한 1회성 "금지된 힘" 업그레이드 획득. 메타 서사 장치("나를 이겨야 앞으로 나아간다")로도 활용.
- **조준선 감정 표현 (Cursor Emotion)** — 커스텀 커서 참고: Crop의 조준 커서에 미묘한 감정 표현 추가. 적이 없을 때 → 커서 중심에 작은 눈 아이콘(편안). 적 근접 시 → 눈이 날카로워짐. 체력 위험 시 → 커서가 살짝 흔들림. 게임플레이 정보를 시각적 캐릭터성으로 표현.
- **빌드 시너지 하이라이트** — 빌드 확인 UI 참고: 빌드 확인 창 열 때, Cat과 Crop의 업그레이드 중 시너지 조합이 있으면 두 슬롯에 동시에 황금 테두리 + 연결선 표시. 예: "Cat 대시 카운터"와 "Crop 패링 후 투사체" 콤보. 두 플레이어가 서로의 업그레이드에 관심을 갖게 유도.

## 적 (02_Enemies)

- **역할 모방 적 (Mimic Fighter)** — Moonscars Umbra 참고: Cat의 근접 슬래시를 쓰는 "그림자 검사" vs Crop의 원거리 투사체를 쓰는 "그림자 사수" 두 유형. 플레이어가 자신의 공격 패턴을 외부에서 마주치는 경험 → "저게 나잖아" 반응 유도. 처음 만날 때 특별 연출(영상 반전 효과).
- **조준 방해자 (Aim Jammer)** — 커스텀 커서 참고: 화면에 가짜 조준점 파티클을 여러 개 생성하는 적. Crop의 실제 조준선과 시각적 혼란을 유발. Cat이 근접으로 Jammer를 빠르게 처리하지 않으면 Crop 오조준 위험 → 역할 분담 긴박하게 강제.
- **빌드 적응 가드 (Adaptive Guard)** — 빌드 뷰어 참고: 엘리트 적으로 등장. 런 중 플레이어가 가장 많이 쌓은 업그레이드 유형에 맞춰 저항 형태를 바꿈. "근접 강화 런이면 근거리 반격막 전개, 원거리 강화 런이면 고속 돌진 패턴". 런마다 다른 전략이 필요한 적.

## 맵 (03_Maps)

- **기도 사당 방 (Shrine Room)** — Moonscars Wish 시스템 참고: 던전 내 사당 방에서 Cat이 상호작용 → 1~3개 선택지 팝업. 강한 효과는 반드시 트레이드오프 포함 ("Cat 공격력 +25%, Crop 방어막 쿨다운 +50%"). Cat이 상호작용하되 Crop의 동의 버튼도 함께 요구 → 두 플레이어 합의를 게임플레이로 표현.
- **조준 연습 구간 (Shooting Range Room)** — 커스텀 커서 참고: 이동하는 더미 타겟이 등장하는 훈련 방. Crop이 일정 수 이상 명중 시 골드/업그레이드 보상 획득. Cat은 더미가 흘리는 소형 적을 처리. 자연스러운 조준 연습 + 역할 협력 동시 달성.
- **빌드 회고 방 (Loadout Review Room)** — 빌드 확인 UI 참고: 보스 직전 쉼터 방에서 BuildViewerUI가 자동으로 열림. Cat과 Crop이 각자 업그레이드 목록을 잠깐 확인하는 호흡. "이번 보스는 원거리 약점이니 Crop 중심으로 가자" 같은 전략 대화가 자연스럽게 발생하는 공간 설계.

## 전투 (04_Combat)

- **패링 3중 피드백** — Moonscars 패링 + 피드백 시스템 참고: Crop 패링 성공 시 동시에 3중 피드백 발동. ① 흰색 링 파티클 폭발 ② 0.1초 히트스톱 ③ 협공 게이지 20% 즉시 충전. 단순 방어가 "공격 기회 창출"로 체감되게 하는 피드백 레이어 설계. Moonscars에서 배운 핵심 원칙.
- **충전 조준선 시각화** — 커스텀 커서 참고: Crop이 마우스 버튼 홀드로 강화 투사체 충전 중일 때 커서 주변에 원형 충전 바(Image Filled Radial 360)가 채워짐. 충전 완료 시 커서 진동 + 색 전환(흰→노랑). 충전 피드백을 커서 자체로 표현해 화면 집중력 분산 최소화.
- **런 시너지 배지** — 빌드 확인 UI 참고: 업그레이드 선택 화면에서 현재 보유 업그레이드와 시너지가 있는 신규 선택지에 "시너지" 배지 표시. Cat 빌드와 Crop 빌드 간 교차 시너지도 표시 → 두 플레이어가 서로의 업그레이드 선택에 영향을 미치게 만드는 UI 유도.

## 스토리 (05_Story)

- **그림자의 질문** — Moonscars Umbra 서사 참고: Shadow Encounter 직전 짧은 텍스트 연출. 그림자 Cat이 "왜 계속 싸우는 거야?" 묻고, 그림자 Crop이 "우린 이미 한 번 무너진 적 있잖아" 말함. 런 횟수마다 대사가 달라져 메타 서사 누적. "가장 강한 적은 과거의 우리 자신"이라는 주제 표현.
- **소원의 대가** — Moonscars Wish 트레이드오프 참고: 기도 사당에서 강력한 소원을 선택할 때 Crop이 "이거 괜찮아?" 하고 묻고 Cat이 끄덕임(또는 거부) 선택. 강한 기도 선택 후 Crop의 잎사귀 색이 살짝 어두워지는 비주얼 변화. 선택이 두 캐릭터 관계에 영향을 주는 것처럼 느껴지는 서사 연출.
- **런 일지 자동 기록** — 빌드 확인 UI 참고: 런 종료 결과 화면에 "이번 런 빌드 요약"을 자동으로 기록. 예: "9번째 런 — Cat: 폭풍 슬래시+대시 카운터 / Crop: 3연탄+관통탄 / 2층에서 사망". 플레이어가 자신의 성장 여정을 돌아볼 수 있는 작은 서사 기록 장치.

## 기술 메모

- **커스텀 커서 & 마우스 조준**: 첫 단계는 `Cursor.SetCursor(crosshairTexture, hotspot, CursorMode.Auto)` 한 줄로 즉시 구현 가능(5분). Crop 투사체 방향은 `Camera.main.ScreenToWorldPoint(Mouse.current.position.ReadValue())` → Crop 위치 간의 `.normalized` 벡터. 충전 바 등 애니메이션이 필요해지면 그때 소프트웨어 커서로 전환해도 늦지 않음.
- **런 중 빌드 확인 UI**: 선행 작업은 `RunInventory` 싱글톤을 먼저 만들고 업그레이드 선택 로직에 `AddUpgrade()` 연결하는 것. 빌드창 자체는 GridLayoutGroup + `Time.timeScale=0` + DOTween `.SetUpdate(true)` 조합으로 빠르게 구현 가능. Cat/Crop 탭 분리는 협력 역할 시각화에 효과적 — 처음부터 넣는 것을 추천.
