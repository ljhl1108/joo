## 캐릭터 (01_Characters)

- **기절 상태 분리** — Cuphead 유령 메카닉 참고: 일정 피격 누적 시 Cat 또는 Crop이 "기절" 상태 진입 → 상대방의 특정 행동(Cat 대시, Crop 패리 성공)으로만 회복 가능 — 단순 공유 HP보다 훨씬 강한 협동 강제 구조
- **캐릭터 전용 업그레이드 트리** — 드롭 시스템에서 Cat 업그레이드 1개 + Crop 업그레이드 1개 + 공용 1개 보장으로 매 선택이 두 플레이어 모두에게 의미 있게 됨
- **협동 발동형 슈퍼 스킬** — Cuphead의 슈퍼 아트처럼, Cat과 Crop이 모두 특정 조건(패리 성공, 연속 처치)을 채우면 단독으로는 발동 불가한 협동 공격 발동 — 둘 중 하나만으론 쓸 수 없음

## 적 (02_Enemies)

- **위협 예산 기반 방 구성** — 가중치 밸런싱 참고: 각 방에 "위협 포인트 예산" 부여 후 예산 소진까지 적 소환 → 층 깊이에 따라 예산 증가 — 1층엔 약한 적 많이, 5층엔 강한 적 적게 대신 고압적으로
- **근접/원거리 취약 적 비율 테이블** — 1층은 근접 취약 60%, 원거리 30%, 층 증가마다 혼합 요구 적 비중 늘림 → 초반엔 Cat이 주역, 후반엔 두 플레이어가 동등하게 기여해야 하는 난이도 곡선
- **페이즈 전환형 미니보스** — Cuphead의 Baroness Von Bon Bon처럼 일반 방에 등장 가능한 "2페이즈 미니보스" 타입 도입 → 페이즈 전환 시 잠깐 무적 + 새로운 취약 타입으로 변신 (근접 취약 → 원거리 취약 전환)

## 맵 (03_Maps)

- **방별 취약 타입 힌트 아이콘** — 입장 전 문 위에 작은 아이콘(검 = 근접, 구근 = 원거리)으로 이 방의 주요 적 취약 타입 힌트 → 전략적 선택(지금 Cat 능력이 약하면 다른 루트 선택)
- **씨드 기반 방 생성 + 기록** — 가중치 시스템과 시드(Seed) 연동으로 동일 씨드 = 동일 런 재현 가능 → 나중에 데일리 챌린지 모드로 확장 가능
- **상점 방 재고 가중치** — 층 깊이에 따라 상점 재고 희귀도 테이블 변화 — 초반 상점엔 Common만, 중반에 Uncommon 등장, 최종 층 직전 상점엔 Rare/Legendary 가능

## 전투 (04_Combat)

- **패리 연동 슈퍼 게이지** — Cuphead 패리 시스템 참고: Crop의 방어막 패리 성공 시 공유 슈퍼 게이지 충전 → 게이지 최대 시 Cat이 강화 대시(무적+데미지 대폭 상승) 또는 Crop이 폭발 탄막 발사 가능
- **등급 시스템 — 층별 S랭크 조건** — Cuphead의 P랭크처럼 각 층 클리어 시 등급 산출 (피격 횟수, 협동 발동 횟수, 패리 성공률) → 총 등급 합산으로 런 결과 화면에 "PERFECT RUN" 특별 달성 표시
- **드롭 선택 UI — 카테고리 시각 분리** — 3지선다 업그레이드 화면에서 Cat 전용은 주황 테두리, Crop 전용은 초록 테두리, 공용은 흰색 — 한눈에 누구 업그레이드인지 파악 가능

## 스토리 (05_Story)

- **악마와의 계약 설정** — Cuphead의 "영혼을 건 빚" 모티프 참고: Cat이 Crop(양파)을 지키기 위해 어둠의 존재와 계약 → 본체가 합쳐진 이유를 스토리로 설명 (양파가 힘을 주는 대신 Cat의 몸에 묶임)
- **보스 = 계약 채무자들** — 각 보스는 같은 악마에게 힘을 빌린 다른 생명체 → 그들을 물리쳐야 계약의 빚을 갚을 수 있음 — 보스별 짧은 대화창으로 사연 전달
- **엔딩 분기: 빚 청산 vs 반란** — 모든 보스 격파 후 선택지: 약속대로 양파를 악마에게 넘길지, 악마 자체를 최종 보스로 맞설지 → 2가지 엔딩 중 협동으로 결정

## 기술 메모

- **가중치 인카운터 시스템**: 위협 예산(Threat Budget) + WeightedRandom 유틸리티를 ScriptableObject 기반으로 구성하면 데이터 드리븐 밸런싱이 가능 — 코드 수정 없이 에디터에서 적 강도와 등장 확률 조율. OnionCat 우선 적용: 근접/원거리 취약 적 비율을 층별로 테이블화하여 협동 강제 강도를 체계적으로 설계
- **런타임 키 리바인딩 UI**: `InputAction.PerformInteractiveRebinding()` 호출 전 반드시 `action.Disable()` 선행 — 빠뜨리면 리바인딩 입력이 게임에 즉시 반영됨. 마우스 이동(position/delta) 제외 설정 필수. 바인딩 저장은 `SaveBindingOverridesAsJson()` → PlayerPrefs로 1줄 구현 가능. OnionCat은 P1(게임패드)·P2(키보드+마우스)를 별도 키로 저장해 각자 독립 리바인딩 지원
