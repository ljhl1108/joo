## 캐릭터 (01_Characters)

- **협동 아드레날린 게이지** — Returnal 참고: P1 고양이와 P2 작물이 번갈아 적을 처치하면 "협동 콤보 스택" 증가(최대 5단계), 스택에 따라 이동속도+, 쿨다운- 등 버프 적용. 한 명 피격 시 1단계 감소. 구현 힌트: `float comboTimer`로 연속 협동 기여 시간 측정.

- **죽음 기록 로그** — Returnal 내러티브 참고: 각 런에서 죽을 때 마지막 위치·적 이름·처치 수를 한 줄 로그로 저장. 다음 런 시작 화면에 "지난 런: 2층 수호자에게 패배 — 처치 17" 텍스트 표시. 짧은 텍스트로 스토리 감각 부여. 구현 힌트: `PlayerPrefs`에 JSON 직렬화.

- **기생 업그레이드 (Parasite형)** — Returnal Parasite 참고: 강력한 패시브지만 부작용 동반하는 업그레이드. 예: "P1 공격력 +40% but 대시 쿨다운 +1초", "P2 투사체 수 +2 but 방패 게이지 -25%". 플레이어가 약점을 감수하며 빌드 구성 → 전략 깊이 증가.

## 적 (02_Enemies)

- **층별 적 세트 테마** — Returnal 바이옴 참고: 1층=식물형(근접 취약), 2층=기계형(원거리 취약), 3층=혼합 보스. 층마다 픽셀아트 색상 팔레트도 통일(1층: 초록 계열, 2층: 파랑·금속). 구현 힌트: `EnemySpawnTable` ScriptableObject로 층별 적 목록 관리.

- **탄막 패턴 적** — Returnal 탄막 참고: 원거리 취약 적 중 일부는 탄막을 발사. 플레이어 P1은 근접으로 탄막 근원을 쳐야 하고, P2는 원거리로 멀리서 지원. "근접-원거리 협동 강제" 상황 설계. 구현 힌트: 탄막 중앙 적에 `OnlyMeleeVulnerable` 태그.

- **무피격 보상 트리거 적** — Returnal 퍼펙트 보상 참고: 특정 적은 두 플레이어 모두 피격 없이 처치하면 추가 아이템 드롭. 적 처치 시 `perfectKill` 플래그 확인. 협동 방어 의식 강화.

## 맵 (03_Maps)

- **층 테마 색상 팔레트** — Returnal 바이옴 참고: 각 던전 층마다 전체 타일셋, 적, 파티클 색상을 통일된 팔레트로 구성. URP 2D Global Light 색상 온도를 층별로 변경(1층: 따뜻한 초록, 2층: 차가운 파랑). 구현 힌트: `Light2D` 컴포넌트의 색상을 층 로드 시 코루틴 페이드.

- **비밀 방: 기록 보관소** — Returnal 파편 스토리 참고: 일부 런에서만 등장하는 특수 방. 진입 시 이전 런 기록("지난 런 로그") 한 줄 표시 + 소량 Ether(영구 재화) 보상. 스토리 감각 + 영구 진행 연결.

- **쇼트컷 없는 선형 층 구조** — Returnal 바이옴 구조 참고: OnionCat도 층 스킵 없이 1→2→3 순서. 대신 층 입구마다 "난이도 예고 텍스트" 표시("2층: 기계 군단. 작물의 사격이 열쇠다."). 기대감 형성.

## 전투 (04_Combat)

- **Y축 기반 레이어 정렬 + 나무/바위 교차** — 정렬 레이어 시스템 참고: 플레이어가 나무 뒤를 지나갈 때 나무 뒤로 숨는 연출. `Sorting Group` + `YSortedRenderer` 조합으로 구현. 나무 상단은 `Foreground` 레이어, 하단은 `Default` 레이어로 분리. 탑다운 게임 완성도 크게 향상.

- **히트스톱 중 BGM 피치 유지** — BGM 매니저 참고: 히트스톱(Time.timeScale=0)을 사용할 때 BGM이 멈추지 않도록 `Time.unscaledDeltaTime` 기반 페이드 코루틴 사용. 타격감과 청각 경험이 동시에 살아 있어야 임팩트 극대화.

- **보스 체력 50% 음악 변화** — BGM 매니저 참고: 보스 2페이즈 진입 시 BGM 피치 1.15배로 자연스럽게 올라가는 연출. 단순하지만 긴장감 증폭 효과 강함. 구현 힌트: `BGMManager.SetPitch(float)` 메서드 추가.

## 스토리 (05_Story)

- **반복 추락 내러티브** — Returnal 참고: OnionCat 세계관에서 고양이가 죽을 때마다 양파밭으로 다시 소환되는 저주. 게임 오버 화면에 "고양이가 또 돌아왔다… (런 횟수)번째" 텍스트. 런 횟수가 쌓일수록 미묘하게 텍스트가 변화.

- **기억 파편 수집** — Returnal 파편 스토리 참고: 던전 곳곳에 "기억 파편" 아이템 배치. 수집하면 고양이와 작물의 관계, 저주의 기원이 한 줄씩 밝혀짐. 클리어 후 수집한 파편으로 스토리 퍼즐 완성. 저장: `PlayerPrefs` 비트마스크.

- **퍼펙트 런 엔딩 분기** — Returnal 클리어 달성 감각 참고: 첫 클리어 시 일반 엔딩, 퍼펙트(모든 기억 파편 수집 + 무피격 보스 처치) 클리어 시 히든 엔딩 이미지 해금. 단순하지만 재플레이 동기 강화.

## 기술 메모

- **스프라이트 정렬 레이어 시스템**: `Transparency Sort Mode`를 Custom Axis Y=1로 설정하는 것만으로 고정 오브젝트 Y 정렬 자동 해결. 플레이어·적 등 움직이는 오브젝트는 `LateUpdate()`에서 `sortingOrder = -(y * 100)` 패턴으로 동적 갱신. `Sorting Group` 컴포넌트로 복합 스프라이트(고양이+화분+작물)를 하나의 정렬 단위로 묶는 것이 OnionCat에서 가장 중요.

- **BGM 씬 전환 매니저**: 두 AudioSource 크로스페이드 패턴이 핵심 — 기존 소스 페이드 아웃 동시에 새 소스 페이드 인. `DontDestroyOnLoad` 싱글톤으로 씬 전환에도 음악 유지. 구현 순서: ① 싱글톤 BGMManager 오브젝트 생성 → ② AudioSource 두 개 부착 → ③ BGMDatabase ScriptableObject 제작 → ④ 각 씬 초기화 오브젝트에서 `BGMManager.Instance.Play(clip)` 호출. 일시정지·히트스톱과의 충돌 주의 (`Time.unscaledDeltaTime` 필수).
