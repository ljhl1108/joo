## 캐릭터 (01_Characters)

- **팔레트 언락 진행 구조** — Cosmetic Skin System 참고: 기본 스킨 외 "흑묘+자색양파" 세트처럼 고양이·양파를 쌍으로 묶은 세트 스킨을 제공, 특정 런 달성 시 해금. 시각적 일관성과 수집 욕구를 동시에 자극함. `SkinData.SO`에 `pairedSkinId` 필드 추가로 구현 가능.

- **사망 누적 스킨** — Monolith "유령 고양이" 아이디어: 사망 누적 횟수(50회 등)를 달성하면 흑백 반투명 유령 스킨 해금. 신규 플레이어도 "죽으면 뭔가 생긴다"는 위안과 진행감을 느낌. `PlayerPrefs`의 총사망 횟수 키와 SkinManager.UnlockSkin 연동.

- **조명 반응 스킨** — URP 2D Lighting 참고: 특정 스킨에 발광(Emission) 효과를 줘서 어두운 던전에서 빛나게 구현. "용암 양파" 스킨은 `Point Light 2D`를 자식 오브젝트로 갖고 은은한 주황빛을 방사. Sprite-Lit-Default 셰이더 + 런타임 Light2D 컴포넌트 토글.

## 적 (02_Enemies)

- **색상 경고 적** — Monolith 탄막 가독성 철학 + URP Lighting 참고: 적이 공격 직전 자체 `Point Light 2D`가 빨갛게 펄스치는 방식으로 예고. 별도 UI 없이 조명만으로 공격 타이밍 전달. 원거리 약점 적은 파란빛, 근접 약점 적은 빨간빛으로 취약점 색상 코딩 가능.

- **탄막 밀도 조절 적** — Monolith 히트박스 관대함 철학 참고: 탄막 밀도가 높은 적(스크린을 가득 채우는 패턴)은 플레이어 히트박스를 일시적으로 더 작게 조정하는 "탄막 과부하 모드" 도입. 탄막 수가 임계값 초과 시 `CapsuleCollider2D.size *= 0.7f` 일시 적용, 일정 시간 후 복구.

- **자폭 발광 적** — URP Lighting 참고: 자폭형 적이 카운트다운 중 `Point Light 2D.intensity`가 0에서 최대치로 빠르게 상승. 빛이 밝아질수록 폭발 임박을 플레이어가 직관적으로 인식. 코루틴으로 Mathf.Lerp 처리.

## 맵 (03_Maps)

- **어두운 방 챌린지** — URP 2D Lighting 참고: 특정 특수 방은 `Global Light 2D.intensity = 0`으로 완전 암흑. 고양이 주변 작은 `Point Light 2D`만 유지 → 근접전 강요. 이 방 클리어 시 추가 보상 제공. 난이도 분기 요소이자 시각적 이벤트.

- **발광 통로** — URP Lighting 참고: 방과 방을 잇는 복도에 `Freeform Light 2D`로 좁은 빛 줄기 설치. 어두운 배경에서 복도가 빛으로 표시되어 이동 방향 직관적 안내. 별도 화살표 UI 없이 조명만으로 내비게이션 해결.

- **런 종료 시 맵 팔레트 변경** — Cosmetic Skin System 응용: 스킨과 별도로 선택한 "테마 팔레트"에 따라 타일맵 색조(`Tilemap Renderer`의 material color)도 변경. 기본 회색 던전 외 "용암 던전(빨강)", "얼음 던전(파랑)" 테마 선택 가능. 시즌 이벤트 활용 여지.

## 전투 (04_Combat)

- **패리 시 발광 연출** — URP Lighting + Monolith 피드백 철학 참고: 양파(Player 2)가 패리 성공 시 화면 전체에 짧은 흰색 `Global Light 2D` 플래시(0.05초). 히트스톱과 동시에 발동하면 성공감 극대화. `StartCoroutine`으로 Intensity 0→2→0 처리, 1프레임 이상 지속하지 않음.

- **취약점 시각화 통일** — Monolith 색상 코딩 참고: 근접 약점 적은 신체의 특정 파츠가 **주황색 펄스 발광**, 원거리 약점 적은 **파란색 펄스 발광**. 플레이어가 어느 공격을 써야 할지 색상만으로 0.5초 내 파악. `Coroutine PingPong`으로 `Point Light 2D.intensity` 반복 진동.

- **빌드 다양성 강제 메카닉** — Monolith 빌드 다양성 참고: 업그레이드 선택지를 3장 제시할 때 한 플레이어당 같은 카테고리 업그레이드 연속 2번 불가. 고양이가 연속으로 근접 업그레이드를 고르면 3번째는 반드시 공유 업그레이드 또는 양파 업그레이드가 포함. 비공식 팀 강제 균형 메카닉.

## 스토리 (05_Story)

- **스킨으로 드러나는 서사 조각** — Cosmetic Skin System 참고: 각 스킨 해금 시 짧은 1줄 플레이버 텍스트 표시. "흑묘 스킨: 어둠 속에서 수백 번 죽은 고양이." 스킨이 단순 외형 변경 아닌 캐릭터 역사의 단면으로 기능. `SkinData.SO`에 `flavorText` 필드 추가.

- **조명으로 표현하는 공간 분위기** — URP Lighting 참고: 첫 번째 층(입문 던전)은 따뜻한 노란 조명, 보스 층은 차가운 파란/보라 조명. 층마다 조명 테마를 다르게 설정해 대사 없이 "이 곳은 다른 곳이다"는 감각 전달. `Global Light 2D.color`를 층 진입 시 Lerp로 부드럽게 전환.

- **Monolith의 미니멀 서사 참고** — Monolith 참고: 스토리는 환경과 아이템 설명 몇 줄로만 암시. OnionCat도 굳이 대화 시스템 구현 없이, 아이템 이름·설명과 방 이름(예: "양파 농장의 폐허", "군주의 흔적")으로 세계관 전달. 개발 부담 최소화 + 플레이어 상상력 활용.

---

## 기술 메모

- **URP 2D Lighting System**: 던전 분위기는 `Global Light 2D` Intensity 0.1~0.2로 기본 어둠 설정, 토치·아이템 위치에 `Point Light 2D` 배치, 공격 예고는 빨간 펄스 코루틴으로 구현. Sprite Renderer Material을 `Sprite-Lit-Default`로 일괄 변경하는 것이 첫 적용 시 가장 중요한 단계 (안 하면 조명 무시됨).

- **Cosmetic Skin System**: `SkinData ScriptableObject` 먼저 3~4개 만들어 배열에 등록하고, `CharacterSkinApplier.ApplySkin()`을 `Start()`에서 호출하는 최소 구현부터 시작. 팔레트 스왑 셰이더는 초기에 불필요 — `SpriteRenderer.color` tint로도 픽셀아트 색조 변경이 충분히 잘 보임. 해금 조건은 Achievement 시스템과 연결하되, 처음엔 `PlayerPrefs`에 직접 쓰는 단순 구조로 시작할 것.
