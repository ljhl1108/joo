## 캐릭터 (01_Characters)

- **대시 통과 데미지** — Dash I-Frame 참고: Cat의 무적 대시가 적을 통과할 때 자동으로 경미한 접촉 데미지(이동 중 슬래시)를 부여하는 "관통 대시" 업그레이드 추가. 기본은 순수 회피 기술이지만 업그레이드 후 공격 이동 기술로 전환. 구현: 대시 코루틴 중 OnTriggerEnter2D로 적 충돌 시 `enemy.TakeDamage(1)`만 호출.
- **Onion 기절-구출 시스템** — Death Road to Canada 점진적 실패 참고: Cat이 대시를 활용해 무적으로 구출하는 것이 핵심 메카닉. Onion HP 0 → 3초 "기절" 상태, Cat이 Onion 위치로 대시하거나 1초 이상 옆에 있으면 구출 성공. 구출 실패 시 런 종료. 대시의 용도가 회피 외 "구출"로 확장.
- **대시 방향 고정 업그레이드** — Dash I-Frame 참고: 기본 대시는 입력 방향으로 이동하지만, 업그레이드 후 Cat의 facing 방향으로만 대시(적을 향해 돌진). Cat이 Onion이 조준하는 방향으로 자동 정렬 → 자연스럽게 두 플레이어 방향 동기화 훈련.

## 적 (02_Enemies)

- **대시 반응 적 — "회피 감지 포식자"** — Dash I-Frame 참고: Cat이 대시를 시작하면 0.1초 후 대시 도착 예상 위치로 미리 이동하는 적. I-Frame으로 피해는 피하지만 도착 지점에 적이 기다리고 있음 → Onion이 원거리로 선제 제거 필요. 구현: Cat의 velocity 벡터를 매 프레임 감지해 예측 이동.
- **보스 페이즈 전환 연출** — Boss Health Bar UI 참고: HP 66% 도달 시 보스가 잠깐 무적(1.5초)이 되며 화면 전체 플래시 + 체력바 색상이 빨강→파랑으로 변환. "이제 Onion 차례"를 색상으로 명확히 전달. 플레이어가 혼란스러워하지 않도록 보스 머리 위에도 화살표 이펙트 0.5초 표시.
- **좀비 군집 적** — Death Road to Canada 군집 AI 참고: 개별 추적 없이 Cat 쪽으로 방향만 조정하는 저비용 군집 적 (슬라임, 잡초 등). 군집 내 충돌 처리 없이 겹쳐서 몰려오는 형태. 10~20마리가 동시에 등장하는 "군중 방"에 사용. 개별 HP는 1이지만 양으로 압박.

## 맵 (03_Maps)

- **대시 필수 지형 — 가시 틈새 통로** — Dash I-Frame 참고: 가시밭 사이 좁은 틈이 있어 일반 걷기로는 데미지를 받는 지형. 대시 I-Frame으로 통과하면 무피해. Onion은 Cat이 지나가는 동안 원거리 지원만 가능. "대시 교사 방"으로 초반에 한 번 등장시켜 대시의 I-Frame 기능을 가르침.
- **보스 방 입장 전 회복 공간** — Death Road to Canada 자원 관리 + Boss HUD 참고: 보스 방 직전에 항상 "회복 샘" 방 1개 고정 배치. 최대 HP 20% 회복 가능한 샘 + 1개의 랜덤 소비형 아이템 상자. 보스 입장 전 자원 점검 → DRTC의 탐험 vs 보존 판단 구조와 동일.
- **자원 공유 방** — Death Road to Canada 공유 차량 자원 참고: 방 중앙에 "공유 상자" 1개 존재, 개봉 시 Cat과 Onion 중 현재 HP가 더 낮은 쪽에게 자동으로 회복 아이템 지급. 두 플레이어가 동시에 상자에 닿아야 개봉 가능 (협력 강제). 1인 플레이 시에는 일반 상자로 동작.

## 전투 (04_Combat)

- **대시 쿨다운 공유 없음** — Dash I-Frame 설계 확인: Cat의 대시 쿨다운은 독립적으로 관리. Onion의 방패/패리와 별개 쿨다운. 두 생존 기술이 각자 독립적이므로 "Cat 대시 중 Onion 패리"도 동시에 가능 → 협력 최대 압박 순간에 두 기술 동시 사용 허용.
- **보스 약점 색상 UI 연동** — Boss Health Bar UI 참고: 보스 몸통에도 체력바 색상과 동일한 색상 테두리 오라 효과 적용. 체력바가 파랑이면 보스 몸에 파란 테두리 → UI를 안 보는 플레이어도 인지 가능. 구현: SpriteRenderer의 Material에 `_OutlineColor` 파라미터를 Shader에서 제어.
- **대시-슬래시 연계 기술** — Dash I-Frame + Melee Combat 참고: 대시 종료 직후 0.1초 이내에 슬래시 입력 시 데미지 1.5배 "돌진 슬래시" 발동. 타이밍 습득이 필요하지만 숙련자에게 강력한 공격 옵션 제공. 구현: 대시 종료 후 `dashSlashWindow = 0.1f` 타이머, 슬래시 입력 시 배율 적용.

## 스토리 (05_Story)

- **보스 이름에 스토리 단서** — Boss Health Bar UI 참고: 보스 이름을 단순 "3층 보스"가 아닌 "양파밭 수호자 '가시'" 같은 고유명사로. 보스 HUD에 표시되는 이름이 스토리 세계관의 첫 접촉점. 이름 하나로 "이 세계에 이름 있는 존재들이 있다"는 느낌 전달.
- **대시 능력의 기원 이야기** — Dash I-Frame 참고: Cat이 왜 무적 대시를 쓸 수 있는지 짧은 설명: "Onion의 줄기에서 나오는 식물 에너지가 Cat을 일시적으로 감싸 모든 공격을 차단." Onion이 등에 있기 때문에 가능한 능력 → 두 캐릭터의 공생 관계를 능력 설명으로 강화.
- **자원 위기 대사** — Death Road to Canada 자원 관리 참고: HP가 20% 이하로 떨어지면 Cat과 Onion이 자동으로 짧은 대화 출력. "버텨봐 Onion!" / "Cat, 빨리 나가야 해!" 등. 게임플레이 위기가 감정적 순간으로 자동 연결. 런마다 랜덤으로 다른 대사 선택.

## 기술 메모

- **Dash I-Frame System**: OnionCat에 가장 빨리 적용 가능한 구현 순서 — ① `PlayerIFrame` 레이어 생성 (Physics 2D Layer Matrix에서 EnemyProjectile/EnemyHitbox와 충돌 해제) → ② `CatDash.cs`의 코루틴에서 `gameObject.layer` 전환 + `rb.linearVelocity` 설정 → ③ 스프라이트 반투명(`color.a = 0.5f`) 시각 피드백 추가. **`[SerializeField] private int normalLayer, iFrameLayer`** — 유니티 에디터에서 레이어 인덱스 직접 입력 필요.
- **Boss Health Bar UI**: 구현 우선순위 — `Image.fillAmount` + `CanvasGroup.alpha` 두 가지만 제어하면 80%는 완성됨. 지연 체력바(`healthBarDelayFill`)는 있으면 폴리시 느낌이 확 살아나므로 초반 프로토타입 후 바로 추가 권장. 페이즈 색상은 `healthBarFill.color = phaseColor` 한 줄로 전환 가능. **모든 Image/TMP 참조는 유니티 에디터에서 드래그 앤 드롭 설정 필요.**
