## 캐릭터 (01_Characters)

- **"화분 무게" 스탯** — Dome Keeper 참고: Cat이 Crop(화분)을 등에 싣고 있어 속도가 제한된다는 것을 직관적으로 보여주는 시각적 스탯. 화분이 무거울수록 Cat 이동속도 소폭 감소, 대신 Crop이 더 많은 투사체를 발사 가능. "이 화분은 Cat을 느리게 하지만 Crop을 강하게 한다" 의사결정 추가.

- **아웃라인 컬러 커스터마이징** — Sprite Outline System 참고: Cat과 Crop의 기본 아웃라인 색을 메타 진행 잠금 해제 보상으로 제공. 예: 처음엔 흰색/녹색만, 10런 클리어 후 주황/파랑 해금. 시각적 개인화 보상이면서 런 횟수를 늘리는 동기 부여.

- **"다이스 모드" 특성** — Dicey Dungeons 참고: Cat의 대시 횟수와 Crop의 탄약이 고정 숫자 대신 랜덤 주사위 결과로 결정되는 런 변형 특성. "이번 런은 모든 쿨다운이 주사위로 결정됩니다." 불확실성이 핵심인 고난이도 모드용 특성.

## 적 (02_Enemies)

- **"페이즈 전환 적"** — Dome Keeper 페이즈 루프 참고: 적이 두 가지 상태를 오가며 각 상태에서 다른 약점을 가짐. 예: 근접 페이즈(갑옷 착용, Cat 공격 튕김, Crop 투사체에만 약함) → 원거리 페이즈(갑옷 해제, Cat 근접에만 약함). Cat과 Crop이 번갈아 타깃을 바꿔야 하는 협동 요구.

- **"적 아웃라인 텔레그래프 적"** — Sprite Outline System 참고: 공격 직전 아웃라인이 빨간색으로 펄스처럼 점멸하는 적. 플레이어는 색상 변화를 보고 패리/회피 타이밍 예측. 초보자도 패턴을 학습할 수 있게 하는 시각 교육 시스템.

- **"힌트 학습 적"** — Contextual Hint 참고: 특정 적이 처음 등장했을 때만 위에 아이콘 + 한 줄 설명이 표시됨. "이 적의 방어막은 방패 패리로 부술 수 있습니다". 적 자체에 힌트 정보가 내장되어 있어 도감처럼 동작.

## 맵 (03_Maps)

- **"굴착 방" (Dig Room)** — Dome Keeper 굴착 메카닉 참고: 특수 방으로, 방 안에 부서지는 벽/블록이 가득 차 있음. Cat이 근접 슬래시로 블록을 부수며 경로 개척 → Crop은 뒤에서 적으로부터 방어. 방 안에 숨겨진 아이템은 블록 깊은 곳에 있음. Cat-Crop 역할 분리가 자연스럽게 발생.

- **"압박 타이머 방"** — Dome Keeper 웨이브 카운터 참고: 방 진입 시 카운트다운 타이머 시작 → 시간 내 모든 적 처치 못하면 방 전체에 독 안개 발생. 플레이어가 신중함과 빠른 행동 사이에서 균형을 잡도록 강제.

- **"2단 구조 방"** — Dome Keeper 지상/지하 구조 참고: 방이 상층(Cat 전용, 근접전 중심)과 하층(Crop 사격 포지션)으로 분리된 구조. 위아래 플랫폼으로 나뉘어, Cat은 돌아다니며 적을 끌어당기고 Crop은 아래 안전 구역에서 사격. 투사체 약점 적은 아래서만 보임.

## 전투 (04_Combat)

- **"캐릭터별 약점 색 코딩"** — Sprite Outline + Dicey Dungeons 캐릭터 구분 참고: 근접 약점 적 = 빨간 아웃라인(Cat 담당), 원거리 약점 적 = 파란 아웃라인(Crop 담당), 둘 다 필요한 적 = 보라 아웃라인. 플레이어가 텍스트 읽지 않아도 시각적으로 즉시 역할 분담 판단. 구현: SpriteOutlineController + EnemyWeakness enum 조합.

- **"에피소드 런 변형"** — Dicey Dungeons 에피소드 시스템 참고: 메타 진행이 쌓이면 일반 런 외에 "에피소드 런" 선택지 추가. 예: "에피소드 1 - Cat이 공격 불가, Crop만 싸운다", "에피소드 2 - 투사체가 모두 패리 필요". 기존 시스템을 비틀어 재사용 → 개발 공수 없이 컨텐츠 2배 효과.

- **"패리 힌트 자동 표시"** — Contextual Hint System 참고: Crop이 첫 패리 성공 → 자동으로 "패리 성공 시 적이 1.5초 기절합니다" 힌트 표시. 첫 패리 실패가 3회 연속 → "L2/LT를 적 공격 직전에 누르세요" 힌트. 실패 횟수로 힌트 조건을 트리거하는 적응형 힌트 시스템.

## 스토리 (05_Story)

- **"화분의 무게는 사랑"** — Dome Keeper 굴착 리소스 참고: 던전 깊은 곳에서 발견하는 유물(Relic)이 Cat과 Crop의 과거 이야기 파편을 담고 있음. Cat이 왜 Crop을 등에 싣고 다니는지, Crop이 왜 싸우는지 유물 설명 텍스트 2~3줄로 암시. 플레이 중 자연스럽게 서사를 발견하는 Dome Keeper 방식.

- **"처음 함께한 던전"** — Dicey Dungeons 캐릭터 고유성 참고: Cat과 Crop이 각자의 관점에서 같은 사건을 다르게 기억하는 구조. 게임 오버 화면에서 Cat 버전 대사 / Crop 버전 대사가 번갈아 등장. "또 실패야..." (Cat) vs "괜찮아, 다시 시작하면 돼." (Crop) - 성격 대비가 관계성을 보여줌.

- **"화분의 꽃이 피면"** — Dome Keeper 자원 관리/목표 참고: 던전 탈출의 최종 목표가 Crop(작물)이 꽃을 피워 열매를 맺는 것. 런이 진행될수록 Crop의 화분에서 작은 싹이 자라는 비주얼 진행 표시. 클리어 시 꽃이 활짝 피는 엔딩 이미지 → 명확한 감정적 페이오프.

## 기술 메모

- **Sprite Outline Highlight System**: 적 약점 색 코딩(빨강/파랑/보라)을 `EnemyWeakness enum` + `SpriteOutlineController.ShowOutline(color)`로 연동하는 것이 OnionCat 첫 번째 적용 포인트. `MaterialPropertyBlock` 사용으로 적이 많아도 드로우콜 증가 없이 개별 아웃라인 색 제어 가능. 구현 우선순위: 적 약점 표시 → 패리/대시 피드백 플래시 → 아이템 상호작용 하이라이트 순서로.

- **Contextual Hint Popup System**: 구현 시 가장 먼저 `HintData` ScriptableObject 구조를 잡고 `hintId`를 명확히 관리해야 중복 힌트/누락 힌트 방지. `PlayerPrefs.Save()`는 힌트 표시 직후 즉시 호출해야 게임 강제 종료 시에도 "이미 봤음" 상태 유지. OnionCat에서는 첫 런에 최소 4~5개의 핵심 힌트(근접 약점 적, 원거리 약점 적, 숍, 패리, 보스 방)를 우선 제작.
