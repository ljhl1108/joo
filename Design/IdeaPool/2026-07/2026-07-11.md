## 캐릭터 (01_Characters)

- **역할 고착 방지 업그레이드** — Caveblazers 참고: 두 플레이어가 자연스럽게 "고양이 = 탱커, 양파 = 딜러"로 고착되는 것을 막기 위해, 한 런에서 하나씩만 선택 가능한 "역할 전환 업그레이드" 추가. 예) "고양이 슬래시 → 원거리 충격파 발생", "양파 투사체 → 근접 폭발 전환". 구현: 업그레이드 선택 시 두 플레이어 Action Map 동적 변경
- **준비 화면 캐릭터 반응** — 협동 준비 화면 참고: P1이 Ready 누르면 고양이 스프라이트가 "앞발 들기" 애니메이션, P2가 Ready 누르면 양파 스프라이트가 "빙글 돌기" 재생. Animator의 SetTrigger("Ready") 활용. 두 캐릭터 모두 Ready 시 함께 "Jump" 애니메이션 → 게임 시작 연출
- **약점 피드백 일체화** — 데미지 숫자 참고: 근접 약점 적 공격 시 고양이 슬래시 이펙트가 빨간색으로 변하고, 숫자도 "WEAK! 24" 표시. 양파의 경우 원거리 약점 적 공격 시 투사체 색상 + 숫자 모두 강조. 시각 신호 레이어를 두 가지(이펙트 색 + 숫자)로 이중화

## 적 (02_Enemies)

- **데미지 숫자로 약점 유도** — 데미지 숫자 참고: 비약점 공격 시 회색 작은 "2" 숫자와 "✕" 표시, 약점 공격 시 빨간 "WEAK! 15" 표시. 플레이어가 숫자 색만 봐도 "이 적은 근접이 필요해"를 즉각 파악 가능. 처음에는 숫자로, 이후 몸체 색 변화(약점 피격 시 빨간 플래시)를 병행하면 시각 계층 완성
- **Caveblazers식 조합 취약 적** — Caveblazers 아이템 시너지 참고: 단순히 근접/원거리 약점이 아닌, "근접으로 스턴 → 양파가 마무리 원거리 공격" 구조의 적. 스턴 상태에서만 원거리 피해를 입는 보스 개념으로 확장 가능. 구현: Enemy FSM에 Stunned 상태 추가, 스턴 중 원거리 DamageType에만 취약
- **그룹 약점 역할 분담** — Caveblazers 역할 분담 참고: 소형 적 무리 중 "방패 오크(원거리 면역)"와 "궁수 고블린(근접 면역)"이 함께 등장하는 방. 고양이가 방패 오크를 치는 동안 양파는 궁수 고블린을 처리해야 함. 첫 번째 진정한 협동 필수 상황 구현

## 맵 (03_Maps)

- **강제 튜토리얼 첫 방** — Caveblazers 단점(진입 장벽) 참고: 첫 번째 방은 무조건 동일 방 프리팹 사용 (랜덤 생성 제외). 방 가운데 더미 적 1마리 배치, 벽에 조작 힌트 타일 표시. 고양이 조작 (WASD + 슬래시) 확인 → 양파 조작 (마우스 조준 + 발사) 확인 → 문 열림. Room 프리팹에 TutorialFirstRoom 태그로 절차적 생성에서 제외
- **준비 화면에서 미리 보기 가능한 던전 테마** — 협동 준비 화면 참고: Ready 화면에서 배경으로 "이번 런 던전 테마(숲/지하/화산)"를 흐릿하게 표시. GameData에 런 시작 시 씨드 + 테마를 미리 결정해 준비 화면에서 로드. 플레이어에게 "어떤 곳에 가게 될지" 기대감 부여
- **아이템 시너지를 유도하는 방 배치** — Caveblazers 아이템 시너지 참고: 상점 방 직전에 "시너지 힌트 방" 배치. 예) 벽에 "독 + 폭발 = 독폭발" 조합 그림 타일 표시. 복잡한 구현 없이 타일 스프라이트로 조합 가이드 제공 (Tilemap 레이어 활용)

## 전투 (04_Combat)

- **데미지 숫자 크리티컬 스택** — 데미지 숫자 참고: 같은 위치에 연속 히트 시 숫자가 겹치지 않고 약간씩 위로 쌓이도록 처리. Initialize()에서 `xRand = Random.Range(-1f, 1f)`로 가로 분산, 이전 숫자 위치 기억해 Y 오프셋 추가. 결과: 연타 공격이 시각적으로 쌓이며 카타르시스 향상
- **준비 화면 → 게임 시작 연출** — 협동 준비 화면 참고: 두 플레이어 Ready 후 즉시 씬 전환하지 않고, "3... 2... 1... Go!" 카운트다운 0.5초 연출 후 페이드인. 이 시간 동안 플레이어가 손을 컨트롤러/마우스에 올릴 수 있음. Coroutine + SceneManager.LoadSceneAsync 조합
- **저항 피격 피드백** — 데미지 숫자 참고: 비약점 공격이 막힐 때 데미지 숫자 없이 "딱" 하는 금속 충돌음 + 회색 "✕" 스프라이트만 표시. 오브젝트 풀에서 DamageType.Resist 처리, TextMeshPro 대신 간단한 SpriteRenderer 이미지로 대체 가능. 플레이어에게 "이 공격은 통하지 않는다"를 즉각 인지

## 스토리 (05_Story)

- **준비 화면 배경 대사** — 협동 준비 화면 참고: 준비 화면에서 고양이와 양파가 서로 말을 주고받는 짧은 대사 루프 표시. "오늘도 같이 가는 거지?" / "당연하지, 내가 없으면 넌 원거리 못 쏘잖아." 런 시작 전 두 캐릭터 관계를 자연스럽게 전달. TextMeshPro 대화창 or 말풍선 스프라이트로 구현
- **약점 발견의 스토리 장치** — 데미지 숫자 참고: 게임 세계관에서 "약점"은 적들이 가진 '봉인 마법'으로 설명. 첫 런에서 양파가 "이 녀석... 슬래시에만 반응해! 고양이 네가 해야 해!"라는 인게임 대사로 약점 시스템 첫 설명. 약점 첫 발견 시 한 번만 재생 (PlayerPrefs로 플래그 관리)
- **Caveblazers식 런 종료 이야기** — Caveblazers 빠른 사망 참고: 게임 오버 시 "이번 런 이야기"를 한 줄 자동 생성. 예) "고양이와 양파는 3층에서 오크 대장에게 패배했다. 하지만 다음엔..." 처치 수, 클리어 방 수, 마지막 사인 적을 조합해 텍스트 자동 생성. string.Format()으로 간단 구현

## 기술 메모

- **부유 데미지 숫자**: OnionCat에서 가장 빠르게 전투 피드백을 향상시킬 수 있는 기능. TextMeshPro + 오브젝트 풀 조합으로 구현. 핵심은 **DamageType 열거형으로 색상·크기를 분리**하고, 비약점(Resist) 타입을 추가해 "이 공격은 통하지 않는다"는 피드백도 같은 시스템에서 처리하는 것. 20개 초기 풀 사이즈로 시작.
- **협동 플레이 준비 화면**: OnionCat은 P1 키보드/패드 + P2 마우스라는 비대칭 구조이므로 PlayerInputManager의 표준 합류 방식 대신 **고정 배분 방식** 사용 권장. P2(양파)는 항상 합류된 것으로 처리, P1(고양이)만 Ready 버튼 누름. 구현 순서: ① 씬 만들기 → ② P1/P2 슬롯 UI → ③ P1 Ready 감지 → ④ P2 마우스 클릭 Ready → ⑤ 카운트다운 → ⑥ 씬 전환.
