## 캐릭터 (01_Characters)

- **솔로 모드 AI 보조** — Young Souls 참고: 1인 플레이 시 Cat이 Onion을 자동 조작하는 간단한 AI(자동 조준 + 발사만) 제공. 솔로 테스트 빌드에서도 게임이 플레이 가능해짐. AI Onion은 Cat이 공격한 적을 자동 타겟팅, 초당 1회 발사. 개발 중 밸런스 테스트에도 유용.
- **패리 마크 시스템** — Nine Sols 태그&폭발 참고: Onion이 패리 성공 시 적에게 시각적 "마크" 이펙트 부착. Cat이 마크된 적을 슬래시하면 추가 데미지 + 파티클 폭발. 두 플레이어가 소통 없이는 발동 불가 → 협력 필수성 강화. 마크 지속시간 3초.
- **업그레이드 트리 차별화** — Young Souls 개별 빌드 참고: Cat 업그레이드(대시 거리 증가, 슬래시 범위 확대, 연속 슬래시)와 Onion 업그레이드(투사체 분열, 방패 쿨다운 감소, 패리 창 확대)를 완전히 분리. 두 트리가 겹치는 항목 없도록 의도적 설계. 한 명이 방어에 집중하면 다른 한 명이 딜에 집중하는 빌드 자연 유도.

## 적 (02_Enemies)

- **Behavior Tree 엘리트 적 — "투사체 감지 수비형"** — Behavior Tree + Nine Sols 전조 참고: `Selector(Onion조준감지→방어자세 전환 / Cat접근감지→근접공격 / 기본순찰)` 구조. Onion이 조준하면 방패를 들어 투사체를 막으며 Cat 방향으로 돌진 → Cat 전용 적으로만 잡을 수 있음. 방어 자세 전환 시 0.5초 전조 애니메이션 필수.
- **마크 반응 적** — Nine Sols 패리/태그 참고: Onion의 패리 반사 투사체에 맞으면 특수 경직 상태(2초) 진입하는 적 타입. 일반 투사체로는 경직 없음 → 패리 숙련도를 높은 보상으로 직접 연결. Cat이 경직된 적을 슬래시 시 크리티컬 데미지.
- **페이즈 전환 보스 AI** — Behavior Tree 참고: 보스 HP 70%/40% 구간에서 State Machine으로 페이즈 전환, 각 페이즈 내부는 Behavior Tree로 공격 패턴 조합. 1페이즈: 근접 위주 / 2페이즈: 투사체 추가 / 3페이즈: 두 공격 랜덤 조합. Cat/Onion을 별개 타겟으로 추적 분리.

## 맵 (03_Maps)

- **조작법 안내 방** — How to Play 참고: 첫 번째 런 시작 전 "튜토리얼 방" 대신 짧은 "조작 연습 방" 제공. 두꺼비집 형태의 안전한 공간에 더미 타겟 배치. Cat 슬래시 → 더미 반응, Onion 패리 연습용 느린 투사체 발사기 존재. 클리어 조건 없이 플레이어가 원하는 만큼 연습 후 문으로 나가면 진행.
- **좁은 복도 협력 방** — Young Souls 포지션 기반 설계 참고: Cat이 앞에서 적을 막고 Onion이 뒤에서 원거리 지원하는 구조가 강제되는 1×5 타일 폭 복도 방 추가. 복도 방에서만 등장하는 "벽 뚫기 불가" 특수 적 타입 1종 배치.
- **엘리트 룸** — Young Souls 던전 구조 참고: 일반 방보다 강한 엘리트 적 1마리가 등장하는 도전 방. 클리어 시 일반 업그레이드 2개 중 선택 → 위험 대비 보상 비율이 일반 방보다 높음. 방 입장 전 문에 엘리트 아이콘 표시로 선택권 부여.

## 전투 (04_Combat)

- **패리 창 업그레이드** — Nine Sols 패리 시스템 참고: 기본 패리 창 0.12초 → 업그레이드로 0.18초까지 확장 가능. 초보자 접근성을 위한 최소 보조 시스템. 패리 성공 시 피드백(금속음 + 흰빛 + 0.06초 히트스톱)은 고정, 창 크기만 업그레이드.
- **위험 탈출 우선 행동** — Behavior Tree 참고: HP 30% 이하 적은 전투 AI 우선순위가 바뀜 — 공격 전에 항상 탈출 시도. 이를 막으려면 Cat(근접 막기)과 Onion(원거리 봉쇄)이 동시에 포위 구도 형성 필요. 팀워크로 처치해야 하는 마지막 순간 압박 연출.
- **2인 동시 처치 보너스** — Young Souls 협력 메카닉 참고: Cat 슬래시와 Onion 투사체가 같은 프레임(±2프레임)에 적에게 적중 시 "협력 처치" 판정 → 추가 골드 드롭 + 짧은 슬로우 모션(0.3초). 협력 처치 횟수 통계로 기록.

## 스토리 (05_Story)

- **패리 실패의 스토리 연출** — Nine Sols 패리 시스템 참고: Onion이 패리를 실패해 큰 데미지를 받을 때 Cat이 "괜찮아?!" 대사 출력 (자동 트리거). 반대로 패리 성공 시 Onion이 짧게 환호하는 대사. 게임플레이 결과가 캐릭터 감정으로 자연스럽게 연결.
- **조작법 안내의 내러티브 통합** — How to Play 참고: 조작법 화면을 단순 텍스트가 아니라 "Cat의 일기" 형식으로 구성. 예: "오늘 Onion이 방패 쓰는 법을 가르쳐줬다. 방향을 잘 맞춰야 한다고 했다." — 기능 설명이 동시에 스토리 전달.
- **Young Souls식 허브 성장** — Young Souls 도시 허브 참고: 런 클리어/실패 후 메인 메뉴 화분 정원에 새로운 꽃/씨앗이 추가. 5런마다 Onion이 새로운 짧은 독백 대사 해금 ("이 씨앗은 어디서 온 걸까..."). 메타 진행이 스토리 조각 수집으로 연결.
