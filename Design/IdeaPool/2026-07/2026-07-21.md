## 캐릭터 (01_Characters)

- **협공 Break 연출** — Haven 참고: Cat의 슬래시와 Crop의 투사체가 0.3초 윈도우 내에 같은 적에게 맞으면 "협공 Break" 발동 → 슬로모(0.2배, 0.15초) + 노란 충격파 파티클 + Toast "협공!" 동시 출력. 두 플레이어가 능동적으로 타이밍을 맞추게 유도하는 보상 설계.
- **패링 후 슬로모 강화** — Unsighted 패링 + TimeScale 참고: Crop이 패링 성공 시 0.15초간 시간이 0.15배로 느려지면서 Cat이 안전하게 강타 위치로 이동할 시간을 얻음. 패링이 단순 방어가 아닌 "공격 기회 창출"로 기능하게 만드는 핵심 순간.
- **Anima 공유 체력 → 공유 HP 바** — Unsighted 공유 Anima 참고: OnionCat의 공유 체력을 HUD에서 단일 HP 바로 표시. 두 캐릭터가 각자 피격될 때 같은 바가 줄어드는 것을 보여줌 → "우리가 하나"임을 시각적으로 강조. 바가 30% 이하면 붉게 맥동.

## 적 (02_Enemies)

- **방패 기사 (Shield Warden)** — Haven 방어/공격 역할 교환 참고: 앞면에 거대 방패를 들고 있어 Crop의 원거리 투사체를 100% 막음. Cat이 대시로 측면 또는 후면에 근접 강타를 먹여 방패를 잠깐 내리게 만들면 Crop이 그 순간 원거리 집중 사격. Break 타이밍 협력 강제.
- **시간 흡수체 (Timestopper)** — TimeScale 참고: 주변에 슬로우 필드를 방출하는 적. 필드 내 플레이어 이동 속도 50% 감소. Cat이 대시 무적으로 필드를 뚫어 근접 파괴 vs Crop이 원거리로 필드 외부에서 저격. 역할 선택의 재미.
- **알림 소환사 (Alert Summoner)** — Toast 알림 연계 참고: 화면 외부에 숨어 있다가 Toast 알림("소환사 감지!")으로 위치를 알리고 잠깐 뒤에 적들을 소환. 알림이 게임플레이 정보 전달 도구로 기능하는 사례.

## 맵 (03_Maps)

- **쉼터 방 (Nest Room)** — Haven Nest 참고: 보스 직전 방에 "쉼터 방" 유형 추가. 전투 없이 Cat이 Crop에게 물을 주는 인터랙션(버튼 입력) → 체력 20% 회복 + 짧은 대화 연출. 전투 긴장감을 잠깐 내려놓는 감정 완충 공간.
- **협공 연습 방 (Synergy Room)** — Haven Break 시스템 참고: 특정 방에 "방패 더미(Shield Dummy)" 오브젝트 배치. 두 플레이어가 Break 타이밍을 자유롭게 연습 가능. 첫 Break 성공 시 골드 보상 + Toast "첫 협공 성공!". 튜토리얼이 아닌 자연스러운 발견.
- **시간 왜곡 구간 (Time Rift Zone)** — TimeScale 참고: 방 내 특정 타일에 진입하면 플레이어만 슬로모(0.5배) 적용, 적은 정상 속도. 극한의 반응 요구 구간. 클리어 보상으로 TimeScale 업그레이드 획득 가능("아드레날린: 슬로모 중 데미지 +30%").

## 전투 (04_Combat)

- **협공 Break 게이지** — Haven + Unsighted 공유 자원 참고: 화면 하단에 "협공 게이지(Synergy Gauge)" 표시. Cat 근접 공격 + Crop 원거리 공격 양쪽이 동시에 적에 명중할 때 게이지 충전. 게이지 MAX 시 강력한 "합동 필살기" 발동 가능. 협력하지 않으면 게이지가 천천히 감소.
- **슬로모 처형기** — TimeScale + 보스전 참고: 보스 체력 0 도달 시 0.05배 슬로모 0.8초 → Cat과 Crop이 동시에 최후 공격 컷씬(프리즈 프레임) → 폭발 이펙트. 보스 처치의 카타르시스를 극대화. 코-op에서 "우리가 해냈다"는 감각.
- **Toast 기반 전투 피드백** — Toast System 참고: 전투 중 모든 주요 이벤트를 Toast로 화면 우하단에 출력. 단, 중복 방지: 같은 메시지 0.5초 이내 재발생 시 기존 Toast 시간 연장(쌓아올리지 않음). 화면 오른쪽 상단은 적 패턴 집중 구역 → Toast는 반드시 우하단 배치.

## 스토리 (05_Story)

- **관계가 스탯이 된다** — Haven 식사/대화 시스템 참고: 런 중 쉼터 방에서 두 플레이어가 협력 인터랙션(물 주기, 고양이 쓰다듬기 등)을 하면 "유대 포인트" 충전 → 런 종료 후 영구 스탯 소폭 강화. "같이 하면 강해진다"는 게임플레이 언어로의 서사 표현.
- **Anima 위기 연출** — Unsighted 타이머 참고: 공유 체력이 20% 이하일 때 배경 음악이 조용한 긴장감 있는 버전으로 전환 + Cat의 모션이 조금 흔들림 + Crop의 잎사귀가 처짐. 수치 대신 시각/청각 연출로 위기감 전달.
- **첫 협공 순간** — Haven Break 감정 참고: 런 중 처음으로 협공 Break가 발생하면 일반 Toast가 아닌 화면 중앙에 큰 연출("협공 각성!") + BGM 잠깐 전환. 두 플레이어가 동시에 "오!" 하는 순간을 의도적으로 설계.

## 기술 메모

- **TimeScale / Bullet Time**: 가장 바로 적용 가능한 요소는 `패링 성공 시 SlowMotion(0.15f, 0.1f)`. 주의: Coroutine 내 `WaitForSecondsRealtime` 필수, `Time.fixedDeltaTime`도 함께 조정해야 물리 버그 없음. 보스 처치 슬로모는 `SlowMotion(0.05f, 0.8f)` + DOTween 카메라 줌인 `SetUpdate(true)` 동시 실행.
- **Toast Notification**: 구현 첫 단계는 ToastManager 싱글톤 + ToastItem 프리팹(CanvasGroup + TMP_Text) 세팅. OnionCat은 전투 피드백(협공, 패링, 약점)에 집중 사용 — 아이템 획득은 별도 팝업으로 분리 권장. 중복 방지 로직(0.5초 쿨다운 딕셔너리)을 처음부터 넣어야 나중에 노이즈 문제 없음.
