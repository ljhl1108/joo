## 캐릭터 (01_Characters)
- **역할 색상 코딩** — Neon Abyss 아이템 시각화 참고: Cat은 주황색 글로우, Crop은 파란색 글로우를 기본 UI/이펙트에 적용해 화면 혼잡 시에도 두 플레이어 역할을 즉시 구분 가능하게 함. 튜토리얼 약점 인디케이터와 색상 일치 필수.
- **Cat 포켓 아이템** — Moonlighter 포켓 시스템 참고: Cat은 런 실패 시에도 소규모 "부적 슬롯" 1개를 보존. 부적은 런 간 영구 업그레이드 대상이 되어 플레이어에게 소속감 부여. 구현: `PlayerPrefs`에 부적 ID 저장.
- **Crop 진화 단계** — Neon Abyss 해치몬 진화 참고: 런 중 Crop이 특정 아이템 3개 조합 시 외형+능력 1단계 진화. 캐릭터 스프라이트를 스크립터블 오브젝트로 분리 후 런타임 교체로 구현 가능.

## 적 (02_Enemies)
- **강제 협력 적 쌍** — Moonlighter 무기 전환 참고: "쉴드 골렘(근접만 통함) + 저격 스프라이트(원거리만 통함)" 쌍을 항상 같이 등장시키는 패턴. Cat이 골렘에 묶이는 동안 Crop이 스프라이트를 처치해야 하는 설계. 적 스폰 테이블에 "강제협력 페어" 태그 추가.
- **2페이즈 보스** — Neon Abyss 보스 설계 참고: 1페이즈는 Cat의 180° 슬래시 유효 범위에서만 공격 패턴, 2페이즈 전환 시 날아다니며 Crop의 원거리 전담 구도로 전환. 페이즈 전환 트리거: `OnHealthPercentReached(0.5f)`.
- **해치몬 미니 적** — Neon Abyss 참고: 처치 시 알을 드롭하는 소형 적. 알에서 30초 뒤 더 강한 변형체 부화 — 클리어 속도를 올리는 동기 부여. 구현: 알 오브젝트에 타이머 코루틴 + 새 적 스폰.

## 맵 (03_Maps)
- **역할 특화 방** — Moonlighter 안전 지점 참고: 순수 근접 방(원거리 적 없음)과 순수 원거리 방을 교대로 배치해 각 플레이어의 "내 시간"을 보장. 방 템플릿에 `RoomType.MeleeOnly / RangeOnly / Mixed` 열거형 추가.
- **비밀 방 조건** — Moonlighter 비밀 방 참고: Cat과 Crop이 동시에 특정 벽을 공격(Cat 근접 + Crop 원거리)해야 열리는 비밀 방. 순수한 협력 미니게임으로 기능. 구현: 벽 오브젝트에 두 히트 타입 플래그 비트마스크로 추적.
- **안전 치유 구간** — Moonlighter 치유 웅덩이 참고: 2~3방마다 안전 구역 배치, 입장 시 최대 체력의 25% 회복. RNG 런에서 극단적 난이도 완화. 방 배치 로직에 `guaranteedHealRoomEvery = 3` 설정.

## 전투 (04_Combat)
- **듀오 시너지 아이템** — Neon Abyss 시너지 참고: "Cat이 대쉬 직후 3초 내 Crop 발사 적중 = 2배 피해" 같은 타이밍 기반 시너지. 아이템 스크립터블 오브젝트에 `DuoSynergyTrigger` 이벤트 채널 추가. 시각 피드백: Cat 대쉬 직후 Crop 조준선이 황금색으로 변함.
- **패링 반사탄** — 2D 물리 참고: Onion 패링 성공 시 투사체 velocity를 반전하는 것이 아니라, `LayerMask`를 PlayerProjectile로 교체해 반사 투사체가 적에게 2배 피해. `Physics2D.IgnoreLayerCollision` 동적 전환으로 구현.
- **대쉬 관통 피해** — 2D 물리 참고: 대쉬 무적 중 적을 통과할 때 `OnTriggerStay2D`로 접촉한 적에게 소량 접촉 피해(아이템 해금 조건). Layer Matrix에서 대쉬 중 PlayerDash 레이어로 교체해 TriggerOnly 판정.

## 스토리 (05_Story)
- **상점 주인 NPC** — Moonlighter 상점 루프 참고: 마을 허브에 상인 NPC 배치, Cat이 획득한 재료를 팔면 다음 런에서 업그레이드 구매 가능. "Cat은 던전 탐험가, Crop은 상인의 화분"이라는 스토리 동기 부여. 구현 우선순위 낮음 — 코어 전투 완성 후.
- **공유 신체의 기원** — 게임 컨셉 심화: Cat이 Crop을 등에 얹은 이유를 런 중 발견하는 메모/파편 방식. 각 던전 테마에 1~2개 로어 조각. 구현: ScriptableObject 기반 로어 데이터베이스.
- **해치몬 vs 약점 적** — Neon Abyss + OnionCat 결합: Crop이 키운 해치몬이 특정 적(같은 컬러)에게 유효 피해를 줌 → 시각적으로 "Crop이 키운 동반자가 약점을 안다"는 스토리 뉘앙스.

## 기술 메모
- **2D 물리**: `Physics2D.IgnoreLayerCollision(Player, Enemy, true/false)`을 대쉬 시작/종료에 연결하면 무적 대쉬를 단 두 줄로 구현 가능. Layer Matrix를 먼저 정리하면 불필요한 `OnCollision` 콜백 자체가 없어져 성능+코드 모두 깔끔해짐.
- **튜토리얼 시스템**: 구현 순서 — ① TutorialManager(첫 실행 감지) → ② TutorialTooltipUI(팝업 UI) → ③ TutorialTriggerZone(방 배치) → ④ HintSystem(런 중 힌트). `Time.timeScale = 0`은 New Input System 콜백은 막지 않으므로 일시정지 팝업 구현 시 안전하게 사용 가능.
