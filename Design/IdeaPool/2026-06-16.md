## 캐릭터 (01_Characters)

- **능력 스택 시각화** — Gunfire Reborn 참고: Cat의 대시 횟수나 Onion의 탄약 수를 픽셀아트 아이콘으로 Cat 머리 위에 작게 표시. Cat이 달리면서도 Onion 자원 상태가 한눈에 보여야 협력 판단이 빨라짐. 구현 힌트: Canvas의 World Space 모드 + Follow 스크립트.
- **원소 친화성 수동선택** — Gunfire Reborn의 빌드 자연 분화 참고: 런 시작 시 Cat은 "화염 / 빙결 / 번개" 중 친화 속성 선택 → 해당 속성 업그레이드가 더 자주 등장. 강요 없이 매 런마다 다른 스타일 유도.
- **파트너 상태 아이콘** — Gunfire Reborn의 팀 HUD 참고: Onion이 방어막을 올린 상태, 탄약 없는 상태를 Cat 플레이어도 주변시로 알 수 있게 화면 모서리에 간단 아이콘 표시. 구현 힌트: UI Image + Animator로 깜빡임/색 변화.

## 적 (02_Enemies)

- **원소 약점 적** — Gunfire Reborn의 원소 속성 시스템 참고: "불꽃 슬라임"은 Onion의 기본 물 탄환으로만 처치 가능, "철갑 병사"는 Cat의 근접 참격으로만 방어구 파괴 가능. 시각적으로 약점 속성을 적 머리 위 작은 아이콘으로 표시. 구현 힌트: EnemyBase에 `WeaknessType` enum 추가.
- **부활 방해자** — Gunfire Reborn의 부활 시스템 반전: OnionCat에서는 죽은 플레이어가 없어 부활 대신, "Cat이 스턴되면 Onion도 움직임 불가"라는 패널티를 노리는 적. Cat을 스턴 후 도망치며 카이팅하는 원거리 적 → Onion이 먼저 처리해야 하는 상황 연출.
- **거울 방패 적** — 픽셀아트 렌더링 셋업의 히트 플래시 참고: 피격 시 반짝이는 방패를 가진 적. 방패 활성화 중 근접 공격 반사(Cat 역피해), 방패 비활성화 시(주기적 3초) 원거리 공격만 통함 → Onion이 타이밍 맞춰야 하는 협력 기믹.

## 맵 (03_Maps)

- **픽셀 해상도 방 분류** — 픽셀아트 렌더링 셋업 참고: 방 크기를 기준 해상도(320×180)의 정수 배율로 설계. 1배(소형), 2배(중형), 3배(보스방). 카메라가 방 경계에 맞춰 깔끔하게 스냅 → Pixel Perfect Camera와 완벽 호환.
- **원소 지형 타일** — Gunfire Reborn의 원소 속성 참고: 불꽃 바닥(지속 화염 피해), 물 웅덩이(Cat 이동속도 감소, Onion 탄환 강화) 타일. 같은 방도 어느 타일을 밟느냐에 따라 전술이 달라짐. 구현 힌트: Tilemap Collider2D + OnTriggerStay2D.
- **보물방 잠금 해제 조건 다양화** — Gunfire Reborn의 보물방 구조 참고: 기본은 열쇠 소비, 추가로 "이 방에서 피해 없이 생존", "30초 내 클리어" 등 도전 조건 클리어 시 열리는 보물방 변형. 구현 힌트: RoomClearCondition ScriptableObject로 조건 분리.

## 전투 (04_Combat)

- **디버그 모드 활용 밸런싱** — 디버그 & 치트 시스템 참고: F3(아이템 스폰) 반복으로 강한 빌드 상태에서의 보스 전투를 빠르게 테스트. "이 빌드 조합이 너무 강하면 보스 체력 몇 배 조정?" → 수치 밸런싱 사이클 단축. 개발 초기부터 치트 시스템 구축 권장.
- **스택형 패시브 시각화** — Gunfire Reborn의 스크롤 스택 참고: 같은 업그레이드를 여러 번 획득 시 Cat 무기 주변에 픽셀아트 링 이펙트로 스택 수 표시 (1링 = 1스택). Onion 탄환 속도 업그레이드 스택도 탄환 색으로 표현. 구현 힌트: SpriteRenderer Color.Lerp.
- **패링 타이밍 가이드** — 픽셀아트 렌더링 셋업의 히트 플래시 참고: Onion 방어막 패링 성공 시 화면 전체 0.1초 흰색 플래시 + 히트스톱 0.05초. 실패 시 피격 빨간 플래시. 명확한 피드백으로 패링 타이밍 학습 곡선 완화.

## 스토리 (05_Story)

- **운명의 화분** — Gunfire Reborn의 캐릭터 설정 참고: Cat이 Onion을 등에 메게 된 이유 — "신비한 화분이 Cat의 등에 저주처럼 달라붙었다. 화분의 Onion은 이 저주를 풀 방법을 알고 있다고 주장한다." 협력의 동기가 서로의 이해관계에서 출발.
- **던전의 비밀** — Gunfire Reborn의 챕터 구조 참고: 던전이 3개 구역(숲/지하/탑)으로 나뉘며 각 구역 보스가 화분 저주의 단서를 가짐. 보스 처치마다 스토리 조각 1개 획득. 구현 힌트: GameEvent ScriptableObject로 보스 처치 → 스토리 팝업 연결.
- **두 목소리** — Gunfire Reborn의 멀티 캐릭터 대사 참고: 전투 중 Cat과 Onion의 짧은 대화 이벤트. "이 녀석들 근접엔 강하다!" (Cat) / "그럼 내가 맡을게." (Onion) — 협력 강조 + 캐릭터 개성 구축. 구현 힌트: Dialogue Trigger에 근접/원거리 약점 적 등장 시 랜덤 대사.

## 기술 메모

- **픽셀아트 렌더링 셋업**: 프로젝트 초기에 **스프라이트 임포트 프리셋**과 **Pixel Perfect Camera** 먼저 구축할 것. 나중에 PPU나 Filter Mode 바꾸면 이미 제작한 스프라이트 전부 영향받음. 기준 해상도 320×180을 잠그고 시작 권장.
- **디버그 & 치트 시스템**: `#if UNITY_EDITOR || DEVELOPMENT_BUILD` 블록으로 감싸면 릴리즈 빌드에서 자동 제거됨. 개발 초기(첫 번째 방 완성 직후)에 F1(무적)/F2(적 즉사)/F4(방 스킵) 3가지만 먼저 구현해도 테스트 속도가 크게 향상됨.
