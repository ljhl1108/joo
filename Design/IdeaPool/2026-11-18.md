## 캐릭터 (01_Characters)

- **마법서 발동 방식 차별화** — Alina 카드 참고: 1번 마법서는 "클릭 즉시 발사(빠름·좁음)", 2번은 "0.3초 차지 후 넓은 발사", 3번은 "쓸 때마다 발동 위치 순환". 지금처럼 쿨타임·범위만 다른 게 아니라 **플레이 감촉이 다른 행동 방식**을 각 슬롯에 고정하면 작물 플레이어가 세 슬롯을 모두 활용하는 이유가 생김
- **씨앗 경제 — 근접 연타로 씨앗 회복** — Alina의 에너지 관리 참고: 고양이의 근접 공격이 적에게 맞을 때마다 씨앗 소량(0.5~1개) 회복 → 고양이가 적극적으로 붙으면 작물이 더 많이 쏠 수 있는 협동 구조. 씨앗이 0개일 때 "빈 주먹 사격"(약한 무료 공격) 추가로 작물이 완전히 쓸모없는 상황 방지
- **패링 카드 업그레이드 경로** — Alina의 Block → Parry Block → Perfect Parry 경로 참고: 작물 실드 장비를 "실드 쿨타임 단축 → 패링 창 확대 → 패링 성공 시 쿨타임 초기화" 단계로 세분화하면 같은 실드 장비도 단계에 따라 플레이가 완전히 달라짐

## 적 (02_Enemies)

- **블록-반격형 적** — Alina의 Counter 카드 참고: 평소엔 블록 자세를 유지하다가 플레이어가 근접 공격 시 카운터를 날리는 적. 작물이 씨앗으로 블록을 먼저 깨주면(원거리 약점 × 2) 고양이가 안전하게 접근 가능 — 협동 조율이 필요한 설계
- **에너지 흡수형 적** — Alina의 에너지 관리 참고: 피격 시 작물의 씨앗 탄약을 소량 흡수하는 적. 무작정 쏘다 보면 보스 전에 탄이 떨어지는 압박. "아끼면서 쏘는" 경제 판단을 강요

## 맵·런 구조 (03_Maps)

- **유기 방 외곽선 버그 수정 포인트** — 절차적 방 형태 참고: 현재 `RoomShape.Apply`에서 문 근처 꼭짓점이 흔들려 출입구 주변 판정이 튀는 경우가 생길 수 있음. 문 위치에서 1.5칸 반경의 꼭짓점에 `perturbMask`를 적용해 흔들기를 0으로 줄이면 해결. `distToDoor < 1.5f → amplitude * 0` 처리 추가 권장
- **대형 방 꼭짓점 수 최적화** — 절차적 방 형태 참고: 그려진 방(PaintedRoom)은 1920×1080이라 판정 폴리곤 꼭짓점이 수백 개일 수 있음. `PaintedRoomImporter.Soften`에서 더글라스-푸커(Douglas-Peucker) 알고리즘으로 불필요한 꼭짓점을 제거하면 Physics2D 계산량을 줄일 수 있음

## 전투·협동 (04_Combat)

- **합동기 첫 발동 버튼 힌트 — 패드/키보드 자동 전환** — 버튼 프롬프트 시스템 참고: 합동기 게이지 100% 첫 도달 시 "고양이 [RB] + 작물 [Space]를 같이 누르세요" 말풍선을 HUD에 띄울 때, 패드 연결 여부에 따라 아이콘이 자동으로 바뀌게. P1이 Xbox 패드이면 `<sprite=RB>`, 키보드만이면 `<sprite=E>`로 치환. `InputDeviceTracker.LastUsed_P1`으로 판단
- **세트 보너스를 행동 연계 발동으로** — Alina의 렐릭+카드 조합 참고: 현재 세트 보너스가 수동 패시브 위주라면, "바람 세트 2단계 — 대쉬 완료 직후 0.5초 이동 속도 보너스"처럼 **행동을 트리거로 발동하는 보너스**를 넣으면 세트 보너스를 "의식하면서 쓰는" 재미가 생김. `EffectTrigger`에 `OnDashEnd` 추가로 구현 가능

## 아이템·세트 (05_Items)

- **커브 씨앗 탄 마법서 고유기** — Alina의 카드 조합 참고: 작물 고유기 R로 "씨앗 최대 3발 충전 → 한꺼번에 베지어 곡선 궤적으로 발사". 3발이 같은 목표를 다른 각도로 감싸서 들어감. 범위가 넓어 뭉친 적에게 효과적이지만 단발보다 느림. `CurvingProjectile.Init(start, controlPoint, enemyPos, 0.4f)` 한 줄로 구현 가능
- **패드 감지 아이콘 세트 에셋** — 버튼 프롬프트 참고: `ButtonPromptSet` ScriptableObject 2개(Xbox계열, 키보드)를 먼저 만들고, Xelu's FREE Controller Prompts(CC0 라이선스) 에셋을 TMP Sprite Asset으로 임포트. HUD의 합동기 아이콘 한 곳에만 먼저 붙여 테스트한 뒤 확장

## 스토리·메타 (07_StoryMeta)

- **말하는 책이 패드/키보드 힌트를 직접 말해주기** — 버튼 프롬프트 참고: `Dialogue.Say()`로 나오는 책의 대사에 버튼 프롬프트 치환을 적용. "패링하려면 `<btn=B>` 버튼을 타이밍에 맞춰 누르세요"가 패드면 ⬛ 아이콘, 키보드면 "[S]"로 나옴. 대사 텍스트 자체를 수정하지 않아도 기기 전환에 자동 대응
- **처음 판 vs. 반복 판 대사 분기 + 모드 힌트** — Alina의 짧은 런 참고: 고양이 없이 작물 단독 키보드 모드일 때 "낡은 책: 오늘은 혼자군. 어깨가 허전하겠는걸." 같은 대사 한 줄 추가로 소로 플레이를 인식하는 연출. `CoopInputLayout.CurrentMode == CoopMode.KeyboardOnly` 조건으로

## 기술 메모

- **절차적 유기 방 형태**: 현재 `RoomShape.Apply`의 Perlin 흔들기 amplitude를 `cellSize * 0.2f` 이하로 제한하면 문 근처 판정 튐을 거의 없앨 수 있음. 추가로 꼭짓점 간 최소 거리 체크(`if dist < 0.1f → 제거`)로 뾰족한 삼각형 판정 방지. 적용 순서: 문 위치 가져오기 → 거리 마스크 계산 → Perlin 흔들기 → Catmull-Rom 평활화
- **기기별 버튼 프롬프트**: 가장 빠른 구현 경로 — ① Xelu's CC0 아이콘 TMP Sprite Asset으로 임포트 ② `InputDeviceTracker` 싱글턴을 `GameManager.Awake`에서 초기화 ③ HUD의 합동기 버튼 아이콘 하나에 `ButtonPromptText` 붙이기 → 테스트 후 말풍선 대사 치환으로 확장. 패드 없는 환경(빌드 서버 테스트)에서 null device로 크래시 나지 않게 `device != null` 체크 필수
