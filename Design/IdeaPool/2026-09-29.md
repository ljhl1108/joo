## 캐릭터 (01_Characters)

- **Cat 근접 투사체 반사 (Deflect)** — Huntdown의 근접 커버 메카닉 참고: Cat 슬래시가 날아오는 투사체에 타이밍 맞으면 반사. Crop 방패(패링)와 다른 레이어의 방어 수단. 구현 힌트: `OnTriggerEnter2D` → 투사체 진행 방향 `velocity *= -1.5f` + 반사한 쪽으로 `targetTag` 교체

- **Crop 임시 무장 교체** — Huntdown의 바닥 픽업 아이템처럼, 방에서 특수 씨앗(산탄/유도/관통) 획득 시 한시적으로 발사 패턴 교체. 탄약 소진 시 기본 씨앗으로 자동 복귀. 구현 힌트: `ProjectileProfile` ScriptableObject를 `currentProfile`로 교체 + 탄약 카운터 관리

- **공유 체력 시각화 강화** — Astalon의 공유 체력 풀처럼 "누가 맞아도 같이 아프다"는 느낌을 강조. Cat이 맞으면 화분 흔들림, Crop이 맞으면 잎이 쳐지는 개별 피격 연출을 공유 HP 감소에 결합. 구현 힌트: `OnDamageTaken` 이벤트에 피격 주체(`Cat`/`Crop`) 파라미터 추가 → 각 연출 분기

## 적 (02_Enemies)

- **방패 전진형 적 (Shield Pusher)** — Huntdown의 방패형 적처럼, 정면 방어 방패를 들고 천천히 전진. 측면 또는 Cat 슬래시 근접(방패 안쪽)으로만 피해 가능. Crop 원거리는 방패에 막힘 → 코옵 강제. 구현 힌트: 적 `Shield` 오브젝트가 정면 Collider 역할 → `CompareTag("PlayerAttack")` 차단, 근접 어택 레이어만 통과

- **자폭 접근형 적 (Exploding Sprout)** — Huntdown의 자폭형처럼, 느리게 Cat+Crop을 향해 접근 후 폭발. Crop이 원거리로 폭발시키면 다른 적도 연쇄 피해. Cat은 반사 또는 밀쳐내기로 방향 제어. 구현 힌트: `ExplodeOnDeath` + `Physics2D.OverlapCircleAll` 범위 피해 + 다른 자폭형과 충돌 시 연쇄

- **Astalon식 구역 잠금 수호자** — 특정 지형 앞을 지키는 적. 근접 약점형 vs 원거리 약점형이 같은 방에 페어로 배치. 둘 다 처치해야 다음 문 열림. 구현 힌트: `RoomClearCondition`에 두 적 모두의 `OnDeath` 이벤트 연결 → 양쪽 처치 시 문 잠금 해제

## 맵 (03_Maps)

- **Cat 전용 통로 / Crop 전용 활성화 경로** — Astalon의 캐릭터별 진입 구역처럼, 좁은 고양이 전용 환기구 통로(Cat만 통과)와 멀리 있는 레버를 Crop이 원거리로 맞춰야 열리는 문 분리. 구현 힌트: 환기구 콜라이더에 `Layer: Player` 만 통과 설정 + 레버 트리거에 `targetTag = "PlayerProjectile"` 조건

- **Huntdown식 폭발 연쇄 구역** — 방 안에 폭발 배럴 클러스터가 전략적으로 배치된 "도화선 방". Cat이 배럴을 타격하거나 적이 투사체를 맞으면 연쇄 폭발로 여러 적 일소 가능. 리스크: 잘못 건드리면 Cat도 피해. 구현 힌트: `Barrel` 오브젝트 `OnDeath` → `Physics2D.OverlapCircleAll` 연쇄 폭발

- **영구 해금 지름길** — Astalon의 Alucanum 구매 지름길처럼, 메타 진행에서 씨앗(화폐)으로 던전 내 지름길 문을 영구 해제. 새 런에서도 해당 지름길 활용 가능 → "반복 플레이가 점점 빨라지는" 경험. 구현 힌트: `MetaProgress.shortcutsUnlocked[]` 배열 → 씬 로드 시 지름길 문 자동 해제

## 전투 (04_Combat)

- **보스 취약점 전환 (Phase Shift)** — Huntdown의 3단계 패턴 + 취약점 설계 결합: 보스 HP 2/3에서 근접 → 원거리 취약점 전환. HP 1/3에서 양쪽 모두 취약 + 패턴 강화. 코옵에서 "지금은 내 차례다!" 모멘트 생성. 구현 힌트: `BossPhaseController`에 HP 임계값 → `currentWeakness` 변경 이벤트 발행

- **임시 무기 시너지** — Crop의 임시 무기와 Cat의 슬래시 조합 효과. 예: Cat이 얼음 씨앗으로 얼린 적을 슬래시하면 빙산 파편 스플래시. 구현 힌트: 피격 시 `StatusEffect.Frozen` 있으면 `OnMeleeHit`에서 추가 이펙트 + 범위 피해

- **Deflect-Chain 콤보** — Cat이 반사한 투사체를 Crop이 방패로 다시 받아 적에게 보내는 연계. 시각적으로 화려하고 코옵 소통의 상징적 장면. 구현 힌트: 반사된 투사체에 `bounceCount` 필드 추가, Crop 방패에 `bounceCount > 0` 투사체 재반사 로직

## 스토리 (05_Story)

- **Astalon식 캐릭터 관계 역전** — Astalon처럼 죽음 반복 속에서 두 캐릭터(Cat과 Crop)의 관계가 점점 드러나는 구조. Cat은 처음에 Crop을 짊어지는 게 불만이지만, 실패를 반복하며 서로 없으면 살아남지 못한다는 걸 깨달음. 대화 힌트는 런 시작/사망 시 짧은 대사로

- **폭발 이후 세계** — Huntdown의 80년대 SF 세계관처럼, OnionCat의 배경도 "대폭발 이후 독소로 가득 찬 땅"으로 구체화. 고양이와 식물은 독소 변이로 생긴 이종 생명체. 던전은 변이 생물들이 가득한 지하 연구소. 스토리상 정당성 강화

- **부활 의식의 대가** — Astalon에서 죽으면 입구로 돌아오는 것처럼, OnionCat에서 런 실패 시 "씨앗을 바쳐 다시 태어난다"는 서사적 설명. 영구 화폐(씨앗)가 단순한 게임 자원이 아닌 생명력 자체. 클리어할수록 씨앗이 감소하는 메카닉 고려

## 기술 메모

- **Unity Test Runner**: `PlayerStats.Modify()` 계산, `PoolManager` Spawn/Despawn, `RunData` 씨드 재현성 테스트 3개를 우선 작성할 것. 플레이 모드 테스트보다 Edit Mode 테스트가 훨씬 빠르므로 로직 검증은 Edit Mode 우선. Test Runner 창: `Window → General → Test Runner`

- **세이브 데이터 리셋**: 설정 메뉴에 "현재 런 포기"(1차 확인만)와 "전체 초기화"(이중 확인 필수) 두 가지로 분리. 전체 초기화 후 `Application.Quit()` 또는 씬 재로드가 안전. `Directory.Delete()` 전체 폴더 삭제 금지 → 특정 파일명 리스트로 관리. OnionCat은 플레이어 2인 공유 기기 시나리오 고려해 `_p1`/`_p2` 파일 분리 구조를 초반부터 설계할 것
