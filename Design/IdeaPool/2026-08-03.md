## 캐릭터 (01_Characters)

- **공유 HP = Onion 탄약 연동** — Revita의 HP=탄약 시스템 참고: Onion이 투사체를 발사할 때마다 공유 HP에서 소량(-1~2) 소모. Cat의 근접 공격 적중 시 HP 회복. "Onion이 많이 쏠수록 Cat이 더 활발히 싸워야 한다"는 협동 루프 강화. 구현: `SharedHPPool.TrySpendHP(cost)` → false면 발사 불가, `RestoreHP(amount)` Cat 적중 콜백.

- **과열 방지 콤보 리듬** — Revita의 밀리/원거리 교차 강제 참고: Onion 투사체 연속 5발 발사 시 "과열" 상태 → 1.5초 쿨타임 발생. 쿨타임 중 Cat이 근접 공격 적중하면 즉시 리셋. 두 플레이어가 자연스럽게 Cat→Onion→Cat 리듬을 형성. 구현: `OnionShooter` int `burstCount`, 5발 시 `StartCoroutine(Cooldown(1.5f))`, Cat 적중 이벤트로 StopCoroutine.

- **Revita식 대시 회복** — Revita의 대시+근접 = HP 회복 참고: Cat의 대시 중 근접 슬래시가 적중하면 일반 근접보다 HP 회복량 1.5배. "위험한 대시 공격 = 더 큰 보상"으로 공격적 플레이 유도. 구현: `CatMelee.OnHit()` → `isDashing ? SharedHP.RestoreHP(dashBonus) : SharedHP.RestoreHP(baseBonus)`.

## 적 (02_Enemies)

- **A\* 추적 근접형 적 (정원 지렁이)** — A\* 경로 탐색 참고: 벽 사이 좁은 통로를 정확하게 추적하는 지렁이 형태 적. NavMesh 없이 Tilemap 그리드로 Cat 위치까지 최단 경로 계산. Cat만 근접 공격으로 처치 가능 → 플레이어가 Cat을 앞세워야 함. 구현: `WormEnemy : EnemyAStarMover`, `repathInterval = 0.3f`, 근접 약점 설정.

- **거리 유지 원거리 적 (씨앗 발사 꽃)** — A\* 역방향 이동 참고: Onion만 처치 가능한 꽃 적. Cat이 가까이 다가오면 A\*로 최적 후퇴 경로 계산, 멀어지면 접근. 항상 일정 거리(4~6타일)를 유지하며 씨앗 탄막 발사. 협동으로 Cat이 접근을 차단하고 Onion이 처치. 구현: `FlowerEnemy`에 `minRange=3f, optimalRange=5f` + A\* 역경로 도망 로직.

- **코덱스 미등록 미스터리 적** — Lore Codex 해금 시스템 참고: 처음 등장 시 이름이 `???`로 표시되는 적. 처음 처치 후 코덱스에 항목 추가 + 약점 공개. 베스티어리 수집 동기 부여. 구현: `EnemyCodexEntry.isFirstKill = true` → `Die()` 시 `CodexManager.TryUnlock(codexId)`, UI 토스트 알림.

## 맵 (03_Maps)

- **A\* 그리드 실시간 업데이트** — A\* 경로 탐색 참고: 방 내 특정 이벤트로 벽이 생기거나 사라질 때(함정 발동, 문 열림), `PathGrid.BuildGrid()` 재호출로 경로 즉시 업데이트. 동적 장애물에 대응하는 적 AI. 구현: `RoomEvent.OnTrigger()` → `pathGrid.BuildGrid()` → 모든 적 A\* mover에 `forceRepath = true` 신호.

- **코덱스 해금 비밀방** — Lore Codex + 방 시스템 참고: 특정 조건(층 보스 첫 클리어 등)으로만 등장하는 "기억의 방". 입장 시 Cat과 Onion의 과거 스토리 코덱스 항목 1개 자동 해금 + 특수 아이템 1개. 구현: `SecretMemoryRoom` — `RunDataSO.bossFirstKills` 조건 체크, 입장 시 `CodexManager.TryUnlock("memory_01")`.

- **적 약점 지도 표시** — Lore Codex 약점 데이터 참고: 방에 처음 들어설 때 이미 코덱스에 등록된 적은 머리 위에 아이콘(⚔️ or 🌿)으로 약점 즉시 표시. 미등록 적은 `?` 아이콘. 코덱스 수집이 실질적인 전투 이득으로 연결. 구현: `EnemyInfoDisplay.cs` → `CodexManager.IsUnlocked(id)` 시 약점 스프라이트 활성화.

## 전투 (04_Combat)

- **Revita식 협동 블랭크 (공유 HP 소모형)** — Revita HP 희생 + Gungeon Blank 참고: Cat 대시 + Onion 방패 동시 발동 시 "공유 HP 10 소모" 대신 화면 내 모든 투사체 제거 + 근처 적 0.5초 스턴. "비용을 치르고 살아남는" 극한 협동 기술. 구현: `CoopBlankAbility` — 동시 입력 감지 후 `SharedHPPool.SpendHP(10)` 성공 시 발동.

- **A\* 경로 예측 선제 공격** — A\* 경로 탐색 참고: 적이 이동할 경로를 A\*로 예측, 그 경로 위에 Onion이 투사체를 미리 배치("선제 사격"). 구현보다는 디자인 아이디어 — 플레이어가 적 이동 경로를 읽고 예측 사격하는 플레이를 유도하려면 적 이동이 A\* 기반으로 예측 가능해야 함.

- **과열 상태 시각 연출** — Revita HP 관리 UI 참고: Onion이 과열 상태일 때 화분 테두리가 주황→빨강으로 점멸, 냉각 중엔 서서히 파란색으로. Cat 근접 적중 시 즉시 초록 플래시로 냉각 완료 알림. 구현: `OnionHeatUI.cs` — `Image.color` DOTween 루프, Cat 이벤트 연동 색상 전환.

## 스토리 (05_Story)

- **코덱스로 공개되는 Cat/Onion 관계** — Lore Codex 참고: 게임 첫 시작 시 Cat과 Onion의 첫 만남 기록만 코덱스에 해금. 층마다 보스를 처치하며 "왜 Cat이 Onion을 등에 업게 됐는가"의 단편이 순서대로 공개. 플레이 횟수 = 스토리 진행. 구현: `CodexEntry` "memory_01~05", `bossDefeatedFlags` 배열로 조건 관리.

- **Revita식 멜랑꼴리 분위기** — Revita 세계관 참고: Cat이 왜 이 정원(던전)을 헤매는지에 대한 무거운 배경. 코덱스 항목을 통해 단편적으로 공개 ("Cat은 한때 이 정원의 수호자였다"). 밝은 픽셀아트와 다크한 스토리의 대비가 몰입도 높임.

- **첫 코덱스 항목 튜토리얼 연동** — Lore Codex + Tutorial_System 참고: 게임 첫 번째 적 처치 시 코덱스 해금 알림 팝업 → "코덱스에 새 항목이 추가됐어요! [일시정지 → 코덱스]에서 확인하세요." 자연스럽게 코덱스 UI 위치를 학습. 구현: `TutorialManager`에 `codexFirstUnlock` 플래그, `CodexManager.OnUnlock` 이벤트 구독.

## 기술 메모

- **A\* 그리드 경로 탐색**: `PathGrid`는 방 생성 시 1회만 `BuildGrid()` 호출, 이후 문 열림/닫힘 시에만 부분 재생성. 적마다 `InvokeRepeating("UpdatePath", randomOffset, 0.5f)`로 탐색 시간 분산. Unity 2022 이상이면 `PriorityQueue<PathNode,int>` 사용해 `List.Sort()` 제거로 성능 향상. OnionCat 방 크기(~20×20 타일) 기준 탐색 시간 < 0.1ms로 충분히 빠름.
- **로어 코덱스 화면**: `CodexEntrySO` ScriptableObject 1개 = 항목 1개. 최소 구현은 TextMeshPro 스크롤뷰만으로 가능 (이미지 없이도 동작). 해금 ID는 `Save_Load_System.md`의 영구 데이터에 포함시켜 런 간 유지. 적 처치/아이템 획득 이벤트와 `CodexManager.TryUnlock(id)` 한 줄 연동만으로 수집 시스템 완성.
