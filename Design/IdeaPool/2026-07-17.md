## 캐릭터 (01_Characters)

- **파리 타이밍 시각화** — Chicory P2 브러시 조준 참고: Onion의 방패 파리 성공 가능 창을 조준 커서 주변에 흰 링으로 표시. 파리 타이밍이 어려운 초보도 시각적 단서로 배울 수 있음. 구현: `AnimationEvent` 연동 + UI 링 페이드 인/아웃
- **Cat 대시 방향 예고** — It Takes Two 역할 명확화 참고: Cat이 대시하기 0.2초 전에 이동 예정 경로를 반투명 점선으로 표시. Onion이 Cat의 다음 위치 예측해 탄막 배치 가능. 구현: `Rigidbody2D.MovePosition` 예정 경로 계산 후 `LineRenderer` 표시
- **공동 체력 게이지 시각화** — DDA 레이어 표현: Cat+Onion이 공유하는 화분 체력을 게이지로 표시하되, 체력이 낮을수록 화분 균열 스프라이트로 전환. 플레이어가 위기감을 직관적으로 느낌. 구현: ScriptableObject `SharedHealthState`에 체력 정도별 스프라이트 배열

## 적 (02_Enemies)

- **파리 거울 적 (Shield Mimic)** — Danmaku 반사탄 참고: Onion의 투사체만 흡수해 되돌려 보내는 원거리 전용 적. Cat의 근접 슬래시로만 처치 가능. "원거리 쓰지 말고 Cat 보내!" 소통 강제 유발. 구현: `OnTriggerEnter2D`에서 태그 검사 후 투사체 반사 방향 계산
- **탄막 분리 포탑 (Split Cannon)** — 나선형 탄막 패턴 참고: 사방으로 나선형 탄막을 쏘지만 Cat이 근접으로 한 번 쳐야 패턴이 멈추는 적. Cat이 탄막을 뚫고 달려들어야 하는 리스크. Onion이 뒤에서 Cat의 엄호 사격으로 경로 개척. 구현: `SpiralPattern` + Cat 히트 시 `StopAllCoroutines()`
- **유도탄 폭격기 (Homing Bomber)** — HomingBullet 참고: 1.5초간 플레이어를 추적하다 직선 폭발하는 유도탄 3~4개를 동시에 발사. Onion이 방패로 1개 막고, Cat이 나머지 피하는 협력 패턴. DDA: 고급 플레이어에겐 유도 시간 2초, 초보엔 1초로 조정. 구현: `HomingBullet.homingDuration` 을 `DifficultyController` 배율로 제어

## 맵 (03_Maps)

- **좁은 탄막 복도 방** — N-Way + 조준탄 조합 참고: 폭이 좁아 탄막 회피 공간이 극도로 제한된 방. 벽에 반사탄 기믹 추가 시 더욱 긴장감. Cat이 앞에서 탱킹 + Onion이 뒤에서 원거리 처치. 구현: Room 프리팹 중 "Narrow Corridor" 타입 추가, 반사탄 Wall 태그 별도
- **패리 연습 방 (안전 방)** — DDA + Chicory 튜토리얼 방 참고: 특정 층 첫 방에서 처치 불가 연습용 적이 느린 탄막을 패턴별로 쏴 줌. 파리 성공 시 보상 아이템. 실제 전투 전 몸 풀기. 구현: `SafeRoomFlag` 컴포넌트 → 사망 불가 + 보상 상자 확정 스폰
- **비밀 협력 방** — It Takes Two 공동 발견 참고: Cat+Onion이 동시에 특정 스위치를 밟으면 해금되는 숨겨진 방. 타이밍 맞추기 위해 자연스럽게 "3, 2, 1!" 카운트다운 발생. 구현: 두 `TriggerZone` 오브젝트 동시 활성화 체크 (`AND` 조건 0.5초 이내)

## 전투 (04_Combat)

- **협력 피니셔** — It Takes Two 보스 클라이맥스 참고: 보스 HP 10% 이하 시 "동시 공격" 프롬프트. Cat 슬래시 + Onion 차지샷 ±0.3초 이내 동시 입력 → 화면 채우는 협력 피니셔 연출. 단순히 마지막 공격이 아닌 두 플레이어의 호흡을 맞추는 감정적 클라이맥스. 구현: `CoopFinisherManager.CheckSimultaneousInput(cat, onion, 0.3f)` → `Cinemachine` 줌 이벤트
- **탄막 파리 → 반사 공격** — BouncingBullet 참고: Onion이 방패로 적 탄막 파리 성공 시 탄이 마우스 조준 방향으로 반사. "적의 탄막을 역이용해 다른 적 처치" 스킬 표현. 파리 후 반사탄은 적에게 2배 데미지. 구현: `OnParrySuccess()` 이벤트 → `BouncingBullet.Initialize(mouseDir, baseSpeed * 1.5f)`
- **DDA 유령 부활** — DDA 안전망 참고: 사망 5회 이상 누적 시 사망한 플레이어가 반투명 유령 상태로 유지. 파트너가 3초간 옆에 있으면 부활. 영구 사망 아니지만 긴장감은 유지. 구현: `GhostReviveSystem.OnDeath()` + `PerformanceTracker.deathCount >= 5` 조건 체크

## 스토리 (05_Story)

- **화분의 비밀** — Chicory 공유 몸통 구조 참고: 고양이와 파 식물이 왜 같은 화분을 공유하는지에 대한 스토리. "오래전 마법사의 실험으로 두 생명이 하나의 흙에 뿌리내려 함께 살아야 하는 저주". 협력 게임플레이에 서사적 정당성 부여.
- **파가 자라는 엔딩** — It Takes Two 감정 클라이맥스 참고: 던전 클리어 후 화분의 파 식물이 완전히 피어나는 장면. 고양이와 파의 유대가 완성되는 엔딩 연출. 런 중 파 식물의 성장 정도(아이템 수집량)가 엔딩 연출 길이에 영향. 구현: `SeedCountManager` 변수가 엔딩 컷씬 `Animator` 파라미터에 전달
- **보스가 주는 교훈** — 각 층 보스가 두 플레이어에게 "협력의 교훈"을 말하는 짧은 대사 한 줄. 예: "혼자선 강해도, 둘이서야 완전하지." DDA 작동 중일 때 보스 대사가 미묘하게 달라짐 ("이 정도도 못 하나? 아직 배울 것이 많구나").

## 기술 메모

- **탄막 패턴 시스템**: 코루틴 기반 `BossAttackSequencer`로 N-Way → 나선 → 조준탄 조합 패턴을 순서 제어하는 방식이 OnionCat 보스 구현에 가장 실용적. 핵심은 `DifficultyController.CurrentBulletSpeedMult`를 각 패턴의 `speed` 파라미터에 곱해주는 단 한 줄 연결.
- **동적 난이도 조정 시스템**: 구현 우선순위는 (1) `PerformanceTracker` 사망/방클리어 이벤트 연결 → (2) 적 체력 배율 ScriptableObject 3단계 → (3) 유령 부활 순서로 단계적 추가. 처음부터 복잡하게 만들 필요 없음. 사망 횟수 기반 단순 체력 배율만으로도 초보 보호 효과 충분.
