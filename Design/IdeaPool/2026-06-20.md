## 캐릭터 (01_Characters)

- **대시 캔슬 콤보** — Have a Nice Death 참고: P1(고양이)의 대시 중 공격 입력 시 콤보가 끊기지 않고 이어지는 "대시 캔슬" 구현. `CatAttack.cs`에서 `isDashing` 플래그 체크 → 대시 애니메이션 중단 없이 공격 phase 진행. 타격감과 조작 유연성 동시 향상.
- **공유 화폐 협의** — 30XX 참고: P1/P2가 방 클리어 후 상점에서 같은 골드 풀을 소비함. "내가 살게" vs "네가 사" 협의가 발생 → 자연스러운 소통 강제. `SharedResources.cs` 싱글턴으로 관리, 골드 변경 시 HUD에 `OnGoldChanged` 이벤트 발송.
- **긴급 조작 전환** — 30XX 부활 시스템 참고: P1이 기절 상태(보스 특수 공격 피격)에 빠지면 P2가 일시적으로 이동까지 제어하는 "긴급 모드" 발동. `IncapacitatedState`에서 `InputRouter.SetExclusiveControl(Player.P2)` 호출 → 5초 타이머 후 자동 복귀.

## 적 (02_Enemies)

- **페이즈별 경로탐색 전략 변경** — NavMesh + HaND 참고: 보스 페이즈 1에서는 A* 정확 추적, 페이즈 2에서는 직선 돌진(빠른 속도), 페이즈 3에서는 플로우 필드로 전 방향 포위. 페이즈 전환 시 `EnemyPathfinder.SetStrategy(strategy)` 호출로 깔끔하게 교체.
- **협동 필수 보스 패턴** — 30XX 벤치마크: 보스가 두 개의 발판을 동시에 밟아야 특수 방어막 해제. P1과 P2가 각자 다른 위치로 이동해야 함. 구현: 두 `PressurePlate` 오브젝트 모두 `isPressed` 시 `BossShield.Deactivate()` 호출.
- **방패 적 (앞면 무적)** — HaND 참고: 앞면 Collider는 `IgnoreLayer`로 P1 근접 공격 무시, 뒷면만 피격 가능. P2가 원거리로 뒤를 공격해 방패를 부수면 P1 근접 공격 가능. `EnemyWeakness.cs`의 `currentVulnerableAngle` 범위 체크로 구현.

## 맵 (03_Maps)

- **경로탐색 최적화 방 설계** — NavMesh 참고: 방마다 "적 경로탐색 그래프"를 별도 보유. 방 프리팹에 `RoomNavGraph` 컴포넌트 → 방 진입 시 `AstarPath.active.Scan()` 대신 미리 구운 그래프 로드. 씬 로딩 속도 개선.
- **비대칭 지형 방** — 30XX 참고: 한쪽은 고지대 플랫폼(P2 원거리 유리), 반대쪽은 밀집 통로(P1 근접 유리). 방 레이아웃 자체가 두 플레이어에게 각자 최적 위치를 제공 → "어디 서야 더 잘 싸울까" 판단 발생.
- **언어별 방 이름 표시** — 로컬라이제이션 참고: 방 이름(예: "어둠의 제단 / Altar of Darkness")을 String Table "RoomNames"로 관리. 방 진입 배너 텍스트가 자동으로 현재 언어로 출력. `LocalizedString`으로 간단 구현.

## 전투 (04_Combat)

- **히트스톱 + 어그로 콤보** — HaND 타격감 참고: P1 근접 공격 히트 시 0.08초 히트스톱 + P2의 카메라가 같은 방향으로 0.1초 흔들림. 두 플레이어 모두 타격 체감 공유 → 협동감 강화. `FeedbackSystem.cs`에서 `HitStopAllPlayers()` 호출.
- **동시 공격 연계 스킬** — 30XX 동시 기여 패턴 참고: P1 근접 공격 + P2 원거리 공격이 0.5초 내 동일 적에게 동시 명중 시 "협동 폭발" 발동 — 데미지 1.5배 + 이펙트. `CombatSynergy.cs`에서 최근 타격 시간 기록 후 체크.
- **적 경로탐색 조작 함정** — NavMesh 응용: 특정 방에 "함정 타일" 배치 → 적 A* 경로가 함정을 통과하도록 유도. P2가 원거리로 적을 함정 쪽으로 밀어내고 P1이 우회로 막는 전술 가능. NavMesh 가중치로 함정 타일 Penalty 낮게 설정.

## 스토리 (05_Story)

- **기업 부서장 보스** — HaND 기업 풍자 참고: OnionCat 세계관에서 악당 조직을 "농업 대기업"으로 설정. 각 층 보스는 "농약 과장", "비료 이사", "제초제 사장" 같은 직함. 유머러스한 보스 대사로 긴장 완화 + 세계관 매력 추가.
- **두 언어로 나누어진 편지** — 로컬라이제이션 참고: 게임 내 스토리 편지(Lore Item)를 수집하면, 언어 설정에 따라 한국어 버전/영어 버전이 다른 내용 포함 (서로 보완적 관점). 두 언어 유저 간 정보 공유 커뮤니티 형성 유도.
- **Ace & Nina → Cat & Onion** — 30XX 참고: 두 캐릭터가 각자 고유 과거를 가지는 서사 구조. P1(고양이)은 과거 혼자 싸우던 전사, P2(양파)는 평화를 원하는 식물 정령 → 억지로 한 몸이 된 후 갈등과 협동의 성장 서사. 짧은 런 종료 시 대화 한 줄씩 공개.

## 기술 메모

- **NavMesh & 2D 경로탐색**: 프로토타입은 직선 추적으로 시작하고, 방에 장애물(기둥/상자)이 필요해질 때 **A* Pathfinding Project** 무료 버전 도입. 핵심 코드는 `Seeker.StartPath()` + `OnPathComplete()` 콜백으로 0.5초마다 경로 재계산. OnionCat은 플레이어가 한 위치에 모여 있으므로 단일 추적 목표 처리로 충분.
- **로컬라이제이션 시스템**: 지금 당장 UI 텍스트를 하드코딩하지 말 것. 버튼/레이블에는 `LocalizedString` 사용 습관 들이기. String Table "UI_Strings" 하나에 메뉴/HUD/업그레이드 텍스트 통합 관리. 한국어 폰트는 **NotoSansKR**로 TMP Font Atlas 미리 생성해두기 (생성 시간 오래 걸림).
