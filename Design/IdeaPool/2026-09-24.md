## 캐릭터 (01_Characters)

- **협력 부활 — 들어 올리기** — Castle Crashers 참고: Cat이 쓰러지면 Onion이 솔로로 조종하며 부활 지점으로 유도 → 공유 바디 개념에 맞는 부활 연출 (Coop_Revival_System.md 심화 적용)
- **Onion 쉴드 파티 시각 피드백** — Sprite Depth Sorting 참고: 쉴드 활성 중 OnionSpriteRenderer에 빛나는 머티리얼 교체(`shieldMaterial`) → 양파가 번쩍이며 Cat을 보호하는 연출 강조
- **스탯 배분 간소화** — CC의 4스탯 시스템 참고: Cat(힘/속도), Onion(마력/방어) 각자 2스탯씩 갖고 레벨업마다 1포인트 배분 → 역할 정체성 유지하면서 빌드 다양성 생성

## 적 (02_Enemies)

- **마법 저항 슬라임 변종** — CC의 마법 저항 적 참고: 특정 슬라임이 근접 무적 + 원거리에만 반응 → 두 플레이어의 협력 강제 메카닉의 자연스러운 표현
- **방패병 적** — CC의 Knight계 적 참고: 정면에서 Onion 투사체를 막는 방패 보유 → Cat이 뒤로 돌아가야 하는 포지셔닝 강제, 2인 협력 퍼즐
- **군중 컨트롤러 적** — CC의 Necromancer 참고: 죽은 적을 부활시키거나 Cat을 잡아 이동 봉쇄 → Onion이 빠르게 처치해야 하는 긴박감 생성

## 맵 (03_Maps)

- **협력 잠금 문 방** — CC의 문 잠금 참고: Cat이 스위치를 누르는 동안 Onion이 적을 막는 구조의 방 → 물리적 협력이 필요한 특수 방 타입 아이디어
- **다이나믹 스프라이트 정렬 테스트 방** — 깊이 정렬 테스트: 여러 오브젝트가 겹치는 좁은 통로형 방에서 SortingGroup 동작 검증 → 아티팩트 없는 렌더링 보장
- **데모 전용 단축 맵** — Demo Build Config 참고: 첫 번째 바이옴만 포함한 3방 구성 미니 맵 + 미니 보스 방 → 15~25분 데모 플레이타임에 맞춤

## 전투 (04_Combat)

- **투사체 방향 오토에임 (상황적)** — CC의 화살 에임 참고: Onion이 조준 안 해도 가장 가까운 원거리 약점 적으로 약한 자동 조준 → 2인 플레이 시 Cat 조작에 집중하는 경우에도 Onion 기여 유지
- **파티 클리어 보너스** — CC의 협력 클리어 참고: 두 플레이어 모두 체력이 있는 상태로 방을 클리어하면 추가 골드/아이템 드롭 → 협력 생존 인센티브
- **하이퍼아머 임팩트** — CC의 Boss 강타 참고: 보스가 강타 시 히트스톱 + 화면 흔들림 + 양파가 화분에서 탈출할 뻔한 연출(파티클) → 타격감 극대화 아이디어

## 스토리 (05_Story)

- **동물 오브 수집** — CC의 동물 오브 시스템 참고: 각 방에 숨겨진 소동물이 있어 구출하면 화분에 같이 탑승 → 수집 동기 + 공유 바디 비주얼 확장
- **캐릭터 잠금 해제 스토리** — CC의 플레이어블 캐릭터 확장 참고: 특정 조건 달성(50회 파리 처치 등)으로 새 고양이 품종·양파 품종 잠금 해제 + 짧은 해제 연출
- **마을 NPC 귀환 서사** — CC 마을 주민 구출 구조 참고: 각 바이옴 보스를 처치하면 납치된 NPC가 허브 지역으로 귀환, 대화가 생김 → 세계 회복 서사 진행감

## 기술 메모

- **Sprite Depth Sorting**: OnionCat의 공유 바디에서 PlayerRoot에 `SortingGroup` 붙이고, `LateUpdate`에서 `sortingOrder = -y * 10` 갱신. 방향 전환은 `transform.localScale.x = -1` 대신 `SpriteRenderer.flipX`를 모든 파트에 일괄 적용해야 Collider 오동작 방지.
- **GameJam Demo Build**: `DEMO_BUILD` Scripting Define Symbol + `DemoGate.MAX_RUNS = 3`으로 콘텐츠 제한. Editor 메뉴 `Build/Build Demo`로 씬 목록과 심볼 자동 설정. 제출 직전 `Debug/Reset All Save Data`로 PlayerPrefs 초기화.
