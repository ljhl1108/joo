## 캐릭터 (01_Characters)

- **고양이 발소리 표면 구분** — Footstep Surface Sound 참고: 돌바닥(Stone) · 흙바닥(Dirt) · 잔디(Grass) 세 종류로만 나눠도 충분. `RoomFloor` 타일에 `surfaceType` 필드 추가 → `CatController` walk 애니메이션 `AnimationEvent`에서 `Sfx.Play(SfxId.FootXxx)`. 현재 발소리가 없으므로 1~2일 작업으로 체감 무게감이 크게 오름.
- **발소리 볼륨 위계** — Steel Assault 참고: 발소리는 전투음의 절반 이하 볼륨으로 조정. `SoundBank`에 `footVolume = 0.35f` 기준값 세팅 후 플레이테스트로 조절.
- **고양이 이동 마스터리 느낌** — Steel Assault 참고: 슬라이드·대쉬·점프 조합으로 적을 피하는 쾌감이 핵심. 고양이 대쉬 충전이 적의 텔레그래프를 읽고 맞춰 쓸 때 가장 재미있도록 → 적의 황색 텔레그래프 → 대쉬 타이밍 창이 충분히 넓은지 플레이테스트.

## 적 (02_Enemies)

- **적 텔레그래프 애니메이션 품질** — Steel Assault 참고: 적 공격 준비 프레임 수 = 텔레그래프 명확도. 황색 선이 뜨기 직전 1~2프레임 "웅크리기" 애니메이션이 있으면 더 자연스럽다. DirectionalSprite에 Idle→WindUp→Attack 세 태그로 구분 권장.
- **세트 시너지 임계점 설계** — Despot's Game 참고: 세트 2개(작은 보너스)·4개(강한 보너스) 구조가 명확한 목표를 만든다. 현재 OnionCat 세트 단계(`CombatModifiers.Has(세트, 단계)`)가 이 구조인지 확인 → 단계 1·2 보너스 차이가 체감될 만큼 큰지 `sets.csv`에서 점검.
- **적 종류와 "군단 조합"의 명확성** — Despot's Game 참고: 플레이어가 적 조합에서 패턴을 읽을 수 있어야 "어떤 세트가 이 방에 유리한가"를 판단할 수 있다. `EnemyRoster.squads` 조합표가 적 종류를 잘 섞어주는지, 같은 취약점(예: 얼음 취약)인 적 묶음이 충분히 나오는지 체크.

## 맵·런 구조 (03_Maps)

- **갈림길 아이콘 한 세트** — RunMap UI 참고: 현재 `MapScreen`에 방 종류 아이콘이 없을 경우 추가 필요. 최소 세트: 전투(칼)·보물(상자)·상점(돈주머니)·휴식(하트)·마을(등불). 한 번에 그릴 수 있는 간단한 16×16 픽셀 아이콘 5종. `TODO_Art.md`에 아트 요청으로 올려도 됨.
- **2P 선택 확인 UX** — RunMap 참고: 고양이와 양파가 동시에 버튼을 눌러야 선택이 확정되면 답답할 수 있다 → "한 명이 고르면 3초 타임아웃 후 자동 확정" 패턴이 현실적. `CoopInputLayout`의 협동 판정 로직 재사용 가능.
- **보상 미리보기 (보물·상점 방)** — Hades 맵 참고: 보물·상점 방 노드에 작은 아이콘으로 보상 종류를 미리 표시하면 갈림길 선택에 의미가 생긴다. 구현: 맵 생성 시 각 노드에 `rewardHint` 필드를 추가하고 아이콘을 겹쳐 표시. 복잡도는 낮고 재미 증가폭이 크다.

## 전투·협동 (04_Combat)

- **표면별 타격음 연계** — Footstep Surface Sound 참고: 발소리와 같은 `SurfaceType` 시스템으로 "흙바닥에서 슬라임 착지 → 둔탁한 소리, 돌바닥 → 딱딱한 소리"를 구현할 수 있다. `EnemyBase`의 착지 이벤트(날아온 적이 착지할 때)에서 `SurfaceType` 조회 → 적합한 SFX 재생.
- **세트 보너스 가시성** — Despot's Game 참고: 현재 세트 단계가 올라가는 시점에 명확한 피드백(HUD 플래시 + SFX)이 없으면 플레이어가 세트 의식을 못 한다. `PassiveHost.Recalculate` 후 단계가 오르면 `CoreHUD`에서 세트 아이콘 강조 + `Sfx.Play(SfxId.SetUnlock)`.
- **Steel Assault식 적 저지 타이밍** — Steel Assault 참고: 적 공격 직전 1프레임의 "풀 차지" 포즈가 플레이어에게 "지금 대쉬!" 반사 신호를 준다. `Enemy_Telegraph_System`과 연계하여 황색 선 사라지는 프레임 직전에 애니메이션 `WindUpPeak` 태그를 추가하는 것 고려.

## 아이템·세트 (05_Items)

- **세트 단계별 체감 차이 점검** — Despot's Game 참고: 세트 2개 보너스가 너무 약하면 "세트 의식"이 생기지 않는다. `sets.csv`에서 단계 1·2 보너스를 비교하고, 단계 1 보너스가 "조금 좋다"가 아니라 "체감된다" 수준인지 확인. 예: 태양 세트 1단계 = 공격력 +15%, 2단계 = 공격력 +35% + 불꽃 효과.
- **장비 미리보기 아이콘 개선** — Despot's Game 참고: 보상 선택 화면(`UpgradeSelectUI`)에서 현재 세트 진행도를 작은 점으로 표시 (예: ☆☆○○ → 태양 2/4). 플레이어가 "이거 고르면 세트 완성 임박"을 직관적으로 인식.
- **중복 장비 레벨업 한도 명시** — Despot's Game 중복 단위 시너지 참고: 같은 장비를 중복으로 얻을 때 레벨이 오른다 → 최대 레벨 도달 후 "완전 중복"을 씨앗으로 환전하는 UX가 명확해야 한다. 현재 `Dismantle` 로직이 충분히 가시적인지 체크.

## 스토리·메타 (07_StoryMeta)

- **마을 방 아이콘 디자인** — RunMap UI 참고: 마을 방(`StepKind.Village`)을 지도에서 한눈에 구분하려면 고유 아이콘(등불 또는 나무)이 필요. 현재 아트 요청 목록에 없으면 `TODO_Art.md`에 R-번호로 추가.
- **갈림길 선택 → 대사 연동** — Despot's Game 임의성 비판 참고: 갈림길에서 고른 방의 종류에 따라 "낡은 책"이 짧은 반응 대사를 치면 세계관이 살아있는 느낌 (예: 상점 방 선택 시 "씨앗을 아껴야 한다는 걸 모르진 않겠지?"). `StoryLines.cs`에 3~5줄 추가로 가능.
- **발소리로 분위기 강화** — Footstep 참고: 마을 방(나무 바닥)과 전투 방(흙·돌)의 발소리 차이가 장소 전환을 소리로도 알려준다. 등대탑(돌·메아리)은 `pitchVariance`를 더 넓게 설정하면 차갑고 울리는 느낌.

## 기술 메모

- **발소리·표면 사운드**: `SfxId`에 `FootStone` / `FootDirt` / `FootGrass` 세 가지 추가 → `Assets/Audio/SFX/` CC0 음원 준비 → `SoundBank` 재빌드 → `CatController` walk 프레임에 `AnimationEvent` 삽입으로 완성. 1일 이내 작업.
- **런 맵 갈림길 UI**: `RunMap.cs`·`MapScreen`이 이미 있으므로 추가할 것은 ① 방 종류 아이콘 스프라이트 ② 현재 위치 강조 ③ 연결선(LineRenderer 또는 UI Image) ④ 2P 선택 확인 UX. 우선순위: ①·② 먼저 넣고 ③·④는 플레이테스트 후.
