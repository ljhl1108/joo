## 캐릭터 (01_Characters)

- **작물별 "빛 색 연출 강화"** — Garden Story 참고: 각 작물의 고유 탄·스킬 연출을 색으로 더 선명하게 차별화. 양파=빨간 소용돌이, 해바라기=노란 빛줄기, 버섯=파란 포자. 관객이 한눈에 "지금 어떤 작물이냐"를 알아챌 수 있게. (`CropData.lightColor` → 탄 파티클 컬러에 반영)

- **고양이 야성 게이지 충전 시각 피드백** — We Need to Go Deeper의 "계기판" 아날로그 느낌 참고: 야성 게이지가 올라갈 때 고양이 발밑 `CatPips`에 불이 쌓이는 느낌 외에, 고양이 눈동자가 조금씩 광기를 띠는 연출. 발동 직전 1초간 짧은 경고 연출로 P2에게도 타이밍 전달.

- **P1/P2 역할 선언 효과음** — We Need to Go Deeper에서 "너 조종해, 나 쏠게" 외치는 소통 패턴 참고. 런 시작 시 첫 조작 버튼을 각자 누르면 짧은 "고양이 야옹 / 작물 흔들림" 사운드로 역할 확인 연출. 첫 협동감 형성에 효과적.

## 적 (02_Enemies)

- **내부/외부 위기 동시 발생 방 디자인** — We Need to Go Deeper 참고: 방에 들어가면 적이 두 그룹으로 나뉘어 하나는 고양이를 쫓고 하나는 P2(작물)를 직접 위협. 현재 P2는 이동 불가이므로 "화분에 올라타는 적" 아이디어. 화분에 붙으면 작물이 직접 떼어내야 (R 스킬 쿨다운 압박). 고양이도 근처에 오면 떼어낼 수 있음 → 협동 판단 발생.

- **계절 테마 변형 적** — Garden Story 참고: 스테이지 1(밀밭)에서 나오는 슬라임·방패병이 스테이지 3(해안)에선 외관과 행동이 약간 다른 버전으로 재등장. 같은 `ModularEnemy` 베이스에 이동 패턴 1개만 교체. `EnemyRoster.ResolveRoom`의 테마 교체 로직 활용.

- **공생 적(Symbiotic Enemy)** — 혼자서는 약하지만 쌍으로 붙어 있으면 강해지는 적. 한 마리가 쉴드를 만들고 다른 마리가 공격. 하나를 제거하면 나머지는 패닉 상태. We Need to Go Deeper의 "팀원 협력" 역설 참고: 플레이어가 역할을 나눠 동시에 각자 한 마리씩 처리해야 효율적. `EnemyBuilder`에 `symbiote` 특성 추가 고려.

## 맵·런 구조 (03_Maps)

- **그려진 방에 "입구 연출" 강화** — Garden Story의 계절별 등장 연출 참고: 방 입구에서 걸어 들어오는 `CatController.WalkIn` 애니메이션이 이미 있음. 보스방 입구에서는 조금 더 천천히, 화면이 어두워지다 밝아지는 1초 연출을 추가하면 "방 전환이 중요한 사건"임을 느끼게 함.

- **마을 방 계절 텍스처 교체** — Garden Story의 계절 순환 참고: `MetaProgress.Chapter` 1→4에 따라 마을 방 `Room_Special`의 배경을 교체. 1장=봄 꽃밭, 2장=여름 무성함, 3장=가을 낙엽, 4장=겨울 등대 빛. `StageArt.places` 텍스처 세트를 챕터 인덱스로 교체.

- **통로 방(Corridor Room)** — We Need to Go Deeper의 "이동 구간" 참고: 전투 없이 짧게 지나가는 좁은 통로 방. 일반 적은 없지만 함정·구덩이·이동 타일이 가득. 고양이가 먼저 뛰어가고 작물이 씨앗으로 함정을 처리하는 협동. 런 1개당 2~3개 삽입하면 전투 사이 긴장 완화 역할.

---

## 전투·협동 (04_Combat)

- **역할 비중 역전 보스 단계** — We Need to Go Deeper의 역할별 의존성 참고: 보스 1페이즈는 고양이 근접이 메인, 2페이즈에서 보스가 작물을 직접 타겟팅 → P2가 R 스킬 타이밍을 잡는 게 핵심이 됨. 양쪽이 각자 "내 차례"를 느끼게 하는 보스 설계. `ShadowWitch` 2페이즈 적용 가능.

- **공동 대응 기회창(Window)** — We Need to Go Deeper의 "동시 처리" 참고: 보스가 짧은 취약 상태를 열 때 고양이+작물이 동시에 타격해야 최대 피해. 고양이만 치면 50%, 작물만 치면 20%, 동시 타격이면 100%+보너스. 현재 협동 콤보 시스템(`Attacker.Cat/Onion`)을 확장. "함께 치라"는 명확한 UI 신호(노란 반짝임) 필요.

- **P2 긴급 지원 버튼** — We Need to Go Deeper에서 조종사가 위기 시 소리치는 패턴 참고. P2가 고양이 HP가 임계치 이하로 떨어지면 1회 무료 치유 씨앗을 발사할 수 있는 단축 버튼. 쿨타임 90초. P2가 "항상 보조할 수 있다"는 안도감 → 작물 플레이어의 긴장 완화.

## 아이템·세트 (05_Items)

- **공생 세트 (Symbiosis Set)** — We Need to Go Deeper의 역할 의존성 + Garden Story의 공동체 테마 참고. 고양이 장비 2개 + 작물 장비 2개가 같은 세트일 때 효과 발동: "고양이가 근접 공격 후 작물 다음 탄 강화 ×1.5". 양쪽 모두가 같은 세트 아이템을 갖춰야 발동 → 보상 선택 시 P1/P2 소통 필수. `PassiveSetBonus` 확장 — 고양이·작물 각각의 세트 개수 AND 조건.

- **계절 아이템 시리즈** — Garden Story의 계절 테마 참고. 봄(빠른 연사+치유), 여름(화염+광역), 가을(둔화+트랩), 겨울(관통+빙결) 세트. 같은 계절 장비 3개 이상이면 계절 세트 보너스. 현재 세트 체계(Sun, Wind…)에 추가로 계절 테마 세트 4종을 `ContentBuilder`에 등록.

- **복구 아이템 (Repair Kit)** — Garden Story의 "자원 → 복구" 흐름 참고. 아이템 슬롯 한 칸을 "소모품 복구 키트"로 — 방 클리어 후 HP 대신 방어막 1칸 회복 OR 대쉬 충전 2칸 즉시. 가방 아이템으로 분류. 쉬운 방에서 굳이 쓸 필요 없어 선택지가 생김.

## 스토리·메타 (07_StoryMeta)

- **마을 방문마다 달라지는 주민 대사** — Garden Story의 계절별 NPC 대사 변화 참고. 현재 `StoryLines.cs`의 책·고양이 대사에 더해, 마을 방에 등장하는 단역 NPC(토끼, 버섯, 도라지 같은 작물 주민들)가 챕터 진행에 따라 한두 마디씩 바꿈. "빛이 조금 더 밝아졌어요" / "어제 밀밭에서 이상한 소리가…" 등. `Dialogue.Play` 호출, `MetaProgress.Chapter` 분기.

- **등대탑 복구 시각적 변화** — Garden Story의 "복구가 보이는 세계" 참고. 각 챕터 클리어 후 등대탑 방의 배경이 조금씩 바뀜: 1→금이 간 창문, 2→창문 수리됨, 3→등대 불빛 깜박임, 4→환하게 켜짐. `RoomArt.Apply` 또는 `PaintedRoomView`에 챕터 인덱스별 오버레이 그림 교체.

- **"함께 이겨낸" 엔딩 연출** — We Need to Go Deeper의 팀 생존 카타르시스 참고. 최종 보스 처치 후 고양이+작물이 화면 가운데 모여 짧은 합동 승리 연출(작물이 고양이 등에서 활짝 핌). 현재 `Ending_Clear_Presentation` 범주. P1·P2 모두 버튼을 눌러야 다음으로 넘어가는 연출로 "둘이 같이 끝냈다"는 감각 강조.

## 기술 메모

- **Unity Sprite Shape**: OnionCat의 절차 생성 곡선 벽과 직접 경쟁하지 않음 — 그려진 방의 판정 경계를 아티스트가 에디터에서 미세 조정할 때 Sprite Shape가 유용. `PaintedRoomImporter.Soften`이 충분하지 않은 복잡한 모서리를 에디터에서 직접 다듬는 용도. `com.unity.2d.spriteshape` 패키지 추가 후 `PolygonCollider2D` 생성 옵션으로 현재 코드와 혼용 가능.

- **멀미 방지 접근성**: `HitFeelSettings.asset`의 흔들림 수치에 `AccessibilitySettings.ScreenShakeIntensity` 배율(0.0~1.0)을 곱하는 방식이 가장 안전. PlayerPrefs에 저장, 일시정지 메뉴에서 즉시 적용. 2인 중 한 명이 민감한 경우를 위한 힌트 문구("더 민감한 플레이어 기준으로 설정") UI에 추가.
