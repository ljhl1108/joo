# 게임 데이터 표 (공용 문서)

사람과 Claude가 **같이 고치는 표**. 표(CSV)가 원본이고, 그림과 함께 보는 화면(HTML)은 표에서 자동으로 만든다.

| 파일 | 내용 |
|---|---|
| `enemies.csv` | 적·보스·엘리트 (2026-10-18~) |
| `items.csv` | 장비·마법서(스킬)·패시브 + 보류된 아이디어 (2026-10-18~) |
| `sets.csv` | 세트 10개 × 2/4/6/8세트 보너스 |
| `cats.csv` · `cat_weapons.csv` | 고양이 종류 (특성·야성 게이지) + 고양이마다 전용 무기·특수 공격 (2026-10-18~, 아이디어) |
| `crops.csv` · `crop_seeds.csv` | 작물 종류 (특성·전용 스킬 R) + 작물마다 전용 씨앗 (R 강화) (2026-10-18~, 아이디어) |
| `stages.csv` | 스테이지 6개 — 순서·해금·보스·분위기·타일 요구사항·**타일/소품 프롬프트** (2026-10-18~) |
| `style.csv` | 그림 종류별 **공통 프롬프트** (적·보스·아이콘·타일·소품) — 한 번 고치면 모든 프롬프트에 반영 |
| `build_viewer.py` · `뷰어_갱신.bat` | 표 → `도감.html` (탭: 스테이지 / 고양이 / 작물 / 적 / 아이템, 그림 + 바뀐 칸 표시). HTML은 git에 안 올림 |
| (예정) `cats.csv` · `crops.csv` | 고양이·작물 |

## 쓰는 법

1. `enemies.csv` / `items.csv` / `sets.csv`를 엑셀로 열어서 고친다
2. 저장할 때 **"CSV UTF-8(쉼표로 분리)"** 형식으로 (그냥 "CSV"로 저장하면 한글이 깨짐)
3. `뷰어_갱신.bat` 더블클릭 → 브라우저에 도감이 열린다
   - **마지막 커밋 이후 바뀐 칸은 노란색**, 새 줄은 "새로 추가", 지운 ID는 맨 아래에
   - 위쪽 버튼: 스테이지별 · 바뀐 것만 · 요청 있는 것만 · 검색
4. Claude에게 "표 고쳤어"라고 하면 바뀐 내용을 보고 게임에 반영한다

## 열 설명

| 열 | 쓰는 법 |
|---|---|
| ID | 바꾸지 말 것 (Claude가 이걸로 찾음). 공통 `C01` · 스테이지 `S1-1` · 소환 `X01` · 보스 `B1` · 엘리트 `E1`. 새 적은 빈 번호로 |
| 상태 | `아이디어` · `구현` · `컨펌` · `보류` — 확인했으면 `컨펌`으로 바꿔 주세요 |
| 위험도 | 1~3. 방 난이도+1까지만 나온다 |
| 체력 · 속도 | 숫자. 바꾸면 Claude가 게임에 반영. 체력은 **게임 안 최종값** (2026-10-22 기준선: 코드 표 ×5, 소환물·보스 ×3) |
| 움직임 · 공격 · 특성 · 설명 | 자유롭게 글로. 🔴 = 피해야 하는 공격 / 🟡 = 양파가 막을 수 있는 탄 |
| 역할 | `고양이` · `양파` · `협동` — 누가 상대하기 편한지 |
| 도형 · 색 · 크기 | 그림이 없을 때의 임시 모양 (도형: Blob · Bug · Circle · Diamond · Star · Tall · Triangle · Square). **크기는 4등급만**: 작음 0.5 · 보통 0.6 · 큼 0.75 · 보스 1.1 (고양이 그림 ≈ 0.8×0.94) |
| 그림 | 정식 그림이 생기면 유니티 `Assets` 기준 경로 (예: `Sprite/Enemies/Bee.png`). 비우면 도형으로 |
| 프리팹 | 유니티 프리팹 이름 — 바꾸지 말 것 |
| 메모 | 참고 게임·아이디어 등 아무거나 |
| **요청** | **Claude에게 바라는 것을 말로** (예: "갑옷 3번으로", "이거 빼기"). Claude가 반영하고 비운다 |

## 아이템 표 열 (`items.csv`)

| 열 | 쓰는 법 |
|---|---|
| ID | 바꾸지 말 것. 아직 없는 아이디어는 `IDEA_` + 번호 (새 아이디어도 이렇게) |
| 주인 | `고양이` · `양파` · `공용`(고른 사람 것) |
| 부위 | 무기 · 머리 · 몸 · 발 · 장신구 (고양이) / 무기 · 마법서 · 화분 (양파) / 패시브 |
| 등급 | 일반 · 희귀 · 에픽 · 전설 |
| 세트 | 세트 이름 또는 `없음` — 세트 보너스는 `sets.csv` |
| 효과 이름 · 효과 | 장비에 붙은 효과 (분해하면 효과 목록에 남아 다른 장비에 끼울 수 있음) |
| 능력치(Lv1) | 레벨 1 기본 능력치 — 레벨마다 같은 만큼 더 붙는다 |
| 스킬 · 스킬 설명 | 마법서만. 할퀴기는 고양이 무기만 |
| 상태 | `구현` · `보류`(아직 못 만듦, 사유는 메모) · `아이디어` · `컨펌` |
| 아이콘 · 에셋 | 유니티 경로·에셋 이름 — 바꾸지 말 것 (아이콘은 그림이 생기면 경로만 바꾸기) |

`sets.csv`는 한 줄 = 세트 하나의 한 단계 (ID `Sun2` = 햇살 2세트). 도감에서는 세트 묶음 맨 위에 나온다.

## 그림 프롬프트 (AI 그림 요청)

- 적·아이템 표의 **`그림 프롬프트`** 열 = 그 그림만의 내용 (영어). 스테이지 표는 `타일 프롬프트`·`소품 프롬프트`
- 도감 카드의 **"프롬프트 복사"** 버튼 = `style.csv`의 공통 앞부분 + 그 내용을 합쳐서 복사 → AI 그림 도구에 붙여 넣기
- 그림 크기·규칙은 `style.csv`의 `크기`·`메모` 열 (적 32×32, 보스 64×64, 아이콘 32×32, 타일 32×32)
- 다 만든 그림은 유니티 폴더에 넣고 `그림`(적) / `아이콘`(아이템) 열에 경로를 적으면 도감에 바로 보인다. 타일은 `Guides/tileset_request.md`

## 주의

- 엑셀이 `1-2` 같은 값을 날짜로 바꾸므로 ID는 글자로 시작하게 (`S1-2`)
- 셀 병합·색칠은 CSV에 저장되지 않는다 (꾸미기는 HTML이 함)
- Claude가 표를 고치는 동안에는 엑셀을 닫아 두기 (파일 잠김)
- 구매 에셋 그림(SPUM·Cainos 등)은 이 저장소로 복사하지 않는다 — HTML이 유니티 폴더의 그림을 경로로만 불러온다 (그래서 이 PC에서만 보임)
