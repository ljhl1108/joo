# 게임 데이터 표 (공용 문서)

> 사람과 Claude가 **같이 고치는 표**. 표(CSV)가 원본이고, 그림과 함께 보는 화면(HTML)은 표에서 자동으로 만든다.
> 기준 2026-11-08 · 설계 문서(`Design/01~08`)의 목록은 이 표를 읽기 좋게 옮긴 것 — 어긋나면 표가 맞다

| 파일 | 내용 |
|---|---|
| `enemies.csv` | 적·보스·엘리트 (2026-10-18~) |
| `items.csv` | 장비·마법서(스킬)·패시브 + 보류된 아이디어 (2026-10-18~) |
| `sets.csv` | 세트 10개 × 2/4/6/8세트 보너스 |
| `cats.csv` · `cat_weapons.csv` | 고양이 종류 (특성·야성 게이지) + 고양이마다 전용 무기·특수 공격 (2026-10-18~, 아이디어) |
| `crops.csv` · `crop_seeds.csv` | 작물 종류 (특성·전용 스킬 R) + 작물마다 전용 씨앗 (R 강화) (2026-10-18~, 아이디어) |
| `stages.csv` | 스테이지 6개 — 순서·해금·보스·분위기·타일 요구사항·**타일/소품 프롬프트** (2026-10-18~) |
| `backgrounds.csv` | **배경 요청** — 스테이지마다 겹별로 그릴 것 (바닥·벽 시트 · 바닥 장식 · 방 바깥 · 소품 · 문) + 고정 장소 큰 그림 (2026-11-08~, 아래 "배경 표") |
| `style.csv` | 그림 종류별 **공통 프롬프트** (적·보스·아이콘·타일·장식·방 바깥·소품) — 한 번 고치면 모든 프롬프트에 반영 |
| `build_viewer.py` · `뷰어_갱신.bat` | 표 → `도감.html` (탭: 스테이지 / 배경 / 고양이 / 작물 / 적 / 아이템, 그림 + 바뀐 칸 표시). HTML은 git에 안 올림 |

## 쓰는 법

1. `enemies.csv` / `items.csv` / `sets.csv`를 엑셀로 열어서 고친다
2. 저장할 때 **"CSV UTF-8(쉼표로 분리)"** 형식으로 (그냥 "CSV"로 저장하면 한글이 깨짐)
3. `뷰어_갱신.bat` 더블클릭 → 브라우저에 도감이 열린다
   - **마지막 커밋 이후 바뀐 칸은 노란색**, 새 줄은 "새로 추가", 지운 ID는 맨 아래에
   - 위쪽 버튼: 스테이지별 · 바뀐 것만 · 요청 있는 것만 · 검색
4. Claude에게 "표 고쳤어"라고 하면 바뀐 내용을 보고 게임에 반영한다

## 열 설명

| 열 | 쓰는 법 |
|---|---|
| ID | 바꾸지 말 것 (Claude가 이걸로 찾음). 공통 `C01` · 스테이지 `S1-1` · 소환 `X01` · 보스 `B1` · 엘리트 `E1`. 새 적은 빈 번호로 (**한 번 쓴 번호는 다시 쓰지 않는다**) |
| ID 접두어 | **임시 `TMP-`** = 지금 게임에서 쓰지만 교체할 것 (예: `TMP-B1` 영웅 기사) · **폐기 `OLD-`** = 안 쓰기로 한 것 — 지우지 않고 기록으로 (예: `OLD-B4` 눈 여왕). 원래 번호를 붙여 두어서 아트 폴더(`B1` 등)와 이어진다. 도감에서는 맨 아래 "임시·폐기" 묶음 |
| 상태 | `아이디어` · `구현` · `컨펌` · `보류` · `임시` · `폐기` — 확인했으면 `컨펌`으로 바꿔 주세요 |
| 위험도 | 1~3. 방 난이도+1까지만 나온다 |
| 체력 · 속도 | 숫자. 바꾸면 Claude가 게임에 반영. 체력은 **게임 안 최종값** (2026-10-22 기준선: 코드 표 ×5, 소환물·보스 ×3) |
| 움직임 · 공격 · 특성 · 설명 | 자유롭게 글로. 🔴 = 피해야 하는 공격 / 🟡 = 양파가 막을 수 있는 탄 |
| 역할 | `고양이` · `양파` · `협동` — 누가 상대하기 편한지 |
| 도형 · 색 · 크기 | 그림이 없을 때의 임시 모양 (도형: Blob · Bug · Circle · Diamond · Star · Tall · Triangle · Square). **크기는 4등급만**: 작음 0.5 · 보통 0.6 · 큼 0.75 · 보스 1.1 → 아트 그림 높이 = 크기 × 120px (작음 60 · 보통 72 · 큼 90 · 보스 132px, 고양이 약 86px — `Art/Final`) |
| 그림 | 정식 그림이 생기면 유니티 `Assets` 기준 경로 (예: `Sprite/Enemies/Bee.png`). 비우면 도형으로 |
| 프리팹 | 유니티 프리팹 이름 — 바꾸지 말 것 |
| 메모 | 참고 게임·아이디어 등 아무거나 |
| **요청** | **Claude에게 바라는 것을 말로** (예: "갑옷 3번으로", "이거 빼기"). Claude가 반영하고 비운다 |

## 아이템 표 열 (`items.csv`)

| 열 | 쓰는 법 |
|---|---|
| ID | 바꾸지 말 것. 아직 없는 아이디어는 `IDEA_` + 번호 (새 아이디어도 이렇게) |
| 주인 | `고양이` · `양파` · `공용`(고른 사람 것) |
| 부위 | 무기 · 머리 · 몸 · 발 · 장신구 (고양이) / 무기 · 마법서 · 화분 (양파) / 패시브 |
| 등급 | 일반 · 희귀 · 에픽 · 전설 |
| 세트 | 세트 이름 또는 `없음` — 세트 보너스는 `sets.csv` |
| 효과 이름 · 효과 | 장비에 붙은 효과 (분해하면 효과 목록에 남아 다른 장비에 끼울 수 있음) |
| 능력치(Lv1) | 레벨 1 기본 능력치 — 레벨마다 같은 만큼 더 붙는다 |
| 스킬 · 스킬 설명 | 마법서만. 할퀴기는 고양이 무기만 |
| 해금 | 온실에서 기억 파편으로 해금하는 가격 (`파편 2`). **빈칸 = 처음부터 보상에 나옴**. 바꾸면 Claude가 `GreenhouseBuilder.cs`에 반영 |
| 상태 | `구현` · `보류`(아직 못 만듦, 사유는 메모) · `아이디어` · `컨펌` |
| 아이콘 · 에셋 | 유니티 경로·에셋 이름 — 바꾸지 말 것 (아이콘은 그림이 생기면 경로만 바꾸기) |

`sets.csv`는 한 줄 = 세트 하나의 한 단계 (ID `Sun2` = 햇살 2세트). 도감에서는 세트 묶음 맨 위에 나온다.

## 배경 표 (`backgrounds.csv`)

배경은 **한 장짜리 그림이 아니라 겹을 쌓는다** (방 모양이 글자 지도로 바뀌고, 방을 스테이지마다 다시 쓰기 때문). 시점은 **사선 탑다운** (2026-11-07 결정).

```
⑥ 분위기    빛 · 안개 · 날리는 이삭               ← Claude (조명·파티클) — 그림 거의 없음
⑤ 소품      수레 · 상자 · 물뿌리개 · 등불 기둥     ← 하나씩 배치, 발 높이로 앞뒤 정렬
④ 벽·담     돌담 · 울타리 · 출구 문                ← 타일, 충돌 있음 (글자 지도 W·X 자리에 자동)
③ 바닥 장식 꽃 · 돌멩이 · 흙 얼룩 · 낙엽            ← 방에 들어갈 때마다 무작위로 흩뿌림 (게임 코드 준비됨)
② 바닥      잔디 · 흙길                            ← 이어지는 타일
① 방 바깥   방을 둘러싼 밀밭 · 덤불 · 어둠          ← 채우기 타일
```

| 열 | 쓰는 법 |
|---|---|
| ID | `BG-<스테이지>-<종류>` (SHEET 바닥·벽 시트 · DECAL 장식 · OUT 방 바깥 · PROP 소품 · DOOR 문) · 고정 장소 `BG-FARM` 등 |
| 겹 | 위 그림의 ①~⑤ |
| 크기 · 개수 | 그림 한 장의 크기 · 몇 개 그릴지 |
| 내용 | 무엇을 그리나 (스테이지 표에서 옮김) |
| 스타일 · 그림 프롬프트 | `style.csv`의 공통 앞부분(스타일 ID) + 이 그림만의 내용 → 도감 "프롬프트 복사" |
| 상태 | `요청` · `초안` · `완성` · `게임 적용` · `임시 (…)` · `아이디어` |
| 파일 | 다 그린 그림의 경로 (예: `Art/Final/Backgrounds/ST1/BG-ST1-SHEET`) |

**공통 규격**
- 한 칸 = **64×64 px** (2026-11-08 — 캐릭터 그림과 같은 픽셀 밀도. 고양이 약 86px ≈ 1.3칸, 보통 적 72px ≈ 1.1칸) ✅ 게임 적용
- 화면 1920×1080 → 가로 30칸 × 세로 17칸
- 방은 고양이보다 칸이 작아지므로 **통로는 2칸 이상**
- 방은 **돌리지 않은 네모** — 벽·담이 화면에 가로·세로로 뻗는다 (아이소메트릭 마름모 ✗). 벽은 윗면 + 앞면이 보이고, **아래쪽(앞쪽) 벽은 낮게** (캐릭터를 가리지 않게)
- 바닥 위 원형 예고·장판은 납작하게 그리지 않는다 (게임 판정이 원)
- **모든 그림은 같은 픽셀 크기로** · 바닥 대비는 캐릭터보다 한 단계 낮게 · 빨강·노랑 큰 면적은 피하기 (적 공격 예고 색)
- AI 그림이 칸에 딱 맞지 않아도 괜찮다 — 큰 그림으로 주면 Claude가 잘라서 칸에 맞춘다
- 다 만든 그림은 `Art/Final/Backgrounds/<스테이지ID>/` (시트는 `layout.json`, 낱장은 `manifest.json`과 함께) → 유니티 메뉴 **OnionCat > Art > Import Backgrounds**가 잘라서 연결

**바닥·벽 타일 시트 칸 배치** (`BG-*-SHEET`, 가로 8칸 · 64px 격자 = 512×512)

```
열→   0        1        2        3        4        5        6        7
행0  바닥     바닥2    바닥3    바닥4    (비움)   (비움)   특수1    특수2     ← 바닥 변형 4장 (특수 = 물·빙판 등)
행1  벽┌     벽─위    벽┐      벽─위2   안쪽┘    안쪽└                       ← 바깥 벽 윗줄 (앞면이 보임)
행2  벽│왼   (비움)   벽│오            안쪽┐    안쪽┌                       ← 바깥 벽 옆
행3  벽└     벽─아래  벽┘                                                  ← 바깥 벽 아랫줄 (낮게 — 얇은 윗면만)
행4  덩어리 윗테 왼·가운데·오른   (비움)   구덩이┌  구덩이─  구덩이┐
행5  덩어리 몸통 왼·가운데·오른   (비움)   구덩이│  구덩이■  구덩이│     ← 가운데(Block_1_1)는 지금 없음 — 넣어 주면 좋음
행6  덩어리 앞면 왼·가운데·오른   (비움)   구덩이└  구덩이─  구덩이┘
행7  덩어리 밑단 왼·가운데·오른
```
- 바닥은 이어 붙여도 이음새가 안 보이게 (seamless). 반복 티는 ③ 장식이 덮어 준다 → 바닥 자체는 차분하게
- "안쪽" 4장은 ㄱ자 방처럼 꺾인 곳 · 덩어리(방 안의 솟은 벽 `X`)는 9칸 + 앞면 줄 · 구덩이는 가장자리 8 + 가운데 1

**고정 장소** (농장·마을·등대 입구·등대탑)는 한 장으로 그려도 된다 — 서 있는 물체(나무·집·등대)는 앞뒤 정렬 때문에 따로 떼어 주기. 충돌은 Claude가 맞춘다.

## 그림 프롬프트 (AI 그림 요청)

- 적·아이템 표의 **`그림 프롬프트`** 열 = 그 그림만의 내용 (영어). 스테이지 표는 `타일 프롬프트`·`소품 프롬프트`
- 도감 카드의 **"프롬프트 복사"** 버튼 = `style.csv`의 공통 앞부분 + 그 내용을 합쳐서 복사 → AI 그림 도구에 붙여 넣기
- 그림 크기·규칙은 `style.csv`의 `크기`·`메모` 열 (적 128×128 칸 · 보스 192×192 칸 · 고양이·작물 128×128 칸, 4방향 SW·SE·NW·NE · 타일 64×64 · 아이콘 32×32는 UI용). 줄마다의 프롬프트에는 크기·방향을 쓰지 않는다 (style.csv가 맡음)
- 다 만든 그림은 유니티 폴더에 넣고 `그림`(적) / `아이콘`(아이템) / `파일`(배경) 열에 경로를 적으면 도감에 바로 보인다

## 주의

- 엑셀이 `1-2` 같은 값을 날짜로 바꾸므로 ID는 글자로 시작하게 (`S1-2`)
- 셀 병합·색칠은 CSV에 저장되지 않는다 (꾸미기는 HTML이 함)
- Claude가 표를 고치는 동안에는 엑셀을 닫아 두기 (파일 잠김)
- 구매 에셋 그림(SPUM·Cainos 등)은 이 저장소로 복사하지 않는다 — HTML이 유니티 폴더의 그림을 경로로만 불러온다 (그래서 이 PC에서만 보임)
