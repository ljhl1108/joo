## 1. 전투 원칙

[GameConcept](../GameConcept.md) 핵심 원칙의 전투 쪽 풀이.

| # | 원칙 | 게임에서 |
|---|---|---|
| 1 | 실수 한 번에 판이 끝나지 않는다 | 공유 체력 100, 패시브 실드가 한 대를 통째로 막음. 단, 계속 맞으면 분명히 죽는다 |
| 2 | 시원시원하다 | 히트스톱 · 넉백 · 흔들림 · 데미지 숫자 · 튕겨 나가는 사망 |
| 3 | 공격은 반드시 예고된다 | 🟡 막기 / 🔴 피하기, 예고가 시작되면 확정 ([02_Enemies](02_Enemies.md) 1장) |
| 4 | 패링·실드는 보조 | 몰라도 깰 수 있다. 패링을 전제로 한 설계는 "잘하면 보너스"로만 |
| 5 | 협동은 "잘하면 더 좋다" | "못하면 손해"로 만들지 않는다 |

### 타격감 원칙 ✅

- **너그러운 판정** — 할퀴기는 그림보다 약간 넓게, 고양이 피격 판정은 그림보다 작게
- **히트스톱은 맞은 적만 멈춘다** (전역 시간 정지 ✗) → 다른 플레이어의 흐름을 끊지 않음
- 넉백은 공격이 날아온 방향으로 즉시. 보스·방패병은 덜 밀림
- 멀미 옵션 — 화면 흔들림 슬라이더 ✅ · 색약·자막 📝

## 2. 협동 장치

| 장치 | 무엇 | 상태 |
|---|---|---|
| 협동 콤보 | 고양이·작물 공격이 **1초 안에 번갈아** 같은 적에 맞으면 ×1.5 ("누가 때렸나" 기준) | ✅ |
| 합동 게이지 | 협동 콤보 · 패링 · 2인 기믹이 채움. 한쪽만 때리면 거의 안 참 | ✅ |
| 합동기 | 게이지가 차면 둘이 1.5초 안에 각자 버튼 (ARCHONS식) | ✅ 1종 |
| 같이 모으는 세트 | 세트 단계 = 고양이 장비 효과 + 작물 장비 효과 합산 ([05_Items](05_Items.md) 3장) | ✅ |
| 공유 가방 | 가방은 하나, 누가 쓰든 같은 가방에서 빠짐 | ✅ |
| 패리 마크 | 패링 → 적에게 마크 → 고양이가 할퀴면 폭발 | 📝 |
| 2인 기믹 | 둘이 해야 풀리는 방 (3장) | ✅ 1종 |

### 합동기

- 한쪽이 먼저 누르면 "상대를 기다리는 중", 늦어도 게이지는 유지 (실수에 관대하게)
- 지금 1종 — ONION STORM
- 📝 **합동기 종류 = 작물 × 가장 많이 모은 세트** — 처음엔 작물별 1개, 세트 조합은 나중에

  | | ☀️ 햇살 | 🍃 바람 | 🌧️ 빗물 | 🪨 흙 |
  |---|---|---|---|---|
  | 🧅 양파 | 매운 불꽃 회오리 | 매운 태풍 | 최루 폭우 | 양파 지뢰밭 |
  | 🌻 해바라기 · 🍄 버섯 | … | … | … | … |

- 📝 발동 중 잠깐 무적 + 연출 (컷인 또는 줌인)
- 📝 최종전에서는 합동기가 마녀의 마법으로 ([07_StoryMeta](07_StoryMeta.md))

### 같이 모으는 세트 — 왜

"너 햇살 골라, 나도 햇살 고를게" — 서로의 보상 선택에 참견하게 만드는 장치.

### 공유 가방

- 소모품 전용 (장비와 별개). 고양이가 지나가면 자동으로 줍고, 작물은 클릭으로도 주움
- "그거 지금 내가 쓸게!" 같은 대화가 목적
- 📝 소모품 종류 추가 (지금 3종)

### 패리 마크 📝

- 작물 패링 성공 → 적에게 3초 마크 → 고양이가 마크된 적을 할퀴면 폭발 + 추가 피해
- 원칙 4에 따라 **보너스로만**. 패링 없이도 모든 적·보스를 잡을 수 있어야 한다
