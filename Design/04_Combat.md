# 전투 시스템

## 공격

### 고양이 (근접)
| 종류 | 설명 | 상태 |
|------|------|------|
| 할퀴기 | 180° 부채꼴, 쿨다운 0.2초 | 구현 완료 |
| 찌르기 | 직선 관통 (MeleeAttack_Stab) | 미구현 |
| 회전 | 360° 스핀 (MeleeAttack_Spin) | 미구현 |

### 양파 (원거리)
| 종류 | 설명 | 상태 |
|------|------|------|
| 투사체 | 마우스 방향 발사 | 구현 완료 |
| 액티브 실드 | 방향 차단 + 패링 (0.2~0.3초) | 구현 완료 |
| 충전 샷 | 마우스 버튼 길게 누르면 크기 3배·데미지 5배 대형 씨앗 발사. 충전 중 방향 전환 불가 → Cat이 Crop 보호 협력 필요 | 미구현 |
| 탄약 유형 전환 | 직선 관통탄·폭발탄·표준탄 3종 전환. `ProjectileType` enum으로 관리 | 미설계 |

## 회피
- 고양이 대쉬: 직선 돌진 + 무적 (구현 완료)
- 패시브 실드: 피격 시 쉴드 우선 소모 (구현 완료)
- 피격 무적: 1.5초 (구현 완료)
- **패리 시너지 버프** (Dead Cells 참고): 양파 패리 성공 시 고양이의 다음 근접 공격 1.5배. 화면에 금빛 플래시로 시각 피드백. 두 플레이어 타이밍 협동의 짜릿함

## 성장 방식 (미설계)

### 런 내 성장
- 방 클리어 보상으로 **업그레이드 선택** (Hades 스타일)
- 업그레이드 후보 예시:
  - 공격력 / 공격속도 증가
  - 투사체 수 증가
  - 실드 최대치 증가
  - 대쉬 쿨다운 감소
- **연동 레벨업 패시브** (Children of Morta 참고): 고양이가 특정 스킬 업그레이드 시 작물에 연계 패시브 자동 부여. 반대 방향도 동일. 둘 다 성장해야 최대 시너지 발동
- **크로스 시너지 업그레이드** (Brotato 참고): 업그레이드가 개별 효과 + "상대 플레이어와 조합 시 추가 효과" 발동. 예: 고양이 "전기 대시" + 작물 "연쇄 탄환" = 대시 경로 전기장 생성 후 탄환 통과 시 관통력 추가
- **듀오 강화** (Hades Duo Boon 참고): 고양이·양파 각각 지정 업그레이드 보유 시 보상방에서 "협동 강화" 추가 출현. 예: "화분 폭풍" — 대쉬 직후 2초간 양파 투사체 3방향 자동 분기

### 런 간 성장 (영구 강화)
- 미설계 (메타 진행 방식 논의 필요)

## 스킬 시스템
- 액티브 스킬 / 패시브 스킬 구분 여부 미정
- 작물 교체 시 스킬 세트 전환 연동 가능성
- **공유 궁극기 게이지** (Children of Morta 참고): P1·P2 각자 액션 시 공유 게이지 충전. 100% 달성 시 협동 궁극기 발동 (P1 대쉬 + P2 발사가 동시 트리거되는 콤보기). 단독 발동 불가

## 타격감 설계 원칙

- **너그러운 히트박스**: Cat 슬래시 판정 반경은 스프라이트보다 약간 넓게, 플레이어 Hurtbox는 스프라이트의 70%
- **히트 시각 피드백**: 슬래시가 아슬아슬하게 닿은 경우 판정 반경 경계에서 흰 점멸 파티클 재생 → 타격감과 회피 피드백 동시 확보
- **히트스톱**: Time.timeScale 대신 맞은 적의 Rigidbody2D + Animator만 0.06초 정지 → 2인 플레이에서 P2 원거리 흐름 방해 없음

## Cat/Crop 연계 시스템

- **연계 체인 아이템** (RoR2 참고): "Cat 슬래시 명중 → 2초 내 Crop 투사체 명중 시 전기 폭발 발동". 두 플레이어 행동이 시너지를 만드는 구조
- **패리 반격 카운터**: Crop 패리 성공 시 투사체 즉시 반사 + 다음 3초간 Cat 슬래시 데미지 ×2

## 레벨 / 경험치 (미설계)
- 로그라이크 특성상 런 내 레벨 시스템 도입 여부 미정
- 적 처치 → 경험치 → 레벨업 → 스탯 소폭 증가 방식 고려
