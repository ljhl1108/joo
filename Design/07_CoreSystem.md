## 0. 한 문장과 참고 게임

> **"하데스처럼 축복으로 강해지는 고양이 위에서, 양파가 스킬을 모아 조합하고 전장에 정원을 심는다.
>  둘이 서로를 돕고, 합을 맞추면 합동기가 터진다."**

| 참고 게임 | 가져올 것 | 어디에 |
|---|---|---|
| **Hades** | 행동 슬롯(공격·특수·던지기·대쉬)마다 축복이 붙는 구조, 듀오 축복, 방 단위 진행·보상 문 | 고양이, 맵 |
| **Shape of Dreams** | QWER 스킬을 런 중 얻어 조합하는 구조, 패드 자동 조준(가까운 적) + 원하면 수동 조준 | 양파 |
| **LoL 유미** | 아군 위에 올라탄 채 마우스로 조준·스킬을 쓰는 감각, 아군 강화 | 양파 |
| **ARCHONS** | 협동 합동 필살기 | 합동기 |
| **It Takes Two** | 둘이 함께 해야 풀리는 기믹 | 방·적·보스 기믹 |
| Enter the Gungeon | 읽히는 탄막, 회피 중심 전투 | 공통 |

### 피드백으로 확정된 것

- [x] 양파는 **마우스 조준 + QWER 스킬 + 1~5 아이템** (유미 방식). 패드는 Shape of Dreams식 자동/수동 조준
- [x] 양파 성장 = **스킬을 얻어 조합** (Shape of Dreams)
- [x] 고양이 성장 = **하데스식 축복**
- [x] **식물 심기** — 공간 설계. 고양이 강화 / 공격 / 적 약화. 심는 방식은 **작물마다 다른 특성**
- [x] **합동기** · **둘이 해야 풀리는 기믹**
- [x] **고양이도 원거리 지원 가능** — 서로 돕는 구조. 둘이 같이 원거리 빌드로 가는 런도 허용 (v2)
- [x] **가방은 각자** 관리하고 아이템을 주고받는다 (v2)
- [x] 런 간 성장은 6장 초안 그대로 시작 (v2)

### 모든 설계가 지킬 제약

1. **2인 1캐릭터** — 보상이 한 명에게만 쏠리지 않게
2. **비대칭** — **작물은 움직이지 않는다** (철칙). 기본 역할은 고양이=근접·이동, 작물=원거리·심기지만,
   **축복·스킬로 상대 영역을 넘나들 수 있다** (v2에서 "고양이는 절대 원거리 불가"를 완화)
3. **협동에 이유가 있어야** — 혼자 하는 게임 둘을 붙인 것처럼 되면 실패
4. **읽을 수 있어야** — 빌드는 복잡해도 화면은 단순하게
5. **실력 차이 수용** — 역할별 난이도. 실수 한 번에 런이 끝나지 않게
6. **쉬워도 도전의식이 생기게** — 예고(노랑=막기 가능 / 빨강=피하기)와 확정 공격. 패링·실드는 보조

이미 구현되어 그대로 쓰는 것: 공유 체력 · 텔레그래프 색 규칙 · 협동 콤보 · 방향 방어(정면 차단 / 등 2배) · 역할별 난이도 · 업그레이드 카드 UI · 방 단위 진행(Room → ExitDoor)

## 1. 입력

### 기본 구성: 고양이 = 패드, 양파 = 키보드+마우스

한 PC에서 2인이 할 때 가장 자연스러운 구성이다. 양파가 키보드를 쓰므로 **로컬 2인에서 고양이는 패드가 기본**이 된다.
(온라인 Remote Play Together라면 각자 아무 입력이나 가능)

| 양파 행동 | 키보드+마우스 (유미식) | 패드 (Shape of Dreams식) |
|---|---|---|
| 조준 | 마우스 커서 | **자동: 가장 가까운 적** / 오른스틱을 기울이면 수동 |
| 기본 공격 (씨앗 탄) | 좌클릭 (누르고 있으면 연사) | RT |
| 실드 | 우클릭 | LT |
| 스킬 1·2·3 (획득 스킬) | Q · W · E | X · Y · B (또는 RB+버튼) |
| 작물 고유기 (심기 계열) | R | RB |
| 아이템 사용 | 1 ~ 5 | 십자키 좌우 선택 + 십자키 위 사용 |
| 아이템 건네기 | Shift + 1 ~ 5 | 십자키 아래 |
| 합동기 | Space | LB |

| 고양이 행동 | 패드 | 키보드 (혼자 테스트용) |
|---|---|---|
| 이동 | 왼스틱 | WASD |
| 공격 (할퀴기) | X | F |
| 특수 (걷어차기) | Y | G |
| 던지기 | B (조준: 오른스틱, 놓으면 가장 가까운 적) | R |
| 대쉬 | A | Space |
| 아이템 사용 / 선택 / 건네기 | 십자키 위 / 좌우 / 아래 | 1~3 / — / Shift+1~3 |
| 합동기 | RB | E |

- **심기 위치 지정**: 마우스는 커서 위치. 패드는 "가장 가까운 적 발밑" 자동, 오른스틱으로 수동
- 조작이 많아 보이지만 처음에는 기본 동작만 있고, 런이 진행되며 슬롯이 채워진다 (하데스·Shape of Dreams와 같은 학습 곡선)
- **쉬움 난이도**: 조준 보정 강화, 쿨다운 끝난 스킬 자동 시전 옵션

## 2. 고양이 — 하데스식 "축복" 성장

### 2-1. 기본 동작 (행동 슬롯 4개)

| 슬롯 | 기본 동작 | 비고 |
|---|---|---|
| **공격** | 할퀴기 3타 콤보 (3타째 넉백 큼) | 현재 구현 |
| **특수** | 걷어차기 — 적을 크게 날려보냄. **식물 쪽으로 차 넣기**가 핵심 사용법 | 신규. 날아간 적이 벽·적·식물에 부딪히면 추가 피해 |
| **던지기** | **털뭉치** — 던지면 적에게 붙어 둔화. 바닥에 떨어진 털뭉치를 다시 주우면 재충전 (기본 1개) | 하데스의 '캐스트' 자리. 고양이의 원거리 지원 |
| **대쉬** | 짧은 무적 이동 | 현재 구현 |

- 털뭉치 자체는 피해가 작다. **원거리 딜러가 되려면 축복으로 키워야** 한다 → 기본은 근접, 원거리는 "빌드 선택"

### 2-2. 축복 — 정원 정령 4종 (가칭)

하데스의 신들처럼, 방 보상으로 **정령의 축복**을 받는다. 축복은 위 4개 슬롯 중 하나에 붙고, 슬롯당 1개다. 같은 슬롯에 새 축복을 받으면 기존 축복과 교체할지 고른다.

| 정령 | 테마 | 공격 축복 예 | 던지기 축복 예 | 대쉬 축복 예 |
|---|---|---|---|---|
| ☀️ 햇살 | 화상 | 할퀴기가 화상을 입힘 | 털뭉치가 불붙어 폭발 | 대쉬 경로에 불꽃 |
| 🌧️ 빗물 | 둔화·젖음 | 할퀴기가 적을 젖게 함 (다음 피해 증가) | 털뭉치가 물방울 3갈래로 퍼짐 | 대쉬 끝에 물웅덩이 |
| 🍃 바람 | 넉백·속도 | 3타째 넉백이 2배 | **털뭉치 3개 + 자동 회수** (원거리 빌드의 핵심) | 대쉬 2회 충전 |
| 🪨 흙 | 방어·가시 | 할퀴기 적중 시 보호막 획득 | 털뭉치가 맞은 자리에 가시 돋움 | 대쉬 중 닿은 적 기절 |

- **패시브 축복**: 슬롯에 붙지 않는 효과 (예: 체력 50% 이하면 공격력 증가)
- **축복 강화**: 같은 정령의 축복이 겹치면 등급이 오름 (하데스의 일반 → 영웅 → 전설)
- 세계관 연결: 떠도는 정원을 지키던 정령들이 마법사의 정원을 되찾으려는 둘을 돕는다

### 2-3. 고양이가 양파를 돕는 축복 (v2)

양파가 돌봄 스킬로 고양이를 돕듯, 고양이도 양파를 돕는다. 정령마다 **양파 지원 축복**이 섞여 나온다.

| 축복 예 | 효과 |
|---|---|
| 그루밍 (빗물) | 대쉬하면 화분에 물이 튀어 **양파 스킬 쿨다운 1초 감소** |
| 햇볕 쬐기 (햇살) | 가만히 서 있으면 양파 기본 탄 피해 증가 |
| 흙 다지기 (흙) | 고양이가 밟은 자리에 심은 식물이 2배 빨리 자람 |
| 꼬리 바람 (바람) | 고양이 공격 적중 시 양파 다음 탄이 관통 |
| 털뭉치 표식 | 털뭉치가 붙은 적에게 양파 탄이 유도됨 |

### 2-4. 빌드 방향 예

| 빌드 | 고양이 | 양파 | 플레이 감각 |
|---|---|---|---|
| 정석 | 근접 축복 위주 | 심기·사격 | 고양이가 들어가 싸우고 양파가 전장 설계 |
| **둘 다 원거리** | 바람 던지기 + 털뭉치 표식 | 사격 위주 | 거리를 벌리고 같이 쏘는 탄막 빌드. 고양이는 회피·위치 담당 |
| 탱커 고양이 | 흙 축복 | 돌봄·방해 | 고양이가 버티고 양파가 살리고 묶음 |
| 정원 폭파 | 햇살 + 걷어차기 | 터지는 박 위주 | 박에 적을 차 넣어 연쇄 폭발 |

## 3. 양파 — Shape of Dreams식 "스킬 조합" + 심기

### 3-1. 작물 = 캐릭터 (런 시작 전 선택)

작물마다 **기본 탄**과 **고유기(R, 심기 계열)**가 다르다. 심기의 성격이 곧 작물의 특성이다.

| 작물 | 기본 탄 | 고유기 (R) — 무엇을 심는가 | 성격 |
|---|---|---|---|
| 🧅 양파 | 단발, 균형형 | **매운 양파** — 주변 적 시야 방해 (공격이 늦어짐) | 적 약화 |
| 🥕 당근 | 관통, 느림 | **당근 포탑** — 가까운 적을 자동 사격 | 공격 |
| 🧄 마늘 | 짧은 산탄 | **마늘 울타리** — 적을 막는 벽, 닿으면 넉백 | 공간 통제 |
| 🌿 부추 | 빠른 연사, 약함 | **캣닢 덤불** — 안에 있는 고양이 공격속도·이동속도 증가 | 고양이 강화 |

- 처음에는 양파만 쓸 수 있고, 나머지는 온실에서 해금한다 (7장)
- 심어둔 식물은 **방을 나가면 사라진다**. 동시에 최대 3개 (화면 복잡도 제한)
- 식물은 적의 빨간 공격에 파괴될 수 있다 → 어디에 심을지가 판단

### 3-2. 획득 스킬 (Q·W·E) — 런 중 조합

방 보상으로 스킬을 얻어 Q·W·E 슬롯에 넣는다. 슬롯이 차면 교체한다.
스킬은 **4계열**로 나뉘고, 같은 계열을 모으거나 섞으며 빌드를 짠다.

| 계열 | 스킬 예 | 역할 |
|---|---|---|
| 🌱 **심기** | 가시덩굴 (둔화+지속피해) · 터지는 박 (닿으면 폭발) · 반딧불 꽃 (주변을 밝힘) | 공간 설계 |
| 💚 **돌봄** (유미식) | 영양제 (고양이 회복) · 뿌리 갑옷 (고양이 보호막) · 광합성 (고양이 다음 공격 강화) | 고양이 지원 |
| 🎯 **사격** | 충전탄 · 산탄 · 유도 씨앗 · 꿰뚫는 가시 | 직접 딜 |
| 🌀 **방해** | 포자 구름 (적 경직) · 넝쿨 올가미 (적을 끌어옴) · 꽃가루 (적 실명) | 적 약화 |

**스킬 변형 (조합의 핵심)**
- 스킬마다 **변형 요소(가칭: 비료)**를 붙일 수 있다
  - 예: 터지는 박 + **"번식" 비료** = 터질 때 작은 박 2개를 남김
  - 예: 유도 씨앗 + **"씨앗 심기" 비료** = 맞은 자리에 가시덩굴이 자람 → 사격 계열이 심기 계열과 이어짐
- 같은 스킬을 다시 얻으면 레벨업 (피해·범위·쿨다운)

### 3-3. 양파의 게임성 — "움직이지 않는 대신 하는 일"

| 양파의 일 | 재미 |
|---|---|
| 조준 (사격·방해) | 직접 손맛. 약점 저격 |
| 심기 | 전장을 설계. 고양이가 싸울 무대를 만듦 |
| 돌봄 | 유미처럼 고양이를 살리는 판단 |
| 가방·아이템 | 언제 쓸지, 고양이에게 건넬지 |
| 실드 | 노란 공격 막기 (보조) |
| 합동기 호출 | 타이밍을 정하는 지휘자 |

→ 계열을 어떻게 모으느냐에 따라 **같은 양파라도 플레이가 완전히 달라진다**
(심기 위주 = 전략가 / 사격 위주 = 딜러 / 돌봄 위주 = 서포터)

## 4. 협동 — "같이 하고 있다"는 느낌

### 4-1. 협동 콤보 → 합동 게이지 (현재 구현의 확장)

- **고양이 공격과 양파 공격이 1초 안에 번갈아** 맞으면 ×1.5
  - ⚠️ 현재 구현은 "근접↔원거리" 기준 → 고양이도 원거리를 쓰게 되므로 **"누가 때렸나(고양이/양파)" 기준으로 변경** 필요
- 협동 콤보가 터질 때마다 **합동 게이지**가 찬다. 한쪽만 때리면 거의 차지 않는다
- 패링 성공·식물 연계(식물에 적을 차 넣기)도 게이지를 채운다

### 4-2. 합동기 (ARCHONS식)

- 게이지가 가득 차면 **두 사람이 1.5초 안에 각자 합동기 버튼**을 눌러 발동
  - 한 명이 먼저 누르면 화면에 "상대를 기다리는 중" 표시. 시간이 지나도 게이지는 사라지지 않는다 (실수에 관대하게)
- 발동 중 잠깐 무적 + 연출 (컷인 또는 줌인)
- **합동기 종류 = 고양이의 주 정령 × 양파의 작물**

| | ☀️ 햇살 | 🌧️ 빗물 | 🍃 바람 | 🪨 흙 |
|---|---|---|---|---|
| 🧅 양파 | 매운 불꽃 회오리 | 최루 폭우 | 매운 태풍 | 양파 지뢰밭 |
| 🥕 당근 | 당근 미사일 폭격 | … | … | … |

  → 처음엔 작물별 1개(4종)만 만들고, 정령 조합은 나중에 확장
- 주 정령 = 축복을 가장 많이 받은 정령 (UI에 표시)

### 4-3. 듀오 축복 (하데스 듀오 축복 × 양파 스킬)

고양이의 **특정 정령 축복** + 양파의 **특정 계열 스킬**을 둘 다 가지고 있으면 보상에 듀오 축복이 등장한다.

| 고양이 | 양파 | 듀오 축복 |
|---|---|---|
| ☀️ 햇살 축복 | 🌱 터지는 박 | **불꽃 박** — 고양이가 박을 때리면 화염 폭발 |
| 🍃 바람 축복 | 🌱 가시덩굴 | **가시 폭풍** — 걷어찬 적이 덩굴에 닿으면 덩굴이 퍼짐 |
| 🌧️ 빗물 축복 | 💚 영양제 | **단비** — 회복할 때 주변 식물이 즉시 다 자람 |
| 🪨 흙 축복 | 🌀 넝쿨 올가미 | **대지 고정** — 끌려온 적이 고양이 앞에서 기절 |
| 🍃 바람 던지기 | 🎯 유도 씨앗 | **쌍성** — 털뭉치 주위를 씨앗이 돌며 같이 날아감 (원거리 빌드) |

→ 두 사람이 **"너 그거 먹으면 듀오 나와!"** 하고 서로의 보상 선택에 참견하게 만드는 장치

### 4-4. 각자의 가방과 주고받기 (v2)

**원칙: 가방은 각자. 필요한 사람에게 건네야 쓸 수 있다 → 말을 하게 만든다.**

| 항목 | 고양이 | 양파 |
|---|---|---|
| 칸 수 | 3칸 | 5칸 (1~5) |
| 줍기 | 바닥 아이템은 **먼저 줍기 버튼을 누른 사람**의 가방으로 | 〃 |
| 건네기 | 버튼 한 번 → 0.5초 연출 (꼬리로 화분에 건넴 / 잎으로 내려줌) | 〃 |

**아이템 종류**

| 종류 | 예 | 주고받기가 생기는 이유 |
|---|---|---|
| 공용 | 회복 열매, 폭탄 씨앗 | 누가 들고 있느냐에 따라 "지금 네가 써!" |
| 고양이 전용 | 캣닢 통조림 (잠깐 광폭화), 정령의 이슬 (축복 등급 +1) | 양파가 주웠으면 건네줘야 함 |
| 양파 전용 | 물뿌리개 (스킬 쿨다운 초기화), 비료 주머니 (즉석 비료) | 고양이가 주웠으면 건네줘야 함 |

- 전용 아이템은 상대 가방에 **들어가긴 하지만 쓸 수 없다** (회색 표시 + "건네주세요" 아이콘)
- 화폐(씨앗)는 **공동 지갑** → 상점에서 "이거 사자" 상의

### 4-5. 둘이 해야 풀리는 기믹 (It Takes Two식)

**원칙: 기믹을 못 풀어도 보상만 놓친다. 런이 끝나거나 진행이 막히지는 않는다.**
(주 경로를 막는 기믹은 아주 쉽게, 어려운 기믹은 보너스 방에)

| 종류 | 기믹 | 고양이 | 양파 |
|---|---|---|---|
| 방 | **쌍둥이 스위치** | 발판을 밟고 버팀 (적이 몰려옴) | 멀리 있는 수정을 쏨 |
| 방 | **어둠의 방** | 램프 반경만 보임 → 앞장서서 탐색 | 반딧불 꽃을 심어 길을 밝힘 |
| 방 | **덩굴 문** | 할퀴면 잠깐 열림 | 열린 틈에 씨앗을 심어 문을 영구히 고정 |
| 적 | **쌍둥이 정령** | 한 마리를 맡음 | 다른 한 마리를 동시에 (2초 내) — 아니면 부활 |
| 적 | **뿌리 방패병** | 등 뒤로 돌아감 | 정면에서 시선을 끎 (방패병 구현됨 — 확장) |
| 보스 | **영웅 현자의 결계** | 결계 안에서 버팀 | 결계 밖 기둥 4개를 순서대로 쏨 |
| 보상 | **두 자물쇠 상자** | 리듬 타격 (할퀴기 타이밍) | 움직이는 과녁 맞히기 |

## 5. 맵 구조 (v2 제안)

### 5-1. 후보 비교

| | **A. 방 연결형** (Hades) | **B. 층 탐색형** (Isaac·Gungeon) | **C. 노선 지도형** (Slay the Spire + 방) |
|---|---|---|---|
| 형태 | 방 하나 클리어 → 문 2~3개 중 선택 → 다음 방 | 한 층에 방 10~15개가 연결. 미니맵 보며 자유 탐색, 보스방 찾기 | 스테이지 시작 시 갈림길 지도 전체 공개 → 노선 선택, 각 칸은 방 하나 |
| 경로 결정 | 문 앞에서 **둘이 상의** | **이동하는 고양이**가 결정 | 지도에서 **둘이 상의** |
| 양파 참여 | 높음 (문 선택에 같은 발언권) | **낮음** — 이동·탐색·되돌아가기 동안 양파는 할 일이 없음 | 높음 |
| 템포 | 빠름. 모든 방이 전투·이벤트 | 느림. 빈 방 되돌아가기 발생 | 빠름 |
| 비밀·탐험 | 약함 | **강함** (비밀방, 숨은 상점) | 중간 (지도에 ? 칸) |
| 런 길이 조절 (20~30분) | 쉬움 (방 개수 고정) | 어려움 (탐색 시간 편차 큼) | 쉬움 |
| 제작 | 방 템플릿 + 문 보상 | 절차 생성 레이아웃 + 미니맵 + 방 연결 | 지도 생성 + 지도 UI + 방 템플릿 |
| 현재 구현과 | **가장 가까움** (Room → ExitDoor) | 큰 변경 | 중간 |

### 5-2. 추천: **A. 방 연결형 (하데스식) + 보상 미리보기 문**

1. **양파가 소외되지 않는다** — B는 "어디로 갈지"를 움직이는 고양이가 정한다. 탐색·되돌아가기 시간 동안 움직이지 못하는 양파는 구경꾼이 된다
2. **문 선택이 곧 대화** — "축복 문으로 갈까, 스킬 문으로 갈까?" 하데스의 보상 문이 이 게임에서는 **두 사람의 협상 장치**가 된다 (보상 쏠림 방지와도 연결)
3. **템포** — "시원시원한 전투" 방향에 맞고, 런 20~30분을 맞추기 쉽다
4. **현재 구조 그대로 확장** — 방 단위 진행이 이미 구현되어 있다

**A의 약점(탐험 부족) 보완**
- 방 안의 비밀: 부서지는 벽·숨은 식물 화분 (→ 둘이 해야 풀리는 기믹과 연결)
- 특수 방을 문 보상으로 섞기
- 나중에 원하면 **C처럼 "다음 2개 방까지 미리보기"** 추가 (노선 계획 대화가 더 늘어남)

### 5-3. 스테이지 구성 예 (스테이지 1, 8개 방)

```
[시작] → 전투 → 전투 → (갈림길) → 전투 → [특수] → 전투 → [휴식 정원] → [보스]
                          ↘ 기믹 보너스 방 ↗
```

| 방 종류 | 내용 | 문 표시 |
|---|---|---|
| 전투 | 일반 전투. 클리어 보상은 문에 표시된 것 | 보상 아이콘 (축복/스킬/비료/아이템/씨앗) |
| 기믹 보너스 | 4-5의 2인 기믹. 성공하면 좋은 보상 | ❓ |
| 상점 | 공동 지갑으로 구매 | 💰 |
| 휴식 정원 | 체력 회복 **또는** 스킬·축복 1개 강화 중 택1 (둘이 상의) | 🌿 |
| 보스 | 스테이지 끝 | 💀 |

## 8. 제작 순서 제안 (작은 것부터 검증)

1. **양파 스킬 슬롯 구조** — Q·W·E·R 입력, 쿨다운 UI, 스킬 SO(ScriptableObject) 기반 클래스
   → 기존 업그레이드 카드(`UpgradeData`)를 스킬 획득 보상으로 확장
2. **식물 1종 (터지는 박) + 고양이 걷어차기** → "차 넣는 게 재밌나?" 검증
3. **고양이 축복 슬롯 구조** — 정령 1종(햇살)으로 공격·대쉬·던지기 축복, 털뭉치 기본 던지기
4. **협동 콤보 기준 변경**(근접/원거리 → 고양이/양파) + **합동 게이지 + 합동기 1종**
5. **보상 문** — 방 클리어 후 문 2개에 보상 표시 (맵 구조 A)
6. **가방 2개 + 건네기** — 공용·전용 아이템 2~3종
7. 기믹 1종 (쌍둥이 스위치) — 보너스 방에 넣기
8. 여기까지 플레이해보고 확장 여부 결정
