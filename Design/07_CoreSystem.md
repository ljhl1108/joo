3. **협동에 이유가 있어야** — 혼자 하는 게임 둘을 붙인 것처럼 되면 실패
4. **읽을 수 있어야** — 빌드는 복잡해도 화면은 단순하게
5. **실력 차이 수용** — 역할별 난이도. 실수 한 번에 런이 끝나지 않게
6. **쉬워도 도전의식이 생기게** — 예고(노랑=막기 가능 / 빨강=피하기)와 확정 공격. 패링·실드는 보조

## 1. 입력

### 기본 구성: 고양이 = 패드, 양파 = 키보드+마우스

한 PC에서 2인이 할 때 가장 자연스러운 구성이다. 양파가 키보드를 쓰므로 **로컬 2인에서 고양이는 패드가 기본**이 된다.
(온라인 Remote Play Together라면 각자 아무 입력이나 가능)

| 양파 행동 | 키보드+마우스 (유미식) | 패드 (Shape of Dreams식) |
|---|---|---|
| 조준 | 마우스 커서 | **자동: 가장 가까운 적** / 오른스틱을 기울이면 수동 |
| 기본 공격 (씨앗 탄) | 좌클릭 (누르고 있으면 연사) | RT |
| 실드 | 우클릭 | LT |
| 스킬 1·2·3 (획득 스킬) | Q · W · E | X · Y · B (또는 RB+버튼) |
| 작물 고유기 (심기 계열) | R | RB |
| 공유 가방 사용 | 1 ~ 5 | — (패드 양파는 미구현) |
| 합동기 | Space | LB |

| 고양이 행동 | 패드 | 키보드 (혼자 테스트용) |
|---|---|---|
| 이동 | 왼스틱 | WASD |
| 공격 (할퀴기) | X | 왼쪽 Shift |
| 특수 (걷어차기) | Y | 왼쪽 Ctrl |
| 던지기 | B (조준: 오른스틱, 놓으면 가장 가까운 적) | Q |
| 대쉬 | A | Space |
| 공유 가방 사용 / 선택 | 십자키 위 / 좌우 | Z / X |
| 합동기 | RB | E |

**키보드 모드 (패드 없음)** — 한 키보드를 나눠 쓸 때 (2026-10-03 구현에서 확정)
- 고양이는 위 표의 키보드 열. 양파는 W가 고양이 이동과 겹치므로 스킬을 숫자로 옮긴다:
  스킬 **1 2 3 / 고유기 4** · 아이템 **6~0** · 합동기 **마우스 휠 클릭**
- 패드를 꽂으면 자동으로 패드 모드(위 양파 표)로 바뀌고, 고양이는 패드에만 묶인다 (`CoopInputLayout`)

- **심기 위치 지정**: 마우스는 커서 위치. 패드는 "가장 가까운 적 발밑" 자동, 오른스틱으로 수동
- 조작이 많아 보이지만 처음에는 기본 동작만 있고, 런이 진행되며 슬롯이 채워진다 (하데스·Shape of Dreams와 같은 학습 곡선)
- **쉬움 난이도**: 조준 보정 강화, 쿨다운 끝난 스킬 자동 시전 옵션

## 3. 양파 — Shape of Dreams식 "스킬 조합" + 심기

### 3-1. 작물 = 캐릭터 (런 시작 전 선택)

작물마다 **기본 탄**과 **고유기(R, 심기 계열)**가 다르다. 심기의 성격이 곧 작물의 특성이다.

| 작물 | 기본 탄 | 고유기 (R) — 무엇을 심는가 | 성격 |
|---|---|---|---|
| 🧅 양파 | 단발, 균형형 | **매운 양파** — 주변 적 시야 방해 (공격이 늦어짐) | 적 약화 |
| 🥕 당근 | 관통, 느림 | **당근 포탑** — 가까운 적을 자동 사격 | 공격 |
| 🧄 마늘 | 짧은 산탄 | **마늘 울타리** — 적을 막는 벽, 닿으면 넉백 | 공간 통제 |
| 🌿 부추 | 빠른 연사, 약함 | **캣닢 덤불** — 안에 있는 고양이 공격속도·이동속도 증가 | 고양이 강화 |

- 처음에는 양파만 쓸 수 있고, 나머지는 온실에서 해금한다 (7장)
- 심어둔 식물은 **방을 나가면 사라진다**. 동시에 최대 3개 (화면 복잡도 제한)
- 식물은 적의 빨간 공격에 파괴될 수 있다 → 어디에 심을지가 판단

### 3-2. 획득 스킬 (Q·W·E) — 런 중 조합

방 보상으로 스킬을 얻어 Q·W·E 슬롯에 넣는다. 슬롯이 차면 교체한다.
스킬은 **4계열**로 나뉘고, 같은 계열을 모으거나 섞으며 빌드를 짠다.

| 계열 | 스킬 예 | 역할 |
|---|---|---|
| 🌱 **심기** | 가시덩굴 (둔화+지속피해) · 터지는 박 (닿으면 폭발) · 반딧불 꽃 (주변을 밝힘) | 공간 설계 |
| 💚 **돌봄** (유미식) | 영양제 (고양이 회복) · 뿌리 갑옷 (고양이 보호막) · 광합성 (고양이 다음 공격 강화) | 고양이 지원 |
| 🎯 **사격** | 충전탄 · 산탄 · 유도 씨앗 · 꿰뚫는 가시 | 직접 딜 |
| 🌀 **방해** | 포자 구름 (적 경직) · 넝쿨 올가미 (적을 끌어옴) · 꽃가루 (적 실명) | 적 약화 |

**스킬 변형 (조합의 핵심)**
- 스킬마다 **변형 요소(가칭: 비료)**를 붙일 수 있다
  - 예: 터지는 박 + **"번식" 비료** = 터질 때 작은 박 2개를 남김
  - 예: 유도 씨앗 + **"씨앗 심기" 비료** = 맞은 자리에 가시덩굴이 자람 → 사격 계열이 심기 계열과 이어짐
- 같은 스킬을 다시 얻으면 레벨업 (피해·범위·쿨다운)

### 3-3. 양파의 게임성 — "움직이지 않는 대신 하는 일"

| 양파의 일 | 재미 |
|---|---|
| 조준 (사격·방해) | 직접 손맛. 약점 저격 |
| 심기 | 전장을 설계. 고양이가 싸울 무대를 만듦 |
| 돌봄 | 유미처럼 고양이를 살리는 판단 |
| 가방·아이템 | 언제 쓸지, 고양이에게 건넬지 |
| 실드 | 노란 공격 막기 (보조) |
| 합동기 호출 | 타이밍을 정하는 지휘자 |

→ 계열을 어떻게 모으느냐에 따라 **같은 양파라도 플레이가 완전히 달라진다**
(심기 위주 = 전략가 / 사격 위주 = 딜러 / 돌봄 위주 = 서포터)

## 4. 협동 — "같이 하고 있다"는 느낌

### 4-1. 협동 콤보 → 합동 게이지 (현재 구현의 확장)

- **고양이 공격과 양파 공격이 1초 안에 번갈아** 맞으면 ×1.5
  - ✅ 2026-10-03: "근접↔원거리" 기준에서 **"누가 때렸나(고양이/양파)" 기준으로 변경 완료** (`Attacker`)
- 협동 콤보가 터질 때마다 **합동 게이지**가 찬다. 한쪽만 때리면 거의 차지 않는다
- 패링 성공·식물 연계(식물에 적을 차 넣기)도 게이지를 채운다

### 4-2. 합동기 (ARCHONS식)

- 게이지가 가득 차면 **두 사람이 1.5초 안에 각자 합동기 버튼**을 눌러 발동
  - 한 명이 먼저 누르면 화면에 "상대를 기다리는 중" 표시. 시간이 지나도 게이지는 사라지지 않는다 (실수에 관대하게)
- 발동 중 잠깐 무적 + 연출 (컷인 또는 줌인)
- **합동기 종류 = 고양이의 주 정령 × 양파의 작물**

| | ☀️ 햇살 | 🌧️ 빗물 | 🍃 바람 | 🪨 흙 |
|---|---|---|---|---|
| 🧅 양파 | 매운 불꽃 회오리 | 최루 폭우 | 매운 태풍 | 양파 지뢰밭 |
| 🥕 당근 | 당근 미사일 폭격 | … | … | … |

  → 처음엔 작물별 1개(4종)만 만들고, 정령 조합은 나중에 확장
- 주 정령 = 축복을 가장 많이 받은 정령 (UI에 표시)

### 4-3. 같이 모으는 세트 (v3 — 듀오 축복 대체)

패시브 세트는 **고양이 조각과 양파 조각을 합쳐서** 센다 (6장).
→ "너 햇살 골라, 나도 햇살 고를게" — 서로의 보상 선택에 참견하게 만드는 장치는 그대로, 규칙은 더 단순하게.

### 4-4. 공유 가방 (v3)

**가방은 하나. 누가 쓰든 같은 가방에서 빠진다** → "그거 지금 내가 쓸게!" 같은 대화.

| 항목 | 내용 |
|---|---|
| 칸 수 | 5칸 (화면 가운데, 양파 스킬 위) |
| 사용 | 고양이 = 선택 칸 사용 (십자키 위 / Z), 선택 이동 (십자키 좌우 / X) · 양파 = 숫자키로 그 칸 바로 사용 |
| 줍기 | 고양이가 지나가면 자동. 양파는 클릭으로도 주울 수 있음 |
| 아이템 | 회복 열매 · 캣닢(고양이 강화) · 물뿌리개(양파 쿨다운 초기화) — 누가 써도 효과는 같음 |

> v2의 각자 가방·건네기·전용 아이템은 폐지 (테스트 피드백: 공유가 더 자연스러움).

### 4-5. 둘이 해야 풀리는 기믹 (It Takes Two식)

**원칙: 기믹을 못 풀어도 보상만 놓친다. 런이 끝나거나 진행이 막히지는 않는다.**
(주 경로를 막는 기믹은 아주 쉽게, 어려운 기믹은 보너스 방에)

| 종류 | 기믹 | 고양이 | 양파 |
|---|---|---|---|
| 방 | **쌍둥이 스위치** | 발판을 밟고 버팀 (적이 몰려옴) | 멀리 있는 수정을 쏨 |
| 방 | **어둠의 방** | 램프 반경만 보임 → 앞장서서 탐색 | 반딧불 꽃을 심어 길을 밝힘 |
| 방 | **덩굴 문** | 할퀴면 잠깐 열림 | 열린 틈에 씨앗을 심어 문을 영구히 고정 |
| 적 | **쌍둥이 정령** | 한 마리를 맡음 | 다른 한 마리를 동시에 (2초 내) — 아니면 부활 |
| 적 | **뿌리 방패병** | 등 뒤로 돌아감 | 정면에서 시선을 끎 (방패병 구현됨 — 확장) |
| 보스 | **영웅 현자의 결계** | 결계 안에서 버팀 | 결계 밖 기둥 4개를 순서대로 쏨 |
| 보상 | **두 자물쇠 상자** | 리듬 타격 (할퀴기 타이밍) | 움직이는 과녁 맞히기 |

## 5. 맵 구조 (v2 제안)

### 5-1. 후보 비교

| | **A. 방 연결형** (Hades) | **B. 층 탐색형** (Isaac·Gungeon) | **C. 노선 지도형** (Slay the Spire + 방) |
|---|---|---|---|
| 형태 | 방 하나 클리어 → 문 2~3개 중 선택 → 다음 방 | 한 층에 방 10~15개가 연결. 미니맵 보며 자유 탐색, 보스방 찾기 | 스테이지 시작 시 갈림길 지도 전체 공개 → 노선 선택, 각 칸은 방 하나 |
| 경로 결정 | 문 앞에서 **둘이 상의** | **이동하는 고양이**가 결정 | 지도에서 **둘이 상의** |
| 양파 참여 | 높음 (문 선택에 같은 발언권) | **낮음** — 이동·탐색·되돌아가기 동안 양파는 할 일이 없음 | 높음 |
| 템포 | 빠름. 모든 방이 전투·이벤트 | 느림. 빈 방 되돌아가기 발생 | 빠름 |
| 비밀·탐험 | 약함 | **강함** (비밀방, 숨은 상점) | 중간 (지도에 ? 칸) |
| 런 길이 조절 (20~30분) | 쉬움 (방 개수 고정) | 어려움 (탐색 시간 편차 큼) | 쉬움 |
| 제작 | 방 템플릿 + 문 보상 | 절차 생성 레이아웃 + 미니맵 + 방 연결 | 지도 생성 + 지도 UI + 방 템플릿 |
| 현재 구현과 | **가장 가까움** (Room → ExitDoor) | 큰 변경 | 중간 |

### 5-2. 추천: **A. 방 연결형 (하데스식) + 보상 미리보기 문**

1. **양파가 소외되지 않는다** — B는 "어디로 갈지"를 움직이는 고양이가 정한다. 탐색·되돌아가기 시간 동안 움직이지 못하는 양파는 구경꾼이 된다
2. **문 선택이 곧 대화** — "축복 문으로 갈까, 스킬 문으로 갈까?" 하데스의 보상 문이 이 게임에서는 **두 사람의 협상 장치**가 된다 (보상 쏠림 방지와도 연결)
3. **템포** — "시원시원한 전투" 방향에 맞고, 런 20~30분을 맞추기 쉽다
4. **현재 구조 그대로 확장** — 방 단위 진행이 이미 구현되어 있다

**A의 약점(탐험 부족) 보완**
- 방 안의 비밀: 부서지는 벽·숨은 식물 화분 (→ 둘이 해야 풀리는 기믹과 연결)
- 특수 방을 문 보상으로 섞기
- 나중에 원하면 **C처럼 "다음 2개 방까지 미리보기"** 추가 (노선 계획 대화가 더 늘어남)

### 5-2b. 보상 흐름 (v3)

1. 전투방을 깨면 **고양이 카드 3장(왼쪽) + 양파 카드 3장(오른쪽)** — 두 사람이 **동시에** 각자 1장
   (한쪽이 고르는 동안 다른 쪽이 기다리지 않는다)
2. 카드 3장은 성장 3축(체급·패시브·특수)이 섞여 나온다
3. 고른 뒤 출구 앞에 **표식 2개 = 다음 방의 중점 축** (POWER / PASSIVE SET / SPECIAL 중 2개)
   → 고른 축의 카드가 다음 방에서 **두 사람 모두 2장씩 보장** (나머지 1장은 다른 축)
4. 첫 방은 중점 없음 (축마다 1장씩)

> 방마다 한 사람만 받던 v2보다 성장이 2배 빠르고, 표식으로 "이번엔 세트 모으자" 같은 상의가 생긴다.

### 5-3. 스테이지 구성 예 (스테이지 1, 8개 방)

```
[시작] → 전투 → 전투 → (갈림길) → 전투 → [특수] → 전투 → [휴식 정원] → [보스]
                          ↘ 기믹 보너스 방 ↗
```

| 방 종류 | 내용 | 문 표시 |
|---|---|---|
| 전투 | 일반 전투. 클리어 보상은 문에 표시된 것 | 보상 아이콘 (축복/스킬/비료/아이템/씨앗) |
| 기믹 보너스 | 4-5의 2인 기믹. 성공하면 좋은 보상 | ❓ |
| 상점 | 공동 지갑으로 구매 | 💰 |
| 휴식 정원 | 체력 회복 **또는** 스킬·축복 1개 강화 중 택1 (둘이 상의) | 🌿 |
| 보스 | 스테이지 끝 | 💀 |
