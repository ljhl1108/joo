## 0. 무엇을 정하려는 것인가

"이 게임 어떤 게임이야?"에 한 문장으로 답할 수 있게 만드는 **전투·협동·성장 구조**.

| 게임 | 한 문장 | 구조 |
|---|---|---|
| Enter the Gungeon | "총을 모아서 바꿔 쓰는 게임" | 무기 수집 + 교체. 무기 자체가 보상 |
| Hades | "축복을 조합해 빌드를 만드는 게임" | 고정 무기 + 축복 조합, 두 신의 **듀오 축복** |
| Brotato | "제약이 있는 캐릭터로 빌드를 짜는 게임" | 캐릭터별 제약 + 아이템 시너지 |
| 세피리아류 | "기본 무기가 갈래로 분화하는 게임" | 고정 기본 무기 + 아티팩트로 형태 분화 |

### 모든 안이 지켜야 할 제약

1. **2인 1캐릭터** — 보상이 한 명에게만 쏠리면 다른 한 명이 심심하다
2. **비대칭** — 고양이는 이동·근접, 양파는 원거리·방어. **철칙: 고양이는 원거리 공격을 하지 않고, 작물은 움직이지 않는다**
3. **협동에 이유가 있어야** — 혼자 하는 게임 둘을 붙여놓은 것처럼 되면 실패
4. **읽을 수 있어야** — 두 사람이 한 화면을 본다. 빌드는 복잡해도 화면은 단순하게
5. **실력 차이 수용** — 역할별 난이도, 실수 한 번에 런이 끝나지 않을 것
6. **"쉬워도 도전의식이 생기는"** — 예고(노랑=막기 가능 / 빨강=피하기)와 확정 공격으로 **읽히는 난이도**. 패링·실드는 보조

### 세 안 모두에 그대로 남는 것 (이미 구현됨)

공유 체력(숫자) · 텔레그래프 색 규칙 · 협동 콤보(근접↔원거리 1초 내 ×1.5) · 방향 방어(정면 차단 / 등 2배) · 역할별 난이도 · 1+1+1 업그레이드 카드(고양이·작물·공용)

## 1. 입력 방식 — 먼저 정리 (세 안 공통 전제)

### 선택지 비교

| 구성 | 고양이 (P1) | 양파 (P2) | 장점 | 단점 |
|---|---|---|---|---|
| **① 패드 + 마우스** (현재 구현) | 패드 | 마우스(+키보드 약간) | 양파 조준이 가장 정밀·쾌적. 한 PC 2인에 자연스러움 | 책상 공간 필요, 소파 플레이 불가 |
| ② 패드 + 패드 | 패드 | 패드 (오른스틱 조준) | 소파·TV 플레이. 스팀덱·콘솔 이식 쉬움 | 스틱 조준은 정밀도↓ → 양파가 "조준 게임"이면 답답 |
| ③ 키보드 + 마우스 (한 키보드 공유) | WASD+Space/F | 마우스 | 패드 없어도 됨 | 한 책상에 두 사람이 붙어야 함. 공간 좁음 |
| ④ 온라인 (Remote Play Together) | 자유 | 자유 | 떨어져 사는 커플도 가능 | 개발 부담 없음 (스팀 기능). 입력 지연 약간 |

### 결론: **"양파는 마우스 하나로 완결"을 기준으로 설계하되, 패드로도 플레이 가능하게**

- 양파의 모든 행동을 **마우스 버튼 4개 안**에 넣는다: 좌클릭 / 우클릭 / 휠 클릭 / 휠 굴리기 (+옆버튼 선택)
  → 양파 플레이어는 **키보드가 필요 없음** → 패드 쥔 고양이 옆에서 마우스만 들고 있으면 된다 (① 구성이 가장 편해짐)
- 패드 양파는 **오른스틱 조준 + 소프트 락온(보정)** 으로 지원. 조준 보정 강도는 "양파 난이도"에 포함
- 따라서 **"정밀 조준이 핵심 재미"인 안일수록 패드 양파가 불리**하다 → 아래 세 안의 차이점 중 하나

| 양파 입력 | 마우스 | 패드 |
|---|---|---|
| 조준 | 커서 | 오른스틱 (+보정) |
| 기본 공격 | 좌클릭 | RT |
| 실드 | 우클릭 | LT |
| 특수 (안마다 다름) | 휠 클릭 | RB |
| 선택 전환 (안마다 다름) | 휠 굴리기 | LB / 십자키 |

> 고양이 입력은 모든 안에서 동일: 이동 / 대쉬 / 할퀴기 / **특수기 1개** (패드 A·B·X·Y 중 하나 추가)

## 2. 초안 A — 「포탑 고양이」 (사수형)

> **한 문장: "고양이가 몰고 다니는 포탑, 양파는 작물 무기를 갈아 끼우는 사수"**
> 참고: Enter the Gungeon(무기 수집), Lovers in a Dangerous Spacetime(탑승형 포수)

### A-1. 전투

**고양이 (운전수 겸 근접)**
- 기본: 할퀴기 3타 콤보 (3타째 넉백 큼) · 대쉬 (무적 프레임)
- 특수: **덮치기** — 짧은 도약 후 착지 범위 공격. 쿨다운 6초
- 역할: 양파가 쏘기 좋은 위치로 **몸을 옮겨주는 것** 자체가 일

**양파 (사수)**
- 기본: 현재 작물의 탄 발사 (좌클릭)
- 특수: **작물 고유 스킬** (휠 클릭) — 작물마다 다름
- 자원: **수분(탄약)** — 쏘면 줄고, 고양이가 **물웅덩이를 밟거나 대쉬로 적을 통과하면** 충전. 비면 느린 기본탄만
- 실드: 노란 공격 1회 차단 (현행 유지)

**작물 = 무기** (런 중 방에서 획득, 2개까지 들고 휠로 교체)

| 작물 | 기본 탄 | 고유 스킬 |
|---|---|---|
| 양파 | 단발, 균형형 | 매운 가스 — 주변 적 시야 방해(공격 지연) |
| 당근 | 관통 저격, 느림 | 약점 조준 모드 — 잠깐 시간 느려짐 |
| 마늘 | 산탄, 근거리 | 악취 오라 — 가까이 온 적 넉백 |
| 부추 | 빠른 연사, 약함 | 채찍 — 적 하나를 끌어당김 |

**강해지는 방법 (런 중)**: 작물 획득(큰 변화) + 카드(수치·효과) + 작물 레벨업(같은 작물 중복 획득 시)

### A-2. 협동감 & 양파의 게임성

- **양파의 재미 = 조준·약점 저격·탄약 관리·무기 교체 판단.** 이동은 없지만 "무엇을 어디에 언제 쏠지"가 전부 양파 몫
- 약점 시스템: 큰 적·보스에 **양파만 맞출 수 있는 약점**(빛나는 부위) → 명중 시 경직 → 고양이가 들어가 딜
- 협동 루프: 고양이가 위치를 잡아줌 → 양파가 약점 저격 → 경직 → 고양이 근접 딜 (협동 콤보 ×1.5)
- 소통이 자연스럽게 생김: "왼쪽으로 좀 가줘!", "물 밟아줘, 탄 없어!"

### A-3. 런 간 성장

- **해금 중심**: 씨앗으로 온실에서 **새 작물을 재배(해금)** → 다음 런부터 드롭 풀에 등장
- 영구 스탯은 아주 소량 (최대 체력 +10 × 3단계 정도)
- 기억 파편: 보스 처치 시 획득, 스토리 해금 (공통)

### A 평가

| 좋은 점 | 걱정 |
|---|---|
| 작물=무기 설정과 가장 잘 맞음. 보상이 눈에 확 보임 | **양파가 주인공, 고양이가 운전수**로 느껴질 위험 (A-1 덮치기로 보완해도 쏠림) |
| 슈팅 게임을 좋아하는 사람에게 양파 재미가 확실 | **패드 양파가 불리** (정밀 조준이 핵심이라) |
| 구현이 비교적 단순 (탄 종류 = 프리팹 교체) | 실력이 조준 실력에 직결 → 초보 양파가 답답할 수 있음 |

## 3. 초안 B — 「떠도는 정원」 (정원사형)

> **한 문장: "양파가 전장에 정원을 심고, 고양이가 그 정원을 무기로 싸운다"**
> 참고: 타워디펜스의 설치 판단 + Hades의 근접 액션. 세계관(떠도는 정원·씨앗)과 가장 밀착

### B-1. 전투

**고양이 (전사)**
- 기본: 할퀴기 3타 콤보 · 대쉬
- 특수: **걷어차기** — 적을 크게 날려보냄 (쿨다운 4초). **심어둔 식물 쪽으로 차 넣는 것**이 핵심 사용법
- 날아간 적이 벽·다른 적·식물에 부딪히면 추가 피해

**양파 (정원사)**
- 기본: 씨앗 탄 (좌클릭) — 약한 견제 사격. 딜의 주력이 아님
- 특수: **심기** (휠 클릭) — 커서 위치에 식물을 심는다. **씨앗 게이지** 소모 (적 처치·협동 콤보로 충전)
- 선택: 휠 굴리기로 들고 있는 씨앗 3종 중 선택
- 실드: 노란 공격 1회 차단 (현행 유지)

**식물 (예시)**

| 식물 | 효과 | 고양이와의 연계 |
|---|---|---|
| 가시덩굴 | 밟은 적 둔화 + 지속 피해 | 걷어차서 덩굴에 넣으면 속박 |
| 터지는 박 | 적이 닿거나 공격받으면 폭발 | 걷어차서 박에 맞추면 연쇄 폭발 |
| 해바라기 | 주변 고양이 공격속도↑ | 고양이가 근처에서 싸우면 강해짐 |
| 민들레 | 고양이가 지나가면 씨앗 게이지 충전 | 고양이가 "수확"하러 가야 함 |
| 치유 새싹 | 다 자라면(5초) 고양이가 먹어 체력 회복 | 안전할 때 먹으러 가는 판단 |

- 식물은 **방을 나가면 사라짐**. 동시에 최대 3~4개 (화면이 지저분해지지 않게)
- 식물은 적의 빨간 공격에 파괴될 수 있음 → 위치 선정이 판단

**강해지는 방법 (런 중)**: 새 씨앗 종류 획득 · 식물 강화 카드("가시덩굴이 2배 넓게") · 고양이 발톱 카드 · **접목 카드**(두 식물 특성 합치기, 예: 폭발하는 가시덩굴)

### B-2. 협동감 & 양파의 게임성

- **양파의 재미 = "공간을 설계하는 것".** 몸은 못 움직이지만 전장의 지형을 바꾼다 → 이동의 부재를 **배치로** 대체
- 템포가 다른 두 역할: 고양이는 초 단위 반사신경, 양파는 방 전체를 보는 판단 → **실력 차이가 있는 커플에 잘 맞음**
  (게임을 덜 해본 쪽이 양파를 해도 기여가 크고, 잘하는 양파는 콤보 설계로 깊이가 생김)
- 협동 루프: 양파가 덩굴·박을 심음 → 고양이가 적을 차 넣음 → 연쇄 폭발. **둘 중 하나만으로는 안 되는** 큰 한 방
- 소통: "거기 박 심어놨어, 그쪽으로 차!", "해바라기 옆에서 싸워"
- **조준 정밀도가 덜 중요** → 패드 양파도 쾌적 (심기는 격자 스냅 가능)

### B-3. 런 간 성장

- **로드아웃 중심**: 온실에서 씨앗 품종을 재배(해금)하고, **런 시작 전 들고 갈 씨앗 3종을 고른다**
  → "이번엔 폭발 조합으로 가자" 같은 **런 전 작전 회의**가 커플 대화거리가 됨
- 고양이는 **발톱 장신구** 1개 선택 (해금형, 예: 걷어차기 쿨다운↓ / 대쉬 2회)
- 영구 스탯 소량 + 기억 파편 (공통)

### B 평가

| 좋은 점 | 걱정 |
|---|---|
| **"움직이지 못하는 양파"라는 약점을 정체성으로 바꿈** | 식물 AI·충돌·연쇄 판정 등 **시스템 구현량이 가장 많음** |
| 세계관(떠도는 정원, 씨앗 화폐)과 완전히 일치 → 한 문장이 명확 | 화면이 복잡해질 위험 → 식물 수 제한·색 구분 필수 |
| 실력 차이 수용이 가장 좋음. 패드/마우스 둘 다 자연스러움 | 양파의 "직접 때리는 손맛"이 약함 (씨앗 탄·폭발 연출로 보완) |

## 4. 초안 C — 「한 몸 두 마음」 (공명형)

> **한 문장: "둘이 박자를 맞출수록 강해지고, 빌드도 둘이 함께 만드는 게임"**
> 참고: Hades 듀오 축복, It Takes Two(둘이 동시에 해야 풀리는 기믹), 리듬 협동

### C-1. 전투

**고양이**
- 기본: 할퀴기 3타 콤보 · 대쉬
- 특수: **발톱 기술** — 런 중 **분화**하는 기술 1개 (시작: 회전베기 → 분화 예: 돌진베기 / 연속할퀴기 / 할퀴어 띄우기)

**양파**
- 기본: 씨앗 탄 (좌클릭)
- 특수: **작물 기술** — 역시 분화 (시작: 충전탄 → 분화 예: 산탄 / 관통 / 유도)
- 실드: 노란 공격 1회 차단 + **타이밍 맞추면 패링**(보조, 성공 시 공명 게이지 보너스)

**핵심: 공명 게이지 (둘이 공유)**
- 고양이 공격과 양파 공격이 **번갈아** 맞을수록 빠르게 참 (현재 협동 콤보를 확장)
- 한쪽만 계속 때리면 거의 안 참 → 자연스럽게 "주고받는" 리듬이 생김
- 게이지가 차면 **합동기**: **두 사람이 1초 안에 각자 버튼을 눌러야** 발동
  - 예: "양파 폭풍" — 고양이가 회전하며 양파가 사방으로 씨앗을 뿌림 (화면 정리용 대기술)
  - 한 명만 누르면 발동 대기 표시 → 상대가 눌러주면 발동 (실수해도 날아가지 않음)

**강해지는 방법 (런 중)**
- 각자 카드는 **단순**하게 (수치·분화)
- **듀오 카드**: 고양이 카드 X + 작물 카드 Y를 둘 다 가지면 등장하는 특별 카드
  (예: 고양이 "불꽃 발톱" + 양파 "기름 씨앗" → 듀오 "화염 정원": 씨앗 맞은 적을 할퀴면 폭발)
- **카드 선택권 교대**: 방마다 카드를 고르는 사람이 번갈아 바뀜 → 상대 빌드를 보고 맞춰주는 선택이 생김

### C-2. 협동감 & 양파의 게임성

- **양파의 재미 = "지휘자"**: 공명 게이지 관리, 합동기 타이밍 호출, 패링으로 게이지 보너스, 듀오 카드를 노린 빌드 방향 결정
- 협동이 **시스템 차원에서 강제**됨 → "같이 하고 있다"는 감각이 가장 강함
- 소통: "지금 합동기 쓸게, 눌러!", "나 불꽃 발톱 먹었으니까 너 기름 씨앗 골라"
- 입력 부담 중간: 조준은 필요하지만 A만큼 정밀도가 결정적이지 않음

### C-3. 런 간 성장

- **유대(Bond) 레벨**: 함께 클리어한 방·합동기 사용 횟수로 오름 → **새 합동기·듀오 카드 해금** (둘이 같이 쌓는 성장)
- 온실: 영구 스탯 소량 + 분화 갈래 해금 (씨앗 화폐)
- 기억 파편 (공통)

### C 평가

| 좋은 점 | 걱정 |
|---|---|
| **협동 정체성이 가장 강함.** "혼자 하는 게임 둘"이 될 수 없음 | 둘의 합이 안 맞으면 **서로 탓하게 될 위험** (게이지 설계를 관대하게 해야) |
| 이미 있는 협동 콤보·카드 구조를 그대로 확장 → 초기 구현이 가장 빠름 | 분화마다 애니메이션·이펙트 필요 → 장기 제작량 큼 |
| 듀오 카드 발견이 반복 플레이 동기 | 양파의 "자기만의 영역"이 B보다 약함 (고양이와 비슷한 공격 역할) |

## 6. 추천

**B(떠도는 정원)를 뼈대로, C의 공명 게이지·듀오 카드를 살로 붙이는 안.**

이유:
1. **"양파는 움직이지 못한다"는 문제를 가장 근본적으로 푼다** — 몸 대신 전장을 움직인다. A·C는 양파를 "움직이지 않는 사수"로 두고 보완하는 쪽
2. **목표 플레이어(실력 차이가 있는 커플·친구)**에 가장 맞는다 — 템포가 다른 두 역할이라 누가 어느 쪽을 해도 기여감이 있다
3. **입력 고민이 사라진다** — 정밀 조준이 핵심이 아니라 패드+마우스, 패드+패드 모두 성립
4. 게임 제목·세계관(정원·씨앗·작물)과 한 문장이 맞아떨어진다

C에서 가져올 것: 공명 게이지 → 합동기 (협동 콤보의 확장, 이미 절반 구현됨), 듀오 카드(식물 × 발톱)
A에서 가져올 것: 작물별 기본 탄 차이 (당근=관통 등) 정도만. 작물 교체는 메타 해금으로

### 검증 방법 (결정 전에 작게 만들어보기)

지금 있는 스테이지 1에 **식물 1종(터지는 박) + 고양이 걷어차기**만 넣어서 플레이해본다 (반나절~하루 분량).
- "박에 적을 차 넣는 게 재밌나?" → 재밌으면 B 확정
- 양파 플레이어가 "심고 기다리는 게 지루하다"고 하면 → 씨앗 탄의 비중을 올리거나 C 쪽으로 기운다
