### 모든 설계가 지킬 제약 (변경 없음)

1. **2인 1캐릭터** — 보상이 한 명에게만 쏠리지 않게
2. **비대칭 철칙** — 고양이는 원거리 공격을 하지 않고, 작물은 움직이지 않는다
3. **협동에 이유가 있어야** — 혼자 하는 게임 둘을 붙인 것처럼 되면 실패
4. **읽을 수 있어야** — 빌드는 복잡해도 화면은 단순하게
5. **실력 차이 수용** — 역할별 난이도. 실수 한 번에 런이 끝나지 않게
6. **쉬워도 도전의식이 생기게** — 예고(노랑=막기 가능 / 빨강=피하기)와 확정 공격. 패링·실드는 보조

## 1. 입력

### 기본 구성: 고양이 = 패드, 양파 = 키보드+마우스

한 PC에서 2인이 할 때 가장 자연스러운 구성이다. 양파가 키보드를 쓰므로 **로컬 2인에서 고양이는 패드가 기본**이 된다.
(온라인 Remote Play Together라면 각자 아무 입력이나 가능)

| 양파 행동 | 키보드+마우스 (유미식) | 패드 (Shape of Dreams식) |
|---|---|---|
| 조준 | 마우스 커서 | **자동: 가장 가까운 적** / 오른스틱을 기울이면 수동 |
| 기본 공격 (씨앗 탄) | 좌클릭 (누르고 있으면 연사) | RT |
| 실드 | 우클릭 | LT |
| 스킬 1·2·3 (획득 스킬) | Q · W · E | X · Y · B (또는 RB+버튼) |
| 작물 고유기 (심기 계열) | R | RB |
| 아이템 1~5 | 1 ~ 5 | 십자키 (선택) + A (사용) |
| 합동기 | Space | LB |

| 고양이 행동 | 패드 | 키보드 (혼자 테스트용) |
|---|---|---|
| 이동 | 왼스틱 | WASD |
| 공격 (할퀴기) | X | F |
| 특수 | Y | G |
| 대쉬 | A | Space |
| 포효 | B | R |
| 합동기 | RB | E |

- **심기 위치 지정**: 마우스는 커서 위치. 패드는 "가장 가까운 적 발밑" 자동, 오른스틱으로 수동
- 양파 조작이 많아 보이지만, 처음에는 Q 하나만 있고 런이 진행되며 슬롯이 채워진다 (하데스·Shape of Dreams와 같은 학습 곡선)
- **양파 쉬움 난이도**: 조준 보정 강화, 쿨다운 끝난 스킬 자동 시전 옵션

## 2. 고양이 — 하데스식 "축복" 성장

### 2-1. 기본 동작 (행동 슬롯 4개)

| 슬롯 | 기본 동작 | 비고 |
|---|---|---|
| **공격** | 할퀴기 3타 콤보 (3타째 넉백 큼) | 현재 구현 |
| **특수** | 걷어차기 — 적을 크게 날려보냄. **식물 쪽으로 차 넣기**가 핵심 사용법 | 신규. 날아간 적이 벽·적·식물에 부딪히면 추가 피해 |
| **대쉬** | 짧은 무적 이동 | 현재 구현 |
| **포효** | 주변 적 경직 + 시선 끌기 (쿨다운 8초) | 하데스의 '캐스트' 자리. 철칙상 원거리 투사체 대신 **근거리 범위기** |

### 2-2. 축복 — 정원 정령 4종 (가칭)

하데스의 신들처럼, 방 보상으로 **정령의 축복**을 받는다. 축복은 위 4개 슬롯 중 하나에 붙고, 슬롯당 1개다. 같은 슬롯에 새 축복을 받으면 기존 축복과 교체할지 고른다.

| 정령 | 테마 | 공격 슬롯 축복 예 | 대쉬 슬롯 축복 예 |
|---|---|---|---|
| ☀️ 햇살 | 화상 (지속 피해) | 할퀴기가 화상을 입힘 | 대쉬 경로에 불꽃 |
| 🌧️ 빗물 | 둔화·젖음 | 할퀴기가 적을 젖게 함 (다음 피해 증가) | 대쉬 끝에 물웅덩이 |
| 🍃 바람 | 넉백·속도 | 3타째 넉백이 2배 | 대쉬 2회 충전 |
| 🪨 흙 | 방어·가시 | 할퀴기 적중 시 보호막 획득 | 대쉬 중 닿은 적 기절 |

- **패시브 축복**: 슬롯에 붙지 않는 효과 (예: 체력 50% 이하면 공격력 증가)
- **축복 강화**: 같은 정령의 축복이 겹치면 등급이 오름 (하데스의 일반 → 영웅 → 전설)
- 세계관 연결: 떠도는 정원을 지키던 정령들이 마법사의 정원을 되찾으려는 둘을 돕는다

## 3. 양파 — Shape of Dreams식 "스킬 조합" + 심기

### 3-1. 작물 = 캐릭터 (런 시작 전 선택)

작물마다 **기본 탄**과 **고유기(R, 심기 계열)**가 다르다. 심기의 성격이 곧 작물의 특성이다.

| 작물 | 기본 탄 | 고유기 (R) — 무엇을 심는가 | 성격 |
|---|---|---|---|
| 🧅 양파 | 단발, 균형형 | **매운 양파** — 주변 적 시야 방해 (공격이 늦어짐) | 적 약화 |
| 🥕 당근 | 관통, 느림 | **당근 포탑** — 가까운 적을 자동 사격 | 공격 |
| 🧄 마늘 | 짧은 산탄 | **마늘 울타리** — 적을 막는 벽, 닿으면 넉백 | 공간 통제 |
| 🌿 부추 | 빠른 연사, 약함 | **캣닢 덤불** — 안에 있는 고양이 공격속도·이동속도 증가 | 고양이 강화 |

- 처음에는 양파만 쓸 수 있고, 나머지는 온실에서 해금한다 (4장)
- 심어둔 식물은 **방을 나가면 사라진다**. 동시에 최대 3개 (화면 복잡도 제한)
- 식물은 적의 빨간 공격에 파괴될 수 있다 → 어디에 심을지가 판단

### 3-2. 획득 스킬 (Q·W·E) — 런 중 조합

방 보상으로 스킬을 얻어 Q·W·E 슬롯에 넣는다. 슬롯이 차면 교체한다.
스킬은 **4계열**로 나뉘고, 같은 계열을 모으거나 섞으며 빌드를 짠다.

| 계열 | 스킬 예 | 역할 |
|---|---|---|
| 🌱 **심기** | 가시덩굴 (둔화+지속피해) · 터지는 박 (닿으면 폭발) · 반딧불 꽃 (주변을 밝힘) | 공간 설계 |
| 💚 **돌봄** (유미식) | 영양제 (고양이 회복) · 뿌리 갑옷 (고양이 보호막) · 광합성 (고양이 다음 공격 강화) | 고양이 지원 |
| 🎯 **사격** | 충전탄 · 산탄 · 유도 씨앗 · 꿰뚫는 가시 | 직접 딜 |
| 🌀 **방해** | 포자 구름 (적 경직) · 넝쿨 올가미 (적을 끌어옴) · 꽃가루 (적 실명) | 적 약화 |

**스킬 변형 (조합의 핵심)**
- 스킬마다 **변형 요소(가칭: 비료)**를 붙일 수 있다
  - 예: 터지는 박 + **"번식" 비료** = 터질 때 작은 박 2개를 남김
  - 예: 유도 씨앗 + **"씨앗 심기" 비료** = 맞은 자리에 가시덩굴이 자람 → 사격 계열이 심기 계열과 이어짐
- 같은 스킬을 다시 얻으면 레벨업 (피해·범위·쿨다운)

**아이템 (1~5)**
- 소모품: 회복 열매, 폭탄 씨앗, 정령의 이슬(축복 등급 1회 상승) 등
- **가방은 양파가 관리**한다 → 양파 = 보급·지휘 담당이라는 정체성 강화 (고양이는 싸움에 집중)

### 3-3. 양파의 게임성 — "움직이지 않는 대신 하는 일"

| 양파의 일 | 재미 |
|---|---|
| 조준 (사격·방해) | 직접 손맛. 약점 저격 |
| 심기 | 전장을 설계. 고양이가 싸울 무대를 만듦 |
| 돌봄 | 유미처럼 고양이를 살리는 판단 |
| 가방·아이템 | 언제 회복할지, 폭탄을 쓸지 |
| 실드 | 노란 공격 막기 (보조) |
| 합동기 호출 | 타이밍을 정하는 지휘자 |

→ 계열을 어떻게 모으느냐에 따라 **같은 양파라도 플레이가 완전히 달라진다**
(심기 위주 = 전략가 / 사격 위주 = 딜러 / 돌봄 위주 = 서포터)

## 4. 협동 — "같이 하고 있다"는 느낌

### 4-1. 협동 콤보 → 합동 게이지 (현재 구현의 확장)

- 고양이 공격과 양파 공격이 **1초 안에 번갈아** 맞으면 ×1.5 (구현됨)
- 협동 콤보가 터질 때마다 **합동 게이지**가 찬다. 한쪽만 때리면 거의 차지 않는다
- 패링 성공·식물 연계(식물에 적을 차 넣기)도 게이지를 채운다

### 4-2. 합동기 (ARCHONS식)

- 게이지가 가득 차면 **두 사람이 1.5초 안에 각자 합동기 버튼**을 눌러 발동
  - 한 명이 먼저 누르면 화면에 "상대를 기다리는 중" 표시. 시간이 지나도 게이지는 사라지지 않는다 (실수에 관대하게)
- 발동 중 잠깐 무적 + 연출 (컷인 또는 줌인)
- **합동기 종류 = 고양이의 주 정령 × 양파의 작물**

| | ☀️ 햇살 | 🌧️ 빗물 | 🍃 바람 | 🪨 흙 |
|---|---|---|---|---|
| 🧅 양파 | 매운 불꽃 회오리 | 최루 폭우 | 매운 태풍 | 양파 지뢰밭 |
| 🥕 당근 | 당근 미사일 폭격 | … | … | … |

  → 처음엔 작물별 1개(4종)만 만들고, 정령 조합은 나중에 확장
- 주 정령 = 축복을 가장 많이 받은 정령 (UI에 표시)

### 4-3. 듀오 축복 (하데스 듀오 축복 × 양파 스킬)

고양이의 **특정 정령 축복** + 양파의 **특정 계열 스킬**을 둘 다 가지고 있으면 보상에 듀오 축복이 등장한다.

| 고양이 | 양파 | 듀오 축복 |
|---|---|---|
| ☀️ 햇살 축복 | 🌱 터지는 박 | **불꽃 박** — 고양이가 박을 때리면 화염 폭발 |
| 🍃 바람 축복 | 🌱 가시덩굴 | **가시 폭풍** — 걷어찬 적이 덩굴에 닿으면 덩굴이 퍼짐 |
| 🌧️ 빗물 축복 | 💚 영양제 | **단비** — 회복할 때 주변 식물이 즉시 다 자람 |
| 🪨 흙 축복 | 🌀 넝쿨 올가미 | **대지 고정** — 끌려온 적이 고양이 앞에서 기절 |

→ 두 사람이 **"너 그거 먹으면 듀오 나와!"** 하고 서로의 보상 선택에 참견하게 만드는 장치

### 4-4. 둘이 해야 풀리는 기믹 (It Takes Two식)

**원칙: 기믹을 못 풀어도 보상만 놓친다. 런이 끝나거나 진행이 막히지는 않는다.**
(주 경로를 막는 기믹은 아주 쉽게, 어려운 기믹은 보너스 방에)

| 종류 | 기믹 | 고양이 | 양파 |
|---|---|---|---|
| 방 | **쌍둥이 스위치** | 발판을 밟고 버팀 (적이 몰려옴) | 멀리 있는 수정을 쏨 |
| 방 | **어둠의 방** | 램프 반경만 보임 → 앞장서서 탐색 | 반딧불 꽃을 심어 길을 밝힘 |
| 방 | **덩굴 문** | 할퀴면 잠깐 열림 | 열린 틈에 씨앗을 심어 문을 영구히 고정 |
| 적 | **쌍둥이 정령** | 한 마리를 근접으로 | 다른 한 마리를 동시에 (2초 내) — 아니면 부활 |
| 적 | **뿌리 방패병** | 등 뒤로 돌아감 | 정면에서 시선을 끎 (방패병 구현됨 — 확장) |
| 보스 | **영웅 현자의 결계** | 결계 안에서 버팀 | 결계 밖 기둥 4개를 순서대로 쏨 |
| 보상 | **두 자물쇠 상자** | 리듬 타격 (할퀴기 타이밍) | 움직이는 과녁 맞히기 |

## 5. 런 흐름 예시 (스테이지 1, 7개 방)

| 방 | 보상 | 상태 |
|---|---|---|
| 시작 | — | 고양이: 기본 4슬롯 / 양파: 작물 고유기(R) + 빈 Q |
| 1 | 정령 축복 (햇살 공격) | 할퀴기에 화상 |

## 7. 제작 순서 제안 (작은 것부터 검증)

1. **양파 스킬 슬롯 구조** — Q·W·E·R 입력, 쿨다운 UI, 스킬 SO(ScriptableObject) 기반 클래스
   → 기존 업그레이드 카드(`UpgradeData`)를 스킬 획득 보상으로 확장
2. **식물 1종 (터지는 박) + 고양이 걷어차기** → "차 넣는 게 재밌나?" 검증
3. **고양이 축복 슬롯 구조** — 정령 1종(햇살)으로 공격·대쉬 축복 2개
4. **합동 게이지 + 합동기 1종** — 협동 콤보에 연결
5. 기믹 1종 (쌍둥이 스위치) — 방 템플릿에 넣기
6. 여기까지 플레이해보고 확장 여부 결정
