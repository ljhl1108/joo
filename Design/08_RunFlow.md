## 2. 지도 (슬레이 더 스파이어식) 🔶

스테이지마다 **갈림길 지도** 한 장. 방을 깨고 출구로 가면 지도가 열리고, 이어진 다음 방 중 하나를 고른다.

```
 층  0      1      2      3      4      5      6      7
    시작 ─┬ 전투 ─ 보물 ─ 전투 ─ 엘리트 ┬ 상점 ─┐
          ├ 전투 ─ 전투 ┬ 상점 ─ 전투 ─┴ 전투 ─┼ 휴식 ─ 보스
          └ 전투 ─ 엘리트 ┴ 보물 ─ 전투 ─ 보물 ─┘
```

| 규칙 | 내용 |
|---|---|
| 층 | 8층 (0 시작 · 1~5 갈림길 · 6 휴식 정원(저장) · 7 보스) → 한 스테이지에 방 8개, 3스테이지 ≈ 24방 ≈ 1시간 |
| 길 | 시작에서 3갈래로 출발, 층마다 옆 칸으로만 이어짐 (선이 엇갈리지 않게) |
| 방 종류 | 1층은 전투만. 2~5층: 전투 ≈ 50% · 보물 15% · 상점 13% · 엘리트 12% (3층부터) · 휴식 10% (3~4층). 스테이지마다 상점·보물이 적어도 하나씩 |
| 고르기 ✅ | 출구로 가면 지도가 열림 (게임 멈춤). P1 방향키 + 확인 / P2 마우스 클릭. **둘이 같은 곳을 고르면 바로, 한 명만 고르면 5초 뒤 그쪽으로** — 5초 안에 다른 곳을 고르면 "의견이 달라요" → 마지막에 고른 쪽으로 5초 다시 (2026-10-18 결정). 스테이지 고르기·물음표 방 선택지도 같은 방식 |
| 보기 | 지도는 언제든 `M` (패드 Select 길게 📝)로 볼 수 있음 |
| 당위성 | 앞으로 갈 길이 다 보이니까 "상점까지 씨앗을 모을지 / 엘리트로 세게 키울지 / 휴식 정원 쪽이 안전할지"를 **둘이 상의**하게 된다 |

- 📝 다음 단계: 보물방의 보상 축 미리보기(고양이 장비 / 양파 장비)

### 물음표 방 🔶 (2026-10-18 결정 → 구현)

지도에 `?` 방 (2~5층 약 14%, 스테이지마다 적어도 하나). 가운데 `?`를 밟거나 클릭하면 이야기 + 선택지 2~3개 — **둘이 상의해서** 고른다 (위 고르기 방식).
이벤트는 `Assets/Scripts/Map/RunEvents.cs` 표 (한 런에 같은 이벤트는 한 번).

| 이벤트 | 선택지 |
|---|---|
| 떠돌이 씨앗 상인 | 씨앗 30 → 희귀 이상 장비 / 씨앗 60 → 에픽 이상 / 지나간다 |
| 수상한 샘물 | 마신다: 체력 -20, 에픽 장비 / 병에 담아 판다: 씨앗 +20 / 지나간다 |
| 영웅의 짐 꾸러미 | 뒤진다: 반반 씨앗 +50 · 함정 체력 -15 / 조심조심: 씨앗 +15 |
| 기억의 꽃 | 향기: **기억 파편 +1** / 꽃잎: 체력 +30 |
| 도박하는 거북 | 씨앗 25 → 반반 +50 / 씨앗 50 → 반반 에픽 장비 / 지나간다 |
| 햇볕 드는 낮잠 자리 | 체력 +25 / 합동 게이지 가득 |
| 저주받은 화분 | 체력 -30, 전설급 장비 / 지나간다 |
| 버려진 손수레 | 장비 카드 / 씨앗 +30 |

- 📝 다음: 캐릭터를 만나는 이벤트 (새 고양이·작물 — 4장 해금), 스테이지별 전용 이벤트
- 📝 Shape of Dreams식 확장: 방에 들어가기 전 "보상 미리보기"(이 방을 깨면 무엇) — 지도 노드에 작은 아이콘

| 순서 | 스테이지 | 보스 | 비고 |

| 1 (고정) | 무너진 정원 | 영웅 기사 ✅ | 입문 |
| 가운데 (무작위 2개 중 고르기) | 버섯 늪 · 뿌리 지하 온실 · 서리 겨울 정원 | **성녀 궁수** 🔶 (어느 구역에 진을 쳤든) | 처음 런에선 1개, 해금되면 2개 → 3개 |

- 보스를 깨면 보스 보상(에픽 이상) → 다음 스테이지. 스테이지 사이에서 저장

### 해금 이야기 — 퀘스트를 깨면 이야기가 진행되며 길이 열린다 🔶 (2026-10-18 결정)

| 단계 | 조건 | 한 판 | 이야기 |
|---|---|---|---|
| 1 | 퀘스트 1 **"탑의 현자 마법사를 쓰러뜨려라"** | 정원 → 가운데 1 → 탑 (3스테이지) | 현자를 쓰러뜨렸지만 진짜 마법사의 흔적이 없다. 궁수가 떨어뜨린 지도 조각이 정원 깊은 곳을 가리킨다 |
| 2 | 퀘스트 2 **"정원 깊은 곳 두 구역에서 보스를 쓰러뜨려라"** (서로 다른 가운데 구역, 여러 런에 걸쳐도 됨) | 가운데 2개 (4스테이지) | 두 구역의 기억이 이어진다 — 오염된 수호자들이 무언가를 지키고 있었다 |

| 4 | (다 깸) | + 진짜 마지막 스테이지 (6스테이지 📝) | 진엔딩 |

- 퀘스트는 **마지막 보스까지 깬 런에서** 확인 → 엔딩 화면에 "퀘스트 완료 + 이야기 + 다음 목표". 못 깼으면 "다음 목표 (진행도)"

## 4. 방 모양을 다양하게 — 아이디어 📝

지금 방 12개는 글자 지도라 모양은 자유인데, 결국 "벽으로 둘러싼 사각형 + 안쪽 장애물"로 읽힌다. 다양하게 만드는 방향:

### A. 윤곽 자체를 바꾸기 (글자 지도로 바로 가능)
| 모양 | 플레이 차이 |
|---|---|
| **도넛** (가운데 큰 기둥·구덩이) | 빙글빙글 돌며 싸움 — 걷어차서 가운데 구덩이로 |
| **덤벨** (방 2개 + 좁은 통로) | 통로에서 길목 지키기 vs 넓은 쪽으로 끌어내기 |
| **섬** (구덩이 바다 위 섬 여러 개 + 다리) | 걷어차기 = 즉사, 원거리 적이 다른 섬에서 쏨 → 양파 활약 |
| **대각선·계단** | 사각 격자 느낌이 사라짐 |
| **긴 복도 (가로 3화면)** | 카메라가 따라감, 적이 파도처럼 |
| **원형 아레나** | 보스방 전용 느낌 |

### B. 바닥이 다른 방 (스테이지 특색 — 추천)
| 스테이지 | 지형 |
|---|---|
| 정원 | 덤불(들어가면 적이 못 봄) · 꽃밭 |
| 버섯 늪 | 얕은 물(느려짐, 젖음) · 독 웅덩이 · 버섯 발판(밟으면 튕겨 오름) |
| 온실 | 컨베이어 벨트 · 스프링클러 장치(주기적으로 젖음) · 유리 바닥(깨지면 구덩이) |
| 서리 정원 | 빙판(미끄러짐 — 걷어찬 적이 멀리 감) · 눈더미(부서지는 벽) |
| 탑 | 순간이동 마법진 · 회전하는 방(벽이 움직임) · 어둠(양파 빛 주변만 보임) |

### C. 조립식 방 (아이작·스펠렁키식)
- 방 = 큰 윤곽 1개 + 작은 "덩어리"(장애물 묶음 5×5) 여러 개를 무작위로 끼움 → 같은 방도 매번 다름
- 덩어리를 스테이지별로 → 스테이지마다 다른 느낌을 타일 없이도
- 지금 글자 지도에 "덩어리 자리" 글자(예: `?`)만 추가하면 된다

### D. 싸우는 중에 바뀌는 방
- 두 번째 파도에서 벽이 무너지며 방이 넓어짐 / 다리가 생김 / 물이 차오름

**추천 순서**: B(스테이지 지형 — 타일셋과 같이) → C(조립식 — 반복 피로 해결) → A는 방을 새로 그릴 때마다 조금씩 → D는 보스방부터

  - 메뉴 `OnionCat > Rooms > Add New Room Shapes` (모양은 `Assets/Editor/RoomShapeBuilder.cs`)
- C: 방 템플릿에 `?` = 덩어리 자리 → **방에 들어갈 때마다** 3×3 장애물 묶음 16종 중 하나를 무작위로 (좌우 뒤집기 포함) — 새 방 6개에 자리 10곳
  - 덩어리 목록 `Resources/RoomChunks.asset` (메뉴 `OnionCat > Rooms > Build Room Chunks`), 기존 방에도 `?`를 넣으면 바로 적용
