## 1. 길 — 고정된 마을, 무작위 스테이지 ✅

```
언덕 위 농장 → 1 → 2 → ■ 마을 → 3 → 4 → ■ 등대 입구 → 5 → ■ 등대탑 → 6 (최종)
```

| 자리 | 테마 | 정해지는 법 |
|---|---|---|
| 1 | 해 질 녘 밀밭 | 고정 |
| 2 | 독안개 늪 · 시든 유리온실 · 서리 과수원 | 무작위 (고르지 않음 — 다 고르게 하면 판이 획일화) |
| 3 · 4 | 2단계 풀 | 무작위 — 새 테마를 고르기 전까지 1단계 테마의 **밤 버전** |
| 5 | 등대 오르는 길 (바다 절벽) | 고정 |
| 6 | 별 없는 하늘 | 고정 |

- **판이 끝나는 곳 = 이야기 단계** (`StoryRoute.EndIndex`): 1단계 마을 · 2단계 등대 입구 · 3단계 등대탑 · 4단계 최종
- 마을은 스테이지 사이의 장면 — 등불(빛 색깔 퀘스트) · 샘물 · 가판대 (`StepKind.Village`)
- 스테이지가 오를수록 적 체력 ×1.35씩, 위험도 상한 +1

## 2. 갈림길 지도 ✅

스테이지마다 지도 한 장 (슬레이 더 스파이어식). 방을 깨고 출구로 가면 지도가 열리고, 이어진 다음 방 중 하나를 고른다.

```
 층  0      1      2      3      4      5      6      7
    시작 ─┬ 전투 ─ 보물 ─ 전투 ─ 엘리트 ┬ 상점 ─┐
          ├ 전투 ─ 전투 ┬ 상점 ─ 전투 ─┴ 전투 ─┼ 휴식 ─ 보스
          └ 전투 ─ 엘리트 ┴ 보물 ─ 전투 ─ 보물 ─┘
```

| 규칙 | 내용 |
|---|---|
| 층 | 8층 — 0 시작 · 1~5 갈림길 · 6 휴식 정원(저장) · 7 보스 |
| 길 | 시작에서 3갈래, 층마다 옆 칸으로만 이어짐 (선이 엇갈리지 않게) |
| 방 비율 | 1층은 전투만. 2~5층: 전투 ≈ 50% · 보물 15% · 상점 13% · 엘리트 12% (3층부터) · 휴식 10% (3~4층) · 물음표 ≈ 14%. 스테이지마다 상점·보물·물음표가 적어도 하나씩 |
| 고르기 | P1 방향키 + 확인 / P2 마우스. **둘이 같은 곳을 고르면 바로, 한 명만 고르면 5초 뒤 그쪽으로.** 5초 안에 다른 곳을 고르면 "의견이 달라요" → 마지막에 고른 쪽으로 5초 다시 |
| 보기 | **M** = 언제든 지도 보기 (패드 Select 길게 📝) |

**왜 지도인가** — 앞길이 다 보이니까 "상점까지 씨앗을 모을지 / 엘리트로 세게 키울지 / 휴식 쪽이 안전할지"를 **둘이 상의**하게 된다. 예전 출구 표식 두 개 고르기는 앞이 안 보여 고르는 이유가 약했다.

📝 다음: 노드에 보상 미리보기 (보물방·엘리트가 고양이 장비인지 작물 장비인지)

## 3. 물음표 방 ✅ — 하이리스크 하이리턴

가운데 `?`를 밟거나 클릭하면 이야기 + 선택지 — 고르기는 지도와 같은 방식. 표 `Assets/Scripts/Map/RunEvents.cs` (한 판에 같은 이벤트는 한 번).

### 손해 규칙

- **바로 끝나는 손해**(지금 체력·씨앗·매복 전투)는 그대로
- **능력치 손해**(최대 체력·받는 피해·대쉬 봉인)는 **"방 N개 동안"만** — `TimedEffects`, HUD 왼쪽 위에 남은 방 수, 중간 저장됨
- "지나간다"는 항상 있고, 결과는 고르기 전에 다 보인다 (확률은 도박 이벤트만)

> 근거 (2026-10-22 피드백): "합동 게이지·체력 같은 효과는 흥미가 안 생김" · "최대 체력이 영구로 줄면 다음엔 물음표 방을 안 갈 것 같다"

### 이벤트 10개

| 이벤트 | 크게 얻는 것 | 크게 잃는 것 |
|---|---|---|
| 악마의 계약 | 전설급 장비 고르기 | 최대 체력 −30% (3방) |
| 저주받은 왕관 | 주는 피해 ×2 (4방) | 받는 피해 ×2 (4방) |
| 도박꾼의 상자 | 50% 전설급 장비 | 50% 엘리트 3마리 매복 (이기면 에픽) |
| 피의 제단 | 에픽 이상 장비 | 지금 체력 절반 — 또는 씨앗 60 |
| 시간의 모래시계 | 적 체력 절반 (3방) | 대쉬 봉인 (3방) |
| 영웅의 유물 | 기억 파편 +3 | 이번 스테이지 보스 체력 +50% |
| 금지된 씨앗 | 전설급 장비 고르기 | 방에 들어갈 때마다 체력 −8 (4방) |
| 영웅의 짐 꾸러미 | 50% 씨앗 +80 | 50% 매복 3마리 (이기면 희귀) |
| 도박하는 거북 | 34% 씨앗 ×3 | 66% 씨앗 전부 잃음 (20 이상일 때) |
| 기억의 꽃 | 기억 파편 +2 | 받는 피해 ×2 (2방) |

- **매복** = 그 방에 엘리트가 나타남 (위험도 = 스테이지 + 2, 고양이에게서 떨어진 곳). 다 쓰러뜨리면 보상 (`DungeonManager.StartAmbush`)

### 아직 안 넣은 안 📝

| 안 | 내용 |
|---|---|
| 거울의 방 | 고양이·작물 장비 맞바꿈 |
| 둘의 저울 | 한 사람 장비 +2, 다른 사람 −1 |
| 세트 즉시 장착 | 무작위 세트 효과를 바로 붙임 |
| 캐릭터를 만나는 이벤트 | 길 잃은 고양이·작물을 데려오면 해금 (4장) |
| 스테이지 전용 이벤트 | 테마마다 하나씩 |
