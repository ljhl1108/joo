# 맵과 런 구조

> 구현된 방 시스템(글자 지도·무작위 순서·앞뒤 정렬)은 `00_Implemented.md` 8장. 이 문서는 **런 구조와 앞으로 만들 방**.
> ✅ 구현됨 · 🔶 잠정 · 📝 계획 · ❓ 결정 대기

---

## 1. 진행 방식 — 방 연결형 (하데스식) ✅

방 하나를 깨면 출구로 다음 방. 층을 돌아다니는 탐색형(아이작)은 쓰지 않는다.

- **작물이 소외되지 않는다** — 탐색형은 어디로 갈지를 움직이는 고양이가 정하고, 되돌아가는 동안 작물은 구경꾼이 된다
- **출구 선택이 곧 대화** — "보물방 갈까, 상점 갈까?" 다음 방을 둘이 상의해서 고른다
- 템포가 빠르고 런 길이를 맞추기 쉽다
- 약점(탐험 부족)은 방 안의 비밀(부서지는 벽·숨은 화분)과 특수 방으로 보완

## 2. 런 구조 — C안 (섞은 방식) ✅

🔶 **런 길이 약 1시간.** 스테이지 수·방 수는 해 보고 조정. 중간 저장이 있다 (`05_Items.md` 6장).

| 방 | 내용 | 보상 | 상태 |
|---|---|---|---|
| **시작방** | 런·스테이지 시작 | — | ✅ |
| **전투방** | 일반 전투 | 씨앗 + 낮은 확률로 일반·희귀 장비 | ✅ 전투 / 📝 보상 |
| **보물방** (2~3방마다) | 전투 없음 | 각자 3개 중 1개 동시 선택 | 📝 (지금은 전투방마다 이 화면이 뜸) |
| **엘리트방** (선택 경로) | 엘리트 변종·미니보스, 어려움 | 에픽 이상 확정 | 📝 |
| **상점** (스테이지마다 1곳) | 씨앗으로 구매·리롤·**효과 갈아끼우기** | — | 📝 |
| **휴식 정원** | 체력 회복 / 효과 갈아끼우기 / **저장** | — | 📝 |
| **기믹 보너스 방** | 2인 기믹 (`04_Combat.md` 3장). 못 풀어도 보상만 놓침 | 좋은 보상 | 📝 |
| **보스방** | 스테이지 끝 | 전설 확률이 있는 상자 → 다음 스테이지 | ✅ 보스 / 📝 상자 |

- **출구 앞 표식으로 다음 방 종류를 미리 보여주고 고른다** (보물방 / 엘리트 / 상점). 고양이는 밟고 양파는 클릭
  - ✅ 표식 자체는 구현됨 (지금은 v3 "중점 축" 표식 — 방 종류 표식으로 교체 예정)
- 고르는 횟수를 줄이고 **선택 하나하나의 무게를 키운다** (1시간 런에서 메뉴 시간이 길어지지 않게)

### 스테이지 흐름 예 (🔶 수치는 조정)

```
[시작] → 전투 → 전투 → (표식: 보물방 / 엘리트) → … → [상점] → 전투 → [휴식 정원·저장] → [보스] → 다음 스테이지
```

## 3. 스테이지 (3개)

| 스테이지 | 컨셉 | 적 성향 | 색 | 보스 |
|---|---|---|---|---|
| 1 | **무너진 정원** (지상) | 식물형 — 근접 취약 위주 (고양이 주도) | 따뜻한 초록·노랑 | 영웅 기사 ✅ |
| 2 | **뿌리 지하 온실** | 골렘·관리 구조물 — 원거리 취약 위주 (작물 주도) | 차가운 파랑·금속 | 성녀 궁수 |
| 3 | **마법사의 탑** | 혼합 + 협동 적 (실드·반사 어픽스) | 보라·암흑 | 현자 마법사 |

- 스테이지 테마 전환은 바닥·벽 타일 교체로 (방 글자 지도는 그대로 재사용)

## 4. 방 만들기

- 방 모양·적 배치는 **글자 지도**로 그린다 ✅ — 방법은 `Guides/room_layout.md`
- 방마다 난이도 등급(tier)을 매겨 런 순서에서 점점 어려워지게 ✅
- 장애물 = 벽(탄 막음·CRASH), 구덩이 = 걷어찬 적만 낙사 ✅
- 📝 특수 방 아이디어
  - **비밀 방**: 특정 벽을 할퀴면 균열 → 숨겨진 방 (좋은 장비 1개)
  - **어둠의 방**: 고양이 주변만 보임 → 양파가 반딧불 꽃을 심어 길을 밝힘
  - **덩굴 문**: 고양이가 할퀴면 잠깐 열리고, 양파가 틈에 씨앗을 심으면 영구 고정
  - **두 자물쇠 상자**: 고양이 리듬 타격 + 양파 움직이는 과녁
