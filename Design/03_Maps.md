## 1. 진행 방식 — 방 연결형 ✅

방 하나를 깨면 출구로 다음 방 (하데스식). 층을 돌아다니는 탐색형(아이작)은 쓰지 않는다.

| 이유 | |
|---|---|
| 작물이 소외되지 않는다 | 탐색형은 어디로 갈지를 움직이는 고양이가 정하고, 되돌아가는 동안 작물은 구경꾼이 된다 |
| 고르기가 곧 대화 | "보물방 갈까, 상점 갈까?" 다음 방을 둘이 상의한다 (지금은 갈림길 지도에서) |
| 템포 | 빠르고, 런 길이를 맞추기 쉽다 |
| 약점 보완 | 탐험이 부족한 것은 방 안의 비밀(부서지는 벽·숨은 화분)과 특수 방으로 |

## 2. 방 종류

| 방 | 내용 | 보상 | 상태 |
|---|---|---|---|
| 시작방 | 스테이지 시작 | — | ✅ |
| 전투방 | 일반 전투 (난이도 1~3 풀에서) | 씨앗 + 낮은 확률로 장비 | ✅ |
| 보물방 | 전투 없음 | 각자 3장 중 1장 동시 선택 | ✅ (상자 그림 🎨) |
| 엘리트방 | 강화된 적, 어려움 | 에픽 이상 우선 | ✅ 변종 / 📝 미니보스 |
| 상점 | 씨앗으로 구매·리롤·**효과 갈아끼우기** | — | ✅ (가판대 그림 🎨) |
| 휴식 정원 | 체력 회복 / 효과 갈아끼우기 / **저장** | — | ✅ (샘물 그림 🎨) |
| 물음표 방 | 이벤트 선택지 ([08_RunFlow](08_RunFlow.md) 3장) | 크게 얻거나 잃음 | ✅ |
| 마을 | 스테이지 사이의 장소 — 등불 · 샘물 · 가판대 | 빛 색깔 퀘스트 | ✅ (꾸미기 📝) |
| 기믹 보너스 방 | 2인 기믹 ([04_Combat](04_Combat.md) 3장). 못 풀어도 보상만 놓침 | 좋은 보상 | 📝 |
| 보스방 | 스테이지 끝 | 에픽 이상 → 다음 스테이지 | ✅ |

- 보물·상점·휴식·마을은 `Room_Special` 하나를 돌려 쓴다
- 고르는 횟수를 줄이고 **선택 하나하나의 무게를 키운다** — 1시간 런에서 메뉴 시간이 길어지지 않게

## 3. 방 모양

방은 **글자 지도**로 그린다 ✅ (W 벽 · X 덩어리 · o 구덩이 · ? 덩어리 자리 …). 그림은 방에 들어갈 때 스테이지 것으로 입혀진다.

| 방향 | 내용 | 상태 |
|---|---|---|
| **A. 윤곽 바꾸기** | 도넛 · 덤벨 · 섬 · 대각선 계단 · 긴 복도 · 원형 아레나 (방 13~18) | ✅ 2026-10-18 |
| **C. 조립식 덩어리** | 템플릿의 `?` 자리에 들어갈 때마다 3×3 장애물 묶음 16종 중 하나 (`RoomChunks`) — 같은 방도 매번 다름 | ✅ 2026-10-18 (새 방 6개에만 자리 10곳) |
| **B. 바닥이 다른 방** | 스테이지 지형 (아래 표) | 📝 다음 — 이어지는 특수 바닥 그림과 함께 |
| **D. 싸우는 중에 바뀌는 방** | 두 번째 파도에서 벽이 무너지며 넓어짐 · 다리가 생김 · 물이 차오름 | 📝 보스방부터 |

### B. 스테이지 지형 📝

| 스테이지 | 지형 |
|---|---|
| ST1 해 질 녘 밀밭 | 그림자 웅덩이 (적이 솟고, 빛을 비추면 줄어듦) · 밀밭 덤불 (들어가면 적이 못 봄) |
| ST2 독안개 늪 | 얕은 물 (느려짐·젖음) · 독 웅덩이 · 버섯 발판 (밟으면 튕겨 오름) |
| ST3 시든 유리온실 | 고양이 쪽으로 자라는 덩굴 · 스프링클러 (주기적으로 젖음) · 유리 바닥 (깨지면 구덩이) |
| ST4 서리 과수원 | 빙판 (미끄러짐) · 눈더미 (부서지는 벽) |
| ST5 등대 오르는 길 | 주기적으로 덮치는 파도 (밀려남) · 등대 빛이 훑을 때만 멀리 보임 |
| ST6 별 없는 하늘 | 빛 반경 안만 보임 |

테마 기믹의 이야기 쪽 이유는 [07_StoryMeta](07_StoryMeta.md) 1장 "스테이지 테마".

## 4. 특수 방 아이디어 📝

| 방 | 내용 |
|---|---|
| 비밀 방 | 특정 벽을 할퀴면 균열 → 숨겨진 방 (좋은 장비 1개) |
| 어둠의 방 | 고양이 주변만 보임 → 작물이 반딧불 꽃을 심어 길을 밝힘 |
| 덩굴 문 | 고양이가 할퀴면 잠깐 열리고, 작물이 틈에 씨앗을 심으면 영구 고정 |
| 두 자물쇠 상자 | 고양이 리듬 타격 + 작물 움직이는 과녁 |
