## 방 구성 방식

- 방 클리어 → 문 열림 → 다음 방 이동 (구현 완료)
- 방 종류:
  - 일반 전투방
  - 보상방 (아이템 / 업그레이드 선택)
  - 보스방
  - 상점방 (미정)
  - 이벤트방 (미정)

## 레이아웃 설계 방향
- 각 스테이지마다 타일셋 컨셉 구분
- 방 크기 / 장애물 배치는 스테이지 컨셉에 따라 변화
- 현재: SimpleMapGenerator 임시 사용 → 추후 프리팹 기반 방 시스템으로 교체
