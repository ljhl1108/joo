## 방 구성 방식

- 방 클리어 → 문 열림 → 다음 방 이동 (구현 완료)
- 방 종류:
  - 일반 전투방
  - 보상방 (아이템 / 업그레이드 선택)
  - 보스방
  - 상점방 (미정)
  - 이벤트방 (미정)

## 레이아웃 설계 방향
- 각 스테이지마다 타일셋 컨셉 구분
- 방 크기 / 장애물 배치는 스테이지 컨셉에 따라 변화
- 현재: SimpleMapGenerator 임시 사용 → 추후 프리팹 기반 방 시스템으로 교체
- **목표 구조** (Spelunky 참고): 4×4 그리드에서 클리어 경로 먼저 확보 후 나머지 방 배치. 초기엔 전투방 3~4종 + 보스방 1종만 있어도 충분. `DungeonGenerator.cs` 하나로 전체 레이아웃 관리
- 적 배치 시 `EnemySpawnPoint`에 `MeleeWeak` / `RangedWeak` 태그 부여 → 방 생성 단계부터 약점 시스템과 연동

## 특수 방 아이디어

- **비밀 연구실 방** (Binding of Isaac 참고): 특정 벽에 Cat 슬래시 3회 가하면 균열 → 숨겨진 방 개방. 내부에 고급 업그레이드 1개 보장. 벽 `hitCount` 변수로 관리
- **씬 전환 연출** (방 이동 시): 문 통과 시 즉시 이동 대신 0.3초 페이드 아웃 → 카메라 이동 → 0.3초 페이드 인. `FadeRoutine` 코루틴 재사용. 이동 감각이 세련되어짐
