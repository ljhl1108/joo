- 고양이 종류마다 **전용 무기**를 두면 캐릭터 정체성이 확실해진다 (하데스의 무기 선택처럼)

## 1. 칸 구성 ✅

| | 고양이 (P1) | 작물 (P2) |
|---|---|---|
| **무기** (기본 공격) | 1칸 — **고양이 종류 전용** (발톱 고양이 = 발톱만, 검 고양이 = 검만, 마법 고양이 = 지팡이만) | 1칸 — **작물 종류 전용** (씨앗 종류) |
| **장비** | 4칸: **머리 / 몸 / 발 / 장신구** | **마법서 3칸** (= 스킬 Q·W·E) + **화분 1칸** |
| **고유기** | — | R = 작물 무기의 고유기 (지금의 매운 양파·당근 포탑 등) |
| **패시브 아이템** | 🔶 최대 6개 (가지고 있으면 적용) | 🔶 최대 6개 |
| 합계 장비 칸 | 무기 1 + 장비 4 = 5 | 무기 1 + 마법서 3 + 화분 1 = 5 |

### 칸마다 바꾸는 것 (효과 설계 기준)

| 칸 | 주로 바꾸는 행동 | 효과 예 |
|---|---|---|
| 고양이 머리 | 특수 동작 (걷어차기·던지기) | 걷어찬 적이 불탐 / 털뭉치 3개 |
| 고양이 몸 | 방어·체력·실드 | 피격 시 주변 넉백 / 방 시작 시 실드 +1 |
| 고양이 발 | 이동·대쉬 | 대쉬 경로에 가시 / 대쉬 +1칸 |
| 고양이 장신구 | 조건부 (자유) | 체력 50% 이하일 때 공격 속도 증가 |
| 작물 마법서 ×3 | 스킬 (심기·돌봄·사격·방해) | 터지는 박 / 영양제 / 산탄 / 포자 구름 |
| 작물 화분 | 실드·패링 | 패링 성공 시 폭발 / 실드 2번 막기 |

- **고양이 행동은 고양이 종류가 정한 기본기 + 장비가 바꾸는 구조.** 지금의 할퀴기·걷어차기·털뭉치·대쉬가 "발톱 고양이"의 기본기가 된다.
- 작물의 지금 획득 스킬(Q·W·E)은 **마법서**로 옮긴다.

## 2. 아이템 = 기본 능력치 + 효과 1개 ✅

```
아이템 (예: 고양이 발 「불씨 장화」)
├─ 부위: 발
├─ 기본 능력치: 이동속도 +8%          ← 장비 자체 (레벨업하면 오름)
└─ 효과: 「불꽃 발자국」 — 대쉬 경로에 불꽃   ← 세트·등급이 붙는 곳
         세트: 햇살 / 등급: 희귀
```

- **세트 소속은 효과에 붙는다.** "화염 세트 아이템인데 얼음 효과"처럼 어색해지지 않게.
- 효과는 **행동을 바꾸는 것** 위주로 만든다. "+5% 공격력" 같은 숫자만 있는 효과는 지양 (숫자는 기본 능력치가 담당).
- 그래서 아이템을 설계할 때 **효과를 먼저 만들고**, 장비는 효과를 담는 그릇으로 본다.

### 등급 ✅ — 일반 · 희귀 · 에픽 · 전설

- 같은 아이템이 등급별로 있는 게 아니다. **아이템마다 등급이 하나 정해져 있다.**
- 등급이 높을수록 효과가 강하거나 특이하다. **전설에는 판을 뒤집는 사기급 아이템**이 있다.
  - 예: 「쌍둥이 그림자」 — 대쉬하면 0.5초 뒤 같은 경로로 분신이 한 번 더 지나감
- 색: 일반 흰색 / 희귀 파랑 / 에픽 보라 / 전설 주황

### 중복·분해 ✅

| 상황 | 처리 |
|---|---|
| **같은 아이템**을 또 얻음 | 그 아이템 **레벨업** — 기본 능력치가 단순히 오름 (효과는 그대로) |
| **같은 부위의 다른 아이템**을 얻음 | 둘 중 하나를 고르고, 나머지는 **분해** |
| 분해 | ① 씨앗(돈)을 받고 ② 그 **효과가 "효과 목록"에 등록**된다 |
| 효과 목록 | 같은 부위 장비라면 등록된 효과 중 **원하는 걸 골라 끼울 수 있다** (세트도 효과를 따라 바뀜) |

- 효과 갈아끼우기는 **상점·휴식 정원에서만** (전투 중 메뉴 시간 방지)
- 🔶 패시브도 분해 → 다른 패시브 레벨업에 쓰는 안 검토 중

## 3. 세트 ✅

- **고양이·작물의 장비 효과를 합쳐서** 센다 → 둘이 같은 세트를 노려야 완성된다 (협동 장치)
- 단계: **2 / 4 / 6 / 8**. 여러 세트를 섞어서 2+2+4처럼 조합할 수 있다
- 8세트는 두 사람이 장비 전부를 한 세트로 맞춰야 나오는 **어려운 만큼 성취감 있는 목표**
- 🔶 **세트 효과가 붙은 패시브는 아주 적게** (전설·에픽 일부만). 패시브 6칸이 세트를 쉽게 채우지 않게

## 4. 무기 표현 ✅ — 캐릭터 위에 겹쳐 그리기 (세피리아식)

- **고양이 그림에는 무기가 없다** (맨몸 동작). 무기는 별도 그림 1장을 손 위치에 겹쳐 그린다
- 공격 동작 = 코드로 무기 그림을 휘두르기(회전·찌르기) + 베기 이펙트
- 무기 종류(발톱·검·지팡이)마다 **공격 방식 코드가 다르다**. 같은 종류 안의 무기끼리는 그림·수치·효과만 다르다
- 장비(머리·몸 등)는 **아이콘만** — 캐릭터 그림은 바뀌지 않음 (아트 작업량 방지)

## 6. 중간 저장 (이어하기) ✅

1시간 런을 한 번에 끝내기 어려우므로 필수.

- **저장 시점:** 휴식 정원·스테이지 사이 (방 안 전투 중에는 저장 안 함 — 저장 남용 방지)
- **저장 내용:** 스테이지 번호·다음 방 순서·체력·장비·효과 목록·패시브·씨앗·합동 게이지·런 기록(시간·처치 수)
- **메인 메뉴:** 저장된 런이 있으면 **CONTINUE** 버튼. 새 런을 시작하면 저장을 덮어쓸지 확인
- **죽으면 저장 삭제** (로그라이크 규칙 — 되살리기 불가)
- 형식: JSON 파일 (`Application.persistentDataPath`), 메타 진행(온실·씨앗 해금)과는 다른 파일
