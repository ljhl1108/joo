## 0. 왜 장비인가 (2026-10-09, v3 업그레이드 카드를 대체)

- 보상 종류(체급·패시브·특수)가 많아져 **방마다 보상 종류를 나누기 어려웠다**
- "능력을 고른다"보다 **"아이템을 얻는다"**가 손맛·줍는 재미가 크다
- 고양이 종류마다 **전용 무기**를 두면 캐릭터 정체성이 확실해진다 (하데스의 무기 선택처럼)

| 참고 게임 | 가져온 것 |
|---|---|
| 세피리아 | 무기를 캐릭터 위에 겹쳐 그리기, 장비·효과 조합 |
| 하데스 | 무기 종류 = 플레이 방식 |
| 아이작 / 엔터 더 건전 | 보물방·상점·몹 드롭, 판을 뒤집는 전설 아이템 |
| 디아블로 | 장비 부위·세트 효과·바닥 드롭 (단, 능력치 나열은 피함) |

## 1. 칸 구성 ✅

| | 고양이 (P1) | 작물 (P2) |
|---|---|---|
| 무기 (기본 공격) | 1칸 — **고양이 종류 전용** (발톱 고양이 = 발톱만) | 1칸 — **작물 종류 전용** 씨앗 |
| 장비 | 머리 · 몸 · 발 · 장신구 | 마법서 3칸 (= 스킬 Q·W·E) · 화분 |
| 고유기 | — | R = 작물의 고유기 |
| 패시브 | 최대 6개 🔶 | 최대 6개 🔶 |

### 칸마다 바꾸는 것 (효과 설계 기준)

| 칸 | 주로 바꾸는 행동 | 효과 예 |
|---|---|---|
| 고양이 머리 | 특수 동작 (특수 공격·던지기) | 특수 공격에 맞은 적이 불탐 / 털뭉치 3개 |
| 고양이 몸 | 방어·체력·실드 | 피격 시 주변 넉백 / 방 시작 시 실드 +1 |
| 고양이 발 | 이동·대쉬 | 대쉬 경로에 가시 / 대쉬 +1칸 |
| 고양이 장신구 | 조건부 (자유) | 체력 50% 이하일 때 공격 속도 증가 |
| 작물 마법서 ×3 | 스킬 (심기·돌봄·사격·방해) | 터지는 박 / 영양제 / 산탄 / 포자 구름 |
| 작물 화분 | 실드·패링 | 패링 성공 시 폭발 / 실드 2번 막기 |

고양이 행동 = **고양이 종류가 정한 기본기 + 장비가 바꾸는 것**.

## 2. 아이템 = 기본 능력치 + 효과 1개 ✅

```
아이템 (예: 고양이 발 「불씨 장화」)
├─ 부위: 발
├─ 기본 능력치: 이동속도 +8%          ← 장비 자체 (레벨업하면 오름)
└─ 효과: 「불꽃 발자국」 — 대쉬 경로에 불꽃   ← 세트·등급이 붙는 곳
         세트: 햇살 / 등급: 희귀
```

- **세트는 효과에 붙는다** — "화염 세트인데 얼음 효과"처럼 어색해지지 않게
- 효과는 **행동을 바꾸는 것** 위주. "+5% 공격력" 같은 숫자는 기본 능력치가 담당
- 설계할 때 **효과를 먼저** 만들고, 장비는 효과를 담는 그릇으로 본다

### 등급 ✅

| 등급 | 색 | |
|---|---|---|
| 일반 | 흰색 | |
| 희귀 | 파랑 | |
| 에픽 | 보라 | |
| 전설 | 주황 | 판을 뒤집는 사기급 (예: 대쉬하면 0.5초 뒤 분신이 같은 경로로 한 번 더) |

아이템마다 등급이 하나 정해져 있다 (같은 아이템의 등급별 버전은 없음).

### 중복·분해 ✅

| 상황 | 처리 |
|---|---|
| 같은 아이템을 또 얻음 | **레벨업** — 기본 능력치만 오름 (효과는 그대로) |
| 같은 부위의 다른 아이템 | 새 것을 장착하고 기존 것은 **가방**으로 (8칸이 꽉 차면 분해) |
| 분해 | ① 씨앗을 받고 ② 그 **효과가 효과 목록에 등록** |
| 효과 목록 | 같은 부위 장비에 등록된 효과 중 원하는 걸 골라 끼움 (세트도 효과를 따라 바뀜) — **상점·휴식 정원에서만** |

## 3. 세트 ✅

- **고양이·작물의 장비 효과를 합쳐서** 센다 → 둘이 같은 세트를 노려야 완성 (협동 장치)
- 단계 **2 / 4 / 6 / 8**. 섞어서 2 + 2 + 4처럼 조합 가능
- 8세트는 두 사람이 장비 전부를 한 세트로 맞춰야 나오는 **어려운 만큼 성취감 있는 목표**
- 🔶 세트가 붙은 패시브는 아주 적게 (전설·에픽 일부만) — 패시브 6칸이 세트를 쉽게 채우지 않게
- 세트 10개와 단계별 보너스는 [05_Items_Content](05_Items_Content.md) 1장

## 4. 무기 표현 ✅ — 캐릭터 위에 겹쳐 그리기 (세피리아식)

- **고양이 그림에는 무기가 없다** (맨몸 동작). 무기는 별도 그림 1장을 손 위치에 겹쳐 그린다 🎨
- 공격 동작 = 코드로 무기 그림을 휘두르기(회전·찌르기) + 베기 이펙트
- 무기 종류(발톱·검·지팡이)마다 공격 코드가 다르다. 같은 종류 안의 무기끼리는 그림·수치·효과만 다름
- 장비(머리·몸 등)는 **아이콘만** — 캐릭터 그림은 바뀌지 않음 (그림 작업량 방지)

## 5. 아이템을 얻는 곳 ✅

| 어디서 | 무엇을 |
|---|---|
| 전투방 | 씨앗 + 바닥 장비 (가끔) |
| 보물방 | 각자 3장 중 1장 (동시 선택) |
| 엘리트방 | 에픽 이상 우선 |
| 상점 | 씨앗으로 구매·리롤·효과 갈아끼우기 |
| 휴식 정원 | 효과 갈아끼우기 · 저장 |
| 보스 | 에픽 이상 |
| 물음표 방 | 크게 얻거나 잃음 ([08_RunFlow](08_RunFlow.md) 3장) |

### 바닥 장비 ✅ (디아블로식, 2026-10-14)

- 적이 죽을 때 가끔 떨어짐 (방당 최대 3) — 등급 색 빛기둥 + 이름표 + 아이콘
- **방을 다 정리해야** 주울 수 있다 (싸우는 중에 줍느라 멈추지 않게)
- 고양이 밟기 / 작물 클릭 → **장비 주인에게** (공용은 주운 사람)
- 안 주우면 방을 나갈 때 씨앗으로

## 6. 중간 저장 ✅

1시간 런을 한 번에 끝내기 어려우므로 필수.

| 항목 | 내용 |
|---|---|
| 언제 | 스테이지 시작 · 휴식 정원 (방 안 전투 중에는 안 함 — 저장 남용 방지) |
| 무엇을 | 길·지도·지나온 길 · 체력 · 장비 · 효과 목록 · 패시브 · 가방 · 씨앗 · 게이지 · 방 N개 효과 · 런 기록 |

| 지울 때 | 죽거나 끝나거나 새로 시작하면 (로그라이크 규칙) |
| 파일 | `run_save.json` — 이야기 진행 `meta.json`과 별도 |
