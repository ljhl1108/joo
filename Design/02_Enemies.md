## 1. 텔레그래프 규칙 — 모든 적·보스 공통 ✅

- 공격 전에 색으로 예고: **노랑 = 양파가 막거나 패링 가능 (투사체류) / 빨강 = 막을 수 없음, 피해야 함 (돌진·접촉류)**
- **예고가 시작되면 공격은 확정** — 때려도, 도망가도 그대로 발동 (취소는 처치뿐). 돌진 중에는 넉백에도 안 밀림
  - 예외: 고양이 **걷어차기**는 예고를 끊는다 (특수기 보상). 보스는 끊기지 않음
- 예고 시간 기본 0.5초 — 📝 난이도 옵션 1순위 (쉬움 = 길게)
- 적 기본 색은 경고색(빨강·노랑)과 겹치지 않게 그린다

## 1-1. 2026-10-22 플레이 피드백 — "특성을 무시하고 패도 죽는다"

- 지금은 고양이가 세서 대부분의 적이 특성(반사·실드·장판 등)을 신경 쓰기 전에 죽음 → 새 적이 많아도 다양성이 체감 안 됨
- 방향 (❓ 어느 것부터):
  1. **임시 기준선**: 밸런스 전체는 나중이지만, "보통 적 = 할퀴기 5~6대, 큰 적 = 10대 이상" 같은 처치 시간(TTK)만 먼저 맞추면 특성이 보이기 시작함
  2. **조합**: 방마다 적을 무작위 대신 "서로 돕는 조합"으로 (등불 관리인 보호막 + 골렘, 허수아비 + 까마귀, 포탑 + 방패) — 아무나 패면 안 되고 순서가 생김
  3. **엘리트 어픽스**: 엘리트에 특성을 하나 더 (반사 버블·갑옷·분노 등)
  4. **무시하면 손해**: 반사 버블·수정 실드·결계처럼 "특성을 무시하면 피해가 안 들어가는" 적 비율을 늘림

## 2. 적 설계 원칙

- **패링을 강제하지 않는다** — 패링·실드로만 잡히는 적·패턴 금지. 패링은 "잘하면 더 크게" 보너스
- **공격 기회를 읽을 수 있게** — 보스의 무방비 시간처럼 "지금 때려라"가 보이는 구간을 만든다
- **협동하면 쉬워지는 적** — 혼자서도 잡히지만, 둘이 역할을 나누면 확실히 편해진다
  - 예 ✅: 방패 근위병 — 양파가 정면에서 시선을 끌고 고양이가 등을 친다
- 적 성향 비율로 스테이지 난이도 곡선: 1스테이지는 근접 취약 위주(고양이 주도) → 갈수록 균등·협동 위주
- 방향 약점은 적마다 각도·배율 설정 (정면 배율 0 = 완전 차단 "BLOCK")
