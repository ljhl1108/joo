## 1. 예고(텔레그래프) 규칙 ✅ — 모든 적·보스 공통

| 색 | 뜻 | 예 |
|---|---|---|
| 🟡 노랑 | 작물이 막거나 패링할 수 있음 | 투사체 |
| 🔴 빨강 | 막을 수 없음 — 피해야 함 | 돌진 · 접촉 · 장판 · 폭발 |

- **예고가 시작되면 공격은 확정** — 때려도 도망가도 그대로 발동 (취소는 처치뿐). 돌진 중에는 넉백에도 안 밀림
- 예고 시간 기본 0.5초 — 📝 난이도 옵션 1순위 (쉬움 = 길게)
- 적 기본 색은 경고색(빨강·노랑)과 겹치지 않게 그린다
- (걷어차기를 켜면 예고를 끊을 수 있음 — 지금 ⏸, 보스는 안 끊김)

## 2. 설계 원칙

| 원칙 | 뜻 |
|---|---|
| 패링을 강제하지 않는다 | 패링·실드로만 잡히는 적·패턴 금지. 패링은 "잘하면 더 크게" |
| 공격 기회가 보인다 | 보스의 무방비 시간처럼 "지금 때려라"가 읽히는 구간 |
| 협동하면 쉬워진다 | 혼자서도 잡히지만, 역할을 나누면 확실히 편함 (예: 방패 근위병 — 작물이 정면에서 시선, 고양이가 등) |
| 순서 퍼즐은 "다른 사람이 먼저 치기"로 | 반사 버블 = 고양이 먼저 · 수정 실드 = 작물 먼저 |
| 난이도 곡선 | 1스테이지는 근접 약점 위주(고양이 주도) → 갈수록 균등·협동 위주 |
| 방향 약점 | 적마다 각도·배율 (정면 배율 0 = 완전 차단 "BLOCK") |

## 3. 다양성 — "특성을 무시하고 패도 죽는다" (2026-10-22 피드백)

고양이가 세서 대부분의 적이 특성(반사·실드·장판)을 신경 쓰기 전에 죽는다 → 적이 많아도 다양성이 체감되지 않음.

| # | 방향 | 상태 |
|---|---|---|
| 1 | **처치 시간 기준선** — 보통 적 = 할퀴기 5~6대 이상, 큰 적 = 10대 이상. 표 hp × 5 (소환물·보스 × 3) | ✅ 임시 |
| 2 | **적 조합** — 전투방의 70%가 서로 돕는 묶음 + 입장 힌트 ([02_Enemies_Content](02_Enemies_Content.md) 2장) | ✅ |
| 3 | **엘리트 어픽스** — 엘리트에 조합형 특성을 하나 더 (반사 버블·갑옷·분노 등) | 📝 |
| 4 | **무시하면 손해** — 반사 버블·수정 실드·결계처럼 특성을 무시하면 피해가 안 들어가는 적 비율을 늘림 | 📝 |
