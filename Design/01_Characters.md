## 고양이 (Player 1 — 이동 / 근접)

| 이름 | 특징 | 기본 공격 | 대쉬 | 상태 |
|------|------|-----------|------|------|
| 기본 고양이 | 밸런스형 | 180° 할퀴기 | 직선 돌진 | 구현 중 |
| (미정) | | | | 미설계 |
| (미정) | | | | 미설계 |

### 고양이 공통 스탯
- 체력: 미정
- 이동속도: 5 (현재 기본값)
- 대쉬: 쿨다운 0.5초 / 무적 0.2초

## 작물 (Player 2 — 원거리 / 실드)

| 이름 | 원거리 공격 | 실드 특성 | 특수 능력 | 상태 |
|------|------------|-----------|-----------|------|
| 양파 | 투사체 발사 | 방향 실드 + 패링 | 미정 | 구현 중 |
| 당근 | 미정 | 미정 | 미정 | 미설계 |
| 부추 | 미정 | 미정 | 미정 | 미설계 |
| 마늘 | 미정 | 미정 | 미정 | 미설계 |

### 작물 선택 방식
- 런 시작 시 P2가 작물 선택
- 작물마다 능력 세트가 고정 (교체 불가)
- 추후 CropData ScriptableObject로 관리
