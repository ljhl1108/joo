# 캐릭터 — 고양이와 작물

> **두 캐릭터의 규칙과 앞으로 만들 종류.** 지금 들어간 기본기·조작은 [00_Implemented](00_Implemented.md) 2~4장, 장비는 [05_Items](05_Items.md).
> 기준 2026-11-08 · 예시 목록 [Data/cats.csv](Data/cats.csv) · [cat_weapons.csv](Data/cat_weapons.csv) · [crops.csv](Data/crops.csv) · [crop_seeds.csv](Data/crop_seeds.csv) (도감 고양이·작물 탭)

## 0. 철칙

- **작물은 움직이지 않는다.** 이 비대칭이 협동을 만든다
- 기본 역할은 고양이 = 이동·근접, 작물 = 조준·스킬·심기
- 단, **장비·스킬로 상대 영역을 넘나들 수 있다** — 고양이 털뭉치 같은 원거리 지원, 둘이 같이 원거리 빌드로 가는 런도 허용
- 런 시작 시 **고양이 종류 + 작물 종류**를 각자 고른다 (지금은 작물만 — 농장 화분에서)

## 1. 종류를 늘리는 공통 규칙 📝 (2026-10-18)

| | 고양이 | 작물 |
|---|---|---|
| 개체 특성 | 종류마다 1개 (예: 발톱 = 등 공격이면 게이지 ×2, 망치 = 안 밀림 + 대쉬 대신 박치기) | 종류마다 1개 (예: 마늘 = 고양이 주변 적에게 지속 피해, 호박 = 실드 +1) |
| 무기칸 | **그 고양이 전용 무기** (발톱 고양이에겐 발톱만) | **그 작물 전용 씨앗** |
| 무기가 바꾸는 것 | 기본 공격 + **특수 공격** | 기본 탄 + **고유기 R 강화** |
| 자원 | **야성 게이지** → 특수 공격 ✅ | R은 쿨다운 (마법서 Q·W·E와 같음) |
| 공통으로 유지 | 털뭉치 · 대쉬 · 머리·몸·발·장신구 | 마법서 3칸 · 화분 · 실드 · 패시브 |

### 야성 게이지 ✅ (2026-10-20)

- 0~100. 일반 공격이 맞으면 찬다 — 무기마다 한 대에 차는 양이 다름 (느린 무기는 많이)
- 가득 차면 **특수 공격** 1번 (무기에 따라 50씩 2번, 또는 시간 동안 소모)
- 키: **키보드 왼쪽 Ctrl / 패드 Y** · 표시: 화면 왼쪽 위 합동 게이지 아래 주황 막대
- 발톱 무기 5종 구현 — 할퀴기 난무 · 회오리 · 덮치기 · 찢어발기기 · 광란 (`CatSpecial`, `WildGauge`)
- 특성으로 차는 방식이 달라짐 📝 — 마법 = 시간이 지나면 저절로 · 검 = 적 예고 중에 때리면 많이 · 도끼 = 체력이 낮을수록 많이
- 📝 이야기 쪽 아이디어: 어두울수록 빨리 찬다 (뒤 스테이지일수록 고양이가 강해짐)

### 걷어차기 ⏸ (2026-10-21 꺼 둠)

- 특수 공격과 역할이 겹쳐서 뺐다. 코드는 남기고 `GameFeatures.Kick`으로 끔 → 나중에 다시 고려
- 걷어차기에 기대던 장비 10개는 **"특수 공격이 맞으면"**으로 바꿈 (한 번에 적 하나당 1번 발동)
- 키는 F / 패드 LB로 옮겨 둠 (원래 자리는 특수 공격이 씀)

### 전용 장비와 세트 📝

- 보상·상점·바닥 드롭에는 **지금 고른 고양이·작물의 전용 장비만** 나온다
- 전용 무기·씨앗에도 효과 갈아끼우기가 된다 → 세트 효과를 전용 무기에 옮겨 담을 수 있음
- **세트 씨앗도 작물 전용으로** (2026-10-20 결정) — 지금 세트 씨앗 10종을 작물별로 나눠 다시 만든다 (예: 햇살 = 고추의 "태양초 씨앗")

### 해금

- 작물 = 마을 등불을 밝힌 답례 ✅ ([08_RunFlow](08_RunFlow.md) 4장)
- 고양이 = 런 중에 만나기 (물음표 방의 길 잃은 검객 등) 또는 기억 파편 📝 — 표의 "해금" 열

## 2. 고양이 (P1)

### 고양이 종류 = 무기 종류

종류마다 기본 공격(무기)과 기본기가 다르다. 같은 종류 안의 무기끼리는 그림·수치·효과만 다르다.
무기는 캐릭터 위에 겹쳐 그린다 ([05_Items](05_Items.md) 4장) — 고양이 그림에는 무기가 없다.

| ID | 종류 | 기본 공격 | 상태 |
|---|---|---|---|
| CAT1 | **발톱 고양이** | 할퀴기 3연타 (짧고 빠름) | ✅ (그림 ✅) |
| CAT2 | 검 고양이 | 넓은 베기 2타 + 찌르기 | 📝 |
| CAT3 | 마법 고양이 | 마법 구슬 (근거리 탄, 3번째는 작은 폭발) | 📝 |
| CAT4 | 망치 고양이 | 느린 내려찍기 (충격파, 가끔 기절) | 📝 |
| CAT5 | 도끼 고양이 | 크게 휘두르기 + 출혈 | 📝 |
| CAT6 | 활 고양이 | 화살 단발 (멀리) | 📝 |
| CAT7 | 총 고양이 | 짧은 연발 (6발 후 재장전) | 📝 |
| CAT8 | 창 고양이 | 긴 찌르기 (사거리 ×2, 폭 좁음) | 📝 |

그림은 8종 모두 있음 (`Art/Final`). 특성·특수 공격은 표에.

### 발톱 고양이 기본기 — 설계 의도

| 동작 | 역할 | 협동 포인트 |
|---|---|---|
| 할퀴기 | 주 딜. 무기에 따라 형태가 바뀜 (회전·도약·3타·연타) | 작물 탄과 번갈아 맞히면 협동 콤보 |
| 특수 공격 | 게이지를 모아 한 방 | 장비 효과 "특수 공격이 맞으면" |
| 털뭉치 | 원거리 지원 (둔화) | 작물이 바쁠 때 고양이가 원거리를 보탬 |
| 대쉬 | 회피 (충전식 2칸, 세피리아식 탄창 표시) | — |

## 3. 작물 (P2)

### 작물 종류 = 캐릭터

작물마다 **빛 색 · 기본 탄 · 고유기 R(심기 계열)**이 다르다. 빛 색은 마을 퀘스트에 쓰인다 ([07_StoryMeta](07_StoryMeta.md) 1장).
설계 원칙 (Brotato식): 작물마다 **강점과 제약을 함께** — 제약이 P2의 플레이 방식을 이끈다.

| ID | 작물 | 빛 | 기본 탄 | 고유기 R | 상태 |
|---|---|---|---|---|---|
| CR1 | 🧅 양파 | 🔴 | 단발 · 균형 | 매운 양파 — 주변 적의 공격이 늦어짐 | ✅ |
| CR7 | 🌻 해바라기 | 🟡 | 빠른 빛 탄 (×1.5) | 햇빛 기둥 — 고양이 회복 | ✅ |
| CR8 | 🍄 푸른 버섯 | 🔵 | 느린 포자탄 (맞으면 독) | 버섯밭 3개 | ✅ |
| CR2 | 🥕 당근 | | 관통 · 느림 | 당근 포탑 — 가까운 적 자동 사격 | 📝 |
| CR3 | 🧄 마늘 | | 짧은 산탄 | 마늘 울타리 — 막는 벽, 닿으면 넉백 | 📝 |
| CR4 | 🌿 부추 | | 빠른 연사 · 약함 | 캣닢 덤불 — 안의 고양이 공격·이동 속도 증가 | 📝 |
| CR5 | 🌶️ 고추 | 🔴 | 화상탄 | 고추 화단 | 📝 |
| CR6 | 🎃 호박 | 🟡 | 굴러가는 큰 탄 (벽에 튕김) | 호박 굴리기 | 📝 |

그림은 8종 모두 있음. 특성 설명은 `crops.csv`.

### 마법서 스킬 Q·W·E — 4계열

마법서 장비 3칸이 스킬을 정한다. 같은 계열을 모으거나 섞어 빌드를 짠다. 전체 목록은 [05_Items_Content](05_Items_Content.md) 3장.

| 계열 | 역할 | 예 |
|---|---|---|
| 🌱 심기 | 공간 설계 | 터지는 박 ✅ · 가시덩굴 · 반딧불 꽃 |
| 💚 돌봄 (유미식) | 고양이 지원 | 영양제 ✅ · 뿌리 갑옷 · 광합성 |
| 🎯 사격 | 직접 딜 | 씨앗 산탄 ✅ · 충전탄 · 유도 씨앗 |
| 🌀 방해 | 적 약화 | 포자 구름 ✅ · 넝쿨 올가미 · 꽃가루 |

- 식물 규칙 ✅ — 동시에 최대 3개, 방을 나가면 사라짐. 📝 적의 빨간 공격에 파괴됨 → 어디에 심을지가 판단
- 📝 스킬 변형 (가칭 비료) — 예: 터지는 박 + "번식" = 터질 때 작은 박 2개. 마법서의 효과로 넣는 방향

### 작물의 게임성 — "움직이지 않는 대신 하는 일"

| 할 일 | 재미 |
|---|---|
| 조준 (사격·방해) | 직접 손맛, 약점 저격 |
| 심기 | 고양이가 싸울 무대를 만듦 |
| 돌봄 | 유미처럼 고양이를 살리는 판단 |
| 가방 | 공유 가방을 언제 쓸지 |
| 실드 | 노란 공격 막기 (보조) |
| 합동기 호출 | 타이밍을 정하는 지휘자 |

→ 계열을 어떻게 모으느냐에 따라 같은 양파라도 전략가 / 딜러 / 서포터로 달라진다.

## 4. 조작 설계

구현된 키 배치는 [00_Implemented](00_Implemented.md) 4장.

- 기본: **고양이 = 패드, 작물 = 마우스** (유미식 조준 + Q W E R). 패드가 없으면 한 키보드를 나눠 쓰는 키보드 모드
- 조작이 많아 보여도 처음엔 기본 동작만, 런이 진행되며 칸이 채워진다 (하데스·Shape of Dreams와 같은 학습 곡선)
- 📝 패드로 작물 (Shape of Dreams식) — 가장 가까운 적 자동 조준, 오른스틱으로 수동. 심기 위치는 "가장 가까운 적 발밑"
- 📝 쉬움 난이도 — 조준 보정 강화, 쿨다운 끝난 스킬 자동 시전 ([GameConcept](../GameConcept.md) 역할별 난이도)
