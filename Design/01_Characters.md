# 플레이어 캐릭터

---

## 고양이 (Player 1 — 이동 / 근접)

| 이름 | 특징 | 기본 공격 | 대쉬 | 상태 |
|------|------|-----------|------|------|
| 기본 고양이 | 밸런스형 | 180° 할퀴기 | 직선 돌진 | 구현 중 |
| 호랑이 | 미정 (공격형 추정) | 미정 | 미정 | 설계 중 |
| (미정) | | | | 미설계 |

### 고양이 공통 스탯
- 체력: 미정
- 이동속도: 5 (현재 기본값)
- 대쉬: 쿨다운 0.5초 / 무적 0.2초

---

## 작물 (Player 2 — 원거리 / 실드)

| 이름 | 원거리 공격 | 실드 특성 | 특수 능력 | 상태 |
|------|------------|-----------|-----------|------|
| 양파 | 투사체 발사 | 방향 실드 + 패링 | 미정 | 구현 중 |
| 당근 | 클릭 유지 시 소형 파편 연사 (0.08초 간격) | 없음 | 땅굴: 0.5초간 화분 수축 → 원거리 불가 + 고양이 이동속도 +50% | 설계 중 |
| 마늘 | 전방 3방향 동시 산탄 | CropHolder 주변 원형 오라 (범위 내 적 이동속도 -30%, 약한 투사체 자동 소각) | 없음 | 설계 중 |
| 부추 | 미정 | 미정 | 미정 | 미설계 |

### 작물 선택 방식
- 런 시작 시 P2가 작물 선택
- 작물마다 능력 세트가 고정 (교체 불가)
- 추후 CropData ScriptableObject로 관리

### 작물 설계 원칙 — 제약 기반 (Brotato 참고)
- 각 작물은 **제약과 강점을 동시에** 가짐
- 제약이 P2 플레이 스타일을 자연스럽게 유도
- 예: 마늘 = 방향 실드 없음 → 고양이에 더 의존 / 당근 = 땅굴 중 원거리 불가 → 타이밍 판단 필요
